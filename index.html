Информатикаға кіріспе қазақ тілінде

Әлемдегі ең танымал бағдарламалау курсы енді ана тілімізде. Әр лекцияның толық аудармасы мен түсіндірмесі бар, курстағы тапсырмаларды да осында орындап, тексере аласыз.

Толық аударма

2

Тест пен жаттығу

Әр лекциядан кейін өзіңізді тексеретін сұрақтар мен жаттығулар бар.

3

Тапсырмалар

Курстың ресми тапсырмалары кеңестерімен және тексеру тізімімен берілген.

Аударылды
0-апта

Scratch

Информатика деген не, ақпаратты екілік жүйемен беру, алгоритмдер, Scratch-та алғашқы бағдарлама.

Дайын ✓
1-апта

C тілі

Бастапқы код және машиналық код, айнымалылар, шарттар, циклдер, компиляция.

Дайын ✓
2-апта

Массивтер

Компиляция қалай жұмыс істейді, жөндеу (debugging), массивтер, жолдар, командалық жол аргументтері.

Дайын ✓
3-апта

Алгоритмдер

Іздеу және сұрыптау алгоритмдері, жұмыс уақыты (Big O), рекурсия.

Дайын ✓
4-апта

Жад

Көрсеткіштер (pointers), он алтылық жүйе, жадты бөлу, файлдармен жұмыс.

Дайын ✓
5-апта

Деректер құрылымдары

Тізімдер, ағаштар, хэш-кестелер, префикстік ағаштар (trie), стек және кезек.

Дайын ✓
6-апта

Python

C тілінен Python тіліне көшу, кітапханалар, сөздіктер, ерекше жағдайларды өңдеу.

Дайын ✓
7-апта

SQL

Деректер базасы, кестелер, сұраныстар, реляциялық модель, SQL инъекциясы.

Дайын ✓
Арнайы лекция

Жасанды интеллект

Генеративті AI, промпттар, минимакс, машиналық оқыту, нейрондық желілер, үлкен тілдік модельдер.

Дайын ✓
8-апта

HTML, CSS, JavaScript

Интернет қалай жұмыс істейді, веб-беттің құрылымы, стильдер және интерактивтілік.

Дайын ✓
9-апта

Flask

Python-мен веб-қосымша жасау, маршруттар, шаблондар, сессиялар.

Дайын ✓
10-апта

Соңы
