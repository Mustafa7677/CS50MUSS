Дайын ✓

Дайын ✓
2-апта

Массивтер

Дайын ✓
3-апта

Алгоритмдер

Дайын ✓

Жад

Дайын ✓

Деректер құрылымдары

Дайын ✓
6-апта

Python

HTML, CSS, JavaScript
