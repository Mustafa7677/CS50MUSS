Flask зертханасы 🧪

Нағыз Flask, нағыз Jinja, нағыз сессиялар, бірақ серверсіз: бәрі браузеріңіздің ішінде, Python (Pyodide) арқылы жұмыс істейді. app.py мен шаблондарды жазып, «▶ flask run» басыңыз. Оң жақта сіздің сайтыңыз, төменде терминалдағы сервер логы.

1Мысалды таңдаңыз не өзіңіз жазыңыз
2«▶ flask run» - сервер іске қосылады
3Сілтемелер мен формалар нағыз сұраулар жібереді
4Кодты өзгертсеңіз, сервер өзі қайта жүктеледі

Тапсырмалар

Әр тапсырманы «Зертханада бастау» арқылы ашып, кодты жазыңыз да «Тексеру» басыңыз. Тексеруші қосымшаңызға нағыз HTTP сұраулар жіберіп (GET, POST, cookie, redirect), жауаптарды тексереді: check50 сияқты. Әр тапсырманың коды бөлек сақталады.

Бұл қалай жұмыс істейді?

Pyodide - браузерге WebAssembly арқылы көшірілген CPython. Біз оған Flask, Werkzeug, Jinja2 пакеттерін жүктеп, қосымшаңызды Flask-тың сынақ клиенті (app.test_client()) арқылы шақырамыз. «Браузердегі» әр сілтеме мен форма Python-ға нағыз HTTP сұрауы ретінде жетеді. Нәтиже нағыз серверден еш айырмашылығы жоқ, тек желіге шықпайды. from cs50 import SQL мен flask_session да жұмыс істейді.
