# QazaqCode: қауіпсіздік моделі және күйі

## Қазір орындалған (сыналған)

| Талап | Қалай | Тест |
|---|---|---|
| Серверде құқық тексеру | барлық жазу SECURITY DEFINER функцияларында; клиент рөлі кестеге жаза алмайды | `db/tests/security.test.mjs` |
| Row Level Security | барлық кестеде, `authenticated` тек SELECT | сол тест |
| Ұйымдар оқшаулауы (A -> B) | RLS + функция тексерістері | 16 тестің ішінде `МЕКТЕП A ... МЕКТЕП B` |
| SUPER ADMIN жеке деректі көрмейді | RLS-те платформа әкімшісіне оқушы деректері жоқ; тек `platform_usage()` | тест |
| Жасырын жауап/тест жағдайлары | бөлек кесте + RLS | тест |
| Шақыру токені | кездейсоқ 24 байт, тек SHA-256 хэші сақталады, мерзім, бір реттік, e-mail байлау | тест |
| Auth cookie | httpOnly, SameSite=Lax, Secure (өндіріс), JWT қолы мен мерзімі тексеріледі | e2e |
| Rate limiting | кіру, тіркелу, сыныпқа қосылу, шақыру (жадта) | e2e |
| Валидация | zod + дерекқор CHECK-тері | тесттер |
| Тақырыптар | HSTS, X-Frame-Options, nosniff, Referrer-Policy, Permissions-Policy | `next.config.mjs` |
| Құпиялар | `.env` ғитке жарияланбайды; service-role кілті қолданылмайды | `.gitignore` |
| Аудит | лицензия/мүшелік/баға/ұйым/тапсырма/сынып | тест |

## Әлі орындалмаған / тәуекелдер

- Supabase Auth драйвері нақты жобаға қарсы сыналмаған.
- CSP (Content-Security-Policy) әлі жоқ (Next.js inline стильдері; nonce негізінде қосу керек).
- Rate limiting көп данада жұмыс істемейді (Redis/WAF керек).
- Файл жүктеу (`file` түрі) қауіпсіз сақтауы жоқ: қазір файл жүктелмейді, тек мәтін/код. Жүктеу қосылса: тип/өлшем/вирус тексеруі, жеке bucket.
- Sandbox жоқ (SANDBOX.md); код сервер жағында орындалмайды.
- Тәуелсіз пентест өткізілмеген.
