# Екі тілділік (kk негізгі, ru қосымша)

Күйі: **ru - бета** (тіл ауыстырғышта «бета» белгісі; `I18N_BETA` in `src/lib/i18n/core.ts`). Ауыр кітапхана жоқ: өз шағын шешім.

## Қалай жұмыс істейді

- **Кілт = қазақша бастапқы мәтін.** Кодта `t("Сақтау")`; kk режимі мәтінді өзгертпей қайтарады (байт-байт бұрынғыдай), ru - `src/lib/i18n/ru/*.ts` каталогынан. Каталогта жоқ кілт -> қазақша мәтін (жалпы fallback), сондықтан аударылмаған жер сынбайды.
- Тілді анықтау (`getLocale`, `src/lib/i18n/index.ts`): cookie `qc_lang` (тек whitelist `kk|ru`) -> кірген қолданушының `profiles.locale` -> `Accept-Language` (ең жоғары басымды тіл ru болса ғана) -> `kk`.
- **Сервер**: `const t = await getT();` (`t.locale` - ағымдағы тіл). **Клиент**: `const t = useT();` (`"@/lib/i18n/client"`, провайдер `layout.tsx`-те; ru болса ғана каталог клиентке беріледі).
- Параметрлер: `t("Сәлем, {name}!", { name })`. Көптік (kk-те көптік жоқ, ru: 1 / 2-4 / 5+): ru мәні `"{n, plural, one {# ученик} few {# ученика} many {# учеников}}"`, kk кілті `"{n} оқушы"`.
- Күн/сан: `fmtDate(d, withTime, t.locale)`, `fmtNum(n, t.locale)`, `fmtDuration(s, t.locale)` (`src/lib/format.ts` -> `src/lib/i18n/format.ts`), уақыт белдеуі Asia/Almaty. Белгі кестелері (`STATUS_LABEL`, `KIND_LABEL`...) кілттерді `N("...")` арқылы белгілейді; көрсеткенде `t(STATUS_LABEL[x] ?? x)`.
- Модуль деңгейіндегі тұрақтылар аударма үшін функция: `const NAV = (t: TFn) => [...]`; экспортталатындар `N("...")` + көрсету кезінде `t(...)`.
- Қате хабарлары: `src/lib/errors.ts` (кілт = қазақша мәтін). Серверлік әрекет қазақша мәтін қайтарады, `ActionForm`/`Toaster`/`Banner` көрсеткенде `t(...)` аударады.
- Тіл ауыстыру: `LangSwitch` (server action `setLangAction`: cookie + `profiles.locale`, `revalidatePath`). Кіргенде `syncLanguage` (cookie бар -> профильге, жоқ -> профильден cookie).
- `<html lang>` динамикалық (`layout.tsx`), `generateMetadata` аударылады.

## Жаңа жол қосу

1. Кодта `t("...")` жазыңыз (JSX мәтін, атрибут, action хабарлама). Дайын құрал: `node scripts/i18n-wrap.cjs <файл...>` қалған қазақша жолдарды автоматты `t()`-ке орайды (кейін `npx tsc --noEmit` көрсеткен `t` жетпейтін жерлерді қолмен түзетіңіз).
2. `node scripts/i18n-sync.mjs` - `kk.ts` жаңарту және аударылмаған кілт санын көру.
3. `node scripts/i18n-sync.mjs --todo /tmp/todo.txt` - ru-да жоқ кілттер (`id<TAB>кілт<TAB>файл`).
4. `id<TAB>аударма` жолдарын файлға жазып: `node scripts/i18n-sync.mjs --merge /tmp/todo.txt /tmp/part.txt <бөлім>` -> `src/lib/i18n/ru/<бөлім>.ts`; жаңа бөлімді `ru.ts`-ке қосыңыз.
5. `node scripts/i18n-sync.mjs --check` және `npm run test:unit` (кілт-паритет, плейсхолдер, көптік, формат).

## Жаңа тіл қосу (мысалы `en`)

1. `core.ts`: `LOCALES`, `pluralCategory`; `format.ts`: `MONTHS`; `profiles.locale` check-те `en` бар.
2. `src/lib/i18n/en/*.ts` + `index.ts` `CATALOGS`; `LangSwitch` батырмасы; `localeFromAcceptLanguage`.
3. Паритет тесті барлық тілге ортақ болуы үшін `tests/unit/i18n.test.mjs`-ті кеңейтіңіз.

## Глоссарий kk <-> ru

| kk | ru |
|---|---|
| сынып | класс |
| мұғалім | учитель |
| оқушы | ученик |
| тапсырма | задание |
| жұмыс (оқушының) | работа |
| баға / балл | оценка / балл |
| пікір | отзыв |
| сабақ / модуль / курс | урок / модуль / курс |
| мектеп әкімшісі | администратор школы |
| платформа әкімшісі (SUPER ADMIN) | администратор платформы |
| ұйым | организация |
| лицензия, пакет, лимит | лицензия, тариф, лимит |
| шақыру | приглашение |
| қосылу коды | код присоединения |
| көмекші | помощник |
| жоба (draft) / жоба (project) | черновик / проект |
| жариялау / мұрағат | опубликовать / архив |
| хабарландыру | уведомление |
| тексеру кезегі | очередь проверки |
| шот / тапсырыс | счёт / заказ |
| ҚҚС, БИН/ЖСН, ИИК | НДС, БИН/ИИН, ИИК |
| мерзім | срок |

Тон: оқушыға арналған беттерде kk «сен» -> ru «ты», ресми жерде «сіз» -> «вы».

## Ескертулер

- Деректер (демо аттары, ұйымдар жазған мәтін, DB хабарландырулары, курс мазмұны) аударылмайды.
- Excel/PDF есептер (`src/lib/reports`) пен e-mail шаблондары қазақша; олар үшін `locale` параметрі бөлек жұмыс.
- Тесттер: `tests/unit/i18n.test.mjs`, `e2e/i18n.spec.ts`.
