# QazaqCode Platform: инвестициялық дайындық (шынайы жағдай)

Бұл құжат инвесторға, серіктеске не заңгерге көрсету үшін. Мұнда **ойдан шығарылған сан, клиент, пікір немесе нарық көлемі жоқ**. 10 000 000 ₸ - коммерциялық мақсат, дәлелденген құн емес. Сатып алу не инвестиция шешімін қабылдауға ешқандай кепілдік емес.

## 1. Қысқаша: қай сатыдамыз

| Көрсеткіш | Күйі |
|---|---|
| Сатысы | **Пилотқа дейінгі** өнім прототипі (MVP-ден асқан, бірақ нақты мектепте сыналмаған) |
| Нақты пайдаланушылар | **Жоқ** (демо дерек пен тесттерден басқа) |
| Табыс | **Жоқ** |
| Төленген клиент / шарт | **Жоқ** |
| Нарықты растау | **Жүргізілмеген** (бұл құжатта нарық көлемі жоқ: расталған дереккөзсіз келтірмейміз) |
| Команда | 1 негізін қалаушы (Sagid Mustafa); код пен тесттердің көп бөлігі ИИ-ассистентпен жасалған (қараңыз §6) |

Инвестор сұрайтын нәрсе - **тартылым (traction)**. Қазір оны көрсетуге болмайды. Төмендегі жол картасы оны қалай алуға болатынын көрсетеді.

## 2. Бар және тексерілген нәрсе (фактілер)

Саны `git` және тесттер бойынша, 2026-10 күйі:

- **Өнім:** көп ұйымды (multi-tenant) платформа: SUPER ADMIN, мектеп әкімшісі, мұғалім, оқушы; сыныптар, 7 түрлі тапсырма, автоматты тест бағалау, курс конструкторы, оқушы кабинеті, хабарландыру, аналитика, Excel/PDF есеп, лицензия (STARTER/PRO/ENTERPRISE), white-label, демо режим, көмекші-кеңесші.
- **Код:** ≈8 800 жол TypeScript/TSX (`src/`), ≈1 900 жол SQL (10 миграция), ≈4 250 жол тест коды.
- **Тесттер:** 118 E2E (Playwright; 7-і rate limit қосулы екінші серверді қажет етеді), 73 дерекқор, 72 unit. Соңғы жергілікті жүгіруде өткен.
- **Қауіпсіздік:** деректер оқшаулауы дерекқор деңгейінде (RLS), барлық жазу серверлік функциялар арқылы, аудит журналы. 20 мәселе табылып түзетілген аудит: [SECURITY-AUDIT.md](SECURITY-AUDIT.md). Тәуелсіз пентест **жүргізілмеген**.
- **Құжаттар:** [ARCHITECTURE.md](ARCHITECTURE.md), [DEPLOY.md](DEPLOY.md), [SECURITY.md](SECURITY.md), [WHITE-LABEL.md](WHITE-LABEL.md), [COMMERCIAL.md](COMMERCIAL.md), [AI-TUTOR.md](AI-TUTOR.md).
- **Лицензиялық тазалық:** Harvard CS50 материалы өнімге кірмейді (`scripts/check-licence.mjs` CI-да тексереді); Harvard және өз материалдарының бөлінісі түбіндегі `COPYRIGHT.md`-де.

## 3. Бар, бірақ сыналмаған / жасалмаған

| Дербес деректер заңы (ҚР) | Заңгер консультациясы керек: деректерді сақтау орны, кәмелетсіздер, келісім, өшіру/экспорт интерфейсі |
| Төлем, шот-фактура | Жасалмаған (лицензияны қолмен береміз) |
| Қолдау процесі, SLA | Жоқ |

## 4. Бизнес-модель (гипотеза: пилотта тексеріледі)

- **Кім төлейді:** мектеп/колледж/IT академия (жылдық лицензия). Оқушы төлемейді.
- **Лицензия:** STARTER 100 оқушы / 5 мұғалім, PRO 500 / 25, ENTERPRISE келісім бойынша (лимиттер өнімде жүзеге асқан).
- **Баға:** **белгіленбеген**. Нарықтық дәлел жоқ. Пилоттан кейін шығынмен (хостинг, қолдау, оқыту сағаттары) және мектептің төлеуге дайындығымен есептеледі.
- **Негізгі гипотезалар (тексерілмеген):**
  1. Мұғалім тест тексеруге кететін уақытты азайтады.
  2. Мектеп әкімшісі нақты аналитика мен есепке ақша төлейді.
  3. Қазақ тіліндегі бағдарламалау оқу жүйесіне сұраныс бар және мектеп оны қолданады.
  4. Лицензияны сатуға болатын кіріс арнасы бар (мектептер, колледждер, академиялар, ресми тендер/келісім).

## 6. Негізгі тәуекелдер (ашық)

1. **Тартылым жоқ.** Нақты пайдаланушы мен табыс жоқ; барлық бизнес-гипотеза тексерілмеген.
2. **Авторлық құқық мәртебесі.** Репозиторийдің барлық коммиттері «Claude» ассистентінің атынан; код пен контенттің көп бөлігін ИИ жасаған. Мұндай материалдың охрана және иелік мәртебесін заңгер анықтауы керек (`licensing/LEGAL-REVIEW.md` §1). Бұл инвестор мен сатып алушының ең алдымен тексеретін мәселесі болуы мүмкін.
3. **Бір адамға тәуелділік.** Команда, қолдау, сату бір адамда.
4. **Деректер заңы мен кәмелетсіздер.** Мектеп оқушыларының деректері: заңдық талаптар өнімді шектеуі мүмкін.
5. **Коммерциялық код ашық репода.** Сатуға дейін жеке репозиторийге көшіру керек (`git subtree split -P qazaqcode`).
6. **Нарық.** Қазақстан мектептері үшін сатып алу тәртібі (тендер, мемлекеттік бағдарламалар) және бәсекелестер зерттелмеген.
7. **Harvard CS50 атауы.** Атауды қолдану заңгер тексеруін қажет етеді; платформа Harvard материалдарын қамтымайды.

## 8. Қаражат бөлу (егер қаржылай қолдау болса: категориялар, сома емес)

Сандарсыз, себебі шығын мен баға расталмаған. Басымдық тәртібімен:

1. Заңгерлік жұмыс (дербес деректер, авторлық құқық, шарттар).
2. Тәуелсіз қауіпсіздік шолуы (пентест) және инфрақұрылым.
3. Пилоттарды жүргізу және мектептерді оқыту (қолдау сағаттары).
4. Серверге код орындау ортасы (sandbox): тек шолудан кейін.
5. Сату және серіктестік.

## 9. Қолданылған сандар қайдан алынды

Барлық санды қайта тексеруге болады: `find src -name '*.ts*' | xargs cat | wc -l`, `npm run test:db`, `npm run test:unit`, `npx playwright test`, `git log`. Нақты мәндер өзгеруі мүмкін.
