# AO17: кинематографиялық қозғалыс жүйесі

Бұл құжат сайттағы барлық анимацияның аудиті, басты беттің сценарийі (storyboard) мен уақыт сызығы, академиялардың визуалды жүйесі және техникалық шешімдер.

## 1. Басты қағида: скролл - тек триггер

- 1-сахна бет ашылғанда скроллсыз өзі басталады. Негізгі кадр біткен соң сахнада жеңіл фондық қозғалыс (ambient) қалады: бұлт, шөп, қыран, Бота тынысы.
- Әр келесі сахна экранға кіргенде **бір рет** іске қосылады (`.is-on`) және **өзі соңына дейін** ойналады. Скроллдың орны анимацияның прогресін басқармайды.
- Кері скролл не қайта кіру сахнаны қайта бастамайды.
- Экраннан тыс сахнаның фондық қозғалысы тоқтайды (`.is-vis` жоқ болса `animation-play-state: paused`).

Іске асыру: `assets/js/main.js` → `initStory()` (IntersectionObserver: `.is-on` бір рет, `.is-vis` экранда тұрғанда), CSS keyframes (`assets/css/style.css`, «БАСТЫ БЕТ: бес сахналы фильм» және «Бота - бүкіл фильмнің кейіпкері» бөлімдері).

### Неге GSAP емес

- Сайт GitHub Pages-те статикалық, PWA ретінде офлайн жұмыс істейді; сыртқы CDN қолданылмайды (KaTeX та жергілікті көшірме).
- Барлық сахна «бір рет іске қосу + өзі ойнау» логикасында: бұл IntersectionObserver + CSS keyframes-пен толық шешіледі (GSAP ScrollTrigger `onEnter` баламасы). Қосымша ~70 КБ кітапхана, жүктеу және лицензия реестріне жаңа компонент қажет емес.
- CSS анимациясы браузердің композиторында орындалады (тек `transform`, `opacity`, `stroke-dashoffset`), негізгі ағынды бөгемейді.
- Болашақта күрделі уақыт сызығы (бір сахнада ондаған тәуелді кадр) қажет болса, GSAP-ты жергілікті `assets/vendor/` ішіне қосып, тек басты бетте жүктеуге болады.

Қақпаны басу → портал: карточка экранға жайылып, академия әлеміне айналады (код таңбалары / әріптер / геометрия), сосын бет ауысады.

### Scene 04 - Programming Universe
код жолдары өзі жазылады → әр жол браузерде нақты интерфейс элементіне айналады (match-cut: тег → компонент) → панельдер кеңістіктен орнына келеді (3D тереңдік) → жеті курс бірінен соң бірі → Бота сайт біткенде қуанады.

### Scene 05 - English Universe
кітаптың мұқабасы ашылады → парақтар аударылады → сөздер кеңістікке ұшып шығады, дыбыс толқыны → кітап парағынан сабақ интерфейсі көтеріледі (match-cut: парақ → сабақ картасы) → A0-C1 баспалдақтары → Бота «Hello!».

### Scene 06 - Mathematics Universe
осьтер → `x² + y² = r²` формуласы ауада → шеңберге айналады → экватор мен меридиан қосылып **3D сфера** → нүктелер → график → шаршы → куб, үшбұрыш → пирамида → 25 пәннің картасы → Бота формуланы түсіндіреді.

### Scene 07 - Сенің саяхатың
үш академияның жолы (көк, қызғылт, алтын) оқушының нақты прогресімен толады → бір алтын жолға тоғысады → шаңырақ пайда болады → Бота жаңа сапарға шақырады; батырма ең алға кеткен академияға «Жалғастыру» деп апарады (прогресс жоқ болса - «Саяхатты бастау»).

## 3a. Мобильді кадр

- Телефонда (≤759px) 1-сахнаның суреті бүкіл секцияның биіктігіне емес, мәтіннің астындағы «сахнаға» сыяды: биіктігі `clamp(380px, 112vw, 540px)`, сондықтан SVG 1600 бірліктің ~800-ін көрсетеді (бұрын ~400). Күн мен Бота сол терезеге орналасады, Бота үлкейеді.
- Ботаның сөз бұлты - SVG емес, жеке HTML (`.st-say`, main.js `initSay`): орны Ботаның көлеңкесінен есептеледі, экран ішіне қысылады, мәтін жолға бөлінеді, Бота жүрсе не экран бұрылса (ResizeObserver, orientationchange) қайта есептеледі.
- Тест: `universe.spec.js` 320, 360, 375, 390, 414, 768, 1280 px енде бұлт пен Бота экран ішінде, көлденең жылжу жоқ.

## 5. Өнімділік және қолжетімділік

- Анимацияланатын қасиеттер: `transform`, `opacity`, `stroke-dashoffset`, `clip-path` (композитор).
- Экраннан тыс сахналардың анимациясы тоқтайды; әр сахна бір рет қана басталады.
- `prefers-reduced-motion` не «Аа → Қозғалысты азайту»: `.st-js`, `.fm-anim`, `.mx-anim` қосылмайды, бәрі бірден соңғы күйінде.
- Кіріспені өткізуге болады (батырма, скролл, басу, перне).
- Барлық сахналық графика `aria-hidden`; мазмұн, сілтемелер мен фокус анимациядан тәуелсіз, анимация кезінде де басылады.
- Сабақ беттерінде мультфильм жоқ; компас тек бұрышта, оқуды жаппайды.
- Тексеру: `tests/e2e/academies.spec.js` (сахналар, қозғалыс азайтылған күй), `tests/e2e/universe.spec.js` (портал, алтын жіп, компас, шоқжұлдыз), `tests/e2e/mobile-audit.spec.js` (6 экран өлшемі), `tests/e2e/a11y.spec.js` (WCAG 2 AA, барлық беттер).

## 6. «АЛАШ 1917»: тарихи кинематографиялық қабат

Әр қозғалыстың мағынасы бар: газет → код, Алаш ағартушылығы → бүгінгі білім, 1917 → болашақ. Түстер: көне қағаз, сия, қола, терең қара. Көне сайт емес, заманауи сән.

### Кіріспе (`index.html` → `.ax17`, сессияда бір рет)

| Уақыт | Не болады |
|---|---|
| 0-0.4 с | Қараңғы, қағаз текстурасы (feTurbulence) шығады |
| 0.4-1.6 с | «1917» сиямен жазылады (SVG мәтін сызығы, кейін құйылады, сия жайылады) |
| 1.9-2.6 с | «АЛАШ» жазылады, астында сызық және жол: «Алаш бастаған білім жолы бүгінгі технологиямен жалғасады» |
| 2.5-3.6 с | Камера жақындайды, сөздерден ою сызылады, ою бұрылып шаңыраққа айналады |
| 3.55-4.0 с | Қола шаңырақ: шеңбер, күлдіреуіш, 24 уық |
| 4.1-5.05 с | Шаңырақтың ортасынан жарық ашылады (`@property --ax-r` радиалды маска), астынан басты бет көрінеді |

«Өткізу» батырмасы, басу, перне, скролл не жанасу кіріспені бірден ашады. Қозғалыс азайтылса не JS жоқ болса кіріспе мүлде жоқ.

### Академияға өту (`a[data-portal]`, `playPassage` in `main.js`)

- **Бағдарламалау:** 1917 жылғы «ҚАЗАҚ» газетінің беті; әріптер код белгілеріне ауысады, тақырып `<AO17 />` болады, камера бет арқылы өтеді.
- **Ағылшын:** көне хат беттері парақталады, қазақша сөздер ағылшынға ауысады («Құрметті оқушы,» → «Dear reader,»), сөздер камераның жанынан ұшып өтеді.
- **Математика:** шаңырақ уықтары түзуге айналып, координата осі мен формулаларды құрайды.

Тігісті өту: шығатын бет «пластинамен» аяқталады, келетін бет алғашқы кадрда дәл сол пластинаны (`html.tx-in body::before`) көрсетіп, оны ерітеді. Артқа қайтқанда өту кері ойнайды (bfcache: `reversePassage`, әйтпесе `tx-back` + WAAPI). Өту кезінде басу не перне бірден өткізеді.

### Сабақ пен сабақ арасы

Cross-document View Transitions: келесі сабақ оңнан, алдыңғысы солдан камера қозғалысымен келеді (`fwd`/`back` түрлері). Күнделікті навигация жарты секундтан аспайды (~0.46 с), кіріспе мен пластина жоқ.

### Шектеулер

Тек `transform`, `opacity`, `clip-path`, маска: 60 FPS, мобильдіде де. Сыртқы кітапхана жоқ. PT Serif өз серверімізде (OFL), офлайнда жұмыс істейді.

## 7. Бүкіл сайттың жүйесі (Дизайн 5.0)

Тақырыптар PT Serif баспа әрпімен жазылады, логотип Unbounded-та қалады. Әр академияның өз мінезі бар: `html[data-ac]` бет жолынан анықталады.

- **`code`:** газет бағаналары, курс реңі.
- **`en`:** хат жолдары, шие түсі.
- **`math`:** уық торы (координата), қола.
- **`core`:** басты бет пен ақпарат беттері.

Әр бет сайт картасында орны бар сахна. `routeOf(url)` беттің деңгейін, тобын, академиясын және ретін береді. `routeKind(from, to)` өту түрін екі беттің орнынан шығарады, сондықтан «артқа» батырмасы өздігінен кері қозғалыс береді.

| Түрі | Қашан | Қозғалыс | Ұзақтығы |
|---|---|---|---|
| `iris` | басты беттен | шаңырақ ортасынан жарық ашылады | 0.78 с |
| `home` | басты бетке | кадр шаңыраққа жиналады, дала жарқырайды | 0.6-0.7 с |
| `dive` | тереңге (академия → курс → сабақ) | басылған карточка жаңа беттің тақырып блогына айналады (`ao-hero`, `ao-title`), камера алға жылжиды | 0.52-0.58 с |
| `rise` | жоғары не артқа | тақырып карточкаға оралады, камера шегінеді | 0.52 с |
| `page-f` / `page-b` | бір курста сабақтан сабаққа | кітап парағы ауысады; мазмұн тізімі, оқу жолағы мен шапка орнында қалады | 0.46 с |

Барлық өту View Transitions (cross-document) арқылы жүреді: Chrome, Edge, Samsung Internet, Safari 18.2+. Firefox-та ақ жарқыл болмайды: мазмұн 0.34 с ішінде қағаздан шығады (`.no-vt`). Келесі бет меңзер сілтемеде тұрғанда алдын ала жүктеледі. Бұл тек `prefetch`: бет орындалмайды, санақ жіберілмейді.

### LEVEL C: микро-интеракциялар

| Элемент | Қозғалыс |
|---|---|
| Батырма, чип, таб, жауап нұсқасы | басқанда 70 мс-та батады (`scale .965`), жібергенде серіппемен қайтады (`--e-spring`) |
| Карточка | меңзерде не пернетақта фокусында 3 px көтеріледі, қола жиек |
| Фокус | қола контур, сақина орнына жиырылады |
| Курс мәзірі, баптаулар, іздеу, `dialog` | шыққан жерінен ашылады, фоны жұмсақ күңгірттенеді |
| Тест: дұрыс жауап | мөрдей басылады (`c-stamp`) |
| Тест: қате жауап | басын шайқайды (`c-shake`) |
| Тест: нәтиже | әр тексерген сайын қайта шығады |
| Форма | қате енгізгенде жиек шиеге айналып шайқалады (`:user-invalid`); фокуста қола жарық |
| Прогресс жолақтары | мәні өзгергенде сиядай ағады |
| Тақырып блоктары | меңзерге қарай белгі мен сахна әр түрлі тереңдікте ығысады (тек тышқан) |

Батырманы басу физикасы жеке `scale` мен `translate` қасиеттерімен жазылған. Компоненттің өз `transform`-ы бұзылмайды.

### Шектеулер мен кепілдер

- Тек `transform`, `opacity`, `clip-path`, `filter` және маска қолданылады; layout анимацияланбайды.
- `prefers-reduced-motion` не сайттағы «Анимация» баптауы қосылса, бетаралық өту өткізіледі (`skipTransition`), микро-қозғалыс пен параллакс өшеді.
- Сілтемелер нақты `<a href>` күйінде қалады: Back/Forward, тікелей URL, жаңарту, якорьлер мен скролл орны браузердің өзінде.
- Прогресс, тест нәтижесі мен жазылған код `localStorage`-та, өту оларға тимейді.
- Тесттер:
  - `tests/e2e/motion.spec.js`: маршрут грамматикасы, нақты беттер арасындағы өту, қозғалыс азайту, мұрағат құжаты, микро-интеракциялар, токендер;
  - `tests/e2e/a11y.spec.js`: барлық бетте axe, жарық және қараңғы режим.

### Екінші кезең

- **Навигациялық жол** (`initCrumbs`): «AO17 › академия › курс › сабақ». Ол сайт картасынан (`routeOf`) құрылады, ағымдағы бет `aria-current="page"` болып белгіленеді. Беттер арасында бір элемент ретінде жылжиды (`ao-crumbs`) және тақырып, оқу жолағы, мазмұн тізімімен бірге қозғалады.
- **Академияға келу** (`assembleArrival`): басты беттен өткен соң интерфейс академияның мінезімен құрастырылады.
  - code: тақырып пен мәтін баспа әрпі терілгендей ашылады (`steps`), тіл белгілері орбитаға ұшып келеді;
  - en: мәтін жарықтан әріпке айналады;
  - math: блоктар сызықтан жазықтыққа жайылып, оське жиналады.
- **Тізім ауысуы** (`initListMotion`): сүзгі, таб, іздеу өзгергенде сол тізімнің көрінетін элементтері 22 мс кезекпен орнына түседі. Мысалы, ойындар каталогы, сөздік, курс сүзгілері.
- **Іздеу**: нәтижелер кезекпен шығады.
- **Фокус** (`initKeyboardArrival`): сілтемені пернетақтамен ашқан адамның фокусы жаңа беттің тақырыбына қойылады.
- **Жеңіл режим** (`html.lite`): трафик үнемдеу қосулы болса, 2 ГБ-тан аз жады не 2 ядролы құрылғыда іске қосылады.
  - қағаз түйіршігі, параллакс және фон бұлдырлығы өшеді;
  - бетаралық өту 0.24 с қарапайым сияға айналады.
- **Алаш мұрағаты**: карточка экранға кіргенде портрет сепиядан айқындалады, есім сиямен басылады.
- **Ою**: футердің үстінде бір қола мүйіз өрнегі бар.

### Әлі жасалмағаны

- Firefox-та бетаралық сахна жоқ, тек жұмсақ шығу бар (браузерде API жоқ).
- Ойын алаңдарының ішкі анимациялары өз күйінде қалды, ойын механикасы бұзылмасын деп. Ойын тақтасында батырма басу әсері де өшірулі: жылдам басуға кедергі болмасын.
- Бота мультфильм сахналары жаңа палитраға боялды, бірақ сурет стилі өзгермеді.

Бейненің өзі тарихи: жарық пен көлеңке, сия, қола, баспа әрпі. Кейіпкер (Бота) сахналардан алынып, орнына AO17 мөрі (`assets/img/seal.svg`) келді.

### Сахнадан сахнаға

- **Академия ауысуы мен құралдар арасы:** ескі кадр сияға батады (сұр, контраст, қараю). Жаңа кадр басылған нүктеден органикалық сия дағы болып жайылады. Бұл анимацияланатын `--ms` маскасы (`@property`).
- **Курс:** карточка кітап мұқабасындай ашылып (`rotateY`), жаңа беттің тақырыбына айналады.
- **Сабақ, Алаш мұрағаты, басты бет, академия өтулері:** бұрынғыдай (7-бөлім).

### Тест пен ойын

- Дұрыс жауапқа қола мөр басылады («✓»), қате жауап сиямен сызылады.
- Толық нәтиже «Қабылданды» мөрімен бекітіледі.
- Ойын нәтижесінің тақырыбы мөрдей басылады.
- Хабарлама (toast) балауыз мөрмен шығады.
