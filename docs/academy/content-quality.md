# AO17 CS Universe: мазмұн сапасы және авторлық құқық

## Сабақ «дайын» деп қашан саналады
Сабақ `tools/academy/content/` ішінде толық жазылып, `python3 tools/academy_build.py --check` тексерісінен өтсе ғана дайын болып саналады. Тексеруден өтпеген сабақ сайтқа шықпайды: build тоқтайды. Басты беттегі және `docs/academy/status.json`-дағы сандар осы тексерістен автоматты есептеледі. Жоспар саны дайын сан ретінде көрсетілмейді.

Автоматты тексерілетін талаптар:
1. Барлық міндетті бөлім бар (A-N), ұзындығы ең аз шектен кем емес.
2. Теорияда кемінде бір дәлелдеу бар.
3. Әр тапсырмада кемінде бір кеңес бар. `mc` нұсқалары қайталанбайды, әр нұсқаның түсіндірмесі бар.
4. `formula` тапсырмасының эталон шешімі мақсатқа эквивалент және шектеулерге сай. Мақсаттың өзі шектеуден өтпейді, сондықтан тапсырма мағыналы.
5. Python мысалдары шынымен іске қосылады және шығысы сабақта жазылғанмен дәл сәйкес.
6. Кілттерді екі тәуелсіз іске асыру (Python `plogic.py` және JS `academy-logic.js`) бірдей есептейді.
7. Сұрақтар сабақтар арасында қайталанбайды, кіріспе мәтіндері бірегей.
8. ID, атау мен алғышарттар оқу картасына (`curriculum.py`) сәйкес.

Автоматты тексерілмейтіні (адам тексеруі керек):
- тілдің табиғилығы, терминологияның біркелкілігі;
- түсіндірменің педагогикалық сапасы;
- дәлелдеулердің толықтығы. Олар автор тексеруінен өтті (`reviewStatus: author-checked`), бірақ тәуелсіз рецензия әлі жоқ (`peer-reviewed` емес).

## Интерактивті модельдер (AO17 Viz) ережелері
1. **Нақты есептеу, сәндік анимация емес.** Әр кадр модельдің шын күйі: алгоритмнің кезегі, процессордың регистрлері, желінің салмақтары, Python-ның айнымалылары. Видео не GIF қолданылмайды.
2. **Оқушы басқарады.** Ойнату/тоқтату, бір қадам алға/артқа, басынан бастау, жылдамдық, кіріс параметрлері; параметр өзгерсе модель бірден қайта есептеледі.
3. **Не болғаны қазақша айтылады.** Әр кадрда «қандай амал, неге, нәтижесі қандай» деген түсіндірме бар (aria-live).
4. **Қажет жерде ғана.** `tools/academy/viz_map.py`-де әр модельге «why» (бұл модель осы сабақта нені түсіндіреді) міндетті; тексеруші онсыз құлайды.
5. **«Егер өзгертсек?»** Әр модель кемінде бір маңызды «қате» сценарийді көрсете алуы керек: алшақтау (η тым үлкен), сызықтық модельдің XOR-ды шеше алмауы, 8 биттік асып кету, use-after-free, теріс салмақ (Дейкстра).
6. **Модель екені айтылады.** C жады моделі шартты мекенжайларды қолданады - бұл бетте жазылған.
7. **Қолжетімділік.** Пернетақта (Бос орын, ← →, R), фокус, 44px батырмалар, қозғалыс азайтылса автоматты ойнату жоқ, axe-core тексерісі (`tests/e2e/viz.spec.js`).
