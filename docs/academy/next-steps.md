# AO17 CS Universe: келесі қадамдар

Нақты күйі: `docs/academy/status.json` (автоматты) және `docs/academy/implementation-progress.md`.

## Келесі сессияның бірінші тапсырмасы
m01-m11 дайын (110 сабақ). Келесі - **m12 Systems Integration** (Level I-дің соңғы модулі): командалық жол, CSV/JSON, Python + C (subprocess), өнімділік, сенімді енгізу, Git, құжаттама, интеграциялық тест; қорытынды жоба p12 Python–C Comparative Computing Project.

## Кейінгі кезеңдер (басымдықпен)
1. **m03-m05** (дискретті құрылымдар, алгоритмдік ойлау, екілік жүйе) және **Set Operations Laboratory**.
2. **Code X-Ray (Python)**: Pyodide-та `sys.settrace` арқылы қадамдап орындау, айнымалылар күйі, шақыру стегі. Бұл нақты орындау болады, симуляция емес. Әр қадамның шектеуін құжаттау керек.
3. **AO17 Judge (Python)**: Pyodide-та оқушы функциясын ашық тесттермен іске қосу, қазақша диагностика. Құпия тесттерді тек серверде жүргізуге болады, ол бөлек жоба (ao-content сияқты Edge Function + оқшауланған орындау).
4. **C**: m10-да C коды build кезінде gcc-мен тексеріледі, оқушы шығысты болжайды. Браузерде шынайы C компиляциясы - жеке зерттеу (clang/wasm өлшемі, лицензиясы).
5. **Virtual Computer**: оқу процессоры (регистрлер, ALU, жады, PC, қарапайым ассемблер), m05 және m11-ге байланысты.
6. **Algorithm Arena**: 1-нұсқа дайын (m09, сұрыптау). Келесісі: іздеу мен граф аралауы, екі алгоритмді қатар салыстыру.
7. **Мұғалім панелі**: `admin.html` оқушы кестесіне `cs50kz:academy` бойынша меңгеру бағанын, әлсіз тақырыптарды және CSV экспортын қосу. Деректер `ao_progress.snapshot` ішінде бұрыннан бар.
8. **Сертификат**: деңгей емтиханы және талаптары. Аккредитация жоқ екенін анық жазу.

- Тапсырма кілттері клиентте тұр (оқу тексерісі). Бұл `docs/academy/architecture.md`-да жазылған.
- Білім картасы әзірге модуль деңгейінде. Сабақ деңгейіндегі граф m02-ден кейін керек болады.
