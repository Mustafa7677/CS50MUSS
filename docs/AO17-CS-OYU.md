# AO17 CS · Ою студиясы

`academy/oyu.html` бетінде оқушы Python кодымен қазақ ою-өрнегін салады. Мұнда цикл, функция, симметрия және рекурсия суретке айналады. Бет жария.

## Қалай жұмыс істейді

- **Python.** Оқушы коды браузерде нағыз Python-да (Pyodide) орындалады. Pyodide сайттың ортақ `CS50KZ.getPyodide()` арқылы жүктеледі.
- **Тасбақа.** `assets/py/oyu_turtle.py` модулі - Python turtle-дің шағын көшірмесі. Ол сурет салмайды: әр сызықты, бояуды және нүктені жазып алады. Суретті `assets/js/ao17-oyu.js` SVG етіп салады: сызықтар қалам сияқты кезекпен сызылады (жылдамдығы: қалыпты, баяу, бірден).
- **Build.** Сол модуль build кезінде CPython-да галереяның 6 оюын және 8 тапсырманың мақсат суретін салады (`tools/academy/oyu.py`). Сондықтан бет Python жүктелмей тұрып та толық көрінеді. Шешімдер бетке жазылмайды, тек мақсат суреті.
- **Командалар.** Стандарт turtle: `forward`, `back`, `left`, `right`, `penup`, `pendown`, `goto`, `setheading`, `home`, `circle`, `dot`, `color`, `pensize`, `fillcolor`, `begin_fill`/`end_fill` және олардың қысқа атаулары. `import turtle`, `from turtle import *` және тікелей шақыру жұмыс істейді.
- **Түстер.** Қазақша түс атаулары Алаш палитрасынан алынады: қызыл, көк, алтын, жасыл, қара, ақ, сары, күлгін, қоңыр, сұр, қызғылт, көгілдір. CSS атаулары мен #hex те жүреді.
- **Қауіпсіздік.**
  - Шексіз цикл бетті қатырмайды: 50 000 қозғалыстан не 400 000 орындалған жолдан кейін код тоқтатылады.
  - Қате жол нөмірімен көрсетіледі, қате жолы редакторда қызылмен белгіленеді.
- **Қазақша кеңес.** Python хабарының астында қазақша кеңес шығады (`oyu_turtle.hint`): белгісіз атау, шегініс, қос нүкте, жақша, `range()`-ке бөлшек сан, командаға мән жетпеуі, тоқтамайтын рекурсия.
- **Жақшасыз команда.** `left` деп жақшасыз жазылса, Python оны қате демейді, бірақ ештеңе салынбайды. Студия мұндай жолды «Ескерту» ретінде көрсетеді (`oyu_turtle.lint`).
- **Редактор.** Ою студиясы мен Бота әлеміне ортақ редактор (`assets/js/ao17-editor.js`, `assets/css/ao17-editor.css`):
  - жол нөмірлері және белгіленген жол;
  - Enter шегіністі сақтайды, `:` белгісінен кейін 4 бос орын қосады; Backspace бір шегініс деңгейін өшіреді;
  - Tab шегініс жасайды, Shift+Tab шегіністі азайтады;
  - Esc, сосын Tab - редактордан шығу (пернетақта тұзағы болмайды);
  - Ctrl+Enter - іске қосу;
  - өзгерістер `execCommand` арқылы енеді, сондықтан Ctrl+Z жұмыс істейді;
  - телефонда қаріп 16px: iOS Safari өріске фокус бергенде бетті үлкейтпейді.

## Сегіз тапсырма

1. **Шаршы** - цикл.
2. **Сегіз қырлы жұлдыз** - бұрыш.
3. **Шаңырақ** - уықтар мен шеңбер.
4. **Қошқар мүйіз** - функция және доғалар.
5. **Айнадай мүйіз** - симметрия (теріс радиус).
6. **Төрт құлақ** - айналмалы симметрия.
7. **Ою жиегі** - қайталау және жылжу.
8. **Өсімдік оюы** - рекурсия.

Тапсырманы таңдағанда мақсат суреті кенепте сұр түспен тұрады. «Тексеру» батырмасы оқушының суреті мен мақсатты 220x220 растрға айналдырып, қабаттасу үлесін (IoU) есептейді. 82%-дан асса, тапсырма орындалды деп саналады. Сызықтың бағыты мен салу реті маңызды емес, тек сурет маңызды.

Сақтау орны - `ao17cs:oyu`: әр тапсырманың коды мен орындалған тапсырмалар. 4 тапсырмадан кейін «Оюшы» жетістігі беріледі.

## Галерея және бөлісу

- **Галерея.** 6 дайын ою: қошқар мүйіз, төрт құлақ, шаңырақ, сегіз қырлы жұлдыз, ою жиегі, өсімдік оюы. Кез келгенін ашып, өзгертуге болады.
- **«Сілтемемен бөлісу».** Код сілтеменің `#k=` бөлігіне жазылады (base64url, UTF-8). Сервер қажет емес: сілтемені ашқан адам сол кодты және сол суретті көреді.
- **Жүктеу.** Суретті PNG (880x880) не SVG ретінде жүктеуге болады.

## Сайтпен байланысы

- Курс бетінде 6, 7 және 9-апталарда (Python, функция, алгоритм) «Студия» жолы бар. Курс бетінің «Python алаңы» бөлімінде студия Бота әлемімен қатар тұрады: орындалған тапсырма саны көрінеді.
- «Курстар» мәзірінде «Ою студиясы» сілтемесі бар.
- «Қалай оқыған дұрыс» бетінде «Сөз бен сурет» тактикасы студияға сілтейді.
