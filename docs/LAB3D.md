# AO17 · 3D зертхана (INSIDE TECH материалдары AO17 ішінде)

INSIDE TECH (github.com/Mustafa7677/3d-learning-) - AO17 командасының 3D оқу платформасы. Оның материалдары AO17-нің өзінде тұрады: оқушы бір сайттан шықпай дәрісті оқиды, тест шешеді және 3D симуляцияны ашады. Прогресс екеуінде ортақ.

## Не бар

AO17 нұсқасында тек Нұрай мен Мустафа бар, Ұстаз кейіпкері жоқ. `tools/sync_inside.py` құрастырудың алдында (strip_ustaz) INSIDE TECH клонында оның комикс, фильм және оқиға жолдарын баяндаушы мәтініне айналдырады (мәтін мен тақта сақталады), «Мустафаға түсіндір» чатындағы кеңесті Нұрай береді; құрастырған соң клон `git checkout` арқылы бастапқы күйіне қайтады. Бумада, деректе немесе комикс кітапханасында «ұстаз» сөзі кез келген түрде қалса, синхрондау тоқтайды (has_ustaz), мұны `tests/e2e/lab3d.spec.js` те тексереді.

## INSIDE TECH толық: AO17 нұсқасы

3D қолданба (`academy/3d/app/`) - INSIDE TECH-тің өз сайтымен бірдей толық қолданба: басты бет, 11 зертхана, IT архипелагы, ойын залы, миссия, тактика, есептер залы, комикс кітапханасы, газет, оқу құралдары, мамандықтар, сабақ жасау. AO17 хабы оның бәрін ретімен көрсетеді (`tools/academy/inside_catalog.py`: топтар, атаулар, сипаттамалар; мұғалім панелі мен аккаунт INSIDE TECH серверін қажет ететіндіктен тізімде жоқ, мұғалімдерге AO17-нің `teacher.html` беті бар).

AO17 нұсқасы INSIDE TECH-тен мына жағынан мықтырақ (бәрін `tools/sync_inside.py` құрастыру алдында клонға қолданады, соңында клон бастапқы күйіне қайтады):
- Ұстаз кейіпкері жоқ (`strip_ustaz`).
- 11 зертхана мен 150 сабақтың атауы қолданбаның ішінде де қазақша (`kazakh_titles`): архипелаг картасында, зертхана беттерінде, іздеуде.
- Тақырып мәзірі 721-1440px енде бір қатарда қалады (`ao17_patches`). Бұрын екі қатарға түсіп, беттің басын жабатын.
- Әр сабақтың толық дәрісі мен тесті AO17-де жеке, іздеу жүйесі көретін бет болып тұр.

Скриншоттарды жаңарту (синхрондаудан кейін): `PW_CHROMIUM=/path/to/chrome python3 tools/inside_shots.py`.

## AO17 CS курсының 2-бөлімі

3D зертхана - AO17 CS курсының екінші бөлімі «Технологияның ішінен» (`academy/course.html#part2`). Бірінші бөлім (12 апта, CS Universe Level I) логикадан жүйеге дейін жүреді, екіншісі машинаның ішіне кіреді. Зертханалардың ұсынылатын реті және 150 сабақтың қазақша атаулары `tools/academy/lab3d_kk.py`-да: сабақ бетінде басты атау қазақша, ағылшынша атауы астында (`lang="en"`). Жаңа сабақтың қазақша атауы жоқ болса, `python3 tools/build.py` қате береді. Курс беті әр апта мен әр зертхананың прогресін және «Жалғастыру» батырмасын көрсетеді (`assets/js/course.js`, деректер тек браузерде). Хабта (`academy/3d/index.html`) басталған сабақ алтын белгімен, барлық тесті шешілген сабақ жасыл белгімен көрінеді, әр зертхананың астында «аяқталды: N / 15» жазылады (`assets/js/lab3d.js`).

## Прогресс

Лекция бетіндегі тестке берілген дұрыс жауап (`assets/js/lab3d.js`) INSIDE TECH-тің `inside-tech:activity` күнделігіне жазылады: әр сұрақ «problem», сабақтың барлық тесті шешілсе «lesson». Сайт бір origin-де тұрғандықтан, бұл белсенділікті 3D қолданба да, «Менің шаңырағым» беті де көреді (серия және әрекет). Шешілген сұрақтар `ao17:lab3d` кілтінде сақталады.

## Жаңарту (INSIDE TECH өзгерсе)

```bash
git clone https://github.com/Mustafa7677/3d-learning- ../3d-learning-
python3 tools/sync_inside.py ../3d-learning-     # pnpm install, build:artifact, сабақтарды JSON-ға шығару, academy/3d/app/ жаңарту
python3 tools/build.py                           # лекция беттерін қайта жасау
```

`academy/3d/app/SOURCE.json` қай INSIDE TECH коммитінен құрастырылғанын сақтайды. Синхрондау кезінде index.html бейімделеді: Google Fonts орнына AO17-нің жергілікті шрифттері (Inter, JetBrains Mono, Unbounded, PT Serif), `noindex`, «AO17 · 3D зертхана» батырмасы.

## Қауіпсіздік

Дәрістегі HTML тегтері (`<ul>`, `<script>` шабуыл мысалдары, модельдің `</s>` токені) әрқашан мәтін болып көрсетіледі: `tools/academy/lab3d.py` ешбір тегті тег ретінде өткізбейді. Мұны `tests/e2e/lab3d.spec.js` тексереді.

## Тексеру

- `python3 tools/build.py`: деректің толықтығы (әр қадамда дәріс, тест жауабының индексі нұсқалар ішінде).
- `npx playwright test e2e/lab3d.spec.js` (tests қалтасында): хаб, лекция беті, тест пен ортақ күнделік, кесте, мысал, XSS, 3D қолданба (қатесіз, сыртқы сұраныссыз), курс сілтемелері, 360px, axe.
