# «Ағылшын тілі A0-C1» курсы: мазмұн жазушыларға арналған шарт

Бұл құжат `en/` курсын толтыратын агенттер мен авторлар үшін міндетті. Үлгі (эталон) сабақ: `en/lectures/week-0.html` (A0 · 1-сабақ). Жаңа сабақты жазар алдында оны толық оқыңыз.

## 2. Файлдар және кім нені жазады

Мазмұн агенті **тек өз файлдарын** жазады. Ортақ файлдарды (`tools/build.py`, `sw.js`, `assets/js/*.js`, `assets/css/*.css`, `tests/**`, `licensing/**`) өзгертпейді.

| Файл | Мазмұны |
|---|---|
| `en/lectures/week-N.html` | сабақ беті, N = 0..23 (қараңыз: 3-бөлім) |
| `assets/data/en-vocab-<lvl>.js` | деңгейдің сөздігі (`a0 a1 a2 b1 b2 c1`) |
| `assets/data/en-grammar-<lvl>.js` | деңгейдің грамматика ережелері |
| `assets/data/en-phrases.js` | IT-фразалар (барлық деңгей бір файлда) |

Сабақ тұғырлары `tools/make_en_pages.py` арқылы жасалған. Дайын сабақ беттерін ол ешқашан қайта жазбайды.

### Сабақ нөмірлері

6 деңгей × 4 сабақ. Файл `week-N`, `N = деңгей_индексі*4 + (сабақ-1)`. Бет атауы мен `.num` ішінде «A0 · 1-сабақ» түрінде жазылады.

| Деңгей | Файлдар | Белгі (`.num`) |
|---|---|---|
| A0 | week-0..3 | `A0 · 1-сабақ` ... `A0 · 4-сабақ` |
| A1 | week-4..7 | `A1 · 1-сабақ` ... |
| A2 | week-8..11 | |
| B1 | week-12..15 | |
| B2 | week-16..19 | |
| C1 | week-20..23 | |

Сабақ тақырыптарының жоспары: `tools/make_en_pages.py` ішіндегі `LESSONS` тізімі (ол тек жоспар; жазғанда тақырыпты нақтылауға болады, сабақтың `h1` мәні курс бетіндегі карточкаға автоматты түседі).

### Тұғырды сабаққа айналдыру

1. `en/lectures/week-N.html` тұғырын `week-0.html` үлгісіне сүйеніп **толық ауыстырыңыз** (head ішіндегі `<!-- build:head -->` блогын, nav мен footer-ді `python3 tools/build.py` өзі толтырады, сондықтан оларды бос қалдыруға болады).
2. Тұғырдағы `<!-- soon -->` белгісін және `<meta name="robots" content="noindex">` жолын **өшіріңіз**. Белгі қалса, сабақ «жақында» болып қалады және статистикаға кірмейді.
3. `python3 tools/build.py` іске қосыңыз: сабақ курс бетінде «Дайын ✓», `en/data/lectures.js`, іздеу, сөздік, шпаргалка, сайтмап және офлайн кэшке автоматты кіреді.

## 3. Сабақ бетінің құрылымы

Мақала `<article class="content" id="main">`. Міндетті бөлімдер (`h2 id`):

1. `goals` - «Сабақ мақсаттары» (4-6 өлшенетін мақсат).
2. Түсіндіру бөлімдері: ереже + мысал + `callout note` «Қазақшамен салыстыру». Әр жаңа ереже үшін қазақ тілімен салыстыру міндетті.
3. Сөздік блогы (`ul.en-vocab`, қараңыз: 4-бөлім), 10-15 сөз.
4. `mistakes` - «Қазақ тілді оқушылардың жиі қателері» (5-8 тармақ; қате мен дұрысы жұптасып көрсетіледі: `<em class="en-bad">`, `<em class="en-good">`).
5. `it-english` - IT-ағылшын бөлімі (деңгейге лайық: A0 - UI жазулары; A1 - stand-up; A2 - commit/баг-репорт; B1 - code review/құжаттама; B2 - ресми e-mail/интервью; C1 - архитектура/дизайн-құжат). Оның жаттығуы бар.
6. `exercises` - «Жаттығулар»: **кемінде 8** `.en-ex` блогы, барлық түрі (fill, choice, match, order, write, listen, speak) және IT-жаттығулар.
7. `summary` - «Қорытынды» (`ul` тізімі және `ul.checklist data-id="enN-self"` + `<p class="progress"></p>`).
8. `quiz` - «Қорытынды тест»: **8 сұрақ** (`div.quiz` > `div.question`, 4 нұсқа, дұрыс жауап орналасуы алуан түрлі).
9. `nav.pager` (алдыңғы/келесі) және `p.translator-note` (үлгідегідей, өзгертпеңіз).

Сабақ басында: `div.lecture-head[data-n=N][style="--lc:#0f766e"]` ішінде `div.num` («A1 · 2-сабақ»), `h1`, бір абзац; одан кейін `nav.en-subnav` (үлгіден көшіріңіз) және деңгей туралы `callout note`.

Ұзындық нормасы: 1500-2800 сөз, оқу 40-60 минут. Жаттығулар (кемінде 8) + тест (8) бар.

`<head>` үшін `week-0.html` үлгісін көшіріңіз: `en-course.css` (және лазым болса `own-viz.css`), `en-course.js` (`defer`), қажет болса `own-viz.js` (`defer`). Сабақ `data-license="B"` және `data-course="en"` дене атрибуттарымен тұрады.

## 4. Сөздік блогы (сабақ ішінде)

```html
<ul class="en-vocab" aria-label="Сәлемдесу сөздері">
  <li data-id="a0-hello"><span class="en-w">hello</span> <span class="en-pos">interj</span>
    <span class="en-m">сәлем</span> <span class="en-p">Оқылуы: хелоу</span>
    <span class="en-s"><q lang="en">Hello, my name is Aida.</q> <small>Сәлем, менің атым Айда.</small></span></li>
</ul>
```

- `data-id` сөздік файлындағы `id`-мен **бірдей** болуы тиіс (қосымша «жаттадым» белгісі сөздік бетімен ортақ). Сабақтағы әр `data-id` `assets/data/en-vocab-<lvl>.js` ішінде болуы керек.
- Дыбыстау батырмасын JS өзі қосады (`.en-w` мәтінінен). Басқа жерге қолмен: `<button type="button" class="en-say" data-say="Мәтін" aria-label="Дыбыстау: Мәтін">🔊</button>`.
- Дыбыстау **тек** браузердің `speechSynthesis` API-імен жұмыс істейді. Қолжетімсіз болса, бет өзі ескерту көрсетеді; сондықтан қазақша оқылуын (`.en-p`) әрқашан жазыңыз.
- IT терминдерін глоссарийге қосу үшін: `<strong>құпиясөз</strong> (<span class="term-en">password</span>)`.

## 5. Жаттығу блогының разметкасы

```html
<div class="en-ex task" data-type="TYPE" data-id="a1-2-ex-name">
  <div class="task-head"><span class="badge easy">Жеңіл</span><h3 id="en5-t1">1. Тақырып</h3></div>
  <p>Нұсқау (қазақша).</p>
  <script type="application/json" class="en-ex-data">{ ... JSON ... }</script>
</div>
```

- `class="en-ex task"`: **осы ретпен** (`en-ex` бірінші; build мұны тапсырма деп санайды).
- `data-id` бет ішінде және бүкіл курс бойынша бірегей (`<деңгей>-<сабақ>-<қысқа атау>`). Прогресс осымен сақталады, оны кейін өзгертпеңіз.
- `h3 id` бірегей (мысалы `en5-t1`). Badge: `easy` / `medium` / `hard` (Жеңіл / Орташа / Қиын).
- JSON дұрыс болуы тиіс (қос тырнақша, соңғы үтірсіз). Мәтіндерде тек `<b> <i> <em> <strong> <code>` теңдеріне рұқсат; қалғаны экрандалады.
- Жауап салыстыру регистрді, апострофтың түрін, тыныс белгілерін және артық бос орынды ескермейді.

### Түрлері (`data-type`) және JSON форматы

**choice** (көп таңдау)
```json
{"items":[{"q":"She ___ a developer.","o":["is","are","am"],"a":0,"e":"she -> <b>is</b>."}]}
```
`a` - дұрыс нұсқа индексі (0-ден), `e` - түсіндірме (міндетті емес, бірақ ұсынылады).

**fill** (бос орын)
```json
{"bank":["am","is","are"],"items":[
 {"t":"I ___ from Almaty.","a":["am","'m"],"h":"кеңес","e":"түсіндірме"},
 {"t":"He ___ a dev and she ___ a tester.","a":[["is"],["is"]]}]}
```
Бос орын - `___` (үш төменгі сызық). Бір бос орында `a` - қабылданатын жауаптар тізімі; бірнеше бос орында `a` - бос орын сайын тізім. `bank` міндетті емес.

**match** (сәйкестендіру)
```json
{"pairs":[["hello","сәлем"],["thank you","рахмет"]]}
```
Оң жақтағы мәндер бірегей болсын.

**order** (сөйлем құру)
```json
{"items":[{"w":["My","name","is","Aida"],"kz":"Менің атым Айда.","a":["My name is Aida"]}]}
```
`w` - сөздер (араластырылып көрсетіледі; тыныс белгісін сөзге жапсыруға болады: `"name?"`). `a` - қабылданатын сөйлемдер (көп нұсқа болса, барлығын жазыңыз), `kz` - тапсырма (міндетті емес).

**write** (қысқа жазба, өзін-өзі тексеру)
```json
{"prompt":"...","min":10,"hint":"...","criteria":["Критерий 1","Критерий 2"],"model":"Үлгі жауап."}
```
`min` - ең аз сөз. Оқушы критерийлердің барлығын белгілегенде ғана жазба орындалды деп саналады. `model` - үлгі жауап (тексерген соң ашылады). Қолжазба құрылғыда сақталады.

**listen** (тыңдау)
```json
{"items":[
 {"say":"Good morning.","a":["Good morning"],"h":"кеңес"},
 {"say":"You are a student.","o":["I am a student.","You are a student."],"a":1,"e":"..."}]}
```
`a` тізім болса - диктант (жазып жауап береді); `o` + `a` сан болса - дұрыс сөйлемді таңдау. Дыбыс жоқ браузерде мәтін көрсетіледі.

**speak** (айту)
```json
{"items":[{"say":"I am a student.","p":"ай эм э стьюдент","kz":"Мен студентпін."}]}
```
Оқушы үлгіні тыңдап, дауыстап қайталап, белгі қояды (дауыс тануы жоқ; сыртқы қызмет қолданылмайды).

Прогресс: нәтиже `localStorage` кілті `cs50kz:en:ex`, сондай-ақ орындалған жаттығу `check:<бет жолы>:<data-id>` = `[true]` түрінде жазылады (бар прогресс жүйесі мен кабинет оны тапсырма ретінде санайды).

## 6. Қорытынды тест

Бар `.quiz` механизмі:
```html
<div class="quiz">
<div class="question" data-answer="b">
<p class="q-text">1. Сұрақ</p>
<label><input type="radio" value="a"> A нұсқа</label>
<label><input type="radio" value="b"> B нұсқа</label>
<label><input type="radio" value="c"> C нұсқа</label>
<label><input type="radio" value="d"> D нұсқа</label>
<p class="explain">Түсіндірме.</p>
</div>
<button class="btn quiz-check" type="button">Жауаптарды тексеру</button>
<p class="result" aria-live="polite"></p>
</div>
```
Дәл 8 сұрақ, 4 нұсқа, `data-answer` ∈ a-d. Бұл сұрақтар аралас тест пен сайт статистикасына автоматты кіреді.

## 8. Деректер файлдарының схемасы

Барлық файл `window.` ғаламдық айнымалысына жазады. Бір жазба = бір жол. Бастапқы 1-2 жолдық түсініктемені сақтаңыз. `id` бүкіл курс бойынша бірегей.

### 8.1 Сөздік: `assets/data/en-vocab-<lvl>.js`
```js
window.CS50KZ_EN_VOCAB = window.CS50KZ_EN_VOCAB || {};
window.CS50KZ_EN_VOCAB.a0 = [
  {"id":"a0-hello","w":"hello","pos":"interj","kz":"сәлем","ex":"Hello, my name is Aida.","exkz":"Сәлем, менің атым Айда.","p":"хелоу","topic":"сәлемдесу","lesson":0,"it":false}
];
```
- `id` (міндетті): `<lvl>-<slug>`; `w` (міндетті): ағылшынша сөз/тіркес; `kz` (міндетті): қазақша мағына.
- `pos`: `noun verb adj adv prep pron conj num modal interj phrase phrasal verb`. `ex`/`exkz`: мысал мен аудармасы. `p`: қазақша жуық оқылуы (IPA жоқ). `topic`: қазақша тақырып (сүзгі осыдан жасалады). `lesson`: сабақ нөмірі N (0-23, сілтеме үшін). `it`: `true` - IT сөзі.
- Деңгей ұсынысы: A0 ≈ 100-150, A1 ≈ 200, A2 ≈ 250, B1 ≈ 300, B2 ≈ 300, C1 ≈ 300 жазба. Тізімдерді сыртқы көзден көшірмеңіз: сөздерді сабақ мазмұнынан өз бетіңізше таңдаңыз.

### 8.2 Грамматика: `assets/data/en-grammar-<lvl>.js`
```js
window.CS50KZ_EN_GRAMMAR = window.CS50KZ_EN_GRAMMAR || {};
window.CS50KZ_EN_GRAMMAR.a0 = [
  {"id":"a0-to-be","title":"to be: am / is / are","rule":"Ереже мәтіні.\n\nЕкінші абзац.","examples":[{"en":"I am a student.","kz":"Мен студентпін."}],"kz":"Қазақшамен салыстыру","mistakes":[{"bad":"I student.","good":"I am a student.","why":"am түсіп қалған."}],"lesson":0,"tags":["етістік"]}
];
```
- `rule`: абзацтар `\n\n` арқылы бөлінеді, `<b> <i> <em> <strong> <code>` рұқсат. `examples`: 2-4 мысал. `kz`: қазақша салыстыру (міндетті емес, бірақ ұсынылады). `mistakes`: қазақ тілді оқушылардың жиі қателері (`bad`, `good`, `why`). `lesson`: сабақ нөмірі.
- `id` анкер болады: `grammar.html#a0-to-be`.

### 8.3 Фразалар: `assets/data/en-phrases.js`
```js
window.CS50KZ_EN_PHRASES = [
  {"id":"ph-standup-1","cat":"standup","lvl":"a1","en":"Yesterday I worked on the login page.","kz":"Кеше мен кіру бетімен жұмыс істедім.","note":"Қосымша түсіндірме"}
];
```
`cat`: `standup review bug commit email interview meeting docs question general`. `lvl`: `a0..c1`. Әр санатта кемінде 10 фраза болсын.

### 8.4 Деңгей тесті: `assets/data/en-placement.js`
```js
window.CS50KZ_EN_PLACEMENT = { version: 1, questions: [
  {"id":"pl-a0-1","lvl":"a0","q":"She ___ a teacher.","o":["am","is","are","be"],"a":1,"e":"she + is."}
]};
```
- 30 шақты сұрақ: әр деңгейге 5. `o` - 2-4 нұсқа, `a` - дұрыс индекс, бір ғана дұрыс жауап болуы керек. Сұрақтар ауызша емес, мәтіндік (грамматика, сөздік, қысқа оқу).
- Нәтиже алгоритмі (`assets/js/en-tools.js`, `placementScore`): деңгейлер төменнен жоғары қарай тексеріледі; деңгейдегі дұрыс жауап үлесі ≥ 60% болса, деңгей «өтті». Қатарынан өткен ең жоғарғы деңгей - бағалау; келесі деңгейде ≥ 34% болса, нәтиже «A2-B1» түрінде диапазон болады. Бастау сабағы - бағалаған деңгейдің 1-сабағы (≥ 85% болса, келесі деңгей).
- Нәтиже **болжамды** және ресми деңгей емес: беттегі ескертуді өзгертпеңіз.

## 9. CEFR-ге сай күрделілік

| Деңгей | Сөйлем | Мәтін ұзындығы | Не қамтиды |
|---|---|---|---|
| A0 | 3-6 сөз | 1-3 сөйлем | әліпби, дыбыс, to be, I have, атаулар, бұйрық |
| A1 | 5-9 сөз | 4-6 сөйлем | Present Simple/Continuous, there is/are, can, Past Simple (to be, тұрақты) |
| A2 | 6-12 сөз | 5-8 сөйлем | қате етістіктер, going to/will, салыстыру, should/must, қарапайым байланыстырғыштар |
| B1 | 8-15 сөз | 8-12 сөйлем | Present Perfect, 0/1 шартты, passive, жанама сөз, relative clauses |
| B2 | 10-20 сөз | 10-15 сөйлем | 2/3 шартты, wish, герундий/инфинитив, фразалық етістіктер, ресми стиль |
| C1 | 12-25 сөз | 12-20 сөйлем | инверсия, hedging, cleft, күрделі зат есімдік топ, идиома мен коллокация |

Лексикасы сол деңгейге лайық болсын: жаңа сөзді жаңа сабаққа 10-15 мөлшерде беріңіз. Әр деңгейде IT желісі (код түсініктемелері, қателер, commit хабарламасы, stand-up, Stack Overflow сұрағы, e-mail, интервью, құжаттама оқу) сол деңгейдегі күрделілікте.

## 10. Қазақ тілді оқушылардың жиі қателері (тексеру тізімі)

Әр сабақта қатысты болғандарын «жиі қателер» бөліміне қосыңыз:

- артикльдің жоқтығы (`I have computer`), `a/an/the` шатасуы;
- етістіктің (`am/is/are`) түсіп қалуы; көмекші етістік (`do/does/did`) ұмытылуы;
- 3-жақ `-s` (`she work`), `did`-тен кейін өткен шақ формасы (`did you went`);
- сөз реті: қазақша SOV (етістік соңда), ағылшынша SVO (`I code write` қате); сын есім зат есімнің алдында;
- предлогтар (қазақша септік жалғауы ағылшынша предлог): `in/on/at`, `depend on`, `listen to`;
- саналатын/саналмайтын зат есім (`informations`, `advices`), көпше жалғау (`two file`);
- дыбыс: `th`, `w/v`, `h`, `ng`, дауысты дыбыстардың ұзындығы (`ship/sheep`);
- қазақша калька: «қолыма алу», «басын айналдыру» сияқты сөзбе-сөз аударма; `make/do`, `say/tell`, `look/see`;
- Present Perfect пен Past Simple шатасуы; шартты сөйлемде `will`/`would`.

## 11. Стиль ережелері

- Түсіндіру жылы әрі нақты, қысқа абзацтармен. Терминдерді қазақша беріп, жақшада ағылшынша: `ырықсыз етіс (passive)`.
- Қазақша мысалдарда ресми «сіз» мен «сен»-ді бір сабақ ішінде тұрақты қолданыңыз.
- Мысалдар шынайы және пайдалы (жұмыс, оқу, технология). Нақты адамдарды, компанияларды, бренд мәтіндерін қолданбаңыз; аттар жалпы (Aida, Dan).
- Кеңестер жеңіл тілмен. Жауапты `<details>` ішінде көрсету үлгісі `week-0.html` үлгісінде жоқ; жаттығу қозғалтқышы «Жауаптарды көрсету» батырмасын өзі қосады.
- Қолжетімділік: әр суретке `alt`, әр формаға `aria-label`, түс контрастын сайт айнымалыларымен сақтаңыз; жаңа CSS жазбаңыз (ортақ файл).
- Мобильді 390 px: көлденең айналу болмауы керек; кесте орнына тізім (`ul`) қолданыңыз.

## 12. Тексеру командалары

```bash
python3 tools/build.py                       # сабақ қосылғанда міндетті; қате болмауы керек
python3 tools/build.py --stats               # by_course.en: lect (дайын), plan (24), quiz, tasks
python3 tools/licence_audit.py --check       # лицензия реестрі
cd tests && PW_PORT=3321 npx playwright test e2e/en-course.spec.js   # ағылшын курсының спектері (өз портыңызды таңдаңыз)
PW_PORT=3321 npx playwright test e2e/pages.spec.js -g "en/"          # беттердің жалпы тексеруі
```
- Дерек файлының синтаксисін тексеру: `node -e "global.window={};require('./assets/data/en-vocab-a1.js');console.log(Object.keys(window.CS50KZ_EN_VOCAB))"`.
- `en-course.spec.js` әр дайын сабақта: тест 8 сұрақ, `.en-ex` ≥ 6, әр жаттығудың дұрыс жауабы `JSON`-нан оқылып тексеріледі, консоль қатесі жоқ, 390 px көлденең айналу жоқ. Жаңа сабаққа ешқандай тест жазу қажет емес, ол автоматты жалпы тексеріледі.
- Порт қақтығысын болдырмау үшін `PW_PORT` қолданыңыз; тоқтату: `fuser -k ПОРТ/tcp` (`pkill -f` қолданбаңыз).
