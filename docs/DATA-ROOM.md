## 1. Бір абзацпен

AO17 (Алаш Орда, 1917): бағдарламалау, математика және ағылшын тілі бір қазақша платформада. Онда браузерде орындалатын код, автотексеру, офлайн режим, мұғалімге арналған сынып құралдары және ашық метрикалар бар. Жанында мектептерге арналған ақылы B2B платформаның прототипі (QazaqCode) тұр.

## 3. Не сатылмайды

- **Harvard CS50 аудармалары** (45 сабақ, CC BY-NC-SA 4.0). Коммерциялық емес лицензиямен таратылады, тегін қалады. Тізімі: `licensing/LECTURE-AUDIT.md`.
- **«CS50» және «Harvard» атаулары.** Олар Harvard-тікі. Бренд сондықтан AO17 болып өзгерді (бұрынғы атауы: CS50MUSS, «CS50 қазақша»).
- **Үшінші тарап компоненттері** (Pyodide, sql.js, KaTeX, qrcode-generator, қаріптер, портреттер). Өз лицензияларымен қалады: `THIRD-PARTY-LICENSES.md`.

## 4. Сапаның дәлелі

- **Автоматты тесттер:** `tests/e2e/` ішінде 34 файл, 235-тен астам сценарий. Тексерілетіндері:
  - барлық бет телефон мен компьютерде, жарық пен қараңғы тақырыпта, axe қолжетімділік тексерісімен;
  - курстар, емтихан, бұлт, мұғалім беті, сертификат;
  - бүлінген жадқа төзімділік;
  - лицензия аудиті.
- **Математика формулаларының дұрыстығы:** `tools/math_verify.py` (sympy).
- **Supabase қауіпсіздігі:** `supabase/security_test.sql`.
- **CI:** әр өзгеріс `.github/workflows/ci.yml` арқылы нақты Postgres-пен тексеріледі.
- **Лицензия аудиті:** `python3 tools/licence_audit.py --check`. Сыныпталмаған файл болса, CI құлайды.

## 5. Технология және шығын

- **Хостинг:** GitHub Pages (тегін), статикалық беттер. Python мен SQL оқушының браузерінде орындалады, сондықтан оқушы саны өскенде шығын сызықты өспейді.
- **Бұлт (өз еркімен):** Supabase. Пайдаланылатыны: прогресс синхрондау, сынып, кері байланыс, ашық метрикалар.
- **Тәуелділіктер:** CDN жоқ (Pyodide-тен басқа), құрастыру жүйесі жоқ (`python3 tools/build.py`).
- **Офлайн:** PWA (`sw.js`).

## 6. Метрикалар

- **Мазмұн:** `docs/INVENTORY.md`.
- **Қолданылу:** `metrics.html` (cookie-сіз жалпы санақ, жария). Санақ Supabase-ке `supabase/schema.sql` қосылғаннан кейін басталады.
- **Пилот өтінімдері:** Supabase → `cs50kz_feedback`, түрі `pilot`.
- **Жоқ:** төлеген клиент, табыс, расталған пайдаланушы саны. Мұны жасырмаймыз: `docs/DUE-DILIGENCE.md`.
