# AO17 MORPH · Математиканың пішінге айналуы

`academy/morph.html` - формула мен пішінді екі жақты байланыстыратын студия. Бет жария.

Негізгі ереже: формуланы өзгертсең, пішін өзгереді; пішінді сүйресең, формула қайта есептеледі. Үш сахна бар, әрқайсысы бір математикалық ұғымды көрсетеді.

## 1. Матрица (сызықтық алгебра)

2×2 матрица жазықтықты түрлендіреді. Canvas-та көрінетіні:

- түрленген тор және бастапқы тордың әлсіз ізі;
- бірлік шаршының бейнесі: det > 0 болса - жасыл, det < 0 болса - қызыл (бағыт аударылды), det = 0 болса - тек жиегі;
- қазақ оюы (қошқар мүйіз) - кеңістікпен бірге өзгереді;
- нақты меншікті векторлардың сызықтары (пунктир) және λ мәндері;
- î мен ĵ нұсқарлары - матрицаның бағандары.

**Формула → пішін.**
- Дайын матрицалар: Бірлік, Бұру 45°, Созу, Ығысу, Шағылысу, Проекция, Мысал (a = 1.1, b = −1, c = 0.5, d = −0.9).
- a, b, c, d сырғытпалары мен сан өрістері ([−3, 3]).
- «Бірліктен A-ға» сырғытпасы мен «Ойнату»: бірлік матрицадан A-ға бірқалыпты өту.
- «Бастапқы күйге қайтару» - бірлік матрица.

**Пішін → формула.** î не ĵ нұсқарының ұшын сүйресең, матрицаның бағаны өзгереді (0.1 қадаммен).

**Есептелетіні:** анықтауыш (ad − bc), ауданның неше есе өзгергені және бағыт, із (a + d), меншікті мәндер. Меншікті мәндер комплекс болса (мысалы, бұру), «нақты меншікті вектор жоқ» деп жазылады.

## 2. Комплекс функция (комплекстік анализ)

Функциялар: z², z³, 1/z, eᶻ, sin z, z + 1/z (Жуковский бейнелеуі).

- **z жазықтығы.** Тор: тік сызықтар - қызыл, көлденең сызықтар - көк. Алтын нүкте мен оның айналасындағы кішкене шаршы.
- **w = f(z) жазықтығы.** Сол тордың бейнесі. Үзілістер (полюс, кесу сызығы) сызықты бөледі.
- **Формула → пішін.** z нүктесін сүйресең, w = f(z) қозғалады.
- **Пішін → формула.** w нүктесін сүйресең, теңдеудің барлық шешімі (алғы бейнелер) z жазықтығында шығады, ал алтын нүкте ең жақын шешімге көшеді. Алғы бейнелер саны:
  - z² - 2;
  - z³ - 3;
  - 1/z - 1;
  - z + 1/z - 2;
  - eᶻ - шексіз көп: −1, 0, 1 тармақтары көрсетіледі;
  - sin z - шексіз көп: төрт шешім көрсетіледі.
- **Жергілікті сипат.** Созылу |f′(z)| және бұру arg f′(z). Алтын шаршы бейнеде де шаршы болып қалады: бұрыштар сақталады (конформды бейнелеу). f′(z) = 0 не полюс болса, бұл да жазылады.
- **Пернетақта.** Canvas-қа Tab-пен барып, нұсқар пернелерімен нүктені 0.05-ке (Shift-пен 0.25-ке) жылжытуға болады.

## 3. Фурье (Фурье анализі)

Тұйық сурет z(t) = Σ cₖ e^(2πikt) қосындысы ретінде салынады. Әр мүше - өз жылдамдығымен айналатын шеңбер (эпицикл).

- **Пішіндер.** Қошқар мүйіз, жүрек, шаршы, сегіз қырлы жұлдыз. Әрқайсысы доға ұзындығы бойынша бірдей 256 нүктеге бөлінген.
- **Коэффициенттер.** Дискретті Фурье түрлендіруімен есептеліп, модулі бойынша кему ретімен қойылады. Ең үлкен үш мүше жазылады.
- **Шеңбер саны.** 1-ден 128-ге дейін. Орташа қате (бастапқы нүктелер мен жуықтаудың орташа қашықтығы) бірден есептеледі. Шаршының бұрыштарында секіріс ешқашан дәл шықпайды.
- **Пішін → формула.** «Өзің сал» батырмасын басып, тордың үстінде тұйық сызық сызсаң, сызық 256 нүктеге бөлініп, коэффициенттері есептеледі.
- **Қозғалыс.** Эпициклдер өзі айналады; «Тоқтату» батырмасы бар. Азайтылған қозғалыс режимінде өзі басталмайды, бірақ «Ойнату» батырмасымен жүреді.
- **Телефон.** Canvas тек сурет салу режимінде бетті жылжытуды тоқтатады; қалған уақытта онымен бетті айналдыруға болады.

## Сабақтармен байланыс

- MORPH-тан сабақтарға:
  - матрица - математика курсының 10, 12, 13, 14-сабақтары, 3D зертхананың анықтауыш пен меншікті векторлар сабақтары;
  - комплекс функция - 67, 68, 69-сабақтар;
  - Фурье - 73, 74-сабақтар.
- Сабақтардан MORPH-қа: сол тоғыз математика сабағының соңында (пән емтиханына сілтеменің алдында) тиісті сахнаға апаратын «AO17 MORPH» блогы бар. Оны `tools/math_pedagogy.py` қояды (`<!-- build:mmorph -->`). Дереккөз біреу: `tools/academy/morph.py` ішіндегі `LINKS`.
- MORPH CS Universe хабында және «Курстар» мәзірінде де бар.

## Қалай жұмыс істейді

- **Деректер build кезінде есептеледі.** Оларды `tools/academy/morph.py` жасап, бетке JSON түрінде (`#mo-data`) салады.
  - Ою Ою студиясының тасбақа модулімен (`assets/py/oyu_turtle.py`) салынады: қошқар мүйіздің Python коды іске қосылып, сызықтары алынады.
  - Фурье пішіндері ортаға келтіріліп, [−1, 1] ауқымына сыйдырылады және 256 нүктеге бөлінеді.
- **Сурет.** `assets/js/ao17-morph.js` төрт canvas-қа салады. Түстер CSS айнымалыларынан (`--mo-*`) оқылады, сондықтан жарық және қараңғы режимде бірдей жұмыс істейді. Тақырып ауысса, сурет қайта салынады.
- **Терезе өлшемі өзгерсе,** алдымен барлық canvas-тың өлшемі жаңарады, сосын сурет салынады. Комплекс сахнада бір сурет функциясы екі canvas-қа салады, сондықтан бұл ретпен жасалмаса, w жазықтығы бос қалады.
- **Build тексерісі** (`validate()`):
  - оюдың екі сызығы бар;
  - әр Фурье пішіні 256 нүкте және [−1, 1] ішінде;
  - сабақтарға сілтемелер бар беттерге апарады.
- **Сақтау.** `ao17cs:morph` кілтінде сақталатыны: `{m: [a, b, c, d], fn, shape, k}`.
