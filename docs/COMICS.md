# AO17 Комикс: «Нұрай, Мустафа және Бота»

CS Universe сабақтарындағы комикстер. Барлығы build кезінде дайын HTML + SVG болып құрастырылады: JavaScript керек емес, іздеу жүйесі мәтінді көреді, экран оқу құралы әр кадрды оқиды.

## Кейіпкерлер

- **Нұрай** (`N`) - үкілі тақиялы оқушы қыз: мұқият, сұрақ қояды. Көңіл-күйлері: `calm`, `happy`, `think`, `wow`, `worried`, `laugh`. Қимылдары: `point`, `chin`, `up`.
- **Мустафа** (`M`) - көк кепкалы оқушы ұл: батыл, асығыс кодтайды, сондықтан тұзаққа жиі түседі. Көңіл-күйлері мен қимылдары Нұрайдікімен бірдей.
- Нұрай мен Мустафа - INSIDE TECH (mustafa7677.github.io/3D-learning-) 3D зертханаларының да кейіпкерлері: екі платформаның әлемі ортақ.
- **Бота** - AO17 маскоты, ботақан. Ол түсіндіреді. Көңіл-күйлері Нұрайдікімен бірдей.

Кейіпкерлер мен сахналар `tools/academy/comic.py` ішінде бағдарламамен салынады. Сыртқы сурет, шрифт не кітапхана қолданылмайды.

## Екі түрі

1. **Авторлық эпизодтар** (`tools/academy/comic_eps.py`). Level I-дің әр модулінің бірінші сабағына бір эпизод бар, барлығы 12 эпизод, әрқайсысында 6 кадр. Эпизод сабақтың кино-түсіндіруінен кейін тұрады (`#s-comic`). Хаб беті: `academy/comics.html`.
2. **«Тұзақ»**. Әр сабақтың «Жиі қателер» (К) бөлімінде 4 кадрлық комикс бар: қате, тоқта, себеп, ереже. Қатені сабақ id-іне қарай кезекпен Нұрай не Мустафа жасайды. Мәтін сабақтың `mistakes[0]` деректерінен алынады, сондықтан ол ешқашан сабақтан алшақтамайды.

## Жаңа эпизод қосу

`comic_eps.py` ішіндегі `EPISODES` тізіміне жаңа жазба қосыңыз:

```python
{"lesson": "ao17-foundation.m13.l01", "title": "...", "teaser": "...", "panels": [
    W("yurt", [Nu("think", "l", "chin"), B("happy")], [("N", "Сұрақ?"), ("B", "Жауап.")], cap="Түсіндірме мәтін"),
    N("screen", [B("happy", "l")], [("B", "...")], prop=code(["print(1 + 1)"], ["2"], check="py")),
    ...
]}
```

- `W(...)` - кең кадр (екі бағанға созылады), `N(...)` - жай кадр. Екі кең кадрдың арасындағы жай кадрлар саны жұп болуы керек, әйтпесе тор бос қалады. Мұны build өзі тексереді.
- Сөйлеуші: `"N"` (Нұрай), `"M"` (Мустафа) не `"B"` (Бота). Бір кадрда ең көбі үш кейіпкер болады, үшеуі тұрса кадрда зат болмайды. Соңына `~` қойсаңыз ойлау бұлты, `!` айқай, `#` жазба болады.
- Заттар (`prop`): `code`, `term`, `cells`, `bits`, `board`, `cards`, `flow`, `set`, `stamp`.
- Әсерлер (`fx`): `idea`, `q`, `sweat`, `spark`. Дыбыс сөз: `sfx="ҚАТЕ!"`.
- **Код кадры тексеріледі.** `check="py"` не `check="c"` берілсе, build кезінде код нағыз Python не gcc-мен (`-std=c11 -Wall -Wextra -Werror`) іске қосылады. Кадрдағы шығыс одан өзгеше болса, build тоқтайды. «…»-мен аяқталған жол басы бойынша салыстырылады (ұзын қате хабарлары үшін). Кадрда кодтың бір бөлігі ғана көрсетілсе, толық бағдарламаны `src=` арқылы беріңіз.

## Тексеру

- `python3 tools/build.py` барлық эпизодты (кейіпкер, тор, код шығысы) және 210 «Тұзақ» комиксін тексереді.
- `npx playwright test e2e/comic.spec.js` (tests қалтасында) хабты, эпизодтарды, «Тұзақ» мәтінінің сабақпен сәйкестігін, телефондағы тік нұсқаны және axe тексерісін қарайды.

## Комикс-мұқабалар (AO17 CS постерлері)

`tools/make_course_posters.py` AO17 CS курсына журнал мұқабалары сериясын жасайды: әр апта - бір нөмір (№ 01-12), мұқабада сол аптаның комикс бейнесі (ауылдағы шамдар, әженің бауырсағы, дастарқанның басы ...), кейіпкер (осы қозғалтқыштың `nurai()` / `mustafa()` суреттері) және апта сұрағы. Тағы екі арнайы шығарылым: курстың негізгі постері (шаңырақ-схема астында Нұрай, Мустафа, Бота) және 2-бөлімнің постері «Технологияның ішінен».

```bash
PW_CHROMIUM=/opt/pw-browsers/chromium python3 tools/make_course_posters.py   # Chromium жолы жергілікті ортаға қарай
```

Шығыс: `assets/img/posters/ao17cs*.jpg` (1000×1500), `assets/img/posters/thumb/` (курс бетіндегі апта карточкалары, 240×360), `assets/img/og/course-ao17cs.jpg` және `ao17cs-3d.jpg` (бөлісу суреті). Мұқабалар `posters.html#ao17cs` бөлімінде және `academy/course.html` апта карточкаларында тұр. Курс бетінің басында курстың негізгі мұқабасы және курс фильмі («Даладан жұлдызға», `film/cs/`) тұр.

### 2-бөлімнің мұқабалары: 11 зертхана

`tools/make_lab_posters.py` 2-бөлімнің әр зертханасына өз нөмірін жасайды (№ 01-11, курстағы ретпен: архитектура, алгоритмдер, математика, желілер, веб, дерекқор, қауіпсіздік, бұлт, AI, ойын, IoT). Қаңқасы, қаріптері мен көмекші функциялары `make_course_posters.py`-дікі, бұрынғы 14 мұқабаға тиіспейді. Мұқабада:

- зертхананың ішіндегі нәрсе изометриялық «3D» көріністе: чип-тақтадағы CPU мен регистрлер, сұрыпталған массив пен лупа, маршрутизаторлар мен пакеттер, нейрон желі, роботтың қолы;
- бір кейіпкер (Нұрай не Мустафа, кезекпен) және оның бір ауыз сөзі;
- зертхананың атауы, бір жолдық сипаттамасы, сабақ пен тест сұрағының саны.

```bash
PW_CHROMIUM=/opt/pw-browsers/chromium python3 tools/make_lab_posters.py   # 11 мұқаба + кішірейтілген нұсқа + бөлісу суреті + афиша
python3 tools/make_lab_posters.py --html                                    # тек афишаның блогы (posters.html)
PW_CHROMIUM=/opt/pw-browsers/chromium python3 tools/make_lab_posters.py net web   # тек осы зертханалар
```

Шығыс: `assets/img/posters/ao17cs-3d-<зертхана>.jpg` (1000×1500), `assets/img/posters/thumb/ao17cs-3d-<зертхана>.jpg` (240×360) және `assets/img/og/ao17cs-3d-<зертхана>.jpg` (1200×630). Мұқабалар төрт жерде тұр:

- афишада: `posters.html#ao17cs-3d` (блокты құрал өзі жазады, `<!-- ao17cs-3d:begin -->` ... `<!-- ao17cs-3d:end -->`);
- курс бетінің 2-бөлімінде: әр зертхананың карточкасында;
- 3D хабында: зертханалар «журнал сөресі» болып тұр, хабтың басында 2-бөлімнің постері;
- әр сабақтың басында: сол зертхананың мұқабасы. Сабақты бөліскенде де сол зертхананың баннері шығады (`tools/build.py`).

Мұқаба коллекциясы енді 23 нөмір (12 апта + 11 зертхана): аптаның не зертхананың барлық сабағы аяқталса, курс бетінде оның мұқабасына «жиналды» мөрі басылады (`assets/js/course.js`).

Кейіпкер солға қарап тұрса (`actor(..., face=-1)`), Мустафаның төсбелгісіндегі «AO» жазуы қайта айналады (`mustafa(..., mirror=True)`), сондықтан ол айнадағыдай «OA» болып көрінбейді.
