C++ бағдарламалау

Жылдамдығы мен күші үшін ойындарда, операциялық жүйелерде, робототехникада қолданылатын тілді нөлден үйреніңіз: жад пен көрсеткіштерден ООП, STL және шаблондарға дейін, соңында өз жобаңызбен.

Бастау: 0-апта → Қорытынды жоба Қорытынды емтихан Курс картасы

64тест сұрағы

main.cpp
#include <iostream>
#include <string>
#include <vector>

int main() {
    std::vector<std::string> qalalar = {"Астана", "Алматы", "Шымкент"};
    for (const auto& q : qalalar) {
        std::cout << "Сәлем, " << q << "!\n";
    }
}
$ g++ -std=c++17 main.cpp -o main && ./main
Сәлем, Астана!
Сәлем, Алматы!
Сәлем, Шымкент!

Алдын ала не білу керек?

Ештеңе керек емес: курс нөлден басталады. Компьютерде мәтіндік файл ашып, терминалды іске қосуды білсеңіз жеткілікті. Басқа тілде (Python, Scratch) жазған болсаңыз, бастапқы апталар жылдамырақ өтеді. Сертификаты бөлек.

Бұл курстан не үйренесің

  • 1
    Компиляторды қолдану

    Кодты g++ арқылы жинап, ескертулер мен қателерді оқып, түзетуді үйренесіз.

  • 2
    Жадты түсіну

    Стек пен үймені, адрес пен көрсеткішті, сілтемені және жадты дұрыс босатуды нақты көресіз.

  • 3
    ООП-ты қолдану

    Класстар, инкапсуляция, мұрагерлік және полиморфизммен нысандық модель құрасыз.

  • 4
    STL-мен жұмыс

    vector, map, set және стандартты алгоритмдерді қолданып, қысқа әрі жылдам код жазасыз.

  • 5
    Шаблондарды жазу

    Бір рет жазып, кез келген типке жұмыс істейтін функциялар мен кластар жасайсыз.

  • 6
    Өз жобаңды аяқтау

    Командалық жолмен жұмыс істейтін, файлға сақтайтын толық бағдарлама жазасыз.

Қайта бастаушы

Python не JavaScript білетін, компьютер жадының қалай жұмыс істейтінін ішінен көргісі келетін адам.

Қалай оқу керек

Бұл курста код браузерде емес, өз компьютеріңізде орындалады: бұл нағыз бағдарламашының жұмыс орнына ұқсас. Әр лекциямен былай жұмыс істеңіз:

  1. Оқыңыз. Лекцияны асықпай оқып, әр код мысалын өз файлыңызға көшірмей, қолмен теріңіз.
  2. Іске қосыңыз. Нәтижені лекциядағы терминал блогымен салыстырыңыз. Қате шықса, оны оқыңыз: ол көмектеседі.
  3. Жаттығыңыз. Тапсырмаларды алдымен өзіңіз шешіңіз, кеңесті кейін ашыңыз, шешімді соңғы кезекте қараңыз.
  4. Тексеріңіз. 8 сұрақтық тестті тапсырып, «Оқыдым ✓» батырмасын басыңыз: прогресіңіз сақталады.

Компьютеріңе орнату (қысқаша)

Windows
  1. MSYS2 орнатқышын жүктеп, орнатыңыз.
  2. MSYS2 UCRT64 терминалында: pacman -S mingw-w64-ucrt-x86_64-gcc
  3. C:\msys64\ucrt64\bin жолын PATH айнымалысына қосыңыз.
  4. Жаңа терминал ашып тексеріңіз: g++ --version
macOS
  1. Терминалда: xcode-select --install (Apple компиляторлар жинағы).
  2. Тексеру: g++ --version (ол іс жүзінде clang, бізге жеткілікті).
Linux
  1. Ubuntu/Debian: sudo apt install g++
  2. Fedora: sudo dnf install gcc-c++
  3. Тексеру: g++ --version
VS Code
  1. VS Code орнатып, «C/C++» (Microsoft) кеңейтімін қосыңыз.
  2. Жаңа қалта ашып, main.cpp жасаңыз, кодты жазыңыз.
  3. Ішкі терминалда (Ctrl+`) іске қосыңыз.

Іске қосу командасы: g++ -std=c++17 -Wall -Wextra main.cpp -o main && ./main

Windows PowerShell-де соңғы бөлігі .\main.exe болады.

Жоба: «Шаңырақ дүкені» қойма есебі

Соңғы аптада аяқтайтын өз жобаңыз: консольде жұмыс істейтін қойма мен сатылым бағдарламасы. Тауарлар класстармен сипатталады, тізім vector пен map-та сақталады, мәліметтер файлға жазылып, келесі іске қосуда қайта оқылады.

  • Тауар, Қойма және Сатылым кластары (инкапсуляция мен мұрагерлік)
  • STL контейнерлері мен сұрыптау алгоритмдері
  • Файлға сақтау және оқу, дұрыс емес енгізуді ұстау
  • Шаблон функциямен жалпы есеп беру
  • Өзіңіз қалаған қосымша мүмкіндік (мысалы, тенгемен баға жеңілдігі)

Жобаны өз компьютеріңізде жазып, лекциядағы өзін-өзі тексеру тізімі бойынша тексересіз. Автотексеретін жүйе жоқ: өзіңіз бағалап, алған біліміңізді мақтанышпен көрсетесіз.
