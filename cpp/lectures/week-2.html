    Массивтер, жолдар және vector

    Бір айнымалыға бір мән сыяды, ал нақты өмірде деректер көп: қонақтар тізімі, апталық температура, дүкеннің сатылымы. Бұл аптада көп мәнді сақтайтын контейнерлерді (C-массив, std::array, std::vector), мәтінмен жұмыс (std::string), сұрыптау мен іздеуді және енгізу ағынының қулығын үйренеміз.

    Неге контейнер керек?

    Наурыз мейрамына 200 қонақ келеді делік. Олардың аттарын сақтау үшін 200 айнымалы жариялауға бола ма? guest1, guest2, ... guest200. Әрине, жоқ. Бізге бір атпен аталатын, бірақ ішінде көп мән жататын құрылым керек. Оны контейнер (container) дейміз. Контейнердің ішіндегі мәндер элемент деп аталады, ал әр элементті оның нөмірі, индексі (index) арқылы табамыз.

    Маңызды ереже, оны әрдайым есте сақтаңыз: индекс 0-ден басталады. Бірінші элементтің индексі 0, екіншісінікі 1, және т.б. Бес элементті массивте соңғысының индексі 4. Бастапқыда ерекше көрінеді, бірақ тез үйренесіз: индекс «басынан неше қадам алыс» деген мағына береді. Бірінші элемент басынан 0 қадам алыс тұр.

    Бүгін C++-тың үш негізгі контейнерімен танысамыз:

    КонтейнерӨлшеміҚашан қолданамыз
    C-массив int a[5]тіркелген, компиляция кезіндеескі код, өте қарапайым жағдай
    std::array<int, 5>тіркелгенөлшемі алдын ала белгілі болғанда
    std::vector<int>өзгереді (өсе алады)әдепкі таңдау көп жағдайда

    Қысқа ереже: күмән болса, std::vector қолданыңыз.

    C-массив

    C-массив - тілдің ең ескі контейнері (ол C тілінен келген). Оның жазылуы: тип аты[өлшем] = {мәндер};. Мысал: бір аптаның таңғы температурасы (градус).

    #include <iostream>

int main() {
    int temp[7] = {-4, -1, 2, 5, 3, 0, -2};   // апталық температура
    int n = sizeof(temp) / sizeof(temp[0]);

    int sum = 0;
    int hottest = temp[0];
    for (int i = 0; i < n; i++) {
        sum += temp[i];
        if (temp[i] > hottest) hottest = temp[i];
    }
    std::cout << "күн саны: " << n << "\n";
    std::cout << "қосынды: " << sum << "\n";
    std::cout << "орташа: " << static_cast<double>(sum) / n << "\n";
    std::cout << "ең жылы: " << hottest << "\n";
    std::cout << "temp[3] = " << temp[3] << "\n";
    return 0;
}

    Бір жол өте пайдалы: sizeof(temp) / sizeof(temp[0]) - бүкіл массивтің байттағы көлемін бір элементтің көлеміне бөліп, элемент санын табады. Алайда бұл тек массив шыққан жерде жұмыс істейді; функцияға берілгенде массив өлшемін жоғалтады (оны 3-аптада көрсеткіштермен түсіндіреміз). Осы себепті бүгін C-массив қолдануды ұсынбаймыз.

    Мұндағы басты қауіп: C-массив шекараны тексермейді. 5 элементті массивтің 5-индексін сұрасаңыз, C++ «жоқ» демейді, жадтың бөтен бөлігіне қарайды. Мұны көрейік:

    return 0;
}

    Анықталмаған мінез

    Шекарадан шығу C++ тілінде «анықталмаған мінез» (undefined behavior). Бұл «қате хабарламасы шығады» дегенді білдірмейді: бағдарлама жұмыс істеп кетуі де, құлауы да, басқа деректі бұзуы да мүмкін. Қауіпті жері дәл осы болжанбайтындық.

    std::array

    std::array - C-массивтің қауіпсіз әрі ыңғайлы «қабығы». Өлшемі әлі де тіркелген, бірақ ол өзінің өлшемін біледі (.size()), .at() арқылы шекараны тексереді және функцияларға ыңғайлы беріледі. #include <array> керек.

    #include <iostream>
#include <array>

int main() {
    std::array<int, 4> prices = {200, 1500, 800, 350};

    std::cout << "өлшемі: " << prices.size() << "\n";
    std::cout << "бірінші: " << prices.front() << ", соңғы: " << prices.back() << "\n";
    std::cout << "prices.at(2) = " << prices.at(2) << "\n";

    int total = 0;
    for (int p : prices) total += p;
    std::cout << "барлығы: " << total << "\n";
    return 0;
}
    $ ./main

бірінші: 200, соңғы: 350

барлығы: 2850

    <int, 4> - екі параметр: элемент типі және өлшемі. Өлшем компиляция кезінде белгілі болуы керек: оны пернетақтадан оқуға болмайды. Ал өлшемі белгісіз болса, бізге vector керек.

    std::vector

    std::vector - өсетін массив. Қонақтар тізімін түзіп, жаңа қонақ келген сайын соңына қосамыз (push_back). Python-дағы list-ке өте ұқсас. #include <vector> керек, ал ішіндегі тип бұрыштық жақшада жазылады.

    #include <iostream>
#include <vector>
#include <string>

int main() {
    std::vector<std::string> guests;
    guests.push_back("Айгерім");
    guests.push_back("Нұрлан");
    guests.push_back("Дәулет");

    std::cout << "қонақ саны: " << guests.size() << "\n";
    std::cout << "екінші қонақ: " << guests[1] << "\n";

    guests.pop_back();
    guests.push_back("Мадина");
    for (std::size_t i = 0; i < guests.size(); i++) {
        std::cout << i + 1 << ". " << guests[i] << "\n";
    }
    std::cout << "бос ма? " << std::boolalpha << guests.empty() << "\n";
    return 0;
}
    $ ./main
қонақ саны: 3
екінші қонақ: Нұрлан
1. Айгерім
2. Нұрлан
3. Мадина
бос ма? false

    Қолданылған негізгі әдістер:

    • push_back(x) - соңына x қосады.
    • pop_back() - соңғы элементті өшіреді.
    • size() - элемент саны (типі std::size_t, таңбасыз).
    • empty() - бос па?
    • front(), back() - бірінші және соңғы элемент.
    • v[i] және v.at(i) - i-ші элементке қол жеткізу.

    Вектор жасаудың бірнеше жолы бар:

    #include <iostream>
#include <vector>

int main() {
    std::vector<int> a = {5, 8, 13};
    std::vector<int> zeros(4);          // төрт нөл
    std::vector<int> sevens(3, 7);      // үш жеті

    for (int x : a) std::cout << x << " ";
    std::cout << "\n";
    for (int x : zeros) std::cout << x << " ";
    std::cout << "\n";
    for (int x : sevens) std::cout << x << " ";
    std::cout << "\n";
    return 0;
}
    $ ./main

0 0 0 0 
7 7 7

    vector<int> zeros(4) - төрт элементті, барлығы нөл. vector<int> sevens(3, 7) - үш элемент, әрқайсысы 7. Бұл жолда жақша санды, ал бұйра жақша мәндер тізімін білдіреді: vector<int> v{3, 7} - екі элемент (3 және 7), ал vector<int> v(3, 7) - үш жеті. Көп адам осы жерде шатасады.

    [] және at(): шекараны тексеру

    v[i] C-массив сияқты шекараны тексермейді (жылдам, бірақ қауіпті). v.at(i) тексереді: шекарадан шықса, ерекше жағдай (exception) лақтырады. Біз оны try/catch блогымен ұстап көрейік:

    #include <iostream>
#include <vector>
#include <stdexcept>

int main() {
    std::vector<int> v = {10, 20, 30};
    try {
        std::cout << v.at(1) << "\n";
        std::cout << v.at(10) << "\n";
    } catch (const std::out_of_range& e) {
        std::cout << "қате ұсталды: " << e.what() << "\n";
    }
    return 0;
}
    $ ./main
20
қате ұсталды: vector::_M_range_check: __n (which is 10) >= this->size() (which is 3)

    try ішіндегі код орындалады; қате болса, бағдарлама бірден catch блогына секіреді. e.what() қатенің сипаттамасын береді: «__n (which is 10) >= this->size() (which is 3)» - яғни сіз 10-ны сұрадыңыз, ал өлшемі тек 3. Егер catch болмаса, бағдарлама terminate шақырып, тоқтайды. Үйренуші үшін ереже: бастапқыда at() қолданыңыз, бағдарламаңыз дұрыс жұмыс істейтініне көз жеткізген соң ғана жылдам []-ге ауыса аласыз.

    Вектор ішінде не болады?

    Вектор жадтағы үздіксіз блокты басқарады. Орын таусылғанда ол жаңа, үлкенірек блок алып, элементтерді көшіреді. Көрнекі: size - қазір қанша элемент бар, capacity - қанша элементке орын бар.

    #include <iostream>
#include <vector>

int main() {
    std::vector<int> v;
    std::size_t lastCap = v.capacity();
    std::cout << "size=0 capacity=" << lastCap << "\n";
    for (int i = 1; i <= 9; i++) {
        v.push_back(i);
        if (v.capacity() != lastCap) {
            lastCap = v.capacity();
            std::cout << "size=" << v.size() << " capacity=" << lastCap << "\n";
        }
    }
    return 0;
}
    $ ./main

size=1 capacity=1
size=2 capacity=2
size=3 capacity=4
size=5 capacity=8
size=9 capacity=16

    Біздің компиляторда сиымдылық 1, 2, 4, 8, 16 болып екі еседен өсті (басқа компиляторда басқаша болуы мүмкін). Осы себепті push_back орташа алғанда жылдам: көшіру сирек болады. Бір маңызды салдар: вектор көшкен кезде ескі мекенжайлар жарамсыз болады. Бұл тақырыпқа 3-аптада көрсеткіштермен оралғанда егжей-тегжейлі тоқталамыз.

    Көрейік: температура тізімін оқу

    Вектордың басты пайдасы: элемент санын алдын ала білмесек те, оларды жинай аламыз. Қолданушыдан алдымен күн санын, сосын әр күннің температурасын сұрап, нөлден төмен күндерді санайық:

    #include <iostream>
#include <vector>

int main() {
    int n;
    std::cout << "Қанша күн? ";
    std::cin >> n;

    std::vector<int> temps;
    for (int i = 0; i < n; i++) {
        int t;
        std::cin >> t;
        temps.push_back(t);
    }

    int below = 0;
    for (int t : temps) {
        if (t < 0) below++;
    }
    std::cout << "нөлден төмен күндер: " << below << " / " << temps.size() << "\n";
    return 0;
}
    $ ./main
Қанша күн? 5
-4 -1 3 7 0
нөлден төмен күндер: 2 / 5

    Бес санның екеуі (-4 және -1) нөлден төмен. Бұл бағдарламада int t; айнымалысы цикл ішінде жарияланып, әр айналымда жаңадан жасалады, ал temps.push_back(t) оның көшірмесін векторға қояды. Вектор өсе бергендіктен, массивтің өлшемін алдын ала болжаудың қажеті жоқ. Бұл - C-массивке қарағанда векторды таңдаудың негізгі себебі.

    Ортасына қою және өшіру

    push_back тек соңына қосады. Вектордың кез келген жеріне элемент қою үшін insert, өшіру үшін erase бар; олар орынды көрсетуге итератор алады (v.begin() + i - «бастан бастап i-ші орын»).

    #include <iostream>
#include <vector>

void show(const std::vector<int>& v) {
    for (int x : v) std::cout << x << " ";
    std::cout << "\n";
}

int main() {
    std::vector<int> v = {10, 20, 30, 40};
    v.insert(v.begin() + 1, 99);      // 1-индекске қою
    show(v);
    v.erase(v.begin());               // бірінші элементті өшіру
    show(v);
    v.erase(v.begin() + 1, v.begin() + 3);   // [1, 3) аралығын өшіру
    show(v);
    v.clear();
    std::cout << "өлшемі: " << v.size() << "\n";
    return 0;
}
    $ ./main
10 99 20 30 40 
99 20 30 40 
99 40 
өлшемі: 0

    Бастапқы тізім: 10 20 30 40. insert(v.begin() + 1, 99) 99-ды екінші орынға қойды, қалғандары оңға жылжыды. erase(v.begin()) бірінші элементті алып тастады. Үшінші жолда аралық өшірілді: [begin + 1, begin + 3) - 1-ші және 2-ші индекстер (20 мен 30), ал соңғы шекара кірмейді. Қалды: 99 және 40. clear() бәрін өшіреді.

    Назар аударыңыз: ортаға қою мен өшіру баяу, себебі кейінгі барлық элементтерді жылжыту керек. Тізім ұзын болса және мұндай әрекет жиі болса, басқа контейнерді (std::list, std::deque) қарастыру керек, бірақ көп жағдайда vector бәрібір жеткілікті жылдам.

    Диапазонды for

    Элементтердің бәрін аралау үшін индексті санамай-ақ, диапазонды for (range-based for) жазуға болады: for (тип x : контейнер). Ол «контейнердің әр элементін алып, ол x болсын» дегенді білдіреді. Алғашында осы нұсқаны таңдаңыз: бір-бір қате (off-by-one) мүмкіндігі жоқ.

    Бір нәзік жері бар: x элементтің көшірмесі ма, әлде өзі ме? Мұны мысалда көрейік:

    #include <iostream>
#include <vector>

int main() {
    std::vector<int> tenge = {1000, 2500, 400};

    for (int x : tenge) x = x * 2;                  // көшірме: өзгермейді
    for (int x : tenge) std::cout << x << " ";
    std::cout << "\n";

    for (int& x : tenge) x = x * 2;                 // сілтеме: өзгереді
    for (const int& x : tenge) std::cout << x << " ";
    std::cout << "\n";
    return 0;
}
    $ ./main
1000 2500 400 
2000 5000 800

    Бірінші циклде int x - көшірме, сондықтан x * 2 оны ғана өзгертті, вектор өзгеріссіз қалды: 1000 2500 400. Екінші циклде int& x - сілтеме (reference), яғни элементтің өзінің басқа аты, сондықтан өзгеріс векторға түседі. Үшінші, const int& - тек оқуға арналған сілтеме, көшірме жасамайды. Ереже: өзгертпейтін болсаңыз, const auto&; өзгертсеңіз, auto&; шағын типтерді (int) көшіре беруге болады. Сілтемені 3-аптада толық түсіндіреміз.

    std::string

    std::string - шын мәнінде таңбалар векторына өте ұқсас, бірақ мәтінмен жұмысқа арналған көптеген әдісі бар. Көбі vector-дегі сияқты: size(), front(), back(), [], push_back().

    #include <iostream>
#include <string>

int main() {
    std::string city = "Almaty";
    std::cout << city.size() << " " << city.front() << " " << city.back() << "\n";
    std::cout << city.substr(0, 3) << "\n";           // 0-ден бастап 3 таңба
    std::cout << city.find("ma") << "\n";             // 2
    std::cout << city.find("xyz") << "\n";            // табылмаса, үлкен сан
    std::cout << (city.find("xyz") == std::string::npos) << "\n";

    city += " 2026";
    city[0] = 'a';
    std::cout << city << "\n";

    }
    for (int i = 0; i < 26; i++) {
        if (count[i] > 1) {
            std::cout << static_cast<char>('a' + i) << ": " << count[i] << "\n";
        }
    }
    return 0;

    Сұрыптау

    Сұрыптау (sorting) - элементтерді белгілі ретпен (әдетте өсу ретімен) орналастыру. Алгоритмдердің ең қарапайымын қолмен жазып көрейік: бұл ойлау үшін пайдалы жаттығу.

    Selection sort (таңдау арқылы)

    Идея: тізімнен ең кішісін тауып, оны бірінші орынға қоямыз; қалғанынан ең кішісін тауып, екінші орынға қоямыз; және т.б. Қолда карта бар адам оларды осылай ретке келтіреді.

    #include <iostream>
#include <vector>
#include <utility>

int main() {
    std::vector<int> a = {29, 10, 14, 37, 13};
    for (std::size_t i = 0; i + 1 < a.size(); i++) {
        std::size_t minIdx = i;
        for (std::size_t j = i + 1; j < a.size(); j++) {
            if (a[j] < a[minIdx]) minIdx = j;
        }
        std::swap(a[i], a[minIdx]);
        std::cout << "қадам " << i + 1 << ": ";
        for (int x : a) std::cout << x << " ";
        std::cout << "\n";
    }
    return 0;
}

Элементтер саны n болса, шамамен n * n салыстыру керек.

    Bubble sort (көпіршік арқылы)

    Идея: көршілес екі элементті салыстырамыз; егер олар қате тәртіппен тұрса, орнын ауыстырамыз. Тізімнің соңына дейін өткенде ең үлкен элемент су бетіне шыққан көпіршік сияқты соңына жетеді.

    #include <iostream>
#include <vector>
#include <utility>

int main() {
    std::vector<int> a = {5, 1, 4, 2, 8};
    for (std::size_t pass = 0; pass + 1 < a.size(); pass++) {
        bool swapped = false;
        for (std::size_t j = 0; j + 1 < a.size() - pass; j++) {
            if (a[j] > a[j + 1]) {
                std::swap(a[j], a[j + 1]);
                swapped = true;
            }
        }
        std::cout << "өту " << pass + 1 << ": ";
        for (int x : a) std::cout << x << " ";
        std::cout << "\n";
        if (!swapped) break;
    }
    return 0;
}

    Тәжірибеде өз алгоритміңізді жазбайсыз: стандартты кітапхана дайын, жылдам std::sort береді. #include <algorithm> керек. Ол begin() мен end() аралығын сұрыптайды:

    Басқа пайдалы алгоритмдер

    <algorithm> және <numeric> кітапханаларында көптеген дайын құралдар бар. Олардың бәрі begin()/end() жұбын қабылдайды, сондықтан векторда да, массивте де жұмыс істейді. Бес жиі қолданылатыны:

    #include <iostream>
#include <vector>
#include <algorithm>
#include <numeric>

int main() {
    std::vector<int> v = {42, 7, 19, 88, 3, 19};

    int total = std::accumulate(v.begin(), v.end(), 0);
    std::cout << "қосынды: " << total << "\n";

    auto mx = std::max_element(v.begin(), v.end());
    auto mn = std::min_element(v.begin(), v.end());
    std::cout << "ең үлкен: " << *mx << " (индекс " << mx - v.begin() << ")\n";
    std::cout << "ең кіші: " << *mn << "\n";
    std::cout << "19 саны: " << std::count(v.begin(), v.end(), 19) << " рет\n";

    auto it = std::find(v.begin(), v.end(), 88);
    std::cout << "88 табылды ма? " << (it != v.end()) << "\n";

    std::reverse(v.begin(), v.end());
    for (int x : v) std::cout << x << " ";
    std::cout << "\n";
    return 0;
}

    Сызықтық іздеу

    Ең қарапайым әдіс: тізімді басынан соңына дейін қарап шығамыз. Табылса, индексін қайтарамыз, таппасақ, -1:

    #include <iostream>
#include <vector>

int findIndex(const std::vector<int>& v, int target) {
    for (std::size_t i = 0; i < v.size(); i++) {
        if (v[i] == target) return static_cast<int>(i);
    }
    return -1;
}

int main() {
    std::vector<int> numbers = {42, 7, 19, 88, 3};
    std::cout << "19 -> " << findIndex(numbers, 19) << "\n";
    std::cout << "50 -> " << findIndex(numbers, 50) << "\n";
    return 0;
}

    Назар аударыңыз: функция векторды const std::vector<int>& арқылы алды. Бұл «көшірмесіз, тек оқу үшін» дегенді білдіреді (3-аптада толық түсіндіреміз). Сызықтық іздеу n элементте ең көбі n қадам жасайды.

    Екілік іздеу

    Тізім сұрыпталған болса, әлдеқайда ақылды әдіс бар. Сөздіктен сөз іздегенді еске алыңыз: ортасын ашасыз, іздеген сөзіңіз бұрын ма, кейін бе екенін білесіз де, қалған жартысына ауысасыз. Әр қадамда іздеу аймағы екі есе кішірейеді. Бұл - екілік іздеу (binary search).

    #include <iostream>
#include <vector>

int binarySearch(const std::vector<int>& v, int target, int& steps) {
    int lo = 0, hi = static_cast<int>(v.size()) - 1;
    steps = 0;
    while (lo <= hi) {
        steps++;
        int mid = lo + (hi - lo) / 2;
        if (v[mid] == target) return mid;
        if (v[mid] < target) lo = mid + 1;
        else hi = mid - 1;
    }
    return -1;
}

int main() {
    std::vector<int> sorted;
    for (int i = 1; i <= 100; i++) sorted.push_back(i * 3);   // 3, 6, ..., 300
    int steps;
    int idx = binarySearch(sorted, 213, steps);
    std::cout << "табылды: индекс " << idx << ", қадам саны: " << steps << "\n";
    idx = binarySearch(sorted, 100, steps);
    std::cout << "100: индекс " << idx << ", қадам саны: " << steps << "\n";
    return 0;
}
    $ ./main
табылды: индекс 70, қадам саны: 5
100: индекс -1, қадам саны: 7

    100 элементтің ішінен 213-ті бар болғаны 5 қадамда таптық, ал жоқ сан (100) 7 қадамнан кейін жоқ деп шықты. Сызықтық іздеу 70 элемент қарар еді. Екілік іздеу n элементте шамамен log2(n) қадам жасайды: миллион элементте 20 қадам ғана. Бірақ есте сақтаңыз: екілік іздеу тек сұрыпталған деректе жұмыс істейді.

    Кодтағы lo + (hi - lo) / 2 - (lo + hi) / 2-нің қауіпсіз түрі: үлкен сандарда lo + hi толып кетуі мүмкін (өткен аптадағы тақырып). Ал int& steps - қадам санын сыртқа қайтарудың тәсілі (сілтеме).

    Ойланып көріңіз: екілік іздеу сұрыпталмаған тізімде не істейді?

    Нәтиже болжанбайды: алгоритм орталықтағы мәнге қарап, «іздеген сан сол жақта» деп шешеді, бірақ тізім ретсіз болғандықтан сан іс жүзінде оң жақта тұруы мүмкін. Бағдарлама бар санды «жоқ» деп айтуы мүмкін. Сондықтан алдымен std::sort, сосын іздеу.

    Алгоритм қаншалықты жылдам?

    Алгоритмдерді салыстырғанда секундтарды емес, қадам санын қарайды, өйткені компьютер жылдамдығы әр қаралғанда өзгеріп тұрады. Тізімнің өлшемі n өскенде қадам саны қалай өсетінін көрейік:

    Алгоритмn = 10n = 1000n = 1 000 000
    Екілік іздеу (log2 n)~4~10~20
    Сызықтық іздеу (n)1010001 000 000
    std::sort (n · log n)~33~10 000~20 000 000
    Selection / bubble (n · n)1001 000 0001 000 000 000 000

    Бір миллион элементті сұрыптағанда n * n алгоритмі шамамен миллион миллион қадам жасайды: ол сағаттап жұмыс істейді. Ал std::sort шамамен жиырма миллион қадам жасайды, яғни секундтың бір бөлігі. Міне, сондықтан күрделі алгоритмдердің қажеті бар. Бұл ойлау тәсілі, яғни «тізім ұлғайғанда уақыт қалай өседі?», бағдарламалаудағы ең маңызды дағдылардың бірі. Мұны ресми түрде O-белгілеу (Big O notation) дейді: сызықтық іздеу O(n), екілік іздеу O(log n), қарапайым сұрыптау O(n²), std::sort O(n log n).

    Енгізу: getline және ағын мәселелері

    Өткен аптада cin >> name жолды бірінші бос орынға дейін ғана оқитынын айттық. Бүкіл жолды (бос орындарымен) оқу үшін std::getline(std::cin, жол) бар:

    #include <iostream>
#include <string>

int main() {
    std::string fullName;
    std::cout << "Толық атыңыз: ";
    std::getline(std::cin, fullName);
    std::cout << "Сәлем, " << fullName << "!\n";
    return 0;
}
    $ ./main
Толық атыңыз: Айгерім Сәрсенбек
Сәлем, Айгерім Сәрсенбек!

    Енді қауіпті жағдай: cin >> мен getline араласса не болады? Алдымен жасты, сосын атын сұрайық:

    #include <iostream>
#include <string>

int main() {
    int age;
    std::string name;
    std::cout << "Жасыңыз: ";
    std::cin >> age;
    std::cout << "Атыңыз: ";
    std::getline(std::cin, name);
    std::cout << "[" << name << "] " << age << "\n";
    return 0;
}
    $ ./main
Жасыңыз: 17
Атыңыз: [] 17

    Ат бос шықты! Неге? Қолданушы 17 жазып Enter басты. cin >> age тек 17 санын алды, ал Enter басқанда түскен жаңа жол таңбасы (\n) ағында қалды. Кейін getline келіп, жолдың басында-ақ осы \n-ды көрді де, «бос жол» деп есептеп, бірден тоқтады. Шешім: getline алдында қалған жаңа жолды cin.ignore арқылы тастау.

    #include <iostream>
#include <string>
#include <limits>

int main() {
    int age;
    std::string name;
    std::cout << "Жасыңыз: ";
    std::cin >> age;
    std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
    std::cout << "Атыңыз: ";
    std::getline(std::cin, name);
    std::cout << "[" << name << "] " << age << "\n";
    return 0;
}
    $ ./main
Жасыңыз: 17
Атыңыз: Нұрлан
[Нұрлан] 17

    std::numeric_limits<std::streamsize>::max() - «қанша таңбаға дейін болса да», ал '\n' - «жаңа жолға дейін» деген мағына. Нәтижесінде жол тазаланады.

    Қате енгізу

    Қолданушы сан орнына мәтін жазса, cin «істен шығады» (fail күйіне өтеді):

    #include <iostream>

int main() {
    int n = -1;
    std::cout << "Сан енгізіңіз: ";
    std::cin >> n;
    if (std::cin.fail()) {
        std::cout << "бұл сан емес, n = " << n << "\n";
    } else {
        std::cout << "сан: " << n << "\n";
    }
    return 0;
}
    $ ./main
Сан енгізіңіз: қырық
бұл сан емес, n = 0

    Бұл жағдайда n нөлге тең болды (C++11-ден бастап сәтсіз оқу нөл қояды), ал std::cin.fail() дұрыс емес енгізуді анықтайды. Одан әрі оқу үшін ағынды cin.clear() арқылы қалпына келтіріп, қалған таңбаларды cin.ignore(...) арқылы тазалау керек. Бұл күрделі мәселе, ол кейінгі апталарда қайта айтылады. Әзірге түсінетініміз: пернетақтадан оқу - сенімсіз қадам, оны әрдайым тексеру керек.

    Жиі қателер

    • Индекс шекарадан шығу. a[5] бес элементті массивте жоқ. Дұрыс диапазон: 0-ден size() - 1-ге дейін.
    • <= орнына < қою керек. for (i = 0; i <= v.size(); i++) - шекарадан шығады. Диапазонды for қолданыңыз.
    • Бос векторға v[0]. Бос векторда бірде-бір элемент жоқ. Алдымен empty() тексеріңіз.
    • int мен size() салыстыру. Ескерту береді: size() таңбасыз. std::size_t қолданыңыз.
    • Диапазонды for-да көшірмені өзгерту. Элементті өзгерткіңіз келсе, auto&.
    • Сұрыпталмаған деректе екілік іздеу. Нәтиже қате.
    • cin >> артынан getline. Жаңа жол ағында қалады, cin.ignore керек.
    • Қазақ әріптерін байт ретінде санау. size() байтты береді.
    • find нәтижесін тексермеу. Табылмаса, npos қайтады.

    Қорытынды

    • Контейнер көп мәнді бір атпен сақтайды; индекс 0-ден басталады.
    • C-массив шекараны тексермейді; std::array - тіркелген өлшемді қауіпсіз нұсқа; std::vector - өсетін әдепкі таңдау.
    • vector: push_back, pop_back, size, at (шекараны тексереді), capacity екі еселеп өседі.
    • Диапазонды for: auto көшіреді, auto& өзгертеді, const auto& тек оқиды.
    • std::string: substr, find, erase, insert; кирилл әріптері UTF-8-де екі байт.
    • Екі өлшемді контейнер: vector<vector<int>>, индекс [жол][бағана].
    • Selection және bubble sort - түсіну үшін; тәжірибеде std::sort. Сызықтық іздеу кез келген тізімде, екілік іздеу тек сұрыпталғанда.
    • getline бүкіл жолды оқиды; cin >> артынан cin.ignore қажет.

    Келесі аптада жадтың өзіне терең үңілеміз: мекенжай, көрсеткіш, сілтеме, stack және heap.

    Өзіңізді тексеріп көріңіз:

    • Массив пен вектордың айырмашылығын түсіндіре аламын.
    • [] мен at() айырмасын білемін.
    • Диапазонды for көшірме мен сілтемені қалай жасайтынын білемін.
    • Selection sort пен bubble sort қадамдарын қолмен орындай аламын.
    • cin >> мен getline араласқанда не болатынын түсіндіре аламын.

    Өзіңізді тексеріңіз

    1. Бағдарлама не шығарады? int a[4] = {3, 6, 9, 12}; std::cout << a[a[0] / 3];

    a[0] / 3 = 3 / 3 = 1, демек a[1] = 6.

    2. std::vector<int> v(3, 7); v.push_back(1); кодынан кейін v.size() неге тең?

    v(3, 7) - үш элемент (7, 7, 7), push_back төртіншіні қосады: өлшемі 4.

    3. Қайсысы шекарадан шыққанда ерекше жағдай (exception) лақтырады?

    at() шекараны тексеріп, std::out_of_range лақтырады. [] тексермейді: анықталмаған мінез.

    4. Төмендегі кодтан кейін v мәндері қандай? std::vector<int> v = {1, 2, 3}; for (int x : v) x = x * 10;

    int x - көшірме. Көшірмені өзгерту векторға әсер етпейді. Өзгерту үшін int& x керек.

    5. Selection sort қалай жұмыс істейді?

    Selection sort: әр қадамда сұрыпталмаған бөліктің ең кішісін таңдап, бастапқы орынға қояды. Бірінші нұсқа - bubble sort сипаттамасы.

    6. Екілік іздеуді қолдану үшін негізгі шарт қайсы?

    Екілік іздеу ортасындағы мәнге қарап жартысын тастайды, бұл тек тізім сұрыпталғанда ғана дұрыс.

    7. int age; std::string name; std::cin >> age; std::getline(std::cin, name); кодында name неге бос шығуы мүмкін?

    Санды оқығаннан кейін \n ағында қалады. getline оны бірден көріп, бос жолмен тоқтайды. Шешім: cin.ignore(...).

    8. std::string s = "Қазақ"; болса, s.size() неге тең (UTF-8)?

    «Қазақ» - 5 кирилл әрпі, әрқайсысы 2 байт, барлығы 10 байт. size() байтты санайды.

    Қосымша ойлану сұрақтары (жауабы жоқ, өзіңіз іздеңіз)
    • Егер bubble sort-тың ішкі циклін j + 1 < a.size() емес, j < a.size() деп жазсақ, қандай қате болады?
    • Екілік іздеуде mid = (lo + hi) / 2 орнына lo + (hi - lo) / 2 жазудың себебі қандай?
    • Бос векторда v.back() шақырса не болады? at() көмектесе ме?
    • Қазақ әріптері бар жолды әріп-әріппен қауіпсіз қалай аралауға болады деп ойлайсыз?

    Жаттығулар

    Жауабы бар тапсырмаларды осы жерде тексеріңіз, ал бағдарлама жазатындарды өз компьютеріңізде іске қосып, тексеру тізімімен салыстырыңыз.

    Жеңіл

    Массив индексі

    Бағдарлама не шығарады?

}

    Индекс 0-ден басталады: a[1] - екінші, a[3] - төртінші элемент.

    Шешімі

    a[1] = 20, a[3] = 40, қосындысы 60.

    $ ./main
60

    Вектор өлшемі

    Бағдарлама не шығарады?

#include <vector>

int main() {

    v.push_back(2);

    Шешімі

    Қосқаннан кейін {4, 9, 2}, pop_back 2-ні өшірді: {4, 9}. size() = 2, back() = 9, қосындысы 11.

    Бағдарлама не шығарады? (Жауабы жолдан және санның өзінен тұрады, арасында бос орын жоқ.)

int main() {

    s[0] = 'N' → «Nauryz». erase(4) «yz»-ді өшіреді → «Naur». Ұзындығы 4. Шығады: Naur4.

    Bubble sort-тың бір өтуі

    Бағдарлама көпіршіктің бір ғана өтуін жасайды. Қандай массив шығады? Сандарды бос орынмен ажыратып жазыңыз.

    #include <iostream>
#include <vector>
#include <utility>

int main() {
    std::vector<int> a = {5, 1, 4, 2, 8};
    for (std::size_t j = 0; j + 1 < a.size(); j++) {
        if (a[j] > a[j + 1]) std::swap(a[j], a[j + 1]);
    }
    for (int x : a) std::cout << x << " ";
    std::cout << "\n";
    return 0;
}
    Кеңес

    Көршілерді жұптап салыстырыңыз: (5,1), (5,4), (5,2), (5,8). Үлкені оңға жылжиды.

    Шешімі

    Бастапқы: 5 1 4 2 8. (5,1) ауысады → 1 5 4 2 8. (5,4) → 1 4 5 2 8. (5,2) → 1 4 2 5 8. (5,8) ауыспайды.

    $ ./main
1 4 2 5 8
    Қиын

    Екілік іздеу қадамдары

    1-ден 100-ге дейінгі сандар тізімінен 99 санын екілік іздеумен іздейміз (mid = (lo + hi) / 2, индекстер 0-ден 99-ға дейін). Бағдарлама қанша қадам санайды? Өз бағдарламаңызды жазып тексеріңіз.

    #include <iostream>
#include <vector>

int main() {
    std::vector<int> v;
    for (int i = 1; i <= 100; i++) v.push_back(i);
    int target = 99;
    int lo = 0, hi = static_cast<int>(v.size()) - 1, steps = 0;
    while (lo <= hi) {
        steps++;
        int mid = (lo + hi) / 2;
        if (v[mid] == target) break;
        if (v[mid] < target) lo = mid + 1;
        else hi = mid - 1;
    }
    std::cout << steps << "\n";
    return 0;
}
    Кеңес

    Қолмен орындап көріңіз: lo=0, hi=99. mid=49 → мәні 50 < 99 → lo=50. Келесі mid=74... Әр қадамда ауқым шамамен екі есе кішірейеді.

    Шешімі

    Қадамдар (индекс → мән): 49→50, 74→75, 87→88, 93→94, 96→97, 98→99 (табылды). Барлығы 6 қадам.

    $ ./main
6
    Өзін тексеру тізімі
    • -Wall -Wextra ескертусіз құрастырылады.
    • 99 үшін 6 қадам шығады.
    • 37 үшін 3 қадам (қолмен тексердім).
    • Жоқ сан үшін (мысалы, 101) бағдарлама тоқтайды, шексіз циклге түспейді.

    Қиын

    Әріп санау

    Қолданушыдан бүкіл жолды getline арқылы оқып, ондағы a әрпінің санын шығаратын бағдарлама жазыңыз. Енгізу: astana almaty aktau. Нәтиже қандай?

    Кеңес

    std::getline(std::cin, line); және for (char c : line) if (c == 'a') count++;. Таңба салыстырғанда бір тырнақша қолданылады.

    Шешімі
    #include <iostream>
#include <string>

int main() {
    std::string line;
    std::getline(std::cin, line);
    int count = 0;
    for (char c : line) {
        if (c == 'a') count++;
    }
    std::cout << count << "\n";
    return 0;
}

    «astana» - 3, «almaty» - 2, «aktau» - 2. Барлығы 7. Іске қосқанда:

    $ ./main
astana almaty aktau
7
    Өзін тексеру тізімі
    • Бос орындары бар жол дұрыс оқылады (cin >> емес, getline).
    • a әріпі жоқ жолда 0 шығады.
