    Жад, көрсеткіштер және сілтемелер

    Бұл апта C++-тың ең ерекше және ең қызықты бөлігі: компьютер жадына тікелей қол жеткізу. Мекенжай, көрсеткіш, сілтеме, стек пен үйме, динамикалық жад, жад ағуы және оларды қауіпсіз басқарудың заманауи жолы - смарт көрсеткіштер. Шаңырақ пен үй мекенжайы аналогиясымен қадамдап түсінеміз.

    Жад және мекенжай

    Өткен аптада айнымалы жадта «қобдиша» екенін айттық. Енді сол қобдишаны жақынырақ көрейік. Жад - бір-бірінің қасында тұрған миллиардтаған кішкентай ұяшықтардан (байттардан) тұратын өте ұзын көше. Әр ұяшықтың өз нөмірі бар: бұл мекенжай (address). int age = 17; деп жазғанда компьютер көшеден 4 байттық бос орын (үй) тауып, оған «age» деген ат қояды және ішіне 17 санын салады. Үйдің екі қасиеті бар: ішіндегі мән және көшедегі мекенжайы.

    Шаңырақ астындағы үйді елестетіңіз. Қазақ үшін шаңырақ - киіз үйдің төбесіндегі дөңгелек, отбасы мен әулеттің белгісі. Әр шаңырақтың астындағы үйдің өз мекенжайы болады. Көрші ауыл «Асан үйіне» барғысы келсе, оған екі жол бар: үйдің ішіне кіріп, не бар екенін көру немесе үйдің мекенжайын (Абай көшесі, 12) қағазға жазып, біреуге беру. Қағаз бен үй екі бөлек зат: қағазда үй жоқ, тек үйге апаратын жол бар. Міне, көрсеткіш (pointer) - дәл сол қағаз.

    Айнымалының мекенжайын & (амперсанд) операторымен аламыз:

    #include <iostream>

int main() {
    int age = 17;
    int* heapValue = new int(99);

    std::cout << "age мәні:        " << age << "\n";
    std::cout << "age мекенжайы:   " << &age << "\n";
    std::cout << "heap мекенжайы:  " << heapValue << "\n";
    std::cout << "sizeof(int*) = " << sizeof(int*) << " байт\n";

    delete heapValue;
    return 0;
}

    Мекенжайлар он алтылық (0x...) жүйесінде жазылады. Сіздің компьютеріңізде олар басқаша шығады, бағдарламаны келесі рет іске қосқанда да өзгереді: оған алаңдамаңыз, бұл қалыпты. Екі мекенжайдың түрі де бөлек: age стекте (0x7f...-пен басталады), ал new арқылы алынған орын үймеде (мұнда 0x5020...) жатыр. Бұл екі аймақ туралы кейінірек айтамыз. sizeof(int*) - 8 байт: мекенжайдың өзі де жадта орын алады, 64-биттік жүйеде ол 8 байт.

    Көрсеткіш: * және &

    Көрсеткіш - мекенжайды сақтайтын айнымалы. Оны жариялау: тип* аты. Мысалы, int* p - «int-ке көрсететін көрсеткіш p». Үш ұғымды қатар үйренейік:

    • &x - «x-тің мекенжайын ал» (қағазға мекенжай жаз).
    • int* p = &x; - p-ға x-тің мекенжайын сал (қағаз дайын).
    • *p - «p көрсеткен үйге кіріп, ішіндегіні ал немесе өзгерт» (dereference, мекенжай бойынша мәнге жету).
    #include <iostream>

int main() {
    int age = 17;
    int* p = &age;          // p - age-тің мекенжайын сақтайды

    std::cout << "age = " << age << ", *p = " << *p << "\n";
    std::cout << "p == &age: " << (p == &age) << "\n";

    *p = 18;                // p көрсеткен үйдің ішін өзгерттік
    std::cout << "age = " << age << "\n";

    int other = 5;
    p = &other;             // енді p басқа үйді көрсетеді
    *p += 10;
    std::cout << "other = " << other << ", age = " << age << "\n";
    return 0;
}
    $ ./main
age = 17, *p = 17
p == &age: 1
age = 18
other = 15, age = 18

    Қадамдап қарайық. p = &age болғаннан кейін *p мен age - бір үй. Сондықтан *p = 18 жазғанда age өзгерді. Одан кейін p = &other - қағазға жаңа мекенжай жаздық, енді p басқа үйді көрсетеді; *p += 10 енді other-ды өзгертті (5 → 15), ал age 18-де қалды.

    * белгісінің екі мағынасы

    Бір таңбаның екі міндеті бар: жариялау кезінде int* p - «p көрсеткіш». Өрнекте *p - «p көрсеткен мәнге жет». Бұл ең көп шатастыратын жер. Есте сақтау үшін: типтен кейінгі * - көрсеткіш типі, айнымалының алдындағы * - мәнге қол жеткізу.

    Көрсеткіштің типі маңызды: int* көрсеткіші «осы мекенжайда int жатыр» деп біледі, сондықтан *p 4 байтты оқиды. double* 8 байтты оқиды. Тип болмаса, мекенжай бойынша тұрған байттарды қалай түсіндіру керегін білмес едік.

    Сілтеме (reference)

    Сілтеме (reference) - бар айнымалының екінші аты. Ол жаңа үй емес, сол үйдің екінші есімі. Жариялануы: тип& аты = айнымалы;.

    #include <iostream>

int main() {
    int guests = 40;
    int& alias = guests;    // сілтеме: guests-тің екінші аты

    alias = 55;
    std::cout << "guests = " << guests << "\n";
    guests++;
    std::cout << "alias  = " << alias << "\n";
    std::cout << "мекенжайлар бірдей: " << (&alias == &guests) << "\n";
    return 0;
}
    $ ./main
guests = 55
alias  = 56
мекенжайлар бірдей: 1

    alias пен guests - бір айнымалының екі аты: біреуін өзгертсек, екіншісі де өзгереді. Мекенжайлары да бірдей. Сілтеменің көрсеткіштен үш айырмашылығы бар:

    • Сілтемені жариялағанда міндетті түрде бастапқы мән беру керек (int& r; қате).
    • Сілтеме ешқашан басқа айнымалыға ауыстырылмайды: ол өмір бойы бір айнымалының аты.
    • Сілтеме бос (nullptr) бола алмайды, ал көрсеткіш бола алады.

    Сілтеменің басты қолданысы - функция параметрлері. 1-аптада функцияға аргумент көшірмемен берілетінін көрдік, сондықтан swap жұмыс істемеді. Енді оны түзетеміз. Екі тәсіл бар: сілтеме және көрсеткіш:

    #include <iostream>

void swapRef(int& a, int& b) {
    int t = a;
    a = b;
    b = t;
}

void swapPtr(int* a, int* b) {
    int t = *a;
    *a = *b;
    *b = t;
}

int main() {
    int x = 5, y = 8;
    swapRef(x, y);
    std::cout << x << " " << y << "\n";
    swapPtr(&x, &y);
    std::cout << x << " " << y << "\n";
    return 0;
}
    $ ./main
8 5
5 8

    Бірінші swapRef(x, y) шақырудан кейін 8 5 болды: сілтеме арқылы функция түпнұсқаны өзгерте алды. Шақыру өте таза: көрсеткіштегідей & жазудың қажеті жоқ. Екінші, swapPtr(&x, &y), көрсеткіштермен істейді: мекенжайларды береміз, ішінде *a, *b арқылы мәндерді өзгертеміз; нәтижесінде қайтадан 5 8. Қазіргі C++ кодында көбіне сілтеме қолданылады, ал көрсеткіш «бос болуы мүмкін» немесе «динамикалық жад» жағдайларына қалдырылады.

    const сілтеме

    Ауыр деректерді (ұзын vector, ұзын string) функцияға мәнмен берсек, әр шақыруда бүкіл деректің көшірмесі жасалады: ол баяу, әрі жадты жейді. Көшірмесіз беру үшін сілтеме қолданамыз, ал функция деректі кездейсоқ бүлдірмеуі үшін const қосамыз:

    #include <iostream>
#include <string>
#include <vector>

int total(const std::vector<int>& v) {      // көшірме жоқ, өзгертуге болмайды
    int s = 0;
    for (int x : v) s += x;
    return s;
}

void shout(const std::string& text) {
    std::cout << text << "!\n";
}

int main() {
    std::vector<int> sales = {120, 90, 150, 100};
    shout("Жиыны: " + std::to_string(total(sales)));
    return 0;
}
    $ ./main
Жиыны: 460!

    Көрсеткіш арифметикасы және массив

    Көрсеткішке сан қосуға болады, бірақ бұл «мекенжайға байт қосу» емес. p + 1 «келесі элемент» дегенді білдіреді: int* болса, компилятор өзі 4 байтқа жылжытады. Бұл массивпен тығыз байланысты: массивтің атауы - оның бірінші элементіне көрсететін көрсеткіш (array-to-pointer decay).

    #include <iostream>

int main() {
    int a[5] = {12, 7, 30, 4, 9};
    int* p = a;                 // массив атауы бірінші элементке көрсетеді

    std::cout << *p << " " << *(p + 1) << " " << *(p + 4) << "\n";
    p++;                        // келесі int-ке (4 байт алға)
    std::cout << *p << "\n";
    p += 2;
    std::cout << "p - a = " << (p - a) << "\n";
    std::cout << "a[3] == *(a + 3): " << (a[3] == *(a + 3)) << "\n";

    for (int* q = a; q != a + 5; q++) std::cout << *q << " ";
    std::cout << "\n";
    return 0;
}
    $ ./main

7

    Бұдан көретініміз: *(p + 1) - p[1]-ге тең жазу. Шын мәнінде a[3] компилятор үшін *(a + 3) дегенді білдіреді. Көрсеткіштерді азайтсақ, олардың арасындағы элемент санын аламыз: p - a == 3. Соңғы цикл көрсеткішпен массивті аралап шығады (a + 5 - соңғы элементтің «артындағы» орын). Сондықтан 2-аптадағы begin()/end() итераторлары көрсеткішке ұқсайды: олар да дәл осы идеяға негізделген.

    Ескерту: көрсеткішті массивтің шегінен тыс жылжыту (p + 10, егер массив 5 элементті болса) анықталмаған мінез. Бұл өткен апта көрген индекс қатесінің дәл өзі, тек басқа жазумен.

    Массив функцияға берілгенде

    Бір маңызды салдар: массивті функцияға бергенде ол көрсеткішке айналады, ал көрсеткіш өлшемді білмейді. 2-аптада sizeof(temp) / sizeof(temp[0]) тәсілі «тек массив жарияланған жерде жұмыс істейді» деп айтқан едік; міне, себебі:

    #include <iostream>

int sumArray(int* a, int n) {
    std::cout << "функция ішінде sizeof(a) = " << sizeof(a) << "\n";
    int s = 0;
    for (int i = 0; i < n; i++) s += a[i];
    return s;
}

int main() {
    int sales[6] = {120, 90, 150, 100, 80, 60};
    std::cout << "main ішінде sizeof(sales) = " << sizeof(sales) << "\n";
    int total = sumArray(sales, 6);
    std::cout << "қосынды: " << total << "\n";
    return 0;
}
    $ ./main
main ішінде sizeof(sales) = 24
функция ішінде sizeof(a) = 8
қосынды: 600

    main ішінде sizeof(sales) - 24 (6 × 4 байт). Ал функцияның ішінде a - жай int*, оның көлемі 8 байт, яғни мекенжайдың көлемі. Функция массив қанша элементті екенін білмейді, сондықтан өлшемді (n) бөлек параметр етіп береміз. Бұл - C стиліндегі массивтердің ең үлкен әлсіздігі. std::vector және std::array мұндай мәселені жояды: олар өлшемін өздері біледі. Осы себепті қазіргі кодта функцияға const std::vector<int>& береміз.

    Қашан көрсеткіш, қашан сілтеме?

    Қарапайым ереже: әдепкі бойынша сілтеме қолданыңыз (T& немесе const T&). Көрсеткішті мына жағдайларда таңдаңыз: нысан болмауы мүмкін (nullptr), көрсеткішті басқа нысанға ауыстыру керек, немесе динамикалық жадпен жұмыс істеп жатырсыз. Сондай-ақ жад иелігі туралы шешім қабылдағанда смарт көрсеткіш таңдаңыз. Ал ескі C кодымен жұмыс істеген кезде көрсеткіштер көп кездеседі, сондықтан олардың оқылуын білу керек.

    nullptr

    Көрсеткіш «ешқайда көрсетпейді» болуы мүмкін. Бұл жағдайды nullptr деген арнайы мән білдіреді. Көрсеткішті ешқашан бастапқы мәнсіз қалдырмаңыз: не нақты мекенжай беріңіз, не nullptr:

    #include <iostream>

int main() {
    int* p = nullptr;
    if (p == nullptr) {
        std::cout << "p ешқайда көрсетпейді\n";
    }
    if (!p) std::cout << "бұл да сол мағына\n";

    int x = 4;
    p = &x;
    if (p != nullptr) std::cout << "енді *p = " << *p << "\n";
    return 0;
}

int main() {
    int* p = nullptr;

    Көрсеткіш және const

    const көрсеткішпен үйлескенде екі түрлі мағына береді. Оларды ажыратудың қарапайым жолы: const сөзі қай нәрсенің оң жағында тұрса, дәл сол тұрақты болады.

    • const int* p - «мән тұрақты»: p арқылы мәнді өзгерту мүмкін емес, бірақ p-ны басқа мекенжайға бұруға болады. Бұл - «тек оқуға арналған терезе».
    • int* const q - «көрсеткіш тұрақты»: мәнді өзгертуге болады, бірақ q басқа жерге көрсете алмайды.
    #include <iostream>

int main() {
    int a = 1, b = 2;

    const int* p = &a;     // мән тек оқылады
    p = &b;                // көрсеткішті ауыстыруға болады
    std::cout << *p << "\n";

    int* const q = &a;     // көрсеткіш тұрақты
    *q = 7;                // мәнді өзгертуге болады
    std::cout << a << "\n";
    return 0;
}

    Әр нұсқа өз шегінен шыққанда компилятор бірден тоқтатады:

    Stack және heap

    Бағдарламаның жады екі негізгі аймаққа бөлінеді:

    • Стек (stack). Жергілікті айнымалылар осында тұрады. Функция шақырылғанда оның айнымалылары үшін кадр жасалады, функция аяқталғанда кадр өзі жойылады. Өте жылдам, автоматты, бірақ өлшемі шектеулі (әдетте бірнеше мегабайт) және деректердің өмір сүру уақыты функциямен байланысты.
    • Үйме (heap). Бұл үлкен, икемді аймақ. Онда орынды біз өзіміз new арқылы сұраймыз және delete арқылы қайтарамыз. Деректер функция біткенде де өмір сүре береді, бірақ жауапкершілік бізде.

    Аналогия: стек - өз үйіңіздегі үстел: жұмыс біткенде бәрі өзі жиналады. Үйме - көпшілік қоймасы: қажетті орын аласыз, бірақ уақытында қайтармасаңыз, ол бос емес болып қала береді.

    Көрсеткіш (p) өзі стекте тұрады, ал ол көрсететін деректер үймеде жатады. Бұл сызбада p жойылса да, үймедегі деректер өзі жойылмайды: оны delete арқылы біз қайтаруымыз керек. Дәл осы нәзік жерде жад қателері туады.

    new және delete

    new үймеден орын алады және оның мекенжайын (көрсеткіш) қайтарады. delete орынды қайтарады.

    #include <iostream>

int main() {
    int* guests = new int;      // үймеден бір int сұрадық
    *guests = 120;
    std::cout << "қонақтар: " << *guests << "\n";
    delete guests;              // қайтарамыз

    int* price = new int(2500); // бастапқы мәнмен
    std::cout << "баға: " << *price << "\n";
    delete price;
    return 0;
}

баға: 2500

    Әр new-ге дәл бір delete сәйкес келуі керек. new int(2500) орынды алып, оған бірден 2500 жазады. delete-тен кейін көрсеткіш әлі де ескі мекенжайды сақтап тұр, бірақ ол мекенжай енді сіздікі емес. Мұны төменде қауіпті қателер бөлімінде көреміз.

    Динамикалық массив

    Өткен аптада std::array өлшемі компиляция кезінде белгілі болуы керек екенін білдік. new int[n] өлшемді орындалу кезінде таңдауға мүмкіндік береді: n пернетақтадан оқылуы мүмкін. Жою үшін квадрат жақшалы нұсқа қолданылады: delete[].

    #include <iostream>

int main() {
    int n;
    std::cout << "Қанша сан? ";
    std::cin >> n;

    int* data = new int[n];
    for (int i = 0; i < n; i++) std::cin >> data[i];

    long long sumSquares = 0;
    for (int i = 0; i < n; i++) sumSquares += static_cast<long long>(data[i]) * data[i];
    std::cout << "квадраттар қосындысы: " << sumSquares << "\n";

    delete[] data;
    return 0;
}

Тәжірибеде динамикалық массивтің орнына std::vector қолданыңыз: ол дәл осы жұмысты (жадты алу, көшіру, қайтару) өзі автоматты атқарады. Құрал қалай жұмыс істейтінін түсіну үшін ғана қолмен жазуды үйрендік.

    Қадамдап көрейік. Көрсеткіш, сілтеме және new/delete жадта қалай көрінетінін төмендегі визуализатормен қадамдап қараңыз: стектегі ұяшықтар, үймедегі блок, көрсеткіштен нысанға баратын сызық, сондай-ақ жад ағуы мен dangling көрсеткіш.

    Жад қателері және AddressSanitizer

    Қолмен жад басқару қателер туғызады. Төрт ең жиі қате бар. Төртеуін де біз әдейі жасап, -fsanitize=address оны қалай ұстайтынын көреміз. Санитайзер - сіздің ең жақсы көмекшіңіз: дәл осы құрал үшін біз бүкіл курс бойы g++ -std=c++17 -Wall -Wextra -fsanitize=address,undefined жалауларын қолдандық.

    RAII: ресурсты автоматты басқару

    Жад қателерінің түбі бір: new мен delete-ті қолмен жұптау. Адам ұмытады. Ал компьютер ұмытпайды. C++-тың ең күшті идеясы осыған негізделген: RAII (Resource Acquisition Is Initialization, «ресурс алу - инициализация»). Қысқаша мағынасы: ресурсты (жад, файл, ілмек) нысанның ішінде ұстаймыз, нысан өмір басында ресурсты алады, ал нысан жойылғанда деструктор оны автоматты қайтарады. Нысан стекте тұрса, ол блоктан шыққанда өзі жойылады, ал сонымен бірге ресурс та босайды.

    Мұнда struct ішінде екі арнайы функция бар: конструктор (нысан жасалғанда орындалады) және деструктор (~ белгісімен, нысан жойылғанда орындалады). Класстарды 4-аптада толық үйренеміз, ал қазір тек олардың не істейтінін бақылайық:

    #include <iostream>
#include <string>

struct Shanyrak {
    std::string name;
    Shanyrak(std::string n) : name(n) { std::cout << "ашылды: " << name << "\n"; }
    ~Shanyrak() { std::cout << "жабылды: " << name << "\n"; }
};

int main() {
    std::cout << "main басталды\n";
    {
        Shanyrak a("үй A");
        Shanyrak b("үй B");
        std::cout << "блок ішінде\n";
    }
    std::cout << "main аяқталуда\n";
    return 0;
}

Егер біз бұл ішке return жазып, ерте шықсақ, немесе ерекше жағдай (exception) туса да, деструктор шақырылар еді. Қолмен delete жазғанда мұндай кепілдік жоқ.

    Смарт көрсеткіштер

    Стандартты кітапхана RAII-ді жадқа қолданатын дайын құралдар береді: смарт көрсеткіштер (smart pointers, #include <memory>). Олар көрсеткіш сияқты жазылады (*, ->), бірақ нысанды өздері жояды.

    std::unique_ptr

    Нысанға жалғыз ие. Иесі жойылғанда нысан да жойылады. Көшіруге болмайды, тек иелікті беруге (std::move) болады. Жасаудың ұсынылатын жолы - std::make_unique.

    #include <iostream>
#include <memory>
#include <string>

struct Guest {
    std::string name;
    Guest(std::string n) : name(n) { std::cout << "келді: " << name << "\n"; }
    ~Guest() { std::cout << "кетті: " << name << "\n"; }
};

int main() {
    std::unique_ptr<Guest> a = std::make_unique<Guest>("Айгерім");
    std::cout << "сәлем, " << a->name << "\n";

    std::unique_ptr<Guest> b = std::move(a);      // иелік берілді
    std::cout << "a бос ма? " << (a == nullptr) << "\n";
    std::cout << "b иесі: " << b->name << "\n";
    return 0;
}

    std::shared_ptr

    Нысанды бірнеше ие бөліседі. Ішінде санауыш бар: көшіргенде артады, ие жойылғанда кемиді, нөлге жеткенде нысан жойылады.

    Қайсысын таңдау керек? Әдепкі ереже: нысанның иесі бір ғана болса, unique_ptr; ал нақты бөлісу қажет болса ғана shared_ptr. Көп жағдайда мүлде көрсеткіш керек емес: жай жергілікті айнымалы немесе std::vector жеткілікті. Қазіргі C++ кодында жалаң new/delete дерлік кездеспейді.

    Тағы бір сөз: құрылымға көрсеткіш арқылы қол жеткізгенде -> операторы қолданылады. p->strings - (*p).strings дегеннің қысқа жазылуы. Мысал ретінде домбыра құрылымын алайық:

struct Dombyra {
    std::string owner;
    int strings;
};

    d->strings = 2;                       // (*d).strings сияқты
    std::cout << d->owner << " домбырасын келтірді\n";
}

int main() {
    Dombyra d{"Ержан", 3};
    Dombyra* p = &d;
    std::cout << p->owner << ": " << p->strings << " ішек\n";
    tune(p);
    std::cout << d.owner << ": " << d.strings << " ішек\n";
    return 0;
}

    Көрсеткішті функциядан қайтару

    Смарт көрсеткіш үймедегі нысанды функциядан қауіпсіз шығарып береді. Бұл өткен бөлімдегі «жергілікті айнымалының мекенжайын қайтару» қатесінің дұрыс балама нұсқасы: нысан стекте емес, үймеде тұр, ал иелік return арқылы шақырушыға беріледі.

    #include <iostream>
#include <memory>
#include <string>

struct Dombyra {
    std::string owner;
    Dombyra(std::string o) : owner(o) { std::cout << "домбыра жасалды: " << owner << "\n"; }
    ~Dombyra() { std::cout << "домбыра жойылды: " << owner << "\n"; }
};

std::unique_ptr<Dombyra> makeDombyra(const std::string& owner) {
    return std::make_unique<Dombyra>(owner);   // үймедегі нысан функциядан шығады
}

int main() {
    std::cout << "main басталды\n";
    {
        auto d = makeDombyra("Нұрлан");
        std::cout << "иесі: " << d->owner << "\n";
    }
    std::cout << "main аяқталды\n";
    return 0;
}

    makeDombyra функциясы нысанды үймеде жасап, unique_ptr арқылы main-ге береді. Ішкі блок аяқталғанда d жойылады, деструктор нысанды өзі қайтарады: «домбыра жойылды». Қолмен delete жоқ, ағу жоқ, ескірген мекенжай да жоқ. Мұндай функцияны зауыт (factory) дейді. Бұл идеяны 4-аптада класстармен және нысандармен жұмыс істегенде көп қолданамыз.

    Жиі қателер

    • delete ұмыту. Жад ағуы. Шешім: смарт көрсеткіш немесе контейнер.
    • delete екі рет шақыру (double free). Бағдарлама құлайды. delete-тен кейін p = nullptr.
    • new[] үшін delete жазу. Дұрысы delete[].
    • Босатылған жадты оқу/жазу. Салбырап қалған көрсеткіш.
    • Жергілікті айнымалының мекенжайын қайтару. Функция біткенде ол жойылады.
    • Бастапқы мәнсіз көрсеткіш. int* p; кездейсоқ мекенжайды көрсетеді. Әрдайым = nullptr.
    • nullptr-ды дереференс жасау. Segfault. Алдымен тексеріңіз.
    • Векторға push_back жасаған соң ескі сілтемені қолдану. Вектор көшеді.
    • * және & мағыналарын шатастыру. Жариялауда тип бөлігі, өрнекте амал.

    Қорытынды

    • Жад - мекенжайы бар ұяшықтар; &x мекенжай береді; көрсеткіш мекенжайды сақтайды; *p мәнге жеткізеді.
    • Сілтеме - айнымалының екінші аты; const T& көшірмесіз тек оқуға беру үшін.
    • p + 1 келесі элементке жылжиды; массив атауы бірінші элементке көрсетеді.
    • nullptr - «ешқайда көрсетпейді»; дереференс жасамас бұрын тексеру.
    • Стек автоматты және жылдам; үйме қолмен басқарылады: new/delete, new[]/delete[].
    • Негізгі қателер: жад ағуы, use-after-free, шекарадан шығу, ескірген көрсеткіш. AddressSanitizer оларды ұстайды.
    • RAII: ресурс нысанның ішінде, деструктор оны өзі қайтарады. unique_ptr - жалғыз ие, shared_ptr - бөлісетін иелер.

    Келесі аптада өз типтерімізді жасаймыз: класстар және нысандар.

    Өзіңізді тексеріп көріңіз:

    • & және * операторларының айырмасын түсіндіре аламын.
    • Сілтеме мен көрсеткіштің үш айырмашылығын айта аламын.
    • Стек пен үйменің айырмасын түсіндіре аламын.
    • Жад ағуы мен салбыраған көрсеткіштің не екенін білемін.
    • -fsanitize=address арқылы бағдарламаны тексере аламын.
    • unique_ptr пен shared_ptr қашан қолданылатынын білемін.

    Өзіңізді тексеріңіз

    1. Бағдарлама не шығарады? int x = 7; int* p = &x; *p = 9; std::cout << x;

    p - x-тің мекенжайы. *p = 9 сол үйдің ішіндегіні өзгертеді, демек x 9 болады.

    2. &x өрнегі нені білдіреді?

    Өрнектегі унарлы & - «мекенжайын ал». Жариялауда (int& r = x;) & басқа мағына береді: сілтеме типі.

    3. Сілтеме мен көрсеткіштің қайсы айырмашылығы дұрыс?

    Сілтеме - бір айнымалының мәңгілік екінші аты: бос болмайды, ауыспайды. Көрсеткіш бос болуы және басқа мекенжайға ауысуы мүмкін.

    4. int* a = new int[5]; жадын қалай дұрыс босатамыз?

    new[] арқылы алынған массив delete[] арқылы қайтарылады. Тек a = nullptr жазу жадты қайтармайды, ол ағуға әкеледі.

    5. Төмендегі функцияның қатесі қайсы? int* f() { int x = 5; return &x; }

    x стекте тұр және f аяқталғанда жойылады. Қайтарылған мекенжай жарамсыз. Компилятор бұл жерде «address of local variable returned» деп ескертеді.

    6. std::unique_ptr<int> a = std::make_unique<int>(5); std::unique_ptr<int> b = a; нәтижесі қандай?

    unique_ptr көшіру конструкторы өшірілген. Иелікті беру үшін std::move(a) жазу керек.

    7. RAII идеясы қандай?

    RAII: ресурсты алу нысанды жасаумен, қайтару деструктормен байланысты. Сондықтан ұмыту мүмкін емес.

    8. Қайсысын -fsanitize=address тауып бере алады?

    AddressSanitizer жад қателерін бағдарлама жұмыс істеп тұрғанда ұстайды: ағу, босатылған жадты қолдану, шекарадан шығу. Логикалық қатені (дұрыс емес есеп) ол көрмейді.

    Қосымша ойлану сұрақтары (жауабы жоқ, өзіңіз іздеңіз)
    • int* p = new int(5); int* q = p; delete p; delete q; кодында не болады? Неге?
    • Неге unique_ptr массивті функцияға көшіре алмайды, бірақ сілтеме арқылы бере алады?
    • Егер shared_ptr екі нысаны бір-біріне көрсетсе (циклдік байланыс), санауыш нөлге жете ме?
    • Стекте жергілікті массив жасап, оның өлшемін өте үлкен қылсақ (мысалы, int a[10000000]) не болады деп ойлайсыз?

    Жаттығулар

    Жауабы бар тапсырмаларды осы жерде тексеріңіз, ал бағдарлама жазатындарды өз компьютеріңізде -fsanitize=address,undefined жалауларымен іске қосыңыз.

    Көрсеткіш арқылы өзгерту

    Бағдарлама не шығарады?

    #include <iostream>

int main() {
    int a = 10;
    int* p = &a;
    *p += 5;
    std::cout << a << "\n";
    return 0;
}
    Кеңес

    *p += 5 - a-ның мәні осы жерде өзгереді.

    Шешімі

    p - a-ның мекенжайы. *p += 5 дегені a += 5: 10 + 5 = 15.

    $ ./main

    Жеңіл

    Сілтеме

    Бағдарлама не шығарады?

    #include <iostream>

int main() {
    int x = 3;
    int& r = x;
    r *= 4;
    std::cout << x << "\n";
    return 0;
}
    Кеңес

    r - x-тің басқа аты. r-ді өзгерту - x-ті өзгерту.

    Шешімі

    r *= 4 - x *= 4: 3 · 4 = 12.

    Көрсеткіш арифметикасы

    Бағдарлама не шығарады?

    #include <iostream>

int main() {
    int a[] = {5, 10, 15, 20};

    std::cout << *p + *(p - 1) << "\n";

}
    Кеңес

    Алдымен p қай элементке көрсетеді? p += 2 болғанда p = &a[2]. *(p - 1) - бір алдыңғы элемент.

    Шешімі

    p = &a[2], *p = 15, *(p - 1) = a[1] = 10. Қосындысы 25.

    Орташа

    Көрсеткішпен алмастыру (арифметикалық айла)

    Бағдарлама не шығарады? Екі санды бос орынмен жазыңыз.

    #include <iostream>

void f(int* a, int* b) {
    *a = *a + *b;
    *b = *a - *b;
    *a = *a - *b;
}

int main() {
    int x = 5, y = 8;
    f(&x, &y);
    std::cout << x << " " << y << "\n";
    return 0;
}
    Кеңес

    Қадамдап жазыңыз: a = 5, b = 8. 1) *a = 5 + 8 = 13. 2) *b = 13 - 8 = 5. 3) *a = 13 - 5 = 8.

    Шешімі

    Бұл үшінші айнымалысыз алмастыру: нәтиже 8 5. Көрсеткіш арқылы функция main-дегі x пен y-ті шынымен өзгертті. (Екі көрсеткіш бір айнымалыға сілтесе, бұл әдіс жұмыс істемейді. Оны өзіңіз ойлап көріңіз.)

    Қиын

    Динамикалық массив

    Қолданушыдан n санын, содан кейін n бүтін санды оқып, оларды new int[n] массивіне сақтап, квадраттарының қосындысын шығаратын бағдарлама жазыңыз. Соңында жадты босатыңыз. Енгізу: 4 және 1 2 3 4. Нәтиже қандай?

    Кеңес

    int* data = new int[n]; - оқу циклі - есептеу циклі - delete[] data;. Қосындыны long long-та жинаңыз: үлкен сандарда int толып кетуі мүмкін.

    Шешімі
    #include <iostream>

int main() {
    int n;
    std::cout << "Қанша сан? ";
    std::cin >> n;

    int* data = new int[n];
    for (int i = 0; i < n; i++) std::cin >> data[i];

    long long sumSquares = 0;
    for (int i = 0; i < n; i++) sumSquares += static_cast<long long>(data[i]) * data[i];
    std::cout << "квадраттар қосындысы: " << sumSquares << "\n";

    delete[] data;
    return 0;
}
    $ ./main
Қанша сан? 4
1 2 3 4
квадраттар қосындысы: 30

    1 + 4 + 9 + 16 = 30.

    Өзін тексеру тізімі
    • -fsanitize=address,undefined ескертусіз, қатесіз жұмыс істейді.
    • delete[] жазылған, санитайзер жад ағуын көрсетпейді.
    • n = 1 және n = 0 үшін де бағдарлама дұрыс жұмыс істейді.

    Қиын

    Қанша байт ағып кетті?

    Төмендегі бағдарламаны -fsanitize=address арқылы іске қосқанда LeakSanitizer қорытынды жолда қанша байт ағып кеткенін көрсетеді. Санды жазыңыз. Соңынан бағдарламаны ағусыз қылу үшін түзетіңіз.

    #include <iostream>

int main() {
    int* a = new int[10];
    double* b = new double(1.5);
    a[0] = 1;
    std::cout << a[0] << " " << *b << "\n";
    return 0;
}
    Кеңес

    10 int - қанша байт? sizeof(int) = 4. double - 8 байт. Екеуі де delete жасалмаған.

    Шешімі

    10 · 4 + 8 = 48 байт, 2 бөлікте. Түзету: delete[] a; және delete b; жазу. Одан да жақсысы: std::vector<int> a(10); және auto b = std::make_unique<double>(1.5);. Іске қосқанда санитайзердің қорытындысы:
