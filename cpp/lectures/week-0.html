    C++-ке кіріспе

    Бұл аптада C++ тілімен алғаш танысамыз: мәтіндік файлдан орындалатын бағдарлама қалай туатынын көреміз, экранға сөз шығарып, пернетақтадан сан оқимыз, типтермен, арифметикамен және компьютер санының «шекарасымен» таныламыз. Ең бастысы - қателерді қорықпай оқуды үйренеміз.

    Неге C++?

    Телефондағы ойын, браузердің қозғалтқышы, банктің жылдам төлем жүйесі, роботтың бақылау бағдарламасы: осының көбі C++ тілінде жазылған. Себебі қарапайым: C++ бағдарламалары өте жылдам жұмыс істейді және компьютердің жадын тікелей басқаруға мүмкіндік береді. Python сияқты тілде «қобдишаға салып қой» деп айтсаңыз жеткілікті, ал C++-та қобдиша қандай үлкен, қайда тұр, қашан босайды - осының бәрін сіз білесіз. Бұл қиындау, бірақ сол себепті компьютердің қалай жұмыс істейтінін шын мәнінде түсінесіз.

    Бұл курс 8 аптаға созылады. Бүгінгі 0-аптада негізді қалаймыз: бағдарламаның жолын, алғашқы кодты, типтерді және қателерді. Келесі апталарда шарттар мен циклдер, массивтер, жад пен көрсеткіштер, кейін класстар келеді. Үй салу сияқты: алдымен іргетас.

    Қалай оқимыз

    Әр лекцияда мысалдарды өз компьютеріңізде жазып, іске қосыңыз. Көзбен оқу мен қолмен жазудың арасы жер мен көктей. Терминалдағы нәтижелерді біз шынымен іске қосып алдық, ал сіздікі де дәл солай шығуы керек. Егер шықпаса, ол қате емес, ол оқу мүмкіндігі.

    Бағдарламаның жолы

    Python-да файлды жазып, бірден python файл.py деп іске қосатынбыз. C++-та жағдай басқаша. Компьютердің процессоры біздің жазған cout << "Сәлем" жолын түсінбейді: ол тек нөлдер мен бірлерден тұратын машина кодын (machine code) ұғады. Сондықтан мәтінді машина кодына аударатын бағдарлама керек. Ол бағдарлама - компилятор (compiler). Біз g++ деген компиляторды қолданамыз.

    Шын мәнінде g++ бір емес, үш жұмысты бірінен соң бірін орындайды:

    1. Препроцессор (preprocessor). Мәтінді компиляторға дейін дайындайды. Ең танымал жұмысы: #include деген жолды көргенде, көрсетілген файлдың бүкіл мазмұнын сол орынға көшіріп қояды. Барлық # белгісімен басталатын жолдар - препроцессорға арналған нұсқау.
    2. Компилятор. Таза C++ мәтінін оқып, грамматикасын тексереді және әр файлдан объектті файл (main.o) жасайды. Бұл файлда машина коды бар, бірақ ол әлі толық емес: cout дегеннің ішінде не бар екенін компилятор бұл сәтте білмейді, тек «ондай нәрсе бар» деп есіне жазып қояды.
    3. Линкер (linker). Объектті файлдарды бір-біріне және стандартты кітапханаға жалғайды. Мысалы, cout-тың нақты кодын кітапханадан тауып, бағдарламаға қосады. Нәтижесінде орындалатын файл шығады.

    Бұл бөлу тек теория емес. Қателердің түрі де осыған байланысты: препроцессор мен компилятордан шыққан қате - компиляция қатесі, линкерден шыққан - жалғау (link) қатесі, ал бағдарлама іске қосылған соң шыққаны - орындалу қатесі. Төменде үшеуін де өз көзіңізбен көресіз.

    Ойланып көріңіз: неге Python-да осындай бөлек қадам жоқ сияқты көрінеді?

    Python бағдарламасын интерпретатор жолма-жол оқып, сол сәтте орындайды. Ал C++ бағдарламасы алдын ала толық аударылады. Аудару жұмысы бір рет жасалып қойғандықтан, іске қосылғанда ештеңе баяулатпайды. Бұл алдын ала аударылған кітап пен сіз сөйлеп тұрғанда аудармашы тілмаштың арасындағы айырмаға ұқсайды.

    Алғашқы бағдарлама

    Бір файл жасайық: main.cpp. Қазақша қарсы алатын ең кішкентай бағдарлама:

    #include <iostream>

int main() {
    std::cout << "Сәлем, әлем!" << std::endl;
    return 0;
}

    Енді оны жолма-жол талдайық, өйткені әр сөздің өз мағынасы бар.

    • #include <iostream>. «iostream файлын осы жерге қос» дегенді білдіреді. iostream - input/output stream, яғни енгізу-шығару ағыны. Онсыз cout дегенді компилятор білмейді.
    • int main() { ... }. Бағдарлама осы функциядан басталады. main деген атау міндетті. Алдындағы int - функция аяқталғанда операциялық жүйеге бүтін сан қайтаратынын білдіреді.
    • std::cout. cout - экранға шығарушы ағын, ал std:: - «стандартты кітапханадағы» дегенді білдіретін есімдер кеңістігі (namespace). Бұл жазу «стандартты кітапханадағы cout» деген мағына береді.
    • <<. Деректерді ағынға «жіберетін» оператор. Нұсқасы сол жаққа қарай ағады: мәтін ағынға құйылады. Оны тізбектеп жазуға болады.
    • std::endl. Жаңа жолға өту. Оның жеңіл баламасы - "\n".
    • return 0;. «Бәрі жақсы аяқталды» деген белгі. main ішінде оны жазбасаңыз да, компилятор өзі қосып қояды.
    • Әр нұсқаудың соңындағы ; міндетті. Қазақ тіліндегі нүкте сияқты: ойдың аяқталғанын білдіреді.

    Құрастырып, іске қосайық. Терминалда файл тұрған қалтаға барып:

    g++ -std=c++17 main.cpp -o main
./main

    -std=c++17 - тілдің 2017 жылғы стандартын қолдан деген сөз. -o main - нәтиже файлының атын main деп қой дегені. Нәтиже:

    $ ./main
Сәлем, әлем!

    Тілдің кириллицаны (қазақ әріптерін) қиналмай шығарғанын көрдіңіз. Ол үшін файл UTF-8 кодтауында сақталуы керек. VS Code пен көптеген редакторлар оны әдепкі бойынша солай сақтайды.

    «\n» және std::endl

    Екеуі де жаңа жолға өткізеді. std::endl қосымша шығару буферін де «босатады», сондықтан жиі шақырылса, сәл баяу. Бастаушы бағдарламаларда айырмашылық байқалмайды, бірақ әдетке айналдыру үшін көбіне "\n" жазамыз. Бағдарлама құлап қалғанда да соңғы жолдың экранға шығуы маңызды болатын жағдайда ғана std::endl керек.

    Өз компьютеріңде іске қос

    Браузерде C++ орындалмайды, сондықтан компилятор керек. Орнату жолы жүйеге қарай өзгереді.

    • Linux (Ubuntu/Debian): sudo apt install g++. Fedora жүйесінде: sudo dnf install gcc-c++.
    • macOS: терминалда xcode-select --install деп жазыңыз. Ол clang компиляторын орнатады, g++ командасы да соған сілтейді. Командалардың қолданылуы бірдей.
    • Windows: ең ыңғайлысы - WSL (Windows Subsystem for Linux) орнатып, ішінде Ubuntu пайдалану. Балама: MSYS2 орнатып, pacman -S mingw-w64-ucrt-x86_64-gcc командасымен MinGW-w64 алу. Осы курстың соңғы тақырыптарындағы -fsanitize=address тәсілі MinGW-да жұмыс істемеуі мүмкін, ал WSL-де істейді.

    Редактор ретінде VS Code жеткілікті. Сайттан жүктеп, «C/C++» кеңейтімін қосыңыз. Орнатқаннан кейін компиляторды тексеріңіз:

    g++ --version

    Версия нөмірі шықса, дайынсыз. Енді ең маңызды ұсыныс: компиляторды қатал жұмыс істеуге мәжбүрлейтін жалауларды әрдайым қосыңыз:

    g++ -std=c++17 -Wall -Wextra main.cpp -o main
    • -Wall - «барлық маңызды ескертулерді көрсет» (warnings).
    • -Wextra - тағы да қосымша ескертулер.
    • Курстың соңына қарай қосатынымыз: -fsanitize=address,undefined. Ол бағдарлама жұмыс істеп тұрғанда жад пен арифметикадағы жасырын қателерді ұстайды. Біз осы лекциядағы барлық мысалды дәл осы жалаулармен іске қостық.

    Ескерту (warning) - қате емес, бағдарлама жұмыс істей береді. Бірақ ескерту көбіне «мұнда бір нәрсе күмәнді» деген дабыл. Тәжірибелі бағдарламашылар ескертусіз код жазуға тырысады. Бір ұсыныс: бағдарлама дұрыс жұмыс істесе де, ескерту шықса, оның себебін түсінбей тұрып өткізіп жібермеңіз.

    Енгізу: std::cin

    Бағдарлама тек сөйлеп қана қоймай, тыңдай да алуы керек. std::cin - пернетақтадан оқитын ағын, ал оператор бұл жолы >>, яғни көрсеткі кері бағытта: деректер ағыннан айнымалыға құйылады. Наурыз мейрамына жиналатын қонақтарды санайтын бағдарлама:

    #include <iostream>

int main() {
    int guests;
    std::cout << "Наурыз мейрамына қанша қонақ келеді? ";
    std::cin >> guests;

    int plates = guests * 3;
    std::cout << "Қонақ саны: " << guests << "\n";
    std::cout << "Қажетті тарелка: " << plates << "\n";
    return 0;
}

    Мұнда int guests; - бүтін сан сақтайтын «қобдиша» (айнымалы). Оның атын біз қойдық. cin >> guests пернетақтадан жазылған санды сол қобдишаға салады. Іске қосайық (пернетақтадан енгізілген бөлігі - 12):

    $ ./main
Наурыз мейрамына қанша қонақ келеді? 12
Қонақ саны: 12
Қажетті тарелка: 36

    Тарелка саны қонақ санынан 3 есе көп: 12 * 3 = 36. Мұндағы * - көбейту белгісі, ол туралы кейінірек толығырақ айтамыз.

    Жиі қате: cout және cin бағыты

    cout << (шығару) - екі кіші белгі, ал cin >> (енгізу) - екі үлкен белгі. Есте сақтау үшін: көрсеткі деректердің қайда барып жатқанын көрсетеді. cout-қа қарай жібереміз (<<), cin-нен айнымалыға аламыз (>>).

    Егер қолданушы сан орнына «қырық» деп жазса не болады? Мұны 2-аптада, енгізу ағыны мәселелерін талдағанда егжей-тегжейлі қараймыз. Әзірге тек санды дұрыс енгізеді деп ойлаймыз.

    Айнымалылар мен типтер

    C++ - статикалық типтелген (statically typed) тіл. Бұл дегеніміз: әр айнымалының типін жазғанда айтуымыз керек, және ол кейін өзгермейді. Python-да x = 5 деп жазып, кейін x = "сәлем" деуге болады. C++-та int x = 5; болса, x мәңгі бүтін сан қалады. Бұл қатаңдық қателерді бағдарлама іске қосылмай тұрып-ақ ұстап береді.

    Алты негізгі тип:

    ТипНе сақтайдыМысал
    intбүтін сан (шамамен ±2 миллиард)int age = 17;
    long longөте үлкен бүтін санlong long population = 20000000LL;
    doubleбөлшек санdouble price = 1250.5;
    charбір таңба (қос емес, бір тырнақшамен)char grade = 'A';
    booltrue немесе falsebool isNauryz = true;
    std::stringмәтін (қос тырнақша)std::string city = "Астана";

    Бір бағдарламада бәрін шығарып, сонымен қатар әр типтің жадтағы көлемін (sizeof, байтпен) өлшейік:

    #include <iostream>
#include <string>

int main() {
    int age = 17;
    long long population = 20000000LL;
    double price = 1250.5;
    char grade = 'A';
    bool isNauryz = true;
    std::string city = "Астана";

    std::cout << std::boolalpha;
    std::cout << "age        = " << age << "\n";
    std::cout << "population = " << population << "\n";
    std::cout << "price      = " << price << "\n";
    std::cout << "grade      = " << grade << "\n";
    std::cout << "isNauryz   = " << isNauryz << "\n";
    std::cout << "city       = " << city << "\n";

    std::cout << "sizeof(int) = " << sizeof(int) << "\n";
    std::cout << "sizeof(long long) = " << sizeof(long long) << "\n";
    std::cout << "sizeof(double) = " << sizeof(double) << "\n";
    std::cout << "sizeof(char) = " << sizeof(char) << "\n";
    std::cout << "sizeof(bool) = " << sizeof(bool) << "\n";
    return 0;
}
    $ ./main
age        = 17
population = 20000000
price      = 1250.5
grade      = A
isNauryz   = true
city       = Астана
sizeof(int) = 4
sizeof(long long) = 8
sizeof(double) = 8
sizeof(char) = 1
sizeof(bool) = 1

    Назар аударыңыз: std::boolalpha жазбасақ, bool мәні 1 немесе 0 болып шығар еді. Ал көлемдер (4, 8, 8, 1, 1) бұл компьютерде шықты. Басқа жүйеде ерекшелік болуы мүмкін, бірақ қазіргі 64-биттік компьютерлерде көбіне осылай.

    Айнымалыны жариялағанда мәнін бірден беріңіз. int x; деп жазып, мән бермесеңіз, ішінде жад қалдығы (кездейсоқ мән) тұрады. Мұндай айнымалыны оқу - қауіпті қате.

    Айнымалы жадта қалай тұрады?

    Айнымалы - жадтағы атау берілген орын. int age = 17; жолы үш нәрсе істейді: 4 байт орын сақтайды, оған age деген ат қояды және оған 17 санын жазады. Кейін age деп жазғанда компилятор сол орынды табады. Жадты қатар тұрған ұяшықтардан тұратын үлкен тор деп елестетіңіз; әр ұяшықтың өз нөмірі (мекенжайы) бар. Мекенжай туралы 3-аптада егжей-тегжейлі айтамыз, ал әзірге есте сақтайық: тип айнымалының қанша орын алатынын және ондағы байттарды қалай түсіну керегін анықтайды.

    Айнымалыға ат қою

    Ат әріп немесе _ белгісінен басталады, ішінде сан болуы мүмкін, бос орын болмайды, ал int, return сияқты кілт сөздерді ат ретінде қолдануға болмайды. Бас әріп пен кіші әріп өзгеше: Age мен age - екі бөлек айнымалы. Ат мағыналы болсын: guestCount деген x дегеннен әлдеқайда түсінікті. Тіпті сіз өзіңіз бір аптадан кейін өз кодыңызды оқығанда алғыс айтасыз.

    Мәтін: std::string

    Мәтін үшін #include <string> қосып, std::string қолданамыз. Жолдарды + арқылы жалғауға болады:

    #include <iostream>
#include <string>

int main() {
    std::string name;
    std::cout << "Атыңыз: ";
    std::cin >> name;

    std::string greeting = "Қош келдіңіз, " + name + "!";
    std::cout << greeting << "\n";
    std::cout << "Жолдың ұзындығы (байт): " << greeting.size() << "\n";
    return 0;
}
    $ ./main

Қош келдіңіз, Айгерім!

    Мұндағы маңызды ерекшелік: «Қош келдіңіз, Айгерім!» жолының ұзындығы 40 шықты, бірақ көзбен санасаңыз, 22 таңба ғана. Себебі кирилл әріптері UTF-8-де екі байт орын алады, ал size() таңбаны емес байтты санайды. Латын әріптері мен цифрлар бір байттан. Бұл туралы 2-аптада тағы айтамыз. Әзірге есте сақтаңыз: std::string - байттар тізбегі.

    Тағы бір ескерту: cin >> name жолды бірінші бос орынға дейін ғана оқиды. «Айгерім Сәрсенбек» деп жазсаңыз, name-ге тек «Айгерім» түседі. Бүкіл жолды оқу жолын 2-аптада (getline) үйренеміз.

    Арифметика

    Төрт амал таныс: + - * /. Бесінші оператор - % (қалдық, modulo): 17 % 5 нәтижесі 2, себебі 17 = 3·5 + 2. Мұны сағат пен күнтізбеде жиі қолданамыз: сағат 23 болса, 5 сағаттан кейін (23 + 5) % 24 = 4.

    Қарапайым дүние көрінгенмен, / операторының бір күтпеген мінезі бар. Теңге айырбасымен бастайық, ол қалыпты жұмыс істейді:

    #include <iostream>
#include <iomanip>

int main() {
    const double rate = 480.0;  // шартты бағам: 1 доллар = 480 теңге
    double tenge;
    std::cout << "Теңге сомасы: ";
    std::cin >> tenge;

    double dollars = tenge / rate;
    std::cout << std::fixed << std::setprecision(2);
    std::cout << tenge << " тг = " << dollars << " $\n";
    return 0;
}
    $ ./main
Теңге сомасы: 150000
150000.00 тг = 312.50 $

    Мұнда const double rate = 480.0; - бағам. Бағамның нақты мәні уақытқа қарай өзгеріп тұрады, бұл тек үлгі сан. std::fixed пен std::setprecision(2) нәтижені нүктеден кейін 2 таңбамен шығарады (#include <iomanip> керек). Бөлгіш пен бөлінгіш екеуі де double болғандықтан, бөлу дәл орындалды.

    Қысқа жазылу және басымдық

    Айнымалының мәнін өзгерту өте жиі қажет болады, сондықтан C++-та қысқа жазылу бар: x += 5 дегені x = x + 5 дегенмен бірдей. Дәл солай -=, *=, /=, %=. Бір қосу үшін x++, бір алу үшін x-- жазамыз. Бұлар циклдерде үнемі кездеседі.

    Математикадағыдай, көбейту мен бөлу қосу мен алудан бұрын орындалады, ал жақша басымдықты өзгертеді. Кіші бағдарламада бәрін бірге көрейік. Сонымен қатар char шынында бүтін сан екенін де көреміз: әр таңбаның өз коды бар ('A' - 65). Сондықтан таңбаға сан қосуға болады:

    #include <iostream>

int main() {
    int score = 10;
    score += 5;
    score -= 3;
    score *= 2;
    score++;
    std::cout << "score = " << score << "\n";

    int a = 2 + 3 * 4;
    int b = (2 + 3) * 4;
    std::cout << "a = " << a << ", b = " << b << "\n";

    char letter = 'A';
    letter = letter + 2;
    std::cout << "letter = " << letter << ", код = " << static_cast<int>(letter) << "\n";
    return 0;
}
    $ ./main
score = 25
a = 14, b = 20
letter = C, код = 67

    Қадамдап есептейік: 10 + 5 = 15, 15 - 3 = 12, 12 * 2 = 24, 24 + 1 = 25. Әрі 2 + 3 * 4 = 14, ал (2 + 3) * 4 = 20. Таңбаға 2 қосқанда 'A' (65) 'C' (67) болды. Бұл идея шифрлау бағдарламаларында да қолданылады.

    Бүтін бөлу

    Енді екі операнд та int болсын. Мысалы, 25 қонақты 6 адамдық үстелге отырғызамыз:

    #include <iostream>

int main() {
    int guests = 25;
    int perTable = 6;

    std::cout << "25 / 6   = " << guests / perTable << "\n";
    std::cout << "25 % 6   = " << guests % perTable << "\n";
    std::cout << "25.0 / 6 = " << 25.0 / perTable << "\n";

    double exact = static_cast<double>(guests) / perTable;
    std::cout << "static_cast: " << exact << "\n";

    int tables = (guests + perTable - 1) / perTable;
    std::cout << "Керек үстел: " << tables << "\n";
    return 0;
}
    $ ./main
25 / 6   = 4
25 % 6   = 1
25.0 / 6 = 4.16667
static_cast: 4.16667
Керек үстел: 5

    Қорытынды: екі бүтін санды бөлсеңіз, нәтиже де бүтін болады, бөлшек бөлігі қиылып тасталады (integer division). 25 / 6 жуық мәні 4,17, бірақ C++ 4 береді. Ал егер бір операнд double болса (25.0 / 6), бүкіл есептеу бөлшек түрінде жүреді. Бүтін айнымалыны бөлшек ретінде бөлгіңіз келсе, оны static_cast<double>(guests) арқылы түрлендіріңіз.

    Соңғы жолда пайдалы амал бар: жоғары қарай дөңгелектеу. 25 қонақ үшін 4 үстел жетпейді, 5 керек. Формула: (guests + perTable - 1) / perTable. Неге жұмыс істейді? Қалдық болса, қосылған perTable - 1 нәтижені дәл келесі бүтінге итереді, ал қалдық болмаса, ештеңе өзгертпейді.

    Ойланып көріңіз: double r = 5 / 2; деген жолда r неге тең?

    2 емес, 2.5 да емес: нәтиже 2. Алдымен оң жағы есептеледі: 5 / 2 екі бүтін сан болғандықтан, бүтін бөлу жасалады және 2 шығады. Тек содан кейін бұл 2 санды double-ға айналдырып r-ге салады: r = 2.0. Тип есептеудің қайда орындалатынын анықтайды, қайда сақталатынын емес.

    Толып кету

    Компьютердің жадында санға берілген орын шектеулі. int 4 байт, яғни 32 бит алады, сондықтан онда шамамен екі миллиардқа дейінгі сан сыяды. Осы шектен асып кетсе не болады? Сағат циферблатын елестетіңіз: 12-ден кейін 1 келеді. int-те де шамамен осындай «айналу» болады.

    #include <iostream>
#include <climits>

int main() {
    int big = INT_MAX;
    std::cout << "INT_MAX = " << big << "\n";

    int next = big + 1;
    std::cout << "big + 1 = " << next << "\n";

    unsigned char c = 255;
    c = c + 1;
    std::cout << "unsigned char 255 + 1 = " << static_cast<int>(c) << "\n";
    return 0;
}
    $ ./main
INT_MAX = 2147483647
main.cpp:8:9: runtime error: signed integer overflow: 2147483647 + 1 cannot be represented in type 'int'
big + 1 = -2147483648
unsigned char 255 + 1 = 0

    Бірінші қызық: INT_MAX + 1 нәтижесі -2147483648 болды. Екіншіден, бағдарлама құлаған жоқ, оның орнына санитайзер (-fsanitize=undefined) «runtime error: signed integer overflow» деп ескертті. Негізінде таңбалы int толып кетуі C++ тілінде анықталмаған мінез (undefined behavior): стандарт нәтиженің қандай болатынын кепілдендірмейді. Біздің компьютерде «айналып кетті», бірақ басқа компиляторда, басқа параметрмен ол мүлде өзгеше жұмыс істеуі мүмкін. Таңбасыз типтер (мысалы unsigned char) үшін айналу ережесі бекітілген: 255 + 1 нәтижесі 0.

    Нақты өмірден мысал: факториал. 12! = 479 001 600, ол int-ке сыяды. 13!-ты int-пен есептеп көрейік:

    #include <iostream>

int main() {
    int f = 1;
    for (int n = 1; n <= 13; n++) {
        f = f * n;
        if (n == 12 || n == 13) {
            std::cout << n << "! = " << f << "\n";
        }
    }
    return 0;
}
    $ ./main
12! = 479001600
main.cpp:6:11: runtime error: signed integer overflow: 479001600 * 13 cannot be represented in type 'int'
13! = 1932053504

    13! шын мәні 6 227 020 800 болуы керек еді, ал бағдарлама 1932053504 деп жалған жауап берді. Ең жаманы: егер санитайзер қосылмаса, бағдарлама ешқандай дабылсыз, үнсіз қате жауап береді. Шешім - үлкен тип:

    #include <iostream>

int main() {
    long long f = 1;
    for (int n = 1; n <= 20; n++) {
        f = f * n;
        if (n == 12 || n == 13 || n == 20) {
            std::cout << n << "! = " << f << "\n";
        }
    }
    return 0;
}
    $ ./main
12! = 479001600
13! = 6227020800
20! = 2432902008176640000

    long long 8 байт алады, 20!-ке дейін жетеді (шамамен 9,2·1018 дейін). Ереже: сан үлкен болуы мүмкін болса (халық саны, ақша, факториал, үлкен жиынтық), алдын ала long long алыңыз.

    const, auto және комментарийлер

    Комментарий (comment) - компилятор еленбейтін, тек адамға арналған жазба. Бір жолдық: // мәтін. Көп жолдық: /* ... */. Жақсы комментарий не істеп жатқанын емес, неге солай істелгенін түсіндіреді.

    const - «тұрақты». Бір рет мән беріп, кейін өзгерту мүмкін емес айнымалы. Бұл тек компиляторға көмек емес, кодты оқитын адамға да: «бұл сан өзгермейді» дегенді айқын айтады. Сиқырлы сандарды (кодтың ортасында түсініксіз 3500) атымен тұрақтыға айналдыру - жақсы әдет.

    auto - «типті компилятор өзі анықта». Оң жақтағы мәннен тип шығады:

    #include <iostream>
#include <string>

// Наурыз тойының бюджеті (теңгемен)
int main() {
    const int guests = 40;             // const: мәнін өзгертуге болмайды
    const long long perGuest = 3500;
    /* auto: тип мәннен анықталады */
    auto total = guests * perGuest;    // long long
    auto half = total / 2.0;           // double
    auto city = std::string("Шымкент");

    std::cout << city << ": бюджет " << total << " тг\n";
    std::cout << "Жартысы: " << half << " тг\n";
    return 0;
}
    $ ./main
Шымкент: бюджет 140000 тг
Жартысы: 70000 тг

    Мұнда guests * perGuest - int мен long long көбейтіндісі, сондықтан total типі long long. Ал total / 2.0 нәтижесі double. auto типті жазудан құтқарады, бірақ оқуды қиындатпауға тырысыңыз: типі айқын емес жерде нақты тип жазған жөн. Егер guests = 41; деп өзгертуге тырыссақ, компилятор бірден тоқтатады: const айнымалыға мән меншіктеуге болмайды.

    Температура мысалы: auto және араласқан арифметика:

    #include <iostream>

int main() {
    double celsius;
    std::cout << "Астанадағы температура (°C): ";
    std::cin >> celsius;
    auto fahrenheit = celsius * 9 / 5 + 32;
    std::cout << celsius << " °C = " << fahrenheit << " °F\n";
    return 0;
}
    $ ./main
Астанадағы температура (°C): -12.5
-12.5 °C = 9.5 °F

    Мұнда celsius * 9 / 5 есептелгенде celsius - double, сондықтан бөлу бөлшек түрінде жүреді. Егер celsius int болса, celsius * 9 / 5 бүтін бөлумен орындалып, бөлшек бөлігі қиылып қалар еді де, нәтиже дәл болмас еді.

    Қателердің үш түрі

    Қате жасау - бағдарламалаудың қалыпты бөлігі. Шеберлер қате жасамайды дегенге сенбеңіз: олар жылдам табады. Қателерді түрлерге бөлсек, қайдан іздеу керегі айқын болады.

    1. Компиляция қатесі

    Компилятор кодты түсінбегенде шығады. Бағдарлама мүлде жасалмайды. Ең әйгілі мысал - нүктелі үтірді ұмыту:

    #include <iostream>

int main() {
    int guests = 12
    std::cout << guests << "\n";
    return 0;
}
    $ g++ -std=c++17 -Wall -Wextra main.cpp -o main
main.cpp: In function ‘int main()’:
main.cpp:5:5: error: expected ‘,’ or ‘;’ before ‘std’
    5 |     std::cout << guests << "\n";
      |     ^~~
main.cpp:4:9: warning: unused variable ‘guests’ [-Wunused-variable]
    4 |     int guests = 12
      |         ^~~~~~

    Хабарламаны оқу өнерін үйреніңіз. Формат: файл:жол:баған: error: сипаттама. Мұнда компилятор 5-жолды көрсетіп тұр, бірақ шын қате алдыңғы жолда (4-жол) ; жоқ. Компилятор көбіне қатені келесі жолда ғана байқайды, сондықтан «қате көрсетілген жолдың өзінде де, алдыңғы жолда да» іздеңіз. Қатенің ең жоғарғысын түзетіп, қайта құрастырыңыз: төменгі қателер көбіне соның салдары.

    Тағы бір жиі кездесетін қате - std:: жазуды ұмыту:

    $ g++ -std=c++17 -Wall -Wextra main.cpp -o main
main.cpp: In function ‘int main()’:
main.cpp:5:5: error: ‘cout’ was not declared in this scope; did you mean ‘std::cout’?
    5 |     cout << guests << "\n";
      |     ^~~~
      |     std::cout
In file included from main.cpp:1:
/usr/include/c++/13/iostream:63:18: note: ‘std::cout’ declared here
   63 |   extern ostream cout;          ///< Linked to standard output
      |                  ^~~~

    Компилятор өзі кеңес береді: «did you mean 'std::cout'?» - «std::cout дегенің бе?». Қатенің мәтінін оқыңыз, көбіне жауап сол жерде.

    Ескертулер

    Төмендегі бағдарлама дұрыс жұмыс істейді, бірақ -Wall -Wextra оның екі жерін күмәнді деп санайды:

    #include <iostream>
#include <vector>

int main() {
    int unusedCount = 5;
    std::vector<int> v = {1, 2, 3};
    for (int i = 0; i < v.size(); i++) {
        std::cout << v[i] << "\n";
    }
    return 0;
}
    $ g++ -std=c++17 -Wall -Wextra main.cpp -o main
main.cpp: In function ‘int main()’:
main.cpp:7:23: warning: comparison of integer expressions of different signedness: ‘int’ and ‘std::vector<int>::size_type’ {aka ‘long unsigned int’} [-Wsign-compare]
    7 |     for (int i = 0; i < v.size(); i++) {
      |                     ~~^~~~~~~~~~
main.cpp:5:9: warning: unused variable ‘unusedCount’ [-Wunused-variable]
    5 |     int unusedCount = 5;
      |         ^~~~~~~~~~~

    Бірінші ескерту: i таңбалы (int), ал v.size() таңбасыз; оларды салыстыру қате нәтиже беруі мүмкін. Екіншісі: unusedCount жарияланып, ешқайда қолданылмаған. Ескертулерді түзетіңіз: біріншісін size_t i немесе int(v.size()) арқылы, екіншісін жолды жою арқылы.

    2. Жалғау (link) қатесі

    Компилятор кодты түсінді, бірақ линкер функцияның нақты денесін таппады:

    #include <iostream>

int ayagy(int x);   // тек жариялау: денесі жоқ

int main() {
    std::cout << ayagy(5) << "\n";
    return 0;
}
    $ g++ -std=c++17 -Wall -Wextra main.cpp -o main
/usr/bin/ld: /tmp/ccXXXXXX.o: in function `main':
main.cpp:(.text+0xe): undefined reference to `ayagy(int)'
collect2: error: ld returned 1 exit status

    undefined reference to 'ayagy(int)' - «ayagy(int) функциясының анықтамасы табылмады». Біз функцияны жарияладық (прототип), бірақ жазып бермедік. Жалғау қатесінде жол нөмірі жоқ немесе көмескі, сондықтан хабарламада «ld returned 1 exit status» (линкер қате жасады) деген сөзді көрсеңіз, функция атауларын тексеріңіз.

    3. Орындалу қатесі

    Бағдарлама құрастырылды, жұмыс істей бастады, бірақ бір сәтте бір нәрсе бұзылды. Мысалы, нөлге бөлу:

    #include <iostream>

int main() {
    int guests = 25;
    int tables;
    std::cout << "Үстел саны: ";
    std::cin >> tables;
    std::cout << "Бір үстелге: " << guests / tables << "\n";
    return 0;
}
    $ ./main
Үстел саны: 0
main.cpp:8:54: runtime error: division by zero
AddressSanitizer:DEADLYSIGNAL
...

    Санитайзер «division by zero» деп көрсетті. Санитайзерсіз бұл бағдарлама «Floating point exception» деген жүйелік хабармен құлайды. Орындалу қателері ең қиын, себебі компилятор оларды алдын ала көрмейді: кіріс деректерге байланысты. Сондықтан бағдарламаны әртүрлі деректермен, әсіресе шеткі мәндермен (0, теріс сан, ең үлкен сан) тексеру керек.

    Төртінші түрі де бар: бағдарлама қателесіз жұмыс істейді, бірақ жауабы қате - логикалық қате (мысалы, бүтін бөлу салдарынан). Оны компилятор да, санитайзер де таппайды. Оны тек сіздің ойлауыңыз мен тестіңіз ұстайды.

    Қатемен жұмыс істеу реті

    1) Хабарламаны соңына дейін оқыңыз. 2) Ең бірінші қатені түзетіңіз. 3) Қайта құрастырыңыз. 4) Түсінбесеңіз, қатенің мәтінін оқыңыз және жолды қарап шығыңыз. Қатені жасырмаңыз: әр қате - түсінуге бір қадам.

    Жиі қателер

    • ; ұмыту. Хабарлама көбіне келесі жолды көрсетеді.
    • std:: жазбау. cout емес, std::cout.
    • << мен >> шатастыру. Шығару - <<, енгізу - >>.
    • = мен == араластыру. Біреуі меншіктеу, екіншісі салыстыру. Бұл туралы келесі аптада көреміз.
    • Бүтін бөлу. int / int бөлшегін тастайды. Бөлшек керек болса, бір жағын double етіңіз.
    • Бастапқы мәнсіз айнымалы. int x; ішінде кездейсоқ нәрсе жатыр.
    • Тырнақшаны шатастыру. 'A' бір таңба (char), "A" мәтін (жол).
    • Ескертуді елемеу. -Wall -Wextra әрқашан қосулы тұрсын.
    • Толып кетуді ескермеу. Сан үлкен болуы мүмкін болса, long long.

    Қорытынды

    Бүгін C++ әлеміне алғашқы қадамды жасадық. Не үйрендік:

    • Бағдарлама мәтіннен препроцессор, компилятор, линкер арқылы өтіп, орындалатын файлға айналады: g++ -std=c++17 -Wall -Wextra main.cpp -o main.
    • Бағдарлама main функциясынан басталады; #include файлдарды қосады; std::cout << шығарады, std::cin >> оқиды.
    • Негізгі типтер: int, long long, double, char, bool, std::string. Әр типтің көлемі шектеулі.
    • int / int бүтін бөлу жасайды; % қалдық береді; бөлшек керек болса, double немесе static_cast.
    • Таңбалы int толып кетуі - анықталмаған мінез; үлкен сандар үшін long long.
    • const өзгермейтін мән үшін, auto типті компилятор шығарады, комментарий кодты түсіндіреді.
    • Қате түрлері: компиляция, жалғау (link), орындалу, және логикалық қате. Хабарламаны оқи біліңіз.

    Келесі аптада бағдарламаға шешім қабылдауды және қайталауды үйретеміз: шарттар, циклдер және функциялар.

    Өзіңізді тексеріп көріңіз:

    • g++ орнатылды, g++ --version нәтиже береді.
    • main.cpp жазып, құрастырып, іске қостым.
    • Препроцессор, компилятор, линкердің айырмашылығын түсіндіре аламын.
    • int / int неге бүтін шығатынын түсіндіре аламын.
    • Компиляция, link және орындалу қателерін ажырата аламын.

    Өзіңізді тексеріңіз

    1. Мына бағдарлама нені шығарады? int a = 7; int b = 2; std::cout << a / b;

    Екі операнд та int, сондықтан бүтін бөлу жасалады, бөлшек бөлігі тасталады: нәтиже 3. Қалдық 7 % 2 = 1 болар еді.

    2. g++ орындайтын үш қадамның дұрыс реті қайсы?

    Алдымен препроцессор (#include және т.б.), сосын компилятор (машина коды), ең соңында линкер (бөліктерді жалғау).

    3. Төмендегі қате қай түрге жатады? Хабарлама: undefined reference to 'ayagy(int)'

    «undefined reference» - линкер функцияның анықтамасын таппағанда шығатын жалғау қатесі. Прототип бар, дене жоқ.

    4. std::cout << (17 % 5); нені шығарады?

    % қалдықты береді: 17 = 3 · 5 + 2, сондықтан 2.

    5. Қай жолда қате бар? const int guests = 40; кейін guests = 41; деп жазылған.

    const мәнді өзгертуге тыйым салады. Бұл қате компиляция кезінде-ақ ұсталады, бағдарлама іске қосылмайды да.

    6. Мына жолда x типі қандай? auto x = 3500 * 40LL; (40LL - long long литералы)

    int мен long long көбейтілгенде нәтиже кеңірек типке, яғни long long-ға келтіріледі. auto соны қабылдайды.

    7. -Wall -Wextra жалаулары не үшін керек?

    Бұл жалаулар компиляторды сынаушы қылады: қолданылмаған айнымалы, таңбасы әртүрлі салыстыру сияқты күмәнді жерлерді көрсетеді. Бағдарламаны өзгертпейді және түзетпейді.

    8. std::string s = "Қош"; болса, s.size() неге 3-тен үлкен шығады?

    «Қ», «о» және «ш» - үшеуі де кирилл әріптері, UTF-8-де әрқайсысы екі байттан алады, сондықтан «Қош» үшін size() 6 береді. Бұл тіл ерекшелігі, қате емес.

    Жаттығулар

    Жеңіл, орташа және қиын деңгейдегі тапсырмалар. Жауабы бар тапсырмаларды осы жерде тексеріңіз, ал бағдарлама жазатындарды өз компьютеріңізде іске қосып, өзіңізді тексеру тізімімен салыстырыңыз.

    Жеңіл

    Бөлу және көбейту

    Бағдарлама не шығарады? Жауабын дәл жазыңыз.

    #include <iostream>

int main() {
    int a = 17;
    int b = 5;
    std::cout << a / b * 2.0 << "\n";
    return 0;
}
    Кеңес

    Амалдар солдан оңға орындалады: алдымен a / b (екеуі де int), содан кейін нәтиже 2.0-ге көбейтіледі.

    Шешімі

    17 / 5 бүтін бөлу, нәтиже 3. Сосын 3 * 2.0 = 6.0, ал cout оны 6 деп шығарады. Бұл бағдарламаны іске қосып тексердік:

    $ ./main
6
    Жеңіл

    Бөлшектен бүтінге

    Бағдарлама не шығарады?

    #include <iostream>

int main() {
    double d = 9.99;
    int k = d;
    std::cout << k << "\n";
    return 0;
}
    Кеңес

    Бөлшек сан int-ке салынғанда бөлшек бөлігі дөңгелектелмей, қиылады.

    Шешімі

    9.99 санын int-ке салғанда бөлшек бөлігі жоғалады: 9.

    $ ./main
9
    Орташа

    Қанша үстел керек?

    Наурыз тойына 47 қонақ келеді. Бір үстелге 6 адам отырады. Үстелдер жоғары қарай дөңгелектеніп есептеледі. Төмендегі бағдарлама қанша үстел шығарады?

    #include <iostream>

int main() {
    int guests = 47;
    int perTable = 6;
    int tables = (guests + perTable - 1) / perTable;
    std::cout << tables << "\n";
    return 0;
}
    Кеңес

    Формуланы қолмен есептеңіз: (47 + 6 - 1) / 6. Алдымен жақшаның ішін, сосын бүтін бөлуді орындаңыз.

    Шешімі

    (47 + 5) / 6 = 52 / 6 = 8 (бүтін бөлу, қалдық тасталады). Шынымен, 7 үстелге 42 адам сыяды, қалған 5 адам үшін сегізінші үстел керек.

    $ ./main
8
    Орташа

    Айналып кету

    unsigned char типі 0-ден 255-ке дейінгі сан сақтайды. Төмендегі бағдарлама не шығарады?

    #include <iostream>

int main() {
    unsigned char c = 250;
    c = c + 10;
    std::cout << static_cast<int>(c) << "\n";
    return 0;
}
    Кеңес

    250 + 10 = 260. 255-тен асқан соң сан 0-ден қайта басталады: 256 орнына 0 келеді.

    Шешімі

    260 санынан 256 алып тастасақ, 4 қалады (260 mod 256 = 4). Таңбасыз типтердің толуы стандартпен бекітілген, сондықтан нәтиже кепілдік:

    $ ./main
4
    Қиын

    Үш күннің орташа температурасы

    Қолданушыдан үш температураны (double) оқып, орташа мәнін нүктеден кейін екі таңбамен шығаратын бағдарлама жазыңыз. Енгізу: -5 3 10. Бағдарламаңыз қандай санды шығарады?

    Кеңес

    Үш санды cin >> a >> b >> c арқылы оқуға болады. Нәтижені std::fixed және std::setprecision(2) арқылы форматтаңыз. (a + b + c) / 3: жақшаны ұмытпаңыз.

    Шешімі
    #include <iostream>
#include <iomanip>

int main() {
    double a, b, c;
    std::cout << "Үш күннің температурасы: ";
    std::cin >> a >> b >> c;
    double avg = (a + b + c) / 3;
    std::cout << std::fixed << std::setprecision(2);
    std::cout << "Орташа: " << avg << "\n";
    return 0;
}
    $ ./main
Үш күннің температурасы: -5 3 10
Орташа: 2.67

    (-5 + 3 + 10) / 3 = 8 / 3 = 2,666..., ол екі таңбаға дейін дөңгелектеніп 2.67 болады.

    Өзін тексеру тізімі
    • g++ -std=c++17 -Wall -Wextra ескертусіз құрастырылады.
    • -5 3 10 үшін 2.67 шығады.
    • Басқа сандармен де тексердім (мысалы, 0 0 0 және 30 30 30).

    Қиын

    Қатені тап және түзет

    Төмендегі бағдарлама құрастырылмайды. Қателерді тауып түзетіңіз. Түзетілген бағдарлама қандай санды шығарады?

    #include <iostream>

int main() {
    int guests = 12;
    double price = 3500.5
    std::cout << "Бюджет: " << guests * prise << "\n";
    return 0
}
    Кеңес

    Бір қате - нүктелі үтір жоқ жолдарда (екі жол). Екіншісі - айнымалы атауында: prise емес, price. Түзеткен соң 12 * 3500.5 есептеліп шығады.

    Шешімі

    Түзетілген нұсқа:

    #include <iostream>

int main() {
    int guests = 12;
    double price = 3500.5;
    std::cout << "Бюджет: " << guests * price << "\n";
    return 0;
}
    $ ./main
Бюджет: 42006

    12 · 3500,5 = 42006. Бұл бағдарламада компилятор алдымен екі қатені ғана көрсетеді. prise қатесін нүктелі үтірлерді қосқан соң ғана көресіз: қателерді бірінен соң бірін түзете беріңіз.

    Өзін тексеру тізімі
    • Үш қатені де таптым (екі ; және prise/price).
    • Түзетілген код ескертусіз құрастырылады.
    • Хабарламалардағы жол нөмірін бағдарламамен салыстыра алдым.
