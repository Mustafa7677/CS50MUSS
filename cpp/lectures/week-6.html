    STL: контейнерлер, итераторлар, алгоритмдер

    C++ стандартты кітапханасы дайын «қоймалар» (контейнерлер) мен «құралдар» (алгоритмдер) береді. Тізім, сөздік, жиын, сұрыптау, іздеу өзіңіз жазбай-ақ бар. Бұл аптада оларды қашан және қалай таңдау керегін үйренеміз.

    STL деген не және неге ол керек?

    Бағдарламашылардың көбі бірдей мәселелерге тап болады: деректер тізімін сақтау, сөз бойынша іздеу, сұрыптау, қайталанбайтын элементтерді таңдау. Әр жолы мұны нөлден жазу уақыт алады және қате қосады. Сондықтан C++ тілінің стандартты кітапханасы (Standard Template Library, қысқаша STL) осындай жұмыстардың бәрін дайын береді. Ол үш бөліктен тұрады:

    • контейнерлер (containers): деректерді сақтайтын «қоймалар» (vector, list, map, set...);
    • итераторлар (iterators): контейнердің ішінде жүретін «көрсеткіш тәрізді» нысандар;
    • алгоритмдер (algorithms): сұрыптау, іздеу, санау сияқты дайын әрекеттер (sort, find, count_if...).

    Бұл үшеуі бір-бірімен итераторлар арқылы байланысады. Бір алгоритм (мысалы, sort) әртүрлі контейнермен жұмыс істей алады, себебі ол контейнердің ішкі құрылымын емес, тек итераторларды біледі. Мұны асхана аналогиясымен түсіндіруге болады: контейнер - ыдыс, итератор - қасық, алгоритм - рецепт. Рецепт қасықпен жұмыс істейді, ал қасық қай ыдыста болса да бірдей.

    Өз компьютеріңде іске қос

    Әр мысалды main.cpp файлына жазып, мынадай команда орында:

    g++ -std=c++17 -Wall -Wextra -fsanitize=address,undefined main.cpp -o main && ./main

    Бұл лекцияда C++17 мүмкіндіктері бар (мысалы, auto [a, b] құрылымдық байланыстыру), сондықтан -std=c++17 жазуды ұмытпаңыз.

    vector: ең жиі қолданылатын контейнер

    Вектор (std::vector) - өлшемі өзгеретін жиым. Элементтері жадта бір-бірінің қасында жатады, сондықтан индекс бойынша қол жеткізу өте жылдам. Басқа контейнерді таңдауға нақты себеп болмаса, әрқашан vector-дан бастаңыз. Бұл - тәжірибелі C++ бағдарламашылардың әдеті.

    #include <iostream>
#include <string>
#include <vector>

int main() {
    std::vector<std::string> cities;           // бос вектор
    cities.push_back("Алматы");
    cities.push_back("Астана");
    cities.push_back("Шымкент");
    cities.push_back("Ақтау");

    std::cout << "Қала саны: " << cities.size() << "\n";
    std::cout << "Біріншісі: " << cities.front() << ", соңғысы: " << cities.back() << "\n";
    std::cout << "[2] = " << cities[2] << "\n";

    cities.insert(cities.begin() + 1, "Қарағанды");   // индекс 1-ге қыстыру
    cities.pop_back();                                // соңғысын алып тастау

    for (const std::string& c : cities) {
        std::cout << c << "; ";
    }
    std::cout << "\n";

    std::vector<int> v(5, 7);      // бес дана 7
    std::vector<int> w{1, 2, 3};   // тізімнен
    std::cout << v.size() << " " << w.size() << " " << w[1] << "\n";
}

    Негізгі әрекеттер: push_back соңына қосады, pop_back соңғысын алып тастайды, size() элементтер санын, front()/back() бірінші және соңғы элементті береді, insert кез келген орынға қыстырады. Вектор жасаудың бірнеше жолы бар: бос (std::vector<int> v;), бір мәннен бірнеше дана (v(5, 7) - бес дана 7) және бастапқы тізіммен (w{1, 2, 3}).

    Суретте айырмашылық көрінеді. Вектордың элементтері қатар тұрғандықтан, бес жүзінші элементті табу үшін бастапқы мекенжайға бес жүз элементтің өлшемін қосу жеткілікті, бұл O(1). Тізімде мұндай жол жоқ, соңына жету үшін бәрін тізбектеп өту керек. Ал қыстыру керісінше: векторда ортаға қыстыру үшін кейінгі элементтердің бәрін жылжыту қажет, тізімде тек екі көрсеткішті өзгертеміз.

    Шектен шығу: [] және at()

    Вектордың v[i] жазуы шекті тексермейді. Егер индекс дұрыс болмаса, анықталмаған әрекет (қате жадты оқу) болады. Қауіпсіз нұсқа - v.at(i). Ол шектен тыс болса, std::out_of_range ерекше жағдайын лақтырады, ал оны ұстап алуға болады. Ерекше жағдайларды 7-аптада толық қараймыз, қазір тек көрейік:

    #include <iostream>
#include <stdexcept>
#include <vector>

int main() {
    std::vector<int> v{10, 20, 30};
    try {
        std::cout << v.at(1) << "\n";
        std::cout << v.at(5) << "\n";     // шектен тыс
    } catch (const std::out_of_range& e) {
        std::cout << "Қате ұсталды: " << e.what() << "\n";
    }
}

    size пен capacity

    Вектор өсу үшін жадты қосымша бөліп қояды. size() - ішінде қанша элемент бар, capacity() - қайта бөлусіз қанша сыяды. Орын таусылғанда, вектор үлкенірек жаңа блок бөліп, ескі элементтерді көшіріп, ескісін босатады. Мұны байқау үшін өсуді бақылайық:

    #include <iostream>
#include <vector>

int main() {
    std::vector<int> v;
    std::size_t last = 0;
    for (int i = 0; i < 20; ++i) {
        v.push_back(i);
        if (v.capacity() != last) {
            last = v.capacity();
            std::cout << "size = " << v.size() << " -> capacity = " << last << "\n";
        }
    }
    std::vector<int> w;
    w.reserve(100);          // бірден орын сұрау: қайта бөлу болмайды
    std::cout << "reserve(100): size = " << w.size() << ", capacity = " << w.capacity() << "\n";
}

    list және deque

    Тізім (std::list) - екі жақты байланысқан түйіндер тізбегі. Ол элементтерге индекс бойынша қол жеткізуге мүмкіндік бермейді (l[3] жоқ), бірақ белгілі орынға қыстыру мен жою өте жылдам, элементтер басқа орынға көшірілмейді, ал итераторлар жарамды күйінде қалады. Дек (std::deque, double-ended queue) - екі жағынан да тез қосуға болатын жиым тәрізді контейнер, ол индекс бойынша қол жеткізуді де қолдайды.

    #include <deque>
#include <iostream>
#include <list>
#include <string>

int main() {
    std::list<std::string> queue;                 // екі жақты байланысқан тізім
    queue.push_back("Нұрсұлтан");
    queue.push_back("Айдана");
    queue.push_front("Сағын");                    // басына қосу - O(1)
    auto it = queue.begin();
    ++it;                                         // екінші элемент
    queue.insert(it, "Дәурен");                   // ортасына қыстыру - O(1) (орын белгілі болса)
    for (const auto& s : queue) std::cout << s << " ";
    std::cout << "\n";

    std::deque<int> d;                            // екі жақтан да тез қосылады
    d.push_back(2);
    d.push_back(3);
    d.push_front(1);
    d.push_front(0);
    std::cout << "deque: ";
    for (int x : d) std::cout << x << " ";
    std::cout << "| d[2] = " << d[2] << "\n";
}

    Практикалық кеңес: нағыз жобаларда list өте сирек керек болады, себебі вектор көбіне оны жылдамдықта басып озады (жадта қатар жатқандықтан процессордың кэші жақсы жұмыс істейді). Екі жақтан қосатын кезек керек болса, deque таңдаңыз. Ал вектордың алдына қосу тұрақты қажет болса, deque немесе басқа құрылым ойластырыңыз.

    map, unordered_map және set

    Вектор индекс (0, 1, 2...) бойынша жұмыс істейді. Кейде индекс орнына кілт керек: «самса» деп сұрап, бағасын алу. Мұндай контейнерлерді ассоциативті (associative containers) дейді.

    std::map<K, V> - «кілт → мән» жұптарының жиынтығы. Кілттер әрқашан сұрыпталған күйде сақталады (ішкі құрылымы тепе-тең екілік ағаш), іздеу мен қосу O(log n). Шай үйінің мәзірін алайық:

    #include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, int> menu;      // тағам -> баға (тг)
    menu["самса"] = 700;
    menu["көк шай"] = 350;
    menu["бешбармақ"] = 3500;
    menu["баурсақ"] = 500;
    menu["самса"] = 750;                  // бар кілтті жаңарту

    std::cout << "Мәзір (әліпби ретімен):\n";
    for (const auto& [name, price] : menu) {
        std::cout << "  " << name << " - " << price << " тг\n";
    }

    auto it = menu.find("қымыз");
    if (it == menu.end()) std::cout << "қымыз жоқ\n";
    std::cout << "самса бар ма? " << menu.count("самса") << "\n";

    std::cout << "Өлшем: " << menu.size() << "\n";
    int zero = menu["шарап"];             // жоқ кілт: автоматты түрде 0-мен қосылады!
    std::cout << "шарап = " << zero << ", өлшем: " << menu.size() << "\n";
}

    std::unordered_map - дәл осындай, бірақ ішінде хэш-кесте жатыр. Кілттер сұрыпталмайды, бірақ іздеу орташа есеппен O(1). Егер реттің қажеті жоқ болса, көбіне осы тез:

    #include <iostream>
#include <string>
#include <unordered_map>
#include <unordered_set>

int main() {
    std::unordered_map<std::string, std::string> capitals;
    capitals["Қазақстан"] = "Астана";
    capitals["Қырғызстан"] = "Бішкек";
    capitals["Өзбекстан"] = "Ташкент";
    capitals["Түркия"] = "Анкара";

    for (const char* k : {"Қазақстан", "Түркия", "Жапония"}) {
        auto it = capitals.find(k);
        if (it != capitals.end()) std::cout << k << " -> " << it->second << "\n";
        else std::cout << k << " -> табылмады\n";
    }

    std::unordered_set<int> seen;
    int total = 0;
    for (int x : {4, 8, 4, 15, 8, 16, 23, 42, 15}) {
        if (seen.insert(x).second) total += x;   // insert жаңа болса ғана true
    }
    std::cout << "Бірегей сандар: " << seen.size() << ", қосындысы: " << total << "\n";
}

    std::set - тек кілттен тұратын (мән жоқ), қайталанбайтын, сұрыпталған жиын. Бұл математикадағы «жиын» ұғымына сәйкес:

    #include <iostream>
#include <set>
#include <string>

int main() {
    std::set<std::string> attended;
    for (const char* s : {"Дана", "Ерлан", "Айгүл", "Дана", "Ерлан", "Бақыт"}) {
        attended.insert(s);
    }
    std::cout << "Сабаққа келгендер (" << attended.size() << "): ";
    for (const auto& s : attended) std::cout << s << " ";
    std::cout << "\n";

    std::cout << "Айгүл келді ме? " << (attended.count("Айгүл") ? "иә" : "жоқ") << "\n";
    attended.erase("Ерлан");
    std::cout << "Ерлан алынды, қалды: " << attended.size() << "\n";

    std::set<int> grades{5, 3, 4, 5, 3, 5};
    std::cout << "Бірегей бағалар: ";
    for (int g : grades) std::cout << g << " ";
    std::cout << "\n";
}

    pair, tuple және құрылымдық байланыстыру

    Кейде екі-үш мәнді бір жерге жинау керек, бірақ ол үшін бөлек класс жазғың келмейді. std::pair<A, B> екі мәнді, std::tuple<...> кез келген санды біріктіреді. Функциядан бірнеше мән қайтару үшін өте ыңғайлы. pair-дің мүшелері first және second, ал tuple үшін std::get<0>(t).

    #include <iostream>
#include <string>
#include <tuple>
#include <utility>
#include <vector>

std::pair<int, int> minMax(const std::vector<int>& v) {
    int lo = v[0], hi = v[0];
    for (int x : v) {
        if (x < lo) lo = x;
        if (x > hi) hi = x;
    }
    return {lo, hi};
}

std::tuple<std::string, int, double> student() {
    return {"Мөлдір", 17, 4.75};
}

int main() {
    std::pair<std::string, int> p{"Алматы", 2};
    std::cout << p.first << ": " << p.second << "\n";

    auto [lo, hi] = minMax({12, -3, 40, 7});
    std::cout << "min = " << lo << ", max = " << hi << "\n";

    auto [name, age, gpa] = student();
    std::cout << name << ", " << age << " жас, орташа балл " << gpa << "\n";

    std::tuple<int, char> t{1, 'a'};
    std::cout << std::get<0>(t) << std::get<1>(t) << "\n";
}

    C++17-дегі құрылымдық байланыстыру (structured binding) auto [lo, hi] = ...; нәтижені бірден бірнеше айнымалыға ашып береді. Бұл .first/.second жазудан әлдеқайда оқылымды. Біз оны map бойынша циклде де қолдандық: for (const auto& [name, price] : menu).

    Итераторлар

    Контейнердің ішінде қалай жүреміз? Вектор үшін индекс жеткілікті, бірақ list немесе map үшін индекс жоқ. Барлық контейнерде жұмыс істейтін бірыңғай құрал - итератор (iterator). Ол «қазіргі орынды көрсететін нысан»: көрсеткіш сияқты оны *it арқылы оқып, ++it арқылы келесіге жылжытамыз.

    Маңызды: end() соңғы элементті емес, соңынан кейінгі орынды көрсетеді. Сондықтан цикл шарты it != v.end(), ал бос контейнерде begin() == end(). Енді итераторлармен нақты жұмыс:

    #include <iostream>
#include <vector>

int main() {
    std::vector<int> v{10, 20, 30, 40, 50};

    for (auto it = v.begin(); it != v.end(); ++it) {
        std::cout << *it << " ";
    }
    std::cout << "\n";

    for (auto it = v.rbegin(); it != v.rend(); ++it) {   // кері бағытта
        std::cout << *it << " ";
    }
    std::cout << "\n";

    auto it = v.begin() + 2;     // кездейсоқ қолжетімді итератор: сандарды қосуға болады
    *it = 99;
    std::cout << "ортасы: " << *it << ", қашықтық: " << (v.end() - it) << "\n";

    // тізімді өзгерту: erase келесі жарамды итераторды қайтарады
    for (auto i = v.begin(); i != v.end();) {
        if (*i % 20 == 0) i = v.erase(i);
        else ++i;
    }
    for (int x : v) std::cout << x << " ";
    std::cout << "\n";
}

    Мұнда не көрдік:

    • auto итератордың ұзын типін компиляторға жаздырады (std::vector<int>::iterator деп жазудың қажеті жоқ).
    • rbegin()/rend() кері бағытта жүреді.
    • Вектор итераторына сан қосып, секіруге болады (v.begin() + 2); мұндай итераторды кездейсоқ қолжетімді (random access) дейді. list итераторы тек ++ және -- біледі.
    • Жою кезінде v.erase(i) келесі жарамды итераторды қайтарады, сондықтан оны i-ге қайта меншіктейміз. Осылай болмаса, қате болады.

    Диапазонға негізделген for (range-based for) итераторларды өзі жасырын қолданады. for (const auto& x : v) жазуы for (auto it = v.begin(); it != v.end(); ++it) дегенмен тең, тек оқуға жеңіл. Қашан итераторды тікелей жазу керек? Айналып өту кезінде элементті жою не орнын білу керек болғанда, не бірнеше контейнерді қатар жүргенде. Қалған жағдайда range-for жеткілікті. Типті auto етіп жазғанда сілтемені (&) және const-ты ұмытпаңыз: тек auto көшірме жасайды, ал auto& элементті өзгертуге мүмкіндік береді.

    Итератордың жарамсыз болуы

    Контейнерді өзгерту кейде бұрын алынған итераторлар мен көрсеткіштерді жарамсыз етеді (iterator invalidation). Мысалы, вектор кеңейгенде барлық элемент жаңа жадқа көшеді, ал ескі итератор босатылған жадқа қарап қалады. Мұны AddressSanitizer ұстады:

    #include <iostream>
#include <vector>

int main() {
    std::vector<int> v{1, 2, 3};
    int* first = &v[0];
    auto it = v.begin();
    v.push_back(4);          // vector кеңейді -> жад көшірілді: итератор мен көрсеткіш жарамсыз
    std::cout << *first << " " << *it << "\n";
}

    <algorithm> алгоритмдері

    Кітапханада жүздеген дайын алгоритм бар, бәрі #include <algorithm> (кейбірі <numeric>) ішінде. Оларды қолмен жазатын болсаңыз, көбіне қате жібересіз, ал стандартты нұсқалар тексерілген әрі оңтайландырылған. Бәрі итераторлар жұбымен жұмыс істейді: (first, last).

    #include <algorithm>
#include <iostream>
#include <numeric>
#include <string>
#include <vector>

int main() {
    std::vector<int> g{72, 95, 58, 88, 95, 41, 66};

    std::sort(g.begin(), g.end());
    std::cout << "Сұрыпталған: ";
    for (int x : g) std::cout << x << " ";
    std::cout << "\n";

    auto it = std::find(g.begin(), g.end(), 88);
    if (it != g.end()) std::cout << "88 индексі: " << (it - g.begin()) << "\n";

    std::cout << "95 саны: " << std::count(g.begin(), g.end(), 95) << "\n";
    std::cout << "60-тан жоғары: " << std::count_if(g.begin(), g.end(), [](int x) { return x > 60; }) << "\n";

    int sum = std::accumulate(g.begin(), g.end(), 0);
    std::cout << "Қосынды: " << sum << ", орташа: " << static_cast<double>(sum) / g.size() << "\n";

    std::vector<int> percent(g.size());
    std::transform(g.begin(), g.end(), percent.begin(), [](int x) { return x / 10; });
    std::cout << "Ондықтар: ";
    for (int x : percent) std::cout << x << " ";
    std::cout << "\n";

    std::cout << "Ең үлкені: " << *std::max_element(g.begin(), g.end())
              << ", ең кішісі: " << *std::min_element(g.begin(), g.end()) << "\n";
    std::cout << "binary_search(66): " << std::binary_search(g.begin(), g.end(), 66) << "\n";
}

    Негізгі алгоритмдер:

    • std::sort(first, last) - өсу ретімен сұрыптайды. Орташа O(n log n).
    • std::find(first, last, x) - бірінші x-тің итераторын не last қайтарады. O(n).
    • std::count / std::count_if - мәнге не шартқа сәйкес элементтер санын береді.
    • std::accumulate(first, last, init) - қосындыны есептейді (<numeric>-тан). Бастапқы мән 0 болса бүтін сан, 0.0 болса бөлшек нәтиже шығады.
    • std::transform - әр элементке функция қолданып, нәтижені басқа жерге жазады.
    • std::min_element / std::max_element - ең кіші/ең үлкен элементтің итераторын береді (мәнін алу үшін * қолданыңыз).
    • std::binary_search - сұрыпталған диапазонда O(log n)-де бар-жоғын тексереді.

    erase-remove идиомасы

    Вектордан барлық берілген мәнді жою үшін std::remove пен erase бірге қолданылады. Қызығы: remove элементтерді шын мәнінде жоймайды, тек керектілерді алдына жылжытып, «жаңа соңды» береді, ал erase қалған құйрықты кесіп тастайды:

    #include <algorithm>
#include <iostream>
#include <vector>

int main() {

    Lambda өрнектері

    Алгоритмдерге көбіне өз шартымызды беру керек: «60-тан жоғары», «аты бойынша салыстыр». Ол үшін жеке функция жазу артық болуы мүмкін. Lambda өрнегі (lambda expression) - аты жоқ шағын функцияны дәл керек жерде жазудың жолы. Жалпы түрі:

    [ұстау](параметрлер) { дене }

    Алдыңғы мысалда [](int x) { return x > 60; } дегенді көрдік. Төртбұрышты жақша ішіндегі бөлік - ұстау тізімі (capture list): lambda өзін қоршаған кодтан қандай айнымалыны алады.

    • [] - ештеңе алмайды;
    • [limit] - limit-тің көшірмесін алады (мәнмен);
    • [&bonus] - bonus-қа сілтеме алады, өзгертуге болады;
    • [=] / [&] - барлығын мәнмен / сілтемемен.
    #include <algorithm>
#include <iostream>
#include <string>
#include <vector>

struct Student {
    std::string name;
    int score;
};

int main() {
    std::vector<Student> s{{"Айдар", 78}, {"Сәуле", 92}, {"Ернар", 85}, {"Гүлім", 92}};

    // score бойынша кему ретімен, тең болса аты бойынша
    std::sort(s.begin(), s.end(), [](const Student& a, const Student& b) {
        if (a.score != b.score) return a.score > b.score;
        return a.name < b.name;
    });
    for (const auto& x : s) std::cout << x.name << " " << x.score << "\n";

    int limit = 80;
    auto passed = [limit](const Student& x) { return x.score >= limit; };   // мәнмен ұстау
    std::cout << "Өткендер: " << std::count_if(s.begin(), s.end(), passed) << "\n";

    int bonus = 0;
    std::for_each(s.begin(), s.end(), [&bonus](const Student& x) {          // сілтемемен ұстау
        if (x.score > 90) ++bonus;
    });
    std::cout << "90-нан жоғары: " << bonus << "\n";

    auto square = [](int x) { return x * x; };
    std::cout << "7*7 = " << square(7) << "\n";
}

    Мәнмен ұстаудың тұзағы: lambda құрылған сәтте көшірме алады және кейін түпнұсқа өзгерсе, ол өзгерісті көрмейді. Сонымен қатар мәнмен алынған көшірмені lambda ішінде өзгерту үшін mutable қажет, бірақ өзгеріс тек lambda көшірмесінде қалады:

    #include <iostream>

int main() {
    int x = 1;
    auto f = [x]() mutable { x += 10; return x; };
    std::cout << f() << " " << f() << " " << x << "\n";
}

    std::function: функцияны мәнге айналдыру

    Кейде функцияны айнымалыда сақтап, параметр ретінде беру керек: «мына әрекетті кейін орында». Жай функцияны, lambda-ны және функтор (operator() бар класс) нысанын бірыңғай түрде ұстайтын тип - std::function<қайтарым(параметрлер)> (<functional> ішінде). Калькулятор жасап көрейік:

    #include <functional>
#include <iostream>
#include <map>
#include <string>

int add(int a, int b) { return a + b; }

struct Multiplier {
    int operator()(int a, int b) const { return a * b; }
};

int main() {
    std::map<std::string, std::function<int(int, int)>> ops;
    ops["қосу"] = add;                                          // жай функция
    ops["көбейту"] = Multiplier{};                              // функтор
    ops["айыру"] = [](int a, int b) { return a - b; };          // lambda

    for (const auto& [name, f] : ops) {
        std::cout << name << "(12, 5) = " << f(12, 5) << "\n";
    }

    std::function<void(const std::string&)> greet = [](const std::string& s) {
        std::cout << "Сәлем, " << s << "!\n";
    };
    greet("Қобыланды");
}

    Үш түрлі «шақырылатын нәрсе» (жай функция, функтор, lambda) бір map-та жатыр. Қолдану: f(12, 5). Бұл - мәзірлер, батырма өңдеушілері, пәрмен кестелері үшін өте ыңғайлы. Бағасы: std::function қосымша аздап жылдамдықты жұмсайды, сондықтан өте қарқынды цикл ішінде оны қолдану керек емес. Кіріспе деңгейінде есте қалатыны: функция да мән бола алады.

    Күрделілік: Big-O

    Контейнерді қалай таңдаймыз? Бір ғана сұрақ қояды: деректер көбейгенде әрекет қанша баяулайды? Мұны өлшеу үшін Big-O белгісі (Big-O notation) қолданылады. O(n) дегеніміз: элементтер саны n екі есе өссе, жұмыс шамамен екі есе көбейеді. Нақты секундтарды емес, өсу заңдылығын бағалаймыз. Миллион сан мен тізімді айналдырғанда айырманы көрейік:

    #include <iostream>
#include <vector>

int main() {
    const int N = 1000000;
    std::vector<int> v(N);
    for (int i = 0; i < N; ++i) v[i] = i * 2;      // сұрыпталған

    int target = 1999998;                          // соңғыға жақын

    // сызықтық іздеу: O(n)
    long linearSteps = 0;
    for (int i = 0; i < N; ++i) {
        ++linearSteps;
        if (v[i] == target) break;
    }

    // екілік іздеу: O(log n)
    long binarySteps = 0;
    int lo = 0, hi = N - 1;
    while (lo <= hi) {
        ++binarySteps;
        int mid = lo + (hi - lo) / 2;
        if (v[mid] == target) break;
        if (v[mid] < target) lo = mid + 1;
        else hi = mid - 1;
    }
    std::cout << "n = " << N << "\n";
    std::cout << "сызықтық іздеу қадамы: " << linearSteps << "\n";
    std::cout << "екілік іздеу қадамы:   " << binarySteps << "\n";
}

    Миллион элементтің ішінен сызықтық іздеу миллион қадам жасады (O(n)), ал екілік іздеу (сұрыпталған деректе) жиырма қадамға тоқтады (O(log n)). Бұл - 50 000 есе айырма! Екілік іздеу әр қадамда іздеу аймағын екіге бөледі: 1 000 000 → 500 000 → ... → 1, және ол log₂(1 000 000) ≈ 20 қадам.

    Графикте n өскен сайын әртүрлі қисықтың қалай алшақтайтыны көрінеді (масштаб шартты, мақсаты - тек өсу формасын салыстыру). O(1) мен O(log n) іс жүзінде жазық, ал O(n²) тез көтеріліп кетеді. Бастапқы кішкентай n кезінде бұл айырма сезілмейді, бірақ деректер көбейгенде шешуші болады.

    Бұл кестеден шығатын практикалық қорытындылар:

    • Белгісіз жағдайда vector таңдаңыз.
    • Кілт бойынша іздеу керек, реттің қажеті жоқ: unordered_map.
    • Сұрыпталған кілттер не диапазонмен жұмыс керек: map / set.
    • Екі жағынан кезек: deque.
    • Ортада қыстыру/жою көп және итераторлар жарамды қалуы керек: list.
    • Дерек сұрыпталған болса, векторда да екілік іздеу (binary_search, O(log n)) қолдануға болады.

    Таңдау сценарийлері

    Кестені жаттап алудың қажеті жоқ, оның орнына «мен не істеймін?» деген сұрақты қойыңыз. Бірнеше нақты жағдай:

    • Спортшылардың нәтижелері. Әр жарыстан кейін нәтиже қосылады, соңында сұрыпталады. Элементтер көп, қыстыру тек соңына. Таңдау: vector + sort.
    • Телефон анықтамалығы. Аты бойынша нөмірді тез табу керек, ал аттардың реті маңызды емес. Таңдау: unordered_map<string, string>. Егер аттар әліпби бойынша шығарылуы керек болса, map.
    • Сабаққа қатысқандар. Бір оқушы екі рет белгіленуі мүмкін, бірегейлері ғана керек. Таңдау: set не unordered_set.
    • Шай үйінің кезегі. Қонақтар соңынан келіп, басынан кетеді. Таңдау: queue (не deque).
    • Мәтіндегі сөз саны. Сөз → сан. Таңдау: map<string, int> не unordered_map (жоғарыдағы 4-жаттығу).
    • Ойын тарихы (undo). Соңғы әрекетті бірінші болып қайтарамыз. Таңдау: stack.

    Қолданылатын контейнерге сенімсіз болсаңыз, ең қарапайымынан (vector) бастап, нақты баяулық байқалғанда ғана ауыстырыңыз. Мамандар «мерзімінен бұрын оңтайландыру - барлық қатенің түп-тамыры» деп айтады: алдымен дұрыс және түсінікті жазыңыз, содан кейін өлшеп, қажет жерін жылдамдатыңыз.

    Бәрін біріктіру: оқушылар рейтингі

    Контейнерлер, алгоритмдер, lambda мен құрылымдық байланыстыруды бір мысалға жинайық. Әр оқушының бағалары map-та (кілт - аты, мән - бағалар векторы). Орташа балл есептеп, рейтингті кему ретімен шығарамыз:

    #include <algorithm>
#include <iostream>
#include <map>
#include <numeric>
#include <string>
#include <vector>

int main() {
    std::map<std::string, std::vector<int>> grades;
    grades["Айдар"] = {4, 5, 5, 3};
    grades["Сәуле"] = {5, 5, 5, 4};
    grades["Ернар"] = {3, 4, 3};
    grades["Гүлім"] = {5, 4, 4, 5, 5};

    std::vector<std::pair<std::string, double>> avg;
    for (const auto& [name, g] : grades) {
        double a = std::accumulate(g.begin(), g.end(), 0.0) / g.size();
        avg.push_back({name, a});
    }
    std::sort(avg.begin(), avg.end(), [](const auto& x, const auto& y) {
        return x.second > y.second;
    });

    std::cout << "Рейтинг:\n";
    int place = 1;
    for (const auto& [name, a] : avg) {
        std::cout << place++ << ". " << name << " - " << a << "\n";
    }

    auto good = std::count_if(avg.begin(), avg.end(), [](const auto& p) { return p.second >= 4.5; });
    std::cout << "Орташа 4.5 және одан жоғары: " << good << " оқушы\n";
}

    Контейнер адаптерлері: stack, queue, priority_queue

    Кейде контейнердің барлық мүмкіндігі керек емес, тек нақты қасиет қажет. Мысалы, асханада табақтар үстіне-үстіне қойылады, ал алғанда ең үстіндегісін аламыз. Мұны стек (stack) дейді: соңғы кірген бірінші шығады (LIFO). Касса алдындағы кезек керісінше: бірінші кірген бірінші шығады (FIFO), оны кезек (queue) дейді. Үшіншісі - басымдық кезегі (priority_queue), онда қосылу ретіне қарамай, ең үлкен (басымдығы жоғары) элемент бірінші шығады. Бұл үшеуі өз алдына контейнер емес, басқа контейнердің (әдепкіде deque не vector) үстіндегі шектелген «қабық», сондықтан оларды адаптер дейді.

    #include <iostream>
#include <queue>
#include <stack>
#include <string>
#include <vector>

int main() {
    // stack: соңғы кірген бірінші шығады (LIFO) - Шай үйіндегі табақтар қатары
    std::stack<std::string> plates;
    plates.push("бірінші табақ");
    plates.push("екінші табақ");
    plates.push("үшінші табақ");
    std::cout << "үстіңгісі: " << plates.top() << "\n";
    plates.pop();
    std::cout << "алғаннан кейін: " << plates.top() << ", қалды: " << plates.size() << "\n";

    // queue: бірінші кірген бірінші шығады (FIFO) - касса кезегі
    std::queue<std::string> line;
    line.push("Ержан");
    line.push("Зере");
    line.push("Мирас");
    std::cout << "кезекте: " << line.front() << " ... " << line.back() << "\n";
    line.pop();
    std::cout << "келесі: " << line.front() << "\n";

    // priority_queue: ең үлкен элемент әрқашан бірінші
    std::priority_queue<int> pq;
    for (int x : {30, 5, 80, 12}) pq.push(x);
    std::cout << "басымдық кезегі: ";
    while (!pq.empty()) {
        std::cout << pq.top() << " ";
        pq.pop();
    }
    std::cout << "\n";
}

Бұл шектеу қасақана жасалған: ол кодты оқитын адамға «мұнда тек осылай жұмыс істейді» деген кепілдік береді. Стек, мысалы, жақшалардың дұрыс жабылғанын тексеруде, браузердегі «артқа» батырмасында, функция шақыруларында қолданылады. Кезек кезекпен өңделетін тапсырмаларда, ал priority_queue «ең маңыздысын бірінші өңде» принципіндегі жүйелерде (мысалы, емхананың шұғыл науқастары) пайдалы.

    Құжаттаманы қалай оқу керек?

    STL-де жүздеген функция бар, оларды жаттап алу мүмкін емес, қажеті де жоқ. Тәжірибелі бағдарламашылар құжаттаманы жиі ашады. Ең танымал анықтамалық сайт - cppreference.com. Онда әр контейнер мен алгоритм үшін қолтаңба, күрделілік, мысал және C++ нұсқасы көрсетіледі. Бірнеше сұрақ қоюды әдетке айналдырыңыз: ол функция нені қайтарады? Итераторларды жарамсыз ете ме? Күрделілігі қандай? Қай C++ стандартынан бастап бар? Бұл төрт жауап көп қатенің алдын алады. Құжаттаманы оқу дағдысы кез келген тілде өсіп келе жатқан бағдарламашыны ерекшелейді.

    Жиі қателер

    1. Вектордан шығып кету. v[v.size()] соңғы емес, соңынан кейінгі орын. Соңғы элемент - v[v.size() - 1] не v.back(). Бос векторда back() шақырмаңыз.
    2. map-ты [] арқылы оқу. Жоқ кілтті қосып жібереді. Бар-жоғын тексеру үшін find не count.
    3. Итераторды жарамсыз ету. Цикл ішінде векторға push_back/erase жасап, ескі итераторды қолдану. erase-тің қайтарымын пайдаланыңыз.
    4. end()-ті оқу. *v.end() - қате; find нәтижесін әрқашан != end() деп тексеріп алыңыз.
    5. sort-ты list-ке қолдану. Оның орнына l.sort().
    6. accumulate-тың бастапқы мәнінің типі. accumulate(.., 0) бөлшек сандарды бүтінге кесіп жібереді; 0.0 жазыңыз.
    7. Артық көшіру. for (auto x : big) әр элементті көшіреді; for (const auto& x : big) дұрыс.
    8. Lambda-ның ұстауын шатастыру. [x] көшірме алады, кейін түпнұсқа өзгерсе, lambda көрмейді. Керек болса, [&x].

    Қорытынды

    • STL = контейнерлер + итераторлар + алгоритмдер; алгоритмдер итераторлар арқылы кез келген контейнермен жұмыс істейді.
    • vector - әдепкі таңдау; list - ортаға қыстыру үшін; deque - екі жақты кезек үшін.
    • map / set сұрыпталған (O(log n)); unordered_map / unordered_set реттелмеген, бірақ орташа O(1).
    • pair, tuple және auto [a, b] құрылымдық байланыстыру бірнеше мәнді ыңғайлы алады.
    • Итератор - контейнердегі орынды көрсетеді; [begin, end) жартылай ашық аралық; өзгертуден кейін жарамсыз болуы мүмкін.
    • Негізгі алгоритмдер: sort, find, count_if, transform, accumulate, min_element/max_element, binary_search.
    • Lambda [ұстау](параметр) { дене } - дәл керек жерде жазылатын шағын функция; std::function оны мән ретінде сақтайды.
    • stack, queue, priority_queue - шектелген қолжетімді адаптерлер (LIFO, FIFO, ең үлкені бірінші).
    • Big-O деректер көбейгенде әрекеттің қалай өсетінін көрсетеді: O(1) < O(log n) < O(n) < O(n log n) < O(n²).

    Өзіңді тексеру тізімі

    • Қай жағдайда vector, list, map, unordered_map таңдауды түсіндіре аламын.
    • size() мен capacity() айырмасын білемін.
    • map[key] оқу кезінде кілт қосатынын білемін.
    • Итератормен контейнерді айналып өте аламын, end() нені көрсететінін білемін.
    • sort мен lambda арқылы өз ретіммен сұрыптай аламын.
    • Lambda ұстау тізімінің ([x] / [&x]) айырмасын айта аламын.
    • O(1), O(log n), O(n), O(n²) мағынасын мысалмен түсіндіре аламын.

    Өзіңізді тексеріңіз

    1. Нәтиже қандай?

    int x = 1;
auto f = [x]() mutable { x += 10; return x; };
std::cout << f() << " " << f() << " " << x;

    Lambda x-тің көшірмесін алды және ол шақырулар арасында сақталады (1 → 11 → 21). Сыртқы x өзгермейді. Компилятормен тексердік: 11 21 1.

    2. Өлшем неше болады?

    std::map<std::string, int> m;
m["x"];
m["y"] = 5;
m.count("z");
std::cout << m.size();

    m["x"] жоқ кілтті 0-мен қосады, m["y"] = 5 тағы біреуін қосады. count ештеңе қоспайды. Барлығы 2.

    3. std::list<int> l; std::sort(l.begin(), l.end()); неге құрастырылмайды?

    std::sort итераторларды азайтып, секіре алуы керек (random access). Тізімнің итераторы тек алға-артқа жүреді, сондықтан тізімнің өз sort әдісі бар.

    4. Вектор итераторы it = v.begin() алынды, содан кейін v.push_back(...) шақырылды. Не туралы айтуға болады?

    Қосқанда вектор жадты қайта бөлуі мүмкін; сонда барлық итератор, көрсеткіш және сілтеме жарамсыз болады. Нақты тексеруде AddressSanitizer heap-use-after-free көрсетті.

    5. Нәтижесі қандай?

    std::vector<int> v{1, 2, 3, 2, 4, 2};
v.erase(std::remove(v.begin(), v.end(), 2), v.end());
for (int x : v) std::cout << x << " ";

    remove керекті элементтерді алға жылжытады, erase қалған құйрықты өшіреді. Барлық 2 алынып, 1 3 4 қалады.

    6. Қай контейнерде кілт бойынша іздеу орташа есеппен O(1)?

    unordered_map хэш-кестеге негізделген, іздеу орташа O(1). map мен set - O(log n), list - O(n).

    7. Нәтижені болжа:

    std::vector<int> v;
v.reserve(50);
v.push_back(1);
v.push_back(2);
std::cout << v.size() << " " << (v.capacity() >= 50);

    reserve тек сыйымдылықты арттырады, өлшемді емес. Екі элемент қосылғандықтан size() = 2, ал capacity() ≥ 50, сондықтан өрнек 1 (true) береді.

    8. Мына цикл не шығарады?

    std::map<std::string, int> m{{"b", 2}, {"a", 1}, {"c", 3}};
for (const auto& [k, v] : m) std::cout << k << v << " ";

    map кілттерді сұрыптап сақтайды, сондықтан реті a, b, c. Құрылымдық байланыстыру кілт пен мәнді k, v аттарына ашады.

    Вектордың өлшемі

    Соңында v.size() неше болады?

    #include <iostream>
#include <vector>

int main() {
    std::vector<int> v{1, 2, 3};
    v.push_back(4);
    v.push_back(5);
    v.pop_back();
    v.insert(v.begin(), 0);
    v.erase(v.begin() + 2);
    std::cout << v.size() << "\n";
    for (int x : v) std::cout << x << " ";
    std::cout << "\n";
}

    Қадамдап жаз: {1,2,3} → push_back(4), push_back(5) → pop_back() → insert басына → erase (begin()+2 индексіндегі элемент).

    Шешімі

    Жауап: 4. Қадамдар: {1,2,3} → {1,2,3,4,5} → {1,2,3,4} → {0,1,2,3,4} → индекс 2 (мән 2) жойылады → {0,1,3,4}. Нақты нәтиже:

    Map тұзағы

    Бағдарлама соңында қандай сан шығарады?

    #include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, int> m;

    m["b"] жазуы оқуға арналған, бірақ кілт жоқ болса не істейді?

    Шешімі

    Жауап: 3. m["b"] кілтті 0 мәнімен қосты (енді екі кілт), шарт ақиқат болғандықтан m["c"] = 3 үшіншісін қосты.

    Орташа

    Күрделілік

    std::map-та кілт бойынша бір элементті табудың күрделілігі қандай? Big-O түрінде жаз (мысалы, O(n)).

    Кеңес

    map ішінде тепе-тең екілік ағаш бар, ал ағаштың биіктігі элементтер санының логарифмі.

    Шешімі

    Жауап: O(log n). unordered_map орташа O(1) береді, бірақ оның кілттері сұрыпталмаған.

    Орташа

    Сөз жиілігі

    Мына мәтіндегі сөздердің қайталану санын есепте: "ақ жол ақ шай жол ақ дастархан шай". Нәтижені жиілігі кему ретімен, жиілік тең болса әліпби ретімен шығар. std::map, std::istringstream, std::sort және lambda қолдан.

    Кеңес

    std::istringstream in(text); while (in >> word) ++freq[word]; сөздерді бөліп санайды. Одан кейін vector<pair<string,int>> құрып, lambda арқылы сұрыпта.

    Шешімі
    #include <algorithm>
#include <iostream>
#include <map>
#include <sstream>
#include <string>
#include <vector>

int main() {
    std::string text = "ақ жол ақ шай жол ақ дастархан шай";
    std::map<std::string, int> freq;
    std::istringstream in(text);
    std::string word;
    while (in >> word) {
        ++freq[word];
    }

    std::vector<std::pair<std::string, int>> v(freq.begin(), freq.end());
    std::sort(v.begin(), v.end(), [](const auto& a, const auto& b) {
        if (a.second != b.second) return a.second > b.second;
        return a.first < b.first;
    });
    for (const auto& [w, c] : v) {
        std::cout << w << ": " << c << "\n";
    }
}

    • ақ: 3 бірінші, содан кейін жол: 2, шай: 2, дастархан: 1.

    Қиын

    Рейстер кестесі

    Рейс құрылымын жаз: код, қайда, жөнелу уақыты (минутпен), орын саны. Төрт рейс құр. Алгоритмдер мен lambda арқылы: (1) рейстерді жөнелу уақыты бойынша сұрыпта және 08:30 түрінде шығар; (2) «Астана» бағытындағы рейстер санын count_if арқылы тап; (3) барлық орын санын accumulate арқылы тап; (4) transform арқылы рейс кодтарының векторын жаса.

    Кеңес

    Уақытты форматтау үшін көмекші функция жаз: сағат = минут / 60, минут = минут % 60. accumulate-тің төртінші аргументі - lambda: [](int s, const Flight& f) { return s + f.seats; }.

    Шешімі
    #include <algorithm>
#include <iostream>
#include <numeric>
#include <string>
#include <vector>

struct Flight {
    std::string code;
    std::string to;
    int depart;     // минут, түн ортасынан бастап
    int seats;
};

std::string hhmm(int m) {
    std::string h = std::to_string(m / 60), mm = std::to_string(m % 60);
    return (h.size() < 2 ? "0" : "") + h + ":" + (mm.size() < 2 ? "0" : "") + mm;
}

int main() {
    std::vector<Flight> f{
        {"KC-101", "Астана", 8 * 60 + 30, 120},
        {"KC-205", "Шымкент", 6 * 60 + 15, 90},
        {"KC-310", "Астана", 19 * 60 + 5, 150},
        {"KC-412", "Ақтау", 12 * 60, 60},
    };

    std::sort(f.begin(), f.end(), [](const Flight& a, const Flight& b) { return a.depart < b.depart; });
    for (const auto& x : f) std::cout << hhmm(x.depart) << " " << x.code << " -> " << x.to << "\n";

    auto toAstana = std::count_if(f.begin(), f.end(), [](const Flight& x) { return x.to == "Астана"; });
    std::cout << "Астанаға рейс: " << toAstana << "\n";

    int seats = std::accumulate(f.begin(), f.end(), 0, [](int s, const Flight& x) { return s + x.seats; });
    std::cout << "Барлық орын: " << seats << "\n";

    std::vector<std::string> codes(f.size());
    std::transform(f.begin(), f.end(), codes.begin(), [](const Flight& x) { return x.code; });
    for (const auto& c : codes) std::cout << c << " ";
    std::cout << "\n";
}

    Қиын

    Нәтижені болжа

    Бағдарлама қандай екі санды шығарады? Жауапты бос орынмен бөліп жаз (мысалы, 7 12).

    #include <algorithm>
#include <iostream>
#include <numeric>
#include <vector>

int main() {
    std::vector<int> v{5, 12, 7, 20, 3, 15};
    int k = 10;
    auto big = [k](int x) { return x > k; };
    k = 100;                                     // lambda ұстаған көшірмеге әсер етпейді
    int n = std::count_if(v.begin(), v.end(), big);
    std::sort(v.begin(), v.end(), std::greater<int>());
    int s = std::accumulate(v.begin(), v.begin() + 3, 0);
    std::cout << n << " " << s << "\n";
}
    Кеңес

    Lambda k-ны құрылған сәтте көшіріп алды, сондықтан кейінгі k = 100 оған әсер етпейді. Сұрыпталғаннан кейін алғашқы үш элементтің қосындысын ал.

    Шешімі

    Жауап: 3 47. big үшін k = 10: 10-нан үлкендер - 12, 20, 15, яғни 3. Кему ретімен сұрыптаудан кейін {20, 15, 12, 7, 5, 3}, алғашқы үшеуінің қосындысы 20+15+12 = 47. Нақты нәтиже:

    $ ./t06_predict
3 47
