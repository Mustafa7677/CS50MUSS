Мазмұны

    B1 · 3-сабақ

    Ырық етіс (Passive)

    Бұл сабақта ырық етісті (passive) үйренеміз: be + V3 құрылымы, оның шақтары және қолданылатын жағдайлары. Себеп пен мақсат байланыстырғыштарын (because, so, to, so that) қарастырып, README мен release notes сияқты құжаттаманы оқып, қысқа README жазамыз.

    СабақтарСөздікГрамматикаIT-фразаларДеңгей тесті
    Деңгей туралы

    B1 - орта деңгейдің бірінші баспалдағы, ол CEFR шкаласындағы B1-ге шамамен сәйкес келеді. Бұл ресми деңгей емес, тек оқу жолындағы бағдар. Мазмұн жасанды интеллект көмегімен дайындалған, сондықтан мұғаліммен тексерген жөн.

    Сабақ мақсаттары

    Осы сабақтың соңында сіз мыналарды істей аласыз:

    • ырық етісті (passive) be + V3 құрылымымен жасайсыз және is / was / has been / will be формаларын таңдайсыз;
    • ырық етісті қашан қолдану керектігін (істеуші белгісіз не маңызды емес) түсініп, белсенді сөйлемді ырық етіске ауыстырасыз;
    • because, because of, since, so, therefore, to, in order to, so that, for + -ing сөздерімен себеп пен мақсатты білдіресіз;
    • README мен API құжаттамасын, release notes-ті ағылшынша оқып, негізгі ақпаратты табасыз;
    • шағын жоба үшін қысқа README бөлімін жазасыз.

    Уақыты: 55-60 минут. Бөлімдер: түсіндіру, оқу мәтіндері, 20 шақты жаттығу, қайталау тізімі, мини-жоба және тест.

    Ырық етіс: be + V3

    Белсенді сөйлемде істеуші бастауыш болады: Dan fixed the bug. Ырық етісте назар істің нәтижесіне не затқа аударылады: The bug was fixed. Құрылым: be (дұрыс шақта) + етістіктің үшінші формасы (V3). Шақты be етістігі көрсетеді:

    • Present Simple: am / is / are + V3 - The data is stored in a database.
    • Past Simple: was / were + V3 - The bug was fixed yesterday.
    • Present Perfect: has / have been + V3 - The server has been restarted.
    • Future: will be + V3 - The new version will be released on Friday.
    • Модальдармен: can / must / should be + V3 - Passwords must be changed every month.

    Болымсыз: The file isn't saved. The email wasn't sent. Сұрақ: Is the file saved? Was the email sent? When was the bug fixed? Істеушіні қосу керек болса, by қолданылады: The app was written by a small team. Көп жағдайда істеуші керек емес.

    Тыңдап көріңіз:

    Қазақшамен салыстыру

    Қазақ тілінде ырық етіс етістікке жалғау қосып жасалады: «сақта-л-ды», «жаз-ыл-ды», «жой-ыл-ды». Мағына ағылшын passive-ке дәл келеді: «Файл сақталды» = The file was saved. Ағылшынша жалғау жоқ, оның орнына be + V3 тұрады. Қазақ тілді оқушылар көбіне be-ті ұмытады: The file saved - қате (бұл «файл сақтады» болып шығады).

    Ырық етісті қашан қолданамыз

    • Істеуші белгісіз: My password was stolen.
    • Істеуші маңызды емес не айқын: The report was sent yesterday.
    • Назар затқа не нәтижеге: The page is updated every hour.
    • Техникалық және ресми мәтін (құжаттама, release notes, есеп): The files are compressed before upload.

    Белсенді сөйлемді ырық етіске ауыстыру қадамдары: (1) белсенді сөйлемнің нысаны жаңа бастауыш болады; (2) be дұрыс шақта қойылады; (3) етістік V3 формасына ауысады; (4) бастапқы бастауыш қажет болса, by-мен соңында қосылады. Мысал: Developers write tests. -> Tests are written by developers.

    Ескерту: тек нысаны бар (өтімді) етістіктің ғана ырық етісі бар. happen, appear, arrive, die сияқты етістіктерден ырық етіс жасалмайды: The error was happened - қате, дұрысы: The error happened.

    Себеп пен мақсат байланыстырғыштары

    Техникалық мәтінде «неге?» және «не үшін?» сұрақтарына жауап беру үшін мына сөздер қажет:

    • because + сөйлем (себебі): We stayed late because the server crashed.
    • because of + зат есім: We stayed late because of the crash. (Артынан сөйлем емес, зат есім келеді.)
    • since / as - себеп (көбіне сөйлем басында): Since the tests failed, we didn't release.
    • so - нәтиже: The tests failed, so we didn't release.
    • therefore - ресми нәтиже: The data is encrypted. Therefore, it is safe.
    • to + негізгі етістік - мақсат (не үшін): I use Git to save versions of my code.
    • in order to + негізгі етістік - сол мақсат, ресмирек: The cache is cleared in order to avoid old data.
    • so that + сөйлем - мақсат (can / will-мен): I wrote comments so that everyone can understand the code.
    • for + -ing - заттың қызметі: This function is used for sorting data.
    Қазақшамен салыстыру

    Қазақша «үшін» сөзі екі мағынада қолданылады: «оқу үшін келдім» (мақсат) және «ол үшін» (біреуге арнап). Ағылшынша мақсатты to + етістік береді: I came here to study, ал for study деген жиі қателік. Тек зат есімнің алдында for: I came here for the course.

    Жаңа сөздер

    • store verb сақтау (деректерді) Оқылуы: стор The data is stored in a file. Деректер файлда сақталады.
    • create verb жасау, құру Оқылуы: криэйт A new folder is created automatically. Жаңа қалта автоматты түрде жасалады.
    • support verb қолдау (мүмкіндікті) Оқылуы: сәпорт This format is not supported. Бұл формат қолдау таппайды.
    • parameter noun параметр (parameter) Оқылуы: пәрэмитә The function takes two parameters. Функция екі параметр алады.
    • return verb қайтару (мәнді) Оқылуы: ритән The function returns a number. Функция сан қайтарады.
    • default noun әдепкі мән (default) Оқылуы: дифолт The default value is zero. Әдепкі мән - нөл.
    • optional adj міндетті емес Оқылуы: опшнәл This parameter is optional. Бұл параметр міндетті емес.
    • required adj міндетті, талап етілетін Оқылуы: рикуайәд A password is required. Құпиясөз міндетті.
    • deprecated adj ескірген (қолданудан шығарылып жатқан) Оқылуы: деприкейтид This method is deprecated. Бұл әдіс ескірген.
    • installation noun орнату (installation) Оқылуы: инстәлейшн Installation takes five minutes. Орнату бес минут алады.
    • usage noun қолдану тәртібі Оқылуы: юсидж See the usage section below. Төмендегі қолдану бөлімін қараңыз.
    • automatically adv автоматты түрде Оқылуы: отәматикли The file is saved automatically. Файл автоматты түрде сақталады.
    • therefore adv сондықтан (ресми) Оқылуы: зеафо The data is encrypted. Therefore, it is safe. Деректер шифрланған. Сондықтан ол қауіпсіз.
    • so that conj ...үшін (мақсат) Оқылуы: соу зэт I wrote comments so that everyone can understand. Бәрі түсінуі үшін түсініктеме жаздым.
    • release notes noun шығарылым жазбалары (release notes) Оқылуы: рилис ноутс Read the release notes before updating. Жаңартудан бұрын шығарылым жазбаларын оқыңыз.

    IT-ағылшын: құжаттаманы оқу

    Құжаттама (documentation) - бағдарламашының ең жиі оқитын мәтіні. Оның тілі қысқа, ырық етіс пен бұйрық рай көп. Мына шағын README-ді оқып көріңіз (құрал ойдан шығарылған):

    # Notes
Notes is a small command-line tool. It is used for saving short notes.

## Installation
1. Download the package.
2. Run the install command.
The tool is installed in your home folder.

## Usage
notes add "Buy milk"   # a new note is created
notes list             # all notes are shown
notes delete 3         # note number 3 is deleted

## Notes
- Your notes are stored in a text file.
- If the file does not exist, it is created automatically.
- The tool must not be used for passwords.

    Құжаттаманы оқу стратегиясы: (1) тақырыптарға қарап, қажет бөлімді табыңыз (Installation, Usage, Parameters, Returns, Examples); (2) Note / Warning / Deprecated белгілерін міндетті түрде оқыңыз; (3) мысал кодты көшіргенше, оның не істейтінін түсіңіз; (4) белгісіз сөзді сөздіктен іздеңіз, бірақ бүкіл сөйлемді түсінуге тырысыңыз.

    Release notes (шығарылым жазбалары) да осыған ұқсас. Әр жолдың басында белгі тұрады:

    Version 2.4
Added: Dark theme is now supported.
Fixed: The export button was not working in some browsers.
Changed: The login page has been redesigned.
Removed: Support for old file formats was dropped.
    • Added - қосылды; Fixed - түзетілді; Changed - өзгертілді; Removed - алынып тасталды; Deprecated - ескірген деп белгіленді;
    • takes ... parameters - ... параметр қабылдайды; returns ... - ... қайтарады; is required / optional - міндетті / міндетті емес; defaults to ... - әдепкі мәні ....

    Оқу мәтіндері

    Мәтіндерді оқыңыз не тыңдаңыз, содан кейін «Қосымша жаттығулар» бөліміндегі сұрақтарға жауап беріңіз.

    Мәтін 1: A function in the documentation

    The function save_note takes two parameters. The first parameter, text, is required. It is the text of the note. The second parameter, tag, is optional. If it is not given, the default value "general" is used.
    save_note функциясы екі параметр алады. Бірінші параметр text міндетті. Бұл - жазбаның мәтіні. Екінші параметр tag міндетті емес. Ол берілмесе, әдепкі "general" мәні қолданылады.

    The function returns the number of the new note. The note is stored in a text file, and the file is created automatically if it does not exist.
    Функция жаңа жазбаның нөмірін қайтарады. Жазба мәтіндік файлда сақталады, ал файл жоқ болса, автоматты түрде жасалады.

    Warning: The old function add_note is deprecated. It will be removed in the next version, so please use save_note instead.
    Ескерту: ескі add_note функциясы ескірген. Ол келесі нұсқада алынып тасталады, сондықтан орнына save_note қолданыңыз.

    Мәтін 2: A maintenance notice

    The system will be updated tonight between 10 pm and midnight. All data has been backed up, so nothing will be lost.
    Жүйе бүгін кеште 22:00 мен түн ортасы аралығында жаңартылады. Барлық дерек көшірілген, сондықтан ештеңе жоғалмайды.

    During the update, the website will not be available. Please save your work before 10 pm in order to avoid problems.
    Жаңарту кезінде сайт қолжетімсіз болады. Мәселе болмауы үшін жұмысыңызды 22:00-ге дейін сақтаңыз.

    After the update, passwords must be changed. A message will be sent to your e-mail address because of the new security rules.
    Жаңартудан кейін құпиясөздерді ауыстыру керек. Жаңа қауіпсіздік ережелеріне байланысты e-mail мекенжайыңызға хабарлама жіберіледі.

    Қазақ тілді оқушылардың жиі қателері

    • be етістігін ұмыту. The file saved automatically. емес, The file is saved automatically. Ырық етісте be + V3 міндетті.
    • V3 орнына негізгі форма қою. The file is save. емес, The file is saved. be-ден кейін үшінші форма.
    • Өтімсіз етістіктен ырық етіс жасау. The error was happened. емес, The error happened. happen, appear, arrive ырық етіс алмайды.
    • Шақты шатастыру. The bug is fixed yesterday. емес, The bug was fixed yesterday. Өткен шақ көрсеткіші бар: was + V3.
    • V2 орнына V3 қою. The report was wrote by Dan. емес, The report was written by Dan. write - wrote - written.
    • because of-тан кейін сөйлем қою. because of the server crashed емес, because of the crash / because the server crashed because of + зат есім; because + сөйлем.
    • Мақсатты for + зат есіммен айту. I came here for study. емес, I came here to study. Мақсат: to + етістік.
    • because пен so-ны бір сөйлемде қатар қою. Because I was late, so I missed it. емес, Because I was late, I missed it. / I was late, so I missed it. Біреуі жеткілікті.

    Қорытынды

    • Ырық етіс = be + V3: is saved, was fixed, has been sent, will be released, must be changed.
    • Қолданылатын жағдай: істеуші белгісіз не маңызды емес, назар нәтижеге; құжаттама мен release notes-те жиі.
    • Тек өтімді етістіктен жасалады; happen, appear ырық етіс алмайды.
    • Себеп: because + сөйлем, because of + зат есім, since / as; нәтиже: so, therefore.
    • Мақсат: to / in order to + етістік, so that + сөйлем; қызмет: for + -ing.
    • README: Installation, Usage, Note; release notes: Added, Fixed, Changed, Removed.

    Келесі сабақта (B1 · 4-сабақ) жанама сөзді, анықтауыш сөйлемді, code review пікірлерін және қысқа презентацияны оқимыз.

    Өзіңізді тексеріп көріңіз:

    • be + V3 құрылымымен кемінде 5 шақта сөйлем құра аламын.
    • Белсенді сөйлемді ырық етіске ауыстыра аламын.
    • because, because of, so, to, so that сөздерін шатастырмаймын.
    • README мен release notes-тің негізгі белгілерін түсінемін.
    • Қарапайым README бөлімін жаза аламын.

    Бүгін, 2 күннен және 1 аптадан кейін қайталаңыз:

    • Бес шақтағы ырық етіс формуласын жазып шығыңыз: is / was / has been / will be / must be + V3.
    • Грамматика анықтамалығы: ырық етіс, ырық етіс шақтары, себеп пен мақсат, so / therefore.
    • Сөздік бетінде сабақ сөздерін сүзіп, «жаттадым» белгісін қойыңыз.
    • Өз жобаңыздың README-інен бір бөлімді ағылшынша қайта жазыңыз.
    • Алдыңғы сабақтардағы шартты сөйлемдер мен Present Perfect формаларын қайталаңыз.

    Мини-жоба: README және release notes

    Жоба 30 минут алады. Нәтиже - өз жобаңыздың құжаттамасына қосуға болатын шағын мәтін.

    • 1-қадам. Өз жобаңызды (не ойдан шығарылған құралды) таңдап, оның не үшін қажет екенін 1-2 сөйлеммен жазыңыз (It is used for ...).
    • 2-қадам. Installation және Usage бөлімдерін жазыңыз. Әр команданың түсініктемесінде ырық етіс қолданыңыз.
    • 3-қадам. Ескерту жазыңыз (must not be ...) және бір so that не in order to сөйлемін қосыңыз.
    • 4-қадам. Release notes үшін 4 жол жазыңыз: Added, Fixed, Changed, Removed.
