Мазмұны

    A1 · 2-сабақ

    There is / there are және орын

    Бұл сабақта заттың бар екенін және қайда тұрғанын айтуды үйренеміз: there is / there are, in / on / under / next to сияқты предлогтар, some / any, much / many, саналатын және саналмайтын зат есімдер. Соңында жоба қалтасын ағылшынша сипаттаймыз.

    СабақтарСөздікГрамматикаIT-фразаларДеңгей тесті
    Деңгей туралы

    A1 - бастапқы деңгей, ол CEFR шкаласына шамамен сәйкес келеді. Бұл ресми деңгей, куәлік немесе емтихан баламасы емес, тек оқу жолындағы бағдар. Мазмұн жасанды интеллект көмегімен дайындалған, сондықтан мұғаліммен тексерген жөн.

    Сабақ мақсаттары

    Осы сабақтың соңында сіз мыналарды істей аласыз:

    • there is / there are арқылы заттың барын не жоғын айтасыз және сұрақ қоясыз: Is there a printer? Are there any files?
    • in, on, under, next to, near, between, behind, in front of сияқты предлогтарды қолданып орынды сипаттайсыз;
    • some / any және much / many / a lot of сөздерін дұрыс таңдайсыз;
    • саналатын және саналмайтын зат есімдерді ажыратасыз (files - information);
    • жұмыс орныңызды және жоба қалтасының құрылымын 6-8 сөйлеммен сипаттайсыз.

    Уақыты: 45-60 минут. Әр жаттығу автоматты тексеріледі, ал жазба жаттығуын өз критерийлеріңізбен өзіңіз бағалайсыз.

    There is / there are

    Бір нәрсенің бар екенін айту үшін ағылшынша there is (жекеше) және there are (көпше) қолданылады. Бұл құрылымның өзі «орын» мағынасын білдірмейді: there бұл жерде тек «бар» дегенді көрсететін көмекші сөз. Қысқа түрі: there's.

    • Болымды: There is a printer in the room. There are three desks.
    • Болымсыз: There isn't a printer here. There aren't any windows.
    • Сұрақ: Is there a printer here? Are there any windows?
    • Қысқа жауап: Yes, there is. No, there isn't. Yes, there are. No, there aren't.
    • Сан сұрау: How many desks are there? - There are six.

    Бір ереже: there is / are сөйлеміне көбіне әлі аталмаған зат кіреді (There is a file in the folder). Белгілі затты the арқылы айтамыз: The file is in the folder.

    • there is phrase ... бар (жекеше) Оқылуы: зеә из There is a bug in the code. Кодта қате бар.
    • there are phrase ... бар (көпше) Оқылуы: зеә а There are two bugs in the code. Кодта екі қате бар.
    • room noun бөлме Оқылуы: рум The meeting room is free. Жиналыс бөлмесі бос.
    • kitchen noun ас үй Оқылуы: кичин There is a kettle in the kitchen. Ас үйде шәйнек бар.
    • hall noun дәліз, холл Оқылуы: хол There is a chair in the hall. Дәлізде орындық бар.
    • floor noun еден; қабат Оқылуы: фло My office is on the second floor. Менің кеңсем екінші қабатта.
    • wall noun қабырға Оқылуы: уол There is a clock on the wall. Қабырғада сағат бар.
    • shelf noun сөре Оқылуы: шелф There are books on the shelf. Сөреде кітаптар бар.
    • lamp noun шам, шырағдан Оқылуы: лэмп There is a lamp on my desk. Менің жазу үстелімде шам бар.
    • monitor noun монитор Оқылуы: монитә There are two monitors on the desk. Үстелде екі монитор бар.
    • table noun үстел Оқылуы: тейбл There is a laptop on the table. Үстелде ноутбук бар.
    • whiteboard noun ақ тақта Оқылуы: уайтбод There is a diagram on the whiteboard. Ақ тақтада диаграмма бар.
    • sofa noun диван Оқылуы: соуфә There is a sofa in the room. Бөлмеде диван бар.
    • clock noun қабырға сағаты Оқылуы: клок There is a clock on the wall. Қабырғада сағат тұр.
    Қазақшамен салыстыру

    Қазақша «Үстелде кітап бар» дегенде алдымен орын, соңында «бар» тұрады. Ағылшынша керісінше: There is a book on the table. Алдымен «бар» формасы (there is / are), кейін зат, соңында орын. «Жоқ» дегенде қазақша «жоқ» сөзі, ағылшынша there isn't / there aren't (немесе there is no ...). Қазақшада «бар» етістік емес, ал ағылшынша is / are нағыз етістік, сондықтан ол санға қарай таңдалады.

    Орын предлогтары

    Орынды қазақша жалғаулармен айтамыз («үстелдің үстінде», «қалтада»). Ағылшынша бұл рөлді предлог (preposition) атқарады. Ол заттан бұрын тұрады.

    • in prep ішінде; -да, -де Оқылуы: ин The file is in the folder. Файл қалтада тұр.
    • on prep үстінде; -да (бетте) Оқылуы: он The phone is on the desk. Телефон жазу үстелінің үстінде.
    • under prep астында Оқылуы: андә The bag is under the desk. Сөмке жазу үстелінің астында.
    • next to prep қасында Оқылуы: некст ту The printer is next to the door. Принтер есіктің қасында.
    • near prep жанында, маңында Оқылуы: ниә The office is near the station. Кеңсе станцияның жанында.
    • between prep арасында (екі нәрсенің) Оқылуы: битуин The lamp is between the chairs. Шам екі орындықтың арасында.
    • behind prep артында Оқылуы: бихайнд The bag is behind the door. Сөмке есіктің артында.
    • in front of prep алдында Оқылуы: ин франт ов The chair is in front of the desk. Орындық жазу үстелінің алдында.
    • above prep үстінде (жоғарыда) Оқылуы: эбав The clock is above the door. Сағат есіктің үстінде.
    • opposite prep қарама-қарсы Оқылуы: опәзит The kitchen is opposite the office. Ас үй кеңсеге қарама-қарсы орналасқан.
    • inside prep ішінде (шектің ішінде) Оқылуы: инсайд The file is inside the folder. Файл қалтаның ішінде.
    • outside prep сыртында Оқылуы: аутсайд The printer is outside the room. Принтер бөлменің сыртында.
    • left noun сол жақ Оқылуы: лэфт The door is on the left. Есік сол жақта.
    • right noun оң жақ Оқылуы: райт The window is on the right. Терезе оң жақта.
    • top noun жоғарғы бөлік Оқылуы: топ The menu is at the top. Мәзір жоғарыда.
    • bottom noun төменгі бөлік Оқылуы: ботәм The button is at the bottom. Батырма төменде.
    • middle noun орта Оқылуы: мидл The table is in the middle. Үстел ортада.
    • corner noun бұрыш Оқылуы: конә The printer is in the corner. Принтер бұрышта.
    • The file is in the folder. (қалтаның ішінде)
    • The laptop is on the desk. (үстелдің үстінде, жанасып тұр)
    • The bag is under the desk.
    • The printer is next to the door.
    • The lamp is between the chairs. (екі нәрсенің арасы)
    • The clock is above the door.
    • The menu is at the top of the page. / on the left, on the right

    Сөйлемдерді there is құрылымымен де айтуға болады: There is a lamp on my desk. There are two chairs next to the table.

    in / on / at

    Үш негізгі предлогты былай ажыратыңыз: in - ішінде (in the folder, in the room); on - беткі қабатта (on the desk, on the wall, on the page); at - нүктеде (at the top, at the door). Сайт бетінде мәзір on the page, ал бетте оның орны at the top.

    Мөлшер: some, any, much, many

    Мөлшерді білдіретін сөздер зат есімнің санала алатынына байланысты таңдалады.

    • some - біраз, бірнеше (болымды сөйлемде): There are some files in the folder.
    • any - болымсыз және сұрақта: There aren't any errors. Are there any errors?
    • many - көп, саналатын көпше зат есіммен: There aren't many files.
    • much - көп, саналмайтын зат есіммен: There isn't much time.
    • a lot of - болымды сөйлемде екі түрге де: There are a lot of bugs. We have a lot of time.
    • a few - бірнеше (саналатын): There are a few tasks left.
    • How many ... ? саналатынға, How much ... ? саналмайтынға: How many files are there? How much time do we have?
    • some pron біраз, бірнеше Оқылуы: сам There are some files in the folder. Қалтада бірнеше файл бар.
    • any pron ешқандай; қандай да бір Оқылуы: эни Are there any errors? Қандай да бір қате бар ма?
    • many pron көп (саналатын) Оқылуы: мэни There are many files here. Мұнда көп файл бар.
    • much pron көп (саналмайтын) Оқылуы: мач There is not much time. Уақыт көп емес.
    • a lot of phrase көп Оқылуы: э лот ов There are a lot of bugs. Қате көп.
    • a few phrase бірнеше, аздаған Оқылуы: э фью There are a few tasks left. Бірнеше тапсырма қалды.
    • how many phrase қанша (саналатын) Оқылуы: хау мэни How many files are there? Қанша файл бар?
    • how much phrase қанша (саналмайтын); бағасы қанша Оқылуы: хау мач How much time do we have? Бізде қанша уақыт бар?

    Саналатын және саналмайтын зат есімдер

    Саналатын зат есімді санауға болады: one file, two files, a user, three users. Олардың көпше түрі бар. Саналмайтын зат есімді санауға болмайды: water, money, information, advice, software, time. Оның көпше түрі жоқ, алдында a / an жоқ, етістік жекеше болады: The information is correct. Мөлшерді some, much, a lot of арқылы немесе өлшем сөзі арқылы береміз: a piece of information, a glass of water.

    • water noun су Оқылуы: уотә There is water on the table. Үстелде су бар.
    • money noun ақша Оқылуы: мани I do not have much money. Менде ақша көп емес.
    • information noun ақпарат Оқылуы: информейшн There is useful information here. Мұнда пайдалы ақпарат бар.
    • advice noun кеңес Оқылуы: эдвайс I need some advice. Маған бір-екі кеңес керек.
    • software noun бағдарламалық жасақтама Оқылуы: софтуэә The company makes software. Компания бағдарламалық жасақтама жасайды.
    Қазақшамен салыстыру

    Қазақшада «көп» сөзі екі түрге де жарайды («көп файл», «көп уақыт»). Ағылшынша many мен much бөлек: many files, much time. Қазақшада «ақпарат», «кеңес» сөздерін «бір ақпарат», «екі кеңес» деп айту мүмкін. Ағылшынша an information, two advices, informations дегендер қате; дұрысы some information, two pieces of advice.

    IT-мазмұны: бет пен қалта

    • document noun құжат Оқылуы: докьюмент There is a document in the folder. Қалтада бір құжат бар.
    • image noun сурет, кескін Оқылуы: имидж There is an image on the page. Бетте бір сурет бар.
    • screenshot noun скриншот, экран суреті Оқылуы: скриншот I send a screenshot. Мен скриншот жіберемін.
    • list noun тізім Оқылуы: лист There is a list of tasks. Тапсырмалар тізімі бар.
    • line noun жол (кодта, мәтінде) Оқылуы: лайн There is an error on line ten. Оныншы жолда қате бар.
    • page noun бет Оқылуы: пейдж There are three pages in the file. Файлда үш бет бар.
    • project noun жоба Оқылуы: проджект We have a new project. Бізде жаңа жоба бар.

    Анықтамалық: there is / there are, орын предлогтары, some / any, much / many, саналатын / саналмайтын.

    Қазақша мен ағылшынша: тікелей салыстыру

    • Бар / жоқ. Қазақша: «Қалтада файл бар». Ағылшынша: There is a file in the folder. Тәртіп өзгереді: бар-зат-орын.
    • Санына байланысты етістік. Қазақша «бар» өзгермейді. Ағылшынша: There is a file / There are two files.
    • Орын. Қазақша: «үстелдің үстінде» (кейінгі қосымша). Ағылшынша: on the desk (алдыңғы предлог).
    • Көп. Қазақша: «көп». Ағылшынша: many (саналатын), much (саналмайтын), a lot of (болымды сөйлемде екеуі).
    • Ешқандай. Қазақша: «ешқандай қате жоқ». Ағылшынша: There aren't any errors немесе There are no errors.
    • Ақпарат, кеңес. Қазақша санауға болады («екі кеңес»). Ағылшынша жоқ: two pieces of advice.

    Оқу мәтіндері

    Мәтін 1. Біздің кеңсе

    There is a big room on the second floor. It is our office.
    Екінші қабатта үлкен бөлме бар. Бұл біздің кеңсе.

    There are six desks in the room. On every desk, there is a laptop and a monitor.
    Бөлмеде алты жазу үстелі бар. Әр үстелде ноутбук пен монитор бар.

    There is a whiteboard on the wall. Next to the whiteboard, there is a window.
    Қабырғада ақ тақта бар. Ақ тақтаның қасында терезе бар.

    There isn't a printer in the room, but there is one in the hall.
    Бөлмеде принтер жоқ, бірақ дәлізде бар.

    There isn't much space, but we like our office.
    Орын көп емес, бірақ біз кеңсемізді жақсы көреміз.

    Мәтін 2. Жоба қалтасы

    project/
  README.md
  src/
    index.html
    style.css
  images/
    logo.png

    Our project folder has three parts.
    Біздің жоба қалтасы үш бөліктен тұрады.

    There is a file called README in the main folder.
    Негізгі қалтада README деп аталатын файл бар.

    There are two files in the src folder: index.html and style.css.
    src қалтасында екі файл бар: index.html және style.css.

    There is one image in the images folder. There is no folder for tests.
    images қалтасында бір сурет бар. Тесттерге арналған қалта жоқ.

    Қазақ тілді оқушылардың жиі қателері

    • «Бар» үшін have қолдану. In the folder have three files. емес, There are three files in the folder.
    • there is / are санға сай емес. There is three files. емес, There are three files.
    • Орынды сөйлем басына қою. On the desk there a laptop. емес, There is a laptop on the desk.
    • Саналмайтын зат есімге көпше жалғау. informations, advices, softwares емес, information, advice, software.
    • much / many араласуы. many time, much files емес, much time, many files.
    • any болымды сөйлемде. There are any files. емес, There are some files. / There aren't any files.
    • Предлог шатасуы. The file is at the folder. / The menu is in the wall. емес, The file is in the folder. The poster is on the wall.
    • Артикльді ұмыту. There is printer in the hall. емес, There is a printer in the hall.

    IT-ағылшын: қалта құрылымы мен қате есебі

    Жоба қалтасын сипаттау бағдарламашыға күн сайын керек: README, тапсырма сипаттамасы, хабарлама. Үлгі:

    There is a folder called images.
There are two files in the folder.
There is no file called logo.svg.

    Қате туралы хабарламада да there is / are жиі қолданылады:

    • There is an error on line ten. (Оныншы жолда қате бар.)
    • There are three errors on the page.
    • There isn't a Save button on the screen.
    • Is there a way to download the file? (Файлды жүктеп алудың жолы бар ма?)

    Dan: Is there a folder for images?
    Суреттерге арналған қалта бар ма?

    Aida: Yes, there is. It is next to the src folder.
    Иә, бар. Ол src қалтасының қасында.

    Dan: Are there any files in it?
    Онда файлдар бар ма?

    Aida: Yes, there are two images.
    Иә, екі сурет бар.

    Қосымша тақырыптық сөздік

    Төмендегі тақырыптық топтарды қажет болғанда ашып қараңыз. Бұл сөздер сабақтағы мәтіндерді толықтырады және сөздік бетінде де бар.

    қала және ғимарат (9 сөз)
    • map noun карта Оқылуы: мэп The map is on the wall. Карта қабырғада.
    • address noun мекенжай Оқылуы: әдрес What is your address? Сіздің мекенжайыңыз қандай?
    • building noun ғимарат Оқылуы: билдин Our office is in a big building. Біздің кеңсе үлкен ғимаратта.
    • entrance noun кіреберіс Оқылуы: энтрэнс The entrance is on the left. Кіреберіс сол жақта.
    • exit noun шығу жолы Оқылуы: эксит The exit is next to the stairs. Шығу жолы баспалдақтың қасында.
    • stairs noun баспалдақ Оқылуы: стеәз The stairs are on the right. Баспалдақ оң жақта.
    • elevator noun лифт Оқылуы: элэвэйтә There is an elevator in the building. Ғимаратта лифт бар.
    • parking noun көлік тұрағы Оқылуы: паакин There is free parking. Тегін көлік тұрағы бар.

    Жаттығулар

    Жеңілден орташаға қарай орындаңыз. Әр жаттығуда «Тексеру» батырмасын басыңыз: қате болса, түсіндірме көрсетіледі. «Жауаптарды көрсету» тек соңғы шара. Нәтиже осы құрылғыда сақталады.

    Жеңіл

    1. There is немесе there are

    Бос орынға дұрыс форманы таңдаңыз.

    Жеңіл

    2. There is / are толықтыру

    Бос орынға is, are, isn't немесе aren't жазыңыз.

    Жеңіл

    3. Предлогты таңдаңыз

    Қай предлог сәйкес келеді?

    Орташа

    4. some, any, much, many, a lot of

    Бос орынға мөлшер сөзін жазыңыз.

    Орташа

    5. Саналатын ба, саналмайтын ба?

    Дұрыс сөйлемді таңдаңыз.

    Жеңіл

    6. Предлогтар

    Предлогтың мағынасын таңдаңыз.

    Орташа

    7. Сөйлем құраңыз

    Сөздерді дұрыс ретпен басыңыз.

    Жеңіл

    8. Дұрыс па, бұрыс па?

    True (дұрыс) не False (бұрыс) таңдаңыз.

    Орташа

    9. Мәтін 1 бойынша сұрақтар

    Мәтін 1-ді («Біздің кеңсе») қайта оқып, жауап беріңіз.

    Орташа

    10. Мәтін 2 бойынша сұрақтар

    Мәтін 2-ні («Жоба қалтасы») қайта оқып, жауап беріңіз.

    Орташа

    11. Қатені табыңыз

    Әр сұрақта төрт сөйлем берілген. Қате бар сөйлемді табыңыз.

    Қиын

    12. Қатені түзетіңіз

    Сөйлемдегі қатені түзетіп, толық дұрыс сөйлемді жазыңыз.

    Орташа

    13. Диктант

    Әр сөйлемді тыңдап, жазыңыз.

    Орташа

    14. Тыңдап таңдаңыз

    Не естідіңіз? Дұрыс нұсқаны таңдаңыз.

    Орташа

    15. Айту жаттығуы

    Әр сөйлемді тыңдап, дауыстап 3 рет қайталаңыз.

    Орташа

    16. Қысқа жазба: менің жұмыс орным

    IT-ағылшын жаттығулары

    Орташа

    17. Қате есебі және қалта

    Дұрыс сөйлемді таңдаңыз.

    Орташа

    18. Қалта мен бет сөздері

    Сөзге мағынасын сәйкестендіріңіз.

    Мини-жоба: жоба қалтасын сипаттау

    Қиын

    19. Мини-жоба: README үшін қалта сипаттамасы

    Ойдан шығарылған шағын жобаңыздың қалтасын README файлы үшін ағылшынша сипаттаңыз.

    Қорытынды

    Бүгін мынаны үйрендік:

    • There is + жекеше / саналмайтын зат, there are + көпше зат. Болымсыз: there isn't / aren't; сұрақ: Is there ... ? Are there ... ?
    • Орын предлогтары: in, on, under, next to, near, between, behind, in front of, above, opposite. Предлог заттан бұрын тұрады.
    • some - болымды, any - болымсыз және сұрақ; many - саналатын, much - саналмайтын, a lot of - болымды сөйлемде екеуіне де.
    • Саналмайтын зат есімдер (water, money, information, advice, software) көпше болмайды, алдында a / an тұрмайды.
    • Қалта құрылымы мен қате есебін ағылшынша сипаттай аласыз: There is an error on line ten.

    Қайталау тізімі

    Сабақтан кейін 1, 3 және 7 күннен соң мына тізімді қайталаңыз:

    • there is / there are: болымды, болымсыз, сұрақ, қысқа жауап.
    • Он орын предлогы мен олармен бес сөйлем.
    • some / any / much / many / a lot of / a few: қайсысы қашан.
    • Бес саналмайтын зат есім: water, money, information, advice, software.
    • Өз жұмыс орныңызды 6 сөйлеммен сипаттаңыз.

    Келесі сабақ: A1 · 3-сабақ: Present Continuous және can.

    Өзіңізді тексеріп көріңіз:

    • There is пен there are-ді санға қарап таңдаймын.
    • Он шақты орын предлогын қолданамын.
    • some / any және much / many ережесін білемін.
    • Саналатын және саналмайтын зат есімдерді ажыратамын.
    • Жұмыс орнымды және жоба қалтасын ағылшынша сипаттай аламын.

    Қорытынды тест

    1. Бос орынға не келеді? There ___ three files in the folder.

    көпше -> there are.

    2. «Дәлізде принтер бар ма?» қалай айтылады?

    Сұрақ: Is there ...?

    3. Қай сөйлем дұрыс?

    Предлог + the + зат есім.

    4. Бос орынға не келеді? How ___ time do we have?

    time саналмайды: much.

    5. Қай сөйлем дұрыс?

    advice саналмайды.

    6. Бос орынға не келеді? There aren't ___ errors on the page.

    Болымсыз сөйлемде any.

    7. The laptop is on the desk. нені білдіреді?

    on - үстінде.

    8. «Оныншы жолда қате бар» ағылшынша:

    There is an error on line ten.
