Мазмұны

    B1 · 2-сабақ

    Шартты сөйлемдер (0, 1 және 2)

    Бұл сабақта шартты сөйлемдердің үш түрін (0, 1 және 2) үйренеміз: жалпы заңдылық, нақты болашақ және ойдан шығарылған жағдай. Unless, as soon as, until, in case сөздерін қарастырып, stand-up-та кедергіні шартты сөйлемдермен түсіндіруді жаттықтырамыз.

    СабақтарСөздікГрамматикаIT-фразаларДеңгей тесті
    Деңгей туралы

    B1 - орта деңгейдің бірінші баспалдағы, ол CEFR шкаласындағы B1-ге шамамен сәйкес келеді. Бұл ресми деңгей емес, тек оқу жолындағы бағдар. Мазмұн жасанды интеллект көмегімен дайындалған, сондықтан мұғаліммен тексерген жөн.

    Сабақ мақсаттары

    Осы сабақтың соңында сіз мыналарды істей аласыз:

    • нөлінші шартты сөйлемді (If you press Save, the file is saved) жалпы заңдылықтар үшін қолданасыз;
    • бірінші шартты сөйлемді (If the tests pass, I will deploy) жасайсыз және if бөлігіне will қоймайсыз;
    • unless, when, as soon as, until, in case сөздерін дұрыс қолданасыз;
    • екінші шартты сөйлеммен (If I had more time, I would ...) ойдан шығарылған жағдай мен кеңесті айтасыз (If I were you, ...);
    • stand-up-та кеше, бүгін және кедергі (blocker) туралы шартты сөйлемдермен баяндайсыз.

    Уақыты: 55-60 минут. Бөлімдер: түсіндіру, оқу мәтіндері, 20 шақты жаттығу, қайталау тізімі, мини-жоба және тест.

    Нөлінші шартты: жалпы заңдылық

    Әрқашан орындалатын жағдайлар үшін екі бөлікте де Present Simple қолданылады: If + Present Simple, Present Simple. Бұл жерде if орнына when да қоюға болады.

    • If the test fails, the build stops. - Тест құласа, build тоқтайды.
    • If you don't save the file, you lose your changes.
    • When the battery is empty, the laptop turns off.
    • If you click this button, the page reloads.

    Бірінші шартты: нақты болашақ

    Мүмкін болатын жағдай мен оның нәтижесі: If + Present Simple, will + негізгі етістік. Ең маңызды ереже: if бөлігінде will қолданылмайды, ол Present Simple-мен айтылады.

    • If the tests pass, I will deploy the app. - Тесттер өтсе, қолданбаны орналастырамын.
    • If you don't back up your files, you will lose them.
    • We won't release on Friday if the server is down. Бөліктердің орны ауыса алады: if-бөлік соңында тұрса, үтір қойылмайды.
    • Негізгі бөлікте can, should, may немесе бұйрық рай болады: If you have any questions, you can ask me. If you see an error, tell me.

    unless = if ... not: Unless you restart the server, the change won't work. (Серверді қайта қоспасаңыз, өзгеріс жұмыс істемейді.) Unless-тен кейін болымсыз етістік қоймайды: unless you don't restart - қате.

    Тағы бір ереже: when, as soon as, before, after, until сөздерінен кейін де болашақ үшін Present Simple қолданылады: I'll call you as soon as I finish. We won't release until all tests pass. Ал in case - «егер ...болып қалса»: Make a backup in case something goes wrong.

    Тыңдап көріңіз:

    Екінші шартты: ойдан шығарылған жағдай

    Қазір шындыққа жанаспайтын не өте екіталай жағдайды айту үшін: If + Past Simple, would + негізгі етістік. Етістік өткен шақта тұрса да, мағынасы қазіргі не болашақ.

    • If I had more time, I would learn Go. - Уақытым көп болса, Go тілін үйренер едім. (Бірақ уақыт жоқ.)
    • If we had a bigger team, we would finish faster.
    • What would you do if the server crashed?
    • be етістігі: барлық жақта were қолданылады (If I were you, ...). Ауызша was да естіледі, бірақ were дұрысырақ.

    Кеңес беру үшін ең пайдалы тіркес: If I were you, I would ... - If I were you, I would ask for help. (Мен сіздің орныңызда болсам, көмек сұрар едім.) Қысқа түрі: I'd. Негізгі бөлікте could (мүмкін болар еді) және might (мүмкін) де келеді: If I had a faster laptop, I could test more.

    Қазақшамен салыстыру

    Қазақшада шартты райды «-са/-се» жалғауы береді және оны екі жағдайға да қолданамыз: «Тест өтсе, орналастырамын» (нақты) және «Уақытым болса, үйренер едім» (ойдан шығарылған). Айырма негізгі етістікте: «-мын» (нақты) және «-ар едім» (ойдан шығарылған). Ағылшынша айырма if бөлігінде де көрінеді: Present Simple (1-түр) не Past Simple (2-түр). Сондықтан қазақ тілді оқушы If I will have time немесе If I would have time деп қателеседі: if бөлігіне will / would қойылмайды.

    Жаңа сөздер

    • unless conj егер ... болмаса Оқылуы: әнлес Unless you restart the server, the change will not work. Серверді қайта қоспасаңыз, өзгеріс жұмыс істемейді.
    • in case conj ...болып қалса (сақтану үшін) Оқылуы: ин кейс Make a backup in case something goes wrong. Бірдеңе дұрыс болмай қалса деп көшірме жасаңыз.
    • as soon as conj ...болысымен Оқылуы: эз сун эз I'll call you as soon as I finish. Бітіре салысымен сізге қоңырау шаламын.
    • until conj ...дейін Оқылуы: әнтил We won't release until all tests pass. Барлық тест өткенше шығармаймыз.
    • otherwise adv әйтпесе Оқылуы: азәуайз Save the file. Otherwise, you will lose it. Файлды сақтаңыз. Әйтпесе, оны жоғалтасыз.
    • condition noun шарт, жағдай Оқылуы: кәндишн The only condition is a strong password. Жалғыз шарт - мықты құпиясөз.
    • depend on phrasal verb ...-ға байланысты болу Оқылуы: дипенд он It depends on the server. Бұл серверге байланысты.
    • blocker noun кедергі (жұмысты тоқтатып тұрған) (blocker) Оқылуы: блокә My blocker is the missing API key. Менің кедергім - жоқ API кілті.
    • blocked adj кедергіге тап болған, тоқтап тұрған Оқылуы: блокт I'm blocked until Dan reviews my code. Дан кодымды қарап шыққанша мен тоқтап тұрмын.
    • wait for phrasal verb күту Оқылуы: уэйт фо I'm waiting for the test results. Мен тест нәтижесін күтіп жатырмын.
    • access noun қолжетімділік, рұқсат (access) Оқылуы: эксес I don't have access to the test server. Менде сынақ серверіне қолжетімділік жоқ.
    • review verb қарап шығу (кодты) Оқылуы: ривью Could you review my code? Кодымды қарап шығасыз ба?
    • assume verb болжау, деп есептеу Оқылуы: әсьюм I assume the server is working. Сервер жұмыс істеп тұр деп есептеймін.
    • available adj қолжетімді, бос Оқылуы: әвейләбл Is the test server available today? Сынақ сервері бүгін қолжетімді ме?
    • risk noun тәуекел Оқылуы: риск There is a small risk of delay. Кешігу тәуекелі аздап бар.

    Қазақ тілді оқушылардың жиі қателері

    • if бөлігіне will қою. If it will rain, we stay at home. емес, If it rains, we will stay at home. if бөлігінде Present Simple қолданылады.
    • if бөлігіне would қою. If I would have time, I would learn Go. емес, If I had time, I would learn Go. 2-түрде if бөлігі Past Simple-де.
    • when / as soon as-тен кейін will қою. I'll call you when I will arrive. емес, I'll call you when I arrive. Уақыт жалғаулықтарынан кейін Present Simple.
    • unless-ке болымсыз етістік қосу. Unless you don't restart, it won't work. емес, Unless you restart, it won't work. unless өзі болымсыз мағына береді.
    • Екінші шарттағы if I was / were. If I was you, I would ask. емес, If I were you, I would ask. Кеңес берген кезде were дұрысырақ.
    • Негізгі бөлікте will қолдану (2-түр). If I had a car, I will go there. емес, If I had a car, I would go there. 2-түрде would керек.
    • Нөлінші шартты 1-түрмен шатастыру. If water boils, it will become gas. (заңдылық) емес, If water boils, it becomes gas. Жалпы заңдылықта will қажет емес.
    • Үтірді дұрыс қоймау. I will deploy, if the tests pass. емес, I will deploy if the tests pass. if бөлігі соңында тұрса, үтір қойылмайды.

    IT-ағылшын: stand-up және кедергі

    Stand-up - команданың қысқа күнделікті жиналысы. Әр адам үш нәрсе айтады: Yesterday (кеше не істедім - Past Simple не Present Perfect), Today (бүгін не істеймін - going to / will), Blockers (кедергілер). Үшіншісінде шартты сөйлемдер өте жиі қолданылады.

    Yesterday: I finished the login form and wrote two tests.
Today: I'm going to connect the form to the server.
Blockers: I'm waiting for the API key.
  If I don't get it by noon, I won't be able to test the form.
  If I had access to the test server, I would finish faster.
    • Кедергіні атау: I'm blocked by ... / I'm waiting for ... / I don't have access to ...
    • Көмек сұрау: Could someone review my code? I need help with ...
    • Тәуекелді ескерту: If this takes longer, we might miss the deadline.
    • Уәде беру: I'll let you know as soon as I have news.
    • Кеңес: If I were you, I would ask Dan. He knows this part well.

    Aida: Yesterday I fixed the search bug. Today I'm going to write tests for it.
    Кеше іздеу қатесін түзеттім. Бүгін оған тест жазамын.

    Dan: Any blockers?
    Кедергі бар ма?

    Aida: Yes. If I don't get access to the test server, I won't be able to finish.
    Иә. Сынақ серверіне қолжетімділік алмасам, аяқтай алмаймын.

    Dan: I'll ask Sam today. As soon as we have news, I'll tell you.
    Мен бүгін Сэмнен сұраймын. Жаңалық болысымен сізге айтамын.

    Оқу мәтіндері

    Мәтіндерді оқыңыз не тыңдаңыз, содан кейін «Қосымша жаттығулар» бөліміндегі сұрақтарға жауап беріңіз.

    Мәтін 1: A stand-up in the morning

    It is nine o'clock, and the team has its daily stand-up. Sam speaks first. "Yesterday I reviewed two pull requests. Today I'm going to update the documentation. No blockers."
    Сағат тоғыз, команда күнделікті stand-up өткізіп жатыр. Сэм бірінші сөйлейді. «Кеше екі pull request қарап шықтым. Бүгін құжаттаманы жаңартамын. Кедергі жоқ».

    Then Aida talks. "I finished the login form yesterday. This afternoon I will test it. But I have one problem: if the API key doesn't arrive today, I won't be able to connect the form to the server."
    Содан кейін Айда сөйлейді. «Кеше кіру формасын аяқтадым. Түстен кейін оны тестілеймін. Бірақ бір мәселе бар: API кілті бүгін келмесе, форманы серверге қоса алмаймын».

    Dan says, "If I were you, I would write to the project manager now. I'll also ask the server team. As soon as the key is ready, I'll send it to you." Aida smiles. "Thanks. That would help a lot."
    Дан: «Сіздің орныңызда болсам, жобаның менеджеріне дәл қазір жазар едім. Мен де сервер командасынан сұраймын. Кілт дайын болысымен сізге жіберемін», - дейді. Айда күліп: «Рахмет. Бұл көп көмектесер еді», - дейді.

    Мәтін 2: An e-mail about a delay

    Subject: Delay in the release. Hi Maria, I'm writing to let you know about the release. If the tests pass today, we will release on Thursday.
    Тақырып: Шығарылымның кешігуі. Сәлем, Мария! Шығарылым туралы хабарлау үшін жазып отырмын. Тесттер бүгін өтсе, бейсенбіде шығарамыз.

    However, the test server is unstable, and unless we fix it, the tests won't finish. If we had two more developers, we could finish earlier, but I understand that it isn't possible right now.
    Алайда сынақ сервері тұрақсыз, оны түзетпесек, тесттер аяқталмайды. Бізде тағы екі бағдарламашы болса, ертерек бітіре алар едік, бірақ қазір бұл мүмкін емес екенін түсінемін.

    As soon as we have news, I'll write to you again. In case you need more details, please call me. Best regards, Aida
    Жаңалық болысымен сізге қайта жазамын. Қосымша мәлімет қажет болып қалса, маған қоңырау шалыңыз. Құрметпен, Айда

    Қорытынды

    • Нөлінші шартты: If + Present Simple, Present Simple - жалпы заңдылық.
    • Бірінші шартты: If + Present Simple, will + негізгі етістік - нақты болашақ. If бөлігінде will болмайды.
    • unless = if not; when, as soon as, until, before + Present Simple (болашақ үшін); in case - сақтану үшін.
    • Екінші шартты: If + Past Simple, would + негізгі етістік - ойдан шығарылған жағдай; If I were you, I would ... - кеңес.
    • Stand-up: Yesterday - Today - Blockers; кедергіні шартты сөйлеммен түсіндіру.

    Келесі сабақта (B1 · 3-сабақ) ырықсыз етісті (passive) және құжаттаманы оқуды қарастырамыз.

    Өзіңізді тексеріп көріңіз:

    • Үш шартты түрінің құрылымын айта аламын.
    • if бөлігіне will / would қоймаймын.
    • unless, as soon as, until, in case сөздерін орнымен қолданамын.
    • If I were you, I would ... деп кеңес бере аламын.
    • Stand-up-та кедергіні ағылшынша түсіндіре аламын.

    Қайталау тізімі

    Бүгін, 2 күннен және 1 аптадан кейін қайталаңыз:

    • Үш түрдің формуласын қағазсыз жазып шығыңыз және әрқайсысына өз мысалыңызды ойлап табыңыз.
    • Грамматика анықтамалығы: нөлінші шартты, бірінші шартты, екінші шартты, when / as soon as / until, unless / in case.
    • Сөздік бетінде сабақ сөздерін сүзіп, «жаттадым» белгісін қойыңыз.
    • Ертеңгі stand-up-ыңызды ағылшынша 30 секундта айтып көріңіз.
    • Алдыңғы сабақтың (Present Perfect) V3 формаларын қайталаңыз.

    Мини-жоба: бір апталық stand-up сценарийі

    Жоба 25-30 минут алады. Нәтиже - нақты командада қолдануға болатын 3 күндік stand-up жазбасы.

    • 1-қадам. Ойдан шығарылған жобаны таңдаңыз (мысалы, қолданба не веб-сайт).
    • 2-қадам. Үш күнге stand-up жазыңыз: Yesterday, Today, Blockers.
    • 3-қадам. Әр күнгі Blockers бөлімінде бір шартты сөйлем жазыңыз: бірі 1-түр, бірі 2-түр, бірі unless/as soon as.
    • 4-қадам. Соңында командадан көмек сұрайтын бір сөйлем қосыңыз (Could someone ... ?).
    Қиын

    21. Жоба: 3 күндік stand-up

    Қорытынды тест

    1. Қай сөйлем дұрыс (1-түр)?

    if + Present Simple, will + негізгі етістік.

    2. Қай сөйлем дұрыс (2-түр)?

    if + Past Simple, would + негізгі етістік.

    3. Unless you restart the server, it won't work. Мағынасы қандай?

    unless = if ... not.

    4. Кеңес беру үшін қай тіркес дұрыс?

    If I were you, I would ...

    5. I'll call you as soon as I ___.

    as soon as-тан кейін Present Simple.

    6. Нөлінші шартты қайсы?

    Жалпы заңдылық: Present Simple екі бөлікте.

    7. Stand-up-тағы blocker дегеніміз не?

    blocker - кедергі.

    8. Make a backup in case something goes wrong. Мағынасы қандай?

    in case - сақтану үшін.
