Мазмұны

    A2 · 3-сабақ

    Салыстыру және санау

    Бұл сабақта заттарды салыстыруды үйренеміз: faster than, more useful than, the best. Санауға болатын және болмайтын зат есімдерді (files және information), much / many / a few / a little сөздерін қарастырып, екі құралды салыстыратын қысқа хабарлама жазамыз.

    СабақтарДағдыларСөздікГрамматикаIT-фразаларДеңгей тесті
    Деңгей туралы

    A2 - бастапқы деңгейден кейінгі баспалдақ, ол CEFR шкаласындағы A2-ге шамамен сәйкес келеді. Бұл ресми деңгей емес, тек оқу жолындағы бағдар. Мазмұн жасанды интеллект көмегімен дайындалған, сондықтан мұғаліммен тексерген жөн.

    Сабақ мақсаттары

    Осы сабақтың соңында сіз мыналарды істей аласыз:

    • сын есімнің салыстырмалы және ең жоғары дәрежесін жасайсыз (faster, more useful, the best) және than сөзін дұрыс қолданасыз;
    • as ... as, too және enough құрылымдарымен екі зат туралы пікір айтасыз;
    • санауға болатын және болмайтын зат есімдерді ажыратасыз (files және information);
    • much, many, a lot of, some, any, a few, a little сөздерінің қайсысы қайда келетінін білесіз;
    • екі құралды салыстырып, қысқа пікір хабарлама жазасыз.

    Уақыты: 50-55 минут. Барлық жаттығу автоматты тексеріледі, жазба жұмысын өзіңіз бағалайсыз.

    Салыстырмалы шырай

    Екі затты салыстырғанда сын есімнің салыстырмалы дәрежесі (comparative) қолданылады, ал «...-дан» мағынасын than береді.

    • Қысқа сын есім (1 буын): + -er: fast - faster, small - smaller, cheap - cheaper. Соңы -e болса, тек -r: safe - safer. Қысқа «дауыссыз + дауысты + дауыссыз» болса, соңғы әріп қосарланады: big - bigger.
    • -y-мен аяқталатын: y түсіп, -ier: easy - easier, happy - happier.
    • Ұзын сын есім (2 және одан көп буын): алдына more: more useful, more expensive, more popular, more powerful.
    • Ерекше: good - better, bad - worse.

    Мысалдар: This tool is faster than that one. Python is easier than C for beginners. This option is more expensive than the old one. Тыңдап көріңіз:

    Қазақшамен салыстыру

    Қазақшада салыстыру жалғауларымен жасалады: «жылдамырақ» (-рақ), «анауынан» (шығыс септік). Ағылшынша бұл екі ұғымның әрқайсысына жеке бөлік бар: сын есімде -er / more, ал «-дан / -ден» орнына than. Қазақ тілді оқушылар кейде екеуін де қояды: more faster - қате; не faster, не more useful.

    Ең жоғары дәреже және as ... as

    Үштен көп заттың ішінен «ең» деп бөліп көрсету үшін ең жоғары дәреже (superlative) қолданылады: алдында the, қысқа сын есімге -est, ұзынына the most.

    • fast - the fastest, cheap - the cheapest, easy - the easiest, big - the biggest;
    • useful - the most useful, popular - the most popular;
    • good - the best, bad - the worst.

    Мысал: This is the best option. It is the most popular tool in our team.

    as ... as екі заттың теңдігін білдіреді: This laptop is as fast as that one. Болымсызы «сондай емес»: Python is not as fast as C. (Python C-дай жылдам емес.)

    too мен enough: too - «тым» (жағымсыз мағына), enough - «жеткілікті». The page is too slow. (тым баяу) / The laptop is fast enough. (жеткілікті жылдам). Назар аударыңыз: enough сын есімнің артында тұрады, too - алдында.

    Санауға болатын және болмайтын зат есімдер

    Ағылшын тілінде зат есімдер екіге бөлінеді. Санауға болатындар (countable) бірнешеу болады: a file - two files, a bug - three bugs. Санауға болмайтындар (uncountable) көпше түрге ие емес және алдына a / an қойылмайды: information, advice, software, equipment, money, time, work, music.

    • I need some information. - informations және an information қате;
    • Can I give you some advice? - advices қате;
    • We have new software. The equipment is old. - softwares, equipments қате;
    • I have a lot of work today. - works бұл мағынада қолданылмайды;
    • This function returns data. - IT-де data көбіне санауға болмайтын сөз ретінде қолданылады.
    • Бірлікті көрсету үшін a piece of қосылады: a piece of advice, a piece of information.

    code сөзі де «бағдарлама коды» мағынасында санауға болмайды: I wrote a lot of code. This code is clean. Сөйлем a code емес, some code дейміз.

    Қазақшамен салыстыру

    Қазақшада «ақпарат», «кеңес», «жұмыс» сөздері көбіне көпше жалғаусыз да, жалғаумен де келеді («кеңестер берді»). Сондықтан ағылшынша advices, informations деп жазып жіберу өте жиі. Сөздікте әр сөздің жанындағы countable / uncountable белгісін қараңыз және осы сөздерді тіркесімен жаттаңыз: some advice, a lot of information.

    Мөлшер сөздері: much, many, some, any, a few, a little

    • many + санауға болатын көпше: many files, many users;
    • much + санауға болмайтын: much time, much memory. Көбіне болымсыз сөйлем мен сұрақта;
    • a lot of - екеуімен де, болымды сөйлемде жиі: a lot of bugs, a lot of work;
    • some - болымды сөйлемде: I have some ideas.; any - болымсыз сөйлем мен сұрақта: I don't have any questions. Do you have any ideas?;
    • a few + санауға болатын (бірнеше): a few bugs; a little + санауға болмайтын (аздап): a little time;
    • Сұрақ: How many files? (санауға болатын) / How much memory? (санауға болмайтын).

    Aida: Which editor is better for our team?
    Біздің команда үшін қай редактор жақсырақ?

    Dan: Editor B has more plugins, but Editor A is faster.
    B редакторында плагин көбірек, бірақ A жылдамырақ.

    Aida: Do we need many plugins?
    Бізге плагин көп керек пе?

    Dan: Not many. We need a few good ones and a lot of speed.
    Көп емес. Бірнеше жақсысы және жылдамдық керек.

    Жаңа сөздер

    • compare verb салыстыру Оқылуы: кәмпеэ Let's compare the two tools. Екі құралды салыстырайық.
    • cheap adj арзан Оқылуы: чип This laptop is cheaper than that one. Бұл ноутбук анауынан арзанырақ.
    • expensive adj қымбат Оқылуы: икспенсив The new phone is very expensive. Жаңа телефон өте қымбат.
    • easy adj оңай Оқылуы: изи This exercise is easy. Бұл жаттығу оңай.
    • difficult adj қиын Оқылуы: дификәлт The last question is difficult. Соңғы сұрақ қиын.
    • safe adj қауіпсіз Оқылуы: сейф This password is safer than the old one. Бұл құпиясөз ескісінен қауіпсізірек.
    • popular adj танымал Оқылуы: попьюлә Python is a popular language. Python - танымал тіл.
    • simple adj қарапайым Оқылуы: симпл The interface is simple. Интерфейс қарапайым.
    • complicated adj күрделі, шатасқан Оқылуы: комплікейтид The code is too complicated. Код тым күрделі.
    • information noun ақпарат (санауға болмайды) Оқылуы: инфәмейшн I need some information. Маған біраз ақпарат керек.
    • advice noun кеңес (санауға болмайды) Оқылуы: эдвайс Thank you for your advice. Кеңесіңізге рахмет.
    • software noun бағдарламалық жасақтама (software) Оқылуы: софтуеә We use free software. Біз тегін бағдарламалық жасақтаманы қолданамыз.
    • storage noun сақтау орны (диск көлемі) (storage) Оқылуы: стораж There is not much storage left. Бос орын көп қалған жоқ.
    • option noun нұсқа, таңдау Оқылуы: опшн This is the best option. Бұл - ең жақсы нұсқа.
    • advantage noun артықшылық Оқылуы: эдвантидж The main advantage is speed. Басты артықшылық - жылдамдық.
    • disadvantage noun кемшілік Оқылуы: дисэдвантидж One disadvantage is the price. Бір кемшілігі - баға.

    Қазақ тілді оқушылардың жиі қателері

    • -er мен more-ды қатар қою. more faster емес, faster Қысқа сын есімде тек -er; more тек ұзын сын есіммен.
    • good-тың салыстыруын жасау. more good, gooder емес, better. good - better - the best: ерекше форма.
    • than орнына that жазу. bigger that me емес, bigger than me. Салыстыру сөзі - than.
    • Ең жоғары дәрежені артиклсіз қолдану. This is best option. емес, This is the best option.. Superlative алдында the керек.
    • Санауға болмайтын сөзді көпше қылу. informations, advices, softwares емес, information, advice, software. Бұл сөздерде көпше жалғау жоқ.
    • Санауға болмайтын сөзге a / an қою. a software, an advice емес, some software, a piece of advice. a / an тек санауға болатын жекеше зат есімнің алдында.
    • many мен much-ты шатастыру. much bugs, many time емес, many bugs, much time. many - санауға болатын көпше, much - санауға болмайтын.
    • Ұзын сын есімге -er жалғау. usefuler, more cheap емес, more useful, cheaper. Буын санына қараңыз: ұзын сын есім - more, қысқасы - -er.

    IT-ағылшын: екі құралды салыстыру

    Командада құрал таңдағанда көбіне қысқа жазбаша пікір жазады. Дұрыс құрылым: (1) не салыстырып жатырсыз, (2) артықшылықтары, (3) кемшіліктері, (4) өз қорытындыңыз. Төмендегі үлгіні оқыңыз:

    I compared two editors for our team.
Editor A is faster than Editor B, and it is cheaper.
However, Editor B has more plugins and is easier to set up.
Editor A does not have many features.
In my opinion, Editor B is the best option because it is the most flexible.

    Пайдалы тіркестер: The main advantage is ... (басты артықшылығы), One disadvantage is ... (бір кемшілігі), It is better than ... for ... (...үшін ... -дан жақсы), In my opinion, ... (менің ойымша), It depends on ... (...-ға байланысты). Құжаттамада да осы құрылымдар көп кездеседі: This method is faster than the old one. You don't need much memory.

    Оқу мәтіндері

    Әр мәтінді оқыңыз не тыңдаңыз, содан кейін сұрақтарға жауап беріңіз.

    Мәтін 1: Choosing a laptop

    Aida needs a new laptop for her studies. She compared two laptops. Laptop A is cheaper than Laptop B, but it is slower.
    Айдаға оқу үшін жаңа ноутбук керек. Ол екі ноутбукті салыстырды. A ноутбугі B-ден арзанырақ, бірақ баяуырақ.

    Laptop B has more memory and a better screen, so it is more expensive. Aida doesn't have much money, but she needs a fast laptop for programming.
    B ноутбугінде жад көбірек және экраны жақсырақ, сондықтан қымбатырақ. Айдада ақша көп емес, бірақ бағдарламалау үшін оған жылдам ноутбук керек.

    In the end, she chose Laptop B. She said, "It is the best option for me."
    Ақыры ол B ноутбугін таңдады. Ол: «Бұл мен үшін ең жақсы нұсқа», - деді.

    Мәтін 2: Dan's advice for new students

    Dan gave some advice to new students. First, you don't need many tools, only a good editor and a few extensions.
    Дан жаңа студенттерге біраз кеңес берді. Біріншіден, көп құрал керек емес, тек жақсы редактор мен бірнеше кеңейтім жеткілікті.

    Second, write a little code every day. Even twenty minutes is enough. Third, don't read too much information at once. It is better to try small examples.
    Екіншіден, күн сайын аздап код жазыңыз. Жиырма минуттың өзі жеткілікті. Үшіншіден, бірден тым көп ақпарат оқымаңыз. Шағын мысалдарды байқап көрген жақсы.

    Finally, ask for help. Everyone has many questions at the beginning.

    Қорытынды

    • Салыстырмалы шырай: қысқа сын есімде -er than (faster than), ұзынында more ... than (more useful than); ерекше: better, worse.
    • Ең жоғары: the -est / the most (the fastest, the most popular, the best).
    • as ... as - теңдік; too - тым; enough - жеткілікті (сын есімнің артында).
    • information, advice, software, equipment, work, code - санауға болмайды: көпше жалғау да, a / an да қойылмайды.
    • many + санауға болатын, much + санауға болмайтын, a lot of - екеуімен; a few / a little - бірнеше / аздап.

    Келесі сабақта (A2 · 4-сабақ) кеңес пен міндетті (should, must, have to), Present Perfect-пен алғашқы танысуды және қате туралы хабарламаны оқуды қарастырамыз.

    Өзіңізді тексеріп көріңіз:

    • Қысқа және ұзын сын есімнің салыстырмалы дәрежесін жасай аламын.
    • than мен the best / the most құрылымдарын шатастырмаймын.
    • information, advice, software сөздеріне көпше жалғау қоспаймын.
    • much, many, a lot of, a few, a little сөздерін орнымен қолданамын.
    • Екі құралды салыстыратын қысқа хабарлама жаза аламын.

    Қайталау тізімі

    Сабақты жапқанда мына тізім бойынша қайталаңыз: бүгін, 2 күннен және 1 аптадан кейін.

    • Сын есімдер: fast, cheap, easy, safe, popular, simple, complicated - әрқайсысының салыстырмалы және ең жоғары дәрежесін жазыңыз.
    • Санауға болмайтын сөздер: information, advice, software, equipment, work, code, time, money - әрқайсысымен some немесе a lot of қолданып сөйлем құрыңыз.
    • Грамматика анықтамалығы: салыстырмалы шырай, ең жоғары дәреже, санауға болатын / болмайтын, much / many.
    • Сөздік бетінде сабақ сөздерін сүзіп, «жаттадым» белгісін қойыңыз.
    • Өзіңіз қолданатын екі құралды (не екі қаланы) 4 сөйлеммен ауызша салыстырыңыз.

    Мини-жоба: құралдарды салыстыру беті

    Жоба 25 минут алады. Мақсаты - командаға не дипломдық жұмыс нұсқаулығына қосуға болатын шағын салыстыру жазбасын дайындау.

    • 1-қадам. Салыстыратын екі құралды таңдаңыз (екі код редакторы, екі бағдарламалау тілі, екі браузер).
    • 2-қадам. Әрқайсысы үшін 2 артықшылық пен 1 кемшілікті жазыңыз (The main advantage is ... One disadvantage is ...).
    • 3-қадам. Кемінде бір -er than, бір more ... than, бір the best / the most құрылымын қолданыңыз.
    • 4-қадам. Қорытындыны In my opinion ... сөзімен аяқтаңыз және бір much / many / a few сөзін қолданыңыз.
    Қиын

    22. Жоба: құралдарды салыстыру

    Қорытынды тест

    1. Қай сөйлем дұрыс?

    fast + er + than.

    2. useful сөзінің салыстырмалы түрі қайсы?

    Ұзын сын есім: more + сын есім.

    3. Қай сөйлем дұрыс?

    good - the best.

    4. Қай сөз санауға болмайтын зат есім?

    advice көпше жалғау алмайды.

    5. Бос орынға не келеді? How ___ memory do you need?

    memory санауға болмайды: how much.

    6. Қай сөйлем дұрыс?

    Болымды сөйлемде some + көпше.

    7. The page is too slow. Мағынасы қандай?

    too - тым (жағымсыз мағына).

    8. Бос орынға не келеді? Python is not ___ fast as C.

    not as ... as - сондай емес.
