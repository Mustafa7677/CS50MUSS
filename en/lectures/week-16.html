Мазмұны

    B2 · 1-сабақ

    Шартты сөйлемдер (2, 3) және wish

    Бұл сабақта шындыққа жанаспайтын қазіргі жағдайды (2-түрлі шарт), өткендегі болмаған оқиғаны (3-түрлі шарт), аралас шартты, wish пен if only құрылымдарын және should have / could have тіркестерін үйренеміз. Соңында оқиғадан кейінгі талдау (post-mortem) жазбасын ағылшынша жазамыз.

    СабақтарДағдыларСөздікГрамматикаIT-фразаларДеңгей тесті
    Деңгей туралы

    B2 - жоғары-орта деңгей, ол CEFR шкаласына шамамен сәйкес келеді. Бұл ресми деңгей емес, тек оқу жолындағы бағдар. Мазмұн жасанды интеллект көмегімен дайындалған, сондықтан мұғаліммен тексерген жөн.

    Сабақ мақсаттары

    Осы сабақтың соңында сіз мыналарды істей аласыз:

    • if + Past Simple, would + етістік құрылымымен қазіргі уақыттағы шындыққа жанаспайтын жағдайды айтасыз;
    • if + had + V3, would have + V3 құрылымымен өткендегі өкінішті жеткізесіз;
    • аралас шартты (өткен себеп - қазіргі салдар) дұрыс құрасыз;
    • wish пен if only арқылы қазіргі және өткен өкінішті ажыратып айтасыз;
    • should have / could have / shouldn't have тіркестерін өткен әрекетті бағалауға қолданасыз;
    • қысқа post-mortem жазбасын (себеп, салдар, әрекет тізімі) ағылшынша жазасыз.

    Уақыты: 45-60 минут. Әр жаттығу автоматты тексеріледі, ал жазба жаттығуын өз критерийлеріңізбен өзіңіз бағалайсыз.

    Екінші түрлі шарт: қазіргі «болса, болар еді»

    B1 деңгейінде бірінші түрлі шартты өттіңіз: If the test fails, we will fix it. Мұнда жағдай нақты, болуы ықтимал. Ал екінші түрлі шарт қазір шындыққа жанаспайтын немесе болуы екіталай жағдайды айтады: «уақытым көп болса, көбірек тест жазар едім» (бірақ уақытым жоқ).

    Құрылымы: if + Past Simple, would / could / might + етістіктің негізгі түрі.

    • If I had more time, I would write more tests. - Уақытым көп болса, көбірек тест жазар едім.
    • If we used a queue, the system might handle the load better. - Кезекті қолдансақ, жүйе жүктемені жақсырақ көтеруі мүмкін еді.
    • What would you do if the production server crashed? - Өнімдік сервер құласа, не істер едіңіз?

    Мұнда had, used, crashed - өткен шақ формасы, бірақ мағынасы өткенге қатысты емес: ол «шындықтан алшақтықты» көрсетеді. Сондықтан if бөлігінде would тұрмайды. Негізгі сөйлемде would (нәтиженің сенімділігі), could (мүмкіндік), might (болуы мүмкін, сенімсіз) таңдалады.

    to be етістігі бұл шартта барлық жаққа were болады, әсіресе кеңес бергенде: If I were you, I would ask the team for help. Ауызша сөйлеуде If I was да кездеседі, бірақ жазбаша және ресми мәтінде were қауіпсіз таңдау.

    Қазақшамен салыстыру

    Қазақша «Уақытым көп болса, көбірек тест жазар едім» дегенде «-са» шартты рай жалғауы мен «-ар едім» тіркесі бар. Ағылшынша екеуі де жеке құрылым: шарт бөлігінде өткен шақ (had), нәтиже бөлігінде would + етістік. Қазақша шарт бөлігінде тек «-са» жалғауы тұрады, ал «had» сияқты өткен шақ белгісі қажет емес, сондықтан оқушылар көбіне If I would have time деп would-ты шарт бөлігіне қойып алады. Есте сақтаңыз: would тек нәтиже бөлігінде.

    Толық ереже: грамматика анықтамалығы.

    Үшінші түрлі шарт: өткендегі болмаған оқиға

    Өткенде болып қойған нәрсені енді өзгерту мүмкін емес. Бірақ «басқаша істесек, нәтиже басқаша болар еді» деп ойлауға болады. Бұл - үшінші түрлі шарт. Ол өкінішті, сынды және талдауды білдіреді.

    Құрылымы: if + had + V3 (өткен шақ есімшесі), would / could / might have + V3.

    • If we had written tests, we would have caught the bug. - Тест жазған болсақ, қатені ұстап алар едік.
    • If I had known about the deadline, I wouldn't have taken that task. - Мерзімді білген болсам, ол тапсырманы алмас едім.
    • The release might have failed if we hadn't checked the config. - Конфигті тексермесек, релиз сәтсіз болуы мүмкін еді.

    Ауызша сөйлеуде I'd қысқартуы екі мағыналы: I'd known (= I had known) және I'd tell (= I would tell). Ол if бөлігінде болса, көбіне had, нәтиже бөлігінде болса, would болады. Жазбаша мәтінде толық форманы қолдану анықтау үшін ыңғайлы.

    Қазақшамен салыстыру

    Қазақша «Тест жазған болсақ, қатені табар едік» деген жерде «-ған болсақ» тіркесі өткен шақты көрсетеді. Ағылшынша бұл had + V3. Қазақ тілді оқушылар өткенді де қазіргі шаққа ұқсас жеңіл форма деп ойлап, If we tested it, we would found it деп қателеседі. Екі жерде де «артқа бір шақ»: had tested және would have found.

    Толық ереже: 3-түрлі шарт.

    Аралас шарт: өткен себеп, қазіргі салдар

    Кейде шарт өткенге, ал нәтиже қазірге қатысты болады (немесе керісінше). Мұндай сөйлем аралас шарт деп аталады.

    • Өткен шарт -> қазіргі нәтиже: If we had chosen a different database, we wouldn't have these performance problems now. - Басқа дерекқорды таңдасақ, қазір бұл өнімділік мәселелері болмас еді.
    • Тұрақты қазіргі қасиет -> өткен нәтиже: If she weren't so careful, she would have missed that bug. - Ол сонша мұқият болмаса, қатені байқамай қалар еді.

    Екі жартысын бөлек ойлаңыз: if бөлігі өткен болса, had + V3; нәтиже қазірге қатысты болса, would + етістік. Қарама-қарсы жағдайда: if бөлігінде Past Simple / were, нәтижеде would have + V3.

    Толық ереже: аралас шарт.

    wish және if only: арман мен өкініш

    wish («қалау, тілеу») шындыққа жанаспайтын қалауды білдіреді. Шарттағыдай, «артқа бір шақ» ережесі жұмыс істейді:

    • қазіргі жағдай: wish + Past Simple - I wish I knew Rust. (Мен Rust білсем ғой; бірақ білмеймін.) I wish the build were faster. (Жинау жылдамырақ болса ғой.)
    • өткен өкініш: wish + had + V3 - I wish I had backed up the database. (Дерекқордың көшірмесін сақтасам ғой.)
    • басқа біреудің әдетіне налу немесе өзгерту: wish + would + етістік - I wish you would stop pushing to the main branch directly. (Негізгі тармаққа тікелей жүктеуді қойсаңыз ғой.)

    If only - дәл сол мағына, бірақ эмоция күштірек: If only we had more time! «Уақытымыз көп болса ғой!» Қазақшада «-са ғой», «-ған болса ғой» құрылымдары осыны береді.

    Ескерту

    I wish I would... деп айтпайды: өзіңіздің әрекетіңіз туралы I wish I could немесе I wish I had қолданылады. wish + would тек басқа адам не нәрсе туралы айтқанда жұмыс істейді.

    Толық ереже: wish және if only.

    should have, could have: өткен әрекетті бағалау

    Өткенде болған нәрсені сынағанда не өкінгенде modal + have + V3 құрылымы қолданылады:

    • We should have tested it. - Біз оны тексеруіміз керек еді (бірақ тексермедік).
    • You shouldn't have deployed on Friday evening. - Жұма кешінде деплой жасамауыңыз керек еді (бірақ жасадыңыз).
    • They could have asked for help. - Олар көмек сұрай алатын еді (мүмкіндік болды, бірақ сұраған жоқ).

    Бұл құрылым 3-түрлі шартпен тығыз байланысты: If we had tested it, we would have found the bug және We should have tested it бір ойды екі жолмен айтады. Тіркесте have әлсіз дауыспен айтылады, жазғанда of емес, have жазылады: should have, should of емес.

    Толық ереже: should have / could have.

    Қосымша: шарттағы инверсия (кіріспе)

    Ресми жазбада if түсіріліп, көмекші етістік сөйлем басына шығады. Бұл - инверсия (сөз ретін айналдыру). Қазір тек танып, түсінуге үйреніңіз:

    • Had we tested the code, we would have found the bug. = If we had tested the code, ...
    • Were I you, I would ask for help. = If I were you, ...
    • Should you need help, contact the team. = If you need help, ... (ресми хат)

    Инверсияны C1 деңгейінде тереңірек қарастырамыз. Толығырақ: грамматика анықтамалығы.

    Сөздік: өкініш, салдар және шарт

    Төмендегі сөздер оқиғаны талдауда және өкінішті айтуда жиі қолданылады. Әр сөздің жанындағы «жаттадым» белгісі сөздік бетімен ортақ.

    • regret verb өкіну Оқылуы: ригрет I regret not writing tests earlier. Тесттерді ертерек жазбағаныма өкінемін.
    • hindsight noun өткенге көз жіберіп түсіну, кейінгі түсінік Оқылуы: хайндсайт In hindsight, we should have asked for help. Артқа қарасақ, көмек сұрауымыз керек еді.
    • consequence noun салдар Оқылуы: консиквенс Every change has a consequence. Әр өзгерістің салдары болады.
    • oversight noun абайсызда жіберілген қате, назардан тыс қалу Оқылуы: оувәсайт The bug was an oversight on our part. Бұл қате біздің абайсыздығымыздан болды.
    • assumption noun болжам, жорамал Оқылуы: әсампшн We made the wrong assumption about the traffic. Біз трафик туралы қате болжам жасадық.
    • prevent verb алдын алу, болдырмау Оқылуы: привент Good tests can prevent many failures. Жақсы тесттер көп ақаулардың алдын алады.
    • overlook verb назардан тыс қалдыру, байқамай қалу Оқылуы: оувәлук We overlooked a small detail in the config. Біз конфигурациядағы бір ұсақ нәрсені байқамай қалдық.
    • blame verb кінәлау Оқылуы: блейм It is not helpful to blame one person. Бір адамды кінәлаудың пайдасы жоқ.
    • responsibility noun жауапкершілік Оқылуы: риспонсибилити I take full responsibility for the delay. Кешігу үшін толық жауапкершілікті өзім аламын.
    • otherwise adv әйтпесе, олай болмаса Оқылуы: азәвайз Back up the data; otherwise, you may lose it. Деректі көшіріп қойыңыз, әйтпесе жоғалтуыңыз мүмкін.
    • provided that conj егер ... шарты орындалса Оқылуы: провайдид зэт You can deploy, provided that all tests pass. Барлық тест өтсе ғана, жібере аласыз.
    • as long as conj ...болғанша, ...шарты бойынша Оқылуы: эз лонг эз It is fine as long as we keep a backup. Көшірме сақтасақ, бәрі дұрыс.
    • in that case phrase ондай жағдайда Оқылуы: ин зэт кейс In that case, we should postpone the release. Ондай жағдайда релизді кейінге қалдыруымыз керек.

    Қысқа диалог: post-mortem кездесуі

    Екі әріптес оқиғадан кейін қорытынды жасайды. Рөлге бөлініп оқыңыз.

    Aida: If we had added a timeout, the service wouldn't have crashed.
    Күту уақытының шегін қойған болсақ, қызмет құламас еді.

    Dan: True. I wish we had thought about that earlier.
    Рас. Мұны ертерек ойласақ ғой.

    Aida: It is nobody's fault. If we had had more time, we would have done it.
    Бұл ешкімнің кінәсі емес. Уақытымыз көп болған болса, істеген болар едік.

    Dan: Let's add it to the action items, so it doesn't happen again.
    Мұны тапсырмалар тізіміне қосайық, қайталанбасын.

    Назар аударыңыз: had had - «болды» мағынасындағы have етістігінің өткен-өткен формасы (had + had). Бұл қате емес.

    Оқу мәтіндері

    Екі қысқа мәтінді оқыңыз. Алдымен жалпы мағынасын түсініңіз, содан кейін жаттығулардағы сұрақтарға жауап беріңіз. Белгіні басып, мәтінді тыңдауға болады.

    Мәтін 1. Жұма күнгі деплой

    Last spring, our team released a new version of the mobile app on a Friday afternoon. Everyone wanted to go home early, so nobody read the release notes carefully. Within an hour, users began to report that payments were failing. We spent the whole evening looking for the cause. It turned out that a small change in the configuration had removed the default timeout. If we had tested the release on the staging server, we would have noticed the problem at once. If we had not been in such a hurry, we would have waited until Monday. I still wish we had taken more time. Since then, we have followed a simple rule: we never deploy after three o'clock on Friday, and every configuration change needs a second pair of eyes.

    Мәтін 2. Командаға жазылған қорытынды хат

    Subject: Post-mortem: payment outage
    Hi all,
    Thank you for joining yesterday's review. Here is a short summary. The outage lasted 55 minutes and affected about 3,000 payments. The root cause was a configuration change that removed the timeout. Nobody acted carelessly; our process simply allowed the mistake. If we had required a second review, the error would probably have been caught. We agreed on three actions: add a review rule for configuration changes, add an automatic timeout test, and write a short checklist for Friday releases. Dan owns the first action, Aida owns the second, and I will write the checklist. We will review our progress next Tuesday.
    Best regards,
    Sam

    Оқу кеңесі

    Мәтін 2-де would probably have been caught - үшінші түрлі шарттың ырықсыз етістегі (would have been + V3). Мұндай құрылым ресми есептерде жиі кездеседі, оны келесі сабақта толық қарастырамыз.

    Қазақ тілді оқушылардың жиі қателері

    • would if-бөлігіне қойылады. If I would have time, I would help. емес, If I had time, I would help. would тек нәтиже бөлігінде тұрады.
    • 2-түрлі шартта was орнына were. If I was you, I would ask. емес, If I were you, I would ask. Кеңес беретін құрылымда ресми дұрыс форма - were.
    • 3-түрлі шартта had ұмытылады. If we tested it, we would have found it. емес, If we had tested it, we would have found it. Өткен оқиға үшін had + V3 керек.
    • would have + V3 орнына қате форма. We would have find the bug. емес, We would have found the bug. have кейін үшінші форма (V3) тұрады.
    • wish-тен кейін шақ дұрыс таңдалмайды. I wish I will know Rust. емес, I wish I knew Rust. wish-тен кейін болашақ шақ тұрмайды: қазіргі арман үшін Past Simple.
    • Өкінішті өткен шақ формасымен айту. I wish I did a backup yesterday. емес, I wish I had done a backup yesterday. Өткен өкініш үшін wish + had + V3.
    • should have орнына should of. We should of tested it. емес, We should have tested it. Ауызша should've естіледі, жазбаша have жазылады.

    IT-ағылшын: post-mortem (оқиғадан кейінгі талдау)

    Қызмет тоқтап қалса не релиз сәтсіз болса, команда post-mortem құжатын жазады. Мақсат - кінәлі іздеу емес, не болғанын түсініп, қайталанбау үшін шара қабылдау. Мұндай құжат әдетте нейтрал, фактілі тілмен жазылады, және үшінші түрлі шарт пен should have тіркестері жиі кездеседі.

    • post-mortem noun оқиғадан кейінгі талдау, постмортем (post-mortem) Оқылуы: поуст-мотем The post-mortem showed three causes. Талдау үш себепті көрсетті.
    • outage noun қызметтің толық тоқтап қалуы (outage) Оқылуы: аутидж The outage lasted two hours. Қызмет екі сағат істемей тұрды.
    • root cause noun түпкі себеп (root cause) Оқылуы: рут коз We found the root cause of the crash. Біз құлаудың түпкі себебін таптық.
    • incident noun оқиға, инцидент (қызметтегі ақау) (incident) Оқылуы: инсидент The incident affected all users. Инцидент барлық пайдаланушыға әсер етті.
    • downtime noun қызмет істемеген уақыт (downtime) Оқылуы: даунтайм Planned downtime starts at midnight. Жоспарлы үзіліс түн ортасында басталады.
    • workaround noun уақытша айналма шешім (workaround) Оқылуы: уәкэраунд There is a simple workaround for now. Әзірге қарапайым айналма шешім бар.
    • regression noun бұрын істеген функцияның бұзылуы (regression) Оқылуы: регрешн The update caused a regression in search. Жаңарту іздеуде регрессия тудырды.
    • timeline noun оқиғалар хронологиясы (timeline) Оқылуы: тайм-лайн The timeline shows when the alert fired. Хронология ескерту қашан шыққанын көрсетеді.
    • safeguard noun қорғаныс шарасы, сақтандыру (safeguard) Оқылуы: сейфгад We added a safeguard against empty input. Біз бос енгізуден қорғайтын тексеріс қостық.
    • action item noun орындалуы тиіс нақты тапсырма (action item) Оқылуы: экшн айтем Each action item has an owner. Әр тапсырманың жауапты адамы бар.

    Мысал құжат (қысқартылған):

    Summary: The login service was down for 42 minutes on 14 March.
Impact: About 8,000 users could not sign in.
Root cause: A configuration change removed the database timeout.
What went well: The alert fired within two minutes.
What went wrong: If a second person had reviewed the change,
  we would have noticed the missing value.
Action items:
  1. Require a review for all configuration changes.
  2. Add a test that checks the timeout is set.

    Пайдалы тіркестер: In hindsight, ... (артқа қарасақ), The root cause was ... (түпкі себеп ...), If we had ..., we would have ..., To prevent this from happening again, we will ... (қайталанбас үшін біз ...). Құжатта «кім кінәлі» емес, «қай процесс жұмыс істемеді» деп жазу - кәсіби дәстүр.

    Жаттығулар

    Жеңілден күрделіге қарай орындаңыз. Әр жаттығуда «Тексеру» батырмасын басыңыз: қате болса, түсіндірме көрсетіледі. «Жауаптарды көрсету» тек соңғы шара. Нәтиже осы құрылғыда сақталады.

    Жеңіл

    1. Шарттың түрін таңдаңыз

    Дұрыс нұсқаны таңдаңыз.

    Орташа

    2. Бос орынды толтырыңыз

    Жақшадағы кеңеске қарап, етістікті дұрыс формада жазыңыз.

    Орташа

    3. Аралас шарт, wish және should have

    Дұрыс нұсқаны таңдаңыз.

    Жеңіл

    4. Сөз бен мағынаны сәйкестендіріңіз

    Әр ағылшын сөзіне қазақша мағынасын таңдаңыз.

    Орташа

    5. Сөйлем мен оның мағынасын сәйкестендіріңіз

    Әр сөйлем қандай жағдайды білдіретінін таңдаңыз.

    Орташа

    6. Сөйлем құраңыз

    Сөздерді дұрыс ретпен басыңыз.

    Орташа

    7. wish және if only

    Дұрыс форманы жазыңыз.

    Орташа

    8. Қатені табыңыз

    Әр сұрақта төрт сөйлем бар. Қатесі бар сөйлемді таңдаңыз.

    Қиын

    9. Қатені түзетіңіз

    Қате сөйлемнің дұрыс нұсқасын таңдаңыз.

    Орташа

    10. should have / could have

    Бос орынға сәйкес тіркесті жазыңыз.

    Қиын

    11. Сөйлемді қайта құрыңыз

    Берілген фактіні шартты сөйлемге айналдырыңыз.

    Орташа

    12. Мәтін 1: түсіну сұрақтары

    Мәтінді қайта қараңыз және дұрыс жауапты таңдаңыз.

    Орташа

    13. Мәтін 1: True / False / Not stated

    Мәтінге сүйеніп, дұрыс жауапты таңдаңыз.

    Орташа

    14. Мәтін 2: түсіну сұрақтары

    Хатты қайта оқып, дұрыс жауапты таңдаңыз.

    Орташа

    15. Тыңдау

    Белгіні басып тыңдаңыз. Алғашқы екеуін жазыңыз, соңғы екеуінде дұрыс нұсқаны таңдаңыз.

    Қиын

    16. Диктант

    Мәтін 1-ден алынған сөйлемдерді тыңдап жазыңыз. Бірінші сөйлем бас әріппен басталады, тыныс белгілері есепке алынбайды.

    Орташа

    17. Айту жаттығуы

    Әр сөйлемді тыңдап, дауыстап 3 рет қайталаңыз. Орындағанда белгіні қойыңыз.

    18. Қысқа жазба: өз тәжірибеңіз

    Орташа

    19. Сөздік: контекстегі сөз

    Бос орынға ең сәйкес сөзді таңдаңыз.

    IT-ағылшын жаттығулары

    Орташа

    20. Post-mortem тілі

    Post-mortem құжатына ең жақсы келетін нұсқаны таңдаңыз.

    Қиын

    21. Post-mortem жазбасын толықтырыңыз

    Бос орындарды дұрыс сөзбен немесе формамен толтырыңыз.

    Қиын

    22. Post-mortem сөйлемдерін құраңыз

    Сөздерді дұрыс ретпен басыңыз.

    Қиын

    23. Мини-жоба: post-mortem қорытындысы

    Мини-жоба: өз post-mortem құжатыңыз

    Бұл жоба 20-30 минут алады. Нақты не ойдан шығарылған шағын оқиғаны таңдаңыз: өз жобаңыздағы бұзылған функция, тоқтап қалған сайт, жоғалған файл, сәтсіз релиз.

    1. Summary - не болды (1-2 сөйлем, өткен шақ).
    2. Impact - кімге және қаншалықты әсер етті.
    3. Root cause - түпкі себеп (кінәлі адамды емес, процесті атаңыз).
    4. What we would do differently - кемінде екі сөйлемде 3-түрлі шарт және бір should have.
    5. Action items - 2-3 нақты шара (We will add ...).

    Нәтижесін соңғы жаттығудың критерийлерімен тексеріңіз, ал құжатты портфолиоңызға не жұмыс блогыңызға қоюға болады. Дайын болғанда мұғаліммен не тілі жақсы адаммен тексерген пайдалы.

    Қайталау тізімі

    • 2-түрлі шарт: if + Past Simple, would + V; were барлық жаққа.
    • 3-түрлі шарт: if + had + V3, would have + V3.
    • Аралас шарт: өткен себеп - қазіргі нәтиже (және керісінше).
    • wish: Past Simple (қазір), had + V3 (өткен), would (біреудің әдеті).
    • should have / shouldn't have / could have + V3; of емес.
    • Инверсия: Had we ..., Were I ..., Should you ... (тану деңгейінде).
    • Post-mortem сөздері: regret, hindsight, root cause, outage, workaround, action item.

    Бір аптадан кейін осы тізімді қайта қарап шығыңыз және сөздік бетінде осы сабақтың сөздерін карточкалармен қайталаңыз.

    Қорытынды

    Бүгін мынаны қарастырдық:

    • 2-түрлі шарт: if + Past Simple, would + етістік (қазір шындыққа жанаспайды); were барлық жаққа.
    • 3-түрлі шарт: if + had + V3, would have + V3 (өткендегі өкініш, талдау).
    • Аралас шарт: if бөлігі мен нәтиже әртүрлі уақытқа қатысты болуы мүмкін.
    • wish / if only: қазіргі арман - Past Simple, өткен өкініш - had + V3, біреудің әдеті - would.
    • should have / could have + V3: өткен әрекетке баға. should of емес.
    • Post-mortem: фактілі, кінәсіз тілмен жазылады: summary, impact, root cause, action items.

    Келесі сабақта (B2 · 2-сабақ) ресми e-mail жазуды, сыпайы өтініш айтуды және ырықсыз етісті (passive) толық қарастырамыз.

    Өзіңізді тексеріп көріңіз:

    • 2-түрлі және 3-түрлі шарттың құрылымын шатастырмаймын.
    • if бөлігіне would қоймаймын.
    • wish пен if only арқылы қазіргі және өткен өкінішті ажырата аламын.
    • should have / shouldn't have + V3 қолдана аламын.
    • Қысқа post-mortem жазбасын ағылшынша жаза аламын.

    Қорытынды тест

    1. Қай сөйлем дұрыс (2-түрлі шарт)?

    2-түрлі шарт: if + Past Simple, would + етістік.

    2. Бос орынға не келеді? If we ___ the config, we would have found the error.

    3-түрлі шарт: if + had + V3.

    3. I wish I knew Rust. сөйлемі нені білдіреді?

    wish + Past Simple - қазіргі шындыққа жанаспайтын қалау.

    4. Қай нұсқа дұрыс?

    should have + V3. of жазылмайды.

    5. Бос орынға не келеді? If I ___ you, I would ask for help.

    Кеңес беретін құрылымда were.

    6. Аралас шарт: If we had chosen another database, we ___ these problems now.

    Өткен шарт, қазіргі нәтиже: would + етістік, яғни wouldn't have (have - толық етістік).

    7. Post-mortem құжатындағы root cause нені білдіреді?

    root cause - ақаудың түпкі себебі.

    8. I wish you would stop interrupting me. мағынасы:

    wish + would басқа біреудің әдетіне налуды не өзгерту қалауын білдіреді.
