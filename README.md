# CS50 қазақша

Гарвард университетінің [CS50x](https://cs50.harvard.edu/x/) курсының қазақ тіліндегі нұсқасы.

**Сайт:** https://mustafa7677.github.io/CS50MUSS/

## Мүмкіндіктері

- **12 лекцияның толық аудармасы** (0–10-апталар және жасанды интеллект), түсіндірмелер мен код мысалдары
- **Тесттер** (90+ сұрақ), **жаттығулар** жауапты автоматты тексерумен, **тапсырмалар** (Problem Sets) кеңестер мен тексеру тізімдерімен
- **Бүкіл сайт бойынша іздеу** — `Ctrl+K` немесе `/`
- **Python кодын браузерде іске қосу** (Pyodide) — «▶ Іске қосу» батырмасы
- **SQL-ды браузерде іске қосу** — нағыз SQLite (sql.js), 7-аптадағы сұраулар демо дерекқорларда бірден орындалады
- **Сынақ алаңы** (`playground.html`) — Python, SQL және 🌐 HTML/CSS/JS (нақты уақыттағы алдын ала қарау, мысалдар)
- **Homepage тексерушісі** (8-апта) — көп файлды веб-жоба редакторы, беттер арасында жүретін алдын ала қарау, 12 талапты автоматты тексеру (беттер, сілтемелер, тегтер, Bootstrap, CSS, JS, HTML құрылымы)
- **9 интерактив визуализация** (`viz.html`, лекциялардың ішінде де): екілік жүйе (0-апта), сұрыптау және сызықтық vs екілік іздеу (3-апта), жад пен көрсеткіштер — swap мәнмен vs көрсеткішпен, сурет сүзгілері grayscale/sepia/reflect/blur/edges пиксель инспекторымен (4-апта), байланысқан тізім, стек пен кезек, екілік іздеу ағашы, хэш-кесте (5-апта)
- **Код тренажері** (`debug.html`): 🐞 «Қатені тап» — C, Python, SQL, HTML, JS-тегі 42 типтік қате; 🔎 «Не шығарады?» — 20 код оқу жаттығуы (жауаптар gcc/Python-да тексерілген)
- **Автотексеруші** ✅ — 6-аптадағы Python тапсырмалары (Hello, Mario, Cash, Readability, DNA — виртуалды файлдар мен argv-мен) және 7-аптадағы SQL Songs (8 сұрау) мен Movies (13 сұрау) — ойдан шығарылған базаларда, нағыз SQLite браузерде жасырын тесттермен тексеріледі (check50 сияқты): кіріс/күтілген/алынған нәтиже, шексіз циклден қорғаныс
- **SQL детектив** 🕵️ «Алтын домбыраның құпиясы» (`detective.html`) — Наурызда мұражайдан ұрланған домбыраны SQL арқылы табу: 10 кестелі түпнұсқа дерекқор, кеңестер, детектив дәптері, жауап SHA-256 арқылы тексеріледі (`tools/make_mystery.py` шешімнің біреу ғана екенін тексереді)
- **Апталық челлендж** 🎯 — апта сайын 4 мақсат: лекция, карточка, тренажер, күннің сұрағы
- **Бота** 🐫 — сайттың түпнұсқа маскоты, 4 көңіл-күйі бар: қалыпты, қуанған, ойланған, таңданған (`assets/img/bota*.svg`): басты бетте сәлемдеседі, лекция соңында кеңес береді, 100% тестте құттықтайды
- **Шпаргалка** 📄 — бүкіл курс бір бетте, басып шығаруға ыңғайлы (`cheatsheet.html`, автоматты жасалады)
- **Курс картасы** 🗺 — 12 лекцияның тақырыптары мен прогресс бір жолда (`map.html`)
- **Мұғалім режимі** 👩‍🏫 — оқушы прогресін код/QR арқылы жібереді, мұғалім бетінде (`teacher.html`) сынып кестесі, CSV экспорт; сервер мен тіркелу жоқ
- **Оқу баптаулары** (Аа) — қаріп өлшемі, жол аралығы, мәтін ені, анимацияны азайту
- **Лекцияны басып шығару / PDF** — таза баспа стилі
- **SEO** — sitemap.xml, robots.txt, JSON-LD, Open Graph; өз 404 беті
- **20 жетістік** 🏅 — оқу, тест, стрик, карточкалар, кодты іске қосу үшін белгілер
- **Флэш-карточкалар** — 269 термин, Лейтнер жүйесімен қайталау (`flashcards.html`)
- **Күннің сұрағы** және 🔥 **стрик** (күндер тізбегі) — басты бетте
- **Аралас тест** — 93 сұрақтан кездейсоқ 10 сұрақ, тақырып бойынша сүзгі (`practice.html`)
- **Жеке прогресс** — оқылған лекциялар, тест нәтижелері, тапсырмалар (тіркелусіз, браузерде сақталады)
- **Терминдер сөздігі** — 260+ информатика термині, қазақша–ағылшынша
- **Сертификат** — барлық лекцияны оқығандарға (бейресми)
- **Офлайн режим** (PWA) — сайтты телефонға қосымша ретінде орнатып, интернетсіз оқуға болады
- Қазақы дизайн (ою-өрнек, көк пен алтын), түнгі режим, мобильді нұсқа, `←` `→` пернелерімен навигация

## Жаңа лекция қосу

1. `lectures/` қалтасына бар лекцияның үлгісімен жаңа бет жасаңыз.
2. `tools/build.py` ішіндегі `ORDER` тізіміне оның атын қосыңыз.
3. Құрастыру скриптін іске қосыңыз:

```
python3 tools/build.py
```

Скрипт әр беттің басын (favicon, PWA, Open Graph), навигацияны, футерді, іздеу индексін, сөздікті, шпаргалканы, тест сұрақтарының жиынын және sitemap.xml-ді жаңартады.

## Локалды іске қосу

`index.html` файлын браузерде ашсаңыз жеткілікті. Офлайн режимді тексеру үшін:

```
python3 -m http.server 8000
```

## Тесттер

Әр push сайын GitHub Actions (`.github/workflows/ci.yml`) екі тексеру жасайды:

1. **Генерацияланған файлдар**: `tools/build.py` және деректер генераторлары қайта іске қосылғанда репозиторийде ешнәрсе өзгермеуі керек.
2. **Браузерлік тесттер** (Playwright, 64 тест): әр бет компьютер мен телефонда (JS қатесі, көлденең жылжу, сынған сілтеме, қолжетімділік), емтихан, SQL детектив, профильді көшіру, Python мен Flask (Pyodide), бұлттық синхрондау (нағыз `supabase/schema.sql` + Postgres).

Локалды іске қосу:

```
cd tests
npm ci
npx playwright install chromium   # бір рет
npx playwright test                # бәрі (бұлт тесті CLOUD_MOCK болмаса өткізіледі)
npx playwright test --grep-invert @slow   # жылдам (~25 с)
```

## Бұлттық синхрондау (Supabase)

Оқушы профильде бұлтты қосса, прогресі ID + кіру коды арқылы кез келген құрылғыда жалғасады, ал мұғалім сынып коды арқылы жанды кестені көреді.

Орнату: Supabase → **SQL Editor** → `supabase/schema.sql` файлын толық қойып, **Run**. Жоба мекенжайы мен publishable кілті `assets/js/cloud.js` ішінде. Кестелерге тікелей қол жеткізу жабық, барлық әрекет құпияны тексеретін функциялар арқылы ғана жүреді.
