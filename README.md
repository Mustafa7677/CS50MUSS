# CS50 қазақша

Гарвард университетінің [CS50x](https://cs50.harvard.edu/x/) курсының қазақ тіліндегі нұсқасы.

**Сайт:** https://mustafa7677.github.io/CS50MUSS/

## Мүмкіндіктері

- **12 лекцияның толық аудармасы** (0–10-апталар және жасанды интеллект), түсіндірмелер мен код мысалдары
- **Тесттер** (90+ сұрақ), **жаттығулар** жауапты автоматты тексерумен, **тапсырмалар** (Problem Sets) кеңестер мен тексеру тізімдерімен
- **Бүкіл сайт бойынша іздеу** — `Ctrl+K` немесе `/`
- **Python кодын браузерде іске қосу** (Pyodide) — «▶ Іске қосу» батырмасы
- **Жеке прогресс** — оқылған лекциялар, тест нәтижелері, тапсырмалар (тіркелусіз, браузерде сақталады)
- **Терминдер сөздігі** — 260+ информатика термині, қазақша–ағылшынша
- **Сертификат** — барлық лекцияны оқығандарға (бейресми)
- **Офлайн режим** (PWA) — сайтты телефонға қосымша ретінде орнатып, интернетсіз оқуға болады
- Қазақы дизайн (ою-өрнек, көк пен алтын), түнгі режим, мобильді нұсқа, `←` `→` пернелерімен навигация

## Құрылымы

```
index.html               — басты бет: прогресс панелі, апталар
lectures/*.html          — лекциялар, тесттер, тапсырмалар
glossary.html            — терминдер сөздігі (автоматты жасалады)
certificate.html         — сертификат
about.html               — курс туралы
assets/css/style.css     — стильдер (күндізгі/түнгі режим, ою-өрнек)
assets/js/main.js        — іздеу, прогресс, тест, Python, офлайн
assets/data/*.js         — лекциялар тізімі мен іздеу индексі (автоматты)
assets/img/              — белгішелер, Open Graph суреті
manifest.webmanifest, sw.js — PWA (офлайн режим)
tools/build.py           — құрастыру скрипті
```

## Жаңа лекция қосу

1. `lectures/` қалтасына бар лекцияның үлгісімен жаңа бет жасаңыз.
2. `tools/build.py` ішіндегі `ORDER` тізіміне оның атын қосыңыз.
3. Құрастыру скриптін іске қосыңыз:

```
python3 tools/build.py
```

Скрипт әр беттің басын (favicon, PWA, Open Graph), навигацияны, футерді, іздеу индексін және сөздікті жаңартады.

## Локалды іске қосу

`index.html` файлын браузерде ашсаңыз жеткілікті. Офлайн режимді тексеру үшін:

```
python3 -m http.server 8000
```
