# CS50 қазақша

Гарвард университетінің [CS50x](https://cs50.harvard.edu/x/) курсының қазақ тіліндегі нұсқасы. Сайтта лекциялардың толық аудармасы, түсіндірмелер, тесттер және тапсырмалар бар.

## Құрылымы

```
index.html            — басты бет (апталар тізімі)
about.html            — курс туралы, авторлар, лицензия
lectures/week-N.html  — әр аптаның лекциясы мен тапсырмалары
assets/css/style.css  — стильдер (күндізгі/түнгі режим)
assets/js/main.js     — мазмұн, тест, тексеру, кодты көшіру
```

## Локалды іске қосу

Сервердің қажеті жоқ: `index.html` файлын браузерде ашсаңыз жеткілікті. Әйтпесе:

```
python3 -m http.server 8000
```
