    Графтар теориясының негіздері

    Әлеуметтік желідегі достар, қалалар арасындағы жолдар, интернет беттерінің сілтемелері, молекуладағы атомдар - бәрі «нүктелер және оларды қосатын сызықтар» түрінде модельденеді.

    Курс туралы

    Бұл сабақтың мазмұны үшін жауапкершілікті курс авторы Sagid Mustafa өзіне алады. Қате немесе түсініксіз жер тапсаңыз, хабарлаңыз. Бұл курс ресми емтихан не куәлік баламасы емес.

    Бір сөйлеммен

    Граф - нүктелер (төбелер) мен оларды қосатын сызықтар (қабырғалар); достық, жолдар, сілтемелер - бәрі граф, ал көп сұрақ (барлық көпірден өту, жол бар ма) төбелердің дәрежелерінен шешіледі.

    Сабақ мақсаттары

    Сабақ соңында сіз мыналарды істей аласыз:

    • граф, төбе, қабырға, дәреже, жол, цикл, байланыстылық ұғымдарын қолдану;
    • «қол алысу» леммасын $\sum\deg v=2|E|$ дәлелдеп, оның салдарларын (тақ дәрежелі төбелер саны жұп) қолдану;
    • толық, циклдік, екі үлесті графтарды тану және қабырға санын есептеу;
    • Эйлер циклі мен жолының бар болу шарттарын тексеру және дәлелдеу;
    • Гамильтон циклі мен Эйлер циклін ажырату;
    • сыбайластық матрицасын құрып, $A^k$ арқылы ұзындығы $k$ маршруттарды санау.

    Қысқаша еске салу

    Жиындар мен жұптар: ретсіз жұп $\{u,v\}$ және реттелген жұп $(u,v)$; $C_n^2=\frac{n(n-1)}2$ - $n$ элементтен жұптар саны. Қатынас ұғымы (граф - симметриялы қатынастың суреті). Матрицаларды көбейту: $(AB)_{ij}=\sum_kA_{ik}B_{kj}$. Математикалық индукция және қарсы жору.

    Алдымен оқыңыз

    • Discrete Mathematics · 4-сабақ: Санау әдістері және рекуррентті қатынастар

    Бұл сабақтар таныс болса, бірден бастай беріңіз. Толық реттілік: оқу жолы.

    Алдымен қолмен: Кенигсберг көпірлері

    Формулаға дейін нақты сандармен ойнап көрейік. Әр қадамды өзіңіз де қағазда қайталаңыз.

    Қалада $4$ аудан және $7$ көпір: дәрежелері (аудандан шығатын көпірлер саны) $5,3,3,3$. Әр көпірден дәл бір рет өтіп, бастапқы орынға оралуға бола ма?

    1. Әр ауданға кірген сайын шығу керек - көпірлер жұп-жұптап қолданылады. Тұйық маршрутта әр төбенің дәрежесі жұп болуы керек.
    2. Мұнда барлық дәрежелер тақ: $5,3,3,3$.
    3. Демек мұндай маршрут жоқ (Эйлер, 1736).
    4. Тексеру: дәрежелер қосындысы $5+3+3+3=14=2\cdot7$ - қол алысу леммасы ✓.

    Байқадыңыз ба? Ұзақ іздеудің орнына бір қарапайым инвариант - дәрежелердің жұптылығы - жауап берді. Графтар теориясы осылай басталды.

    Интуиция

    Кёнигсберг қаласында (қазіргі Калининград) өзен арқылы 7 көпір болды. Қала тұрғындары сұрады: әр көпірден дәл бір рет өтіп, бастаған жерге қайта оралуға бола ма? 1736 жылы Эйлер жауап берді: жоқ, және себебі көпірлердің орналасуында емес, тек әр аралдан шығатын көпірлердің санында. Бұл - графтар теориясының басталуы: геометрия маңызды емес, тек «қай нүкте қаймен қосылған» маңызды.

    Кешке 10 адам жиналып, біреулер қол алысты. Барлық адамның қол алысу сандарының қосындысы әрдайым жұп. Неге? Әр қол алысуды екі адам санайды. Бұл қарапайым бақылаудың салдары: тақ санды адаммен қол алысқан адамдар саны әрдайым жұп.

    Эйлер циклі - әр қабырғадан бір рет өту (пошташы барлық көшені аралайды), ал Гамильтон циклі - әр төбеге бір рет бару (саяхатшы барлық қаланы аралайды). Сырттай ұқсас, бірақ олардың күрделілігі мүлде әртүрлі: біріншісінің қарапайым критерийі бар, ал екіншісі - белгілі «қиын» (NP-толық) есеп.

    Компьютерде граф кесте ретінде сақталады: $A_{ij}=1$, егер $i$ мен $j$ қосылса. Таңқаларлық факт: осы матрицаны $k$-дәрежеге шығарсақ, $(A^k)_{ij}$ - $i$-ден $j$-ге дейінгі ұзындығы $k$ маршруттар саны. Матрицалық алгебра граф туралы сұрақтарға жауап береді.

    Өмірден ұқсастық · қол алысу

    Кешке келгендер қол алысты. Әр қол алысуда екі қол қатысады, сондықтан барлық адамның қол алысу сандарының қосындысы - жұп сан. Демек тақ рет қол алысқан адамдар саны әрдайым жұп.

    Өмірден ұқсастық · метро картасы

    Метро картасы - граф: станциялар төбелер, жолдар қабырғалар. Картада қашықтықтар бұрмаланған, бірақ «қай станциядан қайсысына жетуге болады» дұрыс - граф тек байланыстарды сақтайды.

    Белгілерді оқу

    Жоғары математиканың қиындығының жартысы - белгілерде. Теорияға дейін әр белгіні дауыстап оқып, мағынасын біліп алайық:

    Анықтамалар мен теоремалар

    Анықтама 5.1 · Граф

    Граф (graph) $G=(V,E)$: $V$ - төбелер (vertices) жиыны, $E$ - қабырғалар (edges) жиыны, әр қабырға - екі әртүрлі төбенің ретсіз жұбы $\{u,v\}$ (қарапайым граф: тұзақ пен еселі қабырға жоқ). $u$ мен $v$ қосылса, олар сыбайлас (adjacent). Төбенің дәрежесі (degree) $\deg v$ - оған түйісетін қабырғалар саны.

    Қарапайым тілмен: Граф - төбелер және олардың кейбір жұптарын қосатын қабырғалар; дәреже - төбеден шығатын қабырғалар саны.

    Теорема 5.1 · Қол алысу леммасы

    Кез келген граф үшін $\sum_{v\in V}\deg v=2|E|$. Салдары: тақ дәрежелі төбелер саны жұп.

    Қарапайым тілмен: Барлық дәрежелердің қосындысы қабырғалар санының екі еселігі; сондықтан тақ дәрежелі төбелер саны жұп.

    Негіздеме. 1-қорыту.

    Анықтама 5.2 · Маршрут, жол, цикл, байланыстылық

    Маршрут (walk) - $v_0,v_1,\dots,v_k$ төбелер тізбегі, мұнда әр $\{v_{i-1},v_i\}\in E$; $k$ - ұзындығы. Төбелері қайталанбайтын маршрут - жол (path); $v_0=v_k$, $k\ge3$ және басқа төбелері қайталанбайтын тұйық маршрут - цикл (cycle). Кез келген екі төбе маршрутпен қосылса, граф байланысты (connected).

    Қарапайым тілмен: Маршрут - қабырғалар бойымен жүру; жол - төбелер қайталанбайды; цикл - тұйық жол; байланысты - кез келген екі төбе арасында жол бар.

    Анықтама 5.3 · Арнайы графтар

    Толық граф (complete graph) $K_n$: барлық жұп қосылған, $|E|=\frac{n(n-1)}2$. Цикл $C_n$: $n$ төбе, $n$ қабырға. Екі үлесті граф (bipartite graph): $V=X\cup Y$ ($X\cap Y=\varnothing$) және әр қабырға $X$ пен $Y$-ті қосады; $K_{m,n}$ - толық екі үлесті, $|E|=mn$. Екі граф изоморфты (isomorphic), егер төбелерінің арасында сыбайластықты сақтайтын биекция болса.

    Қарапайым тілмен: Толық граф, цикл, екі үлесті граф - жиі кездесетін құрылымдар.

    Теорема 5.2 · Екі үлестілік критерийі

    Граф екі үлесті $\iff$ оның тақ ұзындықты циклі жоқ.

    Қарапайым тілмен: Төбелерді екі түске қабырғалары әртүрлі түсті болатындай бояуға болады дәл тақ цикл жоқ болса.

    Негіздеме. $\Rightarrow$ (2-қорыту): циклде бөліктер кезектесіп ауысады, сондықтан цикл ұзындығы жұп. $\Leftarrow$ бағытының дәлелі (әр байланысты құрауышта бір төбеден қашықтықтың жұп/тақтығы бойынша бөлу) - есептердің бірінде қадамдық түрде.

    Анықтама 5.4 · Эйлер және Гамильтон циклдері

    Әр қабырғадан дәл бір рет өтетін тұйық маршрут - Эйлер циклі (Eulerian circuit); тұйық емес болса - Эйлер жолы. Әр төбеге дәл бір рет баратын цикл - Гамильтон циклі (Hamiltonian cycle).

    Қарапайым тілмен: Эйлер циклі - әр қабырғадан бір рет; Гамильтон циклі - әр төбеден бір рет.

    Теорема 5.3 · Эйлер теоремасы

    Байланысты граф (кемінде бір қабырғасы бар) Эйлер циклін қамтиды $\iff$ барлық төбелердің дәрежесі жұп. Эйлер жолы (циклсіз) бар $\iff$ дәл екі төбенің дәрежесі тақ; жол сол екі төбеде басталып, аяқталады.

    Қарапайым тілмен: Байланысты графта Эйлер циклі бар дәл барлық дәреже жұп болса.

    Негіздеме. 3-қорыту.

    Теорема 5.4 · Дирак теоремасы

    $n\ge3$ төбелі қарапайым графта әр төбенің дәрежесі $\ge\frac n2$ болса, онда Гамильтон циклі бар.

    Қарапайым тілмен: Әр төбенің дәрежесі жеткілікті үлкен ($\ge\frac n2$) болса, Гамильтон циклі бар.

    Негіздеме. Бұл - жеткілікті шарт (қажетті емес: $C_n$-де дәрежелер 2, бірақ цикл бар). Дәлелін бұл курста келтірмейміз. Гамильтон циклінің бар-жоғын анықтаудың жалпы тиімді алгоритмі белгісіз.

    Анықтама 5.5 · Сыбайластық матрицасы

    $V=\{1,\dots,n\}$ болса, сыбайластық матрицасы (adjacency matrix) $A$: $A_{ij}=1$, егер $\{i,j\}\in E$, әйтпесе 0. Қарапайым граф үшін $A$ симметриялы, диагоналі нөл, $i$-жолдың қосындысы $\deg i$.

    Қарапайым тілмен: Графты кесте ретінде жазу: $i$-жол $j$-баған $1$ - қабырға бар.

    Теорема 5.5 · Маршруттарды санау

    $(A^k)_{ij}$ - $i$-ден $j$-ге дейінгі ұзындығы $k$ маршруттар саны.

    Қарапайым тілмен: Сыбайластық матрицасының $k$-шы дәрежесі ұзындығы $k$ маршруттарды санайды.

    Негіздеме. 4-қорыту (индукция).

    Формула 5.1 · Қабырғалар саны
    $$|E(K_n)|=\frac{n(n-1)}{2},\qquad|E(K_{m,n})|=mn,\qquad\sum_v\deg v=2|E|$$

    $K_n$-де әр төбенің дәрежесі $n-1$.

    Формула 5.2 · Маршруттар
    $$W_k(i,j)=(A^k)_{ij}$$

    $W_k(i,j)$ - $i$-ден $j$-ге дейінгі ұзындығы $k$ маршруттар саны. Маршрутта төбелер қайталануы мүмкін; ал жолдарды санау әлдеқайда қиын.

    Есте сақта

    Эйлер есебін шешу: 1) граф байланысты ма? 2) тақ дәрежелі төбелерді санаңыз: 0 - Эйлер циклі бар; 2 - тек Эйлер жолы (сол екі төбе арасында); 4, 6, ... - ешқайсысы жоқ. Тақ дәрежелілер саны 1 не 3 бола алмайды (қол алысу леммасы).

    Назар аудар

    Сурет граф емес: бір граф көптеген әртүрлі суретпен беріледі, ал қабырғалардың «қиылысуы» төбе емес. Екі графтың изоморфтылығын тексергенде тек суретке емес, инварианттарға (төбе саны, қабырға саны, дәрежелер тізімі, циклдер) қараңыз; бірақ инварианттардың сәйкес келуі изоморфтылықты дәлелдемейді.

    Тоқта, ойлан

    Әрі қарай жүрмес бұрын, өзіңізді тексеріңіз: алдымен жауапты ойланыңыз, сосын ашыңыз.

    1. $K_5$-те неше қабырға бар?

    $\frac{5\cdot4}2=10$.

    2. Дәрежелері $3,3,3$ болатын граф бар ма?

    Жоқ: қосындысы $9$ - тақ, ал қол алысу леммасы бойынша жұп болуы керек.

    3. $C_5$ екі үлесті ме?

    Жоқ: тақ ұзындықты цикл.

    4. Графта дәл екі тақ дәрежелі төбе болса, Эйлер маршруты бар ма?

    Иә, бірақ тұйық емес: бір тақ төбеден басталып, екіншісінде аяқталады.

    Қорытып шығару

    Қорытып шығару 1: қол алысу леммасы

    Мақсат: $\sum\deg v=2|E|$ және тақ дәрежелі төбелер санының жұптығын дәлелдеу.

    Идея: «Төбе-қабырға» жұптарын екі тәсілмен санаймыз: төбелер бойынша - дәрежелердің қосындысы, қабырғалар бойынша - әр қабырға екі рет.

    1. «Төбе-қабырға» жұптарын $(v,e)$, мұнда $v\in e$, екі тәсілмен санаймыз.
    2. Төбелер бойынша: әр $v$ дәл $\deg v$ қабырғада, жұптар саны $\sum_v\deg v$.
    3. Қабырғалар бойынша: әр қабырғада дәл екі төбе, жұптар саны $2|E|$.
    4. Демек $\sum\deg v=2|E|$ - жұп сан.
    5. Қосындыны жұп және тақ дәрежелілерге бөлеміз: жұп дәрежелілер қосындысы жұп, сондықтан тақ дәрежелілер қосындысы да жұп.
    6. Тақ сандардың қосындысы жұп болса, олардың саны жұп. ∎

    ∎

    Қорытып шығару 2: екі үлесті графта тақ цикл жоқ

    Мақсат: Теорема 5.2-нің «$\Rightarrow$» бағытын дәлелдеу.

    Идея: Екі үлесті графта цикл бойымен жүру жақтарды кезекпен ауыстырады - бастапқыға қайту үшін қадамдар саны жұп.

    1. $G$ екі үлесті: $V=X\cup Y$, әр қабырға $X$ пен $Y$ арасында.
    2. $v_0,v_1,\dots,v_k=v_0$ цикл болсын, $v_0\in X$ делік.
    3. Әр қабырға бөлікті ауыстырады: $v_1\in Y$, $v_2\in X$, ..., жалпы $v_i\in X\iff i$ жұп.
    4. $v_k=v_0\in X$, демек $k$ жұп.
    5. Сонымен әр циклдің ұзындығы жұп; тақ цикл жоқ. Мысалы, $K_3$ (үшбұрыш) екі үлесті емес.

    ∎

    Қорытып шығару 3: Эйлер теоремасы

    Мақсат: Байланысты графта Эйлер циклі бар $\iff$ барлық дәрежелер жұп.

    Идея: Қажеттілік: әр кіру шығумен жұптасады. Жеткіліктілік: циклдерді біртіндеп құрып, біріктіреміз.

    1. Қажеттілік. Эйлер циклі бойымен жүргенде әр төбеге «кірген» сайын одан «шығамыз», әр қабырға бір рет қолданылады. Сондықтан әр төбенің қабырғалары «кіру-шығу» жұптарына бөлінеді - дәрежесі жұп (бастапқы төбеде соңғы кіру алғашқы шығумен жұптасады).
    2. Жеткіліктілік (қабырға саны бойынша күшті индукция). Барлық дәрежесі жұп, байланысты $G$ берілсін. Кез келген $v$-ден бастап, қолданылмаған қабырғалармен жүре береміз.
    3. Басқа $u\ne v$ төбеге кіргенде, оның қолданылған қабырғалары тақ (кірулер шығулардан бір артық), ал дәрежесі жұп - демек әрдайым шығатын қолданылмаған қабырға бар. Сондықтан тек $v$-де тоқтаймыз: тұйық маршрут $C$ алдық.
    4. $C$-ның қабырғаларын алып тастаймыз. Қалған графта да барлық дәрежелер жұп (әр төбеден жұп сан қабырға алынды). Оның әр байланысты құрауышы (қабырғасы бар) кіші, индукция бойынша онда Эйлер циклі бар.
    5. $G$ байланысты, сондықтан әр құрауыш $C$-мен ортақ төбеге ие. $C$ бойымен жүріп, әр осындай төбеде құрауыштың Эйлер циклін «кірістіреміз» - $G$-нің Эйлер циклі.
    6. Эйлер жолы: дәл екі тақ төбені ($a,b$) қосымша $\{a,b\}$ қабырғасымен қоссақ, барлық дәреже жұп; Эйлер циклінен сол қабырғаны алып тастасақ, $a$-дан $b$-ға жол шығады (еселі қабырғаға рұқсат етілген графтарда бірдей дәлел).

    ∎

    Қорытып шығару 4: $A^k$ маршруттарды санайды

    Мақсат: Теорема 5.5-ті индукциямен дәлелдеу.

    Идея: Индукция: ұзындығы $k+1$ маршрут - ұзындығы $k$ маршрут және бір қабырға; бұл дәл матрицаларды көбейту.

    1. База $k=1$: $(A^1)_{ij}=1$ дәл $i$ мен $j$ қосылғанда, яғни ұзындығы 1 маршрут саны.
    2. Болжам: $(A^k)_{il}$ - $i$-ден $l$-ге ұзындығы $k$ маршруттар саны.
    3. Қадам: ұзындығы $k+1$ маршрут $i\to j$ соңғы қадамнан алдын қандай да бір $l$ төбесінде тұрады, және $\{l,j\}\in E$.
    4. Әр $l$ үшін мұндай маршруттар саны $(A^k)_{il}\cdot A_{lj}$; барлық $l$ бойынша қосамыз: $\sum_l(A^k)_{il}A_{lj}=(A^{k+1})_{ij}$. ∎
    5. Салдары: $\frac16\operatorname{tr}(A^3)$ - графтағы үшбұрыштар саны (әр үшбұрыш 3 бастапқы нүктеден, 2 бағытпен саналады).

    ∎

    Мысал 4. Маршруттарды санау

    Үшбұрыш $K_3$ үшін $A$ және $A^2$, $A^3$-ті тауып, $1\to1$ ұзындығы 3 маршруттар санын анықтаңыз.

    1. 1-қадам. $A=\begin{pmatrix}0&1&1\\1&0&1\\1&1&0\end{pmatrix}$.
    2. 2-қадам. $A^2=\begin{pmatrix}2&1&1\\1&2&1\\1&1&2\end{pmatrix}$ - диагональ: $\deg i=2$ (бару-қайту).
    3. 3-қадам. $A^3=A^2A$: $(A^3)_{11}=0\cdot2+1\cdot1+1\cdot1=2$ - маршруттар $1\to2\to3\to1$ және $1\to3\to2\to1$.
    4. 4-қадам. $\operatorname{tr}A^3=6$, үшбұрыштар саны $\frac66=1$ ✓.

    Жауабы: $(A^3)_{11}=2$.

    • $\sum\deg v=|E|$ → $2|E|$
      Неге қате: әр қабырға екі төбенің дәрежесіне қосылады.
    • Тақ дәрежелі төбе саны 3 болатын граф → мүмкін емес
      Неге қате: тақ дәрежелілер саны әрдайым жұп.
    • Барлық дәреже жұп - Эйлер циклі бар (байланыссыз графта да) → байланыстылық та керек
      Неге қате: екі бөлек үшбұрыш: дәрежелер 2, бірақ бір цикл жоқ.

      Неге қате: $C_n$-де дәрежелер 2 $<\frac n2$, бірақ цикл бар.

    Визуализация

    Бақылаңыз: Толық граф қабырғалары $\approx\frac{n^2}2$, ал ең көп қабырғалы екі үлесті граф (бөліктері тең) - $\lfloor\frac{n^2}{4}\rfloor$, шамамен жартысы. Мантель теоремасы (дәлелсіз келтіреміз): $n$ төбелі графта үшбұрыш болмаса, қабырғалар саны $\lfloor n^2/4\rfloor$-тен аспайды.

    Бақылаңыз: $K_2$ графының сыбайластық матрицасы $\begin{pmatrix}0&1\\1&0\end{pmatrix}$ - жазықтықта $y=x$ түзуіне қатысты шағылу: ол төбелерді «орындарымен ауыстырады». $A^2=I$: ұзындығы 2 маршрут әрдайым бастапқы төбеге қайтады. Меншікті бағыттар $(1,1)$ және $(1,-1)$, меншікті мәндері $1$ және $-1$ (графтың «спектрі»).

    Қолданыс және мини-жоба

    Қолданыс. Графтар - әлеуметтік желілер, маршруттау (GPS), желі топологиясы, тәуелділіктер (пакеттер, тапсырмалар), молекулалар. Эйлер жолы - ДНҚ фрагменттерін құрастыруда (де Брёйн графтары), Гамильтон циклі - логистикада («коммивояжер есебі»).

    Мини-жоба: «Граф кітапханасы». Графты сыбайластық тізімімен сақтап, дәрежелерді, байланыстылықты (DFS), екі үлестілікті (BFS бояу) тексереміз және Хирхольцер алгоритмімен Эйлер циклін табамыз.

    from collections import deque

def make(edges):
    g = {}
    for u, v in edges:
        g.setdefault(u, []).append(v); g.setdefault(v, []).append(u)
    return g

def connected(g):
    start = next(iter(g)); seen = {start}; stack = [start]
    while stack:
        for w in g[stack.pop()]:
            if w not in seen:
                seen.add(w); stack.append(w)
    return len(seen) == len(g)

def bipartite(g):
    color = {}
    for s in g:
        if s in color: continue
        color[s] = 0; q = deque([s])
        while q:
            u = q.popleft()
            for w in g[u]:
                if w not in color: color[w] = 1 - color[u]; q.append(w)
                elif color[w] == color[u]: return False
    return True

def euler_circuit(edges):                      # Хирхольцер алгоритмі
    g = make(edges)
    if not connected(g) or any(len(n) % 2 for n in g.values()): return None
    adj = {u: list(n) for u, n in g.items()}
    stack, path = [edges[0][0]], []
    while stack:
        u = stack[-1]
        if adj[u]:
            w = adj[u].pop(); adj[w].remove(u); stack.append(w)
        else:
            path.append(stack.pop())
    return path[::-1]

K5 = [(i, j) for i in range(5) for j in range(i + 1, 5)]
print("K5 Эйлер циклі:", euler_circuit(K5))
print("K4 Эйлер циклі:", euler_circuit([(i, j) for i in range(4) for j in range(i + 1, 4)]))
print("C6 екі үлесті:", bipartite(make([(i, (i + 1) % 6) for i in range(6)])), " C5:", bipartite(make([(i, (i + 1) % 5) for i in range(5)])))

    Тақ цикл.

    6. (A²)ᵢᵢ нені көрсетеді (қарапайым граф)?

    Ұзындығы 2, i-ден i-ге маршруттар: бару-қайту.

    7. Гамильтон циклі дегеніміз:

    Анықтама.

    8. Тақ дәрежелі төбелер саны 7 болатын граф:

    Тақ дәрежелілер саны жұп.
