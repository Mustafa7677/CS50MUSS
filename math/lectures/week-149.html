    Stochastic Processes · 2-сабақ

    Марков тізбектері

    Ертеңгі ауа райын болжау үшін бүгінгі ауа райын білу жеткілікті ме, әлде бір апта бұрынғыны да білу керек пе? Марков тізбегі - «болашақ тек қазіргі күйге тәуелді, өткенге емес» деген қарапайым, бірақ өте күшті болжамға негізделген модель.

    ⏱ Оқу ≈ 50 минЕсептер ≈ 1 сағ 10 минТест ≈ 5 минБарлығы ≈ 2 сағ

    Ол бүкіл тізбекті бір ғана өту матрицасымен сипаттайды, ал $n$ қадамдық болжам матрицаның $n$-ші дәрежесіне айналады. Бұл сабақта Марков қасиетін анықтап, Чепмен-Колмогоров теңдеулерін дәлелдейміз, үлестірімнің уақыт бойы өзгеруін есептейміз, екі күйлі тізбектің $P^n$ матрицасын нақты табамыз. Соңында «бірінші қадам талдауы» әдісімен ойыншының күйреу есебін шешеміз: ұту ықтималдығы мен ойынның орташа ұзақтығы.

    Курс туралы

    Бұл сабақтың мазмұны үшін жауапкершілікті курс авторы Sagid Mustafa өзіне алады. Қате немесе түсініксіз жер тапсаңыз, хабарлаңыз. Бұл курс ресми емтихан не куәлік баламасы емес.

    Бір сөйлеммен

    Марков тізбегі - «ертеңгі күн тек бүгінге тәуелді» болатын процесс; бүкіл тізбек бір өту матрицасымен беріледі, ал $n$ қадамдық болжам - оның $n$-ші дәрежесі.

    Сабақ мақсаттары

    Сабақ соңында сіз мыналарды істей аласыз:

    • Марков қасиетін, біртекті тізбекті және өту матрицасын анықтау; стохастикалық матрицаны тану;
    • Чепмен-Колмогоров теңдеулерін дәлелдеп, $n$ қадамдық өту ықтималдықтары $P^n$ екенін көрсету;
    • бастапқы үлестірім бойынша $\mu_n=\mu_0P^n$ есептеу және траекторияның ықтималдығын табу;
    • екі күйлі тізбектің $P^n$ матрицасын нақты есептеу;
    • бірінші қадам талдауымен жұту ықтималдықтары мен орташа жұту уақытын табу;
    • Марков емес процестің мысалын келтіріп, оны дәлелдеу.

    Қысқаша еске салу

    Кездейсоқ процестер, кездейсоқ жүру (1-сабақ). Шартты ықтималдық, толық ықтималдық формуласы (Probability Theory, 3-сабақ). Матрицаларды көбейту (Linear Algebra, 4-сабақ). Меншікті мәндер және матрицаның дәрежелері (Linear Algebra, 8-сабақ). Сызықтық рекуррент теңдеулер (Discrete Mathematics).

    Алдымен қолмен: ауа райын екі күн алға болжау

    Формулаға дейін нақты сандармен ойнап көрейік. Әр қадамды өзіңіз де қағазда қайталаңыз.

    Ашық күннен кейін ашық күн $0{,}9$, жаңбыр $0{,}1$ ықтималдықпен; жаңбырдан кейін екеуі де $0{,}5$. Бүгін жаңбыр. Арғы күні ашық болу ықтималдығы?

    1. Ертең: ашық $0{,}5$, жаңбыр $0{,}5$.
    2. Арғы күн ашық болатын екі жол: «ашық → ашық» $0{,}5\cdot0{,}9=0{,}45$ және «жаңбыр → ашық» $0{,}5\cdot0{,}5=0{,}25$.
    3. Қосамыз: $0{,}45+0{,}25=0{,}7$.
    4. Бұл дәл $P^2$ матрицасының (жаңбыр, ашық) элементі: аралық күйлер бойынша қосынды = матрицаларды көбейту.

    Байқадыңыз ба? Көп қадамдық болжам - мүмкін болатын барлық аралық жолдар бойынша қосу; мұны матрицаны дәрежеге шығару автоматты түрде жасайды.

    Интуиция

    Бақа үш жапырақта секіреді. Келесі жапырақты тек қазір отырған жапырағына қарап таңдайды - бұрын қайда болғанын «ұмытады». Мұндай «есте сақтамайтын» процесс - Марков тізбегі. Барлық ақпарат - «$i$-ден $j$-ге секіру ықтималдығы» $p_{ij}$ кестесінде.

    Екі қадамнан кейін $i$-ден $j$-ге жету үшін аралық $k$ жапырағынан өтеміз: $\sum_kp_{ik}p_{kj}$ - бұл дәл матрицалық көбейтудің $(i,j)$ элементі. Сондықтан $n$ қадам $=P^n$.

    Үлестірім - жатық вектор $\mu$: «бақа қай жапырақта қандай ықтималдықпен». Бір қадам - $\mu\mapsto\mu P$. Көп қадамнан кейін $\mu_n$ көбіне тұрақты векторға жақындайды - бұл 3-сабақтың тақырыбы.

    Бірінші қадам талдауы: «$i$-ден бастағанда не болады?» сұрағына бір қадам жасап, «енді $j$-деміз, есеп өзіне ұқсас» деп жауап береміз. Нәтиже - белгісіздер саны күйлер санына тең сызықтық жүйе.

    Өмірден ұқсастық · үстел ойыны

    «Жыландар мен баспалдақтар» ойынында келесі орын тек қазіргі орын мен сүйекке тәуелді - бұрын қайда болғаныңыз маңызды емес. Бұл - Марков тізбегі. Ал карта ойындарында шыққан карталарды есте сақтау маңызды - Марков емес.

    Өмірден ұқсастық · казино

    Ойыншының күйреуі: капитал $0$ не $N$-ге жеткенде ойын бітеді. «$i$-ден бастағанда ұту ықтималдығы» - бір қадам жасап, «енді $i\pm1$-деміз» деп өзіне ұқсас есепке келтіру. Бұл - бірінші қадам талдауы.

    Белгілерді оқу

    Жоғары математиканың қиындығының жартысы - белгілерде. Теорияға дейін әр белгіні дауыстап оқып, мағынасын біліп алайық:

    Анықтамалар мен теоремалар

    Анықтама 2.1 · Марков тізбегі

    $E$ - ақырлы не саналымды жиын. $\{X_n\}_{n\ge0}$ - Марков тізбегі (Markov chain), егер әр $n$ және $i_0,\dots,i_{n-1},i,j\in E$ үшін (шарт оң ықтималды болғанда) $P(X_{n+1}=j\mid X_n=i,X_{n-1}=i_{n-1},\dots,X_0=i_0)=P(X_{n+1}=j\mid X_n=i)$ - Марков қасиеті (Markov property). Бұл шама $n$-ге тәуелсіз $p_{ij}$ болса, тізбек біртекті; $P=(p_{ij})$ - өту матрицасы (transition matrix).

    Қарапайым тілмен: Келесі күйдің үлестірімі тек қазіргі күйге тәуелді, өткен тарихқа емес.

    Анықтама 2.2 · Стохастикалық матрица

    $P$ - стохастикалық матрица (stochastic matrix): $p_{ij}\ge0$ және әр жолдың қосындысы $\sum_jp_{ij}=1$. Бастапқы үлестірім $\mu_0(i)=P(X_0=i)$ - жатық вектор. $n$ қадамдық өту ықтималдығы (n-step transition probability) $p^{(n)}_{ij}=P(X_{m+n}=j\mid X_m=i)$.

    Қарапайым тілмен: Өту матрицасының әр жолы - бір күйден кейінгі ықтималдықтар, сондықтан теріс емес және қосындысы $1$.

    Теорема 2.1 · Траекторияның ықтималдығы

    $P(X_0=i_0,X_1=i_1,\dots,X_n=i_n)=\mu_0(i_0)\,p_{i_0i_1}p_{i_1i_2}\cdots p_{i_{n-1}i_n}$.

    Қарапайым тілмен: Нақты жолдың ықтималдығы - бастапқы ықтималдық пен өтулер ықтималдықтарының көбейтіндісі.

    Негіздеме. Керісінше, осы формуламен берілген тізбек Марков тізбегі болады - тізбек $\mu_0$ және $P$ арқылы толық анықталады.

    Теорема 2.2 · Чепмен-Колмогоров теңдеулері

    $p^{(m+n)}_{ij}=\sum_kp^{(m)}_{ik}p^{(n)}_{kj}$, яғни $P^{(m+n)}=P^{(m)}P^{(n)}$. Демек $P^{(n)}=P^n$ және $\mu_n=\mu_0P^n$, мұнда $\mu_n(j)=P(X_n=j)$.

    Қарапайым тілмен: $n$ қадамдық өтулер - $P^n$, ал $n$ сәттегі үлестірім - $\mu_0P^n$.

    Негіздеме. Стохастикалық матрицалардың көбейтіндісі стохастикалық.

    Теорема 2.3 · Екі күйлі тізбек

    $P=\begin{pmatrix}1-a&a\\b&1-b\end{pmatrix}$, $0<a+b$. Онда $p^{(n)}_{11}=\frac b{a+b}+\frac a{a+b}(1-a-b)^n$. Егер $0<a+b<2$ болса, $p^{(n)}_{11}\to\frac b{a+b}$.

    Қарапайым тілмен: Екі күйлі тізбекте $P^n$-ді нақты формуламен жазуға болады; ол $\frac b{a+b}$ шегіне геометриялық жылдамдықпен жақындайды.

    Негіздеме. $a=b=1$ болса, тізбек күйлерді кезекпен ауыстырады және шегі жоқ.

    Анықтама 2.3 · Жұту ықтималдығы және жұту уақыты

    $A\subseteq E$ - жұтатын (мақсатты) күйлер. $\tau_A=\min\{n\ge0:X_n\in A\}$ - $A$-ға алғаш жету уақыты. $h_i=P_i(\tau_A<\infty)$ - жету ықтималдығы (hitting probability), $k_i=E_i\tau_A$ - орташа жету уақыты (expected hitting time); $P_i$ - $X_0=i$ шартымен ықтималдық.

    Қарапайым тілмен: Мақсатқа жету ықтималдығы мен орташа уақыты - тізбек туралы негізгі сұрақтар.

    Теорема 2.4 · Бірінші қадам талдауы

    $h_i=1$ ($i\in A$), $h_i=\sum_jp_{ij}h_j$ ($i\notin A$). $k_i$ ақырлы болса: $k_i=0$ ($i\in A$), $k_i=1+\sum_jp_{ij}k_j$ ($i\notin A$).

    Қарапайым тілмен: Бір қадам жасап, есепті өзіне ұқсас есепке келтіреміз - сызықтық теңдеулер жүйесі шығады.

    Негіздеме. Жалпы жағдайда $h$ - осы жүйенің ең кіші теріс емес шешімі (дәлелсіз); төменгі мысалдарда шешім жалғыз.

    Теорема 2.5 · Ойыншының күйреуі

    $\{0,1,\dots,N\}$-да жүру: $p$ ықтималдықпен $+1$, $q=1-p$ ықтималдықпен $-1$, $0$ және $N$ - жұтатын күйлер. $h_i=P_i(N$-ге $0$-ден бұрын жету$)$. (1) $p=\frac12$: $h_i=\frac iN$, $k_i=E_i\tau=i(N-i)$. (2) $p\ne\frac12$, $r=\frac qp$: $h_i=\frac{1-r^i}{1-r^N}$.

    Қарапайым тілмен: Әділ ойында ұту ықтималдығы - капиталдың мақсатқа қатынасы, ойын ұзақтығы $i(N-i)$; әділетсіз ойында ұту ықтималдығы тез кемиді.

    Негіздеме. Әділ ойында ұту ықтималдығы бастапқы капиталдың үлесіне тең.

    Формула 2.1 · Марков қасиеті
    $$P(X_{n+1}=j\mid X_n=i,\dots,X_0=i_0)=p_{ij}$$

    Өткен ұмытылады.

    Формула 2.2 · Чепмен-Колмогоров
    $$p^{(m+n)}_{ij}=\sum_kp^{(m)}_{ik}p^{(n)}_{kj}$$

    $P^{(n)}=P^n$.

    Формула 2.3 · Үлестірімнің эволюциясы
    $$\mu_n=\mu_0P^n$$

    Жатық вектор.

    Формула 2.4 · Екі күйлі тізбек
    $$p^{(n)}_{11}=\frac b{a+b}+\frac a{a+b}(1-a-b)^n$$

    $P=\begin{pmatrix}1-a&a\\b&1-b\end{pmatrix}$.

    Формула 2.5 · Бірінші қадам
    $$h_i=\sum_jp_{ij}h_j,\quad k_i=1+\sum_jp_{ij}k_j$$

    $i\notin A$.

    Формула 2.6 · Күйреу
    $$h_i=\frac{1-r^i}{1-r^N},\ r=\frac qp;\qquad p=\tfrac12:\ h_i=\frac iN,\ k_i=i(N-i)$$

    $0$ және $N$ жұтады.

    Есте сақта

    Марков тізбегі есебін шешу жоспары: (1) күйлерді нөмірлеп, өту матрицасын жазыңыз, әр жол қосындысы $1$ екенін тексеріңіз; (2) «$n$ қадамнан кейін» - $P^n$ не $\mu_0P^n$; (3) «қашан / қандай ықтималдықпен жетеді» - бірінші қадам талдауы: белгісіз $h_i$ не $k_i$ үшін сызықтық жүйе, шекаралық шарттар $A$-да; (4) жауапты шектік жағдайлармен тексеріңіз ($i=0$, $i=N$).

    Назар аудар

    (1) Марков қасиеті «өткен маңызсыз» дегенді білдірмейді: $X_{n+1}$ өткенге тәуелді, бірақ тек $X_n$ арқылы. (2) Әр процесс Марков емес: $Y_n=\xi_n+\xi_{n-1}$ ($\xi_i=\pm1$ тәуелсіз, әділ) - Марков емес (5-мысал). (3) Жолдар қосындысы $1$ болуы керек, бағандардың емес. (4) $\mu_n=\mu_0P^n$ - жатық векторды матрицаға солдан көбейтеміз; $P^n\mu_0^{\top}$ басқа нәрсені есептейді. (5) Бірінші қадам теңдеуі жалғыз шешімді болмауы мүмкін (шексіз күйлер) - онда ең кіші теріс емес шешім керек.

    Тоқта, ойлан

    Әрі қарай жүрмес бұрын, өзіңізді тексеріңіз: алдымен жауапты ойланыңыз, сосын ашыңыз.

    1. $P=\begin{pmatrix}0{,}5&0{,}5\\0{,}2&0{,}8\end{pmatrix}$ - өту матрицасы ма?

    Иә: элементтер теріс емес, әр жолдың қосындысы $1$.

    2. Әділ ойын: капитал $2$, мақсат $8$. Ұту ықтималдығы мен орташа ұзақтығы?

    $\frac28=0{,}25$; $2\cdot6=12$ раунд.

    3. $P(X_2=j\mid X_0=i)$ неге $p_{ij}^2$ емес?

    Екі қадамда аралық күй кез келген $k$ болуы мүмкін: $\sum_kp_{ik}p_{kj}$.

    4. Тізбек $\begin{pmatrix}0&1\\1&0\end{pmatrix}$ үшін $P^{100}$?

    $I$: $P^2=I$, демек жұп дәрежелер $I$.

    Қорытып шығару

    Қорытып шығару 1: траекторияның ықтималдығы

    Мақсат: Теорема 2.1-ді дәлелдеу.

    Идея: Шартты ықтималдықтың көбейту ережесін жазып, әр шарттағы тарихты Марков қасиеті бойынша тек соңғы күймен алмастырамыз.

    1. Шартты ықтималдықтың көбейту ережесі: $P(X_0=i_0,\dots,X_n=i_n)=P(X_0=i_0)\prod_{m=1}^nP(X_m=i_m\mid X_{m-1}=i_{m-1},\dots,X_0=i_0)$.
    2. Марков қасиеті бойынша әр көбейткіш $P(X_m=i_m\mid X_{m-1}=i_{m-1})=p_{i_{m-1}i_m}$.
    3. Демек $P(\dots)=\mu_0(i_0)p_{i_0i_1}\cdots p_{i_{n-1}i_n}$.
    4. (Шарттардың бірі нөлдік ықтималды болса, екі жақ та $0$.) ∎

    ∎

    Қорытып шығару 2: Чепмен-Колмогоров теңдеулері

    Мақсат: Теорема 2.2-ні дәлелдеу.

    Идея: $m$-ші қадамдағы күй бойынша толық ықтималдық формуласы - бұл дәл матрицаларды көбейту.

    1. Толық ықтималдық формуласы $X_{m}$ бойынша ($X_0=i$ шартымен): $P_i(X_{m+n}=j)=\sum_kP_i(X_m=k)\,P_i(X_{m+n}=j\mid X_m=k)$.
    2. Теорема 2.1 бойынша траекториялар бойынша қосындылап, $P_i(X_{m+n}=j\mid X_m=k)=p^{(n)}_{kj}$ - $m$-ге дейінгі тарих маңызсыз.
    3. Демек $p^{(m+n)}_{ij}=\sum_kp^{(m)}_{ik}p^{(n)}_{kj}$ - матрицалық көбейту: $P^{(m+n)}=P^{(m)}P^{(n)}$.
    4. $P^{(1)}=P$; индукция: $P^{(n)}=P^n$. Сол сияқты $\mu_n(j)=\sum_i\mu_0(i)p^{(n)}_{ij}$, яғни $\mu_n=\mu_0P^n$. ∎

    ∎

    Қорытып шығару 3: екі күйлі тізбек

    Мақсат: Теорема 2.3-ті дәлелдеу.

    Идея: $p^{(n)}_{11}$ үшін бір қадамдық рекуррент теңдеу жазамыз; қозғалмайтын нүктеден ауытқу әр қадамда $1-a-b$ есе кішірейеді.

    1. $x_n=p^{(n)}_{11}$. Бір қадам артқа: $x_{n+1}=x_n(1-a)+(1-x_n)b=b+(1-a-b)x_n$.
    2. Қозғалмайтын нүкте: $\pi=b+(1-a-b)\pi\Rightarrow\pi=\frac b{a+b}$.
    3. Айырма: $x_{n+1}-\pi=(1-a-b)(x_n-\pi)$, демек $x_n-\pi=(1-a-b)^n(x_0-\pi)$, $x_0=1$.
    4. $x_0-\pi=\frac a{a+b}$, яғни $x_n=\frac b{a+b}+\frac a{a+b}(1-a-b)^n$. $|1-a-b|<1\iff0<a+b<2$ болса, екінші қосылғыш $\to0$. ∎

    ∎

    Қорытып шығару 4: бірінші қадам талдауы

    Мақсат: Теорема 2.4-ті дәлелдеу.

    Идея: Бірінші қадам бойынша толық ықтималдық; Марков қасиеті бойынша келесі күйден бастап есеп жаңадан басталады.

    1. $i\in A$: $\tau_A=0$, сондықтан $h_i=1$, $k_i=0$.
    2. $i\notin A$: $\tau_A\ge1$. $X_1$ бойынша толық ықтималдық: $h_i=\sum_jP_i(X_1=j)P_i(\tau_A<\infty\mid X_1=j)$.
    3. Марков қасиеті: $X_1=j$ болғаннан кейін тізбек $j$-ден жаңадан басталғандай, демек шартты ықтималдық $h_j$: $h_i=\sum_jp_{ij}h_j$.
    4. Уақыт үшін де солай, бірақ бір қадам қосылады: $E_i\tau_A=\sum_jp_{ij}(1+k_j)=1+\sum_jp_{ij}k_j$. ∎

    ∎

    Қорытып шығару 5: ойыншының күйреуі

    Мақсат: Теорема 2.5-ті дәлелдеу.

    Идея: Рекуррент теңдеуді айырымдар арқылы шешеміз: әділ ойында айырымдар тұрақты (сызықтық шешім), әділетсізде - геометриялық прогрессия.

    1. Бірінші қадам: $h_i=ph_{i+1}+qh_{i-1}$, $h_0=0$, $h_N=1$. Түрлендіреміз: $p(h_{i+1}-h_i)=q(h_i-h_{i-1})$, яғни $d_i=h_{i+1}-h_i=r^id_0$.
    2. $h_i=d_0(1+r+\dots+r^{i-1})$. $r\ne1$: $h_i=d_0\frac{1-r^i}{1-r}$; $h_N=1$ шартынан $h_i=\frac{1-r^i}{1-r^N}$. $r=1$ ($p=\frac12$): $h_i=id_0=\frac iN$.
    3. Уақыт, $p=\frac12$: $k_i$ ақырлы - әр $N$ қадамның ішінде тізбек $2^{-N}$-нен кем емес ықтималдықпен жұтылады, сондықтан $P(\tau>mN)\le(1-2^{-N})^m$. Онда $k_i=1+\frac12(k_{i-1}+k_{i+1})$, $k_0=k_N=0$.
    4. Екінші айырма: $k_{i+1}-2k_i+k_{i-1}=-2$. $k_i=i(N-i)$ шешім ($-(i+1)^2+2i^2-(i-1)^2=-2$ ✓); екі шешімнің айырмасы сызықты және шеттерде нөл - демек нөл. Шешім жалғыз. ∎

    ∎

    Қадамдық шешілген мысалдар

    Мысал 1. Ауа райы

    Күйлер: 1 - ашық, 2 - жаңбыр. $P=\begin{pmatrix}0{,}9&0{,}1\\0{,}5&0{,}5\end{pmatrix}$. $P^2$?

    1. 1-қадам. $(P^2)_{11}=0{,}9\cdot0{,}9+0{,}1\cdot0{,}5=0{,}86$, $(P^2)_{12}=0{,}9\cdot0{,}1+0{,}1\cdot0{,}5=0{,}14$.
    2. 2-қадам. $(P^2)_{21}=0{,}5\cdot0{,}9+0{,}5\cdot0{,}5=0{,}7$, $(P^2)_{22}=0{,}5\cdot0{,}1+0{,}5\cdot0{,}5=0{,}3$.
    3. 3-қадам. Жолдар қосындысы $1$ ✓.
    4. 4-қадам. Теорема 2.3 ($a=0{,}1$, $b=0{,}5$): $p^{(2)}_{11}=\frac{0{,}5}{0{,}6}+\frac{0{,}1}{0{,}6}\cdot0{,}4^2=0{,}8\overline3+0{,}02\overline6=0{,}86$ ✓.

    Жауабы: $P^2=\begin{pmatrix}0{,}86&0{,}14\\0{,}7&0{,}3\end{pmatrix}$.

    Мысал 2. Үлестірімнің эволюциясы

    Бүгін жаңбыр: $\mu_0=(0,1)$. $\mu_1$, $\mu_2$?

    1. 1-қадам. $\mu_1=\mu_0P=(0{,}5;\ 0{,}5)$.
    2. 2-қадам. $\mu_2=\mu_1P=(0{,}5\cdot0{,}9+0{,}5\cdot0{,}5;\ 0{,}5\cdot0{,}1+0{,}5\cdot0{,}5)=(0{,}7;\ 0{,}3)$.
    3. 3-қадам. Бұл $P^2$-ның екінші жолы ✓.
    4. 4-қадам. $n\to\infty$: $\mu_n\to\left(\frac56,\frac16\right)$ - бастапқы ауа райына тәуелсіз (3-сабақ).

    Жауабы: $\mu_2=(0{,}7;0{,}3)$.

    Мысал 3. Траектория ықтималдығы

    $X_0=1$: $P(X_1=1,X_2=2,X_3=2)$?

    1. 1-қадам. Теорема 2.1: $p_{11}p_{12}p_{22}$.
    2. 2-қадам. $=0{,}9\cdot0{,}1\cdot0{,}5=0{,}045$.
    3. 3-қадам. Мағынасы: ертең ашық, сосын екі күн жаңбыр.
    4. 4-қадам. Ескерту: бұл $P(X_3=2)=(P^3)_{12}$-дан кіші - соңғысы барлық жолдарды қосады.

    Жауабы: $0{,}045$.

    Мысал 4. Ойыншының күйреуі

    Әділ ойын, капитал $3$, мақсат $N=10$.

    1. 1-қадам. Ұту ықтималдығы: $h_3=\frac3{10}$.
    2. 2-қадам. Күйреу ықтималдығы: $1-h_3=0{,}7$.
    3. 3-қадам. Ойынның орташа ұзақтығы: $k_3=3\cdot7=21$ раунд.
    4. 4-қадам. Әділетсіз ойын $p=0{,}45$: $r=\frac{11}9$, $h_3=\frac{1-r^3}{1-r^{10}}\approx0{,}128$ (әділ ойындағы $0{,}3$-тің орнына) - аз ғана артықшылық ұту ықтималдығын айтарлықтай азайтады.

    Жауабы: $0{,}3$; $21$.

    Мысал 5. Марков емес процесс

    $\xi_i=\pm1$ тәуелсіз, әділ; $Y_n=\xi_n+\xi_{n-1}$.

    1. 1-қадам. $P(Y_3=2\mid Y_2=0,Y_1=2)$: $Y_1=2\Rightarrow\xi_1=1$; $Y_2=0\Rightarrow\xi_2=-1$; онда $Y_3=\xi_3-1\le0$. Ықтималдық $0$.
    2. 2-қадам. $P(Y_3=2\mid Y_2=0)$: $Y_2=0\iff\xi_1\ne\xi_2$; $Y_3=2\iff\xi_2=\xi_3=1$. $P(\xi_2=1,\xi_3=1\mid\xi_1\ne\xi_2)=\frac12\cdot\frac12=\frac14$.
    3. 3-қадам. $0\ne\frac14$ - $Y_1$ туралы ақпарат болжамды өзгертеді.
    4. 4-қадам. Демек $\{Y_n\}$ Марков тізбегі емес; ал $(\xi_{n-1},\xi_n)$ жұбы - Марков тізбегі.

    Жауабы: Марков емес.

    Жиі қателер

    • Бағандардың қосындысы $1$ → жолдардың қосындысы $1$
      Неге қате: $\sum_jp_{ij}=1$.
    • $P(X_2=j\mid X_0=i)=p_{ij}^2$ → $(P^2)_{ij}=\sum_kp_{ik}p_{kj}$
      Неге қате: Аралық күйлер.
    • $\mu_n=P^n\mu_0$ (бағанмен) → $\mu_n=\mu_0P^n$ (жатық вектор)
      Неге қате: Солдан көбейту.
    • Бірінші қадам теңдеуінде $k_i$-ге $1$ қосуды ұмыту → $k_i=1+\sum_jp_{ij}k_j$
      Неге қате: Қадам уақыт алады.
    • Кез келген процесс Марков → $Y_n=\xi_n+\xi_{n-1}$ - Марков емес
      Неге қате: 5-мысал.
    • Әділ ойында ұту ықтималдығы $\frac12$ → $\frac iN$
      Неге қате: Капитал үлесі.

    Визуализация

    Бақылаңыз: $1-a-b$ - матрицаның екінші меншікті мәні: ол жинақталу жылдамдығын анықтайды. $a+b>1$ болса, $1-a-b<0$ және $p^{(n)}_{11}$ шекті айналып тербеледі. $a=b=1$ етсеңіз, тізбек периодты болады және шек жоқ - мұны 3-сабақта зерттейміз.

    import random

def matmul(A, B):
    return [[sum(A[i][k] * B[k][j] for k in range(len(B))) for j in range(len(B[0]))] for i in range(len(A))]

P = [[0.9, 0.1], [0.5, 0.5]]
a, b = 0.1, 0.5
Pn = [[1.0, 0.0], [0.0, 1.0]]
for n in range(1, 7):
    Pn = matmul(Pn, P)
    formula = b / (a + b) + a / (a + b) * (1 - a - b) ** n
    print(f"n={n}:  p11^(n) = {Pn[0][0]:.6f}   формула {formula:.6f}")

x, rainy, T = 0, 0, 100000
for _ in range(T):
    x = 0 if random.random() < P[x][0] else 1
    rainy += x
print(f"жаңбырлы күндер үлесі ≈ {rainy / T:.4f}   шек a/(a+b) = {a / (a + b):.4f}")

def ruin(i, N, p):
    t = 0
    while 0 < i < N:
        i += 1 if random.random() < p else -1
        t += 1
    return i == N, t

R = 20000
for p in (0.5, 0.45):
    res = [ruin(3, 10, p) for _ in range(R)]
    win = sum(w for w, _ in res) / R
    r = (1 - p) / p
    h = 3 / 10 if p == 0.5 else (1 - r ** 3) / (1 - r ** 10)
    line = f"p={p}:  ұтыс ≈ {win:.4f}   формула {h:.4f}"
    if p == 0.5:
        line += f"   орташа ұзақтық ≈ {sum(t for _, t in res) / R:.2f}   формула 21"
    print(line)
