    Fourier & Laplace Transforms · 6-сабақ

    Дискретті Фурье түрлендіруі және FFT

    Компьютер үзіліссіз функциямен емес, ақырлы сандар тізбегімен жұмыс істейді: микрофон секундына 44100 рет өлшейді, сурет - пиксельдер торы. Дискретті Фурье түрлендіруі (ДФТ) $N$ санды $N$ жиілік коэффициентіне аударады және бұл - қатар мен интегралдың орнына ақырлы қосынды, жуықтаусыз дәл түрлендіру.

    ⏱ Оқу ≈ 50 минЕсептер ≈ 1 сағТест ≈ 5 минБарлығы ≈ 2 сағ

    Оны тікелей есептеу $N^2$ амал талап етеді, ал 1965 жылы кең тараған Кули–Тьюки алгоритмі (FFT) - тек $N\log_2N$: миллион нүкте үшін бұл секунд пен сағаттың айырмасы. Бұл сабақта ДФТ-ны анықтап, кері формуласын бірдің түбірлерінің ортогональдығынан дәлелдейміз, қасиеттерін (симметрия, айналмалы үйірткі, Парсеваль), Фурье қатарымен байланысын және «бүркемелену» (aliasing) құбылысын қорытамыз, FFT алгоритмін және оның күрделілігін дәлелдейміз.

    Курс туралы

    Бұл сабақтың мазмұны үшін жауапкершілікті курс авторы Sagid Mustafa өзіне алады. Қате немесе түсініксіз жер тапсаңыз, хабарлаңыз. Бұл курс ресми емтихан не куәлік баламасы емес.

    Бір сөйлеммен

    Дискретті Фурье түрлендіруі $N$ санды $N$ жиілікке жіктейді; FFT алгоритмі оны $N^2$ емес, $N\log N$ амалмен есептейді - сондықтан телефон дыбысты нақты уақытта талдай алады.

    Сабақ мақсаттары

    Сабақ соңында сіз мыналарды істей аласыз:

    • ДФТ мен кері ДФТ-ны анықтап, кіші $N$ үшін қолмен есептеу;
    • бірдің $N$-ші түбірлерінің ортогональдығын дәлелдеп, кері формуланы қорыту;
    • нақты тізбектің спектріндегі симметрияны, айналмалы үйірткі теоремасын және Парсеваль теңдігін қолдану;
    • ДФТ мен Фурье коэффициенттерінің байланысын және бүркемелену формуласын дәлелдеу;
    • Кули–Тьюки FFT алгоритмін сипаттап, оның $O(N\log N)$ күрделілігін дәлелдеу;
    • FFT-ны көпмүшелерді көбейтуге және сигнал спектрін талдауға қолдану.

    Қысқаша еске салу

    Бірдің $n$-ші дәрежелі түбірлері $e^{2\pi ik/N}$ және олардың қосындысы $0$ (комплекс анализ, 1-сабақ). Фурье қатарының комплекс түрі, $c_n=\frac1{2\pi}\int fe^{-inx}$, Парсеваль теңдігі (2-сабақ). Геометриялық прогрессия қосындысы. Рекуррентті қатынастар және алгоритм күрделілігі $O(\cdot)$ ұғымы.

    Бұл сабақтар таныс болса, бірден бастай беріңіз. Толық реттілік: оқу жолы.

    Алдымен қолмен: 4 нүктелі ДФТ қолмен

    Формулаға дейін нақты сандармен ойнап көрейік. Әр қадамды өзіңіз де қағазда қайталаңыз.

    $x=(1,0,-1,0)$ (бұл $\cos\frac{2\pi n}4$) үшін $X_k=\sum_nx_n\omega^{-kn}$, $\omega=e^{2\pi i/4}=i$.

    1. $X_0=1+0-1+0=0$ - орта мән нөл.
    2. $X_1=1\cdot1+(-1)\cdot\omega^{-2}=1-(-1)=2$ ($\omega^{-2}=i^{-2}=-1$).
    3. $X_2=1+(-1)\cdot\omega^{-4}=1-1=0$; $X_3=1+(-1)\omega^{-6}=1-(-1)=2$.
    4. Спектр $(0,2,0,2)$: тек $k=1$ және $k=3=-1$ жиіліктер - косинус екі экспонентадан тұрады ✓.

    Байқадыңыз ба? ДФТ сигналда қай жиіліктер бар екенін көрсетеді. Нақты сигналда $X_{N-k}=\overline{X_k}$ - спектр симметриялы.

    Интуиция

    Фурье қатарының коэффициенті $c_k=\frac1{2\pi}\int_0^{2\pi}f(x)e^{-ikx}dx$. Интегралды $N$ тең бөлікті тіктөртбұрыштар (не трапеция) әдісімен жуықтасақ, $c_k\approx\frac1N\sum_{n=0}^{N-1}f(x_n)e^{-ikx_n}$, $x_n=\frac{2\pi n}N$. Осы қосынды ($\frac1N$-сіз) - ДФТ. Демек ДФТ - сигналдың «өлшенген» нүктелері бойынша спектрі.

    Бірақ дискреттеудің бағасы бар: $N$ нүктеде $e^{ikx}$ пен $e^{i(k+N)x}$ мәндері бірдей, өйткені $e^{iNx_n}=e^{2\pi in}=1$. Жиілігі $N$-ге айырмашылықты екі тербеліс өлшенген нүктелерде ажыратылмайды - бүркемелену (aliasing). Кинодағы «кері айналатын» дөңгелек дәл осы құбылыс: кадр жиілігі дөңгелектің айналу жиілігінен аз.

    FFT идеясы - «бөліп ал да билей бер»: $N$ нүктенің ДФТ-сын жұп және тақ индексті нүктелердің $\frac N2$ ұзындықты екі ДФТ-сына келтіреміз. Әр деңгейде $N$ амал, деңгей саны $\log_2N$, барлығы $N\log_2N$. $N=1024$ үшін $N^2\approx10^6$, ал $N\log_2N\approx10^4$ - 100 есе жылдам; $N=10^6$ үшін - 50 000 есе.

    Ең таңғаларлық қолданыстардың бірі - көпмүшелерді көбейту. Коэффициенттер тізбегін көбейту - үйірткі, ал ДФТ үйірткіні көбейтіндіге айналдырады. Сондықтан екі $N$-дәрежелі көпмүшенің көбейтіндісін $N^2$ емес, $N\log N$ амалмен табуға болады - үлкен сандарды көбейтудің жылдам алгоритмдері осыған сүйенеді.

    Өмірден ұқсастық · бөліп ал да билей бер

    FFT - тізімді жұп және тақ орындарға бөліп, әр жартысының ДФТ-сын бөлек есептеп, біріктіру. Бөлуді қайталасақ, $\log_2N$ деңгей шығады, әр деңгейде $N$ амал. $N=10^6$ үшін бұл $10^{12}$ орнына $2\cdot10^7$ амал.

    Өмірден ұқсастық · кино дөңгелегі

    Бүркемелену: кинода машина дөңгелегі кері айналып көрінеді - кадр жиілігі дөңгелек жиілігінен төмен. Сигналды тым сирек өлшесек, жоғары жиіліктер төмен жиілік болып «бүркемеленеді».

    Белгілерді оқу

    Жоғары математиканың қиындығының жартысы - белгілерде. Теорияға дейін әр белгіні дауыстап оқып, мағынасын біліп алайық:

    Анықтамалар мен теоремалар

    Анықтама 6.1 · Дискретті Фурье түрлендіруі

    $x=(x_0,\dots,x_{N-1})\in\mathbb C^N$, $\omega=e^{2\pi i/N}$. Дискретті Фурье түрлендіруі (discrete Fourier transform): $X_k=\sum_{n=0}^{N-1}x_n\omega^{-kn}$, $k=0,\dots,N-1$. Матрица түрінде $X=F_Nx$, $(F_N)_{kn}=\omega^{-kn}$. $X_k$ кез келген бүтін $k$ үшін анықталған және $N$ периодты: $X_{k+N}=X_k$.

    Қарапайым тілмен: $N$ санды $N$ жиіліктегі «тербелістермен» салыстырып, әр жиіліктің мөлшерін табамыз.

    Теорема 6.1 · Ортогональдық және кері ДФТ

    (1) Бүтін $j$ үшін $\sum_{n=0}^{N-1}\omega^{jn}=N$, егер $N\mid j$, әйтпесе $0$. (2) Кері ДФТ (inverse DFT): $x_n=\frac1N\sum_{k=0}^{N-1}X_k\omega^{kn}$. Демек $F_N^{-1}=\frac1N\overline{F_N}$, ал $\frac1{\sqrt N}F_N$ - унитар матрица.

    Қарапайым тілмен: Бірдің түбірлерінің дәрежелерінің қосындысы нөл (бүтін айналымнан басқа) - осыдан кері ДФТ формуласы шығады.

    Негіздеме. (1) - бірдің түбірлерінің қосындысы (комплекс анализ, 1-сабақ, Қадамдық шешім).

    Теорема 6.2 · ДФТ қасиеттері

    (1) Нақты $x$: $X_{N-k}=\overline{X_k}$, дербес жағдайда $X_0$ нақты (және $N$ жұп болса, $X_{N/2}$ нақты). (2) Айналмалы жылжу $y_n=x_{n-m}$ (индекстер $N$ модулі бойынша): $Y_k=\omega^{-km}X_k$. (3) Айналмалы үйірткі (circular convolution) $(x\circledast y)_n=\sum_{m=0}^{N-1}x_my_{n-m}$: $\mathcal F[x\circledast y]_k=X_kY_k$. (4) Парсеваль: $\sum_n|x_n|^2=\frac1N\sum_k|X_k|^2$.

    Қарапайым тілмен: Нақты сигналдың спектрі симметриялы; айналмалы үйірткі көбейтіндіге айналады; энергия сақталады.

    Негіздеме. Барлығы ортогональдықтан.

    Теорема 6.3 · Бүркемелену формуласы

    $f(x)=\sum_jc_je^{ijx}$, $\sum|c_j|<\infty$ ($2\pi$ периодты), $x_n=f\left(\frac{2\pi n}N\right)$ болса, $$\frac{X_k}N=\sum_{m=-\infty}^{\infty}c_{k+mN}.$$ Дербес жағдайда $f$ - тригонометриялық көпмүше, $c_j=0$ барлық $|j|\ge\frac N2$ үшін (және $N$ жұп болса, $c_{\pm N/2}$ де нөл) болса, ДФТ коэффициенттерді дәл береді: $c_k=\frac{X_k}N$, $c_{-k}=\frac{X_{N-k}}N$.

    Қарапайым тілмен: Дискретті өлшеуде $k$ және $k+N$ жиіліктер ажыратылмайды - олардың коэффициенттері қосылып кетеді.

    Негіздеме. Бұл - Найквист шарты (Nyquist criterion) дискретті түрі: сигналдағы ең жоғары жиілік өлшеу жиілігінің жартысынан кіші болуы керек.

    Теорема 6.4 · FFT (Кули–Тьюки)

    $N=2M$. $E_k$ - жұп индексті $(x_0,x_2,\dots)$ тізбегінің, $O_k$ - тақ индекстілердің $M$-нүктелі ДФТ-сы. Онда $k=0,\dots,M-1$ үшін $$X_k=E_k+\omega_N^{-k}O_k,\qquad X_{k+M}=E_k-\omega_N^{-k}O_k.$$ $N=2^p$ болса, рекурсия жылдам Фурье түрлендіруі (fast Fourier transform) береді: кешенді көбейту саны $\frac N2\log_2N$, жалпы амал саны $O(N\log N)$.

    Қарапайым тілмен: $N$ нүктелі ДФТ екі $\frac N2$ нүктелі ДФТ-ға бөлінеді - рекурсия $N\log N$ уақыт береді.

    Негіздеме. Тікелей есептеу $O(N^2)$ амал талап етеді.

    Формула 6.1 · ДФТ
    $$X_k=\sum_{n=0}^{N-1}x_n\,\omega^{-kn},\qquad\omega=e^{2\pi i/N}$$

    $k=0,\dots,N-1$; $X$ $N$ периодты.

    Формула 6.2 · Кері ДФТ
    $$x_n=\frac1N\sum_{k=0}^{N-1}X_k\,\omega^{kn}$$

    Бірдің түбірлерінің ортогональдығы.

    Формула 6.3 · Ортогональдық
    $$\sum_{n=0}^{N-1}\omega^{jn}=\begin{cases}N,&N\mid j\\0,&N\nmid j\end{cases}$$

    Геометриялық прогрессия.

    Формула 6.4 · Нақты сигнал
    $$X_{N-k}=\overline{X_k}$$

    $x_n\in\mathbb R$; спектрдің жартысы жеткілікті.

    Формула 6.5 · Айналмалы үйірткі
    $$\mathcal F[x\circledast y]=X\cdot Y,\qquad(x\circledast y)_n=\sum_mx_my_{(n-m)\bmod N}$$

    Көпмүшелерді көбейту үшін нөлдермен толықтырамыз.

    Формула 6.6 · Бүркемелену
    $$\frac{X_k}{N}=\sum_{m\in\mathbb Z}c_{k+mN}$$

    $\sum|c_j|<\infty$; Найквист шартында $X_k=Nc_k$.

    Формула 6.7 · FFT қадамы
    $$X_k=E_k+\omega_N^{-k}O_k,\quad X_{k+N/2}=E_k-\omega_N^{-k}O_k$$

    $N$ жұп; «көбелек» (butterfly).

    Есте сақта

    Есептеу кеңестері: (1) кіші $N$ үшін $\omega$-ның дәрежелерін алдын ала жазыңыз ($N=4$: $\omega=i$, $\omega^{-1}=-i$, $\omega^{-2}=-1$, $\omega^{-3}=i$); (2) нақты сигналда $X_0,\dots,X_{N/2}$-ні есептеп, қалғанын $X_{N-k}=\overline{X_k}$ арқылы алыңыз; (3) тексеру: $X_0=\sum x_n$, ал $x_0=\frac1N\sum X_k$; (4) жиілік индексі $k>\frac N2$ шын мәнінде теріс жиілік $k-N$.

    Назар аудар

    ДФТ сигналды $N$ периодты деп «ойлайды». Үзіліссіз сигналдың кесіндісін алсақ, оның екі шеті сәйкес келмейді, және ДФТ бұл «секірісті» көреді - спектрге жалған жоғары жиіліктер «ағып» кетеді (spectral leakage). Сондай-ақ айналмалы үйірткі кәдімгі (сызықтық) үйірткі емес: көпмүшелерді көбейткенде тізбектерді нәтиже дәрежесінен ұзын болатындай нөлдермен толықтырмасаңыз, жоғарғы коэффициенттер төменгілерге «оралып» қосылады.

    Тоқта, ойлан

    Әрі қарай жүрмес бұрын, өзіңізді тексеріңіз: алдымен жауапты ойланыңыз, сосын ашыңыз.

    1. $x=(1,1,1,1)$ үшін ДФТ?

    $(4,0,0,0)$ - тек тұрақты құраушы.

    2. $N=1024$ үшін тікелей ДФТ мен FFT амалдарының шамамен қатынасы?

    $\frac{N^2}{N\log_2N}=\frac{1024}{10}\approx100$ есе.

    3. Дыбысты секундына $44100$ рет өлшесек, ең жоғары дұрыс жазылатын жиілік?

    $22050$ Гц (Найквист жиілігі).

    4. Нақты сигналда $X_1=3-4i$ болса, $X_{N-1}$?

    $3+4i$.

    Қорытып шығару

    Қорытып шығару 1: ортогональдық және кері ДФТ

    Мақсат: Теорема 6.1-ді дәлелдеу.

    Идея: Геометриялық прогрессияның қосындысы: еселік $q=\omega^j\ne1$ болса, $q^N=1$ болғандықтан қосынды нөл.

    1. (1) $N\mid j$: $\omega^j=e^{2\pi ij/N}=1$, қосынды $N$. Әйтпесе $q=\omega^j\ne1$, геометриялық прогрессия: $\sum_{n=0}^{N-1}q^n=\frac{q^N-1}{q-1}=\frac{e^{2\pi ij}-1}{q-1}=0$.
    2. (2) $\frac1N\sum_kX_k\omega^{kn}=\frac1N\sum_k\sum_mx_m\omega^{-km}\omega^{kn}=\frac1N\sum_mx_m\sum_k\omega^{k(n-m)}$.
    3. Ішкі қосынды (1) бойынша $N[m=n]$ ($0\le m,n\le N-1$ болғандықтан $N\mid(n-m)\iff m=n$).
    4. Нәтиже $x_n$. ∎
    5. Матрица тілінде: $\overline{F_N}F_N=NI$, яғни $\frac1{\sqrt N}F_N$-ның бағандары ортонормаль - унитар матрица; Парсеваль теңдігі осыдан шығады.

    ∎

    Қорытып шығару 2: бүркемелену формуласы

    Мақсат: Теорема 6.4-ті дәлелдеу.

    Идея: Сигналды Фурье қатары арқылы жазып, ДФТ-ға қоямыз; ортогональдық тек $j\equiv k\pmod N$ мүшелерін қалдырады.

    1. $x_n=f\left(\frac{2\pi n}{N}\right)=\sum_jc_je^{2\pi ijn/N}=\sum_jc_j\omega^{jn}$ (қатар абсолютті жинақты).
    2. $X_k=\sum_{n=0}^{N-1}\sum_jc_j\omega^{jn}\omega^{-kn}=\sum_jc_j\sum_n\omega^{(j-k)n}$ (ақырлы қосынды мен абсолютті жинақты қатардың ретін ауыстыруға болады).
    3. Ортогональдық: ішкі қосынды $N$, егер $j\equiv k\pmod N$, әйтпесе $0$.
    4. $X_k=N\sum_{j\equiv k}c_j=N\sum_mc_{k+mN}$. ∎
    5. Найквист: $c_j=0$ үшін $|j|\ge\frac N2$ болса, $k\in[0;\frac N2)$ үшін қосындыда тек $m=0$ қалады ($|k+mN|\ge\frac N2$ кезінде $m\ne0$), $X_k=Nc_k$; $k\in(\frac N2;N)$ үшін тек $m=-1$: $X_k=Nc_{k-N}$.

    ∎

    Қорытып шығару 3: FFT және оның күрделілігі

    Мақсат: Теорема 6.5-ті дәлелдеу.

    Идея: Қосындыны жұп және тақ индекстерге бөлеміз; $\omega_N^2=\omega_{N/2}$ болғандықтан әр бөлік - жарты ұзындықты ДФТ.

    1. $X_k=\sum_{r=0}^{M-1}x_{2r}\omega_N^{-2rk}+\sum_{r=0}^{M-1}x_{2r+1}\omega_N^{-(2r+1)k}$.
    2. $\omega_N^2=e^{2\pi i/M}=\omega_M$: бірінші қосынды $E_k$, екіншісі $\omega_N^{-k}O_k$ (мұнда $E$, $O$ - $M$ периодты).
    3. $k+M$ үшін: $E_{k+M}=E_k$, $O_{k+M}=O_k$, ал $\omega_N^{-(k+M)}=-\omega_N^{-k}$ ($\omega_N^{M}=e^{i\pi}=-1$). Демек $X_{k+M}=E_k-\omega_N^{-k}O_k$.
    4. Күрделілік: $T(N)$ - кешенді көбейту саны. $T(N)=2T\left(\frac N2\right)+\frac N2$ ($\frac N2$ «бұралу» көбейткіші $\omega_N^{-k}O_k$), $T(1)=0$.
    5. $N=2^p$: $\frac{T(2^p)}{2^p}=\frac{T(2^{p-1})}{2^{p-1}}+\frac12$, демек $\frac{T(N)}N=\frac p2$, $T(N)=\frac N2\log_2N$. Қосулар да $N\log_2N$. ∎

    ∎

    Қадамдық шешілген мысалдар

    Мысал 1. Қарапайым ДФТ

    $N=4$: $x=(1,0,0,0)$, $x=(1,1,1,1)$, $x=(0,1,0,-1)$.

    1. 1-қадам. $\omega=i$; $\omega^{-k}$: $1,-i,-1,i$.
    2. 2-қадам. $(1,0,0,0)$: $X_k=x_0=1$ - барлық жиілік бірдей: $(1,1,1,1)$ («импульс - ақ спектр»).
    3. 3-қадам. $(1,1,1,1)$: $X_0=4$, қалғаны $\sum_n\omega^{-kn}=0$ - тұрақты сигнал тек $k=0$-де.
    4. 4-қадам. $(0,1,0,-1)$ - бұл $\sin\frac{2\pi n}4$: $X_k=\omega^{-k}-\omega^{-3k}$; $X_0=0$, $X_1=-i-i=-2i$, $X_2=-1-(-1)=0$, $X_3=i-(-i)=2i$.
    5. 5-қадам. Тексеру: $X_3=\overline{X_1}$ ✓ (нақты сигнал); Парсеваль: $\sum|x|^2=2$, $\frac14(4+4)=2$ ✓.

    Жауабы: $(1,1,1,1)$; $(4,0,0,0)$; $(0,-2i,0,2i)$.

    Мысал 2. Кері ДФТ

    $N=4$, $X=(2,0,2,0)$. $x=?$

    1. 1-қадам. $x_n=\frac14\sum_kX_k\omega^{kn}=\frac14(2+2\cdot\omega^{2n})=\frac12(1+(-1)^n)$.
    2. 2-қадам. $x=(1,0,1,0)$.
    3. 3-қадам. Тексеру: $X_0=1+1=2$ ✓; $X_2=\sum x_n(-1)^n=1+1=2$ ✓.

    Жауабы: $x=(1,0,1,0)$.

    Мысал 3. Бүркемелену

    $f(x)=\cos5x$, $N=4$ нүктеде өлшенеді. ДФТ қай жиілікті «көрсетеді»?

    1. 1-қадам. $\cos5x=\frac12(e^{5ix}+e^{-5ix})$: $c_5=c_{-5}=\frac12$.
    2. 2-қадам. Формула: $\frac{X_k}4=\sum_mc_{k+4m}$. $5=1+4$, $-5=3-8$: $\frac{X_1}4=c_5=\frac12$, $\frac{X_3}4=c_{-5}=\frac12$.
    3. 3-қадам. $X=(0,2,0,2)$ - бұл $\cos x$-тің ДФТ-сымен дәл бірдей!
    4. 4-қадам. Шынында $\cos\frac{5\cdot2\pi n}{4}=\cos\left(\frac{2\pi n}4+2\pi n\right)=\cos\frac{2\pi n}{4}$: 4 нүктеде $\cos5x$ пен $\cos x$ ажыратылмайды. Найквист шарты $5<\frac N2$ бұзылған.

    Жауабы: $\cos x$ сияқты көрінеді.

    Мысал 4. Көпмүшелерді көбейту

    $p=1+2z$, $q=3+z$: $pq$ коэффициенттерін ДФТ арқылы табу.

    1. 1-қадам. Нәтиженің дәрежесі $2$, 3 коэффициент - $N=4$ ұзындыққа нөлдермен толықтырамыз: $a=(1,2,0,0)$, $b=(3,1,0,0)$.
    2. 2-қадам. $A_k=1+2\omega^{-k}$: $(3,1-2i,-1,1+2i)$; $B_k=3+\omega^{-k}$: $(4,3-i,2,3+i)$.
    3. 3-қадам. $A_kB_k$: $(12,(1-2i)(3-i),-2,(1+2i)(3+i))=(12,1-7i,-2,1+7i)$.
    4. 4-қадам. Кері ДФТ: $c_n=\frac14\sum_kA_kB_k\omega^{kn}$: $c_0=\frac{12+1-7i-2+1+7i}4=3$, $c_1=\frac{12+(1-7i)i+2+(1+7i)(-i)}4=\frac{12+7+2+7}{4}=7$, $c_2=\frac{12-(1-7i)-2-(1+7i)}{4}=2$, $c_3=0$.
    5. 5-қадам. $pq=3+7z+2z^2$. Тексеру: $(1+2z)(3+z)=3+z+6z+2z^2$ ✓.

    Жауабы: $3+7z+2z^2$.

    Жиі қателер

    • Кері ДФТ-да $\frac1N$-ді ұмыту → $x_n=\frac1N\sum X_k\omega^{kn}$
      Неге қате: $\overline{F}F=NI$.
    • $X_k$ мен $X_{-k}$ тәуелсіз (нақты сигнал) → $X_{N-k}=\overline{X_k}$
      Неге қате: симметрия.
    • ДФТ кез келген жиілікті дұрыс көрсетеді → Найквист: $|j|<\frac N2$
      Неге қате: бүркемелену.
    • Көпмүшелерді нөлдерсіз көбейту → ұзындық $\ge$ нәтиже коэффициенттерінің саны
      Неге қате: айналмалы «оралу».
    • FFT кез келген $N$ үшін бірдей тиімді → $N=2^p$ ең қарапайым
      Неге қате: басқа $N$ үшін басқа нұсқалары бар.
    • $k>\frac N2$ - жоғары жиілік → шын мәнінде $k-N$ (теріс жиілік)
      Неге қате: периодтылық.

    Визуализация

    Бақылаңыз: $N$ - өлшеу нүктелерінің саны ($x_n=\frac{2\pi n}N$), сатылы сызық - өлшенген мәндер. Екі тербеліс әртүрлі, бірақ әр $x_n$ нүктесінде мәндері бірдей - ДФТ оларды ажырата алмайды. $N$-ді арттырсаңыз да, $k+N$ жиілік сол $N$ үшін әрдайым «бүркенеді»; тек сигналдың ең жоғары жиілігі $\frac N2$-ден кіші болғанда ғана өлшеу оны дәл сипаттайды.

    Бақылаңыз: Көлденең ось - $N$. $N=1024$ кезінде $N^2\approx1{,}05\cdot10^6$ (графиктен тыс), ал $N\log_2N=10240$. Айырма $N$ өскен сайын ұлғаяды: $\frac{N^2}{N\log_2N}=\frac{N}{\log_2N}$.

FFT - XX ғасырдың ең маңызды алгоритмдерінің бірі: дыбыс пен суретті сығу (MP3, JPEG-те косинус нұсқасы), спектр анализаторлары, радиолокация, МРТ суретін қалпына келтіру, Wi-Fi және 4G/5G (OFDM - әр арна бір жиілік), үлкен сандарды көбейту, дифференциалдық теңдеулерді спектрлік әдіспен шешу. Python: numpy.fft.fft.

    Мини-жоба: «FFT-ны өзің жаз». Тікелей ДФТ мен рекурсиялық FFT-ны жазып, нәтижелерін салыстырамыз, уақытын өлшейміз, сосын FFT арқылы екі көпмүшені көбейтеміз және бүркемеленуді көреміз.

    import cmath, math, time

def dft(x):
    N = len(x)
    return [sum(x[n] * cmath.exp(-2j * math.pi * k * n / N) for n in range(N)) for k in range(N)]

def fft(x):
    N = len(x)
    if N == 1:
        return [x[0]]
    E, O = fft(x[0::2]), fft(x[1::2])
    out = [0] * N
    for k in range(N // 2):
        t = cmath.exp(-2j * math.pi * k / N) * O[k]
        out[k], out[k + N // 2] = E[k] + t, E[k] - t
    return out

def ifft(X):
    N = len(X)
    return [v.conjugate() / N for v in fft([v.conjugate() for v in X])]

x = [math.sin(2 * math.pi * 3 * n / 64) + 0.5 * math.cos(2 * math.pi * 10 * n / 64) for n in range(64)]
X1, X2 = dft(x), fft(x)
print("max|DFT - FFT| =", f"{max(abs(a - b) for a, b in zip(X1, X2)):.1e}")
print("үлкен коэффициенттер:", [(k, round(abs(v), 2)) for k, v in enumerate(X2) if abs(v) > 1])

for N in (256, 1024):
    y = [math.cos(n) for n in range(N)]
    t0 = time.perf_counter(); dft(y); t1 = time.perf_counter(); fft(y); t2 = time.perf_counter()
    print(f"N = {N}: ДФТ {t1 - t0:.3f} с, FFT {t2 - t1:.4f} с")

# Көпмүшелерді көбейту: (1 + 2z)(3 + z) және (1 + z)^7
def polymul(p, q):
    n = 1
    while n < len(p) + len(q) - 1:
        n *= 2
    P, Q = fft(p + [0] * (n - len(p))), fft(q + [0] * (n - len(q)))
    return [round(v.real) for v in ifft([a * b for a, b in zip(P, Q)])][: len(p) + len(q) - 1]

print(polymul([1, 2], [3, 1]), polymul([1, 1, 1, 1], [1, 1, 1, 1, 1]))
