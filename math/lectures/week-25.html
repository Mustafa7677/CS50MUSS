    4 · Дифференциалдық есептеу · 5-сабақ

    Дифференциалдау ережелері

    Бұл сабақта анықтамадан әр рет шек есептеудің орнына, туындыны ережелер бойынша тез табуды үйренесіз: қосынды, көбейтінді және бөлінді туындыларын, тригонометриялық функциялардың туындыларын және жоғары ретті туындыларды. Әр ереженің дәлелдеуін де өзіңіз қайталайсыз.

    ПәндерФормулаларСөздікЖаттықтырғыш
    Курс туралы

    Бұл сабақтың мазмұны жасанды интеллект көмегімен дайындалған, сондықтан математик-оқытушымен тексеріп алған жөн. Бұл ресми емтихан не куәлік баламасы емес.

    Сабақ мақсаттары

    Сабақ соңында сіз мыналарды істей аласыз:

    • қосынды, тұрақты көбейткіш, көбейтінді және бөлінді туындыларының ережелерін дәлелдеп, қолдану;
    • көпмүшелік, рационал және тригонометриялық өрнектердің туындысын қателіксіз табу;
    • $\tan x$, $\cot x$, $\sec x$, $\csc x$ функцияларының туындыларын қорытып шығару;
    • жоғары ретті туындыларды есептеп, $n$-ші туындының заңдылығын (индукциямен) көрсету;
    • көбейтіндінің $n$-ші ретті туындысына арналған Лейбниц формуласын қолдану;
    • туындыны Python-да символдық түрде есептейтін шағын бағдарлама жазу.

    Алғышарттар

    Бұл сабаққа алдыңғы туынды анықтамасы және геометриялық мағынасы (негізгі функциялардың туындылары, дифференциалдану ⇒ үзіліссіздік), сонымен қатар шектерді есептеу тәсілдері қажет. Алгебралық түрлендірулер үшін 1. Жоғары математикаға дайындық пәнінен көпмүшеліктер (3-сабақ) және тригонометриялық теңбе-теңдіктер (6-сабақ) керек.

    Интуиция: күрделі өрнекті кірпіштерден құрау

    Алдыңғы сабақта $x^2$, $\sin x$, $\ln x$ сияқты бірнеше «кірпіштің» туындысын анықтамадан шығардық. Бірақ нақты есептерде функциялар олардың қосындысы, көбейтіндісі және бөлінділері түрінде кездеседі: $x^2\sin x$, $\dfrac{e^x}{x^2+1}$, $\dfrac{x}{\ln x}$. Әр жолы айырымдық қатынасты жазып, шекке көшу мүмкін емес, ол өте ұзақ болар еді. Бізге «кірпіш» туындыларынан «үй» туындысын құрайтын ережелер қажет.

    Қарапайым мысал: екі тіктөртбұрышты бір-біріне көбейтіп, ауданын қарастырайық. Тіктөртбұрыштың ұзындығы $f(t)$, ені $g(t)$ уақытқа тәуелді өзгерсін; ауданы $S=f\cdot g$. Уақыт $\Delta t$ өткенде ұзындық $\Delta f$, ені $\Delta g$ өзгереді. Ауданның өсімшесі $\Delta S=f\,\Delta g+g\,\Delta f+\Delta f\,\Delta g$, соңғы мүше өте кіші (екі шексіз аз шаманың көбейтіндісі). Сондықтан ауданның өзгеру жылдамдығы $S'=f\,g'+g\,f'$. Көбейтінді ережесі осыдан шығады: екі көбейткіштің әрқайсысы өзгеріп жатыр, ал өзгерістердің әрқайсысы екіншісін «өзімен бірге» тасымалдайды.

    Бұл сурет «көбейтіндінің туындысы туындылардың көбейтіндісі емес» деген кең тараған қатені түсіндіреді. Егер ұзындық пен ен екеуі де бірқалыпты өссе, ауданның өсу жылдамдығы екі жылдамдықтың көбейтіндісі ($f'g'$) емес, әрқайсысын екіншісінің өзіне көбейтіп қосу ($f'g+fg'$). Бөлінді ережесі де осыдан шығады, бірақ оның түрі күрделірек: бөлшектің мәні алымның өсуімен өседі және бөлгіштің өсуімен кемиді, сондықтан формулада минус таңбасы бар.

    Қосындыға келсек, бәрі қарапайым: екі бағанның ұзындықтарының қосындысы қосынды жылдамдықпен өседі. Ал тұрақты көбейткіш өзгеріс жылдамдығын сол есе үлкейтеді: цехтың шығыны 3 есе көп болса, шығыс өсімі де 3 есе көп. Мұның барлығы «сызықтық» қасиет деп аталады: туындыны алу амалы қосындыны қосындыға, тұрақты көбейткішті тұрақты көбейткішке айналдырады.

    Қосымша, бағдарламалаушылар үшін: бұл ережелер символдық дифференциалдау жүйелерінің (Mathematica, SymPy сияқты) негізі. Бағдарлама өрнекті ағаш түрінде ұсынады (түйіндері: қосу, көбейту, бөлу, функциялар) және әр түйінге сәйкес ережені рекурсивті түрде қолданады. Сабақтың мини-жобасында осындай кішкентай дифференциалдағышты өзіңіз жазасыз.

    Анықтамалар мен теоремалар

    Теорема 5.1 · Сызықтық қасиет

    $f$ және $g$ функциялары $x$ нүктесінде дифференциалданса және $c$ - тұрақты болса, онда $$(c\,f)'=c\,f',\qquad (f\pm g)'=f'\pm g'.$$ Демек $(\alpha f+\beta g)'=\alpha f'+\beta g'$ кез келген тұрақтылар $\alpha,\beta$ үшін.

    Теорема 5.2 · Көбейтінді ережесі (Лейбниц)

    $$(f\cdot g)'=f'\cdot g+f\cdot g'.$$ Үш көбейткіш үшін: $(fgh)'=f'gh+fg'h+fgh'$.

    Теорема 5.3 · Бөлінді ережесі

    $g(x)\ne0$ болса, $$\left(\frac fg\right)'=\frac{f'g-fg'}{g^2},\qquad \left(\frac1g\right)'=-\frac{g'}{g^2}.$$

    Негіздеме. Қосынды мен көбейтіндінің дәлелдеуі 1-2 қорытуда, бөлінді 3-қорытуда беріледі. Ережелердің шарты: $f$ және $g$ дифференциалданады; көбейтіндіде осыдан $f$-тің үзіліссіздігі қолданылады.

    Формула 5.1 · Туындылар кестесі (толықтырылған)
    $$\begin{aligned}&(x^n)'=nx^{n-1},\quad(\sin x)'=\cos x,\quad(\cos x)'=-\sin x,\\ &(\tan x)'=\frac1{\cos^2x},\quad(\cot x)'=-\frac1{\sin^2x},\\ &(e^x)'=e^x,\quad(a^x)'=a^x\ln a,\quad(\ln x)'=\frac1x,\quad(\log_ax)'=\frac1{x\ln a}\end{aligned}$$

    Тангенс пен котангенстің туындылары өз облыстарында ($\cos x\ne0$, $\sin x\ne0$) жарамды. $n$ - кез келген нақты сан болуы мүмкін, $x>0$ болғанда.

    Анықтама 5.1 · Жоғары ретті туынды

    $f'$ функциясының туындысы $f$ функциясының екінші ретті туындысы (second derivative): $f''=(f')'$. Жалпы $f^{(n)}=\left(f^{(n-1)}\right)'$ - $n$-ші ретті туынды. Белгілеулер: $\dfrac{d^2y}{dx^2}$, $\dfrac{d^ny}{dx^n}$.

    Теорема 5.4 · Лейбниц формуласы

    $f$ және $g$ функциялары $n$ рет дифференциалданса, $$(fg)^{(n)}=\sum_{k=0}^{n}\binom nk f^{(k)}\,g^{(n-k)}.$$ Мысалы, $(fg)''=f''g+2f'g'+fg''$.

    Негіздеме. Формула Ньютон биномына ұқсас ($\binom nk$ коэффициенттері); дәлелдеуі индукциямен 7-қорытуда.

    Есте сақта

    Бөлінді ережесінің алымындағы реті маңызды: $f'g-fg'$ (алымның туындысын бөлгішке көбейтіп, бөлгіштің туындысын алымға көбейтіп шегереміз). Тәсіл: «төменгі · жоғарғының туындысы − жоғарғы · төменгінің туындысы, бәрі төменгінің квадратына». Көбейтіндіде реті маңызды емес, бірақ екі қосылғыш болуы керек.

    Назар аудар

    $(f\cdot g)'\ne f'\cdot g'$ және $\left(\dfrac fg\right)'\ne\dfrac{f'}{g'}$. Мысал: $f=g=x$ болса, $(x\cdot x)'=2x$, ал $f'g'=1$. Сол сияқты $f=x^2$, $g=x$ болса, $\left(\frac{x^2}{x}\right)'=1$, ал $\frac{f'}{g'}=2x$.

    Формула 5.2 · Жоғары ретті туындылардың заңдылықтары
    $$(x^m)^{(n)}=\frac{m!}{(m-n)!}x^{m-n},\quad(e^{ax})^{(n)}=a^ne^{ax},\quad(\sin x)^{(n)}=\sin\!\left(x+\frac{n\pi}{2}\right),\quad\left(\frac1x\right)^{(n)}=\frac{(-1)^nn!}{x^{n+1}}$$

    Бірінші формулада $n\le m$ бүтін; $n>m$ болса, көпмүшеліктің $n$-ші туындысы 0. Косинус үшін $(\cos x)^{(n)}=\cos\left(x+\frac{n\pi}2\right)$.

    Туындыны есептеу алгоритмі. Алдымен өрнектің ең сыртқы амалын анықтаңыз: қосынды ма, көбейтінді ме, бөлінді ме? Сонан соң сол амалға сәйкес ережені қолданыңыз. Нәтижедегі ішкі функциялар үшін процесті қайталаңыз. Мысалы, $y=\dfrac{x^2\sin x}{1+x}$: сыртқы амал - бөлінді, алымы - көбейтінді. Тізбек: бөлінді ережесі, оның ішінде алымның туындысына көбейтінді ережесі. Әр қадамда жеткілікті көрнекілікпен жазу қателіктен сақтайды.

    Кейде ережені қолданбай, алдымен өрнекті ықшамдаған тиімді. $y=\dfrac{x^3-x}{x}$ өрнегін бөлінді ережесімен дифференциалдауға болады, бірақ $y=x^2-1$ деп ықшамдасақ, $y'=2x$ бірден шығады ($x\ne0$ болғанда). Дәл осылай $y=(x+1)^2$ өрнегін $x^2+2x+1$ деп жайсақ, $y'=2x+2$. Ережелер жалпы, ал ықшамдау есептеуді жеңілдетеді. Тек облысты ұмытпау керек: ықшамдау облысты өзгертпеуі тиіс.

    Типтік өрнектер және тиімді тәсіл

    Есеп шығарушының тәжірибесінде өрнектердің бірнеше «типі» қайталанады. Әр типке қолайлы тәсілді білу уақытты үнемдейді және қателікті азайтады. Төмендегі кесте ең жиі кездесетін жағдайларды жинақтайды.

    Өрнек түріМысалТәсіл
    көпмүшелік$3x^4-x+2$мүшелеп дифференциалдау
    қосылғыш-бөлшек$\frac{x^2+1}{x}$алдымен $x+\frac1x$ етіп бөлу
    екі функцияның көбейтіндісі$x^2e^x$көбейтінді ережесі

    Ең пайдалы әдеттердің бірі - бөлшекті мүшелеп бөлу. $y=\dfrac{x^3+2x}{x^2}$ өрнегін бөлінді ережесімен дифференциалдауға болады, бірақ $y=x+\dfrac2x$ деп жазсақ, $y'=1-\dfrac2{x^2}$ бірден шығады. Бөлгіші бір мүше болса, жиі осылай ықшамдаған тиімді. Бөлгіші қосынды болғанда ғана бөлінді ережесі шынымен қажет болады. Керісінше, көбейтіндіні жайып жазу қашан тиімді? Көбейткіштердің бірі көпмүшелік болса, мысалы $(x+1)(x+2)$, жайып жазған жеңіл; ал $x^2e^x$ сияқты әртүрлі табиғатты көбейткіштер үшін көбейтінді ережесі ғана жарайды.

    Нәтижені тексеру әдістері. Туындыны тапқаннан кейін оның дұрыстығын үш тәсілмен тексеруге болады. Біріншіден, кіші мән қою: $x=0$ немесе $x=1$ үшін бастапқы функцияның айырымдық қатынасын қолмен есептеп, нәтижемен салыстыру. Екіншіден, өлшемділік пен таңба тексеру: функция өсіп тұрған жерде туынды оң болуы керек. Үшіншіден, ерекше жағдайлар: бөлінді жағдайында бөлгіш нөл болатын нүктеде туынды мағынасыз болуы тиіс. Қағаз бетіндегі есептерде осы тексерулер қателіктің көп бөлігін ұстап алады.

    Қозғалыс мысалы. Дененің координатасы $s(t)=t^2e^{-t}$ емес, оңайырақ $s(t)=t\sin t$ болсын. Жылдамдық $v(t)=s'(t)=\sin t+t\cos t$, үдеу $a(t)=v'(t)=2\cos t-t\sin t$ (әр рет көбейтінді ережесі қолданылды). $t=\frac\pi2$ кезінде $v=1+0=1$, $a=0-\frac\pi2\approx-1{,}57$: дене оңға қарай қозғалып жатыр, бірақ жылдамдығы кеміп барады, себебі үдеу теріс. Мұндай есептерде жоғары ретті туындылардың физикалық мағынасы көрінеді: бірінші туынды - жылдамдық, екінші - үдеу, ал үшінші - «дүрсілдеу» (jerk), оны жолаушылар көлігінде жайлылықты бағалау үшін қолданады.

    Қорытып шығару

    Әр дәлелдеу алдыңғы сабақтағы анықтамаға және шектердің арифметикасына негізделеді. Көбейтіндінің дәлелдеуіндегі «қосып та, шегеріп те жіберу» айлаға көңіл аударыңыз: ол анализде жиі қолданылады.

    Қорытып шығару 1: қосынды мен тұрақты көбейткіштің туындысы

    Мақсат: $(cf)'=cf'$ және $(f+g)'=f'+g'$.

    1. Тұрақты көбейткіш. $\dfrac{cf(x+h)-cf(x)}{h}=c\cdot\dfrac{f(x+h)-f(x)}{h}$.
    2. Шектердің арифметикасы бойынша ($c$ тұрақты) шек $c\,f'(x)$.
    3. Қосынды. $\dfrac{[f(x+h)+g(x+h)]-[f(x)+g(x)]}{h}=\dfrac{f(x+h)-f(x)}{h}+\dfrac{g(x+h)-g(x)}{h}$.
    4. Екі қосылғыштың шегі бар (себебі $f$ және $g$ дифференциалданады), сондықтан қосындының да шегі бар және $f'+g'$-ке тең.
    5. Айырма. $f-g=f+(-1)g$ деп жазып, алдыңғы екі нәтижені қолданамыз.
    6. Салдар. Көпмүшелік $a_nx^n+\dots+a_1x+a_0$ үшін туынды $na_nx^{n-1}+\dots+a_1$ (тұрақты 0).

    ∎

    Қорытып шығару 2: көбейтіндінің туындысы

    Мақсат: $f,g$ дифференциалданса, $(fg)'=f'g+fg'$.

    1. Айырым. $f(x+h)g(x+h)-f(x)g(x)$.
    2. Көмекші мүше. $f(x+h)g(x)$-ті қосып та, шегеріп те жібереміз: $f(x+h)g(x+h)-f(x+h)g(x)+f(x+h)g(x)-f(x)g(x)$.
    3. Топтау. $=f(x+h)\,[g(x+h)-g(x)]+g(x)\,[f(x+h)-f(x)]$.
    4. $h$-ға бөлу. $f(x+h)\dfrac{g(x+h)-g(x)}{h}+g(x)\dfrac{f(x+h)-f(x)}{h}$.
    5. Шектер. $f$ дифференциалданатын болғандықтан үзіліссіз (Теорема 4.1): $f(x+h)\to f(x)$. Сондай-ақ айырымдық қатынастар $g'(x)$ және $f'(x)$-ке ұмтылады.
    6. Нәтиже. $(fg)'=f(x)g'(x)+g(x)f'(x)$.
    7. Үш көбейткіш. $(fgh)'=((fg)h)'=(fg)'h+fg\,h'=f'gh+fg'h+fgh'$.

    ∎

    Қорытып шығару 3: бөліндінің туындысы

    Мақсат: $g(x)\ne0$ болса, $(1/g)'=-g'/g^2$ және $(f/g)'=\dfrac{f'g-fg'}{g^2}$.

    1. Кері шама. $\dfrac{\frac1{g(x+h)}-\frac1{g(x)}}{h}=\dfrac{g(x)-g(x+h)}{h\,g(x)\,g(x+h)}$.
    2. Алымын $-[g(x+h)-g(x)]$ деп жазамыз: $-\dfrac{g(x+h)-g(x)}{h}\cdot\dfrac{1}{g(x)g(x+h)}$.
    3. Шек. Бірінші көбейткіш $-g'(x)$-ке, екінші $\dfrac{1}{g(x)^2}$-ге ұмтылады ($g$ үзіліссіз және $g(x)\ne0$). Нәтиже $\left(\dfrac1g\right)'=-\dfrac{g'}{g^2}$.
    4. Жалпы бөлінді. $\dfrac fg=f\cdot\dfrac1g$. Көбейтінді ережесі: $\left(f\cdot\frac1g\right)'=f'\cdot\frac1g+f\cdot\left(-\frac{g'}{g^2}\right)$.
    5. Ортақ бөлімге келтіреміз: $\dfrac{f'g}{g^2}-\dfrac{fg'}{g^2}=\dfrac{f'g-fg'}{g^2}$.
    6. Салдар. $n$ бүтін оң болса, $(x^{-n})'=\left(\dfrac1{x^n}\right)'=-\dfrac{nx^{n-1}}{x^{2n}}=-nx^{-n-1}$: дәреже ережесі теріс бүтін көрсеткішке де жарамды.

    ∎

    Қорытып шығару 4: тангенс, котангенс, секанс және косеканс туындылары

    Мақсат: бөлінді ережесінен $(\tan x)'$, $(\cot x)'$, $(\sec x)'$, $(\csc x)'$ шығару.

    1. $\tan x=\dfrac{\sin x}{\cos x}$: $(\tan x)'=\dfrac{\cos x\cdot\cos x-\sin x\cdot(-\sin x)}{\cos^2x}$.
    2. Алымы $\cos^2x+\sin^2x=1$. Демек $(\tan x)'=\dfrac{1}{\cos^2x}=1+\tan^2x$.
    3. $\cot x=\dfrac{\cos x}{\sin x}$: $(\cot x)'=\dfrac{-\sin x\cdot\sin x-\cos x\cdot\cos x}{\sin^2x}=-\dfrac{1}{\sin^2x}$.
    4. $\sec x=\dfrac1{\cos x}$: $(\sec x)'=-\dfrac{(\cos x)'}{\cos^2x}=\dfrac{\sin x}{\cos^2x}=\sec x\tan x$.
    5. $\csc x=\dfrac1{\sin x}$: $(\csc x)'=-\dfrac{\cos x}{\sin^2x}=-\csc x\cot x$.
    6. Облыс. $\tan x$ үшін $\cos x\ne0$, яғни $x\ne\frac\pi2+\pi k$; $\cot x$ үшін $x\ne\pi k$.

    ∎

    Қорытып шығару 5: көпмүшелікті үш жолмен дифференциалдау (сәйкестендіру)

    Мақсат: $y=(x^2+1)(3x-2)$ функциясының туындысын екі әдіспен тауып, нәтижелердің сәйкес келуін көрсету: ереженің дұрыстығын дербес мысалда тексеру.

    1. Көбейтінді ережесімен. $f=x^2+1$, $g=3x-2$. $f'=2x$, $g'=3$.
    2. $y'=f'g+fg'=2x(3x-2)+(x^2+1)\cdot3$.
    3. Ашамыз: $6x^2-4x+3x^2+3=9x^2-4x+3$.
    4. Жайып жазып. $y=3x^3-2x^2+3x-2$.
    5. Қосынды ережесімен әр мүшені дифференциалдаймыз: $y'=9x^2-4x+3$.
    6. Сәйкестік. Екі нәтиже бірдей, бұл көбейтінді ережесінің дұрыстығын растайды. Сандық тексеру: $y(1)=2\cdot1=2$, $y(1{,}001)=2{,}002001\cdot1{,}003=2{,}008007\ldots$; айырымдық қатынас $\dfrac{2{,}008007-2}{0{,}001}\approx8{,}007$, ал $y'(1)=9-4+3=8$.

    ∎

    Қорытып шығару 6: $(\sin x)^{(n)}$, $(e^{ax})^{(n)}$ және $(1/x)^{(n)}$ заңдылықтары

    Мақсат: жоғары ретті туындылардың заңдылықтарын индукциямен дәлелдеу.

    1. Синус. $n=1$: $(\sin x)'=\cos x=\sin\left(x+\frac\pi2\right)$. Дұрыс.
    2. Индукциялық өту. $(\sin x)^{(n)}=\sin\left(x+\frac{n\pi}{2}\right)$ болсын. Онда $(\sin x)^{(n+1)}=\cos\left(x+\frac{n\pi}2\right)=\sin\left(x+\frac{n\pi}2+\frac\pi2\right)=\sin\left(x+\frac{(n+1)\pi}2\right)$.
    3. Көрсеткіштік. $(e^{ax})'=ae^{ax}$ (келесі сабақтағы құрама функция ережесінен; $a=1$ үшін де бұрыннан белгілі). Индукциялық өту: $(e^{ax})^{(n+1)}=a\cdot a^ne^{ax}=a^{n+1}e^{ax}$.
    4. $1/x$. $n=0$: $\frac1x=\frac{(-1)^0\,0!}{x^1}$. Дұрыс.
    5. Болжам: $\left(\frac1x\right)^{(n)}=\dfrac{(-1)^nn!}{x^{n+1}}$. Дифференциалдаймыз: $(-1)^nn!\cdot\left(x^{-(n+1)}\right)'=(-1)^nn!\cdot(-(n+1))x^{-(n+2)}$.
    6. $=\dfrac{(-1)^{n+1}(n+1)!}{x^{n+2}}$: формула $n+1$ үшін де орындалады.
    7. Дәреже. $(x^m)^{(n)}=m(m-1)\cdots(m-n+1)x^{m-n}=\dfrac{m!}{(m-n)!}x^{m-n}$; $n=m$ болса, $m!$ тұрақты, келесі туынды 0.

    ∎

    Қорытып шығару 7: Лейбниц формуласы

    Мақсат: $(fg)^{(n)}=\sum_{k=0}^n\binom nkf^{(k)}g^{(n-k)}$ формуласын индукциямен дәлелдеу.

    1. База. $n=1$: $k=0$ және $k=1$ мүшелері $fg'+f'g$ береді: бұл көбейтінді ережесі.
    2. Болжам. $(fg)^{(n)}=\sum_{k=0}^n\binom nkf^{(k)}g^{(n-k)}$.
    3. Дифференциалдау. Әр қосылғыш үшін көбейтінді ережесі: $\left(f^{(k)}g^{(n-k)}\right)'=f^{(k+1)}g^{(n-k)}+f^{(k)}g^{(n-k+1)}$.
    4. Бөлек қосындылар. $\sum_{k=0}^n\binom nkf^{(k+1)}g^{(n-k)}+\sum_{k=0}^n\binom nkf^{(k)}g^{(n+1-k)}$. Біріншісінде индексті $j=k+1$ деп ауыстырамыз: $\sum_{j=1}^{n+1}\binom n{j-1}f^{(j)}g^{(n+1-j)}$.
    5. Біріктіру. $f^{(j)}g^{(n+1-j)}$ мүшесінің коэффициенті $\binom n{j-1}+\binom nj$ (шеткі мүшелерде тек біреуі бар).
    6. Паскаль сәйкестігі. $\binom n{j-1}+\binom nj=\binom{n+1}j$. Сонда $(fg)^{(n+1)}=\sum_{j=0}^{n+1}\binom{n+1}jf^{(j)}g^{(n+1-j)}$.
    7. Мысал. $(xe^x)^{(n)}$: $f=x$ ($f'=1$, $f''=0$), $g=e^x$ ($g^{(m)}=e^x$): тек $k=0,1$ қалады. $(xe^x)^{(n)}=x\,e^x+n\cdot1\cdot e^x=(x+n)e^x$.

    ∎

    Қадамдық шешілген мысалдар

    Мысал 1. Көбейтінді және қосынды ережесі

    $y=(x^2+1)(3x-2)$ және $y=x^3\ln x$ функцияларының туындыларын табыңыз.

    1. 1-қадам. Бірінші функцияда. $f=x^2+1$, $g=3x-2$, $f'=2x$, $g'=3$.
    2. 2-қадам. Көбейтінді ережесі. $y'=2x(3x-2)+(x^2+1)\cdot3=9x^2-4x+3$.
    3. 3-қадам. Екінші функцияда. $f=x^3$, $g=\ln x$: $f'=3x^2$, $g'=\frac1x$ ($x>0$).
    4. 4-қадам. Көбейтінді ережесі. $y'=3x^2\ln x+x^3\cdot\dfrac1x=3x^2\ln x+x^2$.
    5. 5-қадам. Ықшамдау. $y'=x^2(3\ln x+1)$.

    Жауабы: $9x^2-4x+3$; $x^2(3\ln x+1)$.

    Мысал 2. Бөлінді ережесі және жанама

    $y=\dfrac{x^2+1}{x-1}$ функциясының туындысын табыңыз және $x=2$ нүктесінде жанама теңдеуін жазыңыз.

    1. 1-қадам. Бөліктер. Алымы $f=x^2+1$, бөлгіші $g=x-1$: $f'=2x$, $g'=1$.
    2. 2-қадам. Ереже. $y'=\dfrac{2x(x-1)-(x^2+1)\cdot1}{(x-1)^2}$.
    3. 3-қадам. Алымды ықшамдау. $2x^2-2x-x^2-1=x^2-2x-1$. Демек $y'=\dfrac{x^2-2x-1}{(x-1)^2}$.
    4. 4-қадам. Нүктедегі мәндер. $y(2)=\dfrac{5}{1}=5$; $y'(2)=\dfrac{4-4-1}{1}=-1$.
    5. 5-қадам. Жанама. $y-5=-1\cdot(x-2)$, яғни $y=-x+7$.

    Жауабы: $y'=\dfrac{x^2-2x-1}{(x-1)^2}$; жанама $y=-x+7$.

    Мысал 3. Тригонометриялық функциялар

    (а) $y=x^2\sin x$; (ә) $y=\dfrac{\sin x}{1+\cos x}$; (б) $y=\tan x-x$ функцияларының туындыларын табыңыз.

    1. 1-қадам. (а). Көбейтінді ережесі: $y'=2x\sin x+x^2\cos x$.
    2. 2-қадам. (ә) Ереже. $f=\sin x$, $g=1+\cos x$: $f'=\cos x$, $g'=-\sin x$. $y'=\dfrac{\cos x(1+\cos x)-\sin x\cdot(-\sin x)}{(1+\cos x)^2}$.
    3. 3-қадам. (ә) Ықшамдау. Алымы $\cos x+\cos^2x+\sin^2x=\cos x+1$. Сондықтан $y'=\dfrac{1+\cos x}{(1+\cos x)^2}=\dfrac{1}{1+\cos x}$.
    4. 4-қадам. (б). $y'=\dfrac1{\cos^2x}-1=\dfrac{1-\cos^2x}{\cos^2x}=\tan^2x$.
    5. 5-қадам. Тексеру (б). $x$ нөлге жақын болса $\tan x\approx x+\frac{x^3}{3}$, сондықтан $\tan x-x\approx\frac{x^3}3$ және туынды $x^2\approx\tan^2x$. Сәйкес келеді.

    Жауабы: (а) $2x\sin x+x^2\cos x$; (ә) $\dfrac1{1+\cos x}$; (б) $\tan^2x$.

    Мысал 4. Жоғары ретті туынды және экстремум нүктесі

    $y=xe^x$ функциясының $y'$, $y''$ туындыларын және $y'=0$ болатын нүктені табыңыз; $y^{(n)}$ заңдылығын болжаңыз.

    1. 1-қадам. Бірінші туынды. Көбейтінді ережесі: $y'=e^x+xe^x=e^x(1+x)$.
    2. 2-қадам. Екінші туынды. $y''=e^x(1+x)+e^x\cdot1=e^x(x+2)$.
    3. 3-қадам. Үшінші туынды. $y'''=e^x(x+2)+e^x=e^x(x+3)$.
    4. 4-қадам. Заңдылық. $y^{(n)}=e^x(x+n)$ (7-қорытудағы Лейбниц формуласынан да осы шығады).
    5. 5-қадам. Көлденең жанама. $y'=0\iff e^x(1+x)=0\iff x=-1$ ($e^x>0$). $y(-1)=-e^{-1}\approx-0{,}368$.
    6. 6-қадам. Белгі. $y''(-1)=e^{-1}(1)>0$: бұл нүктеде функция ең кіші мәнге ие (келесі сабақтарда дәлелденеді).

    Жауабы: $y'=e^x(x+1)$, $y''=e^x(x+2)$, $y^{(n)}=e^x(x+n)$; көлденең жанама $x=-1$ нүктесінде.

    Жиі қателер

    • $(fg)'=f'g'$ → $(fg)'=f'g+fg'$
      Неге қате: $(x\cdot x)'=2x$, ал $f'g'=1$. Екі көбейткіш те өзгереді және екі үлес қосылады.
    • $\left(\dfrac fg\right)'=\dfrac{f'}{g'}$ не $\dfrac{f'g+fg'}{g^2}$ → $\dfrac{f'g-fg'}{g^2}$
      Неге қате: $\frac{x^2}{x}=x$ болса, туынды 1; $\frac{f'}{g'}=2x$ қате. Алымдағы минус және ретті ұмытпаңыз.
    • $(3x^2)'=3\cdot2x$ деп жазып, келесі қадамда $3$-ті жоғалту: $(3x^2)'=2x$ → $6x$
      Неге қате: тұрақты көбейткіш туындыда сақталады (Теорема 5.1).
    • $(5)'=5$ не $(\pi x)'=\pi$ деп $\pi$-ді жоғалту → $(5)'=0$, $(\pi x)'=\pi$ (тұрақты көбейткіш), $(\pi^2)'=0$
      Неге қате: $\pi$ - сан, айнымалы емес. Тұрақтының туындысы 0, көбейткіш ретінде сақталады.
    • $(\tan x)'=\sec x$ не $\tan^2x$ → $(\tan x)'=\dfrac{1}{\cos^2x}=1+\tan^2x$
      Неге қате: бөлінді ережесінен алым $\cos^2x+\sin^2x=1$ шығады; $\tan^2x$ - тек $\tan x-x$ туындысы.
    • $(a^x)'=x\,a^{x-1}$ → $(a^x)'=a^x\ln a$
      Неге қате: айнымалы көрсеткіште, дәреже ережесі қолданылмайды.
    • Көбейтіндіні алдымен жайып жазбай-ақ екінші рет дифференциалдау: $((x^2+1)(x+3))''=2x\cdot1$ → $y'=3x^2+6x+1$, $y''=6x+6$
      Неге қате: екінші туынды - бірінші туындының туындысы; көбейтінді ережесін екі рет қолдану не жайып жазу керек.
    • Облысты ескермеу: $y=\dfrac{x^2-1}{x-1}=x+1$, $y'=1$ деп $x=1$ нүктесінде де туынды бар деу → $y'=1$ тек $x\ne1$ үшін
      Неге қате: ықшамдағанда облыс өзгермейді; $x=1$ нүктесінде функция анықталмаған.

    Визуализация

    Төмендегі суреттер функция графигі мен оның туындысы графигінің байланысын, сондай-ақ жанаманы көрсетеді.

    Бақылаңыз: $f'$ графигі нөлден өтетін $x=\pm1$ нүктелерінде $f$ графигінде төбе (максимум) мен шұңқыр (минимум) бар. $f'>0$ болатын $|x|>1$ аралықтарында $f$ өседі; $f'<0$ болатын $(-1;1)$-де кемиді. $f''=6x$ нөлден өтетін $x=0$ нүктесінде $f$ графигінің қисаюы өзгереді (иілу нүктесі).

    Бақылаңыз: $x_0=-1$ болғанда жанама көлденең, $f'(-1)=0$ (4-мысал). $x_0$ оңға жылжығанда жанама тіктеп, еңіс $e^{x_0}(1+x_0)$ өсіп барады.

    Бақылаңыз: $\tan x$ әрдайым өседі (туындысы $\frac1{\cos^2x}\ge1>0$). Туынды нөлде ең кіші мәнін алады (1), ал асимптоталарға жақындағанда шексіз үлкейеді: график тіктеп бара жатады.

    20. Қадамдық шешім: жанасу шарты

    Бұл есепті «Кеңес» және «Келесі қадам» батырмаларымен біртіндеп ашып оқыңыз. Алдымен өзіңіз шешіп көріңіз.

    Қолданыс және мини-жоба

    Қолданыс. Дифференциалдау ережелері кез келген есептеу жүйесінің ішкі құрылымы. Автоматты дифференциалдау (Automatic Differentiation) машиналық оқытудағы терең нейрондық желілердің оқытылуын қамтамасыз етеді: желі көптеген қарапайым функциялардың құрамасы, ал бағдарлама әр қарапайым амалдың туындысын көбейтінді мен тізбек ережелерімен автоматты түрде біріктіреді. Физикада және инженерияда күрделі формулалардың өзгеру жылдамдығын (қозғалыс жылдамдығы, ағын, қуат) осы ережелермен табады. Экономикада орташа шығын $\frac{C(q)}{q}$ бөлінді ретінде қаралады: оның минимумы $C'(q)q=C(q)$ шартымен анықталады, яғни шекті шығын орташа шығынға тең болғанда орташа шығын ең аз болады.

    Мини-жоба: «Символдық дифференциалдағыш». Бағдарлама өрнекті кортеж-ағаш түрінде сақтайды және қосынды, көбейтінді, бөлінді, дәреже ережелерін, сондай-ақ $\sin x$, $\cos x$, $e^x$, $\ln x$ туындыларын рекурсивті қолданады. Нәтижені айырымдық қатынаспен тексереді.

    import math

# Өрнек ағашы: ("c", сан), ("x",), ("add", a, b), ("mul", a, b),
# ("div", a, b), ("pow", n) = x**n, ("sin",), ("cos",), ("exp",), ("ln",)  (аргументі x)

def d(e):
    t = e[0]
    if t == "c":   return ("c", 0)
    if t == "x":   return ("c", 1)
    if t == "add": return ("add", d(e[1]), d(e[2]))
    if t == "mul": return ("add", ("mul", d(e[1]), e[2]), ("mul", e[1], d(e[2])))
    if t == "div": # (f'g - f g') / g^2
        f, g = e[1], e[2]
        num = ("add", ("mul", d(f), g), ("mul", ("c", -1), ("mul", f, d(g))))
        return ("div", num, ("mul", g, g))
    if t == "pow": return ("mul", ("c", e[1]), ("pow", e[1] - 1))
    if t == "sin": return ("cos",)
    if t == "cos": return ("mul", ("c", -1), ("sin",))
    if t == "exp": return ("exp",)
    if t == "ln":  return ("div", ("c", 1), ("x",))
    raise ValueError(t)

def ev(e, x):
    t = e[0]
    if t == "c":   return e[1]
    if t == "x":   return x
    if t == "add": return ev(e[1], x) + ev(e[2], x)
    if t == "mul": return ev(e[1], x) * ev(e[2], x)
    if t == "div": return ev(e[1], x) / ev(e[2], x)
    if t == "pow": return x ** e[1]
    if t == "sin": return math.sin(x)
    if t == "cos": return math.cos(x)
    if t == "exp": return math.exp(x)
    if t == "ln":  return math.log(x)

# f(x) = x^2 * sin(x) / (1 + x)
f = ("div", ("mul", ("pow", 2), ("sin",)), ("add", ("c", 1), ("x",)))
df = d(f)

h = 1e-6
for x in (0.5, 1.0, 2.0):
    numeric = (ev(f, x + h) - ev(f, x - h)) / (2 * h)
    print(x, ev(df, x), numeric)

    • Мен қосынды мен тұрақты көбейткіш ережелерін дәлелдей аламын.
    • Мен көбейтінді ережесін «қосып-шегеру» тәсілімен дәлелдей аламын.
    • Мен бөлінді ережесін қорытып шығарып, реті мен таңбасын дұрыс қолдана аламын.
    • Мен $\tan x$, $\cot x$ туындыларын бөлінді ережесінен шығара аламын.
    • Мен екінші және жоғары ретті туындыларды есептеп, заңдылықты индукциямен негіздей аламын.
    • Мен Лейбниц формуласын $n=2,3$ үшін жаза аламын.
    • Мен берілген өрнек үшін қай ережені қолдану қажет екенін алдын ала анықтай аламын.

    Қорытынды тест

    1. y = (x² + 1)(3x − 2) функциясының туындысы қандай?

    2x(3x − 2) + (x² + 1)·3 = 6x² − 4x + 3x² + 3 = 9x² − 4x + 3.

    2. y = x/(x + 1) функциясының туындысы қандай?

    [1·(x + 1) − x·1]/(x + 1)² = 1/(x + 1)².

    3. (tan x)' неге тең?

    (sin x/cos x)' = (cos²x + sin²x)/cos²x = 1/cos²x.

    4. y = x·eˣ үшін y'' неге тең?

    y' = eˣ(x + 1), y'' = eˣ(x + 1) + eˣ = eˣ(x + 2).

    5. (x² · x)' үшін көбейтінді ережесі қандай нәтиже береді?

    2x·x + x²·1 = 3x², және x³-тің туындысы да 3x².

    6. y = x ln x функциясы үшін y'(e) неге тең?

    y' = ln x + 1, y'(e) = 1 + 1 = 2.

    7. sin x функциясының 10-шы ретті туындысы x = π/2 нүктесінде неге тең?

    (sin x)⁽¹⁰⁾ = sin(x + 5π) = −sin x, x = π/2 үшін −1.

    8. Қай пікір қате?

    Бөлінді ережесі (f/g)' = (f'g − fg')/g². (f/g)' = f'/g' қате.
