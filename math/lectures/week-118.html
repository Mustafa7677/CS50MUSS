    Abstract Algebra · 1-сабақ

    Топтар және олардың негізгі қасиеттері

    Бүтін сандарды қосу, нөлден өзге нақты сандарды көбейту, шаршыны бұру, Рубик текшесін айналдыру - бұл әртүрлі амалдардың ортақ құрылымы бар. Әрқайсысында екі элементті біріктіріп үшіншісін аламыз, «ештеңе өзгертпейтін» элемент бар, және әр әрекетті кері қайтаруға болады.

    ⏱ Оқу ≈ 50 минЕсептер ≈ 1 сағТест ≈ 5 минБарлығы ≈ 2 сағ

    Осы ортақ қасиеттерді бөліп алып, оларды аксиома ретінде қабылдасақ, топ ұғымын аламыз. Топ - абстракт алгебраның басты нысаны: оның тілінде симметрия, криптография (Диффи-Хеллман, эллипстік қисықтар), кристаллография және бөлшектер физикасы сипатталады. Бұл сабақта топ аксиомаларын енгізіп, оларды мысалдар мен қарсы мысалдарда тексереміз, бірлік пен кері элементтің жалғыздығын, қысқарту заңын дәлелдейміз және элемент ретінің негізгі қасиеттерін аламыз.

    Курс туралы

    Бұл сабақтың мазмұны үшін жауапкершілікті курс авторы Sagid Mustafa өзіне алады. Қате немесе түсініксіз жер тапсаңыз, хабарлаңыз. Бұл курс ресми емтихан не куәлік баламасы емес.

    Бір сөйлеммен

    Топ - «қайтаруға болатын әрекеттер» жиыны: екі әрекетті қатарынан орындау тағы әрекет, «ештеңе істемеу» бар, әр әрекетті кері қайтаруға болады.

    Сабақ мақсаттары

    Сабақ соңында сіз мыналарды істей аласыз:

    • бинарлық амал мен топ анықтамасын тұжырымдап, берілген жиын мен амалдың топ екенін немесе емес екенін тексеру;
    • бірлік пен кері элементтің жалғыздығын, $(ab)^{-1}=b^{-1}a^{-1}$ ережесін және қысқарту заңын дәлелдеу;
    • $\mathbb Z_n$, $U(n)$, $GL_2(\mathbb R)$, үшбұрыштың симметриялар тобы мысалдарымен жұмыс істеу;
    • Кэли кестесін құрып, оның әр жолы мен бағанында әр элемент дәл бір рет кездесетінін түсіндіру;
    • элемент ретін анықтап, $a^n=e\iff\operatorname{ord}(a)\mid n$ және $\operatorname{ord}(a^k)=\frac{\operatorname{ord}(a)}{\gcd(k,\operatorname{ord}(a))}$ формуласын дәлелдеу;
    • абелдік және абелдік емес топтарды ажырату.

    Қысқаша еске салу

    Жиындар, бейнелеулер, эквиваленттік қатынас (дискретті математика). Бөлінгіштік, қалдықпен бөлу, ЕҮОБ, салыстырулар, модуль бойынша кері элемент (сандар теориясы, 1 және 3-сабақтар). Матрицаларды көбейту, анықтауыш (сызықтық алгебра).

    Алдымен оқыңыз

    • Discrete Mathematics · 3-сабақ: Қатынастар және функциялар

    Бұл сабақтар таныс болса, бірден бастай беріңіз. Толық реттілік: оқу жолы.

    Алдымен қолмен: сағат арифметикасы

    Формулаға дейін нақты сандармен ойнап көрейік. Әр қадамды өзіңіз де қағазда қайталаңыз.

    Сағатта $12$ сағат бар. Қазір $9$:00. $5$ сағаттан кейін, сосын тағы $10$ сағаттан кейін сағат неше болады? Қандай «қосу» кестесі шығады?

    1. $9+5=14$, бірақ сағатта $14-12=2$. Яғни $9+5\equiv2\pmod{12}$.
    2. $2+10=12\equiv0$: сағат $12$:00 (біз оны $0$ деп белгілейміз).
    3. Әр сағатқа «кері» бар: $9$ сағатты жою үшін $3$ сағат қосу жеткілікті ($9+3\equiv0$). $0$ - «ештеңе өзгертпейтін» қосу.
    4. Топтың барлық ережесі орындалды: $\{0,1,\dots,11\}$ қосу $\bmod12$ бойынша - $\mathbb Z_{12}$ тобы.

    Байқадыңыз ба? Топ - сандар, бұрулар не араластырулар болуы мүмкін; маңыздысы - элементтер емес, амалдың төрт ережесі.

    Интуиция

    Тең қабырғалы үшбұрышты өз орнына келтіретін қозғалыстар: $0°$, $120°$, $240°$ бұру және үш осьтен шағылыстыру - барлығы $6$. Екі қозғалысты қатарынан орындау тағы бір қозғалыс береді; «ештеңе істемеу» - бірлік; әр қозғалысты кері қайтаруға болады. Бұл - $6$ элементті топ. Бірақ «алдымен бұру, сосын шағылыстыру» мен «алдымен шағылыстыру, сосын бұру» әртүрлі нәтиже береді: топ амалы ауыстырымды болмауы мүмкін.

    Топ аксиомалары аз, бірақ олардан көп нәрсе шығады. Мысалы, $ax=b$ теңдеуінің әрдайым жалғыз шешімі бар: $x=a^{-1}b$. Сондықтан Кэли кестесінің (көбейту кестесінің) әр жолында әр элемент дәл бір рет кездеседі - судоку сияқты.

    Элементтің реті - оны неше рет «қайталағанда» бірлікке ораламыз. $\mathbb Z_{12}$-да ($12$ сағаттық сағат) $4$-ті қосу: $4,8,0$ - реті $3$. Ал $5$: $5,10,3,8,\dots$ - тек $12$ қадамнан кейін $0$-ге оралады, реті $12$. Айырмашылық $\gcd$-те: $\frac{12}{\gcd(4,12)}=3$, $\frac{12}{\gcd(5,12)}=12$.

    Аксиомалардың әрқайсысы маңызды. $(\mathbb N,+)$-та кері элемент жоқ; $(\mathbb Z,-)$ ассоциативті емес: $(5-3)-1\ne5-(3-1)$; $\{1,2,3,4,5\}$ жиыны $6$ бойынша көбейтуге тұйық емес: $2\cdot3\equiv0$. Мұндай мысалдар анықтаманың әр шартын неге жазатынымызды көрсетеді.

    Өмірден ұқсастық · Рубик текшесі

    Текшенің әр бұрауы - топтың элементі. Екі бұрауды қатарынан жасау - тағы бір бұрау; «ешнәрсе бұрамау» - бірлік; әр бұрауды кері бұрап жоюға болады. Бірақ ретінің маңызы бар: «алдымен оң жақ, сосын жоғары» мен «алдымен жоғары, сосын оң жақ» - әртүрлі нәтиже. Мұндай топ абелдік емес.

    Өмірден ұқсастық · киім кию

    $(ab)^{-1}=b^{-1}a^{-1}$: алдымен шұлық ($b$), сосын аяқ киім ($a$) кисеңіз, шешкенде алдымен аяқ киімді, сосын шұлықты шешесіз. Кері әрекеттер кері ретпен.

    Анықтамалар мен теоремалар

    Анықтама 1.1 · Топ

    $G$ жиынындағы бинарлық амал (binary operation) - бейнелеу $G\times G\to G$, $(a,b)\mapsto ab$. $(G,\cdot)$ - топ (group), егер: (G1) ассоциативтілік (associativity) $(ab)c=a(bc)$; (G2) бірлік элемент (identity element) $e$ бар: $ea=ae=a$; (G3) әр $a$-ның кері элемент (inverse element) $a^{-1}$ бар: $aa^{-1}=a^{-1}a=e$. Барлық $a,b$ үшін $ab=ba$ болса, топ абелдік топ (abelian group) деп аталады. $|G|$ - топтың реті (order) (элементтер саны).

    Қарапайым тілмен: Топ - амалы бар жиын: жақшаларды кез келген ретпен қоюға болады, «бейтарап» элемент бар, әр элементтің кері элементі бар.

    Анықтама 1.2 · Негізгі мысалдар

    $(\mathbb Z,+)$, $(\mathbb Q,+)$, $(\mathbb R^*,\cdot)$ - шексіз абелдік топтар. $\mathbb Z_n=\{0,\dots,n-1\}$ қосу $\bmod n$ бойынша - реті $n$. $U(n)=\{a\in\mathbb Z_n:\gcd(a,n)=1\}$ көбейту $\bmod n$ бойынша - реті $\varphi(n)$. $GL_2(\mathbb R)$ - анықтауышы нөл емес $2\times2$ матрицалар көбейту бойынша - абелдік емес. $D_3$ - тең қабырғалы үшбұрыштың $6$ симметриясы - абелдік емес.

    Қарапайым тілмен: Бүтін сандарды қосу, нөлсіз нақты сандарды көбейту, сағат арифметикасы - бәрі топ.

    Теорема 1.1 · Бірлік, кері элемент, қысқарту

    $G$ - топ. (1) Бірлік элемент жалғыз. (2) Әр элементтің кері элементі жалғыз. (3) $(ab)^{-1}=b^{-1}a^{-1}$, $(a^{-1})^{-1}=a$. (4) Қысқарту: $ab=ac\Rightarrow b=c$ және $ba=ca\Rightarrow b=c$.

    Қарапайым тілмен: «Ештеңе істемейтін» элемент біреу ғана, әр элементтің кері элементі де біреу; көбейтіндінің кері элементі - кері элементтердің көбейтіндісі кері ретпен.

    Негіздеме. (3)-тегі ретке назар: «алдымен шұлық, сосын аяқ киім» - шешкенде керісінше.

    Теорема 1.2 · Теңдеулер және Кэли кестесі

    $G$ - топ, $a,b\in G$. $ax=b$ теңдеуінің жалғыз шешімі $x=a^{-1}b$, $ya=b$ теңдеуінің жалғыз шешімі $y=ba^{-1}$. Демек ақырлы топтың Кэли кестесінің әр жолында және әр бағанында әр элемент дәл бір рет кездеседі.

    Қарапайым тілмен: $ax=b$ теңдеуінің әрдайым дәл бір шешімі бар; сондықтан Кэли кестесінің әр жолы мен бағанында әр элемент бір реттен кездеседі (судоку сияқты).

    Негіздеме. Кері тұжырым жалған: латын квадраты болатын кесте әрдайым ассоциативті амал бермейді.

    Анықтама 1.3 · Элемент реті

    $a\in G$, $a^0=e$, $a^{n+1}=a^na$, $a^{-n}=(a^{-1})^n$. $a^n=e$ болатын ең кіші $n\ge1$ - $a$-ның элемент реті (order of an element) $\operatorname{ord}(a)$; мұндай $n$ болмаса, $\operatorname{ord}(a)=\infty$. Аддитивті жазуда $a^n$ орнына $na$: $\mathbb Z_{12}$-да $\operatorname{ord}(4)=3$.

    Қарапайым тілмен: Элементтің реті - оны неше рет қайталағанда «ештеңе істемеуге» қайтатынымыз.

    Теорема 1.3 · Элемент ретінің қасиеттері

    $\operatorname{ord}(a)=n<\infty$. (1) $a^m=e\iff n\mid m$. (2) $a^i=a^j\iff i\equiv j\pmod n$; сондықтан $e,a,\dots,a^{n-1}$ әртүрлі. (3) $\operatorname{ord}(a^k)=\frac n{\gcd(k,n)}$. (4) Ақырлы топта әр элементтің реті ақырлы.

    Қарапайым тілмен: $a^m=e$ дәл $m$ реттің еселігі болғанда; $a$-ның дәрежесінің реті ретті ортақ бөлгішке бөлгенге тең.

    Негіздеме. Мысалы $\mathbb Z_{24}$-та $\operatorname{ord}(15)=\frac{24}{\gcd(15,24)}=8$.

    Теорема 1.4 · Квадраты бірлік топ

    $G$ топтың әр элементі үшін $a^2=e$ болса, $G$ - абелдік.

    Қарапайым тілмен: Әр элементті екі рет қолдансақ әрдайым бастапқы күйге қайтсақ, амал міндетті түрде ауыстырымды.

    Негіздеме. Кері тұжырым жалған: $\mathbb Z_3$ абелдік, бірақ $1+1\ne0$.

    Формула 1.1 · Топ аксиомалары
    $$(ab)c=a(bc),\quad ea=ae=a,\quad aa^{-1}=a^{-1}a=e$$

    Тұйықтық амалдың анықтамасында.

    Формула 1.2 · Көбейтіндінің кері элементі
    $$(ab)^{-1}=b^{-1}a^{-1}$$

    Рет ауысады.

    Формула 1.3 · Теңдеудің шешімі
    $$ax=b\iff x=a^{-1}b;\qquad ya=b\iff y=ba^{-1}$$

    Жалғыз шешім.

    Формула 1.4 · Элемент реті
    $$a^m=e\iff\operatorname{ord}(a)\mid m$$

    Қалдықпен бөлу арқылы.

    Формула 1.5 · Дәреженің реті
    $$\operatorname{ord}(a^k)=\frac{\operatorname{ord}(a)}{\gcd(k,\operatorname{ord}(a))}$$

    $\operatorname{ord}(a)<\infty$.

    Формула 1.6 · $U(n)$ реті
    $$|U(n)|=\varphi(n)$$

    $\gcd(a,n)=1$ болатын кластар.

    Есте сақта

    Жиын мен амалдың топ екенін тексеру реті: (0) тұйықтық - $a,b\in G\Rightarrow ab\in G$ (ең жиі ұмытылатын қадам); (1) ассоциативтілік - әдетте белгілі амалдан мұраланады (сандарды қосу/көбейту, матрицаларды көбейту, бейнелеулер композициясы), жаңа амал болса - тікелей есептеу; (2) бірлікті табыңыз - $ea=a$ теңдеуін $e$ бойынша шешіңіз; (3) әр элементтің кері элементін табыңыз және ол $G$-ға тиісті екенін тексеріңіз. Бір шарт бұзылса, қарсы мысал келтіру жеткілікті.

    Назар аудар

    Абелдік емес топтарда әдеттегі алгебра ережелері жарамайды: $(ab)^2=a^2b^2$ және $(ab)^{-1}=a^{-1}b^{-1}$ тек $ab=ba$ болғанда дұрыс. $GL_2(\mathbb R)$-да $A=\begin{pmatrix}1&1\\0&1\end{pmatrix}$, $B=\begin{pmatrix}1&0\\1&1\end{pmatrix}$ үшін $AB\ne BA$. Сондай-ақ $ab=ac\Rightarrow b=c$ (сол жақтан қысқарту) дұрыс, бірақ $ab=ca\Rightarrow b=c$ жалпы жағдайда жалған.

    Тоқта, ойлан

    Әрі қарай жүрмес бұрын, өзіңізді тексеріңіз: алдымен жауапты ойланыңыз, сосын ашыңыз.

    1. $(\mathbb Z,-)$ (бүтін сандар азайту амалымен) топ па?

    Жоқ: азайту ассоциативті емес: $(5-3)-1=1$, ал $5-(3-1)=3$.

    2. $\mathbb Z_{12}$-де $3$-тің реті қандай?

    $4$: $3+3+3+3=12\equiv0$, ал одан аз қосындылар $0$ емес.

    3. $U(10)=\{1,3,7,9\}$-да $3$-ке кері элемент қайсы?

    $7$: $3\cdot7=21\equiv1\pmod{10}$.

    4. Топтың Кэли кестесінде бір жолда бір элемент екі рет кездесуі мүмкін бе?

    Жоқ: $ax=ax'$ болса, қысқарту бойынша $x=x'$.

    Қорытып шығару

    Қорытып шығару 1: бірлік пен кері элементтің жалғыздығы

    Мақсат: Теорема 1.1 (1)-(2)-ні дәлелдеу.

    Идея: Екі бірлік болса, оларды бір-біріне көбейтеміз: бір жағынан $e$, бір жағынан $e'$ шығады. Кері элемент үшін де дәл солай - ассоциативтік көмектеседі.

    1. $e$ мен $e'$ - екі бірлік. $e'$ бірлік болғандықтан $ee'=e$; $e$ бірлік болғандықтан $ee'=e'$. Демек $e=e'$.
    2. $b$ мен $c$ - $a$-ның екі кері элементі: $ab=ba=e$, $ac=ca=e$.
    3. $b=be=b(ac)=(ba)c=ec=c$ - ассоциативтілік қолданылды.
    4. Сондықтан $a^{-1}$ белгісі дұрыс анықталған. ∎

    ∎

    Қорытып шығару 2: көбейтіндінің кері элементі және қысқарту

    Мақсат: Теорема 1.1 (3)-(4)-ті дәлелдеу.

    Идея: Үміткерді тексеру жеткілікті: $(ab)(b^{-1}a^{-1})$-ны жақшаларды ауыстырып есептесек, $e$ шығады; кері элемент жалғыз болғандықтан, бұл сол.

    1. $(ab)(b^{-1}a^{-1})=a(bb^{-1})a^{-1}=aea^{-1}=aa^{-1}=e$; дәл солай $(b^{-1}a^{-1})(ab)=e$.
    2. Кері элемент жалғыз (1-қорыту), демек $(ab)^{-1}=b^{-1}a^{-1}$.
    3. $aa^{-1}=a^{-1}a=e$ теңдігі $a$-ның $a^{-1}$-дің кері элементі екенін айтады: $(a^{-1})^{-1}=a$.
    4. Қысқарту: $ab=ac$ теңдігін солдан $a^{-1}$-ге көбейтеміз: $(a^{-1}a)b=(a^{-1}a)c$, $b=c$. Оңнан қысқарту - $a^{-1}$-ге оңнан көбейтіп. ∎

    ∎

    Қорытып шығару 3: теңдеулер және Кэли кестесі

    Мақсат: Теорема 1.2-ні дәлелдеу.

    Идея: Шешімді табу - екі жақты $a^{-1}$-ге көбейту. Жалғыздығы - қысқарту ережесі.

    1. Бар болуы: $x=a^{-1}b$ қойсақ, $ax=aa^{-1}b=b$.
    2. Жалғыздығы: $ax=ax'=b\Rightarrow x=x'$ (қысқарту).
    3. Кэли кестесінің $a$-жолы - $ax$ мәндері, $x\in G$. Әр $b$ үшін $ax=b$ дәл бір $x$-те орындалады, демек $b$ жолда дәл бір рет.
    4. Бағандар үшін - $ya=b$ теңдеуі. ∎

    ∎

    Қорытып шығару 4: элемент ретінің қасиеттері

    Мақсат: Теорема 1.3-ті дәлелдеу, $n=\operatorname{ord}(a)$.

    Идея: $m$-ді $n$-ге қалдықпен бөлеміз: $a^m=a^r$, ал $r<n$, сондықтан $a^r=e$ тек $r=0$ болғанда.

    1. (1) $m=qn+r$, $0\le r<n$ (қалдықпен бөлу). $a^m=(a^n)^qa^r=a^r$. Демек $a^m=e\iff a^r=e\iff r=0$ ($n$ - ең кіші оң дәреже).
    2. (2) $a^i=a^j\iff a^{i-j}=e\iff n\mid i-j$ ((1)-ден).
    3. (3) $d=\gcd(k,n)$. $(a^k)^m=e\iff n\mid km\iff\frac nd\mid\frac kd m\iff\frac nd\mid m$, себебі $\gcd(\frac nd,\frac kd)=1$ (Евклид леммасы). Ең кіші оң $m=\frac nd$.
    4. (4) $|G|=N$ ақырлы: $a,a^2,\dots,a^{N+1}$ ішінде қайталау бар, $a^i=a^j$, $i<j$; онда $a^{j-i}=e$. ∎

    ∎

    Қорытып шығару 5: квадраты бірлік топ абелдік

    Мақсат: Теорема 1.4-ті дәлелдеу.

    Идея: $a=a^{-1}$ барлық элемент үшін. Сонда $ab=(ab)^{-1}=b^{-1}a^{-1}=ba$.

    1. $a^2=e$ болса, $a=a^{-1}$ (екі жақты $a^{-1}$-ге көбейтеміз).
    2. $a,b\in G$: $ab$ да $G$-ның элементі, демек $(ab)^{-1}=ab$.
    3. Теорема 1.1 (3): $(ab)^{-1}=b^{-1}a^{-1}=ba$.
    4. Сонымен $ab=ba$. ∎ Мысал: $U(8)=\{1,3,5,7\}$, барлық квадраттар $\equiv1\pmod8$.

    ∎

    Қадамдық шешілген мысалдар

    Мысал 1. $U(10)$ тобы

    $U(10)$ элементтері, Кэли кестесі және элементтердің реттері.

    1. 1-қадам. $\gcd(a,10)=1$: $U(10)=\{1,3,7,9\}$, $|U(10)|=\varphi(10)=4$.
    2. 2-қадам. Көбейту $\bmod10$: $3\cdot3=9$, $3\cdot7=21\equiv1$, $3\cdot9=27\equiv7$, $7\cdot7=49\equiv9$, $7\cdot9=63\equiv3$, $9\cdot9=81\equiv1$.
    3. 3-қадам. Реттер: $\operatorname{ord}(1)=1$; $3\to9\to7\to1$: $\operatorname{ord}(3)=4$; $\operatorname{ord}(7)=4$; $\operatorname{ord}(9)=2$.
    4. 4-қадам. $3$-тің дәрежелері бүкіл топты береді - топ циклдік (2-сабақ). $3^{-1}=7$.

    Жауабы: $\{1,3,7,9\}$; реттер $1,4,4,2$.

    Мысал 2. Дәреженің реті

    $\mathbb Z_6$-да $4$-тің реті.

    1. 1-қадам. Аддитивті топ: $4$, $4+4=8\equiv2$, $2+4=6\equiv0$.
    2. 2-қадам. Үш қадам: $\operatorname{ord}(4)=3$.
    3. 3-қадам. Формуламен: $4=4\cdot1$, $\operatorname{ord}(1)=6$, $\frac6{\gcd(4,6)}=\frac62=3$ ✓.

    Жауабы: $3$.

    Мысал 3. Абелдік емес топ

    $GL_2(\mathbb R)$-да $A=\begin{pmatrix}1&1\\0&1\end{pmatrix}$, $B=\begin{pmatrix}1&0\\1&1\end{pmatrix}$.

    1. 1-қадам. $\det A=\det B=1\ne0$ - екеуі де топта.
    2. 2-қадам. $AB=\begin{pmatrix}2&1\\1&1\end{pmatrix}$, $BA=\begin{pmatrix}1&1\\1&2\end{pmatrix}$.
    3. 3-қадам. $AB\ne BA$ - топ абелдік емес.
    4. 4-қадам. $(AB)^{-1}=B^{-1}A^{-1}=\begin{pmatrix}1&0\\-1&1\end{pmatrix}\begin{pmatrix}1&-1\\0&1\end{pmatrix}=\begin{pmatrix}1&-1\\-1&2\end{pmatrix}$; тексеру $(AB)(AB)^{-1}=I$ ✓.

    Жауабы: $AB\ne BA$.

    Мысал 4. Жаңа амал

    $G=\mathbb R\setminus\{-1\}$, $a*b=a+b+ab$. Топ па?

    1. 1-қадам. Тұйықтық: $a*b+1=(a+1)(b+1)\ne0$, демек $a*b\ne-1$ ✓.
    2. 2-қадам. Ассоциативтілік: $(a*b)*c+1=(a+1)(b+1)(c+1)=a*(b*c)+1$ ✓.
    3. 3-қадам. Бірлік: $a*e=a\iff e(1+a)=0\iff e=0$ ✓.
    4. 4-қадам. Кері: $a*x=0\iff x=-\frac a{1+a}$, ол $-1$-ге тең емес ✓. Абелдік: $a*b=b*a$.

    Жауабы: Абелдік топ.

    Мысал 5. Топ емес

    (а) $(\mathbb N,+)$; (ә) $(\mathbb Z,-)$; (б) $\{1,\dots,5\}$, көбейту $\bmod6$.

    1. 1-қадам. (а) $0$-ді қоссақ та ($\mathbb N_0$), $1$-дің кері элементі $-1\notin\mathbb N_0$ - G3 бұзылады.
    2. 2-қадам. (ә) $(5-3)-1=1$, $5-(3-1)=3$ - ассоциативті емес.
    3. 3-қадам. (б) $2\cdot3=6\equiv0\notin\{1,\dots,5\}$ - тұйық емес. Дұрысы - $U(6)=\{1,5\}$.

    Жауабы: Үшеуі де топ емес.

    Жиі қателер

    • Тұйықтықты тексермеу → $a,b\in G\Rightarrow ab\in G$
      Неге қате: $\{1,\dots,5\}$, $\bmod6$.
    • $(ab)^{-1}=a^{-1}b^{-1}$ → $b^{-1}a^{-1}$
      Неге қате: Абелдік емес топта қате.
    • $(ab)^2=a^2b^2$ әрдайым → тек $ab=ba$
      Неге қате: $GL_2(\mathbb R)$.
    • $ab=ca\Rightarrow b=c$ → тек бір жақтан қысқарту
      Неге қате: $a$ бір жақта тұруы тиіс.
    • $\operatorname{ord}(a^k)=\frac{\operatorname{ord}(a)}k$ → $\frac{\operatorname{ord}(a)}{\gcd(k,\operatorname{ord}(a))}$
      Неге қате: $\mathbb Z_{24}$, $15$: $8$.
    • $\mathbb Z_n\setminus\{0\}$ көбейту бойынша топ → тек $n$ жай болса
      Неге қате: дұрыс топ - $U(n)$.

    Визуализация

    Бақылаңыз: $k=0,1,2,\dots$ үшін $ka\bmod n$. Сатылар $0$-ге алғаш оралатын $k$ - $\operatorname{ord}(a)$. $a=4$, $n=12$: $0,4,8,0$ - реті $3=\frac{12}{\gcd(4,12)}$. $a=5$ қойыңыз: барлық $12$ мән өтеді, реті $12$. $a=6$: $0,6,0$ - реті $2$.

    Бақылаңыз: Бұл матрица жазықтықты $120°$-қа бұрады. Оны үш рет қолдансақ, бастапқы орынға ораламыз: $\operatorname{ord}=3$. Анықтауышы $1$ - $GL_2(\mathbb R)$-ның элементі. Тең қабырғалы үшбұрыштың алты симметриясы ($D_3$) осындай үш бұрудан және үш шағылыстырудан тұрады.

    Қолданыс және мини-жоба

    Қолданыс. Топтар - симметрияның тілі: молекулалардың симметрия топтары химияда спектрлерді болжайды, кристаллдардың $230$ кеңістіктік тобы - кристаллографияның негізі. Криптографияда $U(p)$ тобы мен эллипстік қисықтағы нүктелер тобы қолданылады: Диффи-Хеллман кілт алмасуы $g^a$, $g^b$ дәрежелерін есептеудің оңай, ал дискретті логарифмнің қиын екеніне сүйенеді.

    Мини-жоба: «Топ тексерушісі». Ақырлы жиын мен амал берілсе, топ аксиомаларын автоматты тексеретін функция жазамыз, $U(n)$ үшін Кэли кестесін құрамыз, элементтердің реттерін есептеп, қай $U(n)$ циклдік екенін анықтаймыз.

    from math import gcd
from itertools import product

def is_group(elements, op):
    els = list(elements)
    if any(op(a, b) not in els for a, b in product(els, els)):
        return "тұйық емес"
    if any(op(op(a, b), c) != op(a, op(b, c)) for a, b, c in product(els, els, els)):
        return "ассоциативті емес"
    ids = [e for e in els if all(op(e, a) == a == op(a, e) for a in els)]
    if not ids:
        return "бірлік жоқ"
    e = ids[0]
    if any(not any(op(a, b) == e == op(b, a) for b in els) for a in els):
        return "кері элемент жоқ"
    return "топ"

print("Z_6, +       :", is_group(range(6), lambda a, b: (a + b) % 6))
print("{1..5}, * m6 :", is_group(range(1, 6), lambda a, b: a * b % 6))
print("{1..6}, * m7 :", is_group(range(1, 7), lambda a, b: a * b % 7))

def U(n):
    return [a for a in range(1, n) if gcd(a, n) == 1]

def order(a, n):
    k, x = 1, a % n
    while x != 1:
        x, k = x * a % n, k + 1
    return k

n = 10
print("U(10) Кэли кестесі:")
for a in U(n):
    print("  ", [a * b % n for b in U(n)])
print("реттер:", {a: order(a, n) for a in U(n)})

cyclic = [n for n in range(2, 31) if any(order(a, n) == len(U(n)) for a in U(n))]
print("циклдік U(n), n ≤ 30:", cyclic)
