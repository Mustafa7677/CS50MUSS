    Number Theory · 4-сабақ

    Ферма, Эйлер және қытай қалдықтары теоремалары

    $7^{2026}$ санының соңғы екі цифрын қалай табамыз? Алдыңғы сабақта дәрежелердің циклі бар екенін көрдік: $7^n\bmod10$ тізбегінің периоды $4$. Бұл кездейсоқ емес.

    ⏱ Оқу ≈ 50 минЕсептер ≈ 1 сағТест ≈ 5 минБарлығы ≈ 2 сағ

    Ферманың кіші теоремасы мен оның Эйлер жалпылауы цикл ұзындығы әрдайым $\varphi(m)$-ді бөлетінін айтады, мұндағы $\varphi$ - Эйлер функциясы. Ал қытай қалдықтары туралы теорема бір үлкен модульдегі есепті бірнеше кіші, өзара жай модульдегі есептерге бөлуге мүмкіндік береді. Бұл үш нәтиже - RSA шифрлауының, жайлыққа тесттердің және компьютерлік алгебраның тиімді алгоритмдерінің негізі. Бұл сабақта олардың барлығын дәлелдеп, шарттарын қарсы мысалдармен тексереміз және Вильсон теоремасын қосамыз.

    Курс туралы

    Бұл сабақтың мазмұны үшін жауапкершілікті курс авторы Sagid Mustafa өзіне алады. Қате немесе түсініксіз жер тапсаңыз, хабарлаңыз. Бұл курс ресми емтихан не куәлік баламасы емес.

    Бір сөйлеммен

    Модуль бойынша дәрежелер циклмен қайталанады, ал Эйлер мен Ферма теоремалары сол циклдің ұзындығын береді; қытай теоремасы бір санды бірнеше модуль бойынша қалдықтарынан қалпына келтіреді.

    Сабақ мақсаттары

    Сабақ соңында сіз мыналарды істей аласыз:

    • Эйлер функциясын анықтап, $\varphi(p^k)$ формуласын және мультипликативтілігін дәлелдеу;
    • Эйлер теоремасын келтірілген қалдықтар жүйесі арқылы дәлелдеп, Ферманың кіші теоремасын салдар ретінде алу;
    • дәреже көрсеткішін $\varphi(m)$ модулі бойынша қысқартып, үлкен дәрежелерді есептеу;
    • қытай қалдықтары туралы теореманы дәлелдеп, салыстырулар жүйесін конструктивті шешу;
    • Вильсон теоремасын дәлелдеу;
    • Ферма теоремасына кері тұжырымның жалған екенін псевдожай және Кармайкл сандарымен көрсету.

    Қысқаша еске салу

    Салыстырулар, қысқарту ережесі, модуль бойынша кері элемент, сызықтық салыстыру, жылдам дәрежелеу (3-сабақ). Канондық жіктеу (2-сабақ). Безу теңдігі және кеңейтілген Евклид алгоритмі (1-сабақ). Биекция, жиынның қуаты (дискретті математика).

    Алдымен оқыңыз

    • Number Theory · 3-сабақ: Салыстырулар

    Бұл сабақтар таныс болса, бірден бастай беріңіз. Толық реттілік: оқу жолы.

    Алдымен қолмен: соңғы цифр

    Формулаға дейін нақты сандармен ойнап көрейік. Әр қадамды өзіңіз де қағазда қайталаңыз.

    $7^{2026}$ санының соңғы цифры қандай?

    1. Соңғы цифр - $10$ бойынша қалдық. $7^1=7$, $7^2=49\to9$, $7^3\to3$, $7^4\to1$.
    2. $7^4\equiv1\pmod{10}$ - цикл ұзындығы $4$. Эйлер бойынша $\varphi(10)=4$ - дәл осы.
    3. $2026=4\cdot506+2$, демек $7^{2026}\equiv7^2\equiv9\pmod{10}$.
    4. Жауап: соңғы цифр $9$.

    Байқадыңыз ба? $a^{\varphi(m)}\equiv1$ болғандықтан, дәреже көрсеткішін $\varphi(m)$ бойынша қалдықпен алмастыруға болады - үлкен дәрежелер кішкене дәрежелерге айналады.

    Интуиция

    $a=3$, $m=7$ алайық. $3\cdot1,3\cdot2,\dots,3\cdot6$ сандарын $7$ бойынша қалдықтарға келтірсек: $3,6,2,5,1,4$ - сол $1,\dots,6$ сандары, тек басқа ретпен. Демек көбейтінділері тең: $3^6\cdot6!\equiv6!\pmod7$. $6!$ саны $7$-мен өзара жай, оны қысқартамыз: $3^6\equiv1\pmod7$. Ферма теоремасының бүкіл дәлелі осы.

    Құрама модульде $1,\dots,m-1$ сандарының бәрі жарамайды: $\gcd(r,m)>1$ сандарды қысқартуға болмайды. Сондықтан $m$-мен өзара жай қалдықтарды ғана аламыз, олардың саны $\varphi(m)$. Сол дәлел $a^{\varphi(m)}\equiv1\pmod m$ береді, мұндағы $\gcd(a,m)=1$.

    Қытай қалдықтары туралы теорема: $0,\dots,14$ санын $3$-ке және $5$-ке бөлгендегі қалдықтар жұбы толығымен анықтайды. $15$ сан және $3\cdot5=15$ жұп бар, әр жұп дәл бір рет кездеседі. Ал $4$ пен $6$ үшін бұлай емес: $x\equiv1\pmod4$, $x\equiv2\pmod6$ мүмкін емес, себебі бірінші шарт $x$-ті тақ, екіншісі жұп етеді.

    Ферма теоремасына кері тұжырым жалған: $2^{340}\equiv1\pmod{341}$, бірақ $341=11\cdot31$. Сондықтан «$a^{n-1}\equiv1$» тесті жай санды дәлелдемейді. Бірақ тест өтпесе, $n$ міндетті түрде құрама - бұл практикада өте пайдалы.

    Өмірден ұқсастық · айналмалы есік

    $a$-ға көбейту - айналмалы есікті бір бөлімге бұру. Қанша бұрасаңыз да, әйтеуір бастапқы күйге қайтасыз, ал толық айналымның бөлімдер саны топтың ретін бөледі. Эйлер теоремасы - Лагранж теоремасының сандар теориясындағы көрінісі.

    Өмірден ұқсастық · қытай генералы

    Аңыз бойынша генерал әскерді $3$, $5$, $7$-ден саптап, қалған адамдарды санап, әскер санын тапқан. Қалдықтар $(2,3,2)$ болса, әскер саны $23$ (не $23+105k$). Бұл - қытай қалдықтары туралы теорема.

    Белгілерді оқу

    Жоғары математиканың қиындығының жартысы - белгілерде. Теорияға дейін әр белгіні дауыстап оқып, мағынасын біліп алайық:

    Анықтамалар мен теоремалар

    Анықтама 4.1 · Эйлер функциясы

    $n\in\mathbb N$ үшін Эйлер функциясы (Euler's totient function) $\varphi(n)=\left|\{r:1\le r\le n,\ \gcd(r,n)=1\}\right|$. $m$-мен өзара жай, $m$ бойынша жұптап салыстырылмайтын $\varphi(m)$ саннан тұратын жиын - келтірілген қалдықтар жүйесі (reduced residue system); мысалы $\{1,5,7,11\}$, $m=12$. $\varphi(1)=1$.

    Қарапайым тілмен: $\varphi(n)$ - $1$-ден $n$-ге дейінгі $n$-мен ортақ бөлгіші жоқ сандар саны.

    Теорема 4.1 · Эйлер теоремасы

    $m\ge1$, $\gcd(a,m)=1$ болса, $a^{\varphi(m)}\equiv1\pmod m$.

    Қарапайым тілмен: Модульмен өзара жай санды $\varphi(m)$ дәрежесіне шығарсақ, $1$ қалдығы шығады.

    Негіздеме. Эйлер теоремасы (Euler's theorem). Шарт $\gcd(a,m)=1$ міндетті: $2^{\varphi(4)}=4\equiv0\pmod4$.

    Теорема 4.2 · Ферманың кіші теоремасы

    $p$ жай. (1) $p\nmid a$ болса, $a^{p-1}\equiv1\pmod p$. (2) Кез келген $a\in\mathbb Z$ үшін $a^p\equiv a\pmod p$.

    Қарапайым тілмен: Жай модуль бойынша: $a^{p-1}\equiv1$ ($p\nmid a$), және әрдайым $a^p\equiv a$.

    Негіздеме. Ферманың кіші теоремасы (Fermat's little theorem). Кері тұжырым жалған: $2^{340}\equiv1\pmod{341}$, $341=11\cdot31$.

    Теорема 4.3 · Қытай қалдықтары туралы теорема

    $m_1,\dots,m_k$ жұптап өзара жай, $M=m_1\cdots m_k$. Кез келген $a_1,\dots,a_k$ үшін $x\equiv a_i\pmod{m_i}$ ($i=1,\dots,k$) жүйесінің шешімі бар және ол $M$ модулі бойынша жалғыз: $x\equiv\sum_{i=1}^k a_iM_iy_i\pmod M$, мұнда $M_i=\frac M{m_i}$, $y_i\equiv M_i^{-1}\pmod{m_i}$.

    Қарапайым тілмен: Өзара жай модульдер бойынша қалдықтар берілсе, оларды қанағаттандыратын сан бар және ол модульдердің көбейтіндісі бойынша жалғыз.

    Негіздеме. Қытай қалдықтары туралы теорема (Chinese remainder theorem). Жұптап өзара жайлық шарты міндетті: $x\equiv1\pmod4$, $x\equiv2\pmod6$ - шешім жоқ.

    Теорема 4.4 · Эйлер функциясының формуласы

    (1) $p$ жай болса, $\varphi(p^k)=p^k-p^{k-1}$. (2) $\gcd(m,n)=1$ болса, $\varphi(mn)=\varphi(m)\varphi(n)$ (мультипликативті (multiplicative)). (3) $n=p_1^{k_1}\cdots p_s^{k_s}$ болса, $\varphi(n)=n\prod_{i=1}^s\left(1-\frac1{p_i}\right)$.

    Қарапайым тілмен: $\varphi$-ді жай көбейткіштер арқылы есептейміз: $\varphi(p^k)=p^k-p^{k-1}$, өзара жай сандарда көбейтіледі.

    Негіздеме. $\gcd(m,n)>1$ болса, (2) жалған: $\varphi(4)=2\ne\varphi(2)^2=1$.

    Теорема 4.5 · Вильсон теоремасы

    $p$ жай болса, $(p-1)!\equiv-1\pmod p$. Керісінше, $n>4$ құрама болса, $(n-1)!\equiv0\pmod n$; $n=4$ үшін $3!\equiv2\pmod4$. Демек $n\ge2$ үшін: $n$ жай $\iff(n-1)!\equiv-1\pmod n$.

    Қарапайым тілмен: $(p-1)!+1$ $p$-ға бөлінеді дәл $p$ жай болғанда - бұл жайлықтың (баяу, бірақ дәл) белгісі.

    Негіздеме. Вильсон теоремасы (Wilson's theorem). Критерий ретінде дұрыс, бірақ тест ретінде баяу: $n-2$ көбейту.

    Формула 4.1 · Эйлер теоремасы
    $$\gcd(a,m)=1\ \Rightarrow\ a^{\varphi(m)}\equiv1\pmod m$$

    Шарт міндетті.

    Формула 4.2 · Ферманың кіші теоремасы
    $$p\nmid a\Rightarrow a^{p-1}\equiv1\pmod p;\qquad a^p\equiv a\pmod p$$

    $p$ жай.

    Формула 4.3 · Көрсеткішті қысқарту
    $$\gcd(a,m)=1:\ a^n\equiv a^{\,n\bmod\varphi(m)}\pmod m$$

    Көрсеткіштер $\varphi(m)$ бойынша.

    Формула 4.4 · Эйлер функциясы
    $$\varphi(n)=n\prod_{p\mid n}\left(1-\frac1p\right)$$

    $\varphi(p^k)=p^k-p^{k-1}$; мультипликативті.

    Формула 4.5 · Қытай қалдықтары
    $$x\equiv\sum_i a_iM_iy_i\pmod M,\quad M_i=\frac M{m_i},\ M_iy_i\equiv1\pmod{m_i}$$

    $m_i$ жұптап өзара жай.

    Формула 4.6 · Вильсон теоремасы
    $$(p-1)!\equiv-1\pmod p$$

    $p$ жай; керісінше, $n\ge2$ және $(n-1)!\equiv-1\pmod n$ болса, $n$ жай.

    Есте сақта

    Үлкен дәрежені есептеу жоспары: (1) $\gcd(a,m)=1$ екенін тексеріңіз; (2) $\varphi(m)$-ді канондық жіктеу арқылы табыңыз; (3) $n$-ді $\varphi(m)$-ге бөлгендегі қалдықты алыңыз; (4) кіші дәрежені жылдам дәрежелеумен есептеңіз. $m$ құрама болса, қытай қалдықтары туралы теорема бойынша $m$-ді жай дәрежелерге бөліп, әрқайсысында бөлек есептеп, қайта жинау жиі оңайырақ. Нақты цикл $\varphi(m)$-ден қысқа болуы мүмкін ($7^4\equiv1\pmod{100}$, ал $\varphi(100)=40$), бірақ ол әрдайым $\varphi(m)$-ді бөледі (абстракт алгебрада: элементтің реті топтың ретін бөледі).

    Назар аудар

    Үш жиі қате. (1) $\gcd(a,m)>1$ болғанда Эйлер теоремасын қолдану: $6^{\varphi(10)}=6^4=1296\equiv6\not\equiv1\pmod{10}$. (2) Дәреже көрсеткішін $m$ бойынша қысқарту: $\varphi(m)$ бойынша қысқарту керек. (3) Қытай қалдықтары туралы теореманы өзара жай емес модульдерге қолдану: $x\equiv1\pmod4$, $x\equiv3\pmod6$ жүйесінің шешімі бар ($x=9$), бірақ $24$ бойынша емес, $\operatorname{lcm}(4,6)=12$ бойынша жалғыз; ал $x\equiv1\pmod4$, $x\equiv2\pmod6$ шешімсіз.

    Тоқта, ойлан

    Әрі қарай жүрмес бұрын, өзіңізді тексеріңіз: алдымен жауапты ойланыңыз, сосын ашыңыз.

    1. $\varphi(12)$ неге тең?

    $12=2^2\cdot3$: $\varphi=2\cdot2=4$ ($1,5,7,11$).

    2. $2^{100}\bmod 13$-ті Ферма арқылы табыңыз.

    $2^{12}\equiv1$; $100=8\cdot12+4$; $2^{100}\equiv2^4=16\equiv3$.

    3. $x\equiv1\pmod3$, $x\equiv2\pmod5$ жүйесін шешіңіз.

    $x\equiv7\pmod{15}$: $7=2\cdot3+1=5+2$ ✓.

    4. Ферма теоремасының керісі дұрыс па: $a^{n-1}\equiv1\pmod n$ болса, $n$ жай ма?

    Жоқ: $2^{340}\equiv1\pmod{341}$, ал $341=11\cdot31$; Кармайкл сандары (мысалы $561$) барлық өзара жай $a$ үшін алдайды.

    Қорытып шығару

    Қорытып шығару 1: Эйлер теоремасы

    Мақсат: Теорема 4.1-ді дәлелдеу.

    Идея: $m$-мен өзара жай қалдықтарды $a$-ға көбейтсек, олар тек орын ауыстырады. Екі жиынның көбейтінділері тең, қысқартсақ $a^{\varphi(m)}\equiv1$.

    1. $r_1,\dots,r_\varphi$ - келтірілген қалдықтар жүйесі ($\varphi=\varphi(m)$), $\gcd(a,m)=1$.
    2. $ar_1,\dots,ar_\varphi$ сандары да $m$-мен өзара жай (екі көбейткіш те өзара жай).
    3. Олар жұптап салыстырылмайды: $ar_i\equiv ar_j\Rightarrow r_i\equiv r_j$ (қысқарту, $\gcd(a,m)=1$) $\Rightarrow i=j$.
    4. Демек $\{ar_i\}$ - сол $\varphi$ класс, басқа ретпен. Көбейтінділер: $a^\varphi\prod r_i\equiv\prod r_i\pmod m$.
    5. $\gcd\left(\prod r_i,m\right)=1$, қысқартамыз: $a^{\varphi(m)}\equiv1\pmod m$. ∎

    ∎

    Қорытып шығару 2: Ферма теоремасы

    Мақсат: Теорема 4.2-ні Эйлер теоремасынан алу.

    Идея: Жай $p$ үшін $\varphi(p)=p-1$ - Эйлер теоремасының дербес жағдайы; $a^p\equiv a$ үшін $p\mid a$ жағдайын бөлек қараймыз.

    1. $p$ жай: $1,\dots,p-1$ барлығы $p$-мен өзара жай, $\varphi(p)=p-1$.
    2. $p\nmid a\Rightarrow\gcd(a,p)=1$, Эйлер: $a^{p-1}\equiv1\pmod p$. Бұл (1).
    3. (2): $p\nmid a$ болса, (1)-ді $a$-ға көбейтеміз: $a^p\equiv a$.
    4. $p\mid a$ болса, екі жақ та $\equiv0$. ∎

    ∎

    Қорытып шығару 3: қытай қалдықтары туралы теорема

    Мақсат: Теорема 4.3-ті дәлелдеу.

    Идея: Шешімді «бөлшектерден» құрастырамыз: әр $m_i$ бойынша $1$, басқаларында $0$ беретін сан тауып, $a_i$-ге көбейтіп қосамыз.

    1. Бар болуы: $M_i=\frac M{m_i}$ - $m_i$-ден басқа барлық модульдердің көбейтіндісі, демек $\gcd(M_i,m_i)=1$ (жұптап өзара жай). Теорема 3.3: $y_i\equiv M_i^{-1}\pmod{m_i}$ бар.
    2. $x=\sum_j a_jM_jy_j$. $j\ne i$ болса, $m_i\mid M_j$, сондықтан $x\equiv a_iM_iy_i\equiv a_i\pmod{m_i}$.
    3. Жалғыздығы: $x$, $x'$ екеуі де шешім болса, әр $i$ үшін $m_i\mid x-x'$.
    4. Жұптап өзара жай сандардың әрқайсысына бөлінетін сан олардың көбейтіндісіне бөлінеді (Евклид леммасы, индукция): $M\mid x-x'$. ∎

    ∎

    Қорытып шығару 4: Эйлер функциясының формуласы

    Мақсат: Теорема 4.4-ті дәлелдеу.

    Идея: $p^k$-мен өзара жай емес сандар - тек $p$-ның еселіктері. Мультипликативтік - қытай теоремасынан: қалдықтар жұптары жеке-жеке өзара жай.

    1. (1) $1,\dots,p^k$ ішінде $p^k$-мен өзара жай емес сандар - тек $p$-ға еселілер: $p,2p,\dots,p^{k-1}\cdot p$, саны $p^{k-1}$. Демек $\varphi(p^k)=p^k-p^{k-1}$.
    2. (2) $\gcd(m,n)=1$. Теорема 4.3: $x\bmod mn\mapsto(x\bmod m,\ x\bmod n)$ - $\mathbb Z_{mn}$ мен $\mathbb Z_m\times\mathbb Z_n$ арасындағы биекция.
    3. $\gcd(x,mn)=1\iff\gcd(x,m)=1$ және $\gcd(x,n)=1$ (ортақ жай бөлгіш $mn$-ді бөлсе, $m$-ді немесе $n$-ді бөледі).
    4. Демек биекция $mn$-мен өзара жай кластарды өзара жай жұптарға аударады: $\varphi(mn)=\varphi(m)\varphi(n)$.
    5. (3) Жай дәрежелер жұптап өзара жай: $\varphi(n)=\prod(p_i^{k_i}-p_i^{k_i-1})=\prod p_i^{k_i}\left(1-\frac1{p_i}\right)=n\prod\left(1-\frac1{p_i}\right)$. ∎

    ∎

    Қорытып шығару 5: Вильсон теоремасы

    Мақсат: Теорема 4.5-ті дәлелдеу.

    Идея: $1..p-1$ сандарын «өз кері элементімен» жұптаймыз: жұптар көбейтіндісі $1$, тек $1$ мен $p-1$ өзіне-өзі кері, олардың көбейтіндісі $-1$.

    1. $p=2$: $1!=1\equiv-1\pmod2$. $p\ge3$ алайық.
    2. Теорема 3.3: әр $a\in\{1,\dots,p-1\}$-дің $p$ бойынша жалғыз кері элементі бар. $a\equiv a^{-1}\iff a^2\equiv1\iff p\mid(a-1)(a+1)\iff a\equiv\pm1$ (Евклид леммасы).
    3. Қалған $2,\dots,p-2$ сандары өзара кері жұптарға бөлінеді, әр жұптың көбейтіндісі $\equiv1$. Демек $(p-1)!\equiv1\cdot(p-1)\equiv-1\pmod p$.
    4. Кері бағыт: $n=ab$, $1<a<b<n$ болса, $a$ мен $b$ - $(n-1)!$ ішіндегі әртүрлі көбейткіштер, $n\mid(n-1)!$.
    5. $n=q^2$, $q$ жай, $q\ge3$: $q$ мен $2q$ ($2q\le n-1$) екеуі де көбейткіш, $q^2\mid(n-1)!$. $n=4$: $3!=6\equiv2$. Барлық жағдайда $(n-1)!\not\equiv-1$. ∎

    ∎

    Қадамдық шешілген мысалдар

    Мысал 1. Ферма бойынша дәреже

    $3^{2026}\bmod13$.

    1. 1-қадам. $13$ жай, $13\nmid3$: $3^{12}\equiv1\pmod{13}$.
    2. 2-қадам. $2026=12\cdot168+10$: $3^{2026}\equiv3^{10}\pmod{13}$.
    3. 3-қадам. Шын циклі қысқа: $3^3=27\equiv1\pmod{13}$, $10=3\cdot3+1$, $3^{10}\equiv3$.
    4. 4-қадам. Тексеру: $3$ - $12$-ні бөледі ✓ (цикл ұзындығы $\varphi$-ді бөледі).

    Жауабы: $3$.

    Мысал 2. Эйлер функциясы

    $\varphi(360)$.

    1. 1-қадам. $360=2^3\cdot3^2\cdot5$.
    2. 2-қадам. $\varphi(360)=360\cdot\frac12\cdot\frac23\cdot\frac45$.
    3. 3-қадам. $=360\cdot\frac{8}{30}=96$.
    4. 4-қадам. Басқаша: $(8-4)(9-3)(5-1)=4\cdot6\cdot4=96$ ✓.

    Жауабы: $96$.

    Мысал 3. Сунь-цзы есебі

    $x\equiv2\pmod3$, $x\equiv3\pmod5$, $x\equiv2\pmod7$.

    1. 1-қадам. $M=105$; $M_1=35$, $M_2=21$, $M_3=15$.
    2. 2-қадам. $35\equiv2\pmod3$, $y_1=2$; $21\equiv1\pmod5$, $y_2=1$; $15\equiv1\pmod7$, $y_3=1$.
    3. 3-қадам. $x\equiv2\cdot35\cdot2+3\cdot21\cdot1+2\cdot15\cdot1=140+63+30=233\equiv23\pmod{105}$.
    4. 4-қадам. Тексеру: $23=7\cdot3+2=4\cdot5+3=3\cdot7+2$ ✓.

    Жауабы: $x\equiv23\pmod{105}$.

    Мысал 4. Соңғы екі цифр

    $7^{2026}\bmod100$.

    1. 1-қадам. $\gcd(7,100)=1$, $\varphi(100)=100\cdot\frac12\cdot\frac45=40$.
    2. 2-қадам. $2026=40\cdot50+26$: $7^{2026}\equiv7^{26}$.
    3. 3-қадам. Шын циклі: $7^2=49$, $7^4=2401\equiv1\pmod{100}$. $26=4\cdot6+2$: $7^{26}\equiv49$.
    4. 4-қадам. Соңғы екі цифр - $49$.

    Жауабы: $49$.

    Мысал 5. Вильсон және псевдожай

    (а) $10!\bmod11$. (ә) $2^{340}\bmod341$ және $341$ жай ма?

    1. 1-қадам. (а) $11$ жай, Вильсон: $10!\equiv-1\equiv10\pmod{11}$.
    2. 2-қадам. (ә) $341=11\cdot31$. $2^{10}=1024=3\cdot341+1$, яғни $2^{10}\equiv1\pmod{341}$.
    3. 3-қадам. $2^{340}=(2^{10})^{34}\equiv1\pmod{341}$.
    4. 4-қадам. Ферма тесті «жай» дейді, бірақ $341$ құрама - $2$ негізіндегі псевдожай сан (pseudoprime). $3$ негізі әшкерелейді: $3^{340}\equiv56\pmod{341}$.

    Жауабы: (а) $10$; (ә) $1$, $341$ құрама.

    Жиі қателер

    • $a^{\varphi(m)}\equiv1$ кез келген $a$ үшін → тек $\gcd(a,m)=1$
      Неге қате: $6^4\equiv6\pmod{10}$.
    • $a^n\equiv a^{n\bmod m}\pmod m$ → $a^n\equiv a^{n\bmod\varphi(m)}$
      Неге қате: $\gcd(a,m)=1$ шартымен.
    • $a^{n-1}\equiv1\pmod n$ болса, $n$ жай → кері тұжырым жалған
      Неге қате: $341$, $561$.
    • $\varphi(mn)=\varphi(m)\varphi(n)$ әрдайым → тек $\gcd(m,n)=1$
      Неге қате: $\varphi(4)=2$, $\varphi(2)^2=1$.
    • Кез келген модульдер жүйесін ҚҚТ шешеді → жұптап өзара жай модульдер
      Неге қате: $x\equiv1\ (4)$, $x\equiv2\ (6)$.
    • Цикл ұзындығы дәл $\varphi(m)$ → $\varphi(m)$-нің бөлгіші
      Неге қате: $7^4\equiv1\pmod{100}$.

    Визуализация

    Бақылаңыз: $a=3$, $m=7$: $n=6$ нүктесінде мән $1$-ге тең, сосын тізбек қайталанады - Ферма, $3^{6}\equiv1$. $m=13$: $3^3\equiv1$, цикл $3$, ол $12$-ні бөледі. $a=2$, $m=6$ ($\gcd=2$) қойыңыз: мән ешқашан $1$ болмайды - Эйлер теоремасының шарты бұзылған.

    Бақылаңыз: $n=0,\dots,14$ үшін $(n\bmod3,\ n\bmod5)$ жұптары барлық $15$ комбинацияны дәл бір реттен береді; $n=15$-тен бастап бәрі қайталанады. Бұл - $\mathbb Z_{15}\to\mathbb Z_3\times\mathbb Z_5$ биекциясы (Теорема 4.3).

    Қолданыс және мини-жоба

    Қолданыс. Ферма тесті - жайлыққа тесттердің ең қарапайымы (оны жетілдірген Миллер-Рабин тесті RSA кілттерін жасауда қолданылады). Қытай қалдықтары туралы теорема RSA шифрын ашуды шамамен $4$ есе жылдамдатады (CRT-RSA), компьютерлік алгебрада үлкен сандарды бірнеше кіші модуль бойынша параллель есептеуге мүмкіндік береді.

    Мини-жоба: «Ферма тесті және оның алданулары». Эйлер функциясын, қытай қалдықтары туралы теорема бойынша шешушіні жазамыз, сосын $10\,000$-ға дейінгі $2$ негізіндегі псевдожай сандарды және Кармайкл сандарын табамыз.

    from math import gcd

def phi(n):
    result, p = n, 2
    while p * p <= n:
        if n % p == 0:
            while n % p == 0:
                n //= p
            result -= result // p
        p += 1
    if n > 1:
        result -= result // n
    return result

print("phi:", [(n, phi(n)) for n in (1, 12, 36, 100, 360, 561)])

def crt(residues, moduli):
    x, M = 0, 1
    for m in moduli:
        M *= m
    for a, m in zip(residues, moduli):
        Mi = M // m
        x += a * Mi * pow(Mi, -1, m)
    return x % M, M

print("Сунь-цзы:", crt([2, 3, 2], [3, 5, 7]))

def is_prime(n):
    if n < 2:
        return False
    d = 2
    while d * d <= n:
        if n % d == 0:
            return False
        d += 1
    return True

N = 10000
pseudo = [n for n in range(3, N, 2) if pow(2, n - 1, n) == 1 and not is_prime(n)]
print("2 негізіндегі псевдожайлар:", len(pseudo), pseudo[:8])
carm = [n for n in pseudo if all(pow(a, n - 1, n) == 1 for a in range(2, n) if gcd(a, n) == 1)]
print("Кармайкл сандары:", carm)

    Өзіңіз жалғастырыңыз:

    1. $10\,000$-ға дейін неше жай сан бар және неше $2$ негізіндегі псевдожай? Тест қаншалықты сенімді?
    2. Табылған әр Кармайкл санын жай көбейткіштерге жіктеп, $p-1\mid n-1$ шартын тексеріңіз (Корсельт критерийі).
    3. crt функциясын $x\equiv1\pmod4$, $x\equiv2\pmod6$ жүйесіне қолданып көріңіз. Не болады және неге?
