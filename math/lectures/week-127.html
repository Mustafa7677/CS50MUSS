    Number Theory · 3-сабақ

    Салыстырулар

    Сағат тілі $12$-ден кейін қайта $1$-ге оралады: $9$ сағаттан кейін $5$ сағат өтсе, сағат $2$-ні көрсетеді. Бұл - модуль бойынша арифметика. Гаусс енгізген салыстыру белгісі $a\equiv b\pmod m$ сандар теориясын түбегейлі жеңілдетті: бөлінгіштік туралы тұжырымдар теңдіктерге ұқсас есептеулерге айналады.

    ⏱ Оқу ≈ 45 минЕсептер ≈ 1 сағТест ≈ 5 минБарлығы ≈ 1 сағ 50 мин

    Бұл сабақта салыстыруларды анықтап, олармен қосу, көбейту, дәрежелеу амалдарының дұрыстығын дәлелдейміз; қысқартудың шартын (жиі қате жіберілетін жер), модуль бойынша кері элементтің бар болу критерийін және сызықтық салыстырудың шешімдер санын дәлелдейміз. Сонымен қатар бөлінгіштік белгілерін салыстырулармен түсіндіріп, үлкен дәрежелерді модуль бойынша жылдам есептеуді үйренеміз - RSA-ның есептеу негізі.

    Курс туралы

    Бұл сабақтың мазмұны үшін жауапкершілікті курс авторы Sagid Mustafa өзіне алады. Қате немесе түсініксіз жер тапсаңыз, хабарлаңыз. Бұл курс ресми емтихан не куәлік баламасы емес.

    Бір сөйлеммен

    Модуль бойынша салыстыру - тек қалдықтарға қарайтын арифметика: үлкен сандарды кішкене қалдықтармен алмастырып, қосуды, көбейтуді және (кейде) бөлуді жасаймыз.

    Сабақ мақсаттары

    Сабақ соңында сіз мыналарды істей аласыз:

    • салыстыру анықтамасын қолданып, оның эквиваленттік қатынас екенін дәлелдеу;
    • салыстырулармен қосу, көбейту, дәрежелеудің дұрыстығын дәлелдеп, есептеулерде қолдану;
    • қысқарту ережесін ($\gcd$ шартымен) дәлелдеп, қате қысқартуды қарсы мысалмен көрсету;
    • модуль бойынша кері элементтің бар болу критерийін дәлелдеп, оны кеңейтілген Евклидпен табу;
    • сызықтық салыстыру $ax\equiv b\pmod m$-ның шешімділік шартын және шешімдер санын дәлелдеу;
    • бөлінгіштік белгілерін түсіндіріп, $a^n\bmod m$-ды жылдам дәрежелеумен есептеу.

    Қысқаша еске салу

    Бөлінгіштік, қалдықпен бөлу, ЕҮОБ, Безу теңдігі, кеңейтілген Евклид алгоритмі, Евклид леммасы (1-сабақ). Канондық жіктеу (2-сабақ). Эквиваленттік қатынас және эквиваленттік кластар (дискретті математика). Екілік санау жүйесі.

    Алдымен қолмен: апта күні

    Формулаға дейін нақты сандармен ойнап көрейік. Әр қадамды өзіңіз де қағазда қайталаңыз.

    Бүгін сәрсенбі. $100$ күннен кейін аптаның қай күні болады? Ал $3^{100}$ күннен кейін?

    1. Апта - $7$ күн, тек $100\bmod7$ маңызды: $100=14\cdot7+2$. Сәрсенбіден $2$ күн кейін - жұма.
    2. $3^{100}$ үшін дәрежелердің $7$ бойынша қалдықтарын жазамыз: $3^1\equiv3$, $3^2\equiv2$, $3^3\equiv6$, $3^4\equiv4$, $3^5\equiv5$, $3^6\equiv1$.
    3. $3^6\equiv1$, демек цикл ұзындығы $6$: $100=16\cdot6+4$, $3^{100}\equiv3^4\equiv4\pmod7$.
    4. Сәрсенбіден $4$ күн кейін - жексенбі.

    Байқадыңыз ба? Үлкен сандармен жұмыс істемей, тек қалдықтармен есептедік. Модуль арифметикасының күші - осында.

    Интуиция

    $a\equiv b\pmod m$ дегеніміз: $a$ мен $b$ $m$-ге бөлгенде бірдей қалдық береді, немесе $m\mid a-b$. Сондықтан $m$ модуль бойынша барлық бүтін сандар $m$ «қалдық кластарына» бөлінеді, және есептеулерде санның өзі емес, тек класы маңызды. $123456789\cdot987654321$ санының соңғы цифрын табу үшін тек $9\cdot1\equiv9\pmod{10}$ жеткілікті.

    Салыстыруларды теңдіктер сияқты қосуға, азайтуға, көбейтуге болады. Бірақ бөлу - қиын: $2\cdot3\equiv2\cdot0\pmod6$, бірақ $3\not\equiv0$. Себебі $2$ пен $6$-ның ортақ бөлгіші бар. Модуль бойынша «бөлу» тек кері элемент бар болғанда мүмкін, ал $a^{-1}\bmod m$ бар $\iff\gcd(a,m)=1$ - тағы да Безу теңдігі.

    $m$ жай болса, $1,\dots,m-1$ барлығының кері элементі бар - $\mathbb Z_p$ өріс (абстракт алгебра пәнінде). Құрама модульде нөлдің бөлгіштері бар: $2\cdot3\equiv0\pmod6$, екеуі де нөл емес.

    Үлкен дәрежелер: $3^{100}\bmod7$ үшін $3^{100}$-ды есептеудің қажеті жоқ. $3^2,3^4,3^8,\dots$ квадраттарын модуль бойынша кезекпен табамыз ($7$ қадам), сосын $100=64+32+4$ бойынша керектілерін көбейтеміз. Мыңдаған таңбалы сандар үшін де бірнеше мың амал жеткілікті.

    Өмірден ұқсастық · сағат

    Сағат - $12$ модулі бойынша арифметика: $9+5=2$. Модуль бойынша барлық сандар бір «шеңберге» оралады, ал $a\equiv b$ дегеніміз - шеңберде бір нүкте.

    Өмірден ұқсастық · сандардың «цифрлық қолтаңбасы»

    $9$-ға бөлінгіштік белгісі: сан мен оның цифрлар қосындысы $9$ бойынша бірдей қалдық береді, өйткені $10\equiv1\pmod9$. Яғни әр цифрдың «салмағы» $9$ бойынша $1$.

    Белгілерді оқу

    Жоғары математиканың қиындығының жартысы - белгілерде. Теорияға дейін әр белгіні дауыстап оқып, мағынасын біліп алайық:

    Анықтамалар мен теоремалар

    Анықтама 3.1 · Салыстыру

    $m\in\mathbb N$. $a$ мен $b$ $m$ модулі бойынша салыстырымды (congruent): $a\equiv b\pmod m$, егер $m\mid a-b$. Эквиваленттісі: $a\bmod m=b\bmod m$. $\bar a=\{a+km:k\in\mathbb Z\}$ - қалдық класы (residue class); кластар жиыны $\mathbb Z_m=\{\bar0,\bar1,\dots,\overline{m-1}\}$.

    Қарапайым тілмен: Екі сан $m$ модулі бойынша салыстырымды, егер оларды $m$-ге бөлгенде қалдықтары бірдей болса.

    Теорема 3.1 · Эквиваленттік және амалдар

    (1) $\equiv\pmod m$ - эквиваленттік қатынас (рефлексивті, симметриялы, транзитивті). (2) $a\equiv b$, $c\equiv d\pmod m$ болса: $a\pm c\equiv b\pm d$, $ac\equiv bd$, $a^n\equiv b^n\pmod m$ ($n\in\mathbb N$). (3) $f$ бүтін коэффициентті көпмүше болса, $a\equiv b\Rightarrow f(a)\equiv f(b)\pmod m$.

    Қарапайым тілмен: Салыстыруларды кәдімгі теңдеулер сияқты қосуға, көбейтуге, дәрежеге шығаруға болады.

    Негіздеме. Сондықтан $\mathbb Z_m$-да кластарды қосу мен көбейту дұрыс анықталған.

    Теорема 3.2 · Қысқарту

    $ac\equiv bc\pmod m$ болса, $a\equiv b\pmod{\frac{m}{\gcd(c,m)}}$. Дербес жағдайда $\gcd(c,m)=1$ болса, $a\equiv b\pmod m$.

    Қарапайым тілмен: Екі жақты $c$-ға қысқартуға болады, бірақ модуль $\gcd(c,m)$-ға бөлінеді; $c$ модульмен өзара жай болса, модуль өзгермейді.

    Негіздеме. $\gcd(c,m)>1$ болса, модуль кішірейеді: $2\cdot3\equiv2\cdot0\pmod6\Rightarrow3\equiv0\pmod3$ - дұрыс, ал $\pmod6$ - жалған.

    Теорема 3.3 · Кері элемент

    $a\cdot x\equiv1\pmod m$ шешімі бар $\iff\gcd(a,m)=1$; онда шешім $m$ модулі бойынша жалғыз - $a$-ның модуль бойынша кері элементі (modular inverse) $a^{-1}\bmod m$. $m=p$ жай болса, $p\nmid a$ кез келген $a$-ның кері элементі бар.

    Қарапайым тілмен: $a$-ға «бөлуге» болады дәл $a$ модульмен өзара жай болғанда.

    Негіздеме. Кеңейтілген Евклид: $ax+my=1\Rightarrow ax\equiv1\pmod m$.

    Теорема 3.4 · Сызықтық салыстыру

    $d=\gcd(a,m)$. $ax\equiv b\pmod m$ шешілетін $\iff d\mid b$. Шешілсе, $m$ модулі бойынша дәл $d$ шешім бар: $x\equiv x_0+k\frac md$, $k=0,\dots,d-1$, мұнда $x_0$ - $\frac ad x\equiv\frac bd\pmod{\frac md}$ салыстыруының шешімі.

    Қарапайым тілмен: $ax\equiv b$ шешілетін $\iff$ $\gcd(a,m)$ $b$-ны бөледі; онда шешімдер саны дәл сол ЕҮОБ-қа тең.

    Негіздеме. Сызықтық салыстыру (linear congruence).

    Теорема 3.5 · Бөлінгіштік белгілері

    $n=\overline{a_k\dots a_1a_0}$ (ондық жазу). (1) $n\equiv a_0+a_1+\dots+a_k\pmod9$ (демек $\pmod 3$). (2) $n\equiv a_0-a_1+a_2-\dots\pmod{11}$. (3) $n\equiv a_0\pmod{10}$, $n\equiv\overline{a_1a_0}\pmod{100}$.

    Қарапайым тілмен: $3$, $9$, $11$-ге бөлінгіштік белгілері $10$-ның дәрежелерінің қалдықтарынан шығады.

    Негіздеме. $10\equiv1\pmod9$, $10\equiv-1\pmod{11}$.

    Формула 3.1 · Салыстыру
    $$a\equiv b\pmod m\iff m\mid a-b$$

    Бірдей қалдық.

    Формула 3.2 · Амалдар
    $$a\equiv b,\ c\equiv d\ \Rightarrow\ a+c\equiv b+d,\ ac\equiv bd,\ a^n\equiv b^n$$

    Бір модуль бойынша.

    Формула 3.3 · Қысқарту
    $$ac\equiv bc\pmod m\Rightarrow a\equiv b\pmod{\frac{m}{\gcd(c,m)}}$$

    Модуль кішірейеді.

    Формула 3.4 · Кері элемент
    $$\exists a^{-1}\bmod m\iff\gcd(a,m)=1$$

    $ax+my=1$ - кеңейтілген Евклид.

    Формула 3.5 · Сызықтық салыстыру
    $$\exists x:\ ax\equiv b\pmod m\iff\gcd(a,m)\mid b$$

    Шешімдер саны $\gcd(a,m)$.

    Формула 3.6 · Жылдам дәрежелеу
    $$a^{2k}=(a^k)^2,\quad a^{2k+1}=a\cdot(a^k)^2$$

    $O(\log n)$ көбейту, әр қадамда $\bmod m$.

    Есте сақта

    Модуль бойынша есептеу ережелері: (1) әр аралық нәтижені дереу $\bmod m$-ге келтіріңіз - сандар кішкене қалады; (2) теріс қалдықтар ыңғайлы: $10\equiv-1\pmod{11}$, $2^3\equiv1\pmod7$; (3) дәреженің циклін табыңыз: $a^k\equiv1$ болса, $a^n\equiv a^{n\bmod k}$; (4) бөлудің орнына кері элементке көбейтіңіз, бірақ алдымен $\gcd$-ті тексеріңіз.

    Назар аудар

    Салыстыруда екі жақты «қысқарту» - ең жиі қате: $4\cdot3\equiv4\cdot6\pmod{12}$ ($12\equiv24\equiv0$), бірақ $3\not\equiv6\pmod{12}$. Дұрысы: $\gcd(4,12)=4$, сондықтан $3\equiv6\pmod3$. Сондай-ақ дәреже көрсеткішін модуль бойынша қысқартуға болмайды: $2\equiv2\pmod5$, бірақ $2^{5}=32\equiv2$, ал $2^{0}=1$ - яғни $n\equiv n'\pmod m$-нан $a^n\equiv a^{n'}\pmod m$ шықпайды (көрсеткіштер басқа модуль бойынша жұмыс істейді - 4-сабақ).

    Тоқта, ойлан

    Әрі қарай жүрмес бұрын, өзіңізді тексеріңіз: алдымен жауапты ойланыңыз, сосын ашыңыз.

    1. $2^{10}\bmod 7$ неге тең?

    $2^3=8\equiv1$, $2^{10}=2^9\cdot2\equiv1\cdot2=2$.

    2. $4x\equiv6\pmod{10}$ неше шешімі бар?

    $\gcd(4,10)=2\mid6$: екі шешім, $x\equiv4$ және $x\equiv9\pmod{10}$.

    3. $123456789$ санын $9$-ға бөлгендегі қалдық?

    Цифрлар қосындысы $45$, $45\equiv0\pmod9$ - қалдық $0$.

    4. $6x\equiv6\pmod9$-дан $x\equiv1\pmod9$ шыға ма?

    Жоқ: $\gcd(6,9)=3$, тек $x\equiv1\pmod3$; мысалы $x=4$: $24\equiv6\pmod9$ ✓.

    Қорытып шығару

    Қорытып шығару 1: амалдардың дұрыстығы

    Мақсат: Теорема 3.1 (2)-ні дәлелдеу.

    Идея: $a=b+km$ түрінде жазып, қосынды мен көбейтіндіні ашамыз - қосымша мүшелердің бәрі $m$-ге еселі.

    1. $a=b+km$, $c=d+lm$.
    2. Қосу: $a+c=b+d+(k+l)m$, демек $a+c\equiv b+d$.
    3. Көбейту: $ac=(b+km)(d+lm)=bd+(bl+dk+klm)m$, демек $ac\equiv bd$.
    4. Дәреже: көбейтуді $n$ рет қолданып (индукция): $a^n\equiv b^n$.
    5. Көпмүше $f(x)=\sum c_ix^i$: әр мүше $c_ia^i\equiv c_ib^i$, қосып $f(a)\equiv f(b)$. ∎

    ∎

    Қорытып шығару 2: қысқарту ережесі

    Мақсат: Теорема 3.2-ні дәлелдеу.

    Идея: ЕҮОБ-ты бөліп шығарып, өзара жай жағдайға келтіреміз, сосын Евклид леммасы.

    1. $ac\equiv bc$: $m\mid(a-b)c$. $g=\gcd(c,m)$, $c=gc'$, $m=gm'$, $\gcd(c',m')=1$.
    2. $gm'\mid(a-b)gc'\Rightarrow m'\mid(a-b)c'$.
    3. Евклид леммасы ($\gcd(m',c')=1$): $m'\mid a-b$.
    4. Демек $a\equiv b\pmod{m'}$, $m'=\frac mg$. ∎
    5. $g=1$: $m'=m$ - модуль өзгермейді.

    ∎

    Қорытып шығару 3: кері элемент

    Мақсат: Теорема 3.3-ті дәлелдеу.

    Идея: Кері элемент = Безу коэффициенті: $ax+my=1$ теңдігін $m$ бойынша қарасақ, $ax\equiv1$.

    1. $\Leftarrow$: $\gcd(a,m)=1$ - Безу: $ax+my=1$, демек $ax\equiv1\pmod m$.
    2. $\Rightarrow$: $ax\equiv1$, яғни $ax-1=my$. $d=\gcd(a,m)$ $ax-my=1$-ді бөледі, $d=1$.
    3. Жалғыздық: $ax\equiv ax'\equiv1$. Онда $a(x-x')\equiv0$; $\gcd(a,m)=1$ - қысқарту: $x\equiv x'\pmod m$.
    4. Жай модуль: $p\nmid a\Rightarrow\gcd(a,p)=1$ ($p$-ның бөлгіштері $1$, $p$). ∎

    ∎

    Қорытып шығару 4: сызықтық салыстыру

    Мақсат: Теорема 3.4-ті дәлелдеу.

    Идея: Салыстыру - Диофант теңдеуі $ax-my=b$. ЕҮОБ-қа бөліп, өзара жай жағдайда кері элементпен шешеміз.

    1. $ax\equiv b\pmod m\iff ax-my=b$ кейбір $y$ үшін. $d=\gcd(a,m)$ сол жақты бөледі, демек шешім бар болса, $d\mid b$.
    2. $d\mid b$: $a=da'$, $b=db'$, $m=dm'$, $\gcd(a',m')=1$. Салыстыру $a'x\equiv b'\pmod{m'}$-мен тең күшті (екі жақты $d$-ға бөлу, модульмен бірге).
    3. Теорема 3.3: $a'$-тің $m'$ модулі бойынша кері элементі бар, шешім $x_0\equiv a'^{-1}b'\pmod{m'}$ - жалғыз.
    4. $m$ модулі бойынша: $x\equiv x_0\pmod{m'}$ болатын кластар $x_0,x_0+m',\dots,x_0+(d-1)m'$ - дәл $d$ шешім ($m=dm'$).
    5. Олар $m$ модулі бойынша әртүрлі: айырмалары $km'$, $0<k<d$, $m$-ге бөлінбейді. ∎

    ∎

    Қорытып шығару 5: жылдам дәрежелеу

    Мақсат: $3^{100}\bmod7$ есептеу және әдістің негіздемесі.

    Идея: Дәреже көрсеткішін екілік жазып, тек квадраттарды есептейміз: $100$-ші дәрежеге $7$ көбейту жеткілікті.

    1. $100=64+32+4$ (екілік: $1100100_2$).
    2. Квадраттар: $3^1\equiv3$, $3^2\equiv2$, $3^4\equiv4$, $3^8\equiv2$, $3^{16}\equiv4$, $3^{32}\equiv2$, $3^{64}\equiv4\pmod7$.
    3. $3^{100}=3^{64}\cdot3^{32}\cdot3^4\equiv4\cdot2\cdot4=32\equiv4\pmod7$.
    4. Тексеру циклмен: $3^6\equiv1\pmod7$ ($3^6=729=104\cdot7+1$), $100=6\cdot16+4$, $3^{100}\equiv3^4\equiv81\equiv4$ ✓.
    5. Көбейтулер саны $\le2\log_2n$ - $n$ мың таңбалы болса да тиімді.

    ∎

    Қадамдық шешілген мысалдар

    Мысал 1. Соңғы цифр

    $7^{2026}$ санының соңғы цифры.

    1. 1-қадам. Соңғы цифр - $\bmod10$.
    2. 2-қадам. $7^1\equiv7$, $7^2\equiv9$, $7^3\equiv3$, $7^4\equiv1\pmod{10}$ - цикл ұзындығы $4$.
    3. 3-қадам. $2026=4\cdot506+2$: $7^{2026}\equiv7^2\equiv9$.
    4. 4-қадам. Соңғы цифр $9$.

    Жауабы: $9$.

    Мысал 2. Кері элемент

    $17^{-1}\bmod43$.

    1. 1-қадам. $43=2\cdot17+9$; $17=1\cdot9+8$; $9=1\cdot8+1$.
    2. 2-қадам. $1=9-8=9-(17-9)=2\cdot9-17=2(43-2\cdot17)-17=2\cdot43-5\cdot17$.
    3. 3-қадам. $-5\cdot17\equiv1\pmod{43}$, $-5\equiv38$.
    4. 4-қадам. Тексеру: $17\cdot38=646=15\cdot43+1$ ✓.

    Жауабы: $38$.

    Мысал 3. Сызықтық салыстыру

    $12x\equiv8\pmod{20}$.

    1. 1-қадам. $\gcd(12,20)=4$, $4\mid8$ - шешім бар, $\pmod{20}$ бойынша дәл $4$.
    2. 2-қадам. $4$-ке бөлеміз: $3x\equiv2\pmod5$.
    3. 3-қадам. $3^{-1}\equiv2\pmod5$ ($3\cdot2=6\equiv1$): $x\equiv4\pmod5$.
    4. 4-қадам. $\pmod{20}$: $x\in\{4,9,14,19\}$. Тексеру: $12\cdot9=108=5\cdot20+8$ ✓.

    Жауабы: $x\equiv4,9,14,19\pmod{20}$.

    Мысал 4. Бөлінгіштік белгісі

    $n=918082$ саны $11$-ге бөліне ме? $9$-ға ше?

    1. 1-қадам. Ауыспалы қосынды (оңнан): $2-8+0-8+1-9=-22\equiv0\pmod{11}$ - бөлінеді.
    2. 2-қадам. Цифрлар қосындысы: $9+1+8+0+8+2=28\equiv1\pmod9$ - бөлінбейді.
    3. 3-қадам. Тексеру: $918082=11\cdot83462$ ✓.

    Жауабы: $11\mid n$, $9\nmid n$.

    Мысал 5. Шешімі жоқ

    $6x\equiv5\pmod{9}$.

    1. 1-қадам. $\gcd(6,9)=3$, $3\nmid5$.
    2. 2-қадам. Теорема 3.4: шешім жоқ.
    3. 3-қадам. Мағынасы: $6x-9y=5$ - сол жағы әрдайым $3$-ке бөлінеді, оң жағы бөлінбейді.

    Жауабы: Шешім жоқ.

    Жиі қателер

    • $ac\equiv bc\pmod m\Rightarrow a\equiv b\pmod m$ → $\pmod{\frac m{\gcd(c,m)}}$
      Неге қате: $4\cdot3\equiv4\cdot6\pmod{12}$.
    • $a^{-1}\bmod m$ әрдайым бар → тек $\gcd(a,m)=1$
      Неге қате: $2^{-1}\bmod6$ жоқ.
    • Дәреже көрсеткішін $\bmod m$ бойынша қысқарту → көрсеткіштер басқа модуль бойынша (Эйлер)
      Неге қате: 4-сабақ.
    • $ax\equiv b\pmod m$-ның әрдайым жалғыз шешімі бар → $0$ не $\gcd(a,m)$ шешім
      Неге қате: $12x\equiv8\pmod{20}$ - 4 шешім.
    • Теріс сан $\bmod m$ теріс → $[0;m)$ аралығына келтіру
      Неге қате: $-5\bmod43=38$.
    • $\mathbb Z_6$-да $2\cdot3=0$ - қате есептеу → нөлдің бөлгіштері
      Неге қате: құрама модульде қалыпты жағдай.

    Визуализация

    Бақылаңыз: $n=0,\dots,m-1$ үшін $a\cdot n\bmod m$ мәндері. $a=5$, $m=12$ ($\gcd=1$): сатылар барлық $0,\dots,11$ мәндерін бір-бірден қабылдайды - көбейту алмастыру, демек $1$ де кездеседі (кері элемент бар). $a=4$ қойыңыз ($\gcd=4$): тек $0,4,8$ - $1$ жоқ, кері элемент жоқ.

    Бақылаңыз: $7^n\bmod10$ тізбегі $1,7,9,3,1,7,9,3,\dots$ - периоды $4$. Сондықтан $7^n\bmod10$ тек $n\bmod4$-ке тәуелді: дәреже көрсеткіші $4$ модулі бойынша «жұмыс істейді», $10$ бойынша емес (Эйлер теоремасы, 4-сабақ: $\varphi(10)=4$).

    Қолданыс және мини-жоба

    Қолданыс. Модуль бойынша арифметика - компьютердің өзінің арифметикасы ($32$/$64$-биттік бүтін сандар $2^{32}$, $2^{64}$ модулі бойынша), бақылау цифрлары (ISBN, IBAN, Луна алгоритмі - банк карталары), хэш-функциялар, псевдокездейсоқ генераторлар ($x_{n+1}=ax_n+c\bmod m$), криптография.

    Мини-жоба: «Модуль бойынша калькулятор». Жылдам дәрежелеуді өзіміз жазып, Python-ның pow(a, n, m) функциясымен салыстырамыз, сызықтық салыстыруды шешетін функция жазамыз және Луна алгоритмімен карта нөмірінің бақылау цифрын тексереміз.

    def power(a, n, m):
    result, base = 1, a % m
    while n > 0:
        if n & 1:
            result = result * base % m
        base = base * base % m
        n >>= 1
    return result

for a, n, m in [(3, 100, 7), (5, 117, 19), (7, 2026, 10), (2, 10**18, 10**9 + 7)]:
    print(f"{a}^{n} mod {m} = {power(a, n, m)}  (pow: {pow(a, n, m)})")

def ext_gcd(a, b):
    if b == 0:
        return a, 1, 0
    g, x, y = ext_gcd(b, a % b)
    return g, y, x - (a // b) * y

def solve_linear(a, b, m):
    g, x, _ = ext_gcd(a, m)
    if b % g:
        return []
    m1 = m // g
    x0 = x * (b // g) % m1
    return [x0 + k * m1 for k in range(g)]

print("12x ≡ 8 (mod 20):", solve_linear(12, 8, 20))
print(" 6x ≡ 5 (mod 9): ", solve_linear(6, 5, 9))

def luhn_ok(number):
    digits = [int(c) for c in str(number)][::-1]
    s = sum(d if i % 2 == 0 else (2 * d - 9 if 2 * d > 9 else 2 * d) for i, d in enumerate(digits))
    return s % 10 == 0

print("Лун:", luhn_ok(4539578763621486), luhn_ok(4539578763621487))
