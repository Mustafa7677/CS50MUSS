Мазмұны

    Numerical Analysis · 3-сабақ

    Сызықтық жүйелерді сандық шешу

    Инженерлік есептеулер, графика, машиналық оқыту - бәрі ақырында $A\mathbf x=\mathbf b$ жүйесін шешуге келеді, кейде миллиондаған белгісізбен. Бұл сабақта Гаусс әдісінің жұмыс көлемін ($\approx\frac23n^3$) есептейміз, «бас элементті таңдау» (pivoting) неге міндетті екенін көрсетеміз, LU жіктелуін қолданамыз, матрицаның шарттылық санымен шешімнің сезімталдығын бағалаймыз және үлкен жүйелерге арналған итерациялық әдістерді (Якоби, Гаусс–Зейдель) және олардың жинақталу шартын үйренеміз.

    Сабақ мақсаттары

    Сабақ соңында сіз мыналарды істей аласыз:

    • Гаусс әдісінің амалдар санын бағалау ($\approx\frac23n^3$) және LU жіктелуін бірнеше оң жақпен шешуге қолдану;
    • бас элементті таңдаудың (partial pivoting) қажеттілігін мысалмен көрсету;
    • вектор мен матрица нормаларын ($\|\cdot\|_\infty$) және шарттылық санын $\kappa(A)=\|A\|\|A^{-1}\|$ есептеу;
    • $\frac{\|\delta\mathbf x\|}{\|\mathbf x\|}\le\kappa(A)\frac{\|\delta\mathbf b\|}{\|\mathbf b\|}$ бағасын дәлелдеу;
    • Якоби және Гаусс–Зейдель итерацияларын орындау;
    • диагоналі басым матрицада итерацияның жинақталатынын түсіндіру.

    Қысқаша еске салу

    Матрицаны векторға көбейту, кері матрица $A^{-1}$ ($AA^{-1}=I$), Гаусс әдісі (жолдармен элементар түрлендірулер), үшбұрышты жүйені кері қоюмен шешу. Қосынды $\sum_{k=1}^nk^2=\frac{n(n+1)(2n+1)}6\approx\frac{n^3}3$. Дөңгелектеу қатесі мен шарттылық ұғымы (1-сабақ).

    Интуиция

    Мектептегі Гаусс әдісі қағазда тамаша жұмыс істейді. Компьютерде екі мәселе бар. Біріншісі - жылдамдық: $n=10\,000$ болса, $\frac23n^3\approx7\cdot10^{11}$ амал. Екіншісі - дәлдік: егер «бас элемент» (бөлгіш) кездейсоқ өте кішкене болса, бөлу дөңгелектеу қатесін алып санға айналдырады. Шешім қарапайым: әр бағанда модулі ең үлкен элементті жоғарыға алып шығамыз.

    Кейбір жүйелер өздері «сезімтал». $x+2y=3$, $1{,}001x+2y=3{,}001$ түзулері іс жүзінде параллель; оң жақты $0{,}001$-ге өзгертсек, шешім $(1,1)$-ден $(0;1{,}5)$-ке «секіреді». Мұндай матрицаның шарттылық саны үлкен ($\approx6000$): кірістің салыстырмалы қатесі шешімде 6000 есе күшеюі мүмкін. Бұл - есептің қасиеті, алгоритмдікі емес.

    Үлкен «сирек» (көп элементі нөл) жүйелерде Гаусс әдісі тиімсіз: ол нөлдерді толтырып жібереді. Оның орнына итерация: $x_1$-ді бірінші теңдеуден, $x_2$-ні екіншісінен... басқаларын алдыңғы жуықтаудан алып есептейміз, және қайталаймыз. Егер әр теңдеуде диагональ коэффициенті «басым» болса, бұл процесс шешімге жинақталады.

    Ереже: бағдарламада $A^{-1}$-ді ешқашан тікелей есептеп, $\mathbf b$-ға көбейтпеңіз. LU жіктелуі әрі жылдамырақ, әрі дәлірек; кері матрица тек өзі қажет болғанда ғана.

    Анықтамалар мен теоремалар

    Теорема 3.1 · Гаусс әдісінің жұмыс көлемі

    $n\times n$ жүйені Гаусс әдісімен шешу шамамен $\frac23n^3$ көбейту/қосу амалын қажет етеді (тура жүріс), ал үшбұрышты жүйені кері қоюмен шешу - $\approx n^2$.

    Негіздеме. 1-қорыту.

    Анықтама 3.1 · LU жіктелуі

    $A=LU$, мұнда $L$ - диагоналі бірлер төменгі үшбұрышты, $U$ - жоғарғы үшбұрышты матрица - LU жіктелуі (LU decomposition). Бас элементті таңдаумен: $PA=LU$, $P$ - алмастыру матрицасы. Сонда $A\mathbf x=\mathbf b$ екі үшбұрышты жүйеге бөлінеді: $L\mathbf y=P\mathbf b$, $U\mathbf x=\mathbf y$ ($\approx2n^2$ амал).

    Анықтама 3.2 · Бас элементті таңдау

    Бас элементті таңдау (partial pivoting): $k$-қадамда $k$-бағанның $k..n$ жолдарынан модулі ең үлкен элементті тауып, оның жолын $k$-жолмен ауыстырамыз. Сонда барлық көбейткіштер $|l_{ik}|\le1$.

    Анықтама 3.3 · Нормалар

    Вектордың максимум нормасы (infinity norm) $\|\mathbf x\|_\infty=\max_i|x_i|$. Оған сәйкес матрица нормасы $\|A\|_\infty=\max_i\sum_j|a_{ij}|$ (жолдар қосындысының максимумы); ол $\|A\mathbf x\|\le\|A\|\|\mathbf x\|$ және $\|AB\|\le\|A\|\|B\|$ қасиеттерін қанағаттандырады.

    Анықтама 3.4 · Матрицаның шарттылық саны

    Айрықша емес $A$ үшін матрицаның шарттылық саны (condition number of a matrix) $\kappa(A)=\|A\|\,\|A^{-1}\|\ge1$. $\kappa$ үлкен болса, жүйе жаман шартталған.

    Теорема 3.2 · Шешімнің сезімталдығы

    $A\mathbf x=\mathbf b$ ($\mathbf b\ne0$) және $A(\mathbf x+\delta\mathbf x)=\mathbf b+\delta\mathbf b$ болса, $$\frac{\|\delta\mathbf x\|}{\|\mathbf x\|}\le\kappa(A)\,\frac{\|\delta\mathbf b\|}{\|\mathbf b\|}.$$

    Негіздеме. 2-қорыту. Ереже: $\kappa\approx10^k$ болса, шешімде шамамен $k$ ондық цифр жоғалуы мүмкін.

    Анықтама 3.5 · Итерациялық әдістер

    $A=D+L+U$ (диагональ, қатаң төменгі, қатаң жоғарғы бөліктер). Якоби әдісі (Jacobi method): $x_i^{(k+1)}=\frac{1}{a_{ii}}\Big(b_i-\sum_{j\ne i}a_{ij}x_j^{(k)}\Big)$. Гаусс–Зейдель әдісі (Gauss–Seidel method): сол формула, бірақ $j<i$ үшін жаңа $x_j^{(k+1)}$ мәндері бірден қолданылады.

    Теорема 3.3 · Диагональ басымдығы жеткілікті

    $A$ жолдар бойынша қатаң диагоналі басым (diagonally dominant) болса ($|a_{ii}|>\sum_{j\ne i}|a_{ij}|$ әр $i$ үшін), онда Якоби және Гаусс–Зейдель әдістері кез келген бастапқы векторда жалғыз шешімге жинақталады.

    Негіздеме. Якоби үшін 3-қорыту; Гаусс–Зейдель үшін дәлел ұқсас, бірақ ұзынырақ, оны келтірмейміз.

    Формула 3.1 · Шарттылық бағасы
    $$\frac{\|\delta\mathbf x\|}{\|\mathbf x\|}\le\kappa(A)\frac{\|\delta\mathbf b\|}{\|\mathbf b\|},\qquad\kappa(A)=\|A\|\|A^{-1}\|$$

    Шарты: $A$ айрықша емес, $\mathbf b\ne\mathbf0$. $A$-ның өзі $\delta A$-ға бұзылса, ұқсас (күрделірек) баға бар.

    Формула 3.2 · Якоби итерациясы
    $$x_i^{(k+1)}=\frac{1}{a_{ii}}\Big(b_i-\sum_{j\ne i}a_{ij}x_j^{(k)}\Big)$$

    $a_{ii}\ne0$. Матрица түрінде: $\mathbf x^{(k+1)}=D^{-1}(\mathbf b-(L+U)\mathbf x^{(k)})$.

    Формула 3.3 · Жұмыс көлемі
    $$W(n,m)\approx\tfrac23n^3+2mn^2$$

    Бір матрицаны LU-ға бір рет жіктеу ($\frac23n^3$) және $m$ оң жақтың әрқайсысы үшін екі үшбұрышты жүйе ($2n^2$). Әр оң жаққа Гаусс әдісін қайталау $\frac23mn^3$ болар еді.

    Есте сақта

    Практикалық ережелер: 1) әрдайым бас элементті таңдаңыз; 2) $A^{-1}\mathbf b$ емес, LU + екі үшбұрышты жүйе; 3) $\kappa(A)$-ны бағалаңыз - ол дәлдіктің шегін көрсетеді; 4) үлкен сирек жүйелер - итерациялық әдістер.

    Назар аудар

    Қалдықтың $\|A\tilde{\mathbf x}-\mathbf b\|$ кіші болуы шешімнің дәл екенін білдірмейді: жаман шартталған жүйеде қалдық $10^{-10}$ болса да, шешім қатесі $\kappa\cdot10^{-10}$ ретті болуы мүмкін. Сондай-ақ анықтауыштың кіші болуы жаман шартталудың өлшемі емес: $10^{-1}I$ ($n=20$) - $\det=10^{-20}$, бірақ $\kappa=1$.

    Қорытып шығару

    Қорытып шығару 1: Гаусс әдісінің амалдар саны

    Мақсат: тура жүрістегі көбейтулер санын бағалау.

    1. $k$-қадамда ($k=1..n-1$) $k$-жолдан төмен $n-k$ жолдың әрқайсысында $n-k$ элементті (оң жағын қоса $n-k+1$) жаңартамыз: әрқайсысында бір көбейту мен бір азайту.
    2. Матрица бөлігі үшін көбейтулер: $\sum_{k=1}^{n-1}(n-k)^2=\sum_{m=1}^{n-1}m^2=\frac{(n-1)n(2n-1)}6\approx\frac{n^3}3$.
    3. Сонша азайту да бар: барлығы $\approx\frac23n^3$ арифметикалық амал (бөлулер мен оң жақ $O(n^2)$).
    4. Кері қою: $i$-теңдеуде $n-i$ көбейту, барлығы $\approx\frac{n^2}2$ көбейту ($\approx n^2$ амал).
    5. Мысал: $n=1000$ - тура жүріс $\approx6{,}7\cdot10^8$ амал, кері қою $\approx10^6$.

    ∎

    Қорытып шығару 2: шарттылық бағасы

    Мақсат: $\frac{\|\delta\mathbf x\|}{\|\mathbf x\|}\le\kappa(A)\frac{\|\delta\mathbf b\|}{\|\mathbf b\|}$ дәлелдеу.

    1. Айырмасын аламыз: $A\delta\mathbf x=\delta\mathbf b$, яғни $\delta\mathbf x=A^{-1}\delta\mathbf b$.
    2. Норма қасиеті: $\|\delta\mathbf x\|\le\|A^{-1}\|\|\delta\mathbf b\|$.
    3. Ал $\mathbf b=A\mathbf x$, сондықтан $\|\mathbf b\|\le\|A\|\|\mathbf x\|$, яғни $\frac{1}{\|\mathbf x\|}\le\frac{\|A\|}{\|\mathbf b\|}$ ($\mathbf x\ne0$, себебі $\mathbf b\ne0$).
    4. Көбейтеміз: $\frac{\|\delta\mathbf x\|}{\|\mathbf x\|}\le\|A^{-1}\|\|A\|\frac{\|\delta\mathbf b\|}{\|\mathbf b\|}=\kappa(A)\frac{\|\delta\mathbf b\|}{\|\mathbf b\|}$. ∎
    5. $\kappa\ge1$: $1=\|I\|=\|AA^{-1}\|\le\|A\|\|A^{-1}\|$.

    ∎

    Қорытып шығару 3: Якоби әдісінің жинақталуы

    Мақсат: қатаң диагоналі басым матрицада Якоби итерациясы жинақталатынын көрсету.

    1. Шын шешім $\mathbf x^*$ де тепе-теңдікті қанағаттандырады: $x_i^*=\frac{1}{a_{ii}}\big(b_i-\sum_{j\ne i}a_{ij}x_j^*\big)$.
    2. Қате $\mathbf e^{(k)}=\mathbf x^{(k)}-\mathbf x^*$: айырсақ, $e_i^{(k+1)}=-\frac{1}{a_{ii}}\sum_{j\ne i}a_{ij}e_j^{(k)}$.
    3. Модульмен: $|e_i^{(k+1)}|\le\frac{\sum_{j\ne i}|a_{ij}|}{|a_{ii}|}\|\mathbf e^{(k)}\|_\infty\le q\|\mathbf e^{(k)}\|_\infty$, мұнда $q=\max_i\frac{\sum_{j\ne i}|a_{ij}|}{|a_{ii}|}$.
    4. Диагональ басымдығы бойынша $q<1$. Демек $\|\mathbf e^{(k)}\|_\infty\le q^k\|\mathbf e^{(0)}\|_\infty\to0$.
    5. Жалғыз шешімнің бар болуы да осыдан шығады: $A$ айрықша емес (әйтпесе $A\mathbf v=0$, $\mathbf v\ne0$ үшін ең үлкен $|v_i|$ жолы басымдыққа қайшы).

    ∎

    Қадамдық шешілген мысалдар

    Мысал 1. Бас элементті таңдау

    $10^{-20}x+y=1$, $x+y=2$ жүйесін double арифметикасында екі тәсілмен шешіңіз.

    1. 1-қадам. Шын шешім: $x=\frac{1}{1-10^{-20}}\approx1$, $y\approx1$.
    2. 2-қадам. Таңдаусыз: көбейткіш $10^{20}$. Екінші теңдеу: $(1-10^{20})y=2-10^{20}$; double-да $1-10^{20}=-10^{20}$ және $2-10^{20}=-10^{20}$, сондықтан $y=1$.
    3. 3-қадам. Бірінші теңдеуден $x=\frac{1-y}{10^{-20}}=0$ - толық қате!
    4. 4-қадам. Таңдаумен: жолдарды ауыстырамыз ($|1|>10^{-20}$). Көбейткіш $10^{-20}$: $(1-10^{-20})y=1-2\cdot10^{-20}$, double-да $y=1$; $x=2-y=1$ ✓.

    Жауабы: Таңдаусыз $x=0$ (қате), таңдаумен $x=1$, $y=1$.

    Мысал 2. Шарттылық саны

    $A=\begin{pmatrix}1&2\\1{,}001&2\end{pmatrix}$. $\kappa_\infty(A)$ және $\mathbf b=(3;3{,}001)^T$ болғанда оң жақты $(3;3)^T$-ке өзгерткендегі әсер.

    1. 1-қадам. $\det A=2-2{,}002=-0{,}002$; $A^{-1}=\frac{1}{-0{,}002}\begin{pmatrix}2&-2\\-1{,}001&1\end{pmatrix}=\begin{pmatrix}-1000&1000\\500{,}5&-500\end{pmatrix}$.
    2. 2-қадам. $\|A\|_\infty=3{,}001$, $\|A^{-1}\|_\infty=2000$, $\kappa\approx6002$.
    3. 3-қадам. $\mathbf b=(3;3{,}001)$: $\mathbf x=(1;1)$. $\mathbf b=(3;3)$: $\mathbf x=(0;1{,}5)$.
    4. 4-қадам. Оң жақтың салыстырмалы өзгерісі $\frac{0{,}001}{3{,}001}\approx3{,}3\cdot10^{-4}$, шешімдікі $\frac{1}{1}=1$ - шамамен 3000 есе күшейді ($\le\kappa$ ✓).

    Жауабы: $\kappa\approx6002$.

    Мысал 3. Якоби

    $4x_1-x_2+x_3=8$, $2x_1+5x_2+2x_3=3$, $x_1+2x_2+4x_3=11$ Бастапқы $\mathbf x^{(0)}=0$, 2 итерация.

    1. 1-қадам. Диагональ басымдығы: $4>2$, $5>4$, $4>3$ ✓.
    2. 2-қадам. $x^{(1)}=\left(\frac84;\frac35;\frac{11}4\right)=(2;\ 0{,}6;\ 2{,}75)$.
    3. 3-қадам. $x_1^{(2)}=\frac{8+0{,}6-2{,}75}{4}=1{,}4625$; $x_2^{(2)}=\frac{3-4-5{,}5}{5}=-1{,}3$; $x_3^{(2)}=\frac{11-2-1{,}2}{4}=1{,}95$.
    4. 4-қадам. Шын шешім $(1;-1;3)$; итерациялар оған жақындайды.

    Жауабы: $\mathbf x^{(2)}=(1{,}4625;\ -1{,}3;\ 1{,}95)$.

    Мысал 4. Гаусс–Зейдель

    Сол жүйе, $\mathbf x^{(0)}=0$, 2 итерация.

    1. 1-қадам. $x_1=\frac84=2$; $x_2=\frac{3-2\cdot2-0}{5}=-0{,}2$; $x_3=\frac{11-2-2(-0{,}2)}{4}=2{,}35$.
    2. 2-қадам. 2-итерация: $x_1=\frac{8-0{,}2-2{,}35}{4}=1{,}3625$; $x_2=\frac{3-2{,}725-4{,}7}{5}=-0{,}885$; $x_3=\frac{11-1{,}3625+1{,}77}{4}\approx2{,}852$.
    3. 3-қадам. Шын шешімнен ауытқуы ($\infty$-нормада): Якоби $\approx1{,}05$, Гаусс–Зейдель $\approx0{,}36$ - Гаусс–Зейдель тезірек.

    Жауабы: $\mathbf x^{(2)}\approx(1{,}3625;\ -0{,}885;\ 2{,}852)$.

    Жиі қателер

    • $\mathbf x=A^{-1}\mathbf b$ деп кері матрицаны есептеу → LU + екі үшбұрышты жүйе
      Неге қате: кері матрица 3 есе қымбат және дәлдігі нашар.
    • Бас элементті таңдамау (нөл емес болса жеткілікті) → модулі ең үлкенін таңдау
      Неге қате: 1-мысал: $10^{-20}$ нөл емес, бірақ нәтиже толық қате.
    • $\det A$ кіші - жүйе жаман шартталған → $\kappa(A)$-ға қарау
      Неге қате: $0{,}1I$: $\det$ өте кіші, $\kappa=1$.
    • Қалдық кіші - шешім дәл → шешім қатесі $\lesssim\kappa\cdot$ салыстырмалы қалдық
      Неге қате: жаман шартталған жүйеде қалдық алдайды.
    • Якобиді кез келген матрицаға қолдану → жинақталу шартын тексеру
      Неге қате: диагональ басым емес матрицада итерация тарап кетуі мүмкін.
    • $\|A\|_\infty$ - бағандар қосындысының максимумы → жолдар қосындысының максимумы
      Неге қате: бағандар - $\|A\|_1$ нормасы.

    Визуализация

    Бақылаңыз: Бұл матрица жазықтықты дерлік бір түзуге «жаншады»: бірлік шаршы өте жіңішке параллелограмға айналады (анықтауыш $-0{,}002$). Кері түрлендіру сол жіңішке бағытты 1000 еседен көп созады - сондықтан $\mathbf b$-ның кішкене өзгерісі $\mathbf x$-ті қатты өзгертеді. Слайдерлермен $c$ элементін өзгертіп, параллелограммның «ашылуын» бақылаңыз.

    Бақылаңыз: Якобидің қатесі $q^k$-тан тез емес кемиді, мұнда $q=\max_i\frac{\sum_{j\ne i}|a_{ij}|}{|a_{ii}|}$; біздің жүйеде $q=0{,}8$. Кейбір матрица кластарында (мысалы, үшдиагональды) Гаусс–Зейдель шамамен екі есе жылдам ($q^{2k}$); жалпы жағдайда бұл кепілді емес. $q\to1$ болса, итерация өте баяулайды.

    Қолданыс және мини-жоба

    Қолданыс. Ақырлы элементтер әдісі (құрылыс, аэродинамика), схемаларды талдау, ең кіші квадраттар (машиналық оқыту), PageRank (итерациялық әдіс), графикадағы түрлендірулер. NumPy-дағы numpy.linalg.solve LAPACK кітапханасының LU-pivoting әдісін қолданады.

    Мини-жоба: «Гаусс, pivoting, итерация». Бас элементті таңдаумен Гаусс әдісін, Якоби мен Гаусс–Зейдельді жазып, Гильберт матрицасының шарттылығын зерттейміз.

    from fractions import Fraction

def gauss(A, b, pivot=True):
    n = len(A); M = [row[:] + [bi] for row, bi in zip(A, b)]
    for k in range(n):
        if pivot:
            p = max(range(k, n), key=lambda i: abs(M[i][k])); M[k], M[p] = M[p], M[k]
        for i in range(k + 1, n):
            l = M[i][k] / M[k][k]
            for j in range(k, n + 1): M[i][j] -= l * M[k][j]
    x = [0.0] * n
    for i in reversed(range(n)):
        x[i] = (M[i][n] - sum(M[i][j] * x[j] for j in range(i + 1, n))) / M[i][i]
    return x

A = [[1e-20, 1.0], [1.0, 1.0]]; b = [1.0, 2.0]
print("таңдаусыз:", gauss(A, b, False), " таңдаумен:", gauss(A, b, True))

def jacobi(A, b, it, seidel=False):
    n = len(A); x = [0.0] * n
    for _ in range(it):
        new = x[:] if not seidel else x
        for i in range(n):
            s = sum(A[i][j] * (new[j] if seidel else x[j]) for j in range(n) if j != i)
            new[i] = (b[i] - s) / A[i][i]
        x = new
    return x
S = [[4, -1, 1], [2, 5, 2], [1, 2, 4]]; c = [8, 3, 11]
print("Якоби 20:", [round(v, 6) for v in jacobi(S, c, 20)])
print("Гаусс-Зейдель 10:", [round(v, 6) for v in jacobi(S, c, 10, seidel=True)])

# Гильберт матрицасы: дәл (бөлшектермен) және float шешімдерді салыстыру
n = 10
H = [[1 / (i + j + 1) for j in range(n)] for i in range(n)]
x_true = [1.0] * n
bh = [sum(H[i][j] for j in range(n)) for i in range(n)]
x_float = gauss(H, bh)
print("Гильберт n=10, float шешімнің ең үлкен қатесі:", max(abs(v - 1) for v in x_float))
