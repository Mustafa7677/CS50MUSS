    Санау әдістері және рекуррентті қатынастар

    Көп санау есептерін бірден формуламен шешу қиын, бірақ «$n$-ші жауапты алдыңғыларымен байланыстыру» оңай. Ханой мұнаралары, Фибоначчи сандары, ешкімнің өз орнына түспейтін орналасулары - бәрі осылай шешіледі.

    Бір сөйлеммен

    Күрделі санау есептерін екі тәсілмен шешеміз: артық санағанды түзету (қосу-шегеру) және «$n$-ші жауапты алдыңғылары арқылы» өрнектеу (рекуррентті қатынас).

    Сабақ мақсаттары

    Сабақ соңында сіз мыналарды істей аласыз:

    • жалпы қосу-шегеру формуласын қолдану және «бұзылған орналасулар» санын $D_n$ табу;
    • есептің шартынан рекуррентті қатынас және бастапқы шарттарды құру;
    • $a_n=c_1a_{n-1}+c_2a_{n-2}$ түріндегі рекурренттерді сипаттамалық теңдеумен шешу (әртүрлі және қайталанатын түбірлер);
    • Бине формуласын қорытып, $F_{n+1}/F_n\to\varphi$ екенін түсіндіру;
    • $a_n=ca_{n-1}+d$ түріндегі біртекті емес рекуррентті шешу;
    • $T(n)=2T(n/2)+n$ сияқты рекурренттерді «ашу» арқылы бағалау.

    Қысқаша еске салу

    Санау: $C_n^k=\frac{n!}{k!(n-k)!}$, Ньютон биномы $\sum_kC_n^k(-1)^k=0$ ($n\ge1$). Квадрат теңдеу $r^2-pr-q=0$ түбірлері $r=\frac{p\pm\sqrt{p^2+4q}}{2}$. Геометриялық прогрессия: $1+c+\dots+c^{n-1}=\frac{c^n-1}{c-1}$ ($c\ne1$). Математикалық индукция (рекуррент шешімін тексеру үшін). $e^{-1}=\sum_{k\ge0}\frac{(-1)^k}{k!}$.

    Алдымен қолмен: баспалдаққа шығу

    Формулаға дейін нақты сандармен ойнап көрейік. Әр қадамды өзіңіз де қағазда қайталаңыз.

    Баспалдаққа бір не екі сатыдан аттап шығамыз. $5$ сатылы баспалдаққа неше тәсілмен шығуға болады?

    1. $a_n$ - $n$ сатыға шығу тәсілдері. Соңғы қадам не $1$, не $2$ саты: $a_n=a_{n-1}+a_{n-2}$.
    2. $a_1=1$ (тек $1$), $a_2=2$ ($1+1$ не $2$).
    3. $a_3=3$, $a_4=5$, $a_5=8$.
    4. Фибоначчи сандары! Тексеру: $5$-ке $1,2$ қадамдармен $8$ құрам: $11111$, $2111$-тің $4$ орналасуы, $221$-дің $3$ орналасуы ✓.

    Байқадыңыз ба? «Соңғы қадамға қарап» есепті кішірек есептерге бөлеміз - рекуррент шығады. Бұл динамикалық бағдарламалаудың идеясы.

    Интуиция

    Ханой мұнарасы: үш діңгек, біріншісінде $n$ диск (үлкені төменде). Бір қадамда бір дискіні ауыстырамыз, үлкенін кішісінің үстіне қоюға болмайды. Барлығын үшінші діңгекке көшіру үшін ең аз неше қадам керек? Үлкен дискіні жылжыту үшін алдымен үстіндегі $n-1$ дискіні көшіру керек, сосын үлкенін, сосын тағы $n-1$-ді. Демек $H_n=2H_{n-1}+1$. Бұл - рекуррентті қатынас: үлкен есеп кішісі арқылы.

    Рекуррентті қатынас - рекурсивті бағдарлама сияқты: оған «база» (бастапқы мән) және «қадам» керек. Бірақ бағдарлама $H_{64}$-ті есептеу үшін 63 рет өзін шақырады, ал жабық формула $H_n=2^n-1$ бірден жауап береді. Рекуррентті «шешу» - жабық формуланы табу.

    Фибоначчи сандары $F_n=F_{n-1}+F_{n-2}$ табиғатта (гүл жапырақтары, күнбағыс тұқымдары) және алгоритмдерде (Евклид алгоритмінің ең нашар жағдайы) кездеседі. Олардың жабық формуласында иррационал $\sqrt5$ бар, бірақ нәтиже әрдайым бүтін - сипаттамалық теңдеу әдісінің күші осында.

    Қосу-шегеру: «ешбір хат өз конвертіне түспеуі» есебін тура санау қиын. Бірақ «кемінде бір хат өз орнында» оқиғаларын қиылыстарымен санау оңай, сосын «артық санағанды» кезекпен түзетеміз. Таңқаларлық нәтиже: $n$ үлкен болса, ешкім өз орнына түспеу ықтималдығы $\frac1e\approx0{,}368$-ге жақындайды.

    Өмірден ұқсастық · қонақтар тізімі

    Футбол не шахмат ойнайтындарды санағанда, екеуін де ойнайтындар екі рет саналады - оларды бір рет шегереміз. Үш үйірме болса, түзетулер кезектесіп: қосу, шегеру, қосу. Бұл - қосу-шегеру принципі.

    Өмірден ұқсастық · пайыздық салым

    $a_n=1{,}1a_{n-1}+100$ - әр жылы $10\%$ өсіп, $100$ қосылатын салым. Рекуррент тек «келесі қадамды» айтады; оны шешу - кез келген $n$ үшін тікелей формула табу.

    Анықтамалар мен теоремалар

    Теорема 4.1 · Жалпы қосу-шегеру принципі

    Ақырлы $A_1,\dots,A_n$ жиындары үшін $$\Big|\bigcup_{i=1}^nA_i\Big|=\sum_i|A_i|-\sum_{i<j}|A_i\cap A_j|+\sum_{i<j<k}|A_i\cap A_j\cap A_k|-\dots+(-1)^{n+1}|A_1\cap\dots\cap A_n|.$$ Бұл - қосу-шегеру принципі (inclusion-exclusion principle).

    Қарапайым тілмен: Бірігудің элементтер санын: жеке жиындарды қосып, қос қиылысуларды шегеріп, үштік қиылысуларды қайта қосып, т.с.с. табамыз.

    Негіздеме. 1-қорыту.

    Анықтама 4.1 · Бұзылған орналасу

    $\{1,\dots,n\}$-нің ешбір элементі өз орнында тұрмайтын алмастыруы бұзылған орналасу (derangement) деп аталады; саны $D_n$.

    Қарапайым тілмен: Бұзылған орналасу - барлық элемент өз орнынан ауысқан алмастыру (хаттарды бәрін қате конвертке салу).

    Анықтама 4.2 · Рекуррентті қатынас

    $a_n$ мүшесін алдыңғы мүшелер арқылы өрнектейтін теңдеу рекуррентті қатынас (recurrence relation) деп аталады. $a_n=c_1a_{n-1}+\dots+c_ka_{n-k}$ ($c_i$ - тұрақты, $c_k\ne0$) - $k$-ретті сызықтық біртекті рекуррент (linear homogeneous recurrence); оның сипаттамалық теңдеуі (characteristic equation) $r^k=c_1r^{k-1}+\dots+c_k$. Шешім $k$ бастапқы шартпен ($a_0,\dots,a_{k-1}$) бірмәнді анықталады.

    Қарапайым тілмен: Рекуррентті қатынас - келесі мүшені алдыңғылары арқылы беретін ереже.

    Теорема 4.2 · Екінші ретті рекуррентті шешу

    $a_n=c_1a_{n-1}+c_2a_{n-2}$, $c_2\ne0$, сипаттамалық теңдеу $r^2-c_1r-c_2=0$. (1) Әртүрлі түбірлер $r_1\ne r_2$ (комплекс те болуы мүмкін): $a_n=\alpha r_1^n+\beta r_2^n$. (2) Қайталанатын түбір $r_0$: $a_n=(\alpha+\beta n)r_0^n$. $\alpha,\beta$ бастапқы шарттардан табылады.

    Қарапайым тілмен: Сипаттамалық теңдеудің түбірлерін тауып, шешімді $Ar_1^n+Br_2^n$ түрінде жазамыз; $A$, $B$ бастапқы шарттардан.

    Негіздеме. 2-қорыту: (1) жағдайдың дәлелі; (2) $r_0^n$ және $nr_0^n$ шешім екенін тікелей қою арқылы тексеруге болады ($r_0=\frac{c_1}{2}$, $c_1^2+4c_2=0$ пайдаланылады).

    Теорема 4.3 · Бине формуласы

    $F_0=0$, $F_1=1$, $F_n=F_{n-1}+F_{n-2}$ болса, $$F_n=\frac{\varphi^n-\psi^n}{\sqrt5},\qquad\varphi=\frac{1+\sqrt5}{2},\ \psi=\frac{1-\sqrt5}{2}.$$ $|\psi|<1$ болғандықтан $F_n$ - $\frac{\varphi^n}{\sqrt5}$-тің ең жақын бүтін саны, және $\frac{F_{n+1}}{F_n}\to\varphi$.

    Қарапайым тілмен: Фибоначчи сандарының нақты формуласы алтын қиманың дәрежелері арқылы.

    Негіздеме. 3-қорыту.

    Теорема 4.4 · Бірінші ретті біртекті емес рекуррент

    $a_n=ca_{n-1}+d$, $c\ne1$ болса, $a_n=c^n\left(a_0-p\right)+p$, мұнда $p=\frac{d}{1-c}$ - тұрақты шешім. $c=1$ болса, $a_n=a_0+nd$.

    Қарапайым тілмен: $a_n=ca_{n-1}+d$ рекурренті - қозғалмайтын нүктеден ауытқу $c$ есе көбейеді.

    Негіздеме. $b_n=a_n-p$ айырмасы $b_n=cb_{n-1}$ біртекті рекурренті қанағаттандырады, демек $b_n=c^nb_0$.

    Формула 4.1 · Бұзылған орналасулар
    $$D_n=n!\sum_{k=0}^{n}\frac{(-1)^k}{k!},\qquad D_n=(n-1)(D_{n-1}+D_{n-2})$$

    $D_1=0$, $D_2=1$, $D_3=2$, $D_4=9$, $D_5=44$. $\frac{D_n}{n!}\to e^{-1}$.

    Формула 4.2 · Ханой мұнарасы
    $$H_n=2H_{n-1}+1,\ H_1=1\ \Longrightarrow\ H_n=2^n-1$$

    Төменгі баға: үлкен дискіні жылжыту үшін басқалары бір діңгекте жиналуы керек, сондықтан $2^n-1$-ден аз мүмкін емес.

    Формула 4.3 · Бөл де билей
    $$T(n)=2T(n/2)+n,\ T(1)=0\ \Longrightarrow\ T(n)=n\log_2n$$

    $n=2^m$ үшін; сұрыптау (merge sort) салыстыруларының ретін береді.

    Есте сақта

    Рекуррентті шешу жоспары: 1) шарттан $a_n$-ді кіші есептер арқылы өрнектеу (соңғы қадамға қарап бөлу); 2) бастапқы шарттарды табу; 3) бірнеше мүшені есептеп, заңдылықты көру; 4) сипаттамалық теңдеу не «ашу»; 5) формуланы бастапқы мүшелермен және индукциямен тексеру.

    Назар аудар

    Бастапқы шарттарды ұмытпаңыз: $a_n=a_{n-1}+a_{n-2}$ рекуррентін Фибоначчи де ($1,1,2,3,\dots$), Люка сандары да ($2,1,3,4,7,\dots$) қанағаттандырады. Рекуррент тек «ережені» береді, ал нақты тізбекті бастапқы мәндер анықтайды. Сондай-ақ сипаттамалық теңдеу әдісі тек тұрақты коэффициентті сызықтық рекурренттерге жарайды.

    Тоқта, ойлан

    Әрі қарай жүрмес бұрын, өзіңізді тексеріңіз: алдымен жауапты ойланыңыз, сосын ашыңыз.

    1. $1$-ден $100$-ге дейін $2$-ге не $3$-ке бөлінетін сандар саны?

    $50+33-16=67$.

    2. $D_3$ неге тең?

    $2$: $(2,3,1)$ және $(3,1,2)$.

    3. $a_n=2a_{n-1}$, $a_0=3$ шешімі?

    $a_n=3\cdot2^n$.

    4. $F_{n+1}/F_n$ неге ұмтылады?

    Алтын қимаға $\varphi\approx1{,}618$.

    Қорытып шығару

    Қорытып шығару 1: қосу-шегеру принципі

    Мақсат: кез келген элемент оң жақта дәл бір рет саналатынын дәлелдеу.

    Идея: Бірігудің әр элементі формулада неше рет саналатынын есептейміз: $m$ жиында болса, $\sum(-1)^{k+1}C_m^k=1$ рет.

    1. Бірігуге жататын $x$ элемент дәл $m\ge1$ жиынға тиесілі болсын.
    2. Ол $\sum|A_i|$-де $m=C_m^1$ рет, $\sum|A_i\cap A_j|$-де $C_m^2$ рет, ..., $j$ жиынның қиылыстарында $C_m^j$ рет саналады.
    3. Оң жақтағы оның жалпы «салмағы»: $C_m^1-C_m^2+C_m^3-\dots+(-1)^{m+1}C_m^m$.
    4. Биномнан: $0=(1-1)^m=\sum_{j=0}^m(-1)^jC_m^j=1-\left(C_m^1-C_m^2+\dots\right)$.
    5. Демек салмақ $=1$: әр элемент дәл бір рет саналады. Бірігуге жатпайтын элемент мүлде саналмайды. ∎

    ∎

    Қорытып шығару 2: екінші ретті рекуррент (әртүрлі түбірлер)

    Мақсат: $a_n=\alpha r_1^n+\beta r_2^n$ барлық шешімді беретінін көрсету.

    Идея: $r^n$ түріндегі шешім іздесек, сипаттамалық теңдеу шығады; екі түбірден құралған комбинация бастапқы шарттарды қанағаттандырады.

    1. $r^n$ түріндегі шешім іздейміз: $r^n=c_1r^{n-1}+c_2r^{n-2}\iff r^{n-2}(r^2-c_1r-c_2)=0$. $r\ne0$ ($c_2\ne0$), демек $r$ - сипаттамалық теңдеудің түбірі.
    2. Рекуррент сызықтық: екі шешімнің кез келген сызықтық комбинациясы да шешім. Сондықтан $\alpha r_1^n+\beta r_2^n$ - шешім.
    3. Бастапқы шарттар: $\alpha+\beta=a_0$, $\alpha r_1+\beta r_2=a_1$. Анықтауыш $r_2-r_1\ne0$, сондықтан $\alpha,\beta$ бірмәнді табылады.
    4. Ал рекурренттің шешімі $a_0,a_1$-мен бірмәнді анықталады (индукция). Демек табылған формула - сол шешім.

    ∎

    Қорытып шығару 3: Бине формуласы

    Мақсат: Фибоначчи сандарының жабық формуласын табу.

    Идея: Фибоначчи үшін $r^2=r+1$, түбірлері $\varphi$ пен $\psi$; $F_0=0$, $F_1=1$ шарттарынан коэффициенттер $\pm\frac1{\sqrt5}$.

    1. Сипаттамалық теңдеу: $r^2=r+1$, түбірлері $\varphi=\frac{1+\sqrt5}2\approx1{,}618$, $\psi=\frac{1-\sqrt5}2\approx-0{,}618$.
    2. $F_n=\alpha\varphi^n+\beta\psi^n$. $F_0=0$: $\alpha+\beta=0$. $F_1=1$: $\alpha(\varphi-\psi)=1$, $\varphi-\psi=\sqrt5$.
    3. $\alpha=\frac1{\sqrt5}$, $\beta=-\frac1{\sqrt5}$: $F_n=\frac{\varphi^n-\psi^n}{\sqrt5}$.
    4. $|\psi|<1$, сондықтан $\left|\frac{\psi^n}{\sqrt5}\right|<\frac12$ барлық $n\ge0$ үшін: $F_n$ - $\frac{\varphi^n}{\sqrt5}$-тің ең жақын бүтіні.
    5. Тексеру: $n=10$: $\frac{1{,}618^{10}}{2{,}236}\approx\frac{122{,}99}{2{,}236}\approx55{,}00$, ал $F_{10}=55$ ✓.

    ∎

    Қорытып шығару 4: бұзылған орналасулар формуласы

    Мақсат: $D_n=n!\sum_{k=0}^n\frac{(-1)^k}{k!}$ қорыту.

    Идея: «$i$ өз орнында» оқиғаларына қосу-шегеру принципін қолданамыз.

    1. $A_i$ - $i$ өз орнында тұратын алмастырулар. $D_n=n!-|A_1\cup\dots\cup A_n|$.
    2. $k$ бекітілген элементтің қиылысы: қалған $n-k$ элемент еркін - $(n-k)!$ алмастыру. Мұндай $k$-жиындар $C_n^k$.
    3. Қосу-шегеру: $|\bigcup A_i|=\sum_{k=1}^n(-1)^{k+1}C_n^k(n-k)!$.
    4. $C_n^k(n-k)!=\frac{n!}{k!}$, демек $D_n=n!-\sum_{k=1}^n(-1)^{k+1}\frac{n!}{k!}=n!\sum_{k=0}^n\frac{(-1)^k}{k!}$.
    5. $\frac{D_n}{n!}=\sum_{k=0}^n\frac{(-1)^k}{k!}\to e^{-1}$; $n=5$: $\frac{44}{120}\approx0{,}3667$, $e^{-1}\approx0{,}3679$.

    ∎

    Қадамдық шешілген мысалдар

    Мысал 1. Ханой мұнарасы

    $H_n=2H_{n-1}+1$, $H_1=1$ рекуррентін шешіңіз.

    1. 1-қадам. Бірнеше мүше: $1,3,7,15,31$ - болжам $2^n-1$.
    2. 2-қадам. Теорема 4.4: $c=2$, $d=1$, $p=\frac{1}{1-2}=-1$. $H_0=0$ деп алсақ ($H_1=2\cdot0+1$ ✓), $H_n=2^n(0+1)-1$.
    3. 3-қадам. $H_n=2^n-1$. Индукция: $2(2^{n-1}-1)+1=2^n-1$ ✓.
    4. 4-қадам. 64 диск, секундына бір қадам: $2^{64}-1\approx1{,}8\cdot10^{19}$ секунд - 500 миллиард жылдан астам.

    Жауабы: $H_n=2^n-1$.

    Мысал 2. Сипаттамалық теңдеу

    $a_n=5a_{n-1}-6a_{n-2}$, $a_0=1$, $a_1=4$.

    1. 1-қадам. $r^2-5r+6=0$, $r_1=2$, $r_2=3$.
    2. 2-қадам. $a_n=\alpha2^n+\beta3^n$. $\alpha+\beta=1$, $2\alpha+3\beta=4$.
    3. 3-қадам. $\beta=2$, $\alpha=-1$: $a_n=2\cdot3^n-2^n$.
    4. 4-қадам. Тексеру: $a_2=5\cdot4-6\cdot1=14$; формула $18-4=14$ ✓.

    Жауабы: $a_n=2\cdot3^n-2^n$.

    Мысал 3. Қайталанатын түбір

    $a_n=4a_{n-1}-4a_{n-2}$, $a_0=1$, $a_1=6$.

    1. 1-қадам. $r^2-4r+4=(r-2)^2=0$: $r_0=2$ (екі еселі).
    2. 2-қадам. $a_n=(\alpha+\beta n)2^n$. $a_0=\alpha=1$; $a_1=2(1+\beta)=6\Rightarrow\beta=2$.
    3. 3-қадам. $a_n=(1+2n)2^n$.
    4. 4-қадам. Тексеру: $a_2=4\cdot6-4\cdot1=20$; формула $5\cdot4=20$ ✓.

    Жауабы: $a_n=(2n+1)2^n$.

    Мысал 4. Рекуррент құру

    $1\times n$ жолақты $1\times1$ және $1\times2$ тақтайшалармен неше тәсілмен жабуға болады?

    1. 1-қадам. $t_n$ - тәсілдер саны. Соңғы тақтайшаға қараймыз: $1\times1$ болса, қалғаны $t_{n-1}$; $1\times2$ болса, $t_{n-2}$.
    2. 2-қадам. $t_n=t_{n-1}+t_{n-2}$; $t_1=1$, $t_2=2$.
    3. 3-қадам. $1,2,3,5,8,13,\dots$ - Фибоначчи: $t_n=F_{n+1}$.
    4. 4-қадам. $n=10$: $t_{10}=F_{11}=89$.

    Жауабы: $t_n=F_{n+1}$; $t_{10}=89$.

    Жиі қателер

    • Рекуррентті бастапқы шарттарсыз «шешу» → шешім $+$ бастапқы шарттар
      Неге қате: бір рекуррентті көп тізбек қанағаттандырады.
    • Қайталанатын түбірде $a_n=\alpha r_0^n+\beta r_0^n$ → $(\alpha+\beta n)r_0^n$
      Неге қате: екі тұрақты бір тұрақтыға қосылып кетеді, екі бастапқы шартты қанағаттандыру мүмкін емес.
    • Қосу-шегеруде таңбаларды ауыстырмау → $+,-,+,\dots$
      Неге қате: жұп сандағы қиылыстар шегеріледі, тақ сандағылар қосылады.
    • $D_n=n!-n\cdot(n-1)!$ → толық қосу-шегеру
      Неге қате: бұл тек бірінші түзету; бірнеше элемент өз орнында болған жағдайлар қайта саналады.
    • $F_n=\frac{\varphi^n}{\sqrt5}$ дәл формула → $F_n=\frac{\varphi^n-\psi^n}{\sqrt5}$ (не ең жақын бүтін)
      Неге қате: $\frac{\varphi^n}{\sqrt5}$ бүтін емес.
    • Сызықтық емес рекуррентке ($a_n=a_{n-1}^2$) сипаттамалық теңдеу → басқа әдіс (логарифм, ауыстыру)
      Неге қате: әдіс тек сызықтық тұрақты коэффициентті рекурренттерге.

    Визуализация

    Бақылаңыз: Баспалдақ (қызыл) - Бине формуласы бойынша нақты Фибоначчи сандары, көк қисық - $\frac{\varphi^x}{\sqrt5}$. Бүтін нүктелерде олардың айырмасы $\frac{|\psi|^n}{\sqrt5}<\frac12$ және тез нөлге ұмтылады: экспоненциалдық өсу $\varphi\approx1{,}618$ негізімен.

    Бақылаңыз: Дербес қосындылар $\frac{D_n}{n!}$ - $n$ хат кездейсоқ салынғанда ешбірі өз конвертіне түспеу ықтималдығы. Олар $\frac1e\approx0{,}3679$ маңында тербеліп, өте тез жинақталады: $n=6$-да айырма $0{,}0002$-ден аз. Жауап іс жүзінде $n$-ге тәуелсіз!

    Қолданыс және мини-жоба

    Қолданыс. Рекуррентті қатынастар - рекурсивті алгоритмдердің жұмыс уақыты (бинар іздеу $T(n)=T(n/2)+1$, сұрыптау), динамикалық бағдарламалау, қаржы (пайыздық өсім $a_n=1{,}1a_{n-1}+d$), популяция модельдері. Жабық формула мен мемоизация - бір мәселеге екі тәсіл.

    Мини-жоба: «Рекурсия, мемоизация, формула». Фибоначчиді үш тәсілмен есептеп, жылдамдықтарын салыстырамыз, бұзылған орналасуларды толық тізіммен тексереміз.

    from functools import lru_cache
from itertools import permutations
from math import factorial, sqrt
import time

def fib_naive(n):
    return n if n < 2 else fib_naive(n - 1) + fib_naive(n - 2)

@lru_cache(None)
def fib_memo(n):
    return n if n < 2 else fib_memo(n - 1) + fib_memo(n - 2)

def fib_binet(n):
    phi = (1 + sqrt(5)) / 2
    return round(phi ** n / sqrt(5))

for f in (fib_naive, fib_memo, fib_binet):
    t = time.time(); v = f(27); print(f.__name__, v, f"{time.time() - t:.4f} с")
print("Бине дәлдігі:", all(fib_binet(n) == fib_memo(n) for n in range(70)), "| n=80:", fib_binet(80) == fib_memo(80))

def derangements(n):
    return sum(1 for p in permutations(range(n)) if all(p[i] != i for i in range(n)))
for n in range(1, 8):
    print(n, derangements(n), round(factorial(n) * sum((-1) ** k / factorial(k) for k in range(n + 1))))

    Өзіңіз жалғастырыңыз:

    1. fib_binet қай $n$-нен бастап қате бере бастайды? Неге? (Жылжымалы үтір дәлдігі туралы ойланыңыз.)
    2. fib_naive(n) неше рет шақырылады? Шақырулар саны $c_n=c_{n-1}+c_{n-2}+1$ рекурренттін қанағаттандыратынын тексеріп, оны $F$ арқылы өрнектеңіз.
    3. Ханой мұнарасын рекурсивті шешетін бағдарлама жазып, қадамдар санын $2^n-1$-мен салыстырыңыз.
