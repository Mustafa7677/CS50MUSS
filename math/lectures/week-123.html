    Abstract Algebra · 6-сабақ

    Көпмүшелер сақинасы

    Мектепте көпмүшелерді бағанмен бөлуді, түбірлерді табуды үйрендік. Енді бұл тәсілдердің бүтін сандар арифметикасымен бірдей екенін көреміз: $F[x]$ көпмүшелер сақинасында ($F$ - өріс) қалдықпен бөлу, Евклид алгоритмі, Безу теңдігі және жайға жіктеу бар; жай сандардың орнын келтірілмейтін көпмүшелер алады.

    ⏱ Оқу ≈ 50 минЕсептер ≈ 1 сағТест ≈ 5 минБарлығы ≈ 2 сағ

    Бірақ «келтірілмейтін» ұғымы өріске тәуелді: $x^2+1$ $\mathbb R$-де жіктелмейді, $\mathbb C$-да $(x-i)(x+i)$, ал $\mathbb Z_2$-де $(x+1)^2$. Бұл сабақта бөлу алгоритмін, Безу теоремасын, түбірлер санының шегін дәлелдеп, келтірілмейтіндікті тексеру құралдарын - рационал түбір теоремасын, $2$-$3$ дәрежелі критерийді және Эйзенштейн критерийін меңгереміз.

    Курс туралы

    Бұл сабақтың мазмұны үшін жауапкершілікті курс авторы Sagid Mustafa өзіне алады. Қате немесе түсініксіз жер тапсаңыз, хабарлаңыз. Бұл курс ресми емтихан не куәлік баламасы емес.

    Бір сөйлеммен

    Өріс үстіндегі көпмүшелер бүтін сандар сияқты әрекет етеді: қалдықпен бөлуге, ЕҮОБ табуға, «жай» (келтірілмейтін) көбейткіштерге жіктеуге болады.

    Сабақ мақсаттары

    Сабақ соңында сіз мыналарды істей аласыз:

    • $F[x]$-те қалдықпен бөлу алгоритмін дәлелдеп, бөлінді мен қалдықты табу;
    • Безу теоремасын және $n$ дәрежелі көпмүшенің өрісте $n$-нен көп түбірі жоқ екенін дәлелдеу;
    • көпмүшелер үшін Евклид алгоритмін және Безу теңдігін қолдану;
    • келтірілмейтін көпмүшені анықтап, $2$-$3$ дәрежелі көпмүшелер үшін түбір критерийін дәлелдеу, $4$ дәрежеде оның жалған екенін көрсету;
    • рационал түбір теоремасы мен Эйзенштейн критерийін дәлелдеп, қолдану;
    • бір көпмүшенің әртүрлі өрістер ($\mathbb Q,\mathbb R,\mathbb C,\mathbb Z_p$) үстінде жіктелуін салыстыру.

    Қысқаша еске салу

    Сақина, бүтіндік облысы, өріс, идеал (5-сабақ). Көпмүшелерді бөлу, Безу теоремасы (precalculus, 3-сабақ). Евклид алгоритмі, Безу теңдігі, Евклид леммасы, арифметиканың негізгі теоремасы (сандар теориясы, 1-2-сабақтар). Комплекс сандар, алгебраның негізгі теоремасы (комплекс анализ).

    Алдымен оқыңыз

    • Abstract Algebra · 5-сабақ: Сақиналар және өрістер
    • Precalculus · 3-сабақ: Көпмүшеліктер мен рационал функциялар

    Бұл сабақтар таныс болса, бірден бастай беріңіз. Толық реттілік: оқу жолы.

    Алдымен қолмен: бағанмен бөлу және түбір

    Формулаға дейін нақты сандармен ойнап көрейік. Әр қадамды өзіңіз де қағазда қайталаңыз.

    $f(x)=x^3-2x^2-5x+6$. $f(1)$-ді есептеңіз, $f$-ті $x-1$-ге бөліңіз және толық жіктеңіз.

    1. $f(1)=1-2-5+6=0$. Безу теоремасы бойынша $x-1$ - $f$-тің бөлгіші.
    2. Бөлу: $x^3-2x^2-5x+6=(x-1)(x^2-x-6)$. Тексеру: $(x-1)(x^2-x-6)=x^3-x^2-6x-x^2+x+6$ ✓.
    3. $x^2-x-6=(x-3)(x+2)$. Демек $f=(x-1)(x-3)(x+2)$, түбірлері $1,3,-2$.
    4. Рационал түбір теоремасымен тексеру: түбірлер $6$-ның бөлгіштері ішінде болуы керек: $\pm1,\pm2,\pm3,\pm6$ ✓.

    Байқадыңыз ба? Түбір табылса, көпмүшені $(x-a)$-ға бөліп, дәрежесін төмендетеміз. Бұл бүтін санды жай көбейткішке бөлгенмен бірдей.

    Интуиция

    Бүтін сандарда $17=3\cdot5+2$, қалдық $|2|<|5|$. Көпмүшелерде «өлшем» - дәреже: $x^4+3x^3-2x+5=(x^2+x+1)(x^2+2x-3)+(8-x)$, қалдықтың дәрежесі $1<2$. Бөлу үшін басқы коэффициентке бөлу керек - сондықтан коэффициенттер өрістен алынады.

    Қалдықпен бөлу бар жерде Евклид алгоритмі бар, демек ЕҮОБ және Безу теңдігі бар, демек Евклид леммасы және жалғыз жіктеу бар. Бүтін сандар үшін 2-сабақта жүргізген бүкіл тізбек көпмүшелерге көшеді.

    $2$ немесе $3$ дәрежелі көпмүше жіктелсе, көбейткіштердің бірі сызықтық болады, демек түбір бар. Сондықтан $2$-$3$ дәрежеде «түбір жоқ $\iff$ келтірілмейді». $4$ дәрежеде бұл жалған: $x^4+4$-тің нақты түбірі жоқ, бірақ $x^4+4=(x^2+2x+2)(x^2-2x+2)$.

    Эйзенштейн критерийі: $x^5-6x+3$ - барлық коэффициент (басқысынан басқа) $3$-ке бөлінеді, ал бос мүше $9$-ға бөлінбейді. Бұл $\mathbb Q$ үстінде келтірілмейтіндікке кепілдік береді, түбірлерді іздемей-ақ.

    Өмірден ұқсастық · көпмүше - сан

    $x=10$ қойсақ, $x^2+3x+2$ саны $132$-ге айналады; ал $(x+1)(x+2)$ - $11\cdot12=132$. Көпмүшені жіктеу - санды жіктеудің «$x$-ке дейінгі» нұсқасы; келтірілмейтін көпмүшелер - жай сандардың баламасы.

    Өмірден ұқсастық · келтірілмейтіндік қай өрісте?

    $x^2+1$ нақты сандарда «жай» (түбірі жоқ), ал комплекс сандарда $(x-i)(x+i)$. Құрылыс материалы (өріс) өзгерсе, «жай» деген ұғым да өзгереді.

    Белгілерді оқу

    Анықтамалар мен теоремалар

    Анықтама 6.1 · Көпмүшелер сақинасы

    $R$ коммутативті сақина. $R[x]$ - $f=a_nx^n+\dots+a_1x+a_0$ ($a_i\in R$) түріндегі көпмүшелер сақинасы (polynomial ring). $a_n\ne0$ болса, $\deg f=n$, $a_n$ - басқы коэффициент; $a_n=1$ болса - келтірілген көпмүше. $\deg0=-\infty$. $R$ бүтіндік облысы болса, $\deg(fg)=\deg f+\deg g$, демек $R[x]$ те бүтіндік облысы.

    Қарапайым тілмен: Көпмүшелерді қосып, көбейтуге болады - олар сақина құрайды; дәреже көбейткенде қосылады (өрісте).

    Теорема 6.1 · Қалдықпен бөлу

    $F$ - өріс, $f,g\in F[x]$, $g\ne0$. $f=qg+r$, $\deg r<\deg g$ болатын $q,r\in F[x]$ бар және жалғыз.

    Қарапайым тілмен: Өріс үстінде көпмүшені кез келген нөл емес көпмүшеге қалдықпен бөлуге болады, қалдықтың дәрежесі кіші.

    Негіздеме. Өріс шарты маңызды: $\mathbb Z[x]$-те $x$-ті $2x$-ке қалдықпен бөлу мүмкін емес.

    Теорема 6.2 · Безу теоремасы және түбірлер саны

    $F$ - өріс. (1) $f(a)$ - $f$-ті $x-a$-ға бөлгендегі қалдық; $f(a)=0\iff(x-a)\mid f$. (2) $\deg f=n\ge0$ болса, $f$-тің $F$-те $n$-нен көп түбірі жоқ.

    Қарапайым тілмен: $f(a)$ - $x-a$-ға бөлгендегі қалдық; түбір = бөлгіш. Дәрежесі $n$ көпмүшенің $n$-нен көп түбірі жоқ.

    Негіздеме. (2) бүтіндік облысы емес сақинада жалған: $\mathbb Z_8$-да $x^2-1$-дің $4$ түбірі бар.

    Теорема 6.3 · ЕҮОБ және Безу теңдігі

    $F[x]$-тің әр идеалы бас идеал: $I=\langle d\rangle$. $f,g$ (бір мезгілде нөл емес) үшін $\langle f,g\rangle=\langle d\rangle$, мұнда $d=\gcd(f,g)$ - келтірілген ортақ бөлгіш, кез келген ортақ бөлгішке бөлінеді, және $d=uf+vg$ кейбір $u,v\in F[x]$ үшін. $d$ Евклид алгоритмімен табылады.

    Қарапайым тілмен: Көпмүшелердің ЕҮОБ-ын Евклид алгоритмімен табамыз, және ол $uf+vg$ түрінде жазылады.

    Негіздеме. $\gcd(x^2-1,x^2+2x+1)=x+1$.

    Анықтама 6.2 · Келтірілмейтін көпмүше

    $f\in F[x]$, $\deg f\ge1$ - $F$ үстінде келтірілмейтін көпмүше (irreducible polynomial), егер $f=gh$ болса, $g$ не $h$ тұрақты болса. Әйтпесе - келтірілетін. $F[x]$-те әр $\deg\ge1$ көпмүше келтірілмейтіндердің көбейтіндісіне тұрақты көбейткіштер мен ретке дейін жалғыз жіктеледі.

    Қарапайым тілмен: Келтірілмейтін көпмүше - тек тривиал түрде жіктелетін көпмүше, яғни «жай» көпмүше.

    Теорема 6.4 · Келтірілмейтіндік критерийлері

    (1) $\deg f\in\{2,3\}$: $f$ $F$ үстінде келтірілмейтін $\iff f$-тің $F$-те түбірі жоқ. (2) Рационал түбір: $f=a_nx^n+\dots+a_0\in\mathbb Z[x]$, $\frac pq$ ($\gcd(p,q)=1$) - түбір болса, $p\mid a_0$, $q\mid a_n$. (3) Эйзенштейн критерийі (Eisenstein's criterion): жай $p$ үшін $p\nmid a_n$, $p\mid a_i$ ($i<n$), $p^2\nmid a_0$ болса, $f$-ті екі тұрақты емес бүтін коэффициентті көпмүшенің көбейтіндісіне жіктеуге болмайды; демек (Гаусс леммасы бойынша) $f$ $\mathbb Q$ үстінде келтірілмейтін.

    Қарапайым тілмен: $2$-$3$ дәрежеде келтірілмейтіндік = түбірдің жоқтығы. Бүтін коэффициентті көпмүшенің рационал түбірлері $\frac pq$ түрінде шектелген. Эйзенштейн жай сан арқылы келтірілмейтіндікті береді.

    Негіздеме. (1) $4$ дәрежеде жалған: $x^4+4$. Гаусс леммасын (бүтін коэффициентті көпмүше $\mathbb Q$-да жіктелсе, $\mathbb Z$-та да жіктеледі) бұл сабақта дәлелсіз қолданамыз.

    Формула 6.1 · Қалдықпен бөлу
    $$f=qg+r,\quad\deg r<\deg g$$

    $F$ - өріс.

    Формула 6.2 · Безу теоремасы
    $$f(a)=0\iff(x-a)\mid f(x)$$

    Қалдық $=f(a)$.

    Формула 6.3 · Түбірлер саны
    $$\left|\{a\in F:f(a)=0\}\right|\le\deg f$$

    $F$ - өріс (бүтіндік облысы).

    Формула 6.4 · Көпмүше ЕҮОБ-ы
    $$\gcd(f,g)=uf+vg$$

    Евклид алгоритмі.

    Формула 6.5 · Рационал түбір
    $$f\!\left(\tfrac pq\right)=0\Rightarrow p\mid a_0,\ q\mid a_n$$

    $\gcd(p,q)=1$.

    Формула 6.6 · Эйзенштейн
    $$p\nmid a_n,\ \ p\mid a_0,\dots,a_{n-1},\ \ p^2\nmid a_0$$

    $\mathbb Q$ үстінде келтірілмейтін.

    Есте сақта

    Көпмүшенің $F$ үстінде келтірілмейтінін тексеру: (1) $\deg\le3$ - түбірлерді іздеңіз ($\mathbb Q$ үшін - рационал түбір теоремасымен ақырлы тізім, $\mathbb Z_p$ үшін - барлық $p$ элементті қойып); (2) $\mathbb Z[x]$ - Эйзенштейнді (кейде $x\mapsto x+1$ ауыстырудан кейін) тексеріңіз; (3) $\mathbb Z_p$-ға келтіру: басқы коэффициент $p$-ға бөлінбесе және $f\bmod p$ келтірілмейтін болса, $f$ $\mathbb Q$ үстінде келтірілмейтін; (4) $\mathbb R$ үстінде келтірілмейтіндер - тек сызықтықтар және дискриминанты теріс квадраттар; $\mathbb C$ үстінде - тек сызықтықтар (алгебраның негізгі теоремасы).

    Назар аудар

    (1) «Түбірі жоқ $\Rightarrow$ келтірілмейтін» тек $2$-$3$ дәреже үшін: $(x^2+1)^2$ $\mathbb R$ үстінде түбірсіз, бірақ келтірілетін. (2) Келтірілмейтіндік өріске тәуелді: $x^2-2$ $\mathbb Q$ үстінде келтірілмейтін, $\mathbb R$ үстінде $(x-\sqrt2)(x+\sqrt2)$. (3) Эйзенштейн - жеткілікті шарт, қажетті емес: $x^2+1$ келтірілмейтін, бірақ ешбір $p$ үшін шарт орындалмайды (тек $x\mapsto x+1$-ден кейін: $x^2+2x+2$, $p=2$). (4) Бүтіндік облысы емес сақинада түбірлер саны дәрежеден асуы мүмкін: $\mathbb Z_8$, $x^2-1$.

    Тоқта, ойлан

    Әрі қарай жүрмес бұрын, өзіңізді тексеріңіз: алдымен жауапты ойланыңыз, сосын ашыңыз.

    1. $x^2+1$ $\mathbb Z_5$ үстінде келтірілмейтін бе?

    Жоқ: $2^2+1=5\equiv0$, демек $x=2$ түбір: $x^2+1=(x-2)(x-3)$ $\mathbb Z_5$-те.

    2. $x^3-2$ $\mathbb Q$ үстінде келтірілмейтін бе?

    Иә: рационал түбірлер тек $\pm1,\pm2$, ешқайсысы түбір емес, ал дәрежесі $3$.

    3. $x^4+10x+5$ $\mathbb Q$ үстінде келтірілмейтін бе?

    Иә: Эйзенштейн, $p=5$ ($5\mid10$, $5\mid5$, $25\nmid5$, $5\nmid1$).

    4. $x^5-1$-ді $x-1$-ге бөлгенде қалдық неге тең?

    $f(1)=0$ (Безу).

    Қорытып шығару

    Қорытып шығару 1: қалдықпен бөлу

    Мақсат: Теорема 6.1-ді дәлелдеу.

    Идея: Бүтін сандарды бағанмен бөлгендей: басқы мүшені жою үшін $g$-ның тиісті еселігін алып тастаймыз, дәреже төмендейді, индукция.

    1. Бар болуы, $\deg f$ бойынша индукция. $\deg f<\deg g$ болса, $q=0$, $r=f$.
    2. $\deg f=n\ge m=\deg g$, басқы коэффициенттер $a$, $b$. $f_1=f-\frac abx^{n-m}g$ - $x^n$ мүшесі жойылады, $\deg f_1<n$ ($b^{-1}$ бар - $F$ өріс).
    3. Индукция: $f_1=q_1g+r$, $\deg r<m$. Онда $f=\left(q_1+\frac abx^{n-m}\right)g+r$.
    4. Жалғыздық: $qg+r=q'g+r'\Rightarrow(q-q')g=r'-r$. $q\ne q'$ болса, сол жақтың дәрежесі $\ge m$, оң жақтың - $<m$. Демек $q=q'$, $r=r'$. ∎

    ∎

    Қорытып шығару 2: Безу теоремасы және түбірлер саны

    Мақсат: Теорема 6.2-ні дәлелдеу.

    Идея: $x-a$-ға бөлгенде қалдық тұрақты, оны $x=a$ қойып табамыз. Түбірлер санын индукциямен шектейміз.

    1. (1) $f=q(x)(x-a)+r$, $\deg r<1$, яғни $r$ - тұрақты. $x=a$: $f(a)=r$. Демек $f(a)=0\iff r=0\iff(x-a)\mid f$.
    2. (2) $n$ бойынша индукция. $n=0$: нөл емес тұрақтының түбірі жоқ.
    3. $f$-тің түбірі $a$ болсын: $f=(x-a)q$, $\deg q=n-1$. $b\ne a$ - басқа түбір: $(b-a)q(b)=0$, $b-a\ne0$, бүтіндік облысында $q(b)=0$.
    4. Индукция: $q$-дің түбірлері $\le n-1$, демек $f$-тікі $\le n$. ∎ (Сандар теориясындағы Лагранж теоремасы - $F=\mathbb Z_p$ жағдайы.)

    ∎

    Қорытып шығару 3: $2$-$3$ дәрежелі критерий

    Мақсат: Теорема 6.4 (1)-ді дәлелдеу.

    Идея: Түбір бар - сызықты көбейткіш бар. Керісінше, $2$-$3$ дәрежелі көпмүшенің кез келген жіктеуінде $1$ дәрежелі көбейткіш болуы керек.

    1. $f$-тің түбірі $a$ бар болса, $f=(x-a)q$, $\deg q=\deg f-1\ge1$ - келтірілетін.
    2. $f=gh$, $g,h$ тұрақты емес: $\deg g+\deg h=\deg f\le3$, екеуі де $\ge1$, демек біреуі $1$ дәрежелі: $g=cx+d$, $c\ne0$.
    3. $a=-\frac dc\in F$ - $g$-нің, демек $f$-тің түбірі.
    4. Сонымен $2$-$3$ дәрежеде: келтірілетін $\iff$ түбір бар. $4$ дәрежеде $2+2$ жіктелу түбір бермейді. ∎

    ∎

    Қорытып шығару 4: рационал түбір теоремасы

    Мақсат: Теорема 6.4 (2)-ні дәлелдеу.

    Идея: $\frac pq$-ды қойып, $q^n$-ге көбейтеміз: шеткі мүшелер $p$ мен $q$-ге бөлінгіштікті береді.

    1. $f\left(\frac pq\right)=0$, $q^n$-ге көбейтеміз: $a_np^n+a_{n-1}p^{n-1}q+\dots+a_1pq^{n-1}+a_0q^n=0$.
    2. $a_0q^n=-p(a_np^{n-1}+\dots+a_1q^{n-1})$, демек $p\mid a_0q^n$. $\gcd(p,q^n)=1$, Евклид леммасы: $p\mid a_0$.
    3. Дәл солай $a_np^n=-q(\dots)$: $q\mid a_np^n$, $\gcd(q,p^n)=1$, демек $q\mid a_n$. ∎

    ∎

    Қорытып шығару 5: Эйзенштейн критерийі

    Мақсат: Теорема 6.4 (3)-ті дәлелдеу ($\mathbb Z[x]$-тегі жіктелу).

    Идея: Көбейткіштердің бос мүшелерінің дәл біреуі $p$-ға бөлінеді; басқы коэффициентке дейін «$p$-ға бөлінгіштікті» тасымалдап, қайшылық аламыз.

    1. $f=gh$, $g=b_kx^k+\dots+b_0$, $h=c_lx^l+\dots+c_0$, $k,l\ge1$, бүтін коэффициенттер.
    2. $a_0=b_0c_0$, $p\mid a_0$, $p^2\nmid a_0$: $b_0$, $c_0$-дің дәл біреуі $p$-ға бөлінеді, мысалы $p\mid b_0$, $p\nmid c_0$.
    3. $p\nmid a_n=b_kc_l$, демек $p\nmid b_k$. $p\nmid b_s$ болатын ең кіші $s$ алайық: $1\le s\le k<n$.
    4. $a_s=b_sc_0+b_{s-1}c_1+\dots+b_0c_s$: $b_0,\dots,b_{s-1}$ $p$-ға бөлінеді, $b_sc_0$ бөлінбейді, демек $p\nmid a_s$. Бірақ $s<n$, шарт бойынша $p\mid a_s$ - қайшылық.
    5. Сонымен $f$ бүтін коэффициентті тұрақты емес көбейткіштерге жіктелмейді; Гаусс леммасы бойынша $\mathbb Q$ үстінде де. ∎

    ∎

    Қадамдық шешілген мысалдар

    Мысал 1. Қалдықпен бөлу

    $x^4+3x^3-2x+5$-ті $x^2+x+1$-ге бөлу.

    1. 1-қадам. $x^4\div x^2=x^2$: $x^4+3x^3-2x+5-x^2(x^2+x+1)=2x^3-x^2-2x+5$.
    2. 2-қадам. $2x^3\div x^2=2x$: $2x^3-x^2-2x+5-2x(x^2+x+1)=-3x^2-4x+5$.
    3. 3-қадам. $-3x^2\div x^2=-3$: $-3x^2-4x+5+3(x^2+x+1)=-x+8$.
    4. 4-қадам. $q=x^2+2x-3$, $r=8-x$, $\deg r=1<2$ ✓.

    Жауабы: $q=x^2+2x-3$, $r=8-x$.

    Мысал 2. Рационал түбірлер

    $2x^3-3x^2-3x+2$ - $\mathbb Q$ үстінде жіктеу.

    1. 1-қадам. Үміткерлер $\frac pq$: $p\mid2$, $q\mid2$: $\pm1,\pm2,\pm\frac12$.
    2. 2-қадам. $f(2)=16-12-6+2=0$ ✓, $f(-1)=-2-3+3+2=0$ ✓, $f\left(\frac12\right)=\frac14-\frac34-\frac32+2=0$ ✓.
    3. 3-қадам. $f=2(x-2)(x+1)\left(x-\frac12\right)=(x-2)(x+1)(2x-1)$.
    4. 4-қадам. Үш түбір - дәреже $3$, басқа түбір жоқ (Теорема 6.2).

    Жауабы: $(x-2)(x+1)(2x-1)$.

    Мысал 3. Өріске тәуелділік

    $x^2+1$ - $\mathbb Q$, $\mathbb R$, $\mathbb C$, $\mathbb Z_2$, $\mathbb Z_5$, $\mathbb Z_3$ үстінде.

    1. 1-қадам. $\mathbb Q$, $\mathbb R$: $x^2\ge0$ - түбір жоқ, $\deg2$ - келтірілмейтін.
    2. 2-қадам. $\mathbb C$: $(x-i)(x+i)$. $\mathbb Z_2$: $1^2+1=0$, $x^2+1=(x+1)^2$.
    3. 3-қадам. $\mathbb Z_5$: $2^2+1=5\equiv0$: $(x-2)(x-3)$. $\mathbb Z_3$: $0,1,4\to1,2,2$ - түбір жоқ, келтірілмейтін.
    4. 4-қадам. Байланыс: $-1$ квадраттық қалдық $\iff p\equiv1\pmod4$ (сандар теориясы, 5-сабақ).

    Жауабы: $\mathbb Q,\mathbb R,\mathbb Z_3$: келтірілмейтін.

    Мысал 4. Түбірсіз, бірақ келтірілетін

    $x^4+4$ (Софи Жермен).

    1. 1-қадам. $x^4+4>0$ - нақты түбір жоқ.
    2. 2-қадам. $x^4+4=(x^2+2)^2-4x^2=(x^2+2x+2)(x^2-2x+2)$.
    3. 3-қадам. Әр көбейткіштің дискриминанты $4-8<0$ - $\mathbb R$ үстінде келтірілмейтін.
    4. 4-қадам. Демек $2$-$3$ дәрежелі критерий $4$ дәрежеге жарамайды.

    Жауабы: $(x^2+2x+2)(x^2-2x+2)$.

    Мысал 5. Эйзенштейн

    $x^5-6x+3$ және $x^4+x^3+x^2+x+1$.

    1. 1-қадам. $x^5-6x+3$: $p=3$: $3\nmid1$, $3\mid-6,3$ (және $0$ коэффициенттер), $9\nmid3$ - келтірілмейтін.
    2. 2-қадам. $\Phi_5=x^4+x^3+x^2+x+1$: тікелей шарт жоқ. $x\mapsto x+1$: $\Phi_5(x+1)=\frac{(x+1)^5-1}x=x^4+5x^3+10x^2+10x+5$.
    3. 3-қадам. $p=5$: $5\mid5,10,10,5$, $25\nmid5$ - келтірілмейтін.
    4. 4-қадам. $f(x)$ жіктелсе, $f(x+1)$ де жіктеледі - демек $\Phi_5$ келтірілмейтін.

    Жауабы: Екеуі де $\mathbb Q$ үстінде келтірілмейтін.

    Жиі қателер

    • Түбірі жоқ - келтірілмейтін → тек $\deg\le3$
      Неге қате: $x^4+4$.
    • Келтірілмейтіндік - көпмүшенің өз қасиеті → өріске тәуелді
      Неге қате: $x^2-2$: $\mathbb Q$ мен $\mathbb R$.
    • Эйзенштейн қолданылмаса - келтірілетін → тек жеткілікті шарт
      Неге қате: $x^2+1$.
    • Кез келген сақинада $\le n$ түбір → тек бүтіндік облысында
      Неге қате: $\mathbb Z_8$: $x^2-1$.
    • Рационал түбірлерді тексермей іздеу → $p\mid a_0$, $q\mid a_n$ - ақырлы тізім
      Неге қате: $\pm1,\pm2,\pm\frac12$.
    • $\mathbb Z[x]$-те қалдықпен бөлу әрдайым бар → басқы коэффициент кері элемент болуы тиіс
      Неге қате: $x\div2x$.

    Визуализация

    Бақылаңыз: Тақ дәрежелі нақты көпмүше $-\infty$-тен $+\infty$-ке өтеді, демек әрдайым нақты түбірі бар - $\mathbb R$ үстінде $3$ дәрежелі көпмүше әрдайым келтірілетін. $a$-ны өзгертіңіз: түбірлер саны $1$ не $3$, бірақ ешқашан $0$ емес. $\mathbb Q$ үстінде жағдай басқа: $x^3-3x+1$ (дәл $a=-3$) - рационал түбірі жоқ ($\pm1$ жарамайды), демек $\mathbb Q$ үстінде келтірілмейтін.

    Бақылаңыз: Үш қисықтың ешқайсысы $x$ осін қиып өтпейді - нақты түбір жоқ. Бірақ $x^4+4$ екі квадраттың көбейтіндісі: кез келген $x$ үшін көк қисықтың мәні қалған екеуінің көбейтіндісіне тең. Бұл - «түбір жоқ $\Rightarrow$ келтірілмейтін» тұжырымының $4$ дәрежеде жалған екенінің суреті.

    Қолданыс және мини-жоба

    Қолданыс. $\mathbb Z_2[x]$-тегі көпмүшелер - CRC бақылау сомаларының (Ethernet, ZIP, PNG) негізі: хабар көпмүше ретінде келтірілмейтін (немесе арнайы) көпмүшеге бөлінеді, қалдық бақылау сомасы болады. Рид-Соломон кодтары ақырлы өрістегі көпмүшелерді қолданады: $n$ дәрежелі көпмүше $n+1$ нүктемен анықталады (Теорема 6.2), сондықтан қосымша нүктелер жоғалған деректерді қалпына келтіреді.

    Мини-жоба: «$\mathbb Z_p[x]$ калькуляторы». $\mathbb Z_p$ үстінде көпмүшелерді бөлу мен ЕҮОБ-ты өзіміз жазамыз, $\mathbb Z_2$ үстіндегі $n$ дәрежелі келтірілмейтін көпмүшелерді санаймыз және CRC бақылау сомасын есептейміз.

    from itertools import product

def trim(f):
    while f and f[-1] == 0:
        f = f[:-1]
    return f

def divmod_p(f, g, p):
    f, g = trim(f[:]), trim(g)
    q = [0] * max(len(f) - len(g) + 1, 1)
    inv = pow(g[-1], -1, p)
    while len(f) >= len(g) and f:
        k = len(f) - len(g)
        c = f[-1] * inv % p
        q[k] = c
        for i, gi in enumerate(g):
            f[i + k] = (f[i + k] - c * gi) % p
        f = trim(f)
    return trim(q), f

def gcd_p(f, g, p):
    while trim(g):
        f, g = g, divmod_p(f, g, p)[1]
    f = trim(f)
    inv = pow(f[-1], -1, p)
    return [c * inv % p for c in f]

# коэффициенттер өсу ретімен: [a0, a1, ...]
print("x^4+x+1 ÷ x^2+1, Z_2 үстінде:", divmod_p([1, 1, 0, 0, 1], [1, 0, 1], 2))
print("gcd(x^2-1, x^2+2x+1), Z_7 үстінде:", gcd_p([6, 0, 1], [1, 2, 1], 7))

def irreducible(f, p):
    n = len(f) - 1
    for d in range(1, n // 2 + 1):
        for coeffs in product(range(p), repeat=d):
            g = list(coeffs) + [1]
            if not divmod_p(f, g, p)[1]:
                return False
    return True

counts = {n: sum(1 for c in product(range(2), repeat=n) if irreducible(list(c) + [1], 2)) for n in range(1, 9)}
print("Z_2 үстіндегі келтірілмейтіндер саны, дәреже 1..8:", counts)

def crc(bits, gen):
    msg = [int(b) for b in bits][::-1]
    shifted = [0] * (len(gen) - 1) + msg
    return divmod_p(shifted, gen, 2)[1]

print("CRC (x^3+x+1):", crc("11010011101100", [1, 1, 0, 1]))
