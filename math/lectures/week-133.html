    Байланыстылық

    Аралық мән теоремасы: $[a,b]$-да үзіліссіз функция $f(a)<0<f(b)$ болса, әлдебір нүктеде нөлге тең. Анализде оны жоғарғы шекара аксиомасымен дәлелдедік. Топология оның шын себебін ашады: $[a,b]$ кесіндісі «бір бөліктен» тұрады, ал үзіліссіз бейнелеу бір бөлікті жыртып екіге бөле алмайды.

    ⏱ Оқу ≈ 55 минЕсептер ≈ 1 сағТест ≈ 5 минБарлығы ≈ 2 сағ

    Бұл қасиет - байланыстылық. Бұл сабақта байланыстылықты анықтап, $\mathbb R$-дің байланысты ішкі жиындары дәл интервалдар екенін, үзіліссіз бейне байланыстылықты сақтайтынын дәлелдейміз. Сосын жол арқылы байланыстылықты енгізіп, оның байланыстылықтан күштірек екенін «топологтың синусоидасы» арқылы көреміз. Нәтижелер: $\mathbb R\not\cong\mathbb R^2$, $[0,1]\not\cong S^1$, қозғалмайтын нүкте және антиподтық нүктелер туралы теоремалар.

    Бір сөйлеммен

    Кеңістік байланысты, егер оны бір-біріне тимейтін екі ашық бөлікке бөлу мүмкін болмаса; ал үзіліссіз бейнелеу байланысты нәрсені ешқашан бөліп жібермейді.

    Сабақ мақсаттары

    Сабақ соңында сіз мыналарды істей аласыз:

    • байланыстылықтың анықтамасын және оның эквивалент түрлерін (ашық-тұйық жиындар, $\{0,1\}$-ге бейнелеулер) дәлелдеу;
    • $\mathbb R$-дің байланысты ішкі жиындары дәл интервалдар екенін дәлелдеу;
    • үзіліссіз бейненің байланыстылығын дәлелдеп, аралық мән теоремасын топологиялық түрде алу;
    • жол арқылы байланыстылықты анықтап, ол байланыстылыққа әкелетінін, ал керісінше жалған екенін көрсету;
    • байланысты компоненттерді санап, байланыстылықты гомеоморфизм инварианты ретінде қолдану ($\mathbb R\not\cong\mathbb R^2$);
    • қозғалмайтын нүкте және антиподтық нүктелер туралы бір өлшемді теоремаларды дәлелдеу.

    Қысқаша еске салу

    Топология, ашық және тұйық жиын, тұйықталу, ішкі кеңістік (1-сабақ). Үзіліссіз бейнелеу, гомеоморфизм (2-сабақ). Жоғарғы шекара аксиомасы, аралық мән теоремасы (нақты анализ, 1 және 3-сабақтар).

    Алдымен оқыңыз

    • Topology · 2-сабақ: Үзіліссіз бейнелеулер және гомеоморфизм

    Бұл сабақтар таныс болса, бірден бастай беріңіз. Толық реттілік: оқу жолы.

    Алдымен қолмен: тамыр табу ойыны

    Формулаға дейін нақты сандармен ойнап көрейік. Әр қадамды өзіңіз де қағазда қайталаңыз.

    $f(x)=x^3+x-1$. $[0,1]$-да $f(x)=0$ теңдеуінің шешімі бар ма? Шешімді $0{,}1$ дәлдікпен табыңыз.

    1. $f(0)=-1<0$, $f(1)=1>0$. Функция үзіліссіз, ал кесінді байланысты - графигі «секірмей» $0$-ден өтуі керек.
    2. Ортасын тексереміз: $f(0{,}5)=0{,}125+0{,}5-1=-0{,}375<0$. Таңба $[0{,}5;1]$-да ауысады.
    3. $f(0{,}75)\approx0{,}42+0{,}75-1=0{,}17>0$. Таңба $[0{,}5;0{,}75]$-да ауысады.
    4. $f(0{,}625)\approx0{,}244+0{,}625-1=-0{,}13<0$, $f(0{,}7)\approx0{,}343+0{,}7-1=0{,}043>0$. Түбір $\approx0{,}68$ (дәлірек $0{,}6823$).

    Байқадыңыз ба? Әр қадамда біз «таңба ауысты, демек ортада нөл бар» дедік. Бұл сенім дәл байланыстылықтан шығады: кесіндіні «таңбасы теріс» және «таңбасы оң» деген екі ашық бөлікке бөлу мүмкін емес.

    Интуиция

    Кеңістік байланыссыз, егер оны екі «бір-біріне тимейтін» ашық бөлікке бөлуге болса: $(0,1)\cup(2,3)$ - анық екі бөлік. Бірақ $\mathbb Q$ та байланыссыз: $\{q<\sqrt2\}$ және $\{q>\sqrt2\}$ - екеуі де $\mathbb Q$-да ашық, бүкіл $\mathbb Q$-ды жабады. Рационал сандар «шаңнан» тұрады.

    Үзіліссіз бейнелеу байланысты кеңістікті жырта алмайды: бейненің әр бөлінуі алғы бейненің бөлінуін береді. Аралық мән теоремасы осыдан шығады: $f([a,b])$ байланысты, демек интервал, демек $f(a)$ мен $f(b)$ арасындағы әр мәнді қамтиды.

    Жол арқылы байланыстылық - кез келген екі нүктені үзіліссіз қисықпен қосуға болады. Бұл күштірек: $y=\sin\frac1x$ графигі мен $y$ осінің кесіндісі бір байланысты жиын құрайды, бірақ кесіндіден графикке жол жүргізу мүмкін емес - график шексіз тербеліп, кесіндіге «жабысады».

    Байланыстылық - инвариант. $\mathbb R$-ден бір нүктені алып тастасақ, екі бөлік қалады; $\mathbb R^2$-ден бір нүктені алып тастасақ - бір бөлік. Демек $\mathbb R\not\cong\mathbb R^2$. Дәл солай $[0,1]$-ден ішкі нүктені алсақ - екі бөлік, ал шеңберден кез келген нүктені алсақ - бір бөлік: $[0,1]\not\cong S^1$.

    Өмірден ұқсастық · арал мен материк

    Материк - байланысты: кез келген екі қаланың арасында құрғақ жол бар. Аралдар тобы - байланыссыз: оларды «теңіз» бөліп тұр. Байланыстылық - «теңізсіз», жол арқылы байланыстылық - «жол салуға болады».

    Өмірден ұқсастық · жіп пен қайшы

    Үзіліссіз бейнелеу - жіпті созу, бұрау. Жіпті екіге бөлу үшін қайшы керек - бұл үзіліссіздікті бұзу. Сондықтан бір тұтас жіптің бейнесі де бір тұтас.

    Белгілерді оқу

    Жоғары математиканың қиындығының жартысы - белгілерде. Теорияға дейін әр белгіні дауыстап оқып, мағынасын біліп алайық:

    Анықтамалар мен теоремалар

    Анықтама 3.1 · Байланыстылық

    $X$ - байланысты кеңістік (connected space), егер $X=U\cup V$, $U\cap V=\varnothing$ болатын бос емес ашық $U$, $V$ жоқ. Әйтпесе $(U,V)$ - $X$-тің бөлінуі (separation). $A\subseteq X$ байланысты, егер ішкі кеңістік ретінде байланысты болса. Ашық әрі тұйық жиын - ашық-тұйық жиын (clopen set).

    Қарапайым тілмен: Кеңістікті екі ашық, бос емес, қиылыспайтын бөлікке «кесу» мүмкін болмаса - ол байланысты.

    Теорема 3.1 · Байланыстылықтың эквивалент түрлері

    Келесілер тең күшті: (1) $X$ байланысты; (2) $X$-тің ашық-тұйық жиындары тек $\varnothing$ және $X$; (3) әр үзіліссіз $f:X\to\{0,1\}$ (дискретті) тұрақты.

    Қарапайым тілмен: Байланыстылықты үш тілде айтуға болады: бөлінбейді; «әрі ашық, әрі тұйық» жиындар тек тривиал; «иә/жоқ» мәнді үзіліссіз функция әрдайым тұрақты.

    Негіздеме. (3) - ең ыңғайлы құрал: «екі мәнді үзіліссіз функция жоқ».

    Теорема 3.2 · $\mathbb R$-дің байланысты жиындары

    $A\subseteq\mathbb R$ байланысты $\iff A$ - интервал, яғни $a,b\in A$, $a<c<b\Rightarrow c\in A$. Атап айтқанда $\mathbb R$, $[a,b]$, $(a,b)$ байланысты, ал $\mathbb Q$, $\mathbb R\setminus\{0\}$ - байланыссыз.

    Қарапайым тілмен: Түзудің байланысты бөліктері - тек интервалдар (тесігі жоқ жиындар). $\mathbb Q$ сияқты «тесікті» жиындар байланыссыз.

    Негіздеме. Дәлел жоғарғы шекара аксиомасына сүйенеді; $\mathbb Q$-да ол жоқ - сондықтан $\mathbb Q$ байланыссыз.

    Теорема 3.3 · Үзіліссіз бейне және аралық мән

    (1) $X$ байланысты, $f:X\to Y$ үзіліссіз болса, $f(X)$ байланысты. (2) Аралық мән теоремасы: $X$ байланысты, $f:X\to\mathbb R$ үзіліссіз, $f(a)<c<f(b)$ болса, $f(x)=c$ болатын $x$ бар.

    Қарапайым тілмен: Байланысты кеңістіктің үзіліссіз бейнесі байланысты; осыдан аралық мән теоремасы шығады.

    Негіздеме. Демек байланыстылық - топологиялық инвариант.

    Теорема 3.4 · Бірігу және тұйықталу

    (1) Ортақ нүктесі бар байланысты жиындардың бірігуі байланысты. (2) $A$ байланысты, $A\subseteq B\subseteq\overline A$ болса, $B$ байланысты. (3) Әр $x$ нүкте ең үлкен байланысты жиында - оның байланысты компоненті (connected component) жатады; компоненттер $X$-ті бөледі және тұйық.

    Қарапайым тілмен: Ортақ нүктесі бар байланысты бөліктерді біріктірсек, нәтиже байланысты; әр нүктенің өзі жататын ең үлкен байланысты бөлігі - компоненті бар.

    Негіздеме. $\mathbb Q$-дың компоненттері - жеке нүктелер (бірақ олар ашық емес).

    Анықтама 3.2 · Жол арқылы байланыстылық

    $X$-тегі жол (path) - үзіліссіз $\gamma:[0,1]\to X$; $\gamma(0)$ - басы, $\gamma(1)$ - соңы. $X$ - жол арқылы байланысты (path-connected), егер әр $x,y$ үшін басы $x$, соңы $y$ жол бар. Мысалы, дөңес жиын (кесінді $\gamma(t)=(1-t)x+ty$), шеңбер, $\mathbb R^n\setminus\{0\}$ ($n\ge2$).

    Қарапайым тілмен: Жол арқылы байланысты - кез келген екі нүктені кеңістіктен шықпайтын үзіліссіз қисықпен қосуға болады.

    Теорема 3.5 · Жол мен байланыстылық

    (1) Жол арқылы байланысты кеңістік байланысты. (2) Керісінше жалған: топологтың синусоидасы (topologist's sine curve) $S=\{(x,\sin\frac1x):0<x\le1\}\cup(\{0\}\times[-1,1])$ байланысты, бірақ жол арқылы байланысты емес. (3) $\mathbb R^n$-нің ашық байланысты ішкі жиыны жол арқылы байланысты.

    Қарапайым тілмен: Жол бар болса - байланысты. Бірақ керісінше әрдайым емес: топологтың синусоидасы бір тұтас, бірақ оның екі бөлігін жолмен қосу мүмкін емес.

    Негіздеме. (3) - практикада ыңғайлы: ашық облыстар үшін екі ұғым бірдей.

    Теорема 3.6 · Қолданыстар

    (1) $\mathbb R\not\cong\mathbb R^2$ және $[0,1]\not\cong S^1$. (2) Қозғалмайтын нүкте: әр үзіліссіз $f:[0,1]\to[0,1]$ үшін $f(x)=x$ болатын $x$ бар. (3) Антиподтық нүктелер: әр үзіліссіз $f:S^1\to\mathbb R$ үшін $f(p)=f(-p)$ болатын $p$ бар.

    Қарапайым тілмен: Байланыстылық - мықты құрал: түзу мен жазықтық гомеоморф емес; кесіндіден өзіне үзіліссіз функцияның қозғалмайтын нүктесі бар; шеңберде қарама-қарсы нүктелерде мәні бірдей нүкте бар.

    Негіздеме. (3) - Борсук-Улам теоремасының бір өлшемді түрі: экваторда температурасы бірдей қарама-қарсы екі нүкте бар.

    Формула 3.1 · Байланыстылық
    $$X=U\sqcup V,\ \ U,V\in\tau\ \Rightarrow\ U=\varnothing\ \lor\ V=\varnothing$$

    Тең күштісі: үзіліссіз $X\to\{0,1\}$ тұрақты.

    Формула 3.2 · $\mathbb R$-де
    $$a,b\in A,\ a<c<b\ \Rightarrow\ c\in A$$

    Байланысты $\iff$ интервал; жоғарғы шекара аксиомасы.

    Формула 3.3 · Аралық мән
    $$f(a)<c<f(b)\ \Rightarrow\ \exists x:\ f(x)=c$$

    Байланысты $X$, үзіліссіз $f$: бейне байланысты.

    Формула 3.4 · Жол
    $$\gamma:[0,1]\to X,\ \ \gamma(t)=(1-t)x+ty$$

    Дөңес жиындағы кесінді.

    Формула 3.5 · Қозғалмайтын нүкте
    $$f:[0,1]\to[0,1]\ \Rightarrow\ \exists x:\ f(x)=x$$

    $g(x)=f(x)-x$.

    Есте сақта

    Байланыстылықты дәлелдеу/жоққа шығару: (1) байланыссыздық үшін - нақты бөліну табыңыз (екі ашық, бос емес, қиылыспайтын, бәрін жабатын) немесе тұрақты емес үзіліссіз $f:X\to\{0,1\}$; (2) байланыстылық үшін - жол құрыңыз (ең оңай), не байланысты жиындардың ортақ нүктелі бірігуі ретінде көрсетіңіз, не байланысты кеңістіктің үзіліссіз бейнесі ретінде; (3) гомеоморфты еместігін дәлелдеу үшін - нүкте(лер)ді алып тастап, компоненттер санын салыстырыңыз (гомеоморфизм $X\setminus\{p\}\cong Y\setminus\{f(p)\}$ береді).

    Назар аудар

    (1) Байланыстылық ішкі кеңістік топологиясында тексеріледі: $\mathbb Q$-дағы $\{q<\sqrt2\}$ $\mathbb R$-де ашық емес, бірақ $\mathbb Q$-да ашық - бөліну жарамды. (2) Байланысты жиындардың қиылысуы байланыссыз болуы мүмкін: шеңбердің екі доғасы екі нүктеде қиылысады. (3) Байланысты $\ne$ жол арқылы байланысты (топологтың синусоидасы); бірақ ашық $\mathbb R^n$-ішкі жиындары үшін тең. (4) Компоненттер тұйық, бірақ ашық болмауы мүмкін ($\mathbb Q$-да нүктелер).

    Тоқта, ойлан

    Әрі қарай жүрмес бұрын, өзіңізді тексеріңіз: алдымен жауапты ойланыңыз, сосын ашыңыз.

    1. $[0,1]\cup[2,3]$ байланысты ма?

    Жоқ: $U=[0,1]$ және $V=[2,3]$ - осы жиында екеуі де ашық (ішкі кеңістік топологиясында), бос емес, қиылыспайды.

    2. Шеңбер $S^1$ мен кесінді $[0,1]$ гомеоморф па?

    Жоқ: кесіндінің ішкі нүктесін алып тастасақ, екі бөлікке бөлінеді; шеңберден кез келген нүктені алып тастасақ, бір тұтас қалады.

    3. Жазықтықтағы $\mathbb R^2\setminus\{0\}$ байланысты ма?

    Иә, тіпті жол арқылы байланысты: кез келген екі нүктені нөлді айналып өтетін сынық сызықпен қосуға болады.

    4. $f:[0,1]\to\mathbb R$ үзіліссіз, $f(0)=3$, $f(1)=-2$. $f$ қандай мәндерді міндетті түрде қабылдайды?

    $[-2;3]$ кесіндісінің барлық мәндерін (аралық мән теоремасы).

    Қорытып шығару

    Қорытып шығару 1: эквивалент түрлер

    Мақсат: Теорема 3.1-ді дәлелдеу.

    Идея: Үш тұжырымды шеңбер бойымен дәлелдейміз: (1)$\Rightarrow$(2)$\Rightarrow$(3)$\Rightarrow$(1). Ашық-тұйық жиын мен оның толықтауышы - дайын бөліну.

    1. (1)$\Rightarrow$(2): $A$ ашық-тұйық, $A\ne\varnothing,X$ болса, $(A,X\setminus A)$ - бөліну.
    2. (2)$\Rightarrow$(3): $f$ үзіліссіз: $f^{-1}(\{0\})$ ашық ($\{0\}$ дискретті $\{0,1\}$-де ашық) және тұйық ($\{0\}$ тұйық). Демек ол $\varnothing$ не $X$ - $f$ тұрақты.
    3. (3)$\Rightarrow$(1): $(U,V)$ бөліну болса, $f=0$ ($U$-да), $f=1$ ($V$-да) үзіліссіз (алғы бейнелер $\varnothing,U,V,X$ - ашық) және тұрақты емес. ∎

    ∎

    Қорытып шығару 2: интервалдар байланысты

    Мақсат: Теорема 3.2-ні дәлелдеу.

    Идея: Интервал емес жиынды «тесігі» $c$ арқылы оңай бөлеміз. Ал интервал бөлінбейтінін көрсету үшін бөліктердің «шекарасын» $s=\sup$ арқылы ұстап, $s$ ешқайсысына сыймайтынын көрсетеміз.

    1. $A$ интервал емес: $a<c<b$, $a,b\in A$, $c\notin A$. $U=A\cap(-\infty,c)$, $V=A\cap(c,\infty)$ - $A$-да ашық, бос емес, бөліну.
    2. $A$ интервал, бірақ $A=U\cup V$ бөліну деп алайық; $a\in U$, $b\in V$, $a<b$. $[a,b]\subseteq A$. $s=\sup(U\cap[a,b])$ (жоғарғы шекара аксиомасы).
    3. $s\in[a,b]\subseteq A$. $s\in U$ болса: $U$ ашық, $s<b$, демек $[s,s+\varepsilon)\subseteq U\cap[a,b]$ - $\sup$-қа қайшы.
    4. $s\in V$ болса: $V$ ашық, $(s-\varepsilon,s]\subseteq V$, демек $U\cap[a,b]$-ның нүктелері $s-\varepsilon$-нен кіші, $\sup\le s-\varepsilon$ - қайшылық. Демек бөліну жоқ. ∎

    ∎

    Қорытып шығару 3: үзіліссіз бейне

    Мақсат: Теорема 3.3-ті дәлелдеу.

    Идея: Бейненің бөлінуін алғы бейнеге көшірсек, бастапқы кеңістіктің бөлінуі шығар еді - бұл мүмкін емес. Аралық мән - «интервалдың бейнесі интервал» дегеннің салдары.

    1. (1) $f(X)=U\cup V$ бөліну болса, $X=f^{-1}(U)\cup f^{-1}(V)$ - ашық, бос емес, қиылыспайтын: $X$-тің бөлінуі. Қайшылық.
    2. Немесе (3) арқылы: $g:f(X)\to\{0,1\}$ үзіліссіз болса, $g\circ f$ - тұрақты, $f$ сюръективті $f(X)$-ке, демек $g$ тұрақты.
    3. (2) $f(X)\subseteq\mathbb R$ байланысты - интервал (Теорема 3.2). $f(a),f(b)\in f(X)$, демек $c\in f(X)$. ∎

    ∎

    Қорытып шығару 4: жол арқылы байланыстылық

    Мақсат: Теорема 3.5 (1)-(2)-ні дәлелдеу.

    Идея: Жол $[0,1]$ кесіндісінің бейнесі, ал кесінді байланысты - демек жол бөлінбейді. Синусоидада жол тербелістерден «өте алмайды»: $x\to0$ болғанда $\sin\frac1x$ шексіз жиі тербеледі.

    1. (1) $f:X\to\{0,1\}$ үзіліссіз, $x,y\in X$, $\gamma$ - $x$-тен $y$-ке жол. $f\circ\gamma:[0,1]\to\{0,1\}$ үзіліссіз, $[0,1]$ байланысты - тұрақты: $f(x)=f(y)$. Демек $f$ тұрақты.
    2. (2) $G=\{(x,\sin\frac1x):0<x\le1\}$ - $(0,1]$-дің үзіліссіз бейнесі, байланысты. $\overline G=S$ ($\sin\frac1x$ әр $y\in[-1,1]$ мәнін $0$-ге жақын шексіз рет қабылдайды). Теорема 3.4 (2): $S$ байланысты.
    3. Жол жоқ: $\gamma=(x(t),y(t))$ - $(0,0)$-ден $(1,\sin1)$-ге жол деп алайық. $t_0=\sup\{t:x(t)=0\}$; $x(t_0)=0$, $t>t_0$ үшін $x(t)>0$.
    4. Әр $\delta>0$ үшін $x([t_0,t_0+\delta])=[0,\varepsilon]$ ($\varepsilon>0$, аралық мән), онда $\frac1{\pi/2+2k\pi}$ және $\frac1{3\pi/2+2k\pi}$ нүктелері бар - $y$ мәндері $1$ мен $-1$. Демек $y$ $t_0$-де үзіліссіз емес - қайшылық. ∎

    ∎

    Қорытып шығару 5: қолданыстар

    Мақсат: Теорема 3.6-ны дәлелдеу.

    Идея: Әр қолданыста «бір нүктені алып тастау» не «айырманың таңбасы» арқылы байланысты жиынның бейнесін қолданамыз.

    1. (1) $f:\mathbb R^2\to\mathbb R$ гомеоморфизм болса, $\mathbb R^2\setminus\{0\}\cong\mathbb R\setminus\{f(0)\}$. Сол жағы жол арқылы байланысты (шеңбер доғаларымен), оң жағы байланыссыз - қайшылық. $[0,1]$ мен $S^1$: $[0,1]\setminus\{\frac12\}$ байланыссыз, $S^1\setminus\{p\}\cong\mathbb R$ байланысты әр $p$ үшін.
    2. (2) $g(x)=f(x)-x$ үзіліссіз, $g(0)=f(0)\ge0$, $g(1)=f(1)-1\le0$. Аралық мән: $g(x)=0$.
    3. (3) $h(p)=f(p)-f(-p)$ - $S^1$-де үзіліссіз, $h(-p)=-h(p)$. $h(p_0)\ne0$ болса, $h(p_0)$ мен $h(-p_0)$ таңбалары қарама-қарсы.
    4. $S^1$ байланысты, аралық мән теоремасы (Теорема 3.3 (2)): $h(p)=0$ болатын $p$ бар. ∎

    ∎

    Қадамдық шешілген мысалдар

    Мысал 1. $\mathbb Q$ байланыссыз

    $\mathbb Q$-дың бөлінуі.

    1. 1-қадам. $U=\{q\in\mathbb Q:q<\sqrt2\}=\mathbb Q\cap(-\infty,\sqrt2)$, $V=\mathbb Q\cap(\sqrt2,\infty)$.
    2. 2-қадам. Екеуі де $\mathbb Q$-да ашық (ішкі кеңістік), бос емес ($1\in U$, $2\in V$), қиылыспайды.
    3. 3-қадам. $\sqrt2\notin\mathbb Q$, демек $U\cup V=\mathbb Q$ - бөліну.
    4. 4-қадам. Әр екі рационал санның арасында иррационал бар, демек $\mathbb Q$-дың компоненттері - нүктелер.

    Жауабы: Байланыссыз.

    Мысал 2. Компоненттер

    $\{x\in\mathbb R:x^2\ne1\}$ және $\mathbb R\setminus\{0,1,2\}$.

    1. 1-қадам. $x^2\ne1\iff x\notin\{-1,1\}$: $(-\infty,-1)\cup(-1,1)\cup(1,\infty)$ - үш интервал, әрқайсысы байланысты.
    2. 2-қадам. Әр интервал ашық-тұйық (жиын ішінде), демек олар - компоненттер. Саны $3$.
    3. 3-қадам. $\mathbb R\setminus\{0,1,2\}$: $(-\infty,0),(0,1),(1,2),(2,\infty)$ - $4$ компонент.
    4. 4-қадам. Жалпы: $\mathbb R$-ден $k$ нүкте алсақ, $k+1$ компонент.

    Жауабы: $3$ және $4$.

    Мысал 3. Қозғалмайтын нүкте

    $f(x)=\cos x$, $[0,1]\to[0,1]$.

    1. 1-қадам. $\cos$ $[0,1]$-да кемиді, $\cos0=1$, $\cos1\approx0{,}540$ - мәндер $[0,1]$-да.
    2. 2-қадам. Теорема 3.6 (2): $\cos x=x$ болатын $x$ бар.
    3. 3-қадам. Бисекция ($g(x)=\cos x-x$, $g(0)=1>0$, $g(1)<0$): $x\approx0{,}7391$.
    4. 4-қадам. Жалғыз: $g'(x)=-\sin x-1<0$ - $g$ қатаң кемиді.

    Жауабы: $x\approx0{,}739$.

    Мысал 4. Гомеоморфты емес

    «$X$» әрпі мен «$O$» әрпі (жазықтықтағы жиындар).

    1. 1-қадам. «$O$» - шеңбер: кез келген нүктені алсақ, байланысты (доға) қалады.
    2. 2-қадам. «$X$»-тің ортаңғы нүктесін алсақ, $4$ компонент қалады.
    3. 3-қадам. Гомеоморфизм $h$ болса, $O\setminus\{h^{-1}(c)\}\cong X\setminus\{c\}$ - $1\ne4$ компонент.
    4. 4-қадам. Демек $X\not\cong O$. «$T$» әрпі - ортаңғы нүктеде $3$ компонент: $X\not\cong T$.

    Жауабы: Гомеоморфты емес.

    Мысал 5. Антиподтық нүктелер

    $f(\theta)=\sin\theta+\frac12\cos2\theta$ - шеңбердегі «температура».

    1. 1-қадам. $h(\theta)=f(\theta)-f(\theta+\pi)=\sin\theta+\frac12\cos2\theta+\sin\theta-\frac12\cos2\theta=2\sin\theta$.
    2. 2-қадам. $h(0)=0$: $\theta=0$ және $\theta=\pi$ нүктелерінде температура бірдей.
    3. 3-қадам. Тексеру: $f(0)=\frac12$, $f(\pi)=0+\frac12=\frac12$ ✓.
    4. 4-қадам. Теорема 3.6 (3) мұндай жұптың бар екенін кез келген үзіліссіз $f$ үшін кепілдейді.

    Жауабы: $f(0)=f(\pi)$.

    Жиі қателер

    • Байланысты $\Rightarrow$ жол арқылы байланысты → керісінше дұрыс
      Неге қате: Топологтың синусоидасы.
    • $\mathbb Q$ «тығыз», демек байланысты → тығыздық байланыстылық емес
      Неге қате: $\sqrt2$ бойынша бөліну.
    • Байланысты жиындардың қиылысуы байланысты → бірігу (ортақ нүктемен) ғана
      Неге қате: Екі доғаның қиылысуы - $2$ нүкте.
    • Бөліну жиындары $X$-тің сыртында ашық болуы керек → ішкі кеңістікте ашық болса жеткілікті
      Неге қате: $\mathbb Q\cap(-\infty,\sqrt2)$.
    • Компоненттер ашық → тұйық, ашық болмауы мүмкін
      Неге қате: $\mathbb Q$-да нүктелер.
    • $\mathbb R^2\setminus\{0\}$ байланыссыз (мысалы $\mathbb R\setminus\{0\}$ сияқты) → $n\ge2$ үшін жол арқылы байланысты
      Неге қате: Шеңбер доғасымен айналып өтеміз.

    Визуализация

    Бақылаңыз: $x\to0$ болғанда график шексіз жиі тербеліп, $y$ осінің $[-1,1]$ кесіндісіне жабысады. График пен кесінді бірге байланысты (тұйықталу), бірақ кесіндіден графикке жол жүргізу мүмкін емес. Графикті жақындатып қараңыз: тербелістер бітпейді.

    Қолданыс және мини-жоба

    Қолданыс. Байланысты компоненттер - кескінді өңдеудің негізгі құралы (суреттегі нысандарды санау, сегментация), желілердің сенімділігін талдау (неше түйінді өшірсек, желі ыдырайды) және роботтардың жол жоспарлауы (конфигурация кеңістігінің екі нүктесі бір компонентте ме). Қозғалмайтын нүкте теоремалары экономикадағы тепе-теңдік (Нэш) пен итерациялық әдістердің жинақталуында қолданылады.

    Мини-жоба: «Компоненттер мен қозғалмайтын нүктелер». Тордағы (пиксельдік сурет) байланысты компоненттерді санайтын алгоритм жазамыз, бисекция арқылы $\cos x=x$ қозғалмайтын нүктесін табамыз және шеңбердегі кездейсоқ «температура» үшін антиподтық нүктелерді іздейміз.

    import math
import random

picture = [
    "##..#....",
    "##..#..##",
    "....#..##",
    "###......",
    "..#...#..",
]

def components(grid):
    rows, cols = len(grid), len(grid[0])
    seen, count = set(), 0
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == "#" and (r, c) not in seen:
                count += 1
                stack = [(r, c)]
                seen.add((r, c))
                while stack:
                    y, x = stack.pop()
                    for dy, dx in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                        ny, nx = y + dy, x + dx
                        if 0 <= ny < rows and 0 <= nx < cols and grid[ny][nx] == "#" and (ny, nx) not in seen:
                            seen.add((ny, nx))
                            stack.append((ny, nx))
    return count

print("суреттегі компоненттер:", components(picture))

def bisect(g, a, b, steps=50):
    for _ in range(steps):
        m = (a + b) / 2
        if g(a) * g(m) <= 0:
            b = m
        else:
            a = m
    return (a + b) / 2

print("cos x = x:", round(bisect(lambda t: math.cos(t) - t, 0, 1), 6))

random.seed(1)
coef = [(random.uniform(-1, 1), random.uniform(-1, 1), k) for k in range(1, 6)]

def temperature(theta):
    return sum(a * math.cos(k * theta) + b * math.sin(k * theta) for a, b, k in coef)

def h(theta):
    return temperature(theta) - temperature(theta + math.pi)

theta = bisect(h, 0, math.pi) if h(0) * h(math.pi) <= 0 else 0.0
print("антиподтық нүкте θ =", round(theta, 6), " T(θ) =", round(temperature(theta), 6), " T(θ+π) =", round(temperature(theta + math.pi), 6))

    Өзіңіз жалғастырыңыз:

    1. picture-де диагональ көршілерді де ескерсек (8 бағыт), компоненттер саны өзгере ме? «Көршілік» таңдауы топологияны таңдауға ұқсас екенін түсіндіріңіз.
    2. Антиподтық нүктені іздегенде $h(0)$ мен $h(\pi)$ таңбалары әрдайым қарама-қарсы (не нөл) болатынын дәлелдеңіз: $h(\theta+\pi)=-h(\theta)$.
    3. $f(x)=x^2$, $[0,1]\to[0,1]$ үшін бисекциямен қозғалмайтын нүктелерді табыңыз. Нешеу және бисекция қайсысын табады?
