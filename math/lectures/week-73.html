    Бір сөйлеммен

    Кез келген периодты сигнал - әртүрлі жиіліктегі синустар мен косинустардың қосындысы; Фурье коэффициенттері әр жиіліктің «қаншалықты қатты» дыбысталатынын айтады.

    Сабақ мақсаттары

    Сабақ соңында сіз мыналарды істей аласыз:

    • тригонометриялық жүйенің $[-\pi;\pi]$-дегі ортогональдығын дәлелдеу;
    • Фурье коэффициенттері $a_n$, $b_n$ формулаларын қорытып, есептеу;
    • жұп функцияның косинустар, тақ функцияның синустар қатары екенін қолдану;
    • $2L$ периодты функцияның Фурье қатарын жазу;
    • Дирихле теоремасын (бөлікті-тегіс функция, секірістегі орташа мән) қолдану және Гиббс құбылысын түсіндіру;
    • Фурье қатары арқылы сандық қатарлардың қосындысын табу.

    Қысқаша еске салу

    Анықталған интеграл, бөліктеп интегралдау, жұп және тақ функцияның симметриялы аралықтағы интегралы ($\int_{-a}^a$ тақ $=0$). Тригонометриялық көбейтіндіні қосындыға түрлендіру: $\sin\alpha\cos\beta=\frac12[\sin(\alpha+\beta)+\sin(\alpha-\beta)]$ т.б. Сан қатары және жинақталу. Периодты функция.

    Алдымен қолмен: тікбұрышты толқынды синустармен құру

    Формулаға дейін нақты сандармен ойнап көрейік. Әр қадамды өзіңіз де қағазда қайталаңыз.

    $\sin x+\frac{\sin3x}3+\frac{\sin5x}5$ қосындысын $x=\frac\pi2$ нүктесінде есептеңіз және $\frac\pi4\approx0{,}785$-пен салыстырыңыз.

    1. $\sin\frac\pi2=1$; $\frac{\sin\frac{3\pi}2}3=-\frac13$; $\frac{\sin\frac{5\pi}2}5=\frac15$.
    2. Қосынды: $1-0{,}333+0{,}2=0{,}867$.
    3. Тағы бір мүше $\frac{\sin7x}7$: $-\frac17$, қосынды $0{,}724$; тағы біреуі: $+\frac19$, $0{,}835$.
    4. Қосындылар $\frac\pi4$ айналасында тербеліп, оған жақындайды. Бұл - тікбұрышты толқынның (биіктігі $\frac\pi4$) Фурье қатары.

    Байқадыңыз ба? Тегіс синустардан «бұрышты» сигнал құруға болады - тек көп мүше керек. Жоғары жиілікті мүшелер өткір бұрыштарды «салады».

    Интуиция

    Векторды базис бойынша жіктеу үшін оны әр базис векторына проекциялаймыз: $\mathbf v=\sum\frac{\mathbf v\cdot\mathbf e_k}{\mathbf e_k\cdot\mathbf e_k}\mathbf e_k$ (базис ортогональ болса). Фурье дәл осыны функцияларға жасады: «скаляр көбейтінді» - $\int_{-\pi}^\pi f(x)g(x)\,dx$, ал «базис» - $1,\cos x,\sin x,\cos2x,\sin2x,\dots$ Олар өзара ортогональ, сондықтан коэффициент - жай проекция.

    Әр коэффициент $f$-тің сол жиіліктегі «үлесін» өлшейді: $b_3$ үлкен болса, сигналда $\sin3x$ тербелісі күшті. Тегіс функцияның коэффициенттері тез кемиді, ал секірісі бар функцияның коэффициенттері баяу ($\frac1n$ сияқты) - секірісті жасау үшін жоғары жиіліктер көп керек.

    Ақырлы қосынды секірісті ешқашан дәл бермейді: секіріс маңында дербес қосынды шамамен $9\%$-ға асып кетеді, және мүше санын арттырғанда бұл «шың» жіңішкереді, бірақ биіктігі кемімейді - Гиббс құбылысы. Секірістің өзінде қатар сол жақ пен оң жақ шектердің орташасына жинақталады.

    Фурье қатары тек «жуықтау» емес, дәл теңдік: оны белгілі нүктеде жазсақ, сандық қатарлардың қосындысын табамыз. Мысалы, $x^2$-тың қатарынан Эйлер есебі $1+\frac14+\frac19+\dots=\frac{\pi^2}6$ бір жолда шығады.

    Өмірден ұқсастық · эквалайзер

    Музыкалық ойнатқыштағы эквалайзер дыбысты жиіліктерге бөледі: бас, орта, жоғары. Фурье коэффициенттері - әр жиілік жолағының деңгейі. Ал Фурье қатары - сол деңгейлерден дыбысты қайта жинау.

    Өмірден ұқсастық · рецепт

    Ортогональдық - әр ингредиентті бөлек «өлшеуге» болатыны: сигналды $\cos nx$-ке көбейтіп интегралдасақ, тек $n$-ші жиіліктің мөлшері қалады, қалғандары жойылады.

    Белгілерді оқу

    Жоғары математиканың қиындығының жартысы - белгілерде. Теорияға дейін әр белгіні дауыстап оқып, мағынасын біліп алайық:

    Анықтамалар мен теоремалар

    Анықтама 1.1 · Тригонометриялық қатар

    Тригонометриялық қатар (trigonometric series): $\frac{a_0}2+\sum_{n=1}^\infty(a_n\cos nx+b_n\sin nx)$. $2\pi$ периодты, $[-\pi;\pi]$-де интегралданатын $f$ үшін оның Фурье коэффициенттері (Fourier coefficients): $a_n=\frac1\pi\int_{-\pi}^\pi f(x)\cos nx\,dx$ ($n\ge0$), $b_n=\frac1\pi\int_{-\pi}^\pi f(x)\sin nx\,dx$ ($n\ge1$); олармен құрылған қатар - $f$-тің Фурье қатары (Fourier series). $\frac{a_0}2$ - $f$-тің орташа мәні.

    Қарапайым тілмен: Тригонометриялық қатар - әртүрлі жиіліктегі косинустар мен синустардың салмақты қосындысы; Фурье коэффициенттері $f$-тен интеграл арқылы есептеледі.

    Теорема 1.1 · Ортогональдық

    Бүтін $m,n\ge0$ үшін: $\int_{-\pi}^\pi\cos mx\cos nx\,dx=\int_{-\pi}^\pi\sin mx\sin nx\,dx=\pi\,[m=n\ne0]$ (ал $m=n=0$ болса, $\int1\,dx=2\pi$); $\int_{-\pi}^\pi\sin mx\cos nx\,dx=0$ барлық $m,n$ үшін.

    Қарапайым тілмен: Әртүрлі жиіліктегі синустар мен косинустардың көбейтіндісінің период бойынша интегралы нөл - олар «бір-біріне кедергі жасамайды».

    Негіздеме. Ортогональ жүйе (orthogonal system). $[m=n]$ - $m=n$ болса $1$, әйтпесе $0$.

    Теорема 1.2 · Коэффициенттердің жалғыздығы

    Тригонометриялық қатар $[-\pi;\pi]$-де $f$-ке бірқалыпты жинақталса, оның коэффициенттері міндетті түрде $f$-тің Фурье коэффициенттері.

    Қарапайым тілмен: Қатар функцияға бірқалыпты жинақталса, коэффициенттер міндетті түрде Фурье формулаларымен беріледі.

    Негіздеме. Бірқалыпты жинақталу мүшелеп интегралдауға рұқсат береді.

    Теорема 1.3 · Жұп және тақ функциялар

    $f$ жұп болса, $b_n=0$, $a_n=\frac2\pi\int_0^\pi f(x)\cos nx\,dx$ - косинустар қатары (cosine series). $f$ тақ болса, $a_n=0$, $b_n=\frac2\pi\int_0^\pi f(x)\sin nx\,dx$ - синустар қатары (sine series).

    Қарапайым тілмен: Жұп функцияда тек косинустар, тақ функцияда тек синустар қалады - есептеу екі есе қысқарады.

    Негіздеме. Жұп × тақ = тақ, оның симметриялы интегралы $0$.

    Теорема 1.4 · Дирихле теоремасы

    $f$ $2\pi$ периодты және бөлікті-тегіс (piecewise smooth) болсын: $[-\pi;\pi]$ ақырлы аралықтарға бөлінеді, әрқайсысында $f$ пен $f'$ үзіліссіз және шеттерінде ақырлы бір жақты шектері бар. Онда Фурье қатары әр $x$ нүктесінде $\frac{f(x^+)+f(x^-)}2$-ге жинақталады; дербес жағдайда $f$ үзіліссіз нүктеде - $f(x)$-ке.

    Қарапайым тілмен: Бөлікті-тегіс функцияның Фурье қатары әр нүктеде жинақталады: үзіліссіз жерде функцияға, секірісте - сол мен оң мәндердің орта мәніне.

    Негіздеме. Дәлелін келтірмейміз (Дирихле ядросы арқылы). Шарт маңызды: тек үзіліссіздік жеткіліксіз - қатары кейбір нүктеде жинақталмайтын үзіліссіз функциялар бар.

    Анықтама 1.2 · Кез келген период

    $2L$ периодты $f$ үшін: $f\sim\frac{a_0}2+\sum\left(a_n\cos\frac{n\pi x}L+b_n\sin\frac{n\pi x}L\right)$, $a_n=\frac1L\int_{-L}^Lf(x)\cos\frac{n\pi x}L\,dx$, $b_n=\frac1L\int_{-L}^Lf(x)\sin\frac{n\pi x}L\,dx$. Интегралдау аралығы ұзындығы $2L$ кез келген аралық бола алады.

    Қарапайым тілмен: Кез келген периодқа көшу үшін айнымалыны масштабтаймыз: $x\to\frac{\pi x}L$.

    Формула 1.1 · Фурье коэффициенттері
    $$a_n=\frac1\pi\int_{-\pi}^{\pi}f(x)\cos nx\,dx,\qquad b_n=\frac1\pi\int_{-\pi}^{\pi}f(x)\sin nx\,dx$$

    $2\pi$ период; $\frac{a_0}{2}$ - орташа мән.

    Формула 1.2 · Фурье қатары
    $$f(x)\sim\frac{a_0}{2}+\sum_{n=1}^{\infty}\left(a_n\cos nx+b_n\sin nx\right)$$

    Бөлікті-тегіс $f$ үшін $\frac{f(x^+)+f(x^-)}2$-ге жинақталады.

    Формула 1.3 · 2L период
    $$a_n=\frac1L\int_{-L}^{L}f(x)\cos\frac{n\pi x}{L}\,dx,\quad b_n=\frac1L\int_{-L}^{L}f(x)\sin\frac{n\pi x}{L}\,dx$$

    Жиілік $\frac{n\pi}L$.

    Формула 1.4 · Тікбұрышты толқын
    $$\operatorname{sign}(\sin x)=\frac4\pi\left(\sin x+\frac{\sin3x}3+\frac{\sin5x}5+\dots\right)$$

    Тақ функция, тек тақ гармоникалар; секірістерде қатар $0$-ге жинақталады.

    Формула 1.5 · Ара тәрізді толқын
    $$x=2\sum_{n=1}^{\infty}\frac{(-1)^{n+1}}{n}\sin nx\quad(-\pi<x<\pi)$$

    $x=\pm\pi$-де қатар $0$-ге жинақталады (секірістің ортасы).

    Формула 1.6 · x² қатары
    $$x^2=\frac{\pi^2}{3}+4\sum_{n=1}^{\infty}\frac{(-1)^n}{n^2}\cos nx\quad(|x|\le\pi)$$

    Үзіліссіз периодты жалғас - барлық жерде теңдік.

    Есте сақта

    Коэффициент есептеу тәсілі: (1) функцияның жұп/тақ екенін тексеріңіз - есептің жартысы жойылады; (2) бөліктеп интегралдағанда $\sin n\pi=0$, $\cos n\pi=(-1)^n$ қолданыңыз; (3) $a_0$-ді бөлек есептеңіз: жалпы $a_n$ формуласы $n=0$-де жиі бөлгішке $n$ береді; (4) тексеру: $\frac{a_0}2$ - функцияның орташа мәні.

    Назар аудар

    Фурье қатары функцияның $[-\pi;\pi]$-ден тыс периодты жалғасын сипаттайды. $f(x)=x$-тің қатары $(-\pi;\pi)$-де $x$-ке тең, бірақ $x=\pi$-де $0$-ге (секірістің ортасына) жинақталады, ал $x=4$ нүктесінде $4-2\pi$-ге. Сондай-ақ «жинақталады» мен «бірқалыпты жинақталады» әртүрлі: секірісі бар функцияда жинақталу бірқалыпты емес (Гиббс), сондықтан дербес қосындының ең үлкен қатесі $0$-ге ұмтылмайды.

    Тоқта, ойлан

    Әрі қарай жүрмес бұрын, өзіңізді тексеріңіз: алдымен жауапты ойланыңыз, сосын ашыңыз.

    1. $f(x)=\sin3x$-тің Фурье коэффициенттері?

    $b_3=1$, қалғаны $0$ - функция өзі бір гармоника.

    2. $f(x)=|x|$ үшін қай коэффициенттер нөл?

    Барлық $b_n$: функция жұп.

    3. Секіріс нүктесінде, мысалы $f(0^-)=-1$, $f(0^+)=1$ болса, Фурье қатары не береді?

    $\frac{-1+1}2=0$.

    4. $a_0$-дің мағынасы қандай?

    $\frac{a_0}2$ - функцияның период бойынша орта мәні.

    Қорытып шығару

    Қорытып шығару 1: ортогональдық

    Мақсат: Теорема 1.1-ді дәлелдеу.

    Идея: Көбейтінділерді қосындыға айналдыратын тригонометриялық формулалармен интегралды $\int\cos kx$ түріндегі интегралдарға келтіреміз - $k\ne0$ болса нөл.

    1. $\int_{-\pi}^\pi\cos kx\,dx=\left[\frac{\sin kx}k\right]_{-\pi}^\pi=0$ және $\int_{-\pi}^\pi\sin kx\,dx=0$ кез келген бүтін $k\ne0$ үшін.
    2. $\cos mx\cos nx=\frac12[\cos(m-n)x+\cos(m+n)x]$. $m\ne n$: екі мүше де $k\ne0$ түрінде - интеграл $0$.
    3. $m=n\ne0$: $\frac12[1+\cos2nx]$, интегралы $\frac12\cdot2\pi=\pi$.
    4. $\sin mx\sin nx=\frac12[\cos(m-n)x-\cos(m+n)x]$ - дәл солай: $\pi[m=n\ne0]$.
    5. $\sin mx\cos nx$ - тақ функция (тақ × жұп), симметриялы аралықтағы интегралы $0$. ∎

    ∎

    Қорытып шығару 2: коэффициенттер формуласы

    Мақсат: Теорема 1.2: бірқалыпты жинақты қатардың коэффициенттерін табу.

    Идея: Қатарды $\cos mx$-ке көбейтіп, мүшелеп интегралдаймыз; ортогональдық бойынша тек $a_m$ мүшесі қалады.

    1. $f(x)=\frac{a_0}2+\sum_n(a_n\cos nx+b_n\sin nx)$, бірқалыпты жинақты.
    2. Екі жағын $\cos mx$-ке ($m\ge1$) көбейтеміз: шектелген функцияға көбейту бірқалыпты жинақталуды сақтайды.
    3. Мүшелеп интегралдаймыз: $\int_{-\pi}^\pi f\cos mx\,dx$ $=\frac{a_0}2\cdot0$ $+\sum_n a_n\int\cos nx\cos mx$ $+\sum_n b_n\int\sin nx\cos mx$.
    4. Ортогональдық бойынша тек $n=m$ мүшесі қалады: $=a_m\pi$. Демек $a_m=\frac1\pi\int f\cos mx\,dx$.
    5. $m=0$: $\int f\,dx=\frac{a_0}2\cdot2\pi$, $a_0=\frac1\pi\int f\,dx$ - жалпы формулаға сай (сондықтан $\frac{a_0}2$ деп жазамыз).
    6. $\sin mx$-ке көбейтіп, дәл солай $b_m$. ∎

    ∎

    Қорытып шығару 3: ара тәрізді толқынның коэффициенттері

    Мақсат: $f(x)=x$, $-\pi<x<\pi$ (периодты жалғас) үшін $b_n=\frac{2(-1)^{n+1}}n$ екенін көрсету.

    Идея: Функция тақ - тек синус коэффициенттері; бір рет бөліктеп интегралдаймыз.

    1. $f$ тақ: $a_n=0$, $b_n=\frac2\pi\int_0^\pi x\sin nx\,dx$.
    2. Бөліктеп: $u=x$, $dv=\sin nx\,dx$, $v=-\frac{\cos nx}n$.
    3. $\int_0^\pi x\sin nx\,dx=\left[-\frac{x\cos nx}n\right]_0^\pi+\frac1n\int_0^\pi\cos nx\,dx=-\frac{\pi(-1)^n}n+0$.
    4. $b_n=\frac2\pi\cdot\frac{\pi(-1)^{n+1}}{n}=\frac{2(-1)^{n+1}}{n}$.
    5. Дирихле бойынша $(-\pi;\pi)$-де қатар $x$-ке, $x=\pm\pi$-де $\frac{\pi+(-\pi)}2=0$-ге жинақталады - шынында, барлық $\sin n\pi=0$ ✓.

    ∎

    Қорытып шығару 4: Базель есебі

    Мақсат: $x^2$-тың Фурье қатарынан $\sum_{n\ge1}\frac1{n^2}=\frac{\pi^2}6$ шығару.

    Идея: $x^2$-тың Фурье қатарын тауып, $x=\pi$ нүктесін қоямыз: $\sum\frac1{n^2}$ шығады.

    1. $f(x)=x^2$ жұп: $b_n=0$. $a_0=\frac2\pi\int_0^\pi x^2dx=\frac{2\pi^2}3$.
    2. $a_n=\frac2\pi\int_0^\pi x^2\cos nx\,dx$; екі рет бөліктеп интегралдап: $\int_0^\pi x^2\cos nx\,dx=\frac{2\pi(-1)^n}{n^2}$, демек $a_n=\frac{4(-1)^n}{n^2}$.
    3. $f$-тің периодты жалғасы үзіліссіз және бөлікті-тегіс ($x=\pm\pi$-де $\pi^2=\pi^2$), сондықтан Дирихле бойынша барлық $x\in[-\pi;\pi]$ үшін $x^2=\frac{\pi^2}3+4\sum\frac{(-1)^n}{n^2}\cos nx$.
    4. $x=\pi$: $\cos n\pi=(-1)^n$, $(-1)^n(-1)^n=1$: $\pi^2=\frac{\pi^2}3+4\sum\frac1{n^2}$.
    5. $\sum\frac1{n^2}=\frac14\cdot\frac{2\pi^2}{3}=\frac{\pi^2}6$. ∎ ($x=0$ қойсақ: $\sum\frac{(-1)^{n+1}}{n^2}=\frac{\pi^2}{12}$.)

    ∎

    Қадамдық шешілген мысалдар

    Мысал 1. Тікбұрышты толқын

    $f(x)=-1$ ($-\pi<x<0$), $f(x)=1$ ($0<x<\pi$), $2\pi$ периодты.

    1. 1-қадам. $f$ тақ: $a_n=0$, $b_n=\frac2\pi\int_0^\pi\sin nx\,dx=\frac2\pi\cdot\frac{1-\cos n\pi}{n}=\frac{2(1-(-1)^n)}{\pi n}$.
    2. 2-қадам. Жұп $n$: $b_n=0$; тақ $n$: $b_n=\frac4{\pi n}$.
    3. 3-қадам. $f(x)=\frac4\pi\left(\sin x+\frac{\sin3x}3+\frac{\sin5x}5+\dots\right)$, $x\ne k\pi$.
    4. 4-қадам. $x=k\pi$-де (секірістер) қатар $\frac{1+(-1)}2=0$-ге жинақталады.
    5. 5-қадам. $x=\frac\pi2$: $1=\frac4\pi\left(1-\frac13+\frac15-\dots\right)$, яғни Лейбниц қатары $1-\frac13+\frac15-\dots=\frac\pi4$.

    Жауабы: $\frac4\pi\sum_{k\ge0}\frac{\sin(2k+1)x}{2k+1}$.

    Мысал 2. Модуль

    $f(x)=|x|$, $-\pi\le x\le\pi$, периодты жалғас.

    1. 1-қадам. Жұп: $b_n=0$; $a_0=\frac2\pi\int_0^\pi x\,dx=\pi$.
    2. 2-қадам. $a_n=\frac2\pi\int_0^\pi x\cos nx\,dx=\frac2\pi\cdot\frac{(-1)^n-1}{n^2}$ (бөліктеп).
    3. 3-қадам. Тақ $n$: $a_n=-\frac4{\pi n^2}$; жұп $n\ge2$: $0$.
    4. 4-қадам. $|x|=\frac\pi2-\frac4\pi\left(\cos x+\frac{\cos3x}9+\frac{\cos5x}{25}+\dots\right)$ - барлық жерде (жалғас үзіліссіз).
    5. 5-қадам. Коэффициенттер $\frac1{n^2}$ сияқты кемиді (тікбұрышты толқында $\frac1n$): функция үзіліссіз, тек «бұрышы» бар.

    Жауабы: $\frac\pi2-\frac4\pi\sum_{k\ge0}\frac{\cos(2k+1)x}{(2k+1)^2}$.

    Мысал 3. Басқа период

    $f(x)=x$, $-1<x<1$, период $2$ ($L=1$).

    1. 1-қадам. Тақ: $b_n=\frac2L\int_0^Lx\sin\frac{n\pi x}{L}dx=2\int_0^1x\sin n\pi x\,dx$.
    2. 2-қадам. Бөліктеп: $\int_0^1x\sin n\pi x\,dx=-\frac{\cos n\pi}{n\pi}+\frac{\sin n\pi}{(n\pi)^2}=\frac{(-1)^{n+1}}{n\pi}$.
    3. 3-қадам. $b_n=\frac{2(-1)^{n+1}}{n\pi}$.
    4. 4-қадам. $x=\frac2\pi\left(\sin\pi x-\frac{\sin2\pi x}2+\frac{\sin3\pi x}3-\dots\right)$, $|x|<1$ - $2\pi$ периодты нұсқадан $x\mapsto\pi x$ ауыстыруымен де шығады.

    Жауабы: $b_n=\frac{2(-1)^{n+1}}{n\pi}$.

    Мысал 4. Жинақталу мәні

    $f(x)=e^x$, $-\pi<x<\pi$ периодты жалғасының Фурье қатары $x=\pi$-де неге жинақталады?

    1. 1-қадам. $f$ бөлікті-тегіс: $(-\pi;\pi)$-де тегіс, шеттерінде ақырлы шектер.
    2. 2-қадам. $x=\pi$-де: сол жақ шек $f(\pi^-)=e^\pi$, оң жақ шек (периодты жалғас) $f(\pi^+)=f(-\pi^+)=e^{-\pi}$.
    3. 3-қадам. Дирихле: $\frac{e^\pi+e^{-\pi}}2=\operatorname{ch}\pi\approx11{,}59$.
    4. 4-қадам. $f(\pi)$ мәні анықталмаған (не кез келген) - қатар оған тәуелсіз.

    Жауабы: $\operatorname{ch}\pi$.

    Жиі қателер

    • $a_0$ қатарда $a_0$ болып тұрады → $\frac{a_0}{2}$
      Неге қате: жалпы формулаға сай болу үшін.
    • Жұп функцияда синус мүшелерін есептеу → $b_n=0$ бірден
      Неге қате: симметрияны пайдаланыңыз.
    • Секірісте қатар $f(x)$-ке жинақталады → $\frac{f(x^+)+f(x^-)}2$
      Неге қате: Дирихле теоремасы.
    • $\cos n\pi=1$ → $\cos n\pi=(-1)^n$
      Неге қате: $n$ тақ болса $-1$.
    • Мүше санын арттырсақ, Гиббс асуы жойылады → асу $\approx9\%$ қалады, тек жіңішкереді
      Неге қате: жинақталу бірқалыпты емес.
    • $2L$ периодта $\frac1\pi$ коэффициенті → $\frac1L$
      Неге қате: формуланы $L$ бойынша ауыстыру.

    Визуализация

    Бақылаңыз: $N$ - қосылған ең жоғары гармоника (тек тақ). $N$-ді арттырыңыз: дербес қосынды тікбұрышқа жақындайды, бірақ $x=0$ мен $x=\pm\pi$ маңында шамамен $1{,}18$-ге дейін асып кетеді (Гиббс: секіріс биіктігі $2$-нің $\approx9\%$-ы). Асу кемімейді, тек секіріске жақындап жіңішкереді. Секірістің дәл өзінде барлық қосынды $0$ - сол мен оң мәндердің орташасы.

    Бақылаңыз: Коэффициенттер $\frac2n$ - баяу кемиді, өйткені периодты жалғаста $x=\pm\pi$-де секіріс бар. $(-\pi;\pi)$ ішінде қосынды $x$-ке жақындайды, ал $x=\pm\pi$-де барлық дербес қосынды $0$ - секірістің ортасы.

    import math

def coef(f, n, kind, N=20000):
    h = 2 * math.pi / N
    g = math.cos if kind == "a" else math.sin
    return sum(f(-math.pi + (k + 0.5) * h) * g(n * (-math.pi + (k + 0.5) * h)) for k in range(N)) * h / math.pi

saw = lambda x: x
sq = lambda x: 1.0 if x > 0 else -1.0
print("x:      b_n сандық", [round(coef(saw, n, "b"), 4) for n in range(1, 6)], " формула", [round(2 * (-1) ** (n + 1) / n, 4) for n in range(1, 6)])
print("square: b_n сандық", [round(coef(sq, n, "b"), 4) for n in range(1, 6)], " формула", [round(2 * (1 - (-1) ** n) / (math.pi * n), 4) for n in range(1, 6)])

def S(x, N):
    return 4 / math.pi * sum(math.sin(k * x) / k for k in range(1, N + 1, 2))

for N in (9, 39, 159, 639):
    peak = max(S(j * math.pi / (40 * N), N) for j in range(1, 200))   # секіріс маңында
    print(f"N = {N:3d}: max S_N ≈ {peak:.4f}  (асу {100 * (peak - 1) / 2:.2f}% секірістен)")

print("Σ 1/n^2 (10^5 мүше) =", round(sum(1 / n**2 for n in range(1, 100001)), 6), "  π²/6 =", round(math.pi**2 / 6, 6))

    1. Гиббс асуы $N$ өскенде неге $\approx8{,}95\%$-да тұрақталады? Шекті мән $\frac2\pi\int_0^\pi\frac{\sin t}t\,dt\approx1{,}179$ екенін сандық тексеріңіз.
    2. $|x|$ үшін коэффициенттерді сандық есептеп, $-\frac4{\pi n^2}$ (тақ $n$) формуласымен салыстырыңыз. Дербес қосындының ең үлкен қатесі $N$ өскенде қалай кемиді?
