    Квадраттық қалдықтар

    $x^2\equiv2\pmod7$ теңдеуінің шешімі бар ма? Бар: $3^2=9\equiv2$. Ал $x^2\equiv3\pmod7$ ше? $1,\dots,6$ сандарының квадраттары $7$ бойынша тек $1,2,4$ қалдықтарын береді, демек жоқ.

    ⏱ Оқу ≈ 50 минЕсептер ≈ 1 сағТест ≈ 5 минБарлығы ≈ 2 сағ

    Модуль бойынша квадрат түбір алу - сандар теориясының классикалық есебі. Ол криптографияда (Рабин шифры, эллипстік қисықтағы нүктелер), кездейсоқ сандар генераторларында және факторлау алгоритмдерінде қолданылады. Бұл сабақта жай модуль бойынша квадраттық қалдықтарды зерттейміз: олардың санын, Эйлер критерийін, Лежандр символын және Гаусстың квадраттық өзарлық заңын. Соңғысының дәлелі ұзақ, сондықтан оны дәлелсіз келтіріп, жобада сандық түрде тексереміз.

    Курс туралы

    Бұл сабақтың мазмұны үшін жауапкершілікті курс авторы Sagid Mustafa өзіне алады. Қате немесе түсініксіз жер тапсаңыз, хабарлаңыз. Бұл курс ресми емтихан не куәлік баламасы емес.

    Бір сөйлеммен

    Квадраттық қалдық - модуль бойынша «квадрат түбірі бар» сан; Лежандр символы оны $\pm1$-мен белгілейді, ал квадраттық өзарлық заңы $p$ модулі мен $q$ модулін таңғаларлық түрде байланыстырады.

    Сабақ мақсаттары

    Сабақ соңында сіз мыналарды істей аласыз:

    • квадраттық қалдық пен Лежандр символын анықтап, кіші модульдер үшін қалдықтар тізімін құру;
    • Лагранж теоремасын (жай модуль бойынша көпмүшенің түбірлер саны) дәлелдеп, құрама модульде жалған екенін көрсету;
    • $\mathbb Z_p^*$-да қалдықтар мен бейқалдықтардың саны тең екенін дәлелдеу;
    • Эйлер критерийін дәлелдеп, одан Лежандр символының мультипликативтілігін және $\left(\frac{-1}p\right)$ формуласын алу;
    • квадраттық өзарлық заңын және $\left(\frac2p\right)$ формуласын Лежандр символын есептеуге қолдану;
    • $p\equiv3\pmod4$ үшін модуль бойынша квадрат түбірді формуламен табу.

    Қысқаша еске салу

    Салыстырулар, модуль бойынша кері элемент, жылдам дәрежелеу (3-сабақ). Ферманың кіші теоремасы, Вильсон теоремасы (4-сабақ). Евклид леммасы (1-сабақ). Көпмүшелерді бөлу, Безу теоремасы (көпмүше үшін: $f(r)=0\Rightarrow(t-r)\mid f$).

    Алдымен қолмен: 7 бойынша квадраттар кестесі

    Формулаға дейін нақты сандармен ойнап көрейік. Әр қадамды өзіңіз де қағазда қайталаңыз.

    $1,\dots,6$ сандарының квадраттарын $7$ бойынша есептеңіз. Қай сандардың $7$ бойынша квадрат түбірі бар?

    1. $1^2=1$, $2^2=4$, $3^2=9\equiv2$, $4^2=16\equiv2$, $5^2=25\equiv4$, $6^2=36\equiv1$.
    2. Квадраттар: $\{1,2,4\}$ - квадраттық қалдықтар. $\{3,5,6\}$ - бейқалдықтар.
    3. Әр қалдық екі рет шығады: $x$ пен $7-x$-тің квадраттары тең. Сондықтан дәл жартысы ($3$-уі) қалдық.
    4. Эйлер критерийімен тексеру: $3^{\frac{7-1}2}=27\equiv-1$ - бейқалдық ✓; $2^3=8\equiv1$ - қалдық ✓.

    Байқадыңыз ба? Квадраттар кестесі әрдайым «жартылай»: $p$ тақ жай болса, нөл емес қалдықтардың тура жартысы - квадраттар. Эйлер критерийі кестесіз тексеруге мүмкіндік береді.

    Интуиция

    Жай $p$ бойынша $x$ пен $-x$-тің квадраттары бірдей: $x^2=(-x)^2$. Сондықтан $1,\dots,p-1$ сандарының квадраттары жұп-жұбымен сәйкес келеді, және әртүрлі квадраттар саны $\frac{p-1}2$. $p=11$: $1,4,9,5,3$ - бес қалдық, қалған бесеуі ($2,6,7,8,10$) квадрат емес.

    Ферма бойынша $a^{p-1}\equiv1$, демек $a^{(p-1)/2}$ саны - $1$-дің квадрат түбірі, яғни $\pm1$. Қай таңба? Эйлер критерийі: $a$ квадрат болса $+1$, болмаса $-1$. Бұл $a$-ның квадрат екенін түбірді іздемей-ақ, бір дәрежелеумен тексеруге мүмкіндік береді.

    Лежандр символы $\left(\frac ap\right)$ - $+1$ (квадрат), $-1$ (квадрат емес) не $0$ ($p\mid a$). Ол мультипликативті: квадрат $\times$ квадрат $=$ квадрат, бейқалдық $\times$ бейқалдық $=$ квадрат (минус $\times$ минус $=$ плюс сияқты).

    Квадраттық өзарлық заңы $\left(\frac pq\right)$ мен $\left(\frac qp\right)$ таңбаларын байланыстырады - бір қарағанда $p$ модулі бойынша мәселе мен $q$ модулі бойынша мәселенің ешқандай байланысы жоқ сияқты. Гаусс бұл заңды «алтын теорема» деп атап, оның сегіз түрлі дәлелін берген.

    Өмірден ұқсастық · айнадағы шағылыс

    $x$ пен $-x$ - бір-бірінің айнадағы шағылысы, екеуінің квадраты бірдей. Сондықтан $p-1$ санның квадраттары тек $\frac{p-1}2$ әртүрлі мән береді - әр квадраттың екі «иесі» бар.

    Өмірден ұқсастық · екі елдің келісімі

    Квадраттық өзарлық: «$p$ - $q$ бойынша квадрат па?» мен «$q$ - $p$ бойынша квадрат па?» сұрақтарының жауабы бірдей, тек екеуі де $4k+3$ түрінде болса - қарама-қарсы. Бір қиын сұрақты екінші оңай сұраққа ауыстыруға болады.

    Анықтамалар мен теоремалар

    Анықтама 5.1 · Квадраттық қалдық және Лежандр символы

    $p$ - тақ жай сан, $p\nmid a$. $a$ - $p$ модулі бойынша квадраттық қалдық (quadratic residue), егер $x^2\equiv a\pmod p$ шешілетін болса; әйтпесе - квадраттық бейқалдық (quadratic nonresidue). Лежандр символы (Legendre symbol): $\left(\frac ap\right)=1$ (қалдық), $-1$ (бейқалдық), $0$ ($p\mid a$). Ол тек $a\bmod p$-ға тәуелді.

    Қарапайым тілмен: $a$ квадраттық қалдық, егер модуль бойынша оның квадрат түбірі бар болса; Лежандр символы жауапты $\pm1$-мен жазады.

    Теорема 5.1 · Лагранж теоремасы

    $p$ жай, $f(t)=c_dt^d+\dots+c_0$ бүтін коэффициентті, $p\nmid c_d$. Онда $f(t)\equiv0\pmod p$ салыстыруының $p$ модулі бойынша әртүрлі шешімдері $d$-дан аспайды.

    Қарапайым тілмен: Жай модуль бойынша $d$ дәрежелі көпмүшенің $d$-дан көп түбірі жоқ - нақты сандардағыдай.

    Негіздеме. Құрама модульде жалған: $t^2\equiv1\pmod8$ - төрт шешім $1,3,5,7$.

    Теорема 5.2 · Қалдықтар саны

    $p$ тақ жай болса, $1,\dots,p-1$ ішінде дәл $\frac{p-1}2$ квадраттық қалдық және $\frac{p-1}2$ бейқалдық бар; қалдықтар - $1^2,2^2,\dots,\left(\frac{p-1}2\right)^2$ сандарының қалдықтары.

    Қарапайым тілмен: Нөл емес қалдықтардың дәл жартысы квадраттық қалдық.

    Негіздеме. $p=7$: $\{1,2,4\}$; $p=11$: $\{1,3,4,5,9\}$.

    Теорема 5.3 · Эйлер критерийі

    $p$ тақ жай болса, кез келген $a$ үшін $\left(\frac ap\right)\equiv a^{\frac{p-1}2}\pmod p$. Салдарлар: (1) $\left(\frac{ab}p\right)=\left(\frac ap\right)\left(\frac bp\right)$; (2) $\left(\frac{-1}p\right)=(-1)^{\frac{p-1}2}$, яғни $-1$ - квадраттық қалдық $\iff p\equiv1\pmod4$.

    Қарапайым тілмен: $a$ квадрат па - оны $\frac{p-1}2$ дәрежесіне шығарып білеміз: $1$ болса - иә, $-1$ болса - жоқ; символ көбейтіндіге көбейтіледі.

    Негіздеме. Эйлер критерийі (Euler's criterion).

    Теорема 5.4 · Квадраттық өзарлық заңы

    $p\ne q$ - тақ жай сандар. (1) $\left(\frac pq\right)\left(\frac qp\right)=(-1)^{\frac{p-1}2\cdot\frac{q-1}2}$: таңбалар тек $p\equiv q\equiv3\pmod4$ болғанда қарама-қарсы. (2) $\left(\frac2p\right)=(-1)^{\frac{p^2-1}8}$: $2$ - қалдық $\iff p\equiv\pm1\pmod8$.

    Қарапайым тілмен: $p$ мен $q$ туралы екі сұрақтың жауабы бірдей, тек екеуі $3\pmod4$ болса қарама-қарсы; $-1$ мен $2$ үшін бөлек ережелер бар (дәлелсіз).

    Негіздеме. Квадраттық өзарлық заңы (law of quadratic reciprocity). Бұл сабақта дәлелсіз келтіреміз (дәлелі Гаусс леммасы арқылы); жобада барлық $p,q<200$ үшін тексереміз.

    Формула 5.1 · Лежандр символы
    $$\left(\frac ap\right)\in\{-1,0,1\},\quad\left(\frac{ab}p\right)=\left(\frac ap\right)\left(\frac bp\right)$$

    $p$ тақ жай.

    Формула 5.2 · Эйлер критерийі
    $$\left(\frac ap\right)\equiv a^{\frac{p-1}2}\pmod p$$

    Бір дәрежелеу.

    Формула 5.3 · Минус бір
    $$\left(\frac{-1}p\right)=(-1)^{\frac{p-1}2}$$

    $p\equiv1\pmod4\iff-1$ квадрат.

    Формула 5.4 · Екі
    $$\left(\frac2p\right)=(-1)^{\frac{p^2-1}8}$$

    $p\equiv\pm1\pmod8\iff2$ квадрат.

    Формула 5.5 · Квадраттық өзарлық
    $$\left(\frac pq\right)\left(\frac qp\right)=(-1)^{\frac{p-1}2\cdot\frac{q-1}2}$$

    $p\ne q$ тақ жай.

    Формула 5.6 · Түбір, $p\equiv3\pmod4$
    $$\left(\frac ap\right)=1\ \Rightarrow\ x\equiv\pm a^{\frac{p+1}4}\pmod p$$

    $x^2\equiv a$.

    Есте сақта

    Лежандр символын есептеу жоспары: (1) $a$-ны $p$ бойынша $[0;p)$-ға келтіріңіз; (2) $a$-ны көбейткіштерге жіктеп, мультипликативтілікті қолданыңыз ($\left(\frac{k^2}p\right)=1$ - квадрат көбейткіштерді алып тастаңыз); (3) $-1$ мен $2$ үшін арнайы формулалар; (4) тақ жай $q$ үшін өзарлық заңы бойынша $\left(\frac qp\right)$-ны $\left(\frac pq\right)$-ға аударыңыз, ол кішірек модуль - қайтадан (1)-ге. Немесе тікелей: Эйлер критерийі, бір жылдам дәрежелеу.

    Назар аудар

    Шарттарға назар аударыңыз. (1) Эйлер критерийі мен өзарлық заңы тек жай модуль үшін. Құрама $n$ үшін Якоби символы $\left(\frac an\right)=1$ болса да, $a$ квадрат болмауы мүмкін: $\left(\frac2{15}\right)=\left(\frac23\right)\left(\frac25\right)=(-1)(-1)=1$, бірақ $15$ бойынша квадраттар $\{0,1,4,6,9,10\}$ - $2$ жоқ. (2) Лагранж теоремасы құрама модульде жалған: $t^2\equiv1\pmod8$ төрт түбірі бар. (3) $p=2$ - ерекше: барлық қалдық квадрат, символ анықталмайды.

    Тоқта, ойлан

    Әрі қарай жүрмес бұрын, өзіңізді тексеріңіз: алдымен жауапты ойланыңыз, сосын ашыңыз.

    1. $\left(\frac{-1}{13}\right)$ неге тең?

    $+1$: $13\equiv1\pmod4$; шынында $5^2=25\equiv-1\pmod{13}$.

    2. $x^2\equiv5\pmod{11}$ шешімі бар ма?

    Иә: $4^2=16\equiv5$ (сонымен қатар $7^2=49\equiv5$).

    3. $11$ бойынша неше квадраттық қалдық бар?

    $\frac{11-1}2=5$: $1,3,4,5,9$.

    4. Эйлер критерийі бойынша $3$ $\pmod{11}$ квадраттық қалдық па?

    $3^5=243=22\cdot11+1\equiv1$ - иә ($5^2=25\equiv3$).

    Қорытып шығару

    Қорытып шығару 1: Лагранж теоремасы

    Мақсат: Теорема 5.1-ді $d$ бойынша индукциямен дәлелдеу.

    Идея: Түбір табылса, $(t-r)$ көбейткішін бөліп шығарып, дәрежені төмендетеміз - индукция; жай модульде нөлдің бөлгіштері жоқ.

    1. $d=0$: $f=c_0$, $p\nmid c_0$ - шешім жоқ. $d=1$: $c_1t+c_0\equiv0$, $\gcd(c_1,p)=1$ - Теорема 3.4 бойынша жалғыз шешім.
    2. $d\ge1$ және $r$ - шешім болсын (жоқ болса, дәлелдейтін ештеңе жоқ). Көпмүшені бөлу: $f(t)=(t-r)g(t)+f(r)$, $g$-ның дәрежесі $d-1$, басқы коэффициенті $c_d$.
    3. $f(r)\equiv0$, демек $f(t)\equiv(t-r)g(t)\pmod p$ әр бүтін $t$ үшін.
    4. $s\not\equiv r$ - басқа шешім болса, $p\mid(s-r)g(s)$, $p\nmid s-r$; Евклид леммасы: $p\mid g(s)$.
    5. Индукция болжамы: $g$-ның шешімдері $\le d-1$, демек $f$-тің шешімдері $\le1+(d-1)=d$. ∎ Құрама модульде Евклид леммасы жоқ, сондықтан дәлел құлайды.

    ∎

    Қорытып шығару 2: қалдықтар саны

    Мақсат: Теорема 5.2-ні дәлелдеу.

    Идея: $x$ пен $p-x$ квадраттары тең, ал $1..\frac{p-1}2$ сандарының квадраттары әртүрлі.

    1. Әр қалдық $a\equiv x^2$, $x\in\{1,\dots,p-1\}$, және $x^2\equiv(p-x)^2$; $x$ мен $p-x$ сандарының бірі $\le\frac{p-1}2$. Демек қалдықтар - $1^2,\dots,\left(\frac{p-1}2\right)^2$.
    2. Олар әртүрлі: $x^2\equiv y^2\Rightarrow p\mid(x-y)(x+y)$; $1\le x,y\le\frac{p-1}2$ болса, $2\le x+y\le p-1$, $p\nmid x+y$, демек $p\mid x-y$, $x=y$.
    3. Сонымен дәл $\frac{p-1}2$ қалдық, қалған $\frac{p-1}2$ - бейқалдық. ∎

    ∎

    Қорытып шығару 3: Эйлер критерийі

    Мақсат: Теорема 5.3-ті дәлелдеу.

    Идея: $a^{\frac{p-1}2}$-нің квадраты $1$, демек өзі $\pm1$. Қалдықтар үшін ол $x^{p-1}\equiv1$; бейқалдықтарды түбірлер санымен (Лагранж) шектейміз.

    1. $p\mid a$: екі жақ та $0$. $p\nmid a$ алайық, $h=\frac{p-1}2$. Ферма: $(a^h)^2=a^{p-1}\equiv1$, демек $p\mid(a^h-1)(a^h+1)$, $a^h\equiv\pm1$.
    2. $a$ қалдық, $a\equiv x^2$: $a^h\equiv x^{p-1}\equiv1$ (Ферма, $p\nmid x$). Демек барлық $h$ қалдық - $t^h-1\equiv0$ салыстыруының шешімдері.
    3. Лагранж (Теорема 5.1): $t^h-1$-дің шешімдері $\le h$. Олар дәл $h$ қалдық, демек бейқалдықтар шешім емес: бейқалдық үшін $a^h\equiv-1$.
    4. (1): $(ab)^h=a^hb^h$, ал $\pm1$ мәндер $p\ge3$ бойынша әртүрлі, демек салыстыру теңдікке айналады.
    5. (2): $a=-1$: $\left(\frac{-1}p\right)\equiv(-1)^h$, екі жақ та $\pm1$. ∎

    ∎

    Қорытып шығару 4: $p\equiv3\pmod4$ үшін түбір

    Мақсат: $\left(\frac ap\right)=1$, $p\equiv3\pmod4$ болса, $x=a^{\frac{p+1}4}$ - $x^2\equiv a$ түбірі.

    Идея: $p=4k+3$ болса, $a^{\frac{p+1}4}$ - дайын түбір: квадратын Эйлер критерийімен тексереміз.

    1. $p\equiv3\pmod4\Rightarrow p+1$ саны $4$-ке бөлінеді, $\frac{p+1}4$ - бүтін.
    2. $x^2=a^{\frac{p+1}2}=a\cdot a^{\frac{p-1}2}$.
    3. Эйлер критерийі: $a^{\frac{p-1}2}\equiv\left(\frac ap\right)=1$.
    4. Демек $x^2\equiv a$; екінші түбір $-x$. ∎ $p\equiv1\pmod4$ үшін мұндай қарапайым формула жоқ (Тонелли-Шенкс алгоритмі қолданылады).

    ∎

    Қорытып шығару 5: $4k+1$ түріндегі жай сандар шексіз

    Мақсат: Эйлер критерийінің салдары.

    Идея: $(2p_1\cdots p_k)^2+1$-нің жай бөлгіші $q$ үшін $-1$ квадраттық қалдық, ал бұл тек $q\equiv1\pmod4$ кезде мүмкін.

    1. Шекті деп алайық: $p_1,\dots,p_k$. $N=(2p_1\cdots p_k)^2+1$, $q$ - $N$-нің жай бөлгіші.
    2. $N$ тақ, демек $q$ тақ; $q\ne p_i$ ($p_i\mid N-1$).
    3. $(2p_1\cdots p_k)^2\equiv-1\pmod q$, демек $\left(\frac{-1}q\right)=1$.
    4. Теорема 5.3 (2): $q\equiv1\pmod4$ - тізімде жоқ, қайшылық. ∎

    ∎

    Қадамдық шешілген мысалдар

    Мысал 1. Қалдықтар тізімі

    $p=13$ үшін квадраттық қалдықтар.

    1. 1-қадам. $1^2,\dots,6^2$: $1,4,9,16,25,36$.
    2. 2-қадам. $\bmod13$: $1,4,9,3,12,10$.
    3. 3-қадам. Қалдықтар $\{1,3,4,9,10,12\}$ - алты ($\frac{13-1}2$), бейқалдықтар $\{2,5,6,7,8,11\}$.
    4. 4-қадам. $12\equiv-1$ қалдық - $13\equiv1\pmod4$ ✓ ($5^2=25\equiv-1$).

    Жауабы: $\{1,3,4,9,10,12\}$.

    Мысал 2. Эйлер критерийі

    $\left(\frac37\right)$.

    1. 1-қадам. $\frac{7-1}2=3$: $3^3=27\equiv6\equiv-1\pmod7$.
    2. 2-қадам. Демек $\left(\frac37\right)=-1$.
    3. 3-қадам. Тексеру: $7$ бойынша квадраттар $\{1,2,4\}$ - $3$ жоқ ✓.

    Жауабы: $-1$.

    Мысал 3. Өзарлық заңы

    $\left(\frac{17}{31}\right)$.

    1. 1-қадам. $17\equiv1\pmod4$: $\left(\frac{17}{31}\right)=\left(\frac{31}{17}\right)=\left(\frac{14}{17}\right)=\left(\frac2{17}\right)\left(\frac7{17}\right)$.
    2. 2-қадам. $17\equiv1\pmod8$: $\left(\frac2{17}\right)=1$.
    3. 3-қадам. $\left(\frac7{17}\right)=\left(\frac{17}7\right)=\left(\frac37\right)=-1$ (алдыңғы мысал).
    4. 4-қадам. Нәтиже $1\cdot(-1)=-1$: $x^2\equiv17\pmod{31}$ шешімсіз.

    Жауабы: $-1$.

    Мысал 4. Модуль бойынша түбір

    $x^2\equiv5\pmod{11}$.

    1. 1-қадам. Эйлер: $5^5=3125=284\cdot11+1\equiv1$ - қалдық.
    2. 2-қадам. $11\equiv3\pmod4$: $x\equiv5^{\frac{11+1}4}=5^3=125\equiv4\pmod{11}$.
    3. 3-қадам. Тексеру: $4^2=16\equiv5$ ✓. Екінші түбір $-4\equiv7$.

    Жауабы: $x\equiv4,7\pmod{11}$.

    Мысал 5. Құрама модуль

    $x^2\equiv1\pmod{8}$ және $x^2\equiv2\pmod{15}$.

    1. 1-қадам. $\bmod8$: $1^2=1$, $3^2=9\equiv1$, $5^2=25\equiv1$, $7^2=49\equiv1$ - төрт түбір, Лагранж теоремасы құрама модульде жалған.
    2. 2-қадам. $\bmod15$: ҚҚТ бойынша $x^2\equiv2\pmod3$ және $x^2\equiv2\pmod5$ қажет.
    3. 3-қадам. $\left(\frac23\right)=-1$ - бірінші шешімсіз. Демек жүйе де шешімсіз, бірақ Якоби символы $\left(\frac2{15}\right)=(-1)(-1)=1$.

    Жауабы: $4$ түбір; шешімсіз.

    Жиі қателер

    • Жай модуль бойынша $x^2\equiv a$-ның түбірі әрдайым бар → тек $\frac{p-1}2$ қалдық үшін
      Неге қате: $x^2\equiv3\pmod7$ шешімсіз.
    • $d$ дәрежелі көпмүшенің кез келген модуль бойынша $\le d$ түбірі → тек жай модуль
      Неге қате: $t^2\equiv1\pmod8$ - 4 түбір.
    • Екі бейқалдықтың көбейтіндісі - бейқалдық → қалдық
      Неге қате: $(-1)(-1)=1$; $3\cdot5=15\equiv1\pmod7$.
    • $-1$ әрдайым квадрат емес → $p\equiv1\pmod4$ болса - квадрат
      Неге қате: $5^2\equiv-1\pmod{13}$.
    • Якоби символы $1$ - квадрат → құрама $n$-де қажетті ғана
      Неге қате: $\left(\frac2{15}\right)=1$.
    • Өзарлық заңында таңба әрдайым өзгереді → тек $p\equiv q\equiv3\pmod4$
      Неге қате: $\left(\frac{17}{31}\right)=\left(\frac{31}{17}\right)$.

    Визуализация

    Бақылаңыз: $n=1,\dots,p-1$ үшін сатылар $n=\frac p2$ түзуіне қатысты симметриялы: $n^2\equiv(p-n)^2$. Сондықтан әр қалдық екі рет кездеседі, ал әртүрлі мәндер саны $\frac{p-1}2$. $p$-ны жай сандарға ($7$, $11$, $13$, $19$) қойып, қалдықтар тізімін оқыңыз. $p=9$ немесе $15$ (құрама) қойсаңыз, мәндер саны басқаша болады.

    Бақылаңыз: Жай $p$ үшін $a=1,\dots,p-1$ мәндерінде график тек екі деңгейде: $1$ (квадраттық қалдық) немесе $p-1\equiv-1$ (бейқалдық), және әр деңгейде дәл $\frac{p-1}2$ саты. $p=7$: $a=1,2,4$ - $1$ деңгейінде, $a=3,5,6$ - $6$ деңгейінде. $p=9$ (құрама) - басқа мәндер де шығады.

    Қолданыс және мини-жоба

    Қолданыс. Модуль бойынша квадрат түбір эллипстік қисық криптографиясында нүктені сығылған түрден қалпына келтіруде қолданылады ($y^2=x^3+ax+b$ бойынша $y$ табу). Рабин шифры $n=pq$ бойынша квадрат түбір алудың қиындығына сүйенеді - бұл $n$-ді факторлаумен тең күшті. Соловей-Штрассен жайлық тесті Эйлер критерийін тексереді.

    Мини-жоба: «Квадраттық өзарлық заңын тексеру». Лежандр символын Эйлер критерийімен есептейміз, $200$-ге дейінгі барлық тақ жай жұптар үшін өзарлық заңын тексереміз, $p\equiv3\pmod4$ үшін түбір формуласын тексереміз және $4k+1$, $4k+3$ түріндегі жай сандарды санаймыз.

    def primes_upto(n):
    sieve = [True] * (n + 1)
    sieve[0] = sieve[1] = False
    for i in range(2, int(n ** 0.5) + 1):
        if sieve[i]:
            sieve[i * i::i] = [False] * len(sieve[i * i::i])
    return [i for i in range(n + 1) if sieve[i]]

def legendre(a, p):
    r = pow(a, (p - 1) // 2, p)
    return -1 if r == p - 1 else r

print("p = 11 қалдықтары:", sorted({x * x % 11 for x in range(1, 11)}))
print("(17/31) =", legendre(17, 31), " (3/7) =", legendre(3, 7))

odd = [p for p in primes_upto(200) if p > 2]
checked, bad = 0, 0
for p in odd:
    for q in odd:
        if p < q:
            checked += 1
            sign = (-1) ** (((p - 1) // 2) * ((q - 1) // 2))
            if legendre(p, q) * legendre(q, p) != sign:
                bad += 1
print("өзарлық заңы:", checked, "жұп, бұзылу:", bad)
print("(2/p) формуласы:", all(legendre(2, p) == (-1) ** ((p * p - 1) // 8) for p in odd))

ok = 0
for p in odd:
    if p % 4 == 3:
        for a in range(1, p):
            if legendre(a, p) == 1:
                x = pow(a, (p + 1) // 4, p)
                ok += (x * x % p == a)
print("p ≡ 3 (mod 4) түбірлері дұрыс:", ok)

P = primes_upto(100000)
print("4k+1:", sum(1 for p in P if p % 4 == 1), " 4k+3:", sum(1 for p in P if p % 4 == 3))
