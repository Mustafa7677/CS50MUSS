    Теңдеулердің түбірін табу

    $x^3-x-2=0$ не $x=\cos x$ сияқты теңдеулердің түбірін формуламен жазу мүмкін емес (не өте қиын), бірақ оны кез келген дәлдікпен сандық түрде табуға болады. Бұл сабақта төрт негізгі әдісті - кесіндіні екіге бөлу, қарапайым итерация (қозғалмайтын нүкте), Ньютон әдісі және хордалар (секанттар) әдісін - құрамыз, олардың жинақтылық шарттарын және жылдамдығын (сызықтық, квадраттық) дәлелдейміз, әдістер қашан істен шығатынын қарсы мысалдармен көрсетеміз.

    Курс туралы

    Бұл сабақтың мазмұны үшін жауапкершілікті курс авторы Sagid Mustafa өзіне алады. Қате немесе түсініксіз жер тапсаңыз, хабарлаңыз. Бұл курс ресми емтихан не куәлік баламасы емес.

    Бір сөйлеммен

    Формуласы жоқ теңдеудің түбірін қадамдап жақындап табамыз: екіге бөлу баяу, бірақ әрдайым жұмыс істейді; Ньютон әдісі өте жылдам (әр қадамда дұрыс цифрлар екі еселенеді), бірақ жақсы бастама керек.

    Сабақ мақсаттары

    Сабақ соңында сіз мыналарды істей аласыз:

    • аралық мән теоремасы бойынша түбірді оқшаулау және екіге бөлу әдісінің қадам санын алдын ала бағалау;
    • қарапайым итерацияның жинақталу шартын $|g'(x)|\le q<1$ тексеру және қатені бағалау;
    • Ньютон формуласын $x_{n+1}=x_n-\frac{f(x_n)}{f'(x_n)}$ қорытып, оның квадраттық жинақталу шарттарын атау;
    • Ньютон әдісі істен шығатын жағдайларды (туынды нөлге жақын, нашар бастапқы нүкте, цикл) тану;
    • хордалар әдісін туындысыз қолдану;
    • жинақталу ретін (сызықтық, квадраттық) ажырату және тоқтату шартын дұрыс таңдау.

    Қысқаша еске салу

    Аралық мән (Больцано–Коши) теоремасы: $f$ $[a,b]$-да үзіліссіз және $f(a)f(b)<0$ болса, $(a,b)$-да түбір бар. Туынды және жанама теңдеуі $y=f(x_0)+f'(x_0)(x-x_0)$. Лагранж теоремасы: $f(x)-f(y)=f'(\xi)(x-y)$. Тейлор формуласы қалдықпен: $f(x)=f(a)+f'(a)(x-a)+\frac{f''(\xi)}{2}(x-a)^2$ ($f\in C^2$). Геометриялық прогрессия: $q^n\to0$, $|q|<1$.

    Алдымен оқыңыз

    • Differential Calculus · 7-сабақ: Орта мән теоремалары және Лопиталь ережесі

    Бұл сабақтар таныс болса, бірден бастай беріңіз. Толық реттілік: оқу жолы.

    Алдымен қолмен: √2-ні Ньютонмен

    Формулаға дейін нақты сандармен ойнап көрейік. Әр қадамды өзіңіз де қағазда қайталаңыз.

    $f(x)=x^2-2$, $x_0=1$. Ньютон әдісі: $x_{n+1}=x_n-\frac{x_n^2-2}{2x_n}=\frac{x_n}2+\frac1{x_n}$. Үш қадам жасаңыз.

    1. $x_1=\frac12+1=1{,}5$.
    2. $x_2=0{,}75+\frac1{1{,}5}=1{,}41\overline6$.
    3. $x_3=0{,}708\overline3+\frac1{1{,}41\overline6}\approx1{,}4142157$.
    4. $\sqrt2=1{,}4142136$: қате $\approx2\cdot10^{-6}$. Дұрыс цифрлар саны: $1\to3\to6$ - әр қадамда шамамен екі еселенеді.

    Байқадыңыз ба? Ньютон әдісі қисықты жанамамен алмастырып, жанаманың нөлін келесі жуықтау етеді. Түбірге жақын болса, жинақталу квадраттық.

    Интуиция

    Бір нөмірді ойладым, 1-ден 1000-ға дейін, «үлкен/кіші» деп жауап берем. Әр сұрақпен аралықты екіге бөлесіз: 10 сұрақта табасыз ($2^{10}=1024$). Бұл - екіге бөлу: баяу, бірақ мүлтіксіз сенімді. Тек $f$ үзіліссіз және кесіндінің ұштарында таңбасы әртүрлі болса жеткілікті.

    Калькуляторға кез келген санды теріп, cos батырмасын қайта-қайта басыңыз. Сан $0{,}739085\dots$-ке жақындайды - бұл $x=\cos x$ теңдеуінің түбірі. Бұл - қарапайым итерация: $x_{n+1}=g(x_n)$. Ол $g$ «қысатын» болғанда ($|g'|<1$) жұмыс істейді, әр қадамда қате шамамен тұрақты есе азаяды.

    Ньютон әдісі - ең жылдам. Қисыққа нүктеде жанама жүргізіп, оның $Ox$ осімен қиылысуын келесі жуықтау етеміз. Түбірге жақын болса, әр қадамда дұрыс цифрлар саны шамамен екі еселенеді: 1, 2, 4, 8, 16 цифр. $\sqrt2$-ні 4 қадамда машиналық дәлдікпен табады. Бірақ жанама жатық болса, ол «ұшып кетеді».

    Тәжірибедегі ереже: сенімділік үшін екіге бөлумен түбірдің маңын табыңыз, сосын Ньютонмен жылдам «жылтыратыңыз». Көптеген стандарт кітапханалар (мысалы, Брент әдісі) дәл осылай жасайды.

    Өмірден ұқсастық · ойын: санды табу

    Екіге бөлу - «$1$-ден $100$-ге дейінгі санды тап, мен «үлкен/кіші» деймін» ойыны: әр сұрақ аралықты екі есе қысқартады. Баяу, бірақ $7$ сұрақта міндетті табасыз.

    Өмірден ұқсастық · таудан түсу

    Ньютон әдісі - тұманда тау беткейінде тұрып, аяқ астындағы еңіс бойынша жер деңгейіне қай жерде жететініңізді болжау. Беткей тегіс болса - тез жетесіз; жар болса - алысқа «лақтырылуыңыз» мүмкін.

    Белгілерді оқу

    Жоғары математиканың қиындығының жартысы - белгілерде. Теорияға дейін әр белгіні дауыстап оқып, мағынасын біліп алайық:

    БелгіҚалай оқыладыНені білдіреді
    $x_n\to r$итерациялар тізбегітүбірге жақындайтын жуықтаулар
    $e_n=|x_n-r|$қате$n$-ші қадамдағы ауытқу
    $e_{n+1}\approx Ce_n^p$жинақталу реті $p$$p=1$ - сызықтық, $p=2$ - квадраттық

    Анықтамалар мен теоремалар

    Анықтама 2.1 · Түбір және жинақталу реті

    $f(r)=0$ болса, $r$ - түбір (root). $x_n\to r$ тізбегінің жинақталу реті (order of convergence) $p\ge1$, егер $e_n=|x_n-r|$ үшін $\lim\frac{e_{n+1}}{e_n^p}=C$, $0<C<\infty$ ($p=1$ болса, қосымша $C<1$ талап етіледі). $p=1$ - сызықтық, $p=2$ - квадраттық.

    Қарапайым тілмен: Жинақталу реті - әр қадамда қате қаншалықты тез кемитіні: сызықтық - бірдей есе, квадраттық - квадраты бойынша.

    Теорема 2.1 · Екіге бөлу әдісі

    $f\in C[a,b]$, $f(a)f(b)<0$. $c_n$ - $n$-қадамдағы кесіндінің ортасы болсын. Онда $(a,b)$-да түбір $r$ бар және $|c_n-r|\le\frac{b-a}{2^{n}}$ ($c_1=\frac{a+b}2$). Дәлдік $\varepsilon$ үшін $n\ge\log_2\frac{b-a}{\varepsilon}$ қадам жеткілікті.

    Қарапайым тілмен: Таңбасы ауысатын кесіндіні екіге бөле берсек, $n$ қадамнан кейін қате $\frac{b-a}{2^{n+1}}$-ден аспайды.

    Негіздеме. 1-қорыту.

    Анықтама 2.2 · Қарапайым итерация

    $f(x)=0$ теңдеуін $x=g(x)$ түріне келтіріп, $x_{n+1}=g(x_n)$ тізбегін құрамыз. $g(r)=r$ болса, $r$ - $g$-ның қозғалмайтын нүктесі (fixed point).

    Қарапайым тілмен: Теңдеуді $x=g(x)$ түріне келтіріп, $g$-ны қайта-қайта қолданамыз.

    Теорема 2.2 · Қозғалмайтын нүкте теоремасы

    $g:[a,b]\to[a,b]$ (кесіндіні өзіне бейнелейді), дифференциалданады және барлық $x\in[a,b]$ үшін $|g'(x)|\le q<1$. Онда $[a,b]$-да жалғыз қозғалмайтын нүкте $r$ бар, кез келген $x_0\in[a,b]$ үшін $x_n\to r$, және $|x_n-r|\le q^n|x_0-r|$, сондай-ақ $|x_n-r|\le\frac{q}{1-q}|x_n-x_{n-1}|$.

    Қарапайым тілмен: $g$ кесіндіні өзіне жіберсе және туындысы $1$-ден кіші болса, қозғалмайтын нүкте жалғыз және итерация оған жинақталады.

    Негіздеме. 2-қорыту.

    Анықтама 2.3 · Ньютон әдісі

    Ньютон әдісі (Newton's method): $x_{n+1}=x_n-\dfrac{f(x_n)}{f'(x_n)}$ ($f'(x_n)\ne0$). Геометриялық мағынасы: $x_{n+1}$ - $(x_n,f(x_n))$ нүктесіндегі жанаманың $Ox$-пен қиылысуы.

    Қарапайым тілмен: Әр қадамда функцияны жанамамен алмастырып, жанаманың нөлін келесі жуықтау етеміз.

    Теорема 2.3 · Ньютон әдісінің жергілікті квадраттық жинақталуы

    $f\in C^2$ түбір $r$ маңайында, $f(r)=0$ және $f'(r)\ne0$ болсын. Онда $r$-дің жеткілікті кіші маңайынан алынған кез келген $x_0$ үшін $x_n\to r$ және $$x_{n+1}-r=\frac{f''(\xi_n)}{2f'(x_n)}(x_n-r)^2$$ қандай да бір $\xi_n$ үшін (ол $x_n$ мен $r$ арасында); демек $e_{n+1}\le Me_n^2$ - квадраттық жинақталу.

    Қарапайым тілмен: Түбірге жеткілікті жақын бастасақ және туынды нөл болмаса, Ньютон әдісінің қатесі әр қадамда квадраттайды.

    Негіздеме. 3-қорыту. «Жеткілікті кіші маңай» шарты маңызды: жаһандық жинақталуға кепілдік жоқ.

    Анықтама 2.4 · Хордалар (секанттар) әдісі

    Туындыны ақырлы айырмамен ауыстырамыз: $x_{n+1}=x_n-f(x_n)\dfrac{x_n-x_{n-1}}{f(x_n)-f(x_{n-1})}$. Екі бастапқы нүкте керек. Ньютон шарттары орындалса, жергілікті жинақталу реті $p=\frac{1+\sqrt5}{2}\approx1{,}618$ (бұл бағаны дәлелсіз келтіреміз).

    Қарапайым тілмен: Туындыны соңғы екі нүктенің қиюшысымен алмастырамыз - туынды есептеудің қажеті жоқ.

    Формула 2.1 · Екіге бөлу қадамы
    $$n\ \ge\ \log_2\frac{b-a}{\varepsilon}$$

    Шарты: $f$ үзіліссіз, $f(a)f(b)<0$. Әр қадамда бір $f$ есептеуі.

    Формула 2.2 · Ньютон формуласы
    $$x_{n+1}=x_n-\frac{f(x_n)}{f'(x_n)}$$

    Шарттары (квадраттық жинақталу үшін): $f\in C^2$, $f'(r)\ne0$, $x_0$ түбірге жеткілікті жақын. Мысалы $\sqrt a$: $x_{n+1}=\frac12\left(x_n+\frac{a}{x_n}\right)$.

    Формула 2.3 · Итерация қатесінің бағасы
    $$|x_n-r|\le\frac{q}{1-q}\,|x_n-x_{n-1}|$$

    $|g'|\le q<1$ болса. Тоқтату шарты: көршілес жуықтаулардың айырмасы, $q$ 1-ге жақын болса, нақты қатені кем бағалайды.

    Есте сақта

    Әдістерді салыстыру: екіге бөлу - әрдайым жинақталады, сызықтық ($q=\frac12$), туынды керек емес; итерация - $|g'|<1$ болса сызықтық; Ньютон - түбірге жақын болса квадраттық, $f'$ керек; хорда - $\approx1{,}618$ ретті, туындысыз. Тоқтату: $|x_{n+1}-x_n|<\varepsilon$ және $|f(x_{n+1})|$ кіші, сондай-ақ қадам санына шек.

    Назар аудар

    Ньютон әдісі істен шығуы мүмкін: (1) $f'(x_n)\approx0$ - жанама жатық, келесі нүкте өте алысқа кетеді; (2) цикл: $f(x)=x^3-2x+2$, $x_0=0$ үшін $x_1=1$, $x_2=0$, ... шексіз тербеледі; (3) еселі түбірде ($f'(r)=0$) жинақталу тек сызықтық. Сондай-ақ $f(a)f(b)<0$ шарты орындалмаса, екіге бөлу түбірді «көрмей» қалуы мүмкін (мысалы, $x^2$ - түбір бар, бірақ таңба өзгермейді).

    Тоқта, ойлан

    Әрі қарай жүрмес бұрын, өзіңізді тексеріңіз: алдымен жауапты ойланыңыз, сосын ашыңыз.

    1. Екіге бөлу әдісінде $[0;1]$-ден бастап $10$ қадамнан кейінгі қатенің шегі?

    $\frac1{2^{11}}\approx0{,}0005$.

    2. Ньютон әдісі $f'(x_n)=0$ болса не болады?

    Жанама көлденең - қадам анықталмайды (нөлге бөлу).

    3. $x=\cos x$ итерациясы $x_{n+1}=\cos x_n$ жинақтала ма?

    Иә: түбір маңында $|g'|=|\sin x|\approx0{,}67<1$.

    4. Квадраттық жинақталуда қате $10^{-3}$ болса, келесі қадамда шамамен?

    $10^{-6}$ ретімен.

    Қорытып шығару

    Қорытып шығару 1: екіге бөлу әдісінің қатесі

    Мақсат: $|c_n-r|\le\frac{b-a}{2^n}$ екенін көрсету.

    Идея: Әр қадамда түбірі бар кесінді екі есе қысқарады, ал түбір мен ортаның қашықтығы кесінді ұзындығының жартысынан аспайды.

    1. Аралық мән теоремасы бойынша $[a,b]$-да түбір бар. Ортасы $c=\frac{a+b}2$. $f(c)=0$ болса - дайын; әйтпесе $f(a)f(c)<0$ не $f(c)f(b)<0$ - жаңа кесінді, онда да түбір бар.
    2. Әр қадамда кесінді ұзындығы екі есе кемиді: $n$ рет бөлгеннен кейінгі кесінді $[a_n,b_n]$ ұзындығы $\frac{b-a}{2^n}$ және ол түбір $r$-ді қамтиды.
    3. $c_n$ - $n$-қадамда таңдалған орта, ол $(n-1)$-кесіндінің ортасы, ұзындығы $\frac{b-a}{2^{n-1}}$; демек $|c_n-r|\le\frac12\cdot\frac{b-a}{2^{n-1}}=\frac{b-a}{2^n}$.
    4. $\frac{b-a}{2^n}\le\varepsilon\iff2^n\ge\frac{b-a}{\varepsilon}\iff n\ge\log_2\frac{b-a}{\varepsilon}$.
    5. Мысал: $[1,2]$, $\varepsilon=10^{-6}$: $n\ge\log_210^6\approx19{,}93$, яғни 20 қадам.

    ∎

    Қорытып шығару 2: қозғалмайтын нүкте теоремасы

    Мақсат: $|g'|\le q<1$ болса итерацияның жинақталуын және қате бағаларын дәлелдеу.

    Идея: Бар болуы - аралық мән теоремасы; жалғыздығы және жинақталуы - Лагранж теоремасы бойынша қашықтықтар әр қадамда $q$ есе қысқарады.

    1. Бар болуы. $h(x)=g(x)-x$ үзіліссіз; $g(a)\ge a$, $g(b)\le b$ (себебі $g$ мәндері $[a,b]$-да), сондықтан $h(a)\ge0\ge h(b)$ - аралық мән бойынша $h(r)=0$.
    2. Жалғыздығы. $r_1\ne r_2$ екі нүкте болса, Лагранж: $|r_1-r_2|=|g(r_1)-g(r_2)|=|g'(\xi)||r_1-r_2|\le q|r_1-r_2|<|r_1-r_2|$ - қайшылық.
    3. Жинақталу. $x_n\in[a,b]$ (индукция). $|x_{n+1}-r|=|g(x_n)-g(r)|=|g'(\xi_n)||x_n-r|\le q|x_n-r|$, демек $|x_n-r|\le q^n|x_0-r|\to0$.
    4. Апостериорлық баға. $|x_{n-1}-r|\le|x_{n-1}-x_n|+|x_n-r|\le|x_{n-1}-x_n|+q|x_{n-1}-r|$, яғни $|x_{n-1}-r|\le\frac{|x_n-x_{n-1}|}{1-q}$.
    5. Сонда $|x_n-r|\le q|x_{n-1}-r|\le\frac{q}{1-q}|x_n-x_{n-1}|$. ∎

    ∎

    Қорытып шығару 3: Ньютон әдісінің квадраттық қатесі

    Мақсат: Теорема 2.3-тегі қате формуласын қорыту.

    Идея: Тейлор формуласын $x_n$ нүктесінде жазып, $r$-ді қоямыз; Ньютон қадамын шегерсек, тек квадраттық мүше қалады.

    1. Тейлор формуласы $x_n$ нүктесінде ($f\in C^2$): $0=f(r)=f(x_n)+f'(x_n)(r-x_n)+\frac{f''(\xi_n)}{2}(r-x_n)^2$, $\xi_n$ - $x_n$ мен $r$ арасында.
    2. $f'(x_n)\ne0$-ге бөлеміз: $\frac{f(x_n)}{f'(x_n)}+r-x_n=-\frac{f''(\xi_n)}{2f'(x_n)}(r-x_n)^2$.
    3. Сол жақ: $r-\left(x_n-\frac{f(x_n)}{f'(x_n)}\right)=r-x_{n+1}$.
    4. Демек $x_{n+1}-r=\frac{f''(\xi_n)}{2f'(x_n)}(x_n-r)^2$.
    5. $r$ маңайындағы кесіндіде $|f''|\le M_2$, $|f'|\ge m_1>0$ ($f'(r)\ne0$ және үзіліссіз болғандықтан осындай маңай бар) болса, $e_{n+1}\le\frac{M_2}{2m_1}e_n^2=Me_n^2$.
    6. $Me_0<1$ болса (жеткілікті жақын бастау), $e_n\to0$ және квадраттық: $Me_n\le(Me_0)^{2^n}$.

    ∎

    Қадамдық шешілген мысалдар

    Мысал 1. Екіге бөлу

    $f(x)=x^3-x-2$ түбірін $[1;2]$ кесіндісінде екіге бөлумен табыңыз (5 қадам).

    1. 1-қадам. $f(1)=-2$, $f(2)=4$ - таңбалары әртүрлі.
    2. 2-қадам. $c_1=1{,}5$: $f=-0{,}125<0$ → $[1{,}5;2]$. $c_2=1{,}75$: $f\approx1{,}61$ → $[1{,}5;1{,}75]$.
    3. 3-қадам. $c_3=1{,}625$: $f\approx0{,}67$ → $[1{,}5;1{,}625]$. $c_4=1{,}5625$: $f\approx0{,}25$ → $[1{,}5;1{,}5625]$.
    4. 4-қадам. $c_5=1{,}53125$: $f\approx0{,}059$ → $[1{,}5;1{,}53125]$. Қате бағасы $\frac{1}{2^5}\approx0{,}031$.
    5. 5-қадам. Шын түбір $r\approx1{,}52138$; $|c_5-r|\approx0{,}0099$ ✓.

    Жауабы: $r\approx1{,}52$; 20 қадам $10^{-6}$ дәлдік береді.

    Мысал 2. Ньютон: сол теңдеу

    $f(x)=x^3-x-2$, $x_0=1{,}5$. Ньютон әдісімен 3 қадам.

    1. 1-қадам. $f'(x)=3x^2-1$.
    2. 2-қадам. $x_1=1{,}5-\frac{-0{,}125}{5{,}75}\approx1{,}521739$.
    3. 3-қадам. $x_2\approx1{,}5213798$, $x_3\approx1{,}52137970680457$.
    4. 4-қадам. Қателер: $\approx3{,}6\cdot10^{-4}$, $10^{-7}$, $10^{-14}$ - әр қадамда цифрлар екі еселенді.

    Жауабы: $r\approx1{,}5213797068$.

    Мысал 3. Квадрат түбір

    $\sqrt2$-ні Ньютон әдісімен $x_0=1$-ден табыңыз.

    1. 1-қадам. $f(x)=x^2-2$: $x_{n+1}=x_n-\frac{x_n^2-2}{2x_n}=\frac12\left(x_n+\frac2{x_n}\right)$.
    2. 2-қадам. $x_1=1{,}5$; $x_2=\frac12(1{,}5+1{,}3333)=1{,}416667$.
    3. 3-қадам. $x_3\approx1{,}4142157$; $x_4\approx1{,}41421356237469$.
    4. 4-қадам. $\sqrt2=1{,}41421356237310$: $x_4$-тің қатесі $\approx1{,}6\cdot10^{-12}$. Бұл әдісті ежелгі Вавилон есептеушілері де қолданған.

    Жауабы: 4 қадамда 12 цифр.

    Мысал 4. Қарапайым итерация

    $x=\cos x$ теңдеуі. $[0{,}5;1]$ кесіндісінде итерация жинақтала ма? 10 қадамнан кейінгі қатені бағалаңыз.

    1. 1-қадам. $g(x)=\cos x$ кемімелі, $g(0{,}5)\approx0{,}878$, $g(1)\approx0{,}540$ - мәндер $[0{,}5;1]$-де ✓.
    2. 2-қадам. $|g'(x)|=|\sin x|\le\sin1\approx0{,}842=q<1$ ✓ - теорема шарттары орындалды.
    3. 3-қадам. $|x_{10}-r|\le q^{10}|x_0-r|\le0{,}842^{10}\cdot0{,}5\approx0{,}09$ (априорлық, өрескел).
    4. 4-қадам. Шын жинақталу жылдамырақ: түбір маңында $|g'(r)|=\sin0{,}739\approx0{,}674$. $r\approx0{,}739085$.

    Жауабы: Жинақталады; $r\approx0{,}739085$.

    Жиі қателер

    • $f(a)f(b)>0$ болса, түбір жоқ → түбір болуы мүмкін (жұп сан)
      Неге қате: $x^2-0{,}01$ $[-1;1]$-де: $f(\pm1)>0$, бірақ екі түбір бар.
    • Ньютон әдісі әрдайым жинақталады → тек түбірге жеткілікті жақын бастаса
      Неге қате: $x^3-2x+2$, $x_0=0$: $0\to1\to0\to\dots$ цикл.
    • $x=g(x)$ итерациясы кез келген $g$-мен жұмыс істейді → $|g'|<1$ шарты
      Неге қате: $x^2=2$ үшін $g(x)=\frac2x$: $|g'(\sqrt2)|=1$, тізбек $1,2,1,2,\dots$ тербеледі.
    • Тоқтату тек $|f(x_n)|<\varepsilon$ бойынша → $|x_{n+1}-x_n|$ және $|f|$ екеуі де
      Неге қате: жатық функцияда $|f|$ кіші, бірақ $x$ түбірден алыс болуы мүмкін.
    • Еселі түбірде де Ньютон квадраттық → $f'(r)=0$ болса - тек сызықтық
      Неге қате: $f=x^2$: $x_{n+1}=\frac{x_n}{2}$ - әр қадамда қате екі есе кемиді.
    • Екіге бөлудің қадам санын $\frac{b-a}{\varepsilon}$ деп есептеу → $\log_2\frac{b-a}{\varepsilon}$
      Неге қате: кесінді экспоненциалды тарылады.

    Визуализация

    Бақылаңыз: Жанама $(x_0,f(x_0))$ нүктесінен жүргізілген; оның $Ox$-пен қиылысуы - келесі жуықтау $x_1$. Қиюшы $h\to0$ кезінде жанамаға айналады - хордалар әдісі осы қиюшыны қолданады. $x_0$-ді өзгертіп, жанама түбірге қаншалықты жақын «түсетінін» бақылаңыз.

    Бақылаңыз: Қиылысу нүктесі - қозғалмайтын нүкте $r\approx0{,}739$. Онда $y=\cos x$ қисығының көлбеулігі $|{-\sin r}|\approx0{,}67<1$ - «өрмекші торы» ішке қарай бұралады. Жасыл қисық $g(x)=\frac{x^2+1}{2}$ қозғалмайтын нүктесі $x=1$-де $g'(1)=1$: шекаралық жағдай, жинақталу өте баяу.

    Қолданыс және мини-жоба

    Қолданыс. Түбір іздеу - калькулятордағы $\sqrt{\ }$, $\ln$; оптимизация ($f'(x)=0$ теңдеуі); қаржыдағы ішкі табыс нормасы (IRR); физикадағы тепе-теңдік нүктелері; компьютер графикасындағы сәуленің бетпен қиылысуы. Python-да scipy.optimize.brentq гибрид әдісті қолданады.

    Мини-жоба: «Төрт әдіс жарысы». Бір теңдеуді төрт әдіспен шешіп, қадам санын және қатенің азаю жылдамдығын салыстырамыз.

    import math
f  = lambda x: x**3 - x - 2
df = lambda x: 3*x*x - 1
r = 1.5213797068045676

def bisection(a, b, eps=1e-12):
    n = 0
    while b - a > eps:
        m = (a + b) / 2; n += 1
        if f(a) * f(m) <= 0: b = m
        else: a = m
    return (a + b) / 2, n

def newton(x, eps=1e-14, maxit=50):
    for n in range(1, maxit + 1):
        x_new = x - f(x) / df(x)
        print(f"  N{n}: қате {abs(x_new - r):.2e}")
        if abs(x_new - x) < eps: return x_new, n
        x = x_new
    return x, maxit

def secant(x0, x1, eps=1e-14):
    n = 0
    while abs(x1 - x0) > eps:
        x0, x1 = x1, x1 - f(x1) * (x1 - x0) / (f(x1) - f(x0)); n += 1
    return x1, n

def fixed_point(g, x, eps=1e-12):
    n = 0
    while True:
        x_new = g(x); n += 1
        if abs(x_new - x) < eps: return x_new, n
        x = x_new

print("екіге бөлу:", bisection(1, 2))
print("Ньютон:", newton(1.5))
print("хорда:", secant(1, 2))
print("итерация x = (x+2)^(1/3):", fixed_point(lambda x: (x + 2) ** (1/3), 1.5))
