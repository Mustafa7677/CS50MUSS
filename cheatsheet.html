Барлық курс бір бетте

Бес курстың әр лекциясының ең маңызды ұғымдары мен синтаксисі. Емтиханға не тапсырмаға дайындалғанда қолданыңыз. Курсты таңдап, тек сол курсты басып шығаруға болады.

0-апта Scratch

  • Информатика - ақпаратты қалай беру және қалай өңдеу туралы ғылым, яғни есеп шығару.
  • Компьютерлер барлық ақпаратты (сан, әріп, түс, сурет, бейне, дыбыс) 0 мен 1 арқылы сақтайды. Бір цифр - бит, 8 бит - байт.
  • Екілік жүйеде орындар 1, 2, 4, 8, 16... Ондық жүйеде орындар 1, 10, 100...
  • ASCII әріптерді сандармен сәйкестендіреді (A = 65), ал Unicode барлық тілдер мен эмодзилерге көбірек бит береді.
  • Түстер RGB арқылы беріледі: 0–255 аралығындағы үш сан.
  • Алгоритм - қадамдық нұсқаулық. Бір есепті шешетін алгоритмдердің тиімділігі әртүрлі болады: n, n/2, log₂ n.
  • Бағдарламалаудың негізгі блоктары: функциялар, шарттар, логикалық өрнектер, циклдер, айнымалылар.
  • Функцияның шығысы жанама әсер не қайтарылатын мән болуы мүмкін.
  • Код тек дұрыс болуы жеткіліксіз, ол жақсы жобаланған болуы керек: қайталауды циклмен және өз функцияларыңызбен (абстракция) жойыңыз.

1-апта C тілі

  • Бастапқы кодты адам жазады. Компилятор оны компьютер түсінетін машиналық кодқа айналдырады: make hello, сосын ./hello.
  • Әр нұсқау ;-мен аяқталады. printf үшін stdio.h, ал CS50 функциялары үшін cs50.h қосылады.
  • Айнымалының типі болады: int, long, float, double, char, bool, string. Әрқайсысының printf үшін өз пішім коды бар.
  • = меншіктеу, ал == теңдікті салыстыру. || НЕМЕСЕ, && ЖӘНЕ.
  • Циклдер: while, for, do-while. break циклдан шығарады.
  • Айнымалы тек өзі жарияланған фигуралы жақшалардың ішінде ғана бар (көріну аймағы).
  • Өз функцияңыздың прототипін main-нің үстіне жазыңыз.
  • Компьютердің шектеулері: бүтін санның толып кетуі, кесу, жылжымалы нүкте дәлсіздігі.

2-апта Массивтер

  • Қателер синтаксистік (компиляцияланбайды) және логикалық (дұрыс жұмыс істемейді) болады. Құралдар: printf, debug50, резеңке үйрек.
  • «Компиляциялау» төрт кезеңнен тұрады: алдын ала өңдеу, компиляциялау (ассемблерге), ассемблерлеу (0 мен 1-ге), байланыстыру.
  • Массив - жадтағы қатар тұрған бір типті мәндер. Индекс 0-ден басталады. C-да массивтің ұзындығын функцияға бөлек беру керек.
  • Жол - \0 (NUL) таңбасымен аяқталатын char массиві. Сондықтан n таңбалы жол n+1 байт алады.
  • Пайдалы кітапханалар: string.h (strlen), ctype.h (isupper, islower, toupper, tolower, isalpha, isdigit).
  • int main(int argc, string argv[]): командалық жол аргументтері. argv[0] бағдарламаның аты.
  • main сәтті болса 0, қате болса басқа сан қайтарады. Оны echo $? арқылы көреміз.
  • Криптография: ашық мәтін + кілт → шифр → шифрланған мәтін.

3-апта Алгоритмдер

  • Компьютер массивтегі мәндерді бірден көрмейді, оларға бір-бірлеп қарайды (жабық есіктер).
  • Сызықтық іздеу O(n), екілік іздеу O(log n), бірақ деректер сұрыпталған болуы керек.
  • Big O жоғарғы шекара, Ω төменгі шекара, Θ екеуі бірдей болғанда. Тек ең басым мүше маңызды.
  • Жолдарды strcmp арқылы салыстырамыз, == арқылы емес.
  • typedef struct арқылы өз деректер типімізді жасаймыз. Өрістерге нүкте арқылы жүгінеміз.
  • Selection sort және bubble sort: O(n²). Merge sort: O(n log n), бірақ көбірек жад керек.
  • Рекурсия: функция өзін кішірек есеппен шақырады. Міндетті түрде базалық жағдай болуы керек.

4-апта Жад

  • Он алтылық жүйе: 0–9 және A–F. Бір цифр 4 бит, екі цифр 1 байт (FF = 255). Алдына 0x жазылады.
  • &x - x-тің мекенжайы. int *p - бүтін санның мекенжайын сақтайтын көрсеткіш. *p - сол мекенжайға бару (дереференс). Мекенжай %p арқылы шығарылады.
  • string = char *: жолдың бірінші таңбасының мекенжайы. s[i] = *(s + i).
  • Жолдарды == арқылы салыстырсақ, мекенжайлар салыстырылады. t = s мекенжайды ғана көшіреді.
  • malloc үймеден жад береді, free оны қайтарады. NULL-ды үнемі тексеріңіз. Valgrind ағып кеткен және жарамсыз жадты табады.
  • Аргументтер мән бойынша беріледі. Функция айнымалыны өзгертуі үшін оның мекенжайын беріңіз.
  • Жад: машиналық код, жаһандық айнымалылар, үйме (heap, malloc), стек (stack, функциялар).
  • Файлдар: fopen, fprintf, fread, fwrite, fclose.

6-апта Python

  • Python интерпретацияланады: python file.py. Жазу жылдамырақ, бірақ орындалуы әдетте C-дан баяуырақ.
  • Нүктелі үтір, фигуралы жақша, айнымалы типі жоқ. Шегініс міндетті. Түсініктеме #-пен басталады.
  • input әрқашан str қайтарады. Санға айналдыру үшін int() не float().
  • f-жолдар: f"hello, {name}". Атаулы параметрлер: print(..., end="").
  • if / elif / else; and, or, not; in.
  • for x in ..., range(n), while True + break (do-while жоқ). for-да else болуы мүмкін.
  • Функциялар: def. main()-ді өзіңіз шақырасыз: if __name__ == "__main__":.
  • Типтер: bool, int (толып кетпейді), float, str, list, tuple, dict, set, range.
  • Объектілердің әдістері бар: s.lower(), s.upper(), list.append().
  • Қателерді try / except арқылы өңдейміз.
  • Кітапханалар: import, from ... import ...; sys, csv; pip install.

7-апта SQL

  • Жалпақ файлды база (CSV) қарапайым, бірақ үлкен деректерге ыңғайсыз. Python-мен csv.reader, csv.DictReader, сөздіктер және sorted арқылы талдай аламыз.
  • Реляциялық база - кестелер, жолдар, бағандар және олардың арасындағы байланыстар. SQL декларативті тіл: не керек екенін айтамыз, қалай екенін емес.
  • CRUD: CREATE/INSERT, SELECT, UPDATE, DELETE/DROP.
  • WHERE, LIKE, GROUP BY, ORDER BY, LIMIT, AS; функциялар: COUNT, AVG, MAX, MIN, SUM, DISTINCT, LOWER, UPPER.
  • SQLite типтері: INTEGER, NUMERIC, REAL, TEXT, BLOB. Шектеулер: NOT NULL, UNIQUE.
  • Бастапқы кілт жолды анықтайды, сыртқы кілт басқа кестеге сілтейді. Байланыстар: бір-біріне, бір-көпке, көп-көпке.
  • Ішкі сұраулар (IN), JOIN ... ON ... және жасырын біріктіру.
  • Индекстер (B-ағаштар) іздеуді жылдамдатады, бірақ жад алады және жазуды баяулатады.
  • Python-да db.execute және ? орын толтырғыштары. Олар SQL инъекциясынан қорғайды.
  • Жарыс жағдайлары транзакциялармен шешіледі: BEGIN TRANSACTION, COMMIT, ROLLBACK.

Арнайы лекция Жасанды интеллект

  • Генеративті AI сурет, дыбыс, бейне, мәтін жасайды. Оны шындықтан ажырату барған сайын қиындайды.
  • Промпт-инжиниринг: жүйелік промпт AI-ға рөл мен шектеулер береді, қолданушы промпты - нақты сұрақ. CS50 үйрегі осылай жасалған.
  • AI-мен код жазу мүмкіндіктеріңізді күшейтеді, бірақ кодты түсіну, тексеру және түзету үшін өз біліміңіз керек.
  • Шешім ағаштары қарапайым ойындарды (Breakout) кодқа тура айналдырады.
  • Минимакс: X максимумды, O минимумды таңдайды. Бірақ ойын үлкен болса (шахмат, го), барлық мүмкіндікті сынау мүмкін емес.
  • Машиналық оқыту: компьютер деректерден үйренеді. Бекіту арқылы оқыту: марапат пен жаза. Зерттеу мен пайдалану: epsilon кездейсоқтығы.
  • Бақылаумен оқытуда адам деректерді белгілейді. Бұл масштабталмайды, сондықтан бақылаусыз оқыту керек.
  • Нейрондық желілер: нейрондар мен қырлардың графы. Параметрлер (мысалы, ax + by + c) деректерден есептеледі.
  • LLM / GPT: ендірулер, назар, ең ықтимал келесі сөз. Олар статистикалық, сондықтан галлюцинациялар болады.

8-апта HTML, CSS, JavaScript

  • Интернет - желілердің желісі. Маршрутизаторлар пакеттерді тасымалдайды.
  • IP әр құрылғыға мекенжай береді (IPv4 - 32 бит, IPv6 - 128 бит). TCP порттар (80, 443) арқылы қызметтерді ажыратады және реттік нөмірлер арқылы жеткізуге кепілдік береді.
  • DNS домен атауларын IP-ге аударады. DHCP құрылғыға IP, маршрутизатор және DNS мекенжайларын береді.
  • HTTP/HTTPS: GET, POST; күй кодтары 200, 301, 404, 500 және т.б. Құралдар: curl -I, әзірлеуші құралдары.
  • HTML: тегтер мен атрибуттар; p, h1–h6, ul/ol/li, table, img, video, a, form/input. Браузер одан DOM ағашын құрады.
  • URL параметрлері: ?key=value&key=value. Тұрақты өрнектер. Клиенттегі тексеруге сенуге болмайды.
  • CSS: қасиеттер; тип, класс (.), ID (#) селекторлары, псевдо-селекторлар (:hover); каскад; сыртқы .css файлы; Bootstrap сияқты фреймворктар.
  • JavaScript: C-ға ұқсас синтаксис; querySelector, addEventListener, оқиғалар, innerHTML, style, setInterval; DOM-ды өзгерту.

CS50 SQL · 0-апта Сұраулар

  • Кесте - жолдар (элементтер) мен бағандардан (қасиеттер) тұрады; деректер базасы төрт амалды қолдайды: жасау, оқу, жаңарту, жою.
  • SQL - деректер базасымен сөйлесетін тіл; SQLite - жеңіл, жиі қолданылатын жүйе.
  • SELECT ... FROM ... - бағандарды таңдау; * - бәрі; идентификаторлар қос тырнақшада, жолдар бір тырнақшада.
  • LIMIT - жол санын шектеу; WHERE - жолдарды шарт бойынша сүзу; =, !=, <>, NOT, AND, OR және жақшалар.
  • NULL - «мән жоқ»; тек IS NULL және IS NOT NULL арқылы тексеріледі.
  • LIKE - үлгі бойынша іздеу: % (кез келген саны) және _ (дәл бір таңба); кириллицада регистрге сезімтал.
  • Аралықтар: <, >, <=, >= және BETWEEN ... AND ... (шеттерін қоса).
  • ORDER BY (ASC әдепкі, DESC кему) және бірнеше бағанмен сұрыптау.
  • Жиынтық функциялар: COUNT, AVG, MIN, MAX, SUM, ROUND, AS және DISTINCT; COUNT("баған") NULL-ды санамайды.

CS50 SQL · 1-апта Байланыстар

  • Реляциялық дерекқорда бірнеше кесте бар және олар бір-біреуге, бір-көпке не көп-көпке байланыста болады.
  • ER диаграммасы мәндер мен олардың байланыстарын «қарғаның аяғы» белгілерімен көрсетеді: шеңбер - нөл, тік сызық - бір, аяқ - көп.
  • Бастапқы кілт жолды бірегей анықтайды; сыртқы кілт басқа кестенің бастапқы кілтіне сілтейді. Көп-көпке байланыс үшін аралық кесте керек.
  • Ішкі сұрау - сұраудың ішіндегі сұрау; бірнеше мән күтілсе = емес, IN қолданамыз.
  • JOIN кестелерді біріктіреді: әдепкі INNER JOIN тек сәйкес жолдарды қалдырады, LEFT/RIGHT/FULL JOIN сәйкес келмегендерді де сақтайды (бос орында NULL).
  • INTERSECT, UNION, EXCEPT нәтиже жиындарын қияды, біріктіреді, айырады.
  • GROUP BY жолдарды топтайды, HAVING топтарды сүзеді, COUNT пен AVG топ ішінде есептейді.

CS50 SQL · 3-апта Жазу

  • INSERT INTO ... VALUES ... кестеге жол қосады. Бағандар тізімі мен мәндер тізімі бір ретпен жүреді.
  • id бағанын жазбасаңыз, SQLite бастапқы кілтті өзі береді (ең үлкен мәнге бірді қосып). AUTOINCREMENT бұрын берілген нөмірді қайта бермейді.
  • Схемадағы NOT NULL, UNIQUE және басқа шектеулер дерекқорды дұрыс емес жолдардан қорғайды. Бірнеше жол қосқанда бірі бұзылса, бірде-бірі қосылмайды.
  • Бірнеше жолды үтірмен бөліп бір INSERT-пен қосуға болады. CSV-ді .import --csv --skip 1 арқылы импорттаймыз. id жоқ CSV үшін уақытша кесте қолданамыз: .import --csv файл temp, сосын INSERT ... SELECT және DROP TABLE.
  • CSV-дегі бос ұяшық кестеге бос мәтін ('') болып түседі, NULL емес. Оны UPDATE ... SET ... = NULL WHERE ... = '' арқылы түзетеміз.
  • DELETE FROM кесте WHERE ... жолдарды өшіреді; WHERE болмаса, барлығы өшеді.
  • Сыртқы кілт сілтеп тұрған жолды өшіру FOREIGN KEY constraint failed қатесін береді. ON DELETE әрекеттері: RESTRICT, NO ACTION, SET NULL, SET DEFAULT, CASCADE.
  • UPDATE кесте SET баған = мән WHERE ... бар деректі өзгертеді; мәнді ішкі сұраумен алуға болады.
  • Триггер (CREATE TRIGGER ... BEFORE/AFTER INSERT/UPDATE/DELETE ON ... BEGIN ... END) басқа оператордың әсерінен өздігінен орындалады; OLD бар жолға, NEW жаңа жолға сілтейді.
  • Жұмсақ жою деректі шынымен өшірмей, deleted бағанымен белгілейді. Бірақ деректі шын өшіруді талап ететін заңдарды ұмытпаңыз.

CS50 SQL · 4-апта Көріністер

  • көрініс - сұраумен анықталған виртуалды кесте: CREATE VIEW ... AS SELECT ...; ол деректі өзінде сақтамайды, әр сұрауда негізгі кестелерден алады;
  • жеңілдету: JOIN арқылы біріктірілген деректі көріністе сақтап, үш деңгейлі кірістірілген сұрауды бір қысқа SELECT-ке айналдыруға болады;
  • агрегаттау: GROUP BY + AVG сияқты есептеулерді көріністе сақтауға болады, жаңа дерек қосылса, көріністі қайта сұрау жеткілікті;
  • CREATE TEMPORARY VIEW - тек байланыс жалғасқанша өмір сүретін уақытша көрініс, ал CTE (WITH ... AS (...)) - бір ғана сұраудың ішіндегі көрініс;
  • бөлектеу: бір кестені қисынды бөліктерге (мысалы, жыл бойынша) бөлетін көріністер;
  • қорғау: көрініс бағандарды жасыра немесе анонимдей алады, бірақ SQLite-та қолжетімділікті басқару жоқ, сондықтан негізгі кесте ашық қалады;
  • көріністі жаңартуға болмайды, бірақ INSTEAD OF триггері арқылы көріністегі DELETE/INSERT әрекеттерін негізгі кестедегі UPDATE/INSERT әрекеттеріне айналдыруға болады, осылай жұмсақ жоюды іске асырамыз.

CS50 SQL · 5-апта Оңтайландыру

  • Индекс сұрауды жылдамдатады: EXPLAIN QUERY PLAN жоспарында SCAN (бәрін қарау) орнына SEARCH ... USING INDEX шығады. Индексті CREATE INDEX-пен құрып, DROP INDEX-пен жоямыз.
  • Бастапқы кілт бойынша индекс автоматты құрылады, ал қалған бағандар үшін оны өзіміз құрамыз.
  • Жабық индекс (covering index) сұрауға қажет барлық деректі индекстің өзінде сақтайды, сондықтан кестеге бару керек емес. Көп бағанды индексте іздейтін баған алда тұрады.
  • Индекс B-ағаш түрінде сақталады: тамыр бағыттайды, жапырақтарда реттелген мәндер жатыр.
  • Айырбастар: индекс орын алады және деректі қосуды баяулатады. Сондықтан әр бағанға индекс құрмаймыз.
  • Ішінара индекс кестенің тек бір бөлігін (мысалы, 2023 жылғы фильмдерді) қамтып, орынды үнемдейді.
  • DROP INDEX файлды кішірейтпейді: бос орын тек белгіленеді. Нағыз тазалау үшін VACUUM керек.
  • Транзакция (BEGIN TRANSACTION, COMMIT, ROLLBACK) бірнеше қадамды бөлінбейтін бірлікке біріктіреді. ACID: атомарлық, үйлесімділік, оқшаулау, беріктік.
  • Жарыс жағдайларын оқшаулау арқылы болдырмаймыз; SQLite-та мұны құлыптар (UNLOCKED, SHARED, EXCLUSIVE) қамтамасыз етеді.

CS50 AI · 0-апта Іздеу

  • Іздеу есебі: агент, күй, бастапқы күй, әрекеттер, ауысу моделі, күй кеңістігі, мақсатты тексеру, жол құны. Шешім - бастапқы күйден мақсатқа апаратын әрекеттер тізбегі, оңтайлысы - ең аз құнды шешім.
  • Түйін күй, ата-ана, әрекет және жол құнын сақтайды; шекара түйіндерді басқарады, қарап шыққан күйлер жиыны қайталануды болдырмайды.
  • DFS шекараны стек (LIFO) ретінде қолданады: жылдам болуы мүмкін, бірақ оңтайлы емес. BFS - кезек (FIFO): оңтайлы, бірақ баяуырақ.
  • Ашкөз іздеу эвристикалық h(n) (мысалы, Манхэттен қашықтығы) бойынша мақсатқа ең жақын түйінді алады. A* g(n) + h(n) қосындысын қолданады; h рұқсат етілген және келісімді болса, оңтайлы.
  • Қарсыластық іздеуде minimax: MAX ең жоғары, MIN ең төмен мәнді таңдайды; мәндерді рекурсия арқылы терминал күйлерден жоғары көтереді.
  • Альфа-бета кесу нәтижені өзгертпей, пайдасыз тармақтарды қияды. Тереңдігі шектелген minimax тереңдік шегінен кейін бағалау функциясын қолданады.

CS50 AI · 2-апта Белгісіздік

  • Ықтималдық: мүмкін әлемдер, аксиомалар (0 мен 1 аралығы, қосынды 1), шартсыз және шартты ықтималдық P(a | b) = P(a ∧ b) / P(b).
  • Кездейсоқ шамалар, ықтималдық үлестірімі, тәуелсіздік P(a ∧ b) = P(a) P(b).
  • Байес ережесі: P(b | a) = P(a | b) P(b) / P(a). Көрінетін салдардан белгісіз себепке өтуге мүмкіндік береді.
  • Бірлескен ықтималдық және нормалау (α).
  • Ережелер: терістеу, қосу-алып тастау, маргиналдау, шартқа келтіру.
  • Байес желілері: бағытталған граф, әр түйін P(X | Parents(X)) үлестіріміне ие.
  • Қорытынды шығару: сұраныс, дәлел, жасырын айнымалылар; санау арқылы нақты қорытынды (inference by enumeration).
  • Жуық қорытынды: семплдеу, қабылдамау семплдеуі, ықтималдықпен өлшеу.
  • Марков модельдері: Марков жорамалы, Марков тізбегі, өту моделі.
  • Жасырын Марков модельдері: жасырын күй мен бақылау, сенсор моделі, сенсор Марков жорамалы; сүзу, болжау, тегістеу және ең ықтимал түсіндірме.

CS50 AI · 4-апта Оқыту

  • Машиналық оқыту - компьютерге нұсқау емес, дерек беріп, заңдылықты өзі табуға үйрету.
  • Бақыланатын оқытуда кіріс-шығыс жұптары бар. Жіктеу дискретті шығыс (Rain/No Rain) береді, регрессия үздіксіз сан береді.
  • Ең жақын көрші жаңа нүктеге ең жақын бақылаудың мәнін береді; k ең жақын көрші k көршінің көпшілік дауысын алады.
  • Перцептрон түзу шешім шекарасын салмақтар арқылы үйренеді: wᵢ ← wᵢ + α(y - h(x))xᵢ. Қатты табалдырық 0/1 береді, жұмсақ (логистикалық) табалдырық сенімділікті білдіреді.
  • Тірек векторлар әдісі екі топтан ең алыс максималды қуысты шекараны таңдайды және сызықтық емес шекараны да құра алады.
  • Шығын функциялары болжамның қателігін өлшейді: 0-1 (жіктеу), L₁ және L₂ (үздіксіз мән; L₂ ауытқуларды қатты жазалайды).
  • Артық үйрену - оқыту деректеріне тым дәл бейімделу. Қарсы құрал: регуляризация cost(h) = loss(h) + λ·complexity(h), сонымен қатар ұстап қалу не k-бүктемелі кросс-валидациямен тексеру.
  • scikit-learn моделін (KNeighborsClassifier, SVC, Perceptron) алмастыру үшін бір жолды ауыстыру жеткілікті.
  • Күшейтілген оқыту: агент әрекет жасайды, орта жаңа күй мен сыйақы не жаза қайтарады. Ол Марков шешім процесі (күйлер, әрекеттер, ауысу моделі, сыйақы функциясы).
  • Q-оқыту Q(s, a) бағасын жаңартады; ε-ашкөз алгоритмі зерттеу мен пайдалануды теңестіреді. Күйлер көп болса, функцияны жуықтау қолданылады.
  • Бақылаусыз оқытуда белгілер жоқ. k-means кластерлеуі нүктелерді жақын орталыққа бөліп, орталықтарды топтың ортасына жылжытып, тепе-теңдікке дейін қайталайды.

  • Айналдыру: window.innerHeight, window.scrollY, document.body.offsetHeight шамалары арқылы беттің соңына жеткенімізді анықтаймыз: window.scrollY + window.innerHeight >= document.body.offsetHeight.
  • Шексіз айналдыру: төменге жеткенде fetch арқылы API-дан келесі жазбалар бөлігін жүктейміз.
  • CSS анимациясы: @keyframes (from/to не 0%...100%) және animation-name, animation-duration, animation-fill-mode, animation-iteration-count, animation-play-state қасиеттері.
  • JavaScript + анимация: style.animationPlayState арқылы анимацияны іске қосу/кідірту, animationend оқиғасымен анимациядан кейін элементті жою.
  • React декларативті: біз көріністі күйге сүйеніп сипаттаймыз, ал DOM-ды React жаңартады. Негізгі ұғымдар: компонент (функция), JSX, пропстар (props), күй (useState).
  • Күйді жаңарту: күйді тікелей өзгертпейміз, setState/setCount шақырамыз; объект күйде қалған өрістерді ...state арқылы сақтаймыз.

CS50 Web · 7-апта Тестілеу, CI/CD

  • assert өрнек False болса AssertionError көтереді: ең қарапайым тест;
  • тест арқылы әзірлеу: әр қатені түзеткенде оны ұстайтын тест қосып, тесттерді әр өзгерістен кейін іске қосу;
  • unittest: TestCase класы, test_ деп басталатын әдістер, assertTrue, assertFalse, assertEqual, құжаттама жолдары, ...F.F шығысы;
  • range(2, int(math.sqrt(n)) + 1): шекараға (off-by-one қатесіне) мұқият болу;
  • Django: TestCase, setUp, тестілеуге арналған бөлек дерекқор, python manage.py test;
  • Client арқылы беттердің жауап кодтарын (200, 404) және контекстті тексеру;
  • Selenium: веб-драйвер браузерді басқарып, пайдаланушының әрекетін модельдейді;
  • CI/CD: жиі біріктіру, әр біріктіруде автоматты тесттер, жиі шығарылым;
  • GitHub Actions: .github/workflows/ci.yml файлындағы YAML жұмыс процесі (name, on, jobs, runs-on, steps);
  • Docker: Dockerfile (FROM, COPY, WORKDIR, RUN, CMD), образ бен контейнер, виртуалды машинадан айырмашылығы;
  • Docker Compose: docker-compose.yml арқылы бірнеше контейнерді (db және web) бірге жүргізу.

CS50 Web · 8-апта Масштабтау, қауіпсіздік

  • сервер: өз ғимаратыңызда не бұлтта; тік (күштірек сервер) және көлденең (көбірек сервер) масштабтау;
  • жүктеме бөлгіш және оның әдістері: кездейсоқ, кезекпен, ең аз қосылым; сессия мәселесі: жабысқақ, дерекқордағы, клиент жағындағы;
  • автомасштабтау, жалғыз ақаулы нүкте және жүрек соғысы;
  • дерекқорды масштабтау: тік және көлденең бөлу; репликация (бір бастапқылы мен көп бастапқылы) және қақтығыстары;
  • кэштеу: Cache-Control, ETag, Django-ның кэш фреймворкі;
  • қауіпсіздік: коммитке құпия салмау, фишинг, HTTPS, құпия және ашық кілтті шифрлау;
  • парольдерді хэштеу (және тұз), ақпарат ағуы, SQL-инъекция және параметрленген сұраулар;
  • API қорғанысы: кілттер, сұрау жиілігін шектеу, аутентификация; кілттерді орта айнымалыларында сақтау;
  • XSS (қолданушы мәтінін экрандау) және CSRF (токен, POST).
