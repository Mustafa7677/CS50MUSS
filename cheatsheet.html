Барлық курс бір бетте

Тоғыз курстың әр лекциясының ең маңызды ұғымдары мен синтаксисі. Емтиханға не тапсырмаға дайындалғанда қолданыңыз. Курсты таңдап, тек сол курсты басып шығаруға болады.

0-апта Scratch

  • Информатика - ақпаратты қалай беру және қалай өңдеу туралы ғылым, яғни есеп шығару.
  • Компьютерлер барлық ақпаратты (сан, әріп, түс, сурет, бейне, дыбыс) 0 мен 1 арқылы сақтайды. Бір цифр - бит, 8 бит - байт.
  • Екілік жүйеде орындар 1, 2, 4, 8, 16... Ондық жүйеде орындар 1, 10, 100...
  • ASCII әріптерді сандармен сәйкестендіреді (A = 65), ал Unicode барлық тілдер мен эмодзилерге көбірек бит береді.
  • Түстер RGB арқылы беріледі: 0–255 аралығындағы үш сан.
  • Алгоритм - қадамдық нұсқаулық. Бір есепті шешетін алгоритмдердің тиімділігі әртүрлі болады: n, n/2, log₂ n.
  • Бағдарламалаудың негізгі блоктары: функциялар, шарттар, логикалық өрнектер, циклдер, айнымалылар.
  • Функцияның шығысы жанама әсер не қайтарылатын мән болуы мүмкін.
  • Код тек дұрыс болуы жеткіліксіз, ол жақсы жобаланған болуы керек: қайталауды циклмен және өз функцияларыңызбен (абстракция) жойыңыз.

1-апта C тілі

  • Бастапқы кодты адам жазады. Компилятор оны компьютер түсінетін машиналық кодқа айналдырады: make hello, сосын ./hello.
  • Әр нұсқау ;-мен аяқталады. printf үшін stdio.h, ал CS50 функциялары үшін cs50.h қосылады.
  • Айнымалының типі болады: int, long, float, double, char, bool, string. Әрқайсысының printf үшін өз пішім коды бар.
  • = меншіктеу, ал == теңдікті салыстыру. || НЕМЕСЕ, && ЖӘНЕ.
  • Циклдер: while, for, do-while. break циклдан шығарады.
  • Айнымалы тек өзі жарияланған фигуралы жақшалардың ішінде ғана бар (көріну аймағы).
  • Өз функцияңыздың прототипін main-нің үстіне жазыңыз.
  • Компьютердің шектеулері: бүтін санның толып кетуі, кесу, жылжымалы нүкте дәлсіздігі.

2-апта Массивтер

  • Қателер синтаксистік (компиляцияланбайды) және логикалық (дұрыс жұмыс істемейді) болады. Құралдар: printf, debug50, резеңке үйрек.
  • «Компиляциялау» төрт кезеңнен тұрады: алдын ала өңдеу, компиляциялау (ассемблерге), ассемблерлеу (0 мен 1-ге), байланыстыру.
  • Массив - жадтағы қатар тұрған бір типті мәндер. Индекс 0-ден басталады. C-да массивтің ұзындығын функцияға бөлек беру керек.
  • Жол - \0 (NUL) таңбасымен аяқталатын char массиві. Сондықтан n таңбалы жол n+1 байт алады.
  • Пайдалы кітапханалар: string.h (strlen), ctype.h (isupper, islower, toupper, tolower, isalpha, isdigit).
  • int main(int argc, string argv[]): командалық жол аргументтері. argv[0] бағдарламаның аты.
  • main сәтті болса 0, қате болса басқа сан қайтарады. Оны echo $? арқылы көреміз.
  • Криптография: ашық мәтін + кілт → шифр → шифрланған мәтін.

3-апта Алгоритмдер

  • Компьютер массивтегі мәндерді бірден көрмейді, оларға бір-бірлеп қарайды (жабық есіктер).
  • Сызықтық іздеу O(n), екілік іздеу O(log n), бірақ деректер сұрыпталған болуы керек.
  • Big O жоғарғы шекара, Ω төменгі шекара, Θ екеуі бірдей болғанда. Тек ең басым мүше маңызды.
  • Жолдарды strcmp арқылы салыстырамыз, == арқылы емес.
  • typedef struct арқылы өз деректер типімізді жасаймыз. Өрістерге нүкте арқылы жүгінеміз.
  • Selection sort және bubble sort: O(n²). Merge sort: O(n log n), бірақ көбірек жад керек.
  • Рекурсия: функция өзін кішірек есеппен шақырады. Міндетті түрде базалық жағдай болуы керек.

4-апта Жад

  • Он алтылық жүйе: 0–9 және A–F. Бір цифр 4 бит, екі цифр 1 байт (FF = 255). Алдына 0x жазылады.
  • &x - x-тің мекенжайы. int *p - бүтін санның мекенжайын сақтайтын көрсеткіш. *p - сол мекенжайға бару (дереференс). Мекенжай %p арқылы шығарылады.
  • string = char *: жолдың бірінші таңбасының мекенжайы. s[i] = *(s + i).
  • Жолдарды == арқылы салыстырсақ, мекенжайлар салыстырылады. t = s мекенжайды ғана көшіреді.
  • malloc үймеден жад береді, free оны қайтарады. NULL-ды үнемі тексеріңіз. Valgrind ағып кеткен және жарамсыз жадты табады.
  • Аргументтер мән бойынша беріледі. Функция айнымалыны өзгертуі үшін оның мекенжайын беріңіз.
  • Жад: машиналық код, жаһандық айнымалылар, үйме (heap, malloc), стек (stack, функциялар).
  • Файлдар: fopen, fprintf, fread, fwrite, fclose.

6-апта Python

  • Python интерпретацияланады: python file.py. Жазу жылдамырақ, бірақ орындалуы әдетте C-дан баяуырақ.
  • Нүктелі үтір, фигуралы жақша, айнымалы типі жоқ. Шегініс міндетті. Түсініктеме #-пен басталады.
  • input әрқашан str қайтарады. Санға айналдыру үшін int() не float().

  • Типтер: bool, int (толып кетпейді), float, str, list, tuple, dict, set, range.
  • Объектілердің әдістері бар: s.lower(), s.upper(), list.append().
  • Қателерді try / except арқылы өңдейміз.
  • Кітапханалар: import, from ... import ...; sys, csv; pip install.

7-апта SQL

  • Жалпақ файлды база (CSV) қарапайым, бірақ үлкен деректерге ыңғайсыз. Python-мен csv.reader, csv.DictReader, сөздіктер және sorted арқылы талдай аламыз.
  • Реляциялық база - кестелер, жолдар, бағандар және олардың арасындағы байланыстар. SQL декларативті тіл: не керек екенін айтамыз, қалай екенін емес.
  • CRUD: CREATE/INSERT, SELECT, UPDATE, DELETE/DROP.
  • WHERE, LIKE, GROUP BY, ORDER BY, LIMIT, AS; функциялар: COUNT, AVG, MAX, MIN, SUM, DISTINCT, LOWER, UPPER.
  • SQLite типтері: INTEGER, NUMERIC, REAL, TEXT, BLOB. Шектеулер: NOT NULL, UNIQUE.
  • Бастапқы кілт жолды анықтайды, сыртқы кілт басқа кестеге сілтейді. Байланыстар: бір-біріне, бір-көпке, көп-көпке.
  • Ішкі сұраулар (IN), JOIN ... ON ... және жасырын біріктіру.
  • Индекстер (B-ағаштар) іздеуді жылдамдатады, бірақ жад алады және жазуды баяулатады.
  • Python-да db.execute және ? орын толтырғыштары. Олар SQL инъекциясынан қорғайды.
  • Жарыс жағдайлары транзакциялармен шешіледі: BEGIN TRANSACTION, COMMIT, ROLLBACK.

  • IP әр құрылғыға мекенжай береді (IPv4 - 32 бит, IPv6 - 128 бит). TCP порттар (80, 443) арқылы қызметтерді ажыратады және реттік нөмірлер арқылы жеткізуге кепілдік береді.

CS50 AI · 4-апта Оқыту

  • Машиналық оқыту - компьютерге нұсқау емес, дерек беріп, заңдылықты өзі табуға үйрету.

  • Перцептрон түзу шешім шекарасын салмақтар арқылы үйренеді: wᵢ ← wᵢ + α(y - h(x))xᵢ. Қатты табалдырық 0/1 береді, жұмсақ (логистикалық) табалдырық сенімділікті білдіреді.
  • Тірек векторлар әдісі екі топтан ең алыс максималды қуысты шекараны таңдайды және сызықтық емес шекараны да құра алады.
  • Шығын функциялары болжамның қателігін өлшейді: 0-1 (жіктеу), L₁ және L₂ (үздіксіз мән; L₂ ауытқуларды қатты жазалайды).
  • Артық үйрену - оқыту деректеріне тым дәл бейімделу. Қарсы құрал: регуляризация cost(h) = loss(h) + λ·complexity(h), сонымен қатар ұстап қалу не k-бүктемелі кросс-валидациямен тексеру.
  • scikit-learn моделін (KNeighborsClassifier, SVC, Perceptron) алмастыру үшін бір жолды ауыстыру жеткілікті.
  • Күшейтілген оқыту: агент әрекет жасайды, орта жаңа күй мен сыйақы не жаза қайтарады. Ол Марков шешім процесі (күйлер, әрекеттер, ауысу моделі, сыйақы функциясы).

  • wish / if only: қазіргі арман - Past Simple, өткен өкініш - had + V3, біреудің әдеті - would.
