Алдын ала не білу керек?

CS50x не CS50P курсын өткен болсаңыз, оңай болады: Python мен SQL негіздері қажет. Жобалар компьютеріңізде орындалады, ал лекциядағы HTML/CSS/JS мысалдарын осы жерде бірден көруге болады. Сертификаты бөлек.
