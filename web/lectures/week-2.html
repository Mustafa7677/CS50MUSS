    ▶ Түпнұсқа бейнежазба мен материалдар (ағылшынша)
    Бұл апта не туралы

    Бұл лекция - Python-ға жылдам шолу: келесі аптада Python тілінде жазылған Django фреймворкімен веб-қосымшалар құрамыз, сондықтан тілдің негізін қазірден бекітіп аламыз. Python-ды бұрын көрген болсаңыз, бұл қайталау болады. Бұл тақырыпты толығырақ CS50P курсынан оқуға болады. Мысалдардың көбін бетте-ақ «▶ Іске қосу» батырмасымен орындап көре аласыз.

    Бұл бет сөзбе-сөз аударма емес. Лектор аудиторияда қалай түсіндірсе, біз де солай баяндаймыз: мағынасы мен кодтың бәрі түпнұсқадағыдай, тек әңгіме ана тілімізде жүреді.

    Кіріспе

    Өткен екі аптада біз не істедік? Алдымен HTML мен CSS арқылы қарапайым веб-беттер құруды үйрендік, сосын Git пен GitHub арқылы кодымыздағы өзгерістерді қадағалап, басқалармен бірге жұмыс істеуді меңгердік. Ал бүгін курста қолданатын екі негізгі бағдарламалау тілінің біріншісіне кірісеміз - Python.

    Python

    Python - өте қуатты, кең тараған тіл. Оның арқасында біз салыстырмалы түрде күрделі веб-қосымшаларды тез жасай аламыз. Бұл курста Python 3 қолданамыз, дегенмен кей жерлерде Python 2 әлі де кездеседі. Сондықтан интернеттен материал іздегенде нұсқасына мұқият болыңыз: екеуі бір-бірінен өзгеше.

    Бағдарламалау тілдерін үйренуді әдетте қайдан бастаймыз? Әрине, «Hello, world» бағдарламасынан. Python-да ол былай жазылады:

    print("Hello, world!")

    Бір ғана жол, ештеңе артық емес. Енді не болып жатқанын ашып көрейік. Python-ға кірістірілген print функциясы (function) бар. Ол жақшаның ішінде аргумент (argument) алады да, сол аргументті командалық жолға (экранға) шығарады.

    Бұл бағдарламаны өз компьютеріңізде қалай жазып, іске қосамыз? Алдымен осы жолды өзіңіз ұнататын мәтін редакторына жазып, файлды something.py деп сақтайсыз. Сосын терминалға барып, файлыңыз жатқан қалтаға өтіп, python something.py деп жазасыз. Жоғарыдағы бағдарламада терминалға «Hello, world!» деген сөздер шығады.

    Компьютеріңіздің баптауына қарай, python орнына python3 деп жазуға тура келуі мүмкін. Тіпті Python-ды алдымен жүктеп алу қажет болар. Орнатқаннан кейін Pip-ті де орнатуды ұсынамыз, өйткені курстың кейінгі кезеңінде керек болады.

    Ал python file.py деп жазғанда нақты не болады? Python-мен бірге жүктелген интерпретатор (interpreter) деген бағдарлама файлыңызды жол-жолымен оқып, әр жолды орындайды. Бұл C немесе Java сияқты тілдерден өзгеше: ол тілдердегі код іске қосылар алдында машина кодына компиляцияланады (compiled). Python-да бұл қадам жоқ, ол кодты тікелей оқып жүре береді. Интерпретатор кітапты дауыстап оқып отырған адам сияқты, ал компилятор алдымен бүкіл кітапты басқа тілге аударып алып, сосын береді.

    Осы сайтта Python кодын бірден орындап көруге болады: төмендегі мысалды «▶ Іске қосу» батырмасымен іске қосыңыз.

    print("Hello, world!")

    Айнымалылар

    Кез келген бағдарламалау тілінің негізгі бөлігі - айнымалыларды жасап, олармен жұмыс істей білу. Python-да айнымалыға мән беру синтаксисі былай:

    a = 28
b = 1.5
c = "Hello!"
d = True
e = None

    Әр жол = белгісінің оң жағындағы мәнді алып, сол жақтағы атпен сақтап қояды. Яғни = - «тең» емес, «сақта» деген команда.

    Кейбір тілдерден айырмашылығы, Python-да айнымалы типтері өздігінен анықталады (inferred). Әр айнымалының типі бар, бірақ оны жасаған кезде анық көрсетудің қажеті жоқ. Ең көп кездесетін типтер:

    • int: бүтін сан;
    • float: ондық бөлшек сан;
    • str: жол, яғни таңбалар тізбегі;
    • bool: не True, не False болатын мән;
    • NoneType: мәннің жоқтығын білдіретін ерекше мән (None).

    Енді сәл қызықтырақ бағдарлама жазайық: қолданушыдан кіріс алып, сәлем айтатын. Ол үшін тағы бір кірістірілген функция - input керек. Ол қолданушыға сұрақ (prompt) көрсетіп, қолданушы не жазса, соны қайтарады. Мысалы, name.py деген файлға мынаны жазамыз:

    name = input("Name: ")
print("Hello, " + name)

    Терминалда бұл бағдарлама «Name:» деп сұрайды, сіз атыңызды жазасыз, ол «Hello, » деп амандасады. Екі нәрсені атап өтейік:

    • Бірінші жолда name айнымалысына нақты мән бермей, input функциясы не қайтарса, соны тағайындап отырмыз.
    • Екінші жолда + операторымен екі жолды біріктіріп (concatenate) жатырмыз. Python-да + сандарды қосады, ал жолдар мен тізімдерді бір-біріне жалғайды.

    Жолдарды пішімдеу

    Жолдарды + арқылы біріктіруге болады, бірақ Python-ның жаңа нұсқаларында одан да жеңіл тәсіл бар. Ол пішімделген жолдар (formatted strings), қысқаша f-жолдар (f-strings). Бұл туралы осы мақаладан толығырақ оқи аласыз.

    Пішімделген жол қолданатынымызды көрсету үшін тырнақшаның алдына f әрпін қоямыз. Мысалы, жоғарыдағы "Hello, " + name орнына f"Hello, {name}" деп жазсақ, нәтиже сондай. Тіпті функцияның өзін жолдың ішіне салуға болады. Сонда жоғарыдағы бағдарламаны бір жолға сыйғызамыз:

    print(f"Hello, {input("Name: ")}")

    Бұл жол соңғы Python нұсқаларында ғана жұмыс істейді (жолдың ішінде сол түрдегі тырнақшаны қайта қолдану). Ескірек нұсқада ішкі тырнақшаны бөлек түрге ауыстыру керек болады.

    Қарапайым үлгісін өзіңіз іске қосып көріңіз:

    name = input("Name: ")
print(f"Hello, {name}")

    Шарттар

    Басқа тілдердегі сияқты, Python да белгілі бір шартқа байланысты кодтың әртүрлі бөліктерін орындауға мүмкіндік береді. Төмендегі бағдарламада қолданушы жазған санға қарай шығысты өзгертеміз:

    num = input("Number: ")
if num > 0:
    print("Number is positive")
elif num < 0:
    print("Number is negative")
else:
    print("Number is 0")

    Бағдарлама қалай құрылған? Python-дағы шарттар кілт сөзден (if, elif немесе else) және (else-тен басқа жағдайда) логикалық өрнектен тұрады. Логикалық өрнек деп мәні не True, не False болатын өрнекті айтамыз. Шарт орындалса, жұмыс істеуі тиіс код оның астына шегініспен (indentation) жазылады. Python-да шегініс - синтаксистің міндетті бөлігі, көркемдік үшін емес. Басқа тілдерде фигуралы жақша не істесе, Python-да шегініс сол рөлді атқарады.

    Бірақ бұл бағдарламаны іске қосқанда, сіз бір қате көресіз. Әдейі қате жасап көрейік: жоғарыдағы кодты «▶ Іске қосу» арқылы орындап, 5 деп жазыңыз.

    Шықты ма? Бұл қате ерекше жағдай (exception) деп аталады. Ерекше жағдай - Python кодын орындап жатқанда қате кеткенде пайда болатын жағдай. Уақыт өте келе мұндай қателерді оқуды жақсы үйренесіз, ал бұл өте бағалы дағды.

    Осы нақты қатеге жақынырақ қарайық. Ең төменгі жолда TypeError тұр. Әдетте бұл Python бір айнымалының бір типте болуын күтіп, бірақ басқа типте тапқанын білдіреді. Біздің жағдайда қате бізге str пен int-ті > белгісімен салыстыруға болмайтынын айтады, ал одан жоғарырақтан бұл салыстыру екінші жолда жасалғанын көреміз.

    Ойланып көрейік: 0 - бүтін сан екені анық, демек num айнымалысы жол болып тұр. Неге? Себебі input функциясы әрқашан жол қайтарады. Ал бізге бүтін сан керек, сондықтан оны int функциясымен бүтін санға айналдыруымыз (cast) қажет. Сонда бірінші жол былай болады:

    num = int(input("Number: "))

    Енді бағдарлама біз ойлағандай жұмыс істейді! Толық нұсқасын тексеріп көріңіз:

    num = int(input("Number: "))
if num > 0:
    print("Number is positive")
elif num < 0:
    print("Number is negative")
else:
    print("Number is 0")
    Ойланып көріңіз: қолданушы 5 деп жазса да, input неге жол қайтарады?

    Қолданушы пернетақтадан не терсе де, компьютер оны таңбалар тізбегі, яғни жол ретінде алады. «5» деген таңба мен 5 саны - екі бөлек нәрсе: біріншісін қосып, салыстыра алмаймыз. Сондықтан санмен жұмыс істеу үшін int(...) арқылы айналдырамыз.

    Тізбектер

    Python-ның ең қуатты жақтарының бірі - жеке айнымалылармен қатар деректердің тізбектерімен (sequences) жұмыс істей алуы.

    Тізбектің бірнеше түрі бар. Олар бір жағынан ұқсас, бір жағынан өзгеше. Айырмашылықты түсіндіргенде екі жұп ұғымды қолданамыз: өзгермелі / өзгермейтін (mutable / immutable) және реттелген / реттелмеген (ordered / unordered). Өзгермелі дегеніміз - тізбек анықталғаннан кейін оның жеке элементтерін өзгерте аламыз. Реттелген дегеніміз - элементтердің орналасу реті маңызды.

    ТипРеттелгенӨзгермелі
    Жол (str)ИәЖоқ
    Тізім (list)ИәИә
    Кортеж (tuple)ИәЖоқ
    Жиын (set)ЖоқҚолданылмайды (элемент қосып, алып тастауға болады)
    Сөздік (dict)ЖоқИә

    Жолдар

    Реттелген: иә. Өзгермелі: жоқ.

    Жолдарды біз әлдеқашан аздап көрдік. Бірақ жолды жай айнымалы деп емес, таңбалар тізбегі деп қарауға болады. Демек, жол ішіндегі жеке таңбаларға қол жеткізе аламыз! Мысалы:

    name = "Harry"
print(name[0])
print(name[1])

    Бұл бірінші (индексі 0) таңбаны, біздің жағдайда H-ты, сосын екінші (индексі 1) таңбаны, яғни a-ны шығарады. Назар аударыңыз: санау бірден емес, нөлден басталады.

    Тізімдер

    Реттелген: иә. Өзгермелі: иә.

    Python тізімі (list) кез келген типтегі мәндерді сақтай алады. Тізімді шаршы жақша мен үтір арқылы жасаймыз. Жолдағыдай, тізімнің бәрін де, жеке элементін де шығаруға болады. Сондай-ақ append арқылы элемент қосып, sort арқылы тізімді сұрыптай аламыз:

    # This is a Python comment
names = ["Harry", "Ron", "Hermione"]
# Print the entire list:
print(names)
# Print the second element of the list:
print(names[1])
# Add a new name to the list:
names.append("Draco")
# Sort the list:
names.sort()
# Print the new list:
print(names)

    Шығыс: алдымен ['Harry', 'Ron', 'Hermione'], сосын Ron, соңында әліпби ретімен сұрыпталған ['Draco', 'Harry', 'Hermione', 'Ron']. Өзіңіз іске қосып көріңіз.

    Кортеждер

    Реттелген: иә. Өзгермелі: жоқ.

    Кортеждер (tuples) әдетте екі-үш мәнді бірге сақтау керек болғанда қолданылады. Мысалы, нүктенің x және y координаталары. Python кодында жақша қолданамыз:

    point = (12.5, 10.6)

    Кортеж анықталған соң оның ішіндегі мәнді өзгерте алмайсыз. Нүктенің координаталары «біртұтас» болғандықтан, бұл дәл керегі.

    Жиындар

    Реттелген: жоқ. Өзгермелі: қолданылмайды.

    Жиындар (sets) тізім мен кортежден екі жағынан ерекшеленеді. Біріншіден, олар реттелмеген. Екіншіден, тізім мен кортежде бірдей элемент бірнеше рет кездесе алады, ал жиын әр мәнді тек бір рет сақтайды. Бос жиынды set функциясымен жасаймыз. Сосын add және remove арқылы элемент қосып, алып тастаймыз, ал len функциясымен жиынның мөлшерін білеміз. len Python-дағы барлық тізбекте жұмыс істейтінін ескеріңіз. Және мынаны байқаңыз: 3 пен 1-ді жиынға екі рет қосқанымызбен, әр элемент тек бір рет қана тұр.

    # Create an empty set:
s = set()

# Add some elements:
s.add(1)
s.add(2)
s.add(3)
s.add(4)
s.add(3)
s.add(1)

# Remove 2 from the set
s.remove(2)

# Print the set:
print(s)

# Find the size of the set:
print(f"The set has {len(s)} elements.")

""" This is a python multi-line comment:
Output:
{1, 3, 4}
The set has 3 elements.
"""

    Жиын сынып журналына ұқсайды, онда есімдер қайталанбайды: екі Айгүл келсе де, журналға бір рет жазылады.

    Сөздіктер

    Реттелген: жоқ. Өзгермелі: иә.

    Python сөздіктері (dictionaries, қысқаша dict) бұл курсқа айрықша қажет болады. Сөздік - кілт-мән жұптарының (key-value pairs) жиыны, мұнда әр кілттің өз мәні бар. Нағыз сөздіктегідей: әр сөз (кілт) өзіне сай түсіндірмеге (мәнге) жетелейді. Python-да сөздікті фигуралы жақшамен жазамыз, кілт пен мәнді қос нүкте бөледі:

    # Define a dictionary
houses = {"Harry": "Gryffindor", "Draco": "Slytherin"}
# Print out Harry's house
print(houses["Harry"])
# Adding values to a dictionary:
houses["Hermione"] = "Gryffindor"
# Print out Hermione's House:
print(houses["Hermione"])

""" Output:
Gryffindor
Gryffindor
"""
    Ойланып көріңіз: houses["Ron"] деп жазсақ не болады?

    Сөздікте «Ron» кілті әлі жоқ, сондықтан Python KeyError береді. Кілт-мән жұбын алдымен қосу керек: houses["Ron"] = "Gryffindor". Тек содан кейін оны оқи аламыз.

    Циклдер

    Цикл - кез келген бағдарламалау тілінің аса маңызды бөлігі. Python-да олар негізінен екі түрде: for циклдері және while циклдері. Әзірге for циклдеріне назар аударамыз.

    for циклі элементтер тізбегін аралап шығып, әр элемент үшін (астына шегіністеп жазылған) код блогын орындайды. Мысалы, мына код 0-ден 5-ке дейінгі сандарды шығарады:

    for i in [0, 1, 2, 3, 4, 5]:
    print(i)

""" Output:
0
1
2
3
4
5
"""

    Бұл кодты range функциясымен қысқартуға болады. Ол бізге сандар тізбегін оңай береді. Төмендегі код жоғарыдағымен дәл бірдей нәтиже береді:

    for i in range(6):
    print(i)

""" Output:
0
1
2
3
4
5
"""

    Мұндай цикл кез келген тізбекпен жұмыс істейді! Мысалы, тізімдегі әр атты шығарғымыз келсе:

    # Create a list:
names = ["Harry", "Ron", "Hermione"]

# Print each name:
for name in names:
    print(name)

""" Output:
Harry
Ron
Hermione
"""

    Тіпті одан да нақтылай аламыз: бір атты алып, оның әр әрпін аралап шығайық!

    name = "Harry"
for char in name:
    print(char)

""" Output:
H
a
r
r
y
"""

    Функциялар

    Біз print және input сияқты бірнеше Python функциясын көрдік. Енді өз функцияларымызды жазуға көшеміз. Бастау үшін санды алып, оның квадратын қайтаратын функция жазайық:

    def square(x):
    return x * x

    Назар аударыңыз: функцияны анықтау үшін def кілт сөзін қолдандық, функция x деген бір кіріс алады, ал функцияның шығысы не болатынын return кілт сөзі көрсетеді.

    Енді бұл функцияны басқаларын шақырғандай, жақшамен «шақыра» аламыз:

    def square(x):
    return x * x

for i in range(10):
    print(f"The square of {i} is {square(i)}")

""" Output:
The square of 0 is 0
The square of 1 is 1
The square of 2 is 4
The square of 3 is 9
The square of 4 is 16
The square of 5 is 25
The square of 6 is 36
The square of 7 is 49
The square of 8 is 64
The square of 9 is 81
"""

    Модульдер

    Жобаларымыз үлкейген сайын функцияларды бір файлға жазып, басқа файлда пайдалану ыңғайлы бола бастайды. Жоғарыдағы жағдайда functions.py деген бір файл жасап, оған мынаны жазуға болады:

    def square(x):
    return x * x

    Ал square.py деген екінші файлға мынау болады:

    for i in range(10):
    print(f"The square of {i} is {square(i)}")

    Бірақ square.py файлын іске қосқанда, мынадай NameError қатесі шығады: Python square деген атты танымайды. Неге? Себебі әдепкі бойынша Python файлдары бір-бірін білмейді. Біз жаңа жазған functions модулінен (module) square функциясын анық import етуіміз керек. Сонда square.py былай болады:

    from functions import square

for i in range(10):
    print(f"The square of {i} is {square(i)}")

    Немесе functions модулін толығымен импорттап, square функциясына нүкте арқылы жетуге болады:

    import functions

for i in range(10):
    print(f"The square of {i} is {functions.square(i)}")

    Бұл екі тәсілдің біріншісі функцияның атын бірден әкеледі, екіншісі бүкіл «қорапты» әкеліп, ішінен қажетті нәрсені нүктемен алады. Мұнда functions.square деп жазсақ, «functions қорабындағы square» деген мағына шығады.

    Импорттауға болатын көптеген кірістірілген модульдер бар, мысалы math немесе csv. Олар бізге тағы да көп функцияны ашады. Сонымен қатар одан да көп мүмкіндік алу үшін сырттан қосымша модульдер жүктеп алуға болады. Біз Django модулін көп қолданамыз, оны келесі лекцияда талқылаймыз.

    Объектіге бағытталған бағдарламалау

    Объектіге бағытталған бағдарламалау (object-oriented programming) - бағдарламалау парадигмасы, яғни бағдарламалау туралы ойлау тәсілі. Оның орталығында ақпарат сақтап, әрекет жасай алатын объектілер (objects) тұр.

    Кластар

    Python-да біраз түрлі айнымалы типтерін көрдік. Ал өз типімізді жасағымыз келсе ше? Python класы (class) - ақпарат сақтап, әрекет жасай алатын жаңа типтегі объект үшін үлгі, яғни қалып. Мысалы, екі өлшемді нүктені анықтайтын класс:

    class Point():
    # A method defining how to create a point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    Кодта біз self кілт сөзін қолданамыз: ол біз қазір жұмыс істеп жатқан объектінің өзін білдіреді. self Python класындағы кез келген әдістің (method) бірінші аргументі болуы тиіс. Ал __init__ - объект жасалғанда автоматты түрде шақырылатын арнайы әдіс.

    Енді жоғарыдағы кластың көмегімен объект жасап көрейік:

    class Point():
    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Point(2, 8)
print(p.x)
print(p.y)

""" Output:
2
8
"""

    Енді қызықтырақ мысал қарастырайық: тек нүктенің координаталарын емес, әуе рейсін білдіретін класс жасайық:

    class Flight():
    # Method to create new flight with given capacity
    def __init__(self, capacity):
        self.capacity = capacity
        self.passengers = []

    # Method to add a passenger to the flight:
    def add_passenger(self, name):
        self.passengers.append(name)

    Бірақ бұл класс кемшін: сыйымдылықты (capacity) белгілегенімізбен, бәрібір тым көп жолаушы қоса аламыз. Жолаушыны қоспас бұрын рейсте орын бар-жоғын тексеретіндей етіп жетілдірейік:

    class Flight():
    # Method to create new flight with given capacity
    def __init__(self, capacity):
        self.capacity = capacity
        self.passengers = []

    # Method to add a passenger to the flight:
    def add_passenger(self, name):
        if not self.open_seats():
            return False
        self.passengers.append(name)
        return True

    # Method to return number of open seats
    def open_seats(self):
        return self.capacity - len(self.passengers)

    Назар аударыңыз: орын бар-жоғын анықтау үшін if not self.open_seats() жолын қолданып отырмыз. Бұл неге жұмыс істейді? Python-да 0 саны False деп түсіндірілуі мүмкін, ал not кілт сөзі одан кейінгі өрнектің қарама-қарсысын береді: not True - False, not False - True. Демек, open_seats нөлді қайтарса, бүкіл өрнек True болады, яғни орын жоқ.

    Жазған класымызды сынап көрейік: оның бірнеше данасын (instance) жасаймыз:

    class Flight():
    def __init__(self, capacity):
        self.capacity = capacity
        self.passengers = []

    def add_passenger(self, name):
        if not self.open_seats():
            return False
        self.passengers.append(name)
        return True

    def open_seats(self):
        return self.capacity - len(self.passengers)

# Create a new flight with o=up to 3 passengers
flight = Flight(3)

# Create a list of people
people = ["Harry", "Ron", "Hermione", "Ginny"]

# Attempt to add each person in the list to a flight
for person in people:
    if flight.add_passenger(person):
        print(f"Added {person} to flight successfully")
    else:
        print(f"No available seats for {person}")

""" Output:
Added Harry to flight successfully
Added Ron to flight successfully
Added Hermione to flight successfully
No available seats for Ginny
"""
    Ойланып көріңіз: төрт адамның біреуіне неге орын табылмады?

    Рейстің сыйымдылығы 3. Үш жолаушыны қосқаннан кейін open_seats() нөл қайтарады, ал not 0 - True. Сондықтан төртінші, Ginny үшін add_passenger False қайтарады да, бағдарлама «No available seats» деп жазады.

    Функционалдық бағдарламалау

    Объектіге бағытталған бағдарламалаудан бөлек, Python функционалдық бағдарламалау парадигмасын (functional programming) да қолдайды. Мұнда функциялар кез келген басқа айнымалы сияқты мән ретінде қарастырылады: оны айнымалыға беруге, басқа функцияға аргумент етіп жіберуге, функциядан қайтаруға болады.

    Декораторлар

    Функционалдық бағдарламалау мүмкін еткен нәрселердің бірі - декоратор (decorator) идеясы. Бұл басқа функцияны өзгерте алатын жоғары ретті функция (higher-order function). Мысалы, функция басталар және аяқталар сәтте хабар беретін декоратор жазайық. Оны @ белгісімен қолданамыз.

    def announce(f):
    def wrapper():
        print("About to run the function")
        f()
        print("Done with the function")
    return wrapper

@announce
def hello():
    print("Hello, world!")

hello()

""" Output:
About to run the function
Hello, world!
Done with the function
"""

    Қалай жұмыс істейді? announce функциясы басқа функцияны (f) алады да, жаңа функцияны (wrapper, яғни «орағыш») құрып, оны қайтарады. Орағыш алдымен бір хабар жазып, сосын түпнұсқа f()-ті шақырады, ең соңында екінші хабарды жазады. @announce деп жазғанда Python hello атын осы орағышқа ауыстырып қояды. Сыйлықты әдемі қағазға орағандай: ішіндегісі сол, бірақ сыртына бірдеңе қосылды.

    Ойланып көріңіз: hello()-ті шақырғанда шын мәнінде қай функция орындалады?

    wrapper. @announce декоратордан кейін hello аты wrapper-ге сілтейді. wrapper ішінде бастапқы hello (f ретінде) екі хабардың арасында шақырылады. Сондықтан шығыс үш жол болады.

    Лямбда функциялары

    Лямбда функциялары (lambda functions) Python-да функция жасаудың тағы бір жолын береді. Мысалы, бұрынғы square функциясын былай жазуға болады:

    square = lambda x: x * x

    Мұнда кіріс : белгісінің сол жағында, ал шығыс оң жағында тұр.

    Бұл біз үлкен функция жазғымыз келмейтін, бір рет қана қолданылатын шағын жағдайларда ыңғайлы. Мысалы, элементтерді қалай сұрыптау керегі бірден түсінікті болмаған кезде. Есімі мен үйі бар адамдар тізімі бар делік, оны сұрыптағымыз келеді:

    people = [
    {"name": "Harry", "house": "Gryffindor"},
    {"name": "Cho", "house": "Ravenclaw"},
    {"name": "Draco", "house": "Slytherin"}
]

people.sort()

print(people)

    Бұл бізге TypeError қатесін береді (өзіңіз іске қосып көріңіз). Себебі Python екі сөздіктің қайсысы кіші екенін салыстыруды білмейді.

    Бұл мәселені sort функциясына key аргументін беру арқылы шешеміз. Ол сөздіктің қай бөлігі бойынша сұрыптау керегін көрсетеді:

    people = [
    {"name": "Harry", "house": "Gryffindor"},
    {"name": "Cho", "house": "Ravenclaw"},
    {"name": "Draco", "house": "Slytherin"}
]

def f(person):
    return person["name"]

people.sort(key=f)

print(people)

""" Output:
[{'name': 'Cho', 'house': 'Ravenclaw'}, {'name': 'Draco', 'house': 'Slytherin'}, {'name': 'Harry', 'house': 'Gryffindor'}]
"""

    Бұл жұмыс істейді, бірақ тек бір рет қолданатын тұтас функция жазуға тура келді. Лямбда функциясын қолдансақ, кодымыз оқуға жеңілірек болады:

    people = [
    {"name": "Harry", "house": "Gryffindor"},
    {"name": "Cho", "house": "Ravenclaw"},
    {"name": "Draco", "house": "Slytherin"}
]

people.sort(key=lambda person: person["name"])

print(people)

""" Output:
[{'name': 'Cho', 'house': 'Ravenclaw'}, {'name': 'Draco', 'house': 'Slytherin'}, {'name': 'Harry', 'house': 'Gryffindor'}]
"""

    Ерекше жағдайлар

    Осы лекцияда біз бірнеше түрлі ерекше жағдайға тап болдық. Енді олармен жұмыс істеудің жаңа жолдарын қарастырайық.

    Төмендегі кодта қолданушыдан екі бүтін сан алып, оларды бөлеміз:

    x = int(input("x: "))
y = int(input("y: "))

result = x / y

print(f"{x} / {y} = {result}")

    Көп жағдайда бұл бағдарлама жақсы жұмыс істейді: мысалы, 10 мен 2 берсек, 10 / 2 = 5.0 шығады. Бірақ нөлге бөлуге тырыссақ, мәселе туады: «ZeroDivisionError» қатесі шығады. Өзіңіз y үшін 0 енгізіп көріңіз.

    Мұндай ұсқынсыз қатемен ерекше жағдайды өңдеу (exception handling) арқылы күресеміз. Келесі кодта екі санды бөлуге try етеміз, ал ZeroDivisionError шықса, оны except арқылы ұстаймыз:

    import sys

x = int(input("x: "))
y = int(input("y: "))

try:
    result = x / y
except ZeroDivisionError:
    print("Error: Cannot divide by 0.")
    # Exit the program
    sys.exit(1)

print(f"{x} / {y} = {result}")

    Енді нөлге бөлсек, Python-ның ұзын қате мәтіні орнына біздің түсінікті хабарымыз шығады: «Error: Cannot divide by 0.» Бағдарлама sys.exit(1) арқылы тоқтайды.

    Бірақ қолданушы x пен y үшін сан емес, мысалы «cat» деп жазса, тағы да қате шығады: ValueError. Мұны да ұқсас жолмен шешеміз!

    import sys

try:
    x = int(input("x: "))
    y = int(input("y: "))
except ValueError:
    print("Error: Invalid input")
    sys.exit(1)

try:
    result = x / y
except ZeroDivisionError:
    print("Error: Cannot divide by 0.")
    # Exit the program
    sys.exit(1)

print(f"{x} / {y} = {result}")

    Осымен бүгінгі лекция аяқталды! Келесі жолы Python-ның Django модулін қолданып, нағыз қосымшалар құрамыз.

    Қорытынды

    • Python кодын интерпретатор жол-жолымен оқып орындайды, компиляция қадамы жоқ.
    • Айнымалылардың типі өздігінен анықталады: int, float, str, bool, None. input әрқашан str қайтарады, сондықтан санға int(...) арқылы айналдырамыз.
    • F-жолдар (f"Hello, {name}") жолдарды +-тан гөрі жеңіл пішімдейді.
    • Шарттар (if, elif, else) шегіністі міндетті түрде қолданады.
    • Тізбектер: жол, тізім, кортеж, жиын, сөздік. Олар реттелген/реттелмеген және өзгермелі/өзгермейтін болып ерекшеленеді.
    • for циклі кез келген тізбекті аралайды, range сандар тізбегін береді.
    • Функцияны def және return арқылы жазамыз, оны import арқылы басқа файлдарда (модульдерде) қолданамыз.
    • Кластар (__init__, self, әдістер) өз типімізді жасауға мүмкіндік береді.
    • Функционалдық бағдарламалау: функциялар мән ретінде жүреді; декораторлар (@) функцияны орап өзгертеді, лямбда шағын атаусыз функция жасайды.
    • try және except ерекше жағдайларды (ZeroDivisionError, ValueError) өңдеуге көмектеседі.

    Өзіңізді тексеріңіз

    1. Python-ның интерпретатор екені нені білдіреді?

    C мен Java-дағыдай бөлек компиляция қадамы Python-да жоқ: интерпретатор кодты тікелей оқып жүре береді.

    2. Қолданушы 7 деп жазды. num = input("Number: ") болғанда, num > 0 неге TypeError береді?

    Түзету: num = int(input("Number: ")).

    3. Мына код не шығарады?

    s = set()
s.add(1)
s.add(2)
s.add(1)
print(len(s))

    Жиын әр мәнді бір рет қана сақтайды, сондықтан 1 екі рет қосылса да, ішінде {1, 2} ғана бар.

    4. houses = {"Harry": "Gryffindor"} болса, houses["Harry"] не береді?

    Сөздікте кілт арқылы оның мәнін аламыз. Тізімдегідей нөмір емес, кілт қолданылады.

    5. Flight(2) рейсіне үш жолаушыны ретімен add_passenger арқылы қостық. Үшінші шақыру не қайтарады?

    Екі жолаушыдан кейін open_seats() нөлге тең, not 0 - True, сондықтан әдіс False қайтарады.

    6. Декоратор @announce қолданылған hello() шақырылғанда не болады?

    @announce деп жазғанда hello аты wrapper-ге ауысады, ал түпнұсқа f ретінде wrapper ішінде шақырылады.

    7. Мына лямбда нені істейді?

    people.sort(key=lambda person: person["name"])

    key әр элементтен сұрыптау үшін қай мәнді алу керегін айтады, лямбда сол мәнді қайтарады.

    8. Қолданушы x үшін cat деп жазса, төмендегі кодта қай ерекше жағдай шығады және оны қайсысы ұстайды?

    try:
    x = int(input("x: "))
except ValueError:
    print("Error: Invalid input")

    Сан емес жолды int-ке айналдыру ValueError береді. except ValueError дәл осыны ұстайды.

    Жаттығу

    Сайттың өз жаттығуы, ресми емес

    Бұл апта үшін CS50 Web-те жеке problem set жоқ: сіз Python-ды келесі аптада Django-да қолданасыз. Дегенмен тілді бекіту үшін төменде сайттың өз шағын тапсырмалары берілген. Олар ресми тапсырма емес, ал автотексеруші браузерде (Pyodide) жұмыс істейді. Кодты редакторға жазып, «Тексеру» батырмасын басыңыз.

    Оңай

    Person класы

    Адамды білдіретін Person класын жазыңыз:

    • __init__(self, name, age) аты мен жасын сақтайды (self.name, self.age);
    • birthday(self) жасты 1-ге арттырады және ештеңе қайтармайды;
    • greet(self) "Hi, I'm Harry and I'm 17" пішіміндегі жолды қайтарады.
    Кеңес

    Flight класындағыдай, мәндерді __init__-те self арқылы сақтаңыз. birthday жаңа мән қайтармай, self.age-ті өзгертуі керек. Жолды f-жолмен құрыңыз.

    Тексеру
    • greet() жолды return етеді, print емес.
    • birthday() объектінің жасын өзгертеді.

    Орташа

    announce декораторы

    Лекциядағы announce декораторын жетілдіріңіз: ол кез келген функциямен жұмыс істесін (аргументтері бар да). Орағыш алдымен About to run the function жазсын, сосын функцияны аргументтерімен шақырсын, сосын Done with the function жазсын, ең соңында функция қайтарған мәнді қайтарсын.

    Кеңес

    Орағышқа *args, **kwargs деп жазсаңыз, ол кез келген аргументтерді қабылдайды да, оларды f(*args, **kwargs) арқылы әрі қарай береді. Нәтижені айнымалыға сақтап қойып, хабардан кейін қайтарыңыз.

    Тексеру
    • Орағыш аргументі бар функциялармен жұмыс істейді.
    • Функцияның қайтарған мәні жоғалмайды.

    Оңай

    Сөздікпен санау

    count_words(text) функциясын жазыңыз: ол мәтіндегі әр сөздің неше рет кездескенін санап, сөздік қайтарады. Регистрге қарамаңыз (The мен the - бір сөз), сөздер бос орын бойынша бөлінеді. Мысалы, count_words("a b a") нәтижесі {"a": 2, "b": 1}.

    Кеңес

    Бос сөздікті жасаңыз, мәтінді .lower().split() арқылы сөздерге бөліп, for циклінде әр сөзді тексеріңіз: сөздікте бар болса санын арттырыңыз, жоқ болса 1 деп қосыңыз.

    Тексеру
    • Регистр ескерілмейді.
    • Бос жолға бос сөздік қайтады.

    Орташа

    lambda арқылы сұрыптау

    Адамдар тізімі берілген: әр адам {"name": ..., "age": ...} сөздігі. Екі функция жазыңыз:

    • sort_people(people) аты бойынша өсу ретімен сұрыпталған жаңа тізім қайтарады (бастапқы тізім өзгермейді);
    • oldest(people) ең үлкен адамның атын қайтарады.

    Екеуінде де lambda қолданыңыз.

    Кеңес

    sorted(тізім, key=lambda person: ...) жаңа тізім қайтарады, ал .sort() бастапқы тізімді өзгертеді. Ең үлкенін табу үшін max(тізім, key=...) бар.

    Тексеру
    • sort_people бастапқы тізімді өзгертпейді.
    • Екі функцияда да lambda қолданылған.
