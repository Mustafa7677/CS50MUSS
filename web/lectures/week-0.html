    HTML және CSS

    Веб-бет қалай жасалады? Сайттың құрылымын HTML-мен сызып, көркемдігін CSS-пен келтіреміз, ал Flexbox, Grid, Bootstrap және Sass бетті әрі ыңғайлы, әрі әр құрылғыға лайық етеді.

    ▶ Түпнұсқа конспект пен материалдар (ағылшынша)
    Бұл апта не туралы

    CS50 Web - бұрынғы CS50 тоқтаған жерден басталатын курс: енді өз веб-қосымшаларымызды жобалап, жасаймыз. Бүгін ең алғашқы қадам: бетті HTML-мен құрастырып, CSS-пен әсемдеуді үйренеміз. Мысалдардың барлығының астында «▶ Көрсету» батырмасы бар: басып, нәтижесін сол жерде көресіз, ал кодты өзгертіп көру үшін «Сынақ алаңына» барыңыз.

    Бұл бет сөзбе-сөз аударма емес. Лектор аудиторияда қалай түсіндірсе, біз де солай баяндаймыз: мағынасы мен кодтың бәрі түпнұсқадағыдай, тек әңгіме ана тілімізде жүреді.

    Кіріспе

    Қош келдіңіз! Бұл курста біз CS50-дің қалдырған жерінен жалғастырамыз: веб-қосымшаларды жобалап, құрастыруды үйренеміз. Курс бойы бірнеше жоба жасаймыз, ал ең соңында өз бетіңізше, өзіңіз қалаған сайтты жасайтын финалдық жоба күтіп тұр.

    Бір нәрсе керек: компьютеріңізде код жазатын мәтін редакторы (text editor) болуы тиіс. Танымалдары: Visual Studio Code, Sublime Text, Atom, Vim. Таңдау сіздікі, қайсысы жақсы көрінсе, соны алыңыз. Ең бастысы - файлды компьютеріңізде жазып, браузерден ашып көру.

    Веб-бағдарламалау

    Курстың жол картасына бір қарап шығайық. Әрқайсысына кейін толық тоқталамыз, ал қазірше аты-жөнін білсеңіз болғаны:

    1. HTML және CSS: бетті сипаттайтын белгілеу тілі және сайтты көркемдеу тәсілі.
    2. Git: нұсқаларды басқару және бірлесіп жұмыс істеу құралы.
    3. Python: сайттарымызды «тірілту» үшін қолданатын кең тараған бағдарламалау тілі.
    4. Django: сайттың сервер жағын (backend) жазуға арналған танымал веб-фреймворк.
    5. SQL, модельдер және миграциялар: деректерді сақтап, іздеу тілі және Django-ның дерекқормен жұмысты жеңілдететін әдістері.
    6. JavaScript: сайтты жылдам әрі интерактивті ететін тіл.
    7. Пайдаланушы интерфейстері: сайтты барынша қолайлы етудің жолдары.
    8. Тестілеу, CI, CD: беттің жаңартулары тегіс өтуін қамтамасыз ететін тәсілдер.
    9. Масштабтау және қауіпсіздік: сайтқа бір мезгілде көп адам кіре алуы және зиянкестерден қорғалуы.

    HTML (Гипермәтін белгілеу тілі)

    HTML (Hypertext Markup Language) - бұл веб-беттің құрылымын сипаттайтын белгілеу тілі (markup language). Бұл бағдарламалау тілі емес: ол ештеңе есептемейді, тек «мұнда тақырып, мұнда абзац, мұнда сурет» деп бетті белгілейді. Оны браузер (Safari, Google Chrome, Firefox және т.б.) оқып, экранға шығарады.

    Ең қарапайым HTML файлын бірге жазып көрейік.

    <!DOCTYPE html>
<html lang="en">
    <head>
        <title>Hello!</title>
    </head>
    <body>
        Hello, world!
    </body>
<html>

    Мұны браузерде ашсақ, бетте «Hello, world!» жазуы шығады. Бірақ бір ғана сәлем үшін файл біраз күрделі көрінбей ме? Жол-жолымен талдайық.

    • Бірінші жолда браузерге «құжатты HTML5-тің ең соңғы нұсқасында жаздым» деп жариялап тұрмыз.
    • Одан кейін бет бір-бірінің ішіне салынған HTML элементтерінен (HTML elements) тұрады, мысалы html және body. Әр элементтің ашатын және жабатын тегі (opening and closing tag) бар: ашатыны <element>, жабатыны </element> түрінде жазылады.
    • Ішкі элементтердің әрқайсысы алдыңғысынан сәл ішке қарай жазылғанын байқаңыз. Браузерге мұның керегі жоқ, бірақ өз кодыңызда осы әдетті міндетті түрде сақтаңыз: кейін өзіңіз оқуға әлдеқайда оңай болады.
    • HTML элементтеріне браузерге қосымша мәлімет беретін атрибуттар (attributes) жазуға болады. Мысалы, бастапқы тегке lang="en" қоссақ, біз «негізгі тіл - ағылшын тілі» деп хабарлаймыз.
    • html ішінде әдетте екі бөлім болады: head және body. head ішінде бет туралы, бірақ экранда көрінбейтін ақпарат тұрады, ал body - сайтқа кірген адам шынымен көретін бөлік.
    • head ішіндегі title - бет атауы. Оны браузердің жоғарғы жағындағы қойындыдан көресіз.
    • Соңында body ішіндегі «Hello, world!» мәтіні - беттің көрінетін бөлігі.
    Конспекттегі бір ұсақ қате

    Лекция конспектісіндегі кейбір мысалдарда файлдың соңы <html> болып жазылған, ал дұрысы - </html>. Кейбір жерде <!DOCTYPE html> жолы <html> жолынан кейін тұр, ал оның орны ең бірінші жол. Біз түпнұсқа кодты өзгертпей көшірдік, браузер мұндай ұсақ қателерді кешіріп, бетті бәрібір көрсетеді. Бірақ өз жобаңызда дұрыс жазыңыз.

    Құжат нысанының моделі (DOM)

    Элементтердің бір-біріне қатынасын көру үшін құжат нысанының моделі (Document Object Model, DOM) бар. Бұл - беттегі элементтерді ағаш тәрізді құрылым ретінде елестету тәсілі. Біз жаңа жазған бет үшін ағаш мынадай болады:

    Ағашқа қарасақ, түсінікті: html - «ата», ал head пен body - оның «балалары». Бұл сурет кейін өте жиі еске түседі: JavaScript-пен бетті өзгерткенде біз дәл осы ағашпен жұмыс істейміз.

    Басқа HTML элементтері

    Бетті өз қалауыңызша жасау үшін элементтер өте көп: тақырыптар, тізімдер, қою әріптер және т.б. Келесі мысалда соның бірнешеуін қатар көрейік. Бір ескерту: HTML-дағы <!-- --> - комментарий. Төмендегі кодта түсіндірмелерді осылай жазып отырмыз.

    <!DOCTYPE html>
<html lang="en">
    <head>
        <title>HTML Elements</title>
    </head>
    <body>
        <!-- We can create headings using h1 through h6 as tags. -->
        <h1>A Large Heading</h1>
        <h2>A Smaller Heading</h2>
        <h6>The Smallest Heading</h6>

        <!-- The strong and i tags give us bold and italics respectively. -->
        A <strong>bold</strong> word and an <i>italicized</i> word!

        <!-- We can link to another page (such as cs50's page) using a. -->
        View the <a href="https://cs50.harvard.edu/">CS50 Website</a>!

        <!-- We used ul for an unordered list and ol for an ordered one. both ordered and unordered lists contain li, or list items. -->
        An unordered list:
        <ul>
            <li>foo</li>
            <li>bar</li>
            <li>baz</li>
        </ul>
        An ordered list:
        <ol>
            <li>foo</li>
            <li>bar</li>
            <li>baz</li>
        </ol>

        <!-- Images require a src attribute, which can be either the path to a file on your computer or the link to an image online. It also includes an alt attribute, which gives a description in case the image can't be loaded. -->
        An image:
        <img src="../../images/duck.jpeg" alt="Rubber Duck Picture">
        <!-- We can also see above that for some elements that don't contain other ones, closing tags are not necessary. -->

        <!-- Here, we use a br tag to add white space to the page. -->
        <br/> <br/>

        <!-- A few different tags are necessary to create a table. -->
        <table>
            <thead>
                <th>Ocean</th>
                <th>Average Depth</th>
                <th>Maximum Depth</th>
            </thead>
            <tbody>
                <tr>
                    <td>Pacific</td>
                    <td>4280 m</td>
                    <td>10911 m</td>
                </tr>
                <tr>
                    <td>Atlantic</td>
                    <td>3646 m</td>
                    <td>8486 m</td>
                </tr>
            </tbody>
        </table>
    </body>
<html>

    Кодта не болып жатқанын сөзбен айтып өтейін:

    • h1-ден h6-ға дейінгі тегтер - тақырыптар: h1 ең үлкені, h6 ең кішісі.
    • strong мәтінді қою, i қиғаш етеді.
    • a - сілтеме; қайда апаратыны href атрибутында жазылады.
    • ul - нүктелі (реттелмеген) тізім, ol - нөмірленген (реттелген) тізім; екеуінің ішінде де li, яғни тізім элементтері болады.
    • img суретке арналған. Оған src (файлдың жолы немесе интернеттегі суреттің сілтемесі) мен alt (сурет жүктелмей қалса көрсетілетін сипаттама) атрибуттары қажет. img ішіне басқа элемент салынбайтындықтан, жабатын тегі керек емес.
    • br - бетке бос орын қосатын жол үзілімі.
    • Кесте үшін бірнеше тег керек: table, оның тақырып бөлігі thead, негізгі бөлігі tbody, жолдары tr, ұяшықтары td (тақырып ұяшығы th).
    Сурет неге көрінбей тұр?

    Көрсету терезесінде үйрек суреті шықпай, орнына alt мәтіні («Rubber Duck Picture») көрінеді: сайтта ../../images/duck.jpeg файлы жоқ. Бұл - alt атрибутының қандай пайдасы барын өз көзіңізбен көретін жақсы мысал. Өз компьютеріңізде суретті жанына қойсаңыз, бәрі дұрыс көрінеді.

    Мұның бәрін жаттап алу керек деп уайымдамаңыз. «Image in HTML» деп жазып іздесеңіз, img тегін бірден табасыз. Ең пайдалы анықтамалардың бірі - W3 Schools.

    Ойланып көріңіз: <img> тегінде alt жазбасақ не болады?

    Сурет жүктелсе, бет көзге бірдей көрінер еді. Бірақ сурет қандай да бір себеппен жүктелмесе (жол қате, интернет баяу), орнында бос орын қалады. Әсіресе экранды дауыстап оқитын бағдарламаларды қолданатын көзі көрмейтін адамдар үшін alt суреттің орнына айтылатын жалғыз мәлімет. Сондықтан alt әрдайым жазылуы тиіс.

    Формалар

    Сайт жасағанда маңызды тағы бір нәрсе - пайдаланушыдан ақпарат жинау. Ол үшін HTML формасы (form) бар. Форма ішінде әртүрлі енгізу өрістері болады. Форма жіберілгеннен кейін ақпаратты қалай өңдейтінімізді курстың кейінгі аптасында үйренеміз. Алдымен қалай көрінетінін қарайық.

    <!DOCTYPE html>
<html lang="en">
<head>
    <title>Forms</title>
</head>
<body>
    <form>
        <input type="text" placeholder="First Name" name="first">
        <input type="password" placeholder="Password" name="password">
        <div>
            Favorite Color:
            <input name="color" type="radio" value="blue"> Blue
            <input name="color" type="radio" value="green"> Green
            <input name="color" type="radio" value="yellow"> Yellow
            <input name="color" type="radio" value="red"> Red

        </div>
        <input type="submit">
    </form>
</body>
</html>

    Мұнда мәтін өрісі, құпиясөз өрісі (теру кезінде әріптер нүктеге айналады), бір ғана түсті таңдауға мүмкіндік беретін радио-түймелер және жіберу батырмасы бар. Радио-түймелердің name атрибуты бірдей екеніне назар аударыңыз: дәл сол оларды «бір топ» етеді, сондықтан біреуін басқанда басқасынан белгі алынады. Мұнда да жаттап алу қажет емес, W3 Schools-та бәрі жазылған.

    Көрсету терезесінде форма жіберілмейді

    Бізде мысалдар қорғалған терезеде көрінеді, сондықтан «Submit» батырмасын басқанмен, ештеңе жіберілмейді. Бұл әдейі жасалған. Форманы нағыз жіберу үшін оны өз компьютеріңізде ашу керек, ал соңғы Project 0 дәл осыны жасатады.

    CSS (Каскадты стиль кестелері)

    HTML бетті «не қайда тұр» деп құрастырады, ал оның көркемдігін CSS (Cascading Style Sheets, каскадты стиль кестелері) келтіреді. HTML қаңқа болса, CSS - киім мен бояу.

    Алғашқы қадам ретінде кез келген HTML элементіне style атрибутын қосып, оған CSS жаза аламыз. Стильді элементтің CSS қасиеттерін (CSS properties) өзгерту арқылы береміз, мысалы color: blue немесе text-align: center. Ең бірінші файлымызға кішкене өзгеріс енгізіп, тақырыпты түрлі-түсті етейік:

    <!DOCTYPE html>
<html lang="en">
    <head>
        <title>Hello!</title>
    </head>
    <body>
        <h1 style="color: blue; text-align: center;">A Colorful Heading!</h1>
        Hello, world!
    </body>
<html>

    Енді қызық нәрсе. Сыртқы элементке стиль берсек, оның ішіндегілердің бәрі сол стильді автоматты түрде алады. Мұны көру үшін стильді h1-ден body тегіне көшіріп көрейік:

    <!DOCTYPE html>
<html lang="en">
    <head>
        <title>Hello!</title>
    </head>
    <body style="color: blue; text-align: center;">
        <h1 >A Colorful Heading!</h1>
        Hello, world!
    </body>
<html>

    Көрдіңіз бе, енді «Hello, world!» мәтіні де көк әрі ортада. Мұны CSS-тің мұрагерлігі дейді: ата-ана элементтің стилі балаларына беріледі.

    Ал дұрыс дизайн үшін стильді жеке жолдардан бөлек алып шығу керек. Мұның бір жолы - head ішінде <style> тегтерінің арасына жазу. Онда қандай түрдегі элементтерді безендіретінімізді, оларға қандай стиль беретінімізді көрсетеміз:

    <html lang="en">
  <!DOCTYPE html>
  <head>
      <title>Hello!</title>
      <style>
          h1 {
              color: blue;
              text-align: center;
          }
      </style>
  </head>
  <body>
      <h1 >A Colorful Heading!</h1>
      Hello, world!
  </body>
  </html>

    Екінші жолы - head ішіне стиль жазылған styles.css файлына апаратын <link> элементін қосу. Сонда HTML файлы былай болады:

    <html lang="en">
  <!DOCTYPE html>
  <head>
      <title>Hello!</title>
      <link rel="stylesheet" href="styles.css">
  </head>
  <body>
      <h1 >A Colorful Heading!</h1>
      Hello, world!
  </body>
  </html>

    Ал styles.css файлы мына түрде болады:

    h1 {
      color: blue;
      text-align: center;
  }
    Бұл мысал неге екі файлдан тұрады?

    link мысалын сайтта толық көрсете алмаймыз, өйткені styles.css деген бөлек файл қажет. Сондықтан соңындағы CSS-ті «▶ Көрсету» батырмасымен дайын үлгі бетке қолданып көрдік. Нақты жобада екі файлды бір қалтаға қойып, браузерден index.html-ді ашасыз.

    CSS қасиеттері өте көп, барлығын бір лекцияда айтып шығу мүмкін емес. HTML элементтері сияқты, «change font to blue CSS» деп іздесеңіз, жауап бірден шығады. Бірақ ең жиі кездесетіндерін біліп алғанымыз жөн:

    • color: мәтіннің түсі;
    • text-align: мәтіннің бет бойынша орналасуы;
    • background-color: фон түсі (кез келген түс болуы мүмкін);
    • width: ені (пиксельмен не беттің пайызымен);
    • height: биіктігі (пиксельмен не пайызбен);
    • padding: элементтің ішінде қанша бос орын қалатыны;
    • margin: элементтің сыртында қанша бос орын қалатыны;
    • font-family: бетте қолданылатын қаріп түрі;
    • font-size: қаріп өлшемі (пиксельмен);
    • border: жиек - өлшемі, түрі (solid, dashed және т.б.) және түсі.

    Үйренгенімізді қолданып, жоғарыдағы мұхиттар кестесін жақсартайық. Бастапқы HTML мынау:

    Қайталауды байқадыңыз ба? Жоғарыда td мен th бірдей стильге ие болды, яғни ұқсас кодты екі рет жаздық. Бұл - артық қайталау. Оны үтір арқылы қысқартуға болады (және керек): үтір «стиль бірнеше түрдегі элементке қатысты» дегенді білдіреді:

    table {
    border: 1px solid black;
    border-collapse: collapse;
}

td, th {
    border: 1px solid black;
    padding: 2px;
}

    CSS селекторлары

    Осы жерде біз CSS селекторларымен (CSS selectors) таныса бастадық. Селектор - «қай элементтерді безендіреміз?» деген сұраққа жауап. Оның көптеген түрі бар, ең негізгілерін қарастырайық:

    • Элемент түрі: осы уақытқа дейін істегеніміз, яғни бірдей түрдегі барлық элементтерді безендіру (h1, table, td).
    • id: HTML элементіне id беруге болады, мысалы <h1 id="first-header">Hello!</h1>. Стильді #first-header{...} деп береміз; тор белгісі (хэштег) «id бойынша іздеп жатырмыз» дегенді білдіреді. Маңызды: екі элементтің id-і бірдей болмайды және бір элементте бірден артық id болмайды.
    • class: id-ге ұқсас, бірақ класты бірнеше элемент ортақ қолдана алады, ал бір элементте бірнеше класс болуы мүмкін. Класты былай береміз: <h1 class="page-text muted">Hello!</h1> (мұнда екі класс бар: page-text және muted). Стильді сынып бойынша беру үшін тор белгісінің орнына нүкте қоямыз: .muted {...}.

    Енді бір мәселе туады: бір-біріне қайшы CSS болса не істейміз? Тақырып класы бойынша қызыл, ал id бойынша көк болуы керек делік. Қайсысы жеңеді? CSS-те мұның айқындылық тәртібі (specificity) бар. Күштіден әлсізге қарай:

    1. жол ішіндегі (inline) стиль, яғни style атрибуты;
    2. id;
    3. class;
    4. элемент түрі.

    Мұны өз көзіңізбен көрейік. Алдымен мына кодқа қарап, тақырып қандай түсті болатынын болжаңыз, содан соң батырманы басып тексеріңіз:

    <style>
    h1 { color: red; }
    .title { color: green; }
    #main-title { color: blue; }
</style>
<h1 id="main-title" class="title">Сәлем, CS50!</h1>
    Ойланып көріңіз: осы CSS-пен тақырыптың түсі қандай болады?

    Көк. Үш ереже де бір элементті таңдайды, бірақ id-дің айқындылығы class пен элемент түрінен жоғары, сондықтан #main-title жеңеді. Мысалы, <h1 class="title" style="color: orange"> деп жазсақ, жол ішіндегі стиль бәрінен басым түсіп, тақырып қызғылт сары болар еді.

    Үтірден басқа элементтерді таңдаудың көптеген тәсілі бар. Лекцияда көрсетілген кестеде олардың біразы берілген (біз оны тізім ретінде жазып отырмыз), ал негізгілерін мысалмен қарастырайық:

    • a, b: a не b элементтерін таңдайды (үтір);
    • a b: a ішіндегі кез келген тереңдіктегі b (ұрпақ селекторы);
    • a > b: a-ның тікелей баласы болатын b;
    • a[b=c]: b атрибуты c мәніне тең a элементтері (атрибут селекторы);
    • a:b: a элементінің b деген ерекше күйі (псевдокласс).
    Түпнұсқадағы кесте

    Лекцияда осы селекторлар слайдта кесте түрінде көрсетілген. Оның мазмұнын жоғарыдағы тізімде мәтінмен бердік, ал әр түрін келесі мысалдарда көреміз. Толық тізім: W3 Schools: CSS Selectors.

    Ұрпақ селекторы

    Ұрпақ селекторын (descendant selector) қолданып, стильді тек нүктелі тізім (ul) ішіндегі тізім элементтеріне береміз. Сыртқы тізім нөмірленген (ol), оның ішінде тағы бір нүктелі тізім салынған:

    <!DOCTYPE html>
<html lang="en">
    <head>
        <title>Using Selectors</title>
        <style>
            ul li {
                color: blue;
            }
        </style>
    </head>
    <body>
        <ol>
            <li>foo</li>
            <li> bar
                <ul>
                    <li>hello</li>
                    <li>goodbye</li>
                    <li>hello</li>
                </ul>
            </li>
            <li>baz</li>
        </ol>

    </body>
<html>

    Нәтижеде тек ішкі тізімнің үш элементі көк болды, ал foo, bar және baz қара күйінде қалды. Себебі олар ul ішінде емес, ol ішінде тұр.

    Ойланып көріңіз: ol > li қызыл, ul li көк болса, қай элемент қандай түсті болады?

    Бір мезгілде екі ереже жазайық: ol > li { color: red; } және ul li { color: blue; }. foo, bar және baz - ol-дың тікелей балалары, сондықтан үшеуі қызыл. Ал hello, goodbye, hello - ul ішіндегі li, олардың тікелей атасы ul, ал ol емес, сондықтан бірінші ереже оларға тимейді, олар көк. (Олар bar элементінің ішінде тұрғандықтан қызылды мұрагерлікпен алар еді, бірақ тікелей берілген ul li ережесі мұрагерліктен күштірек.)

    <style>
    ol > li { color: red; }
    ul li { color: blue; }
</style>
<ol>
    <li>foo</li>
    <li> bar
        <ul>
            <li>hello</li>
            <li>goodbye</li>
            <li>hello</li>
        </ul>
    </li>
    <li>baz</li>
</ol>

    Атрибут селекторы

    Элементтерді оларға берілген атрибуттар бойынша да таңдауға болады, ол үшін төртбұрышты жақша қолданамыз. Мысалы, келесі сілтемелер тізімінде тек Amazon-ға апаратын сілтемені қызыл етеміз:

    <!DOCTYPE html>
<html lang="en">
    <head>
        <title>Using Selectors</title>
        <style>
            a[href="https://www.amazon.com/"] {
                color: red;
            }
        </style>
    </head>
    <body>
        <ol>
            <li><a href="https://www.google.com/">Google</a></li>
            <li><a href="https://www.amazon.com/">Amazon</a> </li>
            <li><a href="https://www.facebook.com/">Facebook</a></li>
        </ol>

    </body>
<html>

    Псевдокластар

    CSS элементтің түрін тұрақты өзгертіп қана қоймай, оны белгілі бір жағдайда өзгерте алады. Мысалы, батырманың үстіне меңзерді апарғанда түсі өзгеретін болсын. Ол үшін псевдокласс (pseudoclass) қолданамыз: ол ерекше жағдайларда қосымша стиль береді. Жазылуы: селектордан кейін қос нүкте қойып, жағдайдың атын жазамыз. Біздегі button:hover тек меңзер үстінде тұрғанда ғана жұмыс істейді:

    <!DOCTYPE html>
<html lang="en">
    <head>
        <title>Pseudoclasses</title>
        <style>
            button {
                background-color: red;
                width: 200px;
                height: 50px;
                font-size: 24px;
            }

            button:hover {
                background-color: green;
            }
        </style>
    </head>
    <body>
        <button>Button 1</button>
        <button>Button 2</button>
        <button>Button 3</button>

    </body>
<html>

    Көрсету терезесінде батырмалардың үстіне меңзерді апарыңыз: қызыл түс жасылға ауысады да, меңзерді алсаңыз, қайтадан қызыл болады. Псевдокластар туралы толығырақ: W3 Schools: Pseudo-classes.

    Бейімделгіш дизайн

    Қазір сайттарды тек компьютерден емес, смартфон мен планшеттен де көреді. Сондықтан сайт кез келген құрылғыда оқуға ыңғайлы болуы керек. Бұл - бейімделгіш дизайн (responsive design).

    Мұның бір жолы - көру аймағын (viewport) білу. Көру аймағы дегеніміз - пайдаланушы экраннан бір мезетте көріп тұрған бөлік. Әдепкіде көп веб-беттер көру аймағы кез келген құрылғыда бірдей деп есептейді, сондықтан көптеген (әсіресе ескі) сайттар телефонда ыңғайсыз болады: бет шағын экранға сыймай, жұрт қолмен үлкейтіп-кішірейтеді. Бет телефонда әлдеқайда жақсы көріну үшін HTML файлының head бөлігіне мына жолды қоссақ жеткілікті. Ол мобильді құрылғыға «үлкен қолдан жасалған көру аймағын емес, құрылғы енімен бірдей көру аймағын пайдалан» дейді:

    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    Екінші жол - медиа-сұраулар (media queries). Бұл - бет қалай көрсетілетініне қарай стильді өзгертетін тәсіл. Мысал ретінде экран белгілі бір өлшемге дейін кішірейгенде фонның түсін өзгертіп көрейік. Медиа-сұрауды @media деп бастап, жақшаның ішіне шартты жазамыз:

    <!DOCTYPE html>
<html lang="en">
    <head>
        <title>Screen Size</title>
        <style>
            @media (min-width: 600px) {
                body {
                    background-color: red;
                }
            }

            @media (max-width: 599px) {
                body {
                    background-color: blue;
                }
            }
        </style>
    </head>
    <body>
        <h1>Welcome to the page!</h1>
    </body>
</html>
    Терезенің енін өзгертіп көріңіз

    Көрсету терезесі беттің ені бойынша созылады: браузердің терезесін тарылтсаңыз (не телефонды бұрсаңыз), мысалдың шарты өзгеріп, түс қызылдан көкке ауысады. Ол үшін «▶ Көрсету» батырмасын қайта басу керек болуы мүмкін.

    Ойланып көріңіз: екі медиа-сұрау бірдей мезетте орындалса, қайсысы жеңеді?

    Мына кодты алайық: body { background-color: white; } және одан кейін @media (min-width: 600px) { body { background-color: lightgreen; } } және @media (max-width: 800px) { body { background-color: lightyellow; } }. Ені 900px болса, тек бірінші медиа-сұрау орындалады: фон ашық жасыл. Ені 500px болса, тек екінші орындалады: ашық сары. Ені 700px болса, екеуі де орындалады, ал айқындылығы бірдей ережелердің ішінде кейін жазылғаны жеңеді, демек фон ашық сары. Мұнда «каскадты» сөзінің мағынасы жатыр.

    Әртүрлі экранға бейімделудің тағы бір жолы - икемді блок (flexbox) деген CSS қасиеті. Ол сыймаған элементтерді келесі жолға оңай «орап» жібереді. Ол үшін барлық элементтерді контейнер ретінде қолданылатын div ішіне саламыз да, оған «ішіндегі элементтер үшін flexbox қолдан» деген стиль береміз. Орау құбылысы жақсырақ көрінсін деп, ішкі div-дерге де қосымша стиль қостық:

    <!DOCTYPE html>
<html lang="en">
    <head>
        <title>Screen Size</title>
        <style>
            #container {
                display: flex;
                flex-wrap: wrap;
            }

            #container > div {
                background-color: green;
                font-size: 20px;
                margin: 20px;
                padding: 20px;
                width: 200px;
            }
        </style>
    </head>
    <body>
        <div id="container">
            <div>Some text 1!</div>
            <div>Some text 2!</div>
            <div>Some text 3!</div>
            <div>Some text 4!</div>
            <div>Some text 5!</div>
            <div>Some text 6!</div>
            <div>Some text 7!</div>
            <div>Some text 8!</div>
            <div>Some text 9!</div>
            <div>Some text 10!</div>
            <div>Some text 11!</div>
            <div>Some text 12!</div>
        </div>
    </body>
</html>

    Терезені тарылтқанда жасыл блоктар қатарда сыймай қалғанда, бір-бірінен кейін келесі жолға түсіп отырады. Бұл flex-wrap: wrap қасиетінің жұмысы. Қарапайым div-дер қатарынан бірінің астына бірі тұрар еді, ал flexbox оларды өз енімен көлденең орналастырып, сыймағанын ғана төменге түсіреді.

    Бейімделуге арналған келесі әйгілі тәсіл - HTML торы (grid). Мұнда бағандардың енін, баған мен жолдардың арасындағы саңылауды анықтауға болады. Үшінші баған үшін auto жазғанымызға назар аударыңыз: ол «бетте қалған бос орынды түгел ал» дегенді білдіреді.

    <!DOCTYPE html>
<html lang="en">
    <head>
        <title>My Web Page!</title>
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <style>
            .grid {
                background-color: green;
                display: grid;
                padding: 20px;
                grid-column-gap: 20px;
                grid-row-gap: 10px;
                grid-template-columns: 200px 200px auto;
            }

            .grid-item {
                background-color: white;
                font-size: 20px;
                padding: 20px;
                text-align: center;
            }
        </style>
    </head>
    <body>
        <div class="grid">
            <div class="grid-item">1</div>
            <div class="grid-item">2</div>
            <div class="grid-item">3</div>
            <div class="grid-item">4</div>
            <div class="grid-item">5</div>
            <div class="grid-item">6</div>
            <div class="grid-item">7</div>
            <div class="grid-item">8</div>
            <div class="grid-item">9</div>
            <div class="grid-item">10</div>
            <div class="grid-item">11</div>
            <div class="grid-item">12</div>
        </div>
    </body>
</html>
    Ойланып көріңіз: Flexbox пен Grid-тің айырмашылығы неде?

    Flexbox элементтерді сыймаса келесі жолға орап, әр жолды өз мазмұнына қарай жасайды. Grid болса бағандардың енін алдын ала анықтап, барлық элементтерді дәл сол тор ұяшықтарына орналастырады. Үшінші бағанның auto болуы терезе кеңейген сайын сол бағанның да кеңейетінін білдіреді. Ал алғашқы екеуі 200px күйінде тұрақты қалады.

    Bootstrap

    Көріп отырсыз, CSS-ті қолмен жазу ұзақ жұмыс. Бақытымызға орай, басқа адамдар жазып қойған, сайт стилін одан да жеңілдететін кітапханалар бар. Курс бойы пайдаланатын әйгілі кітапханалардың бірі - Bootstrap. Оны кодымызға қосу үшін HTML файлының head бөлігіне бір жол жазсақ жеткілікті:

    Bootstrap стильдері интернеттегі сервермен жүктеледі, сондықтан бұл мысалдар интернет қосулы болғанда ғана дұрыс көрінеді. Желі болмаса, бөлімдер стильсіз, қарапайым мәтін күйінде шығады.

    Ойланып көріңіз: үш бағанның col-5, col-5, col-5 болса не болады?

    Sass (Синтаксисі тамаша стиль кестелері)

    Қайталауды азайтудың бірнеше жолын таптық: стильді бөлек файлға шығару, Bootstrap қолдану. Бірақ жақсартатын жерлер әлі бар. Мысалы, бірнеше элементтің стильдері әртүрлі, бірақ түсі бірдей болсын дейік. Кейін сол түсті өзгерткіміз келсе, оны бірнеше жерде түзетуге тура келеді, мұның жалықтыратыны анық.

    Sass (Syntactically Awesome Style Sheets) - CSS-ті тиімдірек жазуға мүмкіндік беретін тіл. Оның бір мүмкіндігі - айнымалылар (variables).

    Sass-пен жұмыс істегенде filename.scss кеңейтілімді жаңа файл жасаймыз. Онда айнымалыны былай жариялаймыз: атының алдына $ қойып, қос нүкте және мән жазамыз. Мысалы, $color: red деп жазсақ, color айнымалысы red мәніне тең болады. Айнымалыны $color деп қолданамыз. Міне, variables.scss файлының мысалы:

    $color: red;

ul {
    font-size: 14px;
    color: $color;
}

ol {
    font-size: 18px;
    color: $color;
}

    Мұны HTML файлымызға тікелей байлай алмаймыз, себебі браузерлердің көбі тек .css файлдарын таниды. Сондықтан компьютерімізге Sass бағдарламасын жүктеп алу керек. Содан кейін терминалға мынаны жазамыз:

    sass variables.scss:variables.css

    Бұл команда variables.scss файлын variables.css файлына компиляциялайды (аударады), ал HTML бетінен сол CSS файлына сілтеме жасауға болады. Үдерісті жылдамдату үшін мына команданы қолдануға болады:

    sass --watch variables.scss:variables.css

    Ол .scss файлында өзгеріс байқалған сайын .css файлын өздігінен жаңартып отырады. Компиляциядан кейінгі CSS-тің нәтижесін мына жерден көре аласыз (екі тізім де қызыл түсті):

    <style>
    ul { font-size: 14px; color: red; }
    ol { font-size: 18px; color: red; }
</style>
<ul><li>foo</li><li>bar</li></ul>
<ol><li>foo</li><li>bar</li></ol>

    Sass-тың келесі қуатты мүмкіндігі - стильді ұялап жазу (nesting). Бұрынғыдай селекторларды ұзақ жазбай, элементтің ішіне ішкі стильді жазамыз. Мысалы, тек div ішіндегі абзацтар мен нүктелі тізімдерге стиль бергіміз келсе, былай жазамыз:

    div {
    font-size: 18px;

    p {
        color: blue;
    }

    ul {
        color: green;
    }
}

    Компиляциядан кейін мынадай CSS-файл шығады. Мұны төмендегі батырмамен тікелей сынап көріңіз, абзац көк, ал тізім жасыл болады:

    div {
    font-size: 18px;
}

div p {
    color: blue;
}

div ul {
    color: green;
}

    Sass-тың тағы бір мүмкіндігі - мұрагерлік (inheritance). Ол бірнеше элемент ортақ қолдана алатын негізгі стильдер жиынын жасауға мүмкіндік береді. Ол үшін класс атының алдына % қойып, стиль жазамыз, кейін басқа стильдің басына @extend %classname деген жолды қосамыз. Мысалы, төмендегі кодта %message ішіндегі стиль барлық үш класқа қолданылады, ал нәтижесінде мынадай бет шығады:

    %message {
    font-family: sans-serif;
    font-size: 18px;
    font-weight: bold;
    border: 1px solid black;
    padding: 20px;
    margin: 20px;
}

.success {
    @extend %message;
    background-color: green;
}

.warning {
    @extend %message;
    background-color: orange;
}

.error {
    @extend %message;
    background-color: red;
}

    Мұны браузер тікелей түсінбейді, сондықтан компиляцияланған нәтижені қарайық. Sass ортақ стильді үш класқа бірдей тарата салады:

    <style>
    .success, .warning, .error {
        font-family: sans-serif;
        font-size: 18px;
        font-weight: bold;
        border: 1px solid black;
        padding: 20px;
        margin: 20px;
    }
    .success { background-color: green; }
    .warning { background-color: orange; }
    .error { background-color: red; }
</style>
<div class="success">Сәтті орындалды</div>
<div class="warning">Абайлаңыз</div>
<div class="error">Қате болды</div>
    Sass компьютерде орындалады

    Sass бағдарламасы браузерде емес, компьютеріңізде орнатылып, терминалда жұмыс істейді. Сондықтан .scss мысалдарын осы сайтта іске қосу мүмкін емес. Біз олардың қолмен компиляцияланған CSS нәтижесін көрсетіп отырмыз. Өз компьютеріңізде орнатып көру үшін: sass-lang.com/install.

    Бүгінгі мазмұн осымен аяқталды. Ал енді өз білімімізді тексереміз.

    Қорытынды

    • HTML - бет құрылымын сипаттайтын белгілеу тілі: элементтер, тегтер, атрибуттар; DOM - олардың ағаш тәрізді құрылымы.
    • Негізгі элементтер: тақырыптар (h1-h6), тізімдер (ul, ol, li), сілтеме (a), сурет (img + alt), кесте, форма (form, input).
    • CSS бетті безендіреді: стильді style атрибутымен, <style> тегімен не бөлек .css файлымен береміз; стиль ата-ана элементтен балаға мұрагерлікпен беріледі.
    • Селекторлар: элемент түрі, #id, .class, үтір, ұрпақ (ul li), тікелей бала (ol > li), атрибут (a[href=...]), псевдокласс (:hover). Қайшылықта айқындылық шешеді: жол ішіндегі стиль, id, class, элемент түрі.
    • Бейімделгіш дизайн: viewport мета-тегі, медиа-сұраулар (@media), Flexbox (display: flex, flex-wrap), Grid (grid-template-columns).
    • Bootstrap - дайын стильдер кітапханасы; 12 бағанды тор жүйесі (col-4, col-lg-3, col-sm-6).
    • Sass - CSS-ті ыңғайлы жазатын тіл: айнымалылар ($color), ұялау, мұрагерлік (%message, @extend); sass командасымен .scss файлы .css-ке компиляцияланады.

    Өзіңізді тексеріңіз

    1. Сурет жүктелмей қалса, оның орнына мәтін көрсететін img атрибуты қайсы?

    alt суреттің сипаттамасын сақтайды: сурет жүктелмесе немесе экранды дауыстап оқитын бағдарлама қолданылса, соны көрсетеді/айтады.

    2. Тақырыптың класы бойынша түсі қызыл, ал id бойынша көк деп жазылған. Жол ішіндегі style жоқ. Тақырып қандай түсті болады?

    Айқындылық тәртібі: жол ішіндегі стиль, id, class, элемент түрі. Id класстан күштірек, сондықтан көк түс жеңеді.

    3. ul li { color: blue; } ережесі қолданылса, ішкі нүктелі тізімі бар нөмірленген тізімде қай элементтер көк болады?

    Ұрпақ селекторы ul li тек ul ішінде орналасқан li элементтерін таңдайды. ol тікелей балалары көк болмайды.

    4. button:hover селекторы нені білдіреді?

    :hover - псевдокласс: ол элементке белгілі бір жағдайда (меңзер үстінде тұрғанда) қосымша стиль береді.

    5. <meta name="viewport" content="width=device-width, initial-scale=1.0"> жолының мақсаты қандай?

    Бұл жол болмаса, телефон өзін кең экран деп есептеп, бетті кішірейтіп көрсетеді. Мета-тег көру аймағының енін құрылғы еніне теңейді.

    6. display: flex; flex-wrap: wrap; қолданылған контейнерде элементтер қатарға сыймай қалса, не болады?

    Дәл осы flex-wrap: wrap қасиетінің міндеті: сыймаған элементтерді келесі жолға орау.

    7. Bootstrap-та col-lg-3 col-sm-6 класстары бар төрт элемент бір row-да тұр. Шағын экранда нәтиже қандай?

    Шағын экранда әр элемент 6 бағанды алады, 6 + 6 = 12, сондықтан бір жолға екі элемент сыяды. Ал үлкен экранда әрқайсысы 3 бағанды алып, 4 x 3 = 12 болғандықтан бір қатарда тұрады.

    8. Браузер .scss файлын неге тікелей оқи алмайды және не істеу керек?

    Sass - CSS-тен жоғары тіл: браузер оны түсінбейді. Алдымен sass variables.scss:variables.css секілді команданы орындап, CSS файлын аламыз, ал HTML-ге сол CSS-ті қосамыз.

    Алғышарт

    Лекциядан есіңізде болса, <form> тегімен HTML формасын жасап, оған <input> тегтері арқылы өрістер қоса аламыз. Курстың кейінгі аптасында форма деректерін қабылдайтын веб-қосымшаларды жазуды үйренеміз. Ал бұл жобада формалар бар веб-серверге, дәлірек айтқанда Google-дың серверіне деректер жібереді.

    Google-да іздеу жасағанда не болады? Анықтап көрейік. google.com сайтына кіріп, іздеу өрісіне «Harvard» деп жазып, «Google Search» батырмасын басыңыз. Күтілгендей, «Harvard» бойынша нәтижелер шығады. Енді браузердің мекенжай жолына (URL) қараңыз. Ол https://www.google.com/search деп басталады: бұл Google сайтындағы іздеуге арналған жол (route). Одан кейін ? және қосымша ақпарат тұр.

    URL-дегі бұл қосымша ақпаратты сұрау жолы (query string) деп атайды. Ол GET параметрлерінің тізбегінен тұрады, әр параметрдің аты мен мәні бар. Сұрау жолы әдетте былай жазылады:

    field1=value1&field2=value2&field3=value3...

    Мұндағы = параметрдің атын мәнінен бөледі, ал & параметрлерді бір-бірінен ажыратады. Бұл параметрлер - форма ақпаратты веб-серверге жіберу тәсілі: форманың деректері URL-ге кодталады.

    Google нәтижелері бетінің URL-ін қарап шығыңыз (мәтін редакторына көшіріп қойсаңыз ыңғайлырақ). Онда Google-дың бірнеше параметр қолданып жатқанын көресіз. Іздеген сөзіміз «Harvard» дегенді қайдан көресіз? Бір параметр q=Harvard болуы керек, яғни Google-дағы іздеу параметрінің аты q (бәлкім, «query» сөзінің қысқартылғаны).

    Басқа параметрлер Google-ға пайдалы мәлімет береді, бірақ іздеу үшін тек q міндетті. Өзіңіз тексеріп көріңіз: https://www.google.com/search?q=Harvard мекенжайына өтіңіз, барлық басқа параметрлер жоқ, бірақ нәтижелер бірдей болады!

    Осы біліммен Google басты бетінің фронтендін қайта жасай аламыз. Төмендегі кодты index.html деп аталатын HTML файлына қойып, браузерде ашыңыз (не төмендегі «Дайын код» бөлімінен жүктеп алыңыз):

    <!DOCTYPE html>
<html lang="en">
    <head>
        <title>Search</title>
    </head>
    <body>
        <form action="https://www.google.com/search">
            <input type="text" name="q">
            <input type="submit" value="Google Search">
        </form>
    </body>
</html>

    Бұл бетті ашқанда өте қарапайым HTML формасын көресіз. «Harvard» сияқты сұрау жазып, «Google Search» батырмасын басыңыз - Google-дың нәтижелер бетіне өтесіз! (Сайттағы көрсету терезесінде батырма жұмыс істемейді, оны өз компьютеріңізде сынаңыз.)

    Бұл қалай жұмыс істеді? Форманың action атрибуты браузерге «форма жіберілгенде деректерді https://www.google.com/search мекенжайына жібер» дейді. Ал аты q болатын input өрісін қосқандықтан, пайдаланушы өрісте не жазса, сол GET параметрі ретінде URL-ге қосылады.

    Сіздің тапсырмаңыз - осы сайтты кеңейтіп, Google Search-тің өз фронтендін жасау: Google интерфейсін зерттеп, ол қандай GET параметрлерін күтетінін анықтап, керекті HTML мен CSS қосасыз.

    Талаптар

    Сайт мына талаптарға сай болуы тиіс:

    1. Беттер. Сайтта кемінде үш бет болуы керек: кәдімгі Google Search беті (оның аты міндетті түрде index.html), Google Image Search беті және Google Advanced Search беті. Google Search бетінің оң жақ жоғарғы бұрышында Image Search пен Advanced Search беттеріне апаратын сілтемелер болсын. Қалған екі бетте оң жақ жоғарғы бұрышта Google Search бетіне қайтатын сілтеме болсын.
    2. Мәтін бойынша іздеу (Text Search). Google Search бетінде пайдаланушы сұрау жазып, «Google Search» батырмасын басқанда, сол сұраудың Google нәтижелері бетіне өтуі керек. Google-дағыдай, іздеу жолағы ортада, бұрыштары дөңгеленген болуы керек. Іздеу батырмасы да ортада, жолақтың астында тұруы тиіс.
    3. Сурет бойынша іздеу (Image Search). Google Image Search бетінде пайдаланушы сұрау жазып, іздеу батырмасын басқанда, сол сұраудың Google суреттер нәтижелері бетіне өтуі керек.
    4. Кеңейтілген іздеу (Advanced Search). Google Advanced Search бетінде пайдаланушы мына төрт өріс үшін мән енгізе алуы керек (Google-дың 2026 жылы өзгертілмес бұрынғы кеңейтілген іздеу параметрлерінен алынды; тек мына өрістерді қолданыңыз):
      • Find pages with... «all these words:»
      • Find pages with... «this exact word or phrase:»
      • Find pages with... «any of these words:»
      • Find pages with... «none of these words:»
    5. Көрнекі үйлесімділік (Visual Consistency). Google-дың Advanced Search бетіндегідей, төрт нұсқа тігінен қатар тұруы, барлық мәтін өрістері солға туралануы керек. Google-дың өз CSS-іне сәйкес, «Advanced Search» батырмасы көк түсті, ақ мәтінді болсын. Оны басқанда, пайдаланушы өз сұрауының іздеу нәтижелері бетіне өтуі керек.
    6. I'm Feeling Lucky. Google Search басты бетіне «I'm Feeling Lucky» батырмасын қосыңыз. Google-дағыдай, оны басқанда пайдаланушы кәдімгі нәтижелер бетін айналып өтіп, сұраудың бірінші нәтижесіне тікелей өтуі керек. Қайта бағыттау туралы хабарлама шығуы мүмкін: уайымдамаңыз, бұл Google-дың қауіпсіздік мүмкіндігінің күтілген салдары.
    7. Эстетика (Aesthetics). Өзіңіз жазған CSS Google-дың өз эстетикасына ұқсауы тиіс.
    Кеңес

    Параметр аттарын анықтау үшін Google-да әртүрлі іздеулер жасап, URL-ді қарап шығыңыз. Браузердегі «Network» (желі) инспекторы да көмектеседі (Google Chrome-да: View -> Developer -> Developer Tools): онда браузер Google-ға жасайтын сұраулардың егжей-тегжейі көрінеді.

    Кез келген input элементінің (type мәні text, submit, number не басқа болсын) name және value атрибуттары болуы мүмкін: форма жіберілгенде олар GET параметрлеріне айналады.

    Google-дың өз HTML-ін қарау да пайдалы: көп браузерде бетті тінтуірдің оң жағымен басып, «View Page Source» таңдауға болады.

    Пайдаланушыға көрінбейтін және өзгертуге болмайтын өріс қосу үшін «hidden» input өрісін қолданыңыз.

    Тексеру

    Ойланып көріңіз: форма action және name="q" дегенді қайдан біледі?

    Форма еш нәрсені «білмейді»: біз оған action арқылы деректерді қайда жіберетінін, ал name арқылы параметрдің атын айтамыз. Google серверінің өз келісімі бойынша іздеу сұрауы q деген атпен келеді, сондықтан біз де дәл солай атаймыз. Атты query деп өзгертсек, Google сұрауды тани алмай, бос іздеу бетін көрсетер еді.
