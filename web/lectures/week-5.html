    JavaScript

    Енді бет браузердің өзінде тіріледі: JavaScript арқылы түймелерге жауап беретін, мәтінді өзгертетін, мәлімет сақтайтын және API-дан деректер алатын сайттар жасаймыз.

    ▶ Түпнұсқа бейнежазба мен материалдар (ағылшынша)
    Бұл апта не туралы

    Осы уақытқа дейін біз беттерді HTML мен CSS-пен жасадық, Git-пен жұмыс істедік, Python мен Django арқылы сервер жағында код жаздық. Бүгін браузердің өзінде жұмыс істейтін жаңа тіл келеді: JavaScript. Мұнда мысалдардың көбін бетте-ақ «▶» батырмасымен іске қосып көре аласыз: батырманы басыңыз, түймелерді басыңыз, кодты өзгертіп көріңіз.

    Бұл бет сөзбе-сөз аударма емес. Лектор аудиторияда қалай түсіндірсе, біз де солай баяндаймыз: мағынасы мен кодтың бәрі түпнұсқадағыдай, тек әңгіме ана тілімізде жүреді.

    Кіріспе

    Қысқаша қайталап өтейік. Біз қарапайым веб-беттерді HTML мен CSS арқылы жасауды үйрендік. Git пен GitHub арқылы кодтағы өзгерістерді қадағалап, басқалармен бірге жұмыс істеуді білдік. Python тілімен танысып, Django арқылы веб-қосымшалар жаза бастадық және Django модельдері арқылы мәліметті сайтымызда сақтауды үйрендік.

    Бүгін біз жаңа бағдарламалау тілін қосамыз: JavaScript. Python-ды білсеңіз, көп нәрсе таныс көрінеді, тек жазылуы сәл басқаша. Ал ең басты айырмашылық - код қайда жұмыс істейтінінде.

    JavaScript

    Бірнеше лекция бұрынғы суретке қайта оралайық. Көпшілік онлайн әрекеттерде клиент (client), яғни сіздің браузеріңіз, серверге HTTP сұранысын (HTTP Request) жібереді, ал сервер HTTP жауабын (HTTP Response) қайтарады.

    Осы уақытқа дейін Django-мен жазған барлық Python кодымыз сервер жағында жұмыс істеді. Ал JavaScript кодты клиент жағында орындауға мүмкіндік береді. Яғни код жұмыс істеп жатқанда серверге ешқандай сұраныс жібермей-ақ, бет өзгере алады. Сондықтан сайттарымыз әлдеқайда интерактивті болады: батырманы бастыңыз - бет бірден жауап береді, интернеттің кідірісін күтпейміз.

    Бетімізге JavaScript қосу үшін HTML-дің ішіне бір жұп <script> тегін қоямыз. Бұл браузерге «осы екі тегтің арасындағы нәрсенің бәрі JavaScript коды, пайдаланушы сайтқа кірген кезде оны орындап жібер» деген белгі. Бірінші бағдарламамыз шамамен мынадай болады:

    alert('Hello, world!');

    alert функциясы пайдаланушыға хабарлама көрсетеді, ол хабарламаны жабуға болады. Мұның нақты HTML құжатының ішінде қалай тұратынын көрейік. Мынау - сәл JavaScript қосылған қарапайым бет:

    <!DOCTYPE html>
<html lang="en">
    <head>
        <title>Hello</title>
        <script>
            alert('Hello, world!');
        </script>
    </head>
    <body>
        <h1>Hello!</h1>
    </body>
</html>

    Бетті ашқанда браузер алдымен осы хабарламаны шығарады, сосын ғана бетті көрсетеді.

    Сайттағы мысалдар туралы

    Сайттағы мысалдар қорғалған «құмсалғышта» (sandbox) жұмыс істейді, ал мұнда alert тереземен шығатын хабарламалар рұқсат етілмеген. Сондықтан оларды іске қосатын жерде нәтижені бетке немесе консольге шығарамыз. Түпнұсқа alert кодын әрқашан көрсетіп отырамыз, ал «тірі» нұсқасы сәл өзгеше болады. Нағыз браузерде өз файлыңызда alert міндетті түрде жұмыс істейді.

    Қане, осы мысалдың «тірі» бауыры: тек терезе орнына console.log қолданамыз. Бұл функция хабарламаны браузердің консоліне шығарады (консоль туралы кейінірек айтамыз). Төмендегі батырманы басыңыз:

    console.log('Hello, world!');

    Оқиғалар

    JavaScript-ті веб-бағдарламалауға өте ыңғайлы ететін бір қасиеті - ол оқиғаға негізделген бағдарламалауды (Event-Driven Programming) қолдайды. Бұл не? Бағдарламалау парадигмасы, оның орталығында оқиғаларды анықтау және оқиға болған кезде жасалатын әрекеттер тұр.

    Оқиға (event) деп дерлік кез келген нәрсені айтуға болады: түймені басу, меңзерді жылжыту, жауап теру, беттің жүктелуі. Пайдаланушының веб-бетпен жасайтын барлық әрекеті дерлік оқиға. Мектептегі қоңырауды елестетіңіз: оқушылар қоңырау соғылғанда ғана орындарынан тұрады. JavaScript-те де солай: біз оқиға тыңдаушыларын (event listeners) қоямыз, олар белгілі бір оқиғаны күтіп тұрады да, ол болғанда ғана біз берген кодты орындайды.

    Жоғарыдағы JavaScript-ті hello деп аталатын функцияға (function) айналдырудан бастайық:

    function hello() {
    alert('Hello, world!')
}

    Енді осы функцияны түйме басылған сайын іске қосайық. Ол үшін бетімізде HTML түймесін жасаймыз да, оған onclick атрибутын береміз. Бұл атрибут браузерге «түйме басылғанда не істеу керек» деген нұсқау береді:

    <button onclick="hello()">Click Here</button>

    Міне осылай JavaScript кодының бір бөлігін белгілі бір оқиға болғанша күте тұруға болады. Функцияның өзі беттің жүктелуімен бірге жазылып қояды, бірақ орындалуы тек түйме басылғанда басталады. Төмендегі нұсқада alert орнына нәтижені бетке жазамыз. Қалай жазылатынын келесі бөлімдерде толық талдаймыз, әзірге түймені басып көріңіз:

    <button onclick="hello()">Click Here</button>
<p id="msg"></p>

<script>
    function hello() {
        document.querySelector('#msg').innerHTML = 'Hello, world!';
    }
</script>

    Айнымалылар

    JavaScript - Python, C немесе бұрын жұмыс істеген кез келген басқа тіл сияқты бағдарламалау тілі. Сондықтан онда да айнымалылар (variables) сияқты таныс құралдар бар. JavaScript-те мән беру үшін үш кілт сөз бар:

    • var: айнымалыны жаһандық (глобал) түрде анықтайды;
    var age = 20;
    • let: айнымалының көрінетін аймағын ағымдағы блокпен (мысалы, функция немесе цикл) шектейді;
    let counter = 1;
    • const: өзгермейтін мәнді (тұрақтыны) анықтайды.
    const PI = 3.14;

    Айырмашылықты өз көзімізбен көрейік. Мына кодты іске қосып, нәтижесін болжап көріңіз: if блогының ішінде жарияланған айнымалыларға блоктан тыс қол жеткізе аламыз ба?

    var a = 1;
let b = 1;
if (true) {
    var a = 2;     // var: блоктан тыс да көрінеді, сол a-ны өзгертеді
    let b = 2;     // let: бұл - блок ішіндегі басқа b
}
console.log(a);
console.log(b);

const PI = 3.14;
try {
    PI = 3;
} catch (e) {
    console.log('const-ты өзгертуге болмайды:', e.name);
}
    Ойланып көріңіз: a мен b неге әртүрлі шықты?

    Алдымен болжап көріңіз. var блокты «елемейді»: ішіндегі var a = 2 сыртқы a-ның өзін өзгертеді, сондықтан 2 шығады. Ал let b = 2 тек if блогының ішінде өмір сүреді, сыртқы b бұрынғыдай 1 күйінде қалады. Қазіргі кодта көбіне let пен const қолданады, себебі олардың мінезін болжау оңай.

    Айнымалыны қолданудың мысалы ретінде санауышты (counter) сақтайтын бетті қарайық:

    <!DOCTYPE html>
<html lang="en">
    <head>
        <title>Count</title>
        <script>
            let counter = 0;
            function count() {
                counter++;
                alert(counter);
            }
        </script>
    </head>
    <body>
        <h1>Hello!</h1>
        <button onclick="count()">Count</button>
    </body>
</html>

    Түймені басқан сайын counter бір-бірден артады да, жаңа мән хабарламада көрсетіледі. Мұнда counter функцияның сыртында тұр, сондықтан әр шақырылғанда нөлден басталмайды, мәні есте қалады. Бірақ alert терезелері тез жалықтырады, сондықтан келесі бөлімде оны бетке жазуды үйренеміз.

    querySelector

    alert арқылы хабарлама көрсетуден басқа, JavaScript беттегі элементтерді өзгертуге де мүмкіндік береді. Ол үшін алдымен document.querySelector деген функциямен танысуымыз керек. Ол DOM-нан (құжат объектілік моделі, Document Object Model) элементтерді іздеп, тауып береді. Мысалы, тақырыпты алу үшін былай жазамыз:

    let heading = document.querySelector('h1');

    Табылған элементті өзгерту үшін оның innerHTML қасиетін өзгертеміз:

    heading.innerHTML = `Goodbye!`;

    Python-дағыдай JavaScript-те де шарттарды (conditions) қолдана аламыз. Мысалы, тақырыпты әрдайым Goodbye! етіп қоймай, Hello! мен Goodbye! арасында ауыстырып тұрғымыз келді делік. Бет мынадай болады. Бір нәрсеге назар аударыңыз: JavaScript-те екі нәрсені салыстыру үшін === қолданамыз. Бұл - қатаң салыстыру, ол мәндердің түрінің де бірдей екенін тексереді. Мүмкін болған жерде әрдайым === қолданған дұрыс.

    console.log(5 == "5");    // true: JavaScript "5" жолын санға айналдырып салыстырады
console.log(5 === "5");   // false: сан мен жол - әртүрлі түр
console.log(5 === 5);     // true

    Енді тақырыпты ауыстыратын бетті өзіңіз басып көріңіз:

    <!DOCTYPE html>
<html lang="en">
    <head>
        <title>Count</title>
        <script>
            function hello() {
                const header = document.querySelector('h1');
                if (header.innerHTML === 'Hello!') {
                    header.innerHTML = 'Goodbye!';
                }
                else {
                    header.innerHTML = 'Hello!';
                }
            }
        </script>
    </head>
    <body>
        <h1>Hello!</h1>
        <button onclick="hello()">Click Here</button>
    </body>
</html>

    DOM-ды өзгерту

    DOM-ды өзгертудің осы идеясымен санауыш бетімізді жақсартайық. Енді alert орнына санды тақырыптың өзіне жазамыз:

    <!DOCTYPE html>
<html lang="en">
    <head>
        <title>Count</title>
        <script>
            let counter = 0;
            function count() {
                counter++;
                document.querySelector('h1').innerHTML = counter;
            }
        </script>
    </head>
    <body>
        <h1>0</h1>
        <button onclick="count()">Count</button>
    </body>
</html>

    Бетті одан сайын қызықты етуге болады: санауыш он санына еселі болған сайын хабарлама көрсетейік. Хабарламада мәтінді бапталған күйде қалыптастыру керек. JavaScript-те мұны үлгі литералдар (template literals) арқылы жасаймыз. Олар үшін бүкіл өрнекті кері тырнақшаға (`) аламыз, ал орынбасатын мәндерді $ белгісі мен ирек жақшаның ішіне жазамыз. Python-дағы f"..." жолдарына өте ұқсас. count функциясын былай өзгертеміз:

    function count() {
    counter++;
    document.querySelector('h1').innerHTML = counter;

    if (counter % 10 === 0) {
        alert(`Count is now ${counter}`)
    }
}

    Мұнда % - қалдық операторы: counter % 10 === 0 санауыш 10-ға қалдықсыз бөлінгенде орындалады. Үлгі литералды және қалдықты alert-сіз-ақ өз көзіңізбен көріңіз:

    let counter = 0;
for (let i = 0; i < 25; i++) {
    counter++;
    if (counter % 10 === 0) {
        console.log(`Count is now ${counter}`);
    }
}

    Енді осы беттің дизайнын жақсартудың бірнеше жолын қарастырайық. Алдымен: CSS-те «инлайн» стильден қашқанымыз сияқты, мүмкіндігінше инлайн JavaScript-тен да қашуымыз керек. Санауыш мысалында мұны былай жасаймыз: button тегінен onclick атрибутын алып тастаймыз да, орнына түйменің onclick қасиетін өзгертетін бір жол жазамыз.

    document.querySelector('button').onclick = count;

    Назар аударыңыз: мұнда count функциясын жақша қойып шақырып тұрған жоқпыз, тек атын атадық. Бұл «функцияны түйме басылғанда ғана шақыр» дегенді білдіреді. Бұл Python сияқты JavaScript те функционалдық бағдарламалауды (functional programming) қолдайтындықтан жұмыс істейді: функцияны да басқа мән сияқты қолдануға болады.

    Ойланып көріңіз: onclick = count мен onclick = count() қандай айырмашылық бар?

    Болжап көріңіз. count - функцияның өзі, оны «кейін, түйме басылғанда шақыр» деп беріп отырмыз. count() - функцияны дәл қазір шақыру, ал onclick-ке сол шақырудың нәтижесі (мұнда бос мән) беріледі. Нәтижесінде санауыш бет жүктелгенде бір-ақ рет артып, түйме басқанда ештеңе болмай қалады.

    Бірақ тек осы өзгерістің өзі жеткіліксіз. Мұны браузердің консолінен (console) көруге болады:

    Біз document.querySelector('button') деп іздегенде, JavaScript ештеңе таппады. Себебі бет жүктелуге аз да болса уақыт кетеді, ал біздің код түйме әлі салынбай жатып жұмыс істеп кеткен. Төмендегі мысалда бұл қатені ойдағыдай қайталаймыз: бұл «бет» әлі бос, түйме жоқ, сондықтан іздеу null қайтарады:

    function count() {
    console.log('басылды');
}
// Түйме әлі жоқ болғандағы жағдай:
document.querySelector('button').onclick = count;

    Кәдімгі браузер консолінде бұл қате шамамен мынадай көрінеді:

    Uncaught TypeError: Cannot set properties of null (setting 'onclick')

    Мұны шешу үшін кодтың бет толық жүктелгеннен кейін ғана орындалатынын көрсетеміз. Ол үшін addEventListener функциясын қолданамыз. Ол екі аргумент алады:

    1. тыңдайтын оқиға (мысалы, 'click');
    2. оқиға анықталғанда орындалатын функция (мысалы, жоғарыдағы hello).

    Бүкіл мазмұн жүктелгеннен кейін ғана код орындалуы үшін мынаны жазамыз:

    document.addEventListener('DOMContentLoaded', function() {
    // Some code here
});

    Жоғарыда біз анонимді функцияны (anonymous function) қолдандық: бұл ешқашан атау берілмейтін функция. Оған атау керек емес, себебі оны тек осы жерде бір-ақ рет қолданамыз. Осының бәрін жинасақ, JavaScript кодымыз мынадай болады:

    let counter = 0;

function count() {
    counter++;
    document.querySelector('h1').innerHTML = counter;

    if (counter % 10 === 0) {
        alert(`Count is now ${counter}`)
    }
}

document.addEventListener('DOMContentLoaded', function() {
    document.querySelector('button').onclick = count;
});

    Мұның толық жұмыс істейтін нұсқасы мынау. alert орнына тақырыптың астындағы жолға хабарлама жазамыз, 10-ға дейін санап көріңіз:

    Local Storage

    Біздің осы кезге дейінгі барлық сайттарымыздағы бір нәрсені байқадыңыз ба? Бетті қайта жүктеген сайын бүкіл ақпарат жоғалады. Тақырыптың түсі қайтадан қара болады, санауыш нөлге түседі, тапсырмалардың бәрі өшіп қалады. Кейде бізге дәл осы керек, бірақ басқа жағдайларда пайдаланушы сайтқа қайта кіргенде пайдалана алатындай ақпаратты сақтағымыз келеді.

    Мұны істеудің бір жолы - Local Storage (жергілікті сақтау орны, local storage): ақпаратты пайдаланушы браузерінде сақтап, кейін оған қайта қол жеткізу. Ақпарат кілт-мән жұптары жиынтығы түрінде сақталады, Python сөздігіне өте ұқсас. Local storage-ті қолдану үшін екі негізгі функция керек:

    • localStorage.getItem(key): берілген кілті бар жазбаны local storage-тен іздеп, сол кілтке сәйкес мәнді қайтарады;
    • localStorage.setItem(key, value): local storage-ке жазба қояды, кілтті жаңа мәнмен байланыстырады.

    Осы жаңа функциялардың көмегімен санауышты қалай жаңартатынымызды көрейік! Төмендегі кодта:

    // Check if there is already a value in local storage
if (!localStorage.getItem('counter')) {

    // If not, set the counter to 0 in local storage
    localStorage.setItem('counter', 0);
}

function count() {
    // Retrieve counter value from local storage
    let counter = localStorage.getItem('counter');

    // update counter
    counter++;
    document.querySelector('h1').innerHTML = counter;

    // Store counter in local storage
    localStorage.setItem('counter', counter);
}

document.addEventListener('DOMContentLoaded', function() {
    // Set heading to the current value inside local storage
    document.querySelector('h1').innerHTML = localStorage.getItem('counter');
    document.querySelector('button').onclick = count;
});

    Мұнда бір ұсақ нәрсе бар: кілті жоқ жазбаны сұрасақ, getItem null қайтарады, ал null шартта жалған болып саналады. Сондықтан !localStorage.getItem('counter') «мұндай жазба әлі жоқ па?» деген сұрақ болады. Сайттың құмсалғышында браузердің нағыз localStorage қоймасына рұқсат жоқ, сондықтан төмендегі нұсқаның басына қайта жүктеуді имитациялайтын шағын қойма қостық. Сақталған санауыш мен кәдімгі айнымалыны салыстырыңыз: «Бетті қайта жүктеу» түймесін басқанда кәдімгі айнымалы нөлге түседі, ал қоймадағы мән қалады:

    <h1 id="stored">0</h1>
<p>Жоғарғы сан - local storage-те, төменгі - кәдімгі айнымалыда.</p>
<h2 id="plain">0</h2>
<button id="plus">Count</button>
<button id="reload">Бетті қайта жүктеу</button>

    const store = (() => {

    API-лер

    JavaScript объектілері

    JavaScript объектісі (JavaScript Object) Python сөздігіне өте ұқсас: ол да кілт-мән жұптарын сақтауға мүмкіндік береді. Мысалы, Гарри Поттерді бейнелейтін объект жасай аламыз:

    let person = {
    first: 'Harry',
    last: 'Potter'
};

    Объектінің бөліктеріне тік жақшалар (person['first']) немесе нүкте (person.first) арқылы қол жеткізіп, оларды өзгерте аламыз. Консольде мұны өзіңіз сынаңыз. Төменде дәл осы қимылдарды жасап көрелік:

    let person = {
    first: 'Harry',
    last: 'Potter'
};

console.log(person.first);        // нүкте арқылы
console.log(person['last']);      // жақша арқылы

person.first = 'Hermione';        // мәнді өзгерту
person.age = 17;                  // жаңа кілт қосу

console.log(person);

    JavaScript объектілерінің ең пайдалы жағы - мәліметті бір сайттан екіншісіне жіберу, әсіресе API-лармен жұмыс істегенде. API (Application Programming Interface, қосымшаны бағдарламалау интерфейсі) - екі түрлі қосымшаның бір-бірімен құрылымдалған түрде сөйлесу тәсілі.

    Мысалы, біздің қосымшамыз Google Maps-тен, Amazon-нан немесе ауа райы қызметінен ақпарат алғысы келуі мүмкін. Мұны сол қызметтің API-ына сұраныс жасау арқылы істейміз, ол бізге құрылымдалған мәліметті жібереді, көбіне JSON (JavaScript Object Notation, JavaScript объект белгілеуі) пішімінде. Мысалы, ұшу рейсі JSON түрінде былай көрінуі мүмкін:

    {
    "origin": "New York",
    "destination": "London",
    "duration": 415
}

    JSON-дағы мәндер тек жолдар мен сандар болуы міндетті емес. Біз тізімдерді, тіпті басқа JavaScript объектілерін де сақтай аламыз:

    {
    "origin": {
        "city": "New York",
        "code": "JFK"
    },
    "destination": {
        "city": "London",
        "code": "LHR"
    },
    "duration": 415
}

    JSON - жай ғана мәтін. Оны JavaScript объектісіне айналдыру үшін JSON.parse, ал кері айналдыру үшін JSON.stringify қолданамыз. API-дан келген жауапты біз осылай «ашамыз» (кейін response.json() дәл осыны істейді):

    const text = '{"origin": {"city": "New York", "code": "JFK"}, "destination": {"city": "London", "code": "LHR"}, "duration": 415}';

const flight = JSON.parse(text);
console.log(flight.origin.city);
console.log(flight.destination.code);
console.log(flight.duration / 60);

console.log(JSON.stringify({ origin: 'Almaty', duration: 270 }));

    Валюта бағамы

    API-ларды қосымшаларымызда қалай қолдануға болатынын көрсету үшін, екі валюта арасындағы айырбас бағамын табатын қосымша жасайық. Жаттығу барысында Еуропалық орталық банктің бағам API-ын (European Central Bank's Exchange Rate API) қолданатын боламыз. Сайтына кірсеңіз, API құжаттамасын көресіз: API-мен жұмысты әдетте дәл құжаттамадан бастаймыз. API-ды мына мекенжайға кіріп сынауға болады: https://api.exchangeratesapi.io/latest?base=USD. Бұл бетке кірсеңіз, АҚШ долларының басқа көптеген валюталарға қатысты бағамын JSON түрінде көресіз. URL-дағы GET параметрін USD-дан кез келген басқа валюта кодына ауыстырып, басқа бағамдар ала аласыз.

    Желі керек мысалдар

    Бұл лекциядағы fetch мысалдары сыртқы серверге сұраныс жібереді, сондықтан сайттың қорғалған ортасында оларды іске қоспаймыз. Нәтижені терминал блоктарымен көрсетеміз. Қосымша: exchangeratesapi.io қызметі кейінгі жылдары API-кілт (API key) талап ете бастады, сондықтан өз компьютеріңізде жоғарыдағы мекенжай кілтсіз жұмыс істемеуі мүмкін. Бірақ идея өзгермейді, ал соңында желісіз-ақ жұмыс істейтін «жасанды сервермен» толық интерактив нұсқа беріп отырмыз.

    Бұл API-ды қосымшада қалай қолдануға болатынын көру үшін, жаңа currency.html файлын жасап, оны JavaScript файлына байлаймыз, бірақ body-ді бос қалдырамыз:

    <!DOCTYPE html>
<html lang="en">
    <head>
        <title>Currency Exchange</title>
        <script src="currency.js"></script>
    </head>
    <body></body>
</html>

    Енді біз AJAX (Asynchronous JavaScript And XML, асинхронды JavaScript және XML) деген нәрсені қолданамыз. Ол беттің жүктелуі аяқталғаннан кейін де сыртқы беттерден ақпарат алуға мүмкіндік береді. Бұл үшін HTTP сұранысын жібере алатын fetch функциясын қолданамыз. fetch уәде (promise) қайтарады. Уәденің егжей-тегжейіне мұнда тоқталмаймыз, бірақ оны «бір кезде келетін мән, бірақ міндетті түрде дәл қазір емес» деп елестетуге болады. Сенімді досыңыз «ертең хабарлаймын» деп уәде бергендей: хабар келгенше сіз өз ісіңізбен айналысасыз. Уәдемен жұмыс істеу үшін оның .then қасиетіне жауап (response) келгенде не істеу керегін сипаттаймыз. Төмендегі үзінді жауапты консольге шығарады:

    document.addEventListener('DOMContentLoaded', function() {
    // Send a GET request to the URL
    fetch('https://api.exchangeratesapi.io/latest?base=USD')
    // Put response into json form
    .then(response => response.json())
    .then(data => {
        // Log data to the console
        console.log(data);
    });
});

    Консольде шамамен мынадай нәрсе көрінеді (бағамдар мысал үшін, шын мәндер күн сайын өзгереді):

    {base: "USD", date: "2020-07-06", rates: {CAD: 1.3584, GBP: 0.7981, JPY: 107.38, EUR: 0.8873, ...}}

    Жоғарыдағы кодтағы маңызды нәрсе: .then аргументі әрдайым функция. response мен data деген айнымалыларды жасап жатқандай көрінгенімен, бұлар - екі анонимді функцияның параметрлері ғана. Сұранысты жібергеннен кейін код күтіп тұрмайды, жауап келгенде ғана бұл функциялар шақырылады. Мұны шағын модельде көріңіз:

    // fetch жауабының орнына: 500 мс кейін келетін уәде
const promise = new Promise(resolve => {
    setTimeout(() => resolve({ rates: { EUR: 0.887 } }), 500);
});

console.log('1. Сұраныс жіберілді');
promise.then(data => {
    console.log('3. Жауап келді, EUR =', data.rates.EUR);
});
console.log('2. Бұл жол жауапты күтпей-ақ шығады!');

    Мәліметті жай консольге шығарудың орнына, JavaScript-пен экранға хабарлама шығара аламыз. Мына кодты қараңыз:

    document.addEventListener('DOMContentLoaded', function() {
    // Send a GET request to the URL
    fetch('https://api.exchangeratesapi.io/latest?base=USD')
    // Put response into json form
    .then(response => response.json())
    .then(data => {

        // Get rate from data
        const rate = data.rates.EUR;

        // Display message on the screen
        document.querySelector('body').innerHTML = `1 USD is equal to ${rate.toFixed(3)} EUR.`;
    });
});

    Бет ашылған бойда мынадай мәтін шығады (toFixed(3) санды үтірден кейін 3 таңбаға дейін дөңгелектейді):

    1 USD is equal to 0.887 EUR.

    Енді сайтты сәл интерактивті етейік: пайдаланушы қай валютаны көргісі келетінін өзі таңдасын. HTML-ді пайдаланушы валюта енгізе алатындай етіп өзгертумен бастаймыз:

    <!DOCTYPE html>

        <script src="currency.js"></script>
    </head>

    Енді JavaScript-ті өзгертеміз: ол форма жіберілгенде ғана жұмыс істейтін және пайдаланушы енгізген мәнді ескеретін болсын. Сондай-ақ қателерді тексеруді де қосамыз:

    document.addEventListener('DOMContentLoaded', function() {
    document.querySelector('form').onsubmit = function() {

        // Send a GET request to the URL
        fetch('https://api.exchangeratesapi.io/latest?base=USD')
        // Put response into json form
        .then(response => response.json())
        .then(data => {
            // Get currency from user input and convert to upper case
            const currency = document.querySelector('#currency').value.toUpperCase();

            // Get rate from data
            const rate = data.rates[currency];

            // Check if currency is valid:
            if (rate !== undefined) {
                // Display exchange on the screen
                document.querySelector('#result').innerHTML = `1 USD is equal to ${rate.toFixed(3)} ${currency}.`;
            }
            else {
                // Display error on the screen
                document.querySelector('#result').innerHTML = 'Invalid Currency.';
            }
        })
        // Catch any errors and log them to the console
        .catch(error => {
            console.log('Error:', error);
        });
        // Prevent default submission
        return false;
    }
});

Жоғарыда data.rates[currency] деп тік жақшамен қол жеткіздік, себебі валюта коды айнымалыда тұр (data.rates.currency деп жазсақ, JavaScript «currency» деген атты іздер еді). Ал .catch желі қатесі сияқты кез келген ақау болса, оны консольге шығарады, қосымша құлап қалмайды.

    Қорытынды

    Бүгін біз JavaScript-пен таныстық. Негізгі идея: код енді браузерде жұмыс істейді, сондықтан бет серверге қайта жүгірместен-ақ өзгере алады. Мына ұғымдарды үйрендік:

    • JavaScript клиент жағында жұмыс істейді; кодты <script> тегінің ішіне не src арқылы бөлек .js файлына жазамыз;
    • оқиғаға негізделген бағдарламалау: оқиға тыңдаушылары (onclick, addEventListener, DOMContentLoaded, onsubmit, onchange, onkeyup);
    • айнымалылар: var, let, const; қатаң салыстыру ===;
    • document.querySelector пен querySelectorAll арқылы DOM элементтерін табу, innerHTML, value, style, dataset, createElement, append арқылы оларды өзгерту;
    • үлгі литералдар (`...${x}...`), анонимді және көрсеткілі функциялар, forEach;
    • консоль және console.log арқылы қатені іздеу;
    • интервалдар: setInterval (және clearInterval);
    • local storage: getItem/setItem арқылы мәлімет бетті қайта жүктегеннен кейін де сақталады;
    • JavaScript объектілері және JSON, API-лар, fetch, уәде (.then, .catch) және AJAX арқылы бет жүктелгеннен кейін сыртқы мәлімет алу.

    Өзіңізді тексеріңіз

    1. button.onclick = count; мен button.onclick = count(); жолдарының айырмашылығы неде?

    Жақшасыз count функцияның өзі (мән ретінде), оны браузер кейін шақырады. Жақшамен count() функция дереу орындалады.

    2. Мына кодтың шығысы қандай? console.log(5 === "5", 5 == "5");

    === түрді де салыстырады: сан мен жол әртүрлі, сондықтан false. Ал == жолды санға айналдырып, true береді. Сондықтан === қолданған дұрыс.

    3. Скрипт <head>-те тұр және ішінде document.querySelector('button').onclick = count; бар, бірақ DOMContentLoaded жоқ. Консольде TypeError шықты. Неге?

    Браузер бетті жоғарыдан төмен оқиды. Скрипт түймеден бұрын орындалса, іздеу ештеңе таппайды. Шешім: кодты DOMContentLoaded оқиғасының ішіне салу.

    4. Жаңа браузерде localStorage.getItem('score') шақырылды, бұрын ештеңе сақталмаған. Нәтиже қандай?

    Кілт жоқ болса, getItem null қайтарады. Сол себепті if (!localStorage.getItem('counter')) тексеруі «әлі жоқ па?» дегенді білдіреді.

    5. fetch(url).then(response => response.json()) жолында response деген не?

    .then аргументі әрдайым функция. Параметрдің атын өзіміз таңдаймыз, оған сұраныстың нәтижесі жауап келгенде беріледі.

    6. Мына код не істейді? const PI = 3.14; PI = 3;

    const тұрақты анықтайды: оған қайта мән беруге тырысу қате береді. Өзгеретін мән үшін let қолданамыз.

    7. HTML-де <button data-color="red"> бар. Түйменің button айнымалысында тұрғанда, JavaScript-те "red" мәніне қалай қол жеткіземіз?

    data-ЕРКІН_АТ атрибуттары элементтің dataset қасиетінде dataset.ЕРКІН_АТ түрінде көрінеді. style.color элементтің CSS түсін өзгертеді, ал button.data-color JavaScript-те қате өрнек (азайту амалы).

    8. setInterval(count, 1000); жолы қандай нәтиже береді?

    Екінші аргумент - миллисекундпен өлшенген кідіріс. 1000 мс = 1 секунд. Қайталауды тоқтату үшін clearInterval қолданамыз.

    Жаттығулар: JavaScript функциялары

    Сайттың өз жаттығулары, ресми тапсырма емес

    Төмендегі алты жаттығуды біз осы сайт үшін қостық: олар JavaScript-тің «DOM-сыз» бөлігін (функциялар, массивтер, объектілер, жолдар) жаттықтырады. Бұл CS50 ресми problem set-і емес. Кодыңызды .js файлына жазып, әр автотексерушіге жүктеңіз (немесе қойыңыз): тексеруші оны браузерде, ауыр жұмысты бөлек ағында (Web Worker) орындап, нәтижелерді күтілетін мәнмен салыстырады. Шексіз цикл жазып қойсаңыз да, ол қауіпсіз тоқтатылады.

    Оңай

    capitalize (бас әріппен бастау)

    capitalize(word) функциясын жазыңыз: жолдың бірінші әрпін бас әріпке, қалғандарын кіші әріпке айналдырып, жаңа жолды қайтарсын. Бос жол берілсе, бос жол қайтарсын. Мысалы, capitalize("jAVAsCRIPT") нәтижесі "Javascript".

    Кеңес

    Жолдың бірінші символы word[0], қалғаны word.slice(1). Бас әріпке .toUpperCase(), кіші әріпке .toLowerCase() айналдырады. Бос жолда word[0] - undefined, оған .toUpperCase() шақырсаңыз қате болады, сондықтан алдымен word.length тексеріңіз.

    Оңай

    sum және average (массив)

    sum(numbers) массивтегі сандардың қосындысын қайтарсын (бос массив үшін 0). average(numbers) орташа мәнді қайтарсын (бос массив үшін 0).

    Кеңес

    Қосындыны жинау үшін let total = 0; жариялап, for (const n of numbers) { total += n; } циклін қолданыңыз. average үшін sum функциясын қайта пайдаланыңыз, бірақ нөлге бөлмеу үшін бос массивті алдын ала тексеріңіз.

    Орташа

    countWords (сөздерді санау)

    countWords(text) жолдағы әр сөздің неше рет кездескенін санап, объект қайтарсын. Сөздер бос орынмен бөлінеді; бас және кіші әріп бірдей саналады (кілттер кіші әріппен жазылады). Мысалы, countWords("to be or not to be") нәтижесі {to: 2, be: 2, or: 1, not: 1}. Бос жол үшін бос объект {} қайтарыңыз.

    Кеңес

    Жолды text.toLowerCase().split(" ") арқылы массивке бөліңіз. Содан кейін әр сөз үшін counts[word] = (counts[word] || 0) + 1 деп жазыңыз: кілт жоқ болса, counts[word] - undefined, ал || оны 0-мен ауыстырады. Қатарынан тұрған артық бос орындар бос жол ("") шығарады: оларды өткізіп жіберіңіз.

    Орташа

    isPalindrome (палиндром)

    isPalindrome(text) жол солдан оңға да, оңнан солға да бірдей оқылса true, әйтпесе false қайтарсын. Регистр мен әріп/цифр емес таңбалар (бос орын, үтір, қос нүкте) ескерілмейді. Мысалы, "A man, a plan, a canal: Panama" палиндром.

    Кеңес

    Алдымен жолды тазалаңыз: text.toLowerCase().replace(/[^a-z0-9]/g, "") тек латын әріптері мен цифрларын қалдырады. Содан кейін жолды кері айналдырыңыз: .split("").reverse().join(""), және түпнұсқамен салыстырыңыз (===).

    Орташа

    oldest және byCity (объектілер массиві)

    Әр адам - объект: {name: "Aigerim", age: 19, city: "Almaty"}. oldest(people) ең үлкен адамның атын (name) қайтарсын (массив бос болса null). byCity(people) адамдарды қала бойынша топтап, {Almaty: ["Aigerim", "Dana"], Astana: ["Bauyrzhan"]} түріндегі объект қайтарсын (аттар массивтегі ретпен).

    Кеңес

    oldest үшін ең үлкенді есте сақтайтын айнымалы алып, массивті бір рет айналып шығыңыз. byCity үшін қала бойынша объектіде массив ашыңыз: if (!(p.city in groups)) groups[p.city] = [];, сосын groups[p.city].push(p.name).

    Оңай

    countdown (console.log және цикл)

    countdown(n) функциясын жазыңыз: ол n-нен 1-ге дейін кері санайды (әр сан жеке console.log жолында), ең соңында Start! деп шығарады. Файлдың соңында countdown(3) шақырыңыз: тексеруші console.log шығысын (3, 2, 1, Start!) салыстырады.

    Кеңес

    for (let i = n; i > 0; i--) { console.log(i); } циклі n-нен 1-ге дейін санайды (0 шықпайды). Циклден кейін console.log("Start!") жазыңыз.

    Таратылатын кодта project3 деген Django жобасы бар, оның ішінде жалғыз mail қосымшасы жатыр.

    Алдымен миграцияларды жасап, қолданғаннан кейін, веб-серверді іске қосу үшін python manage.py runserver орындаңыз. Серверді браузерде ашып, «Register» сілтемесі арқылы жаңа аккаунтқа тіркеліңіз. Бұл жобада жіберетін және алатын хаттарыңыздың бәрі толығымен сіздің дерекқорыңызда сақталады (олар нағыз пошта серверлеріне жіберілмейді), сондықтан кез келген пошта мекенжайын (мысалы, foo@example.com) және парольді таңдай аласыз: нағыз мекенжай болуы міндетті емес.

    Кіргеннен кейін сізді поштаның Inbox (Кіріс) бетіне апарады, бірақ бұл бет әзірге негізінен бос. «Sent» (Жіберілгендер) және «Archived» (Мұрағат) жәшіктеріне өтетін түймелерді басып көріңіз: олар да әзірге бос. «Compose» (Жазу) түймесін басыңыз: жаңа хат жазатын формаға өтесіз. Бірақ әр түйме басқанда жаңа маршрутқа өтпейміз және жаңа веб-сұраныс жасамаймыз: бұл қосымшаның бәрі бір беттен тұрады, интерфейсті JavaScript басқарады. Бұл қалай жұмыс істейтінін таратылатын кодтан қарастырайық.

    mail/urls.py файлын ашып, әдепкі маршрут views.py-дағы index функциясын жүктейтінін байқаңыз. views.py-ды ашып, index функциясына қараңыз: пайдаланушы жүйеге кірген болса, ол mail/inbox.html шаблонын көрсетеді. Шаблон mail/templates/mail/inbox.html файлында тұр. Беттің body-інде алдымен h2 элементінде пайдаланушының электрондық мекенжайы көрсетілетінін көресіз. Одан кейін қосымша ішінде жылжуға арналған түймелер тізбегі бар. Төменірек беттің екі негізгі бөлімі бар, әрқайсысы div арқылы анықталған. Біріншісі (id-і emails-view) пошта жәшігінің мазмұнын қамтиды (әзірге бос). Екіншісі (id-і compose-view) пайдаланушы хат жазатын форманы қамтиды. Жоғарғы түймелер осы көріністерді таңдап көрсетіп, жасыруы керек: мысалы, compose түймесі emails-view-ді жасырып, compose-view-ді көрсетуі тиіс; inbox түймесі керісінше compose-view-ді жасырып, emails-view-ді көрсетуі керек.

    Бұл қалай істеледі? inbox.html файлының төменгі жағында mail/inbox.js JavaScript файлы қосылғанын көріңіз. Оны mail/static/mail/inbox.js жолынан ашып қарайық. Беттің DOM мазмұны жүктелгенде, әр түймеге оқиға тыңдаушылары қосылатынын байқайсыз. Мысалы, inbox түймесі басылғанда, load_mailbox функциясы 'inbox' аргументімен шақырылады; ал compose түймесі басылғанда compose_email функциясы шақырылады. Бұл функциялар не істейді? compose_email алдымен emails-view-ді жасырады (оның style.display қасиетін none етіп) және compose-view-ді көрсетеді (style.display қасиетін block етіп). Содан кейін хат жазу формасындағы барлық енгізу өрістерін (алушының мекенжайы, тақырып, хаттың мәтіні) бос жолға '' теңестіріп, тазалайды. Яғни «Compose» түймесін басқан сайын сізге таза форма көрсетіледі: мұны формаға бірдеңе теріп, Inbox-қа ауысып, қайта Compose-ге оралып, тексере аласыз.

    Ал load_mailbox функциясы алдымен emails-view-ді көрсетіп, compose-view-ді жасырады. Оның сонымен бірге аргументі бар: пайдаланушы көргісі келетін пошта жәшігінің аты. Бұл жобада үш жәшіктен тұратын клиент жасайсыз: inbox (кіріс), sent (жіберілген хаттардың бәрі) және archive (бір кездері кіріс жәшігінде болған, бірақ мұрағатталған хаттар). Демек, load_mailbox аргументі осы үш мәннің бірі болады, ал функция таңдалған жәшіктің атын (бірінші әрпін бас әріпке айналдырып) emails-view-дің innerHTML-ін өзгерту арқылы көрсетеді. Сондықтан браузерде жәшік атын таңдағанда, DOM-да сол жәшіктің (бас әріппен жазылған) атын көресіз.

    Әрине, бұл қосымша әлі аяқталмаған. Барлық жәшіктер әзірге жәшіктің атын (Inbox, Sent, Archive) ғана көрсетеді, ал хаттарды көрсетпейді. Нақты бір хаттың мазмұнын көретін көрініс әлі жоқ. Хат жазу формасына мәтін енгізуге болады, бірақ хатты жіберетін түйме ештеңе істемейді. Міне, осы жерде сіздің рөліңіз басталады!

    API

    Хаттарды алу, жіберу және жаңартуды осы қосымшаның API-ы арқылы жасайсыз. Біз бүкіл API-ды сіз үшін жазып қойдық (және төменде құжаттадық), сондықтан оны JavaScript кодыңызда қолдана аласыз. (Шын мәнінде, бұл жоба үшін барлық Python кодын біз жаздық. Жобаны тек HTML мен JavaScript жазу арқылы аяқтай аласыз.)

    Қосымша мына API маршруттарын қолдайды:

    GET /emails/<str:mailbox>

    /emails/<mailbox> мекенжайына GET сұранысын жіберсеңіз (мұндағы <mailbox> - inbox, sent немесе archive), сол жәшіктегі барлық хаттар тізімі (JSON түрінде) кері хронологиялық ретпен (жаңасы бірінші) қайтарылады. Мысалы, /emails/inbox мекенжайына GET жіберсеңіз, екі хатты бейнелейтін мынадай JSON жауап алуыңыз мүмкін:

    [
    {
        "id": 100,
        "sender": "foo@example.com",
        "recipients": ["bar@example.com"],
        "subject": "Hello!",
        "body": "Hello, world!",
        "timestamp": "Jan 2 2020, 12:00 AM",
        "read": false,
        "archived": false
    },
    {
        "id": 95,
        "sender": "baz@example.com",
        "recipients": ["bar@example.com"],
        "subject": "Meeting Tomorrow",
        "body": "What time are we meeting?",
        "timestamp": "Jan 1 2020, 12:00 AM",
        "read": true,
        "archived": false
    }
]

    Әр хат өзінің id-ін (бірегей идентификатор), sender (жіберушінің мекенжайы), recipients (алушылар массиві), subject (тақырып), body (мәтін) және timestamp (уақыт) жолдарын, сондай-ақ хаттың оқылғанын (read) және мұрағатталғанын (archived) көрсететін екі логикалық мәнді анықтайтынын байқаңыз.

    Мұндай мәндерге JavaScript-те қалай қол жеткіземіз? Есіңізде болса, JavaScript-те веб-сұраныс жасау үшін fetch қолданамыз. Сондықтан мына JavaScript коды:

    fetch('/emails/inbox')
.then(response => response.json())
.then(emails => {
    // Print emails
    console.log(emails);

    // ... do something else with emails ...
});

    /emails/inbox мекенжайына GET сұранысын жасайды, шыққан жауапты JSON-ға айналдырады, содан кейін хаттар массивін сізге emails айнымалысында береді. Бұл мәнді браузер консоліне console.log арқылы шығара аласыз (кіріс жәшігінде хат болмаса, бұл бос массив болады), немесе массивпен басқа бірдеңе істей аласыз.

    Назар аударыңыз: жарамсыз жәшікті (inbox, sent, archive емес басқа нәрсені) сұрасаңыз, орнына {"error": "Invalid mailbox."} JSON жауабын аласыз.

    GET /emails/<int:email_id>

    /emails/email_id мекенжайына GET сұранысын жіберсеңіз (мұндағы email_id - хаттың бүтін санды идентификаторы), хаттың JSON көрінісі қайтарылады:

    {
        "id": 100,
        "sender": "foo@example.com",
        "recipients": ["bar@example.com"],
        "subject": "Hello!",
        "body": "Hello, world!",
        "timestamp": "Jan 2 2020, 12:00 AM",
        "read": false,
        "archived": false
}

    Хат жоқ болса, немесе пайдаланушының оған қолжетімділігі болмаса, маршрут орнына 404 Not Found қатесін және {"error": "Email not found."} JSON жауабын қайтарады.

    Мысалы, 100-ші нөмірлі хатты алу үшін мынадай JavaScript жазуға болады:

    fetch('/emails/100')
.then(response => response.json())
.then(email => {
    // Print email
    console.log(email);

    // ... do something else with email ...
});

    POST /emails

    Әзірге хаттарды қалай алуды көрдік: не жәшіктегі барлық хаттарды, не жалғыз хатты. Хат жіберу үшін /emails маршрутына POST сұранысын жібересіз. Маршрут үш мәлімет талап етеді: recipients (хат жіберілетін барлық пайдаланушылардың үтірмен бөлінген жолы), subject жолы және body жолы. Мысалы, мынадай JavaScript жаза аласыз:

    fetch('/emails', {
  method: 'POST',
  body: JSON.stringify({
      recipients: 'baz@example.com',
      subject: 'Meeting time',
      body: 'How about we meet tomorrow at 3pm?'
  })
})
.then(response => response.json())
.then(result => {
    // Print result
    console.log(result);
});

    Хат сәтті жіберілсе, маршрут 201 күй кодымен және {"message": "Email sent successfully."} JSON жауабымен жауап береді.

    Назар аударыңыз: кемінде бір алушы болуы керек. Ол болмаса, маршрут орнына 400 күй кодымен және {"error": "At least one recipient required."} JSON жауабымен жауап береді. Барлық алушылар осы нақты веб-қосымшада тіркелген жарамды пайдаланушылар болуы тиіс: егер baz@example.com мекенжайына хат жіберуге тырыссаңыз, бірақ мұндай пайдаланушы жоқ болса, {"error": "User with email baz@example.com does not exist."} JSON жауабын аласыз.

    PUT /emails/<int:email_id>

    Қажет болатын соңғы мүмкіндік - хатты оқылған/оқылмаған немесе мұрағатталған/мұрағатталмаған деп белгілеу. Ол үшін (GET емес) PUT сұранысын /emails/<email_id> мекенжайына жібересіз, мұндағы email_id - өзгертпек болған хаттың идентификаторы. Мысалы, мынадай JavaScript коды:

    fetch('/emails/100', {
  method: 'PUT',
  body: JSON.stringify({
      archived: true
  })
})

    100-ші нөмірлі хатты мұрағатталған деп белгілейді. PUT сұранысының денесі {archived: false} болса, хатты мұрағаттан шығарады. Сол сияқты {read: true} немесе {read: false} болуы мүмкін: хатты сәйкесінше оқылған немесе оқылмаған деп белгілейді.

    Осы төрт API маршрутын қолданып (жәшіктегі барлық хатты алу, жалғыз хатты алу, хат жіберу және бар хатты жаңарту), бұл жобаны аяқтауға қажеттінің бәріне ие боласыз!

    Талаптар

    JavaScript, HTML және CSS қолданып, бір беттік қосымшадағы пошта клиентін inbox.js файлының ішінде аяқтаңыз (басқа немесе қосымша файлдарда емес: бағалау кезінде тек inbox.js қарастырылады). Мына талаптарды орындауыңыз керек:

    • Send Mail (хат жіберу): пайдаланушы хат жазу формасын жіберген кезде, хатты шынымен жіберетін JavaScript коды қосыңыз.
      • /emails мекенжайына POST сұранысын жасап, recipients, subject және body мәндерін беру керек шығар.
      • Хат жіберілгеннен кейін пайдаланушының sent жәшігін жүктеңіз.
    • Mailbox (жәшік): пайдаланушы Inbox, Sent немесе Archive жәшігіне кірген кезде, тиісті жәшікті жүктеңіз.
      • Белгілі бір жәшіктің хаттарын сұрау үшін /emails/<mailbox> мекенжайына GET сұранысы керек шығар.
      • Жәшікке кірген кезде, қосымша алдымен сол жәшіктегі ең соңғы хаттарды API-дан сұрауы керек.
      • Жәшікке кірген кезде, беттің жоғарғы жағында жәшіктің аты көрінуі керек (бұл бөлік сіз үшін жасалған).
      • Әр хат өз қорабында (мысалы, шекарасы бар <div> ретінде) көрсетілуі керек: онда хаттың кімнен екені, тақырыбы және уақыты көрсетіледі.
      • Хат оқылмаған болса, ол ақ фонмен көрінуі керек. Хат оқылған болса, сұр фонмен көрінуі керек.
    • View Email (хатты көру): пайдаланушы хатты басқанда, ол сол хаттың мазмұнын көретін көрінісіне өтуі керек.
      • Хатты сұрау үшін /emails/<email_id> мекенжайына GET сұранысы керек шығар.
      • Қосымша хаттың жіберушісін, алушыларын, тақырыбын, уақытын және мәтінін көрсетуі керек.
      • Хатты көрсету үшін inbox.html файлына қосымша div қосқыңыз келуі мүмкін (emails-view және compose-view қатарына). Навигация опциялары басылғанда, дұрыс көріністерді көрсетіп/жасыратындай етіп кодыңызды жаңартуды ұмытпаңыз.
      • DOM-ға өзіңіз қосқан HTML элементіне оқиға тыңдаушысын қалай қосуға болатыны туралы «Кеңестер» бөліміндегі нұсқауды қараңыз.
      • Хат басылғаннан кейін, оны оқылған деп белгілеңіз. Хаттың оқылған-оқылмағанын жаңарту үшін /emails/<email_id> мекенжайына PUT сұранысын жіберуге болатынын есіңізде ұстаңыз.
    • Archive and Unarchive (мұрағаттау және мұрағаттан шығару): пайдаланушыларға өздері алған хаттарды мұрағаттауға және мұрағаттан шығаруға мүмкіндік беріңіз.
      • Inbox-тағы хатты қарап отырғанда, пайдаланушыға оны мұрағаттайтын түйме көрсетілуі керек. Archive-тегі хатты қарап отырғанда, оны мұрағаттан шығаратын түйме көрсетілуі керек. Бұл талап Sent жәшігіндегі хаттарға қолданылмайды.
      • Хатты мұрағатталған/мұрағатталмаған деп белгілеу үшін /emails/<email_id> мекенжайына PUT сұранысын жіберуге болатынын есіңізде ұстаңыз.
      • Хат мұрағатталғаннан немесе мұрағаттан шығарылғаннан кейін, пайдаланушының кіріс жәшігін (inbox) жүктеңіз.
    • Reply (жауап беру): пайдаланушыларға хатқа жауап беруге мүмкіндік беріңіз.
      • Хатты қарап отырғанда, пайдаланушыға хатқа жауап беретін «Reply» түймесі көрсетілуі керек.
      • Пайдаланушы «Reply» түймесін басқанда, оны хат жазу формасына апару керек.
      • Форманы алдын ала толтырыңыз: recipient өрісі бастапқы хатты кім жібергені болсын.
      • Тақырып жолын алдын ала толтырыңыз. Егер бастапқы хаттың тақырыбы foo болса, жаңа тақырып Re: foo болуы керек. (Егер тақырып бұрыннан Re: деп басталса, оны қайта қосудың қажеті жоқ.)
      • Хаттың мәтінін мынадай жолмен алдын ала толтырыңыз: "On Jan 1 2020, 12:00 AM foo@example.com wrote:", содан кейін бастапқы хаттың мәтіні.

    Кеңестер

    • HTML элементін жасап, оған оқиға өңдеушісін қосу үшін мынадай JavaScript жаза аласыз:
    const element = document.createElement('div');
element.innerHTML = 'This is the content of the div.';
element.addEventListener('click', function() {
    console.log('This element has been clicked!')
});
document.querySelector('#container').append(element);

    Бұл код жаңа div элементін жасайды, оның innerHTML-ін орнатады, div басылғанда белгілі бір функцияны орындайтын оқиға өңдеушісін қосады, содан кейін оны id-і container болатын HTML элементіне қосады. (Бұл код id-і container болатын HTML элементі бар деп есептейді: querySelector аргументін өзіңіз элемент қосқыңыз келетін элементке ауыстыруыңыз керек шығар.) Төмендегі нұсқада осыны өзіңіз сынап көріңіз:

    <div id="container"></div>

<script>
    const element = document.createElement('div');
    element.innerHTML = 'This is the content of the div. Мені басыңыз!';
    element.style.border = '1px solid gray';
    element.style.padding = '8px';
    element.style.cursor = 'pointer';
    element.addEventListener('click', function() {
        element.innerHTML = 'This element has been clicked!';
        element.style.background = 'lightgray';
    });
    document.querySelector('#container').append(element);
</script>
    • Стильді қажет болса, mail/static/mail/styles.css файлын өңдеп, қосымша үшін қажетті CSS-ті қосуға болады.
    • Егер сізде JavaScript массиві болса, оның әр элементі арқылы forEach көмегімен өтуге болатынын ұмытпаңыз.
    • Әдетте POST және PUT сұраныстары үшін Django сайтаралық сұранысты жалғандау (CSRF) шабуылдарынан қорғану үшін CSRF токенін талап ететінін есіңізде ұстаңыз. Бұл жоба үшін біз API маршруттарын әдейі CSRF-тен босатып қойдық, сондықтан токен қажет емес. Бірақ нағыз жобада мұндай осалдықтардан әрдайым қорғанған дұрыс!

    Тексеру
    • Таратылатын код жүктелді, миграциялар жасалып қолданылды, python manage.py runserver жұмыс істейді және аккаунт тіркелді.

    • View Email: хатты басқанда жіберуші, алушылар, тақырып, уақыт және мәтін көрінеді (қосымша div), хат PUT арқылы оқылған деп белгіленеді.
    • Archive/Unarchive: Inbox-тағы хатта «мұрағаттау», Archive-тегі хатта «мұрағаттан шығару» түймесі бар (Sent-те жоқ); әрекеттен кейін inbox жүктеледі.
    • Reply: «Reply» түймесі хат жазу формасын ашады; алушы, Re: тақырыбы (қайталанбайды) және "On ... wrote:" жолы мен бастапқы мәтін алдын ала толтырылған.
