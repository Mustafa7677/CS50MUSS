    Кіріспе

    Бұл CS50, 6-апта. Бүгін C-дан Python атты бағдарламалау тіліне көшеміз. Бұл өткен апталар курстың мақсатына кірмеген деген сөз емес. C-ны үйреніп, курс соңында компьютер мен бағдарламалау тілдерінің қалай жұмыс істейтінін төменнен жоғары қарай түсінесіз. Python, Java, C++, Swift сияқты тілдердің бүгінде не істеп жатқанын жақсырақ түсінесіз.

    Scratch-тан бастағанымызды еске түсірейік. Онда алғашқы бағдарлама «hello, world» өте оңай болды: мысыққа «hello, world» деп айтқызу үшін екі пазл бөлігін жалғау жеткілікті еді. Сосын C-ға өттік. Бірінші аптада бірінші жолды, көптеген жақшалар мен фигуралы жақшаларды елемей, тек printf-ке назар аударыңыз дедік. Бүгін мұның бәрі жойылып, «hello, world» шығару үшін тек бір жол қалады:

    print("hello, world")

    Python-ды жоғары деңгейлі тіл (higher-level language) дейміз. Ондаған жылдар бойы адамдар бұрынғы тілдерден не жақсы, не нашар жұмыс істегенін үйренді. Компьютерлер жылдамдады, жады көбейді. Сондықтан сол ресурстардың бір бөлігін компьютерге көбірек жұмыс тапсыруға жұмсауға мүмкіндік туды. Синтаксиске соншалықты педантты болудың, көп код жазудың қажеті жоқ. Сізді қызықтыратын есептерді шешуге, өнімдер жасауға әлдеқайда тез кірісуге болады.

    Нақты өмірде курстан кейін бағдарламалауды жалғастырсаңыз, кейде жұмысқа C, кейде Python, кейде мектепте мүлдем оқымаған басқа тіл ыңғайлы болады. Бұл аптаның қызықты жері: курстан кейін 1–2, бәлкім бірнеше тілдің «дәмін татып», жаңа тілдерді өз бетіңізше үйрене алатын боласыз. Нақты өмірде бұрынғы тілдермен ұқсастықтарды, әлі де қолданылатын парадигмаларды танисыз. Синтаксис әрине өзгереді, бірақ оны Google-дан не ChatGPT сияқты AI-ден сұрайсыз. Жұмыс істеуге жеткілікті білсеңіз, ақырында идеяларға және шешкіңіз келген есептерге назар аударасыз.

    Сондықтан бұл аптаның тапсырмалары мен курстың қалған бөлігінің бір мақсаты — пернетақта алдында өзіңізді жайсыз сезінуге үйрену. Python туралы білуге керектің бәрін айтпаймыз. Сіз құжаттамаға, үйрекке жүгініп, ақырында жаңа тілді өзіңізге өзіңіз үйретесіз.

    Python бағдарламасын іске қосу

    C-да алғашқы апталарда make hello жазатынбыз. make «сиқырлы» түрде hello.c файлын тауып, hello атты бағдарлама жасайтын, сосын ./hello арқылы іске қосатынбыз. Кейін make шын мәнінде clang компиляторын -o, файл аты және -lcs50 сияқты аргументтермен шақыратынын көрдік.

    Бүгіннен бастап Python кодын жазып, іске қосу үшін жай ғана python бағдарламасын шақырамыз. clang C компиляторы болғандай, Python тек бағдарламалау тілі ғана емес, сол тілді түсінетін бағдарлама да. Ол hello.py файлындағы кодты іске қосады. Ол clang-тан сәл басқаша жұмыс істейді, оны да жақын арада көреміз.

    $ code hello.py
$ python hello.py
hello, world

    hello.py-де #include да, int main(void) да жоқ, тек print("hello, world"). make жоқ, тек python hello.py, компиляция қадамы жоқ. Ал бұл кодта C-дан тағы қандай айырмашылықтар бар?

    • F жоқ: функция printf емес, адамға түсініктірек print. f «formatted» дегенді білдіретін, бірақ бұл мүмкіндік бәрібір бар.
    • \n жоқ, бірақ курсор келесі жолда тұр. Адамдар уақыт өте жаңа жолдың көбіне керек екенін байқады, сондықтан ол әдепкі бойынша автоматты түрде беріледі.
    • Нүктелі үтір жоқ: жолдың соңында ой аяқталады, оны анық белгілеудің қажеті жоқ.

    Бір бағдарламада-ақ көп ерекшелік бар, бірақ біз тітіркендіретін нәрселердің бәрінен құтылдық. Енді бағдарламаның мәніне назар аудара аламыз.

    Демо: 5-тапсырма Python-да

    Python-дағы жоғары деңгейлі тілдердің бәрі сияқты, кейбір есептерді әлдеқайда жылдам шешуге болады. Қызық үшін 5-есептер жинағын, яғни ең жылдам емле тексергішті, Python-да жазайық. Терминалды екіге бөлдік: сол жақта C-дағы ресми шешім, оң жақта Python нұсқасы. speller.py алдын ала дайын, ал dictionary.py әзірге бос:

    words = set()


def check(word):
    return word.lower() in words


def load(dictionary):
    with open(dictionary) as file:
        words.update(file.read().splitlines())
    return True


def size():
    return len(words)


def unload():
    return True
    • words = set(): жаһандық айнымалы, Python-дағы set (жиын) объектісі. Ол көп сөзді қайталанбай сақтайды. Python оны өзі басқарады, яғни 5-тапсырмада өзіміз жазған хэш-кестені іске асырады.
    • def check(word):: функция анықтау үшін Python-да жаңа def кілт сөзі қолданылады. Аргументтің типі де, функцияның қайтару типі де көрсетілмейді.
    • return word.lower() in words: «сөздің кіші әріпті нұсқасы жиында бар ма?» деген логикалық өрнек. Бар болса True, жоқ болса False.
    • with open(dictionary) as file:: C-дағы fopen-нің орнына Python-да open. Файлға file деген ат береміз.
    • file.read().splitlines(): файлды басынан аяғына дейін, солдан оңға оқып, әр жолдың соңындағы жаңа жол таңбасы бойынша бөледі. Сонда сөздіктегі барлық сөзбен жиын толтырылады.
    • Python-да жұмыс аз болғандықтан, бәрі дұрыс болды деп, True қайтарамыз (Python-да бас әріппен жазылады).
    • size: жиынның ұзындығын len арқылы қайтарамыз.
    • unload: malloc қолданбадық, Python жадты өзі басқарады. Сондықтан жай ғана True.

    Бар болғаны 19 жол, оның көбі бос жол! Енді салыстырайық:

    $ python speller.py texts/holmes.txt      (Python)
...
TIME IN TOTAL:        1.87

$ ./speller texts/holmes.txt              (C)
...
TIME IN TOTAL:        1.32

    Python шешімі бір-екі минутта жазылды, бірақ ол баяуырақ: 1.87 секунд, ал C 1.32 секунд. Жарты секунд аз сияқты, бірақ бұл жалпы уақыттың едәуір үлесі. Бұл — алғашқы таңдау: Python-да адамның уақыты әлдеқайда аз жұмсалып, жазу оңай болғанымен, код баяуырақ жұмыс істеуі мүмкін.

    Компиляция және интерпретация Себебі мынада: C компиляцияланады. Сондықтан make мен clang-ты іске қосып, 0 мен 1-ді, яғни машиналық кодты орындаймыз. Ал Python-да компьютер кодыңызды әдетте интерпретациялайды (interprets): оны жоғарыдан төменге, солдан оңға оқиды. Бұл бір тілде сөйлемейтін екі адамның арасында тұрып, бір тілден екінші тілге баяу аударып беретін адамға ұқсайды. Сондықтан Python қолданғанда біраз қосымша шығын бар. Бірақ Python қауымдастығы бұл мәселенің үстінде көптен жұмыс істеп келеді. Интерпретатор кодыңызды «жартылай жасырын» түрде байткодқа (bytecode) компиляциялап, соны орындайды, бұл оны қайта-қайта интерпретациялаудан тиімдірек.

    Демо: сүзгілер Python-да

    4-тапсырмадағы көпір суретіне Python арқылы бұлдырату сүзгісін қолданайық:

    from PIL import Image, ImageFilter

before = Image.open("bridge.bmp")
after = before.filter(ImageFilter.BoxBlur(10))
after.save("out.bmp")

    PIL (Python Image Library) кітапханасынан Image және ImageFilter мүмкіндіктерін аламыз. Бұл есепті шешуді әлдеқайда жеңілдетеді. Суретті ашамыз, бұлдырататын сүзгі қолданамыз (әсерін көру үшін 4-тапсырмадағыдан күштірек, 10), нәтижені сақтаймыз. Бірінші рет 4-жолда after орнына басқа айнымалы атын жазып, қате алдым. Түзеткенде, бұлыңғыр көпір шықты. 4 жол ғана!

    4-тапсырманың қиын нұсқасындағы шеттерді анықтау сүзгісі де дәл осылай, тек ImageFilter.FIND_EDGES қолданамыз.

    Функциялар және кітапханалар

    C-дағыдай, Scratch-тан бастап жасағандай, бүгін де идеялардың өзгермейтінін көрсету үшін Scratch, C және Python кодын қатар қоямыз. Мысалы, күлгін «say hello, world» блогы:

    CPython
    printf("hello, world\n");print("hello, world")

    C-да тақырыптық файлдар болды. Олар кітапханалардағы функциялардың прототиптеріне (қолтаңбаларына) қол жеткізуге мүмкіндік беретін. Python-да терминология сәл басқаша:

    • Модуль (module) — Python-дағы кітапхана.
    • Пакет (package) — модульдер жиынтығы.

    Біреу модуль не пакет туралы айтса, ол кітапхананы пайдалану туралы айтып отыр. Кітапхана тілмен бірге стандартты түрде келуі мүмкін, не бірнеше апта бұрын cowsay-ды орнатқандағыдай, өзіңіз жүктеп орнататын үшінші тарап кітапханасы болуы мүмкін.

    C-дан Python-ға көшуді жеңілдету үшін, бұл аптада CS50 кітапханасының Python нұсқасы да бар. Бұл да «жаттықтыру дөңгелегі», оны бір апта ішінде алып тастай аласыз және алып тастауыңыз керек. Ондағы get_string функциясына қол жеткізу үшін #include <cs50.h> емес, мынаны жазасыз:

    from cs50 import get_string

    Бұл сәл ұзақ, бірақ дәлірек: кітапханадан не керек екенін көрсетесіз, әсіресе бүкіл кітапхананы жадқа жүктегіңіз келмесе.

    Кіріс алу

    0-аптада көгілдір «ask» блогымен қолданушыдан атын сұрадық. Бірінші аптада оны C-ға аудардық:

    #include <cs50.h>
#include <stdio.h>

int main(void)
{
    string answer = get_string("What's your name? ");
    printf("hello, %s\n", answer);
}

    Тек кірісті алып, шығару үшін өте көп «шығыр» айналдыру керек. Python-да:

    from cs50 import get_string

answer = get_string("What's your name? ")
print("hello, " + answer)

    Мұнда тағы не ерекше?

    • %s орынбасары жоқ. Оның орнына плюс белгісі. Java не басқа тілді оқыған болсаңыз, мұны көрген шығарсыз. Мұндағы + біріктіру (concatenation), яғни сол жақтағы мен оң жақтағыны жалғау. Scratch-тағы «join» блогының дәл өзі. «Орынбасар қой да, кейін айнымалыны жаз» дегеннен гөрі бұл ыңғайлырақ.
    • Айнымалының типі көрсетілмейді: string answer емес, жай answer. 4-аптада string-ті char * деп өзгерте алар едік, бірақ бәрібір компиляторға типті айту керек еді. Python-да интерпретатор контекстен өзі түсінеді: get_string жол қайтарса, айнымалы жол сақтайды. Функция int қайтарса, айнымалы int сақтайды.
    $ python hello.py
What's your name? David
hello, David

    Python-да бір есепті шешудің тағы да көп жолы бар. print бірнеше аргумент қабылдай алады:

    print("hello,", answer)

    Құжаттамада print 1, 2 не одан көп аргумент алса, оларды әдепкі бойынша бір бос орынмен бөлетіні айтылған. Сондықтан тырнақша ішіндегі бос орынды алып тастадым. Қайсысы жақсы? Шын мәнінде, олар бірдей. Бұл тым маңызды емес айырмашылық, бірақ ол жолдарды шығаруда тілдің C-дан гөрі икемді екенін көрсетеді.

    f-жолдар

    Тағы бір тәсіл бар. Ол бір қарағанда түсініксіз, бірақ түптеп келгенде ыңғайлы. Бұл — көп Python бағдарламашысы осылай жасайтын, яғни «Pythonic» тәсіл:

    print(f"hello, {answer}")
    • Фигуралы жақшалар қайтып оралды, бірақ бағдарлама логикасының бөлігі емес, тырнақшалардың ішінде тұр.
    • Тырнақшалардың алдында f әрпі бар. Бұл printf-тың f-і емес, жақша ішінде, тырнақшаның жанында тұр.

    Бұл пішімделген жол (format string) не қысқаша f-жол (f-string). Фигуралы жақша ішіндегі айнымалының мәні сол жерге қойылады. C-дағы %s-ке ұқсайды, бірақ анығырақ: %s қолданғанда, ол қай айнымалыға сәйкес келетінін есте сақтау керек еді. Мұнда орынбасар тікелей не керек екенін айтады. Айнымалы интерполяцияланады (interpolated), яғни оның мәні сол жерге қойылады.

    Әдейі қате жасайық: f-ті ұмытсақ, нәтиже hello, {answer} болады. Компьютер айтқанымызды сөзбе-сөз орындады. Шешімі: f қосу.

    input: бірінші жаттықтыру дөңгелегін алып тастаймыз

    get_string онша қызық нәрсе істемейді. Python-да пернетақтадан кіріс алатын input функциясы бар, ол get_string сияқты жұмыс істейді:

    answer = input("What's your name? ")
print(f"hello, {answer}")

    CS50 кітапханасы мүлдем жоқ, бірақ бәрі жұмыс істейді.

    Залдан келген сұрақтар

    — Python-да неге main жоқ? Адамдар өңдеп отырған файлдың бағдарламаның негізгі бөлігі болғанын көбіне қалайтынын байқады. Екі жол код жазу үшін неге қосымша синтаксис керек? Дегенмен, main-ді кейін бір мәселені шешу үшін қайтарамыз. Бұл кодты шынайы өмірде скрипт (script) дейді: жоғарыдан төменге, солдан оңға оқылатын жеңіл бағдарлама. Бұл Python сияқты тілдердің артықшылығы: бірден кіріп, жұмысты бітіріп, шыға аласыз. Java да соңғы жылдары осыған көшті.

    Атаулы параметрлер

    Осы уақытқа дейін функцияларға берген аргументтеріміздің бәрі позициялық параметрлер (positional parameters) болды: рет маңызды. printf-те бірінші аргумент тырнақшадағы жол, ал үтірден кейінгілер екінші, үшінші, т.с.с. (Параметр мен аргумент бір нәрсе, тек функцияның көзқарасынан «параметр», ал шақырған жақтан «аргумент» деп айтылады.)

    Python атаулы параметрлерді (named parameters) де қолдайды. Нақты өмірде басқалардың кітапханаларын пайдаланғанда, кейбір функциялар 4, 10, тіпті одан көп аргумент алады. Олардың ретін есте сақтау қиын, ал әріптес оны шатастырып жіберуі мүмкін. Атаулы параметр арқылы қай аргументті беріп отырғаныңызды анық айта аласыз. Мысалы, print-тің автоматты жаңа жолын өзгерту үшін:

    print("hello", end="")

    Екінші аргумент тек "this" болса, ол «this» сөзін шығарар еді. Ал end="" print-тің end параметрінің әдепкі мәнін бос жолға ауыстырады (ішінде ештеңе жоқ). Енді $ бірінші аптадағыдай сол жолда қалады. Шын мәнінде end-тің әдепкі мәні "\n". end="!\n" деп жазып, print-ті «қуанышты» да етуге болады 🙂, бірақ көбіне ол тек әдепкі мәнді өзгерту үшін қолданылады.

    Құжаттама

    Python-да мұндай нәрселерді ресми құжаттамадан оқу C-ға қарағанда әлдеқайда кең тараған: docs.python.org. Ол CS50-нің man pages-іне ұқсайды. Бірақ C үшін бір ресми man pages жоқ, оның бірнеше нұсқасы бар. Ал Python қауымдастығы өз құжаттамасын өзі жүргізеді. Мысалы, functions.html бетінде Python-мен келетін барлық функциялардың толық тізімі бар. Онда print-тің сипаттамасы мынадай:

    print(*objects, sep=' ', end='\n', file=None, flush=False)

    Бұл — Python «прототипі», яғни функцияның аты, аргументтер саны мен түрі.

    • *objects: шығарғыңыз келетін нөл не одан көп объект (сан, жол т.б.).
    • sep=' ': аргументтер арасындағы бөлгіш, әдепкі бойынша бір бос орын. «hello,» мен answer-ді бос орынсыз бөлгенімізде, ол осы себепті автоматты түрде қосылды.
    • end='\n': уәде еткендей, әдепкі мәні жаңа жол.
    • Қалғаны файлдармен жұмысқа қатысты, оған басқа жолы ораламыз.
    Жалқы не қос тырнақша? Python-да жолдарды жалқы тырнақшамен де, қос тырнақшамен де жазуға болады. C-да қос тырнақша жолдар үшін, жалқы тырнақша тек жалғыз таңба (char) үшін болатын. Python-да бәрібір, тек бірізді болыңыз. Бірін таңдап, соны қолданыңыз. Жалқы тырнақша ішіне апостроф жазу керек болса ғана басқасын пайдаланыңыз. Python құжаттамасы жалқы тырнақшаны қолданады, JavaScript әлемінде де жалқы тырнақша кең тараған. CS50 C-мен бірізділік үшін көбіне қос тырнақшаны қолданады. Әр компанияда не қауымдастықта бірізділік үшін өз стиль нұсқаулығы болады.

    Python-да тағы көп тип бар, оларды бүгін пайдаланамыз:

    • range: сандар ауқымы.
    • list: тізім. Бұл массивтің жақсартылған нұсқасы, өткен аптадағы массивтердің бүкіл мәселесін шешеді.

Бірнеше функция керек болса, оларды үтірмен бөлуге не бүкіл кітапхананы импорттауға болады:

Ал Python-ды жасағандар кейбір функционалдықтың мәндерге тікелей қатысты екенін түсінді: жолды бас әріпке не кіші әріпке айналдыру, бірінші әрпін бас әріп ету жиі керек. Python-да Excel, Google Sheets не Apple Numbers сияқты sum және len функциялары бар. Цикл да, математиканы өзіміз жазу да қажет емес. Нәтиже: 59.333333333333336 (соңында тағы дәлсіздік бар). (C нұсқасымен бірізді болу үшін файлды scores.py деп атадық.)

    Бағаларды адам енгізсін десек:

    scores = []
for i in range(3):
    score = int(input("Score: "))
    scores.append(score)

average = sum(scores) / len(scores)
print(f"Average: {average}")

    [] — бос тізім, ұзындығы 0. (Бағаны көбейтуге болар еді, мысалы алдымен «неше баға енгізесіз?» деп сұрап.) Тізімге қалай қосамыз? Массивте тік жақша, өлшемін қадағалау, [i] керек еді. Python-да тізім объект: онда деректерден басқа әдістер де бар. Барлық тізімде append әдісі бар: ол элементті тізімнің соңына қосады. Тізімнің қанша үлкен болатынын алдын ала шешудің қажеті жоқ болды.

    Телефон кітабы: тізімдер мен сөздіктер

    names = ["Kelly", "David", "John"]

name = input("Name: ")

for n in names:
    if name == n:
        print("Found")
        break
else:
    print("Not found")

    Python-да сызықтық іздеу. Бірақ «Not found» шығару ыңғайсыз еді: C-да адамды тапқанымызды не таппағанымызды айнымалымен бақылап, не функциядан ерте қайтып шығу керек еді. Python-да, біртүрлі, бірақ өте ыңғайлы: for циклінде else болуы мүмкін! Циклдан ешқашан break арқылы шықпасаңыз, цикл соңына дейін жеткенде else орындалады. Семантикасы оғаш, бірақ for ішінде бірдеңе болды ма, жоқ па, соны бақылау өте жиі кездеседі, ал else оны дәл шешеді. Бұл Python-дағы циклдердің ең ерекше мүмкіндігі шығар.

    Бірақ сызықтық іздеуді C-да жасадық, бұл жалықтырады. Python-да:

    if name in names:
    print("Found")
else:
    print("Not found")

    name in names — қарапайым логикалық өрнек. Python тізімде бар-жоғын қалай біледі? Шамасы, сызықтық іздеу арқылы. Бірақ оны while не for циклімен өзіңіз жазбайсыз, тек не қалайтыныңызды айтасыз. Бұл ағылшын тіліне ұқсайды: «if name in names?».

    Сөздіктер (dict)

    Өткен аптада хэш-кестелер, жалпы алғанда сөздіктер «швейцар пышағы» деп айттық. Python-да 5-тапсырмадағыдай үлкен еңбексіз-ақ сөздікті dict объектісі ретінде жасай аласыз. Атты нөмірмен байланыстыратын екі бағанды кестені кодта былай жазамыз:

    people = {
    "Kelly": "+1-617-495-1000",
    "David": "+1-617-495-1000",
    "John": "+1-949-468-2750",
}

name = input("Name: ")
if name in people:
    number = people[name]
    print(f"Found {number}")
else:
    print("Not found")
    • Тік жақшалар — тізім. Фигуралы жақшалар мұнда жаңа мақсатта қолданылады: сөздік. Ішінде кілт: мән жұптары үтірмен бөлінген. Бұл 5-аптадағы хэш-кестенің бүкіл іске асырылуы.
    • Айнымалыны names-тен people-ке өзгерттім, себебі онда тек аттар емес, нөмірлер де бар.
    • name in people: Python in-ді «бұл кілт сөздікте бар ма?» деп түсінеді.
    • people[name]: C-да тік жақша массивке сандық индекспен жүгінуге арналған еді (0, 1, 2, 3). Сөздіктерде (тек Python-да емес, басқа тілдерде де) жол индекстері қолданылады. people["David"] Дэвидтің нөмірін береді. Сөздікті жолмен индекстеу өте қуатты.

    Сөздіктер тізімі

    Кілт-мән жұптарын нақты өмірде де жиі көресіз. Google Sheets-те «name» және «number» бағандары бар кесте бар. Бұл деректердің метадеректерін сипаттайды. Кейін «email» не «address» бағандарын қосуға болады. Ал әр жол, электрондық кестені пайдаланған кез келген адам білетіндей, бөлек жазбаны білдіреді: Kelly, David, John. Бұл идеяны тізім мен сөздіктерді біріктіріп іске асыруға болады:

    people = [
    {"name": "Kelly", "number": "+1-617-495-1000"},
    {"name": "David", "number": "+1-617-495-1000", "email": "malan@harvard.edu"},
    {"name": "John", "number": "+1-949-468-2750"},
]

name = input("Name: ")
for person in people:
    if person["name"] == name:
        number = person["number"]
        print(f"Found {number}")
        break
else:
    print("Not found")

    Тік жақша ішінде үш фигуралы жақша: үш сөздіктен тұратын тізім. Әр сөздікте name және number кілттері бар. Дэвидте қосымша email кілті бар, сөздікке кез келген кілт-мән жұбын қоса беруге болады. Бұл кестелерді компьютер жадында іске асырады. Тым жеңілдетіп айтсақ, Google, Microsoft және Apple электрондық кестелерінде экранда әдемі кесте көрсетілгенімен, іштей сөздіктер тізімі сақталады. Кейін деректер базасымен жұмыс істегенде, базадағы жолдарды да сөздіктер тізімінде сақтаймыз.

    Енді тізімде болғандықтан, бұрынғыдай in-мен тексере алмаймыз, цикл керек. Әр айналымда person бір сөздік болады. Оның "name" кілтінің мәні ізделген атқа тең бе деп тексереміз. Тең болса, "number" кілтінің мәнін аламыз. Электронды поштаны алғыңыз келсе, number-ді email-ге ауыстыру жеткілікті.

    — Атты да, нөмірді де экранға шығарғым келсе, біріктіремін бе? Иә, не print-ке үтір арқылы екі аргумент беріңіз. Айтпақшы, f-жолдың ішіне person["number"] өрнегін тікелей жазуға да болады. Бірақ тырнақша ішіндегі тырнақша оқуды қиындатады, сондықтан Дэвид алдымен айнымалыға сақтап, сосын айнымалыны интерполяциялауды жөн көреді.

    sys: командалық жол аргументтері және шығу коды

    Python-мен бірге келетін, бірақ импорттауды қажет ететін (орнату керек емес) көп кітапхана бар. Солардың бірі sys. main болмағандықтан (кем дегенде int main(int argc, ...) жоқ), командалық жол аргументтеріне қалай қол жеткіземіз? sys арқылы:

    from sys import argv

if len(argv) == 2:
    name = argv[1]
    print(f"hello, {name}")
else:
    print("hello, world")

    argv — командалық жол аргументтерінің тізімі. Тізім болғандықтан, оның ұзындығын len арқылы сұраймыз, argc қажет емес. Бірінші нұсқада Python-да printf деп жазып жібердім, ол жоқ 🙂

    $ python greet.py
hello, world
$ python greet.py David
hello, David

    Біз 3 сөз тердік, бірақ 2-ні тексереміз. Python-да argv интерпретаторды есептемейді: Python бағдарламасын Python интерпретаторымен іске қосып отырғаныңыз өзінен-өзі түсінікті. Сондықтан тек интерпретатордан кейінгі сөздер саналады: greet.py және David.

    import sys

if len(sys.argv) != 2:
    print("Missing command-line argument")
    sys.exit(1)

print(f"hello, {sys.argv[1]}")
sys.exit(0)

    Соңғы C бағдарламаларында сәттілікте 0, қатеде 1 қайтардық. Python-да шығу кодтары үшін де sys қолданылады. Бұл жолы from sys import argv емес, бүкіл кітапхананы import sys арқылы импорттадық. Кітапханадан керектің бәрін тізіп шығудың қажеті жоқ, кейін sys.argv және sys.exit деп кітапхананың «аумағын» көрсету жеткілікті. Синтаксис C-дан ұзағырақ, бірақ мүмкіндіктер бірдей.

    CSV файлдарына жазу

    Python-да CSV файлдарымен жұмыс істейтін csv кітапханасы бар. Үтірлерді өзіміз «қолмен» шығарудың қажеті жоқ:

    import csv

file = open("phonebook.csv", "a")

name = input("Name: ")
number = input("Number: ")

writer = csv.writer(file)
writer.writerow([name, number])

file.close()
    • open: C-дағы fopen-нің баламасы, "a" (append) режимінде.
    • csv.writer(file): файлды CSV ретінде жазуға дайындайды.
    • writer.writerow([name, number]): мәндер тізімін бір жол етіп жазады. Бұл әдісті CSV кітапханасының құжаттамасын оқығандықтан білемін.
    • 4-аптадағы phonebook.c-да нөмірді екі рет сұрағанымызды байқадым, бұл жерде түзеттім.

    Kelly, David, John-ды енгізсек, үшеуі де phonebook.csv-ға жазылады. Бірақ бұл Pythonic емес. Python-да мынадай жазу бар:

    import csv

name = input("Name: ")
number = input("Number: ")

with open("phonebook.csv", "a") as file:
    writer = csv.writer(file)
    writer.writerow([name, number])

    with: «келесі файл ашық тұрғанда, оны file деп ата, мына әрекеттерді орында да, файлды өзің жап». Шегініс аяқталғанда файл автоматты түрде жабылады. Бұл C-дағы «файлды жабуды ұмыттым» сияқты қателерден сақтайды. Ондай қателерді Valgrind-сыз байқамайсыз.

    Бірақ бұл CSV-да бағандардың не екенін көрсететін тақырып жолы (header row) жоқ. Файлдың басына name,number жолын бір рет қолмен қосамыз (әр рет қоспау үшін). Сосын DictWriter қолданамыз:

    import csv

name = input("Name: ")
number = input("Number: ")

with open("phonebook.csv", "a") as file:
    writer = csv.DictWriter(file, fieldnames=["name", "number"])
    writer.writerow({"name": name, "number": number})

    Тізім [name, number] «аттар әрқашан бірінші бағанда (0-баған), нөмірлер екінші бағанда (1-баған)» деп болжайды. Біреу Excel не Google Sheets-те бағандардың орнын ауыстырса, кодымыз бұзылар еді. DictWriter-ге fieldnames аргументімен баған аттарын береміз. Сосын тізім емес, сөздік береміз. Сонда DictWriter қай мән қай бағанға түсетінін өзі анықтайды. Мұндай код өзгерістерге әлдеқайда төзімді.

    • Объектілердің әдістері бар: s.lower(), s.upper(), list.append().

    • Кітапханалар: import, from ... import ...; sys, csv; pip install.

counts = {}
for word in text.lower().split():

best = max(counts, key=counts.get)
print(best, counts[best])

    Шешімі
    import csv

name = input("Name: ")

with open("phonebook.csv") as file:
    reader = csv.DictReader(file)
    for row in reader:
        if row["name"] == name:
            print(row["number"])
            break
    else:
        print("Not found")

    Қиын

    DNA

    ДНҚ тізбегі бойынша адамды анықтаңыз. CSV файлында адамдардың аттары және әр STR-ның (мысалы, AGATC, AATG, TATC) ең ұзын қатарынан қайталану саны берілген. Мәтіндік файлда бір адамның ДНҚ тізбегі бар.

    $ python dna.py databases/small.csv sequences/1.txt
Bob
    Кеңес
    • Базаны csv.DictReader арқылы сөздіктер тізіміне оқыңыз. STR аттары — reader.fieldnames[1:].
    • Тізбекті file.read() арқылы оқыңыз.
    • Тарату кодында longest_match(sequence, subsequence) функциясы дайын. Әр STR үшін соны шақырыңыз.
    • Адамның барлық STR саны сәйкес келсе, оның атын шығарыңыз. Ешкім сәйкес келмесе, No match.
    • CSV-дағы сандар жол ретінде оқылады, оларды int-ке айналдыруды ұмытпаңыз!
    Тексеру
    • Аргумент саны дұрыс болмаса, қате хабарын шығарады.
    • small.csv және large.csv-пен барлық тізбек дұрыс анықталады.
