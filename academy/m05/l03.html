AОқу мақсаттары

  • Екілік сандарды бағаналап қосу және көбейту (тасымалмен).
  • Ығысу (shift) мен 2-нің дәрежесіне көбейту/бөлудің байланысын түсіндіру.
  • Екілік қосуды m01 l10-дағы жарты қосындылағыштың тізбегі ретінде көрсету.

CҰғымға кіріспе

Екілік қосу ондық қосудан қарапайым: тек төрт ереже бар. 0 + 0 = 0, 0 + 1 = 1, 1 + 1 = 10 (жаз 0, тасы 1), 1 + 1 + 1 = 11 (жаз 1, тасы 1).

Солға ығысу - оң жаққа 0 қосу - 2-ге көбейту, ондықта 10-ға көбейткендей. Сондықтан процессор 2-нің дәрежесіне көбейтуді ығысумен тез орындайды.

DАкадемиялық теория

Теорема

Ығысу және көбейту

n << k = n · 2ᵏ, ал n >> k = ⌊n / 2ᵏ⌋ (теріс емес n).

Дәлелдеу

Дәлелдеу

n = Σ dᵢ2ⁱ. Солға k ығысу әр цифрды k орын жоғары жылжытады: Σ dᵢ2ⁱ⁺ᵏ = 2ᵏ · n. Оңға ығысу төменгі k цифрды тастайды: Σ_{i≥k} dᵢ2ⁱ⁻ᵏ = ⌊n/2ᵏ⌋, өйткені тасталған бөлік Σ_{i

Ескерту

Толық қосындылағыш

Бір разрядты қосу: S = a ⊕ b ⊕ c_in, c_out = (a ∧ b) ∨ (c_in ∧ (a ⊕ b)). n биттік қосу - n толық қосындылағыштың тізбегі (m01 l10 жарты қосындылағыштың жалғасы).

Теорема

Көбейту - ығысулардың қосындысы

a · b = Σ_{bᵢ = 1} (a << i). Мысалы 13 · 5 = 13·(4 + 1) = (13 << 2) + 13.

EКөрнекі түсіндірме

Екілік қосу: 11 + 6 = 17 = 10001₂. Операцияны << не >> етіп ауыстырып көріңіз.

FҚадамдап қорыту

  1. 1011₂ + 0110₂ (11 + 6).
  2. 0-разряд: 1 + 0 = 1. 1-разряд: 1 + 1 = 10 → 0, тасы 1.
  3. 2-разряд: 0 + 1 + 1 = 10 → 0, тасы 1. 3-разряд: 1 + 0 + 1 = 10 → 0, тасы 1.
  4. Соңғы тасымал: 1. Нәтиже 10001₂ = 17. ✓

JМатематикалық пайымдау

Неге ығысу көбейтуден жылдам? Көбейту схемасы n² биттік амалды қажет етеді, ал ығысу - тек сымдарды жылжыту. Компиляторлар x * 8 өрнегін автоматты түрде x << 3-ке ауыстырады (оңтайландыру).

KЖиі қателер

  • 1 + 1 = 2 деп екілікте жазу.
    Себебі: Екілікте «2» цифры жоқ.
    Түзету: 1 + 1 = 10: 0 жаз, 1 тасы.
  • Теріс санды оңға ығысу = бөлу деп санау.
    Себебі: Таңбалы ығысу ⌊·⌋ береді: −7 >> 1 = −4.
    Түзету: Теріс сандарда арифметикалық ығысу ерекшелігін ескеріңіз (m10).
