Бөлшек сандар

  • күрделі

нұсқа 1.0.0 · тексеру: author-checked

AОқу мақсаттары

  • Екілік бөлшекті (0.101₂ = 1/2 + 1/8) және оның шектілік шартын түсіндіру.
  • IEEE 754 float32 құрылымын (таңба, 8 бит дәреже, 23 бит мантисса) талдау.
  • 0.1 + 0.2 ≠ 0.3 құбылысын түсіндіріп, бөлшек сандарды дұрыс салыстыру.

BАлғышарттар

  • Теріс сандар: қосымша код

CҰғымға кіріспе

Ондықта 1/3 = 0.333... шексіз. Екілікте дәл сол сияқты 1/10 шексіз: 0.0001100110011...₂. Компьютер шексіз биттерді сақтай алмайды, сондықтан 0.1 жуықтап сақталады. Python-да 0.1 + 0.2 == 0.3 жалған - бұл қате емес, екілік жүйенің салдары.

Жылжымалы үтір (floating point): сан = (−1)ˢ · 1.m · 2ᵉ. Ғылыми жазудың екілік нұсқасы: 6.02 · 10²³ сияқты, тек негізі 2.

DАкадемиялық теория

Теорема

Екілік бөлшектің шектілігі

Рационал p/q (қысқартылмайтын) екілікте шекті ⇔ q - 2-нің дәрежесі.

Дәлелдеу

Дәлелдеу

Шекті болса, p/q = m/2ᵏ, демек q | 2ᵏ, яғни q = 2ʲ (жай көбейткіштер, m02 l08). Керісінше q = 2ʲ болса, p/q = p/2ʲ - екілікте j цифрлы бөлшек. 1/10: 10 = 2 · 5, 5 бар - шексіз. ∎

Анықтама

IEEE 754 float32

32 бит: s (1) | e (8) | m (23). Қалыпты сан: (−1)ˢ · 1.m₂ · 2^(e − 127). e = 0 - нөл/субнормал, e = 255 - ∞ не NaN.

Ескерту

Дұрыс салыстыру

a == b орнына |a − b| ≤ ε · max(|a|, |b|) не math.isclose. Ақша үшін бөлшек тип емес, бүтін «тиын» не decimal қолданыңыз.

EКөрнекі түсіндірме

0.1 float32-де: сақталған мән 0.100000001490116... Мантисса шексіз тізбектің кесілген бөлігі.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. 0.75-ті екілікке аударамыз: 0.75 · 2 = 1.5 → 1; 0.5 · 2 = 1.0 → 1. Демек 0.11₂.
  2. 0.1 · 2 = 0.2 → 0; 0.4 → 0; 0.8 → 0; 1.6 → 1; 1.2 → 1; 0.4 → 0 ... қайталанады.
  3. 0.1 = 0.0001100110011...₂ - шексіз периодты.
  4. float32 23 битті ғана сақтайды, сондықтан 0.1 ≈ 0.100000001490116.

GЖұмыс мысалдары

HИнтерактивті эксперимент

0.5, 0.25, 0.75 дәл сақтала ма (сақталған мән = енгізілген)? 0.2, 0.3 ше? Шектілік теоремасымен түсіндіріңіз.

IЖаттығулар

JМатематикалық пайымдау

Жылжымалы үтір - ымыра: салыстырмалы дәлдік (≈7 ондық цифр float32-де) өте үлкен (10³⁸) және өте кіші (10⁻³⁸) сандарды бір форматта сақтауға мүмкіндік береді. Абсолют дәлдік емес, салыстырмалы дәлдік - сандық әдістердің (Level II) негізгі ұғымы.

KЖиі қателер

  • Бөлшек сандарды == арқылы салыстыру.
    Себебі: Жуықтау қателігі.
    Түзету: math.isclose не ε-шекпен салыстыру.
  • Дәреже өрісін ығысусыз оқу.
    Себебі: e 127-ге ығыстырылып сақталады.
    Түзету: Нақты дәреже = e − 127.
