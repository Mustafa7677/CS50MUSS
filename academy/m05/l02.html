05·02Information & Binary Systems

Позициялық санау жүйелері

  • негізгі
  • ≈ 45 мин
  • 3 мақсат
  • 6 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

AОқу мақсаттары

  • Позициялық жүйеде санның мәнін Σ dᵢ · bⁱ түрінде жазу.
  • Ондықтан кез келген жүйеге (қайталап бөлу) және кері (Горнер схемасы) аудару.
  • Екілік ↔ сегіздік/он алтылық аударуды 3/4 биттік топтар арқылы жылдам орындау.

BАлғышарттар

  • Ақпарат және бит

CҰғымға кіріспе

Ондық жүйеде 352 = 3·10² + 5·10¹ + 2·10⁰. Цифрдың мәні оның орнына тәуелді. Кез келген b ≥ 2 негізінде дәл солай: 101₂ = 1·4 + 0·2 + 1·1 = 5.

Он алтылық жүйе (0-9, A-F) программистерге ыңғайлы: бір он алтылық цифр - дәл 4 бит. Сондықтан түстер (#FF8800), жады мекенжайлары, байттар он алтылықпен жазылады.

DАкадемиялық теория

Анықтама

b негізді жазу

(dₖ ... d₁d₀)_b = Σ dᵢ · bⁱ, 0 ≤ dᵢ < b.

Теорема

Жазудың бар болуы және жалғыздығы

Әр n ≥ 1 бүтін санның b негізді жазуы бар және жалғыз (бастағы нөлдерсіз).

Дәлелдеу

Дәлелдеу (бар болуы, күшті индукция)

n < b болса - бір цифр. Әйтпесе n = b · q + r, 0 ≤ r < b (m04 l03, бөлу теңдігі), q < n. Болжам бойынша q-ның жазуы бар; оған r-ді соңғы цифр етіп тіркейміз. Жалғыздық: соңғы цифр міндетті түрде n mod b, ал қалғаны q-ның жазуы (индукция). ∎ Бұл дәлелдеу дәл «қайталап бөлу» алгоритмін береді.

Ескерту

Горнер схемасы

(d₃d₂d₁d₀)_b = ((d₃·b + d₂)·b + d₁)·b + d₀. Цифрларды солдан оңға оқып, «көбейт те қос» - қосымша дәрежелерсіз.

EКөрнекі түсіндірме

Он алтылық 2C = 2·16 + 12 = 44. Екілікте 0010 1100: әр он алтылық цифр - 4 бит.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. 44-ті екілікке аударамыз: 44 = 2·22 + 0.
  2. 22 = 2·11 + 0; 11 = 2·5 + 1; 5 = 2·2 + 1; 2 = 2·1 + 0; 1 = 2·0 + 1.
  3. Қалдықтарды төменнен жоғары оқимыз: 101100₂.
  4. Тексеру (Горнер): ((((1·2 + 0)·2 + 1)·2 + 1)·2 + 0)·2 + 0 = 44. ✓

GЖұмыс мысалдары

HИнтерактивті эксперимент

Он алтылық жазуын қараңыз: FF. Екілікті 4 биттен топтап, әр топты бір он алтылық цифрға аударып тексеріңіз.

IЖаттығулар

JМатематикалық пайымдау

Неге екілік ↔ он алтылық аудару топтап жасалады, ал ондыққа - жоқ? Себебі 16 = 2⁴: 16-ның әр дәрежесі 2-нің дәрежесі, сондықтан төрт бит бір цифрға дәл сәйкес. 10 2-нің дәрежесі емес, сондықтан ондық цифр биттерге «тураланбайды».

KЖиі қателер

  • Қалдықтарды жоғарыдан төмен оқу.
    Себебі: Бірінші қалдық - ең кіші разряд.
    Түзету: Төменнен жоғары (соңғы қалдық - бірінші цифр).
  • Топтауды сол жақтан бастау.
    Себебі: Цифр саны 4-ке бөлінбесе, топтар жылжиды.
    Түзету: Оң жақтан топтаңыз, сол жақты нөлмен толтырыңыз.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
