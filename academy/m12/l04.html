12·04Systems Integration

Python мен C бірге

  • күрделі
  • ≈ 60 мин
  • 3 мақсат
  • 6 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

AОқу мақсаттары

  • Python-дан C бағдарламасын subprocess арқылы компиляциялап, іске қосып, шығысын өңдеу.
  • Бағдарламалар арасындағы мәтіндік протоколды (кілт=мән жолдары) жобалау.
  • Сандарды мәтін арқылы дәл беру шартын (%.17g) түсіндіру.

BАлғышарттар

  • Деректер форматтары
  • Python мен C салыстыру

CҰғымға кіріспе

Python - «желім» тілі: ол басқа бағдарламаларды іске қосып, нәтижелерін біріктіреді. subprocess.run([...], capture_output=True, text=True) бағдарламаны орындап, stdout, stderr және шығу кодын қайтарады. Ауыр есептеу C-да, ал басқару, талдау және есеп - Python-да.

Екі бағдарлама келісуі керек: протокол. Ең қарапайымы - кілт=мән жолдары. Маңызды нәзіктік: double санын мәтінге жазып, қайта оқығанда дәлдік жоғалмауы үшін %.17g керек (%.6f жеткіліксіз). Браузерде subprocess жоқ, сондықтан бұл сабақтың мысалдары build кезінде нағыз CPython + gcc арқылы орындалған.

DАкадемиялық теория

Анықтама

subprocess.run

r = subprocess.run(cmd, input=..., capture_output=True, text=True, timeout=...); r.returncode, r.stdout, r.stderr. cmd - тізім (shell=True емес - қауіпсіз, аргументтер бөлінеді). check=True - нөлдік емес кодта ерекшелік.

Теорема

17 мәнді цифр жеткілікті

Кез келген IEEE 754 double x үшін оны 17 мәнді ондық цифрмен (%.17g) жазып, қайта оқу (strtod, float()) дәл сол x-ті береді.

Дәлелдеу

Негіздеу (схема)

double-ның мантиссасы 53 бит; бір екілік ретте (бірдей экспонента) көрші double-лар арасындағы салыстырмалы қашықтық ≥ 2⁻⁵³ ≈ 1.1·10⁻¹⁶. 17 мәнді ондық цифр дөңгелектеуінің салыстырмалы қатесі ≤ ½·10⁻¹⁶ = 5·10⁻¹⁷, бұл көрші double-лар арасының жартысынан кіші. Демек жазылған ондық сан x-ке ең жақын double болып қалады, ал дұрыс дөңгелектейтін оқу (IEEE 754 талабы) дәл x-ті таңдайды. ∎ (Толық дәлел экспонента шекараларындағы жағдайларды қарайды; 17 - ең аз жарамды сан, 16 кейбір x үшін жеткіліксіз.)

Ескерту

Қауіпсіздік

shell=True және пайдаланушы мәтінін командаға қосу - команда енгізу (command injection) қаупі: «; rm -rf ~». Әрқашан тізім форматы: ['./prog', user_value].

EКөрнекі түсіндірме

C бағдарламасы протокол бойынша кілт=мән жолдарын шығарады. 0.1-ді 10 рет қосу 1.0 бермейді (m05 l05) - %.17g мұны көрсетеді, %.6f «1.000000» деп жасырар еді.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. C бағдарламасын temp бумада жазу және gcc-мен компиляциялау: subprocess.run(['gcc', ..., '-o', exe, src], check=True).
  2. Іске қосу: r = subprocess.run([exe, '1000'], capture_output=True, text=True, timeout=5).
  3. r.returncode тексеру; протоколды талдау: dict(line.split('=', 1) for line in r.stdout.splitlines()).
  4. Python-да тәуелсіз есептеп, салыстыру (differential testing, 10-сабақ).

GЖұмыс мысалдары

HИнтерактивті эксперимент

%.6f және %.15g дәлдікті жоғалтты, %.17g - жоқ (теорема). Python-ның repr(x) ең қысқа дәл жазуды таңдайды. Басқа x мәндерімен (1/3, 2**0.5) тексеріңіз - 16 цифр әрқашан жеткілікті ме?

IЖаттығулар

JМатематикалық пайымдау

«Екі тілдің ең жақсысы» - нақты өндірістің үлгісі: NumPy, Pandas, PyTorch ішінде C/C++ ядросы, сыртында Python. Бұл сабақта олардың ең қарапайым нұсқасын - процестер мен мәтіндік протоколды - жасадық. Ал сапаның кепілі - тәуелсіз есеппен салыстыру: егер C мен Python бір нәтиже берсе, екеуінде бір қате болу ықтималдығы аз.

KЖиі қателер

  • returncode-ты тексермей stdout-ты талдау.
    Себебі: Бағдарлама құласа, жартылай шығыс «дұрыс» болып көрінеді.
    Түзету: check=True не returncode == 0 тексеру.
  • timeout бермеу.
    Себебі: C бағдарламасы шексіз циклға түссе, Python мәңгі күтеді.
    Түзету: timeout=... және subprocess.TimeoutExpired өңдеу.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.

NТереңірек

Honors

  • ctypes арқылы C функциясын (shared library, gcc -shared -fPIC) процесс іске қоспай-ақ Python-дан шақырыңыз. subprocess-тен немен ерекшеленеді?

Research

  • Python C кеңейтулері (CPython C API), Cython және pybind11 - жылдам кітапханалар қалай жасалады?
