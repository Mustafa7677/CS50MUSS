AОқу мақсаттары

  • C-да argc/argv және Python-да sys.argv арқылы аргументтерді оқу.
  • Шығу кодын (0 - сәтті, ≠ 0 - қате) жүйелік интерфейс ретінде қолдану.
  • Аргументтерді тексеру: strtol-дың endptr-і, қолдану туралы хабар (usage) stderr-ге.

BАлғышарттар

  • Бағдарлама жүйе ретінде
  • Стандартты енгізу-шығару

CҰғымға кіріспе

Командалық жол бағдарламасының интерфейсі үш бөлік: аргументтер (./prog 3 5 7), стандартты ағындар (stdin, stdout, stderr) және шығу коды. C-да int main(int argc, char *argv[]): argc - аргументтер саны (бағдарлама атауымен бірге), argv - жолдар массиві. Python-да sys.argv тізімі.

Жақсы командалық жол бағдарламасы: нәтижені stdout-қа, қате хабарларын stderr-ге жазады (сонда құбыр | арқылы тек нәтиже беріледі), және қате кезінде нөлдік емес код қайтарады - сонда басқа бағдарламалар (shell, Python, CI) сәттілікті тексере алады.

DАкадемиялық теория

Анықтама

argc және argv

argv[0] - бағдарлама атауы (не бос жол), argv[1..argc−1] - аргументтер, бәрі жол. Сандарды strtol/atoi арқылы түрлендіру керек. Shell бос орындар бойынша бөледі; тырнақшалар "бір аргумент" жасайды.

Теорема

argv массивінің құрылымы

C11 бойынша argc ≥ 0 және argv[argc] == NULL; демек argv массивін NULL-ға дейін аралау (for (char **p = argv; *p; p++)) argc-ты білмей-ақ барлық аргументті береді.

Дәлелдеу

Негіздеу

C11 5.1.2.2.1/2: «argc мәні теріс емес; argv[argc] нөлдік көрсеткіш болуы керек; argv[0]..argv[argc−1] жолдарға көрсетеді». Демек argv - argc жол көрсеткішінен кейін NULL-мен аяқталатын тізбек. *p == NULL тексерісі дәл argc қадамнан кейін ақиқат болады (бұрынғылары жолдарға көрсетеді, яғни NULL емес), сондықтан цикл барлық аргументті аралап, массивтен шықпай тоқтайды. ∎ (Бұл - жолдардың '\0'-мен аяқталуының (m10 l07) көрсеткіштер деңгейіндегі ұқсасы.)

Ескерту

strtol-ды дұрыс қолдану

atoi("12x") = 12 - қате байқалмайды. strtol(s, &end, 10): end - бірінші түрленбеген таңба; *end != '\0' не end == s болса - жол толық сан емес.

EКөрнекі түсіндірме

argc = 4 (бағдарлама атауы да саналады). Соңғы тексеріс argv[argc] == NULL - шығу коды 0 (теорема). argv[0] нақты жолы build ортасына тәуелді болғандықтан ./prog деп шығарылды.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Есеп: ./stats 3 5 x командасы - x сан емес.
  2. for i in 1..argc−1: long v = strtol(argv[i], &end, 10);
  3. if (end == argv[i] || *end != '\0') { fprintf(stderr, "сан емес: %s\n", argv[i]); return 2; }
  4. Shell-де: ./stats 3 5 x; echo $? → 2. Python-да: subprocess.run(...).returncode == 2.

GЖұмыс мысалдары

HИнтерактивті эксперимент

Python нұсқасы: main(argv) функциясы sys.argv-ті параметр ретінде алады - сондықтан оны тесттен шақыруға болады. Нақты скриптте соңында: sys.exit(main(sys.argv)). Зертхана stderr-ді бөлек көрсетеді - қате хабарлары нәтижеден (stdout) ажыратылғанын көресіз.

IЖаттығулар

JМатематикалық пайымдау

Командалық жол - бағдарламалар арасындағы ең көне және ең тұрақты интерфейс: 50 жылдан бері өзгерген жоқ. Аргументтер + ағындар + шығу коды - кез келген тілде жазылған бағдарламаларды біріктіруге жеткілікті (4-сабақ). CI жүйелері (GitHub Actions) дәл осы шығу кодтарына сүйенеді.

KЖиі қателер

  • atoi арқылы түрлендіріп, қатені тексермеу.
    Себебі: '12x' → 12, 'abc' → 0 - қате үнсіз.
    Түзету: strtol + endptr не Python-да int() + try.
  • Қате болса да 0 қайтару.
    Себебі: Shell, CI, Python бағдарлама сәтті деп ойлайды.
    Түзету: return 1/2 не exit(EXIT_FAILURE).
