CҰғымға кіріспе

Level I аяқталды: 120 сабақ, 12 модуль - логикадан көрсеткіштерге дейін. Қорытынды жоба осының бәрін біріктіреді: бір есептеу есебін (мысалы, жай сандар, сұрыптау, статистика) Python-да және C-да тәуелсіз іске асырып, оларды бір-бірімен дифференциалдық тестілеу арқылы салыстырасыз, өнімділігін өлшейсіз және нәтижені құжаттайсыз.

Дифференциалдық тестілеу идеясы қарапайым: бір спецификацияның екі тәуелсіз іске асыруы мыңдаған кездейсоқ кірісте бірдей нәтиже беруі керек. Айырмашылық табылса - кем дегенде біреуінде қате бар (теорема). AO17 академиясының өзі осылай құрылған: әр қозғалтқыштың JS және Python нұсқалары бір-бірімен тексеріледі.

DАкадемиялық теория

Анықтама

Дифференциалдық тестілеу

Спецификация S, екі іске асыру P және Q. Кірістер жиыны X (кездейсоқ + шеткі жағдайлар). Әр x ∈ X үшін P(x) мен Q(x) салыстырылады; P(x) ≠ Q(x) болатын x - «айырма куәсі».

Теорема

Айырма куәсінің мағынасы

S әр кіріске бір ғана дұрыс нәтиже анықтаса және P(x) ≠ Q(x) болса, онда P мен Q-дың кемінде біреуі x-те S-ке сай емес.

Дәлелдеу

Дәлелдеу (қарама-қайшылық)

Екеуі де x-те дұрыс делік: P(x) = S(x) және Q(x) = S(x). Онда P(x) = Q(x) (теңдіктің транзитивтілігі) - шартқа қайшы. Демек кемінде біреуі қате. ∎ Кері тұжырым дұрыс емес: P(x) = Q(x) барлық сыналған x үшін болса да, екеуінде де бірдей қате болуы мүмкін (m08 l08 - тест қатенің жоқтығын дәлелдемейді). Сондықтан іске асырулар шын мәнінде тәуелсіз болуы керек (әр тіл, әр алгоритм).

Ескерту

Level I-ден Level II-ге

Level II (Intermediate): деректер құрылымдары (ағаштар, үйме, хэш-кестелер), алгоритмдерді талдау, объектіге бағытталған бағдарламалау, деректер базалары, компьютер архитектурасы. Level I-дің әр ұғымы сонда тірек болады.

EКөрнекі түсіндірме

Екі тәуелсіз алгоритм (елек және бөлгіштерді тексеру) 20 кірісте бірдей нәтиже берді - айырма куәсі жоқ. Біреуін әдейі бұзып (мысалы, d * d < k) көріңіз.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Есепті таңдау: спецификация нақты, кіріс кездейсоқ жасалады, нәтиже салыстырылады (сан, тізім).
  2. Python іске асыруы - анық, тесттермен (m08); C іске асыруы - тиімді, санитайзерлермен (m10-m11).
  3. Дифференциалдық тест скрипті: Python C-ны компиляциялап, мыңдаған кіріспен шақырады (4-сабақ), айырманы іздейді.
  4. Өлшеу (5-сабақ, m09 l10): еселеу тәжірибесі, Амдал; README (8-сабақ); Git тарихы (7-сабақ).

GЖұмыс мысалдары

HИнтерактивті эксперимент

Level I-дің «үлкен суреті»: өсу жылдамдықтары (m04 l09) алгоритм таңдауын (m09), тіл таңдауынан (m10) маңыздырақ етеді. Қорытынды жобада осы қисықтарды өз өлшемдеріңізбен (еселеу кестесі) растаңыз.

IЖаттығулар

JМатематикалық пайымдау

Level I-дің негізгі сабағы: сенімділік дәлелден, тесттен және өлшемнен құралады. Логика мен дәлелдеу (m01-m02) «неге дұрыс?» дейді, алгоритмдер (m04, m09) «қаншалықты тез?», тесттер (m08, m12) «шынымен солай ма?», ал жад пен C (m10-m11) «компьютер мұны шын мәнінде қалай орындайды?». Қорытынды жоба осы төрт сұрақтың бәріне бір есеп арқылы жауап береді.

Модуль жобасы: Python–C Comparative Computing Project

Level I қорытынды жобасы. Бір есептеу есебін (ұсыныстар: жай сандарды санау, сұрыптау және медиана, үлкен файлдағы сөздер жиілігі, матрицаларды көбейту) таңдап, оны Python-да және C-да тәуелсіз іске асырыңыз. Python басқарушы скрипті C бағдарламасын компиляциялап, мыңдаған кездейсоқ және шеткі кірістермен екі нұсқаны дифференциалдық тестілейді, өнімділікті еселеу тәжірибесімен өлшейді және нәтижелерді кесте мен README-де ұсынады.

Функционалдық талаптар

  • Спецификация: кіріс/шығыс форматы, шеткі жағдайлар, қате кодтары (README-нің бір бөлімі).
  • Python нұсқасы: таза функциялар, docstring + doctest, бірлік тесттері (кемінде 10, мутанттарды ұстайтын).
  • C нұсқасы: командалық жол аргументтері, тексерілген енгізу, динамикалық жад; gcc -Wall -Wextra -Werror -fsanitize=address,undefined-пен таза.
  • Дифференциалдық тест: кемінде 1000 кездейсоқ кіріс + шеткі жағдайлар; айырма куәсі табылса - тұрақты тест ретінде сақталады.
  • Өнімділік: кемінде 5 өлшем (n еселенеді), уақыт медианасы, өсу дәрежесінің бағасы, Python/C жылдамдық қатынасы, Амдал талдауы.
  • Git тарихы (кемінде 10 мағыналы commit) және README (8-сабақ құрылымы, шектеулер бөлімімен).

Кезеңдер

  • 1. Спецификация және Python нұсқасы + тесттер.
  • 2. C нұсқасы + санитайзерлер.
  • 3. Протокол және Python басқарушы скрипті.
  • 4. Дифференциалдық тест және табылған айырмалар.
  • 5. Өнімділік өлшемі және талдау.
  • 6. README, қорғау презентациясы (5-7 минут).

Қабылдау тесттері

  • 1000+ кездейсоқ кірісте айырма куәсі жоқ (не табылған әр айырма түзетіліп, тест ретінде қосылған).
  • Санитайзерлер мен -Werror-мен C нұсқасы таза.
  • Еселеу кестесіндегі өсу дәрежесі теориялық бағамен ±0.3 шегінде сәйкес не айырмашылық түсіндірілген.
  • Таза машинада README бойынша жобаны 10 минутта іске қосуға болады.

Бағалау рубрикасы

  • Дұрыстық және дифференциалдық тестілеу - 30%
  • C нұсқасының сапасы мен қауіпсіздігі - 20%
  • Өнімділік талдауының адалдығы мен тереңдігі - 20%
  • Python кодының сапасы, тесттер, doctest - 15%
  • Құжаттама, Git тарихы, қорғау - 15%

Жобаны мұғалім рубрикамен бағалайды: бұл бетте автоматты бағаланбайды.
