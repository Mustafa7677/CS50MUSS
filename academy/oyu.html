Ою студиясы

Python кодымен қазақ оюын сал. Цикл - бір қозғалысты қайталау, функция - бір өрнекті қайта-қайта салу, симметрия - бұру мен айнадай шағылыстыру, рекурсия - бұтақтан бұтақ өсіру. Код браузерде нағыз Python-да орындалады.

Python жүктелуде...

Ctrl + Enter - іске қосу. Tab - шегініс.

Командалар

        
Python-ның turtle модулінің командалары. import turtle не from turtle import * деп жазуға да болады.

        
forward(d)  ·  fdd қадам алға
back(d)  ·  bkd қадам артқа
left(a)  ·  lta градус солға бұрылу
right(a)  ·  rta градус оңға бұрылу
penup()  ·  pendown()қаламды көтеру / түсіру
goto(x, y)(x, y) нүктесіне бару
setheading(a)бағытты a градусқа қою (0 - оңға, 90 - жоғары)
home()ортаға оралу, бағыт 0
circle(r, бұрыш)радиусы r доға; r теріс болса - оңға бұралады
color("қызыл")түс: қызыл, көк, алтын, жасыл, қара, сары, қоңыр, күлгін... не #hex
pensize(w)сызық қалыңдығы
begin_fill() ... end_fill()пішінді бояу (fillcolor)
dot(size)нүкте
