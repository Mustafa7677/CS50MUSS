Сызықтық функция: көлбеулік және бастапқы мән

  • негіз
  • ≈ 40 мин
  • 9 жаттығу

Не үйренесіз

  • Функция жазуын (f(x)) оқып, мәнін есептеу.
  • Екі нүкте не кесте бойынша көлбеулікті (slope) табу.
  • y = mx + b теңдеуін құру және m мен b-ның контекстегі мағынасын түсіндіру.

Алдымен ойланыңыз

Алматыдағы екі самокат қызметін салыстырайық. «Жел»: бастау 100 теңге, минутына 40 теңге. «Құйын»: бастау 250 теңге, минутына 25 теңге. Қысқа сапарға біреуі тиімді, ұзақ сапарға - екіншісі. Екеуінің де бағасы уақытқа байланысты бірқалыпты өседі - мұндай тәуелділік сызықтық функция деп аталады, ал оның графигі түзу сызық.

Болжаңыз: 15 минуттық сапарға қайсысы арзан?

  1. «Жел»
  2. «Құйын»
  3. Бағалары бірдей

Түсіндірме

Функция - ереже-машина

Функция әр кіріс санға бір ғана шығыс сан сәйкестендіреді. f(x) = 40x + 100 жазуы «x-ті ал, 40-қа көбейт, 100 қос» дегенді білдіреді. f(15) - «f көбейту 15» емес, «x орнына 15 қой» деген бұйрық:

f(15) = 40 · 15 + 100 = 700

Кері сұрақ: f(x) = 500 болса, x неге тең? Мұнда теңдеу шешеміз: 40x + 100 = 500 → x = 10. Есте сақтаңыз: жақша ішіндегі - кіріс (x), теңдіктің оң жағындағы - шығыс (y).

Көлбеулік: өзгеріс жылдамдығы

Көлбеулік (slope, m) x бір бірлікке өскенде y қаншаға өзгеретінін көрсетеді. Кез келген екі нүкте бойынша:

m = (y₂ − y₁) / (x₂ − x₁) = «көтерілу» / «жүру»

(2; 180) және (5; 300) нүктелері: m = (300 − 180) / (5 − 2) = 120 / 3 = 40.

m > 0солдан оңға көтеріледішама өседі
m < 0төмендейдішама кемиді
m = 0көлденеңөзгермейді
анықталмағантік (x = c)функция емес

Сызықтық функцияның басты белгісі: көлбеулік барлық жерде бірдей. Кестеде x бірдей қадаммен өскенде y те бірдей қадаммен өзгерсе - функция сызықтық.

y = mx + b: екі санның мағынасы

Сызықтық функцияның ең ыңғайлы жазылуы - slope-intercept form:

y = mx + b

  • b - y-қиылысу (y-intercept): x = 0 болғандағы мән, яғни бастапқы мән. График y осін (0; b) нүктесінде қияды.
  • m - көлбеулік: x-тің әр бірлігіне келетін өзгеріс.

Самокат мысалында y = 40x + 100: 100 - бастау ақысы (теңге), 40 - әр минуттың бағасы (теңге/минут). m-нің бірлігі әрқашан «y бірлігі / x бірлігі».

x-қиылысу (x-intercept) - y = 0 болатын нүкте. y = −3x + 12 үшін: 0 = −3x + 12 → x = 4.

Теңдеуді құру: екі дерек жеткілікті

Түзуді анықтау үшін екі мәлімет керек. Жиі кездесетін үш жағдай:

БерілгеніНе істейміз
m және bбірден y = mx + b
m және бір нүктенүктені қойып, b-ны табамыз
екі нүктеалдымен m, сосын b

Мысал: түзу (1; 7) және (4; 16) арқылы өтеді. m = (16 − 7) / (4 − 1) = 3. Енді y = 3x + b теңдеуіне (1; 7) қоямыз: 7 = 3 + b, b = 4. Жауап: y = 3x + 4. Екінші нүктемен тексеру: 3 · 4 + 4 = 16.

Нүкте-көлбеулік түрі де пайдалы: y − y₁ = m(x − x₁).

f(x) жазуындағы жылжулар

SAT кейде g(x) = f(x) + 3 не g(x) = f(x − 2) деп береді. Біріншісі графикті 3 бірлік жоғары көтереді (b өседі). Екіншісі графикті 2 бірлік оңға жылжытады. Сызықтық функцияда екеуінде де көлбеулік өзгермейді - түзу өзіне параллель жылжиды.

Емтихандағы әдіс: «m мен b-ны аула»

  1. Айнымалыларды атаx не (кіріс: уақыт, саны), y не (шығыс: баға, қашықтық)? Бірліктерін жазыңыз.
  2. Көлбеулікті тап«Әр ... сайын» сөзінен не екі нүктеден: y-тің өзгерісін x-тің өзгерісіне бөліңіз. Таңбасына қараңыз.
  3. Бастапқы мәнді тапx = 0 кезіндегі мән берілсе - сол b. Берілмесе, бір нүктені y = mx + b-ға қойып табыңыз.
  4. Тексер де жауап берЕкінші нүктені қойып тексеріңіз. Сұрақ мәнді ме, x-ті ме, әлде m-нің мағынасын ба - соны беріңіз.

Қадамдық мысалдар

Әр қадамды кезекпен ашыңыз: алдымен келесі қадамды өзіңіз болжап көріңіз.

1-мысал

Сызықтық f функциясы үшін f(2) = 11 және f(6) = 23. f(10) неге тең?

  1. Екі нүкте: (2; 11) және (6; 23).
  2. Көлбеулік: m = (23 − 11) / (6 − 2) = 12 / 4 = 3.
  3. b-ны табамыз: 11 = 3 · 2 + b → b = 5. Функция: f(x) = 3x + 5.
  4. f(10) = 3 · 10 + 5 = 35.
  5. Қысқа жол: x 6-дан 10-ға дейін 4-ке өсті, демек y тағы 4 · 3 = 12-ге өседі: 23 + 12 = 35.

Жауап: 35

Қақпан: f(2) мен f(6)-ны қосып не көбейтіп жіберу; f(10) ≠ f(2) + f(6) + ... Әрқашан көлбеулік арқылы жүріңіз.

2-мысал

Су қоймасындағы су деңгейі сызықтық түрде төмендейді: 3-күні 180 см, 8-күні 145 см болды. Бастапқы деңгейі (0-күні) қандай және деңгей қай күні 110 см болады?

  1. Нүктелер: (3; 180) және (8; 145). x - күн, y - см.
  2. m = (145 − 180) / (8 − 3) = −35 / 5 = −7. Деңгей күніне 7 см төмендейді.
  3. b: 180 = −7 · 3 + b → b = 201. Бастапқы деңгей 201 см. Теңдеу: y = −7x + 201.
  4. 110 = −7x + 201 → 7x = 91 → x = 13. Он үшінші күні.

Жауап: Бастапқы деңгей 201 см; 13-күні 110 см

Қақпан: Көлбеуліктің минус таңбасын жоғалту: сонда b = 159 шығып, деңгей «өсіп» кетеді.

Жиі қателер

  • Көлбеулікті (x₂ − x₁) / (y₂ − y₁) деп есептеу.Неге қате: Бөлшек аударылып қалған: көлбеулік - y-тің өзгерісі x-тің өзгерісіне.Дұрысы: «Көтерілу жоғарыда, жүру төменде»: Δy / Δx.
  • Алым мен бөлімде нүктелердің ретін әртүрлі алу: (y₂ − y₁) / (x₁ − x₂).Неге қате: Таңба керісінше шығады.Дұрысы: Екеуінде де бір нүктеден бастаңыз.
  • b-ны кестедегі бірінші мән деп алу, ал кесте x = 1-ден басталған.Неге қате: b - тек x = 0 кезіндегі мән.Дұрысы: Кестеде x = 0 жоқ болса, бір қадам кері шегініңіз не нүктені теңдеуге қойыңыз.

Жаттығу

Қате жауапқа себебі түсіндіріледі. Көмек үш деңгейлі: бағыт, ұқсас мысал, қадамдық шешім.

  1. f(x) = 5x − 8 функциясы берілген. f(6) неге тең?

  2. (−1; 4) және (3; −8) нүктелері арқылы өтетін түзудің көлбеулігін табыңыз.

  3. Жаттығу залына мүшелік құны C = 12 000 + 6500m формуласымен беріледі (m - ай саны). 12 000 саны нені білдіреді?

    1. Айлық төлемді
    2. Бір реттік тіркеу жарнасын
    3. Бір жылдық толық құнын
    4. Айлар санын

  4. Түзу (2; 9) нүктесі арқылы өтеді және көлбеулігі 4. Оның y-қиылысуын (b) табыңыз.

  5. Кестеде сызықтық функция берілген: x = 1 болғанда y = 7, x = 3 болғанда y = 13, x = 5 болғанда y = 19. x = 0 болғанда y неге тең?

  6. f(x) = −2x + 14 функциясының графигі x осін қай нүктеде қияды? x мәнін жазыңыз.

Меңгеруді тексеру

Жаңа есептер, көмексіз. Бәрін дұрыс шешсеңіз, сабақ «меңгерілді» деп белгіленеді (AO17 ережесі, ресми емтихан бағасы емес).

  1. Сызықтық g функциясы үшін g(−2) = 10 және g(4) = −8. g(1) неге тең?

  2. Ауа шарының биіктігі h(t) = 1200 − 150t (метр, t - минут). Қай тұжырым дұрыс?

    1. Шар минутына 150 м көтеріледі
    2. Шар минутына 150 м төмендейді
    3. Шар 150 минутта жерге қонады
    4. Шардың бастапқы биіктігі 150 м

  3. Курьерлік қызмет 5 км-ге жеткізу үшін 1400 теңге, 12 км үшін 2450 теңге алады. Баға қашықтыққа сызықтық тәуелді. Тапсырыстың қашықтыққа тәуелсіз тұрақты бөлігі неше теңге?

Түйін

  • f(a) - x орнына a қою; f(x) = c - теңдеу шешу.
  • Көлбеулік m = Δy / Δx: x бір бірлікке өскендегі y-тің өзгерісі.
  • y = mx + b: b - бастапқы мән (x = 0), m - өзгеріс жылдамдығы.
  • Екі нүктеден: алдымен m, сосын бір нүктені қойып b.
  • Контексте m-нің бірлігі - «y бірлігі / x бірлігі».
