Дәреже және түбір: бес ереже, бір тіл

  • орта
  • ≈ 45 мин
  • 10 жаттығу

Не үйренесіз

  • Дәреже ережелерін жаттамай, мағынасынан шығарып қолдану.
  • Нөл, теріс және бөлшек көрсеткіштердің не білдіретінін түсіну.
  • Түбірді ықшамдау және түбір мен бөлшек көрсеткішті бір-біріне аудару.
  • Негіздері бірдей көрсеткіштік теңдеуді және түбірлі теңдеуді шешу.

Алдымен ойланыңыз

Қалыңдығы 0,1 мм қағаз парағын екіге бүктейміз: қалыңдығы 0,2 мм. Тағы бүктейміз: 0,4 мм. Әр бүктеген сайын қалыңдық екі еселенеді. Шын қағазды 7-8 реттен артық бүктеу қиын, бірақ ойша 20 рет бүктеп көрейік. Қалыңдық 0,1 · 2 · 2 · ... · 2 (жиырма рет) болады. Осындай қайталанған көбейтуді қысқа жазу үшін дәреже ойлап табылған: 0,1 · 220.

Болжаңыз: 20 рет бүктелген қағаздың қалыңдығы шамамен қандай?

  1. 2 мм шамасы
  2. 4 см шамасы
  3. 100 метрден астам

Түсіндірме

Дәреже - қайталанған көбейту

an жазуында a - негіз (base), n - көрсеткіш (exponent). Натурал n үшін бұл - a-ны өзіне n рет көбейту:

25 = 2 · 2 · 2 · 2 · 2 = 32

Екі жиі шатасатын жазу: (−3)2 = 9, өйткені негіз −3; ал −32 = −9, өйткені алдымен 3 квадратталады, минус сосын қойылады. Сол сияқты 2x3 өрнегінде дәрежеге тек x шығарылады, ал (2x)3 = 8x3.

Бес ереже - бәрі санаудан шығады

Ережелерді жаттаудың қажеті жоқ - көбейткіштерді санасаңыз болды. a3 · a2 = (a · a · a) · (a · a) - бес көбейткіш, яғни a5.

ЕрежеФормулаМысал
көбейту (негіздері бірдей)am · an = am+nx3 · x4 = x7
бөлуam / an = am−nx9 / x2 = x7
дәрежені дәрежелеу(am)n = amn(x3)4 = x12
көбейтіндінің дәрежесі(ab)n = anbn(2x)3 = 8x3
бөлшектің дәрежесі(a/b)n = an/bn(x/3)2 = x2/9

Екі шектеу: 1) алғашқы екі ереже тек негіздері бірдей болғанда жұмыс істейді - 23 · 52 ықшамдалмайды; 2) қосуға ереже жоқ: x3 + x4 - x7 емес, ал (a + b)2 - a2 + b2 емес.

Нөл және теріс көрсеткіш

Заңдылыққа қараңыз: көрсеткіш 1-ге кеміген сайын мән 2-ге бөлінеді.

23 = 8, 22 = 4, 21 = 2, 20 = 1, 2−1 = 1/2, 2−2 = 1/4

Осыдан екі анықтама шығады (a ≠ 0):

a0 = 1    және    a−n = 1 / an

Теріс көрсеткіш санды теріс етпейді - ол «бөлшектің екінші қабатына көшір» дегенді білдіреді: 5−2 = 1/25 = 0,04, ал 1 / x−3 = x3. Бөлу ережесімен де тексеруге болады: x2 / x5 = x−3, ал қысқартсақ 1 / x3 қалады.

Түбір - бөлшек көрсеткіш

√9 = 3, өйткені 32 = 9. Түбірді дәреже тілінде жазуға болады: √a = a1/2. Неге? (a1/2)2 = a1 = a - дәл квадрат түбірдің анықтамасы.

a1/n = n√a    am/n = (n√a)m

Бөлшек көрсеткіште бөлім - түбірдің дәрежесі, алым - кәдімгі дәреже. 82/3: алдымен куб түбір (2), сосын квадрат (4). Алдымен түбірді алған оңай - сандар кішірейеді.

Түбірді ықшамдау - ішінен толық квадратты шығару: √72 = √(36 · 2) = 6√2. Ережелері: √(ab) = √a · √b және √(a/b) = √a / √b. Бірақ қосуда жұмыс істемейді: √(9 + 16) = √25 = 5, ал √9 + √16 = 7.

Теңдеулер: негізді теңестір, түбірден құтыл

Көрсеткіштік теңдеу. Екі жақты бір негізге келтірсеңіз, көрсеткіштерді теңестіруге болады:

3x+2 = 81 → 3x+2 = 34 → x + 2 = 4 → x = 2

Негіздер әртүрлі көрінсе, ортақ негіз іздеңіз: 4 = 22, 8 = 23, 9 = 32, 27 = 33, 25 = 52.

Түбірлі теңдеу. Түбірді жалғыз қалдырып, екі жақты квадраттаймыз. Бірақ квадраттау «бөгде» түбір тудыруы мүмкін, сондықтан тексеру міндетті:

√(x + 2) = x → x + 2 = x2 → x2 − x − 2 = 0 → x = 2 не x = −1

x = 2: √4 = 2 - дұрыс. x = −1: √1 = 1, ал оң жақ −1 - сәйкес емес. Жауап тек x = 2. (√ белгісі әрқашан теріс емес мән береді.)

Емтихандағы әдіс: «Бір негіз - бір тіл»

  1. Бәрін дәреже тіліне аударТүбірді бөлшек көрсеткішке (√x = x^(1/2)), бөлшекті теріс көрсеткішке (1/x² = x⁻²) ауыстырыңыз. Сандарды ортақ негізге келтіріңіз.
  2. Ережені көбейткіштерге ғана қолданКөбейту - көрсеткіштерді қосу, бөлу - азайту, дәрежені дәрежелеу - көбейту. Қосылғыштарға бұл ережелер жүрмейді.
  3. Жауап түріне келтірНұсқаларға қараңыз: түбірмен бе, оң көрсеткішпен бе? Өрнекті сол түрге қайта аударыңыз.
  4. Санмен тексерКүмән болса, x = 2 сияқты ыңғайлы сан қойып, бастапқы өрнек пен жауапты салыстырыңыз. Түбірлі теңдеуде әр түбірді бастапқы теңдеуге қойыңыз.

Қадамдық мысалдар

Әр қадамды кезекпен ашыңыз: алдымен келесі қадамды өзіңіз болжап көріңіз.

1-мысал

Өрнекті ықшамдаңыз (x, y ≠ 0): (2x3y)2 · x−4 / (4y5)

  1. Жақшаны дәрежелейміз - әр көбейткішке жеке: (2x3y)2 = 4x6y2.
  2. x-терді жинаймыз: x6 · x−4 = x6−4 = x2.
  3. Сандар: 4 / 4 = 1. y-тер: y2 / y5 = y−3.
  4. Нәтиже: x2y−3. Оң көрсеткішпен жазсақ: x2 / y3.
  5. Тексеру (x = 2, y = 1): бастапқысы (2 · 8 · 1)2 · (1/16) / 4 = 256 / 64 = 4; жауап 4 / 1 = 4.

Жауап: x2 / y3

Қақпан: (2x³y)² ішіндегі 2-ні квадраттауды ұмытып, 2x⁶y² деп жазу.

2-мысал

Есептеңіз: 93/2 · 27−1/3

  1. 93/2: бөлім 2 - квадрат түбір, алым 3 - куб. √9 = 3, 33 = 27.
  2. 27−1/3: минус - «бөлшекке айналдыр», 1/3 - куб түбір. ∛27 = 3, демек 1/3.
  3. Көбейтеміз: 27 · (1/3) = 9.
  4. Екінші жол: бәрін 3 негізіне келтіру. 93/2 = (32)3/2 = 33; 27−1/3 = (33)−1/3 = 3−1. Көбейтінді 32 = 9.

Жауап: 9

Қақпан: 27^(−1/3)-ті −3 деп есептеу: теріс көрсеткіш таңбаны өзгертпейді, санды бөлімге түсіреді.

3-мысал

Теңдеуді шешіңіз: 4x = 8x−1

  1. Ортақ негіз - 2: 4 = 22, 8 = 23.
  2. Сол жақ: (22)x = 22x. Оң жақ: (23)x−1 = 23x−3 (3-ті жақшадағы екі мүшеге де көбейтеміз).
  3. Негіздер тең, демек көрсеткіштер тең: 2x = 3x − 3 → x = 3.
  4. Тексеру: 43 = 64 және 82 = 64.

Жауап: x = 3

Қақпан: (2³)^(x−1)-ді 2^(3x−1) деп жазу: 3 тек x-ке емес, бүкіл (x − 1)-ге көбейтіледі.

Жиі қателер

  • x³ · x⁴ = x¹² деп көрсеткіштерді көбейту.Неге қате: Көбейтуде көрсеткіштер қосылады; олар тек дәрежені дәрежелегенде көбейтіледі.Дұрысы: Көбейткіштерді ойша санаңыз: үшеу мен төртеу - жетеу. x⁷.
  • 2⁻³ = −8 не −6 деп есептеу.Неге қате: Теріс көрсеткіш - кері сан, теріс сан емес.Дұрысы: 2⁻³ = 1 / 2³ = 1/8.
  • √(a² + b²) = a + b деп түбірді қосылғыштарға бөлу.Неге қате: Түбір көбейтінді мен бөліндіге ғана таралады.Дұрысы: Санмен тексеріңіз: √(9 + 16) = 5, ал 3 + 4 = 7.
  • Түбірлі теңдеуде табылған түбірлердің бәрін жауап деп жазу.Неге қате: Екі жақты квадраттау бөгде түбір қосуы мүмкін.Дұрысы: Әр түбірді бастапқы теңдеуге қойып тексеріңіз; √ мәні теріс бола алмайды.

Жаттығу

Қате жауапқа себебі түсіндіріледі. Көмек үш деңгейлі: бағыт, ұқсас мысал, қадамдық шешім.

  1. Есептеңіз: 2³ · 2⁴ / 2⁵

  2. (x⁵)² · x⁻³ = xⁿ болса, n неге тең?

  3. 5⁻² мәнін ондық бөлшекпен жазыңыз.

  4. 16^(3/4) неге тең?

  5. √50 өрнегінің ықшамдалған түрі қайсы?

    1. 25√2
    2. 5√2
    3. 2√5
    4. 10√5

  6. 3^(x + 2) = 81 теңдеуін шешіңіз. x неге тең?

Меңгеруді тексеру

Жаңа есептер, көмексіз. Бәрін дұрыс шешсеңіз, сабақ «меңгерілді» деп белгіленеді (AO17 ережесі, ресми емтихан бағасы емес).

  1. 2^(3x − 1) = 32 теңдеуінде x неге тең?

  2. 27^(2/3) + 4^(−1/2) қосындысын ондық бөлшекпен жазыңыз.

  3. x > 0 үшін x^(−3/2) өрнегіне қайсысы тең?

    1. −√(x³)
    2. 1 / √(x³)
    3. 1 / ∛(x²)
    4. √(x³)

  4. √(2x + 3) = x теңдеуінің шешімін табыңыз.

Түйін

  • Негіздері бірдей: көбейту - көрсеткіштерді қосу, бөлу - азайту, дәрежені дәрежелеу - көбейту.
  • a⁰ = 1; a⁻ⁿ = 1 / aⁿ - теріс көрсеткіш кері санды береді, теріс санды емес.
  • a^(m/n): бөлім - түбір дәрежесі, алым - дәреже.
  • Дәреже мен түбір көбейтінді мен бөліндіге таралады, қосындыға таралмайды.
  • Көрсеткіштік теңдеуде негіздерді теңестіріңіз; түбірлі теңдеуде әр түбірді тексеріңіз.
