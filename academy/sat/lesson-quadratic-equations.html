Квадрат теңдеулер: жіктеу, формула, дискриминант

  • орта
  • ≈ 50 мин
  • 10 жаттығу

Не үйренесіз

  • Квадрат теңдеуді үш тәсілмен шешу: түбір алу, жіктеу, формула.
  • Дискриминант арқылы шешім санын шешпей-ақ анықтау.
  • Түбірлердің қосындысы мен көбейтіндісін коэффициенттерден табу.
  • Мәтінді есепте мағынасыз түбірді алып тастау.

Алдымен ойланыңыз

Мектеп ауласына тіктөртбұрышты гүлзар жасалмақ. Ұзындығы енінен 3 метрге артық, ал ауданы дәл 40 м² болуы керек. Енін x десек, ұзындығы x + 3, ауданы x(x + 3) = 40. Жақшаны ашсақ, x2 + 3x = 40 шығады. Мұнда x бір мезгілде квадратта да, бірінші дәрежеде де тұр - оны сызықтық теңдеудегідей «бір жаққа жинап, бөле салу» мүмкін емес. Мұндай теңдеуге жаңа құралдар керек.

Болжаңыз: гүлзардың ені неше метр?

  1. 4 м
  2. 5 м
  3. 8 м

Түсіндірме

Квадрат теңдеу және неге екі жауап

Квадрат теңдеудің стандарт түрі:

ax2 + bx + c = 0,   a ≠ 0

Ең қарапайым жағдай: x2 = 9. 32 = 9, бірақ (−3)2 де 9. Сондықтан екі жауап бар: x = 3 және x = −3. Қысқаша: x = ±3. Квадраттау таңбаны «жасырады», сондықтан кері амалда екі мүмкіндікті де қалпына келтіру керек. Квадрат теңдеудің нақты түбірлері екеу, біреу не мүлде жоқ болуы мүмкін.

Түбір алу тәсілі - x тек квадрат ішінде тұрғанда:

(x − 2)2 = 25 → x − 2 = ±5 → x = 7 не x = −3

Жақшаны ашудың қажеті жоқ - бірден екі жақтан түбір аламыз, ± белгісін ұмытпаймыз.

Жіктеу және нөлдік көбейтінді

Негізгі идея: көбейтінді нөлге тең болса, көбейткіштердің кемінде біреуі нөл. Басқа ешбір сан бұлай «жіктелмейді»: A · B = 40 болса, A мен B туралы ештеңе айта алмаймыз.

Сондықтан алдымен бәрін бір жаққа жинап, оң жақта нөл қалдырамыз:

x2 + 3x = 40 → x2 + 3x − 40 = 0 → (x + 8)(x − 5) = 0

x + 8 = 0 не x − 5 = 0, яғни x = −8 не x = 5. Назар аударыңыз: түбірдің таңбасы жақшадағы санға қарама-қарсы.

Бос мүше жоқ болса, x-ті жақша сыртына шығарамыз: x2 = 6x → x2 − 6x = 0 → x(x − 6) = 0 → x = 0 не x = 6. Екі жақты x-ке бөлуге болмайды: сонда x = 0 түбірі жоғалады.

Формула және дискриминант

Жіктеу әрдайым «әдемі» шықпайды. Кез келген квадрат теңдеуге жарайтын формула:

x = (−b ± √D) / (2a),   D = b2 − 4ac

D - дискриминант. Мысал: 2x2 − 3x − 1 = 0. a = 2, b = −3, c = −1. D = (−3)2 − 4 · 2 · (−1) = 9 + 8 = 17. x = (3 ± √17) / 4.

Дискриминант түбір астында тұр, сондықтан оның таңбасы шешім санын шешеді:

DНақты шешім саныГрафикте
D > 0екі әртүрліпарабола x осін екі нүктеде қияды
D = 0бір (қайталанған)парабола x осіне жанасады
D < 0жоқпарабола x осіне тимейді

«Теңдеудің неше шешімі бар?» не «бір ғана шешімі болуы үшін k неге тең?» деген сұрақтарда теңдеуді шешпейміз - тек D-ны есептейміз.

Түбірлердің қосындысы мен көбейтіндісі

ax2 + bx + c = 0 теңдеуінің түбірлері x₁ және x₂ болса:

x₁ + x₂ = −b / a,   x₁ · x₂ = c / a

Неге? Формуладағы екі түбірді қоссақ, ±√D қысқарады да, −2b / (2a) = −b / a қалады. Мысал: 2x2 − 14x + 9 = 0 түбірлері «ыңғайсыз» сандар, бірақ қосындысы бірден: 14 / 2 = 7; көбейтіндісі: 9 / 2 = 4,5. SAT осы қысқа жолды тексергенді ұнатады.

Толық квадратқа келтіру - тағы бір тәсіл: x2 + 6x − 7 = 0 → x2 + 6x = 7. Сол жақты толық квадрат ету үшін (6/2)2 = 9 қосамыз: x2 + 6x + 9 = 16 → (x + 3)2 = 16 → x + 3 = ±4 → x = 1 не x = −7.

Түзу мен параболаның қиылысуы

Бір теңдеуі квадраттық жүйе алмастырумен шешіледі. y = x2 және y = 2x + 3: оң жақтарын теңестіреміз.

x2 = 2x + 3 → x2 − 2x − 3 = 0 → (x − 3)(x + 1) = 0

x = 3 (сонда y = 9) және x = −1 (сонда y = 1). Қиылысу нүктелері: (3; 9) және (−1; 1). Қиылысу нүктелерінің саны да шыққан квадрат теңдеудің дискриминантымен анықталады: D > 0 - екеу, D = 0 - түзу параболаға жанасады, D < 0 - қиылыспайды.

Емтихандағы әдіс: «Нөлге келтір - тәсіл таңда - сүз»

  1. Стандарт түрге келтірЖақшаларды ашып, бәрін бір жаққа жинаңыз: ax² + bx + c = 0. Ортақ санға бөлуге болады, бірақ x-ке бөлуге болмайды.
  2. Сұрақ түрін таныШешім саны сұралса - тек дискриминант. Түбірлердің қосындысы не көбейтіндісі сұралса - −b/a және c/a. Түбірлердің өзі керек болса - келесі қадам.
  3. Ең жеңіл тәсілмен шешx тек квадрат ішінде - түбір алу (±). Жұп сан тез табылса - жіктеу. 20 секундта табылмаса - формула.
  4. Түбірлерді сүзМәтінді есепте теріс ұзындық, теріс уақыт сияқты мағынасыз түбірді алып тастаңыз. Қалғанын бастапқы теңдеуге қойып тексеріңіз.

Қадамдық мысалдар

Әр қадамды кезекпен ашыңыз: алдымен келесі қадамды өзіңіз болжап көріңіз.

1-мысал

Теңдеуді шешіңіз: 2x2 − 5x − 3 = 0

  1. a ≠ 1, сондықтан a · c = 2 · (−3) = −6. Көбейтіндісі −6, қосындысы −5 болатын екі сан: −6 және 1.
  2. Ортаңғы мүшені бөлеміз: 2x2 − 6x + x − 3 = 0.
  3. Топтаймыз: 2x(x − 3) + 1(x − 3) = 0 → (2x + 1)(x − 3) = 0.
  4. 2x + 1 = 0 → x = −1/2. x − 3 = 0 → x = 3.
  5. Тексеру: түбірлер қосындысы 2,5 = −b/a = 5/2; көбейтіндісі −1,5 = c/a = −3/2. Сәйкес.

Жауап: x = 3 не x = −1/2

Қақпан: (2x + 1) жақшасынан x = −1 деп жазу: 2x + 1 = 0 теңдеуін соңына дейін шешу керек, x = −1/2.

2-мысал

x2 − 6x + k = 0 теңдеуінің дәл бір нақты шешімі болса, k тұрақтысы неге тең?

  1. Бір шешім - дискриминант нөлге тең.
  2. a = 1, b = −6, c = k. D = (−6)2 − 4 · 1 · k = 36 − 4k.
  3. 36 − 4k = 0 → k = 9.
  4. Тексеру: x2 − 6x + 9 = (x − 3)2 = 0 - жалғыз шешім x = 3.

Жауап: k = 9

Қақпан: b² есептегенде (−6)² = −36 деп алу: теріс санның квадраты оң.

3-мысал

Биіктігі 25 м мұнарадан доп жоғары лақтырылды. Оның жерден биіктігі (метр) t секундтан кейін h = −5t2 + 20t + 25 формуласымен беріледі. Доп неше секундтан кейін жерге түседі?

  1. Жерде h = 0: −5t2 + 20t + 25 = 0.
  2. Екі жақты −5-ке бөлеміз (санға бөлуге болады): t2 − 4t − 5 = 0.
  3. Жіктейміз: көбейтіндісі −5, қосындысы −4: (t − 5)(t + 1) = 0 → t = 5 не t = −1.
  4. Уақыт теріс болмайды, t = −1 алынбайды. Тексеру: −5 · 25 + 100 + 25 = 0.

Жауап: 5 секунд

Қақпан: t = 0 кезіндегі 25-ті «жауап» деп ойлау: ол - бастапқы биіктік, ал сұрақ h = 0 болатын уақытты сұрайды.

Жиі қателер

  • x² = 9 → x = 3 (бір ғана жауап).Неге қате: Теріс санның квадраты да оң: (−3)² = 9.Дұрысы: Түбір алғанда әрқашан ± жазыңыз: x = ±3.
  • x² + 3x = 40 → x(x + 3) = 40 → x = 40 не x + 3 = 40.Неге қате: Нөлдік көбейтінді қасиеті тек оң жақта 0 тұрғанда жұмыс істейді.Дұрысы: Алдымен 40-ты сол жаққа өткізіңіз: x² + 3x − 40 = 0, сосын жіктеңіз.
  • x² = 6x теңдеуінің екі жағын x-ке бөліп, x = 6 деп қана жазу.Неге қате: x = 0 де шешім, ал нөлге бөлуге болмайды - түбір жоғалды.Дұрысы: Бөлмеңіз, жақша сыртына шығарыңыз: x(x − 6) = 0.
  • Дискриминантта теріс c-ны ескермеу: 9 − 8 орнына 9 + 8 болуы керек.Неге қате: −4ac ішінде c теріс болса, екі минус плюс береді.Дұрысы: a, b, c мәндерін таңбасымен бөлек жазып алыңыз, сосын ғана формулаға қойыңыз.

Жаттығу

Қате жауапқа себебі түсіндіріледі. Көмек үш деңгейлі: бағыт, ұқсас мысал, қадамдық шешім.

  1. x² − 9x + 20 = 0 теңдеуінің кіші түбірін табыңыз.

  2. (x − 3)² = 16 теңдеуінің үлкен түбірін табыңыз.

  3. 3x² − 5x + 2 = 0 теңдеуінің дискриминантын есептеңіз.

  4. x² + 4x + 7 = 0 теңдеуінің неше нақты шешімі бар?

    1. Нақты шешімі жоқ
    2. Дәл бір шешім
    3. Екі шешім
    4. Шексіз көп шешім

  5. 2x² − 14x + 9 = 0 теңдеуінің түбірлерінің қосындысы неге тең?

  6. x² = 6x теңдеуінің барлық шешімі қайсы?

    1. Тек x = 6
    2. x = 0 және x = 6
    3. x = −6 және x = 6
    4. x = 0 және x = −6

Меңгеруді тексеру

Жаңа есептер, көмексіз. Бәрін дұрыс шешсеңіз, сабақ «меңгерілді» деп белгіленеді (AO17 ережесі, ресми емтихан бағасы емес).

  1. 2x² + 3x − 20 = 0 теңдеуінің оң түбірін табыңыз.

  2. x² + kx + 16 = 0 теңдеуінің дәл бір нақты шешімі бар және k > 0. k неге тең?

  3. Тіктөртбұрыштың ұзындығы енінен 4 см артық, ауданы 96 см². Периметрі неше сантиметр?

  4. y = x² − 2x параболасы мен y = x + 4 түзуі екі нүктеде қиылысады. Қиылысу нүктелерінің x координаталарының үлкенін табыңыз.

Түйін

  • Стандарт түр: ax² + bx + c = 0. Алдымен бәрін бір жаққа жинаңыз.
  • Түбір алғанда ± ұмытпаңыз; x-ке бөлмеңіз - жақша сыртына шығарыңыз.
  • Нөлдік көбейтінді: (x − p)(x − q) = 0 → x = p не x = q.
  • x = (−b ± √D) / (2a); D = b² − 4ac: оң - екі шешім, нөл - бір, теріс - жоқ.
  • Түбірлер қосындысы −b/a, көбейтіндісі c/a.
  • Мәтінді есепте мағынасыз (теріс) түбірді алып тастаңыз.
