Көпмүшелер: жақшаны ашу және көбейткіштерге жіктеу

  • орта
  • ≈ 45 мин
  • 11 жаттығу

Не үйренесіз

  • Көпмүшелерді қосу, азайту және көбейту (жақшаны қатесіз ашу).
  • Қысқаша көбейту формулаларын екі бағытта да қолдану.
  • Квадрат үшмүшені көбейткіштерге жіктеу.
  • Эквивалент өрнектерді коэффициенттерін салыстыру арқылы табу.

Алдымен ойланыңыз

47 · 53 көбейтіндісін калькуляторсыз, бағандап жазбай-ақ бес секундта табуға бола ма? Болады. 47 - бұл 50 − 3, ал 53 - бұл 50 + 3. Алгебрада (a − b)(a + b) = a2 − b2 деген тепе-теңдік бар. Демек көбейтінді 502 − 32 болады. Бір өрнекті екі түрде - «жақшалы» және «ашылған» - жаза білу есептеуді де, теңдеу шешуді де жеңілдетеді. Бұл сабақ сол екі бағыттағы жолды үйретеді.

Түсіндірме

Көпмүше және ұқсас мүшелер

Көпмүше (polynomial) - бірнеше мүшенің қосындысы: 3x2 − 5x + 7. Әр мүше - коэффициент пен айнымалының дәрежесінің көбейтіндісі. Ең үлкен көрсеткіш - көпмүшенің дәрежесі (мұнда 2). Айнымалысыз мүше (7) - бос мүше.

Ұқсас мүшелер - айнымалы бөлігі дәл бірдей мүшелер: 3x2 пен −8x2 ұқсас, ал 3x2 пен 3x - жоқ (алма мен алмұртты қоспаймыз). Қосқанда тек коэффициенттер қосылады:

(2x2 − 3x + 5) + (x2 + 4x − 2) = 3x2 + x + 3

Азайтқанда минус екінші жақшаның әр мүшесінің таңбасын өзгертеді:

(2x2 − 3x + 5) − (x2 + 4x − 2) = 2x2 − 3x + 5 − x2 − 4x + 2 = x2 − 7x + 7

Көбейту: әр мүшені әр мүшеге

Екі жақшаны көбейткенде біріншінің әр мүшесі екіншінің әр мүшесіне көбейтіледі. Екі екімүше үшін төрт көбейтінді шығады:

(x + 3)(x − 5) = x · x + x · (−5) + 3 · x + 3 · (−5) = x2 − 5x + 3x − 15 = x2 − 2x − 15

Мүшелер көбейсе де ереже сол. (x − 3)(x2 + 2x − 4): x-ті үшеуіне көбейтеміз (x3 + 2x2 − 4x), сосын −3-ті үшеуіне (−3x2 − 6x + 12). Жинасақ: x3 − x2 − 10x + 12.

Тексеру тәсілі: көбейтінді саны = мүшелер санының көбейтіндісі (2 · 3 = 6 көбейтінді). Бір мүшені жоғалтсаңыз, осы санақтан бірден байқалады.

Үш формула - екі бағытта

Үш көбейтінді соншалық жиі кездеседі, оларды дайын күйінде білген тиімді:

АтауыЖақшалы түріАшылған түрі
қосындының квадраты(a + b)2a2 + 2ab + b2
айырманың квадраты(a − b)2a2 − 2ab + b2
квадраттар айырмасы(a − b)(a + b)a2 − b2

Неге (a + b)2 ішінде 2ab бар? Қабырғасы a + b шаршыны елестетіңіз: ол a2 және b2 екі шаршыға және ауданы ab болатын екі тіктөртбұрышқа бөлінеді. Сондықтан (x + 5)2 = x2 + 10x + 25, ал x2 + 25 емес.

Формулалар оңнан солға да оқылады - бұл жіктеу: 4x2 − 25 = (2x)2 − 52 = (2x − 5)(2x + 5). Ескерту: квадраттар қосындысы a2 + b2 нақты сандарда жіктелмейді.

Жіктеу: көбейтуді кері айналдыру

Көбейткіштерге жіктеу (factoring) - қосындыны көбейтінді түрінде жазу. Реті әрқашан бірдей:

1. Ортақ көбейткішті шығар. 3x3 − 12x2 − 15x = 3x(x2 − 4x − 5).

2. x2 + bx + c үшмүшесі. (x + p)(x + q) = x2 + (p + q)x + pq болғандықтан, көбейтіндісі c, қосындысы b болатын екі сан іздейміз. x2 − 4x − 5: көбейтіндісі −5, қосындысы −4 - бұл −5 және 1. Демек (x − 5)(x + 1).

c таңбасыb таңбасыp мен q
++екеуі де оң
+−екеуі де теріс
−кез келгентаңбалары әртүрлі; модулі үлкенінің таңбасы b-мен бірдей

3. ax2 + bx + c (a ≠ 1). Көбейтіндісі a · c, қосындысы b болатын екі сан тауып, ортаңғы мүшені бөлеміз. 2x2 + 7x + 3: a · c = 6, сандар 6 және 1. 2x2 + 6x + x + 3 = 2x(x + 3) + 1(x + 3) = (2x + 1)(x + 3).

Жіктеуді әрқашан кері көбейтіп тексеріңіз - бұл 10 секунд.

Эквивалент өрнектер: коэффициенттерді салыстыру

SAT жиі былай сұрайды: «(2x + 3)(ax − 5) = 8x2 + bx − 15 барлық x үшін орындалады. b неге тең?» Екі көпмүше барлық x үшін тең болса, олардың сәйкес коэффициенттері тең. Сол жақты ашамыз: 2ax2 + (3a − 10)x − 15. x2 алдында: 2a = 8, a = 4. x алдында: b = 3 · 4 − 10 = 2.

Жіктеу бөлшекті қысқартуға да керек: (x2 − 9) / (x2 + x − 6) = (x − 3)(x + 3) / ((x + 3)(x − 2)) = (x − 3) / (x − 2). Қысқартуға тек көбейткіштер жатады; x2-тарды «сызып тастауға» болмайды.

Нұсқалардың қайсысы эквивалент екеніне сенімсіз болсаңыз, x = 2 сияқты сан қойып, бастапқы өрнек пен нұсқаның мәнін салыстырыңыз.

Емтихандағы әдіс: «Ортақ - формула - жұп сан»

  1. Бағытты анықтаНұсқалар жақшалы ма (жіктеу керек), әлде ашылған ба (көбейту керек)? Сұрақ бір ғана коэффициентті сұраса, тек соған үлес қосатын көбейтінділерді есептеңіз.
  2. Ортақ көбейткішті шығарЖіктеуді әрқашан осыдан бастаңыз: сан да, x-тің дәрежесі де ортақ болуы мүмкін.
  3. Формуланы таны не жұп сан іздеЕкі мүше, арасында минус, екеуі де квадрат - квадраттар айырмасы. Үш мүше - көбейтіндісі c (не ac), қосындысы b болатын екі сан.
  4. Кері көбейтіп тексерЖақшаларды ойша ашып, бастапқы өрнек шығатынына көз жеткізіңіз не x орнына сан қойыңыз.

Қадамдық мысалдар

Әр қадамды кезекпен ашыңыз: алдымен келесі қадамды өзіңіз болжап көріңіз.

1-мысал

Ашып, ықшамдаңыз: (3x − 2)2 − (x + 4)(x − 4)

  1. Бірінші бөлік - айырманың квадраты: (3x)2 − 2 · 3x · 2 + 22 = 9x2 − 12x + 4.
  2. Екінші бөлік - квадраттар айырмасы: (x + 4)(x − 4) = x2 − 16.
  3. Азайтамыз, екінші бөлікті жақшада ұстаймыз: 9x2 − 12x + 4 − (x2 − 16).
  4. Минус екі таңбаны да өзгертеді: 9x2 − 12x + 4 − x2 + 16 = 8x2 − 12x + 20.
  5. Тексеру (x = 1): бастапқысы 12 − 5 · (−3) = 1 + 15 = 16; жауап 8 − 12 + 20 = 16.

Жауап: 8x2 − 12x + 20

Қақпан: −(x² − 16)-ны −x² − 16 деп ашу: сонда бос мүше 20 емес, −12 шығады.

2-мысал

Толық жіктеңіз: 3x3 − 12x2 − 15x

  1. Ортақ көбейткіш: әр мүше 3-ке де, x-ке де бөлінеді. 3x(x2 − 4x − 5).
  2. Жақшадағы үшмүше: көбейтіндісі −5, қосындысы −4 болатын сандар. −5 пен 1: (−5) · 1 = −5, −5 + 1 = −4.
  3. x2 − 4x − 5 = (x − 5)(x + 1).
  4. Толық жіктелуі: 3x(x − 5)(x + 1). Тексеру: (x − 5)(x + 1) = x2 − 4x − 5; 3x-ке көбейтсек бастапқы өрнек.

Жауап: 3x(x − 5)(x + 1)

Қақпан: 3x(x² − 4x − 5) күйінде тоқтап қалу: «толық жіктеңіз» дегенде әр көбейткіш ары қарай жіктелмейтін болуы керек.

3-мысал

(2x + 3)(ax − 5) = 8x2 + bx − 15 теңдігі барлық x үшін орындалады (a, b - тұрақтылар). b неге тең?

  1. Сол жақты ашамыз: 2x · ax + 2x · (−5) + 3 · ax + 3 · (−5) = 2ax2 + (3a − 10)x − 15.
  2. x2 коэффициенттерін теңестіреміз: 2a = 8 → a = 4.
  3. x коэффициенттері: b = 3a − 10 = 12 − 10 = 2.
  4. Бос мүшелер: −15 = −15 - сәйкес. Тексеру (x = 1): (5)(−1) = −5 және 8 + 2 − 15 = −5.

Жауап: b = 2

Қақпан: a = 4 деп жауап беру не b-ны есептегенде −10x мүшесін ұмыту (сонда b = 12 шығады).

Жиі қателер

  • (x + 5)² = x² + 25.Неге қате: Ортаңғы мүше 2ab жоғалды: шаршыда екі тіктөртбұрыш бар.Дұрысы: (x + 5)² = (x + 5)(x + 5) = x² + 10x + 25. Күмәндансаңыз, екі жақшаны жазып көбейтіңіз.
  • Азайтқанда тек бірінші мүшенің таңбасын өзгерту.Неге қате: Жақша алдындағы минус - бүкіл жақшаны −1-ге көбейту.Дұрысы: −(x² + 4x − 2) = −x² − 4x + 2. Әр таңбаны жеке аударыңыз.
  • x² − 2x − 15 = (x − 3)(x + 5) деп таңбаларды шатастыру.Неге қате: Көбейтінді −15 дұрыс, бірақ қосынды +2 шығады, ал керегі −2.Дұрысы: Модулі үлкен сан b-ның таңбасын алады: (x − 5)(x + 3).
  • Бөлшекте қосылғыштарды қысқарту: (x² − 9)/(x² + x − 6)-да x²-тарды сызу.Неге қате: Қысқарту - алым мен бөлімді бір санға бөлу; ол тек ортақ көбейткішке жарайды.Дұрысы: Алдымен алым мен бөлімді жіктеңіз, сосын бірдей жақшаларды қысқартыңыз.

Жаттығу

Қате жауапқа себебі түсіндіріледі. Көмек үш деңгейлі: бағыт, ұқсас мысал, қадамдық шешім.

  1. (2x² − 3x + 5) − (x² + 4x − 2) өрнегін ықшамдағанда x-тің коэффициенті неге тең?

  2. (x + 6)(x − 2) = x² + bx − 12 болса, b неге тең?

  3. x² − 7x + 12 үшмүшесінің жіктелуі қайсы?

    1. (x + 3)(x + 4)
    2. (x − 3)(x − 4)
    3. (x − 2)(x − 6)
    4. (x − 12)(x + 1)

  4. (3x − 4)² = 9x² + kx + 16 болса, k неге тең?

  5. 4x² − 25 өрнегінің жіктелуі қайсы?

    1. (2x − 5)²
    2. (4x − 5)(x + 5)
    3. (2x − 5)(2x + 5)
    4. Жіктелмейді

  6. x² + 2x − 35 = (x + a)(x + b), мұнда a > b. a неге тең?

  7. 2x² + 7x + 3 үшмүшесінің жіктелуі қайсы?

    1. (2x + 3)(x + 1)
    2. (2x + 1)(x + 3)
    3. (x + 1)(x + 3)
    4. 2(x + 1)(x + 3)

Меңгеруді тексеру

Жаңа есептер, көмексіз. Бәрін дұрыс шешсеңіз, сабақ «меңгерілді» деп белгіленеді (AO17 ережесі, ресми емтихан бағасы емес).

  1. (x − 3)(x² + 2x − 4) көбейтіндісін ашып жинағанда x-тің (бірінші дәрежелі мүшенің) коэффициенті неге тең?

  2. 2x³ − 18x өрнегінің толық жіктелуі қайсы?

    1. 2x(x² − 9)
    2. 2x(x − 3)²
    3. 2x(x − 3)(x + 3)
    4. x(2x − 6)(x + 3)

  3. (ax + 2)(3x − 1) = 12x² + bx − 2 теңдігі барлық x үшін орындалады. b неге тең?

  4. x + y = 9 және x − y = 4 болса, x² − y² неге тең?

Түйін

  • Қосу мен азайтуда тек ұқсас мүшелер жиналады; минус бүкіл жақшаның таңбаларын аударады.
  • Көбейтуде әр мүше әр мүшеге көбейтіледі.
  • (a ± b)² = a² ± 2ab + b²; (a − b)(a + b) = a² − b².
  • Жіктеу реті: ортақ көбейткіш → формула → көбейтіндісі c, қосындысы b болатын екі сан.
  • Барлық x үшін тең көпмүшелердің сәйкес коэффициенттері тең.
