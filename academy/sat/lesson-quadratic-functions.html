Квадраттық функция: парабола, төбе, үш жазылу түрі

  • орта
  • ≈ 50 мин
  • 11 жаттығу

Не үйренесіз

  • Параболаның бағытын, төбесін, нөлдерін және y-қиылысуын теңдеуден оқу.
  • Үш жазылу түрін (стандарт, жіктелген, төбелік) ажырату және әрқайсысы нені «көрсетіп тұрғанын» білу.
  • Ең үлкен не ең кіші мәнді төбе арқылы табу.
  • Контекстегі есепте төбе мен нөлдердің мағынасын түсіндіру.

Алдымен ойланыңыз

Баскетболшы допты 2 метр биіктіктен жоғары лақтырды. Доптың биіктігі (метр) t секундтан кейін шамамен h(t) = −5t2 + 10t + 2 формуласымен сипатталады. Доп алдымен көтеріледі, бір сәтке «тоқтайды», сосын төмен түседі. Оның жолы түзу емес - доға. Бұл доға парабола деп аталады, ал оның ең биік нүктесі - төбесі - есептің ең қызық жері: доп қаншалықты биікке жетеді?

Болжаңыз: доптың ең үлкен биіктігі қандай?

  1. 2 метр
  2. 7 метр
  3. 12 метр

Түсіндірме

Парабола және a-ның рөлі

Квадраттық функция: f(x) = ax2 + bx + c (a ≠ 0). Оның графигі - парабола: бір осьтен екі жаққа айнадай симметриялы қисық.

aПараболаТөбе
a > 0тармақтары жоғары («күлкі»)ең төменгі нүкте - минимум
a < 0тармақтары төмен («мұң»)ең жоғарғы нүкте - максимум

|a| үлкен болған сайын парабола тар (тік), кіші болған сайын жайпақ. Ал c - y-қиылысу: x = 0 қойсақ, f(0) = c. Доп мысалында c = 2 - лақтырылған сәттегі биіктік.

Сызықтық функциядан айырмасы: өзгеріс жылдамдығы тұрақты емес. y = x2 кестесінде x = 0, 1, 2, 3 болғанда y = 0, 1, 4, 9 - өсім 1, 3, 5 болып өзі өсіп отырады.

Үш жазылу түрі - үш түрлі ақпарат

Бір параболаны үш түрде жазуға болады. Әр түр бір нәрсені есептеусіз «көрсетіп тұрады»:

ТүріЖазылуыБірден көрінетіні
стандарт (standard)y = ax2 + bx + cy-қиылысу: (0; c)
жіктелген (factored)y = a(x − p)(x − q)нөлдер (x-қиылысулар): x = p, x = q
төбелік (vertex)y = a(x − h)2 + kтөбе: (h; k)

Мысал - бір функцияның үш жазылуы:

y = x2 − 8x + 12 = (x − 2)(x − 6) = (x − 4)2 − 4

Біріншісінен y-қиылысу 12, екіншісінен нөлдер 2 мен 6, үшіншісінен төбе (4; −4) көрінеді. SAT-тың сүйікті сұрағы: «Қай эквивалент түрде минимум мәні тұрақты не коэффициент ретінде көрінеді?» - жауабы әрқашан төбелік түр.

Таңбаға абай болыңыз: төбелік түрде жақшада x минус h тұр. y = (x − 3)2 + 5 төбесі (3; 5), ал y = (x + 2)2 − 1 төбесі (−2; −1), өйткені x + 2 = x − (−2).

Төбені табу

Парабола симметриялы, сондықтан төбе әрқашан екі нөлдің дәл ортасында жатыр. Осыдан екі жол шығады:

стандарт түрден: xтөбе = −b / (2a)     жіктелген түрден: xтөбе = (p + q) / 2

Сосын табылған x-ті функцияға қойып, y-ті есептейміз. Мысал: f(x) = x2 − 8x + 12. x = 8 / 2 = 4. f(4) = 16 − 32 + 12 = −4. Төбе (4; −4). Нөлдер арқылы: (2 + 6) / 2 = 4 - сол нәтиже.

Сөздерге дәл болыңыз:

  • «Функцияның ең кіші мәні» - төбенің y координатасы (−4).
  • «Функция ең кіші мәнін қай x-те қабылдайды» - төбенің x координатасы (4).
  • Симметрия осі - x = 4 тік түзуі.

Бір түрден екіншісіне көшу

Стандарттан төбелікке - толық квадратқа келтіру. y = x2 − 6x + 5: x алдындағы санның жартысы −3, оның квадраты 9. 9-ды қосып, бірден азайтамыз:

y = (x2 − 6x + 9) − 9 + 5 = (x − 3)2 − 4

Жылдам жол: төбені −b / (2a) арқылы тауып, a-ны сақтап, бірден жазу. y = 2x2 + 8x + 3: x = −8 / 4 = −2, y = 8 − 16 + 3 = −5. Демек y = 2(x + 2)2 − 5.

Төбе мен бір нүктеден теңдеу құру. Төбесі (3; −2), (5; 6) нүктесі арқылы өтеді: y = a(x − 3)2 − 2. Нүктені қоямыз: 6 = a · 4 − 2 → a = 2.

Жылжулар. g(x) = f(x − 3) + 2 графикті 3 бірлік оңға, 2 бірлік жоғары жылжытады; төбе де солай жылжиды. Жақша ішіндегі өзгеріс «керісінше» әсер етеді: x + 3 - солға.

Контекст: төбе мен нөлдер нені білдіреді

Лақтырылған дене есебінде h(t) = −5t2 + 10t + 2:

  • c = 2 - бастапқы биіктік;
  • төбе (1; 7) - 1 секундта 7 метр максимум биіктікке жетеді;
  • оң нөл - дене жерге түсетін уақыт (h = 0).

Пайда не түсім есептерінде де парабола шығады: баға көтерілсе, сатылым азаяды, сондықтан түсім алдымен өсіп, сосын кемиді. Төбе - ең тиімді баға мен ең үлкен түсім. Сұрақ «қай бағада?» десе - төбенің x-і, «ең көп қанша?» десе - төбенің y-і.

Емтихандағы әдіс: «Түрін таны - керегін оқы»

  1. Не сұралғанын анықтаТөбе ме (максимум, минимум), нөлдер ме (x осін қиюы, жерге түсуі), әлде y-қиылысу ма (бастапқы мән)?
  2. Берілген түрге қараТөбелік түрде төбе дайын; жіктелген түрде нөлдер дайын, ал төбе - олардың ортасы; стандарт түрде x = −b / (2a).
  3. x-ті тап, сосын y-ті есептеТөбенің x координатасын функцияға қойып, мәнін табыңыз. Таңбаларға, әсіресе теріс санның квадратына абай болыңыз.
  4. Сұрақ сөзіне сәйкестендір«Қай уақытта», «қай бағада» - x. «Ең үлкен биіктік», «ең кіші мән» - y. a-ның таңбасы максимум не минимум екенін растайды.

Қадамдық мысалдар

Әр қадамды кезекпен ашыңыз: алдымен келесі қадамды өзіңіз болжап көріңіз.

1-мысал

f(x) = x2 − 8x + 12 функциясының төбесін, нөлдерін және y-қиылысуын табыңыз.

  1. y-қиылысу: f(0) = 12, нүкте (0; 12).
  2. Нөлдер: x2 − 8x + 12 = 0 → (x − 2)(x − 6) = 0 → x = 2 және x = 6.
  3. Төбенің x-і: −b / (2a) = 8 / 2 = 4 (не нөлдердің ортасы: (2 + 6) / 2 = 4).
  4. Төбенің y-і: f(4) = 16 − 32 + 12 = −4. Төбе: (4; −4).
  5. a = 1 > 0, парабола жоғары ашылған, демек −4 - ең кіші мән. Төбелік түрі: (x − 4)2 − 4.

Жауап: Төбе (4; −4); нөлдер 2 және 6; y-қиылысу 12

Қақпан: Ең кіші мән ретінде 4-ті (x координатасын) жазу: мән - y координатасы, яғни −4.

2-мысал

f(x) = −2(x + 1)(x − 5) функциясының ең үлкен мәнін табыңыз.

  1. Жіктелген түр - нөлдер дайын: x + 1 = 0 → x = −1; x − 5 = 0 → x = 5.
  2. Төбе нөлдердің ортасында: x = (−1 + 5) / 2 = 2.
  3. f(2) = −2 · (2 + 1) · (2 − 5) = −2 · 3 · (−3) = 18.
  4. a = −2 < 0 - парабола төмен ашылған, сондықтан 18 шынымен максимум.

Жауап: 18

Қақпан: Нөлдерді 1 және −5 деп алу: (x + 1) жақшасынан x = −1 шығады. Таңба қате болса, төбе x = −2-ге ығысады.

3-мысал

Шеберхананың апталық пайдасы (мың теңге) P(x) = −2x2 + 120x − 1000 формуласымен беріледі, мұнда x - бұйымның бағасы (жүз теңгемен). Қандай бағада пайда ең көп болады және ол қанша?

  1. a = −2 < 0, парабола төмен ашылған - максимум бар, ол төбеде.
  2. x = −b / (2a) = −120 / (2 · (−2)) = 30. Баға: 30 жүз теңге, яғни 3000 теңге.
  3. P(30) = −2 · 900 + 120 · 30 − 1000 = −1800 + 3600 − 1000 = 800.
  4. Бірліктерді қайтарамыз: 800 мың теңге.

Жауап: Бағасы 3000 теңге болғанда пайда ең көп - 800 мың теңге

Қақпан: −1000-ды «ең көп пайда» не «бастапқы пайда» деп түсіндіру: ол x = 0 кезіндегі мән, яғни тегін таратқандағы шығын.

Жиі қателер

  • y = (x + 2)² − 1 төбесін (2; −1) деп оқу.Неге қате: Төбелік түрде жақшада x − h тұр; x + 2 = x − (−2).Дұрысы: Жақшаны нөлге теңестіріңіз: x + 2 = 0 → x = −2. Төбе (−2; −1).
  • x = −b/(2a) формуласында таңбаны жоғалту.Неге қате: b теріс болса, −b оң болады; a теріс болса, бөлім теріс.Дұрысы: a мен b-ны таңбасымен жазып, жақшаға алып қойыңыз: −(−8) / (2 · 1) = 4.
  • «Ең үлкен мән» сұралғанда төбенің x координатасын беру.Неге қате: x - қай жерде, y - қаншалықты.Дұрысы: x-ті тапқан соң оны функцияға қойып, y-ті есептеңіз.
  • f(x − 3) графикті солға жылжытады деп ойлау.Неге қате: Жақша ішіндегі өзгеріс керісінше жұмыс істейді: бұрынғы мәнге жету үшін x 3-ке үлкен болуы керек.Дұрысы: f(x − 3) - 3 бірлік оңға; f(x + 3) - солға; f(x) + 3 - жоғары.

Жаттығу

Қате жауапқа себебі түсіндіріледі. Көмек үш деңгейлі: бағыт, ұқсас мысал, қадамдық шешім.

  1. f(x) = x² − 6x + 5 параболасының төбесінің x координатасын табыңыз.

  2. g(x) = x² − 10x + 21 функциясының ең кіші мәнін табыңыз.

  3. y = −3(x − 2)² + 7 параболасы туралы қай тұжырым дұрыс?

    1. Төбесі (−2; 7), бұл - минимум
    2. Төбесі (2; 7), бұл - максимум
    3. Төбесі (2; 7), бұл - минимум
    4. Төбесі (2; −3), бұл - максимум

  4. y = (x + 4)(x − 10) параболасының симметрия осі x = k түзуі. k неге тең?

  5. y = 2(x − 3)² − 5 параболасы y осін қай нүктеде қияды? y мәнін жазыңыз.

  6. y = x² − 2x − 8 функциясының қай эквивалент түрінде графиктің x-қиылысулары тұрақтылар ретінде көрініп тұр?

    1. y = (x − 1)² − 9
    2. y = (x − 4)(x + 2)
    3. y = x(x − 2) − 8
    4. y = (x + 4)(x − 2)

  7. Зымыран моделінің биіктігі h(t) = −5t² + 30t (метр, t - секунд). Ол ең көп неше метр биіктікке көтеріледі?

Меңгеруді тексеру

Жаңа есептер, көмексіз. Бәрін дұрыс шешсеңіз, сабақ «меңгерілді» деп белгіленеді (AO17 ережесі, ресми емтихан бағасы емес).

  1. f(x) = 2x² + 8x + 3 функциясының ең кіші мәнін табыңыз.

  2. Параболаның төбесі (3; −2) және ол (5; 6) нүктесі арқылы өтеді. Оның теңдеуі y = a(x − 3)² − 2 болса, a неге тең?

  3. f(x) = (x − 1)² + 4 берілген. g(x) = f(x + 3) − 6 функциясының графигінің төбесі қайда?

    1. (4; −2)
    2. (−2; −2)
    3. (−2; 10)
    4. (4; 10)

  4. f(x) = x² + bx + 10 параболасының төбесінің x координатасы 4-ке тең. b неге тең?

Түйін

  • a > 0 - парабола жоғары ашылған (минимум); a < 0 - төмен (максимум).
  • Стандарт түр y-қиылысуды (c), жіктелген түр нөлдерді, төбелік түр төбені (h; k) көрсетеді.
  • Төбенің x-і: −b / (2a) не екі нөлдің ортасы; y-і - сол x-тегі мән.
  • y = a(x − h)² + k жазуында h-тың таңбасы жақшадағыға қарама-қарсы.
  • Контексте: төбенің x-і - «қашан/қай бағада», y-і - «ең көп/ең аз қанша».
