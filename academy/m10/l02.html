AОқу мақсаттары

  • char, short, int, long long, double, unsigned типтерінің өлшемі мен шектерін (sizeof, limits.h) білу.
  • n биттік таңбалы және таңбасыз типтердің ауқымын есептеп, дәлелдеу.
  • Таңбасыз типтегі «айналып кету» (модуль 2ⁿ арифметикасы) мен таңбалы асып кетудің айырмасын ажырату.

BАлғышарттар

  • C және компиляция
  • Теріс сандар: қосымша код

CҰғымға кіріспе

Python-да int шексіз үлкен бола алады. C-да әр типтің тұрақты өлшемі бар: int әдетте 4 байт (32 бит), сондықтан ол тек −2 147 483 648 .. 2 147 483 647 аралығын сақтайды. Өлшемді sizeof береді, шектерді <limits.h>.

Стандарт тек ең аз өлшемдерді кепілдейді (int ≥ 16 бит, long long ≥ 64 бит). Бұл бетте көрсетілген сандар - кәдімгі 64 биттік Linux/gcc жүйесінікі. Таңбасыз (unsigned) типте асып кету анықталған: мән 2ⁿ модулі бойынша айналады. Ал таңбалы int асып кетсе - анықталмаған әрекет (9-сабақ).

DАкадемиялық теория

Анықтама

Ауқымдар

n биттік таңбасыз: 0 .. 2ⁿ − 1. n биттік таңбалы (қосымша код, m05 l04): −2ⁿ⁻¹ .. 2ⁿ⁻¹ − 1.

Теорема

Таңбалы ауқымның асимметриясы

n биттік қосымша кодта ең кіші мән −2ⁿ⁻¹, ең үлкен мән 2ⁿ⁻¹ − 1; теріс мәндер оң мәндерден бір артық.

Дәлелдеу

Дәлелдеу

n бит 2ⁿ әр түрлі үлгі береді. Қосымша кодта жоғарғы бит 0 болатын 2ⁿ⁻¹ үлгі - 0, 1, ..., 2ⁿ⁻¹ − 1 (0 және оң сандар), жоғарғы бит 1 болатын 2ⁿ⁻¹ үлгі - −2ⁿ⁻¹, ..., −1 (теріс сандар; үлгінің мәні = таңбасыз мәні − 2ⁿ). Нөл «оң» жартыда тұрғандықтан, оң сандар 2ⁿ⁻¹ − 1, теріс сандар 2ⁿ⁻¹. ∎ Сондықтан −INT_MIN int-ке сыймайды.

Ескерту

Келтіру (conversion)

Үлкен мәнді таңбасыз типке меншіктеу модуль 2ⁿ бойынша келтіреді: unsigned char c = 300; → c = 300 − 256 = 44. Бұл анықталған. Ал таңбалы типке сыймайтын мәнді меншіктеу нәтижесі іске асыруға тәуелді.

EКөрнекі түсіндірме

%zu - sizeof нәтижесі (size_t) үшін формат. Шектер теоремадағы формулаға сәйкес: 2⁷ − 1 = 127, 2¹⁵ − 1 = 32767, 2³¹ − 1.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. int 32 бит (sizeof(int) = 4, 1 байт = 8 бит).
  2. Таңбасыз: 2³² = 4 294 967 296 мән, 0 .. 4 294 967 295 (UINT_MAX).
  3. Таңбалы: −2³¹ .. 2³¹ − 1 = −2 147 483 648 .. 2 147 483 647.
  4. UINT_MAX + 1u = 0 (модуль 2³²) - анықталған айналу.

GЖұмыс мысалдары

HИнтерактивті эксперимент

8 биттік қосу: 250 + 10 = 260, бірақ 8 битке тек 260 − 256 = 4 сыяды. Бұл - C-дағы unsigned char-дың дәл мінезі. Енді ені 16 бит етіп көріңіз.

IЖаттығулар

JМатематикалық пайымдау

Тұрақты өлшем - жылдамдықтың бағасы: процессор 64 биттік сандарды бір командамен қосады, ал Python-ның шексіз int-і бірнеше командамен. C бағдарламашысы әр айнымалыға «бұл мән қаншалықты үлкен бола алады?» деп сұрақ қояды - бұл Python-да жоқ жаңа жауапкершілік.

KЖиі қателер

  • Сомма/көбейтінді int-ке сыяды деп ойлау (мысалы, 50 000 · 50 000).
    Себебі: 2.5·10⁹ > INT_MAX - таңбалы асып кету (анықталмаған).
    Түзету: long long және 50000LL * 50000.
  • unsigned айнымалыда кері санау: for (unsigned i = n - 1; i >= 0; i--).
    Себебі: i >= 0 әрқашан ақиқат: 0-ден кейін 4294967295.
    Түзету: int i не for (unsigned i = n; i-- > 0; ).

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.

Honors
