AОқу мақсаттары

  • Функцияның жариялауы (прототип) мен анықтамасын ажырату.
  • Мәнмен беру (call by value) ережесін дәлелдеу: функция шақырушының айнымалысын өзгерте алмайды.
  • static жергілікті айнымалыны және рекурсияны C-да қолдану.

BАлғышарттар

  • Басқару құрылымдары
  • Көру аймағы

CҰғымға кіріспе

C функциясының типі бар: int max(int a, int b) - екі int қабылдап, int қайтарады; мән қайтармайтын функция - void. Компилятор кодты жоғарыдан төменге оқиды, сондықтан функцияны шақырмас бұрын оны білуі керек: не анықтаманы жоғары қою керек, не прототип (жариялау) жазу керек: int max(int a, int b);.

C-да аргументтер әрқашан мәнімен беріледі: функция көшірмені алады. Python-да тізімді функция өзгерте алатын (m07 l04), ал C-да int айнымалыны функция өзгерте алмайды - ол үшін көрсеткіш керек (m11).

DАкадемиялық теория

Анықтама

Жариялау және анықтама

Жариялау (прототип) - аты, қайтару типі, параметр типтері; денесі жоқ. Анықтама - денесімен бірге; бағдарламада бір рет. Жариялау көп рет болуы мүмкін (тақырып файлдары .h).

Теорема

Мәнмен беру

f(int x) функциясы x-ке не меншіктесе де, f(v) шақыруынан кейін шақырушының v айнымалысы өзгермейді.

Дәлелдеу

Дәлелдеу

C11 6.5.2.2: шақыру кезінде әр аргумент есептеліп, оның мәні сәйкес параметрге меншіктеледі; параметр - функцияның жергілікті айнымалысы, өз жады ұяшығы бар (шақыру жақтауында, m09 l06). f ішіндегі x = ... тек сол ұяшықты өзгертеді. v - басқа ұяшық; оған f-тің ешбір нұсқауы сілтемейді (v-ның мекенжайы берілмеген). Демек v өзгермейді. ∎ Мекенжай берілсе (f(&v)) - басқа әңгіме (m11 l02).

Ескерту

static жергілікті айнымалы

static int calls = 0; функция ішінде бір рет инициализацияланады және шақырулар арасында мәнін сақтайды (бағдарлама бойы өмір сүреді, бірақ тек функция ішінде көрінеді).

EКөрнекі түсіндірме

Прототип (3-жол) main-ге try_change туралы алдын ала айтады. Функция көшірмені өзгертті - v сол күйі (теорема).

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Есеп: екі санның ЕҮОБ-ын (m03, Евклид алгоритмі) функция етіп шығару.
  2. Прототип: int gcd(int a, int b);
  3. Анықтама: while (b != 0) { int t = a % b; a = b; b = t; } return a;
  4. a мен b - көшірмелер: функция оларды еркін өзгертеді, шақырушының айнымалылары қауіпсіз.

GЖұмыс мысалдары

HИнтерактивті эксперимент

swap жұмыс істемеді - неге? (Теорема.) m11 l02-де көрсеткіштермен дұрыс swap жазамыз: void swap(int *a, int *b).

IЖаттығулар

JМатематикалық пайымдау

Типтелген прототиптер - келісімшарттың (m07 l03) компилятор тексеретін бөлігі: f("мәтін") шақыруы int f(int) үшін компиляцияда ұсталады. Мәнмен беру - таза функция (m07 l04) идеясының тілдік кепілдігі: функция шақырушының айнымалыларын жасырын өзгерте алмайды.

KЖиі қателер

  • Прототипсіз, анықтамадан бұрын шақыру.
    Себебі: C11-де бұл қате (айқын емес жариялау жоқ); ескі компиляторлар int f() деп болжаған.
    Түзету: Прототип не анықтаманы жоғары қою.
  • int функциясының бір тармағында return-ді ұмыту.
    Себебі: Қайтарылған мәнді пайдалану - анықталмаған әрекет.
    Түзету: -Wall (-Wreturn-type) ескертуі; әр жолда return.
