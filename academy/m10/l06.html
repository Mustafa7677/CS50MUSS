Массивтер

  • орта
  • ≈ 50 мин
  • 3 мақсат
  • 6 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақ қадамдарынан құрастырылған)
  1. Сұрақ. C массиві - жадта қатар тұрған бір типті элементтер: int a[5] = {3, 1, 4, 1, 5}; .
  2. Жол. 1-қадам. Есеп: массивтің орташа мәні.
  3. Жол. 2-қадам. Прототип: double mean(const int a[], int n) - n бөлек беріледі.
  4. Жол. 3-қадам. long long s = 0; for (int i = 0; i < n; i++) s += a[i]; - i < n (≤ емес!).
  5. Жол. 4-қадам. return (double)s / n; - бүтін бөлуден сақтану (l03).
  6. Тексер. int a[5]; a[5] = 1; не болады? Жауап: Анықталмаған әрекет: көрші жад бүлінуі мүмкін. Дұрыс (9-сабақ).
  7. Түйін. Ұзындық формуласы және жарамды индекстер. T a[n] үшін sizeof a = n · sizeof(T), демек sizeof a / sizeof a[0] = n; жарамды индекстер - дәл 0, 1, ..., n − 1.
  8. Түйін. Жиі қате: for (int i = 0; i <= n; i++). Дұрысы: i < n.

AОқу мақсаттары

  • Тұрақты өлшемді массивті жариялау, инициализациялау және аралау.
  • Массив ұзындығын sizeof арқылы есептеу және жарамды индекстер 0..n−1 екенін дәлелдеу.
  • Массивті функцияға беру: ұзындықты бөлек параметрмен беру қажеттілігі.

BАлғышарттар

  • Функциялар және прототиптер
  • Тізімдер

CҰғымға кіріспе

C массиві - жадта қатар тұрған бір типті элементтер: int a[5] = {3, 1, 4, 1, 5};. Python тізімінен айырмашылығы: өлшемі тұрақты (append жоқ), ұзындығын массив өзі «білмейді», және C шекараны тексермейді: a[5] жазу қате береді деп кепілдік жоқ - ол көрші жадты бүлдіруі мүмкін.

Ұзындық: sizeof a / sizeof a[0] (тек массив жарияланған жерде). Функцияға массив берілгенде ол бірінші элементтің мекенжайына айналады (m11 l04), сондықтан ұзындықты бөлек параметр етіп береміз: int sum(const int a[], int n).

DАкадемиялық теория

Анықтама

Жариялау түрлері

int a[5]; (мәндері анықталмаған, егер жергілікті болса); int a[5] = {0}; (барлығы 0); int a[] = {1, 2, 3}; (өлшемі 3); int m[2][3]; (2 жол, 3 баған - жол-жолмен сақталады).

Теорема

Ұзындық формуласы және жарамды индекстер

T a[n] үшін sizeof a = n · sizeof(T), демек sizeof a / sizeof a[0] = n; жарамды индекстер - дәл 0, 1, ..., n − 1.

Дәлелдеу

Дәлелдеу

Массив n элементтің үзіліссіз тізбегі, әрқайсысы sizeof(T) байт, аралық толтырусыз (C11 6.2.5: «массив типі - үзіліссіз бөлінген бос емес нысандар жиыны»). Демек жалпы өлшем n · sizeof(T); sizeof a[0] = sizeof(T), бөлу n береді. a[i] - бірінші элементтен i · sizeof(T) байт қашықтықтағы нысан. 0 ≤ i ≤ n − 1 болғанда ол массив ішінде; i = n - массивтің соңынан кейінгі шекара (тек мекенжай ретінде рұқсат, оқуға болмайды), i < 0 не i > n - массивтен тыс. ∎

Ескерту

const параметр

int sum(const int a[], int n) - функция массивті өзгертпейтінін уәде етеді; ішінде a[0] = 1 жазсаңыз, компилятор қате береді (келісімшарт, m07 l03).

EКөрнекі түсіндірме

8 элемент × 4 байт = 32. Ішінара инициализацияда қалған элементтер нөлге тең.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Есеп: массивтің орташа мәні.
  2. Прототип: double mean(const int a[], int n) - n бөлек беріледі.
  3. long long s = 0; for (int i = 0; i < n; i++) s += a[i]; - i < n (≤ емес!).
  4. return (double)s / n; - бүтін бөлуден сақтану (l03).

GЖұмыс мысалдары

HИнтерактивті эксперимент

Функцияда a - массив емес, көрсеткіш (8 байт). Сондықтан sizeof a / sizeof a[0] функция ішінде қате нәтиже береді (gcc бұған -Wsizeof-array-argument ескертуін береді). Ұзындықты әрқашан бөлек беріңіз.

IЖаттығулар

JМатематикалық пайымдау

Python тізімі өз ұзындығын біледі және шекараны тексереді - оның бағасы аздаған уақыт пен жад. C массиві бұл «қауіпсіздік белдігін» алып тастайды. Сондықтан C бағдарламашысы әр циклда шекараны өзі дәлелдеуі керек: инвариант 0 ≤ i < n (m04 l05) - бұл енді теория емес, қауіпсіздік талабы.

KЖиі қателер

  • for (int i = 0; i <= n; i++).
    Себебі: a[n] - шекарадан тыс (бір артық қате).
    Түзету: i < n.
  • Функция ішінде sizeof a / sizeof a[0].
    Себебі: Параметр - көрсеткіш: 8 / 4 = 2.
    Түзету: Ұзындықты параметр етіп беру.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
