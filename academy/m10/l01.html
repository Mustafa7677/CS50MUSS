10·01C Programming Foundations

C және компиляция

  • негізгі
  • ≈ 45 мин
  • 3 мақсат
  • 6 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (авторлық сценарий)
  1. Сұрақ. Процессор C тілін түсінбейді. Онда hello.c қалай іске қосылады?
  2. Бейне. C-дағы мәтін - адамға арналған. Процессор тек машиналық кодты - 0 мен 1-ді түсінеді.
  3. Бейне. Компилятор gcc - кітапты алдын ала толық аударатын аудармашы: hello.c → hello (машиналық код).
  4. Бейне. Іске қосқанда (./hello) тек аударма орындалады. Бастапқы мәтін бұл кезде қатыспайды.
  5. Болжа. hello.c өзгерді, бірақ қайта компиляцияланған жоқ. ./hello не шығарады? Жауап: Сәлем - ескі нәтиже. ./hello - ескі аударма. Өзгеріс орындалатын файлға тек gcc қайта іске қосылғанда түседі.
  6. Болжа. Бота hello.c-дағы «Сәлем»-ді «Сау бол»-ға өзгертті.
  7. Көр. gcc hello.c -o hello қайта жүргізілді: аударма жаңарды, енді «Сау бол».
  8. Түйін. C - компиляцияланатын тіл: компилятор бастапқы кодты бір рет машиналық кодқа аударады, іске қосылатын - сол аударма. Код өзгерген сайын қайта компиляциялау керек.
  9. Түйін. Жиі қате: Компиляция қатесіз өтсе, бағдарлама дұрыс. Дұрысы: Компилятор тек тілдің ережелерін тексереді; логикалық қатені тесттер табады.

AОқу мақсаттары

  • Бастапқы код, компилятор, объект файл, орындалатын файл ұғымдарын ажырату.
  • Компиляция кезеңдерін (препроцессор, компиляция, ассемблер, байланыстырушы) ретімен атау.
  • Қарапайым C бағдарламасын жазып, gcc-мен компиляциялап, іске қосу; ескертулерді (-Wall) оқу.

BАлғышарттар

  • Шағын жоба: есептеу утилитасы
  • Кескін мен дыбыстың цифрлық бейнесі

CҰғымға кіріспе

Python бағдарламаны интерпретатор жол-жолмен орындайды. C-да алдымен компилятор бүкіл бастапқы кодты процессордың машиналық кодына аударады, сосын дайын орындалатын файл іске қосылады. Сондықтан C бағдарламалары жылдам, бірақ қателердің көбі компиляция кезінде (не одан да жаман - орындау кезінде үнсіз) шығады.

Браузерде нағыз C компиляторы жоқ, сондықтан бұл модульде C кодын оқимыз, болжаймыз және талдаймыз. Әр мысал мен «шығысты болжа» тапсырмасының жауабы сайтты құрастыру кезінде нағыз gcc -std=c11 -Wall -Wextra -Werror арқылы алынған. Өз компьютеріңізде: gcc -Wall -o hello hello.c && ./hello.

DАкадемиялық теория

Анықтама

Компиляция кезеңдері

  1. Препроцессор: #include файлдарын қою, #define алмастыру (gcc -E).
  2. Компиляция: C → ассемблер коды (gcc -S).
  3. Ассемблер: → объект файл .o (gcc -c).
  4. Байланыстырушы (linker): объект файлдар + кітапханалар (printf) → орындалатын файл.
Теорема

main-нің қайтару мәні

main-нен return k бағдарламаның шығу кодын k етеді (0 - сәтті). C99/C11-де main соңына return жазылмаса, return 0 деп есептеледі (тек main үшін).

Дәлелдеу

Негіздеу (стандарт бойынша)

C11 5.1.2.2.3: «main функциясынан қайту - exit функциясын main қайтарған мәнмен шақырумен бірдей; main-нің соңғы } белгісіне жету 0 қайтарады». exit(k) операциялық жүйеге k күйін береді, оны shell-де echo $? көрсетеді. Демек return k ⇒ шығу коды k (0..255 аралығына келтіріліп). ∎

Ескерту

Ескертулер - досыңыз

-Wall -Wextra ескертулері көп қатені бағдарламаны іске қоспай-ақ табады: пайдаланылмаған айнымалы, printf форматы мен типтің сәйкессіздігі, мәні берілмеген айнымалы. Бұл курста барлық мысал -Werror-мен (ескерту = қате) өтеді.

EКөрнекі түсіндірме

#include <stdio.h> printf функциясын жариялайды; %d - бүтін санды шығару орны; \n - жаңа жол (C өзі қоспайды).

Интерактивті модель: өзің басқар

Компилятор алдымен мәтінді токендерге бөліп, басымдықты ескеретін құрылымға (RPN/ағаш) аударады: бұл кезеңдерді өрнектің мысалында қадамдап көріңіз.

Интерактивті модель: өзің басқар

Компилятор C кодын осындай қарапайым командаларға аударады. Цикл машиналық деңгейде шартты өту (JZ) мен JMP-ке айналады - әр команданың регистрлерді қалай өзгертетінін көріңіз.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. hello.c файлына код жазамыз.
  2. gcc -E hello.c | tail - препроцессор stdio.h-ты қосқанын көреміз (мыңдаған жол).
  3. gcc -c hello.c → hello.o (машиналық код, бірақ printf әлі «сыртқы сілтеме»).
  4. gcc hello.o -o hello → байланыстыру; ./hello - іске қосу; echo $? - шығу коды 0.

GЖұмыс мысалдары

HИнтерактивті эксперимент

Бірінші printf-те \n жоқ - «бір» мен «екі» бір жолда. \t - табуляция. Шығысты болжап, сосын көрсетіңіз.

IЖаттығулар

JМатематикалық пайымдау

C - «машинаға жақын» тіл: ол жадты, типтердің өлшемін, тіпті қателерді де бағдарламашыға тапсырады. Сондықтан C үйрену - компьютердің шын жұмысын (m05 биттер, m11 жады) түсіну. Python-да жасырылған нәрсенің бәрі мұнда ашық.

KЖиі қателер

  • printf-те \n-ді ұмыту.
    Себебі: C жаңа жолды өзі қоспайды (Python print-тен айырмашылығы).
    Түзету: printf("...\n").
  • Ескертулерді елемеу.
    Себебі: Ескерту көбіне нақты қате (мысалы, %d орнына double берілген).
    Түзету: Әрқашан -Wall -Wextra, ал оқу кезінде -Werror.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.

MРефлексия

NТереңірек

Honors

  • gcc -S hello.c жасап, hello.s файлындағы ассемблер кодын ашыңыз. printf шақыруын табыңыз (call printf не puts) - неге кейде puts?

Research

  • Интерпретатор, компилятор және JIT (PyPy, JavaScript V8) - айырмашылықтары мен артықшылықтары қандай?
