нұсқа 1.0.0 · тексеру: author-checked

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақ қадамдарынан құрастырылған)
  1. Сұрақ. C-ның басқару құрылымдары Python-ға ұқсас, бірақ синтаксисі басқа: шарт жақшада, блок { } ішінде (шегініс - тек оқырманға). for (int i = 0; i < n; i++) - бастау; шарт; қадам. C-да bool типі болмаған (C99-да stdbool.h): шарт - сан, 0 жалған, қалғаны ақиқат.
  2. Жол. 1-қадам. Есеп: 1-ден n-ге дейінгі 3-ке не 5-ке бөлінетін сандардың қосындысы.
  3. Жол. 2-қадам. for (int i = 1; i <= n; i++) - n итерация.
  4. Жол. 3-қадам. if (i % 3 == 0 || i % 5 == 0) sum += i; - || қысқа тұйықталады (m01 l03).
  5. Жол. 4-қадам. sum типі: n = 100 000 үшін қосынды ≈ 2.3·10⁹ > INT_MAX - long long керек.
  6. Тексер. if (x = 0) printf("нөл"); не істейді? Жауап: x-ке 0 меншіктейді және ештеңе шығармайды. Дұрыс: = меншіктеу, өрнек мәні 0 - жалған.
  7. Түйін. for циклының итерация саны. for (int i = a; i < b; i += s) (s > 0, a ≤ b, асып кетусіз) денесі ⌈(b − a)/s⌉ рет орындалады.
  8. Түйін. Жиі қате: if (x = 5) деп жазу. Дұрысы: if (x == 5); -Wall ескертуін оқу.

AОқу мақсаттары

  • if/else, while, do-while, for және switch құрылымдарын жазу және оқу.
  • C-дағы ақиқат ұғымын (0 - жалған, қалғаны - ақиқат) және = мен == айырмасын түсіндіру.
  • Цикл итерацияларын санау (m04 l08) және break/continue әсерін болжау.

BАлғышарттар

  • Операторлар және өрнектер

CҰғымға кіріспе

C-ның басқару құрылымдары Python-ға ұқсас, бірақ синтаксисі басқа: шарт жақшада, блок { } ішінде (шегініс - тек оқырманға). for (int i = 0; i < n; i++) - бастау; шарт; қадам.

C-да bool типі болмаған (C99-да stdbool.h): шарт - сан, 0 жалған, қалғаны ақиқат. Сондықтан if (x = 5) қате емес, ол x-ке 5 меншіктеп, әрқашан ақиқат! -Wall бұл туралы ескертеді.

DАкадемиялық теория

Анықтама

for және while

for (A; B; C) S; ≡ A; while (B) { S; C; } (continue-сіз). do S while (B); - S кемінде бір рет орындалады.

Теорема

for циклының итерация саны

for (int i = a; i < b; i += s) (s > 0, a ≤ b, асып кетусіз) денесі ⌈(b − a)/s⌉ рет орындалады.

Дәлелдеу

Дәлелдеу

k-шы итерацияда (k = 0, 1, ...) i = a + k·s. Дене орындалады ⇔ a + k·s < b ⇔ k < (b − a)/s. Мұндай теріс емес бүтін k-лар: 0, 1, ..., ⌈(b − a)/s⌉ − 1, яғни ⌈(b − a)/s⌉ дана. i бір сарынды өсетіндіктен, шарт бір рет жалған болған соң цикл тоқтайды. ∎ Мысалы, a = 0, b = 10, s = 3: i = 0, 3, 6, 9 - ⌈10/3⌉ = 4.

Ескерту

switch және break

switch-те case-тен кейін break болмаса, орындау келесі case-ке «құлап өтеді» (fall-through). Бұл кейде әдейі, бірақ көбіне қате. gcc -Wextra -Wimplicit-fallthrough ескертеді.

EКөрнекі түсіндірме

for: ⌈10/3⌉ = 4 итерация (теорема). do-while шарт жалған болса да бір рет орындалды.

Интерактивті модель: өзің басқар

for циклының машиналық нұсқасы: шартты тексеру - JZ, қадам - DEC, қайта бастау - JMP. Санағыштың бастапқы мәнін өзгертіп, итерация санын тексеріңіз.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Есеп: 1-ден n-ге дейінгі 3-ке не 5-ке бөлінетін сандардың қосындысы.
  2. for (int i = 1; i <= n; i++) - n итерация.
  3. if (i % 3 == 0 || i % 5 == 0) sum += i; - || қысқа тұйықталады (m01 l03).
  4. sum типі: n = 100 000 үшін қосынды ≈ 2.3·10⁹ > INT_MAX - long long керек.

GЖұмыс мысалдары

HИнтерактивті эксперимент

break жоқ case 2 case 3-ке «құлап өтті». /* fall through */ түсіндірмесі gcc-ге бұл әдейі екенін айтады (әйтпесе -Wextra ескертеді).

IЖаттығулар

JМатематикалық пайымдау

Басқару құрылымдары - m04-тегі псевдокодтың нақты синтаксисі. Логика өзгермеді: инвариант, аяқталу, итерация саны. Тілдің ерекшеліктері (0 - жалған, fall-through, = мен ==) - жаңа қате көздері, және оларды компилятордың ескертулері ұстайды.

KЖиі қателер

  • if (x = 5) деп жазу.
    Себебі: Меншіктеу - әрқашан ақиқат.
    Түзету: if (x == 5); -Wall ескертуін оқу.
  • for (...); { ... } - жақшадан кейін нүктелі үтір.
    Себебі: Цикл денесі - бос нұсқау; блок бір рет орындалады.
    Түзету: ; қоймаңыз; -Wextra -Wempty-body.
