AОқу мақсаттары

  • Бүтін бөлу мен қалдықтың C ережесін (нөлге қарай қию) Python-мен (төменге қарай) салыстыру.
  • Айқын (cast) және айқын емес түрлендірулерді, бүтін сандарды көтеруді қолдану.
  • Операторлардың басымдығы мен ++/-- , +=, тернарлы ?: операторын дұрыс оқу.

BАлғышарттар

  • Типтер және өлшемдер

CҰғымға кіріспе

C-да 7 / 2 - 3, ал 7.0 / 2 - 3.5: нәтиже типі операндтардың типінен анықталады. Бір операнд double болса, екіншісі де double-ға түрленеді. Айқын түрлендіру: (double)a / b.

Назар аударыңыз: теріс сандарда C мен Python әртүрлі! C-да -7 / 2 = -3, -7 % 2 = -1 (нөлге қарай қию), ал Python-да -7 // 2 = -4, -7 % 2 = 1 (төменге қарай). Бір алгоритмді екі тілге аударғанда бұл жасырын қате көзі.

DАкадемиялық теория

Анықтама

C11 бөлу ережесі

Бүтін a / b - нақты бөліндінің бөлшек бөлігі тасталады (нөлге қарай). a % b анықтамасы: (a / b) * b + a % b == a (b ≠ 0).

Теорема

Қалдықтың таңбасы

C-да b ≠ 0 үшін a % b-ның таңбасы a-ның таңбасымен бірдей (не нөл), және |a % b| < |b|.

Дәлелдеу

Дәлелдеу

q = a / b - нөлге қарай қиылған: |q| ≤ |a/b| және q пен a/b таңбалас (не q = 0). r = a − q·b. Егер a ≥ 0, b > 0: q = ⌊a/b⌋, 0 ≤ r < b. Жалпы жағдайда |q·b| ≤ |a| және q·b пен a таңбалас, демек r = a − q·b да a-мен таңбалас (не 0). Қию 1-ден кем бөлшекті тастайды: |a/b − q| < 1 ⇒ |r| = |b|·|a/b − q| < |b|. ∎ Мысалы, −7 = (−3)·2 + (−1).

Ескерту

Басымдық

Жоғарыдан төменге: ++ -- (постфикс) → унарлы - ! (type) → * / % → + - → << >> → < <= → == != → & → ^ → | → && → || → ?: → = += ... Күмән болса - жақша.

EКөрнекі түсіндірме

Соңғы жол: жақша ішіндегі бүтін бөлу бірінші орындалады - (double)3 = 3.00. Қалдықтың таңбасы бөлінгіштікі (теорема).

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Орташа баллды есептеу: int sum = 17, n = 4.
  2. sum / n = 4 - бөлшек жоғалды.
  3. (double)sum / n = 4.25 - sum алдымен double-ға, сосын бөлу.
  4. (double)(sum / n) = 4.00 - қате: бөлу бүтін сандарда бұрын болды.

GЖұмыс мысалдары

HИнтерактивті эксперимент

Python-да C бөлуін модельдедік: int(a / b) нөлге қарай қияды. Қай жағдайларда нәтижелер ерекшеленеді? (Үлкен сандарда a / b float дәлдігін жоғалтады - тапсырмада бүтін сандармен жасаймыз.)

IЖаттығулар

JМатематикалық пайымдау

C өрнектерінің мағынасы типтерге байланысты - бұл Python-дан негізгі айырмашылық. «Бұл өрнектің типі қандай?» деген сұрақ әр бөлу мен әр меншіктеуде қойылуы керек. Ал теріс сандардағы бөлу айырмашылығы - бір тілден екіншісіне аударғанда тест жазудың (m08) неге маңызды екенін көрсетеді.

KЖиі қателер

  • x = x++ сияқты өрнектер.
    Себебі: Бір айнымалыны бір өрнекте екі рет өзгерту - анықталмаған әрекет (9-сабақ).
    Түзету: Бөлек жолдарға бөліңіз.
  • Теріс санның жұптығын x % 2 == 1 арқылы тексеру.
    Себебі: C-да −3 % 2 = −1, сондықтан теріс тақ сан «жұп емес, тақ та емес».
    Түзету: x % 2 != 0.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
