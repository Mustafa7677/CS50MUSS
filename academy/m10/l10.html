AОқу мақсаттары

  • Бір алгоритмді (Эратосфен елегі) Python мен C-да жазып, құрылымдық айырмашылықтарды талдау.
  • Тілдердің семантикалық айырмашылықтарын (бүтін сандар, бөлу, жолдар, жад) тізімдеу.
  • Модуль жобасын (p10 C Numeric Processing Tool) жоспарлау.

BАлғышарттар

  • Анықталмаған әрекет

CҰғымға кіріспе

Бір алгоритм - екі тіл. Python кодында не істелетіні көрінеді, C кодында қалай істелетіні: жад қанша, типтер қандай, шекара қайда. Python шексіз бүтін сандар, тексерілетін индекстер мен автоматты жадты береді; C - тұрақты типтерді, бақыланбайтын массивтерді және жылдамдықты.

Жылдамдық айырмасы әдетте 10-100 есе, бірақ бұл - алгоритмнің құнын (m09 l10) өзгертпейді: O(n²) C коды O(n log n) Python кодынан үлкен n-де баяу. Тілді таңдау - есептің талаптары: жылдам прототип пен кітапханалар (Python) не жадты бақылау мен жылдамдық (C).

Теорема

Эратосфен елегінің дұрыстығы

2..n сандарының ішінен p² ≤ n болатын әр жай p үшін p², p² + p, ... сандарын сызып тастасақ, сызылмай қалған сандар - дәл 2..n аралығындағы жай сандар.

Дәлелдеу

Дәлелдеу

(⇐) Жай сан q ешқашан сызылмайды: сызылатындар k·p (k ≥ p ≥ 2) түрінде - құрама. (⇒) m ≤ n құрама болсын, p - оның ең кіші жай бөлгіші. m = p·k, k ≥ p (әйтпесе k-ның жай бөлгіші p-дан кіші), демек p² ≤ m ≤ n, ал m = p² + (k − p)·p - p үшін сызылатын тізбекте. Демек құрама сандар сызылады. p² ≤ n шарты жеткілікті: p² > n болса, p-ның сызатын сандары n-нен үлкен. ∎ Құны: O(n log log n).

Ескерту

Бірдей алгоритм - бірдей тест

Екі іске асыруды салыстырудың ең сенімді жолы - бірдей кірістерде бірдей нәтиже (m07 l10 рефакторинг, m08 тесттер). Бұл бетте Python нұсқасы браузерде іске қосылады, C нұсқасының шығысы gcc-мен алынған - екеуі бірдей.

EКөрнекі түсіндірме

Python нұсқасы: тізім, шексіз int, тізім құрастыру өрнегі. Төмендегі C нұсқасымен салыстырыңыз.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Python: is_prime = [True] * (n + 1) - тізім өзі жадты бөледі.
  2. C: static bool is_prime[100001]; - өлшем алдын ала белгілі болуы керек (не malloc, m11).
  3. Python: return [i for ...] - нәтиже тізімі. C: санын қайтарып, массивке жазу не бірден шығару.
  4. Екі нұсқа бірдей кірісте бірдей шығыс берсе - аудармаға сенім артады.

GЖұмыс мысалдары

HИнтерактивті эксперимент

Python-да math.factorial(25) оңай есептеледі. C-да 21! long long-тың 2⁶³ − 1 шегінен асады - тексеріс көбейтуге дейін (l09). Python-да -7 // 2 мен -7 % 2 не береді? (l03.)

IЖаттығулар

JМатематикалық пайымдау

Екі тілді білу - бір тілді тереңірек білу. Python-ның «сиқыры» (шексіз int, len, IndexError) C-да қолмен жасалатын жұмыс екенін көргеннен кейін, Python кодының құнын дұрыс бағалайсыз. Ал C-да жазғанда Python-да үйренген әдеттер (тесттер, таза функциялар) қатені азайтады. m11-де C-ның ең терең ұғымы - жад пен көрсеткіштер.

KЖиі қателер

  • Python алгоритмін C-ға сөзбе-сөз аудару (мысалы, -7 // 2).
    Себебі: Семантика әртүрлі: бөлу, асып кету, жолдар.
    Түзету: Аудармадан кейін бірдей тесттермен салыстыру.
  • «C әрқашан жылдам» деп ойлау.
    Себебі: Алгоритм құны (O) тілден маңызды.
    Түзету: Алдымен дұрыс алгоритм, сосын тіл.

Модуль жобасы: C Numeric Processing Tool

Стандартты енгізуден бүтін сандар тізбегін оқып, статистикалық есеп беретін C бағдарламасын жасаңыз: саны, қосынды, ең кіші/ең үлкен, орташа, медиана, жиілік гистограммасы. Бағдарлама қате енгізуді, асып кетуді және бос енгізуді дұрыс өңдеп, түсінікті хабар (stderr) мен шығу кодын беруі керек.

Функционалдық талаптар

  • Енгізу: while (scanf("%d", &x) == 1); сан емес таңбада - stderr-ге хабар және шығу коды 2.
  • Ең көбі 10 000 сан (массив шекарасы тексеріледі); артық болса - хабар.
  • Қосынды long long-та; асып кету алдын ала тексеріледі (l09 әдісі).
  • Медиана үшін өз сұрыптау функцияңыз (m09 l03-l05 алгоритмдерінің бірі).
  • Гистограмма: 10 бірлікті аралықтар бойынша printf-пен туралап шығару (%5d, жұлдызшалар).
  • Python-дағы эталон нұсқа (m09) және екі нұсқаның шығысын салыстыратын тест скрипті; gcc -Wall -Wextra -Werror -fsanitize=address,undefined-пен таза компиляция.

Кезеңдер

  • 1. Енгізуді оқу және қате өңдеу.
  • 2. Қосынды, min/max, орташа (асып кетусіз).
  • 3. Сұрыптау және медиана.
  • 4. Гистограмма форматы.
  • 5. Python эталоны, салыстыру тесттері, README.

Қабылдау тесттері

  • 10 000 кездейсоқ сан енгізуінде нәтиже Python эталонымен дәл сәйкес.
  • Бос енгізу, 'abc' енгізуі және 10 001 сан - бағдарлама құламайды, тиісті хабар мен шығу коды.
  • Санитайзерлермен іске қосқанда бірде-бір қате жоқ.
  • README-де Python мен C нұсқаларының айырмашылықтары (кемінде 4) түсіндірілген.
