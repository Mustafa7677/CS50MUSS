Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақ қадамдарынан құрастырылған)
  1. Сұрақ. printf бірінші аргументтегі формат жолын оқып, әр % белгісі үшін келесі аргументті алады. Формат пен типтің сәйкестігін бағдарламашы қамтамасыз етеді: printf("%d", 3.5) - анықталмаған әрекет (gcc -Wall -Wformat ескертеді).
  2. Жол. 1-қадам. Есеп: енгізуден сандарды соңына дейін оқып, қосынды мен орташаны шығару.
  3. Жол. 2-қадам. int x, n = 0; long long sum = 0;
  4. Жол. 3-қадам. while (scanf("%d", &x) == 1) { sum += x; n++; }
  5. Жол. 4-қадам. if (n == 0) - енгізу бос; әйтпесе printf("%.2f\n", (double)sum / n).
  6. Тексер. scanf("%d", x); (& жоқ) қатесі: Жауап: scanf x-тің мәнін мекенжай деп қабылдайды - анықталмаған әрекет. Дұрыс: & мекенжайды береді (gcc -Wformat ескертеді).
  7. Түйін. scanf-пен оқу циклының аяқталуы. while (scanf("%d", &x) == 1) { ... } циклы шекті енгізуде әрқашан аяқталады және дәл бастағы сәтті оқылатын бүтін сандар тізбегін өңдейді.
  8. Түйін. Жиі қате: scanf("%s", buf) - еншіз. Дұрысы: %31s (буфер өлшемі − 1) не fgets.

AОқу мақсаттары

  • printf форматтарын (%d, %u, %ld, %lld, %f, %.2f, %e, %c, %s, %x, %5d, %-5s, %05d) дұрыс қолдану.
  • scanf-пен енгізу оқу, оның қайтару мәнін (сәтті оқылған элементтер саны) тексеру.
  • Енгізу соңына дейін оқу (while (scanf(...) == 1)) үлгісін қолдану.

BАлғышарттар

  • Жолдар char массиві ретінде

CҰғымға кіріспе

printf бірінші аргументтегі формат жолын оқып, әр % белгісі үшін келесі аргументті алады. Формат пен типтің сәйкестігін бағдарламашы қамтамасыз етеді: printf("%d", 3.5) - анықталмаған әрекет (gcc -Wall -Wformat ескертеді).

scanf("%d", &x) енгізуден санды оқып, оны x-тің мекенжайына (&x) жазады - функция айнымалыны өзгертуі керек, ал мәнмен беру (l05) мұны рұқсат етпейді. scanf сәтті оқылған элементтер санын қайтарады; енгізу бітсе - EOF. Бұл тексерілмесе, бағдарлама бұрынғы «қоқыс» мәнмен жұмыс істейді.

DАкадемиялық теория

Анықтама

Формат спецификаторлары

%d int; %u unsigned; %ld long; %lld long long; %zu size_t; %f double (printf); %lf double (scanf!); %e ғылыми; %c char; %s жол; %x он алтылық; %p мекенжай. Ен және дәлдік: %8.3f, %-10s (солға), %05d (нөлдермен толтыру).

Теорема

scanf-пен оқу циклының аяқталуы

while (scanf("%d", &x) == 1) { ... } циклы шекті енгізуде әрқашан аяқталады және дәл бастағы сәтті оқылатын бүтін сандар тізбегін өңдейді.

Дәлелдеу

Дәлелдеу

Әр сәтті шақыру енгізуден кемінде бір таңба тұтынады (санның цифрлары). Енгізу шекті, сондықтан сәтті шақырулар саны шекті. Цикл шарты 1 емес мәнде жалған: 0 (келесі таңба санды бастамайды - ол тұтынылмайды) не EOF (енгізу бітті). Екі жағдайда да цикл тоқтайды; тоқтағанға дейін әр сәтті оқылған сан өңделеді, ал бірінші сәтсіздіктен кейінгілері - жоқ. ∎ Ескерту: «0 қайтару» жағдайында қате таңба енгізуде қалады - оны өткізбей қайта шақыру шексіз цикл береді.

Ескерту

Буферлеу

stdout әдетте жол бойынша (терминалда) не толық (файлға/құбырға) буферленеді: printf мәтіні бірден көрінбеуі мүмкін. fflush(stdout) не \n көмектеседі; қате хабарлары үшін stderr (fprintf(stderr, ...)) - буферсіз.

EКөрнекі түсіндірме

Ен - ең аз орын саны; - солға туралайды; .3s - ең көбі 3 таңба. %% - пайыз белгісінің өзі.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Есеп: енгізуден сандарды соңына дейін оқып, қосынды мен орташаны шығару.
  2. int x, n = 0; long long sum = 0;
  3. while (scanf("%d", &x) == 1) { sum += x; n++; }
  4. if (n == 0) - енгізу бос; әйтпесе printf("%.2f\n", (double)sum / n).

GЖұмыс мысалдары

HИнтерактивті эксперимент

Тек бір сан оқылды. Қайтару мәнін тексермесек, b-ның мәні анықталмаған болар еді (инициализацияланбаған айнымалы).

IЖаттығулар

JМатематикалық пайымдау

Енгізу - бағдарламаның ең сенімсіз шекарасы (m08 l06). C-да оның қауіпі екі есе: тексерілмеген scanf «қоқыс» мәнді, шектелмеген %s буфер толуын береді. Сондықтан ереже: әр scanf-тің қайтару мәнін тексеру және әр %s-ке ен беру (%31s).

KЖиі қателер

  • scanf("%s", buf) - еншіз.
    Себебі: Ұзын сөз буферді толтырып, көрші жадты бүлдіреді.
    Түзету: %31s (буфер өлшемі − 1) не fgets.
  • double-ды scanf("%f", &d) арқылы оқу.
    Себебі: %f scanf-те float* күтеді - анықталмаған әрекет.
    Түзету: scanf-те double үшін %lf; printf-те %f (екеуі де double үшін).

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.

MРефлексия

NТереңірек

Honors

  • fgets + strtol арқылы енгізуді сенімді оқу: жолды толық оқып, санды тексеріп түрлендіру. Неге бұл scanf-тен қауіпсіз?

Research

  • Формат жолы осалдығы (format string attack): printf(user_input) неге қауіпті? %n спецификаторы не істейді?
