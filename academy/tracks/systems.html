Компьютерлік жүйелер

Бағдарламаның астындағы әлем: биттер, процессор, жад, операциялық жүйе, желі және дерекқор.

Бағыттың соңында: Бағдарламаның аппаратурада, ОЖ-да және желіде қалай орындалатынын түсініп, төменгі деңгейде жұмыс істей алатын инженер.

1-саты

Негіз

Ойлау тәсілі және құралдар

Ақпараттың екілік табиғаты және машина моделі.

Сатының соңында сіз

  • Сандарды, мәтінді, кескінді биттермен көрсету
  • Логикалық схема мен процессор командаларын оқу

Модульдер

  1. Ақпарат және екілік жүйеAO17 сабағы
  2. Логикалық схема - модельИнтерактивті модель
  3. Оқу процессоры - модельИнтерактивті модель

Портфолио жобасы. Binary Information Toolkit (p05).

2-саты

Junior

Тапсырманы өз бетінше орындайды

C, жад және бағдарламаның орындалуы.

Сатының соңында сіз

  • Стек пен үйменің айырмасын түсіндіру
  • Жад қателерін санитайзерлермен табу
  • Командалық жол құралдарын жазу

Модульдер

  1. C тілінің негіздеріAO17 сабағы
  2. Жады және көрсеткіштерAO17 сабағы
  3. CS50x: жад, деректер құрылымыАударма курс
  4. C жады - модельИнтерактивті модель

Портфолио жобасы. Memory Address Explorer (p11).

3-саты

Middle

Жүйені жобалайды және жауап береді

Операциялық жүйелер, желілер және дерекқорлар.

Сатының соңында сіз

  • Процесс, ағын, жоспарлау және синхрондау
  • TCP/IP стегі, HTTP, сокеттер
  • SQL, индекстер, транзакциялар

Модульдер

  1. CS50 SQLАударма курс
  2. Процесс жоспарлау - модельИнтерактивті модель
  3. TCP - модельИнтерактивті модель
  4. Операциялық жүйелерAO17 сабағы, жоспарда
  5. Компьютерлік желілерAO17 сабағы, жоспарда

Портфолио жобасы. Мини-ОЖ жоспарлаушысы не HTTP сервер C-да (жоспарда).

4-саты

Senior

Архитектура, сапа және басқаларды өсіру

Компиляторлар, таралған жүйелер және өнімділік.

Сатының соңында сіз

  • Компилятордың кезеңдерін іске асыру
  • Консенсус және репликация
  • Жүйені деңгейлер бойынша профилдеу

Модульдер

  1. Компилятор: лексер → парсер - модельИнтерактивті модель
  2. КомпиляторларAO17 сабағы
  3. Таралған жүйелерAO17 сабағы

Портфолио жобасы. Шағын тілдің компиляторы (жоспарда).
