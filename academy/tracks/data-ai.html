Деректер және жасанды интеллект

Деректен заңдылық табу: ықтималдық пен статистикадан нейрондық желілер мен модельді өндірісте ұстауға дейін.

Бағыттың соңында: Деректі тазалап талдайтын, модельді таңдап оқытатын, нәтижесін адал бағалап, түсіндіре алатын маман.

1-саты

Негіз

Ойлау тәсілі және құралдар

Python, ықтималдық және деректер ұғымы.

Сатының соңында сіз

  • Python-да деректерді оқу, сүзу, топтау
  • Ықтималдық пен үлестірімнің мағынасын түсіндіру
  • Графикпен деректі сипаттау

Модульдер

  1. Python негіздеріAO17 сабағы
  2. Деректер құрылымыAO17 сабағы
  3. Ықтималдық теориясыAO17 сабағы
  4. Үлкен сандар заңы - модельИнтерактивті модель

Портфолио жобасы. Ашық деректер жиынына сипаттамалық талдау (жоспарда).

2-саты

Junior

Тапсырманы өз бетінше орындайды

Классикалық машиналық оқыту және бағалау.

Сатының соңында сіз

  • Регрессия мен классификация модельдерін оқыту
  • Деректі оқыту/тексеру бөліктеріне бөлу, артық үйренуді тану
  • Градиенттік түсуді түсіндіру және баптау

Модульдер

  1. CS50 AI: іздеу, білім, белгісіздікАударма курс
  2. CS50 AI: оқытуАударма курс
  3. Математикалық статистикаAO17 сабағы
  4. Шешім ағашы, k-means, регрессия - модельдерИнтерактивті модель
  5. Градиенттік түсу - модельИнтерактивті модель

Портфолио жобасы. Классификатор: деректі дайындау, 3 модельді салыстыру, қорытынды есеп (жоспарда).

3-саты

Middle

Жүйені жобалайды және жауап береді

Нейрондық желілер, оңтайландыру және тіл модельдері.

Сатының соңында сіз

  • Нейрондық желіні құрып, backprop-ты түсіндіру
  • Оңтайландыру әдістерін салыстыру
  • Модель қателерін талдап, деректі жақсарту

Модульдер

  1. CS50 AI: нейрондық желілер, тілАударма курс
  2. Математикалық оңтайландыруAO17 сабағы
  3. Нейрондық желі - модельИнтерактивті модель
  4. Терең оқыту практикумыAO17 сабағы, жоспарда

Портфолио жобасы. Нейрондық желіні нөлден (NumPy) жазып, кітапханалық нұсқамен салыстыру (жоспарда).

4-саты

Senior

Архитектура, сапа және басқаларды өсіру

Модельді өндірісте ұстау, этика және зерттеу.

Сатының соңында сіз

  • MLOps: модельдің нұсқалары, мониторинг, дрейф
  • Модельдің әділдігі мен түсіндірмелілігі
  • Ғылыми мақаланы оқып, нәтижені қайталау

Модульдер

  1. MLOpsAO17 сабағы
  2. AI этикасы және сенімділігіAO17 сабағы
  3. Зерттеу әдістемесіAO17 сабағы

Портфолио жобасы. Өндірістік ML жүйесі: деректен мониторингке дейін (жоспарда).
