  1. Тесттер бойынша to_roman(n) іске асырыңыз (1 ≤ n ≤ 3999).

    Жауап кілті

    Үлгі шешім (басқа дұрыс нұсқаны да сайт тесттері қабылдайды):

    PAIRS = [(1000, 'M'), (900, 'CM'), (500, 'D'), (400, 'CD'), (100, 'C'), (90, 'XC'), (50, 'L'), (40, 'XL'), (10, 'X'), (9, 'IX'), (5, 'V'), (4, 'IV'), (1, 'I')]

def to_roman(n):
    out = ''
    for value, sym in PAIRS:
        while n >= value:
            out += sym
            n -= value
    return out
