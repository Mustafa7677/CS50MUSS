Жиі қателер және қолдау

  • free(p) кейін p-ны қолдана беру («әлі мән бар ғой»). Блок аллокаторға қайтты - кез келген сәтте қайта бөлінеді. Түзету: free(p); p = NULL;
  • Бір блокты екі құрылымның екеуі де «иеленеді» деп, екеуі де босатады. Қос босату. Түзету: Әр блоктың бір ғана иесі; басқалары - тек «қарызға алушы».

int vec_push(Vec *v, int x)
{

        int *bigger = realloc(v->data, new_cap * sizeof *bigger);
        if (!bigger)
            return 0;
        v->data = bigger;
        v->cap = new_cap;
    }
    v->data[v->len++] = x;
    return 1;
}

void vec_free(Vec *v)
{
    free(v->data);
    v->data = NULL;
    v->len = v->cap = 0;
}

int vec_pop(Vec *v, int *out)
{
    if (v->len == 0)
        return 0;
    *out = v->data[--v->len];
    return 1;
}

        s += x;
    printf("%d %zu %zu\n", s, v.len, v.cap);
    vec_free(&v);
    return 0;
