    def parse_safe(text):
    rows, bad = [], []
    for i, line in enumerate(text.splitlines(), 1):
        parts = line.split(',')
        if len(parts) != 2:
            bad.append(i)
            continue
        try:
            rows.append((parts[0].strip(), int(parts[1])))
        except ValueError:
            bad.append(i)
    return rows, bad

Шығу билеті және жауап кілті

  1. Level I шолуы: summary_report(results) - {'тест_аты': True/False} сөздігінен 'өтті: X/Y (Z%)' жолын және құлағандардың сұрыпталған тізімін (кортеж) қайтарсын; Z - бүтін пайыз (төмен қарай).

    Жауап кілті

    Үлгі шешім (басқа дұрыс нұсқаны да сайт тесттері қабылдайды):

    def summary_report(results):
    passed = sum(1 for v in results.values() if v)
    total = len(results)
    failed = sorted(k for k, v in results.items() if not v)
    return f'өтті: {passed}/{total} ({passed * 100 // total}%)', failed

  2. Дифференциалдық тест айырма куәсін тапты. Келесі қадам:

    • A Екі нұсқаны да өшіру
    • B Куәні спецификациямен салыстырып, қай нұсқа қате екенін анықтау, оны түзету және куәні тұрақты тест ретінде қосу
    • C Куәні елемеу
    • D Тек C нұсқасын түзету

    Жауап кілті
