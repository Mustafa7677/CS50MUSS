CҰғымға кіріспе

Тізім сұрыпталған болса, ортасындағы элемент көп нәрсе айтады: a[mid] < x болса, x тек оң жақта болуы мүмкін - сол жақ жартыны бір салыстырумен лақтырамыз. Әр қадам іздеу аймағын екі есе қысқартады.

Екілік іздеу қарапайым көрінеді, бірақ оны қатесіз жазу қиын: шекаралар (≤ мен <, mid ± 1) дұрыс болмаса, цикл шексіз айналады не элемент өткізіліп кетеді. Құтқарушы - инвариант (m04 l05): «x бар болса, ол a[lo..hi] ішінде».

DАкадемиялық теория

Анықтама

Инвариант

I: x тізімде бар болса, оның индексі lo ≤ i ≤ hi аралығында. Бастапқыда lo = 0, hi = n − 1 - I ақиқат.

Теорема

Дұрыстық және қадам саны

binary_search дұрыс нәтиже береді және цикл ең көбі ⌊log₂ n⌋ + 1 рет орындалады.

Дәлелдеу

Дәлелдеу

Сақталу: a[mid] < x болса, сұрыпталғандықтан барлық i ≤ mid үшін a[i] ≤ a[mid] < x, демек x (бар болса) mid-тен оңда: lo = mid + 1 I-ді сақтайды. a[mid] > x жағдайы симметриялы. Аяқталу: аралық ұзындығы L = hi − lo + 1 әр қадамда кемінде ⌊L/2⌋-ге дейін қысқарады (mid алынып тасталады, қалған екі бөліктің үлкені ≤ ⌊L/2⌋). L = n-нен бастап k қадамнан кейін L ≤ ⌊n/2ᵏ⌋; k = ⌊log₂ n⌋ + 1 болғанда L = 0, цикл тоқтайды. Нәтиже: L = 0 болғанда I бойынша x жоқ - -1 дұрыс. ∎

Ескерту

bisect

Python-ның bisect.bisect_left(a, x) x-ті кірістіруге болатын бірінші позицияны қайтарады - төменгі шекара (lower bound). Ол да екілік іздеу.

EКөрнекі түсіндірме

67 элементтен 117-ні табу үшін бірнеше қадам жетеді: әр қадамда lo..hi аралығы екі есе қысқарады.

Интерактивті модель: өзің басқар

Инвариант «x бар болса, a[lo..hi] ішінде» әр итерацияда сақталады: lo, hi, mid-тің өзгерісін қадамдап бақылаңыз. x-ті өзгертіп, табылмайтын жағдайды көріңіз.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. lo = 0, hi = n - 1 (жабық аралық [lo, hi]).
  2. Цикл шарты lo <= hi: аралық бос емес.
  3. mid = (lo + hi) // 2; a[mid] == x - табылды.
  4. a[mid] < x - lo = mid + 1 (mid енді керек емес); әйтпесе hi = mid - 1. mid ± 1 болмаса, lo = hi жағдайында цикл шексіз айналуы мүмкін.

GЖұмыс мысалдары

HИнтерактивті эксперимент

Бірінші шақыру жұмыс істеді, екіншісі шексіз циклға түсіп, қадам шегіне жетті. lo = 2, hi = 3 болғанда не болады? lo = mid + 1 деп түзетіңіз.

IЖаттығулар

JМатематикалық пайымдау

Екілік іздеудің мәні тек тізімде емес: «жауап кеңістігінде» де қолданылады. Монотонды шарт (бір жерден бастап әрқашан ақиқат) бар кез келген есепте шекараны log₂ қадаммен табуға болады: бүтін түбір, ең аз сыйымдылық, бірінші қате нұсқа (git bisect).

KЖиі қателер

  • lo = mid (не hi = mid) жабық аралықта.
    Себебі: lo = hi − 1 болғанда mid = lo, аралық қысқармайды - шексіз цикл.
    Түзету: Жабық аралықта mid ± 1; жарты ашық аралықта hi = mid, бірақ шарт lo < hi.
  • Сұрыпталмаған тізімде екілік іздеу.
    Себебі: Инвариант бұзылады - бар элемент «жоқ» болып шығады.
    Түзету: Алдымен сұрыптау (бір рет) не сызықтық іздеу.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
