AОқу мақсаттары

  • Сызықтық іздеуді жазу: бірінші кездесу индексі, барлық индекстер, табылмаса -1.
  • Ең нашар, ең жақсы және орташа жағдайдағы салыстыру санын есептеу.
  • Салыстыруларды санайтын «өлшеуіш» арқылы теорияны тәжірибемен тексеру.

BАлғышарттар

  • Код сапасы

CҰғымға кіріспе

m04 l07-де іздеуді псевдокодпен қарадық. Енді Python-да жазып, оның құнын өлшейміз. Сызықтық іздеу тізімді басынан аяғына дейін қарайды: x-ті тапса - тоқтайды, таппаса - соңына дейін барады.

Бұл модульдің тапсырмаларында тест драйвері элементтерді K класына орайды: әр салыстыру (==, <, ...) санағышты бір арттырады. Сондықтан Python-ның x in a не a.index(x) амалдары да «тегін» емес - олар да сол салыстыруларды жасайды, тек C тілінде.

DАкадемиялық теория

Анықтама

Салыстыру моделі

Алгоритмнің құны - элементтерді салыстыру саны. Бұл модель компьютерге тәуелсіз: салыстыру саны екі есе өссе, уақыт та шамамен екі есе өседі.

Теорема

Төменгі шекара

Ретсіз тізімде x бар-жоғын салыстыру арқылы анықтайтын кез келген алгоритм ең нашар жағдайда n салыстыру жасайды.

Дәлелдеу

Дәлелдеу (қарсылас әдісі)

Алгоритм n − 1 немесе одан аз салыстыру жасап, «жоқ» деп жауап берді делік. Онда кем дегенде бір a[i] позициясы x-пен салыстырылмаған. Қарсылас a[i] = x деп қояды: алгоритм көрген барлық салыстыру нәтижесі өзгермейді (a[i] ешқайсысына қатыспаған), сондықтан алгоритм бәрібір «жоқ» дейді - бірақ x бар. Қайшылық. Демек кез келген дұрыс алгоритм ең нашар жағдайда n салыстыру жасайды. ∎

Ескерту

Орташа жағдай

x тізімде бар және кез келген орында бірдей ықтималдықпен тұрса, салыстырулардың орташа саны (1 + 2 + ... + n) / n = (n + 1) / 2.

EКөрнекі түсіндірме

Ең жақсы жағдай - 1 салыстыру, табылмаса - n = 6. Python-ның in амалы да дәл 6 салыстыру жасады.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Кіріс: тізім a, мән x. Шығыс: x-тің бірінші индексі, жоқ болса -1.
  2. Инвариант: i-ші қадамның басында a[0..i-1] ішінде x жоқ.
  3. a[i] == x болса - i қайтару (бірінші кездесу, өйткені алдында жоқ).
  4. Цикл біткенде инвариант бойынша a[0..n-1] ішінде x жоқ - -1 қайтару.

GЖұмыс мысалдары

HИнтерактивті эксперимент

a.index табылмаған мәнде ValueError береді. Өз linear_search функцияңыз -1 қайтарады - қайсысы қай жағдайда ыңғайлы?

IЖаттығулар

JМатематикалық пайымдау

Сызықтық іздеу «жаман» алгоритм емес: ретсіз деректе ол оңтайлы (теорема). Жылдамырақ іздеу үшін деректің өзі туралы қосымша білім керек - мысалы, оның сұрыпталғаны (келесі сабақ) не хэш-кесте (m08 l04). Алгоритмнің жылдамдығы деректің құрылымынан келеді.

KЖиі қателер

  • Цикл ішінде else: return -1 жазу.
    Себебі: Бірінші элемент сәйкес келмесе бірден -1 қайтарады.
    Түзету: return -1 циклдан кейін.
  • Тапқаннан кейін де циклды жалғастыру.
    Себебі: Ең жақсы жағдай да n салыстыруға айналады.
    Түзету: Тапқан бойда return.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.

MРефлексия

NТереңірек

Honors

  • «Күзетші» (sentinel) әдісі: тізім соңына x қосып, i < n тексерісін алып тастау. Салыстырулар саны қалай өзгереді?

Research

  • Ақпарат іздеу жүйелері миллиардтаған құжатты сызықтық іздемейді - кері индекс (inverted index) қалай жұмыс істейді?
