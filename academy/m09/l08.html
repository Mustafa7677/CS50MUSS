09·08Algorithms with Python

Динамикалық бағдарламалауға кіріспе

  • күрделі
  • ≈ 60 мин
  • 3 мақсат
  • 6 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

AОқу мақсаттары

  • Қайталанатын ішкі есептерді тану және мемоизация (жоғарыдан төмен) қолдану.
  • Кесте толтыру (төменнен жоғары) әдісімен DP шешімін жазу.
  • Оңтайлы ішкі құрылымды дәлелдеп, рекуррент қатынас құру (тиындар, жолдар саны).

BАлғышарттар

  • Ашкөз алгоритмдер

CҰғымға кіріспе

m07 l07-де fib(n) мемоизациясыз экспоненциал шақыру жасағанын көрдік: бір ішкі есеп қайта-қайта шешіледі. Динамикалық бағдарламалау (DP) - әр ішкі есепті бір рет шешіп, нәтижені кестеде сақтау.

DP құру тәртібі: (1) күйді анықтау (мысалы, best[s] - s сомасына ең аз тиын); (2) рекуррент: best[s] = 1 + min(best[s − c]); (3) база: best[0] = 0; (4) есептеу реті: s = 1, 2, ..., amount. Ашкөздік қателескен {1, 3, 4} есебін DP әрқашан дұрыс шешеді.

DАкадемиялық теория

Анықтама

Екі тәсіл

Жоғарыдан төмен: рекурсия + кэш (сөздік не functools.lru_cache). Төменнен жоғары: кестені кіші күйлерден бастап толтыру (цикл). Нәтиже бірдей; екіншісі стек шегіне соқпайды (l06).

Теорема

Тиын есебінің рекурренті

best[0] = 0; s > 0 үшін best[s] = 1 + min{best[s − c] : c ∈ coins, c ≤ s} (ондай c жоқ болса ∞). Бұл s сомасына қажет ең аз тиын санын береді.

Дәлелдеу

Дәлелдеу (оңтайлы ішкі құрылым)

s > 0 сомасының кез келген оңтайлы жиынтығында кемінде бір тиын c бар. Оны алып тастасақ, s − c сомасының жиынтығы қалады; ол s − c үшін оңтайлы болуы керек: әйтпесе одан аз тиынды жиынтыққа c қосып, s үшін бастапқыдан жақсы шешім алар едік - қайшылық. Демек opt(s) = 1 + opt(s − c) қандай да бір c үшін, ал min барлық c-ны қарайды. s бойынша индукциямен best[s] = opt(s). ∎

Ескерту

Құны

Тиын DP: amount · len(coins) амал. Тордағы жолдар: r · c. Экспоненциал рекурсия → көпмүшелік уақыт - DP-ның басты пайдасы.

EКөрнекі түсіндірме

Тордағы жолдар санының рекурсиясы: paths(1, 1), paths(2, 1) сияқты ішкі есептер бірнеше рет қайталанады - DP-ның белгісі.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Есеп: r × c тордың сол жақ жоғарғы бұрышынан оң жақ төменгісіне тек оңға/төмен жүріп неше жол бар?
  2. Күй: ways[i][j] - (i, j)-ге жолдар саны.
  3. Рекуррент: ways[i][j] = ways[i−1][j] + ways[i][j−1]; база: шеттегі ұяшықтар 1.
  4. Кестені жол-жолмен толтыру: r · c амал, ал рекурсия ≈ C(r+c, r) шақыру.

GЖұмыс мысалдары

HИнтерактивті эксперимент

Кестені оқыңыз: best[6] = 2 (3 + 3). Ашкөз 6 үшін 3 береді. Қай сомаларда ашкөз бен DP айырмашылығы бар?

IЖаттығулар

JМатематикалық пайымдау

DP - «есте сақтау арқылы уақытты сатып алу»: кестенің жады экспоненциал уақыттың орнына көпмүшелік уақыт береді. Ең қиын бөлігі - кодты жазу емес, күйді дұрыс таңдау: күй есептің қалған бөлігін шешуге қажетті барлық ақпаратты қамтуы керек.

KЖиі қателер

  • Кестені дұрыс емес ретпен толтыру.
    Себебі: best[s − c] әлі есептелмеген болады.
    Түзету: Тәуелді күйлер алдымен: s = 1, 2, ...; i, j өсу ретімен.
  • Мемоизация кілтіне өзгермелі тізім қолдану.
    Себебі: lru_cache тізімді хэштей алмайды (m08 l03).
    Түзету: Кортеж не бүтін сандар.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.

Honors

Research
