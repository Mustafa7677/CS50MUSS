S08·05Trustworthy AI

Тұрақтылық және adversarial мысал

  • зерттеу
  • ≈ 55 мин
  • 3 мақсат
  • 5 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақ қадамдарынан құрастырылған)
  1. Сұрақ. Модель тест жиынында 99% көрсетсе де, кірістің адамға мүлде байқалмайтын кішкене өзгерісі (суреттегі бірнеше пиксель, мәтіндегі бір таңба) оның шешімін толық өзгертуі мүмкін. Мұндай кіріс - adversarial мысал .
  2. Жол. 1-қадам. Модельдің шешім ұпайын s = w·x + b және ‖w‖₁-ді есептеу.
  3. Жол. 2-қадам. Тұрақтылық радиусы ε* = |s|/‖w‖₁ - бұл кірістің рұқсат етілген шуымен салыстырылады.
  4. Жол. 3-қадам. Ең нашар ауытқуды δᵢ = −ε·sign(wᵢ)·sign(s) арқылы құрып, тексеру.
  5. Жол. 4-қадам. Радиусы шуданкіші шешімдерді «сенімсіз» деп белгілеп, адамға жіберу.
  6. Жол. 5-қадам. Тұрақтылықты арттыру: регуляризация, маржа, adversarial оқыту.
  7. Тексер. Неге жоғары өлшемді модельдер adversarial ауытқуларға осалырақ? Жауап: Себебі ‖w‖₁ өлшем санымен өседі: әр координатадағы кішкене өзгеріс жиналып, ұпайды көп өзгертеді.. Дұрыс: ε* = |s|/‖w‖₁.
  8. Түйін. Сызықтық модельдің тұрақтылық радиусы. w ≠ 0 және w·x + b ≠ 0 болса, ε*(x) = |w·x + b| / ‖w‖₁ (шекарадағы нүкте шешімді өзгертеді деп санағанда). Оған δ i = −ε·sign(w i )·sign(w·x + b) ауытқуы жетеді.
  9. Түйін. Жиі қате: Тек таза тест жиынындағы дәлдікпен бағалау. Дұрысы: Тұрақтылық радиусын не ауытқыған тест жиынында дәлдікті өлшеу.

AОқу мақсаттары

  • Adversarial мысалды (шешімді өзгертетін, адамға байқалмайтын кішкене ауытқу) анықтау.
  • Сызықтық модельде L∞ бойынша шешімді өзгертетін ең кіші ауытқу |w·x + b|/‖w‖₁ екенін Гёльдер теңсіздігімен дәлелдеу.
  • Тұрақтылықты бағалау және жақсарту тәсілдерін (шек маржасы, кіріс валидациясы, тұрақты оқыту) сипаттау.

BАлғышарттар

  • Түсіндірмелілік

CҰғымға кіріспе

Модель тест жиынында 99% көрсетсе де, кірістің адамға мүлде байқалмайтын кішкене өзгерісі (суреттегі бірнеше пиксель, мәтіндегі бір таңба) оның шешімін толық өзгертуі мүмкін. Мұндай кіріс - adversarial мысал. Бұл тек «хакерлік» мәселе емес: шулы сенсор, басқа камера, кішкене өлшеу қатесі де модельді шекараның арғы жағына итеруі мүмкін. Сенімді жүйе тұрақты болуы керек: кірістің кішкене өзгерісі шешімді кенет өзгертпеуі тиіс.

Сызықтық модельде бұл құбылыс толық есептеледі. Шешім - w·x + b таңбасы. Әр ерекшелікті ε-ға (L∞ шегі) өзгертуге рұқсат болса, ұпай ең көп ε·‖w‖₁-ге өзгереді. Демек шешімді өзгерту үшін қажетті ең кіші ε = |w·x + b|/‖w‖₁. Маңызды бақылау: өлшемдер көп болған сайын ‖w‖₁ өседі - әр координатадағы өте кішкене өзгерістер жиналып, үлкен әсер береді. Бұл - жоғары өлшемді модельдердің осалдығының түп-тамыры.

DАкадемиялық теория

Анықтама

Маржа және ауытқу

Сызықтық классификатор f(x) = sign(w·x + b). Ауытқу δ, ‖δ‖∞ = maxi|δi| ≤ ε. x-тегі шешімді өзгертетін ең кіші ε*(x) = min{‖δ‖∞ : f(x + δ) ≠ f(x)}.

Теорема

Сызықтық модельдің тұрақтылық радиусы

w ≠ 0 және w·x + b ≠ 0 болса, ε*(x) = |w·x + b| / ‖w‖₁ (шекарадағы нүкте шешімді өзгертеді деп санағанда). Оған δi = −ε·sign(wi)·sign(w·x + b) ауытқуы жетеді.

Дәлелдеу

Дәлелдеу

s = w·x + b > 0 болсын (теріс жағдай симметриялы). Ауытқудан кейінгі ұпай s + w·δ. Гёльдер теңсіздігі: |w·δ| ≤ ‖w‖₁·‖δ‖∞ (әр мүше |wiδi| ≤ |wi|·max|δj|, қосындыласақ). Демек ‖δ‖∞ = ε болғанда s + w·δ ≥ s − ε‖w‖₁; бұл ε < s/‖w‖₁ болса оң - шешім өзгермейді. Сонымен ε* ≥ s/‖w‖₁. Енді δi = −ε·sign(wi) алайық: w·δ = −ε Σ|wi| = −ε‖w‖₁ (Гёльдердегі теңдік жағдайы). ε = s/‖w‖₁ болғанда ұпай 0-ге, одан көп болса теріске жетеді. Демек ε* = s/‖w‖₁. ∎ Салдар: d өлшемде әр |wi| ≈ c болса, ‖w‖₁ ≈ cd - тұрақтылық радиусы ~1/d кемиді: өлшем көп болған сайын модель нәзігірек.

Ескерту

Тұрақтылықты арттыру

(1) Маржаны үлкейту: шешім шекарасынан алыс нүктелер тұрақты; маржасы кіші шешімдерді адамға жіберу. (2) Кірісті валидациялау және шектеу (s07 l03). (3) Adversarial оқыту: оқытуда ауытқыған мысалдарды қосу. (4) Сызықтық модельде ‖w‖₁-ді регуляризациямен азайту (L1). Тұрақтылықты бөлек метрика ретінде өлшеп, есепте көрсету керек.

EКөрнекі түсіндірме

Ұпай 0.25 (иә). ‖w‖₁ = 4, демек әр ерекшелікті тек ~0.06-ға өзгерту шешімді аударады. ε*-тен сәл аз - иә, сәл көп - жоқ: теорема дәл шекараны береді.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Модельдің шешім ұпайын s = w·x + b және ‖w‖₁-ді есептеу.
  2. Тұрақтылық радиусы ε* = |s|/‖w‖₁ - бұл кірістің рұқсат етілген шуымен салыстырылады.
  3. Ең нашар ауытқуды δᵢ = −ε·sign(wᵢ)·sign(s) арқылы құрып, тексеру.
  4. Радиусы шуданкіші шешімдерді «сенімсіз» деп белгілеп, адамға жіберу.
  5. Тұрақтылықты арттыру: регуляризация, маржа, adversarial оқыту.

GЖұмыс мысалдары

HИнтерактивті эксперимент

Салмақтарды 5 есе кішірейттік (ұпай да 5 есе кіші). ε* өзгерді ме? Неге? (Кеңес: ε* = |s|/‖w‖₁ - алым мен бөлім бірге масштабталады.) Тұрақтылық салмақтардың масштабына емес, неге тәуелді?

IЖаттығулар

JМатематикалық пайымдау

Гёльдер теңсіздігі сызықтық модельдің тұрақтылығын жабық формулаға айналдырады: радиус маржаға (|s|) тура, ал ‖w‖₁-ге кері пропорционал. Бұл нақты нейрон желілер үшін де интуиция береді: олар жергілікті түрде сызықтыққа жақын, ал өлшемі өте үлкен. Сенімді AI тұрақтылықты дәлдік сияқты өлшенетін, есепте көрсетілетін қасиет ретінде қарастырады - және радиусы кіші шешімдерді адамға жібереді.

KЖиі қателер

  • Тек таза тест жиынындағы дәлдікпен бағалау.
    Себебі: Кішкене ауытқуға тұрақсыздық көрінбейді.
    Түзету: Тұрақтылық радиусын не ауытқыған тест жиынында дәлдікті өлшеу.
  • Шекараға жақын шешімдерді де автоматты қабылдау.
    Себебі: Кішкене шу шешімді аударуы мүмкін.
    Түзету: Радиусы шу деңгейінен кіші шешімдерді адамға жіберу.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
