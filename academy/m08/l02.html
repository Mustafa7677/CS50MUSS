08·02Data Structures & Testing

Кортеждер және өзгермейтіндік

  • негізгі
  • ≈ 40 мин
  • 3 мақсат
  • 6 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақ қадамдарынан құрастырылған)
  1. Сұрақ. Кортеж (3, 4) - тізімге ұқсас, бірақ өзгермейді. Ол «бірге жүретін» мәндерге ыңғайлы: координата, (аты, бағасы), функцияның бірнеше нәтижесі: q, r = divmod(17, 5) . Маңызды ұғым: айнымалы - нысанға сілтеме (m06 l02).
  2. Жол. 1-қадам. Функция бірнеше мән қайтаруы керек: min мен max.
  3. Жол. 2-қадам. return (lo, hi) - кортеж.
  4. Жол. 3-қадам. Шақыру: lo, hi = min_max(a) - ашу.
  5. Жол. 4-қадам. Айырбас: a, b = b, a - оң жақ кортеж, сол жақ ашу (уақытша айнымалысыз).
  6. Тексер. a = [1]; b = a; b.append(2). a неге тең? Жауап: [1, 2]. Дұрыс.
  7. Түйін. Бүркеншік ат арқылы өзгеру. b = a (a - тізім) болса, a-ға кез келген орнында өзгерту b арқылы да көрінеді.
  8. Түйін. Жиі қате: b = a деп тізімді «көшіру». Дұрысы: b = a[:] не list(a); ішкі тізімдер болса copy.deepcopy.

AОқу мақсаттары

  • Кортежді (tuple) өзгермейтін тізбек ретінде қолдану, кортежді ашу (unpacking).
  • Айнымалылар мен нысандардың байланысын түсіндіру: бүркеншік ат (alias), is және ==.
  • Өзгермелі және өзгермейтін нысандарды ажыратып, көшірудің (shallow copy) салдарын көрсету.

CҰғымға кіріспе

Кортеж (3, 4) - тізімге ұқсас, бірақ өзгермейді. Ол «бірге жүретін» мәндерге ыңғайлы: координата, (аты, бағасы), функцияның бірнеше нәтижесі: q, r = divmod(17, 5).

Маңызды ұғым: айнымалы - нысанға сілтеме (m06 l02). b = a тізімді көшірмейді: a мен b бір тізімге қарайды. a өзгерсе, b да «өзгереді». Кортежде бұл қауіп жоқ.

DАкадемиялық теория

Анықтама

is және ==

a == b - мәндері тең бе; a is b - бір нысан ба. b = a болғанда a is b; b = a[:] болғанда a == b, бірақ a is not b.

Теорема

Бүркеншік ат арқылы өзгеру

b = a (a - тізім) болса, a-ға кез келген орнында өзгерту b арқылы да көрінеді.

Дәлелдеу

Негіздеу

Меншіктеу b атауын a қарап тұрған нысанға байлайды (жаңа нысан жасамайды). Бір нысан - бір жад. a.append(x) сол нысанды өзгертеді, b сол нысанға қарайды, демек b-да да x бар. ∎ Кортеж өзгермейтіндіктен, бүркеншік ат оны ешқашан «өзгерте» алмайды.

Ескерту

Таяз көшірме

a[:] не list(a) тек сыртқы тізімді көшіреді. Ішкі тізімдер ортақ қалады (5-сабақ): [[1], [2]]-нің таяз көшірмесінде ішкі [1] - сол нысан.

EКөрнекі түсіндірме

b - бүркеншік ат, c - көшірме. Кортеж ашу: x, y = p.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Функция бірнеше мән қайтаруы керек: min мен max.
  2. return (lo, hi) - кортеж.
  3. Шақыру: lo, hi = min_max(a) - ашу.
  4. Айырбас: a, b = b, a - оң жақ кортеж, сол жақ ашу (уақытша айнымалысыз).

GЖұмыс мысалдары

HИнтерактивті эксперимент

TypeError хабарын оқыңыз. Кортежді «өзгерту» үшін не істеу керек? (Жаңа кортеж: p = (5,) + p[1:].)

IЖаттығулар

JМатематикалық пайымдау

Өзгермейтіндіктің пайдасы: кортеж мен жолды сөздік кілті етуге болады (3-сабақ), оларды функцияларға қорықпай беруге болады (m07 l04 - функция оларды бұза алмайды). Бағасы: «өзгерту» әр жолы жаңа нысан жасайды.

KЖиі қателер

  • b = a деп тізімді «көшіру».
    Себебі: Бұл бүркеншік ат, көшірме емес.
    Түзету: b = a[:] не list(a); ішкі тізімдер болса copy.deepcopy.
  • [[0] * n] * m деп тор жасау.
    Себебі: Барлық жол бір нысан.
    Түзету: [[0] * n for _ in range(m)].

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
