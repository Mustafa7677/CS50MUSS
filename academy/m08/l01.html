08·01Data Structures & Testing

Тізімдер

  • 3 мақсат

нұсқа 1.0.0 · тексеру: author-checked

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (авторлық сценарий)
  1. Сұрақ. Сыныптағы 30 атты 30 бөлек айнымалыға сақтайсың ба?
  2. Бейне. Тізім - пойыз: әр вагонда бір мән, вагондар нөмірленген. Нөмір 0-ден басталады!
  3. Болжа. xs[1] неге тең? Жауап: Бота. Индекс 0-ден басталады: xs[0] = Әли, xs[1] = Бота. Индекс - басынан неше вагон өту керегі.
  4. Көр. xs[1] - басынан бір вагон өттік: Бота.
  5. Көр. append пойыздың соңына жаңа вагон тіркейді. Енді len(xs) = 4.
  6. Көр. pop(0) бірінші вагонды ағытады. Қалғандары бір орынға жылжиды - индекстері өзгереді!
  7. Көр. for циклі вагондарды ретпен аралайды: Бота, Дана, Ерлан.
  8. Түйін. Тізім - реттелген мәндер тізбегі: xs[i] i-ші элементті береді (0-ден), append соңына қосады, pop алып тастайды, соңғы индекс - len(xs) − 1.
  9. Түйін. Жиі қате: xs[len(xs)] - соңғы элемент. Дұрысы: Соңғысы - xs[len(xs) − 1] не xs[-1]; xs[len(xs)] IndexError береді.

AОқу мақсаттары

  • Тізім құру, индекстеу, кесінді, append/insert/pop/remove әдістерін қолдану.
  • Амалдардың құнын білу: append және индекстеу O(1), insert(0, x) және x in lst - O(n).
  • Тізімді аралап, сүзгілеп, түрлендіру (m07 l07 тізім құрастыру өрнегі).

BАлғышарттар

  • Рефакторинг

CҰғымға кіріспе

Тізім - ретті, өзгермелі элементтер тізбегі: [3, 1, 4]. Жолдан айырмашылығы - өзгертуге болады: a[0] = 9, a.append(5).

Ішінде тізім жадта қатар тұрған ұяшықтар (m11 l09 динамикалық массив). Сондықтан соңына қосу жылдам, ал басына қосу барлық элементті жылжытады - n қадам. Деректер құрылымын таңдау дегеніміз - амалдардың құнын білу.

DАкадемиялық теория

Анықтама

Негізгі әдістер

append(x), extend(xs), insert(i, x), pop() / pop(i), remove(x), index(x), count(x), sort(), reverse(); len, in, кесінді a[i:j].

Теорема

Сызықтық іздеудің құны

x in lst ең нашар жағдайда len(lst) салыстыру жасайды (m04 l07). Сұрыпталған тізімде bisect модулі O(log n) береді.

Дәлелдеу

Негіздеу

Тізім элементтердің ретсіз жиыны: x-тің орнын білмейміз, сондықтан әр элементті тексеру керек. x жоқ болса, барлық n элемент тексерілмейінше «жоқ» деп айта алмаймыз (бір тексерілмеген элемент x болуы мүмкін). ∎

Ескерту

sort() vs sorted()

a.sort() тізімді орнында өзгертіп None қайтарады; sorted(a) жаңа тізім қайтарады (m07 l04, таза функция).

EКөрнекі түсіндірме

a.sort() None қайтарады, бірақ a-ны өзгертеді. sorted(a) - жаңа тізім.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Есеп: тізімнен қайталанатын элементтерді ретін сақтап жою.
  2. Нәтиже тізімі result = [], көргендер seen = [].
  3. Әр x үшін: if x not in seen: result.append(x); seen.append(x).
  4. Құны: x not in seen - O(n), барлығы O(n²). 4-сабақта set арқылы O(n)-ге түсіреміз.

GЖұмыс мысалдары

HИнтерактивті эксперимент

remove тек бірінші кездесуді өшіреді. index(7) неге ValueError? Алдымен 7 in a деп тексеріңіз.

IЖаттығулар

JМатематикалық пайымдау

Тізім - әмбебап, бірақ әрқашан ең жақсы емес. «Мүшелікті жиі тексеремін» - set; «кілт бойынша іздеймін» - dict; «екі жағынан қосамын» - collections.deque. Құрылымды амалдардың жиілігі бойынша таңдау - алгоритмдік ойлаудың (m04) тәжірибелік жалғасы.

KЖиі қателер

  • a = a.sort() деп жазу.
    Себебі: sort None қайтарады - тізім жоғалады.
    Түзету: a.sort() не a = sorted(a).
  • Тізімді аралап отырып одан элемент өшіру.
    Себебі: Индекстер жылжып, элементтер өткізіліп кетеді.
    Түзету: Жаңа тізім құрыңыз: [x for x in a if ...].

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
