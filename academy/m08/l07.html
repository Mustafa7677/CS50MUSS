Ерекшеліктер

Деңгей: орта · шамамен 50 мин · нұсқа 1.0.0 · тексеру: author-checked

AОқу мақсаттары

  • try/except/else/finally құрылымының орындалу ретін түсіндіру.
  • Нақты ерекшелік түрін ұстау (ValueError, KeyError, FileNotFoundError) және жалпы except-тің қаупін көрсету.
  • raise арқылы өз ерекшелігін көтеру және функция келісімшартын (m07 l03) қорғау.

BАлғышарттар

  • Файлдар

CҰғымға кіріспе

Ерекшелік (exception) - «бұл жерде жалғастыра алмаймын» деген сигнал: int('абв') ValueError көтереді. Ұсталмаса, бағдарлама тоқтап Traceback шығарады (m06 l09).

try: блогында қате шықса, орындау бірден сәйкес except-ке өтеді. else - қате болмағанда, finally - әрқашан орындалады. Ал функция өзі жарамсыз кірісті көрсе, raise ValueError('...') деп хабарлайды - шақырушы шешеді.

DАкадемиялық теория

Анықтама

Құрылым

try: A
except ValueError as e: B
else: C
finally: D
A қатесіз - A, C, D. A-да ValueError - A-ның бір бөлігі, B, D. Басқа қате - A-ның бөлігі, D, сосын қате жоғары көтеріледі.

Теорема

finally әрқашан орындалады

try блогы қалай аяқталса да (қалыпты, return, ұсталған не ұсталмаған қате), finally блогы орындалады.

Дәлелдеу

Негіздеу (жағдайларға бөлу, m02 l05)

try-дан шығудың барлық жолы: (1) қалыпты аяқталу; (2) return/break; (3) except ұстаған қате; (4) ұсталмаған қате. Python семантикасы әр шығу жолына finally-ді тіркейді: (1)-(3)-те finally шығар алдында, (4)-те қате жоғары көтерілер алдында орындалады. Басқа шығу жолы жоқ, демек finally әрқашан орындалады. ∎ (Ерекше жағдай: процестің өзі өлтірілсе - os._exit, қуат сөнуі.)

Ескерту

EAFP және LBYL

LBYL: «секірмес бұрын қара» - if key in d: ... EAFP: «рұқсат сұрағаннан кешірім сұрау оңай» - try: d[key] except KeyError. Python-да EAFP жиі қолданылады, әсіресе файл сияқты сыртқы ресурстарда (тексеру мен ашу арасында файл жоғалуы мүмкін).

EКөрнекі түсіндірме

Орындалу ретін бақылаңыз: return-нан кейін де finally орындалады.

FҚадамдап қорыту

  1. Есеп: пайдаланушы енгізген жасты тексеру.
  2. int(s) - сан емес болса ValueError (Python өзі көтереді).
  3. Сан, бірақ теріс не 150-ден үлкен болса - өзіміз raise ValueError('жас 0..150 аралығында болуы керек').
  4. Шақырушы: try: age = parse_age(s) except ValueError as e: print('қате:', e).

GЖұмыс мысалдары

HИнтерактивті эксперимент

Жалаң except: нөлге бөлуді де, қате типті ('5') де «0» деп жасырды. except ZeroDivisionError деп өзгертіңіз - енді risky('5') қандай қате береді? Бұл жақсы ма?

IЖаттығулар

JМатематикалық пайымдау

Ерекшелік - функция келісімшартының (m07 l03) орындаушысы. «Алғышарт бұзылды» дегенді None не -1 қайтарып жасырудың орнына, raise оны анық айтады: шақырушы оны елемей кете алмайды. Ал except - қатені «жоғалту» емес, оған саналы жауап беру: қайта сұрау, әдепкі мән, түсінікті хабар.

KЖиі қателер

  • except: (не except Exception:) арқылы бәрін ұстау.
    Себебі: Кодтағы қателерді (NameError, TypeError) де жасырады - жөндеу мүмкін болмайды.
    Түзету: Күткен нақты түрді ұстаңыз.
  • try блогына тым көп код салу.
    Себебі: Қай жолдың қатесін ұстағаныңыз белгісіз болады.
    Түзету: try ішінде тек қате шығуы мүмкін жол; қалғаны else-те.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
