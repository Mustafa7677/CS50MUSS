Жиындар (set)

Деңгей: негізгі · шамамен 40 мин · нұсқа 1.0.0 · тексеру: author-checked

AОқу мақсаттары

  • set-ті қайталанбайтын, ретсіз элементтер жиыны ретінде қолдану.
  • | & - ^ амалдарын m03 l02 жиындар амалдарымен байланыстыру.
  • Мүшелікті тексеруді set арқылы O(1)-ге (орташа) түсіру.

BАлғышарттар

  • Сөздіктер

CҰғымға кіріспе

set - m03-тегі математикалық жиынның бағдарламадағы түрі: {1, 2, 3}. Қайталану жоқ, рет жоқ, ал x in s - хэш арқылы бір қадам (3-сабақ сияқты).

Амалдар m03 l02-дегідей: | бірігу, & қиылыс, - айырма, ^ симметриялық айырма; <= ішкі жиын.

DАкадемиялық теория

Анықтама

Амалдар

s.add(x), s.discard(x), x in s, s | t, s & t, s - t, s ^ t, s <= t; бос жиын: set() (ал {} - бос сөздік!).

Теорема

Қайталануды жоюдың құны

«Көргендер» тізімін set-ке ауыстырсақ, ретті сақтап қайталануды жою (1-сабақ) O(n²)-тан орташа O(n)-ге түседі.

Дәлелдеу

Дәлелдеу

Алгоритм n рет «x көрілді ме?» сұрайды. Тізімде әр сұрақ ≤ i салыстыру: Σi = O(n²). set-те әр сұрақ пен қосу орташа O(1): барлығы O(n). Нәтиже тізімі өзгермейді, тек тексеріс құрылымы ауысты. ∎

Ескерту

frozenset

set өзгермелі, сондықтан оны сөздік кілті не басқа set-тің элементі ету мүмкін емес. Өзгермейтін нұсқасы - frozenset.

EКөрнекі түсіндірме

m03 l02 Венн диаграммасының Python нұсқасы. {} - сөздік!

FҚадамдап қорыту

  1. Есеп: екі сыныпта да оқитын оқушылар.
  2. Тізімдермен: [x for x in a if x in b] - O(n·m).
  3. Жиындармен: set(a) & set(b) - орташа O(n + m).
  4. Ретті сақтау керек болса: sb = set(b); [x for x in a if x in sb].

GЖұмыс мысалдары

HИнтерактивті эксперимент

Неше әр түрлі сөз бар? sorted(set(...)) неге қажет (set-тің реті бар ма)?

IЖаттығулар

JМатематикалық пайымдау

set пен dict - бір идеяның (хэш-кесте) екі түрі: set тек кілттерді сақтайды. Сондықтан екеуінде де кілт өзгермейтін болуы керек және ретке сенуге болмайды (set үшін). Тізім, set, dict арасындағы таңдау - «қандай сұрақты жиі қоямын?» сұрағына жауап.

KЖиі қателер

  • Бос жиынды {} деп жасау.
    Себебі: Бұл - сөздік.
    Түзету: set().
  • set-тің ретіне сену.
    Себебі: Ретсіз - нәтиже ретті болмауы мүмкін.
    Түзету: Керек болса sorted() не ретті сақтайтын алгоритм.
