08·05Data Structures & Testing

Ішкі құрылымдар

  • орта
  • ≈ 50 мин

нұсқа 1.0.0 · тексеру: author-checked

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақ қадамдарынан құрастырылған)
  1. Сұрақ. Нақты деректер қабатты: сынып - оқушылар тізімі, әр оқушы - сөздік (аты, бағалары тізімі). students[0]['grades'][-1] - бірінші оқушының соңғы бағасы. Қабаттарды сол жақтан оңға оқимыз.
  2. Жол. 1-қадам. Деректер: [{'name': ..., 'grades': [...]}, ...].
  3. Жол. 2-қадам. Әр оқушының орташасы: sum(s['grades']) / len(s['grades']).
  4. Жол. 3-қадам. Ең жақсы оқушы: max(students, key=lambda s: орташа(s)).
  5. Жол. 4-қадам. Жаңа өріс қосу (деректі бұзбай): [dict(s, avg=...) for s in students].
  6. Тексер. json.loads('{"a": [1, true, null]}') нәтижесі: Жауап: {'a': [1, True, None]}. Дұрыс.
  7. Түйін. Таяз көшірме ішкі нысандарды бөліседі. b = a[:] (не list(a)) болса, барлық i үшін b[i] is a[i].
  8. Түйін. Жиі қате: Таяз көшірмеден кейін ішкі деректі өзгерту. Дұрысы: copy.deepcopy не жаңа құрылым құру.

AОқу мақсаттары

  • Тізім ішіндегі сөздік, сөздік ішіндегі тізім сияқты құрама деректерді оқу және өңдеу.
  • JSON пішімін Python құрылымдарына (json.loads/dumps) аудару.
  • Терең көшірме (copy.deepcopy) пен таяз көшірменің айырмашылығын ішкі құрылымдарда көрсету.

BАлғышарттар

  • Жиындар (set)

CҰғымға кіріспе

Нақты деректер қабатты: сынып - оқушылар тізімі, әр оқушы - сөздік (аты, бағалары тізімі). students[0]['grades'][-1] - бірінші оқушының соңғы бағасы. Қабаттарды сол жақтан оңға оқимыз.

Интернетте деректер жиі JSON пішімінде: ол Python-ның dict/list/str/int/bool/None құрылымдарына дәл сәйкес. json.loads(text) - мәтіннен құрылымға.

DАкадемиялық теория

Анықтама

JSON ↔ Python

object ↔ dict, array ↔ list, string ↔ str, number ↔ int/float, true/false ↔ True/False, null ↔ None. JSON кілттері әрқашан жол.

Теорема

Таяз көшірме ішкі нысандарды бөліседі

b = a[:] (не list(a)) болса, барлық i үшін b[i] is a[i].

Дәлелдеу

Негіздеу

Кесінді жаңа сыртқы тізім жасайды, бірақ оның ұяшықтарына a-ның ұяшықтарындағы сілтемелерді көшіреді (нысандардың өзін емес). Демек b[i] мен a[i] бір нысан. Ішкі нысан өзгермелі болса (тізім), a[i].append(x) b[i]-де де көрінеді. deepcopy рекурсивті түрде әр ішкі нысанның көшірмесін жасайды. ∎

Ескерту

Деректерді өңдеу үлгісі

Сыртқы циклмен жазбаларды аралау, ішкі циклмен/функциямен әр жазбаның өрістерін өңдеу. Жоқ өріс үшін .get(k, әдепкі).

EКөрнекі түсіндірме

JSON мәтіні → тізім ішіндегі сөздіктер → өңдеу → қайтадан JSON.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Деректер: [{'name': ..., 'grades': [...]}, ...].
  2. Әр оқушының орташасы: sum(s['grades']) / len(s['grades']).
  3. Ең жақсы оқушы: max(students, key=lambda s: орташа(s)).
  4. Жаңа өріс қосу (деректі бұзбай): [dict(s, avg=...) for s in students].

GЖұмыс мысалдары

HИнтерактивті эксперимент

7Б сыныбын қосыңыз. Барлық оқушыларды бір сұрыпталған тізімге қалай жинайсыз?

IЖаттығулар

JМатематикалық пайымдау

Ішкі құрылымдар - нақты әлемнің моделі: файл жүйесі - ағаш (m03 l10), JSON - ағаш, кесте - тізімдер тізімі. Оларды өңдеудің ең сенімді тәсілі - рекурсия (m07 l05): әр деңгейде бірдей ереже. Мысалы, кез келген тереңдіктегі тізімді жаю - рекурсивті flatten.

KЖиі қателер

  • Таяз көшірмеден кейін ішкі деректі өзгерту.
    Себебі: Бастапқы деректер де өзгереді.
    Түзету: copy.deepcopy не жаңа құрылым құру.
  • Жоқ өріске ['key'] арқылы қол жеткізу.
    Себебі: KeyError.
    Түзету: .get('key', әдепкі).

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
