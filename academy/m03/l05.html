Эквиваленттік қатынас және бөлу

  • орта
  • ≈ 50 мин

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақ қадамдарынан құрастырылған)
  1. Сұрақ. Кейде әр түрлі нысандарды бір мақсат үшін «бірдей» деп санаймыз: сағат 14:00 мен 2:00-ді циферблатта, 17 мен 5-ті 12-ге бөлгендегі қалдық бойынша. Мұндай «бірдейлік» - эквиваленттік қатынас : рефлексивті, симметриялы, транзитивті.
  2. Жол. 1-қадам. Тұжырым: a ≡ b (mod n) - транзитивті.
  3. Жол. 2-қадам. a ≡ b және b ≡ c: n | (a − b) және n | (b − c).
  4. Жол. 3-қадам. Қосындыны бөледі (m02 l02): n | (a − b) + (b − c) = a − c.
  5. Жол. 4-қадам. Демек a ≡ c (mod n). ∎
  6. Тексер. −4 ≡ ? (mod 3) Жауап: 2. Дұрыс: −4 − 2 = −6 = 3 · (−2).
  7. Түйін. Кластар не бірдей, не қиылыспайды. R эквиваленттік болса, әр a, b үшін не [a] = [b], не [a] ∩ [b] = ∅.
  8. Түйін. Жиі қате: Бір қасиетті тексермей эквиваленттік деп айту. Дұрысы: Рефлексия, симметрия, транзитивтілікті бөлек тексеріңіз.

AОқу мақсаттары

  • Эквиваленттік қатынасты және эквиваленттік класты анықтау.
  • Эквиваленттік қатынас пен жиынды бөлу (partition) арасындағы бір-біріне сәйкестікті дәлелдеу.
  • Модуль бойынша салыстыруды (a ≡ b mod n) эквиваленттік ретінде қолдану.

BАлғышарттар

  • Қатынас қасиеттері

CҰғымға кіріспе

Кейде әр түрлі нысандарды бір мақсат үшін «бірдей» деп санаймыз: сағат 14:00 мен 2:00-ді циферблатта, 17 мен 5-ті 12-ге бөлгендегі қалдық бойынша. Мұндай «бірдейлік» - эквиваленттік қатынас: рефлексивті, симметриялы, транзитивті.

Ол жиынды кластарға бөледі: бір класс ішіндегілер өзара эквивалент, әр түрлі кластар қиылыспайды. mod 3 бойынша ℤ үш класқа бөлінеді: [0], [1], [2].

DАкадемиялық теория

Анықтама

Эквиваленттік класс

[a] = {x ∈ S | x R a}. Мысалы mod 3: [1] = {..., −2, 1, 4, 7, ...}.

Теорема

Кластар не бірдей, не қиылыспайды

R эквиваленттік болса, әр a, b үшін не [a] = [b], не [a] ∩ [b] = ∅.

Дәлелдеу

Дәлелдеу

[a] ∩ [b] ≠ ∅ болсын: c ∈ [a] ∩ [b], яғни c R a және c R b. Симметрия: a R c; транзитивтілік: a R b. Енді x ∈ [a] болса, x R a және a R b, демек x R b, яғни x ∈ [b]. Сонымен [a] ⊆ [b]; симметриялы түрде [b] ⊆ [a]. Демек [a] = [b]. ∎

Теорема

Бөлу ⇔ эквиваленттік

S-тің әр бөлуі (бос емес, қиылыспайтын, бірігуі S болатын бөліктер) «бір бөлікте болу» эквиваленттік қатынасын анықтайды, және керісінше. Бұл сәйкестік бір-біріне.

Анықтама

Модуль бойынша салыстыру

a ≡ b (mod n) ⇔ n | (a − b). Ол - эквиваленттік қатынас; кластары - n қалдық класы.

EКөрнекі түсіндірме

{0..5}-тегі mod 3 салыстыруы. Зертхана эквиваленттік кластарды табады: {0,3}, {1,4}, {2,5}.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Тұжырым: a ≡ b (mod n) - транзитивті.
  2. a ≡ b және b ≡ c: n | (a − b) және n | (b − c).
  3. Қосындыны бөледі (m02 l02): n | (a − b) + (b − c) = a − c.
  4. Демек a ≡ c (mod n). ∎

GЖұмыс мысалдары

HИнтерактивті эксперимент

Бұл эквиваленттік пе? Кластары қандай? (3,4) және (4,3)-ті қосыңыз - кластар қалай өзгерді?

IЖаттығулар

JМатематикалық пайымдау

Эквиваленттік кластар - абстракцияның математикалық негізі. Бөлшек 1/2 = 2/4 = 3/6 - бұл (a, b) жұптарының ad = bc эквиваленттігі бойынша класы. Бағдарламада хэш-кесте (m08) де элементтерді «хэш бойынша бірдей» кластарға бөледі.

KЖиі қателер

  • Бір қасиетті тексермей эквиваленттік деп айту.
    Себебі: Үш қасиеттің бәрі міндетті.
    Түзету: Рефлексия, симметрия, транзитивтілікті бөлек тексеріңіз.
  • Кластар қиылыса алады деп ойлау.
    Себебі: Теорема бойынша не бірдей, не қиылыспайды.
    Түзету: Ортақ элемент табылса, кластар тең.

Модуль жобасы: Set Operations Laboratory
