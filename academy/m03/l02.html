Жиындарға амалдар

Деңгей: негізгі · шамамен 45 мин · нұсқа 1.0.0 · тексеру: author-checked

AОқу мақсаттары

  • ∪, ∩, \, △ және толықтауыш амалдарын есептеу және Венн диаграммасымен көрсету.
  • Жиын тепе-теңдіктерін мүшелік кестесімен (логикаға аудару арқылы) дәлелдеу.
  • Жиындар алгебрасы мен пікірлер логикасының сәйкестігін (m01 l06) пайдалану.

BАлғышарттар

  • Жиындар

CҰғымға кіріспе

Жиындарға амалдар логикалық амалдардың дәл көшірмесі: x ∈ A ∪ B ⇔ (x ∈ A) ∨ (x ∈ B); x ∈ A ∩ B ⇔ (x ∈ A) ∧ (x ∈ B); x ∈ A' ⇔ ¬(x ∈ A). Сондықтан m01-дегі әр логикалық заңның жиындық нұсқасы бар.

Тепе-теңдікті (барлық жиындар үшін ақиқат теңдікті) дәлелдеудің ең сенімді жолы - мүшелік кестесі: x әр жиынға жатуы не жатпауы бойынша барлық жағдайды тексеру. Бұл дәл ақиқат кестесі.

DАкадемиялық теория

Анықтама

Амалдар

A ∪ B = {x | x ∈ A ∨ x ∈ B}; A ∩ B = {x | x ∈ A ∧ x ∈ B}; A \ B = {x | x ∈ A ∧ x ∉ B}; A △ B = (A \ B) ∪ (B \ A); A' = U \ A.

Теорема

Де Морган (жиындар)

(A ∪ B)' = A' ∩ B'; (A ∩ B)' = A' ∪ B'.

Дәлелдеу

Дәлелдеу

x ∈ (A ∪ B)' ⇔ ¬(x ∈ A ∨ x ∈ B) ⇔ ¬(x ∈ A) ∧ ¬(x ∈ B) [логикалық Де Морган] ⇔ x ∈ A' ∩ B'. Әр x үшін мүшелік бірдей, демек жиындар тең. ∎

Теорема

Қосу-алу принципі (екі жиын)

|A ∪ B| = |A| + |B| − |A ∩ B| (шекті жиындар). Қиылыс екі рет саналғандықтан бір рет алынады.

EКөрнекі түсіндірме

Бір тепе-теңдіктің екі жағын салыстырыңыз: (A ∪ B)' мен A' ∩ B' бірдей аймақты бояйды.

FҚадамдап қорыту

  1. Мақсат: A \ (B ∩ C) = (A \ B) ∪ (A \ C).
  2. Мүшелікке аударамыз: a ∧ ¬(b ∧ c).
  3. Де Морган: a ∧ (¬b ∨ ¬c); дистрибутивтілік: (a ∧ ¬b) ∨ (a ∧ ¬c).
  4. Бұл (A \ B) ∪ (A \ C)-ның мүшелік шарты. Тепе-теңдік дәлелденді. ∎

GЖұмыс мысалдары

HИнтерактивті эксперимент

Өрнекті (A ∩ B) ∪ (A ∩ C) етіп өзгертіңіз - аймақ өзгерді ме? Сосын A ∪ (B ∩ C) мен (A ∪ B) ∩ C-ны салыстырыңыз.

IЖаттығулар

JМатематикалық пайымдау

Неге мүшелік кестесі нағыз дәлелдеу, ал бір мысал (A = {1,2}, B = {2,3}) дәлелдеу емес? Себебі тепе-теңдік ТЕК мүшелік шарттарына тәуелді, ал x-тің A, B, C-ге қатысты тек 2³ = 8 түрлі жағдайы бар. Сегіз жағдайды да тексерсек, шексіз көп жиындар жүйесінің бәрін қамтыдық (m02 l05: жағдайларға бөлу).

KЖиі қателер

  • A \ B = B \ A деп санау.
    Себебі: Айырма ауыстырымды емес.
    Түзету: Мысал: {1} \ ∅ = {1}, ∅ \ {1} = ∅.
  • Толықтауышты U-сыз есептеу.
    Себебі: A' тек әмбебап жиынға қатысты анықталады.
    Түзету: Алдымен U-ды анықтаңыз.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
