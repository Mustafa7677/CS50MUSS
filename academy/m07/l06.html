07·06Functions & Abstraction

Рекурсияның дұрыстығы

  • күрделі
  • ≈ 55 мин
  • 3 мақсат
  • 6 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақ қадамдарынан құрастырылған)
  1. Сұрақ. «Рекурсия өзін шақырады, сенуге бола ма?» Бола алады, егер екі нәрсені дәлелдесек: 1) аяқталу - әр шақыру базаға жақындайды (вариант); 2) дұрыстық - базалық жағдай дұрыс және кіші шақырулар дұрыс жауап берсе, оларды біріктіру де дұрыс.
  2. Жол. 1-қадам. Мақсат: binary_digits(n) - n ≥ 1 екілік жазуындағы цифрлар саны.
  3. Жол. 2-қадам. База: n == 1 → 1.
  4. Жол. 3-қадам. Қадам: n ≥ 2 үшін n // 2-нің екілік жазуы n-нің жазуынан соңғы цифрды алып тастағанға тең (m05 l02), сондықтан 1 + binary_digits(n // 2).
  5. Жол. 4-қадам. Вариант: n // 2 < n (n ≥ 2). Күшті индукциямен дұрыс: нәтиже ⌊log₂ n⌋ + 1.
  6. Тексер. Рекурсивті функцияның аяқталуын дәлелдеу үшін не керек? Жауап: Әр шақыруда қатаң кемитін, теріс емес шама. Дұрыс: вариант.
  7. Түйін. Жылдам дәреже. def fast_pow(b, e): if e == 0: return 1 h = fast_pow(b, e // 2) return h * h if e % 2 == 0 else h * h * b fast_pow(b, e) = bᵉ барлық e ≥ 0 үшін.
  8. Түйін. Жиі қате: Аяқталуды тексермеу (мысалы, e // 2 орнына e). Дұрысы: Әр рекурсивті шақыруда кіріс қатаң кемитінін көрсетіңіз.

AОқу мақсаттары

  • Рекурсивті функцияның дұрыстығын күшті индукциямен дәлелдеу: база + «кіші шақырулар дұрыс болса, бұл да дұрыс».
  • Рекурсияның аяқталуын кемитін өлшеммен (m04 l06) дәлелдеу.
  • Бөліп ал да билей рекурсиясын (жылдам дәрежеге шығару) жазып, қадам санын бағалау.

CҰғымға кіріспе

«Рекурсия өзін шақырады, сенуге бола ма?» Бола алады, егер екі нәрсені дәлелдесек: 1) аяқталу - әр шақыру базаға жақындайды (вариант); 2) дұрыстық - базалық жағдай дұрыс және кіші шақырулар дұрыс жауап берсе, оларды біріктіру де дұрыс. Бұл - m02 l08 күшті индукциясының дәл өзі.

Бұл «рекурсивті сенім» (recursive leap of faith): функцияны жазғанда кіші шақыруды «ол дұрыс жұмыс істейді» деп ұйғарамыз - индукциялық болжам сияқты.

DАкадемиялық теория

Теорема

Жылдам дәреже

def fast_pow(b, e):
    if e == 0: return 1
    h = fast_pow(b, e // 2)
    return h * h if e % 2 == 0 else h * h * b

fast_pow(b, e) = bᵉ барлық e ≥ 0 үшін.

Дәлелдеу

Дәлелдеу (күшті индукция e бойынша)

База: e = 0 → 1 = b⁰. Қадам: e ≥ 1, барлық e' < e үшін дұрыс деп ұйғарамыз. e // 2 < e, сондықтан h = b^(e//2). e жұп: e = 2·(e//2), h·h = bᵉ. e тақ: e = 2·(e//2) + 1, h·h·b = bᵉ. Аяқталу: e әр шақыруда e // 2-ге кемиді, ал e ≥ 1 үшін e // 2 < e, вариант теріс емес. ∎

Теорема

Шақырулар саны

fast_pow ⌊log₂ e⌋ + 2 шақыру жасайды (e ≥ 1): әр шақыру e-ні екі есе кемітеді (m04 l07 екілік іздеудің аргументі). Қарапайым power (m07 l05) - e + 1 шақыру.

Ескерту

Үлгі

Рекурсивті функцияны дәлелдеу жоспары: (1) не қайтарады - кейінгі шарт; (2) база; (3) кіші шақырулар кейінгі шартты қанағаттандырады деп ұйғару; (4) біріктіру кейінгі шартты береді; (5) вариант.

EКөрнекі түсіндірме

fast_pow(3, 13): тек 5 шақыру (13 → 6 → 3 → 1 → 0). Қарапайым рекурсия 14 шақыру жасар еді.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Мақсат: binary_digits(n) - n ≥ 1 екілік жазуындағы цифрлар саны.
  2. База: n == 1 → 1.
  3. Қадам: n ≥ 2 үшін n // 2-нің екілік жазуы n-нің жазуынан соңғы цифрды алып тастағанға тең (m05 l02), сондықтан 1 + binary_digits(n // 2).
  4. Вариант: n // 2 < n (n ≥ 2). Күшті индукциямен дұрыс: нәтиже ⌊log₂ n⌋ + 1.

GЖұмыс мысалдары

HИнтерактивті эксперимент

Ағаштың тереңдігі неше? 100-дің екілік жазуы 1100100 - 7 цифр. binary_digits(0) шақырса не болады (алдын ала шарт)?

IЖаттығулар

JМатематикалық пайымдау

Рекурсия жазуда ең үлкен кедергі - бүкіл шақырулар тізбегін басқа ұстауға тырысу. Индукциялық ойлау оны керек етпейді: тек бір қадамды тексереміз. Бұл - күрделі алгоритмдерді (біріктіру сұрыптауы, ағаштар) жазудың негізгі ойлау құралы.

KЖиі қателер

  • Аяқталуды тексермеу (мысалы, e // 2 орнына e).
    Себебі: Вариант кемімейді - шексіз рекурсия.
    Түзету: Әр рекурсивті шақыруда кіріс қатаң кемитінін көрсетіңіз.
  • Бір мәнді екі рет рекурсивті есептеу: fast_pow(b, e//2) * fast_pow(b, e//2).
    Себебі: Шақырулар саны log емес, e-ге айналады.
    Түзету: Нәтижені айнымалыға сақтаңыз (h = ...).

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
