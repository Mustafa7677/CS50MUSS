07·05Functions & Abstraction

Рекурсия

  • орта
  • ≈ 50 мин
  • 3 мақсат
  • 6 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақ қадамдарынан құрастырылған)
  1. Сұрақ. Рекурсия - функцияның өзін-өзі шақыруы. Ол m02 l09-дағы рекурсивті анықтаманың кодтағы бейнесі: n! = n · (n − 1)!, 0! = 1. Кілт - базалық жағдай : онсыз шақырулар шексіз жалғасады (RecursionError).
  2. Жол. 1-қадам. Анықтама: 0! = 1; n! = n · (n − 1)!.
  3. Жол. 2-қадам. Базалық жағдай: if n == 0: return 1.
  4. Жол. 3-қадам. Рекурсивті қадам: return n * factorial(n − 1).
  5. Жол. 4-қадам. factorial(3) → 3 · factorial(2) → 3 · 2 · factorial(1) → 3 · 2 · 1 · factorial(0) → 6.
  6. Түйін. Фибоначчи рекурсиясының шақырулар саны. Тура рекурсивті fib(n) (fib(0)=0, fib(1)=1) шақырулар саны C(n) = 2·F(n + 1) − 1.
  7. Түйін. Жиі қате: Базалық жағдайды ұмыту. Дұрысы: Ең бірінші базалық жағдайды жазыңыз.

AОқу мақсаттары

  • Рекурсивті функцияның екі бөлігін - базалық жағдай мен рекурсивті қадамды жазу.
  • Рекурсия ағашы арқылы шақырулар санын бақылау (Code X-Ray зертханасы).
  • Рекурсивті анықтаманы (m02 l09) Python функциясына тура аудару.

BАлғышарттар

  • Таза функция және жанама әсер

CҰғымға кіріспе

Рекурсия - функцияның өзін-өзі шақыруы. Ол m02 l09-дағы рекурсивті анықтаманың кодтағы бейнесі: n! = n · (n − 1)!, 0! = 1. Кілт - базалық жағдай: онсыз шақырулар шексіз жалғасады (RecursionError).

Әр шақыру өз жергілікті айнымалыларымен бөлек жұмыс істейді (2-сабақ). AO17 рекурсия ағашы зертханасы әр шақыруды, оның аргументтері мен қайтарған мәнін көрсетеді.

DАкадемиялық теория

Анықтама

Рекурсивті функция құрылымы

def f(n):
    if базалық_жағдай(n):
        return тікелей_жауап
    return ... f(кішірек_n) ...
Теорема

Фибоначчи рекурсиясының шақырулар саны

Тура рекурсивті fib(n) (fib(0)=0, fib(1)=1) шақырулар саны C(n) = 2·F(n + 1) − 1.

Дәлелдеу

Дәлелдеу (күшті индукция)

C(0) = C(1) = 1 = 2·F(1) − 1 = 2·F(2) − 1. n ≥ 2: C(n) = 1 + C(n − 1) + C(n − 2) = 1 + 2F(n) − 1 + 2F(n − 1) − 1 = 2(F(n) + F(n − 1)) − 1 = 2F(n + 1) − 1. ∎ Демек шақырулар саны Фибоначчи сандарындай экспоненциал өседі.

Ескерту

Рекурсия тереңдігі

Python әдепкіде ~1000 деңгейден терең рекурсияға рұқсат бермейді (RecursionError). Терең есептер үшін итерация (m09 l06) не мемоизация (m09 l08).

EКөрнекі түсіндірме

fib(5) рекурсия ағашы: 15 шақыру. Бір мән (fib(2)) бірнеше рет есептеледі - оны 8-сабақта жоямыз.

Интерактивті модель: өзің басқар

Рекурсия - функцияның өзін шақыруы. Әр шақыру жаңа кадр ашады (тереңдік өседі), қайту кезінде нәтиже төменнен жоғары жиналады.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Анықтама: 0! = 1; n! = n · (n − 1)!.
  2. Базалық жағдай: if n == 0: return 1.
  3. Рекурсивті қадам: return n * factorial(n − 1).
  4. factorial(3) → 3 · factorial(2) → 3 · 2 · factorial(1) → 3 · 2 · 1 · factorial(0) → 6.

GЖұмыс мысалдары

HИнтерактивті эксперимент

Ағаш неге «тізбек» (тармақсыз)? Базалық жағдайды алып тастап (if-ті өшіріп) не болатынын зертханада көріңіз.

IЖаттығулар

JМатематикалық пайымдау

Рекурсия мен индукция - бір идеяның екі жағы: индукция «кіші жағдай ақиқат болса, үлкені де ақиқат» дейді, рекурсия «кіші жағдайды шешсем, үлкенін шешемін» дейді. Сондықтан рекурсивті функцияның дұрыстығы индукциямен дәлелденеді (6-сабақ).

KЖиі қателер

  • Базалық жағдайды ұмыту.
    Себебі: Шексіз рекурсия - RecursionError.
    Түзету: Ең бірінші базалық жағдайды жазыңыз.
  • Рекурсивті шақыру кішірек кіріспен емес.
    Себебі: factorial(n) ішінде factorial(n) - тоқтамайды.
    Түзету: Әр шақыруда базаға жақындау (вариант, m04 l06).

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
