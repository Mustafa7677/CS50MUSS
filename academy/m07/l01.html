07·01Functions & Abstraction

Функция анықтау

  • негізгі
  • ≈ 40 мин
  • 3 мақсат
  • 6 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

AОқу мақсаттары

  • def арқылы параметрлері бар функция анықтап, return арқылы нәтиже қайтару.
  • return мен print-тің айырмашылығын түсіндіру; return жоқ функцияның None қайтаратынын білу.
  • Әдепкі мәнді параметрлер мен аталған аргументтерді қолдану.

BАлғышарттар

  • Шағын жоба: есептеу утилитасы

CҰғымға кіріспе

Функция - атау берілген, қайта қолданылатын код бөлігі: кірісі (параметрлер) және шығысы (return). m03 l06-дағы математикалық функция сияқты: әр кіріске бір нәтиже.

Ең жиі шатасу: print нәтижені экранға шығарады, ал return оны шақырушыға береді. Есептеген мәнді басқа есепте қолдану үшін тек return жарайды.

DАкадемиялық теория

Анықтама

Анықтау және шақыру

def area(w, h=1):
    return w * h

area(3, 4), area(5), area(h=2, w=3) - позициялық, әдепкі және аталған аргументтер.

Ескерту

return жоқ болса

Функция соңына дейін return-сыз жетсе, None қайтарады. Сондықтан x = print(5) → x = None.

Теорема

Функциялар композициясы

f пен g функциялары return арқылы мән қайтарса, g(f(x)) - тағы бір функция; бір функцияның шығысы келесісінің кірісі (m04 l10 композиция).

Дәлелдеу

Негіздеу

f(x) өрнегі мән береді (return), сондықтан оны кез келген өрнектің ішіне, соның ішінде g-ның аргументіне қоюға болады. Ал print-тейтін f None береді, g(None) мағынасыз не қате - сондықтан композиция тек return-мен жұмыс істейді. ∎

EКөрнекі түсіндірме

shout return жасамайды, сондықтан x = None. Оны return text.upper() етіп өзгертіңіз.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Есеп: шеңбердің ауданы, π ≈ 3.14159.
  2. Кіріс: r. Шығыс: π r².
  3. def circle_area(r): return 3.14159 * r ** 2.
  4. Композиция: сақина ауданы = circle_area(R) − circle_area(r).

GЖұмыс мысалдары

HИнтерактивті эксперимент

Неге TypeError: NoneType + int? double-ды return-мен түзетіңіз.

IЖаттығулар

JМатематикалық пайымдау

Функция - абстракцияның бірінші құралы: шақырушы ІШІН білмей-ақ, тек АТЫ мен КЕЛІСІМШАРТЫН (не алады, не қайтарады) біледі. circle_area-ны ring_area жазушы π-дің қалай есептелгенін ойламайды. Бұл m04 l10 декомпозицияның тілдік жүзеге асуы.

KЖиі қателер

  • Функция ішінде нәтижені print-теп, return жасамау.
    Себебі: Шақырушы мәнді ала алмайды (None).
    Түзету: Есептейтін функция return жасасын; шығаруды бөлек жасаңыз.
  • Функцияны анықтаусыз шақыру.
    Себебі: Python жоғарыдан төмен оқиды - NameError.
    Түзету: def шақырудан бұрын тұруы керек.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
