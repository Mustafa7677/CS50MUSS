07·08Functions & Abstraction

Модульдер

нұсқа 1.0.0 · тексеру: author-checked

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақ қадамдарынан құрастырылған)
  1. Сұрақ. Модуль - функциялар мен айнымалылар жиынтығы бар .py файл. import math - math модулін жүктеп, math.sqrt(16) деп қолдану. Python-ның «батареялары кіріп тұр»: стандартты кітапханада жүздеген модуль бар.
  2. Жол. 1-қадам. geometry.py файлы: def circle_area(r) ... ; def ring_area(R, r) ...
  3. Жол. 2-қадам. Сол файлдың соңында: if __name__ == '__main__': print(circle_area(1)) - тек демо.
  4. Жол. 3-қадам. main.py: from geometry import ring_area; print(ring_area(3, 2)).
  5. Жол. 4-қадам. main.py іске қосылғанда geometry-дің демо жолы шықпайды - __name__ 'geometry'.
  6. Тексер. if __name__ == '__main__': блогы қашан орындалады? Жауап: Файл тікелей іске қосылғанда ғана. Дұрыс.
  7. Түйін. math.isqrt дәлдігі. math.isqrt(n) = ⌊√n⌋ кез келген n ≥ 0 бүтін үшін дәл, ал int(math.sqrt(n)) үлкен n-де қате болуы мүмкін.
  8. Түйін. Жиі қате: Файлды стандартты модульдің атымен атау (random.py, math.py). Дұрысы: Бірегей атау беріңіз.

AОқу мақсаттары

  • import, from ... import және import ... as түрлерін қолдану.
  • Стандартты кітапхананың math, random, statistics модульдерімен жұмыс істеу.
  • Өз модуліңізді құрып, if __name__ == '__main__' үлгісінің мағынасын түсіндіру.

BАлғышарттар

  • Жоғары ретті функциялар

CҰғымға кіріспе

Модуль - функциялар мен айнымалылар жиынтығы бар .py файл. import math - math модулін жүктеп, math.sqrt(16) деп қолдану. Python-ның «батареялары кіріп тұр»: стандартты кітапханада жүздеген модуль бар.

Өз кодыңызды модульдерге бөлу (geometry.py, stats.py) - m04 l10 декомпозициясының файлдар деңгейіндегі түрі. if __name__ == '__main__': блогы файлды тікелей іске қосқанда ғана орындалады, import кезінде - жоқ.

DАкадемиялық теория

Анықтама

Импорт түрлері

  • import math → math.sqrt(2)
  • from math import sqrt, pi → sqrt(2)
  • import statistics as st → st.median([...])
Ескерту

__name__

Файл тікелей іске қосылса __name__ == '__main__'; import етілсе __name__ == модуль аты. Демек тест/демо кодын осы шартпен жабамыз.

Теорема

math.isqrt дәлдігі

math.isqrt(n) = ⌊√n⌋ кез келген n ≥ 0 бүтін үшін дәл, ал int(math.sqrt(n)) үлкен n-де қате болуы мүмкін.

Дәлелдеу

Негіздеу

math.sqrt float (53 биттік мантисса, m05 l05) қайтарады. n > 2⁵³ болса, n-нің өзі float-та дәл бейнеленбейді, демек √n жуықтамасы ⌊√n⌋-ден ауытқуы мүмкін. isqrt тек бүтін арифметиканы (Ньютон әдісі) қолданады. Мысалы n = (10¹⁵ + 1)² − 1 үшін int(sqrt(n)) = 10¹⁵ + 1, ал isqrt(n) = 10¹⁵ (дұрысы). ∎

EКөрнекі түсіндірме

seed - кездейсоқ сандарды қайталанатын етеді: тест үшін маңызды.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. geometry.py файлы: def circle_area(r) ... ; def ring_area(R, r) ...
  2. Сол файлдың соңында: if __name__ == '__main__': print(circle_area(1)) - тек демо.
  3. main.py: from geometry import ring_area; print(ring_area(3, 2)).
  4. main.py іске қосылғанда geometry-дің демо жолы шықпайды - __name__ 'geometry'.

GЖұмыс мысалдары

HИнтерактивті эксперимент

Әр бет шамамен 1000 рет түсе ме? seed-ті өзгертіп, қайталап көріңіз. Неге тестте seed керек?

IЖаттығулар

JМатематикалық пайымдау

Стандартты кітапхананы қолдану - «дөңгелекті қайта ойлап таппау». Бірақ AO17-де алгоритмдерді алдымен өзіміз жазамыз (max, median, sort), сосын кітапханамен салыстырамыз: түсіну үшін жазамыз, жұмыс үшін кітапхананы қолданамыз.

KЖиі қателер

  • Файлды стандартты модульдің атымен атау (random.py, math.py).
    Себебі: import өз файлыңызды жүктеп, стандартты модульді жасырады.
    Түзету: Бірегей атау беріңіз.
  • from module import * қолдану.
    Себебі: Атаулар соқтығысады, қай функция қайдан екені белгісіз.
    Түзету: Нақты атауларды импорттаңыз.
