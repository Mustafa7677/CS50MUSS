07·03Functions & Abstraction

Келісімшарт: алдын ала және кейінгі шарттар

  • орта
  • ≈ 45 мин
  • 3 мақсат
  • 6 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

AОқу мақсаттары

  • Функцияның келісімшартын (алдын ала шарт, кейінгі шарт, мысалдар) docstring-те жазу.
  • Алдын ала шартты assert не ValueError арқылы тексеру.
  • Келісімшарттан тесттер шығару (m04 l02-дегі ұғымның кодтағы түрі).

BАлғышарттар

  • Көру аймағы

CҰғымға кіріспе

m04 l02-де келісімшартты қағазда жаздық. Python-да оны docstring-те - функцияның бірінші жолындағы жолда - жазамыз. help(f) оны көрсетеді, ал оқырман кодты ашпай-ақ функцияны қолдана алады.

Алдын ала шарт бұзылса не істейміз? Екі тәсіл: assert (әзірлеу кезінде қатені ерте табу) не raise ValueError(...) (пайдаланушыға түсінікті хабар). Үнсіз қате нәтиже қайтару - ең нашар тәсіл.

DАкадемиялық теория

Анықтама

Docstring үлгісі

def mean(nums):
    """Сандардың орташасы.
    Алдын ала шарт: nums бос емес.
    Кейінгі шарт: min(nums) ≤ нәтиже ≤ max(nums).
    >>> mean([1, 2, 3])
    2.0
    """
Теорема

Орташаның кейінгі шарты

Бос емес nums үшін min(nums) ≤ mean(nums) ≤ max(nums).

Дәлелдеу

Дәлелдеу

m = min, M = max. Әр x үшін m ≤ x ≤ M. Қосындысы: n·m ≤ Σx ≤ n·M. n > 0-ге бөлсек: m ≤ Σx/n ≤ M. ∎ Бұл кейінгі шартты тестте assert ретінде қолдануға болады.

Ескерту

assert vs raise

assert - «бұл ешқашан болмауы керек» (бағдарламашы қатесі); python -O оны өшіреді. raise ValueError - «пайдаланушы қате кіріс берді» (күтілетін жағдай); әрқашан жұмыс істейді.

EКөрнекі түсіндірме

Бос тізімге түсінікті ValueError. Хабарды өзгертіп көріңіз.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Функция: percent(part, whole) - пайыз.
  2. Алдын ала шарт: whole > 0 және 0 ≤ part ≤ whole.
  3. Кейінгі шарт: 0 ≤ нәтиже ≤ 100.
  4. Тесттер: (0, 10) → 0; (5, 10) → 50; (10, 10) → 100; (1, 0) → ValueError.

GЖұмыс мысалдары

HИнтерактивті эксперимент

AssertionError хабарын оқыңыз. Оны ValueError-ға ауыстырыңыз - қайсысы пайдаланушыға түсініктірек?

IЖаттығулар

JМатематикалық пайымдау

Келісімшарт - тест жазудың нұсқаулығы: алдын ала шарттың шекарасы (бос тізім, whole = 0) және кейінгі шарттың тексерісі (min ≤ m ≤ max). «Келісімшарт бойынша жобалау» (Design by Contract) - Eiffel тілінде басталған, қазір кең қолданылатын әдіс.

KЖиі қателер

  • Алдын ала шарт бұзылғанда үнсіз 0 не None қайтару.
    Себебі: Қате әрі қарай таралып, кейін түсініксіз жерде шығады.
    Түзету: Ерте және түсінікті: raise ValueError('...').
  • Docstring-ті кодтан кейін жазу.
    Себебі: Docstring - функцияның БІРІНШІ жолы ғана.
    Түзету: def-тен кейін бірден.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
