07·02Functions & Abstraction

Көру аймағы

нұсқа 1.0.0 · тексеру: author-checked

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақ қадамдарынан құрастырылған)
  1. Сұрақ. Функция ішінде құрылған айнымалы жергілікті : ол тек сол шақыру кезінде ғана бар, шақыру аяқталғанда жоғалады. Сыртта құрылғаны ғаламдық .
  2. Жол. 1-қадам. count = 0; def add(): count = count + 1.
  3. Жол. 2-қадам. add() → UnboundLocalError: денеде меншіктеу бар, count жергілікті.
  4. Жол. 3-қадам. Шешім 1 (жаман): global count.
  5. Жол. 4-қадам. Шешім 2 (жақсы): def add(count): return count + 1; count = add(count).
  6. Тексер. x = 1; def f(): x = 2; f(); print(x) - не шығады? Жауап: 1. Дұрыс: f ішіндегі x жергілікті.
  7. Түйін. Меншіктеу жергілікті етеді. Функция денесінің кез келген жерінде x = ... болса (global x-сыз), x сол функцияда толығымен жергілікті - тіпті меншіктеуден БҰРЫН оқылса да.
  8. Түйін. Жиі қате: Функция ішінде ғаламдық айнымалыны өзгертуге тырысу. Дұрысы: Параметр + return.

AОқу мақсаттары

  • Жергілікті (local) және ғаламдық (global) айнымалыларды ажырату.
  • LEGB ережесін (Local, Enclosing, Global, Built-in) атау іздеу реті ретінде түсіндіру.
  • Ғаламдық айнымалыны функция ішінде өзгертудің қауіпін және оның орнына параметр/return қолдануды көрсету.

BАлғышарттар

  • Функция анықтау

CҰғымға кіріспе

Функция ішінде құрылған айнымалы жергілікті: ол тек сол шақыру кезінде ғана бар, шақыру аяқталғанда жоғалады. Сыртта құрылғаны ғаламдық. Python атауды іздегенде алдымен жергіліктіден, сосын сыртқы функциядан, сосын ғаламдықтан, соңында кірістірілген атаулардан (len, print) іздейді - LEGB.

Функция ішінде атауға мән берсеңіз (x = ...), ол жергілікті болады - сырттағы x өзгермейді. Бұл қате емес, қорғаныс: функциялар бір-бірінің айнымалыларын байқаусыз бұзбайды.

DАкадемиялық теория

Анықтама

LEGB

Атау іздеу реті: Local → Enclosing (сыртқы функция) → Global (модуль) → Built-in. Бірінші табылғаны қолданылады.

Теорема

Меншіктеу жергілікті етеді

Функция денесінің кез келген жерінде x = ... болса (global x-сыз), x сол функцияда толығымен жергілікті - тіпті меншіктеуден БҰРЫН оқылса да.

Дәлелдеу

Түсіндіру (мысал арқылы)

Python функцияны компиляциялағанда денесін бір рет қарап, меншіктелген атауларды жергілікті деп белгілейді. Сондықтан x = 5; def f(): print(x); x = 1 - f() шақырғанда UnboundLocalError: print(x) жергілікті x-ті іздейді, ол әлі берілмеген. ∎

Ескерту

global қаупі

global x функцияға сыртқы x-ті өзгертуге рұқсат береді, бірақ функция енді тек кірісіне тәуелді емес - оны тестілеу қиындайды (4-сабақ, таза функция).

EКөрнекі түсіндірме

f ішіндегі x - басқа айнымалы. g тек оқиды, сондықтан ғаламдық x-ті көреді.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. count = 0; def add(): count = count + 1.
  2. add() → UnboundLocalError: денеде меншіктеу бар, count жергілікті.
  3. Шешім 1 (жаман): global count.
  4. Шешім 2 (жақсы): def add(count): return count + 1; count = add(count).

GЖұмыс мысалдары

HИнтерактивті эксперимент

Қате неге шықты? add-ты total-ды параметр ретінде алатындай етіп түзетіңіз.

IЖаттығулар

JМатематикалық пайымдау

Жергілікті аймақ - функциялардың тәуелсіздігінің кепілі. Әр шақырудың өз айнымалылары бар (m11 l04-те оны стек кадры деп атаймыз). Рекурсия (5-сабақ) осының арқасында жұмыс істейді: fib(5) пен fib(4)-тің n-дері бір-біріне кедергі келтірмейді.

KЖиі қателер

  • Функция ішінде ғаламдық айнымалыны өзгертуге тырысу.
    Себебі: UnboundLocalError не күтпеген жергілікті айнымалы.
    Түзету: Параметр + return.
  • Кірістірілген атауды (list, sum, max) айнымалы ретінде қолдану.
    Себебі: Built-in жасырылады: sum = 0; sum([1, 2]) - TypeError.
    Түзету: total, nums сияқты атау беріңіз.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.

MРефлексия

NТереңірек

Honors

  • nonlocal кілт сөзімен ішкі функция сыртқы функцияның айнымалысын өзгертсін (счетчик-жабылу). global-дан айырмашылығы?

Research

  • Жабылу (closure) дегеніміз не? Ішкі функция сыртқы функция аяқталғаннан кейін де оның айнымалыларын «есте сақтайды» - мұны қалай іске асырады?
