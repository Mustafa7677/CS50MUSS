02·01Mathematical Proof

Дәлелдеу деген не

  • негізгі
  • ≈ 40 мин
  • 3 мақсат
  • 6 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

AОқу мақсаттары

  • Аксиома, анықтама, теорема, лемма, салдар және болжам (гипотеза) ұғымдарын ажырату.
  • Дәлелдеуді «алғышарттан қорытындыға апаратын, әр қадамы негізделген тізбек» ретінде сипаттау.
  • Көп мысалмен тексеру неліктен дәлелдеу емес екенін нақты мысалмен көрсету.

BАлғышарттар

  • Логика бағдарламада және схемада

CҰғымға кіріспе

Бағдарламаны 100 кіріспен тексеріп, қатесіз деп айтуға бола ма? Жоқ: 101-кіріс оны құлатуы мүмкін. Математикада да солай. Тұжырымның шексіз көп жағдай үшін ақиқат екеніне кепілді тек дәлелдеу береді.

Дәлелдеу дегеніміз - әр қадамы не анықтамадан, не бұрын дәлелденген тұжырымнан, не логика ережесінен (m01) шығатын тізбек. Ол алғышарттан басталып, қорытындымен аяқталады.

Мысал: n² + n + 41 өрнегі n = 0, 1, ..., 39 үшін жай сан береді. 40 рет «иә» деген нәтиже сенім тудырады, бірақ n = 40 болғанда 40² + 40 + 41 = 41². Мысалдар болжам ұсынады, дәлелдеу оны теоремаға айналдырады.

DАкадемиялық теория

Анықтама

Негізгі ұғымдар

  • Аксиома - дәлелдеусіз қабылданатын бастапқы тұжырым.
  • Анықтама - ұғымның мағынасын нақты белгілеу (мысалы, «n жұп ⇔ n = 2k болатын бүтін k бар»).
  • Теорема - дәлелденген маңызды тұжырым. Лемма - басқа дәлелдеуге көмекші тұжырым. Салдар - теоремадан тікелей шығатын тұжырым.
  • Болжам (гипотеза) - әлі дәлелденбеген, бірақ ақиқат деп ұйғарылған тұжырым.
Ескерту

Теореманың пішіні

Көп теорема «∀x (P(x) → Q(x))» пішінінде болады. Оны дәлелдеу үшін еркін x алып, P(x) ақиқат деп ұйғарамыз да, Q(x) шығатынын көрсетеміз. «Еркін» сөзі маңызды: біз x-тің ешбір ерекше қасиетін пайдаланбаймыз.

Теорема

Екі жұп санның қосындысы жұп

a мен b жұп болса, a + b жұп.

Дәлелдеу

Дәлелдеу

a мен b - еркін жұп сандар. Анықтама бойынша a = 2k және b = 2m болатын бүтін k, m бар. Онда a + b = 2k + 2m = 2(k + m). k + m - бүтін сан, сондықтан анықтама бойынша a + b жұп. ∎

EКөрнекі түсіндірме

Әр n үшін n² + n + 41 мәні. Қызыл - тұжырымды бұзатын мән. 40-қа дейін бәрі жай сан, бірақ бұл дәлелдеу емес.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Тұжырымды «егер ... онда ...» пішініне келтіреміз: «a жұп және b жұп → a + b жұп».
  2. Алғышартты анықтамамен ашамыз: a = 2k, b = 2m.
  3. Алгебралық түрлендіру: a + b = 2(k + m).
  4. Қорытындыны анықтамамен жабамыз: 2 · (бүтін сан) - жұп сан.

GЖұмыс мысалдары

HИнтерактивті эксперимент

n² − n + 41 өрнегін зерттеңіз. Бірінші қарсы мысал қай n-де шығады? Ол алдыңғы өрнекпен қалай байланысты?

IЖаттығулар

JМатематикалық пайымдау

Неге «еркін» элемент алу жеткілікті? Егер дәлелдеу x-тің ешбір ерекше қасиетін пайдаланбаса, ол кез келген x үшін бірдей жүреді. Бұл - логикадағы жалпылау ережесі: P(c)-ны еркін c үшін дәлелдесек, ∀x P(x) дәлелденді.

KЖиі қателер

  • Бірнеше мысалмен «дәлелдеу».
    Себебі: Мысалдар тек шекті жағдайды қамтиды.
    Түзету: Еркін элемент алып, анықтамамен жалпы дәлелдеңіз.
  • Дәлелдеуде нақты сан қолдану (a = 4, b = 6).
    Себебі: Бұл тек бір жағдай.
    Түзету: Әріппен белгілеңіз: a = 2k.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
