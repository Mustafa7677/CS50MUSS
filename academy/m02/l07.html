Математикалық индукция

Деңгей: орта · шамамен 55 мин · нұсқа 1.0.0 · тексеру: author-checked

AОқу мақсаттары

  • Индукция принципін (негіз + қадам) домино аналогиясымен және формалды түрде түсіндіру.
  • Қосынды формулаларын индукциямен дәлелдеп, индукциялық болжамды дұрыс қолдану.
  • Негіз бен қадамның екеуі де міндетті екенін қарсы мысалмен көрсету.

BАлғышарттар

  • Қарсы мысал

CҰғымға кіріспе

Домино қатарын елестетіңіз. 1) Бірінші домино құлайды. 2) Кез келген домино құласа, келесісі де құлайды. Онда бәрі құлайды. Бұл - математикалық индукция.

P(n) барлық n ≥ n₀ үшін ақиқат екенін дәлелдеу үшін: негіз - P(n₀) ақиқат; индукциялық қадам - еркін k ≥ n₀ үшін P(k) → P(k + 1). Қадамдағы P(k) - индукциялық болжам: біз оны ұйғарамыз және міндетті түрде пайдаланамыз.

DАкадемиялық теория

Теорема

Индукция принципі

P(n₀) және ∀k ≥ n₀ (P(k) → P(k + 1)) болса, онда ∀n ≥ n₀ P(n).

Теорема

Тақ сандардың қосындысы

1 + 3 + 5 + ... + (2n − 1) = n², n ≥ 1.

Дәлелдеу

Дәлелдеу

Негіз: n = 1: сол жағы 1, оң жағы 1² = 1. ✓ Қадам: еркін k ≥ 1 үшін 1 + 3 + ... + (2k − 1) = k² деп ұйғарамыз. Онда 1 + ... + (2k − 1) + (2k + 1) = k² + 2k + 1 = (k + 1)². Бұл - P(k + 1). Индукция принципі бойынша формула барлық n ≥ 1 үшін ақиқат. ∎

Теорема

Гаусс формуласы

1 + 2 + ... + n = n(n + 1)/2. Қадам: k(k + 1)/2 + (k + 1) = (k + 1)(k + 2)/2.

Ескерту

Индукция неге дұрыс

Керісінше, P жалған болатын n бар деп ұйғарайық. Олардың ең кішісі m болсын (ең кіші элемент принципі). m ≠ n₀, өйткені негіз ақиқат. Онда P(m − 1) ақиқат, ал қадам бойынша P(m) ақиқат - қайшылық (4-сабақ).

EКөрнекі түсіндірме

Әр n үшін сол жақ (қосынды) мен оң жақ (формула) және қадам: формула(n+1) − формула(n) = келесі мүше ме. Бұл сандық тексеру; дәлелдеу - теорияда.

FҚадамдап қорыту

  1. Мақсат: 2 + 4 + ... + 2n = n(n + 1).
  2. Негіз: n = 1, сол жақ 2, оң жақ 1 · 2 = 2. ✓
  3. Болжам: 2 + ... + 2k = k(k + 1). Келесі мүше 2(k + 1) қосамыз: k(k + 1) + 2(k + 1) = (k + 1)(k + 2).
  4. Бұл P(k + 1)-дің оң жағы. Демек формула барлық n ≥ 1 үшін ақиқат. ∎

GЖұмыс мысалдары

HИнтерактивті эксперимент

Кубтардың қосындысы Гаусс қосындысының квадратына тең бе? Формуланы (n(n+1)/2)^2 + 1 етіп өзгертіңіз: қай жер бұзылады - негіз бе, қадам ба?

IЖаттығулар

JМатематикалық пайымдау

Индукциялық қадам - шартты тұжырым: «P(k) ақиқат БОЛСА, P(k + 1) ақиқат». Ол P(k)-ның шынымен ақиқат екенін айтпайды. Сондықтан негізсіз қадам ештеңе дәлелдемейді (n = n + 1 мысалы), ал қадамсыз негіз тек бір жағдайды дәлелдейді.

KЖиі қателер

  • Негізді тексеруді ұмыту.
    Себебі: Қадам шартты; негізсіз тізбек басталмайды.
    Түзету: Әрқашан P(n₀)-ді нақты есептеңіз.
  • Қадамда P(k + 1)-ді дәлелдеудің орнына оны ұйғару.
    Себебі: Бұл дәлелденетін нәрсені пайдалану.
    Түзету: Тек P(k)-ны ұйғарыңыз, P(k + 1)-ге жетіңіз.
  • Болжамды мүлде пайдаланбау.
    Себебі: Онда бұл индукция емес.
    Түзету: Қадамда P(k) тұрған жерді нақты көрсетіңіз.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.

MРефлексия

NТереңірек

Honors

  • Әр n ≥ 5 үшін 2ⁿ > n² екенін индукциямен дәлелдеңіз (нұсқау: қадамда 2k² ≥ (k + 1)² екенін k ≥ 3 үшін көрсетіңіз).

Research

  • Бағдарламадағы цикл инварианты (m04) мен индукцияның байланысын зерттеңіз: «цикл k рет орындалғаннан кейін ...».
