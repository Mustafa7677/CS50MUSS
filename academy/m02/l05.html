02·05Mathematical Proof

Жағдайларға бөлу

  • орта
  • ≈ 45 мин
  • 3 мақсат
  • 6 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақ қадамдарынан құрастырылған)
  1. Сұрақ. «n² + n әрқашан жұп» тұжырымын бір формуламен дәлелдеу қиын көрінеді. Бірақ әр бүтін сан не жұп, не тақ. Екі жағдайды бөлек қарасақ, әрқайсысы оңай: n = 2k болса n² + n = 2(2k² + k); n = 2k + 1 болса n² + n = 2(2k² + 3k + 1).
  2. Жол. 1-қадам. Тұжырым: n² + n жұп.
  3. Жол. 2-қадам. 1-жағдай, n жұп: n = 2k, n² + n = 4k² + 2k = 2(2k² + k).
  4. Жол. 3-қадам. 2-жағдай, n тақ: n = 2k + 1, n² + n = (2k + 1)(2k + 2) = 2(2k + 1)(k + 1).
  5. Жол. 4-қадам. Әр бүтін сан не жұп, не тақ - жағдайлар толық. Екеуінде де жұп, демек n² + n жұп. ∎
  6. Тексер. Қай жағдайлар жүйесі толық ЕМЕС (бүтін n үшін)? Жауап: n < 0; n > 0. Дұрыс: n = 0 қалып қойды.
  7. Түйін. Әдістің негізі. ((p ∨ q) ∧ (p → r) ∧ (q → r)) → r - тавтология.
  8. Түйін. Жиі қате: Жағдайларды толық қамтымау. Дұрысы: Жағдайлар бірігуі барлық мүмкіндікті беретінін бөлек тексеріңіз.

AОқу мақсаттары

  • Мүмкіндіктерді толық қамтитын (бос орынсыз) жағдайлар жүйесін құру.
  • Әр жағдайды жеке дәлелдеп, қорытындыны біріктіру: (P₁ ∨ P₂) ∧ (P₁ → Q) ∧ (P₂ → Q) ⊨ Q.
  • Қалдықтар бойынша бөлуді (n mod k) бүтін сандар туралы тұжырымдарға қолдану.

BАлғышарттар

  • Қайшылыққа келтіру

CҰғымға кіріспе

«n² + n әрқашан жұп» тұжырымын бір формуламен дәлелдеу қиын көрінеді. Бірақ әр бүтін сан не жұп, не тақ. Екі жағдайды бөлек қарасақ, әрқайсысы оңай: n = 2k болса n² + n = 2(2k² + k); n = 2k + 1 болса n² + n = 2(2k² + 3k + 1).

Ең маңызды талап - жағдайлар толық болуы: ешбір мүмкіндік назардан тыс қалмауы керек. «n > 0» мен «n < 0» жағдайлары n = 0-ді ұмытады.

DАкадемиялық теория

Теорема

Әдістің негізі

((p ∨ q) ∧ (p → r) ∧ (q → r)) → r - тавтология.

Теорема

Квадраттың 3-ке қалдығы

Кез келген бүтін n үшін n² mod 3 ∈ {0, 1}. Яғни квадрат 3-ке бөлгенде ешқашан 2 қалдық бермейді.

Дәлелдеу

Дәлелдеу (үш жағдай)

n-нің 3-ке қалдығы 0, 1 не 2 - басқа мүмкіндік жоқ. n = 3k: n² = 3(3k²), қалдық 0. n = 3k + 1: n² = 3(3k² + 2k) + 1, қалдық 1. n = 3k + 2: n² = 9k² + 12k + 4 = 3(3k² + 4k + 1) + 1, қалдық 1. ∎

Ескерту

Салдар

a² + b² = 3c + 2 түріндегі теңдеудің кейбір шешімдері осыдан шектеледі: квадраттардың қалдықтары тек 0 және 1.

EКөрнекі түсіндірме

n² mod 3 мәндері: тек 0 және 1 шығады. Жағдайларға бөлу мұның себебін түсіндіреді.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Тұжырым: n² + n жұп.
  2. 1-жағдай, n жұп: n = 2k, n² + n = 4k² + 2k = 2(2k² + k).
  3. 2-жағдай, n тақ: n = 2k + 1, n² + n = (2k + 1)(2k + 2) = 2(2k + 1)(k + 1).
  4. Әр бүтін сан не жұп, не тақ - жағдайлар толық. Екеуінде де жұп, демек n² + n жұп. ∎

GЖұмыс мысалдары

HИнтерактивті эксперимент

n² mod 4 қандай мәндер қабылдайды? Неліктен 4k + 3 түріндегі сан екі квадраттың қосындысы бола алмайтынын түсіндіріңіз.

IЖаттығулар

JМатематикалық пайымдау

Қалдықтар бойынша шекті тексеру неге нақты дәлелдеу? Себебі n² mod m тек n mod m-ге тәуелді: n = mq + r болса, n² = m(mq² + 2qr) + r². Шексіз көп n небәрі m класқа бөлінді, ал әр класс бір санмен толық сипатталады. Бұл - шекті жағдайға келтірудің дұрыс жолы.

KЖиі қателер

  • Жағдайларды толық қамтымау.
    Себебі: Ұмытылған жағдайда тұжырым жалған болуы мүмкін.
    Түзету: Жағдайлар бірігуі барлық мүмкіндікті беретінін бөлек тексеріңіз.
  • Бір жағдайда ғана дәлелдеп, «қалғаны ұқсас» деу.
    Себебі: Ұқсас көрінсе де, алгебрасы басқа.
    Түзету: Әр жағдайды жеке жазыңыз немесе нақты симметрияны негіздеңіз.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
