02·02Mathematical Proof

Тура дәлелдеу

  • негізгі
  • ≈ 45 мин
  • 3 мақсат
  • 6 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақ қадамдарынан құрастырылған)
  1. Сұрақ. Тура дәлелдеу - ең табиғи әдіс: P ақиқат деп ұйғарамыз да, анықтамалар мен алгебра арқылы Q-ға жетеміз. Бұл m01-дегі modus ponens тізбегі: P → A₁ → A₂ → ... → Q. Көп дәлелдеудің кілті - анықтаманы ашу .
  2. Жол. 1-қадам. Берілгені: n тақ. Мақсаты: n² тақ.
  3. Жол. 2-қадам. Анықтаманы ашамыз: n = 2k + 1.
  4. Жол. 3-қадам. Квадраттаймыз: n² = 4k² + 4k + 1 = 2(2k² + 2k) + 1.
  5. Жол. 4-қадам. 2k² + 2k бүтін, демек n² тақ. ∎
  6. Тексер. «a | b және a | c болса, a | (b + c)» дәлелдеуінің бірінші қадамы: Жауап: b = a·k, c = a·m деп жазу. Дұрыс: алғышарттардың анықтамасын ашамыз.
  7. Түйін. Тақ сандардың көбейтіндісі. a мен b тақ болса, ab тақ.
  8. Түйін. Жиі қате: Екі айнымалыға бір k беру: a = 2k, b = 2k. Дұрысы: Әр айнымалыға жеке әріп: a = 2k, b = 2m.

AОқу мақсаттары

  • Жұп, тақ, бөлінгіштік анықтамаларын бүтін сан арқылы жазу.
  • P → Q пішініндегі тұжырымды тура әдіспен дәлелдеу: P-дан бастап, Q-ға дейін.
  • Дәлелдеуді «берілгені - мақсаты - қадамдар» құрылымымен таза жазу.

BАлғышарттар

  • Дәлелдеу деген не

CҰғымға кіріспе

Тура дәлелдеу - ең табиғи әдіс: P ақиқат деп ұйғарамыз да, анықтамалар мен алгебра арқылы Q-ға жетеміз. Бұл m01-дегі modus ponens тізбегі: P → A₁ → A₂ → ... → Q.

Көп дәлелдеудің кілті - анықтаманы ашу. «n тақ» деген сөз жұмыс істемейді, ал «n = 2k + 1» алгебраға мүмкіндік береді. Соңында нәтижені қайтадан анықтама тіліне жабамыз.

DАкадемиялық теория

Анықтама

Бөлінгіштік

a | b («a b-ны бөледі») ⇔ b = a·k болатын бүтін k бар. Жұп: 2 | n. Тақ: n = 2k + 1.

Теорема

Тақ сандардың көбейтіндісі

a мен b тақ болса, ab тақ.

Дәлелдеу

Дәлелдеу

a = 2k + 1, b = 2m + 1 болсын. Онда ab = 4km + 2k + 2m + 1 = 2(2km + k + m) + 1. 2km + k + m бүтін, сондықтан ab тақ. ∎

Теорема

Бөлінгіштіктің транзитивтілігі

a | b және b | c болса, a | c.

Дәлелдеу

Дәлелдеу

b = a·k және c = b·m. Онда c = (a·k)·m = a·(km), ал km бүтін. Демек a | c. ∎

EКөрнекі түсіндірме

n² + n әрқашан жұп пе? Сандық көрініс болжам береді; дәлелдеуін 5-сабақта жағдайларға бөліп жасаймыз.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Берілгені: n тақ. Мақсаты: n² тақ.
  2. Анықтаманы ашамыз: n = 2k + 1.
  3. Квадраттаймыз: n² = 4k² + 4k + 1 = 2(2k² + 2k) + 1.
  4. 2k² + 2k бүтін, демек n² тақ. ∎

GЖұмыс мысалдары

HИнтерактивті эксперимент

n³ − n әрқашан 6-ға бөліне ме? Қарсы мысал бар ма? Неге? (Нұсқау: n³ − n = (n − 1)n(n + 1) - қатар тұрған үш сан.)

IЖаттығулар

JМатематикалық пайымдау

Тура дәлелдеудің шегі: кейде алғышарт аз ақпарат береді («n² жұп» → n туралы не айтуға болады?). n² = 2k деп жазсақ та, n-ге жету қиын (түбір алу бүтін санды бермейді). Мұндай жағдайда контрапозиция (3-сабақ) жеңілірек.

KЖиі қателер

  • Екі айнымалыға бір k беру: a = 2k, b = 2k.
    Себебі: Бұл a = b деп ұйғарады.
    Түзету: Әр айнымалыға жеке әріп: a = 2k, b = 2m.
  • Қорытындыны анықтамаға жаппау («2(k+m) шықты, бітті»).
    Себебі: k + m бүтін екенін көрсету керек.
    Түзету: Соңғы сөйлем: «... бүтін, сондықтан анықтама бойынша ...».

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.

MРефлексия

NТереңірек

Honors

  • n³ − n әрқашан 6-ға бөлінетінін тура дәлелдеңіз: (n − 1)n(n + 1) көбейтіндісінде міндетті түрде жұп сан мен 3-ке еселі сан бар.

Research

  • Бөлінгіштік қатынасы ішінара реттілік (partial order) бола ма? Рефлексивтілік, антисимметриялылық, транзитивтілікті зерттеңіз (m03).
