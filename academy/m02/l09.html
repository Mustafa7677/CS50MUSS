Рекурсивті анықтама және құрылымдық индукция

Деңгей: күрделі · шамамен 55 мин · нұсқа 1.0.0 · тексеру: author-checked

AОқу мақсаттары

  • Тізбекті, жиынды және деректер құрылымын рекурсивті (негіз + құру ережесі) анықтау.
  • Рекуррент қатынастың жабық формуласын болжап, оны индукциямен дәлелдеу.
  • Рекурсивті анықталған нысандар үшін құрылымдық индукция жүргізу (формулалар мысалында).

BАлғышарттар

  • Күшті индукция

CҰғымға кіріспе

Фибоначчи сандары: F(1) = 1, F(2) = 1, F(n) = F(n−1) + F(n−2). Бұл - рекурсивті анықтама: негіз мәндер және бұрынғы мәндерден жаңасын құру ережесі. Бағдарламалағы рекурсивті функция (m07) - осы анықтаманың кодтағы бейнесі.

Тек сандар емес: m01-дегі «дұрыс құрылған формула» да рекурсивті анықталды (айнымалы - формула; A формула болса, ¬A формула; ...). Мұндай нысандар үшін құрылымдық индукция қолданылады: негізгі нысандар үшін дәлелдеп, құру ережесі қасиетті сақтайтынын көрсетеміз.

DАкадемиялық теория

Анықтама

Рекурсивті анықталған жиын

1) Негіз: кейбір элементтер жиынға жатады. 2) Ереже: жиынның элементтерінен жаңа элементтер құрылады. 3) Жиынға тек осы жолмен алынған элементтер жатады.

Теорема

Құрылымдық индукция

P негіз элементтер үшін ақиқат және әр құру ережесі P-ны сақтаса, P жиынның барлық элементі үшін ақиқат.

Теорема

Формуладағы айнымалылар мен амалдар

Тек екі орынды амалдардан (∧, ∨, →) тұратын, жақшасыз ағаш ретінде қаралатын формулада айнымалы кірістерінің саны амалдар санынан дәл 1-ге артық.

Дәлелдеу

Дәлелдеу

Негіз: бір айнымалы - 1 кіріс, 0 амал: 1 = 0 + 1. ✓ Ереже: A-да v₁ = o₁ + 1, B-да v₂ = o₂ + 1 болсын. (A ∘ B)-да v = v₁ + v₂ = o₁ + o₂ + 2, ал амалдар o = o₁ + o₂ + 1. Демек v = o + 1. ✓ Құрылымдық индукция бойынша барлық формулада. ∎

Теорема

Фибоначчи шегі

F(n) < 2ⁿ барлық n ≥ 1 үшін. Күшті индукция: F(k + 1) = F(k) + F(k − 1) < 2ᵏ + 2ᵏ⁻¹ < 2ᵏ⁺¹ (негіздер n = 1, 2).

EКөрнекі түсіндірме

a(1) = 1, a(n) = a(n−1) + (2n − 1). Жабық формула n² барлық жолда сәйкес. Рекурсия мен 7-сабақтағы қосынды - бір нәрсе.

FҚадамдап қорыту

  1. Рекуррент: T(1) = 1, T(n) = 2T(n−1) + 1 (Ханой мұнаралары).
  2. Мәндер: 1, 3, 7, 15, 31 - болжам: T(n) = 2ⁿ − 1.
  3. Негіз: T(1) = 1 = 2¹ − 1. ✓
  4. Қадам: T(k + 1) = 2T(k) + 1 = 2(2ᵏ − 1) + 1 = 2ᵏ⁺¹ − 1. ✓ Индукция бойынша барлық n ≥ 1. ∎

GЖұмыс мысалдары

HИнтерактивті эксперимент

a(1) = 3, a(n) = 3a(n−1) − 2. Формула дұрыс па? first мәнін 5-ке өзгертсеңіз, формуланы қалай түзету керек?

IЖаттығулар

JМатематикалық пайымдау

Рекурсивті функцияның дұрыстығы мен тоқтауы - дәл құрылымдық индукция. Функция негізгі жағдайда дұрыс жауап берсе және әр рекурсивті шақыру кішірек кіріспен жұмыс істеп, дұрыс нәтижелерді дұрыс біріктірсе, ол барлық кіріс үшін дұрыс. Бұл m07 l06-ның негізі.

KЖиі қателер

  • Рекурсивті анықтамада негізді ұмыту.
    Себебі: Ереже бос жиыннан ештеңе құрмайды; функция тоқтамайды.
    Түзету: Әр рекурсия - алдымен негіз.
  • Бірнеше мәнді рекурсияға (Фибоначчи) бір негіз беру.
    Себебі: F(n) екі алдыңғы мәнге тәуелді.
    Түзету: Екі негіз: F(1) және F(2).

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
