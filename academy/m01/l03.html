Импликация және эквиваленттік

AОқу мақсаттары

  • p → q импликациясының ақиқат кестесін «уәде» мысалымен негіздеу.
  • Тура тұжырымды, керісін (q → p), қарама-қарсысын (¬p → ¬q) және контрапозициясын (¬q → ¬p) жазу.
  • Контрапозицияның тура тұжырыммен эквивалент, ал кері тұжырымның эквивалент емес екенін кестемен дәлелдеу.

BАлғышарттар

  • Терістеу, конъюнкция, дизъюнкция

CҰғымға кіріспе

p → q («егер p, онда q») - уәде сияқты. Мұғалім: «Егер барлық тапсырманы орындасаң (p), онда сынақтан өтесің (q)». Уәде қашан бұзылады? Тек бір жағдайда: сен бәрін орындадың (p = 1), бірақ өтпедің (q = 0).

Ал тапсырманы орындамасаң (p = 0), мұғалім ештеңе уәде еткен жоқ: өтсең де, өтпесең де уәде бұзылмады. Сондықтан p жалған болса, p → q ақиқат. Бұл - «бос ақиқат» (vacuous truth).

p ↔ q («p сонда тек сонда, q») - екі жақты импликация: p мен q мәндері бірдей болса ақиқат.

DАкадемиялық теория

Анықтама

Импликация

p → q = 0 тек p = 1, q = 0 болғанда. p - алғышарт (антецедент), q - салдар (консеквент).

Анықтама

Эквиваленттік

p ↔ q = 1 ⇔ p = q. Ол (p → q) ∧ (q → p) өрнегімен бірдей.

Анықтама

Төрт байланысты тұжырым

Тура: p → q. Кері: q → p. Қарама-қарсы: ¬p → ¬q. Контрапозиция: ¬q → ¬p.

Теорема

Контрапозиция теоремасы

p → q ≡ ¬q → ¬p. Сонымен қатар кері мен қарама-қарсы тұжырымдар өзара эквивалент: q → p ≡ ¬p → ¬q.

Дәлелдеу

Дәлелдеу

¬q → ¬p жалған тек ¬q = 1 және ¬p = 0 болғанда, яғни q = 0 және p = 1. Бұл дәл p → q жалған болатын жалғыз жол. Екі өрнек бір ғана жолда жалған, демек кестелері бірдей. ∎

Теорема

Импликацияны жою

p → q ≡ ¬p ∨ q.

EКөрнекі түсіндірме

Екі өрнекті салыстырыңыз. Сосын b-ны q → p етіп өзгертіңіз: зертхана қарсы мысал табады.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. p → q жалған болатын жолды іздейміз: p = 1, q = 0.
  2. ¬p ∨ q мәнін сол жолда есептейміз: ¬1 ∨ 0 = 0 ∨ 0 = 0.
  3. Қалған үш жолда ¬p = 1 не q = 1, сондықтан ¬p ∨ q = 1.
  4. Екі өрнек бір ғана жолда жалған - олар эквивалент: p → q ≡ ¬p ∨ q.

GЖұмыс мысалдары

HИнтерактивті эксперимент

Екі өрнек эквивалент пе? Сосын b-ны (p → q) ∨ (q → p) етіп өзгертіңіз. Не байқадыңыз?

IЖаттығулар

JМатематикалық пайымдау

Неліктен кері тұжырым эквивалент емес? Бір қарсы мысал жеткілікті: p = 0, q = 1 болғанда p → q = 1, бірақ q → p = 0. Математикада «керісі де ақиқат» деп айту үшін оны бөлек дәлелдеу керек.

KЖиі қателер

  • p жалған болса, p → q жалған деп санау.
    Себебі: Уәде шарты орындалмаса, ол бұзылмайды.
    Түзету: Жалғыз жалған жол - 1 → 0.
  • Тура тұжырым мен керісін шатастыру.
    Себебі: «Жұп болса - 4-ке бөлінеді» жалған, бірақ тура тұжырым ақиқат.
    Түзету: Керісін әрқашан бөлек тексеріңіз.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
