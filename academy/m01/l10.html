Логика бағдарламада және схемада

Деңгей: орта · шамамен 55 мин · нұсқа 1.0.0 · тексеру: author-checked

AОқу мақсаттары

  • Бағдарламадағы шартты логикалық формула ретінде оқып, оны заңдармен ықшамдау.
  • Python-дағы қысқа тұйықталуды (short-circuit) түсіндіріп, оны қауіпсіз тексеру үшін қолдану.
  • Логикалық гейттер (NOT, AND, OR, XOR, NAND) мен формуланың байланысын көрсету және модуль жобасын орындау.

BАлғышарттар

  • Предикаттар және кванторлар

CҰғымға кіріспе

Әр if - логикалық формула. if not (age < 18 or not has_id): оқуға қиын. Де Морган: ¬(a ∨ ¬b) ≡ ¬a ∧ b, яғни if age >= 18 and has_id: - мағынасы бірдей, бірақ айқын.

Қысқа тұйықталу: Python A and B өрнегінде A жалған болса, B-ны есептемейді (нәтиже бәрібір жалған). A or B-да A ақиқат болса, B есептелмейді. Бұл тек жылдамдық емес, қауіпсіздік: x != 0 and 10 / x > 2 нөлге бөлмейді.

Электрондық схемада ¬, ∧, ∨ - логикалық гейттер. Процессор миллиардтаған гейттен тұрады, ал әр гейт - бір логикалық амал.

DАкадемиялық теория

Анықтама

Гейттер

NOT: ¬a. AND: a ∧ b. OR: a ∨ b. XOR: a ⊕ b. NAND: ¬(a ∧ b). NOR: ¬(a ∨ b).

Теорема

NAND-тың әмбебаптығы

¬a ≡ a NAND a; a ∧ b ≡ (a NAND b) NAND (a NAND b); a ∨ b ≡ (a NAND a) NAND (b NAND b). Демек кез келген схеманы тек NAND гейттерімен құруға болады.

Дәлелдеу

Дәлелдеу

a NAND a = ¬(a ∧ a) = ¬a [идемпотенттік]. (a NAND b) NAND (a NAND b) = ¬(a NAND b) = ¬¬(a ∧ b) = a ∧ b. (¬a) NAND (¬b) = ¬(¬a ∧ ¬b) = a ∨ b [Де Морган]. {¬, ∧, ∨} толық (7-сабақ), демек NAND та толық. ∎

Теорема

Жарты қосындылағыш (half adder)

Екі битті қосқанда: қосынды S = a ⊕ b, тасымал C = a ∧ b. Мысалы 1 + 1 = 10₂: S = 0, C = 1.

Ескерту

Python-дағы truthiness

Python-да and/or тек True/False емес, операндтың өзін қайтарады: 0 or 5 = 5, 3 and 0 = 0. Логикалық мағынада 0, бос жол, бос тізім, None - жалған.

EКөрнекі түсіндірме

NAND гейтінің кестесі. a ⊕ b және a ∧ b-ны салыстырып, жарты қосындылағышты құрастырыңыз.

FҚадамдап қорыту

  1. Шарт: if not (is_weekend or not is_sunny) - p = is_weekend, q = is_sunny.
  2. Формула: ¬(p ∨ ¬q).
  3. Де Морган: ¬p ∧ ¬¬q ≡ ¬p ∧ q.
  4. Код: if not is_weekend and is_sunny - «демалыс емес және күн ашық».

GЖұмыс мысалдары

HИнтерактивті эксперимент

OR гейтін тек NAND арқылы жазыңыз: b өрісіне ¬(¬(a ∧ a) ∧ ¬(b ∧ b)) енгізіп тексеріңіз.

IЖаттығулар

JМатематикалық пайымдау

Компилятор логикалық өрнекті ықшамдай ала ма? Тек жанама әсер жоқ болса. f() and False өрнегін False-ға ауыстыру f() шақыруын жояды - ал f() файлға жазатын болса, бағдарлама мағынасы өзгереді. Математикалық эквиваленттік пен бағдарламалық эквиваленттік әрдайым бірдей емес.

KЖиі қателер

  • Шарттың ретін еркін ауыстыру.
    Себебі: Қысқа тұйықталу ретке тәуелді.
    Түзету: Қорғаныш тексерісін әрқашан сол жаққа қойыңыз.
  • and/or әрқашан True/False қайтарады деп ойлау.
    Себебі: Python операндты қайтарады.
    Түзету: Нақты bool керек болса, bool(...) қолданыңыз.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.

MРефлексия

NТереңірек

Honors

  • Толық қосындылағышты (full adder: a, b, тасымал кірісі) екі жарты қосындылағыш пен бір OR арқылы құрып, кестесін тексеріңіз.

Research

  • Модуль жобасы - Logic Expression Analyzer: AO17 логика зертханасын пайдаланып, өз формулаңыздың кестесін, түрін, ДҚФ/КҚФ-ын тауып, есеп жазыңыз (тапсырма беті төменде).

Модуль жобасы: Logic Expression Analyzer

Формуланы талдайтын шағын құрал жобасын жасаңыз (Python). Құрал формуланы жолдан оқып, айнымалыларды табады, ақиқат кестесін шығарады, формуланы тавтология/қайшылық/бейтарап деп жіктейді және канондық ДҚФ-ны береді.

Функционалдық талаптар

  • Кіріс: ¬ ∧ ∨ → ↔ амалдары мен жақшасы бар формула (ASCII түрі де: not, and, or, ->, <->).
  • Басымдық 4-сабақтағыдай; қате енгізуде нақты қазақша хабар.
  • Шығыс: кесте, түрі, ДҚФ; 12-ден көп айнымалыда бас тарту.
  • Кемінде 10 тест: 6-сабақтағы заңдар мен шеткі жағдайлар (тұрақты формула, бір айнымалы).

  • p ∧ ¬p → қайшылық.
