Терістеу, конъюнкция, дизъюнкция

AОқу мақсаттары

  • ¬ (терістеу), ∧ (конъюнкция), ∨ (дизъюнкция) амалдарының ақиқат кестесін жатқа емес, мағынасымен түсіндіру.
  • Инклюзивті «немесе» (∨) мен «не ... не» (⊕) айырмашылығын көрсету.
  • Құрама пікірдің мәнін берілген айнымалы мәндерімен есептеу.

BАлғышарттар

  • Пікір және ақиқат мәні

CҰғымға кіріспе

Құрама пікір жай пікірлерден логикалық амалдар арқылы жасалады. Ең негізгі үшеуі:

  • ¬p - «p емес»: p-ның мәнін керісінше аударады.
  • p ∧ q - «p және q»: екеуі де ақиқат болса ғана ақиқат.
  • p ∨ q - «p немесе q»: кемінде біреуі ақиқат болса ақиқат.

Күнделікті тілдегі «немесе» кейде «тек біреуі» дегенді білдіреді («шай немесе кофе»). Логикада ∨ - инклюзивті: екеуі де ақиқат болса да ақиқат. «Тек біреуі» үшін бөлек амал бар: ⊕ (XOR).

DАкадемиялық теория

Анықтама

Терістеу ¬p

¬p ақиқат ⇔ p жалған. Кесте: p = 0 → ¬p = 1; p = 1 → ¬p = 0.

Анықтама

Конъюнкция p ∧ q

p ∧ q = 1 тек p = 1 және q = 1 болғанда. Қалған үш жағдайда 0.

Анықтама

Дизъюнкция p ∨ q

p ∨ q = 0 тек p = 0 және q = 0 болғанда. Қалған үш жағдайда 1.

Анықтама

Қатаң дизъюнкция p ⊕ q

p ⊕ q = 1 ⇔ p мен q мәндері әр түрлі.

Теорема

Сандық түсінік

0/1 мәндерінде: p ∧ q = min(p, q) = p · q; p ∨ q = max(p, q); ¬p = 1 − p; p ⊕ q = (p + q) mod 2.

Дәлелдеу

Дәлелдеу (∧ үшін)

Төрт жағдайды тексереміз: (0,0): min = 0, көбейтінді 0; (0,1) және (1,0): min = 0, көбейтінді 0; (1,1): min = 1, көбейтінді 1. Барлық жағдайда анықтамамен сәйкес. ∎ Қалғандары дәл осылай тексеріледі.

EКөрнекі түсіндірме

Кесте аралық бағандарды да көрсетеді: алдымен ¬p, сосын нәтиже.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Мысал: p = 1, q = 0, r = 1 болғанда ¬p ∨ (q ∧ r) мәнін табамыз.
  2. Ішкі жақшадан бастаймыз: q ∧ r = 0 ∧ 1 = 0 (екеуі де 1 емес).
  3. ¬p = ¬1 = 0.
  4. Соңғы амал: 0 ∨ 0 = 0. Демек өрнек жалған.

GЖұмыс мысалдары

HИнтерактивті эксперимент

p ⊕ q кестесін p ∨ q кестесімен салыстырыңыз. Қай жолда айырмашылық бар? Сол жолдың мағынасын сөзбен айтыңыз.

IЖаттығулар

JМатематикалық пайымдау

∧ және ∨ ауыстырымды: p ∧ q мен q ∧ p кестелері бірдей. Дәлелдеу - төрт жолды салыстыру. Бірақ бағдарламада ретінің маңызы бар: x != 0 and 10 / x > 1 өрнегінде x = 0 болса, сол жақ жалған, сондықтан оң жағы мүлде есептелмейді (10-сабақтағы қысқа тұйықталу).

KЖиі қателер

  • ∨ амалын «тек біреуі» деп оқу.
    Себебі: Күнделікті тіл логикадан өзгеше.
    Түзету: Тек біреуі керек болса, ⊕ қолданыңыз.
  • ¬p ∨ q өрнегін ¬(p ∨ q) деп оқу.
    Себебі: ¬ тек өзінен кейінгі ең жақын бөлікке әсер етеді.
    Түзету: Терістеу бүкіл өрнекке керек болса, жақша қойыңыз.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.

MРефлексия

NТереңірек

Honors

  • p ⊕ q ⊕ r өрнегі қашан ақиқат? Жалпы ереже ұсынып, дәлелдеңіз (ақиқат айнымалылар санының жұптылығы).

Research

  • Жұптық бақылау битінің (parity bit) ⊕ арқылы қалай есептелетінін зерттеңіз.

Дереккөз және лицензия

  • K. H. Rosen, Discrete Mathematics and Its Applications - пікірлер логикасы тарауы (ұғымдарды салыстыру үшін).
  • H. B. Enderton, A Mathematical Introduction to Logic - пікірлер логикасының формалды анықтамалары.
