Python орындалуын көру

Код жоғарыдан төмен «оқылмайды» - ол орындалады: цикл бір жолға ораламды, функция жаңа жақтау ашады, екі атау бір тізімге сілтеуі мүмкін. Бұл зертханада кодыңызды қадамдап жүргізіп, әр жолдан кейін жадта не өзгергенін көресіз.

Код браузерде нағыз Python-да (Pyodide, CPython 3.12) орындалады - бұл болжам немесе имитация емес. Алғашқы жүктеуге интернет және ~10 секунд керек. Бір орындауда ең көбі 1000 жол қадамы жазылады; input() қолдау көрмейді.

Python Execution Visualizer

Мақсат: кодты «ойша орындау» дағдысы: айнымалының мәні қай жолда өзгеретінін, функция шақырылғанда стекте не болатынын, тізімге сілтеме мен көшірменің айырмасын болжап, трассамен тексеру.

    Түйін
    
      
      
        
    • Айнымалы - мәнге берілген ат. b = a тізімді көшірмейді: екі ат бір нысанға сілтейді. Көшірме керек болса - a[:] не list(a).
      • 
        
    • Әр функция шақыруы стекке жаңа жақтау (frame) қосады; return орындалғанда ол алынады. Рекурсияда жақтаулар базалық жағдайға дейін жиналады.
      • 
        
    • Цикл денесі әр айналымда қайта орындалады; total = total + i ескі мәнді жаңасымен ауыстырады, бірақ ескісін пайдаланып.
