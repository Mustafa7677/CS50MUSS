Жасанды нейрон

Artificial Neuron

Weight, bias және activation-ды қолмен баптап, бір нейронмен деректерді бөл.

3D симуляцияны ашу Дәрісті оқу

  1. Нейронның құрылымы
  2. Шешім шекарасы
  3. Activation: step және sigmoid
  4. Бір нейронның шегі: XOR

1Нейронның құрылымы

Идея

Жасанды нейрон: өте қарапайым формула:

z = w₁·x₁ + w₂·x₂ + b
y = activation(z)
  • w₁, w₂ (weights, салмақтар): әр кірістің маңыздылығы. Үлкен оң салмақ: «бұл белгі өссе, жауап 1-ге жақындайды».
  • b (bias): нейронның «бейімділігі», кірістер нөл болғанда да z-ті жылжытады.
  • activation: z-ті шығысқа айналдыратын функция.

Түйсік

Нейрон: дауыс беру: әр кіріс өз дауысын береді, ал салмақ: сол дауыстың күші. Bias: дауыс беруге дейінгі «алдын ала пікір».

Есептеп көрейік

w₁ = 0.5, w₂ = −0.5, b = 0, нүкте (0.6, 0.2):

z = 0.5·0.6 + (−0.5)·0.2 + 0 = 0.3 − 0.1 = 0.2
step(z) = 1   (себебі z ≥ 0)

Нейрон бұл нүктені 1-класс деп болжайды.

💡 Түйін: биологиялық нейронмен ұқсастық: тек метафора. Жасанды нейрон: көбейту, қосу және бір функция.

Енді сен

Оң жақтағы жүгірткілермен w₁, w₂ немесе b-ны өзгерт. 3D сахнада сымның жуандығы: салмақтың шамасы, түсі: таңбасы.

3D симуляцияда орында

  • w₁, w₂ немесе b мәнін өзгерт
Симуляцияны ашу

Өзіңді тексер

w₁ = 2, w₂ = 1, b = −1. Нүкте (0.5, 0). z неге тең?

Жауабы мен түсіндірмесі

Дұрыс жауап: 0

z = 2·0.5 + 1·0 + (−1) = 1 + 0 − 1 = 0.

Bias (b) не істейді?

Жауабы мен түсіндірмесі

Дұрыс жауап: Нейронның шешімін кірістерге тәуелсіз түрде жылжытады

b: тұрақты қосылғыш. Ол шешім шекарасын салмақтарды өзгертпей жылжытады.

2Шешім шекарасы

Идея

Нейрон z = 0 болатын нүктелерді бөлшекке бөледі. Бұл нүктелер жиыны: шешім шекарасы (decision boundary). Екі кіріс болғанда ол түзу сызық:

w₁·x₁ + w₂·x₂ + b = 0
  • Салмақтар түзудің бағытын анықтайды (бұрады).
  • Bias түзуді жылжытады.

Есептеп көрейік

w₁ = 1, w₂ = 1, b = 0 → шекара x₁ + x₂ = 0, яғни төменгі солдан жоғарғы оңға қарай диагональ. Нүкте (0.5, 0.5): z = 1 > 0 → класс 1. Нүкте (−0.5, −0.5): z = −1 < 0 → класс 0.

b = 0.5 етсек: шекара x₁ + x₂ = −0.5: түзу төмен-солға жылжиды, 1-класс аймағы үлкейеді.

Дәлдік қалай есептеледі

дәлдік = дұрыс жіктелген нүктелер / барлық нүктелер

120 нүктенің 111-і дұрыс болса: 111/120 = 92.5%.

⚠ Жиі қате: салмақтарды үлкейту шекараны жылжытады деп ойлау. Барлық салмақтар мен bias-ты бірдей санға көбейтсең, шекара өзгермейді: тек z-тің «сенімділігі» өседі (бұл sigmoid-та маңызды болады).

Тереңірек: шекара неге түзу және w векторы нені білдіреді

Нейрон p = σ(w·x + b). p = 0.5 болатын нүктелер: шекара. σ(z) = 0.5 тек z = 0 болғанда, демек шекара:

w₁x₁ + w₂x₂ + b = 0

Бұл: түзудің теңдеуі (3D-де жазықтық, n өлшемде гипержазықтық).

w: шекараға перпендикуляр (нормаль). Шекарадағы екі нүкте a мен c алайық: w·a + b = 0 және w·c + b = 0. Азайтсақ: w·(a − c) = 0. Ал a − c: шекара бойымен жатқан вектор. Демек w шекараның кез келген бағытына перпендикуляр.

Шекараның басынан (0,0) қашықтығы = |b| / ‖w‖. Мысалы w = (3, 4), b = −10: ‖w‖ = 5, қашықтық = 2.

Масштабтау тәжірибесі. w мен b-ны 10-ға көбейтсек: шекара сол орында қалады (0 = 0·10), бірақ z 10 есе үлкен → σ әлдеқайда тік. Яғни ‖w‖: модельдің сенімділігі, ал w/‖w‖ пен b/‖w‖: шекараның орны.

Енді сен

Салмақтар мен bias-ты баптап, train дәлдігін 90%-дан асыр. Bias-ты міндетті түрде қолдан.

3D симуляцияда орында

  • Train дәлдігін ≥ 90%-ға жеткіз
  • Bias мәнін 0-ден өзгерт
Симуляцияны ашу
Кеңес
  • Нүктелер сол жақ төменде (0) және оң жақ жоғарыда (1). w₁ мен w₂ екеуін де оң мәнге қойып көр.

Өзіңді тексер

w₁, w₂ және b-ның бәрін 10-ға көбейтсек, шешім шекарасы не болады?

Жауабы мен түсіндірмесі

Дұрыс жауап: Өзгермейді

10·(w₁x₁ + w₂x₂ + b) = 0 теңдеуі w₁x₁ + w₂x₂ + b = 0-мен бірдей. Түзу сол күйінде қалады.

80 нүктенің 68-і дұрыс жіктелді. Дәлдік қанша?

Жауабы мен түсіндірмесі

Дұрыс жауап: 85%

68 / 80 = 0.85 = 85%.

3Activation: step және sigmoid

Идея

Step функциясы қатал: z ≥ 0 → 1, әйтпесе 0. Ол «қаншалықты сенімді» деген ақпаратты жоғалтады. Sigmoid тегіс:

σ(z) = 1 / (1 + e^(−z))

Нәтиже 0 мен 1 арасындағы сан: оны ықтималдық деп оқимыз: «бұл нүктенің 1-класс болу ықтималдығы 0.83».

Есептеп көрейік

z = 0    → σ = 0.50   (екіұдай)
z = 2    → σ ≈ 0.88
z = −2   → σ ≈ 0.12
z = 5    → σ ≈ 0.993

Салмақтарды үлкейтсең, z-тің мәндері де үлкейеді → sigmoid «тіктеледі» және step-ке ұқсай бастайды.

Неге бұл маңызды

Training (4-сабақ) салмақтарды кішкене өзгертіп, нәтиже қаншалықты жақсарғанын өлшейді. Step-те кішкене өзгеріс көбінесе ештеңені өзгертпейді: қадам бағытын табу мүмкін емес. Sigmoid тегіс болғандықтан, әр кішкене өзгерістің әсері көрінеді: бұл градиенттің болуы үшін керек.

💡 Түйін: тегістік: оқытудың шарты. Сондықтан нейрондық желілерде step емес, тегіс activation-дар қолданылады.

Енді сен

Activation-ды sigmoid-қа ауыстыр, сосын |w| ≥ 3 етіп, 3D беттің қалай тіктелетінін көр.

3D симуляцияда орында

  • Activation-ды sigmoid-ке ауыстыр
  • Салмақтарды үлкейтіп (|w| ≥ 3), бетті тіктеп көр
Симуляцияны ашу

Өзіңді тексер

σ(0) неге тең?

Жауабы мен түсіндірмесі

Дұрыс жауап: 0.5

σ(0) = 1 / (1 + e⁰) = 1 / (1 + 1) = 0.5.

Неге training үшін step емес, sigmoid ыңғайлы?

Жауабы мен түсіндірмесі

Дұрыс жауап: Sigmoid тегіс: салмақтың кішкене өзгерісі шығысты да кішкене өзгертеді, сондықтан қай бағытқа жылжу керегін есептеуге болады

Градиенттік оқыту «салмақты сәл өзгертсем, қате қалай өзгереді?» деген сұраққа сүйенеді. Step-те бұл сұрақтың жауабы көбінесе нөл.

4Бір нейронның шегі: XOR

Идея

XOR есебінде қарама-қарсы бұрыштар бір класқа жатады:

x₁   x₂   XOR
 −    −    0
 −    +    1
 +    −    1
 +    +    0

Бір нейронның шекарасы: бір түзу. Ал XOR класын бөлу үшін кемінде екі түзу керек. Сондықтан бір нейрон XOR-ды шеше алмайды: бұл математикалық факт, баптау мәселесі емес.

Тарих

1969 жылы Минский мен Пейперт осыны дәлелдеді. Перцептронға деген қызығушылық күрт төмендеп, «бірінші AI қысы» басталды. Шешім: нейрондарды қабаттарға біріктіру: 1980-жылдары backpropagation алгоритмімен бірге кең таралды.

Есептеп көрейік

Ең жақсы түзу бір бұрышты қалған үшеуінен бөледі. Сонда 4 бұрыштың 3-еуі дұрыс → шамамен 75%. Одан жоғары бір түзумен мүмкін емес.

⚠ Жиі қате: «Ұзағырақ баптасам, бір нейрон да XOR-ды шешеді». Жоқ: шектеу модельдің құрылымында, параметрлерде емес.

Тереңірек: XOR-ды бір нейрон шеше алмайтынының дәлелі

Шешетін w₁, w₂, b бар деп ұйғарайық (z > 0 → класс 1):

  1. (0,0) → 0: b < 0
  2. (1,0) → 1: w₁ + b > 0
  3. (0,1) → 1: w₂ + b > 0
  4. (1,1) → 0: w₁ + w₂ + b < 0

(2) мен (3)-ті қоссақ: w₁ + w₂ + 2b > 0, яғни w₁ + w₂ + b > −b. Ал (1) бойынша b < 0, сондықтан −b > 0. Демек w₁ + w₂ + b > 0: бұл (4)-ке қайшы. ∎

Бұл: 1969 жылғы Минский мен Пейперт кітабындағы атақты нәтиже; ол нейрон желілерге деген қызығушылықты көп жылға суытты. Шешімі: жасырын қабат: бір нейрон «x₁ OR x₂», екіншісі «x₁ AND x₂» болса, шығыс «OR және AND емес» = XOR.

Енді сен

XOR-да нейронды кемінде 5 рет баптап көр. Дәлдік 80%-дан аспайтынына көз жеткіз.

3D симуляцияда орында

  • XOR-да нейронды кемінде 5 рет баптап көр
  • Дәлдік 80%-дан аспайтынын байқа
Симуляцияны ашу

Өзіңді тексер

Неге бір нейрон XOR-ды шеше алмайды?

Жауабы мен түсіндірмесі

Дұрыс жауап: Бір нейронның шекарасы: бір түзу, ал XOR-ға кемінде екі түзу керек

Бұл құрылымдық шектеу. Шешім: жасырын қабат (3-сабақ).

XOR-дың 4 бұрышында бір түзумен ең көбі неше бұрышты дұрыс жіктеуге болады?

Жауабы мен түсіндірмесі

Дұрыс жауап: 3

Мысалы, түзу (−,−) бұрышын қалған үшеуінен бөліп, оны 0, қалғанын 1 десін: (−,+) және (+,−) дұрыс, (+,+) қате. Нәтиже 3/4 = 75%.
