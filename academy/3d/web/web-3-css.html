1Box model

Идея

CSS-те әр элемент: төртбұрышты қорап. Ол төрт қабаттан тұрады (ішінен сыртқа):

  1. content: мәтін не сурет;
  2. padding: мазмұн мен жиек арасындағы ішкі бос орын;
  3. border: жиек;
  4. margin: көрші элементтерге дейінгі сыртқы бос орын.

Есептеп көрейік (content-box)

Әдепкі режимде width тек мазмұнның ені:

толық ені = width + 2·padding + 2·border + 2·margin
          = 200 + 2·20 + 2·4 + 2·16 = 280px

300px алу үшін, мысалы: width 220, padding 10, border 2, margin 28 → 220 + 20 + 4 + 56 = 300.

⚠ Жиі қате: «width: 200px: элемент 200px болады». content-box-та ол 200 + padding + border.

Енді сен

Элемент алатын толық орын (margin қоса) дәл 300px болсын: padding ≥ 10, border ≥ 1. 3D-де қабаттарды бөлек көр.

3D симуляцияда орында

  • Толық ені (margin қоса) = 300px, padding ≥ 10, border ≥ 1
Симуляцияны ашу
Кеңес
  • Толық ені = width + 2·padding + 2·border + 2·margin.

Өзіңді тексер

content-box: width 100, padding 10, border 5, margin 0. Элементтің көрінетін ені қанша?

Жауабы мен түсіндірмесі

Дұрыс жауап: 130px

100 + 2·10 + 2·5 = 130px.

Margin пен padding айырмасы неде?

Жауабы мен түсіндірмесі

Дұрыс жауап: Padding: жиектің ішінде (фон түсі бар), margin: жиектің сыртында (мөлдір)

Padding: қораптың ішкі «толтырмасы», margin: қорап пен көршілер арасындағы бос орын.

2box-sizing: border-box

Идея

content-box-тың мәселесі: padding қосқан сайын элемент кеңейеді, ал макет бұзылады. box-sizing: border-box-та width: жиекке дейінгі бүкіл ені:

content = width − 2·padding − 2·border

Padding көбейсе, мазмұн кішірейеді, ал элементтің өзі сол өлшемде қалады.

Есептеп көрейік

border-box, width 300, padding 24, border 4:

content = 300 − 48 − 8 = 244px
көрінетін ені = 300px (өзгермейді!)

Нақты әлемде

Көп сайт CSS-ті мына жолмен бастайды:

*, *:before, *:after { box-sizing: border-box; }

Сонда «width: 50%»: шынымен жарты, padding-ке қарамастан.

Тереңірек: ені қалай есептеледі

width: 200px; padding: 20px; border: 5px:

  • content-box (әдепкі): экрандағы ені = 200 + 2·20 + 2·5 = 250px. Мазмұн ені 200.
  • border-box: экрандағы ені = 200px, мазмұнға 200 − 40 − 10 = 150px қалады.

Неге border-box ыңғайлы: екі баған width: 50% + padding. content-box-та 50% + padding > 50% → қосындысы 100%-дан асып, екінші баған төмен түседі. border-box-та 50%: шын мәнінде 50%.

Margin ешқашан ендікке кірмейді, ал тігінен көршілес margin-дер біріге алады (margin collapsing): 20px + 30px → 30px.

Енді сен

border-box режиміне ауыс: width = 300px, padding ≥ 20: элементтің өзі 300px болып қалсын.

3D симуляцияда орында

  • border-box, width = 300px, padding ≥ 20: элемент 300px болып қалсын
Симуляцияны ашу

Өзіңді тексер

border-box: width 200, padding 20, border 5. Мазмұнның ені қанша?

Жауабы мен түсіндірмесі

Дұрыс жауап: 150px

200 − 2·20 − 2·5 = 150px.

Неге көп сайт border-box қолданады?

Жауабы мен түсіндірмесі

Дұрыс жауап: width көрінетін өлшемге тең болады: padding қосқанда макет бұзылмайды

Өлшем болжамды болады: «300px» деп жазсаң: 300px аласың.

3Flexbox

Идея

Flexbox: элементтерді бір осьте орналастыру жүйесі. Контейнерге display: flex бересің:

  • flex-direction: негізгі ось: row (көлденең) не column (тік);
  • justify-content: негізгі осьтегі орналасу: flex-start, center, flex-end, space-between, space-around;
  • align-items: көлденең осьтегі тураланым: stretch, flex-start, center, flex-end;
  • gap: элементтер арасындағы аралық.

Есептеп көрейік: space-between

Контейнер 560px, 4 элемент × 120px, gap 8:

бос орын = 560 − 4·120 − 3·8 = 56px
space-between: аралықтарға бөлінеді → 8 + 56/3 ≈ 26.7px

Бірінші элемент сол шетте, соңғысы оң шетте.

💡 Түйін: flex-ке дейін орталау үшін float пен «хакерлік» трюктер керек болатын. Қазір: бір жол: justify-content: center; align-items: center.

Тереңірек: flex-grow бос орынды қалай бөледі

Алгоритм (бір жол):

  1. Әр элементтің flex-basis-ін (бастапқы өлшемін) аламыз
  2. Бос орын = контейнер − Σ basis − аралықтар (gap)
  3. Бос орын > 0 болса: grow салмақтарына пропорционал бөлінеді:
өлшемᵢ = basisᵢ + бос_орын · growᵢ / Σ grow

Мысал: контейнер 600, basis (100, 100, 200), grow (1, 2, 1). Бос орын 200 → +50, +100, +50 → (150, 200, 250).

Назар аудар: grow: 2 элемент басқасынан «2 есе үлкен» болмайды: ол бос орынның 2 есе көп үлесін алады.

  1. Бос орын < 0 болса: shrink. Шын CSS-те кішірейту shrink × basis-ке пропорционал (үлкен элемент көбірек сығылады). Біздің зертхана моделі жеңілдетілген: бәрі бірдей сығылады.

flex: 1 = 1 1 0: basis 0, сондықтан бүкіл кеңістік grow бойынша бөлінеді: тең бағандардың классикалық тәсілі.

Енді сен

Элементтерді шеттерге тарат (space-between) және көлденең осьте ортаға турала (align-items: center).

3D симуляцияда орында

  • row + space-between + align center
Симуляцияны ашу

Өзіңді тексер

flex-direction: row кезінде justify-content қай осьті басқарады?

Жауабы мен түсіндірмесі

Дұрыс жауап: Көлденең ось

justify-content: әрдайым негізгі ось. row-да ол көлденең.

Контейнер 400px, 3 элемент × 100px, gap 0, space-between. Элементтер арасындағы аралық қанша?

Жауабы мен түсіндірмесі

Дұрыс жауап: 50px

Бос орын 400 − 300 = 100px, 2 аралыққа бөлінеді → 50px.

4Тар экран

Идея

Responsive дизайн: бір бет телефонда да, үлкен экранда да дұрыс көрінуі. Flexbox-та мұның кілті: flex-wrap:

  • nowrap (әдепкі): бәрі бір жолда: элементтер сығылады (flex-shrink) немесе шетке шығып кетеді;
  • wrap: сыймағандары келесі жолға түседі.

Есептеп көрейік

Контейнер 300px, элементтер 120px, gap 8:

бір жолға: 120 + 8 + 120 = 248 ≤ 300 ✓, үшіншісі: 248 + 8 + 120 = 376 > 300 ✗

wrap-та: бір жолда 2 элемент. nowrap-та: 4 элемент әрқайсысы шамамен 69px-ке дейін сығылады.

Нақты әлемде

Қазір дүниежүзілік трафиктің жартысынан көбі: телефондар. Media query-лер (@media (max-width: 600px)) мен flex/grid бірге қолданылады. Бұл INSIDE TECH сайтының өзі де телефонда бір бағанға түседі.

⚠ Жиі қате: тек үлкен экранда тексеру. Әрдайым телефон енінде (≈ 360-400px) де қара.

Енді сен

Контейнерді 320px-ке дейін тарылт, wrap қос және кемінде 4 элемент қалдыр.

3D симуляцияда орында

  • Ені ≤ 320px, wrap қосулы, кемінде 4 элемент
Симуляцияны ашу

Өзіңді тексер

Контейнер 260px, элементтер 80px, gap 10, wrap. Бір жолға неше элемент сияды?

Жауабы мен түсіндірмесі

Дұрыс жауап: 3

3·80 + 2·10 = 260 ≤ 260: үшеуі дәл сияды. Төртіншісі: 260 + 10 + 80 = 350 > 260, ол келесі жолға түседі.

flex-wrap: nowrap кезінде орын жетпесе не болады?

Жауабы мен түсіндірмесі

Дұрыс жауап: Элементтер сығылады немесе контейнерден шығып кетеді

nowrap: бәрі бір жолда. Flex-shrink оларды сығады, шегіне жетсе: шетке шығады.
