1Күйлер машинасы

Идея

Жаудың «миы»: finite state machine (FSM): шектеулі күйлер және олардың арасындағы ауысу шарттары.

         қашықтық < қуу радиусы
 [күзет] ───────────────────────▶ [қуу]
    ▲                               │
    │ үйге жетті                    │ қашықтық > бас тарту радиусы
    │                               ▼
    └────────────────────────── [оралу]

Әр күйде жау бір нәрсе істейді: күзетте: екі нүкте арасында жүреді, қууда: ойыншыға қарай, оралуда: үйіне.

Неге FSM?

Логика айқын: әр уақытта жау бір күйде. Жаңа мінез қосу: жаңа күй және оның ауысулары. 1980 жылғы Pac-Man-ның елестерінен бастап, бүгінгі ААА ойындарға дейін қолданылады (күрделірек нұсқасы: behaviour tree).

Есептеп көрейік

Қуу радиусы 3, бас тарту радиусы 4. Ойыншы жаудан:

5 м → күзет
2.5 м → қуу (2.5 < 3)
3.5 м → қуу жалғасады (3.5 < 4)
4.5 м → оралу (4.5 > 4)

💡 Түйін: бас тарту радиусы қуу радиусынан үлкен болуы керек: әйтпесе жау шекарада «дірілдеп», күйден күйге секіре береді (гистерезис).

Тереңірек: шекті автомат формальды түрде және гистерезис

Шекті автомат (FSM): бес нәрсе: күйлер жиыны (patrol, chase, return), бастапқы күй (patrol), кіріс (ойыншыға қашықтық d), ауысу функциясы және әр күйдегі әрекет.

Біздің жау үшін ауысу кестесі:

  • patrol, d < chaseRadius → chase
  • chase, d > giveUpRadius → return
  • return, үйге жетті → patrol
  • басқа жағдайлардың бәрінде: күй өзгермейді

Ойлан: return кезінде ойыншы қайта жақындаса, біздің жау бәрібір алдымен үйге жетеді. Бұл: дизайн шешімі; «return, d < chaseRadius → chase» ауысуын қоссаң, жау қайырымсызырақ болады.

Гистерезис. Неге екі радиус? chaseRadius = giveUpRadius = 3 болса, ойыншы дәл 3 м шекарада тұрғанда кішкене шу (d = 2.99, 3.01, 2.99 …) жауды әр кадрда chase ↔ return арасында «дірілдетеді». Екі шек (кіру 3, шығу 4) арасында «өлі аймақ» пайда болады: chase-ке кірген соң, шығу үшін 1 м алыстау керек.

Бұл қағида бар жерде кездеседі: термостат (20°-та қосылып, 22°-та өшеді), Шмитт триггері электроникада, автопилот.

FSM күйлері көбейсе (10+), ауысулар саны квадраттық өседі: сонда behavior tree немесе иерархиялық FSM қолданылады.

Енді сен

Жауға жақында (ол қуа бастайды), сосын алысқа қаш (ол оралады).

3D симуляцияда орында

  • Жау қуа бастасын (chase)
  • Жау қуудан бас тартып оралсын (return)
Симуляцияны ашу

Өзіңді тексер

Жау «қуу» күйінде, бас тарту радиусы 4, ойыншы 3.9 м қашықтықта. Келесі күй?

Жауабы мен түсіндірмесі

Дұрыс жауап: қуу

3.9 < 4: бас тарту шарты орындалмады, жау қууды жалғастырады.

Қуу мен бас тарту радиусы бірдей болса не болады?

Жауабы мен түсіндірмесі

Дұрыс жауап: Шекарада жау күйлер арасында тоқтаусыз секіреді

Бір шекарада екі бағыттағы ауысу: «діріл». Екі түрлі шек (гистерезис) мұны болдырмайды.

2Қиындықты баптау

Идея

Ойын қиындығы: сандар. Ойын дизайнерлері жүздеген параметрді баптайды: жаудың жылдамдығы, көру радиусы, реакция уақыты. Мақсат: әділ шиеленіс: ойыншы жеңілсе, «өзім қателестім» деп ойлауы керек, «ойын алдады» деп емес.

Әділдік ережелері

  • Жау ойыншыдан баяу болса: ойыншы шеберлікпен қаша алады.
  • Жау ойыншыдан жылдам болса: оған басқа шектеу керек (көру радиусы, кідіріс).
  • Бас тарту радиусы > қуу радиусы: қашудың мағынасы бар.

Есептеп көрейік

Ойыншы 2.6 м/с, жау 1.5 м/с. Ойыншы әр секунд сайын 1.1 м алыстайды. Жау 3 м-ден қуа бастаса, бас тарту радиусы 6-ға жету үшін:

(6 − 3) / 1.1 ≈ 2.7 с

Ойыншыға 3 секундтай қашу: шиеленісті, бірақ мүмкін.

⚠ Жиі қате: қиындықты тек «жаудың жылдамдығын көбейту» арқылы арттыру. Жақсы қиындық: ойыншыдан жаңа шеберлік талап етеді.

Енді сен

Жауды «байқағыш» ет (қуу радиусы ≥ 4), бірақ әділ қалдыр: ойыншыдан баяу, бас тарту радиусы қуу радиусынан үлкен.

3D симуляцияда орында

  • Қуу радиусы ≥ 4
  • Жау ойыншыдан баяу
  • Бас тарту радиусы қуу радиусынан үлкен
Симуляцияны ашу

Өзіңді тексер

Ойыншы 3 м/с, жау 2 м/с, жау 2 м-ден қуа бастады, бас тарту радиусы 5. Ойыншы шамамен қанша секундта құтылады?

Жауабы мен түсіндірмесі

Дұрыс жауап: 3 с

Арақашықтық секундына 1 м өседі: (5 − 2) / 1 = 3 с.

Жау ойыншыдан әрдайым жылдам және бас тарту радиусы шексіз болса не болады?

Жауабы мен түсіндірмесі

Дұрыс жауап: Ойыншы қашып құтыла алмайды: ойын әділетсіз

Құтылудың мүмкіндігі болмаса, ойыншы шеберлігі маңызды болудан қалады.
