Object Pooling & GC Spikes

Ойын неге кенет «қатады»? Жаңа объектілер, қоқыс жинаушы және объектілерді қайта қолдану.

3D симуляцияны ашу Дәрісті оқу

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

1Кенет қату

Идея

JavaScript, C#, Java сияқты тілдерде жадты қоқыс жинаушы (garbage collector, GC) тазалайды. Ыңғайлы: new жазасың, delete ұмытасың. Бірақ GC уақыт алады, ал ойында уақыт кадрлармен өлшенеді: 60 FPS үшін бір кадрға 16,7 мс.

Есептеп көрейік

Шутер: әр кадрда 40 оқ, әрқайсысы 30 кадр өмір сүреді, 300 кадр.

  • Барлығы 12 000 жаңа объект, өлгендері қоқысқа айналады.
  • Қоқыс 3000-ға жеткенде GC іске қосылады: 3000 × 0,01 мс = 30 мс қосымша.
  • Нәтиже: кадрлардың көбі 8,8 мс, бірақ 3 кадр 38,8 мс: ойыншы көретін «қату» (stutter).

Орташа FPS тамаша, бірақ ойыншы орташаны емес, ең нашар кадрды сезеді. Сондықтан ойын әзірлеушілері «1% low» не 99-перцентиль кадр уақытын өлшейді: Cloud 12-сабақтағы p95 сияқты.

Нақты әлемде

Unity-дің Profiler-інде «GC.Alloc» бағаны: ойынның ыстық циклінде ол 0 болуы керек. Шағын шетін жасаулар да (жол біріктіру, массив жасау, лямбда) әр кадрда қоқыс шығарады.

Пулсыз, кадрына 40 оқпен іске қос. Кадр уақыты сызығындағы шыңдарға қара.

2Пул

Пул

Объектілер пулы (object pool): өлген объектіні жоймай, қайта қолдануға сақтау.

const bullet = pool.pop() ?? new Bullet();  // ал
bullet.reset(x, y, dir);
...
pool.push(bullet);                          // қайтар

Есептеп көрейік

Сол 40 оқ, 300 кадр:

  • жаңа объектілер 1200 (12 000 емес: 10 есе аз);
  • пулдың өлшемі 1200 = 40 оқ × 30 кадр өмір: бір мезгілде тірі ең көп оқ;
  • GC 0 рет, ең баяу кадр 8,8 мс.

Бағасы

  • Жад: пул ең көп жағдайға дайын объектілерді үнемі ұстайды.
  • Қате қаупі: объектіні қайтарғанда толық тазаламасаң (reset), ескі оқтың күйі жаңасына «жұғады». Немесе қайтарылған объектіге әлдекім әлі сілтеме ұстап тұрады.
  • Сондықтан пул тек жиі жасалып-жойылатын нәрселерге: оқтар, бөлшектер (particles), жаулар, UI элементтері.

Нақты әлемде

Unity-де ObjectPool<T> (2021-ден бастап кірістірілген), Godot-та, Unreal-да ұқсас механизмдер. Бөлшектер жүйелері мыңдаған ұшқынды бір алдын ала бөлінген массивте ұстайды.

Пулды қосып, сол 40 оқпен іске қос. Кадр сызығы мен жаңа объектілер санын салыстыр.
