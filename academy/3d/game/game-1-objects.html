1Сахна: объектілер ағашы

Комикс · Нұрай, Мустафа және Бота

Сахнадағы актерлер

Барлық комикстер

Идея

Ойындағы әр нәрсе: объект (Unity-де GameObject, Unreal-да Actor, Godot-та Node). Әр объектінің transform-ы бар:

  • position: орны (x, y, z);
  • rotation: бұрылысы;
  • scale: өлшемі.

Объектілер ағаш құрайды: scene graph. Машина: ата-ана, дөңгелектер мен кабина: оның балалары.

Неге ағаш?

Машина жүргенде оның 4 дөңгелегін, кабинасын, шамдарын жеке-жеке жылжытпаймыз: тек машинаны. Балалар өздігінен бірге жүреді. Адам кейіпкерінде: дене → иық → шынтақ → білек → саусақтар. Иықты бұрсаң: бүкіл қол бұрылады.

Есептеп көрейік

Машина     (−2, 0.5, 0)
└── Дөңгелек  local (0.7, −0.3, 0.55)

Дөңгелектің әлемдегі орны = ата-ананың орны + баланың local орны = (−1.3, 0.2, 0.55).

💡 Түйін: бұл: 3D графиканың іргетасы. Three.js, Unity, Blender: бәрі осылай ұйымдастырылған.

Енді сен

Сахнадағы не тізімдегі кемінде 3 түрлі объектіні таңда. Әрқайсысының local және world координатасына қара.

2Ата-ана мен бала

Идея

Баланың координатасы: ата-анасына қатысты (local space). Ойын қозғалтқышы әлемдік (world) координатаны тізбек бойымен есептейді:

world = parent.world × local

Мұндағы «×»: үш амалдың тіркесі: алдымен scale, сосын rotation, сосын translation (жылжыту).

Есептеп көрейік

Машина (−2, 0.5, 0), scale = 2, бұрылыс 90°. Дөңгелек local (0.7, −0.3, 0.55):

1. scale ×2:     (1.4, −0.6, 1.1)
2. 90° бұрылыс:  (1.1, −0.6, −1.4)
3. + машина:     (−0.9, −0.1, −1.4)

Дөңгелектің local мәні өзгерген жоқ: (0.7, −0.3, 0.55) күйінде қалды!

Нақты әлемде

Мұны 4×4 матрицамен жазады: бір матрица scale, rotation және translation-ды біріктіреді, ал тізбек: матрицаларды көбейту. GPU секундына миллиондаған осындай көбейтуді орындайды.

⚠ Жиі қате: ата-ананы масштабтағанда баланың scale мәні өзгереді деп ойлау. Local scale сол күйінде, тек world scale өзгереді.

Тереңірек: трансформация матрицалары

Әр объектінің локалды трансформациясы бар: орын (T), айналу (R), масштаб (S). Ол бір 4×4 матрицаға жиналады: M = T·R·S (оңнан солға: алдымен масштаб, сосын айналу, сосын жылжыту).

Әлемдік матрица: ата-аналар тізбегінің көбейтіндісі:

World(бала) = World(ата-ана) · Local(бала)

Мысал. Ата-ана (5, 0, 0) нүктесінде, Y осі бойымен 90° бұрылған. Бала локалды (2, 0, 0)-да.

Y бойынша θ айналу: x' = x·cosθ + z·sinθ, z' = −x·sinθ + z·cosθ. θ = 90°: (2, 0, 0) → (0, 0, −2). Сосын жылжыту: (5, 0, 0) + (0, 0, −2) = (5, 0, −2).

Ата-ана бұрылса: бала оның айналасында «орбитамен» қозғалады. Біз әр кадр сайын бір ғана ата-ана матрицасын өзгерттік, бірақ бүкіл бұтақ қозғалды: scene graph-тың күші осы.

Рет маңызды: T·R ≠ R·T. «Жылжыт, сосын бұр»: объект басы (0,0,0) айналасында орбитамен ұшады; «бұр, сосын жылжыт»: өз орнында бұрылады.

3Объектіні жалғау

Идея

Ойында объектіні басқасына жалғау (attach) жиі керек: кейіпкер қылышты алады, машинаға жүк салынады. Объектінің ата-анасын ауыстырғанда, ол экранда секірмеуі керек: әлемдегі орны сақталуы тиіс. Сондықтан қозғалтқыш жаңа local координатаны кері есептейді:

local = inverse(newParent.world) × child.world

Есептеп көрейік

Шам әлемде (2, 0.25, 2), машина (−2, 0.5, 0), бұрылыс та, scale те жоқ:

local = (2 − (−2), 0.25 − 0.5, 2 − 0) = (4, −0.25, 2)

Енді машина қайда барса, шам (4, −0.25, 2) қашықтықта бірге жүреді.

Циклге тыйым

Машинаны өз дөңгелегіне жалғауға болмайды: ата-ана → бала → ата-ана... шексіз цикл болып шығады. Қозғалтқыш мұндай әрекетке тыйым салады.

💡 Түйін: «World орнын сақтап reparent»: Unity-дегі SetParent(…, worldPositionStays: true) дәл осы.

Тереңірек: attach кезінде әлемдік орынды сақтау

Объект A-ны жаңа ата-ана P-ге көшірдік, бірақ ол экранда «секірмеуі» керек. Яғни әлемдік матрица өзгермеуі тиіс:

World(P) · Local_жаңа = World_ескі
Local_жаңа = World(P)⁻¹ · World_ескі

Жылжыту ғана болса, кері матрица: жай азайту: P (3, 0, 0)-да, A әлемде (5, 1, 0)-да → жаңа локалды орын (2, 1, 0).

Бұл формуланы ұмытсақ (локалды орынды өзгеріссіз қалдырсақ), A жаңа ата-анасының координаттарына «телепортталады». Біздің зертхананың reparent функциясы осы есепті жасайды, сондай-ақ цикл жасауға тыйым салады (A өзінің ұрпағына бала бола алмайды: әйтпесе World(A) шексіз рекурсия).
