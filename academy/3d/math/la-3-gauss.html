Математика · 3-сабақ · ≈30 мин · 2 қадам · 4 сұрақ

Сызықтық теңдеулер жүйесі және Гаусс әдісі

Үш теңдеу: кеңістіктегі үш жазықтық, ал шешімі олардың қиылысу нүктесі. Белгісіздерді біртіндеп жойып, баспалдаққа келтіру.

3D симуляцияны ашу Дәрісті оқу

  1. Төмен қарай жою
  2. Жоғары қарай: шешім

1Төмен қарай жою

Идея

Жүйе:

 x +  y +  z = 6
2x +  y −  z = 1
 x −  y + 2z = 5

Әр теңдеу кеңістікте жазықтық. Шешім: үшеуі қиылысатын нүкте. Сахнада үш жазықтықты көресің.

Гаусс әдісі белгісіздерді біртіндеп жояды. Жүйені өзгертпейтін үш жол амалы бар:

  1. Екі жолдың орнын ауыстыру: R1 ↔ R2.
  2. Жолды нөлден өзге санға көбейту: R2 ← c·R2.
  3. Бір жолға басқа жолдың еселігін қосу: R2 ← R2 + c·R1.

Мақсат: баспалдақ түрі. Бірінші бағанда R1-ден төмен нөлдер, сосын екінші бағанда R2-ден төмен нөл.

Түйсік

Бір теңдеуден x-ті «ұрлап», басқа теңдеулерден жою. Әр амал жазықтықтарды бұрады, бірақ олардың ортақ нүктесі орнында қалады: шешім өзгермейді.

Есептеп көрейік

  • R2 ← R2 − 2·R1: (0, −1, −3 | −11).
  • R3 ← R3 − R1: (0, −2, 1 | −1).
  • R3 ← R3 − 2·R2: (0, 0, 7 | 21).

Енді соңғы жолдан z = 3 бірден көрінеді.

Нақты әлемде

Гаусс әдісі ғылыми есептеулердің негізі: көпірдің жүктемесін, электр тізбегін, жүздеген айнымалысы бар үлгілерді шешу осыдан басталады. Компьютерлер оны миллиондаған теңдеуге қолданады.

Енді сен

Жол амалдарын таңда: коэффициентке 2, −1 не 1/7 сияқты сандарды жазуға болады. Бірінші бағанды тазала, сосын баспалдақ жаса.

3D симуляцияда орында

  • Бірінші бағанда R1-ден төменгі екі санды нөлге айналдыр
  • Баспалдақ: R3-тегі y коэффициенті де нөл
Симуляцияны ашу

Алдымен болжа

Үш белгісізі бар үш сызықтық теңдеу кеңістікте нені білдіреді?

Жауабы мен түсіндірмесі

Дұрыс жауап: Үш жазықтықты

ax + by + cz = d теңдеуін қанағаттандыратын нүктелер жазықтық құрайды. Үш теңдеуді бірден қанағаттандыратын нүкте үш жазықтықтың қиылысы.

Шешілген мысал

x + 2y = 5 және 3x − y = 1 жүйесін шеш.

  1. R2 ← R2 − 3·R1: (3 − 3)x + (−1 − 6)y = 1 − 15x-ті жою үшін R1-ді 3-ке көбейтіп, R2-ден аламыз.
  2. −7y = −14, яғни y = 2Бір ғана белгісіз қалды.
  3. x + 2·2 = 5, яғни x = 1Кері жүріс: y-ті бірінші теңдеуге қоямыз.
  4. Тексеру: 3·1 − 2 = 1 ✓Шешімді екінші бастапқы теңдеуге қойып тексереміз.

Өзіңді тексер

Қай амал жүйенің шешімін өзгертуі мүмкін?

Жауабы мен түсіндірмесі

Дұрыс жауап: Жолды нөлге көбейту

Нөлге көбейткенде теңдеу 0 = 0-ге айналып, ақпарат жоғалады. Сондықтан көбейткіш нөл болмауы керек.

Баспалдақ түрінің пайдасы неде?

Жауабы мен түсіндірмесі

Дұрыс жауап: Соңғы теңдеуде бір ғана белгісіз қалады

Соңғы жолдан z шығады, оны жоғарыдағыға қойсаң y, сосын x: кері жүріс.

2Жоғары қарай: шешім

Идея

Кері жүріс: соңғы жолдан жоғары қарай. Әр жолды оның бас коэффициенті 1 болатындай етіп, сосын сол бағандағы қалған сандарды жоғарыдан жоямыз. Соңында сол жақ блок бірлік матрица болады:

1 0 0 | x
0 1 0 | y
0 0 1 | z

Оң жақ баған: шешім. Бұл түрі Гаусс-Жордан әдісі деп аталады.

Түйсік

Тұтқынды бір-бірлеп босату: алдымен ең төменгі есікті ашасың (z), сосын соның кілтімен жоғарыдағыларды (y, x).

Есептеп көрейік

  • R3 ← (1/7)·R3: (0, 0, 1 | 3).
  • R2 ← R2 + 3·R3: (0, −1, 0 | −2), сосын R2 ← −1·R2: (0, 1, 0 | 2).
  • R1 ← R1 − R3, R1 ← R1 − R2: (1, 0, 0 | 1).

Шешім: x = 1, y = 2, z = 3. Тексеру: 1 + 2 + 3 = 6, 2 + 2 − 3 = 1, 1 − 2 + 6 = 5.

Нақты әлемде

Жазықтықтар бір нүктеде қиылыспауы да мүмкін: екеуі параллель болса, шешім жоқ; үшеуі бір түзу бойымен қиылысса, шешім шексіз көп. Гаусс әдісі мұны да анықтайды: «0 = 5» деген жол шешім жоқтығын, «0 = 0» деген жол еркін айнымалыны білдіреді.

Енді сен

Кері жүріспен сол жақ блокты бірлік матрицаға келтір. Сахнадағы жарқыраған нүкте үш жазықтықтың қиылысы.

3D симуляцияда орында

  • Сол жақ блокты бірлік матрицаға келтір: оң жақ баған шешімді береді
Симуляцияны ашу

Алдымен болжа

Баспалдақтан кейін соңғы жол 7z = 21. Келесі қадам не?

Жауабы мен түсіндірмесі

Дұрыс жауап: R3-ті 1/7-ге көбейтіп, z-ті табу, сосын жоғары қарай жою

Кері жүріс: соңғы жолдан бастап әр белгісізді табамыз да, оны жоғарыдағы жолдардан жоямыз.

Қатені тап

x + y = 3 және 2x + 3y = 8 жүйесі.

  1. R2 ← R2 − 2·R1
  2. (0, 3 − 2 | 8 − 6) = (0, 1 | 2)
  3. y = 2
  4. x = 3 + 2 = 5
Жауабы

4-жол қате. y-ті бірінші теңдеуге қойғанда x + 2 = 3, яғни x = 3 − 2. Теңдіктің екінші жағына өткенде таңба ауысады.

Дұрысы: x = 3 − 2 = 1

Өз сөзіңмен түсіндір

Гаусс әдісі жүйені қалай шешті және неге жол амалдары шешімді өзгертпейді?

Жақсы түсіндірмеде болатын ойлар
  • әр теңдеу жазықтық, шешім: қиылысу нүктесі
  • төмен қарай жою: баспалдақ
  • кері жүріс: соңғы жолдан жоғары
  • жол амалдары шешімді сақтайды

Өзіңді тексер

Жою кезінде (0, 0, 0 | 5) жолы пайда болса, бұл нені білдіреді?

Жауабы мен түсіндірмесі

Дұрыс жауап: Шешім жоқ

Сол жақтың бәрі нөл, оң жағы нөл емес: ешбір x, y, z бұл теңдеуді қанағаттандырмайды.

Табылған шешімді қалай тексеруге болады?

Жауабы мен түсіндірмесі

Дұрыс жауап: Бастапқы барлық теңдеуге қойып көру

Әр жол амалы шешімді сақтайды, бірақ есептеуде қателесуге болады. Бастапқы теңдеулерге қою ең сенімді тексеру.
