Векторлық кеңістік, базис және сызықтық бейнелеу

Базис: бүкіл кеңістікті құрастыруға жететін ең аз кірпіштер. Бір нүктенің координаталары базиске байланысты, ал тәуелді векторлар кеңістікті толтыра алмайды.

3D симуляцияны ашу Дәрісті оқу

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақтың қадамдарынан құрастырылған)
  1. Сұрақ. b1 = (1, 1), b2 = (1, −1) базисінде t = (3, 1) нүктесінің координаталары қандай?
  2. Бейне. Қала картасы. «Солтүстікке 3 квартал, шығысқа 1» және «диагональ көшемен 2, басқа диагональмен 1»: бір жерді екі түрлі айтудың тәсілі. Орын өзгерген жоқ, тек тор өзгерді. Сахнадағы қисық тор дәл осы жаңа базистің торы.
  3. Болжа. b1 = (1, 1), b2 = (1, −1) базисінде t = (3, 1) нүктесінің координаталары қандай? Жауап: a = 2, b = 1. a + b = 3 және a − b = 1 жүйесінен a = 2, b = 1. Нүкте сол, ал координаталары базиске байланысты.
  4. Көр. 1-қадам, «Жаңа тор, жаңа координаталар». Векторлық кеңістік: қосуға және санға көбейтуге болатын кез келген нәрселер жиыны. Тек көрсеткілер емес: көпмүшеліктер, дыбыс сигналдары, суреттер де векторлар.
  5. Көр. 2-қадам, «Тәуелді векторлар». Векторлар сызықтық тәуелді, егер біреуін басқаларынан құрастыруға болса. Тәуелді векторлар кеңістікті толық кере алмайды: жазықтықта екі параллель вектордың барлық комбинациясы бір түзу ғана.
  6. Көр. Нақты әлемде: Машиналық оқытуда екі белгі бір-бірінің еселігі болса (мысалы, бойы сантиметрмен және бойы метрмен), олар жаңа ақпарат бермейді, ал кейбір әдістердің есебін бұзады (мультиколлинеарлық).
  7. Түйін. Базис: бүкіл кеңістікті құрастыруға жететін ең аз кірпіштер. Бір нүктенің координаталары базиске байланысты, ал тәуелді векторлар кеңістікті толтыра алмайды.
  8. Түйін. Жиі қате: (2, 4) және (−1, −2) векторлары туралы не айтуға болады? Жауап: «Тәуелсіз». Дұрысы: «Тәуелді». Біреуі екіншісінің еселігі: олар бір түзу бойында, базис бола алмайды.

1Жаңа тор, жаңа координаталар

Комикс · Нұрай, Мустафа және Бота

Бір кафе, екі тіл

Барлық комикстер

Идея

Векторлық кеңістік: қосуға және санға көбейтуге болатын кез келген нәрселер жиыны. Тек көрсеткілер емес: көпмүшеліктер, дыбыс сигналдары, суреттер де векторлар.

Базис: кеңістіктің кез келген векторын бір ғана тәсілмен құрастыруға жететін векторлар жиыны:

  1. олар бүкіл кеңістікті керіп тұрады (кез келген вектор солардың комбинациясы);
  2. олар сызықтық тәуелсіз (ешқайсысы басқалардан құрастырылмайды).

Вектордың координаталары базиске байланысты: t = a·b1 + b·b2 болса, осы базисте t = (a, b).

Түйсік

Қала картасы. «Солтүстікке 3 квартал, шығысқа 1» және «диагональ көшемен 2, басқа диагональмен 1»: бір жерді екі түрлі айтудың тәсілі. Орын өзгерген жоқ, тек тор өзгерді. Сахнадағы қисық тор дәл осы жаңа базистің торы.

Есептеп көрейік

Стандарт базис (1, 0), (0, 1): t = (3, 1) координаталары 3 және 1. b1 = (1, 1), b2 = (1, −1): a + b = 3, a − b = 1, яғни a = 2, b = 1.

Сызықтық бейнелеу: қосу мен санға көбейтуді сақтайтын функция, T(a·u + b·v) = a·T(u) + b·T(v). Әр сызықтық бейнелеуді базисте матрицамен жазуға болады: 4-сабақтағы матрицалар дәл осы.

Нақты әлемде

JPEG суретті сығу: сурет пиксельдер базисінен «толқындар» базисіне ауыстырылады. Жаңа базисте көп координата нөлге жақын, сондықтан оларды тастауға болады. Бұл базисті ауыстырудың ең атақты қолданысы.

Енді сен

a мен b сырғытпаларымен t = (3, 1) нүктесіне жет. Сосын базисті стандарт базиске ауыстырып, сол нүктенің жаңа координаталарын тап.

3D симуляцияда орында

  • b1 = (1, 1), b2 = (1, −1) базисінде t = (3, 1) нүктесіне жет: a·b1 + b·b2 = t
  • Стандарт базисте (1, 0) және (0, 1) сол нүктенің координаталарын тап
Симуляцияны ашу

Алдымен болжа

b1 = (1, 1), b2 = (1, −1) базисінде t = (3, 1) нүктесінің координаталары қандай?

Жауабы мен түсіндірмесі

Дұрыс жауап: a = 2, b = 1

a + b = 3 және a − b = 1 жүйесінен a = 2, b = 1. Нүкте сол, ал координаталары базиске байланысты.

Шешілген мысал

b1 = (2, 1), b2 = (1, 3) базисінде t = (5, 5) нүктесінің координаталарын тап.

  1. a·(2, 1) + b·(1, 3) = (5, 5)t-ны базис векторларының комбинациясы ретінде жазамыз.
  2. 2a + b = 5 және a + 3b = 5Координаталар бойынша екі теңдеу шығады.
  3. b = 5 − 2a; a + 15 − 6a = 5; a = 2Алмастыру әдісі: біріншіден b-ны тауып, екіншіге қоямыз.
  4. b = 5 − 4 = 1, сонда осы базисте t = (2, 1)Тексеру: 2·(2, 1) + 1·(1, 3) = (5, 5).

2Тәуелді векторлар

Идея

Векторлар сызықтық тәуелді, егер біреуін басқаларынан құрастыруға болса. Тәуелді векторлар кеңістікті толық кере алмайды: жазықтықта екі параллель вектордың барлық комбинациясы бір түзу ғана.

Тексеру: жазықтықта b1, b2 тәуелді болуы тек егер det [b1 b2] = 0 болса. Бұл 6-сабақтағы анықтауыштың өзі: аудан нөл, тор жаншылды.

Түйсік

Тек солтүстік-оңтүстік бағытта жүре алатын көлік. Ол қанша жүрсе де, шығыстағы үйге жете алмайды. Екінші, тәуелсіз бағыт (шығыс-батыс) керек.

Есептеп көрейік

b1 = (1, 1), b2 = (2, 2): det = 1·2 − 1·2 = 0. t = (3, 1) бұл түзуде емес (3 ≠ 1), сондықтан a, b қандай болса да, жету мүмкін емес.

Ранг: векторлар кере алатын кеңістіктің өлшемі. Тәуелді екі вектордың рангі 1, тәуелсіз екеуінің рангі 2.

Нақты әлемде

Машиналық оқытуда екі белгі бір-бірінің еселігі болса (мысалы, бойы сантиметрмен және бойы метрмен), олар жаңа ақпарат бермейді, ал кейбір әдістердің есебін бұзады (мультиколлинеарлық). Мұны осы тәуелділік арқылы анықтайды.

Енді сен

b2-ні b1-ге параллель етіп қой да, тордың бір түзуге жиналғанын көр. Сосын тәуелсіз базиске қайтып, t-ға қайта жет.

3D симуляцияда орында

  • b2-ні b1-ге параллель етіп қой: тор бір түзуге жиналады
  • Тәуелсіз базиске қайтып, t-ға қайта жет
Симуляцияны ашу

Алдымен болжа

b2 = 2·b1 болса, a·b1 + b·b2 комбинациялары жазықтықтың қай бөлігін жабады?

Жауабы мен түсіндірмесі

Дұрыс жауап: Тек бір түзуді

a·b1 + b·2b1 = (a + 2b)·b1: бәрі b1-дің еселігі, яғни бір түзу бойында.

Қатені тап

(1, 2) және (3, 6) жазықтықтың базисі бола ма?

  1. det [[1, 3], [2, 6]] = 1·6 − 3·2
  2. = 0
  3. Анықтауыш нөл, демек векторлар перпендикуляр
  4. Сондықтан олар базис бола алмайды
Жауабы

3-жол қате. Анықтауыш нөл болса, векторлар тәуелді, яғни параллель, перпендикуляр емес. (3, 6) = 3·(1, 2).

Дұрысы: Анықтауыш нөл, демек векторлар параллель: (3, 6) = 3·(1, 2)

Өз сөзіңмен түсіндір

Неге t нүктесінің координаталары базисті ауыстырғанда өзгерді, ал b2 b1-ге параллель болғанда t-ға неге жету мүмкін болмады?

Жақсы түсіндірмеде болатын ойлар
  • координаталар базиске байланысты, нүкте өзгермейді
  • тәуелді векторлар тек бір түзуді кереді
  • анықтауыш нөл: тор жаншылды

Қисық тордағы координаталар

  1. Түсіну
  2. Жоспар
  3. Шешу
  4. Тексеру

Өзің шығарып болдың ба? Енді шешімді фильм сияқты көр: тақтаға жол-жолымен жазылады, әр қадамның себебі астында айтылады.

3D сахнамен көру

Фильмнің мәтіні (6 кадр)
  1. Түсіну. Жаңа базис, қисық тор. Сұрақ: t нүктесінің осы тордағы координаталары.b1 = (1, 1), b2 = (1, −1), t = (3, 1)
  2. Жоспар. Жоспар: t-ны базис векторларының комбинациясы ретінде жазып, a мен b-ны табамыз.a·b1 + b·b2 = t ⇒ екі теңдеу
  3. Шешу. x және y координаталары бойынша екі теңдеу шығады.a + b = 3, a − b = 1
  4. Шешу. Екі теңдеуді қоссақ, b жойылады. Сахнада b1 бойымен екі қадам жүрдік.Қосамыз: 2a = 4 ⇒ a = 2
  5. Шешу. Енді b2 бойымен бір қадам: дәл t нүктесіне келдік.b = 3 − 2 = 1
  6. Тексеру. Тексеру: комбинация t-ны береді. Бұл базисте t-ның координаталары (2, 1).2·(1, 1) + 1·(1, −1) = (3, 1) ✓
