Меншікті мәндер мен меншікті векторлар

Матрица көп векторды бұрады, бірақ кейбір ерекше бағыттарды тек созады. Сол бағыттарды өз көзіңмен табу: Av = λv.

3D симуляцияны ашу Дәрісті оқу

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақтың қадамдарынан құрастырылған)
  1. Сұрақ. A = [[2, 1], [1, 2]]. (1, 1) бағытындағы векторды A қалай өзгертеді?
  2. Бейне. Глобусты айналдыр: барлық нүкте қозғалады, бірақ ось бойындағы нүктелер орнында қалады. Айналу осі осы түрлендірудің меншікті векторы (λ = 1).
  3. Болжа. A = [[2, 1], [1, 2]]. (1, 1) бағытындағы векторды A қалай өзгертеді? Жауап: Бұрмайды, тек 3 есе созады. 2·1 + 1·1 = 3, 1·1 + 2·1 = 3. Нәтиже (1, 1)-дің 3 еселігі: бағыт өзгерген жоқ.
  4. Көр. 1-қадам, «Бұрылмайтын бағыттар». Матрица көп векторды бұрады. Бірақ кейбір ерекше бағыттарды тек созады не қысады: олар өз түзуінде қалады.
  5. Көр. 2-қадам, «Ығысу мен бұрылыс». Меншікті векторлардың саны матрицаға байланысты: Симметриялық матрицаның (A = Aᵀ) нақты меншікті векторлары әрқашан бар, әрі олар бір-біріне перпендикуляр (45° және 135°: тік бұрыш).
  6. Көр. Нақты әлемде: Дифференциалдық теңдеулер жүйесінде (2-курс) меншікті мәндер жүйенің тағдырын айтады: нақты әрі оң болса, шешім өседі; теріс болса, сөнеді; комплекс болса, тербеледі.
  7. Түйін. Матрица көп векторды бұрады, бірақ кейбір ерекше бағыттарды тек созады. Сол бағыттарды өз көзіңмен табу: Av = λv.
  8. Түйін. Жиі қате: Симметриялық матрицаның меншікті векторлары туралы не белгілі? Жауап: «Олар әрқашан комплекс». Дұрысы: «Олар нақты және бір-біріне перпендикуляр». Бұл спектрлік теорема: симметриялық матрица перпендикуляр осьтер бойымен тек созады.

1Бұрылмайтын бағыттар

Комикс · Нұрай, Мустафа және Бота

Глобустың осі

Барлық комикстер

Идея

Матрица көп векторды бұрады. Бірақ кейбір ерекше бағыттарды тек созады не қысады: олар өз түзуінде қалады. Олар меншікті векторлар, ал созылу еселігі меншікті мән λ:

A·v = λ·v

2×2 матрицаның меншікті мәндерін табу: det(A − λI) = 0 теңдеуі (сипаттамалық теңдеу).

Түйсік

Глобусты айналдыр: барлық нүкте қозғалады, бірақ ось бойындағы нүктелер орнында қалады. Айналу осі осы түрлендірудің меншікті векторы (λ = 1).

Есептеп көрейік

A = [[2, 1], [1, 2]]: det(A − λI) = (2 − λ)² − 1 = 0, яғни λ = 3 не λ = 1.

  • λ = 3: (A − 3I)v = 0, v = (1, 1): 45° бағыты.
  • λ = 1: v = (1, −1): 135° бағыты.

Сахнада барлық бағыттың бейнелерін көресің: тек осы екеуі өз түзуінде қалады.

Нақты әлемде

Google-дың алғашқы PageRank алгоритмі: интернет беттері сілтемелерінің матрицасының меншікті векторы. Тербеліс жүйелерінде (көпір, ғимарат) меншікті мәндер резонанс жиіліктерін береді. Деректерді талдауда (PCA) деректердің ең көп өзгеретін бағыттары ковариация матрицасының меншікті векторлары.

Енді сен

Бағыт сырғытпасын бұра отырып, бейнесі өз түзуінде қалатын бағыттарды тап: біреуі 3 есе созылады, екіншісі ұзындығын өзгертпейді.

3D симуляцияда орында

  • A = [[2, 1], [1, 2]]: 3 есе созылатын бағытты тап
  • Ұзындығы мүлде өзгермейтін екінші бағытты тап (λ = 1)
Симуляцияны ашу

Алдымен болжа

A = [[2, 1], [1, 2]]. (1, 1) бағытындағы векторды A қалай өзгертеді?

Жауабы мен түсіндірмесі

Дұрыс жауап: Бұрмайды, тек 3 есе созады

2·1 + 1·1 = 3, 1·1 + 2·1 = 3. Нәтиже (1, 1)-дің 3 еселігі: бағыт өзгерген жоқ.

Шешілген мысал

A = [[4, 1], [2, 3]] матрицасының меншікті мәндерін тап.

  1. det(A − λI) = (4 − λ)(3 − λ) − 1·2Диагональдан λ-ны алып, анықтауышты есептейміз.
  2. = λ² − 7λ + 12 − 2 = λ² − 7λ + 10Жақшаны ашамыз.
  3. λ² − 7λ + 10 = 0, яғни (λ − 5)(λ − 2) = 0Түбірлердің көбейтіндісі 10, қосындысы 7.
  4. λ₁ = 5, λ₂ = 2Тексеру: 5 + 2 = 7 = 4 + 3 (диагональдың қосындысы), 5·2 = 10 = det A.

Өзіңді тексер

v меншікті вектор болу үшін не орындалуы керек?

Жауабы мен түсіндірмесі

Дұрыс жауап: A·v = λ·v, мұнда v ≠ 0

Бейнесі v-ның еселігі болуы керек: бағыты сақталады (не кері бұрылады, егер λ < 0).

Меншікті мәндер қай теңдеуден табылады?

Жауабы мен түсіндірмесі

Дұрыс жауап: det(A − λI) = 0

(A − λI)v = 0 теңдеуінің нөлден өзге шешімі болуы үшін A − λI ерекше болуы керек, яғни анықтауышы нөл.

2Ығысу мен бұрылыс

Идея

Меншікті векторлардың саны матрицаға байланысты:

  • Симметриялық матрицаның (A = Aᵀ) нақты меншікті векторлары әрқашан бар, әрі олар бір-біріне перпендикуляр (45° және 135°: тік бұрыш).
  • Ығысудың [[1, 1], [0, 1]] тек бір меншікті бағыты бар: x осі (λ = 1). Басқа барлық бағыт қисаяды.
  • Бұрылыстың нақты меншікті бағыты мүлде жоқ. Оның меншікті мәндері комплекс сандар (2-курста кездесесің).

Түйсік

Желдеткіштің қалақшалары: айналғанда ешбір қалақ өз бағытында қалмайды. Ал қағаз парағын бір шетінен ығыстырсаң, тек төменгі жиегі орнында қалады.

Есептеп көрейік

Ығысу: det(A − λI) = (1 − λ)² = 0, λ = 1 (қайталанған). (A − I)v = 0: v = (1, 0). Тек бір бағыт. Бұрылыс: det(A − λI) = λ² + 1 = 0: нақты шешім жоқ.

Нақты әлемде

Дифференциалдық теңдеулер жүйесінде (2-курс) меншікті мәндер жүйенің тағдырын айтады: нақты әрі оң болса, шешім өседі; теріс болса, сөнеді; комплекс болса, тербеледі. Маятниктің тербелісі бұрылыс матрицасының комплекс меншікті мәндерінен шығады.

Енді сен

Ығысудың жалғыз меншікті бағытын тап. Сосын бұрылысты таңдап, бірнеше бағытты байқап көр.

3D симуляцияда орында

  • Ығысудың жалғыз меншікті бағытын тап
  • 90° бұрылыста кемінде 4 бағытты байқап көр: бірде-бірі өз түзуінде қалмайды
Симуляцияны ашу

Алдымен болжа

90° бұрылыс матрицасының нақты меншікті векторы бар ма?

Жауабы мен түсіндірмесі

Дұрыс жауап: Жоқ

Жазықтықта 90° бұрылғанда ешбір вектор өз түзуінде қалмайды. Сипаттамалық теңдеу λ² + 1 = 0: нақты түбірі жоқ.

Қатені тап

A = [[3, 0], [0, 3]] матрицасының меншікті векторларын тап.

  1. det(A − λI) = (3 − λ)² = 0
  2. λ = 3 (екі рет)
  3. A − 3I нөлдік матрица, сондықтан (A − 3I)v = 0 кез келген v үшін орындалады
  4. Демек меншікті вектор тек (1, 0)
Жауабы

4-жол қате. A барлық бағытты бірдей 3 есе созады, ешқайсысын бұрмайды. Сондықтан кез келген нөлдік емес вектор меншікті.

Дұрысы: Демек кез келген нөлдік емес вектор меншікті вектор

Өз сөзіңмен түсіндір

Меншікті вектор деген не, A = [[2, 1], [1, 2]] үшін оларды қайдан таптың, және неге бұрылыстың нақты меншікті векторы жоқ?

Жақсы түсіндірмеде болатын ойлар
  • A·v = λ·v: бағыт сақталады, тек созылады
  • 45° бағытта λ = 3, 135° бағытта λ = 1
  • бұрылыс барлық бағытты бұрады

Өзіңді тексер

Симметриялық матрицаның меншікті векторлары туралы не белгілі?

Жауабы мен түсіндірмесі

Дұрыс жауап: Олар нақты және бір-біріне перпендикуляр

Бұл спектрлік теорема: симметриялық матрица перпендикуляр осьтер бойымен тек созады.

Неге 90° бұрылыстың нақты меншікті векторы жоқ?

Жауабы мен түсіндірмесі

Дұрыс жауап: Ол барлық бағытты бұрады

Бұрылыс анықтауышы 1, ерекше емес. Бірақ ешбір нақты бағытты өз түзуінде қалдырмайды.

3D сахнамен көру

Фильмнің мәтіні (7 кадр)
  1. Түсіну. Сұрақ: A бұрмайтын, тек созатын бағыттар.A = [[2, 1], [1, 2]]
  2. Жоспар. Жоспар: алдымен сипаттамалық теңдеуден λ-ны табамыз, сосын әр λ-ға бағыт. Сахнада бағытты бұрып, тексеріп отырамыз.det(A − λI) = 0
  3. Шешу. Диагональдан λ-ны алып, анықтауышты есептейміз. Сахнада 60°-та көрсеткі әлі бұрылып кетеді.(2 − λ)² − 1 = 0
  4. Шешу. Квадрат 1-ге тең: екі түбір шығады.2 − λ = ±1 ⇒ λ = 3 не λ = 1
  5. Шешу. λ = 3 үшін (A − 3I)v = 0 теңдеуінен v = (1, 1). Сахнада 45° бағыты өз түзуінде қалып, үш есе созылды.λ = 3: v = (1, 1), яғни 45°
  6. Шешу. λ = 1 үшін v = (1, −1): бағыты да, ұзындығы да өзгермейді.λ = 1: v = (1, −1), яғни 135°
  7. Тексеру. Тексеру: екеуі де A·v = λ·v-ны қанағаттандырады. Олар перпендикуляр: симметриялық матрицаның белгісі.A·(1, 1) = (3, 3) ✓, A·(1, −1) = (1, −1) ✓
