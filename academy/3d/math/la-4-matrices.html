Матрицалар және матрицалық амалдар

Матрица сандар кестесі емес, машина: ол бүкіл кеңістікті бұрады, созады, қисайтады. Бағандары базис векторларының қайда баратынын айтады.

3D симуляцияны ашу Дәрісті оқу

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақтың қадамдарынан құрастырылған)
  1. Сұрақ. Матрицаның бірінші бағаны (0, 1, 0). Бұл не туралы айтады?
  2. Бейне. Резеңке торды созу. Тордың үш негізгі ұшын (e1, e2, e3) қайда апарғаныңды айтсаң, тордың қалған барлық нүктесі сызықтық түрде соңынан ереді. Сахнадағы торлы текше дәл осыны көрсетеді.
  3. Болжа. Матрицаның бірінші бағаны (0, 1, 0). Бұл не туралы айтады? Жауап: e1 = (1, 0, 0) векторы барып түсетін нүкте. A·e1 дегеніміз A-ның бірінші бағаны. Матрицаның бағандары базис векторларының бейнелері.
  4. Көр. 1-қадам, «Бағандар: базис қайда барады». 3×3 матрица әр векторды басқа векторға айналдыратын машина: Ең маңызды қасиеті: матрицаның бағандары базис векторлары e1, e2, e3 қайда баратынын көрсетеді.
  5. Көр. 2-қадам, «Көбейту: машиналарды тізбектеу». Матрицаларды көбейту түрлендірулерді тізбектеу: Алдымен A, сосын B. Көбейту реті маңызды: жалпы жағдайда B·A ≠ A·B. Алдымен бұрып сосын созу мен алдымен созып сосын бұрудың нәтижесі әртүрлі.
  6. Көр. Нақты әлемде: Ойындағы робот қолы: иық, шынтақ, білек әрқайсысы өз матрицасымен бұрылады, ал қолдың ұшы солардың көбейтіндісімен табылады (IoT зертханасындағы кинематика). Көбейту реті дұрыс болмаса, қол басқа жаққа созылады.
  7. Түйін. Матрица сандар кестесі емес, машина: ол бүкіл кеңістікті бұрады, созады, қисайтады. Бағандары базис векторларының қайда баратынын айтады.
  8. Түйін. Жиі қате: Жалпы жағдайда A·B мен B·A туралы не айтуға болады? Жауап: «Әрқашан тең». Дұрысы: «Әртүрлі болуы мүмкін». Матрицаларды көбейту коммутативті емес. Сандарда 2·3 = 3·2, ал түрлендірулерде олай емес.
  1. Бағандар: базис қайда барады
  2. Көбейту: машиналарды тізбектеу

1Бағандар: базис қайда барады

Идея

3×3 матрица әр векторды басқа векторға айналдыратын машина:

A·v = (A-ның 1-жолы · v, 2-жолы · v, 3-жолы · v)

Ең маңызды қасиеті: матрицаның бағандары базис векторлары e1, e2, e3 қайда баратынын көрсетеді. Ал кез келген вектор солардың комбинациясы болғандықтан, бағандарды білу бүкіл түрлендіруді білу деген сөз.

Мысалы, z осінен 90° бұрылыс: e1 → (0, 1, 0), e2 → (−1, 0, 0), e3 орнында. Бұл бағандарды қатар қойсақ:

0 −1 0
1  0 0
0  0 1

Түйсік

Резеңке торды созу. Тордың үш негізгі ұшын (e1, e2, e3) қайда апарғаныңды айтсаң, тордың қалған барлық нүктесі сызықтық түрде соңынан ереді. Сахнадағы торлы текше дәл осыны көрсетеді.

Есептеп көрейік

Ығысу (shear): e1 орнында, e2 → (1, 1, 0). Матрица:

1 1 0
0 1 0
0 0 1

(0, 2, 0) нүктесі (2, 2, 0)-ге барады: жоғары көтерілген сайын оңға көбірек ығысады.

Нақты әлемде

Әр 3D ойындағы әр нүкте әр кадрда матрицаға көбейтіледі: модельді әлемге қою, камераға бұру, экранға проекциялау. Видеокарта секундына миллиардтаған осындай көбейту жасайды.

Енді сен

Ұяшықтарды өзгертіп, алдымен 90° бұрылысты, сосын ығысуды құр.

3D симуляцияда орында

  • Ұяшықтарды өзгертіп, z осінен 90° бұратын матрицаны құр: e1 → (0, 1, 0), e2 → (−1, 0, 0)
  • Ығысу: e1 орнында, e2 → (1, 1, 0), e3 орнында
Симуляцияны ашу

Алдымен болжа

Матрицаның бірінші бағаны (0, 1, 0). Бұл не туралы айтады?

Жауабы мен түсіндірмесі

Дұрыс жауап: e1 = (1, 0, 0) векторы барып түсетін нүкте

A·e1 дегеніміз A-ның бірінші бағаны. Матрицаның бағандары базис векторларының бейнелері.

Шешілген мысал

A = [[2, 1], [0, 3]] матрицасын v = (4, −1) векторына көбейт.

  1. A·v = 4·(1-баған) + (−1)·(2-баған)Матрица × вектор: бағандардың комбинациясы, коэффициенттері вектордың координаталары.
  2. = 4·(2, 0) + (−1)·(1, 3)Бағандар: (2, 0) және (1, 3).
  3. = (8, 0) + (−1, −3)Әр бағанды өз санына көбейтеміз.
  4. = (7, −3)Координаталар бойынша қосамыз. Жолдар бойынша тексер: 2·4 + 1·(−1) = 7, 0·4 + 3·(−1) = −3.

Өзіңді тексер

A матрицасының екінші бағаны (2, 0, 5). A·(0, 1, 0) неге тең?

Жауабы мен түсіндірмесі

Дұрыс жауап: (2, 0, 5)

A·e2 әрқашан A-ның екінші бағаны.

Бірлік матрица I не істейді?

Жауабы мен түсіндірмесі

Дұрыс жауап: Әр векторды орнында қалдырады

I-дің бағандары e1, e2, e3: базис орнында, сондықтан барлық вектор орнында.

2Көбейту: машиналарды тізбектеу

Идея

Матрицаларды көбейту түрлендірулерді тізбектеу:

(B·A)·v = B·(A·v)

Алдымен A, сосын B. Көбейту реті маңызды: жалпы жағдайда B·A ≠ A·B. Алдымен бұрып сосын созу мен алдымен созып сосын бұрудың нәтижесі әртүрлі.

Көбейтудің есептеу ережесі: (B·A)-ның i-жолы мен j-бағанындағы сан = B-ның i-жолы мен A-ның j-бағанының скаляр көбейтіндісі.

Түйсік

Киіну реті: алдымен шұлық, сосын аяқкиім. Ретін ауыстырсаң, нәтиже басқа. Бірақ бір амалды қайталау (екі рет 90° бұрылу) ретке тәуелді емес.

Есептеп көрейік

R = 90° бұрылыс. R·R бағандары: e1 → (−1, 0, 0), e2 → (0, −1, 0): 180°. R⁴ = I: төрт рет 90° бұрылғанда кеңістік бастапқы қалпына оралады.

Нақты әлемде

Ойындағы робот қолы: иық, шынтақ, білек әрқайсысы өз матрицасымен бұрылады, ал қолдың ұшы солардың көбейтіндісімен табылады (IoT зертханасындағы кинематика). Көбейту реті дұрыс болмаса, қол басқа жаққа созылады.

Енді сен

Бастапқы матрица: 90° бұрылыс. «90° бұру» түрлендіруін тағы біріктіріп, 180°-ты ал. Сосын төрт бұрылысқа дейін жеткіз.

3D симуляцияда орында

  • Тағы 90° бұрып көбейт: 180° бұрылыс шықты
  • Барлығы төрт рет бұр: кеңістік бастапқы қалпына оралды (I)
Симуляцияны ашу

Алдымен болжа

90° бұрылыс матрицасын өзіне көбейтсек, қандай түрлендіру шығады?

Жауабы мен түсіндірмесі

Дұрыс жауап: 180° бұрылыс

Матрицаларды көбейту түрлендірулерді тізбектейді: екі рет 90° бұру 180° бұруға тең.

Қатені тап

A = [[1, 1], [0, 1]], B = [[0, −1], [1, 0]]. Алдымен A, сосын B: B·A-ны тап.

  1. (B·A)₁₁ = 0·1 + (−1)·0 = 0
  2. (B·A)₁₂ = 0·1 + (−1)·1 = −1
  3. (B·A)₂₁ = 1·1 + 0·0 = 1
  4. (B·A)₂₂ = 1·0 + 0·1 = 0
Жауабы

4-жол қате. (B·A)₂₂ үшін B-ның 2-жолын A-ның 2-бағанына көбейту керек. A-ның 2-бағаны (1, 1), ал мұнда A-ның 2-жолы (0, 1) алынған.

Дұрысы: (B·A)₂₂ = 1·1 + 0·1 = 1

Өз сөзіңмен түсіндір

Матрицаның бағандары не туралы айтады және неге екі рет 90° бұру 180° бұрылыс берді?

  • көбейту: түрлендірулерді тізбектеу
  • төрт бұрылыс: бірлік матрица

Өзіңді тексер

Жауабы мен түсіндірмесі

Матрицаларды көбейту коммутативті емес. Сандарда 2·3 = 3·2, ал түрлендірулерде олай емес.

90° бұрылыс матрицасы R үшін R⁴ неге тең?

Жауабы мен түсіндірмесі

Дұрыс жауап: Бірлік матрица I

4 × 90° = 360°: толық айналым, кеңістік орнына оралады.
