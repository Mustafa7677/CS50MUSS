Анықтауыш

Анықтауыш: матрица көлемді неше есе өзгертетінін айтатын бір сан. Нөл болса, кеңістік жаншылады; теріс болса, айнадай аударылады.

3D симуляцияны ашу Дәрісті оқу

  1. Көлемнің еселігі
  2. Жаншу және аудару

1Көлемнің еселігі

Идея

Анықтауыш det A: матрица көлемді неше есе өзгертетінін айтатын бір сан. Бірлік текше (көлемі 1) A-дан кейін параллелепипедке айналады, ал оның көлемі |det A|.

3×3 матрица үшін формула:

det A = a(ei − fh) − b(di − fg) + c(dh − eg)

мұнда A = [[a, b, c], [d, e, f], [g, h, i]].

Түйсік

Қамыр жаю. Жайған сайын пішіні өзгереді, бірақ қамырдың көлемі сол: мұндай түрлендірудің анықтауышы 1. Ал қамырды екі есе көбейтсең, көлем де екі есе.

Есептеп көрейік

  • diag(1, 2, 3): det = 6.
  • Ығысу [[1, 1, 0], [0, 1, 0], [0, 0, 1]]: det = 1·(1·1 − 0) − 1·(0 − 0) + 0 = 1. Текше қисаяды, бірақ көлемі сол.
  • 90° бұрылыс: det = 1. Бұрылыс көлемді өзгертпейді.

Нақты әлемде

Интегралда айнымалыны ауыстырғанда (2-семестр) анықтауыш шығады: ол кеңістіктің кішкене бөлігі қаншалықты созылатынын айтады (Якобиан). Физикада сұйықтың сығылмайтыны да анықтауыштың 1-ге тең болуымен өрнектеледі.

Енді сен

Ұяшықтарды өзгертіп, текшенің көлемін 6-ға жеткіз. Сосын ығысуды құрып, көлемнің өзгермейтінін көр.

3D симуляцияда орында

  • Бірлік текшені көлемі 6 болатын қорапқа айналдыр: det A = 6
  • Ығысу: пішіні өзгереді, ал көлемі сол (det = 1, бірақ A ≠ I)
Симуляцияны ашу

Алдымен болжа

A = diag(1, 2, 3) (x-ті өзгертпейді, y-ті 2, z-ті 3 есе созады). Бірлік текшенің көлемі қаншаға айналады?

Жауабы мен түсіндірмесі

Дұрыс жауап: 6

Қораптың қырлары 1, 2, 3: көлемі 1·2·3 = 6. Бұл det A.

Шешілген мысал

det [[1, 2, 0], [0, 3, 1], [2, 0, 1]] есепте.

  1. 1·(3·1 − 1·0) − 2·(0·1 − 1·2) + 0·(0·0 − 3·2)Бірінші жол бойынша жіктеу: әр элемент өзінің кіші анықтауышымен, таңбалар + − + ретімен.
  2. = 1·3 − 2·(−2) + 0Кіші анықтауыштарды есептейміз.
  3. = 3 + 4 = 7Минус пен минус плюс береді.
  4. Бірлік текше көлемі 7 болатын параллелепипедке айналадыАнықтауыш: көлемнің еселігі.

Өзіңді тексер

Кез келген бұрылыс матрицасының анықтауышы неге тең?

Жауабы мен түсіндірмесі

Дұрыс жауап: 1

Бұрылыс пішінді де, көлемді де сақтайды, бағдарды да аудармайды.

det(A·B) неге тең?

Жауабы мен түсіндірмесі

Дұрыс жауап: det A · det B

Алдымен B көлемді det B есе, сосын A det A есе өзгертеді: барлығы көбейтіндісі.

2Жаншу және аудару

Идея

  • det A = 0: кеңістік жазықтыққа, түзуге не нүктеге жаншылады. Көлем жоғалады, ақпарат жоғалады, A⁻¹ жоқ (өткен сабақ).
  • det A < 0: көлем сақталуы мүмкін, бірақ кеңістік айнадай аударылады: оң қол жүйесі сол қол жүйесіне айналады.

Анықтауыштың таңбасы бағдарды (оң не сол), ал абсолют мәні көлемді көрсетеді.

Түйсік

Оң қолыңның суретін айнаға қара: айнадағы қол сол қолға ұқсайды. Өлшемі сол, бірақ бағдары керісінше: det = −1.

Есептеп көрейік

  • Жаншу [[1, 0, 0], [0, 1, 0], [0, 0, 0]]: det = 0.
  • Айна [[−1, 0, 0], [0, 1, 0], [0, 0, 1]]: det = −1.
  • Екі жолы бірдей кез келген матрицаның анықтауышы 0.

Нақты әлемде

3D графикада беттің «алдыңғы» және «артқы» жағы анықтауыштың таңбасымен анықталады: модельді айнадай аударсаң, бетінің бағыты керісінше болып, ол көрінбей қалуы мүмкін.

Енді сен

Текшені жазыққа жанш (det = 0), сосын кеңістікті айнадай аудар (det < 0).

3D симуляцияда орында

  • Текшені жазыққа жанш: det A = 0
  • Кеңістікті айнадай аудар: det A теріс
Симуляцияны ашу

Алдымен болжа

A-ның екі бағаны параллель болса, det A қандай?

Жауабы мен түсіндірмесі

Дұрыс жауап: 0

Екі баған бір түзу бойында болса, үш базис вектор бір жазықтыққа түседі: параллелепипедтің көлемі нөл.

Қатені тап

det [[1, 2], [3, 4]] есепте.

  1. det = a·d − b·c
  2. = 1·4 − 2·3
  3. = 4 − 6
  4. = 2
Жауабы

4-жол қате. 4 − 6 = −2. Таңба маңызды: −2 аудан 2 есе өскенін және жазықтық айнадай аударылғанын айтады.

Дұрысы: = −2

Өз сөзіңмен түсіндір

Анықтауыш геометриялық тұрғыдан нені өлшейді? Оның 0, 1 және теріс болуы нені білдіреді?

Жақсы түсіндірмеде болатын ойлар
  • анықтауыш: көлемнің еселігі
  • 0: жаншылады, кері матрица жоқ
  • теріс: айнадай аударылады
  • 1: көлем сақталады (ығысу, бұрылыс)

Өзіңді тексер

det A = 0 болса, A⁻¹ туралы не айтуға болады?

Жауабы мен түсіндірмесі

Дұрыс жауап: Ол жоқ

Көлем нөлге түсті: ақпарат жоғалды. Кері матрица тек det A ≠ 0 болса бар.

det A = −2 нені білдіреді?

Жауабы мен түсіндірмесі

Дұрыс жауап: Көлем 2 есе ұлғаяды және кеңістік айнадай аударылады

Абсолют мәні көлемнің еселігі, ал теріс таңба бағдардың аударылғанын білдіреді.
