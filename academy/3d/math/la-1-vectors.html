Векторлар және олармен амалдар

Вектор: кеңістіктегі көрсеткі де, сандар тізімі де. Қосу көрсеткілерді тізбектеп жүру, санға көбейту оны созу.

3D симуляцияны ашу Дәрісті оқу

  1. Көрсеткілерді тізбектеу
  2. Санға көбейту

1Көрсеткілерді тізбектеу

Идея

Вектор екі түрлі көрінеді, бірақ бұл бір нәрсе:

  • геометриялық: бағыты мен ұзындығы бар көрсеткі;
  • алгебралық: сандар тізімі, мысалы (3, 1, 0).

Сандар көрсеткінің әр ось бойымен қанша жүретінін айтады. Екі векторды қосу дегеніміз көрсеткілерді тізбектеп жүру: алдымен u бойымен, сосын соның ұшынан v бойымен. Координаталарда бұл жай ғана сәйкес сандарды қосу:

u + v = (u1 + v1, u2 + v2, u3 + v3)

Түйсік

Қаладағы жол сілтеу: «шығысқа 3 квартал, солтүстікке 1». Сосын «шығысқа тағы 1, солтүстікке 2». Жалпы: шығысқа 4, солтүстікке 3. Қай ретпен жүрсең де, келетін жерің бір: u + v = v + u. Сахнадағы параллелограмм дәл осыны көрсетеді.

Есептеп көрейік

A нүктесінен B нүктесіне апаратын вектор: AB = B − A. A(1, 1, 0), B(4, 5, 0) болса, AB = (3, 4, 0).

Ұзындығы Пифагор теоремасынан: |v| = √(v1² + v2² + v3²). AB үшін √(9 + 16 + 0) = √25 = 5.

Нақты әлемде

Ойын қозғалтқышында ойыншының орны да, жылдамдығы да, оған әсер ететін жел де векторлар: келесі кадрдағы орны = орны + жылдамдық. Нейрондық желіде сөздер де векторлар (AI зертханасында көрдің).

Енді сен

u тұрақты. v-ның координаталарын өзгертіп, u + v = (4, 3, 2) болатындай ет. Сосын v-ны AB векторына айналдыр.

3D симуляцияда орында

  • u = (3, 1, 0) тұр. v-ны таңда: u + v = (4, 3, 2)
  • A(1, 1, 0) нүктесінен B(4, 5, 0) нүктесіне апаратын AB векторын v етіп қой: оның ұзындығы 5
Симуляцияны ашу

Алдымен болжа

u = (3, 1, 0), v = (1, 2, 0). u + v векторы кеңістікте қай жерге апарады?

Жауабы мен түсіндірмесі

Дұрыс жауап: (4, 3, 0)

Қосу координаталар бойынша жүреді: 3 + 1 = 4, 1 + 2 = 3, 0 + 0 = 0. Геометриялық мағынасы: көрсеткілерді біріне бірін тізбектеп жалғау.

Шешілген мысал

A(1, 2, 0) және B(4, 6, 0). AB векторы мен оның ұзындығын тап.

  1. AB = B − AВектор басынан ұшына қарай: соңғы нүктеден бірінші нүктені аламыз.
  2. AB = (4 − 1, 6 − 2, 0 − 0) = (3, 4, 0)Координаталар бойынша азайту.
  3. |AB| = √(3² + 4² + 0²)Ұзындық Пифагор теоремасынан шығады.
  4. |AB| = √25 = 59 + 16 = 25, ал оның түбірі 5.

Өзіңді тексер

(2, −1, 4) + (1, 3, −4) неге тең?

Жауабы мен түсіндірмесі

Дұрыс жауап: (3, 2, 0)

Координаталар бойынша: 2 + 1 = 3, −1 + 3 = 2, 4 + (−4) = 0.

(6, 8, 0) векторының ұзындығы қандай?

Жауабы мен түсіндірмесі

Дұрыс жауап: 10

√(36 + 64 + 0) = √100 = 10. Бұл 3-4-5 үшбұрышының екі еселенгені.

2Санға көбейту

Идея

Санға көбейту (скалярға көбейту) көрсеткіні созады не қысады:

k·u = (k·u1, k·u2, k·u3)
  • k > 1: ұзарады, бағыты сол;
  • 0 < k < 1: қысқарады;
  • k < 0: бағыты кері бұрылады;
  • k = 0: нөл векторы, көрсеткі жоқ.

Ұзындық |k| есе өзгереді: |k·u| = |k|·|u|.

Түйсік

Фотосуретті үлкейту не кішірейту. Пропорциясы сақталады, тек өлшемі өзгереді. Теріс сан суретті «айналдырып», екінші жаққа қаратады.

Есептеп көрейік

Қосу мен санға көбейтуді біріктірсек, сызықтық комбинация шығады: a·u + b·v. Мысалы, 2·(1, 0, 0) + 3·(0, 1, 0) = (2, 3, 0). Кез келген жазықтық нүктесін (1, 0) мен (0, 1) векторларының комбинациясы ретінде жазуға болады: бұл базис идеясы, оған 7-сабақта ораламыз.

Екі вектор параллель (коллинеар), егер біреуі екіншісінің еселігі болса: (2, 4, 6) = 2·(1, 2, 3).

Нақты әлемде

Анимацияда нысанның жылдамдығын баяулату (k = 0,5) не соқтығысқанда кері лақтыру (k = −1) дәл осы амал.

Енді сен

k сырғытпасын қозғалт: алдымен k·u екі есе ұзын әрі кері бағытта болсын, сосын жартысына дейін қысқарсын.

3D симуляцияда орында

  • k·u екі есе ұзын әрі кері бағытта болсын
  • k·u жартысына дейін қысқарсын, бағыты сол
Симуляцияны ашу

Алдымен болжа

u = (3, 1, 0) векторын k = −2 санына көбейтсек не болады?

Жауабы мен түсіндірмесі

Дұрыс жауап: (−6, −2, 0): бағыты кері, ұзындығы 2 есе

Санға көбейту әр координатаны көбейтеді. |k| ұзындықты өзгертеді, ал теріс таңба бағытты кері бұрады.

Қатені тап

2·(1, −3, 2) − (4, 1, 0) векторын тап.

  1. 2·(1, −3, 2) = (2, −6, 4)
  2. (2, −6, 4) − (4, 1, 0)
  3. = (2 − 4, −6 − 1, 4 − 0)
  4. = (−2, −5, 4)
Жауабы

4-жол қате. −6 − 1 = −7, ал −5 емес: теріс саннан оң санды азайтқанда модуль үлкейеді.

Дұрысы: = (−2, −7, 4)

Өз сөзіңмен түсіндір

Векторды қосу мен санға көбейту геометриялық тұрғыдан не істейді? AB векторының ұзындығы неге 5 шықты?

Жақсы түсіндірмеде болатын ойлар
  • қосу: көрсеткілерді тізбектеу
  • санға көбейту: созу не қысу, теріс сан бағытты бұрады
  • ұзындық Пифагор теоремасынан

Өзіңді тексер

(2, 4, 6) және (1, 2, 3) векторлары туралы не айтуға болады?

Жауабы мен түсіндірмесі

Дұрыс жауап: Параллель

(2, 4, 6) = 2·(1, 2, 3). Еселік векторлар бір түзу бойында жатады.

k = 0 болса, k·u не болады?

Жауабы мен түсіндірмесі

Дұрыс жауап: Нөл векторы (0, 0, 0)

Әр координата нөлге көбейтіледі. Нөл векторының бағыты жоқ.
