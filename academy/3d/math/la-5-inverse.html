Математика · 5-сабақ · ≈25 мин · 2 қадам · 4 сұрақ

Кері матрица және LU жіктелуі

A⁻¹ матрицасы A жасаған түрлендіруді болдырмайды. Ол тек A ақпаратты жоғалтпаса бар: кеңістікті жазықтыққа жаншыған матрицаның керісі жоқ.

3D симуляцияны ашу Дәрісті оқу

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақтың қадамдарынан құрастырылған)
  1. Сұрақ. A ығысу матрицасы e2-ні (1, 1, 0)-ге апарады. A⁻¹ e2-нің бейнесін қайда апарады?
  2. Бейне. Шифр мен кілт. A хатты шифрлайды, A⁻¹ қайта ашады. Шифр ақпаратты жоғалтпаса ғана хатты қалпына келтіруге болады.
  3. Болжа. A ығысу матрицасы e2-ні (1, 1, 0)-ге апарады. A⁻¹ e2-нің бейнесін қайда апарады? Жауап: (0, 1, 0)-ге. A⁻¹ A-ның жасағанын болдырмайды: A⁻¹·A = I. Ығысудың керісі қарама-қарсы жаққа ығысу.
  4. Көр. 1-қадам, «Болдырмау». Кері матрица A⁻¹: A жасаған түрлендіруді болдырмайтын матрица. Ол бар болса, Ax = b теңдеуі бірден шешіледі: x = A⁻¹·b.
  5. Көр. 2-қадам, «Қайтару мүмкін емес». Кері матрица әрқашан бола бермейді. A екі әртүрлі векторды бір векторға апарса, ақпарат жоғалады да, қайтару мүмкін емес. Мұндай матрица ерекше (сингуляр, азғындалған) деп аталады.
  6. Көр. Нақты әлемде: Сандық есептеулерде «жуық ерекше» матрицалар қауіпті: кері матрица бар, бірақ кішкене қате үлкен ауытқу береді. Сондықтан инженерлер матрицаның «шартталу санына» (condition number) қарайды.
  7. Түйін. A⁻¹ матрицасы A жасаған түрлендіруді болдырмайды. Ол тек A ақпаратты жоғалтпаса бар: кеңістікті жазықтыққа жаншыған матрицаның керісі жоқ.
  8. Түйін. Жиі қате: Неге жаншитын матрицаның керісі жоқ? Жауап: «Есептеу тым ұзақ». Дұрысы: «Бірнеше вектор бір векторға түседі». Кері түрлендіру әр нәтижеге бір ғана бастапқы векторды сәйкестендіруі керек.

1Болдырмау

Комикс · Нұрай, Мустафа және Бота

Шифр және кілт

Барлық комикстер

Идея

Кері матрица A⁻¹: A жасаған түрлендіруді болдырмайтын матрица.

A⁻¹·A = A·A⁻¹ = I

Ол бар болса, Ax = b теңдеуі бірден шешіледі: x = A⁻¹·b.

Мысалдар:

  • ығысу [[1, 1, 0], [0, 1, 0], [0, 0, 1]] керісі: [[1, −1, 0], [0, 1, 0], [0, 0, 1]];
  • x бойымен 2 есе созу керісі: x бойымен 2 есе қысу (1/2);
  • 90° бұрылыс керісі: −90° бұрылыс.

Түйсік

Шифр мен кілт. A хатты шифрлайды, A⁻¹ қайта ашады. Шифр ақпаратты жоғалтпаса ғана хатты қалпына келтіруге болады.

Есептеп көрейік

LU жіктелуі: A = L·U, мұнда L төменгі үшбұрышты, U жоғарғы үшбұрышты. Бұл Гаусс әдісінің «жазбасы»: U баспалдақ түрі, L жасаған жою амалдарымыздың коэффициенттері. Бір A матрицасымен көп жүйені (әр түрлі b-мен) шешу керек болса, LU бір рет есептеледі де, әр жаңа b үшін тек екі жеңіл үшбұрышты жүйе шешіледі.

Нақты әлемде

Компьютерлер A⁻¹-ді сирек тікелей есептейді: LU арқылы шешу жылдамырақ және дәлірек. Ойын қозғалтқыштары кері матрицаны камерадан әлемге қайту үшін қолданады (тінтуір басқан нүктені 3D кеңістікте табу).

Енді сен

Ығысуға A⁻¹-ді қолдан: тор текшесі орнына оралғанын көр. Сосын созуды таңдап, оны да кері қайтар.

3D симуляцияда орында

  • Ығысуға A⁻¹-ді қолдан: текше орнына оралды
  • Созуды таңдап, оны да кері қайтар
Симуляцияны ашу

Алдымен болжа

A ығысу матрицасы e2-ні (1, 1, 0)-ге апарады. A⁻¹ e2-нің бейнесін қайда апарады?

Жауабы мен түсіндірмесі

Дұрыс жауап: (0, 1, 0)-ге

A⁻¹ A-ның жасағанын болдырмайды: A⁻¹·A = I. Ығысудың керісі қарама-қарсы жаққа ығысу.

Шешілген мысал

A = [[2, 1], [5, 3]] матрицасының керісін тап.

  1. det A = 2·3 − 1·5 = 1Алдымен анықтауыш: нөл болса, кері матрица жоқ.
  2. 2×2 үшін: A⁻¹ = (1 / det A)·[[d, −b], [−c, a]]Бас диагональды ауыстырып, қосымша диагональдың таңбасын өзгертеміз.
  3. A⁻¹ = [[3, −1], [−5, 2]]a = 2, b = 1, c = 5, d = 3 және det A = 1.
  4. Тексеру: A·A⁻¹ = [[6 − 5, −2 + 2], [15 − 15, −5 + 6]] = IКөбейтінді бірлік матрица болуы керек.

Өзіңді тексер

A⁻¹ белгілі болса, Ax = b теңдеуін қалай шешеміз?

Жауабы мен түсіндірмесі

Дұрыс жауап: x = A⁻¹·b

Екі жағын да солдан A⁻¹-ге көбейтеміз: A⁻¹·A·x = A⁻¹·b, яғни x = A⁻¹·b.

LU жіктелуінің пайдасы неде?

Жауабы мен түсіндірмесі

Дұрыс жауап: Бір матрицамен көп жүйені тез шешу

Гаусс жоюы ең қымбат бөлік. LU оны бір рет сақтап, қайта қолдануға мүмкіндік береді.

2Қайтару мүмкін емес

Идея

Кері матрица әрқашан бола бермейді. A екі әртүрлі векторды бір векторға апарса, ақпарат жоғалады да, қайтару мүмкін емес. Мұндай матрица ерекше (сингуляр, азғындалған) деп аталады.

Белгілері (бәрі бір нәрсе):

  • кеңістікті жазықтыққа, түзуге не нүктеге жаншиды;
  • бағандары сызықтық тәуелді;
  • Ax = 0 теңдеуінің нөлден өзге шешімі бар;
  • анықтауышы нөл (келесі сабақ).

Түйсік

Үш өлшемді затты жерге түскен көлеңкесі бойынша қалпына келтіру. Көлеңке биіктік туралы ештеңе айтпайды: шар мен цилиндрдің көлеңкесі бірдей болуы мүмкін.

Есептеп көрейік

Жаншу матрицасы [[1, 0, 0], [0, 1, 0], [0, 0, 0]]. A·(0, 0, 1) = (0, 0, 0): нөлдік емес вектор нөлге түсті. Ал A⁻¹·(0, 0, 0) әрқашан (0, 0, 0) болуы керек еді: қайшылық. Сондықтан A⁻¹ жоқ.

Нақты әлемде

Сандық есептеулерде «жуық ерекше» матрицалар қауіпті: кері матрица бар, бірақ кішкене қате үлкен ауытқу береді. Сондықтан инженерлер матрицаның «шартталу санына» (condition number) қарайды.

Енді сен

Жаншитын матрицаға A⁻¹ қолданып көр.

3D симуляцияда орында

  • Жаншитын матрицаға A⁻¹ қолданып көр: ол жоқ
Симуляцияны ашу

Алдымен болжа

A кеңістікті xy жазықтығына жаншиды (z → 0). A⁻¹ бар ма?

Жауабы мен түсіндірмесі

Дұрыс жауап: Жоқ

(1, 2, 0), (1, 2, 5), (1, 2, −3) бәрі (1, 2, 0)-ге түседі. Кері матрица қайсысына қайтаратынын біле алмайды: ақпарат жоғалды.

Қатені тап

A = [[2, 4], [1, 2]]. Керісі бар ма?

  1. det A = 2·2 − 4·1
  2. det A = 0
  3. A⁻¹ = (1/0)·[[2, −4], [−1, 2]]: сандар тек өте үлкен болады
Жауабы

3-жол қате. Нөлге бөлуге болмайды. Формула тек det A ≠ 0 үшін жарамды: det A = 0 болса, кері матрица мүлде жоқ.

Дұрысы: det A = 0, сондықтан A⁻¹ жоқ: (2, 1) және (4, 2) бағандары параллель

Өз сөзіңмен түсіндір

Кері матрица не істейді, ығысуды қалай қайтардық, және неге жаншитын матрицаның керісі жоқ?

Жақсы түсіндірмеде болатын ойлар
  • A⁻¹·A = I: түрлендіруді болдырмайды
  • жаншу ақпаратты жоғалтады
  • әртүрлі векторлар бір нәтиже береді

Өзіңді тексер

Неге жаншитын матрицаның керісі жоқ?

Жауабы мен түсіндірмесі

Дұрыс жауап: Бірнеше вектор бір векторға түседі

Кері түрлендіру әр нәтижеге бір ғана бастапқы векторды сәйкестендіруі керек.

Ax = 0 теңдеуінің нөлден өзге шешімі болса, A туралы не айтуға болады?

Жауабы мен түсіндірмесі

Дұрыс жауап: A-ның кері матрицасы жоқ

A·x = 0 = A·0: екі әртүрлі вектор бір нәтиже берді, яғни ақпарат жоғалды.
