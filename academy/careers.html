Кім боламын?

Жеті сұраққа жауап бер: қай IT мамандығы саған жақын екенін көресің. Әр мамандықтың бір күні, құралдары, алғашқы жобасы бар, ал оған 2-бөлімнің сабақтарынан жол салынған.

Тест: жеті сұрақ

Саған ең жақын

    1. Фронтенд әзірлеуші
    2. Бэкенд әзірлеуші
    3. Деректер ғалымы / ML инженер
    4. Киберқауіпсіздік маманы
    5. Ойын әзірлеуші
    6. DevOps / SRE инженері
    7. Желі инженері
    8. Робототехник / IoT инженері

    Фронтенд әзірлеуші

    Адамдар көретін және басатын нәрсенің бәрін жасайды: сайт, қосымша, батырма, анимация.

    Не істейді

    • Дизайнерің суретін нақты, жылдам ашылатын бетке айналдырады
    • Бет телефонда да, үлкен экранда да әдемі көрінуін қадағалайды
    • Пайдаланушы басқанда не болатынын JavaScript-пен жазады

    Бір күні

    1. 09:30 Командамен 15 минуттық кездесу: кеше не істедім, бүгін не істеймін
    2. 11:00 Жаңа төлем бетінің макетін кодқа айналдыру
    3. 14:00 Телефонда батырма экраннан шығып кетті: CSS-ті түзету
    4. 16:30 Әріптестің кодын қарап, пікір жазу (code review)

    Құралдары

    • HTML
    • CSS
    • JavaScript
    • React
    • Figma
    • Браузердің DevTools

    Жолы: 2-бөлімнің 8 сабағы

    1. Интернет қалай жұмыс істейді
    2. HTML және DOM
    3. CSS және бет құрылымы
    4. JavaScript: оқиғалар циклі
    5. Ақау іздеу
    6. Сайтты жариялау
    7. HTTP кэштеу: max-age және ETag
    8. Сұраныс сарқырамасы: await, Promise.all және топтау

    Алғашқы жобаң

    Мектебіңнің кесте сайтын жаса: телефонда ыңғайлы, бүгінгі сабақтар бірінші көрінеді.

    Қайда жұмыс істейді

    Банктер мен маркетплейстер, стартаптар, веб-студиялар, кез келген өнімі бар компания.

    Баг аулау ойынында кодтағы қателерді жой

    Бэкенд әзірлеуші

    Экранның артындағы бәрі соның қолында: деректер, логика, миллиондаған сұранысқа жауап.

    Не істейді

    • Қосымшаның серверін және API-ін жазады
    • Деректерді дерекқорда дұрыс сақтап, тез табады
    • Жүйе қатты жүктемеде де құламайтындай етеді

    Бір күні

    1. 10:00 Жаңа «тапсырысты қайтару» мүмкіндігінің API-ін жобалау
    2. 12:00 Баяу SQL сұранысын табу: индекс қосқанда 3 секунд 20 мс болды
    3. 15:00 Бір сұраныс екі рет келсе ақша екі рет алынбайтынын тексеру
    4. 17:00 Тесттер жасыл, өзгерісті серверге шығару

    Құралдары

    • Python немесе Go
    • SQL
    • PostgreSQL
    • HTTP және REST
    • Docker
    • Git

    Жолы: 2-бөлімнің 8 сабағы

    1. Интернет қалай жұмыс істейді
    2. Сервер жағы және API
    3. Кестелер және SELECT
    4. JOIN: кестелерді біріктіру
    5. Индекстер
    6. Транзакциялар
    7. 401 пен 403: тұлға және рөлдер
    8. Идемпотенттілік: POST пен PUT

    Алғашқы жобаң

    Сыныптың кітапханасына API жаса: кітапты алу, қайтару, кімде қай кітап жүргенін көру.

    Қайда жұмыс істейді

    Банктер, телеком, логистика, мемлекеттік сервистер, такси мен жеткізу қосымшалары.

    Кэш сақшысы ойынында жылдамдықты сына

    Деректер ғалымы / ML инженер

    Деректердің ішінен заңдылық табады және компьютерді мысалдардан үйретеді.

    Не істейді

    • Деректерді жинап, тазалап, графикке айналдырады
    • Болжау жасайтын модельдерді үйретеді және тексереді
    • Модельдің қай жерде қателесетінін және неге екенін түсіндіреді

    Бір күні

    1. 09:00 Кешегі модельдің нәтижесі: дәлдік 94%, бірақ сирек жағдайларда нашар
    2. 11:30 Деректерде қайталанған жолдар табылды: оларды тазалау
    3. 14:00 Жаңа модель үйретілуде, ал бұл уақытта графиктер салу
    4. 16:00 Бизнеске түсіндіру: модель неге осындай шешім қабылдайды

    Құралдары

    • Python
    • NumPy және pandas
    • PyTorch
    • Jupyter
    • SQL
    • Статистика

    Жолы: 2-бөлімнің 8 сабағы

    1. Дерек және деректер жиыны
    2. Жасанды нейрон
    3. Нейрон желілері
    4. Модельді оқыту
    5. Артық бейімделу
    6. Скаляр көбейтінді және ортогональдық
    7. Метрикалар: precision, recall және дәлдік тұзағы
    8. Дерек ағуы: тым жақсы нәтиженің сыры

    Алғашқы жобаң

    Сыныптың бағаларынан қай пәннің қай пәнмен байланысты екенін тауып, графикпен көрсет.

    Қайда жұмыс істейді

    Банктер (алаяқтықты табу), медицина, ауыл шаруашылығы, интернет-дүкендер, зерттеу орталықтары.

    Нейрон ормандарының боссын жең

    Киберқауіпсіздік маманы

    Шабуылшыдай ойлайды, бірақ қорғау үшін: осалдықты олардан бұрын табады.

    Не істейді

    • Жүйелерді бұзып көріп, осал жерлерін табады (пентест)
    • Шабуылды ерте байқайтын бақылау құрады
    • Қызметкерлерге фишингті тануды үйретеді

    Бір күні

    1. 09:00 Түнгі логтар: бір IP 5000 рет құпиясөз теріпті, оны бұғаттау
    2. 11:00 Жаңа сайттағы іздеу жолынан SQL injection табылды: әзірлеушілерге хабарлау
    3. 14:00 Құпиясөздер тұзбен хэштелгенін тексеру
    4. 16:00 Компанияға фишинг жаттығуы: жалған хатты кім басты?

    2. XOR және бір реттік блокнот
    3. Хэштеу

    7. Сертификаттар және сенім тізбегі
    8. Пакеттер мен қабаттар

    Алғашқы жобаң

    Құпиясөз тексергішін жаса: ол құпиясөздің беріктігін бағалап, неге әлсіз екенін айтады.

    Қайда жұмыс істейді

    Банктер, мемлекеттік органдар, телеком, қауіпсіздік компаниялары, CTF жарыстары.

    Брандмауэр қорғанысында серверді қорға

    Ойын әзірлеуші

    Физика, графика, жасанды интеллект және оқиға: бәрін бір әлемге жинайды.

    Не істейді

    • Кейіпкердің қозғалысын, физикасын, соқтығысуын жазады
    • Жаулардың мінез-құлқын (AI) жасайды
    • Ойын әлсіз компьютерде де 60 кадрмен жүруін қамтамасыз етеді

    Бір күні

    1. 10:00 Кейіпкер жылдам жүгіргенде қабырғадан өтіп кетеді: соқтығысуды түзету
    2. 12:30 Жау енді ойыншыны көріп, қуып, жоғалтқанда іздейді
    3. 15:00 Ойыншылар тестінен пікір: 3-деңгей тым қиын
    4. 17:00 Кадр жиілігі түсіп кетті: профайлермен себебін табу

    Бір экранды платформер жаса: секіру, ауырлық күші, бір жау және жеңіс есігі.

    Қайда жұмыс істейді

    Ойын студиялары, мобильді ойындар, білім беру қосымшалары, VR және симуляторлар.

    Пакет-серферде өз рекордыңды жаса

    DevOps / SRE инженері

    Сайт түнде де, мереке күні де, миллион адам кіргенде де жұмыс істеуі осыған байланысты.

    Не істейді

    • Кодты автоматты түрде тексеріп, серверге шығаратын конвейер құрады
    • Серверлердің денсаулығын бақылап, ақауды тез табады
    • Жүктеме өскенде жүйе өздігінен кеңеюін баптайды

    Бір күні

    1. 08:00 Түнгі ескерту: бір сервер жауап бермеді, оркестратор оны ауыстырыпты
    2. 10:30 Сату акциясына дайындық: автомасштабтау шектерін тексеру
    3. 14:00 Жаңа нұсқаны алдымен 5% пайдаланушыға шығару (canary)
    4. 16:00 Ақаудан кейінгі талдау: кінәлі іздемей, себебін жазу

    Алғашқы жобаң

    Өз сайтыңды контейнерге орап, әр өзгерістен кейін автоматты түрде жаңарып тұратындай ет.

    Қайда жұмыс істейді

    Ірі интернет-сервистер, банктер, бұлт провайдерлері, кез келген үлкен жүйесі бар компания.

    Бұлт шыңының боссын жең

    Желі инженері

    Интернеттің тамырларын салады: кабель, маршрутизатор, Wi-Fi, қаладан қалаға жол.

    Не істейді

    • Мекеменің желісін жобалап, баптайды
    • Пакет қайда жоғалғанын тауып, жолды түзетеді
    • Желіні шабуылдан және артық жүктемеден қорғайды

    Бір күні

    1. 09:00 Бір қабаттағы Wi-Fi баяу: арна кептелісін табу
    2. 11:00 Жаңа филиалды VPN арқылы бас кеңсеге қосу
    3. 14:00 Маршрутизация кестесін жаңарту: трафик енді резерв арнамен де жүреді
    4. 16:00 Wireshark-пен пакеттерді талдап, ақауды дәлелдеу

    Телеком операторлары, провайдерлер, банктер, әуежайлар, университеттер, деректер орталықтары.

    Робототехник / IoT инженері

    Кодын нақты әлемде қозғалатын нәрсеге айналдырады: робот, дрон, ақылды жылыжай.

    Не істейді

    • Датчиктерден деректі оқып, шуын сүзеді
    • Мотор мен қолды дәл басқаратын бағдарлама жазады
    • Құрылғы батареяда ай бойы жұмыс істеуін ойластырады

    Бір күні

    2. 11:00 Робот қолы мақсаттан 2 см ауытқиды: кинематиканы тексеру
    3. 14:00 Дәнекерлеу, сымдар, осциллограф: сигналды өлшеу
    4. 16:30 Құрылғы қатып қалса, watchdog оны өзі қайта қосатынын тексеру
