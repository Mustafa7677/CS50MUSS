11·02Memory & Pointers

Көрсеткіштер

  • күрделі
  • ≈ 55 мин
  • 3 мақсат
  • 6 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

AОқу мақсаттары

  • Көрсеткішті «мекенжайды сақтайтын айнымалы» ретінде анықтау; & және * амалдарын қолдану.
  • Көрсеткіш арқылы функцияда шақырушының айнымалысын өзгерту (swap).
  • NULL көрсеткішін және оны тексеру қажеттілігін түсіндіру.

BАлғышарттар

  • Жады моделі

CҰғымға кіріспе

Көрсеткіш (pointer) - мекенжайды сақтайтын айнымалы. int *p = &x; - p «x-ке көрсетеді». *p - p көрсетіп тұрған орындағы мән (сілтемені ашу, dereference): *p = 7; x-ті өзгертеді.

m10 l05-те swap(int a, int b) жұмыс істемеді - көшірмелер. Енді swap(int *a, int *b) мекенжайларды алады да, *a арқылы шақырушының айнымалыларының өзін өзгертеді. scanf("%d", &x)-тегі & да дәл осы себептен (m10 l08).

DАкадемиялық теория

Анықтама

& және *

&x - x-тің мекенжайы (типі: T* , егер x - T). *p - p мекенжайындағы T типті нысан. *&x ≡ x. NULL - «ешқайда көрсетпейді» мәні; *NULL - анықталмаған әрекет (әдетте құлау).

Теорема

Көрсеткіш арқылы swap

void swap(int *a, int *b) { int t = *a; *a = *b; *b = t; } шақыруынан кейін swap(&x, &y) x пен y мәндерін айырбастайды.

Дәлелдеу

Дәлелдеу

Параметрлер a = &x, b = &y (мекенжайлардың көшірмелері - мәнмен беру сақталды, бірақ көшірілгені мекенжай). Бастапқы мәндер x = X, y = Y. t = *a = X. *a = *b: a мекенжайындағы нысан, яғни x-тің өзі, Y-ке тең болады. *b = t: y = X. Функциядан кейін x = Y, y = X. ∎ (x пен y бір айнымалы болса - swap(&x, &x) - мән өзгермейді, бұл да дұрыс.)

Ескерту

Типтің мәні

int * пен char * бірдей мекенжай сақтай алады, бірақ *p қанша байт оқитынын тип анықтайды (l01 - тип оқу тәсілінде). Сондықтан көрсеткіштің типі маңызды.

EКөрнекі түсіндірме

*p = 10 x-ті өзгертті. p енді y-ке көрсетеді. swap көрсеткіштермен жұмыс істеді (m10 l05-тегі қатені түзеттік).

Интерактивті модель: өзің басқар

swap(&x, &y) көшірмелермен емес, мекенжайлармен жұмыс істейді: функция жақтауы жоғалғаннан кейін де main-дегі мәндер өзгерген күйде қалады.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Есеп: функция бір шақырумен екі нәтиже қайтарсын (бөлінді мен қалдық).
  2. C-да return тек бір мән береді.
  3. void divmod(int a, int b, int *q, int *r) { *q = a / b; *r = a % b; }
  4. Шақыру: int q, r; divmod(17, 5, &q, &r); - нәтижелер шақырушының айнымалыларына жазылды.

GЖұмыс мысалдары

HИнтерактивті эксперимент

Көрсеткіш - мәні мекенжай болатын жай ұяшық. *p ≡ mem[mem[P]] - екі қадамдық қатынас. Модельде int **pp (көрсеткішке көрсеткіш) қосып көріңіз.

IЖаттығулар

JМатематикалық пайымдау

Көрсеткіш - «қайда» мен «не» ұғымдарын ажырату. Python-да әр айнымалы іс жүзінде сілтеме (m08 l02 бүркеншік аттар), бірақ ол жасырын. C бұл механизмді ашады: сіз мекенжаймен тікелей жұмыс істейсіз. Бұл - қуат (шығыс параметрлер, деректер құрылымдары) және қауіп (NULL, ілулі көрсеткіштер - 6-сабақ).

KЖиі қателер

  • int *p; *p = 5; (p инициализацияланбаған).
    Себебі: p кез келген мекенжайды сақтауы мүмкін - жадты бүлдіру.
    Түзету: Көрсеткішті әрқашан инициализациялау (&x, malloc не NULL).
  • int* a, b; - b-ны да көрсеткіш деп ойлау.
    Себебі: * тек a-ға қатысты: b - int.
    Түзету: int *a, *b; не бөлек жолдарда.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
