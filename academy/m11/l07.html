11·07Memory & Pointers

Құрылымдар (struct)

  • орта
  • ≈ 50 мин
  • 3 мақсат
  • 6 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақ қадамдарынан құрастырылған)
  1. Сұрақ. struct - әр түрлі типті өрістерді бір атпен біріктіру: struct student { char name[32]; int age; double gpa; }; . Бұл Python-дағы сөздікке (m08 l03) не класқа ұқсайды, бірақ өрістер жиыны компиляция кезінде бекітілген және жадта қатар орналасады.
  2. Жол. 1-қадам. Модель: оқушы = аты, жасы, орташа баллы.
  3. Жол. 2-қадам. typedef struct { char name[32]; int age; double gpa; } Student;
  4. Жол. 3-қадам. Student s = {"Айгүл", 15, 4.8}; - инициализация өрістер ретімен.
  5. Жол. 4-қадам. Функция: void print_student(const Student *s) - көшірмесіз, өзгертусіз; ішінде s->name.
  6. Тексер. p - struct student * болса, p->age неге тең? Жауап: (*p).age. Дұрыс.
  7. Түйін. sizeof(struct) ≥ өрістер өлшемдерінің қосындысы. Кез келген құрылым үшін sizeof(struct S) ≥ Σ sizeof(өріс), ал өрістерді туралауы кемитін ретпен орналастыру толтыруды азайтады.
  8. Түйін. Жиі қате: sizeof(struct) өрістер қосындысына тең деп ойлау. Дұрысы: sizeof пен offsetof-қа сену; өрістерді үлкеннен кішіге реттеу.

AОқу мақсаттары

  • struct-ты жариялау, инициализациялау және өрістерге . мен -> арқылы қатынау.
  • Құрылымның жадтағы орналасуын (туралау, толтыру байттары) түсіндіру және sizeof-ты болжау.
  • Құрылымды функцияға мәнмен және көрсеткішпен беру айырмасын қолдану.

BАлғышарттар

  • Жады қателері
  • Ішкі құрылымдар

CҰғымға кіріспе

struct - әр түрлі типті өрістерді бір атпен біріктіру: struct student { char name[32]; int age; double gpa; };. Бұл Python-дағы сөздікке (m08 l03) не класқа ұқсайды, бірақ өрістер жиыны компиляция кезінде бекітілген және жадта қатар орналасады.

Өріске қатынау: s.age; көрсеткіш арқылы: p->age ≡ (*p).age. Үлкен құрылымды функцияға мәнмен беру оны толық көшіреді; сондықтан әдетте const struct student * беріледі.

DАкадемиялық теория

Анықтама

Туралау (alignment)

Процессор T типті мәнді мекенжайы alignof(T)-ға еселік болғанда тиімді оқиды (int - 4, double - 8). Сондықтан компилятор өрістер арасына толтыру (padding) байттарын қояды, ал құрылымның соңына - жалпы өлшем ең үлкен туралауға еселік болатындай толтыру.

Теорема

sizeof(struct) ≥ өрістер өлшемдерінің қосындысы

Кез келген құрылым үшін sizeof(struct S) ≥ Σ sizeof(өріс), ал өрістерді туралауы кемитін ретпен орналастыру толтыруды азайтады.

Дәлелдеу

Негіздеу

Өрістер жадта қиылыспай, жарияланған ретпен орналасады (C11 6.7.2.1/15); толтыру байттары тек қосылады, ешқашан алынбайды - демек өлшем ≥ қосынды. Мысал: {char c; double d; char e;} - c (1) + 7 толтыру (d 8-ге еселік мекенжайда басталуы үшін) + d (8) + e (1) + 7 соңғы толтыру = 24. Ал {double d; char c; char e;} - 8 + 1 + 1 + 6 = 16. Туралауы үлкен өрістер алдымен тұрса, кейінгі кіші өрістер үшін толтыру қажет болмайды, тек соңғы толтыру қалады. ∎

Ескерту

typedef

typedef struct { ... } Student; - енді struct сөзінсіз Student s; деп жазуға болады. Бұл - тек атау, жаңа мінез емес.

EКөрнекі түсіндірме

Бірдей өрістер, әртүрлі рет - 24 және 16 байт (теорема). offsetof өрістің құрылым басынан қашықтығын береді.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Модель: оқушы = аты, жасы, орташа баллы.
  2. typedef struct { char name[32]; int age; double gpa; } Student;
  3. Student s = {"Айгүл", 15, 4.8}; - инициализация өрістер ретімен.
  4. Функция: void print_student(const Student *s) - көшірмесіз, өзгертусіз; ішінде s->name.

HИнтерактивті эксперимент

Python моделі gcc нәтижелерімен (24, 16, 48) сәйкес пе? Өз құрылымыңызды қосып, оның өлшемін болжаңыз.

IЖаттығулар

JМатематикалық пайымдау

struct - деректерді мағыналы бірліктерге топтау: m08-дегі «жазба» (сөздік) енді типке айналды, және компилятор әр өріске қатынасты тексереді. Жадтағы орналасуды білу - файл форматтары, желі пакеттері, аппаратура регистрлерімен жұмыс істеудің негізі.

KЖиі қателер

  • sizeof(struct) өрістер қосындысына тең деп ойлау.
    Себебі: Толтыру байттары бар.
    Түзету: sizeof пен offsetof-қа сену; өрістерді үлкеннен кішіге реттеу.
  • Үлкен құрылымды мәнмен беру.
    Себебі: Әр шақыруда толық көшірме.
    Түзету: const S * - оқу үшін, S * - өзгерту үшін.
