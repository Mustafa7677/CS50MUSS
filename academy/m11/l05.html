Үйме (heap)

Деңгей: күрделі · шамамен 55 мин · нұсқа 1.0.0 · тексеру: author-checked

AОқу мақсаттары

  • malloc, calloc, realloc және free арқылы динамикалық жад бөлу және босату.
  • malloc нәтижесін (NULL) тексеру және өлшемді sizeof арқылы дұрыс есептеу.
  • «Бөлдің бе - босат» ережесін және иелік (ownership) ұғымын қолдану.

BАлғышарттар

  • Стек және шақырулар

CҰғымға кіріспе

Үйме (heap) - бағдарлама орындау кезінде сұрайтын жад. int *a = malloc(n * sizeof *a); n int-ке орын береді; ол функциядан кейін де өмір сүреді, бірақ free(a) шақырылғанша. Стектен айырмашылығы: өлшемі орындау кезінде анықталады, өмірін бағдарламашы басқарады.

malloc жад таппаса NULL қайтарады - оны тексеру міндетті. malloc берген жад инициализацияланбаған («қоқыс»); calloc нөлдейді. Әр malloc-қа дәл бір free керек: босатылмаса - ағып кету (leak), екі рет босатылса - қос босату (6-сабақ).

DАкадемиялық теория

Анықтама

Функциялар (stdlib.h)

malloc(bytes) - бөлу (инициализациясыз). calloc(n, size) - n · size байт, нөлдермен. realloc(p, new_bytes) - өлшемді өзгерту (мазмұн сақталады, мекенжай өзгеруі мүмкін). free(p) - босату; free(NULL) - ештеңе істемейді.

Теорема

Өлшемді дұрыс есептеу

T *p = malloc(n * sizeof *p); жазылуы p-ның типі қандай болса да n элементке дәл жеткілікті жад сұрайды.

Дәлелдеу

Дәлелдеу

sizeof *p - өрнектің типінің өлшемі; *p-ның типі T (p - T*), сондықтан sizeof *p = sizeof(T), ал sizeof есептелмейді (тек тип қаралады) - p әлі инициализацияланбаса да қауіпсіз. n элементке n · sizeof(T) байт керек (m10 l06 теоремасы). Кейін p-ның типін, мысалы, double-ға өзгертсек, sizeof *p өзі 8-ге өзгереді - sizeof(int) жазылуындай «ескірген» тип қатесі мүмкін емес. ∎ (n · sizeof *p асып кетпеуі үшін n-нің шегін тексеру не calloc.)

Ескерту

Иелік

Жадты кім босатады? Ереже: функция жадты бөліп қайтарса, оны босату - шақырушының міндеті, және бұл құжатта (docstring сияқты түсініктемеде) айтылуы керек. Python-да бұл мәселені қоқыс жинаушы шешеді (10-сабақ).

EКөрнекі түсіндірме

Бұл бағдарлама AddressSanitizer-мен (ағып кетуді де тексереді) таза өтті: әр бөлуге бір free. calloc нөлдеді.

FҚадамдап қорыту

  1. Есеп: n санды оқып, оларды кері ретпен шығару; n орындау кезінде белгілі.
  2. int *a = malloc(n * sizeof *a); if (!a) { fprintf(stderr, ...); return 1; }
  3. Оқу: for (i ...) scanf("%d", &a[i]);
  4. Шығару: for (i = n - 1; i >= 0; i--) ...; соңында free(a).

GЖұмыс мысалдары

HИнтерактивті эксперимент

realloc нәтижесін бөлек айнымалыға аламыз: NULL болса, ескі a жоғалмауы керек. Бұл - 9-сабақтағы динамикалық массивтің ядросы.

IЖаттығулар

JМатематикалық пайымдау

Үйме бағдарламашыға толық бақылау береді: деректер қанша керек болса сонша, қанша уақыт керек болса сонша. Бағасы - жауапкершілік: әр бөлудің иесі болуы керек. Бұл - C-ның ең көп қате туатын жері, сондықтан келесі сабақ толығымен жад қателеріне арналған.

KЖиі қателер

  • malloc(n) - элемент санын байт деп беру.
    Себебі: n int-ке n · 4 байт керек.
    Түзету: malloc(n * sizeof *p).
  • p = realloc(p, ...);
    Себебі: realloc NULL қайтарса, ескі p жоғалады - ағып кету.
    Түзету: Уақытша айнымалыға алып, тексеру.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.

MРефлексия

NТереңірек

Honors

  • malloc-тың қарапайым іске асыруын (бос блоктар тізімі, first-fit) Python-да модельдеңіз: бөлу, босату, фрагментация.

Research

  • glibc malloc (ptmalloc) пен jemalloc, tcmalloc айырмашылықтары. Неге браузерлер мен деректер базалары өз аллокаторларын қолданады?
