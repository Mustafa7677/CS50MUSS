Динамикалық массив

Деңгей: күрделі · шамамен 55 мин · нұсқа 1.0.0 · тексеру: author-checked

AОқу мақсаттары

  • Өлшемі өсетін массивті (len, cap, data) struct және realloc арқылы іске асыру.
  • Сыйымдылықты еселеу стратегиясының амортизацияланған O(1) құнын дәлелдеу.
  • Python list.append-тің ішкі жұмысын осы модельмен түсіндіру.

BАлғышарттар

  • Байланысқан тізім

CҰғымға кіріспе

Массивтің артықшылығы (i-ші элементке O(1)) мен тізімнің икемділігін біріктіру: динамикалық массив. Ол үш өрісті сақтайды: data (үймедегі массив), len (элементтер саны), cap (сыйымдылық). Орын бітсе - realloc арқылы екі есе үлкен массив сұраймыз.

Бір қосу кейде қымбат (барлық элементті көшіру - O(n)), бірақ бұл сирек болады. Орташа алғанда әр append тұрақты уақыт алады - бұл амортизациялық талдау. Python list, C++ vector, Java ArrayList - бәрі осылай жұмыс істейді.

DАкадемиялық теория

Анықтама

Амортизацияланған құн

n амалдың жалпы құны T(n) болса, бір амалдың амортизацияланған құны T(n) / n. Жеке амал қымбат болуы мүмкін, бірақ тізбектің орташасы кіші.

Теорема

Еселеу - амортизацияланған O(1)

Сыйымдылық 1-ден басталып, толғанда екі есе өссе, n рет push жасағанда барлық көшірулер саны 2n-нен кем; демек бір push-тың амортизацияланған құны O(1).

Дәлелдеу

Дәлелдеу

Көшіру тек сыйымдылық 1, 2, 4, ..., 2ᵏ толғанда болады, мұнда 2ᵏ < n (n-ші push-қа дейін). 2ʲ-ден 2ʲ⁺¹-ге өскенде 2ʲ элемент көшіріледі. Барлығы: 1 + 2 + 4 + ... + 2ᵏ = 2ᵏ⁺¹ − 1 < 2n (өйткені 2ᵏ < n). Көшірусіз жазулар - n. Жалпы жұмыс < 3n, бір push-қа < 3. ∎ Ал сыйымдылықты тұрақты c-ға арттырсақ (cap += 10), көшірулер ≈ n²/(2c) - квадраттық.

Ескерту

Python list

CPython list сыйымдылықты шамамен 1.125 есе (+ кішкене тұрақты) өсіреді - жадты үнемдейді, бірақ амортизацияланған құн бәрібір O(1) (кез келген тұрақты еселік > 1 жеткілікті). sys.getsizeof(lst) сыйымдылықтың секірістерін көрсетеді.

EКөрнекі түсіндірме

20 push - тек 6 рет қайта бөлу (1, 2, 4, 8, 16, 32). ASan-мен таза.

FҚадамдап қорыту

  1. Vec v = {0}; - data = NULL, len = cap = 0. realloc(NULL, ...) ≡ malloc.
  2. push: len == cap болса - new_cap = cap ? 2·cap : 1; realloc.
  3. realloc сәтсіз болса - ескі data сақталады (l05: уақытша айнымалы), 0 қайтарамыз.
  4. data[len++] = x. Соңында vec_free.

GЖұмыс мысалдары

HИнтерактивті эксперимент

Python list-тің өлшемі секірістермен өседі - бұл сыйымдылықтың артуы (бір көрсеткіш - 8 байт). Секірістер арасы біртіндеп ұлғаяды ма? (Нақты сандар Python нұсқасына байланысты.)

IЖаттығулар

JМатематикалық пайымдау

Амортизациялық талдау - «кейде қымбат, орташа арзан» құрылымдарды бағалаудың құралы. Ол m09 l10-дағы өлшеу мен m04-тегі O-белгілеуін біріктіреді: еселеу тәжірибесі (кестедегі 100 есе өсу) теорияны растайды. Python list.append-тің «O(1)» деген сөзі енді дәлелденген факт.

KЖиі қателер

  • v->data = realloc(v->data, ...);
    Себебі: NULL қайтса, ескі массив жоғалады (ағып кету).
    Түзету: Уақытша айнымалы + тексеру.
  • data массивіне сақталған көрсеткішті push-тан кейін қолдану.
    Себебі: realloc массивті басқа жерге көшіруі мүмкін - ескі көрсеткіш ілулі.
    Түзету: Индекс сақтау, көрсеткіш емес.

LМеңгеруді бағалау
