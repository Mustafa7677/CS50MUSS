11·01Memory & Pointers

Жады моделі

  • орта
  • ≈ 50 мин
  • 3 мақсат

нұсқа 1.0.0 · тексеру: author-checked

AОқу мақсаттары

  • Жадты нөмірленген байттар тізбегі (мекенжай → байт) ретінде модельдеу.
  • Көп байтты мәндердің жадта орналасуын (little-endian) және sizeof-ты түсіндіру.
  • Бағдарлама жадының аймақтарын (код, глобал, стек, үйме) атау.

BАлғышарттар

  • Python мен C салыстыру

CҰғымға кіріспе

Компьютер жады - өте ұзын байттар тізбегі. Әр байттың нөмірі бар - мекенжай. int x = 258; жазсақ, компилятор x үшін 4 қатар байт бөледі, ал x-тің мекенжайы - бірінші байттың нөмірі. 258 = 0x00000102, ал x86 процессорлары кіші байтты бірінші сақтайды (little-endian): 02 01 00 00.

Бұл сабақтағы зертханада жадты Python-ның bytearray-імен модельдейміз: индекс - мекенжай. Модель шын жадтың маңызды қасиетін көрсетеді: байттардың өзінде тип жоқ, оларды int, char не float деп «оқитын» - бағдарлама.

DАкадемиялық теория

Анықтама

Жад аймақтары

  • Код (text) - машиналық командалар, тек оқуға.
  • Глобал/статикалық деректер - бағдарлама бойы өмір сүреді.
  • Стек - функция шақыруларының жергілікті айнымалылары (4-сабақ).
  • Үйме (heap) - malloc арқылы сұралатын жад (5-сабақ).
Теорема

Little-endian орналасу

Little-endian машинада n байтты таңбасыз v мәнінің мекенжайы a болса, a + i мекенжайындағы байт ⌊v / 256ⁱ⌋ mod 256 (i = 0..n − 1).

Дәлелдеу

Дәлелдеу

v-ның 256 негізіндегі жазылуы: v = Σ bᵢ·256ⁱ, 0 ≤ bᵢ < 256 (m05 l02 санау жүйелері, бірегей). Little-endian анықтамасы бойынша bᵢ (i-ші «цифр») a + i мекенжайына жазылады. bᵢ-ді шығару: v-ны 256ⁱ-ге бөлгенде кіші i цифр қиылады, ал mod 256 келесі цифрларды алып тастайды: bᵢ = ⌊v / 256ⁱ⌋ mod 256. ∎ Мысал: 258 = 2 + 1·256 → байттар 2, 1, 0, 0.

Ескерту

Мекенжайлар неге өзгереді

Қазіргі ОЖ қауіпсіздік үшін әр іске қосуда стек пен үйменің орнын кездейсоқ таңдайды (ASLR). Сондықтан бұл модульдің бағдарламалары мекенжайдың өзін емес, айырмаларын шығарады - олар тұрақты.

EКөрнекі түсіндірме

258 → [2, 1, 0, 0], −1 → [255, 255, 255, 255] (қосымша код). 1-мекенжайдан оқу екі айнымалының байттарын араластырды - тип жадта емес, оқу тәсілінде.

Интерактивті модель: өзің басқар

Жад - нөмірленген ұяшықтар. STORE мәнді мекенжайға жазады, LOAD оқиды: регистр тазаланса да, мән жадта сақталады.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. int x = 258; - 4 байт, мекенжайы &x.
  2. 258 = 1·256 + 2 → байттар (кішіден): 02 01 00 00.
  3. Байттарды unsigned char ретінде оқу: ((unsigned char *)&x)[0] = 2.
  4. Big-endian машинада (кейбір желі протоколдары) реті керісінше: 00 00 01 02.

GЖұмыс мысалдары

HИнтерактивті эксперимент

Теорема формуласы Python-ның to_bytes нәтижесімен бірдей ме? 16909060 = 0x01020304 - байттар қай ретпен шықты? 'big' деп өзгертіп көріңіз.

IЖаттығулар

JМатематикалық пайымдау

«Айнымалы - мәні бар қорап» (m06) метафорасы енді нақтыланады: қорап - мекенжайдағы байттар, ал оның типі - байттарды қалай түсіндіру ережесі. Бұл модель көрсеткіштерді (2-сабақ), массивтерді (3-сабақ) және жад қателерін (6-сабақ) түсінуге кілт.

KЖиі қателер

  • Мекенжай әрқашан бірдей болады деп ойлау.
    Себебі: ASLR әр іске қосуда орындарды өзгертеді.
    Түзету: Айырмаларға және салыстыруларға сүйену.
  • Байттардың реті барлық машинада бірдей деп ойлау.
    Себебі: Big-endian жүйелер де бар (желі реті).
    Түзету: Деректерді файлға/желіге жазғанда байт ретін анық белгілеу.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.

NТереңірек

Honors

  • Big-endian/little-endian анықтайтын C бағдарламасын жазыңыз (int x = 1; бірінші байт 1 ме?).

Research

  • «Endianness» термині «Гулливердің саяхаттарынан» шыққан. Желі протоколдарында (TCP/IP) неге big-endian қабылданды?
