04·08Algorithmic Thinking

Операцияларды санау

  • орта
  • ≈ 50 мин
  • 3 мақсат
  • 6 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақ қадамдарынан құрастырылған)
  1. Сұрақ. Алгоритмнің жылдамдығын секундпен өлшесек, нәтиже компьютерге тәуелді. Сондықтан операция санын есептейміз: салыстыру, меншіктеу не негізгі әрекет n өлшемді кірісте неше рет орындалады. Цикл - қосынды: for i ← 1 to n do (i операция) end → Σ i = n(n + 1)/2.
  2. Жол. 1-қадам. Алгоритм: for i ← 1 to n do for j ← 1 to i do x ← x + 1 end end.
  3. Жол. 2-қадам. Ішкі цикл i рет: T(n) = Σ_{i=1}^{n} i.
  4. Жол. 3-қадам. Гаусс: T(n) = n(n + 1)/2.
  5. Жол. 4-қадам. Тексеру: n = 4 → 10; зертханада «x ← x + 1» жолы 10 рет орындалады.
  6. Түйін. Көпіршікті сұрыптаудың салыстырулары. for i ← 0 to n − 2 do for j ← 0 to n − 2 − i do (A[j] > A[j + 1] салыстыру) end end - дәл n(n − 1)/2 салыстыру.
  7. Түйін. Жиі қате: Кірістірілген циклда ішкі шекараның i-ге тәуелділігін елемеу. Дұрысы: Ішкі итерация санын i арқылы жазып, қосындыны есептеңіз.

AОқу мақсаттары

  • Алгоритмнің негізгі операциясын таңдап, оның орындалу санын n-нің функциясы ретінде жазу.
  • Циклдардың операция санын қосынды (Σ) арқылы есептеп, жабық формулаға келтіру.
  • Есептелген формуланы зертханадағы жол санағышымен тексеру.

BАлғышарттар

  • Іздеу стратегиялары

CҰғымға кіріспе

Алгоритмнің жылдамдығын секундпен өлшесек, нәтиже компьютерге тәуелді. Сондықтан операция санын есептейміз: салыстыру, меншіктеу не негізгі әрекет n өлшемді кірісте неше рет орындалады.

Цикл - қосынды: for i ← 1 to n do (i операция) end → Σ i = n(n + 1)/2. m02-дегі жабық формулалар мен индукция мұнда тікелей қолданылады.

DАкадемиялық теория

Анықтама

Уақыт функциясы

T(n) - n өлшемді кірісте негізгі операцияның (ең нашар жағдайдағы) орындалу саны.

Теорема

Көпіршікті сұрыптаудың салыстырулары

for i ← 0 to n − 2 do for j ← 0 to n − 2 − i do (A[j] > A[j + 1] салыстыру) end end - дәл n(n − 1)/2 салыстыру.

Дәлелдеу

Дәлелдеу

i бекітілгенде ішкі цикл j = 0, ..., n − 2 − i, яғни n − 1 − i рет. Σ_{i=0}^{n−2} (n − 1 − i) = (n − 1) + (n − 2) + ... + 1 = n(n − 1)/2. ∎

Ескерту

Тұрақтылар маңызды емес (әзірге)

3n + 5 мен 2n + 100 - екеуі де «n-ге пропорционал». Үлкен n-де ең маңыздысы - өсу жылдамдығы (9-сабақ).

EКөрнекі түсіндірме

Көпіршікті сұрыптау: c - салыстырулар саны. n = 6: 6·5/2 = 15. Массивті ұзартып, формуланы тексеріңіз.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Алгоритм: for i ← 1 to n do for j ← 1 to i do x ← x + 1 end end.
  2. Ішкі цикл i рет: T(n) = Σ_{i=1}^{n} i.
  3. Гаусс: T(n) = n(n + 1)/2.
  4. Тексеру: n = 4 → 10; зертханада «x ← x + 1» жолы 10 рет орындалады.

GЖұмыс мысалдары

HИнтерактивті эксперимент

n = 16 үшін c = ? Ішкі while неше рет айналады (log₂ n)? T(n) = n · log₂ n формуласын n = 8, 32 үшін тексеріңіз.

IЖаттығулар

JМатематикалық пайымдау

Неге «ең нашар жағдай»? Себебі ол кепілдік береді: ешбір кіріс бұдан баяу болмайды. Орташа жағдай кейде маңыздырақ (жылдам сұрыптау, m09), бірақ оны есептеу үшін кірістердің ықтималдық үлестірімін білу керек (Level II).

KЖиі қателер

  • Кірістірілген циклда ішкі шекараның i-ге тәуелділігін елемеу.
    Себебі: n · n емес, Σ (n − i) болуы мүмкін.
    Түзету: Ішкі итерация санын i арқылы жазып, қосындыны есептеңіз.
  • Негізгі операцияны дұрыс таңдамау.
    Себебі: Мысалы, сұрыптауда меншіктеулер кіріске тәуелді, салыстырулар - жоқ.
    Түзету: Ең жиі не ең қымбат операцияны таңдаңыз және оны атаңыз.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.

NТереңірек

Honors

  • Таңдау сұрыптауының (selection sort) салыстырулар санын шығарыңыз. Ол көпіршіктімен бірдей ме? Алмастырулар саны ше?

Research

  • Амортизацияланған талдау: өлшемі екі есе өсетін динамикалық массивке n элемент қосу неге орташа O(1)? (m11)
