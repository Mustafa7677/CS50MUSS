04·02Algorithmic Thinking

Есепті нақты тұжырымдау

  • негізгі
  • ≈ 40 мин
  • 3 мақсат
  • 6 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақ қадамдарынан құрастырылған)
  1. Сұрақ. «Тізімді сұрыпта» деген есеп толық емес. Нақты тұжырым: кіріс - бүтін сандар тізімі A (ұзындығы n ≥ 0); шығыс - B тізімі, онда B - A-ның қайта ретталуы және B[0] ≤ B[1] ≤ ... ≤ B[n−1]. Мұндағы екі шарт маңызды.
  2. Жол. 1-қадам. Есеп: «тізімде x бар ма, қай орында?».
  3. Жол. 2-қадам. Кіріс: A тізімі (n ≥ 0), x саны. Алдын ала шарт: жоқ (кез келген A).
  4. Жол. 3-қадам. Шығыс: i индексі, A[i] = x; ал x жоқ болса -1.
  5. Жол. 4-қадам. Кейінгі шарт: (i ≠ −1 → A[i] = x) ∧ (i = −1 → ∀j A[j] ≠ x). Бірнеше x болса қайсысы? Тұжырымда анықтау керек (мысалы, ең кіші i).
  6. Тексер. Сұрыптаудың толық кейінгі шарты: Жауап: Шығыс өспелі және A-ның қайта ретталуы. Дұрыс.
  7. Түйін. Әлсіз кейінгі шарт қате алгоритмді өткізеді. Сұрыптаудың кейінгі шарты тек «шығыс өспелі» болса, онда кез келген кіріске бос тізім қайтаратын алгоритм «дұрыс» болып шығады.
  8. Түйін. Жиі қате: Шығысты тек мысалмен сипаттау. Дұрысы: Кейінгі шартты логикалық тұжырыммен жазыңыз.

AОқу мақсаттары

  • Есепті кіріс, шығыс, алдын ала шарт (precondition) және кейінгі шарт (postcondition) түрінде жазу.
  • Шеткі жағдайларды (бос кіріс, бір элемент, теріс сан, үлкен сан) жүйелі тізу.
  • Кейінгі шартты логикалық формула ретінде жазып, оны мысалмен тексеру.

BАлғышарттар

  • Алгоритм деген не

CҰғымға кіріспе

«Тізімді сұрыпта» деген есеп толық емес. Нақты тұжырым: кіріс - бүтін сандар тізімі A (ұзындығы n ≥ 0); шығыс - B тізімі, онда B - A-ның қайта ретталуы және B[0] ≤ B[1] ≤ ... ≤ B[n−1].

Мұндағы екі шарт маңызды. «Өспелі» деген жалғыз шарт жеткіліксіз: бос тізім қайтару да өспелі! «A-ның қайта ретталуы» шарты ғана алгоритмнің деректі жоғалтпауын талап етеді.

DАкадемиялық теория

Анықтама

Келісімшарт

Алдын ала шарт P - кіріс қанағаттандыруы тиіс шарт. Кейінгі шарт Q - шығыс қанағаттандыруы тиіс шарт. Алгоритм дұрыс ⇔ P ақиқат кірістерде ол аяқталып, Q ақиқат болады.

Ескерту

Шеткі жағдайлар тізімі

Бос кіріс; бір элемент; барлық элемент бірдей; бұрыннан сұрыпталған; кері сұрыпталған; теріс сандар мен нөл; өте үлкен сандар; іздеуде - элемент жоқ жағдай.

Теорема

Әлсіз кейінгі шарт қате алгоритмді өткізеді

Сұрыптаудың кейінгі шарты тек «шығыс өспелі» болса, онда кез келген кіріске бос тізім қайтаратын алгоритм «дұрыс» болып шығады.

Дәлелдеу

Дәлелдеу

Бос тізім үшін «∀i (B[i] ≤ B[i+1])» бос ақиқат (m01 l09: бос облыстағы ∀). Демек ол кейінгі шартты қанағаттандырады, бірақ есепті шешпейді. Сондықтан «B - A-ның қайта ретталуы» шарты міндетті. ∎

EКөрнекі түсіндірме

Цифрлар санын есептеу. n = 0 енгізіп көріңіз: нәтиже 0, ал 0 санында 1 цифр бар! Шеткі жағдай тұжырымда ескерілмеген.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Есеп: «тізімде x бар ма, қай орында?».
  2. Кіріс: A тізімі (n ≥ 0), x саны. Алдын ала шарт: жоқ (кез келген A).
  3. Шығыс: i индексі, A[i] = x; ал x жоқ болса -1.
  4. Кейінгі шарт: (i ≠ −1 → A[i] = x) ∧ (i = −1 → ∀j A[j] ≠ x). Бірнеше x болса қайсысы? Тұжырымда анықтау керек (мысалы, ең кіші i).

GЖұмыс мысалдары

HИнтерактивті эксперимент

n = 7, 10, 999, 1000 үшін тексеріңіз. Алгоритмді n = 0 жағдайы да дұрыс болатындай етіп қалай түзетер едіңіз? (Нұсқау: алдын ала шарт n ≥ 1 қою не бөлек тексеру.)

IЖаттығулар

JМатематикалық пайымдау

Келісімшарт m01-дегі импликация: P → Q (бағдарламадан кейін). P жалған кіріске алгоритм ештеңе уәде етпейді - «бос ақиқат». Бұл қате емес, жауапкершілікті бөлу: шақырушы P-ны қамтамасыз етеді, алгоритм Q-ны.

KЖиі қателер

  • Шығысты тек мысалмен сипаттау.
    Себебі: Мысал жалпы ережені анықтамайды.
    Түзету: Кейінгі шартты логикалық тұжырыммен жазыңыз.
  • Бос кірісті ұмыту.
    Себебі: Ең жиі құлау себебі.
    Түзету: Алдын ала шартта жазыңыз не бөлек өңдеңіз.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.

MРефлексия

NТереңірек

Honors

  • Екілік іздеудің толық келісімшартын жазыңыз (алдын ала шарт: A сұрыпталған). Сұрыпталмаған тізімде не болады?

Research

  • Hoare логикасы {P} S {Q} - бағдарламаның дұрыстығын дәлелдеудің формалды жүйесі. Меншіктеу аксиомасын зерттеңіз.
