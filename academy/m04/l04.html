04·04Algorithmic Thinking

Тармақталу және цикл

  • негізгі
  • ≈ 45 мин
  • 3 мақсат
  • 6 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақ қадамдарынан құрастырылған)
  1. Сұрақ. Трассалау кестесі - алгоритмді қолмен орындаудың ең сенімді жолы: әр жолға бір бағана - айнымалы, әр қадамда өзгерген мәнді жазамыз. AO17 зертханасы дәл осындай кестені автоматты түрде құрады.
  2. Жол. 1-қадам. Бағдарлама: x ← 1; while x < 50 do x ← x * 3 end.
  3. Жол. 2-қадам. Трасса: x = 1 → 3 → 9 → 27 → 81.
  4. Жол. 3-қадам. 81 < 50 жалған - цикл тоқтайды. Дене 4 рет, while жолы 5 рет тексерілді.
  5. Жол. 4-қадам. Нәтиже x = 81. Жалпы: x = 3ᵏ, ең кіші k, 3ᵏ ≥ 50 - k = ⌈log₃ 50⌉ = 4.
  6. Түйін. Үшбұрышты кірістірілген цикл. for i ← 1 to n do for j ← i to n do X end end - X нұсқауы n(n + 1)/2 рет орындалады.
  7. Түйін. Жиі қате: Кірістірілген циклдардың санын қосу (n + m). Дұрысы: Көбейту: n · m (не Σ, егер ішкі шекара i-ге тәуелді).

AОқу мақсаттары

  • Ішкі if және циклдардың орындалу ретін трассалау кестесімен қолмен бақылау.
  • while мен for циклдарын бір-біріне аудару және олардың орындалу санын есептеу.
  • Кірістірілген циклдардағы ішкі нұсқаудың орындалу санын есептеу.

BАлғышарттар

  • Псевдокод

CҰғымға кіріспе

Трассалау кестесі - алгоритмді қолмен орындаудың ең сенімді жолы: әр жолға бір бағана - айнымалы, әр қадамда өзгерген мәнді жазамыз. AO17 зертханасы дәл осындай кестені автоматты түрде құрады.

Кірістірілген циклда ішкі цикл сыртқы циклдің әр айналымында толық орындалады: сыртқы n рет, ішкі m рет болса, ішкі денесі n · m рет орындалады (m03 l07: көбейту ережесі).

DАкадемиялық теория

Анықтама

Жол санағышы

AO17-де цикл тақырыбының жолы (for/while) «итерация саны + 1» рет есептеледі: соңғы рет шарт тексеріліп, цикл тоқтайды. Денедегі жол - итерация саны рет.

Теорема

Үшбұрышты кірістірілген цикл

for i ← 1 to n do for j ← i to n do X end end - X нұсқауы n(n + 1)/2 рет орындалады.

Дәлелдеу

Дәлелдеу

i бекітілгенде ішкі цикл j = i, ..., n, яғни n − i + 1 рет. Барлығы Σ_{i=1}^{n} (n − i + 1) = n + (n − 1) + ... + 1 = n(n + 1)/2 (m02 l07, Гаусс). ∎

Ескерту

while ↔ for

for i ← a to b do S end ≡ i ← a; while i ≤ b do S; i ← i + 1 end. Айырмашылығы: for санақты өзі басқарады - қателесу қаупі аз.

EКөрнекі түсіндірме

Кірістірілген цикл: c = n(n+1)/2. Жол санағыштарына қараңыз: 4-жол неше рет орындалды?

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Бағдарлама: x ← 1; while x < 50 do x ← x * 3 end.
  2. Трасса: x = 1 → 3 → 9 → 27 → 81.
  3. 81 < 50 жалған - цикл тоқтайды. Дене 4 рет, while жолы 5 рет тексерілді.
  4. Нәтиже x = 81. Жалпы: x = 3ᵏ, ең кіші k, 3ᵏ ≥ 50 - k = ⌈log₃ 50⌉ = 4.

GЖұмыс мысалдары

HИнтерактивті эксперимент

limit = 50, 81, 82 үшін нәтиже мен дене саны қалай өзгереді? Неліктен limit = 81-де нәтиже 81?

IЖаттығулар

JМатематикалық пайымдау

Неге цикл тақырыбы «итерация + 1» рет саналады? Себебі әр итерация алдында шарт тексеріледі, плюс соңғы тексеріс (жалған) циклды тоқтатады. Бұл қадам санауда маңызды: дәл есептеу (8-сабақ) осы ережеге сүйенеді.

KЖиі қателер

  • Кірістірілген циклдардың санын қосу (n + m).
    Себебі: Ішкі цикл сыртқының әр айналымында толық орындалады.
    Түзету: Көбейту: n · m (не Σ, егер ішкі шекара i-ге тәуелді).
  • while шартының соңғы (жалған) тексерісін ұмыту.
    Себебі: Цикл тоқтау үшін шарт бір рет жалған болуы керек.
    Түзету: Тақырып жолы = дене саны + 1.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.

NТереңірек

Honors

  • for i ← 1 to n do for j ← 1 to n do for k ← 1 to n do X end end end - X неше рет? Ал k ← 1 to j болса? Формуласын шығарыңыз.

Research
