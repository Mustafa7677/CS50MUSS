AОқу мақсаттары

  • AO17 оқу псевдокодының нұсқауларын (←, if, while, for, return, print) және өрнектерін (div, mod, and, or, not, A[i], len) қолдану.
  • Сөзбен берілген алгоритмді псевдокодқа, ал псевдокодты Python-ға аудару.
  • Псевдокодтағы синтаксис қателерін интерпретатор хабары бойынша түзету.

BАлғышарттар

  • Есепті нақты тұжырымдау

CҰғымға кіріспе

Псевдокод - адамға арналған, бірақ компьютерге аударуға оңай жазу. AO17 псевдокодының ережелері аз:

  • Меншіктеу: x ← x + 1 (не :=).
  • Шарт: if шарт then ... else ... end.
  • Циклдар: while шарт do ... end, for i ← a to b do ... end (a мен b қоса).
  • Массив: A ← [3, 1, 4], A[0] - бірінші элемент, len(A).
  • Бүтін бөлу: 7 div 2 = 3, қалдық: 7 mod 2 = 1.

Бұл - оқу тілі: ол толық бағдарламалау тілі емес, бірақ алгоритмдердің өзегін нақты көрсетуге жеткілікті.

DАкадемиялық теория

Анықтама

Нұсқаулар

Меншіктеу, тармақталу (if), шартты цикл (while), санақты цикл (for), нәтиже (return), шығару (print). Блок «end»-мен жабылады; шегініс оқуға көмектеседі.

Анықтама

Бүтін бөлу және қалдық

a div b = ⌊a/b⌋, a mod b = a − b·⌊a/b⌋ ∈ {0, ..., b−1} (b > 0). Мысалы −7 div 2 = −4, −7 mod 2 = 1.

Теорема

Бөлу теңдігі

b > 0 үшін a = b · (a div b) + (a mod b) және 0 ≤ a mod b < b.

Дәлелдеу

Дәлелдеу

q = ⌊a/b⌋ болсын: q ≤ a/b < q + 1. b-ға көбейтеміз (b > 0): bq ≤ a < bq + b. r = a − bq деп алсақ, 0 ≤ r < b және a = bq + r. Анықтама бойынша q = a div b, r = a mod b. ∎

EКөрнекі түсіндірме

Бөлу теңдігі: q·5 + r = x. x-ке теріс сан беріп көріңіз.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Сөзбен: «1-ден n-ге дейінгі жұп сандарды сана».
  2. Айнымалы: c ← 0.
  3. Цикл: for i ← 1 to n do; ішінде: if i mod 2 = 0 then c ← c + 1 end.
  4. Соңы: end, return c. Тексеру: n = 10 → 5.

GЖұмыс мысалдары

HИнтерактивті эксперимент

Бағдарлама нені санайды? n = 20 үшін нәтижені формуламен (n div 3) салыстырыңыз. Шартты i mod 3 = 0 or i mod 5 = 0 етіп өзгертіңіз.

IЖаттығулар

JМатематикалық пайымдау

Псевдокод неге керек, бірден Python жазсақ болмай ма? Псевдокод синтаксистік ұсақ-түйектен (тип, кітапхана, импорт) арылтып, алгоритмнің логикасына назар аудартады. Сонымен қатар ол бір алгоритмді Python-да да, C-да да (m10) бірдей түсіндіреді.

KЖиі қателер

  • for шекарасын Python range сияқты (соңғысыз) оқу.
    Себебі: AO17 псевдокодында to b - b қоса.
    Түзету: Итерация саны b − a + 1.
  • Теріс санның mod-ын теріс деп санау.
    Себебі: Анықтама бойынша 0 ≤ a mod b < b.
    Түзету: Бөлу теңдігінен есептеңіз.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.

MРефлексия

NТереңірек

Honors

  • Бөлу теңдігіндегі q мен r ЖАЛҒЫЗ екенін дәлелдеңіз (a = bq + r = bq' + r' болса, b | (r − r'), ал |r − r'| < b).

Research

  • Әр түрлі тілдерде теріс санды бөлу әр түрлі (C-да −7 / 2 = −3). m10-да C-ның ережесін салыстырыңыз.
