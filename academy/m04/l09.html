04·09Algorithmic Thinking

Асимптотикалық өсу

  • күрделі
  • ≈ 55 мин
  • 3 мақсат
  • 6 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақ қадамдарынан құрастырылған)
  1. Сұрақ. 8-сабақта T(n) = n(n − 1)/2 шықты. Үлкен n-де n² мүшесі шешуші: n = 10⁶ болғанда −n/2 мүшесі елеусіз. Асимптотикалық белгілер тұрақтылар мен кіші мүшелерді тастап, өсудің «формасын» сипаттайды.
  2. Жол. 1-қадам. Дәлелдейік: 3n + 10 = O(n).
  3. Жол. 2-қадам. c мен n₀ іздейміз: 3n + 10 ≤ c·n.
  4. Жол. 3-қадам. c = 4 алсақ: 3n + 10 ≤ 4n ⇔ n ≥ 10. Демек n₀ = 10.
  5. Жол. 4-қадам. Анықтаманың ∃c ∃n₀ бөлігі орындалды. ∎ (Басқа c, n₀ де жарайды: c = 13, n₀ = 1.)
  6. Тексер. Асимптотикалық белгілер бойынша қайсысы ақиқат? Жауап: n = O(n²). Дұрыс: O - жоғарғы шек, ол «бос» болуы мүмкін.
  7. Түйін. n(n − 1)/2 = Θ(n²). Көпіршікті сұрыптаудың салыстырулары квадраттық.
  8. Түйін. Жиі қате: O(n²) = O(n) + O(n) деп қосу ережесін қате қолдану. Дұрысы: Тізбекті бөліктер - қосу (max), кірістірілген - көбейту.

AОқу мақсаттары

  • O, Ω, Θ белгілерінің формалды анықтамасын кванторлармен жазу.
  • Анықтама бойынша f(n) = O(g(n)) екенін c және n₀ тұрақтыларын тауып дәлелдеу.
  • Негізгі функцияларды өсу жылдамдығы бойынша реттеу: 1 < log n < n < n log n < n² < 2ⁿ < n!.

BАлғышарттар

  • Операцияларды санау

CҰғымға кіріспе

8-сабақта T(n) = n(n − 1)/2 шықты. Үлкен n-де n² мүшесі шешуші: n = 10⁶ болғанда −n/2 мүшесі елеусіз. Асимптотикалық белгілер тұрақтылар мен кіші мүшелерді тастап, өсудің «формасын» сипаттайды.

f(n) = O(g(n)) - «f g-дан жылдам өспейді (тұрақты көбейткішке дейін)». Бұл - жоғарғы шек. Ω - төменгі шек, Θ - екеуі де.

DАкадемиялық теория

Анықтама

O, Ω, Θ

f = O(g) ⇔ ∃c > 0 ∃n₀ ∀n ≥ n₀: f(n) ≤ c·g(n). f = Ω(g) ⇔ ∃c > 0 ∃n₀ ∀n ≥ n₀: f(n) ≥ c·g(n). f = Θ(g) ⇔ f = O(g) ∧ f = Ω(g).

Теорема

n(n − 1)/2 = Θ(n²)

Көпіршікті сұрыптаудың салыстырулары квадраттық.

Дәлелдеу

Дәлелдеу

O: n(n − 1)/2 ≤ n²/2 барлық n ≥ 1 үшін, демек c = 1/2, n₀ = 1. Ω: n ≥ 2 үшін n − 1 ≥ n/2, демек n(n − 1)/2 ≥ n²/4; c = 1/4, n₀ = 2. Екеуі де орындалады, демек Θ(n²). ∎

Теорема

Көпмүшенің жоғарғы шегі

a_k nᵏ + ... + a₁n + a₀ = O(nᵏ) (a_k > 0).

Дәлелдеу

Дәлелдеу

n ≥ 1 үшін әр aᵢnⁱ ≤ |aᵢ|nᵏ. Демек қосынды ≤ (|a_k| + ... + |a₀|)·nᵏ; c = Σ|aᵢ|, n₀ = 1. ∎

EКөрнекі түсіндірме

Өсу жылдамдықтары. n = 20-да 2ⁿ ≈ 10⁶, n² = 400. Шекараны 60-қа өзгертіңіз: экспонента қалғанын «жұтып» қояды.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Дәлелдейік: 3n + 10 = O(n).
  2. c мен n₀ іздейміз: 3n + 10 ≤ c·n.
  3. c = 4 алсақ: 3n + 10 ≤ 4n ⇔ n ≥ 10. Демек n₀ = 10.
  4. Анықтаманың ∃c ∃n₀ бөлігі орындалды. ∎ (Басқа c, n₀ де жарайды: c = 13, n₀ = 1.)

GЖұмыс мысалдары

HИнтерактивті эксперимент

n² мен 100n қай n-де қиылысады? 100n = O(n²) бола тұра, кіші n-де неге үлкен? Бұл n₀-ның мағынасы.

IЖаттығулар

JМатематикалық пайымдау

«O» тек жоғарғы шек болғандықтан, «екілік іздеу O(n)» тұжырымы да ақиқат, бірақ пайдасыз. Сондықтан алгоритмді сипаттағанда мүмкіндігінше Θ немесе ең дәл O-ны береміз. Кванторлардың реті маңызды (m01 l09): c мен n₀ АЛДЫМЕН таңдалады, сосын ∀n.

KЖиі қателер

  • O(n²) = O(n) + O(n) деп қосу ережесін қате қолдану.
    Себебі: O(n) + O(n) = O(n), ал кірістірілген цикл - көбейту.
    Түзету: Тізбекті бөліктер - қосу (max), кірістірілген - көбейту.
  • n₀-ды кез келген n үшін тексермеу.
    Себебі: Анықтама n ≥ n₀ БАРЛЫҚ n үшін.
    Түзету: Теңсіздікті алгебралық түрде шешіңіз.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.

MРефлексия

NТереңірек

Honors

  • log_a n = Θ(log_b n) екенін дәлелдеңіз (a, b > 1). Неге сондықтан O(log n) дегенде негіз жазылмайды?

Research

  • P мен NP: көпмүшелік уақытта шешілетін есептер. Неге 2ⁿ алгоритмдер «тәжірибеде шешілмейтін» саналады?
