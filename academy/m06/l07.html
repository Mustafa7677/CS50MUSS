06·07Python Foundations

for циклі және range

  • негізгі
  • ≈ 45 мин
  • 3 мақсат
  • 6 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақ қадамдарынан құрастырылған)
  1. Сұрақ. for i in range(1, 6): - i = 1, 2, 3, 4, 5. Назар аударыңыз: 6 кірмейді . Бұл псевдокодтағы «for i ← 1 to 5»-тен ерекше (m04 l03). range(n) = 0, ..., n − 1 - дәл n элемент. for кез келген тізбекті аралайды: жолдың әріптерін, тізімнің элементтерін.
  2. Жол. 1-қадам. Есеп: 1-ден n-ге дейінгі 3-ке не 5-ке бөлінетін сандардың қосындысы.
  3. Жол. 2-қадам. s = 0; for k in range(1, n + 1): if k % 3 == 0 or k % 5 == 0: s += k.
  4. Жол. 3-қадам. n = 10: 3, 5, 6, 9, 10 → 33.
  5. Жол. 4-қадам. Шекара: range(1, n + 1) - n-ді қосу үшін +1.
  6. Түйін. range(a, b) ұзындығы. len(range(a, b)) = max(0, b − a).
  7. Түйін. Жиі қате: range(1, n) - n-ді қамтиды деп ойлау. Дұрысы: range(1, n + 1).

AОқу мақсаттары

  • range(start, stop, step) мағынасын және оның stop-ты қамтымайтынын білу.
  • for арқылы тізбекті аралап, жинақтаушы айнымалы (қосынды, санақ, максимум) қолдану.
  • Кірістірілген for циклдарының орындалу санын (m04 l08) Python-да тексеру.

BАлғышарттар

  • while циклі

CҰғымға кіріспе

for i in range(1, 6): - i = 1, 2, 3, 4, 5. Назар аударыңыз: 6 кірмейді. Бұл псевдокодтағы «for i ← 1 to 5»-тен ерекше (m04 l03). range(n) = 0, ..., n − 1 - дәл n элемент.

for кез келген тізбекті аралайды: жолдың әріптерін, тізімнің элементтерін. Жинақтаушы айнымалы циклдан бұрын бастапқы мәнмен құрылады (s = 0, c = 0, best = ...).

DАкадемиялық теория

Анықтама

range

range(a, b, s) - a, a + s, a + 2s, ... b-ға жетпей (s > 0 болса < b). Элемент саны max(0, ⌈(b − a)/s⌉).

Теорема

range(a, b) ұзындығы

len(range(a, b)) = max(0, b − a).

Дәлелдеу

Дәлелдеу

Элементтер a, a + 1, ..., b − 1 (b > a болса). Бұл b − 1 − a + 1 = b − a сан. b ≤ a болса, бос. ∎ Сондықтан range(n) дәл n рет айналады - «0-ден санау» ыңғайлылығы.

Ескерту

Жинақтаушы үлгілер

Қосынды: s = 0; s += x. Санақ: c = 0; if шарт: c += 1. Максимум: best = бірінші элемент; if x > best: best = x.

EКөрнекі түсіндірме

range шекаралары. Гаусс қосындысы 5050 (m02 l07).

Интерактивті модель: өзің басқар

for циклында i өзі өзгереді: әр кадрда i мен total-дың мәнін бақылап, қосындының қалай жиналатынын көріңіз.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Есеп: 1-ден n-ге дейінгі 3-ке не 5-ке бөлінетін сандардың қосындысы.
  2. s = 0; for k in range(1, n + 1): if k % 3 == 0 or k % 5 == 0: s += k.
  3. n = 10: 3, 5, 6, 9, 10 → 33.
  4. Шекара: range(1, n + 1) - n-ді қосу үшін +1.

GЖұмыс мысалдары

HИнтерактивті эксперимент

Үшбұрышты төңкеріңіз (n-нен 1-ге дейін). range(n, 0, -1) қолданыңыз.

IЖаттығулар

JМатематикалық пайымдау

«Бір-біріне қате» (off-by-one) - бағдарламалаудағы ең жиі қате. range(a, b) жартылай ашық аралығы [a, b) оны азайтады: ұзындығы b − a, ал [a, b) және [b, c) аралықтары қиылыспай біріктіріледі. Дейкстра осы себептен 0-ден санауды ұсынған.

KЖиі қателер

  • range(1, n) - n-ді қамтиды деп ойлау.
    Себебі: stop қосылмайды.
    Түзету: range(1, n + 1).
  • Жинақтаушыны цикл ішінде нөлдеу.
    Себебі: Әр айналымда қайта басталады.
    Түзету: s = 0 циклден бұрын.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
