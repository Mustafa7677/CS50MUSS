CҰғымға кіріспе

Енді бәрін біріктіреміз: пайдаланушы сандар тізімін енгізеді, бағдарлама статистиканы есептейді: саны, қосындысы, орташасы, ең кішісі, ең үлкені, медианасы. Әр есепті бөлек функция шешеді - сондықтан әрқайсысын жеке тестілей аламыз.

Енгізуді сенімді өңдеу (бос жол, сан емес мән) - утилитаның сапасы. Нашар енгізуге бағдарлама құламауы, түсінікті хабар беруі керек.

DАкадемиялық теория

Анықтама

Медиана

Сұрыпталған тізімнің ортаңғы элементі; жұп ұзындықта - екі ортаңғының орташасы.

Теорема

Медиана индекстері

n элементті сұрыпталған a үшін: n тақ - a[n // 2]; n жұп - (a[n // 2 − 1] + a[n // 2]) / 2.

Дәлелдеу

Дәлелдеу

n = 2m + 1: a[m]-ден солда m, оңда m элемент - ортасы, ал m = n // 2. n = 2m: ортаңғы екеуі a[m − 1] және a[m] (әрқайсысының бір жағында m − 1, екінші жағында m элемент), m = n // 2. ∎

Ескерту

Келісімшарттар

parse_numbers(text) → тізім не ValueError; stats(nums) - алдын ала шарт: nums бос емес; format_report(st) → жол. Бөліктер тек келісімшарт арқылы байланысқан (m04 l10).

EКөрнекі түсіндірме

Утилитаның өзегі. Енгізуге «72, бес» жазыңыз - ValueError. Жобада оны түсінікті хабарға айналдыру керек.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Ішкі есеп 1: мәтіннен сандар тізімі (үтір мен бос орын бөлгіш).
  2. Ішкі есеп 2: статистика (саны, қосынды, орташа, min, max, медиана).
  3. Ішкі есеп 3: есепті форматтау (f-жолдар, 2 таңба).
  4. Біріктіру: main() енгізуді оқып, қатені ұстап, үш бөлікті шақырады.

IЖаттығулар

JМатематикалық пайымдау

Жоба - модульдің «емтиханы»: бөлек дағдылар бір жерге жиналады. Бұл жерде m04-тегі декомпозиция, m06-дағы тіл құралдары және m08-де келетін тестілеу мәдениеті кездеседі. Жақсы жоба - тек жұмыс істейтін емес, тексерілетін және түсінікті жоба.

KЖиі қателер

  • Барлық логиканы бір ұзын бағдарламаға жазу.
    Себебі: Бөліктерді бөлек тексеру мүмкін емес.
    Түзету: parse / stats / report функциялары.
  • Бос енгізуді ескермеу.
    Себебі: len(nums) = 0 - нөлге бөлу.
    Түзету: Алдын ала шартты тексеріп, хабар беріңіз.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.

MРефлексия

NТереңірек

Honors

  • Стандартты ауытқуды (σ = √(Σ(x − x̄)²/n)) есептейтін функция қосып, statistics.pstdev нәтижесімен салыстырыңыз.

Research

  • Python statistics модулінің median, mode, stdev функцияларының шеткі жағдайлардағы мінезін зерттеңіз.

Модуль жобасы: Python Data Calculator

Сандар тізімінің статистикасын есептейтін командалық жол утилитасын жазыңыз. Пайдаланушы сандарды бір жолға (үтір не бос орынмен) енгізеді; бағдарлама саны, қосындысы, орташасы, медианасы, ең кішісі, ең үлкені және ауқымын есептейді.

Функционалдық талаптар

  • Кемінде үш функция: parse_numbers, stats (сөздік қайтарады), format_report.
  • Сенімді енгізу: бос жол, сан емес бөлік - құламай, нақты қазақша хабар және қайта сұрау.
  • Статистика стандартты функцияларсыз (sum/min/max/sorted-тан басқа) есептеледі; нәтиже statistics модулімен салыстырылып тексеріледі.
  • Шығыс f-жолдармен туралап, 2 таңбалы бөлшекпен.

Кезеңдер

  • 1. parse_numbers және оның тесттері.
  • 2. stats: әр шаманың функциясы.
  • 3. format_report.
  • 4. main: енгізу циклы және қате өңдеу.
  • 5. README және мысал сессиясы.

Қабылдау тесттері

  • '72, 85 64 90 78' → орташа 77.80, медиана 78.
  • Бос енгізу мен 'бес' сөзі бағдарламаны құлатпайды.
  • Әр функцияға кемінде 3 тест (assert не AO17 Judge).
  • Нәтижелер statistics.mean/median-мен сәйкес.
