AОқу мақсаттары

  • Python интерпретаторының бағдарламаны жоғарыдан төмен, жолма-жол орындайтынын түсіндіру.
  • print() арқылы мәтін мен сандарды шығару, бірнеше аргумент пен sep/end параметрлерін қолдану.
  • AO17 Judge-де бірінші тапсырманы орындап, тест нәтижесін оқу.

BАлғышарттар

  • Кескін мен дыбыстың цифрлық бейнесі

CҰғымға кіріспе

m04-те алгоритмдерді псевдокодпен жаздық. Енді оларды нағыз тілде - Python-да жазамыз. Python - интерпретацияланатын тіл: бағдарлама алдымен машина кодына толық аударылмайды, интерпретатор оны жолма-жол оқып орындайды.

AO17-де Python браузерде жұмыс істейді (Pyodide - WebAssembly-ге жиналған нағыз CPython). Бірінші рет жүктеу ~10 секунд алады, интернет керек. Компьютерге орнату үшін python.org-дан тегін нұсқасын алыңыз.

DАкадемиялық теория

Анықтама

print()

print(a, b, c) аргументтерді бос орынмен бөліп шығарады, соңында жаңа жол. sep= - бөлгіш, end= - соңғы таңба: print(1, 2, sep='-', end='!') → 1-2!.

Ескерту

Орындалу реті

Интерпретатор жолдарды жоғарыдан төмен орындайды. Қате жолға жеткенде тоқтайды да, Traceback (қате хабарын) шығарады - оның соңғы жолы қатенің түрін айтады (9-сабақ).

Теорема

print шығысының ұзындығы

print(s₁, ..., sₖ) (sep=' ', end='\n') шығаратын таңбалар саны: Σ len(str(sᵢ)) + (k − 1) + 1.

Дәлелдеу

Дәлелдеу

Әр аргумент str() арқылы жолға айналып, толық шығарылады: Σ len. Көршілес аргументтер арасына бір бөлгіш: k аргумент арасында k − 1 аралық. Соңында end - бір таңба. ∎

EКөрнекі түсіндірме

Нағыз Python. Кодты өзгертіп, «Іске қосу» басыңыз (бірінші рет Python жүктеледі).

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Мақсат: «Менің атым Айгүл, 16 жастамын.» шығару.
  2. Мәтін тырнақша ішінде: 'Менің атым Айгүл,'.
  3. Санды мәтінмен бірге print-ке бөлек аргумент ретінде береміз: print('Менің атым Айгүл,', 16, 'жастамын.').
  4. Нәтиже: «Менің атым Айгүл, 16 жастамын.» - аргументтер арасында бір бос орын.

HИнтерактивті эксперимент

sep пен end мәндерін өзгертіп, нәтижені болжаңыз да, тексеріңіз.

IЖаттығулар

JМатематикалық пайымдау

Неге тест шығысты ДӘЛ салыстырады («Сәлем, әлем!» ≠ «Сәлем, әлем»)? Себебі бағдарламаның шығысын көбіне басқа бағдарлама оқиды (m12): бір артық бос орын не нүкте оны бұзады. Дәлдік - бағдарламалаудың бірінші әдеті.

KЖиі қателер

  • Тырнақшаны жабуды ұмыту: print('Сәлем).
    Себебі: Python мәтіннің қай жерде аяқталатынын білмейді - SyntaxError.
    Түзету: Бір түрлі тырнақшамен ашып-жабыңыз: '...' не "...".
  • Print деп бас әріппен жазу.
    Себебі: Python бас/кіші әріпті ажыратады - NameError.
    Түзету: print - кіші әріппен.
