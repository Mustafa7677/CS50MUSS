06·03Python Foundations

Өрнектер және амалдар

  • негізгі

нұсқа 1.0.0 · тексеру: author-checked

Кино-түсіндіру: сабақтың өзегі бір минуттық мультфильмде. Мәтіні төменде.

Фильмнің мәтіні (сабақ қадамдарынан құрастырылған)
  1. Сұрақ. Python өрнектері математикаға ұқсас, бірақ ерекшеліктері бар. / әрқашан float: 7 / 2 = 3.5. // - бүтін бөлу (⌊⌋): 7 // 2 = 3, −7 // 2 = −4. % - қалдық, бөлгіштің таңбасымен: −7 % 2 = 1. ** - дәреже: 2 ** 10 = 1024.
  2. Жол. 1-қадам. Өрнек: 2 + 3 * 4 ** 2 // 5.
  3. Жол. 2-қадам. Алдымен **: 4 ** 2 = 16.
  4. Жол. 3-қадам. Сосын солдан оңға * және //: 3 * 16 = 48; 48 // 5 = 9.
  5. Жол. 4-қадам. Соңында +: 2 + 9 = 11.
  6. Түйін. Бөлу теңдігі Python-да. Кез келген бүтін a және b ≠ 0 үшін a == b * (a // b) + a % b.
  7. Түйін. Жиі қате: / бүтін береді деп ойлау. Дұрысы: Бүтін бөлу үшін //.

AОқу мақсаттары

  • Арифметикалық (+ − * / // % **), салыстыру (== != < <= > >=) және логикалық (and or not) амалдарды қолдану.
  • Амалдардың басымдығын білу: ** > унарлы − > * / // % > + − > салыстыру > not > and > or.
  • // және % арқылы бөлу теңдігін (m04 l03) Python-да тексеру.

BАлғышарттар

  • Айнымалылар және типтер

CҰғымға кіріспе

Python өрнектері математикаға ұқсас, бірақ ерекшеліктері бар. / әрқашан float: 7 / 2 = 3.5. // - бүтін бөлу (⌊⌋): 7 // 2 = 3, −7 // 2 = −4. % - қалдық, бөлгіштің таңбасымен: −7 % 2 = 1. ** - дәреже: 2 ** 10 = 1024.

Салыстыруды тізбектеуге болады: 0 < x < 10 - «0 < x және x < 10». Логикалық and/or m01 l10-дағы қысқа тұйықталумен жұмыс істейді.

DАкадемиялық теория

Теорема

Бөлу теңдігі Python-да

Кез келген бүтін a және b ≠ 0 үшін a == b * (a // b) + a % b.

Дәлелдеу

Дәлелдеу

Python анықтамасы бойынша a // b = ⌊a/b⌋ және a % b = a − b·⌊a/b⌋ (b > 0 үшін m04 l03; b < 0 үшін де ⌊⌋ анықтамасы сақталады, қалдық b-ның таңбасын алады). Демек b·(a // b) + a % b = b·⌊a/b⌋ + a − b·⌊a/b⌋ = a. ∎

Ескерту

Басымдық мысалы

-2 ** 2 = −4, себебі ** унарлы минустан күшті: −(2²). (−2) ** 2 = 4.

Анықтама

Құрама меншіктеу

x += 3 ≡ x = x + 3; x //= 2; x %= 10; т.б.

EКөрнекі түсіндірме

Бөлу теңдігі барлық таңба комбинациясында ақиқат.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Өрнек: 2 + 3 * 4 ** 2 // 5.
  2. Алдымен **: 4 ** 2 = 16.
  3. Сосын солдан оңға * және //: 3 * 16 = 48; 48 // 5 = 9.
  4. Соңында +: 2 + 9 = 11.

GЖұмыс мысалдары

HИнтерактивті эксперимент

Бұл бағдарлама санның цифрларын бөледі. Неге n // 10 % 10 - ондықтар цифры?

IЖаттығулар

JМатематикалық пайымдау

Неге Python // және % теріс сандарда ⌊⌋ қолданады (ал C нөлге қарай кеседі, m10)? Python таңдауы бөлу теңдігін сақтап, қалдықты әрқашан бөлгішпен бір таңбалы етеді - «сағат арифметикасы» (m03 l05, mod) үшін ыңғайлы: (−1) % 12 = 11.

KЖиі қателер

  • / бүтін береді деп ойлау.
    Себебі: Python 3-те / әрқашан float.
    Түзету: Бүтін бөлу үшін //.
  • -x ** 2 = x² деп санау.
    Себебі: ** унарлы минустан күшті.
    Түзету: (-x) ** 2 деп жақшалаңыз.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
