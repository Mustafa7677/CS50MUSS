while циклі

  • негізгі
  • ≈ 45 мин
  • 3 мақсат
  • 6 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

AОқу мақсаттары

  • while циклін жазып, оның шартын, денесін және аяқталуын (m04 l06 вариант) бақылау.
  • break және continue операторларының мағынасын түсіндіру.
  • Санақты (sentinel) циклмен белгісіз ұзындықтағы енгізуді өңдеу.

BАлғышарттар

  • Шартты операторлар

CҰғымға кіріспе

while шарт: - шарт ақиқат болғанша денені қайталау. Ол псевдокодтағы while-дың дәл көшірмесі (m04 l04). Цикл тоқтауы үшін денеде шартқа әсер ететін бір нәрсе өзгеруі керек - әйтпесе шексіз цикл (AO17 Judge оны қадам шегімен тоқтатады).

break циклдан бірден шығады, continue келесі айналымға өтеді.

DАкадемиялық теория

Анықтама

Санақты цикл (sentinel)

Кіріс арнайы мәнмен («0», «stop») аяқталады: while True: x = input(); if x == 'stop': break; ...

Теорема

Цифрлар қосындысы алгоритмінің аяқталуы

while n > 0: s += n % 10; n //= 10 - кез келген n ≥ 0 үшін ⌊log₁₀ n⌋ + 1 айналымда (n > 0) тоқтайды.

Дәлелдеу

Дәлелдеу

Вариант V = n: шарт ақиқат кезде n ≥ 1, ал n //= 10 оны қатаң кемітеді (n ≥ 1 үшін ⌊n/10⌋ < n). Демек цикл тоқтайды. Әр айналым бір цифрды алып тастайды, n-де ⌊log₁₀ n⌋ + 1 цифр бар. ∎

Ескерту

while vs for

Айналым саны алдын ала белгілі болса - for (7-сабақ). Шарт бойынша тоқтасақ - while.

EКөрнекі түсіндірме

Әр айналымда n бір цифрға қысқарады. Бұл - m04-тегі трасса кестесі, бірақ нағыз Python-да.

Интерактивті модель: өзің басқар

while циклының әр айналымында шарт қайта тексеріледі. Code X-Ray әр жолдан бұрынғы n мен steps мәнін көрсетеді - break қай сәтте орындалатынын көріңіз.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. Есеп: 1000 теңге салым жыл сайын 12% өседі. Неше жылда екі есе болады?
  2. money = 1000; years = 0; while money < 2000: money *= 1.12; years += 1.
  3. Вариант: 2000 − money кемиді, өйткені әр айналымда money ≥ 120-ға өседі.
  4. Нәтиже: 7 жыл (1.12⁷ ≈ 2.21 ≥ 2, ал 1.12⁶ ≈ 1.97 < 2).

GЖұмыс мысалдары

HИнтерактивті эксперимент

Енгізуге басқа сандар жазыңыз. 0-ді алып тастасаңыз не болады (Judge хабарын оқыңыз)?

IЖаттығулар

JМатематикалық пайымдау

while True + break стилі ыңғайлы, бірақ аяқталуын дәлелдеу қиындайды: тоқтау шарты цикл тақырыбында емес, денеде жасырын. Ережеміз: break шарты айқын болсын және вариант (не енгізу соңы) көрсетілсін.

KЖиі қателер

  • Цикл айнымалысын денеде өзгертпеу.
    Себебі: Шексіз цикл.
    Түзету: Әр айналымда вариант кемитінін тексеріңіз.
  • Санақты мәнді (0) де қосып жіберу.
    Себебі: Тексеріс қосудан кейін тұр.
    Түзету: Алдымен тексеру, сосын өңдеу.

LМеңгеруді бағалау

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
