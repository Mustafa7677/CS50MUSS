06·02Python Foundations

Айнымалылар және типтер

  • бастапқы
  • ≈ 40 мин
  • 3 мақсат
  • 6 тапсырма

нұсқа 1.0.0 · тексеру: author-checked

AОқу мақсаттары

  • Айнымалыны мәнге берілген атау (сілтеме) ретінде түсіндіру; = меншіктеу екенін, теңдік емес екенін білу.
  • int, float, str, bool типтерін ажырату және type() арқылы тексеру.
  • Типтерді түрлендіру: int(), float(), str(), bool() және олардың шектеулері.

BАлғышарттар

  • Python ортасы және бірінші бағдарлама

CҰғымға кіріспе

x = 5 - «x тең 5» емес, «x атауын 5 мәніне байла» (m04-тегі x ← 5). Сондықтан x = x + 1 мағыналы: оң жақ бұрынғы x-пен есептеліп, нәтиже x-ке беріледі.

Әр мәннің типі бар: 17 - int (бүтін), 3.14 - float (бөлшек, m05 l05), '17' - str (жол), True - bool. Тип амалдарды анықтайды: 17 + 1 = 18, ал '17' + '1' = '171'.

DАкадемиялық теория

Анықтама

Негізгі типтер

  • int - кез келген үлкендіктегі бүтін сан (Python-да шегі жоқ, m05 қосымша кодтан өзгеше).
  • float - IEEE 754 64 бит.
  • str - Unicode мәтін (m05 l06).
  • bool - True/False (int-тің ішкі түрі: True == 1).
Анықтама

Түрлендіру

int('42') = 42; int(3.9) = 3 (нөлге қарай кеседі); float('2.5') = 2.5; str(17) = '17'; bool(0) = False, bool('') = False, қалғандары True.

Теорема

int() кесуі

Нақты x үшін int(x) = ⌊x⌋ (x ≥ 0) және ⌈x⌉ (x < 0) - нөлге қарай дөңгелектеу. Бұл // амалынан (⌊⌋, m04 l03) өзгеше.

Дәлелдеу

Мысалмен көрсету

int(-3.7) = −3, ал −3.7 // 1 = −4.0. Екеуі де x ≥ 0 үшін бірдей, тек теріс сандарда айырмашылық бар - сондықтан «бүтін бөлігі» дегенде қай мағынаны қолданатынымызды нақты айту керек. ∎

EКөрнекі түсіндірме

Бір «17» - екі тип, екі түрлі мінез.

FҚадамдап қорыту

Анимациялық түсіндіру: қадамдар кезекпен ашылады. «Ойнату» не → пернесі.

  1. a = 10; b = a; a = a + 5.
  2. b = a - b атауы a-ның сол сәттегі мәніне (10) байланды.
  3. a = a + 5 - a жаңа мәнге (15) байланды, b өзгермейді.
  4. Нәтиже: a = 15, b = 10. (Тізімдерде бұл басқаша - m08 l02.)

GЖұмыс мысалдары

HИнтерактивті эксперимент

b-ны a-ның жаңа мәніне байлау үшін не өзгерту керек? int('3.5') не береді (тексеріңіз)?

IЖаттығулар

JМатематикалық пайымдау

Python динамикалық типті: айнымалының типі жоқ, мәннің типі бар. x = 5; x = 'бес' - рұқсат. Бұл ыңғайлы, бірақ қатені кешірек байқатады: 'бес' + 1 тек сол жол орындалғанда құлайды. C-да (m10) тип алдын ала жарияланады және компилятор ертерек тексереді.

KЖиі қателер

  • input() нәтижесін санмен қосу.
    Себебі: input әрқашан str қайтарады (4-сабақ).
    Түзету: int(input()) не float(input()).
  • = мен ==-ні шатастыру.
    Себебі: = меншіктеу, == салыстыру.
    Түзету: Шартта әрқашан ==.

Барлық сұраққа дұрыс жауап берсеңіз, сабақ «меңгерілді» деп белгіленеді. Тексеру браузерде өтеді: бұл оқу тексерісі, емтихан емес.
