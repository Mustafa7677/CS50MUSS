Шартты операторлар

Деңгей: негізгі · шамамен 45 мин · нұсқа 1.0.0 · тексеру: author-checked

AОқу мақсаттары

  • if / elif / else құрылымын жазып, шегіністің мағынасын түсіндіру.
  • Күрделі шарттарды логикалық амалдармен құрып, m01 заңдарымен ықшамдау.
  • Барлық тармақтарды тестпен жабу: әр шарттың шекаралық мәндерін тексеру.

BАлғышарттар

  • Енгізу және шығару

CҰғымға кіріспе

Python-да блок шегініспен белгіленеді (псевдокодтағы end-тің орнына): if-тен кейінгі қос нүкте және төрт бос орынмен жазылған жолдар - бір блок.

elif - «әйтпесе, егер». Тармақтар жоғарыдан төмен тексеріледі, бірінші ақиқат тармақ орындалады, қалғандары өткізіледі. Сондықтан шарттардың реті маңызды.

DАкадемиялық теория

Анықтама

Құрылым

if шарт1:
    ...
elif шарт2:
    ...
else:
    ...

Дәл бір тармақ орындалады (else бар болса).

Теорема

elif тізбегі - бөлу (m03 l05)

if c₁ / elif c₂ / ... / else тізбегі кірістер жиынын қиылыспайтын бөліктерге бөледі: i-ші тармақ ¬c₁ ∧ ... ∧ ¬cᵢ₋₁ ∧ cᵢ болғанда орындалады.

Дәлелдеу

Дәлелдеу

i-ші тармаққа жету үшін алдыңғылардың бәрі жалған болуы керек, ал оның өзі ақиқат. Екі түрлі i < j үшін j-ші шарт ¬cᵢ-ді талап етеді, ал i-ші cᵢ-ді - демек олар қиылыспайды. else бәрі жалған жағдайды қамтып, бірігуді толық етеді. ∎

Ескерту

Шекаралық тестілеу

Шарт x >= 50 болса, 49, 50, 51 мәндерін тексеріңіз - қателер жиі шекарада (> мен >= шатасуы).

EКөрнекі түсіндірме

Бағаны өзгертіңіз: 49, 50, 74, 75, 90. Шарттардың ретін ауыстырсаңыз не болады?

FҚадамдап қорыту

  1. Есеп: жыл кібісе ме? Ереже: 4-ке бөлінеді, бірақ 100-ге бөлінбейді, НЕМЕСЕ 400-ге бөлінеді.
  2. Логикалық формула: (y % 4 == 0 and y % 100 != 0) or y % 400 == 0.
  3. Тексеру: 2024 → иә; 1900 → 4-ке бөлінеді, 100-ге де, 400-ге емес → жоқ; 2000 → 400-ге → иә.
  4. Шекаралық мысалдар (1900, 2000) - ең маңызды тесттер.

GЖұмыс мысалдары

HИнтерактивті эксперимент

Бұл екі бөлек if. x = 5 үшін неше жол шығады? Оны бір if/elif/else тізбегіне қалай айналдырар едіңіз?

IЖаттығулар

JМатематикалық пайымдау

Тесттер саны туралы: grade функциясында 4 тармақ және 3 шекара бар. Әр тармаққа кемінде бір тест және әр шекараның екі жағына тест - 8 тест. Бұл «тармақты жабу» (branch coverage) идеясы (m08 l08).

KЖиі қателер

  • Шарттарды кішіден бастау (score >= 50 бірінші).
    Себебі: 95 те «C» алады - бірінші ақиқат тармақ.
    Түзету: Ең қатаң шарттан бастаңыз.
  • Шегіністі араластыру.
    Себебі: IndentationError не логикалық қате.
    Түзету: Әрқашан 4 бос орын.
