Мазмұны

    1-апта

    Шарттар, циклдер және әдістер

    Бағдарламаға шешім қабылдауды, қайталауды және әдістерге бөлуді үйретеміз: if, switch, while, for, өз әдістеріміз, overloading, рекурсия және varargs.

    Өткен аптаның қысқаша мазмұны

    0-аптада біз Java бағдарламасының жолын (.java → javac → .class → JVM), айнымалыларды, типтерді және операторларды қарастырдық. Осы уақытқа дейінгі бағдарламаларымыз жоғарыдан төмен қарай бір сызықпен жүретін. Бүгін оларға «ақыл» береміз: бағдарлама шешім қабылдайды, қайталайды және үлкен жұмысты әдістерге бөледі.

    Шарттар: if, else if, else

    Күнделікті өмірде біз үнемі шартпен сөйлейміз: «егер жаңбыр жауса, шатыр аламын, әйтпесе алмаймын». Java-да да солай. if жақшаның ішіндегі өрнектің boolean мәніне қарайды: true болса, бұйра жақшадағы блок орындалады.

    Нақты мысал: мұражай билетінің бағасы жасқа байланысты. 7 жасқа дейін - тегін, 18-ге дейін - 500 тг, 63-ке дейін - 1500 тг, одан үлкендерге - 700 тг (бұл бағалар шартты). Шарттар жоғарыдан төмен қарай тексеріледі, бірінші ақиқат шарт ғана орындалады, қалғаны өткізіліп жіберіледі.

    import java.util.Scanner;

public class Bilet {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Жасыңыз: ");
        int jas = sc.nextInt();

        int baga;
        if (jas < 7) {
            baga = 0;
        } else if (jas < 18) {
            baga = 500;
        } else if (jas < 63) {
            baga = 1500;
        } else {
            baga = 700;
        }
        System.out.println("Билет бағасы: " + baga + " тг");
    }
}
    $ javac Bilet.java
$ java Bilet
Жасыңыз: 15
Билет бағасы: 500 тг

    Бұл жерде jas = 15 болғанда бірінші шарт (15 < 7) жалған, екіншісі (15 < 18) ақиқат, сондықтан baga = 500, ал қалған шарттарға бағдарлама қарамайды. Сондықтан екінші шартта «jas >= 7 && jas < 18» деп жазудың қажеті жоқ: jas < 7 жалған екені алдын ала белгілі.

    Шарттың құрылымын сызбамен көрейік. Ромб - сұрақ, төртбұрыш - әрекет.

    Мәтіндік сипаттама: сызбада үш сұрақ бір-бірінің астында тұр. Әр «иә» оңға - сәйкес мәнді меншіктеуге апарады, әр «жоқ» төмен - келесі сұраққа. Үш сұрақтың үшеуі де жалған болса, else тармағы (700) орындалады. Бәрінің соңында бағдарлама бір жерге - билет бағасын шығаруға - қосылады.

    Бұйра жақшаны тастамаңыз

    Блокта тек бір нұсқау болса, жақшаны жазбауға болады: if (x > 0) y = 1;. Бірақ бұл қателікке жол ашады: кейін екінші жол қосқанда ол if-ке жатпайды, тек шегінісі соған ұқсайды. Әрқашан жақша қойыңыз.

    Логикалық операторлар және қысқа тізбек

    Күрделі шарт үшін && (және), || (немесе), ! (емес) операторларын қолданамыз. Класс мысалы - кәбісе жыл. Жыл кәбісе болады, егер ол 4-ке бөлінсе, бірақ 100-ге бөлінбесе, немесе 400-ге бөлінсе.

    public class KabisaJyl {
    static boolean kabisa(int jyl) {
        return (jyl % 4 == 0 && jyl % 100 != 0) || jyl % 400 == 0;
    }

    public static void main(String[] args) {
        System.out.println("1900: " + kabisa(1900));
        System.out.println("2000: " + kabisa(2000));
        System.out.println("2024: " + kabisa(2024));
        System.out.println("2025: " + kabisa(2025));
    }
}
    $ javac KabisaJyl.java
$ java KabisaJyl
1900: false
2000: true
2024: true
2025: false

    (Мұнда алдын ала бір static boolean kabisa(int jyl) әдісін қолдандық, оны осы аптаның соңында толық түсіндіреміз.) Енді қысқа тізбек (short-circuit evaluation) идеясы: A && B өрнегінде A жалған болса, B тіпті есептелмейді, себебі нәтиже бәрібір жалған. Сол сияқты A || B-де A ақиқат болса, B тексерілмейді. Бұл құрал өте пайдалы: ол қатеден қорғайды.

    public class QysqaTizbek {
    public static void main(String[] args) {
        int adam = 0;
        int top = 50;

        // Қауіпсіз: алдымен adam != 0 тексереміз
        if (adam != 0 && top / adam > 10) {
            System.out.println("Үлкен");
        } else {
            System.out.println("Бөлуге болмайды немесе кіші");
        }

        // Қауіпті: ретті ауыстырсақ, нөлге бөлу қатесі шығады
        if (top / adam > 10 && adam != 0) {
            System.out.println("Үлкен");
        }
    }
}

$ java QysqaTizbek

    Бірінші if қауіпсіз өтті: adam != 0 жалған болғандықтан, top / adam орындалмады. Екіншісінде шарттардың орнын ауыстырдық, ендеше нөлге бөлу алдымен орындалып, бағдарлама құлады. Қорытынды: қорғау шартын әрқашан алдымен жазыңыз.

    Мәтінді == арқылы салыстырмаңыз

    Мәтіндерді салыстыру үшін a.equals(b) қолданыңыз, ал a == b емес. == мәтіннің мазмұнын емес, оның жадтағы орнын (сілтемесін) салыстырады; нәтижесі күтпегендей болуы мүмкін. Себебін 2-аптада жад диаграммасымен көреміз, қазір ережені жаттап алыңыз: String үшін әрқашан equals.

    Үштік оператор: ?:

    Қарапайым таңдау үшін Java-да қысқа жазу бар: үштік оператор (ternary operator) шарт ? мән1 : мән2. Шарт ақиқат болса, мән1 алынады, әйтпесе мән2. Бұл if-else-тің өрнек түріндегі қысқа нұсқасы: нәтижені бірден айнымалыға салуға болады.

    public class Ushtik {
    public static void main(String[] args) {
        int jas = 20;
        String toby = jas >= 18 ? "ересек" : "бала";
        System.out.println(toby);

        int a = 14, b = 9;
        int ulken = a > b ? a : b;
        System.out.println("Үлкені: " + ulken);

        String kun = 1 == 1 ? "бір" : "бірнеше";
        System.out.println(kun);
    }
}

$ java Ushtik

бір

    Қысқа және түсінікті болғанда ғана қолданыңыз. Үштік операторларды бір-бірінің ішіне салсаңыз, код оқылмай қалады; ондай жағдайда әдеттегі if-else жақсы. Ереже: егер өрнекті дауыстап бір демде оқи алмасаңыз, оны if-ке айналдырыңыз.

    switch: көп таңдау

    Бір айнымалының көп мәніне қарай әрекет таңдау керек болса, if / else if тізбегі ұзарып кетеді. Сондай кезде switch ыңғайлы. Классикалық түрінде әр case соңында break болуы тиіс.

    public class AptaKuni {
    public static void main(String[] args) {
        int kun = 3;
        switch (kun) {
            case 1:
                System.out.println("Дүйсенбі");
                break;
            case 2:
                System.out.println("Сейсенбі");
                break;
            case 3:
                System.out.println("Сәрсенбі");
                break;
            default:
                System.out.println("Басқа күн");
        }
    }
}
    $ javac AptaKuni.java
$ java AptaKuni
Сәрсенбі

    Егер break-ті ұмытсақ, не болады? Java сәйкес келген case-тен бастап төмен қарай барлығын орындай береді, бұл құлау (fall-through) деп аталады. Көбіне бұл - қате:

    public class Qulau {
    public static void main(String[] args) {
        int kun = 3;
        switch (kun) {
            case 1:
                System.out.println("Дүйсенбі");
            case 2:
                System.out.println("Сейсенбі");
            case 3:
                System.out.println("Сәрсенбі");
            case 4:
                System.out.println("Бейсенбі");
                break;
            case 5:
                System.out.println("Жұма");
        }
    }
}
    $ javac Qulau.java
$ java Qulau

Бейсенбі

    Бір күн орнына екі күн шықты, себебі 3-ші case-те break жоқ. Кейде құлау әдейі қолданылады (бірнеше мәнге бір әрекет), бірақ Java 14-тен бері оның әлдеқайда қауіпсіз әрі қысқа жолы бар: switch өрнегі (switch expression). Ол көрсеткімен -> жазылады, құлау болмайды және нәтиже қайтара алады.

    public class Maysym {
    public static void main(String[] args) {
        for (int ay = 1; ay <= 12; ay += 3) {
            String maysym = switch (ay) {
                case 12, 1, 2 -> "қыс";
                case 3, 4, 5 -> "көктем";
                case 6, 7, 8 -> "жаз";
                case 9, 10, 11 -> "күз";
                default -> "белгісіз";
            };
            System.out.println(ay + "-ай: " + maysym);
        }

        int ay = 2;
        int kunSany = switch (ay) {
            case 4, 6, 9, 11 -> 30;
            case 2 -> {
                boolean kabisa = false;
                yield kabisa ? 29 : 28;     // блоктан мән қайтару: yield
            }
            default -> 31;
        };
        System.out.println("Ақпанда " + kunSany + " күн");
    }
}

    Ескеріңіз: бұл жерде алдымен біз for циклін қолдандық (оны төменде түсіндіреміз), ал case 12, 1, 2 - бірнеше мәнді үтірмен тізу. Көрсеткіден кейін не бір өрнек, не { ... } блок келеді; блоктан мәнді yield қайтарады. Switch өрнегі барлық мүмкін мәнді жабуы керек, сондықтан default жиі қажет. switch int, char, String және enum мәндерімен жұмыс істейді; double және boolean үшін жұмыс істемейді.

    Циклдер: while, do-while, for

    Қайталауды цикл (loop) дейді. Бес жүз қайталауды қолмен жазбаймыз: цикл оны өзі жасайды. Java-да үш негізгі цикл бар.

    while

    while әр айналым алдында шартты тексереді: ақиқат болса, денесін орындайды, сосын қайта тексереді. Шарт басынан жалған болса, дене бір рет те орындалмайды. Мысал: жинақ 100 000 тг, жыл сайын 10% артады; қанша жылда 200 000-ға жетеді?

    public class Jinaq {
    public static void main(String[] args) {
        double summa = 100000;
        int jyl = 0;

        while (summa < 200000) {
            summa = summa * 1.10;
            jyl++;
            System.out.printf("%d-жыл: %.0f тг%n", jyl, summa);
        }
        System.out.println("Жету үшін " + jyl + " жыл керек");
    }
}

    do-while

    do-while шартты соңында тексереді, сондықтан дене кемінде бір рет орындалады. Бұл қолданушының енгізуін тексеруге тамаша: алдымен сұрайсыз, сосын дұрыс емес болса, қайталайсыз.

    import java.util.Scanner;

public class DurysSan {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int san;
        do {
            System.out.print("1-10 аралығындағы сан: ");
            san = sc.nextInt();
        } while (san < 1 || san > 10);
        System.out.println("Қабылданды: " + san);
    }
}

    for

    Қайталау саны алдын ала белгілі болса, for ыңғайлы. Оның жақшасында үш бөлік бар, нүктелі үтірмен бөлінген: бастау (int i = 0), шарт (i < 5) және қадам (i++).

    Мәтінмен: бастау орындалады, шарт тексеріледі; ақиқат болса - дене, содан кейін қадам, және қайтадан шарт; жалған болса - цикл біткен. (Қадамның екінші сызбадағы дәл орны - дененің соңынан кейін, шартқа қайту алдында.)

    public class Kesteler {
    public static void main(String[] args) {
        // 7-нің көбейту кестесі
        for (int i = 1; i <= 5; i++) {
            System.out.println("7 x " + i + " = " + (7 * i));
        }

        // 1-ден 100-ге дейінгі қосынды
        int qosindy = 0;
        for (int i = 1; i <= 100; i++) {
            qosindy += i;
        }
        System.out.println("1+2+...+100 = " + qosindy);

        // кері санау, қадамы 2
        for (int i = 10; i > 0; i -= 2) {
            System.out.print(i + " ");
        }
        System.out.println();
    }
}

    i айнымалысының өмірі

    for (int i = ...) ішінде жарияланған i тек сол цикл ішінде ғана көрінеді. Циклден кейін оны қолдансаңыз, компилятор «символ табылмады» дейді. Мұны көрінетін аймақ (scope) деп төменде толық қарастырамыз.

    Ішкі циклдер

    Цикл ішіне басқа цикл жазуға болады. Сыртқы цикл бір айналғанда, ішкісі толық айналып шығады. Кесте мен жолдар-бағандар осылай жасалады. Мысал: қазақ оюларындағы сияқты ретті «мүйіз» үшбұрышы.

    public class Ushburysh {
    public static void main(String[] args) {
        int biikt = 5;
        for (int qator = 1; qator <= biikt; qator++) {
            for (int bos = 0; bos < biikt - qator; bos++) {
                System.out.print(" ");
            }
            for (int juldyz = 0; juldyz < 2 * qator - 1; juldyz++) {
                System.out.print("*");
            }
            System.out.println();
        }
    }
}

    Кеңейтілген for (for-each)

    Тізімнің әр элементін бір-бірлеп өту керек болса, индекс қажет емес. Кеңейтілген for (enhanced for, for-each) мұны қысқа жазады: for (тип элемент : жиын). Массивтерді 2-аптада толық қарастырамыз, қазір тек қарапайым түрін көреміз: { ... } ішінде мәндерді тізіп, массив жасауға болады.

    public class Aspaptar {
    public static void main(String[] args) {
        String[] aspaptar = {"домбыра", "қобыз", "сыбызғы", "шертер", "жетіген"};
        for (String a : aspaptar) {
            System.out.println("Қазақ аспабы: " + a);
        }

        double[] bagalar = {1250.0, 890.5, 2300.0, 450.0};
        double jalpy = 0;
        for (double b : bagalar) {
            jalpy += b;
        }
        System.out.println("Жалпы баға: " + jalpy + " тг");
    }
}

    Бұл оқылатын форма: «аспаптар ішіндегі әр a үшін ...». Бірақ ол элементті өзгерте алмайды және индексті бермейді; индекс керек болса, қарапайым for қолданамыз.

    break және continue

    break циклді бірден аяқтайды. continue ағымдағы айналымның қалғанын өткізіп, келесі айналымға өтеді.

    public class Toqtatu {
    public static void main(String[] args) {
        for (int i = 1; i <= 30; i++) {
            if (i % 3 != 0) {
                continue;           // 3-ке бөлінбесе, өткізіп жібереміз
            }
            if (i > 20) {
                break;              // 20-дан асқанда толық тоқтаймыз
            }
            System.out.print(i + " ");
        }
        System.out.println();
    }
}

    Цикл ізін кестемен қарау

    Цикл күрделі болып көрінгенде, бағдарламашылардың ескі әдісі бар: із кестесі (trace table). Қағазға әр айнымалы үшін баған сызып, әр айналымда мәндерін жазып отырасыз. Мысалы, жоғарыдағы жинақ мысалының басы былай көрінеді:

    2110000иә1210002

    Бұл кестені толтыру қателерді іздеуде жақсы көмек: бағдарлама шынымен не істеп жатқанын көресіз, ал сіз күткенді емес. Кейін System.out.println арқылы сол айнымалыларды шығарып қарау да осы идеяның бір түрі - оны «принт арқылы жөндеу» дейді.

    Әдістер

    Әдіс (method) - аты бар кодтың бөлігі. Бір рет жазып, көп рет шақырамыз. Әдіс - бағдарламаның «кірпіші»: үлкен мәселені кішкентай бөліктерге бөлеміз. Әдістің құрылымы:

    static   double   kdsQosu   (double baga, double paiz)   {  ...  return нәтиже;  }
// ^ модификатор  ^ қайтару   ^ ат      ^ параметрлер            ^ дене
    • Қайтару типі (return type) - әдіс нені қайтарады. Ештеңе қайтармаса, void.
    • Параметрлер (parameters) - әдіске беретін кіріс мәндері, тип пен атпен жазылады.
    • return мәнді қайтарып, әдістен шығады.
    • static - қазір «нысан жасамай шақыруға болады» деп түсінесіз; оның толық мағынасы 3-аптада.
    public class KdsEsep {
    // ҚҚС 12% қосылған баға
    static double kdsQosu(double baga) {
        return baga * 1.12;
    }

    static void salemdeu(String at) {
        System.out.println("Сәлем, " + at + "!");
    }

    static int ulkeni(int a, int b) {
        if (a > b) {
            return a;
        }
        return b;
    }

    public static void main(String[] args) {
        salemdeu("Нұрлан");
        double jana = kdsQosu(10000);
        System.out.println("ҚҚС-пен: " + jana);
        System.out.println("Үлкені: " + ulkeni(14, 9));
        System.out.println(ulkeni(ulkeni(3, 8), 5));   // әдіс ішінде әдіс
    }
}

    Әдіс не үшін керек? 1) қайталанбау (бір кодты көп рет жазбаймыз), 2) атау беру (kdsQosu деген ат кодтың мәнін айтады), 3) бөлек тексеру. Жақсы әдіс бір ғана іс істейді.

    Параметрлер мәнімен беріледі

    Java-да примитив типті параметр әдіске көшірме болып барады. Әдіс ішінде baga-ны өзгертсеңіз, сыртқы айнымалы өзгермейді. Объектілер мен массивтер үшін жағдай басқаша (сілтеме көшіріледі); оны 2- және 3-апталарда көреміз.

    Көрінетін аймақ (scope)

    Айнымалы өзі жарияланған { } блогында ғана өмір сүреді. Блоктан шыққан соң ол жоқ. Әдістің параметрлері мен ішкі айнымалылары тек сол әдісте көрінеді; екі әдісте бірдей аттас айнымалылар бір-біріне кедергі болмайды.

    public class Kerinis {
    static void esepte() {
        int ishki = 5;
    }

    public static void main(String[] args) {
        for (int i = 0; i < 3; i++) {
            int kvadrat = i * i;
        }
        System.out.println(kvadrat);   // блоктан шықтық
        System.out.println(ishki);     // басқа әдістің айнымалысы
        System.out.println(i);         // цикл айнымалысы
    }
}

    Әдісті қайта жүктеу (overloading)

    Java-да бір аттас бірнеше әдіс жазуға болады, егер олардың параметр тізімі (саны не типтері) әртүрлі болса. Мұны overloading (method overloading) дейді. Қайсысын шақыру керегін компилятор аргументтерге қарап таңдайды. Қайтару типі ғана әртүрлі болса, оның өзі жеткіліксіз.

    public class Audan {
    // шаршы
    static double audan(double qabyrga) {
        return qabyrga * qabyrga;
    }

    // тіктөртбұрыш
    static double audan(double eni, double uzyndygy) {
        return eni * uzyndygy;
    }

    // үшбұрыш: табан, биіктік және белгі
    static double audan(double taban, double biiktik, boolean ushburysh) {
        return 0.5 * taban * biiktik;
    }

    static String bagaMatin(int tenge) {
        return tenge + " тг";
    }

    static String bagaMatin(double tenge) {
        return String.format("%.1f тг", tenge);
    }

    public static void main(String[] args) {
        System.out.println(audan(4));
        System.out.println(audan(3, 5));
        System.out.println(audan(6, 4, true));
        System.out.println(bagaMatin(1500));      // int нұсқасы
        System.out.println(bagaMatin(1499.9));    // double нұсқасы
    }
}

    Рекурсия

    Рекурсия (recursion) - әдістің өзін-өзі шақыруы. Қазақ ертегісіндегі «ертегінің ішіндегі ертегі» немесе ішінен кішірек матрешка шығатын ойыншық сияқты: үлкен мәселені дәл сондай, бірақ кішірек мәселеге келтіреміз. Рекурсияның екі міндетті бөлігі бар:

    • базалық жағдай (base case) - тоқтайтын жер, жауабы тікелей белгілі;
    • рекурсивті қадам - мәселені кішірейтіп, өзін шақыру.

    Мысал - факториал: n! = n * (n-1)!, ал 0! = 1.

    public class Faktorial {
    static long faktorial(int n) {
        if (n <= 1) {                  // базалық жағдай
            return 1;
        }
        return n * faktorial(n - 1);  // рекурсивті қадам
    }

    static int sanQosindy(int n) {     // цифрлар қосындысы
        if (n < 10) {
            return n;
        }
        return n % 10 + sanQosindy(n / 10);
    }

    public static void main(String[] args) {
        System.out.println("5! = " + faktorial(5));
        System.out.println("10! = " + faktorial(10));
        System.out.println("20! = " + faktorial(20));
        System.out.println("Цифрлар қосындысы 2024: " + sanQosindy(2024));
    }
}

    Бұл қалай жұмыс істейді? faktorial(4) шақырылғанда, Java оны орындап бітіре алмайды: ол faktorial(3)-тің жауабын күтеді. Ол өз кезегінде faktorial(2)-ні күтеді, және т.с.с. Әр шақыру өзінің кадрын (stack frame) жасап, шақыру стегіне (call stack) қояды - тарелкалар тізбегі сияқты, жоғарғысы ғана жұмыс істейді.

    Сызбаның мәтіндік мәні: оңнан солға емес, төменнен жоғары қарай шақырулар қойылады (faktorial(4) → (3) → (2) → (1)); faktorial(1) базалық жағдай, ол 1 қайтарады. Сосын стек кері ашылады: 2 · 1 = 2, 3 · 2 = 6, 4 · 6 = 24.

    Базалық жағдайды ұмытсақ, не болады? Әдіс өзін шексіз шақырады, стек толады да, StackOverflowError шығады:

    public class Shek {
    static int tereng(int n) {
        return tereng(n + 1) + 1;     // базалық жағдай жоқ!
    }

    public static void main(String[] args) {
        System.out.println(tereng(0));
    }
}

    public class Fibonachchi {
    static int fib(int n) {
        if (n < 2) {
            return n;                       // fib(0)=0, fib(1)=1
        }
        return fib(n - 1) + fib(n - 2);
    }

    public static void main(String[] args) {
        for (int i = 0; i <= 10; i++) {
            System.out.print(fib(i) + " ");
        }
        System.out.println();
    }
}

    Айнымалы санды аргументтер (varargs)

    Кейде әдіске қанша аргумент берілетіні алдын ала белгісіз. Өзіңіздің qosyndy(1, 2), qosyndy(1, 2, 3, 4) түрлерін жеке жазбай, varargs (variable arguments) қолданамыз: типтен кейін үш нүкте .... Әдіс ішінде ол массив болып көрінеді.

    public class Qosyndy {
    static int qosyndy(int... sandar) {
        int jalpy = 0;
        for (int s : sandar) {
            jalpy += s;
        }
        return jalpy;
    }

    static double orta(String belgi, double... bagalar) {
        if (bagalar.length == 0) {
            return 0;
        }
        double jalpy = 0;
        for (double b : bagalar) {
            jalpy += b;
        }
        System.out.println(belgi + ": " + bagalar.length + " мән");
        return jalpy / bagalar.length;
    }

    public static void main(String[] args) {
        System.out.println(qosyndy());
        System.out.println(qosyndy(5));
        System.out.println(qosyndy(1, 2, 3, 4));
        System.out.println(orta("Кітап бағасы", 2500, 3100.5, 1800));
    }
}

    Ережелер: varargs параметр әдістің тізімінде соңғы болуы тиіс және біреу ғана болады. Нөл аргумент беруге де болады (бос массив). System.out.printf өзі де varargs қолданады: пішімнен кейін қанша мән берсеңіз де қабылдайды.

    Бәрін біріктіру: кітап дүкенінің чегі

    Тақырыптарды жеке-жеке білу жеткіліксіз, оларды біріктіре білу керек. Шағын кітап дүкенінің чегін жасайық: әр кітаптың аты, бағасы және саны бар; 5 данадан көп алсаңыз - 10% жеңілдік; әдістер мен цикл бәрін реттейді. Мұнда мынау істеледі: жеңілдік пайызы switch өрнегімен, жол сомасы бөлек әдіспен, барлығы for циклімен жиналады.

    public class KitapDukeni {
    // сатып алынған дана санына қарай жеңілдік (пайыз)
    static int jenildik(int sany) {
        return switch (sany) {
            case 1, 2, 3, 4 -> 0;
            case 5, 6, 7, 8, 9 -> 10;
            default -> 15;
        };
    }

    static double joldyngSomasy(double baga, int sany) {
        double zhalpy = baga * sany;
        return zhalpy - zhalpy * jenildik(sany) / 100;
    }

    public static void main(String[] args) {
        String[] atau = {"Абай жолы", "Қазақ ертегілері", "Алгоритмдер"};
        double[] baga = {3200, 1500, 8900};
        int[] sany = {2, 6, 1};

        double barlygy = 0;
        for (int i = 0; i < atau.length; i++) {
            double soma = joldyngSomasy(baga[i], sany[i]);
            System.out.printf("%-18s %2d дана  жеңілдік %2d%%  %9.2f тг%n",
                    atau[i], sany[i], jenildik(sany[i]), soma);
            barlygy += soma;
        }
        System.out.printf("Барлығы: %.2f тг%n", barlygy);
    }
}

    Бағдарлама бөлінген: jenildik - тек пайызды, joldyngSomasy - тек бір жолдың бағасын, main - тек жинақтауды біледі. Егер жеңілдік ережесі өзгерсе (мысалы, 20%), біз тек бір әдісті түзетеміз. Бұл - «кодты бөлшектеу» дегеннің нақты мағынасы. Массивтер (String[], double[], int[]) мұнда тек «көп мәнді бір жерде сақтау» үшін қолданылды, олармен жан-жақты жұмысты келесі аптада үйренеміз. Тағы бір көрнекі нәрсе - printf пішімдері: %-18s мәтінді 18 орынға солға тураланады, %9.2f - 9 орынға екі таңбалы бөлшек, %% - пайыз белгісінің өзі.

    Өз компьютеріңде іске қос

    Әр мысалды бөлек файлға көшіріп (Bilet.java, Jinaq.java ...), класс атына сай файл атын қойып, іске қосыңыз:

    javac Bilet.java && java Bilet
javac Faktorial.java && java Faktorial

    Кодты бір-екі жерде өзгертіп көріңіз: шартты бұзыңыз, break-ті алып тастаңыз, базалық жағдайды өшіріңіз. Қатені өз көзіңізбен көру - ең жақсы мұғалім.

    Басқару ағыны: қай құралды қашан таңдау керек

    Осы аптада үйренгеніміздің бәрі бір ғана ұғымға жиналады: басқару ағыны (control flow) - бағдарламаның қай жолдарды, қандай ретпен орындайтыны. Кез келген бағдарлама төрт құрылыс блогынан тұрады. Біріншісі - тізбектілік: жолдар жоғарыдан төмен қарай бірінен соң бірі орындалады. Екіншісі - тармақталу: шартқа қарай жолды таңдау (if, switch, ?:). Үшіншісі - қайталау: бір бөлікті бірнеше рет орындау (while, do-while, for). Төртіншісі - әдіс шақыру: басқаруды уақытша басқа жерге беріп, кері қайтару.

    Екі не үш жолдың бірін таңдауif / else if / else
    Бір айнымалының дәл мәніне қарай таңдауswitch (жаңа -> түрі)
    Бір мәнді шартқа қарай тез таңдаушарт ? a : b
    Қайталау саны алдын ала белгіліfor
    Шарт орындалғанша қайталау, саны белгісізwhile
    Кемінде бір рет орындау қажет (енгізуді тексеру)do-while
    Жиынның әр элементін аралаукеңейтілген for
    Қайталанатын жұмысты атау беруәдіс
    Мәселе өзіне ұқсас кіші мәселеге бөлінедірекурсия

    Бағдарлама жазбас бұрын қағазға ойша не істейтінімізді жазу пайдалы: қандай деректер кіреді, не шығады, қай жерде таңдау бар, қай жерде қайталау. Мұны псевдокод (pseudocode) дейді. Алдымен адамның тілімен жазасыз, сосын әр жолды Java-ға аударасыз. Мысалы, банкомат есебі: «әр номинал үшін: қанша купюра сыйса, соны алу; қалған соманы жаңарту». Көріп отырғаныңыздай, бұл бірден for + бүтін бөлу + қалдық екенін айтып тұр.

    Қатені қалай іздейміз?

    Шарттар мен циклдер қосылған кезде логикалық қателер жиі шығады. Үш қарапайым тәсіл: 1) із кестесі қағазда; 2) System.out.println арқылы аралық мәндерді шығару («мына жерде i = ...»); 3) тексеру мәндері - шеткі жағдайларды сынау (0, 1, ең үлкен мән, теріс сан). Қателердің басым бөлігі дәл шеткі жағдайларда жасырынады: циклдің бірінші және соңғы айналымында, шарттың шекарасында (> па, >= ма?).

    Бірнеше әдеттегі «қызыл жалауша»: шартта <= пен < араласуы, айнымалының басында бастапқы мәні жоқ болуы, бір әдісте тым көп іс істелуі, және ең бастысы - жазған кодты бір рет те іске қоспай «дұрыс болар» деп сену. Кішкентай бөлікті жазыңыз, бірден іске қосыңыз, жұмыс істесе ғана жалғастырыңыз.

    Жиі қателер

    1. if (x = 5). Салыстыруға == керек. Java мұны компиляцияда ұстайды, бірақ boolean айнымалымен if (ashyq = true) ұстамайды!
    2. break ұмыту классикалық switch-те: құлау. Жаңа -> түрін қолданыңыз.
    3. Шексіз цикл. while (i < 10) ішінде i-ді арттыруды ұмытсаңыз, бағдарлама тоқтамайды (терминалда Ctrl+C).
    4. Бір-біріне қатесі (off-by-one): i <= n мен i < n арасындағы айырмашылық бір қайталау.
    5. for жақшасынан кейінгі ;. for (...); денесін бос етіп қояды, ал келесі блок цикл емес болып қалады.
    6. Қайтаруды ұмыту. int әдісі барлық жолда return қайтаруы керек, әйтпесе «missing return statement».
    7. Рекурсияда базалық жағдайдың болмауы немесе мәселенің кішіремеуі: StackOverflowError.
    8. Бүтін бөлу. (a + b) / 2 бүтін болады; бөлшек керек болса, 2.0 жазыңыз.
    9. Айнымалының аймағы. Цикл ішінде жарияланған айнымалы сыртта жоқ.

    Қорытынды

    • if / else if / else жоғарыдан төмен тексеріп, бірінші ақиқат тармақты орындайды;
    • &&, || қысқа тізбекпен жұмыс істейді: қорғау шартын алдымен жазыңыз;
    • switch-тің классикалық түрінде break керек, ал жаңа -> түрі қауіпсіз және мән қайтара алады (yield);
    • while (алдымен тексереді), do-while (кемінде бір рет), for (санды қайталау), for-each (жиынды аралау);
    • break циклді аяқтайды, continue ағымдағы айналымды өткізеді;
    • әдіс: қайтару типі, ат, параметрлер, дене, return; айнымалы тек өз блогында көрінеді;
    • overloading: бір ат, әртүрлі параметрлер; рекурсия: базалық жағдай + кішірейген қадам; varargs: тип... ат.

    Келесі аптада деректердің көп мәнін бір жерде сақтауды (массивтер, ArrayList), мәтінмен тереңірек жұмысты және жадтың құрылымын үйренеміз.

    Өзіңізді тексеру тізімі

    • if / else if / else тізбегін жаза аламын және оның қалай тексерілетінін түсіндіре аламын
    • Классикалық switch пен switch өрнегінің айырмашылығын білемін
    • while, do-while және for циклдерінің қайсысын қашан таңдайтынымды білемін
    • Параметрі мен қайтару мәні бар әдіс жаза аламын
    • Overloading мен varargs-ты мысалмен түсіндіре аламын
    • Рекурсияда базалық жағдайдың рөлін түсінемін және стек кадрларын сызып көрсете аламын

    Өзіңізді тексеріңіз

    1. Мына код не шығарады?

    public class Q1 {
    public static void main(String[] args) {
        int n = 2;
        switch (n) {
            case 1: System.out.print("a");
            case 2: System.out.print("b");
            case 3: System.out.print("c"); break;
            case 4: System.out.print("d");
        }
        System.out.println();
    }
}

    n = 2 болғанда case 2-ден бастап орындалады; онда break жоқ, сондықтан case 3 де орындалып, сол жерде break тоқтатады: bc. Нақты нәтиже: bc.

    2. Мына switch өрнегі не береді?

    public class Q2 {
    public static void main(String[] args) {
        int x = 7;
        String r = switch (x % 3) {
            case 0 -> "нөл";
            case 1 -> "бір";
            default -> "басқа";
        };
        System.out.println(r);
    }
}

    7 % 3 = 1, сондықтан case 1 таңдалады. Көрсеткілі түрде құлау жоқ. Нақты нәтиже: бір.

    3. Цикл неше рет қайталанады және не шығарады?

    public class Q3 {
    public static void main(String[] args) {
        for (int i = 0; i < 10; i += 3) {
            System.out.print(i + " ");
        }
        System.out.println();
    }
}

    i мәндері: 0, 3, 6, 9; келесісі 12 < 10 емес, цикл тоқтайды. Нақты нәтиже: 0 3 6 9.

    4. Төмендегі әдіс жұбының қайсысы заңды overloading?

    Overloading-те аттары бірдей, параметр тізімі (саны не типтері) әртүрлі болуы тиіс. Тек қайтару типі немесе параметр аты әртүрлі болса, бұл - қайталанған жариялау қатесі. Соңғы нұсқада аттар әртүрлі, ол overloading емес.

    5. Мына әдіс компиляцияда қандай қате береді?

    static int belgi(int x) {
    if (x > 0) {
        return 1;
    } else if (x < 0) {
        return -1;
    }
}

    x == 0 болғанда әдіс ештеңе қайтармайды; компилятор барлық жолдың return-мен аяқталатынын талап етеді. Шешімі: соңғы else не әдіс соңында return 0;.

    6. f(4) нәтижесі қандай?

    public class Q6 {
    static int f(int n) {
        if (n == 0) {
            return 0;
        }
        return n + f(n - 1);
    }

    public static void main(String[] args) {
        System.out.println(f(4));
    }
}

    f(4) = 4 + 3 + 2 + 1 + 0 = 10. Базалық жағдай бар (n == 0), әр қадам n-ді кішірейтеді. Нақты нәтиже: 10.

    7. Ішкі циклдегі break қалай әсер етеді? Нәтижесі қандай?

    public class Q7 {
    public static void main(String[] args) {
        for (int i = 1; i <= 3; i++) {
            for (int j = 1; j <= 3; j++) {
                if (j == 2) {
                    break;
                }
                System.out.print(i * 10 + j + " ");
            }
        }
        System.out.println();
    }
}

    break тек ішкі циклді тоқтатады: әр i үшін тек j = 1 басылады (j = 2-де шығады). Сыртқы цикл жалғасады. Нақты нәтиже: 11 21 31.

    8. do-while циклі туралы қай тұжырым дұрыс? Мына кодта x неше рет шығады?

    public class Q8 {
    public static void main(String[] args) {
        int i = 10;
        do {
            System.out.print("x");
            i++;
        } while (i < 5);
        System.out.println();
    }
}

    do-while дененің бір рет орындалуына кепілдік береді. Бір x басылып, i = 11, шарт жалған - цикл аяқталады. Нақты нәтиже: x.

    Жаттығулар

    Алты жаттығу: әр деңгейден екіден. Бірнеше жауапты ойша есептеп, содан кейін өз компьютеріңде шынымен тексеріңіз.

    Оңай

    Цикл ізі

    Мына бағдарлама не шығарады?

    public class Jat1 {
    public static void main(String[] args) {
        int s = 0;
        for (int i = 1; i <= 5; i++) {
            if (i % 2 == 0) {
                continue;
            }
            s += i;
        }
        System.out.println(s);
    }
}

    Жауап - бір сан.

    Кеңес

    Кестеге жазыңыз: i = 1, 2, 3, 4, 5. Қайсысында continue орындалады?

    Шешімі

    continue жұп i (2 және 4) кезінде орындалады. Қосылатындар: 1 + 3 + 5 = 9.

    $ java Jat1
9
    Оңай

    Оқушы журналы: баға

    Baga.java жазыңыз: қолданушы орташа баллды (double) енгізеді, ал static String baga(double ball) әдісі мәтіндік баға қайтарады: 4,5 және жоғары - «өте жақсы (5)», 3,5-тен - «жақсы (4)», 2,5-тен - «қанағаттанарлық (3)», одан төмен - «қанағаттанарлықсыз (2)».

    Кеңес

    Шарттарды жоғарыдан төмен жазыңыз: if (ball >= 4.5) ... else if (ball >= 3.5) .... Әдіс әр тармақта return істейді.

    Шешімі

    Шешім:

    import java.util.Locale;
import java.util.Scanner;

public class Baga {
    static String baga(double ball) {
        if (ball >= 4.5) {
            return "өте жақсы (5)";
        } else if (ball >= 3.5) {
            return "жақсы (4)";
        } else if (ball >= 2.5) {
            return "қанағаттанарлық (3)";
        } else {
            return "қанағаттанарлықсыз (2)";
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        sc.useLocale(Locale.US);
        System.out.print("Орташа балл: ");
        double ball = sc.nextDouble();
        System.out.println("Баға: " + baga(ball));
    }
}
    $ java Baga
4.2
Орташа балл: Баға: жақсы (4)
    Өзін тексеру
    • 4.5 → өте жақсы (5)
    • 3.5 → жақсы (4)
    • 2.49 → қанағаттанарлықсыз (2)
    • Әдіс main-нен бөлек жазылған

    Орташа

    Рекурсивті әдіс

    Мына бағдарлама не шығарады?

    public class Jat3 {
    static int f(int n) {
        if (n <= 1) {
            return 1;
        }
        return f(n - 1) + f(n - 2);
    }

    public static void main(String[] args) {
        System.out.println(f(7));
    }
}
    Кеңес

    Кішіден бастаңыз: f(0) = f(1) = 1, содан f(2) = f(1) + f(0), f(3), ... f(7)-ге дейін кесте құрыңыз.

    Шешімі

    Тізбек: f(0)=1, f(1)=1, f(2)=2, f(3)=3, f(4)=5, f(5)=8, f(6)=13, f(7)=21. Тексерілген нәтиже:

    $ java Jat3
21
    Орташа

    Шаңырақ пирамидасы

    Биіктігі n болатын жұлдызшалы пирамида басыңыз: бірінші қатарда 1 жұлдызша, екіншіде 3, үшіншіде 5, ... Пирамида ортаға тураланған болсын. n = 6 үшін барлығы неше жұлдызша басылады? (Жауап - бір сан.)

    Кеңес

    Ішкі цикл екеу: біреуі бос орын (n - qator рет), екіншісі жұлдызша (2 * qator - 1 рет). Жалпы санды санауышпен тексеріңіз.

    Шешімі

    Қатарлар: 1, 3, 5, 7, 9, 11, қосындысы 36 (бұл - алғашқы 6 тақ санның қосындысы, яғни 6²).

    public class Pyramida {
    public static void main(String[] args) {
        int n = 6;
        int jalpy = 0;
        for (int qator = 1; qator <= n; qator++) {
            for (int b = 0; b < n - qator; b++) {
                System.out.print(" ");
            }
            for (int j = 0; j < 2 * qator - 1; j++) {
                System.out.print("*");
                jalpy++;
            }
            System.out.println();
        }
        System.out.println("Жұлдызша саны: " + jalpy);
    }
}
    $ java Pyramida
     *
    ***
   *****
  *******
 *********
***********
Жұлдызша саны: 36
    Өзін тексеру
    • Қатар саны n-ге тең
    • Әр қатар ортаға тураланған
    • n = 6 үшін 36 жұлдызша

    Қиын

    Коллатц қадамдары

    Натурал n санынан бастайық. Егер сан жұп болса, оны 2-ге бөлеміз, тақ болса, 3-ке көбейтіп 1 қосамыз. Осы әрекетті сан 1 болғанша қайталаймыз. Мысалы, 6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1 (8 қадам). n = 27 үшін неше қадам керек?

    Кеңес

    Қадам санау үшін int sanau керек. Цикл: while (n != 1). Үлкен аралық сандар үшін long қолданған дұрыс.

    Шешімі

    Әдіс:

    public class Kollatc {
    static int qadam(long n) {
        int sanau = 0;
        while (n != 1) {
            if (n % 2 == 0) {
                n = n / 2;
            } else {
                n = 3 * n + 1;
            }
            sanau++;
        }
        return sanau;
    }

    public static void main(String[] args) {
        System.out.println(qadam(6));
        System.out.println(qadam(27));
    }
}
    $ java Kollatc
8
111

    27 үшін 111 қадам (аралық ең үлкен мәні 9232).

    Қиын

    Банкомат: ең аз купюра

    Банкомат тенгені 20000, 10000, 5000, 2000, 1000, 500, 200 номиналды купюралармен береді. static int kupyura(int summa, int... nominaldar) әдісін жазыңыз: ол берілген соманы ең аз купюрамен береді (үлкен номиналдан бастап). 48500 тг үшін неше купюра керек?

    Кеңес

    Үлкен номиналдан бастап: sany += summa / nominal; сосын summa = summa % nominal;. Nominal тізімі үлкеннен кішіге реттелген деп есептеңіз.

    Шешімі

    Қолмен: 20000 × 2 = 40000, қалды 8500; 5000 × 1, қалды 3500; 2000 × 1, қалды 1500; 1000 × 1, қалды 500; 500 × 1. Барлығы 2 + 1 + 1 + 1 + 1 = 6. Код:

    public class Bankomat {
    static int kupyura(int summa, int... nominaldar) {
        int sany = 0;
        for (int nominal : nominaldar) {
            sany += summa / nominal;
            summa = summa % nominal;
        }
        return sany;
    }

    public static void main(String[] args) {
        int summa = 48500;
        int n = kupyura(summa, 20000, 10000, 5000, 2000, 1000, 500, 200);
        System.out.println(summa + " тг: " + n + " купюра");
    }
}
    $ java Bankomat
48500 тг: 6 купюра
    Өзін тексеру
    • 48500 → 6
    • 200 → 1
    • 1000 → 1
    • 35000 → 3 (20000 + 10000 + 5000)
