    Java-ға кіріспе

    Java бағдарламасы қалай жасалып, қалай жұмыс істейтінін түсініп, JDK орнатамыз да, алғашқы бағдарламаны жазамыз: айнымалылар, типтер, операторлар, Scanner арқылы енгізу және қателермен танысу.

    Бұл курс туралы

    Java курсы - сегіз аптаға арналған дербес авторлық курс. Алдын ала бағдарламалау білімі қажет емес: тек компьютерде жұмыс істей білсеңіз жеткілікті. Әр аптада түсіндірме, шынымен іске қосылған код мысалдары, терминал нәтижелері, жаттығулар мен тест бар. Барлық мысал Java 17 нұсқасына сай жазылған.

    Java деген не және неге оны үйренеміз?

    Java - 1995 жылы Sun Microsystems компаниясында (кейін оны Oracle сатып алды) жасалған бағдарламалау тілі. Содан бері ол ең көп қолданылатын тілдердің біріне айналды. Банктердің серверлері, Android қосымшалары, ойындар (Minecraft-тың классикалық нұсқасы Java-мен жазылған), үлкен компаниялардың ішкі жүйелері көбіне Java-мен жұмыс істейді. Қазақстандағы банк пен телеком салаларында да Java-мен жазатын мамандарға сұраныс үнемі жоғары.

    Java-ны үйренудің тағы бір артықшылығы бар: ол қатаң типтелген (statically typed) тіл. Яғни әр айнымалының не екенін (бүтін сан ба, мәтін бе) алдын ала айтуымыз керек, ал компилятор біздің қателерімізді бағдарлама іске қосылмай тұрып-ақ ұстап береді. Бастаушы үшін бұл - жақсы көмекші: қате «жасырынып» жүрмей, бірден көрінеді. Сонымен бірге Java сізді нысандық бағдарламалауға (object-oriented programming) табиғи түрде әкеледі, бұл тақырыпқа 3-аптадан бастап жете кірісеміз.

    Бұл апта - алғашқы қадам. Біз мыналарды үйренеміз:

    • Java бағдарламасы қалай жұмыс істейді: JDK, JRE, JVM және байт-код деген не;
    • өз компьютерімізге Java орнатып, алғашқы бағдарламаны жазу;
    • айнымалылар мен примитив типтер, операторлар, типтерді түрлендіру;
    • қолданушыдан Scanner арқылы деректі оқу;
    • қателердің екі түрі: компиляция кезіндегі және орындалу кезіндегі.

    JDK, JRE, JVM және байт-код

    Компьютердің процессоры тек өз «тілін» (машиналық кодты) түсінеді, ал Windows-тағы процессор мен телефондағы процессордың тілі әртүрлі. Көптеген тілдерде бағдарлама белгілі бір жүйе үшін ғана компиляцияланады: Windows үшін жасалған файлды macOS-та іске қосу мүмкін емес. Java мұны басқаша шешеді.

    Java-да жазылған код (.java файлы) алдымен компилятор (compiler) javac арқылы байт-кодқа (bytecode) айналады және .class файлына сақталады. Байт-код - нақты процессорға арналмаған, жалпы «аралық тіл». Содан кейін бұл файлды JVM (Java Virtual Machine, Java виртуалды машинасы) орындайды. JVM - әр жүйеге (Windows, macOS, Linux) бөлек жасалған бағдарлама: ол байт-кодты оқып, сол жүйенің процессорына түсінікті нұсқауларға аударып отырады.

    Міне, сондықтан Java-ның әйгілі ұраны бар: «бір рет жаз, барлық жерде іске қос» (Write Once, Run Anywhere). Бір .class файлын Windows-та да, Linux-та да, macOS-та да өзгертусіз іске қоса аламыз - тек әр жүйеде JVM орнатылған болса болды. Қазақ даласындағы киіз үйді (шаңырақ) елестетіңіз: оны қай жерде болса да жинап, құруға болады, себебі бөлшектері бірдей, ал құрастыру тәсілін жергілікті шебер біледі. Байт-код - сол бөлшектер, JVM - жергілікті шебер.

    Енді үш қысқартуды ажыратып алайық, олар жиі шатастырылады:

    • JVM - байт-кодты орындайтын виртуалды машина (бағдарламаны «жүргізуші»).
    • JRE (Java Runtime Environment) - Java бағдарламасын іске қосуға керек жиынтық: JVM және стандартты кітапханалар.
    • JDK (Java Development Kit) - бағдарлама жазуға арналған жиынтық: JRE, компилятор javac, және басқа құралдар. Біз бағдарламашымыз, сондықтан бізге JDK керек.

    Мәтіндік түрде: JDK-ның ішінде JRE бар, JRE-нің ішінде JVM бар. JDK-да қосымша javac компиляторы және құралдар бар. Сондықтан JDK орнатсаңыз, қалғаны өздігінен келеді.

    Java-ның нұсқалары

    Java жылына екі рет жаңарады, ал кейбір нұсқалар ұзақ қолдауға ие (LTS - Long-Term Support): 8, 11, 17, 21. Біз курста Java 17 мүмкіндіктерімен шектелеміз: олар 17-нің де, одан жаңа JDK-ның да ішінде жұмыс істейді. Сіздің компьютеріңізде 21 тұрса да, қорықпаңыз: бәрі бірдей жұмыс істейді.

    JDK орнату және жұмыс ортасы

    Бағдарлама жазу үшін екі нәрсе керек: JDK және мәтін жазатын орта. Алдымен JDK-ны орнатайық. Ең сенімді тегін нұсқалардың бірі - Eclipse Temurin (OpenJDK-ның жинағы). Басқа жинақтар (Oracle JDK, Microsoft Build of OpenJDK, Amazon Corretto) да жарайды.

    Windows

    Temurin 17 орнатқышын (.msi) жүктеп алыңыз да, орнатқанда «Set JAVA_HOME variable» және «Add to PATH» опцияларын қосыңыз. Содан соң жаңа терминал (PowerShell не Command Prompt) ашыңыз.

    macOS

    Homebrew бар болса, терминалға бір команда жеткілікті: brew install --cask temurin@17. Немесе .pkg орнатқышын жүктеп алуға болады.

    Linux

    Ubuntu мен Debian-да: sudo apt update && sudo apt install openjdk-17-jdk. Fedora-да: sudo dnf install java-17-openjdk-devel.

    Орнатқаннан кейін терминалда нұсқаны тексеріңіз. Екі команда жауап беруі керек: java (орындаушы) және javac (компилятор). Егер javac «табылмады» десе, сізде тек JRE бар, JDK емес.

    $ java -version
openjdk version "17.0.11" 2024-04-16
OpenJDK Runtime Environment Temurin-17.0.11+9 (build 17.0.11+9)
OpenJDK 64-Bit Server VM Temurin-17.0.11+9 (build 17.0.11+9, mixed mode, sharing)
$ javac -version
javac 17.0.11

    Нұсқа нөмірі мен жинақ аты сізде басқа болуы мүмкін, маңыздысы - 17 не одан жоғары екені.

    VS Code және IntelliJ IDEA

    Код жазуға Блокнот та жарайды, бірақ ыңғайлы код редакторы (code editor) немесе IDE (Integrated Development Environment, біріктірілген әзірлеу ортасы) әлдеқайда жақсы. Екі кең тараған таңдау бар:

    • Visual Studio Code - жеңіл, тегін редактор. Java-мен жұмыс үшін «Extension Pack for Java» кеңейтімін орнатасыз. Бастаушыға ыңғайлысы - терминал редактордың ішінде ашылады.
    • IntelliJ IDEA Community - Java-ға арналған күшті тегін IDE: қателерді жазып жатқанда көрсетеді, кодты өзі толықтырады. Жаңа жоба ашқанда JDK-ны таңдау жеткілікті.

    Курстың басында терминалдан javac және java командаларымен жұмыс істегенді ұсынамыз: сонда IDE «артында» не болып жатқанын түсінесіз. Кейін IDE-ге көшсеңіз, ол дәл осы командаларды сіздің орныңызға іске қосады.

    Алғашқы бағдарлама

    Бос қалта жасап, ішінде Main.java атты файл ашыңыз да, мына кодты жазыңыз:

    public class Main {
    public static void main(String[] args) {
        System.out.println("Сәлем, әлем!");
    }
}
    $ javac Main.java
$ java Main
Сәлем, әлем!

    Бұл тек үш жолдай көрінеді, бірақ әр сөздің мәні бар. Бір-бірден қарап шығайық.

    • public class Main - класс (class) жариялаймыз. Java-да барлық код кластың ішінде жазылады. public - класс барлық жерден көрінеді дегенді білдіреді.
    • Файл аты класс атына дәл сәйкес болуы керек: public class Main болса, файл Main.java. Әріп регистрі де маңызды: main.java жұмыс істемейді.
    • public static void main(String[] args) - main әдісі (main method), бағдарламаның кіру нүктесі. JVM бағдарламаны іске қосқанда дәл осы әдісті іздейді. Қазір бұл жолды «қасиетті ән» деп қабылдаңыз, оның әр сөзін келесі аптада және 3-аптада ашамыз.
    • System.out.println("...") - терминалға мәтін шығарады да, жаңа жолға өтеді. System.out - «стандартты шығару», println - «print line».
    • Әр нұсқаудың соңында нүктелі үтір ; тұрады. Қазақ тіліндегі нүкте сияқты: ол бір нұсқаудың аяқталғанын білдіреді.
    • Тұтас блок бұйра жақшамен { } шектеледі.

    Енді терминалда осы қалтада екі команда береміз: алдымен javac (компиляция), содан соң java (орындау). Атап өтейік, javac файл атын .java кеңейтімімен алады, ал java - тек класс атын, кеңейтімсіз.

    Қысқа жол: java Main.java

    Java 11-ден бастап бір файлдан тұратын бағдарламаны компиляциясыз-ақ іске қосуға болады: java Main.java. Ол компиляцияны артта өзі жасайды. Үйрену кезінде бұл өте ыңғайлы, бірақ екі қадамды (javac және java) түсіну маңызды, сондықтан біз әдетте екеуін де көрсетеміз.

    print, println және printf

    Шығарудың үш әдісі бар. println соңында жаңа жолға өтеді, print өтпейді, ал printf пішімдеп шығарады: %d - бүтін сан, %s - мәтін, %.2f - екі таңбалы ондық бөлшек, %n - жаңа жол. Арнайы таңбалар да бар: \n - жаңа жол, \t - табуляция, \" - тырнақша.

    public class Shygaru {
    public static void main(String[] args) {
        System.out.print("Алматы");
        System.out.print(", ");
        System.out.println("Астана");
        System.out.println("Бірінші жол\nЕкінші жол");
        System.out.println("Атауы:\t\"Домбыра\"");
        System.out.printf("Қала: %s, халқы: %d адам%n", "Шымкент", 1200000);
        System.out.printf("Сыйымдылық: %.2f литр%n", 2.5);
    }
}
    $ javac Shygaru.java
$ java Shygaru
Алматы, Астана
Бірінші жол
Екінші жол
Атауы:	"Домбыра"
Қала: Шымкент, халқы: 1200000 адам
Сыйымдылық: 2.50 литр

    Бір ескертпе: Java 17-де printf ондық бөлшекті компьютердің тіл баптауына (locale) қарай жазады. Кейбір жүйеде нүктенің орнына үтір шығуы мүмкін (2,50). Бұл қате емес, тек жергілікті әдет.

    Қазақша әріптер терминалда

    Кейбір Windows терминалдарында қазақша әріптер «?» не шимай болып шығады. Мұны chcp 65001 командасы (UTF-8 кодтауы) жиі түзетеді. Мәселе Java-да емес, терминалдың кодтауында. IDE ішіндегі терминалда әдетте бәрі дұрыс.

    Комментарийлер

    Комментарий (comment) - компилятор елемейтін, тек адамға арналған жазба. Java-да үш түрі бар: бір жолдық //, көп жолдық /* ... */ және құжаттама /** ... */ (оны кейін қарастырамыз).

    public class Pikir {
    /*
     * Бұл көп жолдық комментарий.
     * Компилятор мұны мүлде оқымайды.
     */
    public static void main(String[] args) {
        // Бұл бір жолдық комментарий
        System.out.println("Комментарий көрінбейді"); // жол соңында да болады
        // System.out.println("Бұл жол орындалмайды");
    }
}
    $ javac Pikir.java
$ java Pikir
Комментарий көрінбейді

    Жақсы комментарий не істейтінін емес, неге солай істегенін түсіндіреді. i = i + 1; // i-ге бірді қосамыз деген жазба пайдасыз, ал // ақпан 29 күн болуы мүмкін, жыл кәбісе деген пайдалы.

    Қателердің екі түрі

    Бағдарламашының өмірінің жартысы қатемен өтеді, оған ұялудың қажеті жоқ. Java-да қателер екі кезеңде шығады, оларды ажырату өте маңызды.

    Компиляция кезіндегі қателер

    Бұл - javac кодыңызды оқығанда табатын қателер: нүктелі үтір ұмыттыңыз, айнымалы атын қате жаздыңыз, типтер сәйкес келмеді. Бұл жағдайда .class файлы жасалмайды және бағдарлама мүлде іске қосылмайды. Көрейік: нүктелі үтірді әдейі түсіріп кетейік.

    public class Qate1 {
    public static void main(String[] args) {
        System.out.println("Сәлем")
    }
}
    $ javac Qate1.java
Qate1.java:3: error: ';' expected
        System.out.println("Сәлем")
                                   ^
1 error

    Компилятор бізге файл атын, жол нөмірін, қатенің сипатын және нақты орнын (^ белгісімен) көрсетті. Бұл хабарды оқуға үйреніңіз: ол сізге жау емес, көмекші. Қате хабары көбіне жолдың өзін емес, оның алдыңғы жолын айыптайды, себебі компилятор «осы жерде бір нәрсе жетіспейді» деп жаңа ғана түсінеді. Тағы бір мысал: типтер сәйкес келмеген кезде.

    public class Qate2 {
    public static void main(String[] args) {
        int jas = "он бес";
        int pi = 3.14;
        System.out.println(jas + pi);
    }
}
    $ javac Qate2.java
Qate2.java:3: error: incompatible types: String cannot be converted to int
        int jas = "он бес";
                  ^
Qate2.java:4: error: incompatible types: possible lossy conversion from double to int
        int pi = 3.14;
                 ^
2 errors

    int бүтін сан сақтайды, ал біз оған мәтінді мен ондық бөлшекті салғалы тұрмыз. Java мұны іске қосқанға дейін тоқтатады. Бұл Java-ның қатаң типтелуінің пайдасы: қате кодтың жұмыс істеуіне мүмкіндік бермейді.

    Орындалу кезіндегі қателер

    Екінші түрі - код компиляциядан өтті, бағдарлама іске қосылды, бірақ жұмыс үстінде бір нәрсе бұзылды. Мұндайды орындалу қатесі (runtime error) не ерекше жағдай (exception) дейді. Мысалы, бүтін санды нөлге бөлу:

    public class Qate3 {
    public static void main(String[] args) {
        int adam = 120;
        int top = 0;
        System.out.println("Бөлудің алдында");
        System.out.println(adam / top);
        System.out.println("Бөлудің кейін");
    }
}
    $ javac Qate3.java
$ java Qate3
Бөлудің алдында
Exception in thread "main" java.lang.ArithmeticException: / by zero
	at Qate3.main(Qate3.java:6)

    Назар аударыңыз: «Бөлудің алдында» жолы шықты, яғни бағдарлама жұмыс істей бастады, бірақ нөлге бөлу сәтінде ArithmeticException лақтырылып, бағдарлама тоқтады. Соңғы жол ешқашан шықпады. Хабардағы at Qate3.main(Qate3.java:6) - қателік 6-жолда болғанын білдіреді. Бұл тізбекті стек трассасы (stack trace) дейді.

    Айнымалылар және примитив типтер

    Айнымалы (variable) - атауы бар жад «ұяшығы». Java-да ұяшықты жариялағанда оның типін көрсетеміз: ұяшықта не сақталатынын және қанша орын алатынын. Жариялау үлгісі: тип атау = мән;.

    Java-да сегіз примитив тип (primitive types) бар. Басында бесеуін білу жеткілікті:

    int толып кетсе не болады?

    int-тің көлемі шектеулі: ең үлкені 2 147 483 647. Одан асырсақ, қате шықпайды: сан дөңгелек сағат сияқты кері айналып, ең кіші мәннен қайта басталады. Мұны толып кету (overflow) дейді.

    Java int толғанда ескертпейді: ол жай ғана теріс сан береді. Ақша мен үлкен санаулар (халық, байт, миллисекунд) үшін long қолданыңыз. Ақшаның тиын-тиыны маңызды болса, double да сенімсіз, оған кейін BigDecimal бар, ал бастапқы кезеңде тенгені long-пен санаған дұрыс.

    var: тип автоматты анықталады

    Java 10-нан бастап локалды айнымалыны жариялағанда типті жазбай, var деп жаза аламыз. Компилятор типті оң жақтағы мәннен өзі табады. Бұл «динамикалық» тип емес: тип бәрібір бекітіледі, тек оны өзіңіз жазбайсыз.

    public class VarMysal {

        var jol = true;                // boolean

        System.out.println(qala + " " + adam + " " + bagam + " " + jol);
        // adam = "көп";    // қате болар еді: adam - int
    }

    var тек локалды айнымалыға және бірден мән бергенде жұмыс істейді (var x; деп жазуға болмайды). Бастаушыға кеңес: алғашқы аптада типті ашық жазғаныңыз жөн, сонда типтерді ойша «көресіз». var-ды кейін, тип көрініп тұрған жерде қолданыңыз.

    Айнымалыларға ат беру

    Java-да ат қою ережелері бар. Ат әріптен, _ не $ белгісінен басталады, цифрмен басталмайды; бос орын болмайды; кілт сөздер (class, int, new ...) атау бола алмайды. Регистр маңызды: adam мен Adam - екі бөлек айнымалы. Қабылданған келісім (convention): айнымалы мен әдіс атаулары camelCase (qalaHalqy), кластар PascalCase (KitapDukeni), тұрақтылар БАС_ӘРІППЕН (MAX_JAS) жазылады. Атау мағыналы болсын: x емес, halyq.

    Тұрақты мәнді final кілт сөзімен жарияласақ, оны өзгертуге болмайды: final double KDS = 0.12;.

    String: мәтінмен алғашқы танысу

    String - мәтін жолы. Ол примитив емес, класс, сондықтан оның әдістері бар (оларды нүкте арқылы шақырамыз). 2-аптада String-ті терең қарастырамыз, ал қазір ең қажетті бес әдісті көрейік.

    public class MatinMysal {

    Негізгі қағида: индекстер нөлден басталады. Бірінші таңба - 0-ші, соңғысы - length() - 1-ші. Бұл Java-да (және көп тілде) жалпы ереже. substring(0, 4) төртінші индекске дейін алады, оның өзін қоспайды.

    Мәтінді жалғағанда + сандармен араласса, абай болыңыз: Java оператормен солдан оңға қарай жүреді. 1 + 2 + "3" нәтижесі "33" (алдымен 1+2=3, сосын жалғау), ал "3" + 1 + 2 нәтижесі "312". Бұл тест сұрақтарының бірінде кездеседі.

    Операторлар

    Оператор - әрекет белгісі. Арифметикалық операторлар: + - * / %. Соңғысы % - қалдық (modulo): 17 % 5 нәтижесі 2. Ең үлкен таңқаларлық нәрсе - бүтін санды бөлу: екі бүтін сан бөлінсе, нәтиже де бүтін болады, бөлшек бөлігі тасталады (дөңгелектелмейді).

    public class Operatorlar {
    public static void main(String[] args) {
        System.out.println(17 / 5);        // бүтін бөлу
        System.out.println(17 % 5);        // қалдық
        System.out.println(17 / 5.0);      // біреуі double болса, нәтиже double
        System.out.println(2 + 3 * 4);     // көбейту алдымен
        System.out.println((2 + 3) * 4);   // жақша алдымен

        int sany = 10;
        sany += 5;      // sany = sany + 5
        sany *= 2;      // sany = sany * 2
        sany++;         // 1-ге арттыру
        System.out.println(sany);

        System.out.println(7 > 3);                 // салыстыру
        System.out.println(7 == 3);
        System.out.println(5 != 3 && 2 < 1);       // және
        System.out.println(5 != 3 || 2 < 1);       // немесе
        System.out.println(!(5 > 3));              // емес
    }
}

    Операторлар тобы:

    • арифметикалық: + - * / %;
    • меншіктеу: =, және қысқа түрлері += -= *= /= %=; x++ пен x-- мәнді 1-ге арттырады/азайтады;
    • салыстыру: == != < > <= >= нәтижесі - boolean;

    Есіңізде болсын: = мән меншіктейді, ал == мәндерді салыстырады. Екеуін шатастыру - бастаушылардың классикалық қатесі.

    Басымдық: алдымен жақша, сосын * / %, сосын + -, сосын салыстыру, сосын &&, сосын ||. Күмән болса, жақша қойыңыз: ол код оқуға да көмектеседі.

    Типтерді түрлендіру

    Кейде бір типті екіншісіне айналдыру керек. Java екі бағытты ажыратады.

    Кеңейту (widening) - кішіден үлкенге (int → long → double). Ақпарат жоғалмайды, сондықтан Java мұны автоматты жасайды. Тарылту (narrowing) - үлкеннен кішіге (double → int). Мұнда ақпарат жоғалуы мүмкін (бөлшек бөлігі, көлем), сондықтан Java сізден анық келісім сұрайды: типті жақшамен жазасыз, мұны casting (type casting) дейді.

    public class Turlendiru {
    public static void main(String[] args) {
        int a = 7;
        double b = a;                   // кеңейту, автоматты
        System.out.println(b);

        double bagam = 470.99;
        int butin = (int) bagam;        // тарылту: бөлшек ТАСТАЛАДЫ
        System.out.println(butin);

        int bol1 = 7 / 2;               // 3
        double bol2 = 7 / 2;            // 3.0 (бөлу әлі int-пен болды!)
        double bol3 = 7 / 2.0;          // 3.5
        double bol4 = (double) 7 / 2;   // 3.5
        System.out.println(bol1 + " " + bol2 + " " + bol3 + " " + bol4);

        long kop = 3000000000L;
        System.out.println((int) kop);  // сыймайды, мән бұрмаланады

        char c = 'A';
        System.out.println(c + 1);          // int болып кетеді
        System.out.println((char) (c + 1)); // қайта char
        System.out.println((int) 'a');
    }
}

    Ең басты сабақ - төртінші жол: double bol2 = 7 / 2; нәтижесі 3.0. Неге? Себебі Java алдымен оң жақты есептейді (7 / 2 екеуі де int, нәтиже 3), содан кейін ғана 3-ті double-ға айналдырады. Оң жақтағы өрнек сол жақтағы типке қарамайды. Бөлшек нәтиже керек болса, операндтардың кемінде біреуі double болуы тиіс: 7 / 2.0 не (double) 7 / 2. Жақшамен casting бөлуден бұрын орындалатынын ескеріңіз.

    Scanner: қолданушыдан енгізу

    Бағдарлама тек өзі есептеп қоймай, адаммен «сөйлесуі» керек. Енгізуді оқу үшін java.util пакетіндегі Scanner класы бар. Оны қолдану үшін үш қадам: 1) файлдың басына import java.util.Scanner; жазамыз, 2) new Scanner(System.in) арқылы нысан жасаймыз (System.in - пернетақта), 3) nextInt(), nextDouble(), nextLine() әдістерін шақырамыз.

    Алғашқы нақты бағдарламамыз - тенге калькуляторы: доллар сомасын теңгеге айналдырады. Курс шартты болсын: 1 доллар = 470 теңге.

    import java.util.Locale;
import java.util.Scanner;

public class TengeKalkulyator {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        sc.useLocale(Locale.US);            // ондық нүктені дұрыс оқу үшін
        final double BAGAM = 470.0;         // шартты бағам: 1 USD = 470 тг

        System.out.print("Доллар сомасы: ");
        double dollar = sc.nextDouble();

        double tenge = dollar * BAGAM;
        System.out.printf("%.2f USD = %.2f тг%n", dollar, tenge);
        sc.close();
    }
}

    Неге useLocale?

    Scanner сандарды компьютердің тіл баптауына сай оқиды. Егер жүйе орыс не қазақ аймағына орнатылған болса, ондық бөлгіш үтір болып, 25.5 жазсаңыз InputMismatchException шығады. sc.useLocale(Locale.US) нүктені әрқашан қабылдайтын етеді. Бұл бағдарламаны тұрақты қылады.

    Scanner-дің негізгі әдістері: nextInt() - бүтін сан, nextDouble() - ондық бөлшек, next() - бір сөз (бос орынға дейін), nextLine() - бүтін жол (Enter-ге дейін). Енді бірнеше тип араласатын мысал: қала аты, халқы және өсім пайызы.

    import java.util.Locale;
import java.util.Scanner;

public class QalaHalqy {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        sc.useLocale(Locale.US);

        System.out.print("Қала аты: ");
        String qala = sc.nextLine();
        System.out.print("Халқы: ");
        int halyq = sc.nextInt();
        System.out.print("Жылдық өсім (%): ");
        double osim = sc.nextDouble();

        int kelesiJyl = (int) (halyq * (1 + osim / 100));
        System.out.println(qala + ": келесі жылы шамамен " + kelesiJyl + " адам");
    }
}

    nextInt() және nextLine() тұзағы

    Бұл - Java-дағы ең танымал «құпия». nextInt() санды оқиды, бірақ санның артынан келетін Enter таңбасын (жаңа жол) оқымай қалдырады. Содан кейін nextLine() шақырсақ, ол сол қалған бос жолды ғана алып, бос мәтін қайтарады да, бағдарлама бізден жауап күтпей кете барады. Көрейік:

    import java.util.Scanner;

        System.out.print("Атыңыз: ");
        String at = sc.nextLine();          // бос жол оқылады!

    import java.util.Scanner;

public class TuzaqTuzetu {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Жасыңыз: ");
        int jas = sc.nextInt();
        sc.nextLine();                      // қалған Enter-ді жұтамыз
        System.out.print("Атыңыз: ");
        String at = sc.nextLine();
        System.out.println("Аты: [" + at + "], жасы: " + jas);
    }
}
    $ javac TuzaqTuzetu.java
$ java TuzaqTuzetu
19
Жасыңыз: Атыңыз: Әлия
Аты: [Әлия], жасы: 19

    Ұсыныс: бір бағдарламада сан мен жолды араластыру қажет болса, барлығын nextLine() арқылы жол ретінде оқып, сосын Integer.parseInt(...) арқылы санға айналдырыңыз. Бұл тұзақтан толық құтылдырады.

    Өз компьютеріңде іске қос

    1. Бос қалта жасаңыз: mkdir java-kurs && cd java-kurs.
    2. Редактормен Main.java файлын ашып, алғашқы бағдарламаны жазыңыз.
    3. Терминалда: javac Main.java. Қате болмаса, ештеңе шықпайды, бірақ Main.class жасалады (ls не dir арқылы тексеріңіз).
    4. Іске қосу: java Main.
    5. Қате шықса, хабарды оқыңыз: жол нөмірі мен ^ белгісі сізге қайда қарау керегін көрсетеді.
    javac Main.java && java Main
# немесе компиляциясыз қысқа жол:
java Main.java

    Суретті мәтінмен айтсақ: byte 1 байт, short және char 2 байт, int 4 байт, long мен double 8 байт алады. Тип неғұрлым үлкен болса, соғұрлым көбірек мән сыйғызады.

    Жиі қателер

    1. Файл аты мен класс аты сәйкес емес. public class Main болса, файл тек Main.java. Хабар: class Main is public, should be declared in a file named Main.java.
    2. java командасына .class не .java қосып жазу. java Main.class қате; дұрысы java Main.
    3. Нүктелі үтірді ұмыту (;) немесе жақшаны жаппау. Қате хабары келесі жолға сілтеуі мүмкін.
    4. Бүтін бөлу. 5 / 2 нәтижесі 2, 2.5 емес. Орташа есептегенде (a + b) / 2.0 жазыңыз.
    5. = мен == шатастыру.
    6. Регистр. system.out.println (кіші s) жұмыс істемейді: System бас әріппен.
    7. Қос пен жалғыз тырнақша. char c = "A"; - қате. Бір таңбаға 'A', мәтінге "A".
    8. nextInt()-тен кейін nextLine(). Жоғарыда қарастырылған бос жол тұзағы.
    9. int толуы. Үлкен санды int-ке салмаңыз; long қолданыңыз және литералға L жазыңыз.

    Қорытынды

    Бұл аптада біз Java әлеміне алғашқы қадамымызды жасадық. Не үйрендік:

    • Java коды javac арқылы байт-кодқа айналады, оны JVM орындайды; сондықтан «бір рет жаз, барлық жерде іске қос»;
    • JDK - жазу құралдары, JRE - іске қосу ортасы, JVM - виртуалды машина;
    • бағдарлама public class Main ішіндегі public static void main(String[] args) әдісінен басталады, файл аты класс атына тең;
    • System.out.println, print, printf арқылы шығарамыз; комментарийлер // және /* */;
    • компиляция қатесі бағдарламаны іске қосқызбайды, орындалу қатесі жұмыс үстінде шығады, логикалық қатені тек біз табамыз;
    • примитив типтер: int, long, double, boolean, char; String - класс; var типті өзі табады;
    • бүтін бөлу бөлшегін тастайды; (int) типін тарылтады; int толып кетуі мүмкін;
    • Scanner арқылы nextInt, nextDouble, nextLine оқимыз және nextInt-тен кейінгі бос жол тұзағын білеміз.

    Келесі аптада бағдарламаға «шешім қабылдауды» (if, switch), қайталауды (for, while) және өз әдістерімізді жазуды үйретеміз.

    Өзіңізді тексеру тізімі

    • JDK орнатып, java -version және javac -version командаларын іске қостым
    • Алғашқы Main.java бағдарламасын өзім жазып, компиляциялап, іске қостым
    • JDK, JRE және JVM айырмашылығын өз сөзіммен айта аламын
    • Компиляция және орындалу қателерін ажырата аламын
    • int бөлуі неге бөлшекті тастайтынын түсіндіре аламын
    • Scanner арқылы сан мен жолды оқып, nextLine() тұзағын айналып өте аламын

    Өзіңізді тексеріңіз

    1. Java бағдарламасын әр жүйеде (Windows, macOS, Linux) өзгертусіз іске қосуға мүмкіндік беретін құрамдас қайсы?

    Байт-код жүйеге тәуелсіз, ал оны әр жүйенің өз JVM-і сол жүйенің процессорына арнап орындайды. javac тек бастапқы кодты байт-кодқа аударады.

    2. Мына жол не шығарады?

    System.out.println(10 / 4);

    Екі операнд та int, сондықтан бөлу бүтін болады да, бөлшек бөлігі (0,5) тасталады: нәтиже 2.

    3. Мына бағдарлама не шығарады?

    public class Jalgau {
    public static void main(String[] args) {
        System.out.println(1 + 2 + "3" + 4 + 5);
    }
}

    Солдан оңға: 1 + 2 = 3, сосын 3 + "3" мәтінге айналып "33", одан әрі жалғау жалғасып "3345" шығады. Нақты нәтиже: 3345.

    4. Қай жол компиляция қатесін береді?

    double-ды int-ке автоматты салуға болмайды (ақпарат жоғалады). Дұрысы: int z = (int) 3.7;. Қалған үшеуі заңды: кеңейту не дәл сәйкес тип.

    5. javac Main.java командасының нәтижесі не?

    javac - компилятор: ол .java файлын .class байт-код файлына айналдырады. Іске қосуды java Main орындайды.

    6. Мына код не шығарады?

    public class Tanba {
    public static void main(String[] args) {
        char c = 'A';
        c += 2;
        System.out.println(c);
    }
}

    c += 2 қысқа жазу ішінде автоматты (char) casting жасайды: 'A' (65) + 2 = 67, ол - 'C'. Нақты нәтиже: C.

    7. Мына код не істейді?

    public class Sheksiz {
    public static void main(String[] args) {
        System.out.println(5.0 / 0);
    }
}

    Нөлге бөлу қатесі тек бүтін бөлуде болады. double бөлуінде нәтиже Infinity болады. Нақты нәтиже: Infinity.

    8. int jas = sc.nextInt(); String at = sc.nextLine(); жазылса және алдымен «19», Enter басылса, at не болады?

    nextInt() Enter таңбасын оқымай қалдырады, сондықтан nextLine() бірден сол қалдықты (бос жолды) алады. Шешімі - араға қосымша sc.nextLine(); қою.

    Жаттығулар

    Алты жаттығу: екі оңай, екі орташа, екі қиын. Нәтижесі бар жауаптарды ойша есептеп, содан кейін өз компьютеріңде тексеріңіз.

    Оңай

    Бөлу тізбегі

    Мына өрнек не шығарады?

    System.out.println(7 / 2 * 2.0);

    Нәтижені дәл жазыңыз (ондық бөлшегімен).

    Кеңес

    Амалдарды солдан оңға қарай орындаңыз. 7 / 2 - екі int. Содан кейін нәтиже 2.0-ге көбейтіледі.

    Шешімі

    7 / 2 = 3 (бүтін бөлу), 3 * 2.0 = 6.0. Тексерілген нәтиже: 6.0.

    Оңай

    Менің визиткам

    Vizitka.java бағдарламасын жазыңыз: ол үш айнымалыны (аты-жөні String, қала String, жасы int) жариялап, println және printf арқылы үш жолдық визитка шығарсын. Өз деректеріңізді қолданыңыз.

    Кеңес

    Файл аты класс атына сай болуы керек: public class Vizitka. Мәтінге %s, бүтін санға %d, жаңа жолға %n қолданыңыз.

    Шешімі

    Мысал шешім:

    public class Vizitka {
    public static void main(String[] args) {
        String at = "Айгүл Сейітқызы";
        String qala = "Астана";
        int jas = 17;
        System.out.println("Аты-жөні: " + at);
        System.out.printf("Қала: %s, жасы: %d%n", qala, jas);
        System.out.println("Бағдарламалау - менің жаңа хоббиім!");
    }
}
    $ java Vizitka
Аты-жөні: Айгүл Сейітқызы
Қала: Астана, жасы: 17
Бағдарламалау - менің жаңа хоббиім!

    • Файл аты Vizitka.java, класс аты Vizitka
    • javac Vizitka.java қатесіз өтеді

    Орташа

    Валюта айырбастау

    Бағам: 1 доллар = 470 теңге. Қолданушыдан доллар сомасын (double) алып, теңгемен екі таңбалы бөлшекпен шығаратын бағдарлама жазыңыз. Бағдарлама 25 доллар үшін қанша теңге шығарады? (Тек санды жазыңыз.)

    Кеңес

    Мәнді final double BAGAM = 470.0; түрінде жариялаңыз. Оқу: sc.nextDouble(). Шығару: printf("%.2f%n", ...).

    Шешімі

    Бағдарлама:

    import java.util.Locale;
import java.util.Scanner;

public class Aqsha {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        sc.useLocale(Locale.US);
        final double BAGAM = 470.0;
        System.out.print("Доллар: ");
        double usd = sc.nextDouble();
        System.out.printf("Теңге: %.2f%n", usd * BAGAM);
    }
}
    $ java Aqsha
25
Доллар: Теңге: 11750.00

    25 · 470 = 11750, яғни 11750.00.

    Орташа

    Қатені тап: орташа жас

    Екі оқушының жасы 17 және 20. Мына бағдарлама орташа жасты 18,5 деп шығаруы керек еді:

    public class Orta {
    public static void main(String[] args) {
        int jas1 = 17;
        int jas2 = 20;
        double ortasha = (jas1 + jas2) / 2;
        System.out.println(ortasha);
    }
}

    Іс жүзінде ол не шығарады? Жауабын жазыңыз, содан соң қатені түзетіңіз.

    Кеңес

    Қай бөлу орындалады: бүтін бе, әлде ондық па? Жақшаның ішіндегі jas1 + jas2 қандай тип?

    Шешімі

    Нәтиже 18.0: (17 + 20) / 2 = 37 / 2 бүтін бөлу = 18, сосын double-ға салынады. Түзету: бөлгішті 2.0 жазу немесе (double) casting жасау.

    public class Orta {
    public static void main(String[] args) {
        int jas1 = 17;
        int jas2 = 20;
        double ortasha = (jas1 + jas2) / 2.0;
        System.out.println(ortasha);
    }
}
    $ java Orta
18.5
    Қиын

    Қала халқының өсімі

    Қаланың халқы 1 200 000 адам, жылына 2,5 % өседі. Жылына бір рет өсім қосылады (күрделі пайыздай). 3 жылдан кейін халық sanyн (int) casting арқылы бүтін санға дейін қысқартып есептеңіз. Жауап қанша? Ескерту: 3-ші жылда нәтиже тек соңында бүтінге келтіріледі, аралық шамалар double күйінде қалады.

    Кеңес

    Әр жылы халық 1.025 есе артады, яғни үш жылда 1.025-тің үшінші дәрежесіне көбейтіледі. Бүтінге аудару ең соңында жасалады.

    Шешімі

    Қарапайым жазба:

    public class Osim2 {
    public static void main(String[] args) {
        int halyq = 1200000;
        double k = 1.025;
        int uShJylDan = (int) (halyq * k * k * k);
        System.out.println(uShJylDan);
    }
}
    $ java Osim2
1292268

    1 200 000 · 1,025³ = 1 292 268,75, ал (int) бөлшекті тастайды: 1292268.

    Қиын

    Секундтан сағатқа

    Қолданушыдан секунд sanyн (int) алып, оны сағат:минут:секунд пішімінде шығаратын бағдарлама жазыңыз (минут пен секунд әрқашан екі таңбалы: 1:02:05). 100000 секунд үшін бағдарлама не шығарады?

    Кеңес

    Сағат = jalpy / 3600 (бүтін бөлу). Қалған секундтан минут: (jalpy % 3600) / 60. Секунд: jalpy % 60. Екі таңбаға толтыру үшін printf-те %02d.

    Шешімі

    Бағдарлама:

    import java.util.Scanner;

public class Uaqyt {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Секунд sany: ");
        int jalpy = sc.nextInt();

        int saghat = jalpy / 3600;
        int minut = (jalpy % 3600) / 60;
        int sekund = jalpy % 60;

        System.out.printf("%d:%02d:%02d%n", saghat, minut, sekund);
    }
}
    $ java Uaqyt
100000
Секунд sany: 27:46:40

    Тағы бір тексеру, 3725 секунд:

    $ java Uaqyt
Секунд sany: 3725
1:02:05
    Өзін тексеру
    • 3725 → 1:02:05
    • 59 → 0:00:59
    • 3600 → 1:00:00
    • 100000 → 27:46:40
