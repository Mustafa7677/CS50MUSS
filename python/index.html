Python бағдарламалау

Әлемдегі ең сүйікті тілдердің бірін нөлден үйреніңіз: алғашқы print-тен бастап тесттер, кітапханалар мен объектілерге дейін. Код осы браузердің өзінде орындалады, тапсырмалар бірден тексеріледі.

def main():
    name = input("Атыңыз? ").strip()
    hello(name)

def hello(to="әлем"):
    print(f"Сәлем, {to}!")

main()

Онда 0-1 апталар сізге таныс болады (CS50x 6-апта: Python). Бірақ CS50P-да әр тақырып тереңірек: ерекше жағдайлар, тесттер, тұрақты өрнектер және ООП. Бұл курстың сертификаты бөлек беріледі.
