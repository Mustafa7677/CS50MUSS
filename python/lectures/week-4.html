    4-апта

    Кітапханалар

    Python-ның күші тек тілдің өзінде емес, оның айналасындағы мыңдаған дайын кітапханада. Бұл аптада random, statistics, sys модульдерін, командалық жол аргументтерін, pip пакеттерін, API мен JSON-ды үйреніп, өз кітапханамызды жасаймыз.

    ▶ Түпнұсқа бейнежазба мен материалдар (ағылшынша)

    Бұл бет сөзбе-сөз аударма емес. Лектор аудиторияда қалай түсіндірсе, біз де солай баяндаймыз: мағынасы мен кодтың бәрі түпнұсқадағыдай, тек әңгіме ана тілімізде жүреді.

    Кітапханалар

    Осы уақытқа дейін біз кодтың бәрін өзіміз, нөлден жаздық. Бірақ шынайы өмірде бағдарламашылар олай істемейді. Ойлап көріңізші: сізге кездейсоқ сан керек болса, оны қалай жасайтынын өзіңіз ойлап табасыз ба? Әлде біреу баяғыда жазып, мыңдаған рет тексеріп қойған кодты пайдаланасыз ба? Әрине, екіншісі!

    Міне, осындай басқа біреу (немесе кешегі сіздің өзіңіз) жазған, кез келген бағдарламада қолдануға болатын код бөліктерін кітапханалар (libraries) деп атаймыз. Python-да функцияларды не мүмкіндіктерді басқалармен бөлісу үшін оларды модуль (module) етіп рәсімдейді. Модуль дегеніміз - негізінде, ішінде пайдалы функциялары бар кәдімгі .py файл.

    Бір жайтты байқаған боларсыз: ескі жобаңыздан кодты көшіріп алып, жаңасына қойып жатсаңыз, бұл - ойланатын белгі. Мүмкін, сол кодты бөлек модульге немесе кітапханаға айналдырып, кез келген жаңа жобаға «әкеліп» қолданған дұрыс шығар. Бүгінгі лекцияның соңында дәл осыны жасаймыз.

    random

    Python-мен бірге келетін, қосымша ештеңе орнатпай-ақ қолдануға болатын кітапханалардың бірі - random. Аты айтып тұрғандай, ол кездейсоқтықпен жұмыс істейді. Ағылшындарда «алдыңғы бағдарламашылардың иығына тұру» деген тіркес бар: біз кездейсоқ сан жасаудың математикасын білмесек те, оны білетін адамдардың еңбегін пайдалана аламыз.

    Ал модульді өз бағдарламамызға қалай жүктейміз? Ол үшін import деген кілт сөз бар. Ол Python-ға «мына кітапхананы алып кел, мен оның функцияларын қолданамын» дейді.

    random модулінің ішінде random.choice(seq) деген функция бар. Оқылуына назар аударыңыз: random - біз импорттайтын модуль, ал нүктеден кейінгі choice - сол модульдің ішіндегі функция. Ол seq, яғни тізбек (sequence) қабылдайды, біздің жағдайда - тізім, және одан кездейсоқ бір элементті таңдап береді. Тиын лақтыратын бағдарлама жазайық. Терминалда code generate.py деп, мынаны жазамыз:

    import random

coin = random.choice(["heads", "tails"])
print(coin)

    choice-қа берілген тізімге қараңыз: тік жақша, тырнақшалар және үтір. Тізімде екі элемент болғандықтан, Python математиканы өзі есептеп, әрқайсысына 50% мүмкіндік береді: «heads» (елтаңба) не «tails» (сан). Бірнеше рет іске қосып көріңіз, жауап әр жолы өзгеріп отырады. Код шынымен жұмыс істейді!

    from ... import

    Кодты сәл жақсартуға болады. Байқасаңыз, import random жолы бүкіл random модулін, оның барлық функцияларымен бірге әкеледі. Ал бізге тек біреуі, choice ғана керек болса ше? Ол үшін from кілт сөзі бар: ол модульдің ішінен дәл не алғымыз келетінін нақты айтуға мүмкіндік береді:

    from random import choice

coin = choice(["heads", "tails"])
print(coin)

    Енді біз random-нан тек choice функциясын ғана алдық. Осы сәттен бастап random.choice деп жазудың қажеті жоқ, жай ғана choice деп жаза береміз. Функция бағдарламамызға тікелей жүктелді, сондықтан код қысқарып, оқуға жеңілдеді.

    Қайсысы жақсы?

    Екеуі де дұрыс. import random ұзынырақ, бірақ кодты оқыған адам random.choice дегеннен функцияның қайдан келгенін бірден көреді. from random import choice қысқарақ, бірақ өз кодыңызда да choice деген атау болса, екеуі қақтығысып қалуы мүмкін. Жағдайға қарай таңдаңыз.

    randint

    Ары қарай жүрейік. random.randint(a, b) функциясы a мен b аралығындағы кездейсоқ бүтін санды жасайды, екі шеті де қоса алғанда:

    import random

number = random.randint(1, 10)
print(number)

    Бұл код 1 мен 10 аралығындағы кездейсоқ санды шығарады. Ойын сүйегін (кубикті) лақтыру керек пе? random.randint(1, 6) - бар болғаны сол.

    shuffle

    Үшінші функция - random.shuffle(x). Ол тізімді кездейсоқ ретпен араластырады, карта сапырған сияқты:

    import random

cards = ["jack", "queen", "king"]
random.shuffle(cards)
for card in cards:
    print(card)
    Ойланып көріңіз: неге cards = random.shuffle(cards) деп жазбадық?

    Себебі shuffle басқа функциялардай жаңа мән қайтармайды. Ол cards тізімінің өзін, «орнында» (in place) араластырады. Егер cards = random.shuffle(cards) деп жазсақ, cards-қа None меншіктеліп, тізімнен айырылып қалар едік!

    Кодты бірнеше рет іске қосыңыз: валет, дама, патша әр жолы басқа ретпен шығады. Сонымен, кездейсоқ мәлімет алудың үш тәсілін көрдік: choice, randint және shuffle. Басқа функциялары туралы Python құжаттамасынан оқи аласыз: random.

    statistics

    Python-мен бірге келетін тағы бір кітапхана - statistics. Оны қалай пайдалануға болады? Мысалы, оның mean деген өте ыңғайлы функциясы бар, ол сандардың орташа мәнін (mean) есептейді. Терминалда code average.py деп жазып, мынаны теріңіз:

    import statistics

print(statistics.mean([100, 90]))

    Бұл жолы басқа кітапхананы, statistics-ті импорттадық. mean функциясы мәндер тізімін қабылдап, олардың орташасын қайтарады. python average.py деп іске қоссақ, 95 шығады: екі бағаның орташасы. Мектептегі тоқсандық бағаңызды есептейтін бағдарлама дайын! Өз бағдарламаларыңызда бұл модульдің тағы қандай мүмкіндіктері пайдалы болатынын ойланып көріңіз: медиана, мода, стандартты ауытқу... Толығырақ: statistics.

    Командалық жол аргументтері

    Осы уақытқа дейін бағдарламаға мәнді не кодтың ішіне жазып қойдық, не input арқылы сұрадық. Ал мәнді бағдарламаны іске қосқан сәтте, терминалдың өзінде бергіміз келсе ше? Мысалы, жай python average.py емес, python average.py 100 90 деп жазып, бірден 100 мен 90-ның орташасын алсақ?

    Бағдарлама атынан кейін терминалда жазылатын осындай сөздер командалық жол аргументтері (command-line arguments) деп аталады. Оларды алу үшін sys модулі керек. Оның ішінде argv деген тізім бар, ол қолданушының командалық жолда не жазғанын сақтайды. Терминалда code name.py деп, мынаны жазайық:

    import sys

print("hello, my name is", sys.argv[1])
    $ python name.py David
hello, my name is David

    Бағдарлама қолданушының командалық жолда не жазғанына қарайды. David сөзі sys.argv[1]-де сақталды. Неге 1? Тізімдердің нөлден басталатынын есіңізге түсіріңіз.

    Ойланып көріңіз: онда sys.argv[0]-де не сақталған?

    Бағдарламаның өз аты: name.py! python сөзінен кейін жазылғанның бәрі sys.argv-ке түседі: ["name.py", "David"]. Сондықтан қолданушы берген бірінші аргумент әрқашан sys.argv[1]-де болады.

    Бұл мысалдарды терминалда іске қосыңыз

    Командалық жол аргументтері бар мысалдарда ▶ Іске қосу батырмасы жоқ: браузерде командалық жол болмайды. Оларды өз компьютеріңізде не cs50.dev-те терминал арқылы іске қосыңыз.

    Аргумент берілмесе

    Біздің бағдарламада кішкентай бір мәселе бар. Қолданушы атын жазуды ұмытса не болады? Өзіңіз байқап көріңіз: python name.py деп, ешқандай атсыз іске қосамыз.

    $ python name.py
Traceback (most recent call last):
  File "name.py", line 3, in <module>
    print("hello, my name is", sys.argv[1])
IndexError: list index out of range

    Интерпретатор list index out of range, яғни «тізім индексі ауқымнан тыс» деген қате берді. Себебі ешнәрсе жазылмағандықтан, sys.argv[1] деген орын мүлдем жоқ: тізімде тек name.py ғана бар. Өткен аптада үйренген try мен except осында көмекке келеді:

    import sys

try:
    print("hello, my name is", sys.argv[1])
except IndexError:
    print("Too few arguments")

    Енді атын ұмытқан қолданушы қорқынышты қызыл жазудың орнына «аргумент тым аз» деген пайдалы кеңес алады. Бірақ одан да сақ бола аламыз ба? Қолданушы тым көп аргумент жазса ше? Мысалы, python name.py David Malan. Олай болса, аргументтер санын тікелей тексерейік:

    import sys

if len(sys.argv) < 2:
    print("Too few arguments")
elif len(sys.argv) > 2:
    print("Too many arguments")
else:
    print("hello, my name is", sys.argv[1])

    Тексеріп көрсеңіз, әр жағдай бөлек өңделетінін көресіз. Аргумент тым аз болса да, тым көп болса да, қолданушы не дұрыс емес екенін және оны қалай түзету керегін нақты біледі.

    sys.exit

    Логикалық тұрғыдан код қазір дұрыс. Бірақ бір нәрсе көңілге қонбайды: негізгі жұмысымыз, яғни сәлем беру, else-тің ішіне тығылып қалды. Қателерді тексеруді бағдарламаның қалған бөлігінен бөлек ұстаған әлдеқайда әдемі. Мұны қалай істейміз? sys модулінде exit деген функция бар: ол қолданушы қате жасаса, бағдарламадан бірден шығуға мүмкіндік береді:

    import sys

if len(sys.argv) < 2:
    sys.exit("Too few arguments")
elif len(sys.argv) > 2:
    sys.exit("Too many arguments")

print("hello, my name is", sys.argv[1])

    Қараңызшы, қандай таза! Алдымен «күзетшілер» тұр: аргументтер дұрыс болмаса, sys.exit хабарды шығарып, бағдарламаны сол жерде тоқтатады. Сондықтан соңғы жолға жеткенде, sys.argv[1] міндетті түрде бар екеніне сенімді бола аламыз, ол ешқашан қате тудырмайды.

    Қорытып айтсақ: sys.argv қолданушыға командалық жолдан мәлімет беруге мүмкіндік береді, ал sys.exit қате болса, бағдарламадан шығудың жолын ұсынады. Толығырақ: sys.

    Кесінді (slice)

    Енді бағдарламамыз бір емес, бірнеше адамға сәлем берсін. Аргумент тым аз болмаса, sys.argv-тегі әр элементті аралап шығайық:

    import sys

if len(sys.argv) < 2:
    sys.exit("Too few arguments")

for arg in sys.argv:
    print("hello, my name is", arg)
    Ойланып көріңіз: python name.py David Carter Rongxin деп іске қоссақ, неше жол шығады?

    Үш емес, төрт жол! Есімдерден бөлек, hello, my name is name.py деген күлкілі жол да шығады. Себебі sys.argv-тің ең бірінші элементі - бағдарламаның өз аты, ал біз тізімді басынан бастап аралап жатырмыз.

    $ python name.py David Carter Rongxin
hello, my name is name.py
hello, my name is David
hello, my name is Carter
hello, my name is Rongxin

    Интерпретатор тізімнің бірінші элементін, name.py-ті елемеуі үшін не істейміз? Мұнда кесінді (slice) көмектеседі. Кесінді тізімнің қай жерден басталып, қай жерде аяқталатынын интерпретаторға айтуға мүмкіндік береді. Нанның бір шетін кесіп тастағандай:

    import sys

if len(sys.argv) < 2:
    sys.exit("Too few arguments")

for arg in sys.argv[1:]:
    print("hello, my name is", arg)

    Тізімді 0-ден бастаудың орнына, тік жақшада [1:] деп жаздық. Бұл «1-индекстен бастап, соңына дейін» дегенді білдіреді. Қос нүктенің сол жағы - басы, оң жағы - соңы. Оң жағын бос қалдырсақ, «тізімнің соңына дейін» деген сөз. Енді іске қоссақ, тек есімдер шығады. Қарапайым ғана синтаксиспен кодты жақсартып алдық.

    Кесінділермен ойнап көріңіз

    x[1:3] - 1 мен 2 индекстегі элементтер (соңғы шекара қосылмайды), x[:2] - алғашқы екеуі, x[-1] - ең соңғысы, x[:-1] - соңғысынан басқасының бәрі. Кесінді жолдарға да қолданылады: "CS50"[:2] → "CS".

    Пакеттер

    Python-ның соншалықты танымал болуының бір себебі - тілге жаңа мүмкіндіктер қосатын көптеген қуатты сыртқы кітапханалар (third-party libraries). Яғни Python-ды жасаушылар емес, бүкіл әлемдегі бағдарламашылар жазған кітапханалар. Папка ретінде ұйымдастырылған осындай кітапханаларды пакеттер (packages) деп атаймыз.

    Қазіргі кезде қолжетімді барлық сыртқы пакеттер жиналған каталог бар, ол PyPI (Python Package Index) деп аталады. Оны пакеттердің үлкен кітапханасы немесе дүкені деп елестетіңіз, тек мұнда бәрі тегін.

    Сондай пакеттің бірі - cowsay, ол сиырға қолданушымен «сөйлеуге» мүмкіндік береді. Ия, бағдарламашылар да әзілдегенді жақсы көреді. Бірақ ол Python-мен бірге келмейді, оны орнату керек. Ол үшін Python-ның пакет менеджері (package manager) pip бар: ол пакеттерді жүйеңізге тез орнатады. Терминалда былай жазамыз:

    $ pip install cowsay

    Біраз мәтін шыққаннан кейін пакет орнатылады, енді оны кодта пайдалана аламыз. Терминалда code say.py деп, мынаны жазайық:

    import cowsay
import sys

if len(sys.argv) == 2:
    cowsay.cow("hello, " + sys.argv[1])

    Бағдарлама алдымен қолданушының командалық жолда дәл бір аргумент жазғанын тексереді, яғни sys.argv-те дәл екі элемент болуы керек: бағдарламаның аты мен сол аргумент. Сосын сиыр қолданушыға тіл қатады. python say.py David деп іске қосыңыз, сонда сиырдың Дэвидке «hello» деп тұрғанын көресіз:

    $ python say.py David
  ____________
| hello, David |
  ============
            \
             \
               ^__^
               (oo)\_______
               (__)\       )\/\
                   ||----w |
                   ||     ||

    Тағы бір өзгеріс енгізейік:

    import cowsay
import sys

if len(sys.argv) == 2:
    cowsay.trex("hello, " + sys.argv[1])

    Енді «hello» дейтін - тираннозавр! Сонымен, сыртқы пакеттерді қалай орнатып, қолдануға болатынын көрдіңіз. Толығырақ: PyPI-дағы cowsay беті. Басқа пакеттерді PyPI-дан іздей аласыз.

    Браузерде жұмыс істемейді

    cowsay, requests сияқты сыртқы пакеттерді қажет ететін мысалдарды осы беттен іске қосу мүмкін емес. Оларды өз компьютеріңізде не cs50.dev-те pip install ... арқылы пакетті орнатқаннан кейін іске қосыңыз.

    API

    Кітапханалар бізге басқалардың кодын өз компьютерімізде пайдалануға мүмкіндік береді. Ал API (application programming interface), яғни «қолданбалы бағдарламалау интерфейсі» бір қадам әрі барады: ол басқалардың кодына, көбіне интернеттегі басқа біреудің серверіне қосылуға мүмкіндік береді. Мейрамханадағы даяшыны елестетіңіз: сіз асханаға өзіңіз кірмейсіз, тапсырысты даяшыға айтасыз, ол асханадан дайын тамақты әкеліп береді. API - сондай даяшы.

    Python бағдарламамыз интернетпен сөйлесу үшін requests пакеті керек: ол бағдарламаға веб-браузер сияқты әрекет етуге мүмкіндік береді. Терминалда pip install requests деп орнатып, сосын code itunes.py деп жаңа файл ашамыз.

    Apple iTunes-тің өз API-і бар екен, оны өз бағдарламаларыңызда қолдана аласыз. Браузерде мына сілтемені ашып көріңіз: https://itunes.apple.com/search?entity=song&limit=1&term=weezer. Сонда мәтіндік файл жүктеледі. Дэвид бұл сілтемені Apple-дың API құжаттамасын оқып құрастырған. Оны оқып көрейік: бұл сұрау song-ты (әнді) іздейді, нәтижелер саны limit бірге шектелген, ал іздеу сөзі (term) - weezer (атақты рок-топ). Жүктелген файлды ашсаңыз, оның пішімі бізге Python-дан таныс бір нәрсеге ұқсайтынын байқайсыз.

    Бұл пішім JSON (JavaScript Object Notation) деп аталады. Ол - қолданбалар арасында мәлімет алмасуға арналған мәтіндік пішім. Яғни Apple бізге өз бағдарламамызда оқып, түсіне алатын JSON файлын беріп тұр. Мәтіндік редакторға мынаны жазайық:

    import requests
import sys

if len(sys.argv) != 2:
    sys.exit()

response = requests.get("https://itunes.apple.com/search?entity=song&limit=1&term=" + sys.argv[1])
print(response.json())

    requests.get қайтарған мән response-қа сақталады. Дэвид бұл API туралы Apple құжаттамасын оқығандықтан, жауаптың JSON болатынын біледі. python itunes.py weezer деп іске қоссақ, Apple қайтарған JSON-ды көреміз. Тек бір ерекшелігі: response.json() JSON жауапты Python сөздігіне (dictionary) айналдырады. Бірақ шығыс... басыңыз айналуы мүмкін! Бәрі бір ұзын жолға тығылып қалған.

    Бақытымызға орай, Python-да JSON-мен жұмыс істейтін кіріктірілген json кітапханасы бар. Ол алынған мәліметті түсінуге көмектеседі. Кодты өзгертейік:

    import json
import requests
import sys

if len(sys.argv) != 2:
    sys.exit()

response = requests.get("https://itunes.apple.com/search?entity=song&limit=1&term=" + sys.argv[1])
print(json.dumps(response.json(), indent=2))

    json.dumps функциясы indent параметрі арқылы шығысты шегініспен әдемілеп, оқылатын етеді. python itunes.py weezer деп қайта іске қоссақ, сол JSON шығады, бірақ бұл жолы әлдеқайда түсінікті:

    $ python itunes.py weezer
{
  "resultCount": 1,
  "results": [
    {
      "wrapperType": "track",
      "kind": "song",
      "artistName": "Weezer",
      "trackName": "Say It Ain't So",
      ...
    }
  ]
}

    Енді шығыстың ішінде results деген тізімді көресіз. Сол тізімнің ішінде сөздіктер бар, әрқайсысында көптеген кілттер. Солардың ішінен trackName мәнін тауып көріңіз. Сіздің нәтижеңізде қандай ән аты тұр?

    Ал тек ән атын ғана шығарғымыз келсе ше? Кодты былай өзгертеміз:

    import json
import requests
import sys

if len(sys.argv) != 2:
    sys.exit()

response = requests.get("https://itunes.apple.com/search?entity=song&limit=50&term=" + sys.argv[1])

o = response.json()
for result in o["results"]:
    print(result["trackName"])

    Мұнда response.json() нәтижесін o-ға сақтадық (кіші «о» әрпі, «object» сөзінен). Сосын o ішіндегі results тізімін аралап, әр нәтиженің trackName-ін шығарамыз. Нәтижелер санын да 50-ге көбейткенімізге назар аударыңыз. Іске қосып көріңіз: экранға Weezer тобының 50 әні тізіліп шығады. Небәрі бірнеше жол кодпен!

    Толығырақ: requests құжаттамасы және Python-ның JSON құжаттамасы.

    Өз кітапханаларымызды жасау

    Ал енді ең қызығы: Python бағдарламашысы ретінде сіз өз кітапханаңызды жасай аласыз! Бір кодты қайта-қайта пайдаланғыңыз келетін, тіпті басқалармен бөліскіңіз келетін жағдайларды елестетіңіз.

    Біз осы курста «hello» дейтін кодты көп жаздық. Ендеше, «hello» мен «goodbye» дей алатын модуль жасайық. Терминалда code sayings.py деп, мынаны жазамыз:

    def hello(name):
    print(f"hello, {name}")


def goodbye(name):
    print(f"goodbye, {name}")

    Бұл кодтың өзі қолданушы үшін ештеңе істемейді: біз екі функцияны анықтадық, бірақ ешқайсысын шақырмадық. Бірақ басқа бағдарламашы осы модульді өз бағдарламасына импорттаса, жоғарыдағы функциялардың мүмкіндіктерін өз кодында пайдалана алады.

    Біз жасаған модульді қолданатын кодты жазып көрейік. Терминалда code say.py деп, жаңа файлға мынаны жазамыз:

    import sys

from sayings import goodbye

if len(sys.argv) == 2:
    goodbye(sys.argv[1])
    $ python say.py David
goodbye, David

    Бұл код sayings модулінен goodbye мүмкіндігін импорттайды. Байқадыңыз ба? sayings.py файлының атынан .py-ді алып тастасақ, модульдің аты шығады. Қолданушы командалық жолда дәл бір аргумент жазса, бағдарлама «goodbye» деп, сол аргументті қоса шығарады. Біздің бірінші кітапханамыз дайын!

    if __name__ == "__main__"

    Кітапхана файлында main() шақыруы болса, оны импорттаған сәтте сол main да орындалып кетеді. Мұның алдын алу үшін файлдың соңына main()-нің орнына if __name__ == "__main__": деп жазып, main()-ді соның ішіне шегініспен қояды. Файл тікелей іске қосылса, main орындалады, ал импортталса - орындалмайды. Бұл аптаның Little Professor тапсырмасы дәл осы құрылымды талап етеді.

    Қорытынды

    Кітапханалар Python-ның мүмкіндіктерін кеңейтеді. Кейбіреулері Python-мен бірге келеді, оларды тек импорттау жеткілікті. Басқалары - pip арқылы орнатылатын сыртқы пакеттер. Ал өз пакеттеріңізді өзіңіз үшін де, басқалар үшін де жасай аласыз! Бұл лекцияда сіз мыналарды үйрендіңіз:

    • кітапханалар мен модульдер: import және from ... import;
    • random: choice, randint, shuffle;
    • statistics: mean;
    • командалық жол аргументтері: sys.argv және sys.exit;
    • кесінді: sys.argv[1:];
    • пакеттер, PyPI және pip install;
    • API, requests және JSON (json.dumps);
    • өз кітапханаларымызды жасау және импорттау.

    Өзіңізді тексеріңіз

    1. from random import choice деп жазғаннан кейін функцияны қалай шақырамыз?

    from ... import функцияны бағдарламаға тікелей жүктейді, сондықтан модуль атынсыз, жай choice деп жазамыз. Ал random деген атау бұл жағдайда анықталмаған.

    2. cards = ["jack", "queen", "king"] болса, x = random.shuffle(cards) орындалғаннан кейін x-те не болады?

    shuffle тізімнің өзін орнында араластырады және ешқандай мән қайтармайды, яғни None қайтарады. Араластырылған тізім cards-тың өзінде.

    3. python name.py David Malan деп іске қосылса, sys.argv неге тең?

    sys.argv - жолдар тізімі. Оның 0-элементі бағдарламаның аты, ал қолданушы аргументтері 1-ден басталады. python сөзі тізімге кірмейді.

    4. python name.py деп (атсыз) іске қосылса, print(sys.argv[1]) қандай қате береді?

    Тізімде тек name.py бар, 1-индексте ешнәрсе жоқ: list index out of range.

    5. sys.exit("Too few arguments") не істейді?

    sys.exit бағдарламадан бірден шығады, сондықтан одан кейінгі код орындалмайды. Сол себепті қате тексерулерін бағдарламаның басына «күзетші» етіп қоюға болады.

    6. names = ["name.py", "David", "Carter", "Rongxin"] болса, names[1:] неге тең?

    [1:] - 1-индекстен бастап соңына дейінгі кесінді. Тек 0-элемент, name.py, қалып қояды.

    7. import cowsay жолы ModuleNotFoundError берсе, ең алдымен не істеу керек?

    cowsay - Python-мен бірге келмейтін сыртқы пакет. Оны алдымен pip пакет менеджерімен PyPI-дан орнату керек. (Файлды cowsay.py деп атасаңыз, керісінше, Python өз файлыңызды импорттап, шатасады!)

    8. sayings.py файлында goodbye функциясы бар. Оны say.py-да қолдану үшін қай жол дұрыс?

    Модульдің аты - файл атының .py-сіз бөлігі. from-нан кейін модуль, import-тан кейін ондағы функция жазылады. Өз файлыңызды pip арқылы орнатудың қажеті жоқ, ол бір папкада тұрса жеткілікті.

Бұл аптаның тапсырмаларының көбі сыртқы пакеттерді (emoji, pyfiglet, inflect, requests) қажет етеді, сондықтан оларды cs50.dev-те орындаған ыңғайлы: терминалда алдымен update50 орындаңыз. Кейбірі қысқартылған бүркеншік аттарды (aliases) да түсінеді: :thumbsup: деп жазсаңыз да, 👍 шығады. Бүркеншік аттары бар кодтардың тізімі: carpedm20.github.io/emoji.

    Орташа

    Frank, Ian and Glen’s Letters (Фрэнк, Иэн және Гленнің әріптері)

    FIGlet - 1990-жылдардың басында жасалған бағдарлама, ол кәдімгі мәтіннен үлкен әріптер құрастырады. Бұл - ASCII-арттың бір түрі:

     _ _ _          _   _     _
| (_) | _____  | |_| |__ (_)___
| | | |/ / _ \ | __| '_ \| / __|
| | |   <  __/ | |_| | | | \__ \
|_|_|_|\_\___|  \__|_| |_|_|___/

    FIGlet қолдайтын қаріптердің мысалдары: figlet.org/examples.html. Кейін ол Python-ға pyfiglet деген модуль ретінде көшірілді.

    figlet.py файлында мынадай бағдарлама жазыңыз:

    • Нөл немесе екі командалық жол аргументін күтеді:
      • нөл - қолданушы мәтінді кездейсоқ қаріппен шығарғысы келсе;
      • екі - белгілі бір қаріппен шығарғысы келсе: біріншісі -f немесе --font, екіншісі - қаріптің аты.
    • Қолданушыдан мәтін (str) сұрайды.
    • Сол мәтінді қалаған қаріппен шығарады.

    Егер қолданушы екі аргумент берсе де, біріншісі -f не --font болмаса, немесе екіншісі қаріп аты болмаса, бағдарлама қате хабарымен sys.exit арқылы шығуы керек (мысалы, Invalid usage).

    Қалай тексеру керек: python figlet.py test, python figlet.py -a slant және python figlet.py -f invalid_font - үшеуі де Invalid usage деп шығуы керек. python figlet.py -f slant деп іске қосып, CS50 енгізсеңіз, мына нәтиже шығады:

       ___________ __________
  / ____/ ___// ____/ __ \
 / /    \__ \/___ \/ / / /
/ /___ ___/ /___/ / /_/ /
\____//____/_____/\____/

    Сол сияқты -f rectangles қарпімен Hello, world, -f alphabet қарпімен Moo енгізіп көріңіз. Аргументсіз іске қоссаңыз, қаріп кездейсоқ таңдалады, сондықтан нәтиже әр жолы әртүрлі болады.

    Кеңес

    Орнату: pip install pyfiglet. pyfiglet құжаттамасы онша түсінікті емес, бірақ модульді былай қолдануға болады:

    from pyfiglet import Figlet

figlet = Figlet()

    Қолжетімді қаріптер тізімін (list) figlet.getFonts() қайтарады. Қаріпті figlet.setFont(font=f) арқылы орнатасыз (f - қаріп аты, str), ал мәтінді print(figlet.renderText(s)) арқылы шығарасыз (s - мәтін). Кездейсоқ қаріп таңдау үшін random модулінің функцияларын еске түсіріңіз.

    Автотексеруші жоқ

    pyfiglet пакеті браузерде қолжетімсіз. Бұл тапсырманы өз компьютеріңізде не cs50.dev-те pip install pyfiglet орнатып орындаңыз.

    Тексеру
    • python figlet.py test → sys.exit арқылы Invalid usage
    • python figlet.py -a slant → Invalid usage
    • python figlet.py -f invalid_font → Invalid usage
    • -f slant + CS50 → жоғарыдағы үлкен әріптер
    • Аргументсіз іске қосқанда кездейсоқ қаріп таңдалады.
    • check50 cs50/problems/2022/python/figlet өтеді.

    Орташа

    Adieu, Adieu (Қош бол, қош бол)

    «The Sound of Music» фильмінде негізінен ағылшынша айтылатын «So Long, Farewell» деген ән бар. Оның бір жолы мынадай (француз тілінде «adieu» - «қош бол»):

    Adieu, adieu, to yieu and yieu and yieu

    Әрине, бұл жол грамматикалық тұрғыдан дұрыс емес. Әдетте ол Оксфорд үтірімен былай жазылар еді: «Adieu, adieu, to yieu, yieu, and yieu». Айтпақшы, «yieu» деген сөз мүлде жоқ, ол жай «you»-мен ұйқасу үшін ойлап табылған!

    adieu.py файлында қолданушыдан аттарды, әр жолға біреуден, қолданушы control-d баспайынша сұрайтын бағдарлама жазыңыз. Қолданушы кемінде бір ат енгізеді деп есептеңіз. Сосын сол адамдармен қоштасыңыз: екі атты бір and-пен, үш атты екі үтір мен бір and-пен, ал n атты n−1 үтір мен бір and-пен бөліңіз:

    Adieu, adieu, to Liesl
Adieu, adieu, to Liesl and Friedrich
Adieu, adieu, to Liesl, Friedrich, and Louisa
Adieu, adieu, to Liesl, Friedrich, Louisa, and Kurt
Adieu, adieu, to Liesl, Friedrich, Louisa, Kurt, and Brigitta
Adieu, adieu, to Liesl, Friedrich, Louisa, Kurt, Brigitta, and Marta
Adieu, adieu, to Liesl, Friedrich, Louisa, Kurt, Brigitta, Marta, and Gretl

    Қалай тексеру керек: python adieu.py деп іске қосып, Liesl теріп Enter, сосын control-d басыңыз: Adieu, adieu, to Liesl шығуы керек. Екі ат (Liesl, Friedrich) енгізсеңіз, Adieu, adieu, to Liesl and Friedrich; үш ат (Louisa қосылса) енгізсеңіз, Adieu, adieu, to Liesl, Friedrich, and Louisa шығады.

    Кеңес

    control-d басылғанда input EOFError көтереді, оны try/except EOFError арқылы ұстаңыз. inflect модулінде көп пайдалы әдіс бар, солардың бірі тізімді дәл осылай «and» және үтірлермен біріктіреді. Орнату: pip install inflect.

    Тексеру
    • Liesl → Adieu, adieu, to Liesl
    • Liesl, Friedrich → Adieu, adieu, to Liesl and Friedrich
    • Liesl, Friedrich, Louisa → Adieu, adieu, to Liesl, Friedrich, and Louisa
    • cs50.dev-те біріктіру үшін inflect қолданылды.
    • check50 cs50/problems/2022/python/adieu өтеді.

    Орташа

    Guessing Game (Сан табу ойыны)

    Мен 1 мен 100 аралығындағы бір санды ойладым... Ол қандай сан? 50! Ал егер ол шынымен кездейсоқ болса ше?

    game.py файлында мынадай бағдарлама жазыңыз:

    • Қолданушыдан деңгейді, n-ді сұрайды. Қолданушы оң бүтін сан енгізбесе, қайта сұрайды.
    • random модулі арқылы 1 мен n аралығындағы (екі шеті де қоса) кездейсоқ бүтін сан жасайды.
    • Қолданушыдан сол санды табуды сұрайды. Болжам оң бүтін сан болмаса, қайта сұрайды.
      • Болжам ойланған саннан кіші болса, Too small! деп шығарып, қайта сұрайды.
      • Болжам үлкен болса, Too large! деп шығарып, қайта сұрайды.
      • Болжам дәл тапса, Just right! деп шығарып, бағдарламадан шығады.

    Қалай тексеру керек: Level: сұрағына cat не -1 енгізсеңіз, бағдарлама Level:-ді қайта сұрауы керек. 10 енгізсеңіз, Guess: сұралады; оған cat не -1 жазсаңыз, Guess: қайта сұралады. Деңгей 1 болып, болжам 1 болса - Just right! (басқа жауап болуы мүмкін емес!). Деңгей 10, болжам 100 болса - Too large!. Деңгей 10000, болжам 1 болса - сірә, Too small! (жолыңыз болса, Just right! шығуы мүмкін, бірақ әр жолы емес, ал Too large! ешқашан шықпауы керек).

    Кеңес

    random модулінде бүтін сан қайтаратын функциялар бар, мысалы randint пен randrange. Оң бүтін сан алғанша сұрайтын бөлікті өткен аптадағыдай while True, try/except ValueError арқылы жеке функцияға шығарсаңыз, оны деңгей үшін де, болжам үшін де қолдана аласыз.

    Тексеру
    • Level: → cat, -1 - қайта сұрайды
    • Guess: → cat, -1 - қайта сұрайды
    • Деңгей 1, болжам 1 → Just right!
    • Деңгей 10, болжам 100 → Too large!
    • Деңгей 10000, болжам 1 → Too small!
    • check50 cs50/problems/2022/python/game өтеді.

    Қиын

    Little Professor (Кішкентай профессор)

    Қызығы, Дэвидтің бала кезіндегі алғашқы ойыншықтарының бірі Little Professor болған. Бұл «калькулятор» Дэвидке шешуге он түрлі математикалық есеп беретін. Мысалы, ойыншық 4 + 0 = деп көрсетсе, Дэвид (әрине, дұрыс болса) 4 деп жауап береді. 4 + 1 = болса, 5 деп жауап береді. Дэвид қате жауап берсе, ойыншық EEE деп көрсететін. Ал бір есепке үш рет қате жауап берілсе, ойыншық дұрыс жауапты өзі көрсетіп қоятын (мысалы, 4 + 0 = 4 не 4 + 1 = 5).

    professor.py файлында мынадай бағдарлама жазыңыз:

    • Қолданушыдан деңгейді, n-ді сұрайды. Қолданушы 1, 2 не 3 енгізбесе, қайта сұрайды.
    • X + Y = түріндегі он (10) математикалық есепті кездейсоқ жасайды, мұнда X пен Y - әрқайсысы n таңбалы теріс емес бүтін сан. Қосудан (+) басқа амалдың қажеті жоқ.
    • Қолданушыдан әр есепті шешуді сұрайды. Жауап дұрыс болмаса (немесе тіпті сан болмаса), EEE деп шығарып, қайта сұрайды: бір есепке барлығы үш мүмкіндік беріледі. Үш реттен кейін де дұрыс жауап болмаса, бағдарлама дұрыс жауапты шығарады.
    • Соңында қолданушының ұпайын шығарады: 10 есептің нешеуіне дұрыс жауап берді.
    Маңызды: x, y ретімен

    x пен y-ті жасау реті маңызды. Бағдарлама кездейсоқ сандарды x, y жұбымен, бір уақытта бір есептен жасауы керек: алдымен x0 мен y0, сосын x1 мен y1 және т.с.с. (барлық x-ті алдын ала жасап алмаңыз).

    Бағдарламаны мына құрылыммен жазыңыз. Мұндағы get_level қолданушыдан деңгейді сұрайды (қажет болса, қайта сұрайды) және 1, 2 не 3 қайтарады; generate_integer level таңбалы бір кездейсоқ теріс емес бүтін сан қайтарады, ал level 1, 2 не 3 болмаса, ValueError көтереді:

    import random


def main():
    ...


def get_level():
    ...


def generate_integer(level):
    ...


if __name__ == "__main__":
    main()

    Қалай тексеру керек: деңгейге -1 не 4 енгізсеңіз, Level: қайта сұралады. 1 енгізсеңіз, бір таңбалы сандармен есептер басталады, мысалы 6 + 6 =; 10 есептен кейін бағдарлама дұрыс жауаптар санын шығарып, аяқталады. Бірінші есепке қате жауап берсеңіз, EEE шығып, сол есеп қайта сұралады. Үш рет қате жауап берсеңіз, дұрыс жауап шығады (мысалы, 6 + 6 = 12) да, келесі есепке көшеді; қалғанының бәріне дұрыс жауап берсеңіз, ұпай 9 болады. Барлық 10 есепке дұрыс жауап берсеңіз, ұпай 10. Ұпайды ресми демодағыдай Score: 9 түрінде шығарыңыз.

    Кеңес

    Ерекше жағдайды raise ValueError арқылы көтеруге болады. random модулінде бүтін сан қайтаратын randint пен randrange функциялары бар. «n таңбалы теріс емес сан»: 1-деңгейде 0-ден 9-ға дейін, 2-деңгейде 10-нан 99-ға дейін, 3-деңгейде 100-ден 999-ға дейін. Үш мүмкіндікті санау үшін ішкі for циклі ыңғайлы.

    Тексеру
    • main, get_level, generate_integer функциялары бар, соңында if __name__ == "__main__":.
    • Деңгей -1, 4 → Level: қайта сұралады
    • Қате жауап → EEE және сол есеп қайта сұралады
    • Үш рет қате → дұрыс жауап шығады, қалғаны дұрыс болса ұпай 9
    • generate_integer(4) → ValueError

    Қиын

    Bitcoin Price Index (Bitcoin баға индексі)

    CoinCap v3 API

    CoinCap v2 API жабылғандықтан, тапсырма CoinCap v3 API-ге көшірілді. Ол үшін CoinCap-те тіркеліп, API кілтін (API key) алу керек: CoinCap Dashboard-та «Add New Key» батырмасын басыңыз. Бұрын v2-мен бастаған болсаңыз, кодыңызды v3-ке ауыстырыңыз. API туралы толығырақ: CoinCap API құжаттамасы.

    Bitcoin - цифрлық валютаның, яғни криптовалютаның бір түрі. Ол банк сияқты орталық мекемеге емес, транзакцияларды тіркейтін таратылған желіге, блокчейнге сүйенеді. Bitcoin-ға сұраныс болғандықтан (адамдар оны алғысы келеді), оны бір валютаны (мысалы, USD) Bitcoin-ға айырбастап сатып алуға дайын.

    bitcoin.py файлында мынадай бағдарлама жазыңыз:

    • Қолданушы сатып алғысы келетін Bitcoin санын, n-ді командалық жол аргументі ретінде күтеді. Егер аргументті float-қа айналдыру мүмкін болмаса, бағдарлама қате хабарымен sys.exit арқылы шығуы керек.
    • CoinCap Bitcoin баға индексінің API-іне сұрау жібереді: https://rest.coincap.io/v3/assets/bitcoin?apiKey=YourApiKey (YourApiKey-ді өз API кілтіңізбен ауыстырыңыз). Ол JSON нысанын қайтарады, оның ішкі кілттерінің арасында Bitcoin-ның қазіргі бағасы бар. Кез келген ерекше жағдайды ұстауды ұмытпаңыз, мысалы былай: 
      import requests

try:
    ...
except requests.RequestException:
    ...
    • n Bitcoin-ның қазіргі құнын USD-мен, үтірден кейін төрт таңбамен, мыңдықтарды , арқылы бөліп шығарады.

    Қалай тексеру керек: python bitcoin.py → sys.exit арқылы Missing command-line argument; python bitcoin.py cat → Command-line argument is not a number. python bitcoin.py 1, 2 және 2.5 - сәйкесінше 1, 2 және 2.5 Bitcoin бағасын төрт ондық таңбамен, мыңдықтарды үтірмен бөліп шығаруы керек (демо жазылған кезде 1 Bitcoin $38,761.0833 тұрған, сіздің нәтижеңіз басқа болады).

    Кеңес

    sys модулінде argv бар екенін еске түсіріңіз. requests модулінің көп әдісі бар, солардың ішінде get пен json. Орнату: pip install requests. CoinCap API-і мынадай JSON қайтарады:

    {
  "data": {
    "id": "bitcoin",
    "rank": "1",
    "symbol": "BTC",
    "name": "Bitcoin",
    "supply": "19823321.0000000000000000",
    "maxSupply": "21000000.0000000000000000",
    "marketCapUsd": "1939613325892.4607145113457500",
    "volumeUsd24Hr": "12341417371.3505338276601668",
    "priceUsd": "97845.0243474572557500",
    "changePercent24Hr": "1.4324165997531723",
    "vwap24Hr": "96203.8859537212418977",
    "explorer": "https://blockchain.info/"

    Байқаңыз: priceUsd - жол, оны float-қа айналдыру керек. Соманы төрт ондық таңбамен, мыңдық бөлгішпен былай шығаруға болады:

    print(f"${amount:,.4f}")
    Автотексеруші жоқ

    Бұл тапсырма requests пакеті мен интернетке қосылуды қажет етеді, ал олар браузердегі тексерушіде жоқ. Оны өз компьютеріңізде не cs50.dev-те pip install requests орнатып орындаңыз.

    Тексеру
    • python bitcoin.py → Missing command-line argument
    • python bitcoin.py cat → Command-line argument is not a number
    • python bitcoin.py 2.5 → баға $###,###.#### пішімінде
