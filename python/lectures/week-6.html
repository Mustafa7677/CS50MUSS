    6-апта

    Файлдармен жұмыс

    Осы уақытқа дейін бағдарлама жабылған сәтте бәрі ұмытылып қалатын. Бүгін бағдарламаларымызға файл оқып, файл жазуды үйретеміз: мәтіндік файлдар, CSV кестелері, тіпті суреттер.

    ▶ Түпнұсқа бейнежазба мен материалдар (ағылшынша)

    Бұл бет сөзбе-сөз аударма емес. Лектор аудиторияда қалай түсіндірсе, біз де солай баяндаймыз: мағынасы мен кодтың бәрі түпнұсқадағыдай, тек әңгіме ана тілімізде жүреді.

    Файлдық енгізу-шығару

    Бір қызық нәрсені байқадыңыз ба? Осы уақытқа дейін біз жазған бағдарламалардың бәрі мәліметті тек жадта (memory) сақтады. Қолданушы атын енгізді, біз оны айнымалыға салдық, экранға шығардық... Ал бағдарлама аяқталған сәтте бәрі жоғалып кетеді. Тақтаға бормен жазып, сабақ соңында өшіріп тастағандай. Келесі жолы бағдарламаны іске қоссаңыз, ол сізді мүлде танымайды.

    Бүгінгі тақырып осы мәселені шешеді. Файлдық енгізу-шығару (file I/O, input/output) - бағдарламаның файлды кіріс ретінде оқуы немесе шығыс ретінде файл жасауы. Яғни тақтаның орнына дәптерге жазу: дәптер сабақтан кейін де қалады.

    Таныс нәрседен бастайық. Терминалға code names.py деп жазып, мына кодты жазамыз:

    name = input("What's your name?")
print(f"hello, {name}")

    Іске қоссақ, бәрі күткендей: атымызды сұрайды, сәлем береді. Ал енді бір емес, бірнеше атты енгізгіміз келсе ше? Есіңізде ме, бір айнымалыда бірнеше мәнді сақтауға мүмкіндік беретін деректер құрылымы бар еді - тізім (list). Соны қолданайық:

    names = []

for _ in range(3):
    name = input("What's your name?")
    names.append(name)

    Енді бағдарлама атты үш рет сұрайды. Әр жауапты append әдісі names тізімінің соңына қосып отырады. Айтпақшы, name айнымалысы мұнда тек бір сәтке керек, сондықтан кодты қысқартуға болады: input-тің нәтижесін тікелей append-ке береміз.

    names = []

for _ in range(3):
    names.append(input("What's your name?"))

    Нәтижесі алдыңғымен бірдей, тек бір жол аз. Енді жиналған аттарды әліпби ретімен сұрыптап, әрқайсысына сәлем берейік:

    names = []

for _ in range(3):
    names.append(input("What's your name?"))

for name in sorted(names):
    print(f"hello, {name}")
    $ python names.py
What's your name?Hermione
What's your name?Harry
What's your name?Ron
hello, Harry
hello, Hermione
hello, Ron

    Тамаша, жұмыс істейді. Бірақ бағдарламаны қайта іске қоссақ, Гермиона да, Гарри де, Рон да ізім-қайым жоқ. Бар мәлімет бағдарламамен бірге өлді. Міне, файлдық енгізу-шығару дәл осы мәліметті кейін қайта пайдалану үшін сақтап қоюға мүмкіндік береді. sorted туралы толығырақ: Python құжаттамасы.

    open

    Python-да файлмен жұмыстың бәрі бір функциядан басталады: open. Ол Python-ға кірістірілген функция, файлды ашып, бағдарламаңызда пайдалануға береді: одан оқуға да, оған жазуға да болады.

    Қалай істейтінін көрсету үшін сәл артқа шегініп, бір ғана атпен жұмыс істейік:

    name = input("What's your name? ")

file = open("names.txt", "w")
file.write(name)
file.close()

    Жол-жолымен оқиық. open("names.txt", "w") - «names.txt деген файлды жазу үшін аш» деген сөз. Екінші аргумент - файлды ашу режимі (mode), ал "w" - write, яғни «жазу». Ашылған файлды file деген айнымалыға саламыз. Сосын file.write(name) атты файлға жазады, ал file.close() файлды жабады (close). Кітапты оқып болған соң жауып, сөреге қойғандай.

    python names.py деп іске қосып, атымызды енгізейік. Файлға сақталды! Енді бағдарламаны тағы бір рет, басқа атпен іске қосайық.

    Ойланып көріңіз: алдымен «Hermione», сосын «Harry» енгізсек, names.txt ішінде не болады?

    Тек Harry! "w" режимі файлды әр ашқан сайын басынан бастап қайта жазады: бұрынғы ішіндегісі толығымен өшіп кетеді. Дәптердің бетін жыртып тастап, жаңа бетке жазғандай.

    Бізге керегі - әр жаңа атты бұрынғыларының соңына қосу. Алдымен ескі файлды терминалда rm names.txt деп өшірейік. Сосын кодта бір ғана әріпті өзгертеміз:

    name = input("What's your name? ")

file = open("names.txt", "a")
file.write(name)
file.close()

    Өзгеріс - "w" орнына "a", яғни соңына қосу (append). Бағдарламаны бірнеше рет іске қоссақ, аттар файлда жиналып жатады. Бірақ файлды ашып қарасақ, жаңа мәселе көреміз:

    HermioneHarryRon

    Аттар бір-біріне жабысып қалды! Неге? Себебі write біз берген мәтінді дәл сол күйінде жазады, print сияқты соңына жаңа жол таңбасын өзі қоспайды. Оны өзіміз қосуымыз керек. Тағы да rm names.txt деп файлды өшіріп, кодты түзетейік:

    name = input("What's your name? ")

file = open("names.txt", "a")
file.write(f"{name}\n")
file.close()

    Енді әр аттың соңында \n бар, сондықтан әрқайсысы өз жолында тұрады:

    Hermione
Harry
Ron

    Код жақсы жұмыс істейді. Бірақ оны әлі де жақсартуға болады. Шынымды айтсам, файлды жабуды ұмытып кету өте оңай. Ал жабылмаған файл - ашық қалған есік сияқты: кейде жазғаныңыз файлға толық түспей қалуы мүмкін. open туралы толығырақ: Python құжаттамасы.

    Файлды ашу режимдері

    "r" - оқу (read, әдепкі режим); "w" - жазу, файл бар болса, ішіндегісі өшіріледі; "a" - соңына қосу, бұрынғы мазмұн сақталады. "w" мен "a" файл жоқ болса, оны өздері жасайды.

    with

    «Файлды жабуды ұмытпа» дегенді әр жолы есте ұстаудың орнына, Python-ға мұны өзі істетуге болады. Ол үшін with кілт сөзі бар:

    name = input("What's your name? ")

with open("names.txt", "a") as file:
    file.write(f"{name}\n")

    Мұны былай оқыңыз: «names.txt-ті соңына қосу режимінде аш, оны file деп ата, және осы блок бойы онымен жұмыс істе». with-тен кейінгі жолдың шегініспен жазылғанына назар аударыңыз. Шегіністі блок аяқталған сәтте Python файлды өзі жабады, close жазудың қажеті жоқ.

    Файлды оқу

    Осы уақытқа дейін біз тек файлға жаздық. Ал одан оқығымыз келсе ше? Режимді "r", яғни read етеміз:

    with open("names.txt", "r") as file:
    lines = file.readlines()

for line in lines:
    print("hello,", line)

    readlines әдісінің ерекше қабілеті бар: файлдың барлық жолын оқып, оларды тізім етіп қайтарады. Біз сол тізімді lines деп сақтаймыз да, әр жолға сәлем береміз. Іске қосайық:

    $ python names.py
hello, Hermione

hello, Harry

hello, Ron
    Ойланып көріңіз: аттардың арасында артық бос жолдар қайдан шықты?

    Файлдағы әр жолдың соңында біз өзіміз жазған \n тұр, readlines оны да оқып алады. Оның үстіне print өзінің әдепкі \n-ін қосады. Нәтижесінде бір жаңа жолдың орнына екеуі шығады.

    Шығыс әдемі емес. Мұны түзетудің бірнеше жолы бар, ең қарапайымы - әр жолдың оң жағындағы артық таңбаларды кесіп тастау:

    with open("names.txt", "r") as file:
    lines = file.readlines()

for line in lines:
    print("hello,", line.rstrip())

    rstrip (right strip, «оң жақтан тазала») жолдың соңындағы бос орындар мен жаңа жол таңбасын алып тастайды. 0-аптадағы strip-тің тек оң жақпен жұмыс істейтін туысы. Енді шығыс дұрыс.

    Бірақ кодты одан да қысқартуға болады. Файлдың өзін for циклімен тікелей аралап шығуға болады екен: әр қадамда цикл бізге келесі жолды береді. Бөлек lines тізімі қажет емес:

    with open("names.txt", "r") as file:
    for line in file:
        print("hello,", line.rstrip())

    Шығыс дұрыс. Тек бір нәрсені жоғалтып алдық: аттар енді сұрыпталмаған, файлда қандай ретпен тұрса, сол ретпен шығады. Сұрыптау үшін алдымен барлық атты жинап алуымыз керек, сосын ғана ретке келтіреміз:

    names = []

with open("names.txt") as file:
    for line in file:
        names.append(line.rstrip())

for name in sorted(names):
    print(f"hello, {name}")

    Мұнда names - аттарды жинайтын бос тізім. Файлдың әр жолын тазалап, жадтағы осы тізімге қосамыз. Файл жабылғаннан кейін тізімді сұрыптап, әр атқа сәлем береміз. Енді аттар әліпби ретімен шығады. Тағы бір ұсақ-түйек: бұл жолы open-ға режимді мүлде бермедік. Себебі "r" - әдепкі мән, оны жазбасақ та Python файлды оқу үшін ашады.

    Жарайды, аттарды сақтауды үйрендік. Ал оқушының атымен қатар, басқа мәліметті де сақтағымыз келсе ше? Мысалы, оның атын және қай факультетте (house) оқитынын?

    CSV

    Бір жолда бірнеше мәнді сақтаудың ең кең тараған тәсілі - CSV (comma-separated values), яғни «үтірмен бөлінген мәндер». Бұл - кәдімгі мәтіндік файл, бірақ әр жолы кестенің бір қатары, ал мәндер бір-бірінен үтірмен бөлінеді. Excel кестесінің ең қарапайым, мәтіндік нұсқасы деп елестетіңіз.

    Терминалда code students.csv деп жазып, файлды мынадай етіп толтырайық:

    Hermione,Gryffindor
Harry,Gryffindor
Ron,Gryffindor
Draco,Slytherin

    Әр жол - бір оқушы туралы бір жазба (record): алдымен аты, үтір, сосын факультеті.

    split арқылы бөлу

    Енді code students.py деп жаңа бағдарлама ашып, осы файлды оқиық:

    with open("students.csv") as file:
    for line in file:
        row = line.rstrip().split(",")
        print(f"{row[0]} is in {row[1]}")

    Әр жолмен екі нәрсе істейміз. Алдымен rstrip соңындағы жаңа жол таңбасын алып тастайды. Сосын split(",") жолды үтір тұрған жерден кесіп, бөліктерін тізім етіп қайтарады: "Hermione,Gryffindor" → ["Hermione", "Gryffindor"]. Сонда row[0] - жолдың бірінші элементі (аты), row[1] - екіншісі (факультеті).

    $ python students.py
Hermione is in Gryffindor
Harry is in Gryffindor
Ron is in Gryffindor
Draco is in Slytherin

    Код жұмыс істейді, бірақ row[0], row[1] деген жазуды бірінші рет көрген адамға сәл жұмбақ көрінеді. Нөл деген не, бір деген не? Python мұны әдемірек жазуға мүмкіндік береді:

    with open("students.csv") as file:
    for line in file:
        name, house = line.rstrip().split(",")
        print(f"{name} is in {house}")

    Мұнда split екі мән қайтарады: үтірге дейінгісін және үтірден кейінгісін. Python оларды сол жақтағы екі айнымалыға бірден, ретімен таратып береді: біріншісі name-ге, екіншісі house-қа. Бір айнымалының орнына екеуіне бір жолда меншіктедік! Бұл тәсілді тарқату (unpacking) дейді. Енді код өзін-өзі түсіндіріп тұр.

    Жазбаларды сұрыптау

    Енді тағы да сұрыпталған тізім шығарғымыз келеді делік. Аттармен істегендей, алдымен бәрін тізімге жинаймыз:

    students = []

with open("students.csv") as file:
    for line in file:
        name, house = line.rstrip().split(",")
        students.append(f"{name} is in {house}")

for student in sorted(students):
    print(student)

    students деген тізім жасап, оған әр оқушы туралы дайын сөйлемді қосамыз, сосын тізімді сұрыптап шығарамыз. Жұмыс істейді. Бірақ бір кемшілігі бар: біз тізімде жай мәтіндерді сақтап тұрмыз. «Hermione is in Gryffindor» деген сөйлемнен атты қайта бөліп алу оңай емес, ал кейін тек факультеттерді шығарғымыз келсе ше?

    Сөздіктер тізімі

    Есіңізде ме, Python-да сөздік (dictionary) бар: онда әр кілтке бір мән сәйкес келеді. Әр оқушыны жеке сөздік етіп сақтасақ, аты мен факультеті бір-бірінен бөлек, атымен шақырылып тұрады:

    students = []

with open("students.csv") as file:
    for line in file:
        name, house = line.rstrip().split(",")
        student = {}
        student["name"] = name
        student["house"] = house
        students.append(student)

for student in students:
    print(f"{student['name']} is in {student['house']}")

    Әр жол үшін student деген бос сөздік жасаймыз, оған "name" және "house" кілттерімен мәндерді саламыз, сосын дайын сөздікті students тізіміне қосамыз. Сонымен, бізде енді сөздіктердің тізімі бар. f-жол ішінде student['name'] деп жалқы тырнақша қолданғанымызға назар аударыңыз: f-жолдың өзі қос тырнақшамен басталғандықтан, ішіндегі қос тырнақша Python-ды шатастырар еді.

    Бос сөздік жасап, оны жол-жолымен толтыру сәл ұзақ. Сөздікті бір жолда, бірден мәндерімен жазуға болады:

    students = []

with open("students.csv") as file:
    for line in file:
        name, house = line.rstrip().split(",")
        student = {"name": name, "house": house}
        students.append(student)

for student in students:
    print(f"{student['name']} is in {student['house']}")

    Нәтиже бұрынғыдай, тек... сұрыптау жоғалып кетті.

    Сұрыптау кілті

    Өкінішке қарай, бұрынғыдай жай ғана sorted(students) деп жаза алмаймыз. Неге? Себебі тізімнің әр элементі енді сөздік, ал Python екі сөздіктің қайсысы «бірінші» тұруы керегін білмейді. Атымен бе? Факультетімен бе? Біз оған айтуымыз керек: «бұл тізімді оқушының аты бойынша сұрыпта».

    students = []

with open("students.csv") as file:
    for line in file:
        name, house = line.rstrip().split(",")
        students.append({"name": name, "house": house})


def get_name(student):
    return student["name"]


for student in sorted(students, key=get_name):
    print(f"{student['name']} is in {student['house']}")

    sorted-тің key деген параметрі бар. Оған функция береміз, ал sorted сол функцияны әр элементке қолданып, нәтижесі бойынша сұрыптайды. Біздің get_name функциясы өте қарапайым: оқушының сөздігін алып, оның "name" мәнін қайтарады. Сонда sorted әр оқушыны атымен салыстырады. Іске қоссақ, тізім аттар бойынша сұрыпталып шығады.

    Тағы бір нәзік жайт: key=get_name деп жазғанда get_name-нен кейін жақша қойған жоқпыз. Біз функцияны өзіміз шақырмаймыз, оны sorted-ке береміз, ал шақыруды sorted өзі қажет кезде жасайды. Иә, Python-да функцияны да басқа функцияға аргумент ретінде беруге болады!

    lambda

    Бірақ ойланып көріңізші: get_name-ді біз бір ғана жерде қолданамыз. Бір рет қолданылатын функцияға бөлек ат беріп, бөлек анықтап отырудың қажеті бар ма? Python мұндайда кодты ықшамдауға мүмкіндік береді:

    students = []

with open("students.csv") as file:
    for line in file:
        name, house = line.rstrip().split(",")
        students.append({"name": name, "house": house})

for student in sorted(students, key=lambda student: student["name"]):
    print(f"{student['name']} is in {student['house']}")

    Мұндағы lambda - анонимді функция (anonymous function, lambda), яғни атауы жоқ функция. Ол Python-ға былай дейді: «Міне, саған атсыз бір функция: маған student берілсе, оның name-ін ал да, key-ге қайтар». Қос нүктеге дейін - параметр, қос нүктеден кейін - қайтарылатын мән, return сөзі де керек емес. Нәтиже get_name нұсқасымен бірдей.

    Морт код

    Өкінішке қарай, біздің код әлі де морт, яғни оңай сынады. Мысалы, CSV файлды өзгертіп, факультеттің орнына әр оқушының қай жерде өскенін жазайық. Бағдарламамызға не болар екен? students.csv-ті былай өзгертейік:

    Harry,"Number Four, Privet Drive"
Ron,The Burrow
Draco,Malfoy Manor

    Бағдарламаны іске қоссақ, қате шығады. Енді факультет емес, үй (home) туралы сөйлеп отырғандықтан, кодтағы атауларды да ауыстырайық:

    students = []

with open("students.csv") as file:
    for line in file:
        name, home = line.rstrip().split(",")
        students.append({"name": name, "home": home})

for student in sorted(students, key=lambda student: student["name"]):
    print(f"{student['name']} is in {student['home']}")
    Ойланып көріңіз: атауларды ауыстырдық, бірақ бағдарлама бәрібір жұмыс істемейді. Неге?

    Гарридың мекенжайына қараңыз: Number Four, Privet Drive. Мекенжайдың өз ішінде үтір бар! split(",") оны да бөлгіш деп санап, жолды үш бөлікке бөледі: Harry, "Number Four және Privet Drive". Ал біз оларды тек екі айнымалыға тарқатпақ болдық.

    ValueError: too many values to unpack (expected 2)

    Python-ның ValueError: too many values to unpack қатесі осыны айтып тұр: «тарқататын мән тым көп». Біз бағдарламаны CSV файлды үтір арқылы жай бөлуге болады деп есептеп жазғанбыз. Ал CSV стандарты мұндай жағдайды мәнді қос тырнақшаға алу арқылы шешеді. Тырнақшаларды ескеретін кодты өзіміз жазуға уақыт жұмсауымызға болар еді. Бірақ, шын мәнінде, мұны біреу бізден бұрын жасап қойған: CSV файлдарды талдайтын (parse), яғни дұрыс оқитын дайын құрал бар!

    csv кітапханасы

    Python-ның кірістірілген csv кітапханасында (library) reader деген объект бар. Атынан көрініп тұрғандай, ол CSV файлды оқиды және «Number Four, Privet Drive» ішіндегі артық үтірге шатаспайды. reader for циклінде жұмыс істейді: әр қадамда CSV файлдың келесі жолын береді. Ол жолдың өзі тізім, оның әр элементі жолдағы бір мәнге сәйкес келеді: row[0] - бірінші мән, row[1] - екінші мән.

    import csv

students = []

with open("students.csv") as file:
    reader = csv.reader(file)
    for row in reader:
        students.append({"name": row[0], "home": row[1]})

for student in sorted(students, key=lambda student: student["name"]):
    print(f"{student['name']} is from {student['home']}")
    $ python students.py
Draco is from Malfoy Manor
Harry is from Number Four, Privet Drive
Ron is from The Burrow

    Енді бағдарлама күткендей жұмыс істейді. Тырнақшаны да, ішіндегі үтірді де csv.reader өзі дұрыс өңдеді.

    Дөңгелекті қайта ойлап таппаңыз

    CSV-ді split(",")-пен бөлу алғашында оңай көрінеді, бірақ тырнақша, үтір, жаңа жол сияқты ерекше жағдайлар көп. Мұндай кең тараған пішімдерге әрқашан дайын кітапхананы қолданыңыз: оны мыңдаған адам тексерген.

    DictReader

    Осы уақытқа дейін бағдарламаның өзі CSV файлдың қай бөлігі ат, қай бөлігі мекенжай екенін «шешіп» отырды: row[0] - ат, row[1] - үй. Ал ертең біреу бағандардың орнын ауыстырып жіберсе ше? Бағдарламамыз үнсіз, бірақ қате жұмыс істей бастайды.

    Бұл ақпаратты CSV файлдың өзіне жазып қойған әлдеқайда дұрыс. Файлды былай өзгертейік:

    name,home
Harry,"Number Four, Privet Drive"
Ron,The Burrow
Draco,Malfoy Manor

    Бірінші жол енді деректер емес, тақырып жолы (header row): ол файлды оқитын кез келген адамға не бағдарламаға «әр жолда алдымен name, сосын home келеді» деп ашық айтып тұр.

    Енді csv кітапханасының DictReader деген бөлігін қолданып, файлды одан да икемді оқи аламыз:

    import csv

students = []

with open("students.csv") as file:
    reader = csv.DictReader(file)
    for row in reader:
        students.append({"name": row["name"], "home": row["home"]})

for student in sorted(students, key=lambda student: student["name"]):
    print(f"{student['name']} is in {student['home']}")

    reader-ді DictReader-ге ауыстырдық. Ол әр жолды тізім емес, сөздік етіп береді, ал кілттері тақырып жолынан алынады. Енді біз row[0] деп орнын емес, row["name"] деп атын айтамыз. CSV файлды жасаған адам бірінші жолға дұрыс тақырыптарды жазса болды, бағандар қай ретпен тұрса да, бағдарлама керек мәліметті тауып алады. Мұны қорғаныстық бағдарламалау (defensive programming) дейді: кодты болашақтағы өзгерістерге алдын ала дайындап жазу.

    CSV файлға жазу

    Біз осы уақытқа дейін CSV файлдарды тек оқыдық. Ал оларға жазғымыз келсе ше?

    Алдымен сәл тазалық жасайық. Терминалда rm students.csv деп файлды өшіреміз. Бұл команда students.csv тұрған папкада тұрсаңыз ғана жұмыс істейді. Сосын students.py-ді былай өзгертеміз:

    import csv

name = input("What's your name? ")
home = input("Where's your home? ")

with open("students.csv", "a") as file:
    writer = csv.DictWriter(file, fieldnames=["name", "home"])
    writer.writerow({"name": name, "home": home})

    Мұнда csv кітапханасының DictWriter мүмкіндігін пайдаланамыз. Ол екі параметр қабылдайды: жазылатын file және жазылатын өрістердің атаулары, fieldnames. Ал writerow әдісі параметр ретінде сөздік қабылдайды. Сөзбе-сөз айтсақ, біз Python-ға «name және home деген екі өрісі бар бір жол жаз» деп тұрмыз. Үтір мен тырнақшаның бәрін DictWriter өзі ойлайды: мекенжайда үтір болса, оны тырнақшаға өзі алады.

    $ python students.py
What's your name? Harry
Where's your home? Number Four, Privet Drive
$ cat students.csv
Harry,"Number Four, Privet Drive"

    Айтпақшы, оқуға да, жазуға да болатын файл түрлері өте көп: мәтін мен CSV - солардың бастамасы ғана. CSV туралы толығырақ: Python құжаттамасы.

    Екілік файлдар және PIL

    Бүгін қарастыратын тағы бір файл түрі - екілік файл (binary file). Екілік файл дегеніміз - жай ғана нөлдер мен бірлердің жиынтығы. Мәтіндік файлдан айырмашылығы, оны «оқып» шығуға болатын әріптер жоқ, бірақ ол кез келген нәрсені сақтай алады: музыканы да, суретті де.

    Суреттермен жұмыс істеу үшін Python-да PIL деген танымал кітапхана бар (қазіргі атауы - Pillow). Онымен бір қызық нәрсе жасап көрейік: анимациялы GIF (animated GIF). Бұл - ішінде бірнеше сурет бар, кезекпен қайта-қайта ойнатылатын сурет файлы. Әр сурет бір кадр, ал бәрі бірге қарапайым анимация немесе бейне әсерін береді. Балалық шақтағы дәптердің шетіне салынған, жылдам парақтағанда қозғалатын суреттерді есіңізге түсіріңіз.

    Бізде мысықтың екі «костюмі» бар делік: costume1.gif және costume2.gif (Scratch-тағы таныс мысық). Екеуіне мұқият қарасаңыз, мысықтың аяқтарының орны сәл басқаша. Бастамас бұрын осы екі суретті курс сайтынан жүктеп алып, өз ортаңызға (IDE) сақтаңыз: оларсыз төмендегі кодты орындау мүмкін емес.

    Терминалда code costumes.py деп жазып, мына кодты жазамыз:

    import sys

from PIL import Image

images = []

for arg in sys.argv[1:]:
    image = Image.open(arg)
    images.append(image)

images[0].save(
    "costumes.gif", save_all=True, append_images=[images[1]], duration=200, loop=0
)
    Браузерде іске қосылмайды

    Бұл мысал Pillow кітапханасы мен компьютердегі сурет файлдарын қажет етеді, сондықтан оны осы беттен емес, өз компьютеріңізде немесе cs50.dev-те орындаңыз.

    Кодты қадамдап қарайық. Алдымен PIL-ден Image мүмкіндігін импорттаймыз. Бірінші for циклі командалық жолда берілген суреттерді аралап, әрқайсысын Image.open арқылы ашып, images тізіміне қосады. sys.argv[1:] дегені - argv тізімін екінші элементінен бастап кесу (slicing): бірінші элемент бағдарламаның өз аты (costumes.py), ол бізге керек емес.

    Соңғы жолдар бірінші суретті costumes.gif деп сақтайды және оған екінші суретті жалғайды. Параметрлерге қараңыз: save_all=True - барлық кадрды сақта; append_images=[images[1]] - екінші суретті келесі кадр етіп қос; duration=200 - әр кадр 200 миллисекунд көрсетілсін; loop=0 - анимация шексіз қайталансын. Енді терминалда іске қосайық:

    $ python costumes.py costume1.gif costume2.gif
$ code costumes.gif

    Міне, мысық жүріп келеді! Екі қарапайым суреттен анимациялы GIF жасадық. Pillow туралы толығырақ: Pillow құжаттамасы.

    Қорытынды

    Біз бүгін файлдарды мәтін түрінде жазып, оқуды ғана емес, нөлдер мен бірлер арқылы, яғни екілік түрде оқып, жазуды да көрдік. Енді бағдарламаларыңыз бір нәрсені есте сақтай алады. Осы жаңа мүмкіндіктермен не жасайтыныңызды көруге асығып отырмыз!

    • файлдық енгізу-шығару: мәліметті бағдарлама аяқталғаннан кейін де сақтау;
    • open және режимдер: "r" (оқу), "w" (қайта жазу), "a" (соңына қосу); write, close, жаңа жол үшін \n;
    • with: файлды автоматты түрде жабу; readlines, for line in file және rstrip;
    • CSV: split(","), тарқату (name, house = ...), сөздіктер тізімі;
    • sorted(..., key=...) және анонимді функция lambda;
    • csv кітапханасы: reader, DictReader, DictWriter, тақырып жолы;
    • екілік файлдар және PIL арқылы анимациялы GIF жасау.

    Өзіңізді тексеріңіз

    1. names.txt файлында бірнеше ат бар. open("names.txt", "w") деп ашып, бір ат жазсақ, не болады?

    "w" режимі файлды басынан қайта жазады. Бұрынғы мазмұнды сақтап, соңына қосу үшін "a" керек.

    2. file.write(name) арқылы үш ат жазылды, бірақ файлда олар HermioneHarryRon болып жабысып тұр. Неге?

    write мәтінді дәл сол күйінде жазады. Әр атты жаңа жолдан бастау үшін f"{name}\n" деп жазу керек.

    3. with open("names.txt") as file: жазуының file = open(...)-тен басты артықшылығы неде?

    with блогынан шыққан сәтте Python файлды өзі жабады, close-ты ұмытып кету мүмкін емес.

    4. names.txt файлының әр жолында бір ат бар. for line in file: print("hello,", line) неге аттардың арасында бос жол қалдырады?

    Файлдан оқылған әр жол \n-мен аяқталады, оған print-тің әдепкі \n-і қосылады. line.rstrip() мұны түзетеді.

    5. Жолда Harry,"Number Four, Privet Drive" тұр. name, home = line.rstrip().split(",") не істейді?

    split тырнақшаны білмейді, жолды үш бөлікке бөледі, ал айнымалы екеу ғана. Мұндай файлдарды csv.reader дұрыс оқиды.

    6. sorted(students, key=lambda student: student["name"]) жолында lambda не істейді?

    lambda - анонимді функция. sorted оны әр элементке қолданып, нәтижесі (аты) бойынша сұрыптайды.

    7. CSV файлдың бірінші жолы name,home. csv.DictReader оқыған әр row қандай болады?

    DictReader тақырып жолын кілт ретінде алады да, қалған әр жолды сөздік етіп береді. Сондықтан row["name"] деп жаза аламыз.

    8. python costumes.py costume1.gif costume2.gif іске қосылғанда sys.argv[1:] неге тең?

    [1:] тізімді екінші элементтен бастап соңына дейін кеседі, яғни бағдарламаның өз атынсыз барлық аргументті береді.

    (Problem Set 6) Ресми тапсырма беті: cs50.harvard.edu/python/psets/6. Бұл аптаның бағдарламалары командалық жол аргументтерімен іске қосылады және файлдармен жұмыс істейді. Алғашқы үш тапсырманы осы беттегі автотексерушіде тексере аласыз: ол бағдарламаңызды python lines.py hello.py сияқты командалармен іске қосып, керек файлдарды өзі дайындайды. Компьютерде жұмыс істесеңіз, ресми check50 командасын да қолданыңыз.

    Оңай

    Lines of Code (Код жолдары)

    Бағдарламаның күрделілігін өлшеудің бір жолы - оның код жолдарын (lines of code, LOC) санау, бос жолдар мен түсініктемелерді есептемей. Мысалы, мына бағдарламада:

    # Say hello

name = input("What's your name? ")
print(f"hello, {name}")

    төрт емес, екі-ақ жол код бар: бірінші жолы - түсініктеме, екіншісі - бос (тек бос орыннан тұрады). Бұл көп емес, демек бағдарлама күрделі болмауы ықтимал. Әрине, бір бағдарламада (не функцияда) екіншісінен көбірек жол болуы оның міндетті түрде күрделірек екенін білдірмейді. Мысалы, мына функция:

    def is_even(n):
    if n % 2 == 0:
        return True
    else:
        return False

    мынадан екі есе күрделі емес:

    def is_even(n):
    return n % 2 == 0

    алғашқысында екі еседен де көп жол болса да. Тіпті оқуға жеңіл болса, алғашқысын қарапайымырақ деп айтуға болар! Сондықтан код жолдарының санына сын көзбен қарау керек.

    Солай болса да, lines.py файлында бағдарлама жазыңыз: ол дәл бір командалық жол аргументін (command-line argument) - Python файлының атын (не жолын) күтеді және сол файлдағы код жолдарының санын, түсініктемелер мен бос жолдарды есептемей, шығарады. Егер қолданушы дәл бір аргумент бермесе, немесе файл аты .py-мен аяқталмаса, немесе ондай файл жоқ болса, бағдарлама sys.exit арқылы аяқталуы керек.

    #-тан басталатын кез келген жолды (алдында бос орындар болуы мүмкін) түсініктеме деп есептеңіз. (Docstring түсініктеме болып саналмайды.) Тек бос орындардан тұратын жолды бос жол деп есептеңіз.

    Қате жағдайларындағы хабарлар (ресми «How to Test» бөліміндегідей):

    $ python lines.py
Too few command-line arguments
$ python lines.py hello.py goodbye.py
Too many command-line arguments
$ python lines.py invalid_extension.txt
Not a Python file
$ python lines.py non_existent_file.py
File does not exist
    Кеңес

    str-дің көп әдісі бар, солардың ішінде lstrip пен startswith. open файл табылмаса, FileNotFoundError қатесін көтеруі мүмкін: оны try/except арқылы ұстаңыз. Бағдарламаңызды 6-аптаның бастапқы кодында және өз бағдарламаларыңызда сынап көріңіз.

    Тексеру
    • python lines.py → Too few command-line arguments
    • Екі аргумент → Too many command-line arguments; .txt → Not a Python file; жоқ файл → File does not exist
    • Түсініктеме мен бос жолы бар hello.py → 2; docstring код ретінде саналады.
    • check50 cs50/problems/2022/python/lines өтеді.

    Pizza Py (Пицца мәзірі)

    Гарвард алаңындағы ең танымал пиццерия - Pinocchio’s Pizza & Subs, қысқаша Noch’s. Ол «қалың қамырлы» сицилиялық пиццасымен белгілі.

    Студенттер әдетте пиццаны тілімдеп сатып алады, бірақ мәзірде тұтас пиццалар да бар. Міне, сицилиялық пиццалардың CSV файлы, sicilian.csv:

    Sicilian Pizza,Small,Large
Cheese,$25.50,$39.95
1 item,$27.50,$41.95
2 items,$29.50,$43.95
3 items,$31.50,$45.95
Special,$33.50,$47.95

    Кәдімгі пиццалар үшін regular.csv файлы да бар. Әрине, CSV файл тұтынушыға онша ыңғайлы емес. ASCII-арт түрінде безендірілген кесте әлдеқайда әдемі:

    +------------------+---------+---------+
| Sicilian Pizza   | Small   | Large   |
+==================+=========+=========+
| Cheese           | $25.50  | $39.95  |
+------------------+---------+---------+
| 1 item           | $27.50  | $41.95  |
+------------------+---------+---------+
| 2 items          | $29.50  | $43.95  |
+------------------+---------+---------+
| 3 items          | $31.50  | $45.95  |
+------------------+---------+---------+
| Special          | $33.50  | $47.95  |
+------------------+---------+---------+

    pizza.py файлында бағдарлама жазыңыз: ол дәл бір командалық жол аргументін - Pinocchio’s пішіміндегі CSV файлдың атын (не жолын) күтеді және PyPI-дағы tabulate пакеті арқылы ASCII-арт кестесін шығарады. Кестені кітапхананың grid пішімімен безендіріңіз. Егер қолданушы дәл бір аргумент бермесе, немесе файл аты .csv-мен аяқталмаса, немесе ондай файл жоқ болса, бағдарлама sys.exit арқылы аяқталуы керек.

    Қате хабарлары: аргумент жоқ болса - Too few command-line arguments; тым көп болса - Too many command-line arguments; sicilian.txt сияқты файл - Not a CSV file; жоқ файл - File does not exist. Ал python pizza.py regular.csv мынаны шығаруы керек:

    +-----------------+---------+---------+

+=================+=========+=========+

+-----------------+---------+---------+
| 1 topping       | $14.75  | $20.95  |
+-----------------+---------+---------+
| 2 toppings      | $15.95  | $22.95  |
+-----------------+---------+---------+
| 3 toppings      | $16.95  | $24.95  |
+-----------------+---------+---------+
| Special         | $18.50  | $26.95  |
+-----------------+---------+---------+
    Кеңес

    csv модулінің reader және DictReader әдістерін еске алыңыз. open FileNotFoundError көтеруі мүмкін. tabulate пакетінде бір ғана функция бар; оны pip install tabulate арқылы орнатасыз. Тақырып жолын headers параметрі арқылы беріңіз (мысалы, headers="firstrow" немесе DictReader-мен headers="keys").

    Тексеру
    • Аргументсіз → Too few command-line arguments; екі аргумент → Too many command-line arguments
    • sicilian.txt → Not a CSV file; жоқ файл → File does not exist
    • regular.csv мен sicilian.csv → grid кестесі
    • check50 cs50/problems/2022/python/pizza өтеді.

    Scourgify (Тазарту дуасы)

    «Әйтеуір, бәрі сыйды, - деді Тонкс сандықтың қақпағын тарс жауып. - Мынаны да сәл тазалап жіберуге болады». Ол таяқшасын Хедвигтің торына бағыттады: «Скурджифай». Бірнеше қауырсын мен саңғырық ғайып болды.

    - Гарри Поттер және Феникс Ордені

    Деректерді де жиі «тазалау» керек болады, яғни мәндерді біркелкі, ыңғайлырақ пішімге келтіру. Мысалы, оқушылардың мына CSV файлын қарайық, before.csv (толық файлда 53 оқушы бар, мұнда басы ғана):

    name,house
"Abbott, Hannah",Hufflepuff
"Bell, Katie",Gryffindor
"Bones, Susan",Hufflepuff
"Boot, Terry",Ravenclaw
"Brown, Lavender",Gryffindor
...
"Wood, Oliver",Gryffindor
"Zabini, Blaise",Slytherin

    Файлдың әр «жолында» үш мән бар (тегі, аты және факультеті), бірақ алғашқы екеуі бір «бағанға» (name) біріктірілген: қос тырнақшаға алынған, тегі мен аты үтір және бос орын арқылы бөлінген. Хогвартс әр оқушыға жаппай рассылка арқылы үлгі хат жібергісі келсе, бұл ыңғайсыз: хатты «Dear Potter, Harry,» деп бастау оғаш болар еді, «Dear Harry,» деген дұрыс.

    scourgify.py файлында бағдарлама жазыңыз, ол:

    • қолданушыдан екі командалық жол аргументін күтеді:
      • кіріс ретінде оқылатын, бар CSV файлдың атын; оның бағандары ретімен name және house деп есептеледі;
      • шығыс ретінде жазылатын жаңа CSV файлдың атын; оның бағандары ретімен first, last және house болуы керек;
    • кірісті шығысқа түрлендіреді: әр name-ді аты (first) мен тегіне (last) бөледі. Әр оқушының аты да, тегі де бар деп есептеңіз.

    Егер қолданушы дәл екі аргумент бермесе, немесе біріншісін оқу мүмкін болмаса, бағдарлама sys.exit арқылы қате хабарымен аяқталуы керек:

    $ python scourgify.py
Too few command-line arguments
$ python scourgify.py 1.csv 2.csv 3.csv
Too many command-line arguments
$ python scourgify.py invalid_file.csv output.csv
Could not read invalid_file.csv

    Ал python scourgify.py before.csv after.csv бағандары ретімен first, last, house болатын жаңа after.csv файлын жасауы керек.

    Кеңес

    csv модулінде DictReader мен DictWriter бар. DictWriter-ге fieldnames-ті файлға жазуды аргументсіз writeheader әдісі арқылы тапсыра аласыз. "Potter, Harry"-ді бөлгенде үтірден кейінгі бос орынды ұмытпаңыз.

    Тексеру
    • Аргументсіз → Too few command-line arguments; үш аргумент → Too many command-line arguments
    • Жоқ файл → Could not read invalid_file.csv
    • after.csv бірінші жолы first,last,house, ал "Potter, Harry",Gryffindor → Harry,Potter,Gryffindor
    • check50 cs50/problems/2022/python/scourgify өтеді.

    Қиын

    CS50 P-Shirt (CS50 футболкасы)

    Гарвардта CS50-ді бітірген студенттерге дәстүр бойынша өздерінің «I took CS50» футболкасы беріледі. Оны интернеттен сатып алудың қажеті жоқ, бірақ виртуалды түрде киіп көргіңіз келе ме?

    shirt.py файлында дәл екі командалық жол аргументін күтетін бағдарлама жазыңыз:

    • sys.argv[1]-де - кіріс ретінде оқылатын (ашылатын) JPEG не PNG файлдың аты (не жолы);
    • sys.argv[2]-де - шығыс ретінде жазылатын (сақталатын) JPEG не PNG файлдың аты (не жолы).

    Бағдарлама кіріс суретті shirt.png өлшеміне келтіріп (өлшемін өзгертіп, қиып), оның үстіне фоны мөлдір shirt.png-ді салып, нәтижені шығыс файл ретінде сақтауы керек.

    Кірісті Image.open арқылы ашыңыз, өлшемін өзгертіп, қиюды ImageOps.fit арқылы жасаңыз (method, bleed және centering үшін әдепкі мәндерді қолданып), футболканы Image.paste арқылы үстіне салыңыз, ал нәтижені Image.save арқылы сақтаңыз.

    Мына жағдайларда бағдарлама sys.exit арқылы аяқталуы керек:

    • қолданушы дәл екі аргумент бермесе;
    • кіріс пен шығыстың аттары .jpg, .jpeg не .png-мен аяқталмаса (бас-кіші әріпке қарамастан);
    • кірістің кеңейтімі шығыстың кеңейтімімен бірдей болмаса;
    • көрсетілген кіріс файл жоқ болса.

    Кіріс - демодағыдай дәл керек қалыпта түскен адамның суреті деп есептеңіз: өлшемі өзгертіліп, қиылғанда футболка оған дәл келеді. Өз суретіңізбен сынағыңыз келсе, оны VS Code файл шолғышына, shirt.py тұрған папкаға сүйреп әкеліңіз. Суреттерді тапсырудың қажеті жоқ.

    Қате хабарлары (ресми «How to Test» бөлімінен):

    $ python shirt.py
Too few command-line arguments
$ python shirt.py before1.jpg before2.jpg before3.jpg
Too many command-line arguments
$ python shirt.py before1.jpg invalid_format.bmp
Invalid output
$ python shirt.py before1.jpg after1.png
Input and output have different extensions
$ python shirt.py non_existent_image.jpg after1.jpg
Input does not exist

    Ал python shirt.py before1.jpg after1.jpg Маппеттің CS50 футболкасын киген суретін (after1.jpg) жасауы керек. Бастамас бұрын wget арқылы shirt.png мен muppets.zip-ті жүктеп, unzip muppets.zip деп маппеттердің суреттерін шығарып алыңыз.

    Кеңес

    Файлдың кеңейтімін os.path.splitext арқылы анықтауға болады. open FileNotFoundError көтеруі мүмкін. Pillow-ды pip install Pillow арқылы орнатасыз. Суретті shirt = Image.open("shirt.png") деп ашасыз, оның ені мен биіктігін кортеж ретінде size = shirt.size деп аласыз, ал бір суретті екіншісінің (мысалы, photo) үстіне photo.paste(shirt, shirt) деп саласыз: мұнда бірінші shirt - үстіне салынатын сурет, екіншісі - photo-ның қай пикселдері жаңартылатынын көрсететін «маска». Суретті VS Code-та code shirt.png деп ашуға болады.

    Бұл тапсырма компьютерде орындалады

    Pillow кітапханасы мен сурет файлдары қажет болғандықтан, бұл тапсырманың автотексерушісі жоқ. Оны өз компьютеріңізде немесе cs50.dev-те жазып, check50 арқылы тексеріңіз.

    Тексеру

    • .bmp → Invalid output; әр түрлі кеңейтімдер → Input and output have different extensions; жоқ файл → Input does not exist
    • python shirt.py before1.jpg after1.jpg футболка киген суретті жасайды.
    • check50 cs50/problems/2022/python/shirt өтеді.
