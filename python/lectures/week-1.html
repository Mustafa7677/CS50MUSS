    1-апта

    Шарттар

    Бүгін бағдарламамызға шешім қабылдауды үйретеміз. Салыстыру операторлары, if, elif, else, or мен and, бөлудің қалдығы, өз логикалық функцияларымыз және match - бәрі осы аптада.

    ▶ Түпнұсқа бейнежазба мен материалдар (ағылшынша)

    Бұл бет сөзбе-сөз аударма емес. Лектор аудиторияда қалай түсіндірсе, біз де солай баяндаймыз: мағынасы мен кодтың бәрі түпнұсқадағыдай, тек әңгіме ана тілімізде жүреді.

    Шарттар

    Өткен аптада біз жазған бағдарламалардың бәрі бір ерекшелігімен ұқсас еді: олар жоғарыдан төменге қарай, жол-жолымен, әрдайым бірдей орындалатын. Қолданушы не енгізсе де, бағдарлама сол бір жолмен жүріп өтетін. Ал шынайы өмірде біз үнемі таңдау жасаймыз: жаңбыр жауса - қолшатыр аламыз, жаумаса - алмаймыз. Бүгін бағдарламамызға да осылай шешім қабылдауды үйретеміз.

    Бұл үшін шарттар (conditionals) керек. Шарттар бағдарламаға белгілі бір жағдайға қарап, бір жолды емес, екінші жолды таңдауға мүмкіндік береді. Жол айырығында тұрған жүргізушіні елестетіңіз: солға бұрылу керек пе, әлде оңға ма? Бағдарлама да дәл солай, шартқа қарап, сол жақ немесе оң жақ жолға түседі.

    Ал шешім қабылдау үшін алдымен сұрақ қою керек. Python-да математикалық сұрақ қоюға арналған бірнеше салыстыру операторлары (comparison operators) бар. Олардың көбі сізге мектептен таныс:

    • > және < - «үлкен» және «кіші»;
    • >= - «үлкен немесе тең»;
    • <= - «кіші немесе тең»;
    • == - «тең»;
    • != - «тең емес».

    Тек ==-ге ерекше назар аударыңыз: мұнда теңдік белгісі екеу. Неге? Өйткені жалғыз = бізде бос емес, 0-аптада көргеніміздей, ол меншіктеу, яғни «оң жақтағы мәнді сол жақтағы айнымалыға сал» дегенді білдіреді. Ал екі теңдік белгісі мүлде басқа нәрсе істейді: ештеңені өзгертпей, екі мәнді салыстырады. Кез келген салыстыру осылай құрылады: сол жақтағы мән оң жақтағы мәнмен салыстырылады.

    if нұсқауы

    Ал, теориядан тәжірибеге көшейік. Терминалға code compare.py деп жазып, жаңа файл ашамыз. Екі санды салыстыратын бағдарлама жазамыз:

    x = int(input("What's x? "))
y = int(input("What's y? "))

if x < y:
    print("x is less than y")

    Алғашқы екі жол таныс: қолданушыдан екі сан сұраймыз, int арқылы оларды бүтін санға айналдырып, x пен y айнымалыларына сақтаймыз. Ал үшінші жол жаңа. if x < y: деп жазылған бұл жолды if нұсқауы (if statement) дейді. Оны қазақша былай оқыңыз: «егер x y-тен кіші болса, онда...». Шарт орындалса, астындағы шегініспен жазылған жол іске қосылады, x is less than y шығады. Орындалмаса, Python ол жолды жай аттап өте шығады.

    Жолдың соңындағы қос нүктені (:) және келесі жолдың шегінісін ұмытпаңыз. Өткен аптада def-те көргендей, Python қай жолдар if-тің «ішінде» екенін дәл осы шегініске қарап біледі.

    Ал Python шарттың орындалған-орындалмағанын қалай шешеді? Әр салыстырудың жауабы - екі мәннің бірі ғана: True (ақиқат) немесе False (жалған). Мұндай «иә/жоқ» мәндерін логикалық мән (Boolean) дейді, Python-дағы типі - bool. Математик Джордж Бульдің құрметіне аталған. Сонымен, x < y салыстыруы True болса, интерпретатор шегіністегі блокты орындайды, False болса - орындамайды. Бар болғаны осы.

    Басқару ағыны, elif және else

    Біздің бағдарлама әзірге тек бір жағдайды біледі. x y-тен үлкен болса ше? Немесе екеуі тең болса? Онда бағдарлама үнсіз қалады. Түзетейік, тағы екі сұрақ қосамыз:

    x = int(input("What's x? "))
y = int(input("What's y? "))

if x < y:
    print("x is less than y")
if x > y:
    print("x is greater than y")
if x == y:
    print("x is equal to y")

    Мұнда бірінен соң бірі келетін үш if бар. Python алдымен бірінші if-тің шартын тексереді. Сосын, нәтижесі қандай болса да, екіншісін тексереді. Сосын үшіншісін. Шешімдердің осылай бірінен соң бірі ағып өтетін ретін басқару ағыны (control flow) деп атайды.

    Мұны суретпен көрсетсек, түсінікті болады. Кодты блок-сызба (flowchart) түрінде салайық: ромбтың ішінде - сұрақ, тіктөртбұрыштың ішінде - әрекет, ал бағыттауыштар бағдарламаның қай жаққа жүретінін көрсетеді:

    Ойланып көріңіз: x = 1, y = 2 енгізсек, бағдарлама неше сұрақ қояды?

    Үш сұрақтың үшеуін де! Бірінші сұрақтың жауабы True, экранға x is less than y шығады. Біз жауапты білдік қой. Бірақ бағдарлама оны түсінбейді: ол бәрібір «x y-тен үлкен бе?» деп сұрайды, сосын «тең бе?» деп тағы сұрайды. Блок-сызбадан қараңыз: қай жолмен жүрсеңіз де, үш ромбтың бәрінен өтесіз.

    Бір ойланып көріңізші: үш сұрақтың үшеуінің де жауабы бір мезетте True бола ала ма? Әрине, жоқ! Сан бір мезетте әрі кіші, әрі үлкен бола алмайды. Сондықтан бір сұраққа «иә» деп жауап алсақ, қалғандарын қоюдың мәні жоқ. Мұны Python-ға elif арқылы айтамыз. Бұл «else if» сөздерінің қысқартылғаны, яғни «әйтпесе, егер...»:

    x = int(input("What's x? "))
y = int(input("What's y? "))

if x < y:
    print("x is less than y")
elif x > y:
    print("x is greater than y")
elif x == y:
    print("x is equal to y")

    Енді бағдарлама азырақ шешім қабылдайды. Алдымен if тексеріледі. Ол ақиқат болса, төмендегі elif-тердің ешқайсысы іске қосылмайды, Python оларды түгел аттап өтеді. Ал if жалған болса ғана бірінші elif тексеріледі. Ол ақиқат болса, соңғы тексеру де орындалмайды. Блок-сызбасы енді былай:

    Айырмашылықты байқадыңыз ба? Енді «True» бағыттауышы бірден соңына, «stop»-қа апарады. Шынын айтсақ, сіздің компьютеріңіз бұл екі бағдарламаның жылдамдығынан ешқандай айырма сезбейді. Бірақ күніне миллиардтаған, тіпті триллиондаған осындай есептеулер жасайтын онлайн серверді елестетіңізші. Сонда әр артық сұрақ жиналып келіп, айтарлықтай уақыт пен ресурс алады. Кішкентай болып көрінген код шешімдері осылай үлкен әсер етеді.

    Ал бағдарламаны тағы бір рет жақсартуға болады. Ойланып көріңіз: соңғы elif x == y сұрағы бізге шынымен керек пе? Егер x y-тен кіші болмаса және үлкен де болмаса, онда ол y-ке міндетті түрде тең. Басқа нұсқа жоқ! Сондықтан бұл сұрақты қоймай-ақ, «қалған барлық жағдайда» орындалатын әдепкі жолды else арқылы жасаймыз:

    x = int(input("What's x? "))
y = int(input("What's y? "))

if x < y:
    print("x is less than y")
elif x > y:
    print("x is greater than y")
else:
    print("x is equal to y")

    else-тің шарты жоқ екенін байқаңыз: ол жоғарыдағы сұрақтардың бірде-біреуі ақиқат болмаса ғана іске қосылады. Мектептегі сынып журналы сияқты: «Асқар келді ме? Жоқ. Айгүл келді ме? Жоқ. Ендеше, қалғанның бәрі келген». Бағдарламаның күрделілігі қалай азайғанын қараңыз, енді үш емес, ең көбі екі сұрақ қойылады:

    or

    Шарттарды бір-бірімен біріктіруге де болады. Мұнда бізге логикалық операторлар (logical operators) көмектеседі. Біріншісі - or, яғни «немесе». Ол бірнеше баламаның кез келгені ақиқат болса, шартты ақиқат деп санайды. Мысалы, бізге x пен y-тің қайсысы үлкен екені маңызды емес, тек тең бе, тең емес пе, соны білгіміз келсін:

    x = int(input("What's x? "))
y = int(input("What's y? "))

if x < y or x > y:
    print("x is not equal to y")
else:
    print("x is equal to y")

    «Егер x y-тен кіші немесе үлкен болса, онда тең емес». Нәтиже бұрынғыдай дұрыс, бірақ код қарапайымдала түсті, тиімділігі артты.

    Код жаман емес. Бірақ әрдайым өзімізден сұрап отырайық: дизайнды бұдан да жақсартуға бола ма? Бола ма екен, ойланыңыз... Бізге керегі - «тең емес пе?» деген сұрақ. Ал бұл үшін бізде дайын оператор бар емес пе?

    x = int(input("What's x? "))
y = int(input("What's y? "))

if x != y:
    print("x is not equal to y")
else:
    print("x is equal to y")

    or мүлде жоқ болып кетті! Біз бар болғаны бір ғана сұрақ қоямыз: «x y-ке тең емес пе?». Бір сұрақ - бір жауап. Өте тиімді!

    Түсінікті болу үшін сұрақты керісінше де қоюға болады, «тең бе?» деп:

    x = int(input("What's x? "))
y = int(input("What's y? "))

if x == y:
    print("x is equal to y")
else:
    print("x is not equal to y")

    Мұндағы == операторы сол жақ пен оң жақтың бір-біріне тең-теңсіздігін тексереді. Тағы бір рет еске салайын: екі теңдік белгісі мұнда өте маңызды. Жалғыз = жазсаңыз, интерпретатор қате береді. Бұл бағдарламаның блок-сызбасы ең қарапайымы:

    = мен == шатастырмаңыз

    x = y - «y-тің мәнін x-ке сал» (меншіктеу). x == y - «x пен y тең бе?» (салыстыру, нәтижесі True не False). if x = y: деп жазсаңыз, Python SyntaxError береді. Бұл - жаңадан бастаушылардың ең жиі жіберетін қатесі.

    and

    or-дың жұбы бар - and, яғни «және». Ол шарттардың бәрі ақиқат болғанда ғана ақиқат болады. Мұны көрсету үшін жаңа бағдарлама жазайық. Терминалда code grade.py деп орындаңыз. Бұл бағдарлама ұпайға қарап баға қояды. Американдық мектептерде бағалар әріппен беріледі: A - ең жоғарысы (біздің «5»-ке ұқсас), F - құлау:

    score = int(input("Score: "))

if score >= 90 and score <= 100:
    print("Grade: A")
elif score >=80 and score < 90:
    print("Grade: B")
elif score >=70 and score < 80:
    print("Grade: C")
elif score >=60 and score < 70:
    print("Grade: D")
else:
    print("Grade: F")

    python grade.py деп іске қосып, ұпай енгізсеңіз, бағаңызды аласыз. Бірақ кодқа мұқият қараңызшы. Әр жолда екі салыстыру, әр шекарада < мен <= кезектесіп келеді. Бір жерде қателесіп, < орнына <= жазып жіберу оңай, ал мұндай қатені байқау қиын. Мұнда қателерге орын көп.

    Бағдарламашылар қолданушыға ғана емес, өзіне де толық сенбеуге тиіс. Кодты түзетейік. Python-да салыстыруларды математикадағыдай бір-біріне тізбектеп жазуға болады, мысалы 90 <= score <= 100, яғни «score 90 бен 100-дің аралығында»:

    score = int(input("Score: "))

if 90 <= score <= 100:
    print("Grade: A")
elif 80 <= score < 90:
    print("Grade: B")
elif 70 <= score < 80:
    print("Grade: C")
elif 60 <= score < 70:
    print("Grade: D")
else:
    print("Grade: F")

    Мұндай салыстыруларды тізбектеу (chained comparisons) басқа бағдарламалау тілдерінде сирек кездеседі, ал Python-да бұл әбден қалыпты нәрсе. Оқуға да жеңіл: дәл математика дәптеріндегідей.

    Дегенмен, бұдан да жақсырақ жасауға болады. elif-тің қалай жұмыс істейтінін еске түсірейік: Python екінші сұраққа жетті ме, демек бірінші сұрақтың жауабы False болды. Яғни score >= 80 тексеріліп жатқанда, біз ұпайдың 90-нан кем екенін білеміз! Ендеше оны қайта сұраудың қажеті жоқ:

    score = int(input("Score: "))

if score >= 90:
    print("Grade: A")
elif score >= 80:
    print("Grade: B")
elif score >= 70:
    print("Grade: C")
elif score >= 60:
    print("Grade: D")
else:
    print("Grade: F")

    Бағдарлама азырақ сұрақ қою арқылы жақсарды. Оқуға жеңіл, ал болашақта оны өзгерту (мысалы, шекараны ауыстыру) әлдеқайда оңай: әр шекара бір-ақ жерде жазылған.

    Ойланып көріңіз: соңғы нұсқаға 105 енгізсек, не шығады? Ал алғашқы нұсқаға ше?

    Соңғы нұсқа Grade: A шығарады, себебі 105 >= 90. Ал алғашқы екі нұсқа Grade: F береді: 105 ешбір аралыққа түспейді де, else-ке құлайды. Екеуі де ақылға қонымсыз! Нағыз бағдарламада ұпайдың 0 мен 100 аралығында екенін алдымен бөлек тексерген дұрыс. Бұл - кодты әрдайым «шетін» мәндермен тексеріп көру керек екенінің жақсы мысалы.

    Python-ның басқару ағыны туралы құжаттамасынан толығырақ оқи аласыз.

    Бөлудің қалдығы

    Математикада санның жұп не тақ екенін білдіретін ұғым бар, оны жұп-тақтық (parity) дейді. Санның жұп-тақтығын қалай тексереміз? Мұнда 0-аптада аз-кем таныстырған % операторы, яғни бөлудің қалдығы көмектеседі. Ол бір санды екіншісіне бөлгенде қалдық қалатынын не қалмайтынын көрсетеді.

    Мысалы, 4 % 2 нөлге тең, себебі 4 екіге қалдықсыз бөлінеді. Ал 3 % 2 - нөл емес (дәлірек айтқанда, 1), себебі 3-ті екіге бөлгенде бір қалады. Базарда 3 алманы екі балаға бөліп бергендей: әрқайсысына біреуден, біреуі артылып қалады. Демек, сан жұп болса, оның екіге бөлгендегі қалдығы әрдайым нөл.

    Терминалда code parity.py деп жаңа бағдарлама ашып, мынаны жазайық:

    x = int(input("What's x? "))

if x % 2 == 0:
    print("Even")
else:
    print("Odd")

    Енді қолданушы кез келген бүтін сан енгізіп, оның жұп (Even) не тақ (Odd) екенін біле алады. Бұл жерде екі операторды бірге қолданғанымызды байқаңыз: алдымен % қалдықты есептейді, сосын == оны нөлмен салыстырады.

    Жұп-тақтықты тексеретін өз функциямыз

    0-аптада өз функцияларымызды жазудың қаншалықты пайдалы екенін көрдік. Мұнда да солай істейік: «сан жұп па?» деген сұраққа жауап беретін жеке функция жазамыз:

    def main():
    x = int(input("What's x? "))
    if is_even(x):
        print("Even")
    else:
        print("Odd")


def is_even(n):
    if n % 2 == 0:
        return True
    else:
        return False


main()

    Бір қызық нәрсеге назар аударыңыз: if is_even(x): жолында ешқандай салыстыру операторы жоқ! Ешқандай < не == жоқ. Сонда да ол жұмыс істейді. Неге? Себебі is_even функциясы main-ге логикалық мән, яғни True немесе False қайтарады. Ал if-ке дәл осы керек: оған тек «иә» не «жоқ» деген жауап берілсе болды. if жай ғана is_even(x)-тің ақиқат не жалған екеніне қарайды.

    Функцияның атына да назар аударыңыз: is_even, яғни «жұп па?». Логикалық мән қайтаратын функцияларды осылай сұрақ ретінде атау - жақсы әдет. Сонда if is_even(x): қарапайым сөйлем сияқты оқылады: «егер x жұп болса».

    Питондық стиль

    Бағдарламалау әлемінде питондық (Pythonic) деген сөз бар. Ол кейбір тәсілдердің Python-ға ғана тән, Python бағдарламашыларына ерекше ұнайтын стильмен жазылғанын білдіреді. Мысалы, is_even функциямызды былай қайта жазуға болады:

    def main():
    x = int(input("What's x? "))
    if is_even(x):
        print("Even")
    else:
        print("Odd")


def is_even(n):
    return True if n % 2 == 0 else False


main()

    Төрт жол бір жолға сыйып кетті! Ал бұл жолды дауыстап оқып көріңізші: «return True if n % 2 == 0 else False», яғни «қалдық нөл болса True қайтар, әйтпесе False». Ағылшынша сөйлемнің өзі сияқты. Мұндай бір жолдық шартты шартты өрнек (conditional expression) дейді. Шартты өрнектер көп тілде бар, бірақ дәл осылай оқылатын стиль - нағыз питондық.

    Бірақ одан әрі жүре аламыз. Өзімізге сұрақ қояйық: n % 2 == 0 салыстыруының өзі не береді?

    Ойланып көріңіз: n = 7 болса, n % 2 == 0 өрнегінің мәні қандай?

    False. 7 % 2 = 1, ал 1 == 0 жалған. Яғни салыстырудың өзі-ақ дайын логикалық мән! Оны True if ... else False деп қайта орап жатудың қажеті жоқ.

    def main():
    x = int(input("What's x? "))
    if is_even(x):
        print("Even")
    else:
        print("Odd")


def is_even(n):
    return n % 2 == 0


main()

    Python n % 2 == 0 өрнегін есептеп, True не False алады да, соны тікелей main-ге қайтарады. Ең қысқа, ең таза нұсқа. Ал «қай нұсқа дұрыс?» деп сұрасаңыз, үшеуі де дұрыс жұмыс істейді. Өткен аптадағы ереже әлі де күшінде: өзіңізге және әріптестеріңізге оқуға ең түсінікті нұсқаны таңдаңыз.

    match

    Соңғы тақырып. if, elif және else-ке ұқсас тағы бір құрал бар: match нұсқауы (match statement). Ол айнымалының мәнін бірнеше нақты мәнмен салыстырып, сәйкес келгенін орындайды. Мұны түсіну үшін алдымен таныс құралмен бір бағдарлама жазайық. «Гарри Поттерді» оқыған боларсыз: Хогвартсқа келген әр оқушыны Сұрыптау қалпағы бір үйге жібереді. Есімге қарап үйін айтатын бағдарлама:

    name = input("What's your name? ")

if name == "Harry":
    print("Gryffindor")
elif name == "Hermione":
    print("Gryffindor")
elif name == "Ron":
    print("Gryffindor")
elif name == "Draco":
    print("Slytherin")
else:
    print("Who?")

    Алғашқы үш шарттың бірдей нәтиже шығаратынын байқадыңыз ба? Үшеуі де Gryffindor. Бір нәрсені үш рет қайталау - кодты жақсартуға болатынының белгісі. Таныс or кілт сөзін қолданайық:

    name = input("What's your name? ")

if name == "Harry" or name == "Hermione" or name == "Ron":
    print("Gryffindor")
elif name == "Draco":
    print("Slytherin")
else:
    print("Who?")

    elif-тер азайды, код оқуға жеңілдеді. Әр салыстыруда name == қайта жазылғанына назар аударыңыз. name == "Harry" or "Hermione" деп қысқартуға болмайды, Python оны мүлде басқаша түсінеді.

    Енді сол есімдерді үйлерге match арқылы сәйкестендірейік:

    name = input("What's your name? ")

match name:
    case "Harry":
        print("Gryffindor")
    case "Hermione":
        print("Gryffindor")
    case "Ron":
        print("Gryffindor")
    case "Draco":
        print("Slytherin")
    case _:
        print("Who?")

    Бұл қалай жұмыс істейді? match сөзінен кейінгі мән (мұнда name) әр case сөзінен кейінгі мәнмен кезекпен салыстырылады. Сәйкестік табылса, сол case-тің шегіністегі коды орындалады да, салыстыру тоқтайды, қалған case-тер қаралмайды. Ал соңғы case _:-ге назар аударыңыз. Астын сызу белгісі (_) кез келген мәнге сәйкес келеді, сондықтан ол else сияқты жұмыс істейді: жоғарыдағылардың ешқайсысы сәйкес келмесе, осы орындалады.

    Ойланып көріңіз: қолданушы harry деп кіші әріппен жазса, не шығады?

    Who? шығады. match та, == да жолдарды әріп-әрпімен салыстырады, ал "harry" мен "Harry" Python үшін әртүрлі жолдар. Мұны түзету үшін 0-аптадағы әдістер көмектеседі: мысалы, name.strip().title().

    Бұл кодта да үш case бірдей нәрсе істейді. Оларды да біріктіре аламыз:

    name = input("What's your name? ")

match name:
    case "Harry" | "Hermione" | "Ron":
        print("Gryffindor")
    case "Draco":
        print("Slytherin")
    case _:
        print("Who?")

    Мұндағы жалғыз тік сызық (|) or кілт сөзі сияқты: бір case-тің ішінде бірнеше мәнді тексеруге мүмкіндік береді. «Harry немесе Hermione немесе Ron болса - Gryffindor».

    match не if?

    match бір айнымалыны көптеген нақты мәндермен салыстыру керек болғанда ыңғайлы. Ал «үлкен бе?», «аралықта ма?» сияқты сұрақтар үшін әдеттегі if/elif/else қалады. match Python-ның 3.10 нұсқасынан бастап қана бар.

    Қорытынды

    Енді сізде Python-да шартты нұсқаулар арқылы сұрақ қойып, жауабына қарай әрекет ететін бағдарламалар жазу күші бар. Бұл лекцияда біз мыналарды талқыладық:

    • шарттар және салыстыру операторлары: >, <, >=, <=, ==, !=;
    • if нұсқауы және логикалық мәндер (True, False, типі bool);
    • басқару ағыны, elif және else, блок-сызбалар;
    • or - шарттардың кез келгені ақиқат болса;
    • and - шарттардың бәрі ақиқат болса, және салыстыруларды тізбектеу (90 <= score <= 100);
    • бөлудің қалдығы (%) және жұп-тақтық;
    • логикалық мән қайтаратын өз функциямызды жазу (is_even);
    • питондық стиль және шартты өрнек;
    • match, case, case _ және |.

    Өзіңізді тексеріңіз

    1. x = 10 болса, мына код не шығарады?

    if x > 0:
    print("A")
if x > 5:
    print("B")

    Бұл екі бөлек if, сондықтан екеуі де тексеріледі. 10 > 0 те, 10 > 5 те ақиқат, демек екі жол да шығады.

    2. Енді екінші if-ті elif-ке ауыстырдық. x = 10 болса, не шығады?

    if x > 0:
    print("A")
elif x > 5:
    print("B")

    if ақиқат болған соң, Python elif-ті мүлде тексермейді. Сондықтан тек A шығады.

    3. if x = 5: деп жазылған бағдарламаны іске қоссақ, не болады?

    Салыстыру үшін екі теңдік белгісі (==) керек. Жалғыз = - меншіктеу, ол if-тің шартында рұқсат етілмейді.

    4. 17 % 5 неге тең?

    % бөлудің қалдығын береді: 17 = 5 × 3 + 2, демек қалдық 2.

    5. Мына кодта қате бар. score = 85 болса, не шығады?

    if score >= 60:
    print("Grade: D")
elif score >= 70:
    print("Grade: C")
elif score >= 80:
    print("Grade: B")
else:
    print("Grade: F")

    85 >= 60 ақиқат, сондықтан бірінші тармақ орындалады да, қалғаны тексерілмейді. Шарттардың реті маңызды: ең үлкен шекарадан бастау керек.

    6. def is_even(n): return n % 2 == 0 болса, is_even(4) нені қайтарады?

    4 % 2 = 0, ал 0 == 0 салыстыруының нәтижесі - True логикалық мәні. Функция соны қайтарады.

    7. Студент былай жазды. Қолданушы Draco енгізсе, не шығады?

    if name == "Harry" or "Hermione":
    print("Gryffindor")
else:
    print("Who?")

    Python мұны (name == "Harry") or ("Hermione") деп оқиды. Бос емес жол "Hermione" әрдайым ақиқат деп саналады, сондықтан кім енгізсе де Gryffindor шығады. Дұрысы: name == "Harry" or name == "Hermione".

    8. match нұсқауындағы case _: не істейді?

    _ - «қалған кез келгені» деген белгі. Жоғарыдағы case-тердің ешқайсысы сәйкес келмесе, осы орындалады.

    Орташа

    File Extensions (Файл кеңейтімдері)

    Windows пен macOS кейде жасырып тұрса да, көп файлдың атының соңында нүктеден (.) басталатын кеңейтімі болады. Мысалы, GIF суреттерінің аты .gif-пен, JPEG суреттерінікі .jpg не .jpeg-пен аяқталады. Файлды екі рет басқанда, компьютер оны қай бағдарламамен ашу керегін осы кеңейтімге қарап шешеді.

    Ал веб-браузерлер файлды қалай көрсету керегін медиа типтерге (бұрынғы атауы - MIME типтері) қарап анықтайды. Веб-серверден файл жүктегенде, сервер файлмен бірге оның медиа типін көрсететін HTTP тақырыпшасын жібереді. Мысалы, GIF-тің медиа типі - image/gif, JPEG-тікі - image/jpeg. Сервер әдетте медиа типті файлдың кеңейтіміне қарап анықтайды. Жиі кездесетін типтер: MDN тізімі.

    extensions.py файлында қолданушыдан файлдың атын сұрап, егер ол (бас-кіші әріпке қарамастан) төмендегі жұрнақтардың бірімен аяқталса, сол файлдың медиа типін шығаратын бағдарлама жазыңыз:

    • .gif → image/gif
    • .jpg және .jpeg → image/jpeg
    • .png → image/png
    • .pdf → application/pdf
    • .txt → text/plain
    • .zip → application/zip

    Файлдың аты басқа жұрнақпен аяқталса немесе мүлде жұрнағы болмаса, оның орнына жиі қолданылатын әдепкі мәнді, application/octet-stream шығарыңыз. Енгізудің бас-кіші әрпі мен екі шетіндегі бос орындар нәтижеге әсер етпеуі керек.

    Өзіңізді тексеріңіз: happy.jpg енгізілсе, не шығады?

    Кеңес

    Жолдың немен аяқталатынын тексеретін жол әдісін іздеңіз. Медиа типтердің «image/» бөлігі кеңейтіммен әрдайым бірдей бола бермейтінін байқаңыз: .jpg үшін image/jpg емес, image/jpeg, ал .txt үшін text/plain.

    Тексеру
    • happy.jpg → image/jpeg
    • document.pdf → application/pdf
    • Қалған форматтардың бәрі тексерілді, кеңейтімсіз файл → application/octet-stream
    • check50 cs50/problems/2022/python/extensions өтеді.

    Орташа

    Math Interpreter (Математикалық интерпретатор)

    Python математиканы біледі: сіз мәндер мен айнымалыларды қосатын, азайтатын, көбейтетін, бөлетін код жаза аласыз. Ал енді Python-ды білмейтін қолданушылардың да есептей алатын бағдарламасын жазайық.

    interpreter.py файлында қолданушыдан арифметикалық өрнек сұрап, оның нәтижесін есептейтін және бір ондық таңбаға дейін пішімделген float мәні ретінде шығаратын бағдарлама жазыңыз. Қолданушы өрнекті x y z пішімінде, x пен y арасына және y мен z арасына бір бос орын қойып енгізеді деп есептеңіз, мұнда:

    • x - бүтін сан;
    • y - +, -, * немесе /;
    • z - бүтін сан.

    Мысалы, қолданушы 1 + 1 енгізсе, бағдарлама 2.0 шығаруы керек. y / болса, z нөл болмайды деп есептеңіз. Байқадыңыз ба: python өзі Python тілінің интерпретаторы болса, сіздің interpreter.py математиканың интерпретаторы болмақ!

    Өзіңізді тексеріңіз: 2 - 3 енгізілсе, не шығады?

    Кеңес

    str-тің split әдісі жолды бөліктерге бөледі, ал бөліктерді бірден бірнеше айнымалыға меншіктеуге болады. Мысалы, expression 1 + 1 сияқты жол болса,

    x, y, z = expression.split(" ")

    x-ке 1, y-ке +, z-ке 1 меншіктейді (бәрі әлі жол екенін ұмытпаңыз). Бір ондық таңба үшін 0-аптадағы f-жол пішімін еске түсіріңіз.

    Тексеру
    • 1 + 1 → 2.0, 2 - 3 → -1.0
    • 2 * 2 → 4.0, 50 / 5 → 10.0

    Meal Time (Тамақ уақыты)

    Таңғы асты 7:00 мен 8:00 аралығында, түскі асты 12:00 мен 13:00 аралығында, кешкі асты 18:00 мен 19:00 аралығында ішу әдетке айналған елде жүрсіз делік. Қай уақытта не жеу керегін айтып тұратын бағдарлама болса, жақсы болмас па еді?

    meal.py файлында қолданушыдан уақытты сұрап, қазір breakfast time, lunch time не dinner time екенін шығаратын бағдарлама жазыңыз. Тамақ уақыты болмаса, ештеңе де шығармаңыз. Қолданушы уақытты 24 сағаттық пішімде, #:## немесе ##:## түрінде енгізеді деп есептеңіз. Әр тамақтың уақыт аралығы шекараларын қоса алғанда есептеледі: мысалы, 7:00, 7:01, 7:59, 8:00 немесе олардың арасындағы кез келген уақыт - таңғы ас уақыты.

    Бағдарламаны төмендегі құрылыммен жазыңыз. Мұнда convert - main шақыра алатын функция: ол 24 сағаттық пішімдегі time жолын сағат санына, float-қа айналдырады. Мысалы, "7:30" (7 сағат 30 минут) берілсе, convert 7.5 (7,5 сағат) қайтаруы керек.

    def main():
    ...

if __name__ == "__main__":

    Бұл соңғы екі жолды өшірмеңіз

    if __name__ == "__main__": жолы check50-ге convert функцияңызды бөлек тексеруге мүмкіндік береді. Бағдарламаңыз дұрыс жұмыс істейді деп сенімді болсаңыз да тексерістен өтпесе, осы жолдардың орнында екенін тексеріңіз. Оның мағынасын кейінгі апталарда толық түсінеміз.

    Қосымша сынақ (міндетті емес): 12 сағаттық уақытты да қолдайтын етіңіз, яғни қолданушы #:## a.m., ##:## a.m., #:## p.m., ##:## p.m. пішімдерінде де енгізе алсын.

    Өзіңізді тексеріңіз: convert("18:45") нені қайтарады?

    Кеңес

    split мұнда да көмектеседі: time "7:30" болса, hours, minutes = time.split(":") hours-қа "7", minutes-ке "30" меншіктейді. 1 сағатта 60 минут бар екенін ұмытпаңыз. Ал «аралықты қоса алғанда» дегенді лекциядағы 7 <= t <= 8 сияқты тізбектелген салыстырумен жазу ыңғайлы.

    Тексеру
    • 7:00 және 7:30 → breakfast time
    • 12:42 → lunch time, 18:32 → dinner time
    • 11:11 → ештеңе шықпайды
    • convert("7:30") 7.5 қайтарады, if __name__ == "__main__": орнында.
