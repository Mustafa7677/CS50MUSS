    CS50P туралы

    CS50P (CS50's Introduction to Programming with Python) - Гарвардтың Python бағдарламалау курсы. Алдын ала ешқандай білім керек емес. CS50x-ті өткен болсаңыз, алғашқы апталар таныс көрінеді (CS50x 6-апта: Python), бірақ мұнда әр тақырыпқа асықпай, тереңірек тоқталамыз. Мысалдардың бәрін осы беттің өзінде ▶ Іске қосу батырмасымен орындап көре аласыз.

    Бұл бет сөзбе-сөз аударма емес. Лектор аудиторияда қалай түсіндірсе, біз де солай баяндаймыз: мағынасы мен кодтың бәрі түпнұсқадағыдай, тек әңгіме ана тілімізде жүреді.

    Python-да код жазу

    Ал, бастайық! Бағдарлама жазу үшін бізге алдымен код жазатын орын керек. CS50P-да бұл - VS Code, яғни мәтіндік редактор (text editor). Оны кәдімгі Word сияқты елестетіңіз, тек мұнда әдемі мақала емес, компьютерге арналған нұсқаулық жазамыз. Редактордың төменгі жағында терминал (terminal) бар: тінтуірмен батырма баспай-ақ, компьютерге мәтін түрінде команда беретін терезе.

    Терминалға code hello.py деп жазайық. Бұл «hello.py деген жаңа файл аш» деген сөз. Соңындағы .py - бұл Python файлы екенінің белгісі. Ашылған файлға бағдарламашылардың бәрі дерлік ең бірінші жазатын жолды жазамыз:

    print("hello, world")

    Енді оны іске қосайық. Терминалға қайта оралып, доллар белгісінің ($) жанына python hello.py деп жазып, Enter басамыз. Мұнда не болып жатқанын ойлап көріңізші. Компьютер, шын мәнінде, тек нөл мен бірлікті түсінеді. Ол «print» деген ағылшын сөзін білмейді. Сондықтан ортада аудармашы бар: python бағдарламасы біздің мәтінімізді оқып, интерпретациялайды (interpret), яғни компьютер түсінетін нөл мен бірлікке айналдырады. Python дегеніміз, бір жағынан, тіл, ал екінші жағынан, сол тілді түсінетін аудармашы.

    $ python hello.py
hello, world

    Экранда hello, world пайда болды. Құттықтаймын, сіз алғашқы бағдарламаңызды жаздыңыз! Бір жол ғана болса да, бұл - нағыз бағдарлама.

    Функциялар

    Енді осы бір жолды мұқият қарайық. Ондағы print - функция (function). Функцияны тілдегі етістік сияқты елестетіңіз: «шығар», «сұра», «есепте». Python кейбір етістіктерді алдын ала біледі. Мысалы, print «экранға бірдеңе жаз» дегенді білдіреді.

    Бірақ «жаз» деу жеткіліксіз: не жазу керек? Сол «не» жақша ішінде беріледі. Функцияға берілетін мұндай мәлімет аргумент (argument) деп аталады. Біздің мысалда "hello, world" - print-ке берілген аргумент. Демек, етістік (функция) пен оның толықтауышы (аргумент) бірге келеді: «Жаз: hello, world».

    Қателер

    Енді әдейі бір қате жасап көрейін. Соңғы жақшаны ұмытып, print("hello, world" деп жазамын да, іске қосамын:

    $ python hello.py
  File "hello.py", line 1
    print("hello, world"
         ^
SyntaxError: '(' was never closed

    Python бірден ашуланды! Бірақ байқасаңыз, ол бізге көмектесуге тырысып тұр: қай файлда (hello.py), қай жолда (line 1) және не дұрыс емес екенін («( жақшасы ешқашан жабылмады») айтып тұр. Мұндай қателерді бағдарламашылар bug (bug, «қоңыз») деп атайды.

    Бір нәрсені есіңізге сақтаңыз: қате - сіздің бағдарламалауға қабілетсіз екеніңіздің белгісі емес. Әлемдегі ең мықты бағдарламашылар да күн сайын қате жібереді. Айырмашылық - олар қате хабарын оқып, шешуге дағдыланған. Бұл хабарлар әрдайым дәл осылай нақты бола бермейді, бірақ көбіне ізге түсіреді. Сондықтан қызыл жазу шықса, үрейленбей, алдымен оны оқыңыз.

    Алғашқы бағдарламаны жақсарту

    «hello, world» жақсы ғой, бірақ біз әлемге емес, нақты адамға сәлем бергіміз келеді. Ол үшін қолданушыдан атын сұрау керек. Мұны істейтін функция да бар: input. Оның аргументі - қолданушыға көрсетілетін сұрақ мәтіні (prompt):

    input("What's your name? ")
print("hello, world")

    Іске қоссақ, бағдарлама атымызды сұрайды. Біз «David» деп жазып, Enter басамыз... бірақ бағдарлама бәрібір hello, world деп жауап береді. Неге? Себебі біз атты сұрадық, бірақ оны ешқайда сақтамадық. Қолданушы жазған жауап ауада қалқып барып, жоқ болды. Оны ұстап қалу үшін бізге айнымалы керек.

    Айнымалылар

    Айнымалы (variable) - мәнді сақтайтын қобдиша сияқты. Оның сыртына жапсырма жапсырып, атау береміз, ішіне мән саламыз. Кейін сол атау арқылы мәнді қайта аламыз:

    name = input("What's your name? ")
print("hello, world")

    Мұндағы = белгісіне ерекше назар аударыңыз. Математикада ол «тең» дегенді білдіреді, ал бағдарламалауда мағынасы басқа: «оң жақтағыны есепте де, нәтижесін сол жақтағы қобдишаға сал». Мұны меншіктеу (assignment) дейді. Сондықтан бұл жолды оңнан солға қарай оқыған дұрыс: алдымен input орындалады, қолданушының жауабы name деген қобдишаға салынады.

    Жарайды, атты сақтадық. Енді оны шығарайық. Мынадай нұсқа жазылды делік:

    name = input("What's your name? ")
print("hello, name")
    Ойланып көріңіз: «David» енгізсек, не шығады?

    hello, name шығады! Тырнақшаның ішіндегінің бәрі Python үшін жай мәтін. Ол ішіндегі name сөзін айнымалы деп танымайды, әріп-әрпімен шығара салады.

    Онда айнымалыны тырнақшадан шығарып, бөлек береміз:

    name = input("What's your name? ")
print("hello,")
print(name)
    What's your name? David
hello,
David

    Жақындап қалдық! Ат шықты, бірақ екі бөлек жолда. Мұны сәлден соң түзетеміз. Python-дағы мәндердің түрлері туралы толығырақ: деректер типтері.

    Түсініктемелер

    Бағдарлама ұзарған сайын бір мәселе туады: бір айдан кейін өз кодыңызға қарап, «мен мұнда не істемек болдым?» деп ойлайсыз. Сол үшін түсініктемелер (comments) бар. Олар - кодтың шетіне жазылған ескертпелер, компьютерге емес, адамға арналған. Python-да түсініктеме # белгісінен басталады, ал интерпретатор оны мүлде елемейді:

    # Қолданушыдан атын сұраймыз
name = input("What's your name? ")
print("hello,")
print(name)

    Түсініктеме сізге де, кодыңызды кейін оқитын әріптесіңізге де көмектеседі. Оны өзіңізге арналған шағын «істер тізімі» ретінде де қолдануға болады.

    Псевдокод

    Осы соңғы ойды дамытайық. Кейде тапсырманы оқисыз да, қай жерден бастарыңызды білмейсіз. Сондай кезде кодты бірден жазбай, алдымен әр қадамды қарапайым тілмен түсініктеме ретінде жазып шығыңыз. Мұны псевдокод (pseudocode), яғни «жалған код» дейді. Ол әлі Python емес, бірақ ойыңыздың жоспары:

    # Қолданушыдан атын сұраймыз
name = input("What's your name? ")

# Сәлем айтамыз
print("hello,")

# Енгізілген атты шығарамыз
print(name)
    Кеңес: алдымен ой, сосын код

    Тапсырманы бастағанда алдымен әр қадамды # түсініктеме етіп жазыңыз, сосын әрқайсысының астына кодын толтырыңыз. Үлкен бағдарламалар да дәл осылай, жоспардан басталып жазылады.

    Бағдарламаны одан әрі жақсарту

    Енді әлгі екі жолға бөлінген мәселеге оралайық. Бірінші тәсіл: екі жолды + арқылы бір жолға жалғаймыз. Жолдар үшін + «қос» емес, «жалға» дегенді білдіреді. Мұны біріктіру (concatenation) дейді:

    # Қолданушыдан атын сұраймыз
name = input("What's your name? ")

# Сәлем мен енгізілген атты шығарамыз
print("hello, " + name)

    "hello, " соңына бос орынды әдейі қойғанымызға назар аударыңыз. Онсыз hello,David болып жабысып қалады. Екінші тәсіл: print-ке үтір арқылы екі аргумент береміз. Иә, кейбір функциялар бірнеше аргумент қабылдай алады:

    # Қолданушыдан атын сұраймыз
name = input("What's your name? ")

# Сәлем мен енгізілген атты шығарамыз
print("hello,", name)

    Нәтиже - hello, David. Бұл жолы бос орынды біз қоймадық, оны print аргументтердің арасына өзі қойды. Бұл қайдан білді? Оны келесі бөлімде түсінеміз.

    Жолдар және параметрлер

    Біз осы уақытқа дейін мәтінмен жұмыс істеп келдік. Бағдарламалауда мәтін жол (string) деп аталады, Python-да оның типі str. Енді мына кодқа тағы бір қарайық. Ол неге атты жаңа жолдан шығарып еді?

    # Қолданушыдан атын сұраймыз
name = input("What's your name? ")
print("hello,")
print(name)

    Жауап print құжаттамасында жазылған. Онда print-тің біз байқамаған бірнеше аргументі бар екені көрсетілген. Солардың бірі - end='\n'. \n - «жаңа жолға көш» деген арнайы таңба. Яғни біз ештеңе айтпасақ, print әр жолдың соңына автоматты түрде \n қосады. Мұны әдепкі мән (default value) дейді: біз басқаша айтпасақ, функция осылай істейді.

    Ал басқаша айтуға болады! end-ке өз мәнімізді берейік:

    # Қолданушыдан атын сұраймыз
name = input("What's your name? ")
print("hello,", end="")
print(name)

    Енді бірінші print соңына ештеңе қоспайды, сондықтан екіншісі сол жолдан жалғасады: hello,David. Ортасында бос орын керек болса, end=" " деп жазыңыз. Үтір арқылы берілген аргументтер арасындағы бос орынның құпиясы да осында: оны sep деген басқа параметр басқарады, оның әдепкі мәні - бір бос орын.

    Сонымен, функцияның қабылдай алатын аргументтерін параметрлер (parameters) деп атаймыз. end="" сияқты атымен берілетіндерін атаулы параметрлер (named parameters) дейді.

    Тырнақшамен шағын мәселе

    Мынадай тапсырма берілді делік: экранға hello, "friend" деп, тырнақшасымен шығару керек. Ойланбастан print("hello,"friend"") деп жазсақ, Python шатасып кетеді. Ол екінші тырнақшаны көріп, «жол осы жерде бітті» деп ойлайды да, қалғанын түсінбейді.

    Шешімнің екі жолы бар. Біріншісі: сырттағы тырнақшаларды жалқы тырнақшаға (') ауыстыру. Сонда ішіндегі қос тырнақшалар Python-ды шатастырмайды. Екіншісі, жиірек қолданылатыны: тырнақшаның алдына кері қиғаш сызық (\) қою. Ол Python-ға «келесі таңба - жолдың соңы емес, кәдімгі тырнақша» дейді. Мұны экрандау (escape) деп атайды:

    print('hello, "friend"')
print("hello, \"friend\"")

    Жолдарды пішімдеу

    Енді, менің ойымша, ең әдемі тәсілге келдік. Бланк толтырып көрдіңіз бе? «Құрметті ______, сізді шақырамыз...» Бос орынға кейін нақты есім жазылады. Python-да да дәл осындай «бланк» бар:

    # Қолданушыдан атын сұраймыз
name = input("What's your name? ")
print(f"hello, {name}")

    Тырнақшаның алдындағы кішкентай f әрпіне назар аударыңыз. Ол Python-ға «бұл жай жол емес, бланк» дейді. Python фигуралы жақшадағы {name}-ді көргенде, оның орнына айнымалының мәнін қояды. Мұндай жолды f-жол (f-string, «format» сөзінен) деп атайды. f-ті ұмытсаңыз, экранға тура hello, {name} деп шығады, байқап көріңіз. Бұл курста f-жолды өте жиі қолданамыз.

    Жолдар туралы тағы

    Бағдарламашылардың бір алтын ережесі бар: қолданушыға ешқашан толық сенбе. Ол қасақана істемесе де, атының алдына бос орын қойып жіберуі немесе бәрін кіші әріппен жазуы мүмкін. Біздің бағдарлама соған дайын болуы керек.

    Бақытымызға орай, жолдардың өз құралдары бар. Жолға тиесілі мұндай функцияларды әдістер (methods) дейді. Олар жолдың атынан кейін нүкте қойып шақырылады. Мысалы, strip әдісі жолдың екі шетіндегі бос орындарды тазалайды:

    # Қолданушыдан атын сұраймыз
name = input("What's your name? ")

# Жолдың басы мен соңындағы бос орындарды аламыз
name = name.strip()

# Нәтижені шығарамыз
print(f"hello, {name}")

    name = name.strip() жолына қараңыз: оң жақта name-нің тазаланған нұсқасы жасалады да, сол name қобдишасына қайта салынады. Енді аттың алдына не соңына қанша бос орын жазылса да, бәрі алынып тасталады.

    Ал кіші әріппен жазылған атты қалай түзетеміз? Ол үшін title әдісі бар, ол әр сөзді бас әріппен бастайды:

    # Қолданушыдан атын сұраймыз
name = input("What's your name? ")

# Бос орындарды аламыз
name = name.strip()

# Әр сөздің бірінші әрпін бас әріп етеміз
name = name.title()

# Нәтижені шығарамыз
print(f"hello, {name}")

    Бір кішкентай кеңес: терминалда python hello.py деп қайта-қайта жазу жалықтырады. Пернетақтадағы ↑ (жоғары) бағыттауышы соңғы командаларды қайта шақырады.

    Код жұмыс істейді, бірақ сәл ұзын. Әдістерді бір-біріне тізбектей жалғауға болады, сол жақтан оңға қарай орындалады: алдымен strip, сосын оның нәтижесіне title:

    # Қолданушыдан атын сұраймыз
name = input("What's your name? ")

# Бос орындарды алып, әр сөзді бас әріппен бастаймыз
name = name.strip().title()

# Нәтижені шығарамыз
print(f"hello, {name}")

    Тіпті одан әрі барып, бәрін input-пен бір жолға сыйғызуға болады:

    # Атын сұрап, бос орындарды алып, әр сөзді бас әріппен бастаймыз
name = input("What's your name? ").strip().title()

# Нәтижені шығарамыз
print(f"hello, {name}")

    Қай нұсқа жақсы? Бұл сұраққа кейінірек ораламыз. Жолдардың басқа әдістері: Python құжаттамасындағы str.

    Бүтін сандар немесе int

    Мәтіннен сандарға көшейік. Python-да бүтін сан (integer) int деп аталады. Математиканың таныс операторлары мұнда да бар: +, -, *, /. Тек біреуі жаңа болуы мүмкін: %. Бұл пайыз емес, бөлудің қалдығы (modulo): 7 % 3 = 1, себебі 7-ні 3-ке бөлгенде 1 қалады.

    Айтпақшы, Python кодын міндетті түрде файлға жазу керек емес. Терминалда жай ғана python деп жазсаңыз, >>> белгісі шығады. Бұл - интерактивті режим: 1+1 деп жазсаңыз, бірден 2 деп жауап береді. Бір нәрсені тез тексеруге ыңғайлы, бірақ бұл курста негізінен файлдармен жұмыс істейміз.

    Ендеше, өз калькуляторымызды жазайық. code calculator.py деп жаңа файл ашамыз:

    x = 1
y = 2

z = x + y

print(z)

    Іске қоссақ, 3 шығады. Таңғаларлық ештеңе жоқ. Калькулятор тек 1 мен 2-ні қосатын болса, пайдасы шамалы, сондықтан сандарды қолданушыдан сұрайық:

    x = input("What's x? ")
y = input("What's y? ")

z = x + y

print(z)
    Ойланып көріңіз: x = 1, y = 2 енгізсек, не шығады?

    12 шығады! Бұл - бүкіл лекциядағы ең маңызды сабақтардың бірі. Пернетақтадан не жазылса да, input оны әрқашан мәтін ретінде қайтарады. Біз үшін бұл 1 саны, ал Python үшін «1» деген таңба. Ал жолдар үшін + «жалға» дегенді білдіреді: «1» мен «2» жалғанып, «12» болады.

    Шешім: мәтінді санға айналдыру керек. Ол үшін int функциясы бар:

    x = input("What's x? ")
y = input("What's y? ")

z = int(x) + int(y)

print(z)

    Енді 3 шығады. Мәнді бір типтен басқа типке айналдыруды (мұнда жолдан бүтін санға) типті келтіру (casting) дейді.

    Кодты ықшамдауға болады: санға айналдыруды бірден, енгізу кезінде жасаймыз:

    x = int(input("What's x? "))
y = int(input("What's y? "))

print(x + y)

    Мұнда функция функцияның ішінде отыр. Мұндай кодты ішінен сыртқа қарай оқыңыз, математикадағы жақшалар сияқты: алдымен ішкі input орындалып, мәтін қайтарады, сосын сол мәтінді сыртқы int санға айналдырады. Толығырақ: int.

    Оқылатын код жеңеді

    Енді әлгі «қай нұсқа жақсы?» деген сұраққа оралайық. Байқағаныңыздай, бір есепті бірнеше жолмен шешуге болады: біреуі қысқа, біреуі ұзынырақ, бірақ түсінікті. Нақты бір дұрыс жауап жоқ, бірақ бір ереже бар: кодыңыз оқылатын болуы керек. Кодты бір рет жазасыз, ал оқу жүз рет келеді, сізге де, басқаларға да. Бәрін бір жолға тығып, «мықтымын» деп ойлаудың қажеті жоқ. Ертең өзіңіз түсінбей қалатын болсаңыз, ол ұтыс емес. Түсініктемелер жазыңыз, кодты бөліктерге бөліңіз, ол үшін ұялмаңыз.

    Float негіздері

    Біздің калькулятордың бір кемшілігі бар: ол тек бүтін сандарды түсінеді. 1.5 енгізсек, int қате береді. Ондық бөлшегі бар сандар үшін басқа тип керек: жылжымалы нүктелі сан (floating-point value), Python-да float. Мысалы, 0.52 немесе 3.14. Кодта бір ғана сөзді ауыстырамыз:

    x = float(input("What's x? "))
y = float(input("What's y? "))

print(x + y)

    Енді 1.2 мен 3.4 енгізсек, 4.6 шығады.

    Ал нәтижені ең жақын бүтін санға дөңгелектегіміз келсе ше? Бұл үшін round функциясы бар. Құжаттамада ол round(number[, ndigits]) деп жазылған. Мұндағы тік жақшаға назар аударыңыз: құжаттамада ол «мұны беру міндетті емес» дегенді білдіреді. Яғни round(n) деп жалғыз санды берсек, ол бүтінге дөңгелектейді:

    # Қолданушыдан сандарды аламыз
x = float(input("What's x? "))
y = float(input("What's y? "))

# Дөңгелектенген нәтиже
z = round(x + y)

# Нәтижені шығарамыз
print(z)

    Үлкен сандарды оқу қиын: 1000000 бір миллион ба, әлде он миллион ба? Ағылшын тілді елдерде мыңдықтарды үтірмен бөледі: 1,000,000. f-жол мұны да біледі:

    # Қолданушыдан сандарды аламыз
x = float(input("What's x? "))
y = float(input("What's y? "))

# Дөңгелектенген нәтиже
z = round(x + y)

# Пішімделген нәтижені шығарамыз
print(f"{z:,}")

    Жазылуы сәл жұмбақ: {z:,}. Қос нүктеден кейінгі бөлік Python-ға z-ті қалай көрсету керегін айтады, ал үтір «мыңдықтарды үтірмен бөл» дегенді білдіреді. Нәтиже: 1,000 немесе 2,500.

    Float туралы тағы

    Енді бөлуді қарайық, онда қызық нәрсе бар:

    # Қолданушыдан сандарды аламыз
x = float(input("What's x? "))
y = float(input("What's y? "))

# Нәтижені есептейміз
z = x / y

# Нәтижені шығарамыз
print(z)

    2-ні 3-ке бөлсек, 0.6666666666666666 шығады. Алтылар шексіз жалғаса беретін сияқты. Әдетте мұншама дәлдік керек емес, екі таңба жетеді. round-тың әлгі міндетті емес екінші аргументі осында керек болады:

    # Қолданушыдан сандарды аламыз
x = float(input("What's x? "))
y = float(input("What's y? "))

# Есептеп, дөңгелектейміз
z = round(x / y, 2)

# Нәтижені шығарамыз
print(z)

    Нәтиже 0.67. Дәл осыны f-жолмен де жасауға болады:

    # Қолданушыдан сандарды аламыз
x = float(input("What's x? "))
y = float(input("What's y? "))

# Нәтижені есептейміз
z = x / y

# Нәтижені шығарамыз
print(f"{z:.2f}")

    :.2f пішімін «нүктеден кейін 2 таңбамен, float етіп» деп оқыңыз. Толығырақ: float.

    round пен :.2f айырмашылығы

    round(x, 2) жаңа сан қайтарады (мысалы, 0.5), ал f"{x:.2f}" әрқашан екі таңбалы жол береді ("0.50"). Ақша сияқты мәндерді шығарғанда, әдетте f-жол ыңғайлырақ.

    def: өз функцияларымыз

    Осы уақытқа дейін біз Python-ның дайын функцияларын қолдандық: print, input, int, round. Ал Python-да біз қалаған «етістік» болмаса ше? Ештеңе етпейді, оны өзіміз жасаймыз! Мысалы, hello деген функция болса ғой деп армандайық:

    name = input("What's your name? ")
hello()
print(name)

    Іске қоссақ, NameError қатесі шығады: Python «hello деген сөзді білмеймін» дейді. Әділ ескерту. Оны үйретейік. Ол үшін def (define, «анықтау») деген кілт сөз бар:

    def hello():
    print("hello")


name = input("What's your name? ")
hello()
print(name)

    def hello(): жолы «hello деген жаңа функция жасаймын, ол былай істейді:» дегенді білдіреді. Ал «былай» дегені - астындағы шегініспен (indentation) жазылған жолдар. Python-да шегініс сәндік үшін емес, оның мағынасы бар: қай жол функцияның ішінде, қайсысы сыртында екенін Python дәл соған қарап анықтайды. Бағдарлама енді жұмыс істейді, бірақ әлі де «hello» мен атты екі жолға шығарады.

    Функцияны жақсартайық: ол кімге сәлем беретінін сырттан қабылдасын:

    # Өз функциямызды құрамыз
def hello(to):
    print("hello,", to)


# Өз функциямызбен шығарамыз
name = input("What's your name? ")
hello(name)

    Жақша ішіндегі to - функцияның параметрі. Оны функцияның ішіндегі бос қобдиша деп елестетіңіз. hello(name) деп шақырғанда, Python name-нің мәнін («David») алып, сол to қобдишасына салады да, функцияның ішін орындайды. Мәндер функцияларға дәл осылай беріледі.

    Енді параметрге әдепкі мән берейік, print-тің end-і сияқты:

    # Өз функциямызды құрамыз
def hello(to="world"):
    print("hello,", to)


# Өз функциямызбен шығарамыз
name = input("What's your name? ")
hello(name)

# Аргументсіз шақырамыз
hello()

    Бірінші шақыру hello, David шығарады. Ал екіншісі ештеңе бермегендіктен, әдепкі мәнді алып, hello, world шығарады. Өзіңіз іске қосып, тексеріп көріңіз.

    Бағдарлама өскен сайын тағы бір сұрақ туады: кодты қалай ретке келтіреміз? Әдетте бағдарламашылар ең маңызды бөлікті жоғарыға, main деген функцияға жазады, ал көмекші функцияларды төменге қояды. Солай істеп көрейік:

    def main():

    # Өз функциямызбен шығарамыз
    name = input("What's your name? ")
    hello(name)

    # Аргументсіз шақырамыз
    hello()


# Өз функциямызды құрамыз
def hello(to="world"):
    print("hello,", to)
    Ойланып көріңіз: бұл бағдарламаны іске қоссақ, не болады?

    Ештеңе болмайды! Біз екі функцияны анықтадық, яғни Python-ға «бұлар былай істейді» деп үйреттік. Бірақ ешқайсысын шақырмадық. Рецептті жазып қойғанмен, тамақ өзінен-өзі пісіп қалмайды ғой.

    Шешімі бір ғана жол: файлдың ең соңында main-ді шақырамыз:

    def main():

    # Өз функциямызбен шығарамыз
    name = input("What's your name? ")
    hello(name)

    # Аргументсіз шақырамыз
    hello()


# Өз функциямызды құрамыз
def hello(to="world"):
    print("hello,", to)


main()
    Неге main соңында шақырылады?

    Python файлды жоғарыдан төменге қарай оқиды. main() ең соңында шақырылса, ол кезге дейін hello да анықталып болған. Сондықтан функцияларды кез келген ретпен жаза аламыз: ең маңыздысы (main) жоғарыда, көмекшілері төменде.

    Мән қайтару

    Біздің hello бір әрекет жасайды, экранға жазады, бар болғаны сол. Бірақ көп функцияның міндеті басқа: олар есептеп, нәтижесін бізге қайтарып беруі керек. input солай істейтін: қолданушының жауабын бізге қайтарып береді, ал біз оны айнымалыға сақтаймыз. Мұны қайтарылатын мән (return value) дейді. Өз функцияларымыз да мән қайтара алады, ол үшін return кілт сөзі бар. Калькуляторымызға оралайық:

    def main():
    x = int(input("What's x? "))
    print("x squared is", square(x))


def square(n):
    return n * n


main()

    Не болып жатқанын қадамдап қарайық. main x-ті square-ге береді. square оны n деп атап, n * n-ді есептейді де, return арқылы нәтижені шақырған жерге, яғни main-ге қайтарады. main сол нәтижені print-ке береді. Функциялар бір-біріне жұмыс тапсырып, нәтижесін алып отырған шағын командаға ұқсайды.

    print пен return - екі түрлі нәрсе

    print мәнді экранға шығарады, бірақ бағдарлама сол мәнді ары қарай қолдана алмайды. return мәнді шақырған жерге қайтарады, сондықтан онымен ары қарай есептей беруге болады: square(square(3)) = 81.

    Қорытынды

    Осы бір лекцияда сіз өз бағдарламаларыңызда сан рет қолданатын дағдыларды үйрендіңіз:

    • Python-да алғашқы бағдарламаларды жазу және python hello.py арқылы іске қосу;
    • функциялар мен аргументтер: print, input, int, float, round;
    • қателер мен олардың хабарлары;
    • айнымалылар және = меншіктеу;
    • түсініктемелер (#) және псевдокод;
    • жолдар (str), олардың әдістері (strip, title) және параметрлер (end="");
    • f-жолдар: f"hello, {name}", f"{z:,}", f"{z:.2f}";
    • бүтін сандар (int) және жылжымалы нүктелі сандар (float);
    • оқылатын код принципі;
    • def арқылы өз функцияларымызды құру, main және қайтарылатын мән (return).

    Өзіңізді тексеріңіз

    1. x = input("x: ") және y = input("y: ") болса, 1 мен 2 енгізгенде print(x + y) не шығарады?

    input әрқашан жол қайтарады, ал жолдар үшін + біріктіреді: "1" + "2" = "12".

    2. print("hello,", end="") не істейді?

    end параметрінің әдепкі мәні "\n". Оны "" етсек, келесі print сол жолдан жалғасады.

    3. " david malan ".strip().title() нәтижесі қандай?

    strip шеттегі бос орындарды алады, title әр сөзді бас әріппен бастайды.

    4. z = 2 / 3 болса, print(f"{z:.2f}") не шығарады?

    :.2f үтірден кейін екі таңбаға дейін дөңгелектеп, жол етіп шығарады.

    5. Мына бағдарлама іске қосылса, не болады?

    def main():
    print("hello")

    Функция анықталды, бірақ шақырылмады. Соңына main() қосу керек.

    6. def square(n): return n * n болса, square(square(2)) неге тең?

    Алдымен ішкі square(2) = 4, сосын square(4) = 16. return болғандықтан мәнді ары қарай қолдануға болады.

    7. Python-да int(input("x: ")) жолында қай функция бірінші орындалады?

    Ішкі функция бірінші: input жол қайтарады, сосын int оны санға айналдырады.

    Тапсырмалар жинағы 0

    Making Faces (Бет-әлпет)

    Эмодзилерден бұрын эмотикондар болды: :) - күлімдеген бет, :( - мұңды бет. Қазір бағдарламалар оларды автоматты түрде эмодзиге айналдырады!

    faces.py файлында convert функциясын жазыңыз: ол жол қабылдап, ішіндегі әр :)-ты 🙂-ге, әр :(-ты 🙁-ге ауыстырып, қайтарады. Қалған мәтін өзгермейді.

    Сол файлда main функциясын жазыңыз: ол қолданушыдан мәтін сұрап, оған convert-ті қолданып, нәтижесін шығарады. Файлдың соңында main-ді шақыруды ұмытпаңыз.

    Оңай

    Einstein (Эйнштейн)

    Физиканы оқымасаңыз да, E = mc² формуласын естіген боларсыз: E - энергия (Джоуль), m - масса (килограмм), c - жарық жылдамдығы (шамамен 300000000 метр/секунд). Формула масса мен энергияның баламалы екенін білдіреді.

    einstein.py файлында қолданушыдан массаны бүтін сан (кг) ретінде сұрап, оған тең Джоуль санын бүтін сан етіп шығаратын бағдарлама жазыңыз. Қолданушы бүтін сан енгізеді деп есептеңіз.

    Өзіңізді тексеріңіз: массасы 1 кг болса, неше Джоуль?

    Кеңес

    input жол қайтарады, оны int арқылы санға айналдырыңыз. Python-да дәрежеге шығару - **: c ** 2. float емес, int қолданыңыз, әйтпесе 9e+16 шығады.

    Тексеру
    • 14 → 1260000000000000000
    • check50 cs50/problems/2022/python/einstein өтеді.

    Орташа

    Tip Calculator (Шайпұл калькуляторы)

    АҚШ-та мейрамханада даяшыға тамақ құнының 15% не одан көп мөлшерінде шайпұл қалдыру әдетке айналған. Біз сізге шайпұл калькуляторының көп бөлігін жазып қойдық (кодын автотексерушіде көресіз), бірақ екі функцияны жазуға үлгермедік:

    • dollars_to_float - $##.## пішіміндегі жолды қабылдап (# - цифр), басындағы $-ты алып тастап, соманы float етіп қайтарады. Мысалы, $50.00 → 50.0.
    • percent_to_float - ##% пішіміндегі жолды қабылдап, соңындағы %-ті алып тастап, пайызды float етіп қайтарады. Мысалы, 15% → 0.15.

    Қолданушы мәндерді күтілген пішімде енгізеді деп есептеңіз.

    Кеңес

    float жолды бөлшек санға айналдырады. Жолдың басынан не соңынан таңбаны алып тастайтын әдістерді құжаттамадан іздеңіз (мысалы, removeprefix, removesuffix не replace). Пайызды 100-ге бөлуді ұмытпаңыз.

    Тексеру
    • $50.00 және 15% → Leave $7.50
    • $15.00 және 25% → Leave $3.75
    • check50 cs50/problems/2022/python/tip өтеді.
