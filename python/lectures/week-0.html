    CS50P туралы

    CS50P (CS50's Introduction to Programming with Python) - Гарвардтың Python бағдарламалау курсы. Алдын ала білім керек емес. Егер CS50x-ті өтсеңіз, алғашқы апталар таныс болады (CS50x 6-апта: Python), бірақ мұнда әр тақырып әлдеқайда тереңірек әрі баяуырақ түсіндіріледі. Барлық мысалды осы беттің өзінде ▶ Іске қосу батырмасымен орындауға болады.

    Python-да код жазу

    • VS Code - мәтіндік редактор (text editor). Мәтінді өңдеуден бөлек, файлдарды көріп, терминалда (terminal) мәтіндік командаларды іске қосуға болады.
    • Терминалда code hello.py деп жазсаңыз, жаңа файл ашылады.
    • Редакторға print("hello, world") деп жазыңыз. Бұл - бағдарлама үйренушілердің бәрі дерлік жазатын әйгілі алғашқы бағдарлама.
    print("hello, world")
    • Бағдарламаны іске қосу үшін терминал терезесін басып, доллар белгісінің қасына python hello.py деп жазып, Enter басыңыз.
    • Компьютер тек нөл мен бірлікті түсінетінін еске түсірейік. python hello.py іске қосылғанда, Python hello.py-дегі мәтінді интерпретациялап (interpret), компьютер түсінетін нөл мен бірлікке айналдырады.
    • Нәтижесі - терминалда hello, world жазуы.
    $ python hello.py
hello, world

    Құттықтаймыз! Сіз алғашқы бағдарламаңызды жаздыңыз.

    Функциялар

    • Функциялар (functions) - компьютер не бағдарламалау тілі қалай орындауды алдын ала білетін етістіктер, яғни әрекеттер.
    • hello.py бағдарламасындағы print функциясы терминалға мәтін шығаруды біледі.
    • print функциясы аргумент (argument) қабылдайды. Біздің мысалда "hello, world" - print-ке берілген аргумент.

    Қателер

    • Қателер (bugs) - бағдарламалаудың табиғи бөлігі. Бұл - сіз шешуге тиіс мәселелер. Көңіліңіз түспесін! Бұл - мықты бағдарламашы болу жолының бір бөлігі.
    • hello.py-де байқаусызда print("hello, world" деп, соңғы ) жақшасын ұмытып кеттік делік. Сонда интерпретатор терминалда қате туралы хабар шығарады.
    • Қате туралы хабарлар көбіне қатені көрсетіп, оны қалай түзетуге болатынын меңзейді. Бірақ интерпретатор әрқашан осылай көмектесе бермейтінін де ескеріңіз.
    $ python hello.py
  File "hello.py", line 1
    print("hello, world"
         ^
SyntaxError: '(' was never closed

    Алғашқы бағдарламаны жақсарту

    • Бағдарламаны жекелендірейік. hello.py-ге тағы бір функция қосамыз: input. Ол аргумент ретінде сұрақ мәтінін (prompt) қабылдайды:
    input("What's your name? ")
print("hello, world")
    • Бірақ бұл өзгеріс жеткіліксіз: бағдарлама қолданушы енгізгенді шығара алмайды. Ол үшін айнымалылармен танысу керек.

    Айнымалылар

    • Айнымалы (variable) - бағдарлама ішіндегі мәнге арналған жай ғана «ыдыс».
    • Бағдарламада өз айнымалыңызды былай құра аласыз:
    name = input("What's your name? ")
print("hello, world")

    Ортадағы = белгісінің бағдарламалауда ерекше рөлі бар: ол оң жақтағыны сол жаққа меншіктейді (assignment). Яғни input("What's your name? ") қайтарған мән name айнымалысына сақталады. Бұл - математикадағы «тең» емес.

    • Кодты былай өзгертсеңіз, күтпеген нәтиже шығады:
    name = input("What's your name? ")
print("hello, name")
    • Қолданушы не жазса да, бағдарлама hello, name деп шығарады. Тырнақша ішіндегі name - айнымалы емес, жай мәтін.
    • Кодты тағы өзгертейік:
    name = input("What's your name? ")
print("hello,")
print(name)

    Терминалдағы нәтиже:

    What's your name? David
hello,
David

    Мақсатқа жақындап қалдық! Толығырақ: Python құжаттамасындағы деректер типтері.

    Түсініктемелер

    • Түсініктемелер (comments) - бағдарламашы өз кодында не істеп жатқанын белгілеп, басқаларға да код бөлігінің мақсатын түсіндіретін жазбалар. Қысқасы, өзіңізге және кодыңызды оқитын басқаларға арналған ескертпелер.
    • Python-да түсініктеме # белгісінен басталады, интерпретатор оны елемейді:
    # Қолданушыдан атын сұраймыз
name = input("What's your name? ")
print("hello,")
print(name)
    • Түсініктемелер өзіңізге арналған «істер тізімі» бола алады.

    Псевдокод

    • Псевдокод (pseudocode) - түсініктеменің маңызды түрі. Ол, әсіресе тапсырманы қалай орындау керегін әлі білмегенде, ерекше «істер тізіміне» айналады:
    # Қолданушыдан атын сұраймыз
name = input("What's your name? ")

# Сәлем айтамыз
print("hello,")

# Енгізілген атты шығарамыз
print(name)
    Кеңес: алдымен ой, сосын код

    Тапсырманы бастағанда алдымен әр қадамды қарапайым тілмен # түсініктеме етіп жазыңыз, сосын әр түсініктеменің астына кодын толтырыңыз. Бұл - ірі бағдарламалардың да жазылу тәсілі.

    Бағдарламаны одан әрі жақсарту

    • Кодты былай өзгертуге болады:
    # Қолданушыдан атын сұраймыз
name = input("What's your name? ")

# Сәлем мен енгізілген атты шығарамыз
print("hello, " + name)
    • Жолдар арасындағы + оларды біріктіреді (concatenation).
    • Кейбір функциялар бірнеше аргумент қабылдайды. Үтір , арқылы бірнеше аргумент беруге болады:
    # Қолданушыдан атын сұраймыз
name = input("What's your name? ")

# Сәлем мен енгізілген атты шығарамыз
print("hello,", name)

    «David» енгізсек, терминалда hello, David шығады. Жарайды! print аргументтерінің арасына өзі бір бос орын қояды.

    Жолдар және параметрлер

    • Жол (string), Python-да str деп аталады, - мәтін тізбегі.
    • Бұрынғы кодқа қайта оралайық. Нәтиже бірнеше жолға бөлініп шыққан еді:
    # Қолданушыдан атын сұраймыз
name = input("What's your name? ")
print("hello,")
print(name)
    • Функциялар өз жұмысына әсер ететін аргументтер қабылдайды. print құжаттамасына қарасаңыз, оның қабылдайтын аргументтері туралы көп нәрсе білесіз.
    • Құжаттамада print-тің автоматты түрде end='\n' аргументін алатыны жазылған. \n - жаңа жол. Яғни end параметрінің әдепкі мәні (default value) - жаңа жолға көшу.
    • Бірақ end аргументін өзіміз беріп, жаңа жолға көшпеуге болады:
    # Қолданушыдан атын сұраймыз
name = input("What's your name? ")
print("hello,", end="")
print(name)

    end="" бергенде, біз end-тің әдепкі мәнін ауыстырдық, сондықтан бірінші print-тен кейін жаңа жол басталмайды. «David» енгізсек, нәтиже hello,David болады (бос орын қажет болса, end=" " жазыңыз).

    • Демек, параметрлер (parameters) - функция қабылдай алатын аргументтер. Ал end="" сияқты атымен берілетіндері - атаулы параметрлер.

    Тырнақшамен шағын мәселе

    • Жолдың ішіне тырнақша қосу оңай емес. print("hello,"friend"") жұмыс істемейді, интерпретатор қате береді.
    • Мұны екі жолмен шешуге болады. Біріншісі - сыртқы тырнақшаларды жалқы тырнақшаға ауыстыру: print('hello, "friend"').
    • Екінші, жиірек қолданылатын тәсіл - кері қиғаш сызық: print("hello, \"friend\""). Кері қиғаш сызық интерпретаторға келесі таңбаны жолдың бір бөлігі ретінде, яғни кәдімгі тырнақша ретінде қабылдауды айтады. Мұны экрандау (escape) дейді.
    print('hello, "friend"')
print("hello, \"friend\"")

    Жолдарды пішімдеу

    • Жолдарды қолданудың ең әсем тәсілі шығар:
    # Қолданушыдан атын сұраймыз
name = input("What's your name? ")
print(f"hello, {name}")

    print(f"hello, {name}") ішіндегі f әрпіне назар аударыңыз. Ол Python-ға бұл жолды ерекше өңдеуді айтады: фигуралы жақша ішіндегі {name} айнымалының мәнімен ауыстырылады. Мұндай жол f-жол (f-string) деп аталады. Бұл курста оны жиі қолданамыз.

    Жолдар туралы тағы

    • Қолданушы әрқашан күткендей жазады деп ойламаңыз. Енгізілгенді тексеріп, түзетіп отыру керек.
    • Жолдардың ішінде бос орындарды алып тастау мүмкіндігі бар. name-ге strip әдісін (method) қолдансақ (name = name.strip()), қолданушы енгізгеннің сол және оң жағындағы бос орындар жойылады:
    # Қолданушыдан атын сұраймыз
name = input("What's your name? ")

# Жолдың басы мен соңындағы бос орындарды аламыз
name = name.strip()

# Нәтижені шығарамыз
print(f"hello, {name}")

    Енді аттың алдына не соңына қанша бос орын жазсаңыз да, бәрі алынып тасталады.

    • title әдісі әр сөзді бас әріппен бастайды:
    # Қолданушыдан атын сұраймыз
name = input("What's your name? ")

# Бос орындарды аламыз
name = name.strip()

# Әр сөздің бірінші әрпін бас әріп етеміз
name = name.title()

# Нәтижені шығарамыз
print(f"hello, {name}")
    • Терминалда python деп қайта-қайта жазудан шаршаған боларсыз. Пернетақтадағы ↑ (жоғары) бағыттауышы соңғы командаларды қайта шақырады.
    • Кодты қысқартып, әдістерді тізбектей шақыруға болады:
    # Қолданушыдан атын сұраймыз
name = input("What's your name? ")

# Бос орындарды алып, әр сөзді бас әріппен бастаймыз
name = name.strip().title()

# Нәтижені шығарамыз
print(f"hello, {name}")
    • Тіпті одан да әрі баруға болады:
    # Атын сұрап, бос орындарды алып, әр сөзді бас әріппен бастаймыз
name = input("What's your name? ").strip().title()

# Нәтижені шығарамыз
print(f"hello, {name}")

    Толығырақ: Python құжаттамасындағы str.

    Бүтін сандар немесе int

    • Python-да бүтін сан (integer) int деп аталады.
    • Математикадан +, -, *, / және % операторлары таныс. Соңғысы, %, - бөлудің қалдығы (modulo): 7 % 3 = 1.
    • Python кодын міндетті түрде файлға жазу керек емес. Терминалда жай python деп жазсаңыз, >>> белгісі шығады. Мұнда кодты бірден, интерактивті түрде орындауға болады: мысалы, 1+1 деп жазсаңыз, нәтижесі шығады. Бұл курста бұл режимді сирек қолданамыз.
    • Өз калькуляторымызды жазайық. Терминалда code calculator.py деп жазып, бірнеше айнымалы жариялайық:
    x = 1
y = 2

z = x + y

print(z)

    python calculator.py іске қосылғанда, терминалда 3 шығады. Енді оны input арқылы интерактивті етейік:

    x = input("What's x? ")
y = input("What's y? ")

z = x + y

print(z)
    • 1 мен 2 енгізсек, нәтиже қате, 12 болып шығады. Неге?
    • Біз + белгісінің екі жолды біріктіретінін көрдік. Пернетақтадан енгізілгеннің бәрі интерпретаторға мәтін ретінде келеді, яғни ол - жол. Сондықтан кірісті жолдан бүтін санға айналдыру керек:
    x = input("What's x? ")
y = input("What's y? ")

z = int(x) + int(y)

print(z)

    Енді нәтиже дұрыс. int(x) қолдануды типті келтіру (casting) дейді: мән бір типтен (мұнда жолдан) басқа типке (бүтін санға) айналдырылады.

    • Бағдарламаны былай жақсартуға болады:
    x = int(input("What's x? "))
y = int(input("What's y? "))

print(x + y)

    Бұл - функцияны функцияның ішінде шақыруға болатынын көрсетеді. Алдымен ішкі функция орындалады, сосын сыртқысы: алдымен input, сосын int. Толығырақ: int.

    Оқылатын код жеңеді

    • Бір есепті шешудің көптеген жолы бар және олардың әрқайсысының өз дәлелі болуы мүмкін.
    • Қай жолды таңдасаңыз да, кодыңыз оқылатын болуы керек. Өзіңізге және басқаларға код не істейтінін түсініктемелер арқылы түсіндіріңіз. Кодты оқуға оңай етіп жазыңыз: өте ұзын бір жол әрқашан ең жақсы шешім емес.

    Float негіздері

    • Жылжымалы нүктелі сан (floating-point value), Python-да float, - ондық бөлшегі бар нақты сан, мысалы 0.52.
    • Кодты float-ты қолдайтындай өзгертейік:
    x = float(input("What's x? "))
y = float(input("What's y? "))

print(x + y)

    Енді қолданушы 1.2 мен 3.4 енгізсе, нәтиже 4.6 болады.

    • Нәтижені жуық бүтін санға дөңгелектегіміз келді делік. Python құжаттамасында round функциясының аргументтері round(number[, ndigits]) деп жазылған. Тік жақша - бағдарламашы міндетті емес (қосымша) нәрсені бере алатынын білдіреді. Сондықтан round(n) санды жуық бүтінге дөңгелектейді:
    # Қолданушыдан сандарды аламыз
x = float(input("What's x? "))
y = float(input("What's y? "))

# Дөңгелектенген нәтиже
z = round(x + y)

# Нәтижені шығарамыз
print(z)
    • Үлкен сандарды пішімдеп шығарғымыз келсе ше? Мысалы, 1000 емес, 1,000:
    # Қолданушыдан сандарды аламыз
x = float(input("What's x? "))
y = float(input("What's y? "))

# Дөңгелектенген нәтиже
z = round(x + y)

# Пішімделген нәтижені шығарамыз
print(f"{z:,}")

    Сәл жұмбақ көрінсе де, print(f"{z:,}") мыңдықтарды үтірмен бөледі: 1,000 не 2,500.

    Float туралы тағы

    • Бөлшек сандарды қалай дөңгелектейміз? Алдымен бөлуді жазайық:
    # Қолданушыдан сандарды аламыз
x = float(input("What's x? "))
y = float(input("What's y? "))

# Нәтижені есептейміз
z = x / y

# Нәтижені шығарамыз
print(z)

    x = 2, y = 3 енгізсек, нәтиже 0.6666666666666666 - шексіз жалғасатын сияқты.

    • Үтірден кейін екі таңбаға дейін дөңгелектейік:
    # Қолданушыдан сандарды аламыз
x = float(input("What's x? "))
y = float(input("What's y? "))

# Есептеп, дөңгелектейміз
z = round(x / y, 2)

# Нәтижені шығарамыз
print(z)
    • Мұны f-жолмен де жасауға болады:
    # Қолданушыдан сандарды аламыз
x = float(input("What's x? "))
y = float(input("What's y? "))

# Нәтижені есептейміз
z = x / y

# Нәтижені шығарамыз
print(f"{z:.2f}")

    :.2f - «үтірден кейін 2 таңбамен float етіп шығар» деген пішім. Нәтиже алдыңғы тәсілмен бірдей. Толығырақ: float.

    round пен :.2f айырмашылығы

    round(x, 2) жаңа сан қайтарады (мысалы, 0.5), ал f"{x:.2f}" - әрқашан екі таңбалы жол ("0.50"). Ақша сияқты мәндерді шығарғанда, әдетте f-жол ыңғайлырақ.

    def: өз функцияларымыз

    • Өз функцияларымызды жасай алсақ, керемет болар еді ғой?
    • hello.py-нің соңғы нұсқасын еске түсірейік:
    # Атын сұрап, бос орындарды алып, әр сөзді бас әріппен бастаймыз
name = input("What's your name? ").strip().title()

# Нәтижені шығарамыз
print(f"hello, {name}")

    Бізге «hello» деп айтатын арнайы функция жасайық! Кодты түгел өшіріп, басынан бастайық:

    name = input("What's your name? ")
hello()
print(name)

    Бұл кодты іске қоссақ, интерпретатор қате береді: hello деген функция анықталмаған (NameError).

    • hello функциясын def (define - анықтау) кілт сөзімен өзіміз құрайық:
    def hello():
    print("hello")


name = input("What's your name? ")
hello()
print(name)

    def hello(): астындағының бәрі шегініспен (indentation) жазылғанына назар аударыңыз. Python шегініс арқылы қай жол функцияға тиесілі екенін түсінеді. Шегініссіз жазылған жол функциядан тыс саналады. Бұл бағдарламаны іске қоссақ, нәтиже әлі біз қалағандай емес.

    • Кодты жақсартайық:
    # Өз функциямызды құрамыз
def hello(to):
    print("hello,", to)


# Өз функциямызбен шығарамыз
name = input("What's your name? ")
hello(name)

    Бұл жолы функция бір параметр қабылдайды: to деген айнымалы. hello(name) шақырылғанда, компьютер name-нің мәнін функцияға to ретінде береді. Мәндер функцияларға осылай беріледі. Өте пайдалы!

    • Параметрге әдепкі мән беруге болады:
    # Өз функциямызды құрамыз
def hello(to="world"):
    print("hello,", to)


# Өз функциямызбен шығарамыз
name = input("What's your name? ")
hello(name)

# Аргументсіз шақырамыз
hello()

    Өзіңіз тексеріп көріңіз: бірінші hello күткендей жұмыс істейді, ал мәнсіз шақырылған екіншісі әдепкі бойынша hello, world шығарады.

    • Функцияның бағдарламаның басында тұруы міндетті емес. Оны төменге жылжытуға болады, бірақ онда main деген негізгі функция мен бөлек hello функциясы бар екенін көрсету керек:
    def main():

    # Өз функциямызбен шығарамыз
    name = input("What's your name? ")
    hello(name)

    # Аргументсіз шақырамыз
    hello()


# Өз функциямызды құрамыз
def hello(to="world"):
    print("hello,", to)

    Бірақ бұл код ештеңе істемейді! python hello.py іске қоссақ, ештеңе болмайды. Себебі ешкім main функциясын шақырмады, бағдарлама «жанданбады».

    • Кішкентай ғана өзгеріс main-ді шақырып, бағдарламаны жұмыс күйіне келтіреді:
    def main():

    # Өз функциямызбен шығарамыз
    name = input("What's your name? ")
    hello(name)

    # Аргументсіз шақырамыз
    hello()


# Өз функциямызды құрамыз
def hello(to="world"):
    print("hello,", to)


main()
    Неге main соңында шақырылады?

    Python файлды жоғарыдан төменге оқиды. main() соңында шақырылса, ол кезде hello да анықталып болған. Сондықтан функцияларды кез келген ретте жазуға болады: ең маңыздысы (main) жоғарыда, көмекшілері төменде.

    Мән қайтару

    • Көп жағдайда функция жай бір әрекет жасап қана қоймай, нәтижесін бағдарламаның басқа бөлігіне қайтаруы керек. Мысалы, x + y-ті шығарудың орнына оны қайтару. Мұны қайтарылатын мән (return value) дейміз.
    • calculator.py-ге оралып, кодты былай жазайық:
    def main():
    x = int(input("What's x? "))
    print("x squared is", square(x))


def square(n):
    return n * n


main()

    Мұнда x square функциясына беріледі. Ол n * n-ді есептеп, нәтижесін return арқылы main-ге қайтарады, ал main оны шығарады.

    print пен return - екі түрлі нәрсе

    print мәнді экранға шығарады, бірақ бағдарлама оны қолдана алмайды. return мәнді шақырған жерге қайтарады, сол мәнмен ары қарай есептеуге болады: square(square(3)) = 81.

    Қорытынды

    Осы бір лекцияда сіз өз бағдарламаларыңызда сан рет қолданатын дағдыларды үйрендіңіз:

    • Python-да алғашқы бағдарламаларды жазу және python hello.py арқылы іске қосу;
    • функциялар мен аргументтер: print, input, int, float, round;
    • қателер мен олардың хабарлары;
    • айнымалылар және = меншіктеу;
    • түсініктемелер (#) және псевдокод;
    • жолдар (str), олардың әдістері (strip, title) және параметрлер (end="");
    • f-жолдар: f"hello, {name}", f"{z:,}", f"{z:.2f}";
    • бүтін сандар (int) және жылжымалы нүктелі сандар (float);
    • оқылатын код принципі;
    • def арқылы өз функцияларымызды құру, main және қайтарылатын мән (return).

    Өзіңізді тексеріңіз

    1. x = input("x: ") және y = input("y: ") болса, 1 мен 2 енгізгенде print(x + y) не шығарады?

    input әрқашан жол қайтарады, ал жолдар үшін + біріктіреді: "1" + "2" = "12".

    2. print("hello,", end="") не істейді?

    end параметрінің әдепкі мәні "\n". Оны "" етсек, келесі print сол жолдан жалғасады.

    3. " david malan ".strip().title() нәтижесі қандай?

    strip шеттегі бос орындарды алады, title әр сөзді бас әріппен бастайды.

    4. z = 2 / 3 болса, print(f"{z:.2f}") не шығарады?

    :.2f үтірден кейін екі таңбаға дейін дөңгелектеп, жол етіп шығарады.

    5. Мына бағдарлама іске қосылса, не болады?

    def main():
    print("hello")

    Функция анықталды, бірақ шақырылмады. Соңына main() қосу керек.

    6. def square(n): return n * n болса, square(square(2)) неге тең?

    Алдымен ішкі square(2) = 4, сосын square(4) = 16. return болғандықтан мәнді ары қарай қолдануға болады.

    7. Python-да int(input("x: ")) жолында қай функция бірінші орындалады?

    Ішкі функция бірінші: input жол қайтарады, сосын int оны санға айналдырады.

    Эмодзилерден бұрын эмотикондар болды: :) - күлімдеген бет, :( - мұңды бет. Қазір бағдарламалар оларды автоматты түрде эмодзиге айналдырады!

    Tip Calculator (Шайпұл калькуляторы)

    АҚШ-та мейрамханада даяшыға тамақ құнының 15% не одан көп мөлшерінде шайпұл қалдыру әдетке айналған. Біз сізге шайпұл калькуляторының көп бөлігін жазып қойдық (кодын автотексерушіде көресіз), бірақ екі функцияны жазуға үлгермедік:

    • dollars_to_float - $##.## пішіміндегі жолды қабылдап (# - цифр), басындағы $-ты алып тастап, соманы float етіп қайтарады. Мысалы, $50.00 → 50.0.
    • percent_to_float - ##% пішіміндегі жолды қабылдап, соңындағы %-ті алып тастап, пайызды float етіп қайтарады. Мысалы, 15% → 0.15.

    Қолданушы мәндерді күтілген пішімде енгізеді деп есептеңіз.

    Кеңес

    float жолды бөлшек санға айналдырады. Жолдың басынан не соңынан таңбаны алып тастайтын әдістерді құжаттамадан іздеңіз (мысалы, removeprefix, removesuffix не replace). Пайызды 100-ге бөлуді ұмытпаңыз.
