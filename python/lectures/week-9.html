    Бұл бет сөзбе-сөз аударма емес. Лектор аудиторияда қалай түсіндірсе, біз де солай баяндаймыз: мағынасы мен кодтың бәрі түпнұсқадағыдай, тек әңгіме ана тілімізде жүреді.

    Тағы басқалар

    Міне, соңғы лекцияға да жеттік! Артқа бір қараңызшы: функциялар мен айнымалылардан бастап, шарттар, циклдер, ерекшеліктер, кітапханалар, тесттер, файлдар, тұрақты өрнектер және объектіге бағытталған бағдарламалауға дейін жол жүріп өттік. Бұл - аз емес.

    Бүгінгі тақырыптың аты - «Et Cetera». Латынша бұл «және қалғандары», біздіңше айтқанда «тағы басқалар» деген сөз. Python құжаттамасын ашып көрсеңіз, біз әлі тиіспеген «қалғандары» өте көп екенін байқайсыз. Бәрін бір сабаққа сыйғызу мүмкін емес, бірақ бүгін солардың ішіндегі ең пайдалыларын, күнделікті кодта жиі кездесетіндерін бір-бірлеп ашып көрсетеміз. Бұларды білсеңіз, кодыңыз қысқарақ, түсініктірек және «питонша» болады.

    set: жиын

    Математикадан есіңізде болар: жиын (set) - ішінде бірдей мәндер қайталанбайтын мәндер жинағы. {1, 2, 3} - жиын, ал онда екі рет «2» болуы мүмкін емес. Python-да да осындай тип бар. Оның неге керек екенін көрсету үшін, алдымен онсыз жазып көрейік. Бізде Хогвартс оқушыларының тізімі бар, әр оқушы - атауы мен үйі (факультеті) жазылған сөздік:

    students = [
    {"name": "Hermione", "house": "Gryffindor"},
    {"name": "Harry", "house": "Gryffindor"},
    {"name": "Ron", "house": "Gryffindor"},
    {"name": "Draco", "house": "Slytherin"},
    {"name": "Padma", "house": "Ravenclaw"},
]

houses = []
for student in students:
    if student["house"] not in houses:
        houses.append(student["house"])

for house in sorted(houses):
    print(house)

    Мақсатымыз - қандай үйлер бар екенін, әрқайсысын бір реттен шығару. Сондықтан бос houses тізімін жасап, әр оқушыны аралаймыз. Егер оқушының үйі тізімде әлі жоқ болса ғана, оны қосамыз. Gryffindor үш рет кездеседі, бірақ тізімге бір-ақ рет түседі. Соңында үйлерді әліпби бойынша шығарамыз:

    $ python houses.py
Gryffindor
Ravenclaw
Slytherin

    Жұмыс істейді. Бірақ қайталанбауын біз өзіміз, if ... not in ... арқылы қадағалап отырмыз. Ал Python-да бұл жұмысты өзі істейтін дайын құрал бар екен:

    students = [
    {"name": "Hermione", "house": "Gryffindor"},
    {"name": "Harry", "house": "Gryffindor"},
    {"name": "Ron", "house": "Gryffindor"},
    {"name": "Draco", "house": "Slytherin"},
    {"name": "Padma", "house": "Ravenclaw"},
]

houses = set()
for student in students:
    houses.add(student["house"])

for house in sorted(houses):
    print(house)

    Байқадыңыз ба? if мүлде жоқ. set() бос жиын жасайды, ал оған append емес, add арқылы мән қосамыз. Gryffindor-ды үш рет қоссақ та, жиын оны бір-ақ рет сақтайды, қайталанатынын өзі елемей қояды. Нәтиже бұрынғыдай. Жиынды кіреберістегі қонақтар тізімі сияқты елестетіңіз: бір адамды екі рет жазу мағынасыз, ол бәрібір бір адам. Толығырақ: Python құжаттамасындағы set.

    Жиынның реті жоқ

    Жиынның элементтері белгілі бір ретпен тұрмайды, сондықтан houses[0] деп жаза алмайсыз. Әдемі ретпен шығару керек болса, біз сияқты sorted қолданыңыз.

    Жаһандық айнымалылар

    Басқа бағдарламалау тілдерінде жаһандық айнымалы (global variable) деген ұғым бар: кез келген функциядан қол жеткізуге болатын, барлық функцияға ортақ айнымалы. Python-да да мұндай мүмкіндік бар. Банк шотын модельдеп көрейік:

    balance = 0


def main():
    print("Balance:", balance)


if __name__ == "__main__":
    main()

    Мұндағы balance ешбір функцияның ішінде емес, файлдың ең жоғарғы деңгейінде жасалды. Сондықтан ол жаһандық. main оны еш қиындықсыз оқиды, Balance: 0 шығады. Бәрі жақсы сияқты, солай емес пе? Асықпаңыз. Енді шотқа ақша салып, шешіп көрейік:

    balance = 0


def main():
    print("Balance:", balance)
    deposit(100)
    withdraw(50)
    print("Balance:", balance)


def deposit(n):
    balance += n


def withdraw(n):
    balance -= n


if __name__ == "__main__":
    main()
    Ойланып көріңіз: бұл бағдарлама не шығарады?

    Біз Balance: 0, сосын Balance: 50 күтеміз. Бірақ бірінші жолдан кейін бағдарлама қатемен құлайды! Себебін төменде түсіндіреміз.

    $ python bank.py
Balance: 0
Traceback (most recent call last):
  ...
UnboundLocalError: cannot access local variable 'balance' where it is not associated with a value

    UnboundLocalError! Неге бұлай болды? Себебі Python функцияның ішінде balance += n, яғни balance-қа жаңа мән меншіктеу әрекетін көрді де, «balance - осы функцияның өз, жергілікті айнымалысы (local variable)» деп шешті. Ал ол жергілікті айнымалының әзірге ешқандай мәні жоқ, сондықтан оған 100 қосу мүмкін емес. Қысқасы: жаһандық айнымалыны функцияның ішінен оқуға болады, бірақ біз жазғандай өзгертуге болмайды.

    Python-ға «жоқ, мен жаңа айнымалы жасап жатқан жоқпын, жоғарыдағы ортақ balance-ты айтып тұрмын» деп нақты айту керек. Ол үшін global кілт сөзі бар:

    balance = 0


def main():
    print("Balance:", balance)
    deposit(100)
    withdraw(50)
    print("Balance:", balance)


def deposit(n):
    global balance
    balance += n


def withdraw(n):
    global balance
    balance -= n


if __name__ == "__main__":
    main()
    $ python bank.py
Balance: 0
Balance: 50

    Енді global balance жолы әр функцияға: «balance - жергілікті емес, ең жоғарыда жасалған жаһандық айнымалы» дейді. Бағдарлама жұмыс істеді.

    Бірақ тоқтай тұрайық. Өткен аптада объектіге бағытталған бағдарламалауды үйрендік қой. Сол күшімізді пайдаланып, жаһандық айнымалысыз, класс арқылы жазып көрейік:

    class Account:
    def __init__(self):
        self._balance = 0

    @property
    def balance(self):
        return self._balance

    def deposit(self, n):
        self._balance += n

    def withdraw(self, n):
        self._balance -= n


def main():
    account = Account()
    print("Balance:", account.balance)
    account.deposit(100)
    account.withdraw(50)
    print("Balance:", account.balance)


if __name__ == "__main__":
    main()

    account = Account() арқылы жаңа шот ашамыз. Енді баланс - жаһандық айнымалы емес, сол шоттың өз дана айнымалысы self._balance. Класстың барлық әдістері оған self арқылы қол жеткізеді, ешқандай global керек емес. Оның үстіне, @property арқылы балансты сырттан тек оқуға рұқсат бердік, ал өзгерту тек deposit пен withdraw арқылы жүреді. Нағыз банктегідей!

    Жаһандық айнымалыларды үнемдеңіз

    Жалпы алғанда, жаһандық айнымалыларды өте сирек қолданған жөн, мүмкін болса, мүлде қолданбаған дұрыс. Бағдарламаның кез келген жерінен өзгертуге болатын айнымалы - қате қайдан шыққанын іздегенде ең үлкен бас ауруы.

    Тұрақтылар

    Кейбір тілдерде мәнін өзгертуге болмайтын айнымалылар жасауға болады. Оларды тұрақтылар (constants) деп атайды. Тұрақтылар «қорғана бағдарламалауға» көмектеседі: маңызды мәнді біреу абайсызда (не өзіміз қателесіп) өзгертіп жіберу мүмкіндігі азаяды. Python-да бұл қалай көрінеді?

    MEOWS = 3

for _ in range(MEOWS):
    print("meow")

    Мұндағы MEOWS - біздің тұрақтымыз. Тұрақтыларды әдетте БАС ӘРІППЕН атайды және кодтың ең жоғарғы жағына қояды. Бірақ бір құпияны ашайын: бұл тек тұрақты сияқты көрінеді. Шын мәнінде Python-да мәнді өзгертуге тыйым салатын ешқандай механизм жоқ! Төменде MEOWS = 4 деп жазсаңыз, Python үнсіз келісе салады. Мұнда бәрі ар-ұятқа сеніп құрылған: атауы бас әріппен жазылған айнымалыны көрсеңіз, оны өзгертпеңіз. Бұл - бағдарламашылар арасындағы келісім.

    Класс ішінде де «тұрақты» жасауға болады. Енді тырнақшамен жазып отырмын, себебі Python тұрақтыларды толық қолдамайтынын білеміз:

    class Cat:
    MEOWS = 3

    def meow(self):
        for _ in range(Cat.MEOWS):
            print("meow")


cat = Cat()
cat.meow()

    MEOWS класстың ішінде, бірақ ешбір әдістің ішінде емес, жеке тұр. Сондықтан класстың барлық әдістері оған Cat.MEOWS арқылы қол жеткізе алады.

    Тип нұсқамалары

    Көп тілдерде (мысалы, C тілінде) айнымалыны жасағанда оның типін нақты жазу керек: «бұл - бүтін сан», «бұл - жол». Курстың басында көргеніміздей, Python мұны талап етпейді, типті өзі анықтайды. Ыңғайлы ғой! Бірақ ыңғайлылықтың өз бағасы бар: айнымалыларыңыз дұрыс типте екеніне көз жеткізу бәрібір жақсы әдет.

    Бұған mypy деген бағдарлама көмектеседі. Ол кодыңызды іске қоспай-ақ оқып шығып, типтер дұрыс қолданылғанын тексереді. Оны терминалда орнатуға болады:

    $ pip install mypy

    Енді мына кодқа қараңыз:

    def meow(n):
    for _ in range(n):
        print("meow")


number = input("Number: ")
meow(number)

    Сіз қатені бірден байқаған шығарсыз: input әрқашан str қайтарады, ал meow-ға int керек сияқты. Бірақ Python мұны тек бағдарлама іске қосылып, range-ке жол берілгенде ғана біледі. Python-ға алдын ала «кеңес» берейік. Мұны тип нұсқамасы (type hint) деп атайды: параметрдің атынан кейін қос нүкте қойып, күтілетін типті жазамыз:

    def meow(n: int):
    for _ in range(n):
        print("meow")


number = input("Number: ")
meow(number)

    Бағдарламаны іске қоссақ, ол бәрібір қате береді. Неге? Себебі Python тип нұсқамаларын орындау кезінде мүлде тексермейді, олар тек кеңес қана. Ал оларды оқитын - mypy:

    $ mypy meows.py
meows.py:7: error: Argument 1 to "meow" has incompatible type "str"; expected "int"  [arg-type]
Found 1 error in 1 file (checked 1 source file)

    mypy бағдарламаны іске қоспай-ақ қатені тауып, қалай түзету керегіне бағыт берді: 7-жолда meow-ға int орнына str берілген. Тип нұсқамасын айнымалыларға да қосуға болады:

    def meow(n: int):
    for _ in range(n):
        print("meow")


number: int = input("Number: ")
meow(number)

    Енді number-ның да int болуы керек екенін айттық. mypy meows.py-ды қайта іске қоссақ, ол бізге әлдеқайда нақты жауап береді: қате meow-ды шақырған жерде емес, одан бұрын, input-тің str нәтижесін int болуы тиіс айнымалыға салған жерде. Ендеше, түзетейік:

    def meow(n: int):
    for _ in range(n):
        print("meow")


number: int = int(input("Number: "))
meow(number)

    Енді енгізуді int-ке келтірдік, сондықтан mypy ешқандай қате таппайды. Ал енді әдейі жаңа қате жасап көрейін. meow бізге жол қайтарады деп ойлап, нәтижесін айнымалыға сақтайық:

    def meow(n: int):
    for _ in range(n):
        print("meow")


number: int = int(input("Number: "))
meows: str = meow(number)
print(meows)

    Мұнда не дұрыс емес? meow ештеңе қайтармайды, оның тек жанама әсері (side effect) бар: экранға «meow» жазады. Ал біз сол жоқ нәтижені str айнымалыға сақтамақпыз. mypy бұл жерде де қате туралы хабарлайды. Оны тіпті айқынырақ ету үшін функцияның қайтаратын мәнінің типін де жазуға болады, ол үшін жақшадан кейін -> бағыттауышын қоямыз:

    def meow(n: int) -> None:
    for _ in range(n):
        print("meow")


number: int = int(input("Number: "))
meows: str = meow(number)
print(meows)

    -> None жазбасы mypy-ға «бұл функция ешқандай мән қайтармайды» дейді. Енді mypy мәселені нақты көрсетеді:

    $ mypy meows.py
meows.py:7: error: "meow" does not return a value (it only ever returns None)  [func-returns-value]
Found 1 error in 1 file (checked 1 source file)

    Шынымен жол керек болса, функцияны жол қайтаратындай етіп өзгертейік:

    def meow(n: int) -> str:
    return "meow\n" * n


number: int = int(input("Number: "))
meows: str = meow(number)
print(meows, end="")

    Қызық трюк: "meow\n" * n бір жолды n рет қайталап, бір үлкен жол жасайды, әр «meow» жаңа жолдан басталады. Енді meows айнымалысында n рет «meow» жазылған бір str сақталады. Ал print-тегі end="" соңғы \n-нен кейін артық бос жол шықпауы үшін. mypy бұл жолы ешқандай қате таппайды. Толығырақ: Python құжаттамасындағы тип нұсқамалары және mypy құжаттамасы.

    Docstring: құжаттама жолдары

    Функцияның не істейтінін түсіндірудің қалыптасқан, стандартты тәсілі бар. Ол - құжаттама жолы (docstring). Функцияның атынан кейінгі бірінші жолға үш қос тырнақшамен жазылады:

    def meow(n):
    """Meow n times."""
    return "meow\n" * n


number = int(input("Number: "))
meows = meow(number)
print(meows, end="")

    Үш тырнақшаның арасындағы мәтін функцияның не істейтінін сипаттайды. Бұл # түсініктемесіне ұқсайды, бірақ айырмасы бар: docstring функцияның өзіне «жабысып» қалады, оны Python да, басқа құралдар да оқи алады. Docstring арқылы функцияның барлық ерекшеліктерін бірыңғай пішіммен құжаттауға болады:

    def meow(n):
    """
    Meow n times.

    :param n: Number of times to meow
    :type n: int
    :raise TypeError: If n is not an int
    :return: A string of n meows, one per line
    :rtype: str
    """
    return "meow\n" * n


number = int(input("Number: "))
meows = meow(number)
print(meows, end="")

    Мұнда бірнеше өріс бар: :param n: - параметр не үшін керек, :type n: - оның типі, :raise TypeError: - функция қандай жағдайда қандай ерекшелік лақтырады, :return: мен :rtype: - не және қандай типте қайтарылады. Бұлай жазудың артықшылығы неде? Sphinx сияқты қалыптасқан құралдар docstring-терді автоматты түрде оқып, олардан веб-беттер мен PDF файлдар түріндегі әдемі құжаттама жасап береді. Оны басқалармен бөлісуге, жариялауға болады. Толығырақ: PEP 257: docstring.

    argparse

    Бағдарламамыз командалық жол аргументтерін қабылдасын делік. Мысалы, python meows.py -n 3 десек, үш рет мияулайтын болсын. Өзіміз білетін sys.argv арқылы жазайық:

    import sys

if len(sys.argv) == 1:
    print("meow")
elif len(sys.argv) == 3 and sys.argv[1] == "-n":
    n = int(sys.argv[2])
    for _ in range(n):
        print("meow")
else:
    print("usage: meows.py [-n NUMBER]")

    sys модулін импорттаймыз, ол бізге sys.argv тізімін береді, онда бағдарлама іске қосылғанда берілген командалық жол аргументтері жатады. Бірнеше if арқылы қолданушы бағдарламаны дұрыс іске қосқанын тексереміз: аргумент мүлде жоқ болса, бір рет мияулаймыз; -n мен сан берілсе, сонша рет; әйтпесе қалай қолдану керегін айтамыз.

    Ал енді бағдарламамыз әлдеқайда күрделеніп, ондаған опция қосылды деп елестетіңіз: -n, -v, --help, кез келген ретпен... Әр мүмкін комбинацияны if арқылы тексеру - нағыз азап. Бірнеше аргументтің өзінде-ақ бас қатып, қолымызды сілтеп кетуіміз мүмкін!

    Бақытымызға орай, командалық жол аргументтерін талдаудың (parsing) бүкіл ауыр жұмысын өз мойнына алатын argparse кітапханасы бар:

    import argparse

parser = argparse.ArgumentParser()
parser.add_argument("-n")
args = parser.parse_args()

for _ in range(int(args.n)):
    print("meow")

    sys орнына argparse импорттадық. ArgumentParser класынан parser деген объект жасаймыз. Оның add_argument әдісі арқылы argparse-ке қолданушыдан қандай аргументтер күтетінімізді айтамыз, мұнда - -n. Соңында parse_args әдісі қолданушы берген аргументтерді талдап, дұрыс берілгенін тексереді. Нәтижесінде args.n арқылы -n-нен кейін жазылған мәнді аламыз.

    Одан да жақсы жасауға болады. Бағдарламаны дұрыс қолданбаған адамға қалай қолдану керегі туралы ақпарат берейік:

    import argparse

parser = argparse.ArgumentParser(description="Meow like a cat")
parser.add_argument("-n", help="number of times to meow")
args = parser.parse_args()

for _ in range(int(args.n)):
    print("meow")

    Бағдарламаның сипаттамасын (description) және -n аргументінің түсіндірмесін (help) қостық. Енді қолданушы -h немесе --help деп іске қосса, argparse бізге бір жол код жаздырмай-ақ, анықтаманы өзі құрастырып береді:

    $ python meows.py -h
usage: meows.py [-h] [-n N]

Meow like a cat

options:
  -h, --help  show this help message and exit
  -n N        number of times to meow

    Бағдарламаны тағы да жетілдірейік:

    import argparse

parser = argparse.ArgumentParser(description="Meow like a cat")
parser.add_argument("-n", default=1, help="number of times to meow", type=int)
args = parser.parse_args()

for _ in range(args.n):
    print("meow")

    Екі жаңалық бар. default=1 - қолданушы -n бермесе, әдепкі мән 1 болады. type=int - argparse мәнді өзі int-ке айналдырады, сондықтан циклде int(args.n) деп жазудың қажеті жоқ. Ал қолданушы -n cat деп жазса ше? argparse оған өзі түсінікті қате хабарын шығарады. Толығырақ: argparse.

    Тарқату

    Бір айнымалыдағы мәнді бірден екі айнымалыға бөліп алу керемет болар еді, солай емес пе? Python-да бұл мүмкін:

    first, _ = input("What's your name? ").split(" ")
print(f"hello, {first}")

    Бұл бағдарлама толық атты бір бос орыннан бөліп, қолданушының атын алуға тырысады (тәсілі әлі аңғал: аты-жөні үш сөзден тұрса, жұмыс істемейді). split екі элементтен тұратын тізім қайтарады, ал біз оны бірден екі айнымалыға «тарқатып» саламыз: біріншісі first-ке, екіншісі _-ке. Төменгі сызық _ - «бұл мән маған керек емес» дегеннің жалпы қабылданған белгісі.

    Бұл - тарқатудың (unpacking) ең қарапайым түрі. Тарқатудың басқа, күштірек түрлерін түсінсеңіз, кодыңыз әлдеқайда әсем болады. Мысал үшін Гарри Поттер әлеміндегі сиқыршылардың ақшасын алайық: галлеон, сикль және кнат. 1 галлеон = 17 сикль, 1 сикль = 29 кнат (біздің теңге мен тиын сияқты, тек сәл шатасқан):

    def total(galleons, sickles, knuts):
    return (galleons * 17 + sickles) * 29 + knuts


print(total(100, 50, 25), "Knuts")
    $ python unpack.py
50775 Knuts

    Функция бүкіл соманы кнатқа айналдырып қайтарады. Ал тиындарымыз бір тізімде сақталса ше?

    def total(galleons, sickles, knuts):
    return (galleons * 17 + sickles) * 29 + knuts


coins = [100, 50, 25]

print(total(coins[0], coins[1], coins[2]), "Knuts")

    coins тізімін жасап, әр мәнді индекс бойынша, 0, 1, 2 деп бір-бірлеп береміз. Жұмыс істейді, бірақ тым сөзуар. Тізімді функцияға бүтіндей бере салсақ қандай жақсы болар еді! Тарқату дәл соны істейді:

    def total(galleons, sickles, knuts):
    return (galleons * 17 + sickles) * 29 + knuts


coins = [100, 50, 25]

print(total(*coins), "Knuts")

    Тізімнің алдындағы жалғыз жұлдызша * оны «ашып», ішіндегі әр элементті функцияға жеке аргумент етіп береді. Яғни total(*coins) дәл total(100, 50, 25) сияқты. Қапшықтағы үш тиынды үстелге төгіп, үш бөлек тиын етіп бергенмен бірдей.

    Енді ақша түрлерін атауымен, кез келген ретпен бергіміз келсін:

    def total(galleons, sickles, knuts):
    return (galleons * 17 + sickles) * 29 + knuts


print(total(galleons=100, sickles=50, knuts=25), "Knuts")

    Нәтиже бұрынғыдай дұрыс. «Атау» мен «мән» деген сөздерді естігенде ойыңызға не келеді? Әрине, сөздіктер! Тиындарды сөздікте сақтайық:

    def total(galleons, sickles, knuts):
    return (galleons * 17 + sickles) * 29 + knuts


coins = {"galleons": 100, "sickles": 50, "knuts": 25}

print(total(coins["galleons"], coins["sickles"], coins["knuts"]), "Knuts")

    Сөздіктің мәндерін "galleons", "sickles" сияқты кілттер арқылы аламыз. Тағы да сөзуар. total үш аргумент күтеді, сондықтан сөздікті жай ғана бере алмаймыз. Бірақ мұнда да тарқату көмектеседі:

    def total(galleons, sickles, knuts):
    return (galleons * 17 + sickles) * 29 + knuts


coins = {"galleons": 100, "sickles": 50, "knuts": 25}

print(total(**coins), "Knuts")

    Қос жұлдызша ** сөздікті тарқатады, және ол кілттерді де, мәндерді де береді. Яғни total(**coins) дәл total(galleons=100, sickles=50, knuts=25) сияқты. Сондықтан сөздіктегі кілттер функция параметрлерінің атауларымен дәл сәйкес болуы керек.

    Бір жұлдызша мен екі жұлдызша

    * - тізімді (жалпы, тізбекті) реттік аргументтерге тарқатады. ** - сөздікті атау=мән түріндегі аргументтерге тарқатады.

    args пен kwargs

    Курстың басында print құжаттамасына қарағанымыз есіңізде ме? Онда оның прототипі былай жазылған:

    print(*objects, sep=' ', end='\n', file=sys.stdout, flush=False)

    Сол кезде *objects-тің алдындағы жұлдызшаға мән бермеген едік. Енді оның сырын ашатын кез келді. Алдымен екі терминді бөліп алайық:

    • позициялық аргументтер (positional arguments, қысқаша args) - орнына қарай берілетін аргументтер, мысалы print("Hello", "World");
    • кілттік аргументтер (keyword arguments, қысқаша kwargs) - атымен берілетін аргументтер, мысалы print(end="").

    print-тің прототипінен көргеніміздей, функцияға «саны әзірге белгісіз позициялық аргументтер келеді» деп айтуға болады. Сол сияқты «саны белгісіз кілттік аргументтер келеді» деп те айтуға болады:

    def f(*args, **kwargs):
    print("Positional:", args)


f(100, 50, 25)
    $ python f.py
Positional: (100, 50, 25)

    Функцияның ішінде args барлық позициялық аргументтерді жинап алды. Енді атымен берілетін аргументтерді жіберейік:

    def f(*args, **kwargs):
    print("Named:", kwargs)


f(galleons=100, sickles=50, knuts=25)
    $ python f.py
Named: {'galleons': 100, 'sickles': 50, 'knuts': 25}

    Байқадыңыз ба? Атымен берілген мәндер kwargs-қа сөздік түрінде жиналды. Бұл - тарқатудың керісінше бағыты: шақырғанда * мен ** жинақты «шашады», ал функцияның параметрлерінде бөлек аргументтерді бір жинаққа «жинайды». Атаулары туралы: args пен kwargs деп атау - жай дәстүр, ең маңыздысы - жұлдызшалар.

    Ендеше, print-ке оралсақ, оның *objects параметрі кез келген санды позициялық аргумент қабылдай алады. Сондықтан print-ке бір, екі не он аргумент бере аламыз. Толығырақ: print.

    map

    Бір сәтке артқа шегініп, үлкен суретке қарайық. Курсты біз процедуралық бағдарламалаудан (procedural programming) бастадық: команданы бірінен соң бірін жаздық. Кейін Python - объектіге бағытталған тіл екенін ашып көрсеттік. Осы уақытқа дейін мән қайтармай, тек жанама әсері бар функцияларды да көп көрдік. Ал Python тағы бір стильді қолдайды: функционалдық бағдарламалау (functional programming). Мұнда функциялардың өзі мән сияқты: оларды айнымалыға салуға, басқа функцияға аргумент етіп беруге болады. Мұны көрсету үшін code yell.py деп жаңа файл ашайық:

    def main():
    yell("This is CS50")


def yell(word):
    print(word.upper())


if __name__ == "__main__":
    main()

    yell («айқайла») берілген сөзді бас әріппен, яғни айқайлап шығарады: THIS IS CS50. Ал шексіз көп сөздің тізімін айқайлай алсақ ше? Кодты өзгертейік:

    def main():
    yell(["This", "is", "CS50"])


def yell(words):
    uppercased = []
    for word in words:
        uppercased.append(word.upper())
    print(*uppercased)


if __name__ == "__main__":
    main()

    Әр сөзді аралап, бас әріпке айналдырып, uppercased тізіміне жинаймыз. Ал соңында сол тізімді * арқылы тарқатып, print-ке бөлек-бөлек аргумент етіп береміз, сондықтан сөздер бос орынмен шығады. Әлгі тарқату бірден пайдаға асты! Енді тізімнің тік жақшаларын алып тастап, сөздерді жай аргумент етіп берейік:

    def main():
    yell("This", "is", "CS50")


def yell(*words):
    uppercased = []
    for word in words:
        uppercased.append(word.upper())
    print(*uppercased)


if __name__ == "__main__":
    main()

    *words арқылы функция енді кез келген санды аргумент қабылдай алады, дәл print сияқты. Ал енді функционалдық бағдарламалаудың алғашқы құралы - map. Ол бір функцияны мәндер тізбегінің әрқайсысына «қолданып» шығады:

    def main():
    yell("This", "is", "CS50")


def yell(*words):
    uppercased = map(str.upper, words)
    print(*uppercased)


if __name__ == "__main__":
    main()

    map екі аргумент алады. Біріншісі - әр элементке қолданылатын функция. Екіншісі - сол функция қолданылатын тізбектің өзі. Сонымен words-тегі әр сөз str.upper функциясына беріледі, ал нәтижелері uppercased-ке қайтарылады. Мұқият қараңыз: str.upper-дің соңында жақша жоқ! Біз функцияны шақырып жатқан жоқпыз, оны map-қа беріп жатырмыз, ал шақыруды map өзі істейді. Функцияны мән ретінде беру деген осы. Толығырақ: map.

    Тізімдік өрнектер

    Тізімдік өрнек (list comprehension) тізімді бір ғана әсем жолмен, «жүріп бара жатып» жасауға мүмкіндік береді. Мұны кодымызға енгізейік:

    def main():
    yell("This", "is", "CS50")


def yell(*words):
    uppercased = [arg.upper() for arg in words]
    print(*uppercased)


if __name__ == "__main__":
    main()

    map-тың орнына тік жақшаның ішіне Python өрнегін жаздық. Оны дауыстап оқысаңыз, қазақша сөйлемге ұқсайды: «words-тегі әр arg үшін arg.upper() ал». Нәтижесі - жаңа тізім.

    Бұл идеяны одан әрі дамытайық. Басқа бағдарламаға көшеміз: code gryffindors.py.

    students = [
    {"name": "Hermione", "house": "Gryffindor"},
    {"name": "Harry", "house": "Gryffindor"},
    {"name": "Ron", "house": "Gryffindor"},
    {"name": "Draco", "house": "Slytherin"},
]

gryffindors = []
for student in students:
    if student["house"] == "Gryffindor":
        gryffindors.append(student["name"])

for gryffindor in sorted(gryffindors):
    print(gryffindor)

    Мұнда тізімді құрастыру кезінде шарт бар: егер оқушының үйі Gryffindor болса, оның атын тізімге қосамыз. Соңында барлық аттарды әліпби бойынша шығарамыз. Тізімдік өрнек мұны да әлдеқайда әсем жаза алады, өйткені оның ішіне шарт та сыяды:

    students = [
    {"name": "Hermione", "house": "Gryffindor"},
    {"name": "Harry", "house": "Gryffindor"},
    {"name": "Ron", "house": "Gryffindor"},
    {"name": "Draco", "house": "Slytherin"},
]

gryffindors = [
    student["name"] for student in students if student["house"] == "Gryffindor"
]

for gryffindor in sorted(gryffindors):
    print(gryffindor)

    Бос тізім, цикл, if, append - бәрі бір ғана нұсқаулыққа сыйды! «students-тегі әр student үшін, егер үйі Gryffindor болса, student["name"] ал». Жақшалардың ішінде ұзын өрнекті бірнеше жолға бөліп жазуға болады, ол тек оқуға ыңғайлы болу үшін.

    Ойланып көріңіз: [n * n for n in range(5) if n % 2 == 1] нәтижесі қандай?

    [1, 9]. range(5) - 0, 1, 2, 3, 4. Солардың тақтары (1 мен 3) ғана шарттан өтеді, сосын әрқайсысы квадратталады.

    filter

    Python-ның filter функциясы тізбектен белгілі бір шарт ақиқат болатын элементтерді ғана, яғни оның ішкі жиынын қайтарады. Елеуіш сияқты: керегі қалады, қалғаны өтіп кетеді.

    students = [
    {"name": "Hermione", "house": "Gryffindor"},
    {"name": "Harry", "house": "Gryffindor"},
    {"name": "Ron", "house": "Gryffindor"},
    {"name": "Draco", "house": "Slytherin"},
]


def is_gryffindor(s):
    return s["house"] == "Gryffindor"


gryffindors = filter(is_gryffindor, students)

for gryffindor in sorted(gryffindors, key=lambda s: s["name"]):
    print(gryffindor["name"])

    is_gryffindor - біздің сүзгі функциямыз. Ол s оқушысын алып, үйі Gryffindor болса True, әйтпесе False қайтарады. filter да map сияқты екі аргумент алады: біріншісі - тізбектің әр элементіне қолданылатын функция (мұнда is_gryffindor), екіншісі - сүзгіден өткізілетін тізбек (мұнда students). gryffindors-та тек Gryffindor оқушылары қалады. Тек бұл жолы олар аттар емес, тұтас сөздіктер, сондықтан оларды сұрыптау үшін sorted-ке key=lambda s: s["name"] арқылы «аты бойынша сұрыпта» деп айтамыз.

    Бір рет қана керек кішкентай функцияға жеке ат беріп, def жазу міндетті емес. filter-ге анонимді функция, яғни lambda беруге болады:

    students = [
    {"name": "Hermione", "house": "Gryffindor"},
    {"name": "Harry", "house": "Gryffindor"},
    {"name": "Ron", "house": "Gryffindor"},
    {"name": "Draco", "house": "Slytherin"},
]


gryffindors = filter(lambda s: s["house"] == "Gryffindor", students)

for gryffindor in sorted(gryffindors, key=lambda s: s["name"]):
    print(gryffindor["name"])

    Оқушылар тізімі сол күйі, нәтиже де сол: Harry, Hermione, Ron. Тек is_gryffindor функциясы енді бір жолдық lambda болып, тура керек жерге жазылды. Толығырақ: filter.

    Сөздіктік өрнектер

    Тізімдік өрнектің идеясын сөздіктерге де қолдануға болады. Алдымен әдеттегі тәсілмен жазайық:

    students = ["Hermione", "Harry", "Ron"]

gryffindors = []

for student in students:
    gryffindors.append({"name": student, "house": "Gryffindor"})

print(gryffindors)

    Бұл код әзірге (әзірге!) ешқандай өрнек қолданбайды, бұрыннан білетін тәсілмен жазылған: әр оқушы үшін сөздік жасап, тізімге қосамыз. Енді осы сөздіктерді тізімдік өрнекпен жасайық:

    students = ["Hermione", "Harry", "Ron"]

gryffindors = [{"name": student, "house": "Gryffindor"} for student in students]

print(gryffindors)
    $ python gryffindors.py
[{'name': 'Hermione', 'house': 'Gryffindor'}, {'name': 'Harry', 'house': 'Gryffindor'}, {'name': 'Ron', 'house': 'Gryffindor'}]

    Бүкіл алдыңғы код бір жолға сыйды: students-тегі әр student үшін сөздіктің құрылымын көрсеттік. Ал одан да ықшамдай аламыз:

gryffindors = {student: "Gryffindor" for student in students}

print(gryffindors)

    Бұл жолы тік жақша емес, фигуралы жақша, ал ішінде кілт: мән жұбы. Бұл - нағыз сөздіктік өрнек (dictionary comprehension): нәтижесі тізім емес, кілт пен мән жұптарынан құралған бір сөздік.

    enumerate

    Оқушыларды нөмірлеп, рейтинг сияқты шығарғымыз келсін. Бұрынғы білімімізбен:

    students = ["Hermione", "Harry", "Ron"]

for i in range(len(students)):
    print(i + 1, students[i])
    $ python enumerate.py
1 Hermione
2 Harry
3 Ron

    Жұмыс істейді, бірақ range(len(students)) және students[i] - сәл шатасқан жазу. Python мұны оңайлатады: enumerate әр қадамда элементтің индексін де, мәнін де бірге береді:

    students = ["Hermione", "Harry", "Ron"]

for i, student in enumerate(students):
    print(i + 1, student)

    Нәтиже дәл сондай. Мұнда да тарқату жасырынып тұр: enumerate әр қадамда (0, "Hermione") сияқты жұп береді, ал біз оны бірден i мен student-ке тарқатамыз. Индекс әлі де нөлден басталатындықтан, i + 1 деп жазамыз. Толығырақ: enumerate.

    Генераторлар мен итераторлар

    Python-да мәселе тым үлкейіп кеткенде компьютеріңіздің ресурсы таусылып қалмауын қамтамасыз ететін бір тәсіл бар. Оны түсіну үшін ұйқыдан бастайық. АҚШ-та ұйықтай алмай жатқан адам іштей «қой санайды» деген әдет бар: бір қой, екі қой, үш қой... (Біздің ауылда да бұл әдіс таныс шығар.) Ендеше, code sleep.py:

    n = int(input("What's n? "))
for i in range(n):
    print("🐑" * i)
    Ойланып көріңіз: n = 3 енгізсек, неше жол шығады және бірінші жол қандай?

    Үш жол шығады, бірақ біріншісі бос! range(3) 0-ден басталады, ал "🐑" * 0 - бос жол. Одан кейін бір қой, сосын екі қой.

    Бағдарлама біз сұраған мөлшерде қой санайды. Әдетімізше, оны main функциясымен ретке келтірейік:

    def main():
    n = int(input("What's n? "))
    for i in range(n):
        print("🐑" * i)


if __name__ == "__main__":
    main()

    Біз кодтың бөліктерін бөлек функцияларға шығарып, абстракциялауға дағдыландық. Бір жол қойды жасауды sheep функциясына берейік:

    def main():
    n = int(input("What's n? "))
    for i in range(n):
        print(sheep(i))


def sheep(n):
    return "🐑" * n


if __name__ == "__main__":
    main()

    Мұнда санау циклі әлі де main-де. sheep функциясына көбірек жұмыс тапсырайық: ол бүкіл отарды жасап қайтарсын:

    def main():
    n = int(input("What's n? "))
    for s in sheep(n):
        print(s)


def sheep(n):
    flock = []
    for i in range(n):
        flock.append("🐑" * i)
    return flock


if __name__ == "__main__":
    main()

    sheep flock (отар) тізімін құрастырып, тұтасымен қайтарады. Әртүрлі сандармен іске қосып көріңіз: 10, 1000, 10000... Ал 1000000 деп жазсаңыз ше? Бағдарлама қатып қалуы, тіпті құлауы мүмкін. Себебі біз миллион жолдан тұратын алып тізімді, оның үстіне соңғы жолдары миллион қойдан тұратын тізімді, бәрін бірден жадта жасауға тырыстық. Ал экранға шығару бір-бірлеп болса да, біз оның басталуын бүкіл тізім дайын болғанша күтеміз. Компьютер мұндай есептеуді аяқтауға қиналады.

    Бұл мәселені yield кілт сөзі шешеді. Ол нәтижені бүтіндей емес, кішкене бөліктерімен, бір-бірлеп қайтарады:

    def main():
    n = int(input("What's n? "))
    for s in sheep(n):
        print(s)


def sheep(n):
    for i in range(n):
        yield "🐑" * i


if __name__ == "__main__":
    main()

    Айырмашылық кішкентай, бірақ маңызды. return функцияны толық аяқтап, бір мән қайтарады. Ал yield бір мәнді «береді» де, функцияны сол жерде кідіртеді. for циклі келесі мәнді сұрағанда, функция тоқтаған жерінен жалғасып, келесі қойларды береді. Құрамында yield бар функция генератор (generator) деп аталады. Ал for циклі сияқты мәндерді бір-бірлеп алып отыратын объект - итератор (iterator). Генератор жадта бір мезетте бір ғана жолды ұстайды, сондықтан миллион қой да енді компьютерді қинамайды.

    Құдықтан су тарту сияқты

    Тізім қайтару - бүкіл құдықтың суын бірден бір шелекке құйып беруге тырысқанмен бірдей. Генератор - керек кезде бір шелектен тартып беретін құдық. Ішетін су бірдей, бірақ шелек жарылмайды.

    Толығырақ: Python құжаттамасындағы генераторлар және итераторлар.

    Құттықтаймыз!

    Курстан шығып бара жатқанда, сізде бағдарламалау есептерін шешуге арналған ой моделі мен толық құрал-сайман жиынтығы бар. Бәрін бір қатарға тізіп көрейік:

    • бірінші, функциялар мен айнымалыларды үйрендіңіз;
    • екінші, шарттарды;
    • үшінші, циклдерді;
    • төртінші, ерекшеліктерді;
    • бесінші, кітапханаларды;
    • алтыншы, модульдік тесттерді;
    • жетінші, файлдармен енгізу-шығаруды;
    • сегізінші, тұрақты өрнектерді;
    • жақында, объектіге бағытталған бағдарламалауды;
    • ал бүгін - күнделікті жұмыста қолдануға болатын тағы көптеген құралдарды.

    Бірінші сабақта бір жолдық print("hello, world") жазғанымызды еске алыңызшы. Сол кезде *objects деген жұлдызша сізге жұмбақ болып көрінген шығар. Ал бүгін оның не екенін білесіз. Міне, сіз жүріп өткен жол осы.

    Соңғы лекцияда Python-ның «тағы басқа» пайдалы құралдарымен таныстық:

    • docstring: функцияны құжаттаудың стандартты тәсілі, Sphinx;
    • argparse: командалық жол аргументтерін талдау, help, default, type;
    • тарқату: * тізімді, ** сөздікті аргументтерге тарқатады;
    • *args пен **kwargs: саны белгісіз позициялық және кілттік аргументтер;
    • функционалдық бағдарламалау: map, filter, lambda;
    • тізімдік және сөздіктік өрнектер;
    • enumerate: индекс пен мәнді бірге алу;

    Өзіңізді тексеріңіз

    1. print(len({1, 2, 2, 3, 3, 3})) не шығарады?

    Жиында қайталанатын мәндер сақталмайды: {1, 2, 3}, яғни 3 элемент.

    2. [n * 2 for n in range(4) if n % 2 == 0] нәтижесі қандай?

    range(4) - 0, 1, 2, 3. Жұптары (0 мен 2) ғана шарттан өтіп, екіге көбейтіледі: 0 мен 4.

    3. Мына код не шығарады?

    def f(*args, **kwargs):
    print(args, kwargs)


f(1, 2, x=3)

    Позициялық аргументтер args-қа кортеж болып, ал атымен берілгендер kwargs-қа сөздік болып жиналады.

    4. def total(a, b, c): return a * 100 + b * 10 + c болса, total(*[1, 2, 3]) неге тең?

    * тізімді тарқатады: total(1, 2, 3) = 100 + 20 + 3 = 123.

    5. Мына код не шығарады?

    def count(n):
    for i in range(n):
        yield i


x = count(3)
print(next(x), next(x))

    Генератор әр сұрағанда келесі мәнді береді де, тоқтаған жерінен жалғасады: алдымен 0, сосын 1.

    6. Функцияның ішінде balance += n жолы UnboundLocalError береді. balance файлдың басында жасалған болса, мұны қалай түзетуге болады?

    global Python-ға бұл айнымалы жергілікті емес, жаһандық екенін айтады. Ал ең таза жол - класс қолдану.

    7. {w: len(w) for w in ["hi", "cat"]} нәтижесі қандай?

    Сөздіктік өрнек: кілт - сөздің өзі, мән - оның ұзындығы.

    8. def meow(n: int): ... болса, python meows.py арқылы іске қосқанда meow("3") шақыруы туралы қай тұжырым дұрыс?

    Тип нұсқамалары - тек кеңес. Python оларды орындау кезінде тексермейді, ал mypy кодты іске қоспай-ақ тексереді.

    Оңай

    Passing Scores (Өткен ұпайлар)

    Мұғалім сыныптың ұпайларын бір жолға, бос орынмен бөліп жазады: 45 50 99 12. Кім өтті? Өту шегі - 50 ұпай (50 өтеді).

    scores.py файлында екі функция жазыңыз:

    • passing(scores) - бүтін сандар тізімін қабылдап, 50 және одан жоғары ұпайлардың жаңа тізімін бастапқы ретімен қайтарады. Оны тізімдік өрнекпен (не filter-мен) жазып көріңіз.
    • main() - қолданушыдан ұпайлар жолын сұрап, оны int тізіміне айналдырады (мұнда да тізімдік өрнек ыңғайлы), өткен ұпайларды , арқылы бір жолға шығарады, ал келесі жолға Passed: k/n жазады (k - өткендер саны, n - барлық ұпай саны). Ешкім өтпесе, бірінші жол бос болады.

    Мысалы, 45 50 99 12 енгізілсе, 50, 99 және Passed: 2/4 шығады.

    Кеңес

    [int(s) for s in line.split()] жолды сандар тізіміне айналдырады. Тізімді , арқылы шығару үшін тарқатуды есіңізге алыңыз: print(*passed, sep=", ").

    Тексеру
    • 45 50 99 12 → 50, 99 және Passed: 2/4
    • passing([10, 50, 99]) → [50, 99]
    • passing тізімдік өрнекпен (не filter-мен) жазылған.

    Square Generator (Квадраттар генераторы)

    Қой санағандай, енді квадраттарды санайық. squares.py файлында squares(n) генераторын жазыңыз: ол 1, 4, 9, ..., n * n мәндерін тізім етіп қайтармай, yield арқылы бір-бірлеп беруі керек. main функциясы дайын: ол n-ді сұрап, әр квадратты жеке жолға шығарады.

    Генератор екенін тексеру үшін автотексеруші squares(10**12)-ден бірінші мәнді сұрайды. Тізім құрастыратын шешім мұнда жадқа сыймай қалады, ал генератор бірден 1 береді.

    Өзіңізді тексеріңіз: n = 4 болса, соңғы шығатын сан қандай?

    Кеңес

    Лекциядағы sheep функциясының соңғы нұсқасына қараңыз. Тек range 0-ден емес, 1-ден басталып, n-ді қоса алуы керек.

    Тексеру
    • 3 → 1, 4, 9 (әрқайсысы жеке жолда)
    • 0 → ештеңе шықпайды
    • squares тізім емес, yield қолданатын генератор.

Жоба сізге шынымен қызықты болсын, өйткені оны өзіңіз ойлап табасыз, өзіңіз жоспарлайсыз және өзіңіз жүзеге асырасыз. Ресми тапсырма беті: cs50.harvard.edu/python/project. Талаптарды міндетті түрде сол беттен оқып шығыңыз, ал төменде олардың негізгісін қазақша түсіндіреміз.

    Талаптар

    Жобаңыз Python-да жазылады және мына файлдардан тұрады:

    • project.py - негізгі бағдарлама. Онда main функциясы және кемінде тағы үш функция болуы керек. Ол функциялар класстың ішінде емес, файлдың ең жоғарғы деңгейінде (main сияқты) жазылуы тиіс.
    • test_project.py - сол үш функцияға арналған pytest тесттері. Тест функцияларының аттары test_-мен басталады, мысалы custom_function үшін test_custom_function.
    • requirements.txt - жобаңыз қолданатын pip арқылы орнатылатын кітапханалар тізімі, әрқайсысы жеке жолда.
    • README.md - жобаңыздың сипаттамасы: не істейді, қандай файлдардан тұрады, қандай шешімдер қабылдадыңыз. Ең басында жоба бейнежазбасының URL-сілтемесі тұрады.

    Сонымен қатар жобаңызды көрсететін, ұзақтығы 3 минуттан аспайтын бейнежазба түсіресіз. Барлық файлдар бір папкада болуы керек. Жоба submit50 cs50/problems/2022/python/project командасымен тапсырылады. Бейнежазбаның мазмұны, README ұзындығы сияқты қалған толық талаптарды ресми беттен қараңыз.

    Идеялар

    Не жазарыңызды білмей тұрсаңыз, мына идеялардан бастауға болады. Ең жақсы жоба - өзіңізге не жақыныңызға шынымен пайдалы болатын жоба:

    • Қазақ тілі сөздігі: сөзді енгізсеңіз, аудармасын не мағынасын табады, жаңа сөз қосуға мүмкіндік береді (сөздікті CSV файлда сақтауға болады).
    • Теңге конвертері: теңгені долларға, еуроға, рубльге айналдырады, нәтижені әдемі пішімдеп шығарады.
    • ҰБТ тест жаттықтырушысы: файлдан сұрақтарды оқып, кездейсоқ ретпен береді, ұпайды санап, соңында нәтижені көрсетеді.
    • Латын әліпбиіне көшіргіш: кириллицадағы қазақ мәтінін латын әліпбиіне аударады (сөздікпен немесе тұрақты өрнектермен).
    • Сабақ кестесі: аптаның күніне қарай сабақтарды, үй тапсырмаларын және мерзімдерді көрсететін командалық жол бағдарламасы (argparse пайдалы болады).
    • Үй бюджеті: кіріс пен шығысты тіркеп, айлық есеп шығаратын бағдарлама.
    Кеңес: кішкентайдан бастаңыз

    Алдымен ең қарапайым жұмыс істейтін нұсқасын жазыңыз, сосын бірте-бірте жетілдіріңіз. Функцияларды тестілеуге ыңғайлы етіп жазыңыз: олар input пен print-ке тәуелді болмай, мән қабылдап, мән қайтарсын. Сонда test_project.py жазу оңай болады.

    Тексеру
    • Жоба идеясын таңдадым.
    • project.py-да main және тағы кемінде үш жоғарғы деңгейлі функция бар.
    • test_project.py-да сол үш функцияның тесттері бар, pytest test_project.py өтеді.
    • requirements.txt дайын.
    • 3 минуттан аспайтын бейнежазба түсірдім.
    • README.md жаздым, басында бейнежазбаның сілтемесі бар.
