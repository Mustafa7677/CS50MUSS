Команда фотолары. Файл атауы: `gulzat`, `dastan`, `magzhan`, `merey`, `sagid` + `.jpg` (не `.webp`, `.png`).
Ұсынылатын өлшем: тік 4:5, ені кемінде 640 px, көлемі 300 КБ-тан аз. Файл қосылса, `python3 tools/build.py` оны «Команда» бетіне өзі қояды.
Фото жарияланғанда, оларда көрінген адамдардың өздері келісім берген болуы керек.
